0046 第一章  引言
0047 全国大学生智能汽车竞赛是一项以智能汽车为研究对象的创意性科技竞赛，核心旨在锻炼和提升大学生的综合知识运用能力、工程实践能力与科技创新意识。本次参赛作品为走马观碑组别智能模型车，依据该组别竞赛规则与赛事要求，本参赛队自主设计并制作了一款可自主识别赛道、精准完成碑体识别、稳定自主行驶的智能模型汽车。本次设计的智能模型汽车以龙芯2K0300作为主控核心，依托摄像头实时采集赛道环境、路径及碑体信息，结合PID控制算法对电机与舵机进行闭环控制，在保障车辆行驶速度与稳定性的同时，满足走马观碑组别赛事的识别与行驶要求。
0048 目前，国内外学界在智能车控制、机器视觉、机械结构优化等相关领域已开展大量研究，为本作品的设计与实现提供了充足的理论支撑和技术参考。在智能车控制领域，现有研究提出了基于PID的速度与转向控制方法、适配复杂场景的模糊转向控制策略，同时依托机器视觉的图像预处理、边缘检测、目标与赛道中心线提取等算法，为本次智能车路径导航、碑体识别与运动精准控制提供了核心技术支撑；在机械结构优化领域，关于车模重心配重优化、传感器安装布局优化的相关研究，有效为本车的机械改造、传感器布局调试提供了理论依据与实践指导。本文将围绕本次走马观碑组别智能模型车的整体设计、硬件电路、软件算法、调试优化等核心内容，完整阐述作品的设计思路、实现过程与整体性能情况。
0049 第二章  模型车设计方案
0050 2.1  设计主要思路
0051 本模型车的设计遵循稳定优先、速度其次、逐步优化的原则，整体采用模块化设计思想，将系统分为机械结构、硬件电路和控制软件三个模块，各模块之间通过标准接口连接，便于调试与维护。
0052 在设计思路上，首先确定传感器方案，根据赛道特点选择合适的传感器类型与安装位置；其次设计硬件电路，包括电源管理、电机驱动、信号调理等模块；然后开发控制软件，实现赛道信息采集、决策判断与执行控制；最后通过系统联调与参数优化，提升整车性能。
0053 2.2  技术方案概要
0054 本模型车的系统总体架构如图2.1所示，主要由主控模块、传感器模块、电源模块、电机驱动模块、无刷电调模块和执行机构六部分组成。主控模块负责整体逻辑调度、图像识别算法运算与闭环控制运算；传感器模块集成摄像头、陀螺仪、编码器等器件，采集赛道图像、碑体信息以及车身姿态、车轮转速等车辆状态数据；电源模块为全车逻辑电路与功率器件提供分级稳定供电；电机驱动模块负责驱动转向相关外设，无刷电调模块接收主控控制信号驱动两侧动力电机；执行机构包含左右无刷动力电机，依靠车轮差速实现整车转向与行进运动控制。
0055 图2.1 系统总体架构框图
0056 在控制策略上，采用速度与转向双闭环控制结构。转向环根据赛道识别得到的路径偏差，规划左右两轮目标转速差；速度环对比设定目标车速与编码器反馈的实际车速，同步调节两侧电机输出占空比。双闭环协同运算，动态调整两轮差速大小，实现三轮模型车沿赛道稳定行驶。
0057 第三章  机械结构设计
0058 3.1  车模安装及改造
0059 本模型车以竞赛指定F车模为基础载体，结合三轮车差速行驶控制方案以及全车传感器的布局安装需求，对原车机械结构进行针对性优化与改造。原车基础结构存在重心偏高、外设安装点位不足、轮胎抓地性能适配性差等问题，无法满足车辆高速稳定行驶、精准碑体识别与灵活差速转向的赛事要求。因此本次改造围绕行驶稳定性、结构合理性、传感器采集精度三大核心目标开展，全面优化整车机械布局与硬件搭载结构。整体结构如图3.1所示。

0062 3.1.1 重心优化布置设计
0063 车辆重心高度与重心位置直接决定智能车行驶的平稳性与过弯极限，是影响三轮差速车模动态性能的核心因素。原车重心分布较为分散且整体位置偏高，车辆高速行驶或快速差速过弯时，极易出现车身侧倾、晃动甚至打滑失控等问题。为改善整车动力学性能，本次改造对全车重载器件进行专项布局优化，将电池、主控板等大质量、大体积核心元器件统一布置在车体靠后、低位的安装区域。该布局方式可有效降低整车整体重心高度，同时使重心集中于车体中心
0064 后侧，大幅减小车辆高速过弯时的侧倾力矩，抑制车身抖动与偏移。在提升差速转向稳定性的同时，有效增强车辆直线行驶的抗干扰能力，保障智能车在连续弯道、变速行驶工况下的行驶稳定性。
0065 3.1.2 轮胎适配优化处理
0066 轮胎作为车辆与赛道的唯一接触部件，其摩擦特性与抓地性能直接影响车辆加速、减速及差速转向的控制精度。原车标配轮胎表面纹路较浅、摩擦系数较低，在赛道高速行驶、紧急转向及变速过程中，容易出现车轮打滑、空转等问题，导致车速采集偏差、转向响应滞后，严重影响赛事行驶精度。针对竞赛标准赛道的路面特性，本次对车模轮胎进行专项更换优化，选用适配赛道工况的高抓地轮胎。优化后的轮胎摩擦系数适配性更强，能够有效提升车轮与赛道地面的贴合度与抓地能力，可有效抑制车辆起步加速、差速转向以及制动过程中的车轮打滑、空转现象，提升动力输出的稳定性与转向控制的精准度，匹配三轮差速车模的行驶控制需求。

0082 整车硬件系统由主控板、驱动板、传感器转接板三块电路板组成。各电路板借助铜柱支撑、3D 打印支架与粘接结构固定于车模底盘如图3.6所示，板间通过标准化接插件、排针实现电气互联。布线设计充分考虑电磁兼容问题，功率电源线与弱信号信号线分区走线、相互分离；高速敏感信号做好噪声隔离，降低大电流开关带来的电磁干扰。

0089 4.1.1电源电路设计
0090 本模型车采用3S锂电池供电，额定电压12.6V，容量为3000mAh。电源电路分为主电源和逻辑电源两部分：主电源直接为电机、电调驱动供电，逻辑电源通过稳压芯片转换为3.3V 和5V，为主控板和传感器供电。稳压电路采用SCT2450与RT9013-33GB芯片实现两级电压转换，SCT2450芯片标称持续输出电流5A，为本系统预留充足功率裕量，满足各模块供电需求。在电源输入端增加多级滤波电容，总电容容量为1204.7μF，有效抑制电源纹波，提高系统稳定性；电路额外设计5V上电时序控制电路与电源指示灯，便于硬件调试与状态观测，完整电源电路原理图如图4.3所示。

0092 4.1.2传感器接口电路设计
0093 传感器接口电路依据各类外设的电气特性与通信方式进行针对性设计。本车外设接口涵盖陀螺仪接口、ToF 传感器接口、编码器接口、无刷电调接口、屏幕接口以及尾灯接口等，统一规划信号与电源布线。 针对编码器这类脉冲信号传感器，接口电路串联限流电阻并搭配 RC 滤波网络，抑制传输线路引入的高频干扰，保证测速脉冲信号完整可靠；陀螺仪、ToF 等数字传感器采用 I2C 通信，接口直接引出 3.3V 电源、时钟与数据引脚，匹配器件电平标准；屏幕接口预留多路 3.3V 通信引脚，满足显示屏数据传输需求。所有接口统一划分电源域，区分 3.3V 逻辑电源与 5V 外设电源，避免不同电压器件相互影响，各类传感器与外设接口电路如图4.4所示。

0095 4.2  电机驱动电路设计
0096 电机驱动电路采用两片DRV8701E 栅极驱动芯片搭配TPH1R403NL N沟道MOS管搭建两路独立全桥驱动电路，分别控制左右驱动电机。DRV8701E为外置MOS管栅极预驱芯片，本身不承载大功率电机电流，功率输出能力由外接MOS管决定。电路采用PH/EN控制模式，主控输出方向（PH）与使能（EN）信号，通过调节EN引脚PWM占空比实现电机转速调节。
0097 主控信号先经过SN74HC125PWR三态缓冲器进行信号整形驱动，提升控制信号稳定性，削弱电机侧开关噪声向主控电路传导。电路在功率电源VM输入端配置去耦电容，同时搭配肖特基二极管D4、D5用于吸收电机反向电动势，保护功率器件。DRV8701E内置欠压、过流、过热故障检测功能，便于程序实现故障保护逻辑。驱动电路与主控逻辑共地设计，简化硬件布线；模块搭载LR8347T33电源芯片与状态指示灯，直观观测驱动模块上电状态。完整电机驱动电路如图4.5、图4.6所示。

0100 4.3  负压驱动设计
0101 无刷电调电路以 Ai8051 单片机作为主控芯片，搭配 FD6288Q 栅极预驱芯片与六颗 TPN70R60NL 功率 MOS 管组成三相全桥逆变电路，实现无刷电机驱动控制。电路采用反电动势换相方案，通过分压电阻网络采集三相端电压，完成转子位置检测，无需额外霍尔传感器。
0102 外部电源接入后经多级大容量电容滤波，再通过稳压芯片转换生成 5V 电源，为单片机、预驱芯片等逻辑器件供电。主控接收外部 PWM 调速信号，经由电平转换电路送入 Ai8051；芯片运算输出六路驱动信号至 FD6288Q，经栅极预驱放大后控制三相 MOS 管有序导通，驱动无刷电机运转。电路同时设计电压采集电路实现电池电压监测，搭载 RUN、ERR 状态指示灯方便调试与故障判断，并预留串口接口支持参数调试，完整无刷电调电路原理图如图4.7所示。

0110 第五章  控制软件与算法
0111 5.1  代码设计介绍
0112 控制软件采用分层模块化设计，基于 Linux 多线程框架开发，主要划分如下功能模块：
0113 （1）初始化模块：完成系统硬件资源初始化、参数从 Flash 读取、AI 模型加载、网页图传服务启动、信号捕获函数注册，实现上电硬件自检与程序运行环境搭建。
0114 （2）图像感知模块：独立开辟图像采集线程，持续读取摄像头图像，完成图像预处理、赛道巡线识别、目标碑体检测、AI 模型推理运算，输出赛道偏差、碑体目标信息。
0115 （3）传感器采集模块：在主线程定时轮询读取 ToF、陀螺仪等传感器数据，完成数据预处理，为控制算法提供车身状态信息。
0116 （4）控制算法模块：实现 PID 运算、速度规划、差速转向逻辑，根据视觉与姿态信息计算左右两轮目标输出量。
0117 （5）执行驱动模块：输出 PWM 信号控制左右有刷动力电机，同时驱动负压无刷风机，实现车辆行进、转向与负压吸附控制。
0118 （6）人机交互与调试模块：支持 OLED 菜单在线调参、串口性能数据打印、网页端实时图像传输，并且搭载信号捕获、程序退出清理机制，实现紧急情况下电机安全停机。

0120 5.2  控制理论基础
0121 本模型车的控制系统基于经典控制理论设计，采用PID控制算法实现速度与转向的闭环调节。PID控制器由比例（P）、积分（I）、微分（D）三个环节组成，其控制律如公式1所示：
0122 u(t)=Kp·e(t)+Ki·∫e(t)dt+Kd·de(t)/dt                            （1）
0123 其中，u(t)为控制输出，e(t)为系统偏差，Kp为比例系数，Ki为积分系数，Kd为微分系数。通过合理整定三个参数，可以使系统获得良好的动态响应和稳态精度。
0124 在转向控制中，系统偏差为赛道中心线与车辆中心的横向偏差，PID 输出左右两轮转速差指令；在速度控制中，系统偏差为目标速度与编码器采集的实际速度差值，PID 输出整车基准行驶占空比。两路 PID 控制器独立运算，结合差速驱动逻辑分配左右电机输出，依靠车轮差速实现车辆转向，保证三轮车沿赛道稳定行驶。
0125 5.3  主要算法说明
0126 5.3.1  赛道信息采集与处理算法
0127 赛道信息采集由UVC摄像头完成，采样频率为30Hz。原始数据经过灰度压缩、滤波降噪处理后，提取赛道特征点，计算赛道中心线与车辆的偏差。摄像头传感器图像处理流程包括：图像灰度化、二值化、噪声去除、边缘检测、赛道提取和偏差计算。其中二值化采用固定阈值方法，赛道提取采用迷宫边界跟踪搜线算法。
0128 图5.2 赛道处理算法流程图
0129 5.3.2  转向控制算法
0130 转向控制采用位置式 PID 算法，依据图像处理得到的赛道横向偏差求解左右轮目标速度差值，依靠后轮差速方式实现三轮小车转向。为提高系统响应速度和稳定性，在 PID 基础上增加了输出限幅、异常偏差容错处理。运动控制周期为5ms，通过限制电机最大 PWM 占空比防止电机堵转，结合里程信息实现分段调速，提升直道行驶速度与弯道转向平稳性。
0131 图5.3 转向控制算法流程图
0132 5.3.3  速度控制算法
0133 速度控制采用三环串级 PID 控制架构，由外向内依次为视觉外环、陀螺仪角速度中环、电机速度内环，依靠左右有刷电机差速实现转向，配合负压风机抑制车身抖动，提升车辆高速行驶稳定性。
0134 控制系统以图像识别得到的赛道横向偏差作为外环输入，通过位置式 PID 计算得到车辆期望横摆角速度，运算过程增加积分限幅与输出限幅，防止积分饱和与转向指令过大造成车辆失控。陀螺仪角速度中环接收期望角速度指令，结合陀螺仪采集的车身实际角速度进行闭环运算，输出左右车轮转速差值，能够快速抑制车身瞬时姿态扰动，弥补视觉识别存在的滞后问题。最内层为电机速度闭环，采用增量式 PID 控制左右有刷电机，增量算法仅更新控制量变化值，输出平稳无突变，适配电机 PWM 驱动方式，借助编码器反馈保证车轮转速稳定跟随目标指令。
0135 程序通过pid_init()函数在上电启动、运行模式切换时统一复位全部 PID 积分项与历史误差，清除上一周期运算数据残留，避免车辆启动时发生抖动；系统内置通用限幅函数，对每一层 PID 输出进行范围约束，保证整套控制系统始终在硬件安全区间内运行。

0147 第七章  结论
0148 本参赛队围绕全国大学生智能汽车竞赛要求，完成了智能模型汽车的设计、制作与调试。模型车以龙芯2K0300为主控核心，采用视觉摄像头+姿态传感器+编码器传感器方案，通过闭环PID控制算法实现赛道自主识别与稳定行驶。车辆依靠有刷电机驱动左右车轮实现差速转向，配备无刷风机产生负压吸附车身，减小行驶过程中的车身抖动。经测试，模型车能够在标准赛道上完成全程行驶，最快圈速为________秒，平均速度为________m/s。
0149 在制作过程中，团队在机械结构优化、电路抗干扰设计、控制算法整定等方面进行了深入探索，解决了差速转向控制耦合干扰、负压风机与动力有刷电机协同控制难度大等关键技术问题，积累了丰富的工程实践经验。
0150 然而，模型车仍存在一些不足之处：
0151 （1）高速差速过弯过程中车身仍存在小幅晃动，极限工况下行驶稳定性有待进一步提升。
0152 （2）视觉摄像头在光照剧烈变化场景下，碑体与赛道识别效果容易受到干扰。
0153 （3）整车机械装配存在一定公差，长时间运行后支架螺丝容易出现轻微松动。
0154 针对上述问题，后续可以从以下方向进行改进：
0155 （1）优化控制算法结构，引入前馈控制，削弱速度与转向控制之间的耦合，提升高速过弯稳定性。
0156 （2）完善图像预处理算法，增加曝光自适应调节机制，提升视觉系统对光照变化的适应能力。
0157 （3）在关键连接位置增加防松垫片，优化 3D 打印支架装配结构，提升整车机械结构可靠性。
0158 通过本次竞赛，团队成员在硬件设计、软件开发、系统调试等方面得到了全面锻炼，培养了工程实践能力和团队协作精神。感谢竞赛组委会提供的平台，感谢带队老师的悉心指导。

0577 /**
0578 * @brief 位置式 PID (适用于：视觉环、角度环)
0579 */
0580 float pid_loc_ctrl(PID_STRUCT *pid, float target, float current_val) {
0581 float error = target - current_val;
0582 // 积分累加与限幅 (抗饱和)
0583 pid->integrator += error;
0584 pid->integrator = xianfu(pid->integrator, pid->max_interator, -pid->max_interator);
0585 // 微分计算
0586 float d_term = error - pid->last_err;
0587 // PID 输出计算
0588 pid->out = (pid->kp * error) + (pid->ki * pid->integrator) + (pid->kd * d_term);
0589 pid->out = xianfu(pid->out, pid->out_max, -pid->out_max);
0590 pid->last_err = error; // 更新历史误差
0591 return pid->out;
0592 }
0593 /**
0594 * @brief 增量式 PID (适用于：电机速度环)
0595 */
0596 float pid_inc_ctrl(PID_STRUCT *pid, float target, float current_val) {
0597 // 基础参数保护
0598 if (pid->kp < 0) pid->kp = 0;
0599 if (pid->ki < 0) pid->ki = 0;
0600 if (pid->kd < 0) pid->kd = 0;
0601 float error = target - current_val;
0602 // 增量公式：ΔPWM = Kp*(e1-e2) + Ki*e1 + Kd*(e1-2e2+e3)
0603 // 此处采用简化的微分项实现
0604 pid->out += pid->kp * (error - pid->last_err) +
0605 pid->ki * error;
0606 pid->out = xianfu(pid->out, pid->out_max, -pid->out_max);
0607 // 状态更新
0608 //pid->last_derivative = error - pid->last_err; // 记录 E(k)-E(k-1)
0609 pid->last_err = error;                        // 记录 E(k)
0610 return pid->out;
