0053 引言
0054 智能汽车竞赛发展背景
0055 全国大学生智能汽车竞赛是受教育部高等教育司委托，由教育部高等学校自动化类专业教学指导委员会（现为中国自动化学会）于2005年创办的一项全国性大学生科技竞赛，被列入国家教学质量与教学改革工程资助项目。竞赛以迅猛发展的汽车电子为背景，融合了控制、模式识别、传感技术、电子、计算机、机械等多个学科，旨在通过实践锻炼学生的创新能力和团队协作精神。
0056 历经近二十年的持续发展，竞赛规模不断扩大，参与高校覆盖全国绝大部分省区市，参赛队伍数量逐年攀升，累计参与学生已达相当规模，成为我国高校工科领域最具影响力的赛事之一。2017年，竞赛被纳入中国高等教育学会发布的《全国普通高校学科竞赛排行榜》，成为教育部认可的A类赛事。2020年，主办单位转由中国自动化学会承担，芯片平台也由单一供应商逐步开放为多家厂商并行，进一步激发了技术创新的活力。
0057 经过多年积淀，该竞赛已成为培养我国自动驾驶与智能车辆领域后备人才的重要实践平台，为深化高等工程教育改革、推动产教融合发挥了积极作用。
0058 智能车制作情况
0059 本智能车系统以第二十一届全国大学生智能汽车竞赛为背景，采用F型三轮车模作为整车平台，以龙芯LS2K0300为主控芯片，通过USB彩色摄像头识别赛道元素与障碍物，采用DRV8701E驱动两个RS380直流有刷电机提供驱动力，并利用STC32G12K128制作电调驱动两个无刷电机提供下压力，整车由12.6V锂电池供电。
0060 F型三轮车模采用双电机后轮驱动、前部万向轮导向的结构，行驶方向为万向轮在前、双驱动轮在后。由于没有独立的前轮转向机构，转向完全依靠左右后轮的差速控制实现，这对驱动系统的响应精度和实时性提出了较高要求。在机械布局上，将主控板、驱动电路及电池集中布置于车身后端，使整车重心落于两个后驱动轮附近，以提高转向灵敏度和加速时的抓地力。
0061 主控芯片采用龙芯LS2K0300处理器，该芯片基于龙架构指令系统，主频达1.0GHz，集成丰富的外设接口，支持USB2.0、SPI、I2C、UART、PWM等通信协议，能够满足图像采集、实时路径识别与控制算法对计算能力的需求。摄像头选用USB彩色摄像头，通过USB2.0接口与主控连接，相比传统灰度传感器，彩色图像可提供更丰富的色彩信息，便于识别赛道元素及目标板。图像处理算法在提取赛道边界与中线的基础上，进一步对障碍物和目标板进行颜色特征匹配，实现多目标的综合判别。
0062 电机驱动方面，两个RS380直流有刷电机分别驱动左右后轮，驱动芯片选用DRV8701E，通过驱动外部N沟道MOSFET实现对电机的精确控制，支持宽电压输入并集成过流保护功能。下压力系统由两个无刷电机构成，其电调以STC32G12K128单片机为核心自主制作，该芯片运行速度快、中断资源丰富，能够满足无刷电机六步换相控制的实时性要求。下压力随车速动态调节，在高速过弯时增加下压力以提升轮胎附着力，在直道高速行驶时适当减小以降低能耗。整车采用12.6V锂电池供电。整车的机械结构、电路布局与软件算法的设计均围绕稳定性和响应速度展开，力求在保证赛道识别精度的前提下获得具有竞争力的行驶性能。

0066 系统总体设计方案
0067 设计思路与方案概要
0068 本方案面向全国大学生智能车竞赛走马观碑组需求，基于F型三轮车模平台，设计以龙芯LS2K0300处理器为核心的智能驾驶系统。F型三轮车模采用双电机后轮驱动、前部万向轮导向的结构，转向完全依靠左右后轮差速控制实现，这对驱动响应精度和实时性提出了较高要求。整车采用12.6V锂电池供电，主控芯片为龙芯LS2K0300，摄像头选用USB彩色摄像头完成赛道元素与障碍物的图像采集，两个RS380直流有刷电机由DRV8701E驱动提供驱动力，两个无刷电机配合涵道风扇提供动态下压力，其电调以STC32G12K128单片机为核心自主制作。
0069 系统采用实时视觉检测，通过卷积神经网络识别目标物与障碍物的类型[1]，结合深度学习实现障碍物距离估计与轨迹预测。采用串级PID控制方向，并设计动态避障策略，提升系统鲁棒性。项目充分发挥龙芯LS2K0300处理器的硬件加速特性，通过深度优化OpenCV视觉处理流水线，在单核LA264架构上实现了图像采集、灰度转换、边缘检测等关键任务的高效并行处理。实测数据显示，单帧图像处理时延稳定控制在5毫秒以内，支持高达120帧/秒的高速图像解析能力。在障碍物识别方面，系统采用多模态融合检测策略，基于OpenCV的RGB色彩空间阈值分割技术实现障碍物的快速定位，结合卷积神经网络有效区分赛道边界与障碍物。测试结果表明，系统在1米范围内可稳定识别障碍物的类型，识别准确率达95%以上，为后续避障决策提供了可靠的感知输入。
0070 系统总体架构
0071 系统总体架构分为硬件层、感知层、决策层和执行层四个层次。硬件层以龙芯LS2K0300主控模块为核心，集成USB彩色摄像头、六轴IMU、电机编码器等多类传感器，同时包含DRV8701E双路有刷电机驱动模块以及STC32G12K128无刷电机电调模块；感知层基于OpenCV框架实现图像采集、预处理、特征提取与目标检测；决策层采用串级PID的控制策略，完成路径规划与避障决策；执行层通过DRV8701E驱动RS380电机实现后轮差速驱动，通过无刷电机调节下压力以优化过弯与直道行驶的动态附着力。
0072 软件系统采用模块化设计理念，遵循高内聚、低耦合的架构原则，确保各功能模块职责明确、接口清晰、易于维护和扩展。系统主要由外设初始化模块、参数配置模块、传感器数据采集与融合模块、速度控制模块、视觉感知与目标检测模块和智能控制策略模块等核心模块构成。系统采用协同任务分配，主函数负责图像采集、赛道检测和目标识别，控制任务由定时器中断回调执行，有效利用龙芯处理器的计算资源以提升系统实时性。
0073 车模机械结构与硬件电路设计安装
0074 车模选型与总体机械布局
0075 本项目选用全国大学生智能汽车竞赛指定的三轮F车模作为基础平台。该车模采用前轮万向轮、后轮双驱动差速转向的结构形式，行驶方向为万向轮在前、双驱动轮在后，具有良好的运动灵活性和高速稳定性。由于没有独立的前轮转向机构，转向完全依靠左右后轮的差速控制实现，这对整车重心布局和驱动响应精度提出了较高要求。整车搭载龙芯LS2K0300主控芯片、USB彩色摄像头、DRV8701E电机驱动模块及STC32G12K128电调模块，各部件在车模上的布局直接影响系统的动态性能与可靠性。
0076 为充分挖掘车模的运动潜能并满足竞赛对高速稳定性的要求，对车模进行了以下适配。
0077 （1）重心调整：通过合理布置12.6V锂电池、主控电路板、驱动电路板以及负压风扇等主要部件的安装位置，将整车重心适当后移并降低高度。重心后移使更多载荷落于两个后驱动轮上，有助于提升起步加速时的抓地力和高速过弯时的稳定性；重心降低则有效抑制了车体在高速行驶中的侧倾趋势，减少了因重心偏高导致的失控风险。同时，整车左右两侧的元器件分布力求均衡，确保左右轮在直道行驶时受力一致，避免因偏载引起的跑偏问题。
0078 （2）传感器安装支架：采用轻质高强度的碳纤维杆制作支架，将USB彩色广角摄像头固定于车模前部上方，确保摄像头视野开阔且拍摄角度适宜，能够完整覆盖前方赛道区域。摄像头选用无畸变广角镜头，可有效消除画面边缘畸变对图像识别的干扰，实时捕捉赛道内的路障、目标板等关键元素。支架高度和俯仰角度经过反复调试，兼顾了远距离前瞻视野与近距离赛道细节的清晰度，为图像处理算法提供高质量的原始输入。
0079 （3）电路固定：核心板、主板和电调模块均采用螺丝刚性固定于车模底盘，确保在高速运动和剧烈振动过程中各电路板不会发生松动或移位，避免因接触不良引发的系统故障。功率连接线均采用XT60和XT30插头，信号连接线采用带锁扣的接线端子，有效防止振动导致的连接线松脱，保证了供电与信号传输的可靠性。通过上述机械结构的优化设计，整车在动力响应、视觉感知和系统可靠性方面均得到有效保障，为后续控制算法的稳定运行奠定了坚实基础。

0083 传感器的选型与安装设计
0084 本系统配置了多种传感器以实现全面的环境感知和姿态检测：
0085 （1）USB彩色广角摄像头：作为系统的核心视觉感知传感器，选用高分辨率、高刷新率的无畸变彩色摄像头，实时采集前方赛道图像数据。相较于传统灰度摄像头，彩色摄像头能够提供更丰富的色彩通道信息，使系统可基于HSV色彩空间对赛道中的红色锥桶、蓝色目标板等彩色元素进行阈值分割和特征匹配，有效区分赛道边界与不同类型的目标物，为障碍识别和目标板检测提供关键的视觉依据。摄像头安装于车模前部上方的碳纤维支架上，朝向赛道前方，其安装高度和俯仰角度经过反复标定，确保视野覆盖范围满足竞赛赛道宽度要求，同时兼顾远距离前瞻与近端细节的清晰度。
0086 （2）六轴IMU：选用ST公司的LSM6DSR六轴惯性测量模块，集成三轴陀螺仪和三轴加速度计，用于实时检测车辆的俯仰角、横滚角、航向角以及三个轴向的线性加速度。该模块具备高量程范围和低噪声特性，能够适应车模高速运动过程中的剧烈动态变化。IMU模块刚性安装于碳纤维支架上，在车模几何中心位置，以尽可能减小因车体旋转运动带来的臂杆效应干扰，确保测量的角速度与加速度数据真实反映车体质心处的运动状态。在数据处理层面，采用扩展卡尔曼滤波算法[2]，将IMU姿态数据与轮速编码器反馈进行深度融合，有效抑制单一传感器在长时间运行中的积分漂移和噪声累积问题，显著提升了车模姿态估计的稳定性和位置推算精度。
0087 （3）直流电机编码器：采用1024线正交编码器，分别安装于左右后轮驱动电机的尾部，随电机旋转，用于精确测量电机转速。正交编码器同时输出A、B两路相位差90°的脉冲信号，通过判别两路信号的相位先后关系即可获取电机的旋转方向，结合单位时间内的脉冲计数即可换算得到实时转速。1024线的分辨率在低速段和高速段均能提供足够的测速精度，使速度闭环控制周期可压缩至毫秒级，有效抑制电机加减速过程中的超调与振荡，实现平滑的速度跟踪。
0088 总体电路架构固定与连接
0089 系统电路板采用分层布局设计，以优化整车重心分布并提升电磁兼容性能。龙芯LS2K0300核心板通过排针直接插接于主板上，无需额外的线缆转接，有效减少了信号传输路径上的寄生参数和接触不良风险。主板集成了电源管理、电机驱动、调试按键以及各类外设接口，是整车的电气与控制中枢；主板安装于车模中部，以平衡整车重心。两个无刷电机电调集成于一块独立的电调板上，专门用于驱动负压风扇电机，与主板连接，接收来自PWM信号。
0090 主板在设计上高度集成，单板整合了5V/3.3V稳压电源、DRV8701E有刷电机驱动电路、调试按键及状态指示灯、IMU接口、编码器接口和PWM信号输出接口等功能模块，简化了板间互连，降低了因多板堆叠带来的故障点。电调的功率地线与信号地线在主板采用单点接地方式汇合，避免大电流回路对敏感信号造成干扰。电源线缆采用大截面硅胶软线，确保在大电流工况下线路压降最小化，同时硅胶绝缘层具有良好的耐温性能，适应电机持续大功率输出时的工作环境。
0091 在机械固定方面，主板和电调板均通过减震橡胶垫圈与铜柱支撑相结合的方式刚性固定于车模底盘，既有效吸收了车模高速运动中来自路面的高频振动，又保证了电路板在剧烈加减速和过弯工况下不发生相对位移。各模块间的连接器均选用带锁扣的插头，防止振动松脱。通过上述分层布局、高集成度主板设计以及严谨的机械固定与信号隔离措施，整车电气系统在有限的安装空间内实现了功能分区清晰、功率回路最短、信号干扰最小化，为车模在高速竞赛环境下的稳定运行提供了可靠的硬件保障。
0092 主控电路
0093 主控模块选用龙芯LS2K0300作为智能车的核心控制器。该芯片基于LA264处理器核架构，主频达1GHz，采用高集成度设计。其性能可与ARM Cortex-A53相媲美，具备丰富的外设接口资源（包括USB2.0、LCD显示、I2C、高速SPI、ADC、eMMC、SDIO等），能够高效处理复杂的控制算法并实现多传感器数据融合，为智能车提供稳定的计算支撑。
0094 龙芯LS2K0300处理器基于自主设计的硬件架构，采用完全自主的LoongArch指令集架构。处理器支持图像采集、预处理与特征提取的并行加速处理，使得传统依赖于PC端的视觉算法能够以低于1瓦的超低功耗稳定运行。
0095 针对龙芯LS2K0300的LA264单核处理器架构特性，基于LoongArch指令集深度优化I/O端口驱动程序，设计专用单目摄像头采集电路，通过USB接口实现320×240分辨率@120fps视频流的低延迟传输。使用DMA控制器，使图像数据能够绕过CPU直接写入共享内存池，较传统中断传输方式降低30%的CPU资源占用。
0096 电源部分设计
0097 本车模采用12.6V航模锂电池作为唯一电源输入，经电源管理模块转换后，为系统提供12.6V、5V和3.3V三种供电电压，分别满足不同功能模块的用电需求。
0098 主板上电逻辑由行程开关配合MOS管HY19P03D构成启动电路实现。HY19P03D是一款P沟道功率MOS管，具备低导通电阻和快速开关特性。当用户推动启动按键时，MOS管栅极被拉低而导通，电池电压经MOS管输送至后级电源转换电路，系统上电启动。当需要关机时，推动按键，MOS管关断，整机断电。这种软启动方案既避免了机械开关在大电流工况下触点烧蚀的隐患，又使系统具备断电保护能力，提升了电源管理的安全性和可靠性。
0099 12.6V为电池直接输出电压，主要用于驱动两个RS380直流有刷电机和两个无刷负压风扇电机。该电压处于DRV8701E电机驱动器的宽电压输入范围之内。无刷电机电调同样直接取用12.6V作为功率电源，由电调板上的STC32G12K128控制MOS管三相桥完成换相驱动。

0115 控制软件与算法设计
0116 软件架构与任务调度
0117 系统软件基于龙芯LS2K0300处理器，采用模块化分层设计，遵循高内聚、低耦合的架构原则。整体软件划分为驱动层、感知层、决策层和执行层四个层次。驱动层封装了摄像头、六轴IMU、电机编码器、PWM输出以及GPIO等外设的底层操作，提供统一硬件访问接口；感知层基于OpenCV框架实现图像采集、预处理与视觉特征提取，并完成IMU姿态数据的读取与滤波融合；决策层包含赛道状态机、目标识别状态机、串级PID控制器和绕行决策逻辑，负责根据感知信息做出路径规划与避障决策；执行层将控制量转换为电机PWM占空比和无刷电机转速指令，通过DRV8701E驱动器和电调模块完成车辆运动控制。
0118 系统采用协同任务分配模型，充分利用龙芯LS2K0300的单核计算资源。前台主循环以图像帧率为驱动，负责USB摄像头图像采集、预处理、赛道检测与目标识别，帧率不低于100帧/秒；后台控制任务由定时器中断服务程序触发，周期为5毫秒，负责IMU数据读取、编码器计数、串级PID运算和PWM输出控制。主循环与中断服务程序之间通过共享内存进行数据交换：主循环将计算得到的赛道中线误差、元素状态标志、红色块检测结果等写入共享变量，中断服务程序读取这些数据执行控制运算，同时将当前速度、姿态角等状态反馈供主循环状态机决策使用。这种设计将计算密集型的视觉任务与控制实时性要求高的运动任务分离，前台视觉处理不受中断控制任务的影响，后台控制任务以严格的5毫秒周期锁定执行，既保证了图像处理的高吞吐率，又满足了高速运动下控制响应的实时性要求。
0119 图像预处理与赛道检测算法
0120 摄像头采集的彩色图像首先缩放至160×120分辨率以降低计算负载。预处理流程包括色彩空间转换、高斯滤波和自适应阈值二值化。图像经BGR到灰度图转换后，采用3×3高斯核进行平滑降噪[3]，随后使用大津法计算自适应阈值完成二值化[4]，确保在不同光照条件下均能获得清晰的赛道黑白图像。
0121 赛道边线提取的核心算法为差比和搜索与动态跟踪相结合的方案。首先在二值化图像底部逐列统计连续白点数量，取最大值所在列作为最长白列，该列的顶部行号即为有效搜索截止行。随后从该行向上逐行搜索赛道边界：对每一行，基于上一行已找到的边界位置，在左右各15像素的局部窗口内检测黑白跳变点——当当前像素为白、左侧连续两像素为黑时判定为左边界，当前像素为白、右侧连续两像素为黑时判定为右边界。若局部搜索失败，则从最长白列位置重新执行全局搜索作为兜底策略。边界搜索完成后，系统对左右边线进行平滑处理，消除单像素噪声造成的边界跳动。
0122 为应对十字路口、圆环等元素造成的边界丢失，算法中引入了基于角点检测与几何补线的综合处理策略。系统通过检测边线斜率变化率定位角点：当连续多行的横向位移量发生突变时，判定为角点区域，并根据角点位置关系（左上角点、左下角点、右上角点、右下角点）将其分为四种类型。对于十字路口场景，检测到双侧上下角点后，采用直线插补连接对应角点，恢复丢失的边线；对于圆环场景，利用圆弧内侧的单调转折点配合角点位置，通过贝塞尔曲线拟合生成平滑的圆弧过渡边线，确保车模在圆环内获得连续的路径指引。此外，系统还通过长白列连续性、边界趋势一致性和斜率阈值等指标，综合判定当前赛道为直道、弯道、坡道等不同场景——当搜索截止行接近图像顶部且顶部赛道宽度超过43像素时判定为坡道，当一侧边线斜率小于阈值而另一侧出现大量丢线时判定为大弯道，为后续状态机切换提供依据。

0124 障碍物与目标板识别算法
0125 目标识别模块基于龙邱开源提供的PyTorch框架和NCNN轻量级神经网络推理框架实现。模型结构采用自研轻量级分类器，以深度可分离卷积（Depthwise Separable Convolution）为基本构建单元[5]，在显著降低计算量的同时保持特征表达能力。网络主体由多个DWConvBlock堆叠而成，每个模块包含3×3深度卷积和1×1逐点卷积，配合批归一化与ReLU激活函数。在特征提取后端引入了ECA（Efficient Channel Attention）注意力机制，通过自适应一维卷积核大小的通道注意力加权，以极少的计算开销增强关键通道的特征响应，帮助模型更好地区分相似类别目标。
0126 在训练优化方面，针对实际场景中不同目标板识别难度不均衡的问题，综合采用了三项优化策略：其一，引入Focal Loss损失函数替代标准交叉熵损失，通过聚焦因子自动降低易分类样本的贡献权重，使模型训练重心向难以区分的类别偏移；其二，在数据加载环节对远距离样本施以加权采样策略，提高训练过程中远距离低分辨率样本的出现频率，从而增强模型对远距离目标板的识别能力；其三，在损失函数中引入类别权重参数，对标注样本量较少或易混淆的类别赋予更高权重，进一步平衡各类别间的训练充分度。
0127 模型训练过程依托TensorBoard进行可视化监控，实时记录训练集与验证集的损失曲线和准确率变化趋势，便于及时调整超参数并判断过拟合风险。训练完成后，使用独立的测试集对模型进行综合评价，通过绘制混淆矩阵直观展示各类别间的误判分布情况，并结合精确率、召回率及F1分数对模型性能进行全面评估。此外，利用热力图对模型中间层特征响应进行可视化诊断，分析模型在不同目标类别上的关注区域，验证模型是否聚焦于目标板的关键判别特征而非背景干扰，为模型结构的迭代优化提供方向性指导。
0128 模型输入尺寸为60×60×3，输出层为六分类，涵盖急救包、救护车、枪、手雷、望远镜、装甲车等六个类别。经上述优化策略训练后的模型参数量约56k，具备极高的计算效率。部署阶段通过ONNX作为中间表示，利用onnx-sim工具完成算子融合与图优化，随后转换为NCNN推理框架所支持的fp32模型格式。实测单次推理耗时满足控制周期要求，为车模在高速运动中的实时目标识别提供了可靠保障。
0129 整个目标识别流程分为红色块检测、ROI截取和神经网络推理三个阶段，由独立的状态机管理。
0130 红色块检测采用颜色阈值分割与连通域分析相结合的方案。在160×120图像上逐像素判断RGB通道特征：红色像素的判定条件为R通道值大于60，且R与G的差值大于50，R与B的差值大于40。满足条件的像素在掩膜中标记为白色，其余为黑色，由此生成红色掩膜图像。对掩膜执行8连通域分析，获取所有红色区域的外接矩形、质心和面积信息。为提高检测准确性，系统对每个候选区域进行多级筛选：第一级为面积阈值，筛除面积小于5的噪点区域；第二级为赛道内位置判定，利用红色块底部以下多行的左右边线坐标，判断红色块是否位于赛道有效区域内；第三级结合当前元素阶段（十字、圆环、弯道）对可能造成误触发的红色块进行排除，例如在圆环入口阶段忽略位于环岛弧顶上方非路径前方的红色块，在十字路口阶段忽略位于横向通道上的红色块。这种多级筛选策略有效抑制了环岛红色路肩、十字路口旁侧物体以及急救包颜色干扰等常见误触发场景。
0131 对于通过筛选的红色块，系统进一步计算其二阶中心矩，获取倾斜角度和各向异性特征。倾斜角度通过公式θ=0.5×atan2(2μ₁₁, μ₂₀-μ₀₂)计算，各向异性由协方差矩阵的特征值之比确定。这些特征用于指导目标板ROI的截取：对于倾斜明显且填充率较低的红色块，根据倾斜方向对ROI进行横向偏移补偿，并适当减小纵向偏移量，确保将完整的目标板图像包含在推理窗口内，避免因视角倾斜导致的裁切不全。ROI尺寸根据红色块填充率动态调整，填充率越低则扩大倍数越大，以容纳目标板周围的上下文信息，辅助分类器做出更准确的判断。

0133 神经网络推理的启动时机由状态机精确控制。系统在空闲状态下持续进行红色块检测，一旦检测到有效红色块且其纵向位置足够靠下，表明目标板距离车模约1米以内，即进入接近状态，同时将车速降低至预设的接近速度档位。在接近状态下逐帧跟踪红色块，当红色块面积和纵向位置达到预设阈值时，触发ROI截取并送入神经网络推理。推理结果结合分类置信度判定目标物类型，进而决策绕行方向：武器类目标采取左绕行，急救包与望远镜等物资类采取右绕行，车辆类目标则直行通过。整个识别流程从红色块检测到完成推理的总耗时控制在可接受范围内，确保了车模在高速接近目标板时能及时做出避障决策。
0134 运动控制算法
0135 运动控制采用串级PID架构，从外到内依次为角度环（外环）、角速度环（中环）和速度环（内环）。三个控制环的运算周期均为5毫秒，与定时器中断周期同步，构成了“误差—角度—角速度—转矩”的完整控制链路。
0136 角度环的输入为视觉感知得到的赛道中线误差，该误差由近场、远场和超远场三部分加权融合得到。近场误差取自图像底部71至89行的加权平均值，确保车身当前位置的稳定性；远场误差取自95至112行，用于感知前方约1.5至2米处的弯道趋势；超远场误差取自103至114行，为长直道末端的高速入弯提供更早的预判信息。三者的融合权重λ根据当前车速和弯道曲率自适应调整：λ随车速升高而增大，随弯道趋势增强而增大（弯道提前量由4像素增加至18像素时，λ从0.42增加至0.68）。同时，系统通过判断近场与远场、远场与超远场的误差方向是否相反，识别短连续弯场景并自动降低远场权重，防止因提前看到下一弯道而导致的过冲或振荡。角度环将融合后的误差通过分段PID控制器转换为目标偏航角速度：误差绝对值小于4像素时采用较低比例增益（Kp=3.0）以避免直道振荡；误差介于14至18像素时增益提高至Kp=6.4以增强弯道纠偏能力；误差大于18像素时采用最高增益（Kp=7.6）应对急弯。
0137 角速度环的输入为目标偏航角速度与IMU实测角速度的偏差。IMU的陀螺仪数据在上电后首先经过约1.5秒的零偏校准——采用一阶低通滤波（α=0.02）逐步收敛零偏值，然后以14.3LSB/°/s的灵敏度系数转换为角速度值（单位rad/s）。角速度环采用位置式PID控制，比例增益为20.0，积分增益为1.2，输出限幅为720。环路的输出经过一阶低通滤波后，再经过斜率限制器进行平滑处理——限幅器根据当前误差大小动态调整步长：直道上上升步长0.57、下降步长0.46、过零步长0.51，弯道中分别提升至0.73、0.58和0.64，以避免方向突变造成的车身晃动。
0138 速度环的输入为目标速度与实际轮速的偏差。左右轮编码器为1024线正交编码器，每5毫秒读取一次脉冲计数并清零，通过公式ω=脉冲数/(1024×0.005)×2π换算为角速度（rad/s）。目标速度由基础速度乘以启动斜坡系数和场景缩放系数得到：启动斜坡在前170个控制周期（约0.85秒）内从0.35线性递增至1.0，实现平稳起步；场景缩放系数根据当前元素阶段动态选择——直道正常行驶为1.0，弯道根据曲率降速至0.48~0.70，圆环内降速至0.64，十字路口降速至0.48，接近目标板时根据当前速度降速至0.08~0.34。速度环采用增量式PID控制[6]，并在误差较大时动态提高增益，以提升加减速响应速度。
0139 角速度环的输出经运动学分解得到左右轮目标速度差：Δω=2×ω_yaw×L/(2×R_wheel)，其中L为轮距（0.15m），R_wheel为车轮半径（0.03m）。左右轮目标速度分别减去和加上该差值，与实际轮速比较后送入速度环，输出PWM占空比经死区判断和方向控制后驱动DRV8701E实现电机控制。无刷电机下压力控制采用开环方式，根据车速动态调节PWM占空比：直道高速时提供约40%转速以增加下压力，弯道中根据侧向加速度预测值线性增加至60%~80%，直道低速或停止时降至20%以降低能耗。
0140 赛道元素识别状态机
0141 系统通过有限状态机管理赛道元素的识别与过渡，涵盖十字路口、圆环、坡道和普通弯道等场景。状态机的输入为赛道边线检测结果（丢线统计、角点位置、边界连续性、斜率特征等），输出为当前元素阶段标志，该标志同时用于速度决策和补线策略选择。
0142 十字路口的识别依据双边丢线行数、角点数量和边界连续性三个维度的综合判定。当双边丢线行数超过阈值（15行）且上下角点同时存在、或角点数量达到3个以上且宽度异常行数超过20行、或角点数量为1个但超宽行数超过50行且边界趋势异常时，判定进入十字入口状态。在十字入口状态下，系统通过角点连线恢复丢失的边线，并持续检测边界趋势——当任一侧边线恢复连续且双边丢线行数降至阈值以下时，转入十字内部状态。十字内部状态维持边线补线，同时继续监测角点数量——当双边丢线再次增多且角点数量恢复至2个以上时，转入十字出口状态，直至边线完全恢复连续后退出十字，恢复正常巡线。
0143 圆环的识别利用左侧或右侧边线的单调转折点配合角点检测。以左圆环为例，当右边线连续且近似直线、左边线不连续、检测到左下角点或左上角点与单调转折点同时存在、且搜索截止行在图像上部15行以内时，判定进入左圆环接近状态。接近状态下使用转折点和角点连线补齐左边线，并持续跟踪转折点的下移趋势——当转折点下移至55行以下且左上角点出现时，转入圆环入口状态。入口状态采用贝塞尔曲线拟合生成圆环内侧引导线，并通过15帧的静态中线保持使车模稳定进入环内。进入圆环内部后，系统通过检测对侧边线的转折点判断出口位置——转折点出现后使用直线连接至图像底部，并在丢线恢复后转入出口状态，最终在边线完全恢复正常后退出圆环。
0144 普通弯道的判定基于搜索截止行和边线斜率：当搜索截止行大于20行且一侧边线斜率超过阈值而另一侧出现大量丢线时，判定为弯道，状态保持至搜索截止行恢复至15行以内。坡道检测则利用直道状态下顶部赛道宽度超过43像素的特征进行判定，状态保持约10帧后自动退出。
0145 目标板绕行决策算法
0146 目标板绕行决策由独立的状态机管理，与赛道元素识别状态机并行运行。系统在识别目标板类别后，首先锁存当前赛道元素状态和速度信息，然后将赛道阶段临时切换为正常巡线模式，以防止绕行期间因视觉特征异常而误进入其他元素状态。
0147 绕行决策的核心是场景分类与参数自适应选择。系统根据锁存的元素阶段和绕行方向，通过detect_detour_scene函数将绕行场景划分为九种类型：常规直道绕行、高速直道绕行、弯道外绕、弯道内绕、大曲率外绕、大曲率内绕、十字路口绕行以及相应的速度优化版本。每种场景对应一组预设的绕行参数，包括：外甩偏移量、保持偏移量、固定纠偏值、阶段切换帧数阈值以及各阶段速度档位。
0148 绕行过程分为三个阶段。阶段1将赛道中线偏移至目标板所在侧的边线外侧：左绕行时将中线设定为左侧边线向左偏移offset_err1像素，右绕行时将中线设定为右侧边线向右偏移offset_err1像素，使车模主动远离障碍物。该阶段持续监测红色块位置，若红色块连续丢失超过invalid_cnt_thresh帧，或红色块纵向位置异常跳变，则转入阶段2。阶段2减小偏移量至offset_err2，维持车模在偏离赛道中心但逐渐回归的姿态。该阶段持续frame_cnt帧，帧数阈值由stage2_cnt_thresh控制，该阈值与速度相关以保证在不同车速下绕行轨迹的一致性。若阶段2中检测到视觉串道，系统立即启用固定虚拟中线进行补救，持续一定帧数后恢复。阶段3取消强制偏移，让车模依靠正常PID控制回归赛道中心，同时监测底部多行的中线误差——当平均误差小于30像素或阶段持续时间超过30帧时，判定绕行完成，释放状态锁，恢复原有的元素阶段和速度档位。
0149 在绕行过程中，系统通过编码器累计路程和红色块纵向位置的双重监测确保安全。若累计路程超过预设阈值仍未完成绕行，强制进入下一阶段；若红色块纵向位置在阶段1中异常升高，表明车模可能已经越过目标板，则提前触发阶段切换，避免过度外甩导致的赛道冲出。整套绕行策略在保障避障安全的前提下，最大限度维持了车速和路径连续性，不同场景的参数适配使得车模在直道、弯道、十字路口等不同几何条件下均能完成稳定绕行。

0157 系统调试过程
0158 系统调试过程分为硬件调试、软件调试和系统联调三个阶段。
0159 硬件调试阶段：首先对电源管理模块进行单独测试。验证行程开关配合MOS管HY19P03D构成的软启动电路是否正常工作，确认按下行程开关后系统正常上电、主控锁定信号生效后供电保持。测试SCT2450STER降压电路在不同负载条件下的输出电压稳定性，验证5V输出在电机启停大电流冲击下的波动范围是否满足主控供电要求；测试RT9013-33GB LDO输出的3.3V电源纹波，确保编码器和蜂鸣器获得洁净供电。然后对电机驱动模块进行单独测试：验证DRV8701E栅极驱动器的PWM控制功能，通过改变占空比观察RS380电机转速的线性度；确认方向控制IO的正确逻辑，测试死区设置防止H桥直通。无刷电机电调模块以STC32G12K128为核心，单独调试六步换相逻辑，验证PWM信号对负压风扇转速的线性控制。最后对传感器模块进行单独测试：验证USB彩色摄像头的图像采集质量，调整曝光参数以适应赛道不同光照条件；测试LSM6DSR六轴IMU的数据读取频率和精度，验证上电零偏校准的收敛效果；测试1024线正交编码器的计数方向与电机转向的对应关系，确认A/B相脉冲的准确读取。
0160 软件调试阶段：首先调试外设初始化模块，确保摄像头、IMU、编码器、PWM和GPIO等所有硬件设备能够正常初始化并进入工作状态。然后调试传感器数据采集模块，验证摄像头的图像采集帧率、IMU的数据读取频率和编码器计数清零时序是否满足设计要求。接着调试视觉感知模块：通过调整二值化阈值、高斯滤波核大小、差比和搜索步长等参数，优化赛道边线提取的鲁棒性；针对不同光照条件设置OTSU自适应阈值，确保二值化效果的一致性；调试角点检测和补线算法，通过绘制边线和角点标注验证十字路口和圆环场景下的边线恢复效果；调试红色块检测模块，调整RGB通道差值阈值以平衡检测灵敏度与抗干扰能力，验证连通域分析和赛道内筛选逻辑的有效性。NCNN神经网络推理模块的调试重点在于验证模型加载成功、输入输出张量尺寸匹配以及推理结果的正确性，通过逐帧标注推理结果与人工比对进行准确率评估。控制算法模块的调试借助VOFA上位机完成：首先在车模架空状态下验证速度环的正反转向和PID收敛效果，然后通过串口波形观察角度环的误差跟踪响应和角速度环的抗扰动性能。
0161 系统联调阶段：将各模块整合后进行系统联调。首先在低速状态下测试系统的整体功能，包括赛道循迹、弯道响应、十字路口和圆环通过等。然后逐步提高车速，观察系统在不同速度下的表现，调整角度环分段PID的增益参数和融合权重系数以优化弯道响应速度与直道稳定性之间的平衡。在调试过程中，重点关注以下问题：视觉处理延迟对控制实时性的影响，通过调整图像处理流水线和共享内存锁机制优化同步，确保控制周期严格锁定在5毫秒；多传感器数据融合的时间同步问题，通过统一时基确保IMU姿态数据与视觉误差在同一控制周期内对齐；不同赛道元素下速度档位和绕行参数的自适应调整，通过实车反复测试确定各场景下的最优参数组合。

0188 围绕第二十一届全国大学生智能汽车竞赛走马观碑组赛题需求，设计并实现了一套基于龙芯LS2K0300处理器的智能车视觉导航与避障系统。系统以国产自主龙架构处理器为核心，采用F型三轮车模为平台，完成了从硬件选型、机械改装、电路设计到软件算法开发的全流程设计与调试工作。

0190 在软件层面，系统基于OpenCV开源视觉库和NCNN神经网络推理框架，构建了完整的图像处理、赛道检测、目标识别与运动控制链路。采用协同任务分配实现视觉感知与控制运算的并行执行——以不低于100帧/秒的速率完成图像处理，同时中断以5毫秒周期执行串级PID控制。赛道检测算法通过差比和动态搜索、角点识别与贝塞尔曲线补线，实现了对直道、弯道、十字路口、圆环和坡道的稳定识别与通过；目标识别模块利用颜色阈值分割与轻量化卷积神经网络分类器，实现了对急救包、救护车、武器、望远镜和装甲车等目标板的实时分类与绕行决策。运动控制采用近/远/超远场加权融合的角度环配合角速度环与速度环的三层串级PID架构，结合元素状态机和场景自适应的速度缩放策略，实现了高速循迹与平稳过弯的兼顾。

0192 存在的问题与分析
0193 尽管系统整体运行稳定，但仍有以下不足需要在后续工作中改进：
0194 （1）光照鲁棒性不足。当前视觉算法依赖固定RGB阈值进行红色块检测和OTSU全局阈值二值化，在强光直射、阴影遮挡或赛道光线不均等极端光照条件下，边线提取和目标板检测的稳定性显著下降。虽然OTSU算法具有一定的自适应能力，但对于红色块的RGB阈值仍需人工标定，缺乏动态自适应机制。
0195 （2）圆环与十字路口的通过成功率有待提高。当前元素状态机依赖角点检测和丢线统计进行状态切换，在高速进入圆环或十字时，若车身姿态偏角过大，可能导致角点漏检或边界连续性误判，从而引发状态机切换时机偏差。此外，圆环内部的贝塞尔曲线拟合中线为静态预设，未根据实际入环姿态进行动态调整，存在一定程度的路径偏差。
0196 （3）目标板推理置信度阈值固定。当前模型推理的置信度阈值为固定值0.4，未考虑目标板距离远近对图像清晰度的影响。距离较远时截取的ROI分辨率较低，推理置信度往往偏低，可能导致漏检；距离较近时背景干扰增加，可能出现误分类。固定阈值难以兼顾远距离与近距离的识别需求。
0197 （4）下压力控制为开环方式。当前负压风扇仅根据车速进行开环PWM调节，未引入车模姿态（如侧倾角、横摆角速度）作为反馈，在高速急弯中可能出现下压力响应滞后或过量的情况，影响弯道极限抓地力。
0198 进一步改进方向
0199 针对上述问题，未来可从以下几个方面进行改进：
0200 （1）引入自适应阈值与动态曝光控制。可基于图像全局亮度统计动态调整红色块检测的RGB阈值，或切换至HSV色彩空间结合动态范围自适应调节；同时通过USB摄像头的V4L2接口动态调整曝光时间和增益，使图像亮度稳定在预设范围内，降低光照变化对视觉感知的影响。
0201 （2）优化圆环与十字的状态机判定逻辑。可引入基于历史帧的状态平滑机制，对角点检测结果进行时序滤波，减少单帧误判导致的状态抖动；圆环内部中线可基于入环时的车身姿态进行在线贝塞尔曲线参数调整，使路径更贴合实际行驶轨迹。
0202 （3）引入距离自适应置信度阈值。可根据红色块面积或纵向位置估计目标板距离，动态调整推理置信度阈值——距离较近时适当降低阈值以提高检出率，距离较远时提高阈值以降低误报率。同时可考虑对连续多帧推理结果进行时序平滑，以投票方式输出最终分类结果。
0203 （4）引入下压力闭环控制。可基于IMU测量的侧向加速度和横摆角速度，结合车速估算当前侧向载荷转移量，实时计算所需的下压力目标值，形成负压风扇转速的闭环调节，在提升弯道极限的同时避免直道不必要的能耗。
0204 （5）探索更高效的视觉模型部署方案。当前NCNN推理运行FP32模型，推理耗时仍有优化空间。后续可尝试INT8量化部署，进一步降低推理延迟，为更高帧率的视觉处理留出余量；同时可探索更轻量化的网络结构（如SqueezeNet、MobileNetV3），在保持准确率的前提下进一步提升推理速度。

0412 A.3.3 位置式PID计算
0413 float calculate_pid(PID_Controller &pid, float target)
0414 {
0415 float error = target - pid.actual;
0416 // 积分限幅
0417 pid.integral += error;
0418 float integral_limit = pid.max_output * 0.35f / pid.Ki;
0419 pid.integral = clamp(pid.integral, -integral_limit, integral_limit);
0420 // 微分滤波
0421 float derivative = error - pid.error[0];
0422 pid.filtered_D = pid.filtered_D * (1 - pid.alpha) + pid.Kd * derivative * pid.alpha;
0423 // 输出
0424 pid.output = pid.Kp * error + pid.Ki * pid.integral + pid.filtered_D;
0425 pid.output = clamp(pid.output, -pid.max_output, pid.max_output);
0426 pid.error[0] = error;
0427 return pid.output;
0428 }
