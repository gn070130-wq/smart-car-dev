0063 第一章 引言
0064 智能车是以汽车电子为背景，涵盖控制、模式识别、传感技术、电子、电气、计算机、机械等多学科的科技创意性设计，由主要路径识别、速度采集、角度控制及车速控制等模块组成。其设计与开发涉及控制、模式识别、传感技术、汽车电子、电气、计算机、机械等多个学科，可以分为三大部分：传感器检测部分，执行部分，CPU。
0065 全国大学生智能汽车竞赛以“立足培养，重在参与，鼓励探索，追求卓越”为指导思想，旨在促进高等学校素质教育，培养大学生的综合知识运用能力、基本工程实践能力和创新意识，激发大学生从事科学研究与探索的兴趣和潜能,倡导理论联系实际、求真务实的学风和团队协作的人文精神，为优秀人才的脱颖而出创造条件，是一项鼓励创新的科技竞赛活动。
0066 走马观碑要求在规定的汽车模型平台上，使用龙芯公司的微控制器作为核心控制模块，通过增加图像传感器、电机驱动模块以及编写相应控制程序，制作完成一个能自主循迹同时协同完成赛道的模型汽车。针对任务要求，我们采用灵眼PRO实现赛道循迹，通过模型识别图片确定绕行方向，利用自动控制算法实现车模的运动控制。
0067 本篇技术报告主要从机械、硬件、软件、调试工具等方面，详细的介绍了车模的设计和制作方案，以及我们做车过程积累的经验，希望对以后的参赛选手能够带来启发和帮助。
0068 第二章 车模整体设计
0069 2.1车模机械设计思路和实现技术方案
0070 在本次的比赛过程中我们采用的是F车。F车是三轮车模，考虑到本赛题需要车模有比较强的机动性和稳定性，故对F车模安装负压组件，并且调整重心位置到驱动电机附近。重心在驱动电机附近不仅可以提供足够的下压分力，保证后轮不打滑，同时还保留了一部分分力给前轮，保证起步时不发生严重的翘头现象。在调试过程中发现车模前轮在快速运行时，由于减震弹簧的存在，会加剧整车的晃动造成摄像头画面模糊，针对此问题我们增加了垫片，使弹簧压得更紧，有效解决了过分晃动的问题。为了最大程度提高负压风扇进风量同时保证一个相对来说比较低的重心，我们设计了一个负压支板，利用电机固定位进行固定，有效减小了支架对负压风扇进风口的遮挡面积。

0117 第五章 系统软件设计及算法实现
0118 高效稳定的控制程序和高适应性的算法是智能车快速平稳运行的基础。我们设计的智能车采用龙芯中科公司生产的LS2K0300芯片作为控制器，通过摄像头采集赛道信息，为使小车快速平稳运行，我们使用了编码器测速对小车进行速度闭环。速度和方向控制算法方面，我们采用工业控制广泛采用的经典PID算法，配合理论计算与实际参数调试过程使程序和小车充分契合，使智能车达到快速平稳运行的目的。
0119 5.1控制流程
0120 5.2摄像头处理
0121 5.2.1摄像头数据采集
0122 采用灵眼pro摄像头采集赛道图像。采用大津法进行二值化处理，然后通过最长白列和种子生长法得到赛道边线。对边线进行滤波处理和逆透视变换之后得到赛道中线，用于控制车模行驶方向。
0123 5.2.2 摄像头误差计算
0124 （1）得到赛道中线后，对预瞄点的xy坐标与车身位置计算误差，误差作为转向环PID的输入误差。
0125 5.2.3  识别部分
0126 使用二值化图像判断赛道上是否存在目标板，当赛道中线上存在黑色区域时，对该区域进行处理，可以精准的截取到目标板上的图片，通过训练的模型进行识别处理后判断行驶方式。
0127 5.3 运动控制处理
0128 整体采用图像偏差PID串角速度PID串速度PID的控制方式。
0129 5.3.1 转向、位置控制-位置式PD
0130 将所测得中线偏差经过PD算法控制两轮差速实现转向、位置控制。
0131 位置PD，将偏差的比例（Proportion）和微分（Differential）通过线性组合构成控制量，用这一控制量对被控对象进行控制，这样的控制器称PD控制器。
0132 y=p*er+d*(er-erl)
0133 式中 p为比例项      d为微分项
0134 er为偏差       erl为上一次偏差
0135 （1）微分项d
0136 一般的控制系统，不仅对稳定控制有要求，而且对动态指标也有要求，通常都要求负载变化或给定调整等引起扰动后，恢复到稳态的速度要快，因此光有比例和积分调节作用还不能完全满足要求，必须引入微分作用。比例作用和积分作用是事后调节，而微分作用则是事前预防控制，即一发现y有变大或变小的趋势，马上就输出一个阻止其变化的控制信号，以防止出现过冲或超调等。
0137 d越大，微分作用越强，d越小，微分作用越弱。系统调试时通常把d从小往大调，具体参数由试验决定。
0138 （2）比例项p
0139 p控制按偏差er的比例关系对被控对象进行控制，偏差一旦产生，控制器立即产生控制作用，以减小偏差。当仅有比例控制时系统输出存在稳态误差。p参数越大，比例作用越强，动态响应越快，消除误差的能力越强。但实际系统是有惯性的，控制输出变化后，实际y值变化还需等待一段时间才会缓慢变化。由于实际系统是有惯性的，比例作用不宜太强，比例作用太强会引起系统振荡不稳定p参数的大小应在以上定量计算的基础上根据系统响应情况，进行调试决定，通常将P参数由大向小调，以能达到最快响应又无超调为最佳参数。

0144 第六章 系统开发及调试工具
0145 6.1 VSCode开发工具
0146 开发工具使用的VSCode开发环境，在该软件上可以进行代码的编写以及一些库调用。
0147 VSCode（Visual Studio Code）是一款由微软开发的免费开源代码编辑器，凭借其轻量级、高性能和强大的扩展性，已成为嵌入式开发的主流工具。它支持跨平台开发，通过丰富的插件生态系统（如C/C++、RT-Thread、PlatformIO等）可实现代码智能补全、语法检查、工程管理和硬件调试等完整开发流程，配合GCC/Keil/IAR等工具链，能够高效完成从代码编写、编译构建到烧录调试的全套嵌入式开发工作，其简洁的界面和高度可定制性特别适合嵌入式项目的开发需求。
0148 6.2 MobaXterm远程终端软件
0149 MobaXterm是一款功能强大的远程终端工具，专为开发者和系统管理员设计，集成了SSH客户端、X11服务器、串口终端和网络工具包。它支持多标签页操作，内置SFTP文件传输和宏命令功能，提供便携版和安装版两种形式，特别适合嵌入式开发中的远程调试和服务器管理任务。作为PuTTY的增强替代品，MobaXterm简化了跨平台开发环境配置，大幅提升工作效率。
0150 6.3 下位机调试
0151 在调试过程中需要不断地修改变量的值来达到整定参数的作用，对此我们选用了液晶屏配合按键和拨码开关的调试方法。此外，比赛的时候，修改参数我们同样用这个模块进行修改。
0152 为了实现更加高效率的进行动态调节参数，并且实时地观察麦克风时延和角度以及编码器、陀螺仪的数据，我们设计了模块化的多级菜单系统，实现了对于其余应用接近无感的参数读取与设置。菜单模块支持按键和按键调参作为比较基本的调参形式具有可以在赛场上整定参数、灵活、可靠的优点。
0153 其中液晶屏我们选用 tft 液晶，该液晶具尺寸小，高分辨率等特点。界面自行进行设计。按键采用五向按键其便于操作并且节省空间。设计五向按键进行调参，显示，方案选择等部分。

0837 float angle_abc_degree(
0838 float ax, float ay,
0839 float bx, float by,
0840 float cx, float cy
0841 ) {
0842 // 向量 BA = A - B
0843 float v1x = ax - bx;
0844 float v1y = ay - by;
0845 // 向量 BC = C - B
0846 float v2x = cx - bx;
0847 float v2y = cy - by;
0848 float dot = v1x * v2x + v1y * v2y;
0849 float len1 = sqrtf(v1x * v1x + v1y * v1y);
0850 float len2 = sqrtf(v2x * v2x + v2y * v2y);
0851 if (len1 == 0.0f || len2 == 0.0f) {
0852 return -1.0f;  // 点 A 或 C 与 B 重合，角度无效
0853 }
0854 float cos_theta = dot / (len1 * len2);
0855 // 防止浮点误差导致 acosf 参数超出 [-1, 1]
0856 if (cos_theta > 1.0f) cos_theta = 1.0f;
0857 if (cos_theta < -1.0f) cos_theta = -1.0f;
0858 return acosf(cos_theta) * 180.0f / 3.14159f;
0859 }
