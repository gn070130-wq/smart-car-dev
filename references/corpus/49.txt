0016 摘 要
0017 本文设计了一种以龙芯2K0300为核心控制单元、以STC32G12K128单片机为无刷电调主控的智能车系统。系统通过USB摄像头实时采集赛道信息，采用灰度化处理与动态阈值算法生成二值化图像，并提取黑色引导线，实现赛道识别与路径跟踪。系统利用方向编码器检测车辆实时速度，并通过PID控制算法调节左右驱动电机转速，实现车辆速度与运动方向的闭环控制。针对赛道中央的目标识别任务，系统结合赛道边线检测与逆透视变换，对赛道中的红色色块进行处理，截取赛道中央的目标模型图像，并根据识别结果完成减速、目标识别及绕行等控制。
0018 为提高车辆运行速度与系统控制稳定性，采用上位机、按键模块和IPS114显示屏等调试工具，开展了大量软硬件联合测试。实验结果表明，该系统能够完成预期功能，具有较好的可行性与稳定性。

0083 引 言
0084 全国大学生智能汽车竞赛是以“立足培养、重在参与、鼓励探索、追求卓越”为宗旨，鼓励创新的一项科技竞赛活动。赛题走马观碑要求在F车模上，使用龙芯2K0300作为核心控制模块，通过使用摄像头陀螺仪等传感器获取赛道信息，增设驱动模块，编写相应控制程序，制作出一辆能够自主运行的智能车。
0085 在本次比赛中，本组根据规则使用F车模，采用龙芯2K0300，实现了一套能够自主识别路线和模型的完备系统。
0086 在制作小车的过程中，我们对小车的整体构架进行了深入的研究，分别在机械、硬件和软件上都进行过改进。硬件上主要是改进电路。软件上反复改动控制算法，从PID到串级控制系统,再到模糊PID都进行了一些研究。机械上为了运行更加稳定进行了多轮的改进。
0087 在这份报告中，我们通过对整体方案、机械、硬件、软件等方面的介绍，详细阐述我队在此次智能汽车竞赛备赛过程中的思路想法。我队成员涉及自动化及测控等专业，在准备比赛的过程中，队员查阅了大量的资料，学习各个队伍的经验，反复调试各项参数。所有队员都为此次智能汽车竞赛付出了相当多的努力。
0088 模型车设计思路与技术方案概述
0089 机械设计思路
0090 （1）车身长度尽量缩短，降低转向需要的角速度。
0091 （2）整车重心尽量低，防止车辆运行时跳轮。
0092 （3）整车纵向重心偏向于后轮，保持在后轮轴前端左右，便于转向。
0093 （4）整车横向重心尽量在两轮中心的轴线上，使车辆运行时不易左右晃动。
0094 （5）尽量减小车身前部的重量，减少转向所需转动惯量。
0095 （6）在后轮上方增加负压，增加转向轮摩擦力，便于转向。
0096 （7）前轮将弹簧换成无弹性的3D打印件，防止前轮上下弹动，避免反复翘头。
0097 1.2  硬件设计思路
0098 （1）尽量缩小电路板体积，减小车体重量。
0099 （2）尽量缩小各个电路板之间的距离，使用长度短的通信线和电源线互相连接。
0100 （3）合理布局按键，开关等交互式元器件位置，便于调试。
0101 （4）保障各个模块供电稳定，使用多种稳压方案保持MCU及外设正常使用。
0102 （5）选用大封装电容电阻用于滤波以及单点接地。
0103 1.3  软件设计思路
0104 （1）通过陀螺仪读取加速度与角速度。
0105 （2）通过编码器与图形处理确定电机速度。
0106 （3）通过摄像头采集图像，对赛道的图像进行处理，获得准确的行进路线。
0107 （4）根据获取的路线对小车的转向和速度进行控制。

0139 电路设计说明
0140 3.1 龙芯LS2K0300核心板主控扩展板
0141 图3.1 主控原理图
0142 图3.2 主控PCB图
0143 总述：面向搭载龙芯 LS2K0300 核心板的控制系统，原理图按电源、核心板、传感器、执行器和人机交互功能分区。双路 5V 供电用于降低外围负载对主控电源的扰动。
0144 3.1.1 电池电源
0145 电池电源由XT30（CN1） 接入 VCC_IN。输入端并联 470µF电解电容（C15）及多只滤波电容，用于降低线缆阻抗和开关电源脉动。稳压二极管BZT52C16、HY19P03B与 拨动开关 构成输入保护及开关相关电路，下拉电阻R1、上拉电阻R34 用于栅极偏置和控制节点约束。
0146 3.1.2 5V稳压电路
0147 U2 采用 SCT24500STER 降压芯片。VCC_BAT 经肖特基二极管（SS54）进入输入端，C13（100uF）、C6（4.7µF）和 C7（100nF）滤波；开关节点经 电感（4.7µH）和 C10/C14 输出，再由 肖特基二极管（SS54）形成 VCC_5V，同时防止电源倒灌进芯片引起芯片发烫。R11 与 LED5V 指示5V电源状态。
0148 3.1.3 3V电源电路
0149 使用 RT9013-33GB 将 VCC_5V 稳压为 VCC_3V3。输入侧设置 C11（10µF）和 C3（100nF），输出侧设置 C12（10µF）及 C4（100nF），共同为输入电源和输出电源滤波，使引出的3V电源稳定。R12 与 LED3V3 用于3V电源指示。
0150 3.1.4 核心板
0151 删去空闲引脚，改用排母紧凑排列。同时5V电源为核心板供电前先通过1206封装的100nF和10uF以及1uF的钽电容进行滤波处理，防止核心板因为5V供电不稳引起死机。
0152 3.2 DRV8701驱动板
0153 图3.3 驱动原理图
0154 图3.4 驱动PCB图
0155 总述：电路以 VM 作为电机功率母线，采用“栅极驱动器 + 外置功率 MOSFET”的结构实现两路全桥。每路电机由一颗 DRV8701 和四颗 TPH1R403NL 构成，左右两路拓扑对称。
0156 3.2.1 电源
0157 使用 XT30U-M连接器接入功率电源，正端连接 VM，负端连接 GND。C36（220µF）并联在 VM 与 GND 之间，为两路 H 桥换相和电机启动提供局部储能，并抑制母线电压突变。电池电源 经 电阻（2kΩ）送入 3.3V 节点，经过稳压二极管（BZT52C3V3）对地钳位；R7（1kΩ）与“电源指示”LED 串联到地。
0158 3.2.2 双路H桥电路
0159 左右两路结构一致，每路使用四颗 TPH1R403NL N 沟道 MOSFET：两颗高侧、两颗低侧；两桥臂中点连接电机端子。DRV8701 分别输出 GH、SH 和 GL 信号控制桥臂。高侧漏极接 VM，低侧源极接 GND，桥臂中点输出到电机。
0160 3.2.3 栅极驱动电路
0161 采用 DRV8701驱动芯片。VM 为驱动器功率输入，8701与外部电容组成电荷泵，为高侧 N 沟道 MOSFET 提供栅极驱动；DVDD/VREF 旁路电容稳定芯片内部逻辑与参考节点。
0162 3.2.4 休眠模式
0163 两颗 DRV8701 的 NSLEEP 均连接到拨动开关。开关控制3.3V 与 NSLEEP 控制入口，NSLEEP 同时经 限流电阻（330Ω）连接“使能指示”LED。NSLEEP 有效时两路驱动器工作并点亮指示；无效时进入休眠并关闭栅极驱动输出。
0164 3.3 STC32G12K电调
0165 图3.5 电调原理图
0166 图3.6 电调PCB图
0167 总述：左右通道分别完成控制运算、三相互补 PWM 生成、栅极驱动、六管逆变以及电机状态采样。两侧共用 VBAT 功率母线与 VCC5V 辅助电源，控制和采样网络按通道编号 1、2 分开。
0168 3.3.1 单片机控制
0169 采用 STC32G12K128 系列 LQFP48 控制器。两颗控制器分别连接 PWMAH/PWMAL、PWMBH/PWMBL、PWMCH/PWMCL 六路互补驱动信号，以及 VBATADC、ABMF、BBMF、CBMF、PWM 输入和 LED 网络。VCC5V 通过 0Ω 电阻送入控制器供电端，10µF 与 100nF 电容就近去耦。LPCAP 引脚配置 100nF 电容到地，按原图稳定内部电源/参考节点。LED1、LED2 分别由 VCC5V 经发光二极管与 10kΩ 电阻连接到控制器网络，用于通道状态指示。
0170 3.3.2 PWM输入
0171 左右通道三针输入接口。PWM 信号先经 100Ω 串联电阻进入单片机；VCC5V 经 B5819WS 肖特基二极管引至接口电源脚，另一脚连接 GND。
0172 3.3.3 FD6288D三相栅极驱动
0173 预区输出 HOA/HOB/HOC 与 LOA/LOB/LOC，分别驱动 A、B、C 三个半桥。VCC 接 VCC5V，COM 接 GND；VB1/VS1、VB2/VS2、VB3/VS3 构成三组高侧自举驱动。每个高侧自举支路采用 B5819WS 二极管和 2.2µF 电容，为高侧栅极提供浮动驱动电源。驱动器本地配置 2.2µF 去耦电容；功率驱动电源经 R43/R42（4.7Ω）与 TVS/钳位器件进行滤波和保护。
0174 3.3.4 三相 MOSFET 功率级
0175 每个通道使用六颗TPH1R403NL沟道 MOSFET 组成三相全桥。上管漏极接 VBAT，下管源极接 GND；每组上下管中点形成 VSA、VSB、VSC 三相输出并连接电机端子

0188 4.2 图像处理
0189 4.2.1 图像二值化与基础扫线
0190 摄像头读取320 * 240大小的一帧图像之后先进行裁剪得到60 * 80大小的图像，拷贝进数组之后进行二值化处理。这里我们选用了大津法动态阈值算法，同时针对赛道可能出现的过暗或过曝对二值化阈值进行了专门的处理。在基础扫线部分，由于图像畸变的原因，靠近车的那部分图像较为稳定而远离车的那部分容易受到干扰，所以我们采用了先扫最底边5行找到左右边界得到中线再以底边5行为基准往上找到顶边行的策略。
0191 4.2.2 元素处理
0192 十字：
0193 我们观察道十字的特点是两边的缺口是白色的没有边，我们主要就是把两边的缺口补斜线；补线的思路是找到缺口的上端点和下端点，根据两个端点的横纵坐标能够计算出要补的线的斜率，算出斜率后补线。
0194 圆环：
0195 通过观察我们可知圆环的特点是一边是完整的一条边，而另一边是有两个缺口的边，以此特点我们根据两个缺口丢边数的变化来判断圆环。
0196 路障：
0197 对于路障场景，图像的特点是一边是正常边线；另一边的边线会突然内收，以此特点我们可以找到内收点的横纵坐标偏倚中线进行处理。
0198 坡道：
0199 对于坡道场景，图像上与长直道较为相似，坡道主要的特点集中在顶边行附近的左右边界的宽度比正常赛道宽，以此为特点和其他条件的辅助即可完成坡道的处理。
0200 斑马线：
0201 对于斑马线场景，当初次检测道斑马线后不做任何处理并进行延时防止多次识别，当第二次识别到多个“白黑白“跳变点时判断为终点斑马线。
0202 模型绕行：
0203 对于模型绕行的场景，我们采用了单边巡线的方案，当检测到模型减速之后，将边界直接赋值给中线，同时编码器记录车运行的距离，当距离到达预设值后退出模型绕行状态机。
0204 4.3 速度与转向控制
0205 4.3.1 转向误差的获取
0206 当图像处理完成后将实际中线与理论中线（39）做差得到转向偏差。
0207 4.3.2 三串环
0208 图 3.3 角速度环代码节选
0209 图 3.4 位置环代码节选
0210 图 3.5 速度环代码节选
0211 我们采用了转向环串角速度环串速度环方案，图像处理得到的转向偏差输入给转向环得到目标角速度；目标角速度与陀螺仪采集的实际角速度做差算出angle_out；得到左右轮的目标速度后，左右轮的目标速度输入到速度环中计算出控制电机的占空比完成对电机的控制。
0212 4.3.3 速度决策
0213 速度决策的目的时让车在实际运行时直道加速弯道减速的效果。在进入不同的元素时会对目标速度进行额外处理。

0215 4.3.4 动态前瞻
0216 前瞻行在小车的运行控制方面至关重要，它取决于车到哪里开始计算误差转弯。固定前瞻在车高速运行时会出现路径外切反应迟钝等特点，由此我们采用了动态前瞻的方案。实现的效果是直道时前瞻变远弯道时前瞻变近。

0218 4.4 红块处理与模型识别
0219 4.4.1 数据集采集
0220 我们采集数据集时，采用了识别到红色就保存一次320x240原图的方法，直接保存在板卡的文件夹上，拍摄好之后传输到PC端，使用能够批量处理图片的脚本再做二次处理。这样既能保证拍到的图片是自己需要的，也能便于在PC端上使用脚本反复改进红色截图等处理。只要摄像头高度角度不变，这些原图也能一直用得上。
0221 图 3.8 数据集示意图
0222 4.4.2 模型训练与部署
0223 考虑到模型识别需要，我选择了320x240的摄像头分辨率和逆透视方案，一方面能够使可用像素点更加丰富，另一方面使背景都是蓝白赛道，此外还使不同距离下的图片增添了相似性，有利于模型学习。在制作模型的时候，通过对混淆矩阵、易错图片的观察，以及实车部署与电脑端检验的对比测试，我们逐渐发现在模型中更加注重图片边缘特征和内部纹理有利于模型更好的识别，并且在实车部署时有很大的提升。此外由于车模运动时图片会出现模糊，为了增加鲁棒性，我们做数据增广时加入了一定的模糊处理和色彩变化等处理。在训练时，我们还选择了GPU和租聘服务器加速训练，以便于快速得到结果。为了推理速度更快，我们使用了onnx2ncnn转化，最终实测实车部署16ms左右。
0224 4.4.3 红块处理
0225 考虑到赛题要求识别后绕行，所以这需要我们尽可能缩减循环一次的时间，与此同时增加红块识别的距离。所以在红块识别上，我们花费了很大的功夫来缩减时间和提高截图精度。在缩减时间方面，一开始我们使用的是HSV，但是在测试时，我们发现一帧320x240图像RGB转HSV需要7-8ms，所以最后我们选用了RGB范围判断检测红色来节约时间。在增加识别距离上，我们在60cm处进行模型识别，80cm处进行减速，给控制留足余量。
0226 此外,为了避免红色判断到隔壁的道路上,我们对跑赛道的边线做了反逆透视变换,红色点只在边线内部搜索。
0227 对于路障和模型上的红块,我们通过红色中心点和边线的关系来进行判断,红色路障在边线的外部,而模型红块在边线内,一旦找到足量的红色点就进行区分判断,如果不是路障就进一步判断。
