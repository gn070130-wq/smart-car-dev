# 控制环与调参

真实代码的时序/尺度案例见 [ZouMaGuanBei移植核对](repos/zoumaguanbei/porting-and-debug.md)：5ms轮速回调与逐帧角速度误差计算并非同一时间基准，固定周期参数及帧相关保持量不能无换算搬到另一平台。

## 先画实际闭环

常见三环结构是：图像/路径误差→方向控制→目标横摆角速度→角速度反馈控制→左右轮目标差→独立轮速反馈控制→PWM。方向误差也可能直接给差速，或用几何曲率生成角速度前馈。优先沿用户代码确认，不强制三环。

| 量 | 建议明确的单位和含义 |
|---|---|
| 横向误差 `e_y` | 像素或米，不能混用 |
| 航向误差 `e_psi` | 弧度或度 |
| 横摆角速度 `omega` | rad/s或deg/s，和IMU输出量程一致 |
| 左右轮速 | m/s、轮rpm、电机rpm或周期脉冲数，注明齿比与周期 |
| 执行输出 | 占空比、百分比或硬件计数，注明正负方向与饱和范围 |

工程坐标可约定x向前、y向左、逆时针横摆为正；这仅为推导约定，当前硬件符号要实测映射。轮距为B时：

```text
v = (v_R + v_L)/2
omega = (v_R - v_L)/B
v_L* = v_base - B*omega*/2
v_R* = v_base + B*omega*/2
```

若角速度内环输出已是轮速差，则不要再次乘B/2。若输出定义为完整差 `v_R-v_L`，混合时每侧分配其一半；若定义为半差则直接加减。命名含糊常导致两倍控制量。

编码器换算：先确定计数在电机轴还是轮轴、是否已四倍频、计数器位宽、方向和读取后清零方式。若 `C` 是每轮转的有效脉冲，`D` 是轮直径，`v=ΔN*πD/(C*dt)`。电机轴计数需按实际传动关系换成轮轴计数；不要把1024再固定乘4，SDK可能已转换。

## 离散控制的语义

PID并不要求三项全用。方向PD、角速度P/PI、轮速PI均常见。位置式意味着输出绝对控制量，不意味着被控对象必然是机械位置；增量式也不意味着没有积分累积或绝不会饱和。

若使用连续形式参数，一种离散表达为：

```text
I_k = I_(k-1) + e_k*dt
D_k = (e_k-e_(k-1))/dt
u_k = Kp*e_k + Ki*I_k + Kd*D_k + feedforward
```

固定周期、差分未滤波的增量式可写为：

```text
Δu_k = Kp*(e_k-e_(k-1)) + Ki*dt*e_k
       + Kd/dt*(e_k-2e_(k-1)+e_(k-2))
u_k = u_(k-1) + Δu_k
```

这些是解释公式，不替代用户实现。有些工程已把dt吸收到离散增益；此时再乘除dt会改变控制器。变周期需重新处理系数、滤波和状态，不能机械套用上面的固定周期增量式。

检查输出限幅、积分状态限幅/条件积分/反算抗饱和、微分滤波、目标斜率限制。仅最后钳位PWM不等于积分已防饱和。模式切换、停止、失效后恢复时，按当前工况重置或平滑接续状态；不要每帧复位导致积分永不生效。

外环输出快于新图像到达时，应核查重复误差带来的差分含义；按新帧更新方向环或使用一致时间基准，不能假装同一帧包含新的视觉信息。

## 轮速分配与限幅

大转向和高基准速度同时出现时，左右轮目标可能超出驱动能力。检查是分别钳位、同比缩放还是降低基准速度；它们对路径曲率和平均速度影响不同。急弯的基准速度、轮速差、风扇和电源能力要一起考虑，不能通过无限加大Kp弥补轮胎打滑。

前馈帮助克服可建模负载/目标变化，反馈修正残差。速度目标→PWM的前馈需要标定，量纲不能与速度直接相加。方向曲率前馈常与 `omega_ff=v*κ` 联系，但以实际路径/单位和已有内环接口为准。

## 调参顺序和证据

先确认电机/编码器/IMU符号及时间基准，再在低风险条件下验证轮速内环、角速度环、最后方向外环。执行实车动作以前确认当前操作授权及场地；没有硬件时可完成代码审查、回放和测试。

| 现象 | 优先看什么 | 有证据后可调整什么 |
|---|---|---|
| 单轮阶跃跟不上 | 供电、PWM是否饱和、反馈单位、采样延迟 | 轮速PI/前馈/目标斜率 |
| 轮速稳、角速度跟不上 | 轮距、IMU方向/量程、轮速混合、打滑 | 角速度环与转向能力 |
| 内环稳、直道蛇行 | 中线抖动、视觉时延、外环增益、前瞻 | 方向环、过滤与预瞄 |
| 弯道外切 | 前瞻/可视长度、入弯速度、饱和、轮胎 | 速度规划和路径，再看增益 |
| 出弯后偏置 | 积分残留、状态未退出、路径没恢复 | 复位/抗饱和/恢复条件 |

一次改变一个能检验假设的因素，用相同路线、速度/电量条件比较误差、超调、稳定时间、饱和时长和失败率。不承诺“直道PD小、弯道PD大”对所有工程成立。精确Kp/Ki/Kd必须来自当前单位、周期和响应数据。

## 模糊控制、纯跟踪与LADRC

模糊规则主要是增益调度（15、31、32、44）。核对输入域、归一化、规则表、输出缩放和插值连续性。偏差越大微分越强可能放大噪声，不能无上限提高。

纯跟踪需要统一坐标与有效前瞻点；方向预瞄角经过PID与按曲率几何控制是不同接法。变化前瞻会同时改变误差尺度与响应，不要把参数变化归功于控制器单一因素。

40写有LADRC轮速内环与1ms高优先级调度，可先检索其观测器、控制增益、输入系数、饱和和数据周期。只有写“PID-ADRC”没有给出观测器及扰动补偿接入的18，不能作为已验证实现模板。引入LADRC前先验证现有反馈、算力与离散稳定性；不默认它优于已调好的PI。

资料中的2ms、5ms、10ms仅是案例。5ms=200Hz，100Hz=10ms；52出现两者混写。日志频率不等于控制执行频率，要明确时间戳记录点。
