# 模型连续测试程序

该程序使用 UVC 摄像头、NCNN 模型和逐飞助手 TCP 图像通道，不初始化底盘、电机、编码器、IMU、蜂鸣器或定时器。

红色候选、最长白列动态顶部、距离条件和 `32x32 -> 64x64` 模型框与主工程保持一致。红框满足距离条件后，程序每帧持续推理，不进入绕行状态，也不用 95% 置信度门槛停止输出。

编译：

```bash
cd Seekfree_LS2K0300_Opensource_Library/model_test_demo/user
bash build.sh
```

生成文件：

```text
Seekfree_LS2K0300_Opensource_Library/model_test_demo/out/model_test_demo
```

板端每次启动都会依次提示输入逐飞助手 IP 和红块底边最小行号，并连接固定端口 `8086`。行号直接使用 `160x120` 处理画面坐标，可输入 `0~120`。例如输入 `75`，程序会在红块底边行号 `> 75` 时进行模型推理。

助手画面中白框是选中的红块，黑框是实际模型 ROI。

每次推理都会在终端输出最长白列位置、红框、模型 ROI、底边距离、三类概率、最高置信度和推理耗时。按 `Ctrl+C` 结束。
