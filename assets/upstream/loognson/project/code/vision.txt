# VISION 项目版本日志

## V1.0 (2026/02/24)
- 新增 UVC 摄像头数据采集功能，支持彩色 160*120 分辨率，压缩后转为灰度
- 实现 OTSU 大津法和局部二值化，在 WANT_START_ROW（110）到 WANT_END_ROW（30）之间进行二值化处理
- 加入边界检测算法，采用最长白列 + 迷宫二值化方法，获取边界后计算中线和偏差
- 实现陀螺仪零点漂移校准、角速度环、角度环和偏差环的处理与计算
- 添加 DL1B 数据获取和处理功能
- 支持多种元素识别：十字、斑马线、避障、坡道、环岛
- 实现电机控制、编码器计数和速度环闭环控制
- 加入红色色块判定和模型识别框架
- 添加蜂鸣器、按键和拨码开关支持

## V1.1 (2026/03/11)
- 修复编码器读数方向问题：前进时读数为正数，后退时读数为负数
- 修复 PID 控制无法使用的问题，改进发车限幅逻辑
- 解决发车后轮子先反转后正转的问题
- 优化变量初始化，防止开机时随机数影响系统稳定性
- 修复基础扫线时第一行数组越界的问题

## V1.2 (2026/03/23)
- 新增菜单系统，更新发车逻辑，通过菜单进行发车操作
- 实现识别到斑马线或丢线时自动进入菜单的功能
- 加入模型识别功能，优化十字和环岛的识别及补线逻辑

## V1.4 (2026/05/03)
- 优化模型转向控制和环岛处理逻辑
- 调整模型转向的补偿速度和计数逻辑
- 优化环岛检测和处理的阈值参数
- 修改 TCP 配置和 IP 地址
- 启用斑马线检测功能
- 更新 build.sh 中的远程设备 IP 地址
- 重构速度控制模块，使用中间列常量替代左右列常量

## V1.5 (2026/05/20)
- 优化速度决策算法：
  - 非对称低通滤波（入弯 0.25/0.75，出弯 0.15/0.85），入弯减速及时，出弯加速平滑
  - 直道渐进加速，从弯道速度渐变到直道速度，避免突然窜出
  - 非对称速率限制，减速比加速更激进（-6 vs +3），弯道刹车更快
  - 添加避障场景的速度处理（constant_speed）
- 修复模型转向逻辑：
  - 修正 `return_flag` 分支退出条件，检查 `model_return_angle` 而非 `model_turn_angle`
  - 解决左转后向右大幅转弯的问题
- 优化避障检测：
  - 在 `search_roadblock()` 中加入砖红色像素确认
  - 新增 `count_brick_red_pixels()` 函数检测路障区域颜色
  - 几何判断 + 颜色确认双重校验，降低误检率
- 参数适配：
  - 调整 `differ_Kp1/Kp2/Kd` 与速度决策参数的适配关系
  - 优化 `SPEED_DEAD_ZONE` 和 `CURVE_STEEPNESS` 参数配置
