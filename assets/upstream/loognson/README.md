# Loongson LS2K0300 自动驾驶小车项目

## 项目简介

本项目是基于**龙芯 LS2K0300** 芯片的自动驾驶小车解决方案，实现了完整的视觉导航、模型识别、速度控制和转向控制功能。项目采用 C/C++标准开发，结合 OpenCV、TFLM（TensorFlow Lite Micro）和 ncnn 等深度学习框架，实现高效的实时图像处理和模型推理。

### 核心特性

- **视觉导航**：基于图像处理的赛道边界检测、中线提取、特殊元素的识别
- **模型识别**：TFLite 轻量级模型推理，支持红色色块检测和多数投票过滤
- **双环 PID 控制**：偏差环（外环）+ 角速度环（内环）的级联控制结构，支持陀螺仪微分前馈
- **自适应速度控制**：非对称滤波 + 渐进加速，根据赛道曲率动态调整车速，支持直道/弯道/特殊元素的速度决策
- **多传感器融合**：摄像头 + IMU + 编码器的数据融合

## 主要功能模块

### 1. 图像处理模块 (deal_image.cpp)

#### 1.1 图像预处理

- **自适应二值化**：根据图像亮度动态调整阈值，将灰度图像转换为二值图像（0/255）
- **颜色空间转换**：支持 RGB→HSV→YUV 多空间转换，便于不同场景的颜色滤波

#### 1.2 边界搜索与中线提取

**初始化阶段** (`search_edge_init`)：
- 设置左右边界起始搜索行（`WANT_START_ROW`）
- 初始化边界点、拐点、丢线点等数据结构
- 清空历史边界数据，确保帧间独立

**边界追踪算法** (`search_image_edge`)：
- **最长白列搜索**：在左右边界范围内以 5 像素步长扫描，寻找最长白色垂直线段作为中线参考
- **逐行边界搜索**：从起始点开始，结合预测列和预测行加速搜索，处理边界中断情况
- **拐点检测**：识别边界方向突变点，用于判断十字路口等特殊元素
- **中线计算**：中线列坐标 = (左边界列 + 右边界列) / 2，记录每行中线位置

#### 1.3 特殊元素识别

##### 十字路口检测 (`search_cross_road`)

**检测条件**（需同时满足）：
1. 左右边界均有效（`verge.left_first_point.flag == 1 && verge.right_first_point.flag == 1`）
2. 左右拐点位于图像下方区域（48-106 行）
3. 拐点列坐标靠近中线（左拐点 < 中线+5，右拐点 > 中线-5）
4. 左右拐点行差 < 30 像素（排除弯道误判）
5. 左右拐点列差 > 46 像素（确认路口宽度）
6. 拐点上方 2 行和 5 行均为白色（验证十字路口特征）

**识别流程**：
1. **确定十字高度**：从拐点向上搜索，找到黑色像素点，计算十字路口纵向范围
2. **寻找尖点特征**：
   - 左尖点模式：黑-白-黑-白-白-白-白
   - 右尖点模式：白-黑-白-黑-白-白-白
3. **状态判定**：
   - `cross_flag`：正入十字
   - `cross_left_flag`：左入十字
   - `cross_right_flag`：右入十字

##### 斑马线识别 (`search_zebra_line`)

- 在指定行范围（`ZEBRA_START_ROW` 至 `ZEBRA_END_ROW`）扫描
- 检测黑白相间条纹，统计交替次数
- 条纹数量在 `ZEBRA_MIN_TIMES` 至 `ZEBRA_MAX_TIMES` 之间时判定为斑马线
- 触发减速或停车逻辑

##### 障碍物检测 (`search_roadblock`)

**检测条件**（几何判断 + 颜色确认双重校验）：
1. **几何条件**：
   - 左右丢线行 > `OBSTACLE_JUDGE_ROW`（48 行）
   - 左丢线点列 < 中线-15（左障碍物）或右丢线点列 > 中线+15（右障碍物）
   - 左右丢线行差值 < 5（排除弯道误判）
   - 图像中间区域存在白色像素（确认障碍物）
   - 匹配黑-黑-白-白特征模式

2. **颜色确认**：
   - 统计障碍物区域内的砖红色像素数量
   - 砖红色像素数 > 150（20%阈值）时确认为真实障碍物
   - 避免将赛道边界误识别为障碍物

**避障流程**：
- 设置障碍物标志（`left_roadblock_flag` / `right_roadblock_flag`）
- 使用编码器计算行驶距离
- 行驶超过 `OBSTACLE_DISTANCE`（2800，约 24cm）后退出避障

##### 坡道识别 (`search_ramp`)

- 左右边界宽度均小于 `RAMP_STANDER_WIDTH`（42 像素）
- 在 `RAMP_JUDGE_START_ROW` 至 `RAMP_JUDGE_END_ROW` 范围内连续检测 `RAMP_JUDGE_TIMES` 次
- 坡道行驶距离超过 `RAMP_DISTANCE`（12000，约 1.2m）后退出
- 退出坡道后减速 `RAMP_DECREASE_SPEED`（0.2 倍）

##### 环岛检测 (`search_island`)

**检测条件**：
- 在 `JUDGE_ISLAND_MIN_ROW` 至 `JUDGE_ISLAND_MAX_ROW` 范围内
- 黑白像素转换次数符合阈值
- 白色像素数 > `JUDGE_ISLAND_WHITE_COUNT`（15），黑色像素数 > `JUDGE_ISLAND_BLACK_COUNT`（7）

**处理流程**：
1. **类型 0**：检测环岛入口（左边界附近扫描黑白转换）
2. **类型 1**：确认进入环岛，设置标志位
3. **类型 2**：在环岛内搜索右边界
4. **类型 3**：使用最小二乘法拟合右边界，计算切线参数（斜率 k、截距 b）
5. **类型 4**：沿切线行驶，直至退出环岛

### 2. 模型识别模块 (deal_model.cpp)

#### 2.1 TFLite 模型推理

- **输入**：224x224 RGB 图像
- **输出**：类别概率分布
- **优化**：采用 TFLM 轻量级推理，减少内存占用，适配嵌入式场景

#### 2.2 多数投票过滤

- 连续多帧识别，统计各类别出现次数
- 选择出现次数最多的类别作为最终结果
- 根据投票结果计算识别置信度，降低误识别率

#### 2.3 红色色块检测

- **HSV 颜色空间滤波**：设置 H、S、V 阈值范围，精确提取红色区域
- **形态学处理**：腐蚀去除噪点 → 膨胀连接断裂区域 → 连通域分析识别独立色块
- **重心计算**：计算色块中心坐标（`block_x`, `block_y`）
- **偏移量计算**：计算色块相对于图像中心的偏移，用于转向决策

### 3. 速度控制模块 (speed_control.cpp)

#### 3.1 增量式 PID 控制

```cpp
struct PID_Inc {
    float Kp;       // 比例系数
    float Ki;       // 积分系数
    float Kd;       // 微分系数
    float pin;      // 前馈值
    float set;      // 设定值
    float actual;   // 实际值
    // ...
};
```

**增量式输出公式**：
```
output = Kp * (error - last_error) + Ki * error + Kd * (error - 2*last_error + last_last_error)
```

**积分限幅**：设置积分上限（`ERROR_INTEGRAL = 40`），防止积分饱和

#### 3.2 速度决策策略

采用**非对称滤波 + 渐进加速**的自适应速度控制策略：

**核心算法**：
- **非对称低通滤波**：入弯时权重 `0.25/0.75`（快速响应），出弯时权重 `0.15/0.85`（平滑恢复）
- **指数曲线减速**：`curve = 1.0 - exp(-radio * 3.0)`，偏差越大减速越明显
- **渐进直道加速**：根据偏差值从弯道速度平滑过渡到直道速度，避免突然窜出
- **非对称速率限制**：加速上限 `INCREASE_MAX_SPEED = 3`，减速上限 `DECREASE_MAX_SPEED = 6`，弯道刹车更激进

**速度场景**：

| 场景 | 速度策略 | 说明 |
|------|---------|------|
| 直道 | `STRAIGHT_SPEED = 1.4 × constant_speed` | 偏差 < `SPEED_DEAD_ZONE = 8.0`，渐进加速 |
| 弯道 | `max_speed - (max_speed - min_speed) × curve` | 根据偏差自适应减速 |
| 坡道 | `RAMP_DECREASE_SPEED × constant_speed` | 坡道行驶时减速 |
| 环岛 | `constant_speed` 或自适应减速 | 根据环岛类型调整 |
| 避障 | `constant_speed` | 避障时保持恒定速度 |
| 红色色块 | `MODEL_SPEED = 0.6 × set_speed` | 识别到色块时减速转向 |
| 斑马线 | 减速/停车 | 根据标志位控制 |

#### 3.3 差速控制

- **左轮速度** = 基准速度 + 差速值
- **右轮速度** = 基准速度 - 差速值
- **差速系数**：`DIFFER_SPEED` 可配置

#### 3.4 启停控制

- **发车逻辑**：检测启动信号后，逐渐增加 PWM，使用 `departure` 结构体控制，限制最大 PWM 防止过载
- **停车逻辑**：检测停车信号后，逐渐减少 PWM，使用 `motor_stop` 结构体控制，支持红色色块触发停车

### 4. 方向控制模块 (direction.cpp)

#### 4.1 双环 PID 控制架构

```
图像中线偏差 → [偏差环 PID] → 目标角速度 → [角速度环 PID] → 舵机控制量
     ↑                                          ↑
     └────────────────── 陀螺仪反馈 ────────────┘
```

- **外环（偏差环）**：输入为图像中线偏差（`differ_far`），输出为目标角速度，PID 参数：`differ_dir_outer`，支持按速度档位配置 Kp/Ki/Kd
- **内环（角速度环）**：输入为目标角速度与实际角速度的差值，输出为差速控制量，PID 参数：`gyro_dir_inner`，含近端/远端微分前馈

#### 4.2 陀螺仪数据处理

- **四元数姿态解算**：从 IMU 读取陀螺仪数据，计算横滚角、俯仰角、偏航角
- **低通滤波**：对角速度数据进行滤波，减少高频噪声
- **角速度提取**：计算绕 Z 轴的偏航角速度，用于方向控制反馈
- **转向积分**：在模型转向期间积分累计 `model_turn_angle` 和 `model_return_angle`

#### 4.3 转向控制策略

**基于模型识别的转向**：
- 检测红色色块后，根据色块位置（`model_control.block_x`）计算转向角度：`turn_angle = 30.0 ± model_location_differ`
- 使用陀螺仪积分（`model_turn_angle`）控制转向过程，积分达到目标角度后进入回正阶段
- 回正阶段使用独立积分器（`model_return_angle`）控制，确保准确回正到中线
- **注意**：退出条件需检查对应阶段的积分变量，避免逻辑错误

**转向流程**：
1. **转向阶段**（`turn_flag = true`）：根据色块位置向左/右转，积分累计 `model_turn_angle`
2. **回正阶段**（`return_flag = true`）：反向转向回到中线，积分累计 `model_return_angle`
3. **退出条件**：`|model_turn_angle| > turn_angle`（转向阶段）或 `|model_return_angle| > turn_angle`（回正阶段）

**基于图像偏差的转向**：计算中线与图像中心的偏差，通过双环 PID 控制转向角度，支持坡道、环岛等特殊场景的偏差修正

### 5. 设备管理模块 (device.cpp)

#### 5.1 摄像头初始化

- **UVC 配置**：设置分辨率（188x120）、帧率、曝光时间、图像格式（YUV422）
- **缓冲区管理**：分配图像缓冲区，实现阻塞式图像刷新机制

#### 5.2 IMU 初始化

- **零偏校准**：上电后进行静态校准，计算偏移量并存储
- **数据读取**：通过 I2C/SPI 接口读取加速度计和陀螺仪数据，计算姿态角

#### 5.3 TCP 通信

- **客户端连接**：配置 IP 地址和端口，连接远程服务器
- **数据上传**：实时上传图像、传感器（编码器、陀螺仪）和控制参数（速度、方向）
- **远程控制**：接收指令修改控制参数，支持远程启停

#### 5.4 设备自检

- **硬件检测**：摄像头、IMU、电机、编码器状态检测
- **故障处理**：记录故障信息，提示用户检查，进入安全模式

## 常见问题

### Q1：摄像头图像质量差怎么办？

**A**：调整摄像头曝光时间和增益参数，确保光线充足，避免过曝或欠曝。

### Q2：转向角度不稳定怎么办？

**A**：检查陀螺仪校准是否正确，调整双环 PID 参数，特别是角速度环的比例系数。

### Q3：模型识别误判率高怎么办？

**A**：增加多数投票的帧数，调整 HSV 颜色阈值，优化训练数据集。

### Q4：速度决策感觉不跟手（弯道降速不及时或直道加速太慢）怎么办？

**A**：检查以下参数：
- 入弯/出弯滤波权重：入弯 0.25/0.75 偏大则降为 0.2，出弯 0.15/0.85 偏小则改为 0.1
- `DECREASE_MAX_SPEED`：弯道减速不够狠可加大到 8~10
- `INCREASE_MAX_SPEED`：直道加速太慢可加大到 4~5
- `SPEED_DEAD_ZONE`：直道加速条件触发太难可降低到 5~6

### Q5：模型转向时出现左右摇摆或大幅转向怎么办？

**A**：检查以下问题：
- 退出条件是否检查了正确的积分变量（转向阶段检查 `model_turn_angle`，回正阶段检查 `model_return_angle`）
- `calculate_far_differ()` 中 `turn_flag` 和 `return_flag` 的 `prevent_differ` 赋值是否正确
- 陀螺仪零点漂移是否过大，可在静止时校准

### Q6：如何提高运行稳定性？

**A**：确保电源稳定，增加编码器滤波窗口大小，优化图像处理算法的执行时间。
