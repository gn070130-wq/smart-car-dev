# 【学习摘要】疯狂电路

## 组别
**第 21 届全国大学生智能汽车竞赛 · 疯狂电路**（室内视觉循迹竞速类）

## 硬件栈（共识）
| 模块 | 常见选型 |
|------|----------|
| 主控 | 英飞凌 **TC264**（逐飞库常见） |
| 视觉 | **总钻风 / MT9V03X** 灰度摄像头 |
| 运动 | 两轮**差速**；有刷电机 + 编码器；常配**负压涵道** |
| 姿态 | IMU/陀螺仪 |
| 驱动 | DRV8701 等 H 桥；负压侧 AI8051 电调 |

## 软件架构
帧/主循环：图像阈值→边线/中线→元素状态机→转向 PID/差速→速度闭环；PIT 测速；负压常开或按速联动。

## 核心算法
1. 灰度阈值/自适应阈值  
2. 边线搜索 + 中线拟合/前瞻  
3. 元素状态机（十字/环岛/三叉等，队间差异大）  
4. 转向 PD/串级/模糊 PID + 差速分配  
5. 增量/位置式速度 PID  
6. IMU 辅助阻尼/姿态保护  
7. 负压吸附增强抓地  

## 原有局限
报告为主；完整开源整树稀少；赛道元素与参数强耦合；负压+高速易热/电流饱和。

## 开发模式
已开启：可补代码/重构/改算法；输出原+改后+说明+测试。
