# 疯狂电路 · 完整汇总

## 架构
`摄像头帧 → 阈值/边线/中线 → 元素状态机 → 转向量 → 左右差速速度环 → 电机；负压独立或联动`

入口：主循环处理图像；PIT/定时器测速与速度 PID。配置：阈值、PD、目标速度、元素表速。

## 文件结构（逻辑）
```
vision_*     # 采集、阈值、搜边、中线
element_*    # 十字/环岛/三叉状态机
control_*    # 转向PD、速度PID、差速
imu_* / enc_*
ducted_*     # 负压
ui_*         # 按键/IPS
```

## 算法清单
见 `ALGORITHMS.md`。高频：阈值边线、中线前瞻、元素状态机、差速 PD、速度增量 PID、负压。

## 对比与风险
| 方案 | 优 | 风险 |
|------|----|------|
| 固定阈值 | 快 | 曝光漂 |
| 自适应/大津 | 稳 | 算力/闪烁 |
| 强负压+高速 | 抓地 | 发热、电池压降 |
| 复杂元素机 | 覆盖全 | 误触发卡死 |

现场高频故障：反光丢线、环岛进出时机、编码器噪声、电机饱和、中断里做图像。
