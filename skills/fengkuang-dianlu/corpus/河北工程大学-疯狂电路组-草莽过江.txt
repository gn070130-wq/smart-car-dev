摘    要
“恩智浦”杯全国大学生杯智能汽车竞赛是以“立足培养，重在参与，鼓励探索，追求卓越”为宗旨，促进高等学校素质教育，涵盖了人工智能、传感技术、汽车电子、电气、计算机、机械、自动化多项学科，培养大学生综合知识运用能力和创新意识的一项竞赛活动。随着时间的流逝，小而又神奇的智能车也已在赛场上驰骋十余年。虽然每年比赛的主题与项目会有些不同但是主旋律始终是唯快不破、速度为上，而三轮摄像组别更是赛道上一道靓丽的风景线。
本车使用了C语言与C++进行软件系统的开发，主要包括了：PID控制算法和图像算法。其中PID控制算法使用了分别闭环，也包括了俯仰角平衡控制算法、和转向算法；图像算法以大津法-二值化为主，对赛道、地形等进行了图像判别和处理。此外，本项目还使用了多样的传感器技术，使用了如摄像头、电磁感应、陀螺仪、无线串口等传感器。
该智能车系统以32位的TC264D微控制器作为核心控制单元，使用自行设计的主控制电路板以及相关功能电路板，通过总钻风mt9v03摄像头传感器采集赛道相关数据，处理采集到的赛道左右两边黑色引导线的信息；另外通过编码器实时监测当前速度。同时利用PID程序算法，输出PWM波，驱动舵机打角及电机驱动，以完成智能汽车前进、转弯和停车等过程。最终实现发车过后的系统自动依据路况变化进行闭环操作的功能。实际制作中也存在一系列问题，例如机械结构对智能汽车行驶路径的影响、PID参数对汽车行驶路径的影响等等。从结果而论，在制作智能汽车的过程中，本组发掘出大量经验，收获颇多。
本篇技术报告将从机械结构的调整与优化、硬件系统设计与实现、软件设计及思路、系统开发及调试工具、参数说明与总结多个方面详细介绍准备过程。

第一章 引言
1.1 智能车大赛简介
教育部为了加强大学生实践、创新能力和团队精神的培养，在已经举办全国大学生数学建模、电子设计、机械设计、结构设计等四大竞赛的基础上，委托教育部高等学校自动化专业教学指导委员会举办每年一度的全国大学生智能汽车竞赛。
该赛事与教育部已经举办的四大竞赛一样，都是为了提高大学生的动手能力和创新能力而举办的，具有重大的现实意义。与其他大赛不同的是，这个大赛的综合性很强，是以迅猛发展的汽车电子为背景，涵盖了控制、模式识别、传感、电子、电气、计算机和机械等多个学科交叉的科技创意性比赛，这对进一步培养本科生获取知识、应用知识的能力及创新意识，培养硕士生从事科学、技术研究能力，培养博士生知识、技术创新能力具有重要意义。
1.2 智能汽车制作情况概述
根据竞赛规则及功能要求，本智能车以英飞凌公司的32位单片机TC264D为核心控制器，以CMOS视频传感器MTV034为核心传感器，在组委会提供统一车模平台上，构建完整智能小车系统。小车通过摄像头采集道路图像信息送入单片机，在单片机中对输入的原始图像信息进行处理，提取出赛道的特征信息，据此选择最优行进路线并进行速度的控制。整个系统设计包括车体机械结构设计和软/硬件系统设计。车体机械结构设计主要包括前后轮的调节、PCB板的布局、车身底盘的改装、图像传感器、舵机以及编码器的安装等；硬件电路设计部分主要包括：
(1) 用RT9013-33作为核心芯片的稳压电路，可为系统的各功能模块提供了稳定、可靠的工作电源，为智能车的稳定工作提供了有力的保证；
(2) 采用数字摄像头MTV034对赛道进行检测，通过边缘搜线算法获得黑线位置。
(3) 速度传感器采用的是磁性编码器，构成的测速部分，用以完成对速度的实时测量和反馈控制；
(4) 用MOS搭建的电机驱动电路，驱动电机稳定快速的运行；软件系统设计完成了各功能模块的算法及程序设计，包括图像采集及滤波算法设计、搜索黑线算法及赛道中心求解算法设计以及舵机和电机的PID算法设计。本系统利用开发
工具ADS进行编程开发。这些工具的使用，使得软件的设计编程和调试工作得到了保证。所设计的系统经过测试，赛车能够快速安全的行驶。

第二章 系统总体方案设计
根据大赛的统一要求，须在组委会统一提供的车模平台上，自主选择传感器类型，设计系统硬件电路，开发软件算法。本系统主要包括三个大部分，分别为车模的机械结构、硬件电路系统、软件算法。每一个部分又由各个小模块构成。所以要构建一个完整的小车系统，必须先对各个模块进行论证和设计，在将整个系统组合成一个完整系统，进行系统整体的调试。
2.1 系统总体结构
智能车主要由三个部分组成：检测系统，控制决策系统，动力系统。其中检测系统采用总钻风摄像头，控制决策系统用TC264D作为主控芯片，动力系统主要通过差速控制车辆的转角和直流电机的转速。整体的流程为，通过视觉传感器来检测前方的赛道信息，并将赛道信息发送给单片机。同时，通过磁性编码器构成的反馈渠道将车体的行驶速度信息传送给主控单片机。根据所取得的赛道信息和车体当前的速度信息，由主控单片机做出决策，并通过PWM信号控制直流电机进行相应动作，从而实现车体的转向控制和速度控制。智能车系统总体结构框图2.1如下：

第三章 硬件系统的设计与实现
3.1 硬件设计方案与整体说明
从最初进行硬件电路设计时我们就既定了系统的设计目标：可靠、高效、简洁，在整个系统设计过程中严格按照规范进行。可靠性是系统设计的第一要求，我们对电路设计的所有环节都进行了电磁兼容性设计，做好各部分的接地、屏蔽、滤波等工作，将高速数字电路与模拟电路分开使本系统工作的可靠性达到了设计要求。高效是指本系统的性能要足够强劲。简洁是指在满足了可靠、高效的要求后，为了尽量减轻整车重量，降低模型车的重心位置，应使电路设计尽量简洁，尽量减少元器件使用数量，缩小电路板面积，使电路部分重量轻，易于安装。我们在对电路进行了详细分析后，对电路进行了简化，合理设计元件排列、电路走线，使本系统硬件电路部分轻量化指标都达到了设计要求。

第四章 软件的设计与思路
高效的软件程序是智能车高速平稳自动寻线的基础。我们设计的智能车系统采用CMOS摄像头进行赛道识别，图像采集搜索赛道信息及校正处理就成了整个软件的核心内容。而在智能车的转向和速度控制方面，参考往届的经验，我们使用了经典PID控制算法，配合使用理论计算和实际参数补偿的办法，使智能车能够稳定快速寻线。
4.1 赛道中心线提取及优化处理
4.1.1 原始图像的特点
在单片机采集图像信号后需要对其进行处理以提取主要的赛道信息，同时，由于交叉道、起点线的存在，光线、杂点、赛道远处图像不清楚的干扰，图像效果会大打折扣。因此，在软件上必须排除干扰因素，对赛道进行有效识别，并提供尽可能多的赛道信息供决策使用。
在图像信号处理中我们提取的赛道信息主要包括：赛道两侧边沿点位置、通过校正计算的赛道中心位置，中心点规划面积，赛道变化幅度，赛道类型判别。
由于摄像头自身的特性和远小近大的视觉原理，图像会产生梯形式变形，这使得摄像头看到的赛道信息和实际真实的赛道信息有所区别。因此我们选择了130°无畸变的摄像头作为我们的参赛摄像头，而对于15cm摄像头而言，会产生比较大的梯形畸变，所以可以使用逆透视变换，将图像进行校正。而我们因为摄像头高度低，在逆透视之后，图像的很多特征点都不会有较大改进，故没有使用逆透视变换。
摄像头返回的这个矩阵中，每一个像素点都有一个从0至255的灰度值，值越大表示该像素点越亮，相反，越暗的像素点值就越小。同色间的灰度差很小，而不同色间的灰度差很大，使用二值化可以将图像背景和赛道比较好得分割出来。而为了有一个较好的分割效果，我们采用大津法进行分割，需要注意的是，大津法需要设置阈值下限，不然计算出来的阈值有时候会影响寻迹。
4.1.2 赛道搜线算法
单片机在得到如上矫正后的赛道图像后，就会用搜线算法来对其进行处理，从而确定出赛道两边的黑线在哪儿，并计算出相对应的赛道中线，从而指导舵机转向和电机的加减速。搜线算法的基本思想如下：
(1) 自下而上同时搜索左边线与右边线，找到最底端的中心点 ；
(2) 由底端中心向左一定范围和向右一定范围开始逐点搜索，具体的搜索方式是找黑白跳变点，若找到了跳变点，即是搜索到了黑线，将该行存入对应的存储矩阵，跳入下一行，重复步骤（2）；
(3) 当某行搜索不到黑线时且相邻两行的左右边界列坐标差值大于设定的阈值则判定为拐点，若小于阈值则从下一行的最左侧和最右侧重新开始搜线。
4.1.3 赛道中心的计算
得到完整的赛道信息矩阵后，即可通过一定的算法计算出赛道的中线，由于边线很多时候会发生突变造成中线不够平滑，所以需要对中线进行滤波，保证转向控制的平滑性。
4.2 速度PID算法
众所周知，P是比例，D是微分而I是积分，P的作用类比于弹簧的弹力，距离平衡位置越远时弹力越大因此只有P作用时相当于物体一直在上下震荡，系统不是特别稳定，这时就需要引入D实现阻力的作用，D的反作用力与速度变化的大小成正比，阻止物体靠近与远离平衡位置减小超调量，但是可能会出现在快到平衡位置时外力为零，此时系统一直到不了平衡位置则需要引入I进行误差积分以此消除静态误差，速度的PID算法也是基于此原理上进行计算的。
在车辆的调试中我们发现使用开环控制速度具有很大的不稳定性不仅不能保持各车的速度基本一致且与电池的储电量有极大的关系，这对于车辆之间的通讯与距离的把控是十分不利的于是我们使用PID算法对速度进行闭环控制，通过将期望速度与当前速度的差值当为误差系数，通过误差系数得到确切增量，每次计算后更新前次误差与上次误差并返回得出的实际增量使得车辆的行驶速度哪怕在电池保持极低的电量也能保持一个相对稳定的速度。在不停的发车实践中我们最终确定了稳定的各项系数进行了速度闭环。在车辆行驶中也证实了确实有了优化。
4.3 差速算法
通过差速算法让车辆能稳定地转弯，这样能更快地转弯和提速。

4.4 减速算法
通过车辆的不停调试我们发现简单的直接降速实现速度策略会导致车辆磕头使得车跑的十分不顺畅，极大的影响速度。因此我们使用了根据时间的线性减速，这样减缓了速度减小的陡度，也使得车辆不会过于抖，也不再经常出现磕头的情况。
4.5 元素识别
通过搜线中边界做差与阈值相比较的方式，对干扰元器件进行忽略，大大简化了算法

void Track_Basic_Line(void)
{
    stop_bottom_sum = 0;
    stop_mid_sum = 0;
     Left_Corner_Row = 0;
     Left_Corner_Col = 0;
     Right_Corner_Row = 0;
     Right_Corner_Col = 0;
     Flag = 0;
     a=0;
     DIR_Flag = 0;
     int delta_x_left = 0 ;
     int delta_x_right = 0;



    int start_row = 110;
    int end_row = 10;

    Left_Edge[start_row] = 0;
    for(int col =0;col < 187;col++)
    {
        if(bin_image[start_row][col] == 0 && bin_image[start_row][col + 1] == 255)
        {
            Left_Edge[start_row] = col + 1;
            break;
        }
    }

    Right_Edge[start_row] = 187;

    for(int col = 187;col > 0;col--)
    {
        if(bin_image[start_row][col] == 0&& bin_image[start_row][col - 1] == 255)
        {
            Right_Edge[start_row] = col - 1;
            break;
        }
    }

    Track_Center[start_row] = (Left_Edge[start_row] + Right_Edge[start_row]) / 2;

    //开启滑动窗口
    for (int row = start_row - 1;row >= end_row;row--)
    {
        //根据上一行的搜线 向外移动X列
        int search_left_start = Left_Edge[row + 1] - SEARCH_OFFSET_X;
        int search_right_start = Right_Edge[row + 1] + SEARCH_OFFSET_X;

        //防止越界
        if(search_left_start < 0) search_left_start = 0;
        if(search_right_start > 187) search_right_start = 187;

        Left_Edge[row] = 0;
        Right_Edge[row] = 187;
        //从左侧向右
        for (int col = search_left_start; col < 187; col++)
        {
            if (bin_image[row][col] == 0 && bin_image[row][col + 1] == 255)
            {
                Left_Edge[row] = col + 1;
                break;
            }

         }
        //从右侧向左
        for (int col = search_right_start; col > 0; col--)
        {
            if (bin_image[row][col] == 0 && bin_image[row][col - 1] == 255)
            {
                Right_Edge[row] = col - 1;
                break;
            }

         }
        if(row < start_row - 4)
        {
            delta_x_left  = Left_Edge[row] - Left_Edge[row + 5];
            delta_x_right = Right_Edge[row] - Right_Edge[row + 5];

           // 抓左拐点
           if (abs(delta_x_left) > CORNER_THRESHOLD && Left_Corner_Row == 0) {
              Left_Corner_Row = row;
              Left_Corner_Col = Left_Edge[row];
              Flag++;
              DIR_Flag = 5;
            }

           // 抓右拐点
           if (abs(delta_x_right) > CORNER_THRESHOLD && Right_Corner_Row == 0) {
              Right_Corner_Row = row;
              Right_Corner_Col = Right_Edge[row];
              Flag++;
              DIR_Flag =5;
              a=abs(delta_x_right);
            }
            delta_x_left  = Left_Edge[row] - Left_Edge[row + 3];
            delta_x_right = Right_Edge[row] - Right_Edge[row + 3];

               // 抓左拐点
               if (abs(delta_x_left) > CORNER_THRESHOLD && Left_Corner_Row == 0) {
                  Left_Corner_Row = row;
                  Left_Corner_Col = Left_Edge[row];
                  Flag++;
                  DIR_Flag = 3;
                }
               // 抓右拐点
               if (abs(delta_x_right) > CORNER_THRESHOLD && Right_Corner_Row == 0) {
                  Right_Corner_Row = row;
                  Right_Corner_Col = Right_Edge[row];
                  Flag++;
                  a=abs(delta_x_right);
                  DIR_Flag =3;
                }
                if (row >= 15 && row <= 90 )
                {
                    // --- 检测右侧屏幕边缘 ---
                    if (Right_Corner_Row == 0)
                    {
                        int right_edge_flag = 0; // 定义屏幕右边缘累加标志

                        for (int col = 187; col > 187 - 15; col--)
                        {
                            // 寻找单纯的上下黑白跳变点
                            if (bin_image[row][col] == 0 && bin_image[row + 1][col] == 255)
                            {
                                right_edge_flag++;
                            }
                        }

                        // 累加防误判，只有真实的横向路口延伸才会满足
                        if (right_edge_flag >= 3)
                        {
                            Right_Corner_Row = row;
                            Right_Corner_Col = Right_Edge[row + 1];
                            Flag++;
                            DIR_Flag = 88;
                        }
                    }

                    // --- 检测左侧屏幕边缘 ---
                    if (Left_Corner_Row == 0)
                    {
                        int left_edge_flag = 0; // 定义屏幕左边缘累加标志

                        for (int col = 0; col < 15; col++)
                        {
                            // 寻找单纯的上下黑白跳变点
                            if (bin_image[row][col] == 0 && bin_image[row + 1][col] == 255)
                            {
                                left_edge_flag++;
                            }
                        }

                        // 累加防误判，只有真实的横向路口延伸才会满足
                        if (left_edge_flag >= 3)
                        {
                            Left_Corner_Row = row;
                            Left_Corner_Col = Left_Edge[row + 1];
                            Flag++;
                            DIR_Flag = 88;
                        }
                    }
                }




        }
        Track_Center[row] = (Left_Edge[row] + Right_Edge[row])/2;

    }
    }

void Two_col_detect(void)
{
    int row, col;
    Current_Node_Type = NODE_NONE;

    if(Vision_Enable_Flag != 1) return;

    // 搜索每一行，寻找符合特征的横向跳变点
    for(row = 118; row >= 20; row--)
    {
        // 1. 屏幕右侧固定检测区间 [173, 187]
        // 这里完全脱离了 Right_Edge[row] 的动态约束，强制检测边缘
        int right_conduct_flag = 0;
        for(col = 187; col >= 173; col--)
        {
            // 寻找真实的上下黑白跳变（支持正跳变和反跳变，过滤噪点）
            if((bin_image[row][col] == 0 && bin_image[row + 1][col] == 255) ||
               (bin_image[row][col] == 255 && bin_image[row + 1][col] == 0))
            {
                right_conduct_flag++;
            }
        }

        // 必须在边缘固定区域凑够跳变点才判定为路口拐点
        if(right_conduct_flag >= 3)
        {
            Current_Node_Type = NODE_T_ANY;
            Right_Corner_Row = row;
            Right_Corner_Col = 187; // 固定在边缘

            return;
        }

        // 2. 屏幕左侧固定检测区间 [0, 15]
        // 这里完全脱离了 Left_Edge[row] 的动态约束，强制检测边缘
        int left_conduct_flag = 0;
        for(col = 0; col <= 15; col++)
        {
            if((bin_image[row][col] == 0 && bin_image[row + 1][col] == 255) ||
               (bin_image[row][col] == 255 && bin_image[row + 1][col] == 0))
            {
                left_conduct_flag++;
            }
        }
        if(left_conduct_flag >= 3)
        {
            Current_Node_Type = NODE_T_ANY;
            Left_Corner_Row = row;
            Left_Corner_Col = 0; // 固定在边缘

            return;
        }
    }
}

int Get_Map_Direction(void)
{
    int current_order;
    //检测到的路口过多 停车
    if (Current_Node_Index >= TOTAL_NODES)
    {
        return DIR_STOP;
    }

    current_order = Route_Map[Current_Node_Index];//读取当前路口转向方向

    Current_Node_Index++;

    return current_order;
}
