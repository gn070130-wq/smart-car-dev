第一章 引言
1.1 制作背景与任务概述
本项目面向第二十一届全国大学生智能汽车竞赛“疯狂电路智能车”赛题，围绕赛道环境完成模型车的感知、决策与执行系统设计。为形成便于调试和复用的控制平台，本车以 TC264DA 微控制器为控制核心，采用 16 路模拟光电循迹板完成赛道信息采集，并配置六轴惯性测量单元接口、双直流电机驱动通道、显示与按键等人机交互接口；硬件原理图所示的信号与电源网络构成了后续机械安装和软件控制的基础。[1]
1.2 技术路线与报告结构
系统采用光电管循迹与惯性导航融合的跑图方案。16 路模拟光电循迹板检测赛道横向位置，IMU 连续测量角速度和车体运动状态；TC264DA 依次选通 A0-A15 完成 ADC 采样，结合惯性航向进行赛道状态判断、路径跟踪和速度规划，再通过 PWM 与方向信号控制左右电机。[1-3]
第二章说明总体方案与信息流；第三章说明控制、供电、驱动和接口；第四章说明软件模块和控制算法；第五章说明开发、制作、安装和调试；第六章列出主要技术参数；第七章给出结论。

第二章 总体设计方案
2.1 设计目标与总体思路
控制板的总体目标是在有限车载空间和电池供电条件下，为赛道信息采集、姿态测量、电机执行和调试显示提供统一的硬件接口。设计中将主控、传感、驱动与电源网络分开组织：16 路模拟光电板通过四根地址线和一根模拟输出线接入主控，IMU 通过 SPI 连接，左右直流电机分别由独立驱动器控制；电池输入经多级稳压后形成不同电压域，以降低各模块之间的相互干扰。

3.1.3 结构设计考虑
机械结构设计以稳定承载、减小质量和便于调整为主要考虑。侧板和底板共同形成车体的基础承力框架，连接孔和长圆孔既用于固定结构件，也为板卡位置和安装间隙的微调提供条件。底板采用开孔和框架化布局，在不影响主要连接位置的前提下减少非必要材料，使电机、车轮、电池和电路板能够在有限空间内分区布置。
车体内部的器件布置遵循重心集中和受力路径清晰的原则。电池、主控 PCB、驱动模块和电机尽量布置在底板及主板安装板形成的稳定区域内，避免线束或板卡悬空；16 路光电板安装在车体前端，保证检测范围覆盖车头前方，并通过安装孔保持横向方向与车体基准一致。这样的层级布置有利于减少车体运动对传感器安装姿态的影响。
维护与安全方面，结构件采用可拆卸连接，主控板和光电板均保留插拔及检修空间。线束沿板件边缘或支撑件固定，并与车轮、齿轮和电机转动区域保持避让；安装完成后应复核螺钉紧固、接口锁止和板卡边缘间隙。调试或更换模块时，可以按照光电板、主控板、电源和驱动器的功能分区逐项拆装，减少对其他连接的影响。
3.2 电路设计说明
主控制器采用 Infineon TC264DA（U17），外接 20 MHz 晶振 X1，并引出 TMS、TCK、TRST、P21.7 等 JTAG 调试信号。原理图还包含 DBTX/DBRX 串口调试网络，可用于输出运行状态、采集关键变量或进行现场故障定位。主控的模拟输入端用于电池电压采集，BATADC 的换算系数应使用实测基准电压完成标定。[1,5]
16 路模拟光电循迹板采用四位地址选通和一路模拟输出的连接方式。AS 模拟输出接至 D7/P00_7/ADC3_CH5；S0、S1、S2、S3 分别接至 D6/P00_6、D5/P00_5、D4/P00_4、D3/P00_3。读取第 n 路（n=0..15）时，必须按 S3=(n>>3)&1、S2=(n>>2)&1、S1=(n>>1)&1、S0=n&1 设置地址，在地址稳定后读取 D7 的 ADC 原始值。A0 至 A15 在物理上从左到右排列，不允许因软件处理而重排。

4.2 光电管循迹处理
光电循迹首先对 A0-A15 逐路采样，并使用每一路独立的暗场/亮场标定值将 ADC 原始值归一化为响应 q_i。归一化后根据加权中心计算横向误差 e_y，同时统计响应总量、有效通道数、峰值和相邻通道连续性，形成 0~1 的观测置信度。置信度不足时不直接把异常值送入转向控制，而是交给融合滤波器进行门控。
光电观测采用固定的物理顺序：n=0 对应最左侧 A0，n=15 对应最右侧 A15。每次地址切换后先等待采样保持时间，再读取 D7/P00_7/ADC3_CH5。对突发饱和、单通道异常和失线情况分别设置有效性阈值，只有满足总响应、峰值和有效通道数条件的观测才参与后续校正。
S3:S2:S1:S0 = ((n>>3)&1):((n>>2)&1):((n>>1)&1):(n&1),  n=0,...,15	公式1
e_p = sum(w_i * q_i) / sum(q_i),  i=0,...,15	公式2
式中，w_i 为从左到右单调递增的位置权重，q_i 为第 i 路光电管的标定响应，e_p 为光电横向偏差。光电有效性由有效通道数量、响应总量和分布连续性共同判断，避免单个通道突变直接改变转向输出。
4.3 惯性导航与融合跑图
惯性导航以 LSM6DSV16X 的 Z 轴角速度为短时航向预测量。控制周期开始时先扣除估计的陀螺零偏，再通过离散积分得到航向误差预测；光电管提供的横向误差作为外部观测，对预测状态进行校正。这样可以在光电响应短时减弱时保持运动连续性，同时利用光电观测抑制陀螺积分漂移。
融合状态定义为 x=[e_y, psi_e, b_g]^T，分别表示横向误差、相对赛道切线的航向误差和 Z 轴陀螺零偏。状态预测模型为 e_y(k+1)=e_y(k)+v sin(psi_e)Delta t，psi_e(k+1)=psi_e(k)+(omega_z-b_g)Delta t，b_g(k+1)=b_g(k)。光电横向误差作为标量观测 z=e_y，通过三状态扩展卡尔曼滤波更新状态和协方差。
预测模型中的车速 v 由车速估计接口提供，该接口使用电机输出与实车速度标定关系计算当前速度。光电管位置接口返回以阵列中心为零、左负右正的实测坐标，使光电观测与惯性预测统一使用米制单位。
滤波更新加入三倍标准差创新门限：当光电观测与预测状态的差异超过门限时，认为可能存在反光、遮挡或单通道异常，本周期只进行惯性预测，不强行修正航向。观测噪声 R 随光电置信度自适应变化，置信度越高，光电校正权重越大；连续失线时降低基础速度并限制转向量，光电恢复后再逐步恢复闭环控制。
psi_k = psi_(k-1) + (omega_z,k - b_z) * Delta_t	公式3
融合跑图以光电偏差为主要闭环量，以惯性航向为连续运动约束。光电信息有效时，系统依据 e_p 跟踪赛道中心，并利用航向变化识别弯道阶段；光电响应短时减弱或赛道特征过渡时，系统保持惯性航向连续性，抑制转向量突变。光电信号恢复后重新以赛道中心偏差校正车辆路径，避免陀螺仪积分误差长期累积。

4.4 跑图控制输出
跑图控制使用融合后的横向误差 e_y、航向误差 psi_e 及横向误差变化率生成差速控制量 u=k_e e_y+k_psi psi_e+k_d de_y/dt。直道阶段保持较高基础速度，进入弯道时根据航向误差和光电置信度降低基础速度；输出端进行幅值限幅、变化率限制和故障关闭，最后转换为左右电机 PWM_L/DIR_L 与 PWM_R/DIR_R。
控制器的参数整定顺序为先调整光电观测标定和滤波噪声，再调整横向误差比例项，最后加入航向误差和误差变化率项。调试时同时记录 e_y、psi_e、b_g、观测置信度和左右 PWM，避免只根据车模表面现象修改单一参数。
4.5 异常观测与失线恢复
当光电观测无效、创新门控拒绝观测或 IMU 通信异常时，系统进入降级状态。IMU 正常而光电失效时保持最近一次有效航向趋势，降低基础速度并限制最大转向；IMU 或驱动故障时立即关闭电机输出。光电连续有效若干周期后，采用渐增校正权重恢复闭环，避免从失线状态突然跳变到大转向。
一个完整控制周期按“采集—观测—预测—校正—控制—记录”的顺序执行：先按 A0-A15 扫描光电管并读取 IMU，再由 Track_Observe 生成横向观测和置信度；FusionEkf_Predict 使用车速与陀螺角速度进行短时预测，FusionEkf_UpdateOptical 在观测有效且创新通过门控时修正状态，最后 Track_Control 将融合误差转换为左右电机差速。这样，光电负责绝对位置约束，惯导负责短时连续性，故障状态由同一周期统一处理。

第五章 制作、安装与调试
5.1 开发工具
程序开发环境包括 IDE、编译器、JTAG 下载工具和串口调试工具；程序下载与在线调试通过 JTAG 接口完成，串口用于输出运行状态和关键调试数据。
软件调试按照“底层接口、传感器采集、状态估计、运动控制”的顺序分层进行。首先分别验证 GPIO、ADC、SPI、PWM 和串口，再检查光电扫描、IMU 更新及电机输出。串口重点输出 A0-A15 原始值、横向偏差、Z 轴角速度、航向量和左右轮 PWM，便于将程序计算结果与车模实际运动进行对照。
5.2 制作与安装过程
整车制作从电路板和结构件检查开始。电路板完成焊接后，首先检查电源输入端、各级供电网络和地之间是否存在异常连接，并在不连接电机的条件下进行分级上电。确认主控下载、串口输出以及 5 V、3.3 V 和 1.3 V 供电正常后，再依次接入光电循迹板、IMU、电机驱动和显示调试接口。
机械安装以底板、侧板和主板安装板为基准。16 路光电循迹板固定在车体前端，传感器面朝向赛道并保持横向布置；主控 PCB 固定在主板安装板上，接口方向为排线插拔和后续检修留出空间。电池及动力线束靠近车体内部布置，传感器排线沿支撑件固定，避免与车轮、齿轮和电机转动部件接触。
接线完成后逐项核对接口关系：光电板的 S3:S2:S1:S0 对应 D3:D4:D5:D6，AS 模拟输出接入 D7/P00_7/ADC3_CH5；IMU 按 SPI 信号和中断引脚连接；左右电机分别接入对应驱动输出。接口、极性和紧固件检查完成后，先进行抬轮空载测试，再进入整车低速联调。

5.3 调试过程与结果
调试遵循“先静态、后动态，先单模块、后整车”的原则。上电阶段先断开电机负载，检查各级电源和主控运行状态；随后通过 JTAG 与串口确认程序能够稳定执行，并观察采样周期、通信状态及故障标志。单项功能正常后，再逐步接入传感器和执行机构。
光电循迹板调试时，按 A0-A15 的固定顺序逐路读取 ADC 原始值，核对 S3:S2:S1:S0 地址与物理位置是否一致，并比较赛道背景与边界条件下的响应变化。对各通道进行基线和幅值校正后，再计算横向偏差，避免通道一致性差异直接引起转向抖动。
IMU 调试先在车体静止时采集角速度数据，用于确定零偏；随后缓慢向左、向右转动车模，核对 Z 轴角速度符号、航向更新方向和转弯趋势判断。光电扫描与 IMU 更新采用一致的控制周期，使横向偏差和航向变化能够在同一时间基准下参与融合。
电机调试先将车轮悬空，分别验证左右电机方向、PWM 响应和驱动故障信号，再以较低输出进行直线行驶。整车闭环调试从低速直道开始，逐步加入弯道和连续赛道；调试过程中同步记录光电偏差、航向量、赛道状态以及左右轮 PWM，根据跑偏、振荡和转弯滞后现象调整控制参数。
5.4 故障定位与保护
当车模出现持续跑偏或转向振荡时，首先检查 A0-A15 是否按物理位置顺序存储，以及各通道校正值是否连续；若航向量在静止状态下持续变化，则检查 IMU 零偏、采样周期和积分更新；若左右轮响应不一致，则分别核对电机方向、启动区间、PWM 输出和驱动状态。通过将问题划分为感知、状态估计和执行三个层级，可以缩小故障定位范围。
运行过程中持续监测光电有效性、IMU 通信状态、电池电压和电机驱动故障信号。当光电响应无效或驱动器报告故障时，控制程序限制或关闭电机输出，并通过串口和状态指示记录异常信息；恢复正常前不直接进入高速闭环，以避免错误数据造成突发转向。

附录 A 核心算法源代码
竞赛要求技术报告必须附带核心程序源代码。以下代码对应 16 路模拟光电板、LSM6DSV16X 和 TC264DA 控制接口，包含通道标定、观测置信度、三状态扩展卡尔曼滤波、创新门控、陀螺零偏估计、差速控制和失线保护。Track_BackgroundAdc、Track_LineAdc 和 Track_ChannelPositionM 分别读取实车标定的背景值、赛道值及通道物理坐标；底层 GPIO、ADC、SPI、PWM 函数映射到实际工程驱动。
代码阅读提示：程序入口为 Track_NavControlStep，它每个控制周期调用一次，内部依次完成传感器采集、状态融合和电机输出。代码中的底层接口是对 TC264DA 工程驱动的抽象，实际移植时只需保持接口含义和返回单位一致。
（1）通道读取与标定。Track_ReadOneRaw 将 n 的四位二进制地址分别输出到 D3、D4、D5、D6，其中 D3:D6 对应 S3:S0，随后从 D7/P00_7/ADC3_CH5 读取 AS。NormalizeChannel 使用每一路的背景值和赛道值做归一化，因此可以补偿不同光电管的灵敏度差异，并兼容 ADC 响应极性。
（2）光电观测生成。Track_Observe 保持 A0-A15 的物理顺序不变，用标定后的通道坐标计算响应加权位置；总响应、峰值、有效通道数和连续响应长度共同形成 confidence。总响应不足或有效通道过少时，观测标记为无效，避免一只受反光影响的光电管直接造成大幅转向。
（3）惯导预测与 EKF 校正。FusionEkf_Predict 根据车速和 Z 轴角速度推进横向误差、航向误差及陀螺零偏，并同步传播协方差。FusionEkf_UpdateOptical 把光电横向位置作为标量观测，按置信度调整观测噪声；创新超过 3σ 时拒绝本次校正，以抑制遮挡、反光和突发异常。
（4）控制与保护。Track_Control 使用横向误差、航向误差和横向误差变化率生成差速量，并对基础速度和转向量限幅。连续失线时降低速度，长时间失线则停止电机；IMU 通信失败或驱动故障时直接输出零，光电恢复后通过 recovered_cycles 逐步恢复校正权重。
参数整定时先记录 lateral_m、heading_deg、gyro_bias_dps 和 track_confidence，再依次调整通道标定、过程噪声、观测噪声和控制增益。代码中的初始增益仅作为工程起点，最终值应以本车轮胎、舵机和赛道条件下的实测日志为准。
#include <math.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#define TRACK_COUNT             16U
#define TRACK_DT_S              0.005f
#define PI_F                    3.14159265359f
#define DEG_TO_RAD_F            (PI_F / 180.0f)
#define RAD_TO_DEG_F            (180.0f / PI_F)
/* Platform functions are supplied by the TC264DA board support package. */
extern void Gpio_Write(uint8_t pin, uint8_t value);
extern void Track_AddressSettle(void);
extern uint16_t Adc3_Ch5_ReadRaw(void);
extern bool Imu_ReadGyroZ(float *gyro_z_dps);
extern float VehicleSpeedEstimate_Mps(void);
extern uint16_t Track_BackgroundAdc(uint8_t channel);
extern uint16_t Track_LineAdc(uint8_t channel);
extern float Track_ChannelPositionM(uint8_t channel);
extern void Motor_Set(float left_cmd, float right_cmd);
extern bool Driver_FaultActive(void);
extern void Debug_Log(const char *name, float value);
typedef struct {
    float lateral_m;
    float confidence;
    float total_response;
    uint8_t active_count;
    bool valid;
} TrackObservation;
typedef struct {
    /* x[0] = lateral error, x[1] = heading error, x[2] = gyro bias. */
    float x[3];
    float P[3][3];
    uint16_t lost_cycles;
    uint16_t recovered_cycles;
} FusionEkf;
static float clampf(float x, float lo, float hi)
{
    return (x < lo) ? lo : ((x > hi) ? hi : x);
}
static float wrap_pi(float x)
{
    while (x > PI_F)  x -= 2.0f * PI_F;
    while (x < -PI_F) x += 2.0f * PI_F;
    return x;
}
static float NormalizeChannel(uint8_t i, uint16_t raw)
{
    float background = (float)Track_BackgroundAdc(i);
    float line = (float)Track_LineAdc(i);
    float span = line - background;
    if (fabsf(span) < 32.0f) return 0.0f;
    /* This expression supports either ADC polarity after calibration. */
    return clampf(((float)raw - background) / span, 0.0f, 1.0f);
}
static bool Track_ReadOneRaw(uint8_t n, uint16_t *raw)
{
    if ((n >= TRACK_COUNT) || (raw == NULL)) return false;
    Gpio_Write(P00_3, (n >> 3) & 1U);  /* D3 = S3 */
    Gpio_Write(P00_4, (n >> 2) & 1U);  /* D4 = S2 */
    Gpio_Write(P00_5, (n >> 1) & 1U);  /* D5 = S1 */
    Gpio_Write(P00_6, n & 1U);         /* D6 = S0 */
    Track_AddressSettle();
    *raw = Adc3_Ch5_ReadRaw();      /* D7/P00_7/ADC3_CH5 = AS */
    return true;
}
static TrackObservation Track_Observe(void)
{
    uint16_t raw[TRACK_COUNT];
    float response[TRACK_COUNT];
    float sum = 0.0f;
    float weighted_position = 0.0f;
    float max_response = 0.0f;
    uint8_t active = 0U;
    uint8_t longest_run = 0U;
    uint8_t current_run = 0U;
    for (uint8_t i = 0U; i < TRACK_COUNT; ++i) {
        if (!Track_ReadOneRaw(i, &raw[i])) {
            return (TrackObservation){0.0f, 0.0f, 0.0f, 0U, false};
        }
        response[i] = NormalizeChannel(i, raw[i]);
        sum += response[i];
        weighted_position += response[i] * Track_ChannelPositionM(i);
        if (response[i] > max_response) max_response = response[i];
        if (response[i] > 0.18f) {
            ++active;
            if (++current_run > longest_run) longest_run = current_run;
        } else {
            current_run = 0U;
        }
    }
    if ((sum < 0.65f) || (active < 2U) || (max_response < 0.28f)) {
        return (TrackObservation){0.0f, 0.0f, sum, active, false};
    }
    float lateral = weighted_position / sum;
    float concentration = clampf((max_response - 0.20f) / 0.60f, 0.0f, 1.0f);
    float continuity = clampf((float)longest_run / (float)active, 0.0f, 1.0f);
    float confidence = 0.55f * concentration + 0.45f * continuity;
    return (TrackObservation){lateral, confidence, sum, active, true};
}
static void FusionEkf_Init(FusionEkf *f)
{
    *f = (FusionEkf){0};
    f->P[0][0] = 0.010f * 0.010f;   /* lateral uncertainty, m^2 */
    f->P[1][1] = 0.20f * 0.20f;     /* heading uncertainty, rad^2 */
    f->P[2][2] = 0.05f * 0.05f;     /* gyro bias uncertainty */
}
static void FusionEkf_Predict(FusionEkf *f, float speed_mps,
                              float gyro_z_dps, float dt)
{
    const float gyro = gyro_z_dps * DEG_TO_RAD_F;
    float F[3][3] = {
        {1.0f, speed_mps * cosf(f->x[1]) * dt, 0.0f},
        {0.0f, 1.0f, -dt},
        {0.0f, 0.0f, 1.0f}
    };
    float FP[3][3] = {{0}};
    float Pn[3][3] = {{0}};
    f->x[0] += speed_mps * sinf(f->x[1]) * dt;
    f->x[1] = wrap_pi(f->x[1] + (gyro - f->x[2]) * dt);
    for (uint8_t i = 0U; i < 3U; ++i)
        for (uint8_t j = 0U; j < 3U; ++j)
            for (uint8_t k = 0U; k < 3U; ++k)
                FP[i][j] += F[i][k] * f->P[k][j];
    for (uint8_t i = 0U; i < 3U; ++i)
        for (uint8_t j = 0U; j < 3U; ++j)
            for (uint8_t k = 0U; k < 3U; ++k)
                Pn[i][j] += FP[i][k] * F[j][k];
    /* Q increases slightly with speed and protects against model mismatch. */
    Pn[0][0] += 0.0000005f + 0.000002f * fabsf(speed_mps);
    Pn[1][1] += 0.0008f;
    Pn[2][2] += 0.00001f;
    for (uint8_t i = 0U; i < 3U; ++i)
        for (uint8_t j = 0U; j < 3U; ++j)
            f->P[i][j] = Pn[i][j];
}
static bool FusionEkf_UpdateOptical(FusionEkf *f,
                                    const TrackObservation *obs)
{
    if (!obs->valid) {
        if (f->lost_cycles < 60000U) ++f->lost_cycles;
        f->recovered_cycles = 0U;
        return false;
    }
    float pitch = fabsf(Track_ChannelPositionM(8U) -
                        Track_ChannelPositionM(7U));
    float sigma = pitch * (0.35f + 1.65f * (1.0f - obs->confidence));
    float R = sigma * sigma;
    float innovation = obs->lateral_m - f->x[0];
    float S = f->P[0][0] + R;
    /* 3-sigma gate rejects a single saturated or reflective channel. */
    if ((innovation * innovation) > 9.0f * S) {
        if (f->lost_cycles < 60000U) ++f->lost_cycles;
        f->recovered_cycles = 0U;
        return false;
    }
    float K[3] = {f->P[0][0] / S, f->P[1][0] / S, f->P[2][0] / S};
    float old_row[3] = {f->P[0][0], f->P[0][1], f->P[0][2]};
    for (uint8_t i = 0U; i < 3U; ++i) f->x[i] += K[i] * innovation;
    f->x[1] = wrap_pi(f->x[1]);
    for (uint8_t i = 0U; i < 3U; ++i)
        for (uint8_t j = 0U; j < 3U; ++j)
            f->P[i][j] -= K[i] * old_row[j];
    for (uint8_t i = 0U; i < 3U; ++i)
        for (uint8_t j = i + 1U; j < 3U; ++j) {
            float s = 0.5f * (f->P[i][j] + f->P[j][i]);
            f->P[i][j] = s; f->P[j][i] = s;
        }
    f->lost_cycles = 0U;
    if (f->recovered_cycles < 1000U) ++f->recovered_cycles;
    return true;
}
static void Track_Control(const FusionEkf *f, bool optical_accepted, float dt)
{
    static float last_lateral = 0.0f;
    /* Initial gains; finalize them with the logging procedure in Section 5. */
    const float kp_e = 7.50f;
    const float kp_psi = 1.90f;
    const float kd_e = 0.018f;
    float de = (f->x[0] - last_lateral) / fmaxf(dt, 0.001f);
    float correction = kp_e * f->x[0] + kp_psi * f->x[1] + kd_e * de;
    float recovery = clampf((float)f->recovered_cycles / 20.0f, 0.0f, 1.0f);
    float base = optical_accepted ? (0.22f + 0.20f * recovery) : 0.22f;
    if (!optical_accepted) correction = clampf(correction, -0.28f, 0.28f);
    if (f->lost_cycles > 100U) base = 0.0f;
    float left = clampf(base - correction, -1.0f, 1.0f);
    float right = clampf(base + correction, -1.0f, 1.0f);
    Motor_Set(left, right);
    last_lateral = f->x[0];
}
void Track_NavControlStep(void)
{
    static FusionEkf filter;
    static bool initialized = false;
    if (!initialized) { FusionEkf_Init(&filter); initialized = true; }
    float gyro_z_dps = 0.0f;
    TrackObservation obs = Track_Observe();
    bool imu_ok = Imu_ReadGyroZ(&gyro_z_dps);
    if (!imu_ok || Driver_FaultActive()) {
        Motor_Set(0.0f, 0.0f);
        return;
    }
    FusionEkf_Predict(&filter, VehicleSpeedEstimate_Mps(), gyro_z_dps,
                      TRACK_DT_S);
    bool optical_accepted = FusionEkf_UpdateOptical(&filter, &obs);
    Track_Control(&filter, optical_accepted, TRACK_DT_S);
    Debug_Log("lateral_m", filter.x[0]);
    Debug_Log("heading_deg", filter.x[1] * RAD_TO_DEG_F);
    Debug_Log("gyro_bias_dps", filter.x[2] * RAD_TO_DEG_F);
    Debug_Log("track_confidence", obs.confidence);
}
