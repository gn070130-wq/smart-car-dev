摘要
本文对安徽工业大学“怪人协会”参加第二十一届全国大学生智能汽车竞赛疯狂电路组的智能车系统设计方案进行完整阐述。本系统采用N30缩微四轮车模作为运动平台，以英飞凌AURIX TC264作为核心控制器，搭建集视觉感知、路径判断以及运动控制于一体的智能车系统。
智能车通过MT9V034总钻风全局快门数字摄像头获取赛道图像信息，对赛道电路结构进行采集与分析；利用编码器实时检测车辆运行速度，并结合PID控制算法实现电机闭环调节，提高车辆运行过程中的稳定性与响应速度。硬件系统采用DRV8701双电机驱动模块完成电机控制，同时配置IMU660RB姿态传感器、IPS显示屏以及无线通信模块辅助系统调试。
针对疯狂电路组赛道中不同电路网络结构的识别与通过需求，系统设计了图像处理、电路信息识别以及路径决策算法，使智能车能够根据赛道信息自主完成运行任务。通过多轮硬件调试、软件优化以及参数整定，最终验证了该系统方案的可行性，为智能车在复杂电路赛道环境下的稳定运行提供了有效方案。
关键词：TC264；疯狂电路；图像处理；路径识别；PID控制；智能车

第一章  绪 论
1.1 智能车研究背景
智能车是一种高新技术密集型的新型汽车，以汽车电子为背景涵盖控制、模式识别、传感技术、电子、电气、计算机、机械等多科学的科技创意性设计，一般主要由路径识别、速度采集、角度控制及车速控制等模块组成。可实现自动驾驶、自动变速及自动识别道路等功能，是现代电子产业发展中一项重要的组成部分。
在我国，教育部为了加强大学生实践、创新能力和团队合作精神的培养，委托教育部高等学校自动化专业教学指导分委员会主办了每年一度的全国大学生智能汽车竞赛。全国大学生智能汽车竞赛是在竞赛组委会提供的统一汽车模型平台上，使用英飞凌公司的8位、16位、32位微控制器作为核心控制模块，通过设计道路识别传感器和电机驱动电路、编写相应软件及装配模型车，制作一个能够自主识别道路的模型汽车，按照规定路线（路线赛前未知）行进，以完成时间最短者为优胜。
1.2 疯狂电路组任务分析
全国大学生智能汽车竞赛是一项综合性工程实践竞赛，要求参赛队伍利用嵌入式控制技术、传感器技术、电机控制技术以及算法设计能力，实现智能模型车自主完成比赛任务。
疯狂电路组区别于传统智能车竞速组，其主要任务是在规定电路赛道环境下，通过车载传感器获取赛道信息，对不同类型电路网络进行识别与判断，并控制智能车快速、稳定地通过指定路线。比赛赛道包含串联网络、并联网络以及串并联网络等不同形式，要求模型车具备较强的信息感知能力、路径判断能力以及运动控制能力。
针对疯狂电路组比赛特点，本系统采用视觉感知与运动控制相结合的方案，通过摄像头采集赛道信息，利用主控制器完成数据处理与路径规划，同时结合编码器反馈实现速度闭环控制，使智能车能够稳定完成复杂电路赛道运行任务。
1.3 系统总体方案介绍
根据疯狂电路组比赛要求，本智能车系统采用N30缩微四轮车模作为运动平台，以英飞凌AURIX TC264作为核心控制器。
硬件系统主要由主控模块、电源模块、电机驱动模块、视觉采集模块、速度检测模块以及辅助调试模块组成。其中，主控部分采用TC264_btb核心板，配合逐飞缩微学习板完成系统控制；视觉部分采用120° MT9V034总钻风全局快门数字摄像头获取赛道信息；运动控制部分采用DRV8701双电机驱动模块驱动车辆运行，并通过1024线增量式编码器实时获取车辆速度信息，实现闭环控制。
软件系统主要包括图像采集处理、电路信息识别、路径判断、电机控制以及参数调节等模块。系统通过对采集到的赛道信息进行分析，生成车辆运行策略，并利用PID控制算法调整电机输出，使车辆能够快速、稳定地完成比赛任务。
S第二章 机械结构设计及调整
智能车系统不仅需要可靠的软件算法与硬件设计，合理的机械结构同样是影响车辆运行性能的重要因素。在疯狂电路组比赛中，车模需要在保证稳定运行的同时尽可能提高通过速度，因此车辆结构设计需要兼顾轻量化、稳定性以及各模块之间的合理布局。
本系统采用N30缩微四轮车模作为运动平台，围绕降低整车重量、优化重心分布、提高传感器采集稳定性以及减少模块之间干扰等方面进行机械结构设计，使车辆能够满足复杂电路赛道环境下高速稳定运行的需求。
2.1 整车布局
本系统采用N30缩微四轮车模作为基础运动平台。该车模具有体积小、重量轻、结构紧凑等特点，能够满足疯狂电路组对于车辆轻量化和快速响应的要求。
整车结构主要由车模底盘、动力系统、控制系统、传感器系统以及辅助调试模块组成。其中，主控板安装于车身中心区域，保证车辆运行过程中整体受力均衡；电机驱动模块靠近动力输出端布置，以缩短电机连接线路，提高系统响应速度；摄像头安装于车体前方，用于获取前方赛道信息。
在整体布局设计过程中，充分考虑各模块之间的空间关系与信号传输稳定性，通过合理规划硬件安装位置，提高车辆运行可靠性。

2.2 车模轻量化设计
疯狂电路组比赛过程中，车辆重量会影响最终比赛成绩，因此在保证结构强度和运行稳定性的基础上，降低整车重量是提升车辆性能的重要方向。
本系统采用N30缩微四轮车模，车模自身重量较轻。在机械结构设计过程中，对车身各模块安装方式进行优化，减少不必要的结构件，同时合理选择电子模块安装位置，使车辆在保持较高可靠性的同时降低整体质量。
此外，通过优化线路布局，减少过长连接线材的使用，进一步降低车身重量，并减少高速运行过程中线路晃动对系统稳定性的影响。

2.3 摄像头安装设计
在疯狂电路组比赛中，摄像头是获取赛道信息的重要传感器，其安装位置会直接影响图像采集效果。
本系统采用120° MT9V034总钻风全局快门数字摄像头作为视觉采集模块。摄像头安装于车体前方较高位置，使其能够获得更加开阔的赛道视野，减少车体结构对图像区域的遮挡。
同时，为降低车辆运动过程中产生的振动对图像采集造成的影响，摄像头安装结构采用固定连接方式，提高摄像头稳定性，为后续图像处理和赛道信息识别提供可靠的数据来源。摄像头安装如图2.3所示。

2.4 主控及驱动一体化模块布局设计
为提高智能车系统的集成度与运行稳定性，本系统设计制作了主控驱动一体化控制板，将核心控制电路、电源管理电路以及电机驱动接口集成于同一PCB中。
相比传统智能车采用主控板与驱动板分离的结构，一体化设计能够减少板间连接线数量，降低由于接口松动导致的系统故障风险，同时缩短控制信号传输路径，提高系统响应速度。
主控部分采用TC264_btb核心板作为系统控制核心，负责完成传感器数据采集、赛道信息处理以及运动控制算法运行。驱动部分集成电机驱动接口，与车辆动力系统连接，实现对左右电机的独立控制。
在PCB布局过程中，根据功能模块特点进行区域划分，将主控、电源、驱动以及外部接口进行合理规划，减少不同功能模块之间的相互干扰。同时，通过优化元器件布局和线路走向，使控制板结构更加紧凑，满足疯狂电路组对于车模轻量化和高速稳定运行的要求。

2.5 重心调整
车模重心分布会直接影响车辆高速运行过程中的稳定性。在疯狂电路组比赛中，车辆需要在复杂电路赛道中完成快速转向以及连续路径跟踪，因此合理的重心设计对于提高车辆运行稳定性具有重要意义。
在整车结构设计过程中，本系统围绕车体中心进行模块布局，将主驱一体化控制板、电池以及传感器等主要部件进行合理分布，使车辆整体质量尽可能靠近几何中心，减少由于重量分布不均造成的行驶偏移。
其中，主驱一体化控制板作为车辆核心控制模块，安装于车身中部区域，使控制电路与动力系统保持较好的空间平衡；电池作为主要重量来源，根据车辆实际运行状态调整安装位置，使车辆前后轴受力更加均匀；摄像头安装位置经过调节，使车辆在运动过程中保持稳定视野，降低车身姿态变化对图像采集效果的影响。
通过多次测试与调整，最终确定车辆各模块安装位置，使智能车在保证轻量化的同时具备良好的直线运行能力和转向稳定性。

硬件电路设计
智能车硬件系统是实现车辆自主运行的基础，其可靠性直接影响整车性能。本系统针对疯狂电路组比赛需求，设计了一套集主控、电源管理、电机驱动以及传感器接口于一体的主驱一体化控制系统。
硬件系统以Infineon AURIX TC264_btb核心板作为控制核心，通过自主设计的主驱一体化PCB实现各功能模块连接。系统包含电源管理模块、电机驱动模块、传感器采集模块以及辅助调试接口等部分，在满足功能需求的基础上，对PCB布局、线路连接以及模块集成方式进行了优化，提高了系统可靠性和整体集成度。

3.1 TC264主控系统设计
主控系统是智能车完成信息采集、算法处理以及运动控制的核心部分。本系统采用Infineon AURIX TC264_btb核心板作为主控制器。
TC264具有较高的计算性能和丰富的外设资源，能够满足智能车实时控制需求。系统运行过程中，主控芯片负责采集摄像头、编码器以及其他传感器数据，并根据处理结果输出电机控制信号，实现车辆自主运行。
主控部分通过SPI、PWM、GPIO等接口与外围模块连接，实现数据通信和控制任务。

3.2 电源管理电路设计

稳定可靠的电源系统是智能车运行的重要保障。本系统根据不同模块工作需求设计多路电源转换电路，为主控芯片、传感器以及电机驱动模块提供稳定供电。
系统电源部分主要包括输入保护、电压转换以及滤波稳压等功能，通过合理设计降低电源纹波以及负载变化对控制系统造成的影响，提高整车运行稳定性。

3.3 电机驱动电路设计
为了实现智能车运动控制，本系统采用DRV8701双电机驱动模块完成左右电机驱动。
DRV8701能够根据主控输出的PWM控制信号调节电机运行状态，实现车辆速度控制和方向控制。相比传统分立驱动方案，集成化驱动方式具有结构紧凑、控制可靠等特点，适用于空间受限的缩微智能车平台。
在实际设计过程中，将驱动电路与主控系统进行合理连接，通过优化PWM信号传输路径，提高电机控制响应速度。

3.4 传感器接口电路设计
为了实现车辆环境感知和运动状态检测，本系统设计了多种传感器接口。
视觉部分采用MT9V034总钻风全局快门数字摄像头，用于采集赛道图像信息；速度检测部分采用1024线增量式编码器，对左右电机运行状态进行实时反馈；同时配置IMU660RB姿态传感器，用于辅助获取车辆运动状态。
各传感器通过对应接口与主控制板连接，为后续图像处理、路径判断以及运动控制算法提供数据支持。

3.5 主驱一体化PCB设计
为提高系统集成度，本系统自主设计制作了主驱一体化控制PCB，将主控接口、电源管理以及电机驱动相关电路集成于同一块电路板中。
PCB设计过程中，根据功能模块进行区域划分，将高速信号、电源线路以及控制接口进行合理布局，降低模块之间的相互干扰。
相比传统多板连接方案，一体化PCB减少了板间连接线数量，提高了系统可靠性，同时减小了整车空间占用，有利于实现智能车轻量化设计。

第四章 软件控制设计
智能车的软件系统是实现自主运行的核心部分，其主要负责传感器数据采集、赛道信息处理、路径判断以及运动控制等任务。
针对疯狂电路组比赛特点，本系统采用模块化软件设计思想，将程序划分为数据采集层、信息处理层、决策控制层以及执行控制层。
系统通过MT9V034摄像头采集赛道图像信息，经主控制器TC264进行处理，提取有效赛道特征，并根据电路结构信息完成路径判断。同时，通过编码器实时反馈电机运行状态，结合PID控制算法调整电机输出，实现智能车稳定运行。
4.1 软件系统总体设计
智能车的软件系统是实现自主运行的核心部分，主要负责传感器数据采集、图像信息处理、路径判断以及运动控制等任务。
针对疯狂电路组比赛中赛道结构复杂、运行速度要求较高的特点，本系统采用模块化的软件设计方案，将程序划分为数据采集模块、图像处理模块、路径决策模块以及运动控制模块。
数据采集模块主要负责获取摄像头图像信息、编码器速度信息以及其他传感器数据；图像处理模块对采集到的赛道图像进行分析，提取有效道路特征；路径决策模块根据当前赛道状态判断车辆运行方向；运动控制模块通过PID算法调节电机输出，实现车辆稳定运行。

4.2 摄像头图像采集与处理
在疯狂电路组比赛中，智能车需要根据赛道中的电路结构完成自主运行，因此准确获取赛道信息是实现智能控制的基础。
本系统采用MT9V034总钻风全局快门数字摄像头作为视觉采集模块，通过摄像头实时获取前方赛道图像信息，并将采集数据传输至TC264主控制器进行处理。
由于车辆运行过程中存在速度变化以及环境干扰，图像处理算法需要具备较好的实时性和稳定性。系统通过对原始图像进行预处理，提取赛道中的有效特征信息，为后续路径判断提供数据支持。
4.2.1 图像采集
摄像头作为智能车获取外部环境信息的重要传感器，其采集效果直接影响后续算法性能。
系统通过摄像头接口实时获取赛道图像数据，并利用TC264强大的数据处理能力完成图像缓存和分析。
在摄像头安装过程中，通过调整摄像头高度以及俯视角度，使其能够获取较完整的赛道区域，保证车辆运行过程中能够提前获取前方路径信息。

4.2.2 图像预处理
由于实际比赛环境中可能存在光照变化、赛道反光以及车辆振动等因素，原始图像通常包含一定噪声，因此需要进行预处理。
系统首先对采集图像进行灰度化处理，将彩色图像转换为灰度数据，降低计算复杂度；随后通过滤波处理减少图像噪声，提高图像稳定性；最后根据赛道特征进行二值化处理，使目标区域与背景区域产生明显区别。
经过预处理后的图像能够更加突出赛道有效信息，为后续特征提取提供基础。

4.2.3 赛道特征提取
经过图像预处理后，系统进一步对图像中的有效区域进行分析，提取车辆运行所需的关键特征。
通过检测赛道边界、中心位置以及路径变化趋势，计算车辆当前相对于目标路径的偏差量。
该偏差数据作为运动控制的重要输入，为后续路径调整以及电机控制提供依据。
4.3 电路信息识别算法
疯狂电路组与传统循迹组最大的区别在于，车辆不仅需要完成基本路径跟踪，还需要对赛道中的电路结构进行判断。
本系统通过摄像头采集赛道图像，对不同区域的道路结构进行分析，根据图像中特征变化判断当前电路状态。
系统主要根据道路连接关系、路径变化以及节点特征进行综合判断，并将识别结果传递给路径决策模块。
通过电路信息识别算法，车辆能够根据赛道实际情况选择合理运行路径，提高比赛过程中的通过效率。

4.4 路径判断与决策算法
在完成赛道信息采集和电路结构识别后，系统需要根据当前状态确定车辆下一步运动策略。
路径决策模块主要完成以下任务：
（1）判断车辆当前所在赛道状态；
（2）分析前方道路变化情况；
（3）选择合理行驶路径；
（4）生成对应控制参数。
根据不同赛道结构，系统动态调整车辆运行策略，使车辆能够稳定通过复杂电路区域。







4.5 PID控制算法介绍
在工程实际中，应用最为广泛的调节器控制规律为比例、积分、微分控制，简称PID控制，又称PID调节。PID控制器问世至今已有近70年历史，它以其结构简单、稳定性好、工作可靠、调整方便而成为工业控制的主要技术之一。当被控对象的结构和参数不能完全掌握，或得不到精确的数学模型时，控制理论的其它技术难以采用时，系统控制器的结构和参数必须依靠经验和现场调试来确定，这时应用PID控制技术最为方便。即当我们不完全了解一个系统和被控对象，或不能通过有效的测量手段来获得系统参数时，最适合用PID控制技术。PID控制，实际中也有PI和PD控制。
PID控制器是一种线性控制器，它根据给定值与实际输出值构成控制偏差。将偏差的比例(P)、积分(I)和微分(D)通过线性组合构成控制量，对被控对象进行控制，故称PID控制器，原理框图如图4.19所示。

简单说来，PID控制器各校正环节的作用如下：
比例环节：及时成比例地反映控制系统的偏差信号，偏差一旦产生，控制器立即产生控制作用，以减少偏差。
积分环节：主要用于消除静差，提高系统的无差度。积分作用的强弱取决于积分时间常数，越大，积分作用越弱，反之则越强。
微分环节：能反映偏差信号的变化趋势(变化速率)，并能在该偏差信号变得太大之前，在系统中引入一个有效的早期修正信号，从而加快系统的动作速度，减小调节时间。
数字PID控制算法通常分为位置式PID控制算法和增量式PID控制算法。
4.5.1 位置式PID
位置式PID中，由于计算机输出的u (k) 直接去控制执行机构(如阀门)，u(k)的值和执行机构的位置(如阀门开度)是一一对应的，所以通常称公式(4.2)为位置式PID控制算法。
位置式PID控制算法的缺点是：由于全量输出，所以每次输出均与过去的状态有关，计算时要对过去e(k)进行累加，计算机工作量大；而且因为计算机输出的u(k)对应的是执行机构的实际位置，如计算机出现故障，u(k)的大幅度变化，会引起执行机构位置的大幅度变化，这种情况往往是生产实践中不允许的，在某些场合，还可能造成严重的生产事故。因而产生了增量式PID 控制的控制算法，所谓增量式PID 是指数字控制器的输出只是控制量的增量△u(k)。

增量式PID具有以下优点：
(1) 由于计算机输出增量，所以误动作时影响小，必要时可用逻辑判断的方法关掉。
(2) 手动/自动切换时冲击小，便于实现无扰动切换。此外，当计算机发生故障时，由于输出通道或执行装置具有信号的锁存作用，故能保持原值。
(3) 算式中不需要累加。控制增量△u(k)的确定仅与最近k次的采样值有关，所以较容易通过加权处理而获得比较好的控制效果。
但增量式PID也有其不足之处：积分截断效应大，有静态误差；溢出的影响大。使用时，常选择带死区、积分分离等改进PID控制算法。
4.5.3 PID参数整定
运用PID控制的关键是调整KP、KI、KD三个参数，即参数整定。PID参数的整定方法有两大类：一是理论计算整定法。它主要是依据系统的数学模型，经过理论计算确定控制器参数；二是工程整定方法，它主要依赖工程经验，直接在控制系统的试验中进行，且方法简单、易于掌握，在工程实际中被广泛采用。由于智能车系统是机电高耦合的分布式系统，并且要考虑赛道的具体环境，要建立精确的智能车运动控制数学模型有一定难度，而且我们对车身机械结构经常进行修正，模型参数变化较为频繁，理论计算整定法可操作性不强，最终我们采用了工程整定方法。此外，我们先后实验了几种动态改变PID参数的控制方法。
4.6 电机速度闭环控制算法
为了提高智能车运行过程中的速度稳定性，本系统采用基于编码器反馈的速度闭环控制策略。
车辆运行过程中，通过左右电机编码器实时获取当前速度信息，并将实际速度反馈至TC264控制器。
控制器计算目标速度与实际速度之间的误差，通过PID控制算法计算输出控制量，并转换为PWM信号控制电机驱动模块，实现对电机转速的动态调节。
相比开环控制方式，速度闭环控制能够有效降低由于电池电压变化、负载变化以及赛道阻力变化造成的速度波动，提高车辆高速运行稳定性。

void wheel_speed_pid_reset(void)
{
    l_wheel_pid.integral = 0.0f;
    l_wheel_pid.last_error = 0.0f;

    r_wheel_pid.integral = 0.0f;
    r_wheel_pid.last_error = 0.0f;

    l_target_vel_cmps = 0.0f;
    r_target_vel_cmps = 0.0f;
    steer_vel_delta_cmps = 0.0f;
}

float wheel_speed_pid_calc(Speed_Pid *pid, float target_vel, float now_vel)
{
    float error;
    float corr;
    float pwm_out;

    error = target_vel - now_vel;

    if (pid->ki > 0.000001f || pid->ki < -0.000001f)
    {
        /*
         * 只有 KI 真正非零时才累计积分。
         * 调车意义：KI 为 0 时让积分保持清零，避免“看似关闭 I 项但历史积分仍在影响输出”。
         * 风险提示：如果速度忽快忽慢，先看 KP 和编码器速度是否稳定，不要先打开积分。
         */
        pid->integral += error;
        pid->integral = limit_float(pid->integral,
                                    pid->i_limit,
                                    -pid->i_limit);
    }
    else
    {
        pid->integral = 0.0f;
    }

    corr = pid->kp * error + pid->ki * pid->integral;
    /*
     * 单轮 PI 修正先限幅，再叠加 base_speed。
     * 为什么限在这里：防止某一侧编码器异常或轮子悬空时，PI 输出把单轮 PWM 拉到过大。
     * 调松风险：差速动作会更激烈，驱动电流和轮胎打滑风险上升。
     */
    corr = limit_float(corr, pid->out_max, pid->out_min);

    pwm_out = (float)base_speed + corr;
    /*
     * 最终仍受 MOTOR_DUTY_LIMIT 约束。
     * 读代码时注意：即使 PID 算出更大的 PWM，也不会越过电机安全上限。
     */
    pwm_out = limit_float(pwm_out,
                          (float)MOTOR_DUTY_LIMIT,
                          -(float)MOTOR_DUTY_LIMIT);

    pid->last_error = error;

    return pwm_out;
}
