摘要
本文详细阐述了东华大学VAPOR队针对第二十一届全国大学生智能汽车竞赛“疯狂电路”组别所设计的缩微自主巡线智能赛车系统。该组别对车模的硬件自研能力、高密度集成度及极限工况下的抗干扰性能提出了极高要求。本团队确立了“极致轻量、高度集成、敏捷控制”的设计理念，完成了集机械、电路、算法于一体的全栈式自主研发。
在机械结构方面，车模以高强度碳纤维底板为核心骨架，采用6061铝合金CNC侧板与纯钛M2主轴构建高同轴度传动机构；摄像头支架采用穿透PCB的碳纤维中空圆管与热熔胶阻尼固封设计，杜绝了高频共振与图像抖动；底盘搭载由1103无刷电机与尼龙离心风机驱动的负压吸附模组，配合柔性导流裙边，在不增加车体转动惯量的前提下大幅提升了极限过弯抓地力。
在硬件电路方面，整车采用高度集成的单板自研PCB方案。系统构建了“12V母线分离→5V一级核心降压→3.3V独立多路级联稳压”的低噪声供电拓扑；主控基于英飞凌32位双核微控制器SAK-TC264DA；动力驱动采用DRV8701E预驱配合MOS管构建双有刷H桥；同时在主板上集成了基于STC32G12K128专用单片机与FD6288T预驱的无感无刷（BLDC）负压电调电路。
在软件算法与控制方面，视觉端通过MT9V03x全局快门灰度摄像头采集图像，经隔行压缩、最长白列基点定位与局部窗口扫描快速提取赛道中线；元素识别结合角点检测与固定矩形框出口可行性判断，配合预置路径表与三态有限状态机（FSM）实现了十字、T型岔路的精准导航；底盘运动控制采用融合LSM6DSRTR陀螺仪角速度微分负反馈的方向环PD控制，辅以速度加减速平滑与负压缓启动策略，有效抑制了车身振荡，实现了车模在极限车速下的平稳贴地巡线。

引言
智能车研究背景
为加强大学生实践、创新能力和团队精神的培养，促进高等教育教学改革，受教育部高等教育司委托(教高司函[2005]201号文，附件1)，由教育部高等自动化专业教学指导分委员会（以下简称自动化分教指委）主办全国大学生智能汽车竞赛。全国大学生智能汽车竞赛是一项面向全国大学生的多学科交叉探索性创意工程竞赛，旨在培养大学生的综合工程实践能力、跨学科创新意识及团队协作精神。随着汽车工业向智能化、网联化与电气化方向纵深发展，智能车竞赛的内容与形式持续与前沿工业技术深度接轨。
本届竞赛全新设立的“疯狂电路”组别，对参赛车模的硬件自研能力与系统集成度提出了极高要求。该组别突破了以往模块化拼装的传统模式，要求参赛队伍在紧凑的缩微车模底盘尺寸限制下，自主设计并制作涵盖电源管理、主控最小系统、有刷电机动力驱动、无感无刷负压电调以及多源传感器接口的高度集成化单板PCB电路。这不仅要求系统在高频数字信号与大功率电机强电磁干扰（EMI）并存的环境下具备极佳的电磁兼容性（EMC），更对车模在缩微复杂赛道中的高速巡线、岔路决策与极限姿态控制提出了严苛挑战。
围绕“疯狂电路”赛题的核心要求，东华大学VAPOR队针对缩微赛道的高动态特性与高集成电路设计标准，开展了全栈式的软硬件与机械协同研发，旨在打造一款具备极高硬件集成度、优异动力响应与强鲁棒导航能力的智能赛车。
智能车制作情况概述
我们队在充分理解赛题规则与缩微赛道运行工况的基础上，确立了“极致轻量、高度集成、敏捷控制”的设计理念，历经系统建模、方案论证、PCB迭代、机械结构优化及算法联调等研发阶段，最终完成了车模的整车制作。全车系统制作概况如下：
机械结构与模块化布局
车模结构采用轻量化与高刚度设计，充分考虑重心分布与转动惯量优化。定制了高强度碳纤维底板和紧凑型摄像头碳纤维支架，有效杜绝了车身颠簸引起的图像抖动；将高速无刷电机与尼龙风扇紧密结合，在保障缩微车模轻量化优势的同时，提供了强劲的地面负压吸附力。
硬件电路系统设计
整车硬件采用完全自主设计的高集成度单板方案。供电架构采用3S 95C高倍率FPV锂电池输入，构建了“12V母线分离→5V一级核心降压→3.3V独立多路级联稳压”的分布式电源管理系统；主控系统基于英飞凌32位双核微控制器SAK-TC264DA；动力驱动采用基于SN74HC125缓冲与DRV8701E+SIZ340DT的大电流有刷H桥；同时在主板上完整集成基于STC32G12K128专用单片机与FD6288T预驱的无感无刷（BLDC）负压电调，实现了强弱电物理隔离与超低噪声供电。
3.软件算法与控制体系
视觉感知端通过MT9V03x全局快门灰度摄像头采集图像，经隔行压缩与动态基点搜索、局部窗口扫描快速提取赛道边界；元素识别端结合角点检测与矩形框多向出口可行性判定，配合预置路径表与三态有限状态机（FSM）实现对十字、T型等复杂岔路的零失误导航；底盘控制端采用融合LSM6DSRTR六轴陀螺仪角速度微分负反馈的方向环PD控制（角速度阻尼抑制车体振荡），辅以速度加减速步进平滑与负压风扇软启动策略，实现了车模在极限车速下的平稳贴地飞行。
4.开发与无线调试体系
系统基于英飞凌官方AURIX Development Studio（ADS）进行多核底层与应用层代码开发；利用逐飞科技的高速WiFi SPI通信模块链路与上位机“逐飞助手”建立无线通道，实现了图像二值化边线、控制量示波器波形、状态机转移的实时遥测与在线参数无感整定，极大加速了算法的迭代验证。


机械结构设计
控制算法固然是智能车系统的决策中枢，但机械结构作为一切控制量落地的物理载体，直接决定了车模的性能上限与动态响应边界。若底盘结构与配重存在缺陷，车模在高速工况下极易诱发剧烈的侧倾、甩尾甚至侧翻失稳，导致顶层控制策略失真；同时，机械系统的刚度、转动惯量及左右对称性，也直接制约着加减速响应敏捷度与轨迹跟踪精度。因此，我们在车模自制过程中，围绕“低质心、低转动惯量、高刚度与高对称性”展开综合设计与结构调校，为整车的高速极限过弯与平稳巡线奠定坚实的物理基础。
车模总体结构
本车模严格遵循“疯狂电路”组别关于自制缩微轻量化车模的规则要求。设计参考了龙邱科技开源闪电鼠Q车模的核心构型，并针对全自研单板PCB、无刷负压风道及视觉前瞻布局进行了深度结构重构与定制改良。
整车以自制高强度碳纤维底板作为核心承载骨架，将有刷动力传动机构、无刷负压吸附模组、高集成度PCB及碳纤维摄像头支架高度紧凑地集成于一体。通过合理规划电池与电机的空间配重，在实现整车极致轻量化的同时显著降低了质心高度与横摆转动惯量，最终构建了兼具高结构刚度与优异动态响应特性的缩微车模总体方案。
各个模块介绍
PCB模块
作为“疯狂电路”组别的核心承载体，自研单板PCB集成了主控、电源管理、有刷动力驱动及无感无刷电调等多个强弱电电路。在高速贴地行驶与极限过弯工况下，PCB若发生形变或高频振动，不仅会导致接插件松动、焊点疲劳断裂，还会直接引起固定在其上的传感器与摄像头发生机械抖动，影响感知精度。因此，PCB在车体机械结构上的固定需兼顾结构刚度、抗振减噪、电气绝缘与轻量化要求。

在机械固定方案上，我们在核心PCB的四角及关键受力区域精准设计了定位安装孔，与下方的高强度碳纤维底板安装孔完全对齐，并采用单通六角尼龙隔离柱配合尼龙螺母和M2螺丝进行四角四点刚性紧固，固定结构如图2.1和图2.2所示。

摄像头支架模块
视觉传感器作为车模路径规划与元素识别的核心信息源，其安装稳定性直接决定了图像采集质量。车模在极限车速巡线与急转工况下，长杆结构极易产生高频共振与左右摆动，进而引发图像前瞻跳动及算法误判。为此，本系统设计了一套高刚度、轻量化、紧凑抗振的碳纤维立柱式摄像头支架结构。
支架整体由底座固定座、高强度碳纤维中空圆管立柱、顶部转接件与角度锁定结构组成。
支架底座采用轻量化3D打印定制件，通过高强度胶黏工艺刚性锚定在前端碳纤维底板上，为整根立柱提供坚实的根部力矩支撑。为进一步降低系统重心并提升空间利用率，我们在主板PCB对应位置开设了专用沉孔，碳纤维立柱直接纵向穿透PCB，由底板向上延伸至预设前瞻高度。支撑杆选用轻量化高模量碳纤维中空圆管，在具备极高抗弯抗扭刚度的同时大幅减轻了高处悬臂质量，有效降低了整车的转动惯量与质心高度。顶部采用轻量化安装座承托MT9V03x摄像头模块，配合长螺栓与尼龙隔柱预设了最佳下俯视角与视场覆盖范围。在实车调试确定最佳前瞻仰角后，我们采用高韧性热熔胶与螺纹双重锁紧工艺对顶部铰接缝隙及线缆应力集中点进行了全包裹固化封胶。该设计不仅实现了摄像头视角的物理零位永久固化，更利用胶体的阻尼特性吸收了电机旋转传递至顶端的高频微振，确保图像采集在任何剧烈颠簸工况下均平稳无抖动。

负压模块
在“疯狂电路”缩微赛道的高动态竞速中，车模自重极轻（仅100多克），若仅依靠车身重力，轮胎与地面的附着力极限将极为有限，极易在高速入弯时产生侧滑、甩尾甚至侧翻。为此，本系统设计了一套高转速、高密封性、低扰动的地面效应负压吸附模组，通过在车底人为构建局部强负压区，在不增加车身物理质量与转动惯量的前提下，成倍提升车轮的法向压力与过弯极限。 
负压模块整体由动力驱动核心（1103无刷电机+尼龙离心风机）、底盘吸气风道及底部柔性导流裙边三部分构成。具体结构如图2.6和图2.7所示。

动力模块
底盘传动系统的刚度与同轴度直接决定了动力输出效率与加减速响应敏捷度。为实现轻量化与高传动精度的兼顾，我们采用了龙邱科技提供的高精度 6061铝合金CNC侧板与高功率密度电机构建侧向传动单元。
该侧板具备极高的结构刚度与孔位加工精度，保证了高负荷运转下电机齿轮与车轮齿圈的精确啮合间隙，杜绝因形变引起的扫齿与传动损耗。动力源选用龙邱科技 LQ1518-030K-A高速强磁电机，自重极轻且转动惯量极小，电机输出轴中心齿轮同时驱动同侧前后两组轮毂齿圈，实现了敏捷高效的四轮动力传递。
为消除车轴轴向间隙并降低旋转摩擦阻力，车轴自内向外严格遵循以下时序装配：车轴尾部→铝合金防松自锁螺母→6061侧板→铝合金轴套→内轴承→轮毂→外轴承→车轴头部

硬件电路设计
硬件电路作为智能车系统的物理载体与神经中枢，其设计的合理性直接决定了车模的运行稳定性、响应速度及性能上限。针对“疯狂电路”组别对系统高集成度、强抗干扰能力及复杂控制逻辑要求，本章从系统架构、电源管理、单片机系统、核心控制及外设感知五个维度，详细阐述了车模的硬件电路设计方案。

电源管理部分
电源管理系统是整车硬件电路的能量心脏。疯狂电路组别要求系统具备极高的集成度，在紧凑的PCB空间内，大功率电机驱动带来的电磁干扰和瞬态电压跌落会对高精度传感器和微控制器造成致命影响。因此，本系统设计了一套多路独立和逐级降压的强抗干扰电源管理方案。
电池选型与全车供电拓扑
系统采用300mAh量级的高倍率3S 95C FPV（航模）锂电池 作为总能量源。满电电压为12.6V。该电池具备极低的内阻和高达95C的瞬态放电能力，能够完美支撑双有刷电机全速急停以及无刷负压风扇启动时的浪涌电流。还兼具重量轻的特点，完美符合缩微赛道对于轻重量的需求。

软件算法流程图

图4.1 软件算法流程图
图像采集与预处理
摄像头型号为MT9V03x全局快门灰度摄像头，采集图像分辨率，经过图像压缩后分辨率为。图像预处理主要包括压缩和二值化两步。
图像压缩
原始图像数据存储在mt9v03x_image_1二维数组中，共个像素点。为降低计算负担并保留赛道轮廓特征，系统采用隔行隔列采样法将图像压缩至维度，存储于Ori_Image二维数组中。压缩算法以步长为2遍历原始图像的行列像素并直接提取子窗口左上角像素，操作高效快捷。
图像二值化
为从摄像头采集的灰度图像中精准提取赛道信息，系统首先对图像进行二值化处理。该过程将图像像素的灰度值转换为仅包含0（黑色）和255（白色）的二值图像，其中黑色代表赛道上的引导线（前景），白色代表背景（如蓝色背景布）。算法使用了一个全局固定的灰度阈值，将所有低于该阈值的像素设为黑色（0），其余设为白色（255）。此方法简单高效，适用于光照相对均匀的比赛环境，能有效保留赛道边缘的轮廓信息。
边线提取与中线拟合
扫线基点搜索
为保证搜线的起始点落在赛道内部，首先通过快速最长白列算法寻找图像底部的最长白列。同时从图像底部向上扫描若干行，统计每一列从底部向上连续白色像素的个数，找到连续白色长度最大的列索引。这一列通常位于赛道中心附近，为后续左右边界的搜索提供了一个可靠的起始位置。
边线搜索
搜线过程采用最简单的扫线策略，从图像底部向上以步长为3提取赛道左右边界，以减少算法复杂度。首先利用最长白列的列索引，在最后一行附近搜索黑白白跳变点（符合赛道边界特征），分别找到左边界基点和右边界基点，若同时找到则计算该行中线。对于后续行，搜线范围以上一行左右边界为中心，向左/右各扩展若干像素作为搜索窗口，从而避免全图扫描，极大提高了速度。在每个搜索窗口内，从左向右找黑白白跳变作为左边界，从右向左找黑白白跳变作为右边界。若某侧未找到边界，则将左边界置为0，右边界置为COL-1，以保证中线的连续性。同时，若左边界值大于等于右边界值（交叉现象），则使用上一行边界进行修正，防止中线异常。
中线计算
每一行的中线取左右边界的算术平均值。搜线完成后得到完整的中线数组，用于后续误差计算。
元素识别与路径导航算法
角点检测
角点（即赛道拐点）是识别特殊元素的关键特征。本算法从图像自底向上隔行判断，检测左右边线的突变位置。判定条件为：连续三行边界变化较小，但与前几行相比出现较大偏移。满足条件的行索引分别记录为左右角点。角点一旦确定，即可判断赛道即将进入转弯或节点区域。
固定矩形框赛道可行性检测
为了更精确地分辨十字、T 型等岔路，系统在图像中定义了一个矩形检测框（位置由RECT_TOP_CUR、RECT_BOTTOM_CUR、RECT_LEFT_CUR、RECT_RIGHT_CUR确定）。算法检测矩形框的四条边上是否存在黑‑白‑白跳变，若存在该跳变情况，则说明该条边线上存在赛道特征，分别标记并统计存在出口的总数。这一信息与角点结合，可以准确区分十字路口、T型路口、直角弯道。
路径导航算法
根据比赛赛道类型，系统预置了多条路径表，每条路径表是一个由预先存储好的转弯方向组成的数组，对应赛道上每个节点的期望动作。导航算法根据当前节点计数从选定的路径表中读取下一步动作，同时结合矩形框检测的实际出口信息进行校验。节点计数在每个节点判定完成后递增，从而实现按序通过。
节点状态机管理算法
节点处理状态机管理整个通过节点的流程。状态机包括NONE（空闲）、DETECTED（已检测到节点）、TURNING（正在转向）。在NONE 状态，持续检测角点和矩形框出口，当满足条件后，进入DETECTED状态。此时根据导航方向锁定陀螺仪目标偏航角，进入TURNING状态中准备转向操作。在TURNING状态中，转向动作分为三种情况：直行，调用拉线算法将整条中线强制拉向图像中心，并启动计时器。当持续时间超过预设时间时，退出节点，重置状态。左转：利用左角点辅助定位，利用拉线算法将中线强制偏向左目标。当陀螺仪积分偏航角减小到目标值时，判定转向完成，重置状态。右转：对称处理即可。

// 函数简介       出界保护函数
// 参数说明       uint8 (*img)[COL]二值图像
//-------------------------------------------------------------------------------------------------------------------
volatile uint8 Out_Flag = 0;
volatile uint8 Run_Flag = 0;
uint16 Protection(uint8 (*img)[COL])
{
    uint16 white_count = 0;
    uint8 row, col;
    if (Run_Flag && node_state == NODE_NONE)
    {
        for (row = 0; row < ROW; row += 2)
        {
            for (col = 0; col < COL; col += 2)
            {
                if (img[row][col] == WHITE)
                {
                    white_count++;
                }
            }
        }
        if (white_count < 10)
        {
            Out_Flag = 1;
            Run_Flag = 0;
            Start_Flag = 0;
        }
    }
    return white_count;
}

// 菜单显示（应在主循环中调用）
void menu_proc(void)
{
    char buf[20];
    uint8_t y = 10;           // 菜单区域起始Y坐标（横屏时菜单在右侧，起始Y=0）
    uint8_t x = 140;         // 菜单区域起始X坐标
    uint8_t line_height = 16; // 每行高度

    // 显示每个菜单项
    for (uint8_t i = 0; i < MENU_COUNT; i++)
    {
        uint8_t ypos = y + i * line_height;
        if (ypos + line_height > 135) break; // 超出屏幕则停止显示

        // 显示高亮箭头
        if (i == menu_sel)
        {
            ips114_show_string(x, ypos, ">");
        } else {
            ips114_show_string(x, ypos, " ");
        }

        // 显示名称
        ips114_show_string(x + 8, ypos, menu_params[i].name);

        // 显示值
        if (menu_params[i].type == 0)
        {  // int
            int val = *(int*)menu_params[i].var_ptr;
            sprintf(buf, "%d", val);
        } else if (menu_params[i].type == 1)
        { // float
            float val = *(float*)menu_params[i].var_ptr;
            if (menu_params[i].name == "Step")
            {
                // 步进值显示为具体值
                sprintf(buf, "%.2f", val);
            } else {
                sprintf(buf, "%.2f", val);
            }
        } else { // special
            if (i == MENU_STEP) {
                    // 步进项显示当前步进值
                    sprintf(buf, "%.2f", current_step);
                } else {
                    sprintf(buf, "[ ]");
                }
        }
        ips114_show_string(x + 40, ypos, buf);
    }
}
