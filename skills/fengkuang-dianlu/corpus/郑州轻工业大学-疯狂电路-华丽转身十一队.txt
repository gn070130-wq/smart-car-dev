摘要
本技术报告详细阐述了第二十一届全国大学生智能汽车竞赛 "疯狂电路" 组别中，本队的系统设计方案。针对赛事规则中高速循迹与负压吸附协同作业的高难度要求，本队设计了一套以英飞凌 TC264 双核微控制器为核心，集双路电机驱动、负压风机控制、机器视觉导航与多闭环运动控制于一体的智能车系统。
在硬件设计层面，系统采用三级降压电源架构，以 TPS82130 集成降压转换器为电源枢纽，实现 12V 动力母线、5V 中间总线和 3.3V 逻辑总线的分区供电；驱动部分采用两片 DRV8701E 全桥栅极驱动器配合外置功率 MOSFET 构建双路独立 H 桥，实现双电机四象限运行与电流闭环控制；负压系统通过外接基于 STC32G12K128 的无刷电调驱动 1202.5 无刷电机，为车体提供稳定吸附力。PCB 采用四层板设计，通过功率回路最小化与电源域物理分隔保障信号完整性与散热性能。
在软件算法层面，采用 MT9V034 灰度摄像头采集赛道图像，通过 Otsu 自适应阈值分割与八邻域搜索提取赛道边界，经最小二乘直线拟合获得循迹偏差；速度控制采用增量式 PI 算法实现左右轮独立闭环，方向控制采用非线性变增益 PD 外环与 LSM6DSRTR 陀螺仪角速度内环相结合的双闭环结构，并结合 Flash 预存路径信息辅助复杂节点判断，实现高精度循迹与稳定转向。
实验结果表明，该系统在赛道识别稳定性、转向响应速度及负压吸附可靠性上均表现优异，成功实现了高速工况下的精准循迹与稳定运行。

第一章 系统概述及创新点
1.1 系统概述
本系统为全国大学生智能汽车竞赛 "疯狂电路" 组别设计的整车控制硬件平台。系统以英飞凌 SAK-TC264D-40F200N 微控制器为核心，集成双路有刷直流电机驱动、无刷负压风机驱动接口及多电压轨电源管理，实现对智能车整车运动的精确控制。
整车采用 3S 300mAh 锂电池供电，系统电压轨包括 12V 动力母线、5V 中间总线和 3.3V 逻辑总线三级。动力部分驱动两路 LQ1518-030K-A 有刷直流电机（额定电压 11.1V，空载转速 42000rpm），负压部分驱动 1202.5 无刷电机实现车体负压吸附功能。
系统采用分层架构，自下而上分为电源层、驱动层、控制层和接口层：
电源层：3S 锂电池输入经保护滤波后，一路直供 12V 动力母线，另一路经降压芯片生成 5V，再经 LDO 稳压至 3.3V。
驱动层：两片 DRV8701E 全桥栅极驱动器配合外置功率 MOSFET，构建两路独立 H 桥，实现双电机四象限运行。
控制层：TC264 双核微控制器运行电机控制算法、姿态解算和赛道识别决策。
接口层：提供 FPC 摄像头接口、编码器接口、调试接口及状态指示。

1.2 硬件创新
1.2.1三级降压电源架构与集成降压方案
本系统电源部分采用三级逐级降压的配电方案。3S 锂电池输出电压约 11.1V，经保护与滤波电路后形成 12V 动力母线，直接向电机 H 桥和负压电调供电；同时通过 TPS82130 降压芯片生成 5V/3A 中间总线，为摄像头、编码器等外设供电；最后经多路 LDO 稳压得到 3.3V 逻辑总线，为主控及数字电路供电。
作为电源架构的核心转换器件，TPS82130SILR 负责将 12V 动力母线降至 5V 中间总线。该器件由 TI 公司推出，是一款内置功率电感的集成型降压转换器，采用 USIP-8 封装（尺寸 3.0mm×2.8mm），具有以下特点：
（1）稳定的电压转换：可将 3S 锂电池 9V~12.6V 的输入电压稳定输出为 5V，最大输出电流达 3A，为后级 3.3V LDO 和 5V 外设提供可靠的中间电源。5V 总线作为二级配电节点，起到了动力域与逻辑域之间的供电衔接作用。
（2）高度集成化设计：芯片内部已集成开关 MOSFET 和功率电感，外围电路仅需配置输入输出电容即可正常工作，显著缩减了 PCB 布板面积和元器件数量，这对于车体空间紧张的智能车应用尤为关键。
（3）高效低损耗运行：采用固定频率 PWM 控制方式，典型转换效率超过 95%；轻载条件下自动切换至省电模式以降低静态功耗，从而延长电池续航时间。高效率也意味着发热量更小，减轻了散热设计负担。
（4）宽输入电压范围：支持 3V~17V 输入，完全覆盖 3S 锂电池从满电 12.6V 到放电截止 9V 的整个工作区间，确保在电池电压逐渐下降的过程中 5V 输出始终保持稳定。

输出端采用大容量陶瓷电容与高频去耦电容搭配的方式，以保障输出电压的瞬态响应能力和低纹波特性。其输出基准电压经典值为，输出电压计算公式为

1.2.2 分立式H桥双电机驱动与电流闭环
电机驱动部分采用 DRV8701E 全桥栅极驱动器搭配外置 N 沟道 MOSFET 的分立式 H 桥方案。系统共使用两片 DRV8701E，每片独立驱动一个 H 桥，分别控制两台 LQ1518-030K-A 有刷直流电机。
DRV8701E 芯片内部集成了电流采样放大器、VDS 过流检测及过热保护功能，配合低导通内阻的功率 MOSFET，可实现大电流、高效率的电机驱动。H 桥拓扑支持四象限运行，能够完成电机正反转、能耗制动以及再生制动等多种工况。
每个 H 桥均在低边侧设置电流采样电阻，采样所得电压信号经 DRV8701E 内置放大器放大后输入主控 ADC，从而实现电机相电流的实时采集与闭环调节。电流闭环的作用主要体现在三个方面：抑制启动瞬间的冲击电流、实现转矩闭环控制，以及在电机堵转时提供有效保护。

1.2.3 外置无刷电调负压驱动方案
负压吸附系统采用 1202.5 型无刷电机作为风机动力源，通过主板上预留的接口外接无刷电子调速器进行驱动。主控输出的 PWM 调速信号经缓冲处理后送至电调，以此控制负压风机的转速；电调本身由 12V 动力母线直接供电。将三相逆变电路独立于主控板之外，有效降低了主控板的发热量并缩减了主板体积。
该负压电调以 STC32G12K128 单片机为主控芯片，是一款专为三相无刷直流电机（BLDC）设计的电子调速器（ESC）。功率级采用 EG2134 专用栅极驱动芯片驱动 6 路 NMOS 管构成三相全桥逆变电路，支持电池直接供电，并通过 3Pin 接口接收 PWM 或 PPM 调速信号

1.3.4 预存路径辅助节点判断
赛前根据赛道实际布局人工规划一条最优行驶路线。车辆沿该路线完成一次记录行驶后，系统将所得路径信息自动写入 Flash 保存。正式比赛时，车辆读取已存储的路径数据，与实时视觉检测结果协同工作，辅助车辆按照预定路线完成自主行驶。
在该方案中，预存路径信息主要承担全局路线引导的作用，而视觉系统则持续负责局部赛道边界、中线及循迹偏差的实时检测。两者结合后，车辆在复杂交叉节点和连续弯道等视觉容易失效的场景下，运行可靠性得到明显提升。



第二章 硬件电路设计
2.1 主控单元设计
2.1.1 TC264 主控芯片选型与作用
主控采用英飞凌 AURIX 系列SAK-TC264D-40F200N微控制器，是整个系统的运算与控制核心。
该芯片基于 TriCore 架构，集成两个主频 200MHz 的处理器内核，内置 2MB Flash 和 256KB SRAM。其主要作用体现在以下方面：
（1）电机实时控制 利用芯片内置的捕获比较单元（CCU6）和通用定时器（GPT12），产生高精度 PWM 信号驱动电机，并通过 ADC 采集电流采样信号，实现转速闭环和电流闭环控制。双核架构中，一个内核专门负责电机控制的实时任务，保证控制周期的确定性。
（2）图像采集与处理 通过并行接口采集摄像头图像数据，利用另一个内核运行赛道识别和路径规划算法，输出转向和速度决策。双核分工确保图像识别不会影响电机控制的实时性。
（3）传感器数据融合 通过 ADC、SPI、UART 等接口采集编码器、陀螺仪等传感器数据，进行车速测量和姿态解算，为控制算法提供反馈。
（4）系统管理与通信 负责整车的状态管理、故障诊断、参数存储以及与上位机的通信调试。
TC264 在汽车电子领域有广泛应用，工业级温度范围和高抗干扰能力满足智能车竞赛复杂电磁环境下的可靠运行需求。LQFP144 封装提供充足的 I/O 引脚，支持多路传感器和执行器的同时接入。

2.1.2 时钟与调试接口
主控采用 20MHz 无源晶振作为外部时钟源，经内部 PLL 倍频至 200MHz 系统时钟。通过 2x5P 双排排座引出 JTAG 调试接口，支持程序下载和在线调试。

2.2 电源系统设计
2.2.1 三级降压电源架构
电源系统采用三级降压架构：
3S锂电(11.1V) → 保护滤波 → 12V动力母线 → 电机H桥 / 负压电机
                             ↓
                         TPS82130降压 → 5V/3A → 多路LDO → 3.3V
12V 母线直接为电机驱动级和负压电调供电；5V 总线为摄像头、编码器等外设供电；3.3V 总线为主控和逻辑电路供电。
2.2.2 TPS82130 核心降压电路
TPS82130SILR是系统电源架构的核心器件，承担从 12V 动力母线到 5V 中间总线的降压转换。
该芯片是 TI 推出的集成电感降压转换器，USIP-8 封装（3.0mm×2.8mm），其主要作用和特点如下：
（1）电压转换作用 将 3S 锂电池的 9V~12.6V 输入电压稳定降压至 5V 输出，最大输出电流 3A，为后续 3.3V LDO 和 5V 外设提供稳定的中间电源。5V 总线作为系统的二级配电枢纽，是连接动力域与逻辑域的桥梁。
（2）高集成度优势 TPS82130 内部集成了开关 MOSFET 和功率电感，外围仅需输入输出电容即可工作，大幅减少了 PCB 占用面积和器件数量。对于空间受限的智能车应用，这一特性尤为重要。
（3）高效率与低损耗 采用固定频率 PWM 控制模式，典型转换效率可达 95% 以上。轻载时自动进入省电模式，降低静态功耗，延长电池续航时间。高效率意味着更少的发热，减少了散热设计压力。
（4）宽输入电压适应 输入电压范围 3V~17V，完全覆盖 3S 锂电池的工作电压范围（满电 12.6V 至放电截止 9V），在电池电压波动过程中始终保持稳定的 5V 输出。
输出端配置大容量陶瓷电容和高频去耦电容组合，保证输出电压的瞬态响应和低纹波特性。

第三章 软件系统设计
3.1 软件总体架构
本系统以 TC264 微控制器为核心，完成图像处理、路径判断、角速度信息采集、速度检测、方向控制及电机驱动等任务。软件采用主循环与周期任务相结合的结构：主循环主要负责图像获取与处理、路径判断等任务；定时中断周期执行陀螺仪角速度采集、编码器测速、速度闭环和方向内环等实时控制任务，以保证图像处理与运动控制之间的协调性和实时性。
车辆运行过程采用状态管理方式，根据当前运行状态执行相应控制逻辑。系统上电后完成外设及控制参数初始化，进入运行后持续进行视觉检测、路径判断和闭环控制；当出现图像异常、电机堵转或到达终点等状态时，程序执行相应处理。
3.2 赛道视觉检测

负压风机采用电子调速器驱动，TC264 输出 PWM 控制信号调节风机工作状态。风机启动阶段采用缓启动方式，以减小瞬时冲击；正常运行后保持设定输出，为车辆高速运行提供稳定的负压吸附能力。

3.9 异常状态处理
软件针对车辆运行过程中可能出现的异常状态设置相应保护逻辑。主要包括图像异常处理、电机堵转处理和终点停车。当视觉信息异常或驱动状态异常时，程序进入对应处理流程；车辆到达预设终点后，系统判定运行完成并执行停车。

// ===== 1. 图像自适应阈值分割（deal_img.c） =====
 
uint8 calcOtsuThreshold(void)
{
    getGrayscaleHistogram();
    uint32_t sum = 0, valueSum = 0;
    uint64_t sigma = 0, maxSigma = 0;
    float w1 = 0, w2 = 0;
    int32_t u1 = 0, u2 = 0;
    uint8 minimumValue = 0, maximumValue = 255;
 
    minimumValue = minGray;
    maximumValue = maxGray;
    if(maximumValue < minThreshold)     return minThreshold;
    if(minimumValue > maxThreshold)     return maxThreshold;
 
    minimumValue = minimumValue < minGrayscale ? minGrayscale : minimumValue;
    maximumValue = maximumValue > maxGrayscale ? maxGrayscale : maximumValue;
 
    uint32_t lowSum[256] = {0};
    uint32_t lowValueSum[256] = {0};
    for (uint16_t i = minimumValue; i <= maximumValue; ++i)
    {
        sum += grayHistogram[i];
        valueSum += grayHistogram[i] * i;
        lowSum[i] = sum;
        lowValueSum[i] = valueSum;
    }
    for (uint16_t i = minimumValue; i < maximumValue + 1; ++i)
    {
        w1 = (float)lowSum[i] / sum;
        w2 = 1 - w1;
        u1 = (int32_t)(lowValueSum[i] / w1);
        u2 = (int32_t)((valueSum - lowValueSum[i]) / w2);
        sigma = (uint64_t)(w1 * w2 * (u1 - u2) * (u1 - u2));
        if (sigma >= maxSigma)
        {
            maxSigma = sigma;
            otsuThreshold = i;
        }
        else
        {
            break;
        }
    }
    otsuThreshold = otsuThreshold < minThreshold ? minThreshold : otsuThreshold;
    otsuThreshold = otsuThreshold > maxThreshold ? maxThreshold : otsuThreshold;
    lastOtsuThreshold = otsuThreshold;
    return otsuThreshold;
}
// ===== 2. 中线拟合与视觉偏差计算（direction.c） =====
 
uint8 fitMidLine(float result[2])
{
    LineFitSum_t sum = {0};
    uint8 previousRow = 255;
    uint8 row;
 
    for(row = seedCenterY; row < validLineEnd; ++row)
    {
        float x;
        float y;
 
        if(!centerPointIsContinuous(row, previousRow))
        {
            continue;
        }
        previousRow = row;
        x = rowForwardScale[row];
        y = (centerLine[row] - XM / 2) * rowLateralScale[row];
        sum.x += x;
        sum.y += y;
        sum.xy += x * y;
        sum.xx += x * x;
        ++sum.count;
    }
 
    if(sum.count >= 2)
    {
        const float divisor = sum.count * sum.xx - sum.x * sum.x;
 
        if(absFloat(divisor) >= 0.000001f)
        {
            result[0] = (sum.count * sum.xy - sum.x * sum.y) / divisor;
            result[1] = (sum.y - result[0] * sum.x) / sum.count;
            return sum.count;
        }
    }
    return 0;
}
 
void updateLineError(void)
{
    lastLineErr = lineErr;
 
    if(validLineEnd && (fitMidLine(midFit) >= 2))
    {
        const float slopeWeight = fitKWeight / 10.0f;
        const float offsetWeight = fitBWeight / 100.0f;
 
        lineErr = midFit[0] * slopeWeight + midFit[1] * offsetWeight;
        lineErr = clampFloat(lineErr, lineErrLimit, -lineErrLimit);
    }
    else
    {
        lineErr = lastLineErr;
    }
 
    if(goMode == United_RUN)
    {
        lineErr = blendMapHeading(lineErr);
    }
    lineErr = clampFloat(lineErr, lineErrLimit, -lineErrLimit);
 
    if(!(lineErr == lineErr))
    {
        lineErr = lastLineErr;
    }
}

    if(findEdgeSeeds())
    {
        traceEdgesUp(seedLeft,seedCenterY,seedRight,seedCenterY);
        updateLostEdges(2);
 
        if(distanceGateEnabled())
        {
            if(routeNodeIndex < stopNodeIndex)
            {
                if(pathSource == PATH_SOURCE_WAIT)
                {
                    extractStraightPath();
                }
                else if(pathSource == PATH_SOURCE_MAP)
                {
                    extractMappedPath();
                }
                else
                {
                    extractVisualPath();
                }
            }
        }
        else if(goMode != United_RUN)
        {
            switch(routeDirections[routeNodeIndex])
            {
                case ROUTE_STRAIGHT:
                    makeCenterPath();
                    break;
                case ROUTE_LEFT:
                    makeLeftPath();
                    break;
                case ROUTE_RIGHT:
                    makeRightPath();
                    break;
            }
        }
        else if(goMode == United_RUN)
        {
            applyMappedPath();
        }
    }
 
    recordNodeDistance();
 
    /* 先记录45度转弯中心，再执行Map模式节点切换。 */
    finishMappedNode();
    updateLineError();
    applyApproachHeading();
    applyRouteHeading();
    speedSegment = classifyRoadSpeed();
 
}
// ===== 4. 速度与方向闭环控制（control.c） =====
 
void runWheelSpeedLoop(void)
{
    WheelOutputRange_t range;
 
    carCfg.targetSpeed = selectTargetSpeed();
    calculateWheelTargets();
    wheelPid.errorCeiling = 100.0f;
    wheelPid.errorFloor = -100.0f;
    range = chooseWheelOutputRange();
 
    updateWheelChannel(driveInfo.targetL, driveInfo.speedL, &wheelPid.errorLeft, wheelPid.errorHistoryLeft, wheelPid.deltaHistoryLeft, (float)wheelPid.kpLeft, (float)wheelPid.kiLeft, &wheelPid.outputLeft, range.leftMin, range.leftMax);
 
    updateWheelChannel(driveInfo.targetR, driveInfo.speedR, &wheelPid.errorRight, wheelPid.errorHistoryRight, wheelPid.deltaHistoryRight, (float)wheelPid.kpRight, (float)wheelPid.kiRight, &wheelPid.outputRight, range.rightMin, range.rightMax);
}
 
void runLaneLoop(void)
{
    float proportionalGain;
 
    lanePid.error = ((runState == TEST) && (carCfg.mode == SPEED_TEST)) ? 0.0f : -lineErr;
    lanePid.errorDelta = lanePid.error - lanePid.previousError;
    lanePid.previousError = lanePid.error;
 
    proportionalGain = lanePid.kp / 10.0f + absFloat(lanePid.error * lanePid.error) / 3000.0f * lanePid.extraKp / 10.0f;
    lanePid.output = proportionalGain * lanePid.error + lanePid.kd / 10.0f * lanePid.errorDelta;
    lanePid.correctedCurvature = lanePid.output / 100.0f * PI / 180.0f;
    lanePid.correctedCurvature = limitCurvatureByAcceleration( lanePid.correctedCurvature);
    lanePid.commandedCurvature = lanePid.correctedCurvature
                                 * 180.0f / PI * 100.0f;
}
 
void runYawRateLoop(void)
{
    yawPid.previousError = yawPid.error;
    yawPid.error = clampFloat(lanePid.targetYawRate + motionAtt.yawRate, 600.0f, -600.0f);
    pushHistory(yawPid.errorHistory, 5, yawPid.error);
 
    yawPid.kp = yawPid.baseKp;
    yawPid.kd = yawPid.baseKd;
    pushHistory(yawPid.deltaWindow, 3, yawPid.errorHistory[0] - yawPid.errorHistory[3]);
    pushHistory(yawPid.feedbackWindow, 3, motionAtt.yawRate);
    yawPid.derivative = yawPid.feedbackWindow[0] - yawPid.feedbackWindow[3];
    yawPid.rawOutput = yawPid.kp / 10.0f * yawPid.errorHistory[0] - yawPid.kd / 10.0f * yawPid.derivative;
 
    pushHistory(yawPid.outputWindow, 3, yawPid.rawOutput);
    yawPid.output = 0.8f * yawPid.outputWindow[0] + 0.2f * yawPid.outputWindow[1];
    yawPid.output = clampFloat(yawPid.output, 2055.0f, -2055.0f);
}
// ===== 5. 1 ms惯性测量数据更新（IMU.c） =====
 
void imuSampleUpdate(void)
{
    ImuRawSample_t raw;
 
    readImuRaw(&raw);
    applyFirstOrderLowPass(35, 1000, (float)raw.gx - gyroBias.x, &filteredGyroX);
    applyFirstOrderLowPass(35, 1000, (float)raw.gy - gyroBias.y, &filteredGyroY);
    applyFirstOrderLowPass(35, 1000, (float)raw.gz - gyroBias.z, &filteredGyroZ);
    applyFirstOrderLowPass(35, 1000, (float)raw.ax, &filteredAccX);
    applyFirstOrderLowPass(35, 1000, (float)raw.ay, &filteredAccY);
    applyFirstOrderLowPass(35, 1000, (float)raw.az, &filteredAccZ);
 
    filteredAccX = accToG(filteredAccX);
    filteredAccY = accToG(filteredAccY);
    filteredAccZ = accToG(filteredAccZ);
    filteredGyroX = gyroToDps(filteredGyroX);
    filteredGyroY = gyroToDps(filteredGyroY);
    filteredGyroZ = gyroToDps(filteredGyroZ);
 
    attitudeUpdate(filteredGyroX / 57.3f, filteredGyroY / 57.3f, -filteredGyroZ / 57.3f, -filteredAccX, -filteredAccY, -filteredAccZ, &attitude);
 
    motionAtt.yawRate = filteredGyroZ;
    motionAtt.pitchRate = filteredGyroY;
    motionAtt.pitch = attitude.pitch;
    motionAtt.trueYawRate = motionAtt.yawRate;
    motionAtt.turnAngle += motionAtt.trueYawRate * IMU_SAMPLE_DT;
    yawAngle = motionAtt.turnAngle;
}
// ===== 6. 电机与负压输出（motor.c） =====
 
void motorOutputApply(void)
{
    selectDriveOutput();
    driveInfo.pwmR = func_limit_ab(driveInfo.pwmR, -9333, 9333);
    driveInfo.pwmL = func_limit_ab(driveInfo.pwmL, -9333, 9333);
 
    motorMagnitude[0] = setMotorDirection(driveInfo.pwmL, MOTOR_DIR_L, Dir_L);
    motorMagnitude[1] = setMotorDirection(driveInfo.pwmR, MOTOR_DIR_R, Dir_R);
    pwm_set_duty(MOTOR_PWM_L, motorMagnitude[0]);
    pwm_set_duty(MOTOR_PWM_R, motorMagnitude[1]);
}
 
void setVacuumDuty(uint32 duty)
{
    if(duty > 10)
    {
        duty = 0;
    }
    vacuumDuty = (int32)duty;
 
    if(duty == 0)
    {
        pwm_init(MOTOR_Pressure, 50, 500);
    }
    else if(duty <= 7)
    {
        pwm_set_duty(MOTOR_Pressure, 500 + 50 * duty);
    }
    else
    {
        pwm_set_duty(MOTOR_Pressure, 675 + 25 * duty);
    }
}
