第一章　引　言
1.1　第二十一届智能车大赛介绍
全国大学生智能汽车竞赛是一项极具影响力的学科竞赛，由中国自动化学会主办，旨在激发大学生创新活力、培育智能车领域专业人才、推动智能交通与人工智能技术进步。竞赛以“立足培养、重在参与、鼓励探索、追求卓越”为指导思想，为全国高校学生提供了将自动控制、模式识别、传感技术、电子、电气、计算机与机械等多学科知识综合应用的实践平台。
比赛分为分赛区选拔赛和全国总决赛两个阶段。分赛区选拔赛中，各参赛队伍需充分发挥智慧与团队协作精神，设计并制作一辆能够自主完成复杂任务的智能车，评委会从车辆性能、任务执行情况、创新程度等多维度综合考量，选拔表现优异的队伍晋级全国总决赛。全国总决赛汇聚各赛区精英队伍，在复杂环境下考察智能车的精准感知、快速决策与准确执行能力，是展示智能车顶尖技术水平与创新成果的重要舞台。
参加智能汽车竞赛，对学生而言是一次全方位的锻炼。通过备赛与参赛，学生能够在实际操作中大幅提升工程实践能力与科学素养，培养自主学习和自我提升的能力，同时结识志同道合的伙伴，为未来的职业发展和学术研究筑牢根基。
1.2　第二十一届智能车大赛规则介绍
本队参加的组别为“疯狂电路”。本届大赛指定统一车模平台，对车模的机械调整与修改有严格要求。比赛在室内缩微场地进行，赛道为蓝色地面，设有宽度约 20±5mm 的白色中心引导线，包含元器件 路肩 等赛道元素。参赛车模需从起跑线出发，连续运行一圈数后返回起跑线并准确停车；允许增加负压风扇以增强抓地力；传感器及电子部件（除特定情况外）不得包含独立微处理器，传感器数量自定，需搭配契合组别特性的传感器及辅助传感器。主控制器采用 32 位微控制器，本队选用 AURIX TC264高性能单片机。

第二章　机械结构设计
智能小车的机械部分设计对整个车辆的性能至关重要，它直接决定了车辆的理论最高速度与运行稳定性。因此在调试之前保证良好的机械结构非常重要。智能小车的机械部分包括传感器安装支架设计、摄像头固定角度与高度调整、陀螺仪的减震安装、编码器的同轴连接、电路板的防震固定、车模重心平衡调节、电池的轻量化安装及负压风扇的适配等方面。本章重点介绍这些机械部分的设计。
2.1　智能车机械结构总体设计
智能车机械结构的整体设计思路是以提高车辆的稳定性、灵活性和响应速度为核心目标，追求低重心、轻量化以及高刚性。为尽可能实现轻量化，本队选用轻质材料制作非承重部件，并采用下沉式布局降低整体结构重心，将电池、主板等重质部件尽可能布置在车辆底部，提高车辆稳定性，减小高速行驶时的侧翻风险。
2.1.1　车模选择
本队选用逐飞（SEEKFREE）成品车模作为基础平台，并对车模轮胎进行了更换，采用自制硅胶轮胎以提升抓地力。车模采用双电机差速驱动方式，无转向舵机，通过左右轮转速差实现转向，结构简洁、响应迅速。
2.1.2　车模整体布局
车模主要由主板、电机驱动板、总钻风摄像头、IMU660RB 陀螺仪、左右磁编码器、负压风扇、电池等模块组成。主板与驱动板采用铜柱固定于车模上平面，电池布置于底盘后方，负压风扇布置于底盘中央上方以产生下压力。车模的长、宽、高分别为 240mm、150mm、245mm。

图2.1　车模整体布局
2.2　智能车机械结构部分设计
2.2.1　电池的固定
在车辆行驶过程中，电池会受到加速、减速、转弯时产生的惯性力以及持续振动等作用，固定不牢固的电池可能脱落，影响小车行驶。本队使用魔术贴和绑带将电池固定在车辆后方，使其更加稳固。无论小车如何加速、过弯，电池都能保持稳定位置。同时，魔术贴和绑带便于快速更换、检查或调整电池位置，并具有一定的缓冲作用，能够吸收振动能量，降低电池损坏风险。
2.2.2　轮胎处理
为提升轮胎的摩擦系数与耐磨性，本队采用自制硅胶轮胎，并在轮胎表面涂抹软化剂，使轮胎表皮变软、与地面的接触面积更大，从而增强抓地力。同时使用胶水将胎皮与轮毂粘接，避免高速行驶时跳轮，提高整体耐磨性与稳定性。
2.2.3　传感器的设计与安装
摄像头：摄像头采用总钻风（MT9V03X）灰度摄像头，安装于车头前瞻位置，通过镜头倾角调整扩大视野，可提前捕捉前方赛道的走向。由于不同场地光线情况差异较大，且比赛调试时间有限，本队在摄像头上方加装 3D 打印的非承重遮光板，遮挡过曝光线，减少环境光对图像采集的影响。
陀螺仪：本队选用 IMU660RB 六轴陀螺仪，用于实时检测车模的角速度与姿态，帮助判断小车当前转弯速度，进而参与转向内环控制。陀螺仪通过减震海绵安装于车身重心附近，降低机械振动对姿态数据稳定性的影响。
编码器：本队采用左右两个磁编码器，分别与驱动轮同轴安装，用于实时测量车轮的转速与转动方向，为速度闭环控制和里程计算提供精确反馈。
2.3　系统电路板的固定及连接
本队电路板主要包括主板、电机驱动板等。主板使用铜柱固定于车模上平面，驱动板固定于车模靠近电机的位置，保证连接的牢固与检修的方便。电源线使用 17AWG 线材和电源端子连接，信号线使用杜邦线连接，便于快速更换与局部维修。所有连接线材均使用扎带固定在车模上，减小线缆晃动对车辆重心与信号的影响。
第三章　硬件电路的设计
智能车电路部分主要包括单片机最小系统、电源模块、电机驱动模块、负压风扇驱动模块与传感器模块。各模块的总体设计原则是：紧凑、易于拆换、稳定可靠。主控制器采用英飞凌 AURIX™ TC264 双核微控制器。
3.1　硬件电路整体构架
系统以 TC264 最小系统为核心，通过电源模块将电池电压转换为各模块所需的 5V 与 3.3V；总钻风摄像头、IMU660RB 陀螺仪、左右磁编码器、按键等作为感知输入；左右电机与负压风扇作为执行输出；同时配置 IPS200 屏幕、RGB 状态灯与无线串口用于人机交互与调试。整体框架如图 3.1 所示。

图3.1　硬件电路整体框架图
3.2　硬件电路部分模块
3.2.1　单片机最小系统模块
本队选用的 TC264 单片机来自英飞凌专为汽车电子设计的 AURIX 系列，属于高性能 32 位 MCU。它采用 TriCore 架构，集成双核 CPU，最高主频达 200MHz，具备强大的处理能力，能够从容应对智能汽车竞赛中复杂且需实时处理的图像与运动控制任务。
TC264 内部集成了丰富的资源，拥有大容量 Flash 与 SRAM，足以存储复杂的控制程序及运行过程中产生的大量数据。其具备丰富的通信接口，包括 UART、SPI、I2C、CAN 等，可满足车模内部各模块间高速、稳定的数据交互需求。此外，TC264 还内置多个高精度定时器与 ATOM 等 PWM 输出通道，可精准控制电机转速，保障车模运动控制的精确性。
3.2.2　电源模块
电源模块是车模各组件稳定工作的基础。系统通过插头接入 3S 锂电池，借助开关控制电路通断，并采用稳压芯片分别构建 5V 与 3.3V 稳压电路，结合滤波电容、限流电阻等元件对输入电源进行滤波、稳压处理，为车模提供稳定的直流电压。滤波电容可抑制输入电压的纹波与噪声，发光二极管可直观显示电源工作状态。
3.2.3　电机驱动模块
车模采用双电机差速驱动方式。TC264 通过 ATOM 定时器输出 15kHz 的 PWM 信号，并配合方向控制引脚控制 H 桥驱动电路，实现左右电机的正反转与调速。PWM 频率设置为 15kHz，可有效降低电机运行噪声，提高调速平稳性。左右电机分别配有磁编码器，通过定时器编码器模式进行脉冲计数，实现转速与里程的精确测量。
3.2.4　负压风扇驱动模块
为增强车模在高速运行与过弯时的抓地力，本队增加了负压风扇。负压风扇采用无刷电机驱动，TC264 通过 PWM 信号调节风扇转速，进而控制底盘负压大小。负压大小根据行驶状态动态调节，在直线加速与高速过弯时增大负压，提高轮胎与地面的附着力，抑制侧滑。
3.2.5　传感器模块
（1）摄像头：总钻风 MT9V03X 灰度摄像头作为核心视觉传感器，通过 DVP 接口配合 DMA 完成图像采集，通过 UART 接口配置曝光时间等参数。摄像头实时采集赛道图像，为循迹与元素识别提供依据。
（2）陀螺仪：IMU660RB 六轴陀螺仪通过 SPI 接口与主控通信，实时输出三轴角速度与三轴加速度，为转向内环角速度控制和姿态解算提供数据。
（3）磁编码器：左右两个磁编码器与驱动轮同轴安装，输出 A/B 相脉冲，由定时器编码器模式计数，实现车轮转速与转动方向的精确测量。
第四章　总体理论分析及控制软件算法实现
4.1　系统控制总体设计
本辆智能车采用“环境感知—决策规划—运动执行”的闭环架构。感知层利用摄像头实时捕捉赛道图像，通过算法准确识别赛道线，同时陀螺仪提供车身姿态数据，编码器提供轮速与里程；决策层根据感知到的赛道信息，计算转向控制量与目标速度，并结合地图节点信息进行路径规划；执行层通过 PWM 信号实现左右电机的差速驱动，并动态调节负压风扇。系统总体控制框图如图 4.1 所示。

图4.1　系统总体控制框图
4.2　软件系统设计及实现
软件系统围绕赛道精准识别、快速决策和稳定控制展开，采用模块化设计思想，便于开发、调试和功能扩展。整个系统以 TC264 双核微处理器为核心：CPU0 负责基础时钟与调试初始化，CPU1 负责参数初始化、设备初始化以及主循环中的图像采集、图像处理、方向控制与地图记录等任务。中断服务程序中以 500μs 为基准周期，分时执行电压检测、状态机跟踪、测速、速度环、方向内环与陀螺仪数据读取，实现多任务实时调度。
软件各功能模块主要包括：Init（参数与设备初始化）、deal_img（图像处理与元素识别）、direction（中线拟合与偏差计算）、control（方向环与速度环）、motor（电机输出与负压控制）、IMU（姿态解算）、speed（速度决策）、map/Node（地图记录与节点规划）、Filter（数字滤波）、GUI/observer（显示与调试）、Flash（参数与地图存储）以及 RGB（状态指示）。
4.3　相关控制设计
4.3.1　图像处理与赛道元素识别
图像处理是循迹控制的基础。系统采用大津法（OTSU）自适应阈值分割，对采集的灰度图像进行二值化，将白色引导线从蓝色背景中分离。随后采用八邻域边界搜索算法，从起点向左右两侧逐行搜索赛道边界，得到左右边界点，进而提取赛道中线。为提高中线稳定性，采用最小二乘法对中线点进行直线拟合，得到赛道中心线的斜率与截距，据此计算车模相对于赛道中心的横向偏差。
针对断路区、虚线区、六边形环岛、直角、十字等特殊元素，系统通过四方位（上、下、左、右）边界搜索与白色像素统计进行识别：当中间区域白色像素少于设定阈值时判定为断路，依赖惯导数据通过；虚线区通过多轮向上搜索直至找到有效引导线来适配；环岛与直角则根据三向或两向引导线特征进行判定，并结合陀螺仪累计角度控制绕环进度。
4.3.2　转向控制设计
车模采用差速转向方式，转向控制采用“方向外环＋方向内环”的串级闭环结构，如图 4.2 所示。方向外环以摄像头提取的赛道横向偏差为输入，采用 PD 控制（含非线性比例增益）将位置偏差转换为期望转向曲率，并通过向心加速度限幅对曲率进行约束，防止高速过弯时侧滑。方向内环以陀螺仪检测的车模角速度为反馈，采用微分先行的 PD 控制，将期望角速度转换为左右电机的差速控制量，实现快速、稳定的转向响应。串级结构使外环输出的期望角速度作为内环的给定值，内环的快速响应抑制了车模角速度的波动，提高了转向的平稳性与精度。

图4.2　方向串级闭环控制框图
4.3.3　速度控制设计
速度控制采用双轮独立闭环控制。以编码器反馈的左右轮速与目标轮速的偏差为输入，采用增量式 PI 控制算法，结合误差限幅与抗积分饱和处理，输出 PWM 控制量。为配合差速转向，目标轮速根据方向环输出的转向量对左右轮分别进行加减，实现转向时左右轮的转速差配合。
速度决策根据赛道类型动态设定期望速度：直道高速行驶以提升效率，弯道减速以保证转向稳定，并区分长直道冲刺、短直道、刹车段、弯道与停车等状态。在图像与地图联合运行模式下，系统根据当前路段剩余里程与前方拐点信息，实现“满格加速—减速段—过弯段”的分段调速，兼顾速度与稳定性。
4.3.4　地图与节点路径规划
针对缩微光电组需连续运行并返回起跑线的赛制，本队设计了基于节点（Node）的地图记录与回放机制。在录制运行阶段，系统实时记录赛道中各拐点的方向（左转/右转/直行）以及相邻拐点之间的路段里程，并存储至 Flash。在正式运行阶段，系统将存储的节点信息与实时图像处理结果进行融合，在接近拐点时根据存储的方向与角度信息提前调整转向与速度，实现更高效、更稳定的循迹。
4.4　参数调试
辅助调试程序包括两个部分：一是基于按键与 IPS200 屏幕的菜单与 PID 参数输入程序，可在现场快速整定方向环、速度环参数；二是基于无线串口模块的数据发送，将理想速度与实际速度等关键数据实时上传至上位机，通过虚拟示波器观察各环路的响应曲线，据此确定最优参数。系统还提供“观察者模式”，可分别显示图像数据、控制输出、IMU 数据与里程数据，便于分模块定位问题。

第五章　开发工具、制作、安装、调试过程说明
5.1　开发工具
5.1.1　软件开发环境
软件开发在英飞凌 AURIX Development Studio（ADS）集成开发环境下进行，配合 TASKING 编译器完成编译与下载。ADS 集成了编译器、调试器与代码分析工具，能够生成体积小、性能优的代码，并支持快速定位问题，适合 AURIX 系列 MCU 的嵌入式开发。底层驱动基于逐飞科技提供的 TC264 开源库，并在此基础上编写应用层算法。
5.1.2　硬件开发环境
硬件开发环境使用 Altium Designer 进行原理图设计与 PCB 绘制。Altium Designer 将原理图设计、电路仿真、PCB 绘制编辑、自动布线与信号完整性分析等功能融合在一起，可在统一界面中完成整个设计流程，减少设计错误，提高设计效率。
5.2　制作过程
（1）设计与绘制电路图：根据功能需求，设计并绘制智能车相关电路图，明确电源电压、电流、功耗等性能指标，确保各模块获得稳定供电。
（2）PCB 设计与制作：将电路图转化为 PCB 板，完成布线与布局，选择合适的制造商制作 PCB 板。
（3）元器件焊接：根据 PCB 板上的元器件位置进行焊接，确保焊接质量，避免虚焊、冷焊、短路等问题。
（4）程序开发：依据竞赛规则明确任务，设计分层架构程序，涵盖传感器采集处理、电机驱动与决策算法等模块，采用 C 语言进行开发。
（5）调试：完成硬件制作和程序开发后，先单独调试各模块，得到稳定数据后再整体联调。
5.3　安装过程
将车模底板框架拼装好，使用螺丝固定各部件，安装车轮和电机，确保电机轴与车轮对齐，使用热熔胶加固关键连接点；在底板上选择合适位置安装电池，确保电池方便取放；将驱动板固定在靠近电机的位置，使用杜邦线连接电机与驱动板；将主板固定在车模中央，使用杜邦线连接主板与驱动板、传感器等；将电池连接到主控板电源输入端，确保电源线连接牢固、无短路风险；在车头正前方安装摄像头，使用支架固定并调整视角；在底板中央安装陀螺仪并加装减震；安装负压风扇并固定。
5.4　调试过程
完成硬件制作和程序开发后，先单独调试传感器模块，确保数据采集准确，通过示波器与屏幕观察输出信号；再对电机驱动与负压风扇控制模块进行单独调试；最后将各模块集成联调，检查模块间的通信与协作。在模拟赛道上观察智能车运行情况，根据运行表现优化决策算法与控制参数，并在真实竞赛赛道上进行测试，针对实战中出现的问题及时分析原因并修改代码。

7.1　不足与改进
1、不足：稳定性有待提升。智能车在复杂赛道长时间运行时，高速过弯或连续颠簸路段下摄像头易因车身振动出现图像模糊，导致赛道元素误判。
改进：硬件上采用减震支架固定摄像头与陀螺仪，降低车身振动对传感器的影响；算法上引入自适应滤波处理图像，通过多帧融合修正元素识别结果。
2、不足：复杂光环境下的感知精度有限。低光或强光直射时，摄像头图像对比度下降，影响边界识别精度。
改进：优化摄像头参数配置，增加自动曝光调节；为摄像头增加遮光罩，减少环境光干扰；结合陀螺仪姿态信息进行数据仲裁，提升复杂光环境下的感知精度。

算法1　大津法（OTSU）自适应阈值分割
算法 1  大津法(OTSU) 自适应阈值分割
输入: 灰度图像 gray[H][W]
输出: 分割阈值 T
 
1. 统计灰度直方图 hist[0..255]
2. 计算像素总数 N 与灰度值总和 S
3. maxSigma ← 0, T ← 0
4. for t ← 0 to 255 do
5.     w1 ← 前景像素数 / N              // 前景权重
6.     w2 ← 1 - w1                       // 背景权重
7.     u1 ← 前景灰度均值
8.     u2 ← 背景灰度均值
9.     sigma ← w1 * w2 * (u1 - u2)^2     // 类间方差
10.    if sigma > maxSigma then
11.        maxSigma ← sigma
12.        T ← t
13.    end if
14. end for
15. 用阈值 T 二值化: 灰度 > T 记为白(赛道线), 否则记为黑(背景)
16. return T
算法2　八邻域边界搜索与中线提取
算法 2  八邻域边界搜索与赛道中线提取
输入: 二值图像 binary[H][W], 起点 (cx, cy)
输出: 左右边界点集 L[], R[], 中线 mid[]
 
1. 从起点分别向左、右搜索赛道边界
2. L ← 向左生长的边界点集; R ← 向右生长的边界点集
3. for i ← 0 to H-1 do
4.     mid[i] ← (L[i].x + R[i].x) / 2    // 每行中线坐标
5. end for
6. 对 mid[] 中有效点做最小二乘直线拟合, 得到斜率 k 与截距 b
7. 横向偏差 e ← k * x_ref + b           // 车模相对赛道中心的偏移
8. return mid, k, b, e
算法3　方向串级闭环控制
算法 3  方向串级闭环控制
输入: 横向偏差 e_pos, 角速度反馈 w_gyro, 车速 v
输出: 左右轮差速控制量 diff
 
// —— 外环: 位置偏差 → 期望曲率 ——
1. e_pos ← 限幅(e_pos, -E_MAX, E_MAX)
2. curv ← Kp1 * e_pos + Kd1 * (e_pos - e_pos_last)
3. a_c ← v^2 * curv                              // 向心加速度
4. 若 |a_c| > a_max 则按 a_max 反解限幅 curv      // 防侧滑
5. w_ref ← v * curv                              // 期望角速度
// —— 内环: 角速度闭环 (微分先行 PD) ——
6. e_w ← w_ref + w_gyro
7. e_w ← 限幅(e_w, -W_MAX, W_MAX)
8. diff ← Kp2 * e_w + Kd2 * (w_gyro - w_gyro_last)
9. diff ← 限幅(diff, -DIFF_MAX, DIFF_MAX)
10. 更新 e_pos_last, w_gyro_last
11. return diff
算法4　双轮增量式速度环控制
算法 4  双轮增量式速度环控制
输入: 目标车速 v_ref, 左右轮实测速度 v_L, v_R, 转向差速量 diff
输出: 左右电机 PWM 输出 PWM_L, PWM_R
 
1. vL_ref ← v_ref - diff/2       // 转向时左右轮期望速度
2. vR_ref ← v_ref + diff/2
3. for 每侧轮 w ∈ {L, R} do
4.     e ← v_w_ref - v_w                  // 速度误差
5.     e ← 限幅(e, -E_MAX, E_MAX)
6.     Δu ← Kp * (e - e1) + Ki * e        // 增量式 PI
7.     u ← 限幅(u + Δu, -U_MAX, U_MAX)
8.     if u 饱和 then u ← u - Ki * e      // 抗积分饱和
9.     PWM_w ← u
10. end for
11. return PWM_L, PWM_R
算法5　电机差速输出
算法 5  电机差速输出
输入: 速度环输出 u_speed, 方向环输出 u_dir
输出: 左右电机 PWM
 
1. PWM_L ← u_speed + u_dir        // 串级合成
2. PWM_R ← u_speed - u_dir
3. PWM_L ← 限幅(PWM_L, -PWM_MAX, PWM_MAX)
4. PWM_R ← 限幅(PWM_R, -PWM_MAX, PWM_MAX)
5. 根据 PWM 正负设置方向引脚, 输出对应占空比
6. 定时器输出 PWM 至左右电机驱动
算法6　二阶巴特沃斯低通滤波
算法 6  二阶巴特沃斯低通滤波
输入: 当前采样 x[n]
输出: 滤波后 y[n]
 
1. y[n] ← b0*x[n] + b1*x[n-1] + b2*x[n-2]
        - a1*y[n-1] - a2*y[n-2]
2. 更新历史值:
   x[n-2]←x[n-1], x[n-1]←x[n]
   y[n-2]←y[n-1], y[n-1]←y[n]
3. return y[n]
// 系数 a1,a2,b0,b1,b2 由截止频率与采样频率预先计算
算法7　地图节点路径记录与回放
算法 7  地图节点路径记录与回放
输入: 当前节点方向 dir, 里程 odom
输出: 路段长度表 L[], 节点方向表 D[]
 
// —— 录制运行阶段 ——
1. 若 dir 为左转/右转(非直行) 且 转向角累计超过阈值:
2.     L[i] ← odom - odom_last      // 记录本路段里程
3.     D[i] ← dir                   // 记录拐点方向
4.     odom_last ← odom; i ← i + 1
// —— 正式运行阶段 ——
5. path ← odom - odom_last          // 已行路程
6. remain ← L[i] - path             // 剩余路程
7. 若 remain 小于阈值: 提前按 D[i] 调整转向与目标速度
8. return L, D
