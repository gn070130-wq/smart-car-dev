摘要
本文围绕第二十一届全国大学生智能车竞赛疯狂电路赛道的竞赛车模制作，介绍本队以小型化、轻量化和稳定运行为目标完成的车模方案。系统采用 TC264 作为主控，结合总钻风摄像头、编码器、六轴陀螺仪、有刷电机驱动和无刷负压风机控制，实现赛道图像识别、路径规划、速度闭环与差速转向控制；机械结构在 N30Pro 四轮双驱动车模基础上改造，通过加高侧板、异形 PCB 主板承力和碳素杆摄像头支架压缩空间并降低质量。报告从总体方案、机械结构、硬件电路、软件算法和调试方法等方面对车模设计与实现过程进行说明。
关键词：疯狂电路；智能车；TC264；图像处理；路径规划；四轮双驱动；轻量化

第一章 系统设计总方案
1.1 系统总体方案的选定
本车参加的赛道为疯狂电路赛道，赛道图案由白色电路图形铺设在蓝色底面上。与常规单一路径循迹相比，该赛道更强调车模对节点结构的识别、路径规划的稳定性以及小空间内连续转向的响应能力。因此，系统方案的选定不仅要考虑传感器能否稳定识别白色路径，还要考虑整车质量、重心、线束长度、电源扰动和机械刚度对实际运行的影响。
在循迹传感器方面，本车选用总钻风摄像头作为主要赛道信息采集模块；在速度反馈方面，选用增量式编码器获取左右轮实际速度并构成速度闭环；在姿态检测方面，主板集成六轴陀螺仪，用于提供车身角速度和转向角度参考。车模采用四轮双驱动差速控制方式，通过左右两侧驱动轮速度差实现转向。
1.2 系统总体结构
系统以 TC264 为核心，电源模块为主板、传感器和执行机构提供稳定供电。图像采集模块和传感器模块将赛道信息、速度及姿态信息送入 TC264；TC264 完成图像处理、路径判断和闭环控制后，分别输出有刷电机驱动信号和无刷负压风机控制信号，形成感知、决策和执行相互闭合的控制链路。系统整体结构如图1.1所示。

图1.1 系统整体结构框图
1.3 车模整体布局
整车在逐飞科技 N30Pro 车模基础上进行改造。为降低质量和压缩空间，本队舍弃原有主板安装板，绘制定制异形主板并直接安装在两侧侧板之间，使主板同时承担电气连接和部分机械支撑作用。

第二章 机械结构设计及调整
智能车的控制算法决定了车模的决策方式，但机械结构直接限制了算法能够发挥的上限。本车机械结构设计的重点是保证传感器安装稳定、降低冗余质量、缩短线束并保持整车重心合理。
2.1 侧板加高与主板承力设计
原 N30Pro 车模侧板高度较低，如果按照原侧板高度安装，后侧电池与 PCB 主板容易发生干涉。为解决这一问题，本队在原侧板结构基础上适当加高侧板，并采用碳纤维材料重新打印。

图2.1 原侧板与加高侧板对比
2.2 摄像头安装结构
摄像头安装的稳定性直接影响图像边界和节点识别。本车采用碳素杆作为摄像头支架材料，在较低质量下获得较高的刚度。摄像头支架安装在主板前部预留孔位上，底部通过螺丝与 PCB 固定，并使用热熔胶进行二次加固。

图2.2 摄像头碳素杆支架与主板连接
2.3 电池安装与重心布置
本车将电池直接放置在后侧底板上，并使用胶带固定。后置电池布置能够避开摄像头支架和主板主要元件区域，使主板上方空间更简洁，同时便于比赛现场快速更换。

图2.3 电池后侧底板固定方式
2.4 四轮双驱动传动结构
本车采用四轮双驱动差速控制结构，左右两侧驱动轮分别由对应电机驱动。差速结构机械部件较少，车体尺寸更容易压缩，同时左右轮速度差可以直接由软件控制，适合疯狂电路赛道中连续小半径转向的运行需求。

图2.4 四轮双驱动底盘侧向结构

第三章 系统硬件电路设计
硬件电路是智能车稳定运行的基础。本车硬件设计围绕体积小、走线短、抗干扰和便于调试展开。
3.1 主控电路设计
主控芯片选用英飞凌 SAK-TC264D-40F200N BC，本队在 PCB 上直接使用裸片而不采用最小系统板，以减少插针、转接板和多余布线带来的高度与质量。TC264 属于 AURIX TC26xD 系列，具有双 TriCore 内核、200 MHz 主频、2.5 MB Flash、240 KB RAM、48 路 DMA、GTM 通用定时模块、12 位 SAR ADC、QSPI、ASCLIN 和 I2C 等外设资源，能够同时承担图像采集、编码器测速、PWM 输出、陀螺仪通信和调试通信等任务。

图3.1 TC264 主控部分原理图

图像采集部分选用 MT9V034 总钻风摄像头。MT9V034 为 1/3 英寸 Wide-VGA CMOS 图像传感器，具有全局快门、752×480 有效像素、60 fps 满分辨率输出和 10 位像素数据能力，适合车模在运动状态下获取边界清晰的灰度图像。主控通过像素时钟、行同步和场同步信号完成图像接收，并在软件中进行压缩和二值化处理。

图3.2 主板其余外设原理图

姿态检测芯片选用 LSM6DSRTR，该器件集成三轴加速度计和三轴陀螺仪，陀螺仪量程最高可达 ±4000 dps，加速度量程支持 ±2/±4/±8/±16 g，可通过 SPI 或 I2C 与主控通信。实际程序主要使用其 Z 轴角速度对转向控制进行辅助反馈。速度反馈采用逐飞科技 1024 线增量式编码器，左右轮速信号经 TC264 定时器或捕获资源计数后参与速度闭环运算。

图3.3 六轴陀螺仪原理图
3.2 电源模块设计
整车使用逐飞科技300mAh 小体3S电池供电。电源入口采用SI7617DN-T1-GE3 作为主开关 MOS，该器件为 P 沟道30V MOSFET，采用PowerPAK 1212-8封装，可承受较大瞬时电流，适合在小型PCB上实现整车上电控制。电源入口并联 TVS1400DRVR 平钳位TVS管，用于吸收电机和负压风机启停时的浪涌和尖峰电压。

图3.5 电源供电原理图
主电源降压芯片选用 TPS565201DDCR，该芯片为 4.5V至17V输入、5A 同步降压转换器，集成高低侧MOSFET，采用 D-CAP2 控制方式并具有较快的瞬态响应，适合先将 3S 电池电压降至 5V 母线。由于主控、传感器和调试接口对 3.3V供电噪声比较敏感，本设计再由 LDO从5V降至3.3V。

图3.6 降压电路原理图
单片机电源单独采用TP5108E23E-33，该LDO为3.3V固定输出、500mA 级低压差线性稳压器，具有较高 PSRR 和使能控制功能，可降低电机电流波动对TC264核心供电的影响。摄像头、陀螺仪等其他外设则使用 RT9013-33GB 提供 3.3V 供电，RT9013为过流500mA的LDO，具有低静态电流、过流和过温保护等特性。主控与外设分路供电后，调试过程中即使外设接口出现较大负载变化，主控仍能保持较稳定的运行状态。

图3.7 主板3.3V稳压电路原理图
3.3 电机驱动电路设计
有刷电机驱动芯片选用 DRV8243HQRXYRQ1。DRV8243-Q1 内部集成 N 沟道 H 桥、电荷泵、电流检测和保护诊断电路，支持 4.5 V 至 35 V 工作电压和 12 A 峰值输出电流，RXY 封装面积约为 3 mm×4.5 mm。相比分立 MOS 方案，集成 H 桥能减少外部器件和大电流走线长度，便于在小型异形主板上完成左右驱动电机的控制。

图3.8 电机驱动部分原理图
本车为四轮双驱动结构，TC264 通过 PWM 信号控制左右两路电机输出，通过左右轮目标速度差实现转向。DRV8243 的电流检测和故障提示引脚在调试时可用于判断电机卡滞、瞬态过流或温升异常等问题，提高车模在连续小半径转向时的可靠性。
无刷负压风机电调参考逐飞开源 ai8051u 无感无刷电调设计，电调控制芯片选用 AI8051U，作为独立风机控制器负责换相和调速。AI8051U 具有 32 位 8051 扩展架构、硬件浮点和丰富 PWM/ADC 资源，能够满足小型无感 BLDC 电调的计时、采样和换相要求。

图3.9 无刷电调原理图（1）
无刷电调功率驱动芯片选用 FD6288Q，该芯片集成三路独立半桥栅极驱动，支持 5 V 至 20 V 供电、3.3 V/5 V 逻辑输入，具有欠压保护、防直通和死区控制功能。三相桥臂 MOS 管选用 TPN2R703NL，该器件为 30 V N 沟道功率 MOSFET，10 V 驱动时导通电阻典型等级较低，封装小且适合高频开关。TC264 仅向电调提供风机目标控制信号，风机的三相驱动由独立电调完成，从而减轻主控运算和定时资源压力。

3.4 主板 PCB 设计
主板外形根据车体侧板、摄像头支架、电池位置和接口方向绘制为异形结构，并通过安装孔直接固定在两侧侧板上。PCB 上将 TC264 最小系统、电源稳压、电机驱动、摄像头接口、编码器接口和陀螺仪等部分集成在同一块板上，减少了模块之间的排线和插接件。

图3.13 主板PCB正面图

图3.14 主板PCB背面图
布局时将电池输入、电机驱动和负压风机接口尽量靠近功率器件放置，大电流走线采用较宽线宽和较短回路；摄像头、陀螺仪和主控晶振等对噪声敏感的器件则与功率回路保持距离。在 TC264 供电引脚、LDO 输出端和电机驱动芯片电源端就近放置去耦电容，以降低快速 PWM 开关对图像采集和主控运行的影响。

第四章 系统软件设计和算法实现
4.1 程序运行主要流程
车模软件采用“图像识别-路径决策-运动控制-调试交互”分层结构。摄像头采集完成后，图像处理模块对当前帧进行压缩、阈值计算、二值化、边界提取和节点识别；路径决策模块根据节点识别结果和路线表选择目标方向；运动控制模块根据循迹误差、编码器速度和陀螺仪角速度计算左右轮输出。
4.2 图像采集与预处理

第五章 开发环境与上位机调试工具
5.1 开发环境
主控程序使用 AURIX Development Studio（ADS）进行开发、编译和下载。ADS 对英飞凌 AURIX 系列单片机支持较完整，便于配置 TC264 工程、调试外设初始化和检查程序运行状态。
5.2 VOFA 波形调试
VOFA 主要用于观察车模运行过程中的关键变量波形，例如图像误差、左右轮目标速度、编码器速度、PWM 输出、陀螺仪角度和节点状态标志。通过波形可以判断车辆摆动来源是图像误差抖动、速度环振荡还是转向参数过强。

图5.1 无线串口调试界面
5.3 逐飞助手与无线调试
逐飞助手用于摄像头图像显示、无线图传、菜单参数调整和部分外设验证。调试时可以先通过屏幕或图传观察二值化效果和边界提取情况，再通过无线串口修改曝光、阈值、基础速度和PID参数。无线串口调参采用简单的数据帧格式，便于现场快速修改参数并减少反复编译下载的时间。

{
    uint8 i, j;
    uint8 threshold_now;
    const uint8 threshold_min = 80;  // 阈值下限，防止图像整体过白
    const uint8 threshold_max = 180; // 阈值上限，防止图像整体过黑
    static uint8 threshold_inited = 0;
 
    // 每帧重新计算大津阈值
    threshold_now = Otus_threshold();
 
    if (threshold_inited == 0)
    {
        outsthreshold = threshold_now;
        threshold_inited = 1;
    }
    else
    {
        // 阈值低通滤波：旧阈值占3份，新阈值占1份
        outsthreshold = (uint8)((outsthreshold * 3 + threshold_now) / 4);
    }
 
    outsthreshold = (uint8)func_limit_ab(outsthreshold, threshold_min, threshold_max); // 二值化阈值限幅
    outsthreshold_last = outsthreshold;
 
    for (i = 0; i < 60; i++)
    {
        for (j = 0; j < 94; j++)
        {
            if (j < 10)
            {
                dis_image[i][j] = get_image[i][j] > outsthreshold ? 255 : 0;
            }
            else if (j > 78)
            {
                dis_image[i][j] = get_image[i][j] > outsthreshold ? 255 : 0;
            }
            else
            {
                dis_image[i][j] = get_image[i][j] > outsthreshold + outs ? 255 : 0;
            }
        }
    }
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介    角度环位置式PID控制器
// 参数说明
// 返回参数     pid计算结果
// 使用示例
//-------------------------------------------------------------------------------------------------------------------
float yaw_pid_ctrl(pid_param *pid, float target, float actual)
{
  pid->target = target; // 获取目标值
  pid->actual = actual; // 获取实际值
 
  pid->last_err = pid->err;             // 计算上次误差
  pid->err = pid->target - pid->actual; // 计算此次误差
 
  pid->err_int += pid->err; // 误差积分
 
  //  func_limit(pid->err_int, y);                                 //积分限幅
 
  pid->out_p = pid->kp * pid->err;
  pid->out_i = pid->ki * pid->err_int;
  pid->out_d = pid->kd * (pid->err - pid->last_err);
 
  pid->out = pid->out_p + pid->out_i + pid->out_d; // 计算输出
  //  pid->out = func_limit_ab(pid->out, V_MIN, V_MAX);                                  //输出双边限幅
 
  return pid->out;
}
 
//-------------------------------------------------------------------------------------------------------------------
// 函数简介    电机增量式PID控制器
// 参数说明
// 返回参数     pid计算结果
// 使用示例
// 备注信息     内含总输出限幅
//-------------------------------------------------------------------------------------------------------------------
float motor_pid_ctrl(pid_param *pid, float target, float actual)
{
  pid->actual = actual; // 获取实际值
  pid->target = target; // 获取目标值
 
  pid->err = pid->target - pid->actual; // 获取误差
 
  pid->out_p = pid->kp * (pid->err - pid->last_err);
  pid->out_i = pid->ki * pid->err;
  pid->out_d = pid->kd * (pid->err - 2 * pid->last_err + pid->llast_err);
 
  //前馈
  float delta_ff = pid->kff * (target - pid->last_target);
  pid->last_target = target;
 
  pid->out +=  pid->out_p + pid->out_i + pid->out_d + delta_ff;    //带前馈的输出
 
  // 输出双边限幅
  pid->out = func_limit_ab( pid->out, -pid->max_out, pid->max_out);
 
  pid->llast_err = pid->last_err;   //误差更新
  pid->last_err = pid->err;
 
 
  return pid->out; // 返回包含前馈的最终输出
}
