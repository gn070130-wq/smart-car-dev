第一章　引言
1.1　项目背景与参赛任务
第二十一届全国大学生智能汽车竞赛疯狂电路组属于缩微赛道组别。比赛要求自制缩微轻量车模沿电路原理图式赛道自主运行，在满足完赛条件的基础上尽量通过各回路中的电子元件图形。赛道以蓝色底材为背景，采用宽度为20 mm±5 mm的白色引导线构成导线、节点、回路和元件图形；场地尺度约为2～4 m。电子元件图形不仅是计分对象，也会改变局部线宽、轮廓和连通关系，是视觉检测中的主要干扰来源。公开说明给出的元件外接正方形边长小于15 cm，元件引线长度不小于15 cm，相邻并联支路元件之间的最近距离不小于20 cm；绝缘区域还可能随机放置电子锥桶，锥桶距最近导线不小于15 cm，车模触碰锥桶判为比赛失败。［1-2］
比赛设置科目三包含串联、并联及反馈回路，需要车模根据拓扑和元件分布选择路线。预赛、决赛使用的电路图及发车区域原则上在比赛前一周公布。车模从发车区出发并返回发车区，发车区只能经过一次；通过元件数量不足2个时不能形成有效成绩。最终成绩与实际运行时间、称重折算时间以及通过元件数量等因素有关，具体计算式和参数应以参赛赛区及全国总决赛最新正式规则为准。［1-2］
本车采用逐飞科技MT9V03X（总钻风）灰度摄像头作为主要赛道感知装置，通过图像处理识别白色引导线、元件区域和岔路口；利用已公布的赛道图建立先验拓扑图，并以在线视觉结果修正车辆所处节点和可行支路；规划模块在优先提高已通过元件数量的前提下选择预计时间短、转弯风险低的路径。循迹控制采用位置—角速度—轮速三串级PID：摄像头中线误差经位置式PID生成目标横摆角速度，角速度环根据陀螺仪反馈生成左右轮差速修正量，左右轮速度环根据编码器反馈输出PWM和方向信号，经电机驱动作用于龙邱科技030直流有刷电机，完成循迹、分岔转向、回路切换和返航。
1.2　相关工作与文献综述
传统点式光电或线阵传感方案计算量小、循迹实时性高，但在电路符号造成的线宽突变、多分支节点和复杂回路中，只能获得有限的局部信息，难以同
时完成元件识别和拓扑判断。灰度摄像头能够在一个视场内保留导线连续性、分支数量、元件轮廓及相对位置，更适合疯狂电路组的“局部感知+全局规划”任务。逐飞科技公开资料显示，总钻风摄像头采用MT9V034灰度图像传感器，具有全局快门、帧率可调、自动曝光以及手动曝光时间调节能力，可根据分辨率和处理器资源配置输出帧率。［3］
在图像算法方面，可先利用灰度阈值分割得到白色导线区域，再结合形态学处理、连通域、骨架或中心线提取获得局部可行路径。岔路口可通过前视区域内连通分支数、骨架端点和多帧连续性判定；元件区域可依据局部宽度变化、轮廓形状和与引线的拓扑关系检测。为抑制单帧噪声，应将候选目标与车辆运动方向、历史帧位置和先验赛道拓扑联合验证。
路径准备阶段可把赛道抽象为图G=(V,E)：节点V表示发车区、岔路口、回路汇合点和元件，边E表示车辆可通行的导线段。赛前根据公布的赛道图比较不同路线的元件覆盖数、预计用时和转弯风险，选定一条稳定路线后，将各节点的预期事件和左转、直行、右转、返航、停车等动作编译成固定动作表。比赛时摄像头只负责确认事件并推进动作表索引，不执行在线图搜索，从而减少计算分支和随机行为。
1.3　设计目标与主要工作
本项目的总体目标是完成一辆能够在疯狂电路赛道上自主感知、规划和运行的缩微智能车。系统以“可靠完赛优先、元件覆盖其次、运行时间优化最后”为阶段目标：首先保证车辆能稳定识别白色引导线并返回发车区；其次在串联、串并联和复杂回路中正确识别岔路口及元件区域，减少漏行支路；最后通过路径代价和速度策略优化总成绩。
主要工作包括：①搭建MT9V03X图像采集链路并完成曝光、视场和阈值标定；②设计导线中心提取、元件区域检测、岔路口识别与时序确认算法；③根据赛前公布的赛道图完成路线比较，生成按事件顺序执行的固定动作表，并实现动作索引、超时和一致性校验；④设计以摄像头中线误差为外环输入、横摆角速度为中环反馈、左右轮速为内环反馈的三串级PID，并驱动龙邱科技030直流有刷电机；⑤完成轻量化安装、电源与驱动接口、软件状态机以及异常停车策略；⑥按三个科目逐级开展识别精度、控制响应、动作表执行成功率、完赛率和运行时间测试。

第二章　系统总体设计
2.1　总体设计思路
系统采用感知层、事件同步层、固定动作表执行层和运动控制层四级结构。感知层由MT9V03X摄像头采集赛道灰度图像，输出导线中线误差、候选元件和分岔方向，同时由陀螺仪提供车体z轴横摆角速度、左右轮编码器提供轮速；事件同步层对岔路口、元件区域和发车区进行多帧确认，维护当前动作序号；固定动作表执行层读取该序号对应的预期事件、分支动作和基础速度，不进行在线路线搜索；运动控制层采用位置—角速度—轮速三串级PID，将中线误差逐级转换为目标角速度、左右轮目标速度和电机PWM，驱动龙邱科技030直流有刷电机完成循迹和转向。
设计的关键约束包括：白线与元件图形共用相同材料导致轮廓干扰；并联与反馈回路会产生多个合法方向；摄像头视场、速度和处理时延共同决定预瞄距离；车重参与缩微组成绩折算，因此结构和电路需兼顾轻量化与可靠性；随机锥桶虽位于绝缘区域，但车辆偏离引导线后仍有碰撞风险。总体策略是在直线段提高速度，在元件区域和岔路口提前降速，并通过多帧确认和先验拓扑降低误判。
2.1.1　任务需求分解
任务被拆分为三个核心闭环：图像感知负责从当前视场获得可行路径和语义事件；动作表执行负责核对当前事件并读取预先确定的下一支路动作；运动控制负责把左转、直行、右转及基础速度稳定转换为实际轨迹。各环节均设置有效性标志、动作索引和超时机制，避免无效图像、重复事件或未确认岔路口错误推进动作序列。

整车由轻量化差速底盘、MT9V03X摄像头、横摆角速度传感器、左右轮编码器、主控制器、双路有刷电机驱动、电源及调试通信模块组成。摄像头向主控提供灰度图像和同步信号，陀螺仪提供横摆角速度ωz，编码器提供左右轮速vL、vR；主控完成图像处理、事件确认、固定动作表推进和三串级PID计算；双路H桥把PWM及方向信号转换为龙邱科技030直流有刷电机的端电压，使左右轮产生所需的平均速度和速度差。调试接口记录事件编号、动作索引、e_p、ω*、ωz、Δv*、轮速目标/反馈和PWM，便于定位识别、决策与控制问题。
工作时，车辆先完成电源、摄像头、陀螺仪、编码器、电机方向和动作表校验，随后等待发车。进入运行状态后，图像任务完成ROI截取、导线中线提取和事件识别；动作表模块按当前索引给出目标支路与基础速度v0；位置外环根据中线误差计算目标角速度ω*，角速度中环根据ω*与ωz之差计算差速修正Δv*，轮速内环分别跟踪vL*=v0-Δv*、vR*=v0+Δv*并输出左右电机PWM。检测到与当前表项一致的岔路口或元件事件后执行动作并推进索引；执行到RETURN项后沿预定返航序列运行，最终确认发车区并清零积分、停车。

2.3　方案比较与选型
感知方案比较的重点不是单纯循迹精度，而是能否识别元件轮廓和多分支连通关系。点式或线阵传感器资源占用低，但前视范围有限；灰度摄像头能同时观察导线、元件和岔路口，因此选用MT9V03X作为主要传感器。路径决策方面，在线拓扑规划适应性较强，但状态维护、异常分支和调试工作量较大；固定动作表行为确定、计算量小、问题容易复现。考虑比赛前会公布赛道图，本车选择方案A：赛前确定路线并生成固定动作表，比赛时由在线视觉事件驱动顺序执行，以稳定完赛为优先目标。
控制方案比较中，单位置环结构简单，但只根据中线偏差修正差速，无法直接约束车体旋转速度；位置—轮速双串级可稳定驱动力，却仍可能在急弯和连续弯出现转向过快、过冲或摆动。三串级在二者之间增加横摆角速度环，可把“应转多少”进一步分解为“以多快的角速度转动”，再由轮速环保证电机执行，因此选择位置—角速度—轮速三串级PID。该方案需要额外的角速度和编码器反馈，并增加参数整定工作量，但更适合元件图形、T形岔路和连续支路引起的快速方向变化。［6］
固定动作表在赛前按分层目标生成：首先选择能够稳定通过较多有效元件的路线；元件数量相同时优先预计时间较短、急转弯较少、识别特征更清晰的路线。动作表至少包含序号、预期事件类型、分支动作、基础速度、通过确认条件和超时处理。规则或赛道版本变化时重新生成并整体校验动作表，比赛过程中不修改路线。

2.4　系统工作流程
上电后主控依次初始化时钟、存储、通信、图像采集和PWM输出，读取动作表及参数版本，检查摄像头帧同步和执行机构状态。自检通过后进入待机，发车触发后从动作表第0项开始循迹。每帧图像先完成有效性检查、灰度归一化和ROI处理，再提取导线中心及候选事件；普通路段直接进行预瞄控制，元件区域进行通过确认，岔路口则锁定事件、减速、读取当前表项并执行左转/直行/右转。车辆离开节点后推进索引并恢复跟踪，直到到达当前表项的最后一项即到达终点。
2.4.1　正常流程、异常流程与安全状态
正常流程为“初始化—动作表校验—待机—循迹—事件确认—读取当前动作—分支执行—通过确认—动作索引加一—返航—完成”。若图像连续若干帧无有效导线则停车。若检测事件与当前表项不一致，系统不跳项、不改路线，而是保持当前索引并低速重识别；连续不一致或动作超时则停车等待人工处理。若驱动输出长时间饱和、电池电压过低或关键通信中断，同样进入故障状态。
第三章　机械结构设计
3.1　车模结构设计主要思路
机械结构设计的目标不是单纯追求零件数量少，而是在比赛约束下同时满足低质量、低重心、结构稳定、视场可靠和便于维修五项要求。设计时先确定左右轮差速底盘和轮组运动范围，再确定摄像头的空间基准，随后安排主控板、电池和负压风机的位置，最后进行线束整理和防松处理。这样可以避免因先布置电路或线束而反复改变车体几何基准。

最终机械系统以龙邱科技 MINI 闪电鼠-Q 两轮差速车模为基础，由镂空底盘、左右驱动轮组、摄像头支架、主控/驱动板固定件、电池固定结构、负压风机支架和线束导向件组成。整体布置采用“前部保证感知、中部保证稳定、底部降低重心、后部避免遮挡”的原则。
结构设计的评价依据包括：轮组在最大转向和振动工况下无干涉；摄像头高度和倾角能够重复恢复；主控板和电池固定后不发生相对位移；线束不进入轮组、风机和电机运动范围；拆装后能够快速完成机械基准复位。车重以完整比赛状态称量为准。

3.2　最终成品车机械部分安装及改造
最终车模的机械安装以成品底盘为基准。左右驱动轮、电机和底板保持原车结构；车头安装摄像头可调支架；主控/驱动板固定在底盘中部；电池安装在车体低位并靠近几何中心；负压风机安装在中前部。各部件的位置先满足轮组运动和摄像头视场，再通过支架减重、螺钉防松和线束导向完成局部改造。
机械改造主要包括：保留镂空底盘以降低质量；使用可重复定位的摄像头支架；使用尼龙螺柱或绝缘垫片固定主控/驱动板；使用魔术贴固定电池；增加负压风机轻量支架；对排线和动力线设置独立走线通道。安装后依次检查轮组全行程、摄像头视场、部件松动、线束干涉和底盘绝缘。

3.3　传感器设计安装、系统电路板固定及连接
传感器安装以“基准明确、姿态稳定、拆装可复现”为原则。MT9V034摄像头位于车头前部，镜头中心距地面约18 cm，向前下方倾斜50°；支架通过定位面和螺钉固定，拆装后能够恢复同一姿态。IMU660RB集成在主控板上，用于输出z轴横摆角速度。左右电机端各安装1个SDI-ENC类增量式编码器，单个质量约1.2 g，工作电压3.3–5 V、约1024线、最高转速约50000 r/min，用于左右轮速度反馈。
系统电路板固定与连接采用“板卡居中、动力线短、信号线分离”的方式。TC264主控、IMU660RB、两路DRV8701有刷驱动及AI8051无刷电调相关接口集中在一体化主板上，主板使用绝缘件固定在底盘中部。XP01803ULT 3S1P、11.1 V、180 mAh电池经XT30和总开关接入VCCBAT；动力线连接电机驱动和负压电调，摄像头排

3.4　以前尝试过的失败方案与迭代
前期曾尝试根据比赛尺寸和轮距要求自制车模底盘。第一版采用薄板和螺钉拼接，虽然外形尺寸可以调整，但底盘刚度不足，电机工作时会产生明显振动，摄像头安装角度也会随碰撞发生变化。第二版改用3D打印结构件，将电池、主控板和电机安装孔集成到同一底板上，但常用打印材料的强度和层间结合能力不足，轮轴附近容易出现变形，长时间运行后轮组平行度下降。

在减重方面，自制车模还存在两个矛盾：如果增加加强筋和金属连接件，结构稳定性有所改善，但质量达不到缩微车模的轻量化要求；如果继续削薄底板和支架，虽然质量下降，却会造成摄像头支架、轮轴安装座和电池固定点刚度不足。尝试委托网上打印后，尺寸精度和材料强度能够改善，但多次修改需要重复开模或打印，单件成本较高，交付周期也不利于快速迭代。

因此，团队将自制方案中的有效经验保留下来，例如低重心布置、摄像头前置和强弱电分离；同时放弃刚度不足、加工成本高且难以快速复现的自制底盘，最终选择龙邱成品车模作为机械平台。
几轮试制表明，自制车模的问题并不只在单个零件，而在于底盘刚度、轮组安装精度、摄像头基准和加工一致性相互耦合：底盘变形会改变轮胎接触状态，轮组不平行会增加控制摆动，摄像头角度漂移又会被误认为是PID参数问题。最终方案采用成熟成品底盘，把主要精力转向支架定位、低重心安装和可重复标定。
选择成品车模后，结构优化转为“保留成熟底盘、局部减重和功能化改造”。底盘、轮组和电机安装位置尽量不改动，只对摄像头支架、主控板固定、电池绑带、风机支架和线束路径进行优化；每次改动都以整车质量、结构刚度、视场遮挡和拆装复现性为评价依据。

3.4.1　自制车模方案的问题与取舍
本节记录前期自制方案的主要问题和最终取舍。自制车模并非完全没有价值，它帮助团队明确了低重心、摄像头前置和电路板集中安装等设计方向；但从比赛所需的稳定性、重量和迭代效率综合判断，成品车模更适合作为最终平台。
第四章　硬件电路设计
4.1　硬件总体架构
本车硬件设计围绕两个目标展开：一是保证图像、姿态和轮速闭环稳定运行；二是在满足电气可靠性的前提下持续减轻车体质量。系统按功能划分为动力层、供电层、控制层、反馈层和执行层：动力层由XP01803ULT电池提供11.1 V母线；供电层产生5 V和3.3 V逻辑电源；控制层由TC264完成图像处理、动作表和三串级PID；反馈层由MT9V034、IMU660RB和左右SDI-ENC提供状态信息；执行层由DRV8701驱动两路030电机，并由AI8051电调控制负压风机。
系统信号和能量流向为：XP01803ULT电池经XT30和总开关输入VCCBAT；VCCBAT一方面供给两路有刷电机驱动和负压电调，另一方面经AP63205产生5 V、再经TLV75733产生3.3 V；TC264采集摄像头、IMU和编码器信息，计算动作表、基础速度和三串级PID输出；DRV8701将PWM/方向信号转换为左右030电机的驱动电压，AI8051控制负压风机。该顺序也对应本章后续各节的说明顺序。

第五章　控制软件与算法设计
5.1　软件总体架构
软件按“驱动层—感知层—认知规划层—三串级控制层—诊断记录层”划分。图像帧到达触发采集完成事件；感知与规划模块按图像频率更新中线误差、支路动作和基础速度；角速度采样与左右轮编码器计数在更快周期更新；位置外环、角速度中环、轮速内环按由慢到快的多速率方式运行。诊断层记录各环设定值、反馈值、误差、积分项、限幅状态和最终PWM，以便区分视觉、姿态和执行层故障。

5.2　信息采集与预处理
摄像头以固定周期采集赛道灰度图像。为减小TC264的图像处理负担，完整图像到达后先进行有效性检查，再按照车辆实际前视范围截取感兴趣区域（ROI），并根据控制所需分辨率进行裁剪与压缩，仅保留能够覆盖近端循迹区和前方元素识别区的像素。裁剪后的灰度图像进入二值化处理：设灰度图为I(x,y)，阈值为τ，则B(x,y)=1（I(x,y)≥τ）表示白色赛道区域，B(x,y)=0表示背景。阈值τ由赛前标定获得，并根据不同光照条件保留修正接口。由此形成“摄像头采集→裁剪压缩→二值化→巡线/元素识别”的视觉处理主链。
二值图像生成后，程序逐行搜索白色区域并提取左右边界，分别保存为左边线数组x_L(y)和右边线数组x_R(y)。巡线阶段不只计算中点，还同步提取后续元素判断所需的基础赛道信息，包括各扫描行白色连续区长度、左右边线之间的赛道宽度w(y)=x_R(y)-x_L(y)、宽度随纵向位置的变化趋势，以及图像最左边和最右边是否出现与赛道连通的白边。左右边线需满足相邻行连续、跳变量受限且与当前行白色区域相匹配等巡线规则；只有通过有效性检查的边线点才参与中线及画框参数计算。普通路段的中心点取x_c(y)=[x_L(y)+x_R(y)]/2，并通过多行连续性抑制单点噪声。
为保证元素识别与运动控制共享一致的几何基准，程序在每帧同时维护有效左/右边线长度、白边出现位置、赛道宽度变化量和中点数组。若某侧边线短时丢失，则仅使用仍满足连续性的有效数据并降低该帧元素置信度；若两侧边线均无法形成有效数组，则视觉帧标记为无效，控制器采用上一帧有效中线短时保持并进入降速重识别。控制反馈链中的陀螺仪和编码器仍按原方案完成零偏、低通和定窗差分处理，为后续转弯角度判断和三串级PID提供反馈。
5.2.1　数据处理链与参数
视觉数据处理链为：MT9V03X灰度帧→图像有效性检查→ROI裁剪与压缩→二值化→逐行搜索左右边线→统计白色连续区长度、赛道宽度变化和左右白边→生成有效边线数组及中点数组→基于画框的元素候选判断→框边与赛道相交关系校验→元素处理/普通巡线。需要标定的主要参数包括ROI范围、压缩比例、二值化阈值、边线允许跳变量、正常赛道宽度范围、白边判定阈值以及各类元素画框尺寸。上述参数应在实际比赛赛道尺寸和摄像头18 cm高度、50°倾角条件下通过样本图像确定，并记录对应版本。
5.3　赛道/目标信息检测算法
赛道信息检测以左右边线数组为核心。对每个有效扫描行，程序记录左边界x_L(y)、右边界x_R(y)、中点x_c(y)、白色连续区长度以及赛道宽度w(y)。正常导线段应具有较稳定的宽度和连续边线；当w(y)出现持续增大、单侧边线明显外扩、有效边线长度突变，或图像最左/最右边出现与赛道相连的白边时，说明当前视场可能进入岔路或电子元件区域。上述特征不直接触发转向，而是作为后续画框识别的候选条件，以减少元件轮廓、节点和局部反光造成的误判。
元素识别借鉴“先确定几何框、再利用框边与赛道关系验证”的画框思路。首先从符合巡线规则的左右边线数组中计算画框中心横坐标。设有效左边线点集合为L、有效右边线点集合为R，则可用两侧有效横坐标均值的平均值确定x_f，即x_f=(mean(L)+mean(R))/2，使画框横向位置随实际赛道中心变化。画框中心纵坐标y_f由二值图像边缘白边确定：当左侧出现有效白边时取对应左白边纵坐标，当右侧出现有效白边时取对应右白边纵坐标；具体采用哪一侧由当前候选元素和动作方向确定。画框的宽度W_f和高度H_f不在运行中自由搜索，而是根据实际赛道元素在当前摄像头姿态下的像素尺寸进行静态标定。这样可将元素判断约束在与真实赛道尺度一致的局部区域内。
获得(x_f,y_f,W_f,H_f)后，在二值图像中构造候选元素框，并分别检查框的上、下、左、右四条边与白色赛道区域的相交位置和相交数量。只有当四边相交关系与当前预期元素或转向拓扑一致，并且框内/框外边线连续性满足要求时，才将候选判为合理元素；若相交关系不符，则撤销该候选并继续普通巡线。该方法把“赛道宽度突变、左右白边”等粗特征用于定位，把“框边与赛道的相交关系”用于二次确认，避免仅凭局部白块面积直接触发元素状态。事件仍采用多帧确认和动作表一致性校验，评价指标包括元素识别召回率/误报率、框位置误差、相交关系判定成功率、处理频率和端到端时延。
5.3.1　基于画框的元素识别与动态偏置处理
当画框验证通过后，系统由TRACK进入元素处理状态。以当前识别框的纵坐标y_f作为偏置起始行（偏置行），仅对该行上方、也就是更远前视区域的中点数组进行方向性偏置：执行左转动作时，将这些中点统一向左侧增加预先标定的偏置量；执行右转动作时则向右侧偏置。偏置后的中点继续作为位置外环的目标路径，从而在不直接硬切左右电机PWM的情况下，通过原有“位置—角速度—轮速”三串级PID完成平滑转向。随着车辆向元素靠近，画框在图像中的纵向位置会变化，程序每帧重新计算y_f，因此偏置行随识别结果动态更新；这使车辆转向引导区域能够随相对位置变化而前移或后移，而不是固定在某一预瞄行。
元素转弯状态的退出以累计转角为主要条件。进入ACTION_EXECUTE时记录当前航向角或清零由陀螺仪角速度积分得到的相对转角Δψ；运行过程中持续计算Δψ，当其达到对应左转/右转动作的标定角度阈值后，停止中点偏置并退出转弯状态，重新使用正常左右边线中点巡线。为防止仅靠角度积分造成漂移，实车调试时还应结合“重新获得连续有效左右边线/中点”作为恢复普通巡线的辅助条件。待实测参数包括：边线跳变量、正常赛道宽度范围、左右白边判定阈值、各元素框W_f/H_f、框边相交判据、左右偏置量、偏置行更新范围、转弯退出角度、连续确认帧数、识别精度、处理频率和最坏时延。

5.4.1 三串级PID控制结构与控制律
三环的参数确定遵循“由内而外”：首先断开外环与中环，分别整定左右轮速度环，使030电机能够稳定跟踪阶跃和斜坡速度；其次接入角速度环，以周期性目标角速度或受控侧向扰动观察ωz的响应，调整比例、微分和限幅；最后在低速直线与缓弯上接入摄像头位置外环，从较小K_pp开始提高响应，再用K_pd抑制摆动，只有存在稳定偏置时才加入少量K_pi。［6］
完成基本参数后，系统微调按“由外而内”进行：先根据中线跟踪表现调整位置环；若转弯速度异常、急弯过不去或连续弯响应不足，再检查角速度环；若目标轮速与实际轮速仍不一致，最后回到速度环和电机前馈。调参前必须确认相机、陀螺仪、编码器和电机极性正确，机械结构紧凑、重心稳定，赛道及轮胎状态一致。
控制周期应满足内环快于外环。参考资料给出的示例组合包括位置/角速度/速度环为10 ms/5 ms/5 ms、10 ms/5 ms/2 ms或10 ms/2 ms/2 ms，但这些仅作为初始调度参考；最终周期必须由本车摄像头帧率、传感器带宽、主控负载和实测相位裕量确定。［6］
验证时分别记录三环的设定值和反馈值，评价位置误差均方根/峰值、横摆角速度超调与调节时间、左右轮速稳态误差和PWM饱和占比；再在直线、弯道、连续弯、元件区域和T形岔路上统计脱线次数、完赛率和运行时间。
5.4.2 三串级PID数据流与工程保护
三串级控制按多速率数据流运行：每次有效图像更新e_p和ω*；角速度任务在更快周期读取ωz并更新Δv*；速度任务在最快周期读取编码器并刷新uL、uR。上一层输出在下一次更新前保持，且带时间戳和有效期。若图像超时，位置外环停止更新并将ω*平滑回零；若陀螺仪超时，立即取消差速命令并降速；任一编码器失效时关闭相应速度环并停车。
为避免级联饱和，限幅顺序应与物理能力一致：先按路径状态限制v0，再限制ω*与Δv*，最后限制轮速目标和PWM。上层输出达到限幅时冻结相应积分；左右轮目标超过允许范围时按比例缩放，尽量保持差速比。分岔动作期间可切换独立的ω_max、Δv_max和基础速度，但参数切换必须采用斜坡或无扰切换。

5.6　代码设计与资源使用
本车控制程序整体在逐飞科技面向 TC264 的开源库及配套例程基础上搭建。工程结构采用“底层驱动—数据采集—视觉处理—任务决策—运动控制”的分层方式：底层部分复用逐飞库中已经完成适配的主控初始化、GPIO、定时器、PWM、编码器、摄像头及调试通信等基础接口；在此之上自行编写图像裁剪压缩、二值化、左右边线搜索、白边与赛道宽度特征提取、画框元素识别、动态中点偏置、固定动作表以及三串级 PID 等应用层算法。这种方式能够减少重复编写底层驱动带来的工作量，同时保持核心视觉与控制算法的独立性，便于比赛前根据赛道和实车状态快速调整参数。
关键数据结构包括图像缓冲区、左右边线数组、中点序列、视觉事件、固定动作表、当前动作索引和控制状态。调试过程中对应用层算法参数与逐飞库配置分别管理，避免修改底层接口后引起图像采集、PWM 输出或编码器计数异常。最终提交时应补充实际 Flash/RAM/CPU 占用、任务周期、最坏执行时间（WCET）、中断负载、日志带宽、ADS 工程版本和逐飞库版本；核心算法源码置于附录 B。
5.6.1　资源占用与实时性分析
本车主控制器采用 Infineon AURIX TC264，片上 Flash 闪存容量为 2.5 MB，用于存放底层驱动程序、图像处理程序、任务决策程序、运动控制程序以及相关控制参数。系统软件在逐飞科技 TC264 开源库及配套例程基础上进行开发，并将与比赛任务直接相关的视觉识别、状态判断和运动控制算法独立组织，便于程序调试和参数修改。TC264D 官方资料给出的片上 Flash 容量为 2.5 MB。
实时控制部分采用定时中断与图像任务相结合的运行方式。其中，车辆转向控制程序设置在周期为 2 ms 的定时中断中执行。中断触发后，控制程序根据当前赛道中线偏差及车辆反馈状态更新转向控制量，并进一步形成左右驱动轮的差速控制输出，使车辆能够连续修正自身行驶方向。采用固定周期中断执行转向控制，可以使相邻两次控制计算之间具有稳定的时间间隔，避免主循环中图像处理和元素识别任务执行时间变化对转向控制造成明显影响，从而保证循迹和转弯过程中的控制连续性。
视觉处理部分以 MT9V03X 灰度摄像头采集的图像作为输入，依次完成图像裁剪与压缩、二值化、左右边线搜索、中点提取、赛道特征统计以及元素识别等处理，并向后续控制和任务决策模块输出赛道中线位置、元素识别结果及相应状态信息。在当前程序及实际运行工况下，图像处理速度约为 220 FPS。该处理速度能够持续提供赛道前方的视觉信息，使图像感知结果能够及时参与循迹控制、元素判断和动作状态更新。
从系统实时运行情况来看，2 ms 定时中断主要承担对时间敏感的车辆转向控制，图像处理则按照有效图像帧连续执行，两类任务在软件结构上相互配合。转向控制具有固定的执行节拍，不依赖完整视觉算法在主循环中的单次执行过程；视觉模块则持续更新控制所需要的赛道位置和元素信息。因此，在实际循迹、转弯及元素识别过程中，系统能够保持稳定的控制响应和连续的视觉信息更新，满足智能车运行过程中的实时性要求。
本文正文主要说明核心算法的基本原理、输入输出关系及其在系统中的作用，不展开大段程序源代码。其中，图像处理算法以摄像头灰度图像为主要输入，输出赛道边线、中线及元素识别信息，为车辆循迹和任务判断提供依据；转向控制算法以视觉检测得到的赛道位置偏差及车辆反馈状态为输入，输出左右电机控制量，用于实现车辆方向修正和稳定转向。上述核心算法子程序及对应程序源代码统一收录于附录 B，并注明程序模块与第五章相关算法说明之间的对应关系。

9.1　工作总结
本组疯狂电路组智能车的总体技术方案：以MT9V03X灰度摄像头获取导线、元件和岔路信息，利用赛前公布的赛道图选择稳定路线并生成固定动作表，比赛中以在线视觉事件同步动作索引、按序执行分支和返航动作；控制层采用位置—角速度—轮速三串级PID，把中线误差逐级转换为目标横摆角速度、左右轮目标速度和PWM，经双路H桥驱动龙邱科技030直流有刷电机。该方案以决策行为确定、调试方便和稳定完赛为优先目标。
9.2　主要技术指标
经过整车设计、软件调试及赛道测试，本车已形成以视觉感知、固定动作表决策和三串级 PID 控制为核心的软硬件系统。整车改造后最大外形尺寸约为 15 cm × 14 cm × 18 cm，当前完整车体质量记录约为 103 g，该质量仍需在最终比赛状态下复称确认。动力系统采用 11.1 V 三串锂电池供电，电池容量为 180 mAh；左右驱动轮分别采用 1 个龙邱科技 LQ1518-030K-A 直流有刷电机，电机工作电压为 11.1 V，空载转速约 42000 r/min。
感知系统由 1 个 MT9V03X 灰度摄像头、1 个 IMU660RB 横摆角速度传感器和 2 个增量式轮速编码器组成，不设置附加伺服电机。摄像头安装于车体前部，主要完成白色导线、赛道中线、电子元件区域及岔路信息检测；IMU660RB 提供车体 z 轴横摆角速度反馈，左右编码器分别提供两侧驱动轮速度反馈。编码器名义分辨率约为 1024 线，用于构成左右轮速度闭环。
赛道视觉检测方面，以人工标注或测量基准作为真值与算法输出进行对比。当前测试中，赛道中线位置检测误差约为 1 pixel；在 100 组测试样本的统计口径下，赛道信息检测正确率为 98.00%。视觉程序完成图像裁剪与压缩、二值化、左右边线搜索、中点提取及赛道特征识别后，单次图像处理周期约为 4.55 ms，对应实际图像处理频率约 220 FPS，能够持续向任务决策和运动控制模块提供赛道位置及元素状态信息。
运动控制采用位置—角速度—轮速三串级 PID。位置外环根据摄像头检测得到的中线误差生成目标横摆角速度；角速度中环结合陀螺仪反馈计算左右轮差速修正量；左右轮速度内环利用编码器反馈控制电机 PWM 和方向。实时控制程序采用 2 ms 定时中断执行关键转向控制，即控制更新周期为 2 ms，使高速图像处理与车辆运动控制能够按照不同时间尺度协同运行。
综合上述指标，本车已经建立“约 220 FPS 视觉感知—2 ms 实时运动控制—双轮差速执行”的完整控制链路，并能够完成赛道中线提取、元件及岔路信息判断以及左右轮闭环控制。
9.3　存在问题与改进方向

int Dajin_of_part(uint8_t *img_data, uint32_t pixel_count)//图像分区大津法以远端、中间、近端为区分，分别计算不同的二值化阈值，实现更好的二值化效果，分区间隔为20行
{
    // 大津法（Otsu's method）实现
    // 1. 计算灰度直方图
    uint32_t histogram[256] = {0};
    uint32_t total_pixels = pixel_count;
    
    // 统计每个灰度级的像素数量
    for (uint32_t i = 0; i < pixel_count; i++)
    {
        histogram[img_data[i]]++;
    }
    
    // 2. 计算总灰度值
    uint32_t sum_total = 0;
    for (int i = 0; i < 256; i++)
    {
        sum_total += i * histogram[i];
    }
    
    // 3. 大津法计算最佳阈值
    uint32_t sum_background = 0;      // 背景类灰度总和
    uint32_t weight_background = 0;   // 背景类像素数量
    uint32_t weight_foreground;       // 前景类像素数量
    
    float variance_max = 0;           // 最大类间方差
    int threshold = 0;            // 最佳阈值
    
    for (int t = 0; t < 256; t++)
    {
        weight_background += histogram[t];
        if (weight_background == 0) continue;
        
        weight_foreground = total_pixels - weight_background;
        if (weight_foreground == 0) break;
        
        sum_background += t * histogram[t];
        
        // 计算背景类和前景类的均值
        float mean_background = (float)sum_background / weight_background;
        float mean_foreground = (float)(sum_total - sum_background) / weight_foreground;
        
        // 计算类间方差
        float variance_between = (float)weight_background * (float)weight_foreground * 
                               (mean_background - mean_foreground) * (mean_background - mean_foreground);
        
        // 更新最大方差和阈值
        if (variance_between > variance_max)
        {
            variance_max = variance_between;
            threshold = t;
        }
    }
    
    return threshold;
}

/*************************************************************************
 *  函数名称：uint16 GetOSTU (uint8 OSTUImage[MT9V03X_H][MT9V03X_W])
 *  功能说明：大津法求阈值大小
 *  参数说明：OSTUImage ： 图像数据
 *  函数返回：无
 *  修改时间：2011年10月28日
 *  备    注：  GetOSTU(Image_Use);//大津法阈值
Ostu方法又名最大类间差方法，通过统计整个图像的直方图特性来实现全局阈值T的自动选取，其算法步骤为：
1) 先计算图像的直方图，即将图像所有的像素点按照0~255共256个bin，统计落在每个bin的像素点数量
2) 归一化直方图，也即将每个bin中像素点数量除以总的像素点
3) i表示分类的阈值，也即一个灰度级，从0开始迭代 1
4) 通过归一化的直方图，统计0~i 灰度级的像素(假设像素值在此范围的像素叫做前景像素) 所占整幅图像
        的比例w0，        并统计前景像素的平均灰度u0；统计i~255灰度级的像素(假设像素值在此范围的像素叫做背
        景像素)  * 所占整幅图像的比例w1，并统计背景像素的平均灰度u1；
5) 计算前景像素和背景像素的方差 g = w0*w1*(u0-u1) (u0-u1)
6) i++；转到4)，直到i为256时结束迭代
7) 将最大g相应的i值作为图像的全局阈值
缺陷:OSTU算法在处理光照不均匀的图像的时候，效果会明显不好，因为利用的是全局像素信息。
*************************************************************************/

uint8_t GetOSTU(
    uint8_t *OSTUImage,
    uint16_t width,
    uint16_t height
)
{
    uint32_t pixel_count;
    uint32_t total_sum = 0;

    uint32_t back_count = 0;
    uint32_t back_sum = 0;
    uint32_t fore_count;

    uint16_t histogram[256] = {0};

    int min_value;
    int max_value;
    int threshold_temp;

    uint8_t threshold = 0;

    float difference;
    float sigma;
    float sigma_max = -1.0f;

    pixel_count =
        (uint32_t)width *
        (uint32_t)height;

    /* 防止输入空图像。 */
    if(pixel_count == 0)
    {
        return 0;
    }

    /*
     * 建立灰度直方图，同时计算所有像素的灰度总和。
     */
    for(uint32_t i = 0; i < pixel_count; i++)
    {
        uint8_t gray = OSTUImage[i];

        histogram[gray]++;
        total_sum += gray;
    }

    /* 查找图像中真正存在的最小灰度。 */
    min_value = 0;

    while(min_value < 256 &&
          histogram[min_value] == 0)
    {
        min_value++;
    }

    /* 查找图像中真正存在的最大灰度。 */
    max_value = 255;

    while(max_value > min_value &&
          histogram[max_value] == 0)
    {
        max_value--;
    }

    /* 整张图没有有效像素。 */
    if(min_value >= 256)
    {
        return 0;
    }

    /* 整张图只有一种灰度。 */
    if(min_value == max_value)
    {
        return (uint8_t)min_value;
    }

    threshold = (uint8_t)min_value;

    /*
     * 依次尝试每一个阈值。
     *
     * back_count：灰度 <= 当前阈值的像素数量。
     * fore_count：灰度 > 当前阈值的像素数量。
     */
    for(threshold_temp = min_value;
        threshold_temp < max_value;
        threshold_temp++)
    {
        back_count +=
            histogram[threshold_temp];

        back_sum +=
            (uint32_t)histogram[threshold_temp] *
            (uint32_t)threshold_temp;

        fore_count =
            pixel_count - back_count;

        /* 防止空分类和除以零。 */
        if(back_count == 0)
        {
            continue;
        }

        if(fore_count == 0)
        {
            break;
        }

        /*
         * Otsu类间方差的等价形式。
         *
         * 原函数每个阈值需要4次除法，
         * 这里每个阈值只需要1次除法。
         */
        difference =
            (float)total_sum *
            (float)back_count
            -
            (float)back_sum *
            (float)pixel_count;

        sigma =
            (difference * difference)
            /
            (
                (float)back_count *
                (float)fore_count
            );

        if(sigma > sigma_max)
        {
            sigma_max = sigma;
            threshold =
                (uint8_t)threshold_temp;
        }
    }

    return threshold;
}

//第一个参数是要查找的数组（80个点）
//第二个扫左边线还是扫右边线
//三四是开始和结束点
//找跳变点的话，左边从左往右，右边从右往左，主要是扫描外侧的跳变点！！！

void GetJumpPointFromDet(uint8_t* p,uint8_t type,int L,int H,JumpPointtypedef* JumpPoint)
{
    int i = 0;
    if (type == 'L')                              //扫描左边线
    {
        for (i = L; i <= H; i++)                    //从左往右扫
        {
            if (*(p + i) == 0 && *(p + i + 1) == 1)   //找由黑变白的跳变
            {
                JumpPoint->point = i;                           //记录
                JumpPoint->type = 'T';
                break;
            }
            else if (i == (H))                  //若果扫到最后也没找到(H-1)
            {
                if (*(p + (L + H) / 2) == 1)            //如果中间是白的
                {
                    JumpPoint->point = (L + H) / 2;               //右边线是中点
                    JumpPoint->type = 'W';  //非正确跳变且中间为白，认为没有边（都是白的）->认为是大跳变，可以用来进行区域直角判断（判断节点和直角路口）
                    break;
                }
                else                                  //如果中点是黑的
                {
                    JumpPoint->point = (L + H) / 2;                         //右边线直接最小值
                    JumpPoint->type = 'H';  //非正确跳变且中间为黑，认为没有边（都是黑的）->认为是遇到断开的情况（判断是否的电容等）
                    break;
                }
            }
        }
    }
    else if (type == 'R')                       //扫描右边线
    {
        for (i = H; i >= L; i--)
        {
            if (*(p + i) == 0 && *(p + i - 1) == 1)   //由黑变白
            {
                JumpPoint->point = i;                           //记录左边线
                JumpPoint->type = 'T';                          //正确跳变
                break;
            }
            else if (i == (L))                  //如果扫到最后也没找到(L-1)
            {
                if (*(p + (L + H) / 2) == 1)            //如果中间是白的
                {
                    JumpPoint->point = (L + H) / 2;               //认为左边线是中点
                    JumpPoint->type = 'W';                        //非正确跳变且中间为白，认为没有边（都是白的）
                    break;
                }
                else                                  //非正确跳变且中间为黑
                {
                    JumpPoint->point = (L + H) / 2;                         //如果中间是黑的
                    JumpPoint->type = 'H';                        //左边线直接最大值，认为是大跳变
                    break;
                }
            }
        }
    }
}

//获取真实的赛道边界，主要用于元素的辅助判断
void Get_Actually_L_R_Line(int row, uint8_t type,JumpPointtypedef* JumpPoint)
{
    if (type == 'L')
    {
        ImageDeal[row].LeftBorder2 = 1; //默认左右边界为最左或最右
        if (JumpPoint->type == 'H' || JumpPoint->type == 'W')//为大跳变点或者无边边界
        {
            for (int i = MT9_COMPRESS_W / 2; i > 0; i--)
            {
                if (mt9_binary_image[row][i + 1] == 1 && mt9_binary_image[row][i] == 0)//从中间向左寻找白黑跳变点
                {
                    ImageDeal[row].LeftBorder2 = i;
                    break;
                }
            }
        }
        else if(JumpPoint->type == 'T')//正常跳变点
            ImageDeal[row].LeftBorder2 = ImageDeal[row].LeftBorder;
    }

    else if (type == 'R')
    {
        ImageDeal[row].RightBorder2 = 79;
        if (JumpPoint->type == 'H' || JumpPoint->type == 'W')//为大跳变点或者无边边界
        {
            for (int i = MT9_COMPRESS_W / 2; i < MT9_COMPRESS_W - 1; i++)
            {
                if (mt9_binary_image[row][i] == 1 && mt9_binary_image[row][i + 1] == 0)//从中间向右寻找跳变点
                {
                    ImageDeal[row].RightBorder2 = i;
                    break;
                }
            }
        }
        else if(JumpPoint->type == 'T')//正常跳变点
            ImageDeal[row].RightBorder2 = ImageDeal[row].RightBorder;
    }
}

                /*额外加了这段代码，旨在对应车身不正的时候得不到W_Point_L*/
            }
            if (ImageDeal[Ysite].IsRightFind == 'H' || ImageDeal[Ysite].IsRightFind == 'W')
            {
                /*额外加了这段代码，旨在对应车身不正的时候得不到W_Point_R*/
                int Preliminary_state_IS_W = 0;//初步确定的状态是W状态的标志位

                if(ImageDeal[Ysite].IsRightFind == 'W')//这个点是初步确定为跳变点状态
                {
                    Preliminary_state_IS_W = 1;       //初步确定的状态是确实是W状态
                }
               /*额外加了这段代码，旨在对应车身不正的时候得不到W_Point_R*/
                //从右往左
//                IntervalLow = 20;
                IntervalLow = ImageDeal[Ysite+1].LeftBorder;
                IntervalHigh = MT9_COMPRESS_W - 1;
                for (Xsite = IntervalHigh; Xsite >= IntervalLow; Xsite--)
                {
                    if ((*(PicTemp + Xsite) == 0) && (*(PicTemp + Xsite - 1) == 1))
                    {
                        ImageDeal[Ysite].RightBorder = Xsite;                    //如果右边线的左边还有黑白跳变则为绝对边线直接取出
                        ImageDeal[Ysite].IsRightFind = 'T';
                        break;
                    }
                    else if(*(PicTemp + Xsite) == 1)
                    {
                        ImageDeal[Ysite].IsRightFind = 'W';
                        ImageDeal[Ysite].RightBorder = 79;
                        break;//针对最边上的是白点的情况，证明是白边W！！！

                    }                        
                    else if (Xsite == IntervalLow)
                    {
                        ImageDeal[Ysite].IsRightFind = 'H';
                        ImageDeal[Ysite].RightBorder = ImageDeal[Ysite+1].RightBorder ;
                        break;
                    }
                }
                /*额外加了这段代码，旨在对应车身不正的时候得不到W_Point_R*/
                if(Preliminary_state_IS_W && ImageDeal[Ysite].IsRightFind == 'T')//此行边界本身被确定为W但是再次确定却不是W状态而是T也就是正常巡线得到的边界
                {
                    R_first_W_but_to_T[Ysite] = 1;
                }

                /*额外加了这段代码，旨在对应车身不正的时候得不到W_Point_R*/
            }
            if(ImageDeal[Ysite].IsLeftFind == 'H' && ImageDeal[Ysite].IsRightFind == 'H')   continue_lost_count++;
            else    continue_lost_count = 0;   
        }

        LimitL(ImageDeal[Ysite].LeftBorder);   //限幅
        LimitH(ImageDeal[Ysite].LeftBorder);   //限幅
        LimitL(ImageDeal[Ysite].RightBorder);  //限幅
        LimitH(ImageDeal[Ysite].RightBorder);  //限幅

        ImageDeal[Ysite].Wide = ImageDeal[Ysite].RightBorder - ImageDeal[Ysite].LeftBorder;//获取图像宽度

        if(ImageStatus.Road_type != Normol && Path[Path_Switch].memory_target_angle_turn[Path[Path_Switch].target_angle_index] == 'L')
            ImageDeal[Ysite].Center =ImageDeal[Ysite].LeftBorder + Image_Real_Wide[Ysite]/2;
        else if(ImageStatus.Road_type != Normol && Path[Path_Switch].memory_target_angle_turn[Path[Path_Switch].target_angle_index] == 'R')
            ImageDeal[Ysite].Center =ImageDeal[Ysite].RightBorder - Image_Real_Wide[Ysite]/2;
        else
            ImageDeal[Ysite].Center =(ImageDeal[Ysite].RightBorder + ImageDeal[Ysite].LeftBorder) / 2;

        //重新确定可视距离
        //当图像宽度小于0或者左右边达到一定的限制时，则终止巡边
        if(continue_lost_count > 5 && Ysite <= 10)
        {
            ImageStatus.OFFLine = Ysite + 5;
            break;
        }
        else if(continue_lost_count >= 30 && Ysite <= 35)//需要修改！！！
        {
            ImageStatus.OFFLine = Ysite + 30;
            break;
        }
    }
    int confirm_flag[2] = {0,0}; //只成功重找到一次W的标志位
    for (Ysite = 53 ; Ysite >= ImageStatus.OFFLine; Ysite--)        //为了mos管单独搞的，不知道会不会出大问题,答：不会
    {
        if(L_first_W_but_to_T[Ysite] == 1 && confirm_flag[0] == 0)//有后面confirm_flag的判断是为了只进行一次W的重找，没有就是一直找
        {
            for(int i = Ysite+20;i>=Ysite-17 ;i--)//只找两行试试效果
            {
                if(i<ImageStatus.OFFLine) break;
                if(i>Y_bottom_limit) continue;
                if(i>30)
                {
                    if(mt9_binary_image[i][0] == 1 && mt9_binary_image[i-1][0] == 1 && mt9_binary_image[i-2][0] == 1) //最右边是白点
                    {
                        ImageDeal[i].IsLeftFind = 'W';
                        ImageDeal[i].LeftBorder = 0;
                        confirm_flag[0] = 1;
                        break;                      //从下往上扫扫到跳变点就算成功就退出
                    }
                }
                else if(i>20)
                {
                    if(mt9_binary_image[i][0] == 1 ) //最右边是白点
                    {
                        ImageDeal[i].IsLeftFind = 'W';
                        ImageDeal[i].LeftBorder = 0;
                        confirm_flag[0] = 1;
                        break;                      //从下往上扫扫到跳变点就算成功就退出
                    }
                }
                else if(i>0)
                {
                    if(mt9_binary_image[i][0] == 1 ) //最右边是白点
                    {
                        ImageDeal[i].IsLeftFind = 'W';
                        ImageDeal[i].LeftBorder = 0;
                        confirm_flag[0] = 1;
                        break;                      //从下往上扫扫到跳变点就算成功就退出
                    }
                }
            }
        }

        if(R_first_W_but_to_T[Ysite] == 1 && confirm_flag[1] == 0)//有后面confirm_flag的判断是为了只进行一次W的重找，没有就是一直找
        {
            for(int i = Ysite+20;i>=Ysite-17;i--)//只找两行试试效果
            {
                if(i<ImageStatus.OFFLine) break;
                if(i>Y_bottom_limit) continue;
                if(i>30)
                {
                    if(mt9_binary_image[i][79] == 1 && mt9_binary_image[i-1][79] == 1 && mt9_binary_image[i-2][79] == 1 ) //最右边是白点
                    {
                        ImageDeal[i].IsRightFind = 'W';
                        ImageDeal[i].RightBorder = 79;
                        confirm_flag[1] = 1;
                        break;                      //从下往上扫扫到跳变点就算成功就退出
                    }
                }
                else if(i>20)
                {
                    if(mt9_binary_image[i][79] == 1   ) //最右边是白点
                    {
                        ImageDeal[i].IsRightFind = 'W';
                        ImageDeal[i].RightBorder = 79;
                        confirm_flag[1] = 1;
                        break;                      //从下往上扫扫到跳变点就算成功就退出
                    }
                }
                else if(i>0)
                {
                    if(mt9_binary_image[i][79] == 1 ) //最右边是白点
                    {

                        ImageDeal[i].RightBorder = 79;
                        confirm_flag[1] = 1;
                        break;                      //从下往上扫扫到跳变点就算成功就退出
                    }
                }
            }
        }

    }
    for (Ysite = 58 ; Ysite >= ImageStatus.OFFLine; Ysite--)            //前5行处理过了，下面从58行到（设定的不处理的行OFFLine）
    {
        LimitL(ImageDeal[Ysite].LeftBorder);   //限幅
        LimitH(ImageDeal[Ysite].LeftBorder);   //限幅
        LimitL(ImageDeal[Ysite].RightBorder);  //限幅
        LimitH(ImageDeal[Ysite].RightBorder);  //限幅

        ImageDeal[Ysite].Wide = ImageDeal[Ysite].RightBorder - ImageDeal[Ysite].LeftBorder;//获取图像宽度
        ImageDeal[Ysite].Center =(ImageDeal[Ysite].RightBorder + ImageDeal[Ysite].LeftBorder) / 2;
    }

}
int Frame_Detect(int center_x, int center_y, int frame_width, int frame_height,char dir)
{
    int return_row = 0;
    //框检测！！！
    int Y_bottom = center_y + (int)(1.0*frame_height*3/7);
    int Y_top = center_y - (int)(1.0*frame_height*4/7);
    int X_right = center_x + frame_width/2;
    int X_left = center_x - frame_width/2;
    ImageFrameDetect.frame_bottom_flag = 0;
    ImageFrameDetect.frame_top_flag = 0;
    ImageFrameDetect.frame_right_flag = 0;
    ImageFrameDetect.frame_left_flag = 0;

    //限幅
    Y_bottom = (Y_bottom >= MT9_COMPRESS_H-5) ? MT9_COMPRESS_H-5 : Y_bottom;
    Y_top = (Y_top <= 5) ? 5 : Y_top; //原来是5
    X_right = (X_right >= MT9_COMPRESS_W-5) ? MT9_COMPRESS_W-5 : X_right;
    X_left = (X_left <= 5) ? 5 : X_left;

    //以中心为基准，框检测！！！
    //框检测上下边界！！！
    for (Ysite = Y_top; Ysite <= Y_bottom-2; Ysite++)
    {
        //左边界
//        if(ImageFrameDetect.frame_left_flag == 0)
//        {
//            if(mt9_binary_image[Ysite][X_left] == 0 && mt9_binary_image[Ysite+1][X_left] == 1)      ImageFrameDetect.frame_left_flag = 1;
//        }
        if(ImageFrameDetect.frame_left_flag == 0)
        {
            if(mt9_binary_image[Ysite][X_left] == 0 && mt9_binary_image[Ysite+1][X_left] == 1 )
                  ImageFrameDetect.frame_left_flag = 1;
            /*进这个if说明此时框的上边界正好是图像的直角的一行，且为了避免只有图像只有一行白点导致下一次++找不到白调黑所以对Ysite进行了--处理
             *以此保证下次循环一定能以这个点进行白跳黑判断*/
            if(mt9_binary_image[Ysite][X_left] == 1 && Ysite == Y_top )
            {
                ImageFrameDetect.frame_left_flag = 1;
                Ysite -= 1;
            }
        }
        else if(ImageFrameDetect.frame_left_flag == 1)
        {
            if(mt9_binary_image[Ysite][X_left] == 1 && mt9_binary_image[Ysite+1][X_left] == 0)
            {
                if(return_row == 0 && dir == 'L')  return_row = Ysite;
                ImageFrameDetect.frame_left_flag = 2;
            }
        }
        else if(ImageFrameDetect.frame_left_flag == 2)
        {
            if(mt9_binary_image[Ysite][X_left] == 0 && mt9_binary_image[Ysite+1][X_left] == 1)      ImageFrameDetect.frame_left_flag = 3;

        }
        else if(ImageFrameDetect.frame_left_flag == 3)
        {
            if(mt9_binary_image[Ysite][X_left] == 1 && mt9_binary_image[Ysite+1][X_left] == 0)      ImageFrameDetect.frame_left_flag = 4;    
        }

        //右边界
//        if(ImageFrameDetect.frame_right_flag == 0)
//        {
//            if(mt9_binary_image[Ysite][X_left] == 0 && mt9_binary_image[Ysite+1][X_left] == 1)      ImageFrameDetect.frame_right_flag = 1;
//        }
        if(ImageFrameDetect.frame_right_flag == 0)
        {
            if(mt9_binary_image[Ysite][X_right] == 0 && mt9_binary_image[Ysite+1][X_right] == 1)
                ImageFrameDetect.frame_right_flag = 1;
            /*进这个if说明此时框的上边界正好是图像的直角的一行，且为了避免只有图像只有一行白点导致下一次++找不到白调黑所以对Ysite进行了--处理
             *以此保证下次循环一定能以这个点进行白跳黑判断*/
            if(mt9_binary_image[Ysite][X_right] == 1 && Ysite == Y_top)
            {
                ImageFrameDetect.frame_right_flag = 1;
                Ysite -= 1;
            }
        }
        else if(ImageFrameDetect.frame_right_flag == 1)
        {
            if(mt9_binary_image[Ysite][X_right] == 1 && mt9_binary_image[Ysite+1][X_right] == 0)
            {
                if(return_row == 0 && dir == 'R')  return_row = Ysite;
                ImageFrameDetect.frame_right_flag = 2;
            }
        }
        else if(ImageFrameDetect.frame_right_flag == 2)
        {
            if(mt9_binary_image[Ysite][X_right] == 0 && mt9_binary_image[Ysite+1][X_right] == 1)    ImageFrameDetect.frame_right_flag = 3;

        }
        else if(ImageFrameDetect.frame_right_flag == 3)
        {
            if(mt9_binary_image[Ysite][X_right] == 1 && mt9_binary_image[Ysite+1][X_right] == 0)    ImageFrameDetect.frame_right_flag = 4;   
        }
    }
    //框检测左右边界！！！
    for (Xsite = X_left; Xsite <= X_right-2; Xsite++)
    {
        //上边界
        if(ImageFrameDetect.frame_top_flag == 0)
        {
            if(mt9_binary_image[Y_top][Xsite] == 0 && mt9_binary_image[Y_top][Xsite+1] == 1)        ImageFrameDetect.frame_top_flag = 1;
            else if(mt9_binary_image[Y_top][Xsite] == 1 && mt9_binary_image[Y_top][Xsite+1] == 1)   ImageFrameDetect.frame_top_flag = 1;
        }
        else if(ImageFrameDetect.frame_top_flag == 1)
        {
            if(mt9_binary_image[Y_top][Xsite] == 1 && mt9_binary_image[Y_top][Xsite+1] == 0)        ImageFrameDetect.frame_top_flag = 2;     
        }
        else if(ImageFrameDetect.frame_top_flag == 2)
        {
            if(mt9_binary_image[Y_top][Xsite] == 0 && mt9_binary_image[Y_top][Xsite+1] == 1)        ImageFrameDetect.frame_top_flag = 3;
        }
        else if(ImageFrameDetect.frame_top_flag == 3)
        {
            if(mt9_binary_image[Y_top][Xsite] == 1 && mt9_binary_image[Y_top][Xsite+1] == 0)        ImageFrameDetect.frame_top_flag = 4;
        }

        //下边界
        if(ImageFrameDetect.frame_bottom_flag == 0)
        {
            if(mt9_binary_image[Y_bottom][Xsite] == 0 && mt9_binary_image[Y_bottom][Xsite+1] == 1)  ImageFrameDetect.frame_bottom_flag = 1;
            else if(mt9_binary_image[Y_bottom][Xsite] == 1 && mt9_binary_image[Y_bottom][Xsite+1] == 1) ImageFrameDetect.frame_bottom_flag = 1;
        }
        else if(ImageFrameDetect.frame_bottom_flag == 1)
        {
            if(mt9_binary_image[Y_bottom][Xsite] == 1 && mt9_binary_image[Y_bottom][Xsite+1] == 0)  ImageFrameDetect.frame_bottom_flag = 2;   
        }
        else if(ImageFrameDetect.frame_bottom_flag == 2)
        {
            if(mt9_binary_image[Y_bottom][Xsite] == 0 && mt9_binary_image[Y_bottom][Xsite+1] == 1)  ImageFrameDetect.frame_bottom_flag = 3;
        }
        else if(ImageFrameDetect.frame_bottom_flag == 3)
        {
            if(mt9_binary_image[Y_bottom][Xsite] == 1 && mt9_binary_image[Y_bottom][Xsite+1] == 0)  ImageFrameDetect.frame_bottom_flag = 4;   
        }
    }
    return return_row;
}

void Find_Spinodal(void)//从上至下，找拐点
{
    int i = 0;
    int center_count = 0;//用来统计中心点的平均值的
    for (i = 2; i <= 57; i++)
    {
        if(mt9_binary_image[57 - i + 2][1] == 1  && ImageDeal[57 - i + 2].IsLeftFind == 'W' && ImageFrameDetect.spinodal_L_Ysite == 0)
        {
            ImageFrameDetect.spinodal_L_Ysite = 57 - i + 2;
        }
        if(mt9_binary_image[57 - i + 2][78] == 1  && ImageDeal[57 - i + 2].IsRightFind == 'W' && ImageFrameDetect.spinodal_R_Ysite == 0)
        {
            ImageFrameDetect.spinodal_R_Ysite = 57 - i + 2;
        }
        //取W的下一行为First_W_Point_L等，达到取一个正常的检测框中心的目的！！！
        if(ImageDeal[i].IsLeftFind == 'W' && ImageDeal[i+1].IsLeftFind == 'T' && ImageStatus.First_W_Point_L == 0)     ImageStatus.First_W_Point_L = i+1 ;
        if(ImageDeal[i].IsRightFind == 'W' && ImageDeal[i+1].IsRightFind == 'T' && ImageStatus.First_W_Point_R == 0)   ImageStatus.First_W_Point_R = i+1;
        if(ImageDeal[i].IsLeftFind == 'H' && (ImageDeal[i+1].IsLeftFind == 'T' || ImageDeal[i+1].IsLeftFind == 'W') 
        && ImageStatus.First_H_Point_L == 0)    ImageStatus.First_H_Point_L = i+1;
        if(ImageDeal[i].IsRightFind == 'H' && (ImageDeal[i+1].IsRightFind == 'T' || ImageDeal[i+1].IsRightFind == 'W') 
        && ImageStatus.First_H_Point_R == 0)    ImageStatus.First_H_Point_R = i+1;

        if(ImageFrameDetect.spinodal_L_Ysite != 0 && ImageFrameDetect.spinodal_R_Ysite != 0 && ImageStatus.First_W_Point_L != 0 
        && ImageStatus.First_W_Point_R != 0 && ImageStatus.First_H_Point_L != 0 && ImageStatus.First_H_Point_R != 0) break;//如果都找到了就可以提前结束循环了
    }
    for(i = 59; i >= ImageStatus.OFFLine; i--)//取最下面10行的中心点的平均值作为图像中心，得到更稳定的检测框！！！
    {
        if(ImageDeal[i].IsLeftFind == 'T' && ImageDeal[i].IsRightFind == 'T')
        {
            ImageFrameDetect.image_center_x += ImageDeal[i].Center;
            center_count++;
        }
    }
    if(center_count==0) center_count=1;
    ImageFrameDetect.image_center_x /= center_count;
}

void Element_Handle(void)
{
    if(ImageStatus.Road_type == Normol  && stop_flag == 0 && !nav_active)  Protect_Car();
    // 'N' 段误识别保护：直行段不允许执行转向元素，直接清掉交给距离兜底

    if(Path[Path_Switch].memory_target_angle_turn[Path[Path_Switch].target_angle_index] == 'N'
    && (ImageStatus.Road_type == RightAngle_L || ImageStatus.Road_type == RightAngle_R
     || ImageStatus.Road_type == Node_T || ImageStatus.Road_type == Branch))                        // Node_T/Branch 也有同样的瞬完问题
    {
        ImageFlag.image_element_angle_flag = 0;
        ImageFlag.image_element_Node_flag  = 0;
        ImageFlag.image_element_branch_flag = 0;

        ImageStatus.Road_type = Normol;                          // 本帧会走 Miss_N_Node 按距离推进
    }

    if(ImageStatus.Road_type != Normol && Path[Path_Switch].memory_target_angle_turn[Path[Path_Switch].target_angle_index] == 'V')
    {
        Element_Handle_Navigation();
    }
    else if(ImageStatus.Road_type == RightAngle_L)
    {
        Elment_Handle_RightAngle_L();
    }

    else if(ImageStatus.Road_type == RightAngle_R)
    {
        Elment_Handle_RightAngle_R();
    }

    else if(ImageStatus.Road_type == Node_L)
    {
        Elment_Handle_Node_L();
    }

    else if(ImageStatus.Road_type == Node_R)
    {
        Elment_Handle_Node_R();
    }

    else if(ImageStatus.Road_type == Node_T)
    {
        Elment_Handle_Node_T();
    }

    else if(ImageStatus.Road_type == Branch)
    {
        Elment_Handle_Branch();
    }

    else if(ImageStatus.Road_type == Cross || ImageStatus.Road_type == Odd_Cross)
    {
        Elment_Handle_Cross();
    }

    else if(ImageStatus.Road_type == Correct)
    {
        Elment_Handle_Correct();
    }

    else if(ImageStatus.Road_type == Normol)
    {
        Element_Handle_Miss_N_Node();
    }
}

void remove_isolated_white_noise(
    const uint8_t input[MT9_COMPRESS_H][MT9_COMPRESS_W],
    uint8_t output[MT9_COMPRESS_H][MT9_COMPRESS_W])
{
    int y;
    int x;

    /* 先保留原图，边缘不进行去噪。 */
    memcpy(
        output,
        input,
        MT9_COMPRESS_H * MT9_COMPRESS_W * sizeof(uint8_t)
    );

    for(y = 1; y < MT9_COMPRESS_H - 1; y++)
    {
        const uint8_t *up   = input[y - 1];
        const uint8_t *mid  = input[y];
        const uint8_t *down = input[y + 1];

        uint8_t *dst = output[y];

        /*
         * 分别统计当前窗口左列和中列的3个像素。
         * 输入图像必须是0/1二值图。
         */
        int column_left =
            up[0] + mid[0] + down[0];

        int column_middle =
            up[1] + mid[1] + down[1];

        for(x = 1; x < MT9_COMPRESS_W - 1; x++)
        {
            int column_right =
                up[x + 1] +
                mid[x + 1] +
                down[x + 1];

            /*
             * 3×3白点总数减去当前像素，
             * 就是周围8邻域的白点数量。
             */
            int count_white =
                column_left +
                column_middle +
                column_right -
                mid[x];

            if(mid[x] != 0 && count_white < 2)
            {
                dst[x] = 0;
            }

            /* 窗口向右移动一列。 */
            column_left = column_middle;
            column_middle = column_right;
        }
    }
}
//由于硬件问题，图像获取有些时候会出现一行全白的情况，因此写了这个函数避免，我真没招了，到时候硬件没问题了这代码可以删了 对于T弯道确实会有影响吧，其实对于T弯道没什么影响
void Correct_camera_wrong(void)
{

    for(int Y_site = 5;Y_site<MT9_COMPRESS_H-10;Y_site++)
    {
        int err_col[MT9_COMPRESS_W]={0}; //错误的列
        int err_cnt = 0;
        for(int X_site = 0;X_site<MT9_COMPRESS_W;X_site++)
        {
            if(mt9_binary_image[Y_site][X_site] == 0)//黑点
                break;
            if(mt9_binary_image[Y_site+1][X_site] == 0 &&mt9_binary_image[Y_site-1][X_site] == 0)//其上下均为黑
            {
                err_cnt ++; //白点
                err_col[X_site] = 1;
            }

        }
        if(err_cnt >=(int)(MT9_COMPRESS_W/3))
        {
            for(int X_site = 0;X_site<MT9_COMPRESS_W;X_site++)
            {
                if(err_col[X_site] == 1)  //为错误行
                    mt9_binary_image[Y_site][X_site] = 0;//改为黑色图像
            }
        }
    }
}

int turn_TowPoint = 24;

void Get_TowPoint(int Distance)//取权重行
{
    TowPoint = 0;
    DetTemp = 0;
    float WhiteGain = 0;//通过长白列来判断前瞻
    
    /* 长白列前瞻 */
    WhiteGain = 9 * whitehigh_float;    //whitehigh_float = (float)(whitehigh - 40)/(55 - 5)
    if (WhiteGain >= Gain_High)
       WhiteGain = Gain_High * 1.0;
    else if (WhiteGain <= Gain_Low)
       WhiteGain = Gain_Low * 1.0;

    //元素固定前瞻

//    if(Distance>0 && Distance<=70)
//    {
//            ImageStatus.TowPoint = turn_TowPoint;
//    }
//    else    ImageStatus.TowPoint = 12;
    ImageStatus.TowPoint = 12;

    TowPoint = ImageStatus.TowPoint - WhiteGain;  //白列越长前瞻越长

    //当拟定前瞻取不到后取赛道最高点作为偏差点
    if(ImageStatus.Road_type != Normol)
    {
        if(no_fuya_go == 0)
        {
            if(Distance>0 && Distance<=65)
            {
                TowPoint = turn_TowPoint;
            }
            else    TowPoint = 12;

            if(Distance>=100 || (Path_Switch == 0 && Path[Path_Switch].target_angle_index == 50) || (Path_Switch == 2 && Path[Path_Switch].target_angle_index == 69))
            {
                Outer_Ring_P_use = 560;
            }
            else
            {
                Outer_Ring_P_use = (no_fuya_go == 1) ? Outer_Ring_P_no_fuya : Outer_Ring_P;   // 恢复发车基准
            }
        }
    }
    else
    {
        Outer_Ring_P_use = (no_fuya_go == 1) ? Outer_Ring_P_no_fuya : Outer_Ring_P;       // 普通道路：保持调参值
    }
    if (TowPoint < ImageStatus.OFFLine)
        TowPoint = ImageStatus.OFFLine + 1;

    if (TowPoint >= 48) TowPoint = 48;//限幅
    else if(TowPoint <= 12) TowPoint = 12;//限幅

    Ysite_bottom = (TowPoint - 10);
    Ysite_top = (TowPoint + 10);

}

void Get_Deviation(void)
{
    float UnitAll = 0;
    for (int Ysite = Ysite_bottom; Ysite < Ysite_top; Ysite++)
    {
        DetTemp = DetTemp + Weighting_20[Ysite - Ysite_bottom] * (ImageDeal[Ysite].Center);
        UnitAll = UnitAll + Weighting_20[Ysite - Ysite_bottom];
    }
    DetTemp = (ImageDeal[TowPoint].Center + DetTemp) / (UnitAll + 1);

    ImageStatus.Det_True = DetTemp; //此时的解算出来的平均图像偏差

    ImageStatus.TowPoint_True = TowPoint;   //此时的前瞻
}

int Reference_Error_Row(void)
{
    if(ImageStatus.Road_type == Normol) return 0;

    int last_Distance = 0;
    int last_sum_Distance = 0;
    int Distance = Path[Path_Switch].memory_target_distance[Path[Path_Switch].target_angle_index]/522;

    for(int i = 1;i<5;i++)//向前找五个节点是N则距离累加，当不是N时候退出
    {
        if(Path[Path_Switch].target_angle_index-i<0)    break;

        if(Path[Path_Switch].memory_target_angle_turn[Path[Path_Switch].target_angle_index-i] == 'N')
        {
            last_Distance = Path[Path_Switch].memory_target_distance[Path[Path_Switch].target_angle_index-i]/522;
        }
        else break;
        last_sum_Distance += last_Distance;
    }
    Distance += last_sum_Distance;
    if(Distance>=80  || (Path_Switch == 0 && Path[Path_Switch].target_angle_index == 50) || (Path_Switch == 2 && Path[Path_Switch].target_angle_index == 69))//|| (Long_flag && Distance>=50
    {
        if(Path[Path_Switch].memory_target_angle_turn[Path[Path_Switch].target_angle_index] == 'R')
            ImageStatus.First_W_Point_R += advance_row;//往下看5行，增加稳定性！！！
        else if(Path[Path_Switch].memory_target_angle_turn[Path[Path_Switch].target_angle_index] == 'L')
            ImageStatus.First_W_Point_L += advance_row;//往下看5行，增加稳定性！！！
        if(ImageStatus.First_W_Point_L > 58) ImageStatus.First_W_Point_L = 58;
        if(ImageStatus.First_W_Point_R > 58) ImageStatus.First_W_Point_R = 58;

    }
    return Distance;
}

void Speed_decision(void)
{
    //速度决策
    if(Speed_decision_flag == 0) return ;

    Straight_Speed = target_speed;
    Straight_Speed_no_fuya = no_fuya_speed;
    if(ImageStatus.Road_type == Normol || Path[Path_Switch].memory_target_angle_turn[Path[Path_Switch].target_angle_index] == 'N')
    {
        if(no_fuya_go == 1) //无负压低速
            target_speed_use = Straight_Speed_no_fuya;
        else                //有负压高速
            target_speed_use = Straight_Speed;
    }
    else
    {
        if(no_fuya_go == 1) //无负压低速
            target_speed_use = Road_turn_Speed_no_fuya;
        else                //有负压高速
            target_speed_use = Road_turn_Speed;
    }
    //长直道加速
    if(no_fuya_go == 0)
    {
        if(ImageStatus.Road_type == Normol || Path[Path_Switch].memory_target_angle_turn[Path[Path_Switch].target_angle_index] == 'N')
        {
            if(Path_Switch == 0)
            {
                if(Path[Path_Switch].target_angle_index>=22 && Path[Path_Switch].target_angle_index<=25)
                {
                    target_speed_use = long_Straight_Speed;
                    Long_flag = 1;
                }
                else if(Path[Path_Switch].target_angle_index==26)
                {
                    target_speed_use = long_Straight_Speed+40;
                }
    //            else if(Path[Path_Switch].target_angle_index>=27) //软件盲盒
    //            {
    //                target_speed_use = 200;
    //            }
                else
                {
                    Long_flag = 0;
                }
            }
            else if(Path_Switch == 1)
            {
                if(Path[Path_Switch].target_angle_index==22 ||(Path[Path_Switch].target_angle_index>=24))
                {
                    target_speed_use = long_Straight_Speed;
                    Long_flag = 1;
                }
                else
                {
                    Long_flag = 0;
                }
            }
            else if(Path_Switch == 2)
            {
                if((Path[Path_Switch].target_angle_index >= 8 && Path[Path_Switch].target_angle_index <= 10)||
                    (Path[Path_Switch].target_angle_index >= 12 && Path[Path_Switch].target_angle_index <= 14)||
                    (Path[Path_Switch].target_angle_index >= 26 && Path[Path_Switch].target_angle_index <= 30)||
                    (Path[Path_Switch].target_angle_index >= 32 && Path[Path_Switch].target_angle_index <= 35)||
                    (Path[Path_Switch].target_angle_index >= 41 && Path[Path_Switch].target_angle_index <= 43)||
                    Path[Path_Switch].target_angle_index >= 44
                        )
                {
                    target_speed_use = long_Straight_Speed;
                    Long_flag = 1;
                }
                else
                {
                    Long_flag = 0;
                }
            }
            else if(Path_Switch == 3)
            {
                if( (Path[Path_Switch].target_angle_index >= 14 && Path[Path_Switch].target_angle_index <= 15)
                    ||(Path[Path_Switch].target_angle_index >= 24 && Path[Path_Switch].target_angle_index <= 27)
                    || Path[Path_Switch].target_angle_index == 37
                    ||(Path[Path_Switch].target_angle_index >= 39))
                {
                    target_speed_use = long_Straight_Speed;
                    Long_flag = 1;
                }
                else
                {
                    Long_flag = 0;
                }
            }
        }
    }
}

static void Element_Judgment_With_Yaw_Amend(void)
{
    RoadType_e road_before;
    uint8 index;
    float theory_angle;

    /* 记录识别前的道路类型 */
    road_before = ImageStatus.Road_type;

    /* 执行原来的元素识别 */
    Element_Judgment();

    if(Path_Switch == 0 )
    {
        //以下一起使用
        if(Path[Path_Switch].target_angle_index == 23)
        {
            Path[Path_Switch].target_angle_index++;
            ImageFlag.image_element_angle_flag = 0;
            ImageFlag.image_element_Node_flag = 0;
            ImageFlag.image_element_branch_flag = 0;
            ImageFlag.image_element_cross_flag = 0;
            ImageStatus.Road_type  = Normol;
        }
        if(ImageStatus.Road_type != Node_T &&Path[Path_Switch].target_angle_index == 24)
        {
//            Path[Path_Switch].target_angle_index++;
            ImageFlag.image_element_angle_flag = 0;
            ImageFlag.image_element_Node_flag = 0;
            ImageFlag.image_element_branch_flag = 0;
            ImageFlag.image_element_cross_flag = 0;
            ImageStatus.Road_type  = Normol;
        }
        //以上一起使用
        if(ImageStatus.Road_type != Cross && Path[Path_Switch].target_angle_index == 50)//识别成功，设置标志位和道路类型)
        {
            ImageFlag.image_element_angle_flag = 0;
            ImageFlag.image_element_Node_flag = 0;
            ImageFlag.image_element_branch_flag = 0;
            ImageFlag.image_element_cross_flag = 0;
            ImageStatus.Road_type  = Normol;
        }

    }

    /* 没有发生 Normol -> 元素，不发布请求 */
    if(road_before != Normol || ImageStatus.Road_type == Normol)
    {
        return;
    }

    index = Path[Path_Switch].target_angle_index;

    /*
     * 当前数组容量为45，合法下标是0~44。
     * 不能只判断 index < path_length，因为当前path_length可能是49。
     */
    if(index < 1
       || index >= Path[Path_Switch].path_length)
    {
        return;
    }

    /* 前一段长度必须大于100cm */
    if(Path[Path_Switch].memory_target_distance[index]
       <= CM_TO_ENCODER(85))
    {
        return;
    }

    /* 使用进入当前元素前的理论朝向 */
    theory_angle =
        (float)Path[Path_Switch].memory_target_angle[index - 1];

    /* CPU1只发布请求，不修改post.yaw_angle */
    Yaw_Amend_Publish(
        theory_angle,
        (int)ImageStatus.Road_type
    );
}
