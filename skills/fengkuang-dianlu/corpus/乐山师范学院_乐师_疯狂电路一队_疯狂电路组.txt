摘要


本文以第二十一届全国大学生智能汽车竞赛疯狂电路组赛事要求为依托，针对赛场核心的串联电路网络、并联电路网络及串并联混合电路网络识别与遍历任务，面向场景中二极管、三极管、电阻、运算放大器、电容等常见电子元器件的精准检测识别需求，设计并搭建了一套以英飞凌TC264芯片为主控核心的智能微缩小车完整软硬件控制系统。硬件平台搭载MINI视觉摄像头与高精度IMU惯性传感器，实现环境图像采集与车体姿态实时解算，搭配自主设计的直流有刷驱动电路与无刷驱动电路，为小车灵活运动提供可靠硬件支撑；同时整车在机械结构与硬件布局上采用全方位轻量化优化设计，有效降低车体惯量与整体负载，大幅提升小车的启动响应速度与机动灵活性。软件层面，基于嵌入式开发架构完成视觉识别算法开发，实现对电容、电阻、二极管、三极管等各类分立元器件的高精度、快速识别匹配，并结合串级PID运动控制算法完成小车速度与转向的精准闭环调控，保障小车以最优行进路径、最短行驶时间精准遍历赛场内所有元器件与电路网络。团队依托标准室内竞赛场地完成多轮调试与参数优化，有效解决室内光线干扰、元器件识别误判、小车行进抖动、轨迹偏移等赛场常见问题。整套系统兼具轻量化、高实时性与高稳定性的优势，能够以最轻车体重量、最快行驶速度高效完成疯狂电路组全部竞赛任务。

第一章 引言

随着智能嵌入式技术与机器视觉技术的飞速发展，微型智能车的自主识别、精准控制与智能遍历技术已成为全国大学生智能汽车竞赛的核心研究方向。疯狂电路组作为智能车竞赛的特色组别，区别于传统赛道循迹任务，重点考核小车对室内场景下各类分立元器件及串、并联、串并联混合电路网络的自主识别与精准遍历能力，对车体结构轻量化、视觉识别实时性、运动控制稳定性均提出了极高要求。针对赛事元器件种类繁杂、室内光照环境多变、小车高速行驶易产生轨迹偏移与姿态抖动等难点，传统单一控制算法与常规车体结构难以兼顾速度与精度的双重竞赛需求。

为此，本文以英飞凌TC264主控芯片为核心，搭建集成多传感器感知、双电机驱动的轻量化智能微缩小车软硬件平台，通过优化视觉识别算法与串级PID运动控制策略，解决元器件识别误判、车体运动不稳定等关键问题，实现小车高速、精准、稳定的赛场遍历作业，为智能电路检测与自主移动机器人的小型化、高性能设计提供了实践参考。

5.2.2 MT9V034 摄像头处理
采用图像二值化算法大津法:把图像像素分成两类：背景类、目标前景类，遍历所有可能灰度阈值，找到一个阈值，使得两类之间的方差（类间方差）最大。
把摄像头画面分成前景、背景，把目标物体和背景分割开，不需要手动设置阈值，算法自动算出最优分割阈值。
//输入灰度图像，返回最优二值阈值
int Otsu(unsigned char *gray_img, int width, int height)
{
    int hist[256]={0};
    //1.统计直方图
    for(int i=0;i<width*height;i++) hist[gray_img[i]]++;

    float w0,w1,u0,u1;
    float max_sigma=0;
    int best_thresh=0;
    //遍历全部候选阈值
    for(int T=0;T<256;T++)
    {
        //计算背景、前景权重、均值
        //……省略累加计算
        float sigma = w0*w1*(u0-u1)*(u0-u1);
        if(sigma>max_sigma){
            max_sigma=sigma;
            best_thresh=T;
        }
    }
    return best_thresh;
}
5.3 转向串级 PID 控制
外环输入：目标航向角与 IMU 实时 yaw 角度偏差；内环输入：外环输出量与车体实时角速度偏差；串级 PID 输出PWM 控制量，限制最大、最小打舵区间，直道、迷宫自动调整 PID 参数提升稳定性。
void PID_realize(float speed,float now_speed){			 //串级PID初始化
    pid.SetSpeed=speed;
    pid.ActualSpeed = now_speed;
    pid.err=pid.SetSpeed-pid.ActualSpeed;
    pid.integral=pid.integral+pid.err;
    pid.integral=Mconstrain_float(pid.integral, -pid.imax, pid.imax);
    pid.voltage=pid.Kp*pid.err+pid.Ki*pid.integral+pid.Kd*(pid.err-pid.err_last);
    pid.err_last=pid.err;
    pwm_duty(MOTOR1_A, pid.voltage);
    pwm_duty(MOTOR1_B,0);
}

第八章 结 论

本文完整阐述乐山师范学院乐师疯狂电路队伍针对第二十一届全国大学生智能汽车竞赛疯狂电路组所设计智能微缩小车的全套软硬件方案，系统设计严格遵循赛事官方场地标准与任务规范。硬件方面完成传感器布局规划，实现有刷、无刷电机全套驱动电路设计；软件层面实现电子元器件识别、目标元件遍历、串级 PID 运动控制等完整算法链路。
备赛阶段团队在室内竞赛场地开展大量实车调试，针对易错元器件识别、最短路径规划、速度阶梯优化等关键问题反复迭代，使整车能够稳定完成元器件识别与遍历任务。整套开发实践充分锻炼了团队在嵌入式硬件开发、机器视觉处理、自动控制算法等方面的综合工程实践能力，后续可基于英飞凌 TC4x 系列平台进一步拓展国赛人工智能创新相关功能。
