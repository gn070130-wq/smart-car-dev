第一章 引言
1.1 智能车研究背景
智能车是一种高新技术密集型的新型汽车，以汽车电子为背景涵盖控制、模式识别、传感技术、电子、电气、计算机、机械等多科学的科技创意性设计，一般主要由路径识别、速度采集、角度控制及车速控制等模块组成。可实现自动驾驶、自动变速及自动识别道路等功能，是现代电子产业发展中一项重要的组成部分。
在我国，教育部为了加强大学生实践、创新能力和团队合作精神的培养，委托教育部高等学校自动化专业教学指导分委员会主办了每年一度的全国大学生智能汽车竞赛。全国大学生智能汽车竞赛是在竞赛组委会提供的统一汽车模型平台上，使用英飞凌半导体公司的8位、16位、32位微控制器作为核心控制模块，通过设计道路识别传感器和电机驱动电路、编写相应软件及装配模型车，制作一个能够自主识别道路的模型汽车，按照规定路线（路线赛前已知）行进，以完成时间最短者为优胜。
1.2 方案总体介绍
比赛跑道为蓝色赛道背景，白色赛道线，白线宽为25mm。车模通过采集赛道图像进行路径检测。参赛队员的目标是使智能车按照自主规划最短路径以最短时间完成一圈赛道。
根据竞赛规则相关规定，本赛道智能车系统采用自制车模，以英飞凌公司生产的32位微控制器tc264作为核心控制器，在AURIX-Studio开发环境中进行软件开发。通过传感器将信号输入到推出tc264微控制器，进行进一步处理获得主要的赛道信息；通过编码器来检测车速，并通过单片机进行正交解码进行脉冲计算获得速度和路程；采用差速PD控制；驱动电机采用PI控制，通过PWM控制驱动电路调整电机的功率；而车速的目标值由默认值、运行安全方案和基于图像处理的优化策略进行综合控制。
1.3 本文结构
本文共分为六章。第一章主要是介绍了比赛的背景及智能车系统总体方案的介绍；第二章从智能车系统的机械结构出发，详细阐述了智能车系统各部分机械结构的安装和调整；第三章重点介绍了系统中所涉及的硬件设计方案和原理；第四章是介绍了智能系统的软件算法包括图像处理以及电机的控制策略；第五章对调试过程中的一些手段进行了讲解；第六章则是对智能车一些物理参数进行了简单的汇报。

2.2车模整体结构
2.2.1车模底盘方案的选择
	经过反复筛选，我们最终选择了四轮差速小车。如图2.1所示。

图2.1四轮缩微车模
四轮差速驱动模型结合了两轮差速的灵活控制与多轮驱动的优势，具有更强的负载能力、更高的牵引力以及更好的地形适应性。它通过四个轮子，它能更均匀地分散重量，同时通过差速控制实现灵活转向（包括原地旋转）。此外，四轮设计提升了系统冗余性，即使单轮故障仍可维持基本运动，增强可靠性。且控制算法和硬件较简单。成为我们小车在赛道环境下保持稳定性和强大动力的理想选择。
2.2.2电机的选择
疯狂电路赛道的特点是赛道紧凑，设有路肩，转弯频繁使得电机反复加速减速，在速度较快的情况下发热严重，因此车模需要有较高的扭力、稳定性和散热能力。我们选择了龙邱的030强磁电机，030 电机基于本届缩微赛题特别定制，采用稀土强磁，做到高速高扭、性能暴力，在有限的重量和体积的基础上，将电机性能发挥至极限。所以该电机在堵转电流、功率上普遍高于其他 030 电机，启动电压和启动电流较高，正常闭环调试不易发热。但是其缺点也明显：电机尺寸、重量偏大，大大提高了车摸的惯性。
2.2.3编码器的选择
我们选择的是普地1.2g超轻编码器，尽可能满足减重要求，在智能车中，编码器的主要功能是测量定时器中断周期内的脉冲数，用作速度控制回路中的实际反馈值。通过将此实际值与预设的目标值进行比较，并采用 PID 控制器来调整输出，从而实现精确的速度闭环控制。编码器发送脉冲信号，定时器引脚接收脉冲信号，通过脉冲信号的差异或者根据方向引脚电平判断是正值还是负值，脉冲信号值会在定时器中累计，直到手动清除，所以每次读取编码器值后需要清除累计值，才可以获得实时速度值。
2.2.4主板及电池安装
为了降低重心，在电池安装的时候，我们选择直接用魔术贴将电池固定在集成板中间，和车的底盘和电机质量关于车轴对称，并将大部分的器件集中在车底板上方，这样使得整个小车的重量集中在电机中间，有效的避免了小车的重心偏移。为了保证小车重心的不变，将主板安置在车底板上方，保证重心的稳定性。
2.2.5负压、电调及驱动板安装
车模的负压吸附，核心是通过径流式离心风机制造车底与外界的大气压强差，以此产生吸附力，让车模稳定贴合在立体赛道表面。这种新型负压方案摒弃了空气反推力的传统思路，转而通过高速旋转的离心风机，抽离小车底盘下方的空气，使其形成 “伪真空” 状态。此时小车底盘裙边塌陷，如同一个吸盘，借助大气压强的作用，将小车牢牢地按在赛道表面。风机如图2.2.

第三章 硬件设计
本系统的硬件电路采用集成一体板设计方式。主要包括单片机、电源模块、测速与驱动模块、传感器模块、人机交互模块、无刷驱动模块等部分。
3.1 单片机模块
本车模选用英飞凌AURIX TC264车规级单片机作为整车控制核心。该芯片采用TriCore架构，主频高达200MHz，配备硬件浮点运算单元，算力强、实时性高，能够满足疯狂电路组别高速、高动态的控制需求。TC264承担全车数据采集、算法运算与驱动控制工作。通过片上GPIO外设，实时读取编码器、姿态传感器数据，精准获取车辆行驶状态。依托高性能GTM定时器模块输出多路高精度PWM信号，实现对电机转速与舵机转向的精准调控。同时，芯片可高效运行PID调速、轨迹纠偏等核心控制算法，大幅减小高速行驶时的控制滞后，提升车辆过弯稳定性与直线竞速能力。该芯片具备优异的抗干扰性与运行稳定性，可适应赛场复杂电磁环境与频繁加减速的极限工况，保障系统全程稳定运行，为车模高速、精准、可靠行驶提供核心硬件支撑。
3.2 电源模块
	整个硬件系统的工作完全由电源供电的可靠性决定，电源供电的不稳定会引起电池损耗，单片机复位、电调及传感器损毁等严重问题，因此电源的设计是最重要的硬件电路设计部分之一。
3.2.1 电池

4.2.2 灰度图像二值化
	摄像头采集到的原始图像信息量大，无用信息也多，直接用mcu处理较为吃力，因此我们获取图像后首先进行二值化处理。
​​图像二值化的作用就是将复杂的灰度图像转化为只有黑白两色的简单图像，从而突出目标、去除干扰，为后续的图像分析、识别、检测等任务提供清晰、高效的输入。
赛道图像为蓝底白线，我们就将蓝底规定为远近，白线规定为近景。

我们刚开始使用固定阈值的方法，发现环境多变，无法稳定得到干净的二值化图像。于是我们用大津法二值化
大津法（Otsu's Method），也称为​​大津阈值法​​或​​最大类间方差法（Otsu’s Thresholding）​​，是一种用于图像处理中的​​自动确定二值化阈值​​的经典算法。它由日本学者大津展之（Nobuyuki Otsu）在1979年提出，广泛应用于灰度图像的二值化处理中。
一、基本思想
大津法的核心思想是：​​通过最大化类间方差（或最小化类内方差），自动找到一个最优的灰度阈值，将图像分为前景（目标）和背景两个部分​​。
在灰度图像中，每个像素的灰度值通常在 0（黑）~ 255（白）之间。大津法的目标就是找到一个合适的灰度阈值 T，将所有像素分成两类：
前景（目标）​​：灰度值 ≤ T 的像素
背景​​：灰度值 > T 的像素
然后计算这两类之间的​​类间方差（Inter-class Variance）​​，选择使这个方差最大的 T 值作为最佳阈值，从而实现较为理想的二值化效果。
二、算法原理（简要数学描述）
设图像的灰度级范围为 [0, L-1]，一般 L = 256（8位灰度图）。设：
ni​：灰度值为 i 的像素个数
N：总像素数，N=∑i=0L−1​ni​
pi​：灰度值为 i 的像素出现的概率，pi​=Nni​​
我们尝试选择一个阈值 ​​T​​（0 ≤ T ≤ L-1），将像素分为两类：
C0（背景类）​​：灰度值在 [0, T]
C1（前景类）​​：灰度值在 [T+1, L-1]
然后计算这两类的概率与均值：
C0 类的概率：ω0​(T)=∑i=0T​pi​
C1 类的概率：ω1​(T)=∑i=T+1L−1​pi​=1−ω0​(T)
C0 类的平均灰度：μ0​(T)=ω0​(T)∑i=0T​i⋅pi​​
C1 类的平均灰度：μ1​(T)=ω1​(T)∑i=T+1L−1​i⋅pi​​
图像的全局平均灰度为：μ=∑i=0L−1​i⋅pi​
大津法定义的​​类间方差（σ²）​​为：
σ2(T)=ω0​(T)⋅ω1​(T)⋅(μ0​(T)−μ1​(T))2=ω0​(T)⋅ω1​(T)⋅(μ0​(T)−μ)2（等价形式）
我们的目标是找到使 σ²(T) 最大的那个 T 值，即：
T∗=arg0≤T≤L−1max​σ2(T)
这个 T* 就是大津法求出的最佳阈值。

4.2.3 误差计算
	赛道信息经过初步处理后，将得到一张干净的二值化图像，图像用imageData[120][188]的数组储存(每个点表示为imageData[y][x]，其中y为纵坐标、x为横坐标)。
	误差计算我们用了两种方案，其中第一种利用图像边沿检查的方法从左到右，从下到上找出白线的边界，再用边界上的每个点在图像中的位置与图像中线（imageData[y][188/2]）的偏差经过加权平均的方法算出整体偏差。这种方法存在诸多问题，实际效果也不行。因此我们用另一种方法。
	这种方法的具体步骤如下：

	第一步：寻找白线的起始点

for (int8 y = imageWarp_H - 2; f0 == 0 && y > 30; y--)
		{
			for (int8 x = 0; x < 50; x++)
			{
				for (int8 d = 0; f0 == 0&&d < 13; d+=2)
				{
if (isRo(imageWarp_W / 2 - x, y - d) + isRo(imageWarp_W / 2 - x + 1, y  -d) + isRo(imageWarp_W / 2 - x, y - d + 1) + isRo(imageWarp_W / 2 - x + 1, y - d + 1) == 4)
					{

4.3控制部分
4.3.1 PID控制算法介绍
比例、积分、微分控制，简称 PID 控制。PID控制器问世至今已有近 70 年历史，其有着结构简单、稳定性好、工作可靠、调整方便等优点，现已成为工 业控制领域的主要技术之一。当被控对象的结构和参数不能完全掌握，或得不到精确的数学模型时，控制理 论的其它技术难以采用，系统控制器的结构和参数必须依靠经验和现场调试 来确定，此时应用 PID 控制技术是最为方便的。 PID 控制在实际中也有 PI 和 PD 控制。PID 控制器是一种线性的控制器，其根据给定值与实际输出值构成控制偏差。将偏差的比例(P)、积分(I)和微分(D) 通过线性组合构成控制量，对被控对象进行控制，故称为 PID 控制器，其原理框图如图 4.5所示。
    PID由比例（P）、积分（I）和微分（D）组成
图4.2 PID原理框架图
公式：

PID控制器是一种线性控制器，它根据给定值与实际输出值构成控制偏差。将偏差的比例(P)、积分(I)和微分(D)通过线性组合构成控制量，对被控对象进行控制，故称PID控制器，它的结构简单，参数易 于调整，是控制系统中经常采用的控制算法。
参数如下：
u(t)为控制器输出的控制量；
e(t)为偏差信号；
KP 为比例系数；
TI 为积分时间常数；
TD 为微分时间常数
（1）位置式PID

位置式PID 简单来说就是当前的位置值与你想要达到的位置值的偏差，进行PID控制。
优点:结构简单明了，P和I 作用分明。
缺点：个人认为他的最大缺点就是需要较大的误差累积，运算量大。
（2）增量式PID

增量式就是对于位置误差的增量进行处理，不需要误差累积。
优点:只需要目前的和上一次的偏差即可得出结果，不需要存储每一次的偏差，占内存空间小，切换冲击力小，计算机故障时，仍保持原值。
缺点：积分截断效应大，有稳态误差，溢出的影响大。增量式PID具有以下优点：
(1) 由于计算机输出增量,所以误动作时影响小,必要时可用逻辑判断的方法关掉。
(2) 手动/自动切换时冲击小,便于实现无扰动切换.此外,当计算机发生故障时,由于输出通道或执行装置具有信号的锁存作用,故能保持原值。
所以较容易通过加权处理而获得比较好的控制效果。
但增量式PID也有其不足之处：积分截断效应大,有静态误差；溢出的影响大.使用时,常选择带死区、积分分离等改进PID控制算法。

4.3.2 姿态传感器
只用编码器反馈的值进行PID计算并不能满足稳定运行的要求，我们还选用了LSM6DSRTR陀螺仪作为姿态传感器。LSM6DSRTR是一款九轴陀螺仪模块，支持SPI和IIC1通信。
经过我们测试，加上陀螺仪后能大大提高车模运行的稳定性，这在车模走直线的时候能很好提现：当只用编码器反馈的值进行PID计算时，直线运行总算会左右摇摆，加上陀螺仪后就几乎不会摇摆了。
另外，传感器尽可能地安装在小车车轮中线上，以便于获得准确的姿态数据。
4.3.3 PID控制算法在车模上的具体实现
为了保证车模能够准确且快速的响应，车模使用了串级PID差速控制。串级PID的核心思想就是将几个PID算法串起来使用，上一个PID计算的输出接到这一个PID的输入，最后一个PID的输出就是最终的输出值。
通常，我们喜欢把PID算法叫做闭环，因此我们也给不同物理量的PID闭环赋予了新的名字，比如对于速度的PID闭环，我们喜欢叫它速度环；对于方向的闭环，我们喜欢叫它方向环。其中速度环作为内环输出最终值控制电机，方向环作为外环输出内环目标值，具体控制思路如下图4.3。
图4.3：控制思路
外环方向环不同于位置式PID，为了使小车的控制更加的准确和迅速，车模使用了LSM6DSRTR作为姿态传感器，同时我们将方向环中的积分项也就是I项替换成了陀螺仪的Z轴角速度，同时新增了一个比例项（P），形成了双P双D控制。
具体控制方程如下：
PidAngle.voltage=PidAngle.Kp*PidAngle.err
+ PidAngle. Kp2*PidAngle. err*fabs(PidAngle.err)
+ PidAngle.Kd*(PidAngle.err-PidAngle.err_last)
+ PidAngle.GKd*Gyro_yaw//陀螺仪项
经测试相较于经典位置式PID，小车的行驶更加稳定。

第七章 结论
我们队伍基于英飞凌TC264单片机平台，成功开发了一套智能车系统。系统采用四轮差速驱动结构，通过的负压技术增强抓地力，结合3D打印支架优化了空间布局和重量分布。
