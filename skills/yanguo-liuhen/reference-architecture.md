# 系统架构模式（雁过留痕专科）

## 硬件分层（共识）

```
锂电池(约3S)
  ├─ DC-DC → 5V → LDO 3.3V → MCU / IMU / 屏 / 逻辑
  ├─ 独立稳压 → 舵机(约7.4V)
  ├─ 电池直供 → 有刷 H 桥(DRV8701 + MOS) → 左右电机
  └─ 电池直供 → 无刷电调 → 涵道/负压风扇
摄像头 MT9V034 并行/驱动库 → MCU
编码器×2 → 定时器捕获
激光×N → MOS/三极管开关 ← GPIO（默认关）
```

典型自制板：主板 / 驱动板 / 电调板 / 激光扩展板（锦城、深圳、芜湖等）；或主驱一体 + 激光板（杭州猛攻队）。

## 软件架构：前后台

几乎所有精读报告采用：

| 通道 | 典型内容 | 周期示例 |
|------|----------|----------|
| 主循环 | 等 `mt9v03x_finish_flag` → 搜线 → 元素 → 跟踪 → UI | 跟帧率 50–200 fps，常用 100 |
| PIT 舵机/控制 | 转向计算或写 PWM | 2–5 ms |
| PIT 编码器/电机 | 读速、增量 PID、差速目标 | 5–10 ms |
| PIT IMU | 陀螺采样 | 5 ms |
| PIT 激光关断 | 脉冲超时关激光 | 3 ms |
| PIT 按键/蜂鸣 | 人机与停车计时 | 50–100 ms |

**锦城·我竟无言以队** 主循环骨架（摘要）：

```c
while (1) {
  if (mt9v03x_finish_flag) {
    search_start_point();
    mt9v03x_finish_flag = 0;
    element_start();
    element_ring();          // 靶环
    switch (element.index) { // 十字/环/坡/障/斑马
      case index_cross: element_cross(); break;
      /* ... */
    }
    track();                 // 纯跟踪 + 舵机
  }
}
```

**芜湖·难知如阴队**：单帧链  
`Process_Image → Get_Information(迷宫) → Get_Border → Get_Middle_Line → Deviation → 双PD舵机 + PI差速电机`。

**深圳·开山老组**：显式「感知—路径—执行」三层；路径层纯追踪 + 目标速度决策；执行层舵机 PWM + 增量速度 PID。

## 模块边界（推荐工程切分）

| 模块 | 职责 | 禁止越界 |
|------|------|----------|
| `image` / `camera` | 采集、阈值、边线、中线、特征角点 | 不直接写电机占空比 |
| `element` | 状态机、锁定 index、里程退出 | 不直接开激光（只给任务有效标志） |
| `track` / `servo` | 偏差或纯跟踪 → 舵机 PWM | 不管激光互锁细节 |
| `motor` / `speed` | 目标速、差速、增量 PID | 出界时接受强制清零 |
| `laser` | 全关优先、单路选通、限时 | 不自行做图像决策 |
| `ui` / `iap` | 菜单、参数掉电保存 | |

浙江工院·明天一定队把该分层写得很清楚：视觉只出偏差/状态/任务有效标志；激光只接收稳定性检查后的目标。

## 主控与工具链

- MCU：STC32G144K 系列（竞赛限定 STC）
- IDE：Keil C251 / 逐飞库 `zf_common_headfile.h` 等
- 调试：IPS/TFT 叠加灰度+边线；按键菜单；IAP 存速度/帧率/舵机中值

## 机械对控制的隐含约束

报告反复强调、写代码前应核对：

- 主销后倾 / 内倾 / 前束 → 回正与直线稳定
- 摄像头高度与俯仰 → 前瞻距离与元素可见性
- 重心前后与高低 → 入弯侧滑、制动点头
- 舵机立式 vs 卧式 → 响应与阿克曼近似
- 涵道位置与底板密封 → 有效下压力

控制参数「漂移」时先查机械松动（编码器咬合、舵机虚位、板子复位），再改 PID。
