摘　　要
本文介绍了第二十一届全国大学生智能汽车竞赛雁过留痕组智能车的设计与实现。车模基于竞赛统一车模平台，以 STC32G144K246 单片机为核心，采用总钻风 MT9V034 摄像头、LSM6DSRTR 惯性测量单元与光电编码器进行环境感知，通过负压风扇系统增强轮胎抓地力，采用视觉循迹、闭环运动控制与参数在线微调等算法实现高速稳定循迹。系统实现了赛道循迹与复杂元素通过等功能。在机械结构上，对负压系统与电路板安装进行了针对性改造；在硬件上，自主设计了主板与电机驱动电路；在软件上，采用机器视觉主导的流线型架构，实现了图像处理、运动控制与任务调度。经赛道实测，车模运行稳定，效果良好。
关键词：智能汽车；STC32G；机器视觉；负压吸附；闭环控制

Abstract
This report introduces the design and implementation of the intelligent car of the Yanguoliuhen team in the 21st National University Students Intelligent Car Competition. Based on the unified competition car platform, the system takes the STC32G144K246 MCU as the control core, uses the Zongzuanfeng MT9V034 camera, the LSM6DSRTR IMU and photoelectric encoders for environment sensing, enhances tire grip through a vacuum fan system, and adopts visual tracking, closed-loop motion control and online parameter tuning to achieve high-speed stable tracking. Track tests show that the car can pass straight lanes, curves, crossroads and roundabouts stably.
Keywords: intelligent car; STC32G; machine vision; vacuum adsorption; closed-loop control
第一章 引言
1.1 赛题介绍
全国大学生智能汽车竞赛是面向全国大学生的探索性工程实践活动，以"立足培养、重在参与、鼓励探索、追求卓越"为指导思想，要求参赛队伍在统一车模平台上，综合运用自动控制、模式识别、传感器技术、电子电气、计算机与机械设计等多学科知识，自主设计制作能够沿赛道自主循迹行驶的智能模型车。本队"雁过留痕组"参加第二十一届全国大学生智能汽车竞赛竞速类赛题，任务是在规定的赛道环境下实现智能车的高速稳定循迹，自主通过直道、弯道、十字、环岛等赛道元素，并在保证可靠性的前提下尽可能提高行驶速度。
1.2 技术方案概述
本系统以 STC32G144K246 单片机为核心，通过总钻风 MT9V034 摄像头、LSM6DSRTR 惯性测量单元与光电编码器采集赛道与车辆状态信息，采用"机器视觉主导、图像帧触发控制"的流线型软件架构，通过视觉循迹、闭环运动控制与参数在线微调等算法实现车模的自主行驶。系统主要由机械结构、硬件电路和软件算法三部分组成，其总体设计围绕三条主线展开：
（1）以机器视觉为主导的感知方案。选用总钻风 MT9V034 全局快门摄像头作为主传感器，以 140° 广角视野获取前瞻赛道信息，将图像采集完成信号作为系统最高优先级的任务触发源，构建"感知—决策—执行"强实时流水线。
（2）以负压吸附增强抓地力的机械方案。在车体中部集成由 RS2205 三相无刷电机驱动的负压风扇系统，在车底形成负压区域，增强轮胎抓地力，为高速过弯提供更大的侧向附着极限。
（3）以闭环控制与参数自适应为核心的软件方案。底层采用速度闭环与转向闭环控制，配合里程积分机制，实现全赛道工况下的自适应驾驶。

2.2 转向系统
前轮转向采用 BDS300 数字舵机，沿用原车模转向机构。舵机内置硬件位置控制器，接收主控输出的绝对脉宽指令实现转角定位，其机械中立点标定为特定的基准占空比数值，控制算法的输出实质上是对该基准值的正负偏置，PWM 刷新频率设定为 300Hz，保证转向响应的实时性。
2.3 驱动系统布局
车模采用后驱方案，驱动电机为原装 RS380 有刷直流电机，经 DRV8701+TPH1R403NL 有刷驱动电路供电，通过后轮差速机构输出动力。为增强高速过弯时的轮胎抓地力，本队在车体中部加装了负压风扇系统：自制碳纤维板用于固定 RS2205 三相无刷电机，电机带动 T-MOTOR 5146 负压扇叶高速旋转，在车底形成负压区域。碳板结构刚度高、重量轻，有效降低了负压系统的安装重心，同时便于调整风扇与地面的间隙，实现吸附力与气流阻力的平衡。除车模原有的驱动电机（RS380）与转向舵机（BDS300）之外，本车额外配置的伺服电机为负压风扇电机 1 个（RS2205 三相无刷电机）。全车轮胎选用硅胶胎，其在赛道表面具有较高的摩擦系数，配合负压吸附可显著提升侧向附着极限。
2.4 传感器安装方案
2.4.1 摄像头安装
主传感器采用总钻风 MT9V034 摄像头模组，140° 广角、不带 MCU，图像数据由主控直接采集处理。摄像头安装于车头支架，前倾角度保证足够的前瞻距离；全局快门特性避免了高速行驶时的图像拖影问题。
2.4.2 IMU 安装

3.3 电源管理模块
系统采用电池供电，电源经稳压与滤波后为各模块提供工作电压：主控与传感器模块采用低压供电，电机驱动与负压风扇等动力回路直接由动力电源供电，信号回路与动力回路分开布局，关键控制信号就近设置滤波电容，保障高速运行与负压风扇大电流工况下的系统稳定性。滤波电容以 MLCC 陶瓷电容为主，需要注意的是，MLCC 在直流偏压下实际容量会明显减小，其有效容量可按经验公式估算：
	Ceff = C0 / (1 + k·Vdc)	(1)
其中 C0 为标称容量，Vdc 为直流偏压，k 为与介质材料相关的衰减系数（X5R 材料典型值约 0.2/V，X7R 较小）。为此本车在滤波电容选型时预留了充足裕量，全车电容标称总容量为 8500 μF，确保偏压衰减后仍满足各模块供电纹波要求。电路功耗与储能参数如表 3-1 所示：

第四章 软件算法设计
4.1 系统软件架构
本项目智能车的微处理器控制软件基于单片机裸机开发，采用前后台结合中断调度的流线型架构，摒弃了传统的"定时器强制中断分配控制周期"模式。系统高度以机器视觉为主导，将图像采集完成信号作为系统最高优先级的任务触发源，形成强实时性的"感知—决策—执行"流水线。
软件主要由四个模块构成：
（1）硬件及状态机初始化模块：负责提升系统主频以保障图像算力，完成脉宽调制发生器、摄像头接口、板载屏幕等外设的配置，并对所有全局状态机（如环岛状态、出界计数、任务里程等）进行清零复位，保障系统初始状态的纯净。
（2）视觉感知流水线：涵盖图像缓存、参考点定位、边缘提取、特征点检测（如十字、环岛）以及赛道中线拟合。
（3）里程推算与决策模块：通过环形缓冲机制收集历史编码器脉冲，换算为实际物理位移增量，依据实时里程和视觉特征动态规划当前目标速度。
（4）多维度闭环控制模块：底层封装了速度环与转向环的闭环运算引擎，负责计算最终的执行机构驱动量。
在主循环中，系统进入空闲轮询状态，唯一的阻塞条件是摄像头硬件直接内存存取（DMA）的传输完成标志。当一帧图像传输完毕，硬件中断置位标志；主循环检测到标志后立即重置该标志并切入核心图像处理流水线，依次执行出界检测、边缘扫线及特征识别，拟合出中心线并计算当前的横向几何偏差；随后决策模块利用该几何偏差及前瞻特征更新目标速度；最后控制核心函数提取编码器反馈数据，执行闭环运算，将所得驱动增量直接写入底层定时器寄存器。单次控制流水线在两帧图像极短的时间间隙内无缝衔接，实现了环境感知与物理控制的同步。整个软件的模块划分与调用关系如图 4-1 所示：

4.2 赛道信息采集与处理
4.2.1 图像采集
摄像头采用总钻风 MT9V034 模组，输出图像经硬件 DMA 直接搬运至主控内存，降低采集过程中的 CPU 负担。图像采集完成信号作为系统最高优先级的任务触发源，保证每一帧图像都能被及时处理。
4.2.2 图像处理
图像处理流水线依次执行：出界检测——判断车辆是否严重脱离赛道；边缘扫线——从图像参考中心出发沿赛道边界搜索；特征点检测——识别十字、环岛等赛道元素；赛道中线拟合——由左右边界合成中心线并计算横向几何偏差。若因视距受限导致有效赛道行数过少，代码强制触发重新定位图像中心的逻辑，确保偏差数据的可靠性。
4.3 路径规划与导航算法
4.3.1 中线偏差提取
系统以赛道中线为参考路径，在每个图像处理周期计算车辆相对中心线的横向几何偏差 e(k)，该偏差直接作为转向闭环的输入量，实现"所见即所控"的循迹策略。
4.3.2 里程推算与空间定位
在每一次控制周期开始时，系统不仅读取当前瞬时车速，还遍历专用的里程缓存数组，通过对历史脉冲求和并乘以物理缩放系数，积分推算出真实的物理位移增量。该位移增量贯穿整个控制逻辑，既参与环岛等复杂赛道特征的生命周期管理，也用于精准触发打靶等附加任务动作。
4.4 速度控制策略
驱动电机采用闭环调速方案：以光电编码器的脉冲计数作为实际速度反馈，与目标速度比较得到误差后，经增量式 PID 运算得到占空比增量，叠加到上一周期输出并限幅后下发至电机驱动。增量式控制只依赖最近若干周期的误差信息，天然具备抗积分饱和特性，配合输出限幅保护，能够保证速度环平稳收敛；过弯时再按转向角对左右轮目标速度进行差速分配，使内外侧车轮协调一致，提升弯道平顺性。
4.5 转向控制算法
前轮转向采用位置式闭环：以图像提取的赛道中线横向偏差作为反馈，经比例、微分运算得到舵机控制量；同时引入陀螺仪测量的车身横摆角速度作为阻尼项，抑制高速过弯时的车身摆动。为进一步适应不同曲率与车速的工况，系统根据偏差及其变化率对控制增益进行在线自适应微调——偏差大时增益提高、响应果断，偏差小时增益回落、转向柔和，从而兼顾直道平稳与弯道敏锐。
4.6 视觉与运动控制的融合
本项目中，视觉信息超越了基础的前馈输入范畴，深刻介入到底层的运动决策与安全机制中，两者高度耦合：
（1）视觉决定物理制动时机：视觉处理得到的不仅是单一的几何偏差，更包含丰富的纵深视距信息。当视觉感知前瞻距离缩短（如图像上方丢失大量赛道边界）时，即使未识别出具体的赛道元素，"视距受阻"的信息也会被传递至速度决策模块，迫使期望速度骤降，引导底层电机由驱动模式迅速切换至电磁制动状态。
（2）状态机主导闭环行为：特定视觉特征（如环岛）被识别后，将触发独立的状态机处理流，不仅改变常规的转向偏差计算基准（如强制施加偏差偏置以执行切圆动作），更通过里程积分机制严格监控车辆在该状态下的行驶距离；只有当行驶里程达到预设阈值或视觉特征彻底解除时，控制权才会交还给常规巡航闭环逻辑。这使得底层执行机构犹如具备了全局"驾驶思维"，能够依据宏观赛道形态主动突破常规物理极限。

5.2 硬件调试过程
硬件调试遵循"先电源、后信号，先单元、后整机"的原则：首先检查各电路板供电电压与极性，确认主控最小系统正常上电运行；随后分别测试有刷电机驱动与无刷电调的 PWM 输出及电机转向，确认驱动电路与主控引脚映射正确；再逐个验证摄像头、IMU、编码器与激光头的信号输出，通过逐飞助手与串口确认各传感器数据读取正常；最后进行整车电气联调，排查信号线与动力线间的电磁干扰问题。
5.3 软件调试方法
系统软件采用"模块测试、分系统联调、整车调试"相结合的方法进行调试。首先对摄像头、IMU、编码器、电机等硬件驱动模块进行单独测试，确认各传感器数据读取正常、电机转向正确、串口通信稳定；在算法调试阶段，通过串口将运行数据发送至上位机，利用 VOFA+ 观察速度误差、PID 输出等曲线，为参数调整和故障定位提供依据。速度控制调试时，先将驱动轮架空，在较低目标速度下确认编码器反馈方向正确，再逐步调整比例、积分和微分系数，使电机转速快速跟随目标速度且无明显超调；转向控制调试时，首先标定舵机机械中位，再在低速条件下调整转向环参数，减小转向超调与机械抖动；视觉调试通过逐飞助手叠加显示拟合中线与边界点，分别在不同光照条件下检查二值化阈值与边缘扫线结果。完成各模块测试后进行整车联调，始终采用低速起步、逐步提速的方式，出现异常立即停止电机输出，根据上位机记录的数据判断故障来源。

5.5 调试总结
整车的制作与调试遵循"先单元、后整车，先低速、后高速"的原则：首先完成车模机械改造与电路板焊接测试，分别调试电机速度闭环与舵机转向闭环，借助 VOFA+ 波形确定 PID 参数初值；随后在低速下联调视觉循迹，通过逐飞助手修正摄像头曝光与二值化参数；最后逐步提高车速，针对高速工况进行转向阻尼与速度环参数整定，并通过反复试车优化负压风扇转速与前瞻距离等整车参数，直至车辆在测试赛道上稳定完成全部赛道元素。
第六章 总结与展望
6.1 工作总结
本文设计并实现了一辆竞速组智能车，完成了比赛任务。整车以 STC32G144K246 单片机为控制核心，以总钻风 MT9V034 摄像头为主导传感器，融合 LSM6DSRTR 惯性测量单元与光电编码器反馈，采用负压风扇增强抓地力的机械方案，实现了高速稳定循迹。在软件层面，系统以"机器视觉为主导、图像帧触发控制"的流线型架构组织代码，落地了速度闭环、转向闭环与参数在线微调等一系列控制算法，并通过 VS Code、Keil、VOFA+、逐飞助手四款工具完成了开发、制作、安装与调试的全流程。经赛道实测，车辆能够稳定通过直道、弯道、十字与环岛等赛道元素，运行稳定，效果良好。
6.2 存在的问题与改进方向
目前系统仍存在可改进之处：一是视觉算法的环境适应性可进一步提升，复杂光照条件下的图像阈值策略仍需细化；二是控制参数依赖人工整定经验，后续可探索在线自整定方法；三是可进一步探索更高帧率的图像采集与更精细的路径规划算法，挖掘高速性能潜力。

附录 B 核心算法源代码
本附录给出赛道图像处理中灰度差比和边界提取算法的核心实现节选，其余算法代码从略。
/**
  * @file       Image_Process.c
  * @brief      赛道图像处理核心算法（节选）
  * @details    灰度差比和算法：对行内左右对称邻域做加权灰度差分并累加，
  *             以差分和最大的位置作为赛道边线，实现边界的快速提取。
  */
#include "Image_Process.h"

#define DIFF_POINTS 3            /* 邻域采样点数 */

/**
 * @brief   灰度差比和寻边
 * @param   row       当前处理的行号
 * @param   col_start 搜索起始列
 * @param   col_end   搜索终止列
 * @param   dir       搜索方向（+1 向右 / -1 向左）
 * @return  该行灰度跳变最剧烈的列位置（边线列）
 */
int16 GrayDiffSum(uint8 row, int16 col_start, int16 col_end, int8 dir)
{
    int16 col;
    int16 best_col = col_start;
    int32 max_sum = -32768;

    for (col = col_start; col != col_end; col += dir)
    {
        int32 sum = 0;
        uint8 i;

        /* 左右对称邻域加权差分：离中心越近权重越大 */
        for (i = 1; i <= DIFF_POINTS; i++)
        {
            sum += (int32)((int32)image[row][col - dir * i] -
                           (int32)image[row][col + dir * i]) * (DIFF_POINTS + 1 - i);
        }

        /* 记录差分和最大的位置 */
        if (sum > max_sum)
        {
            max_sum = sum;
            best_col = col;
        }
    }

    return best_col;
}

/**
 * @brief   赛道左右边线提取
 * @details 从图像中间列分别向左右两侧搜索，得到各行的左右边线位置。
 */
void TrackEdgeExtract(void)
{
    uint8 row;

    for (row = 0; row < IMAGE_H; row++)
    {
        left_edge[row]  = GrayDiffSum(row, image_center, 0, -1);
        right_edge[row] = GrayDiffSum(row, image_center, IMAGE_W - 1, 1);
    }
}
