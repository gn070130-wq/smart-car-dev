摘  要
本文以第二十一届全国大学生智能汽车竞赛为背景，介绍了开山老组参赛智能车的系统设计与实现。模型车以STC32G144K单片机为控制核心，采用MT9V034灰度摄像头进行赛道感知，结合逆透视变换、边线提取和纯追踪算法实现路径跟踪；通过增量式PID与斜坡限幅实现速度闭环；利用状态机完成十字、圆环、斑马线制动停车和避障等赛道元素识别，并实现打靶激光发射、延时发车与冲出赛道安全保护。硬件方面设计并实现了主板、双路有刷驱动板和无刷电调三块电路板，其中主板与驱动板为四层板，无刷电调为六层板。经整车联调，系统能够稳定完成竞赛规定的主要任务，直道目标速度达到3.0 m/s。
关键词：智能汽车；STC32G144K；图像处理；纯追踪；PID控制；元素识别

第一章  引言
1.1  竞赛背景与任务分析
全国大学生智能汽车竞赛以“立足培养、重在参与、鼓励探索、追求卓越”为宗旨，要求参赛队伍在规定时间内完成模型车的机械、电路与软件设计，并在指定赛道上完成竞速和任务动作。第二十一届全国大学生智能汽车竞赛在基础竞速之外，还设置了十字、左右圆环、斑马线制动停车、打靶、延时发车、避障等赛道元素和比赛任务，对模型车的图像识别稳定性、路径跟踪精度、速度控制能力以及多任务协同可靠性提出了较高要求。
本队以“稳定通过所有元素、兼顾直道速度、任务动作可靠”为设计目标，采用灰度摄像头作为主要环境感知手段，以STC32G144K单片机作为控制核心，结合纯追踪路径跟踪、增量式速度PID、状态机元素识别和逆透视变换，完成了可复现、可调试、可迭代的智能车系统。
1.2  相关技术综述
智能车视觉导航通常包括图像预处理、赛道边线提取、中线生成和路径跟踪几个环节。针对赛道灰度图像，常用局部动态阈值方法克服光照不均和阴影影响；边线提取可采用逐行搜索或方向跟踪，方向跟踪在弯道和元素处具有更好的连续性。
路径跟踪方面，纯追踪算法以车前固定距离处的前视点为期望点，根据车体几何关系计算期望转向角，具有算法简单、参数直观、弯道适应性好的特点。速度控制方面，增量式PID配合斜坡限幅和目标速度决策，可以在直道高速、弯道减速与元素低速之间平稳过渡。元素识别方面，以边线点数、角点特征和左右线差异作为判据，配合状态机可以稳定完成十字、圆环、斑马线、避障等任务。
本报告所涉及的开源软件库、摄像头传感器和驱动芯片资料见参考文献。

2.3  控制方案概述
控制方案分为“感知—路径—执行”三层：感知层完成图像二值化、边线提取、逆透视变换和元素识别；路径层以纯追踪算法生成期望转向角，并根据转向量、赛道元素给出目标速度；执行层由舵机PWM和速度PID驱动。主循环完成图像处理与任务调度，定时器中断分别完成系统时钟、舵机刷新、编码器采样和速度PID计算，保证控制周期稳定。
 
第三章  机械结构设计与安装
3.1  车模平台与改造思路
车模选用竞赛指定模型车平台，在保留原有车架、转向机构和驱动轮系的基础上，拆除原车控制电路，重新设计安装主控电路板、驱动电路板、无刷电调、摄像头、惯性测量单元和激光阵列。改造中遵循“降低重心、提高刚度、减轻簧上质量、便于拆装维护”的原则，并对传感器支架和电路板安装位置进行了预留。
3.2  传感器安装设计
摄像头安装在车体前部支架上，镜头保持水平并略向下俯视，使近处赛道位于图像底部、远处赛道位于图像顶部；安装角度与逆透视标定工况保持一致，以保证鸟瞰坐标换算准确。摄像头通过2×8P接口连接主板，图像数据经AL422B缓存后由DMA读取。
左右轮编码器与驱动轮轴通过联轴器连接，正交信号分别接入主控PWM编码器通道；IMU660RB固定在车体中部且接近车架中心，以减小振动和离心力对测量带来的影响；7路激光按左右方向排列安装在车头前部，与摄像头鸟瞰图像中的横向位置相对应，激光选择与打靶识别使用同一套坐标映射关系。主要传感器安装位置如表3-1所示。

主板布置在车体上层主安装板上，驱动板布置在靠近驱动电机的位置以缩短大电流走线，无刷电调与无刷电机就近安装。电路板之间采用XT30/XT60接口线连接，利用其防反接和锁紧特性保证功率连接可靠；信号线通过接插件连接，线束沿车架走线槽整理并固定，避免运动过程中摩擦和松脱。功率线与信号线分开走线，减小电机电流对图像和控制信号的影响。

第五章  软件设计
5.1  软件总体结构
软件基于逐飞STC32G144K开源库开发，采用“主循环 + 定时器中断”的结构。主循环负责按键、姿态解算、图像处理、元素识别、路径跟踪、打靶和速度决策；定时器中断分别完成系统时钟、舵机PWM刷新、编码器采样和速度PID计算。主程序流程如图5.1所示，中断任务分配如表5-1所示。

5.2  图像采集与预处理
MT9V034输出188×120灰度图像，帧率默认配置为100fps。图像通过VSYNC和DMA中断完成采集，主循环使用image_copy图像备份数组，在发送和调试时避免图像撕裂。预处理采用5×5局部窗口平均得到局部阈值，再减去去噪系数cap，实现随光照自适应变化的二值化；左右边线在起点搜索时使用独立动态阈值LThreshold、RThreshold，并依据边线追踪结果逐步更新全局threshold。
5.3  边线提取与中线拟合
边线提取从图像近端开始搜索左右边线起点，随后采用方向跟踪算法逐点延伸边线。算法使用四个主方向与四个对角方向，根据局部灰度跳变决定前进方向，并设置局部阈值刷新和方向回溯，能够适应弯道、缺线和元素区域。提取完成后将原始图像坐标通过reflection查表映射到鸟瞰坐标，再按当前贴边方向（左线或右线）向赛道内侧法向偏移centerLineDistance生成中心线。中心线经一阶滤波、等距重采样和角点截断后供路径跟踪使用。
5.4  路径跟踪控制
路径跟踪采用纯追踪算法。取中心线AIM_POS处前视点，根据车体前方距离DEVICE_H计算转向角：
	θ = atan2(2·DEVICE_H·dy, dx² + dy²)	公式1
其中dx、dy为前视点相对车体坐标的纵向与横向距离。转向角乘以PURE_PURSUIT_GAIN后叠加陀螺仪偏航角速度阻尼，得到舵机PWM值，并限制在舵机左、右极限之间。舵机PWM由5ms定时器中断持续刷新。在纯追踪基础上，本系统加入阿克曼转向几何限速与差速计算。根据转向角d查正切表得到tan(d)，按轴距L=PP_AXLE_CM计算转弯半径r=L/tan(d)，再以向心加速度预算PP_A_MAX得到弯道限制车速，并将其限制在PP_MIN_SPEED与PP_MAX_SPEED之间；同时按半轮距计算左右轮差速，差速pp_diff送入速度PID，与左右轮基础占空比叠加，实现转向时内外轮转速差。
	r = L / tan(d)	公式2
	v = sqrt(PP_A_MAX × r)	公式3
	Δv = v × PP_HALF_TRACK_CM / r	公式4
本版本阿克曼参数取PP_AXLE_CM=20 cm、PP_HALF_TRACK_CM=6 cm、PP_A_MAX=6 m/s²、PP_MAX_SPEED=2.5 m/s、PP_MIN_SPEED=0.8 m/s。
5.5  速度闭环控制
速度环采用左右轮独立增量式PID。编码器每5ms采样一次，速度经一阶低通滤波后与目标速度比较，PID输出与基础占空比叠加得到左右电机PWM。为防止输出突变，目标速度通过斜坡逐步逼近：加速时每周期增加0.025 m/s，减速时每周期减小0.02 m/s。速度决策按转向量和赛道元素给出目标速度上限，具体规则如表5-2所示；实际执行时再经阿克曼限速约束。

5.6  赛道元素识别
十字识别采用两态状态机。进入十字区域后，左右边线点数明显减少，系统禁止阈值更新，从远端重新跟踪边线并合成远端正中线，使车辆沿合成中线稳定直行通过十字。
圆环识别采用READY、START、IN、END、EXIT五态状态机，如图5.2所示。系统通过边线缺口、边线点数恢复和角点特征判断进环、环内绕行和出环时机；进环前保持正常巡线，进环后切换贴边方向，出环后恢复主赛道巡线，并复位状态机。发车后延时500ms再开启圆环识别，避免发车区图像干扰。

图5.2  圆环识别五态状态机
斑马线识别沿左边线扫描黑白交替的条带数量，在识别到圆环之后才允许触发。触发后设置制动标志，电机先反转制动300ms，再进入锁停状态，实现可靠停车。
5.7  打靶识别与激光发射
打靶识别根据车速和转向角动态选择扫描行，在左右边线之间搜索靶环边缘，并利用reflection表计算靶环的横向宽度dh和纵向高度dv，通过尺寸范围校验排除干扰目标。识别到靶心后，将靶心列坐标映射到7路激光中的一路：列坐标80~115对应激光0~6，发射后150ms内禁止再次发射，6ms后自动关断激光，避免误触发和连续发射。
5.8  避障与安全保护
避障逻辑通过比较车头附近路宽与前方最窄路宽判断是否存在障碍：当前方明显变窄时，根据左右边线位移判断障碍所在侧，将贴边方向切换到另一侧，并以缩小贴边距离的方式绕行；路宽恢复或超时后退出避障并复位十字、圆环状态机，避免误触发。
安全保护包括两项：冲出赛道保护在图像底部5个固定采样点同时低于灰度阈值时立即停车；斑马线停车采用反转制动后锁停。两种保护均具有锁存机制，重新发车按键会清除锁存标志。

附录A  算法推导与关键设计说明
A.1  纯追踪转向角推导
设前视点在车体坐标系中的纵向距离为dx、横向偏移为dy，前视距离取DEVICE_H。将车辆前方路径近似为圆弧，由前视点几何关系可得期望转向角：
	d = atan2(2·DEVICE_H·dy, dx² + dy²)	公式A-1
式中d为期望转向角，再乘以PURE_PURSUIT_GAIN转换为舵机PWM偏移，并叠加陀螺仪偏航角速度阻尼后输出给舵机。
A.2  阿克曼限速与差速推导
设轴距为L=PP_AXLE_CM、转向角为d，则车辆转弯半径为：
	r = L / tan(d)	公式A-2
为保证侧向加速度不超过PP_A_MAX，允许车速为：
	v = sqrt(PP_A_MAX × r)	公式A-3
车速在PP_MIN_SPEED与PP_MAX_SPEED之间限幅。设半轮距为B_half=PP_HALF_TRACK_CM，则转向时内外轮线速度差为：
	Δv = v × B_half / r	公式A-4
Δv经限幅后作为左右轮差速pp_diff输入速度PID，与左右轮基础占空比叠加。
A.3  增量式PID推导
设e(k)为当前速度误差，e(k-1)、e(k-2)为前两次速度误差，增量式PID输出增量为：
	Δu(k) = Kp·(e(k)-e(k-1)) + Ki·e(k) + Kd·(e(k)-2e(k-1)+e(k-2))	公式A-5
实际PWM占空比由基础值累加Δu得到，并对输出和积分量进行限幅，防止积分饱和。
A.4  逆透视映射与鸟瞰坐标推导
以地面标定点建立世界坐标(X,Y)与图像坐标(col,row)的对应关系，通过单应矩阵求解逆透视映射。设像素比例scale=半宽像素/实际半宽，鸟瞰坐标为：
	x = NEAR_X - X/scale          y = CENTER_Y + Y/scale	公式A-6
式中NEAR_X=119为鸟瞰近端行，CENTER_Y=94为鸟瞰横向中线。标定脚本生成reflection[120][188][2]查表，供边线和中心线变换直接使用。
A.5  打靶坐标映射推导
设靶心鸟瞰列坐标为Y，有效发射区间为Y_MIN~Y_MAX，对应激光编号为：
	k = (int)((Y - Y_MIN) × 7 / (Y_MAX - Y_MIN))	公式A-7
k限制在0~6，实现靶心位置到7路激光的选通映射。

B.1  纯追踪路径跟踪 alongLine
void alongLine(Point roadLine[], int16 count, int16 aimPos)
{
    int16 pos, dx, dy;
    int8 d;
 
    if (count <= 5)
    {
        pp_set_speed = PP_MAX_SPEED;
        pp_diff = 0;
        diff = 0;
        return;
    }
 
    pos = (int16)func_limit_ab(aimPos, 5, count - 2);
    dx = (int16)(MT9V03X_H - roadLine[pos].x + DEVICE_H);
    dy = (int16)(94 - roadLine[pos].y);
 
    d = (int8)func_limit_ab(atan2_int(2 * (int32)DEVICE_H * dy, (int32)dx * dx + (int32)dy * dy), -32, 32);
 
    /* steering with yaw-rate damping (gyro_z from IMU) to kill low-frequency weave */
    final_pwm = (int16)((float)STEER_MID + (float)d * PURE_PURSUIT_GAIN + PP_GYRO_DAMP * gyro_z);
    if (final_pwm < STEER_RIGHT) final_pwm = STEER_RIGHT;
    if (final_pwm > STEER_LEFT)  final_pwm = STEER_LEFT;
 
    /* speed + differential */
    pp_update_speed(d);
    diff = pp_diff;
}
B.2  阿克曼限速与差速计算 pp_update_speed
static void pp_update_speed(int8 d)
{
    uint8 ad = (uint8)func_limit_ab(func_abs((int32)d), 0, 32);
    int16 t = pp_tani[ad];
    int32 r_cm;
    int32 v100;
    int32 dv;
 
    if (t == 0)
    {
        pp_set_speed = PP_MAX_SPEED;
        pp_diff = 0;
        return;
    }
 
    r_cm = (int32)PP_AXLE_CM * 1000 / t;      /* turning radius in cm */
    if (r_cm < 5) r_cm = 5;
 
    /* v100 = speed * 100 (0.01 m/s) */
    v100 = sqrt_int((int32)PP_A_MAX * r_cm * 100);
    if (v100 > (int32)(PP_MAX_SPEED * 100.0f)) v100 = (int32)(PP_MAX_SPEED * 100.0f);
    if (v100 < (int32)(PP_MIN_SPEED * 100.0f)) v100 = (int32)(PP_MIN_SPEED * 100.0f);
    pp_set_speed = v100 / 100.0f;
 
    /* differential in 0.1 m/s units; positive when d>0 (left turn, right wheel faster) */
    dv = v100 * PP_HALF_TRACK_CM / r_cm / 10;
    if (d < 0) dv = -dv;
    pp_diff = (int8)func_limit_ab(dv, -PP_DIFF_MAX, PP_DIFF_MAX);
}
B.3  速度PID motor_speed_pid_calc
void motor_speed_pid_calc(float target_speed, float Left_motor_speed, float Right_motor_speed, int8 diff)
 
{
 
    float left_delta, right_delta;
 
    int16 base_left, base_right;
 
 
 
    motor_gyro_diff = diff;
 
 
 
    // 误差（单位 0.01m/s）
 
    left_speed_err  = (target_speed - Left_motor_speed)  * 100.0f;
 
    right_speed_err = (target_speed - Right_motor_speed) * 100.0f;
 
 
 
    // 增量式PID，全程float计算，不再用int8强转
 
    left_delta = pid_kp * (left_speed_err - left_speed_err_last)
 
               + pid_ki * left_speed_err
 
               + pid_kd * (left_speed_err - 2.0f*left_speed_err_last + left_speed_err_prev);
 
    right_delta = pid_kp * (right_speed_err - right_speed_err_last)
 
                + pid_ki * right_speed_err
 
                + pid_kd * (right_speed_err - 2.0f*right_speed_err_last + right_speed_err_prev);
 
 
 
    // 增量限幅
 
    if (left_delta  >  100.0f) left_delta  =  100.0f;
 
    if (left_delta  < -100.0f) left_delta  = -100.0f;
 
    if (right_delta >  100.0f) right_delta =  100.0f;
 
    if (right_delta < -100.0f) right_delta = -100.0f;
 
 
 
    // ===== 关键修复：增量累加，积分才真正存在 =====
 
    left_pid_out  += (int16)(left_delta  * (PWM_DUTY_MAX / 1000.0f));
 
    right_pid_out += (int16)(right_delta * (PWM_DUTY_MAX / 1000.0f));
 
		
 
		// 累加后立即限幅，防止int16溢出和积分饱和
 
		if (left_pid_out  >  MAX_DUTY*100) left_pid_out  =  MAX_DUTY*100;
 
		if (left_pid_out  < -MAX_DUTY*100) left_pid_out  = -MAX_DUTY*100;
 
		if (right_pid_out >  MAX_DUTY*100) right_pid_out =  MAX_DUTY*100;
 
		if (right_pid_out < -MAX_DUTY*100) right_pid_out = -MAX_DUTY*100;
 
 
 
    // 基础前馈：每周期用当前目标速度实时算，不再依赖TARGET_SPEED的赋值时机
 
    base_left  = (int16)((target_speed * 10.0f + FIX_COMP - motor_gyro_diff) * (PWM_DUTY_MAX / 100.0f));
 
    base_right = (int16)((target_speed * 10.0f - FIX_COMP + motor_gyro_diff) * (PWM_DUTY_MAX / 100.0f));
 
 
 
    // 输出 = 前馈(基础+差速) + 累加PID
 
    left_final_pwm  = base_left  + left_pid_out;
 
    right_final_pwm = base_right + right_pid_out;
 
 
 
    // 总限幅
 
    if (left_final_pwm  > MAX_DUTY * (PWM_DUTY_MAX / 100)) left_final_pwm  = MAX_DUTY * (PWM_DUTY_MAX / 100);
 
    if (left_final_pwm  < 0) left_final_pwm = 0;
 
    if (right_final_pwm > MAX_DUTY * (PWM_DUTY_MAX / 100)) right_final_pwm = MAX_DUTY * (PWM_DUTY_MAX / 100);
 
    if (right_final_pwm < 0) right_final_pwm = 0;
 
 
 
    // 更新历史误差
 
    left_speed_err_prev  = left_speed_err_last;
 
    right_speed_err_prev = right_speed_err_last;
 
    left_speed_err_last  = left_speed_err;
 
    right_speed_err_last = right_speed_err;
 
}
B.4  图像路径处理 loadRoad
void loadRoad(void) {
 
    Point LStart = getLStart(), RStart = getRStart();
 
    int16 i;
 
 
 
    LRoadCount = expRoadCount;
 
    RRoadCount = expRoadCount;
 
    getLBorder(LRoad, LStart, &LRoadCount, 0);
 
    getRBorder(RRoad, RStart, &RRoadCount, 0);
 
 
 
    LBorderCount = LRoadCount;
 
    memcpy(LBorder, LRoad, (uint16)LBorderCount * sizeof(Point));
 
    RBorderCount = RRoadCount;
 
    memcpy(RBorder, RRoad, (uint16)RBorderCount * sizeof(Point));
 
 
 
    getGodRoadLine(LRoad, LRoadCount);
 
    getGodRoadLine(RRoad, RRoadCount);
 
    filterRoad(LRoad, LRoadCount);
 
    filterRoad(RRoad, RRoadCount);
 
    resampleRoad(LRoad, &LRoadCount, 0, 3);
 
    resampleRoad(RRoad, &RRoadCount, 0, 3);
 
    LCorner = findCorner(LRoad, LRoadCount, 0);
 
    RCorner = findCorner(RRoad, RRoadCount, 0);
 
 
 
    /* truncate borders at their first corner so cross/round detection sees short lines */
 
    if (LCorner) {
 
        if (LCorner < 3) LCorner = 0;
 
        else LRoadCount = LCorner;
 
    }
 
    if (RCorner) {
 
        if (RCorner < 3) RCorner = 0;
 
        else RRoadCount = RCorner;
 
    }
 
 
 
    /* follow the configured side (ALONG) to synthesize the centerline */
 
    if (ALONG == ALONG_L) {
 
        getCenterLineByLBorder(LRoad, centerLine, LRoadCount);
 
        centerLineCount = LRoadCount;
 
    } else {
 
        getCenterLineByRBorder(RRoad, centerLine, RRoadCount);
 
        centerLineCount = RRoadCount;
 
    }
 
    ALONG = LRoadCount > RRoadCount ? ALONG_L : ALONG_R;
 
 
 
    /* extend the centerline down to the bottom image row for pure pursuit */
 
    for (i = 1; i < centerLineCount; i++)
 
        if (centerLine[i].x < (MT9V03X_H - 1)) { i--; break; }
 
    if (i < centerLineCount) {
 
        centerLine[i].x = MT9V03X_H - 1;
 
        centerLine[i].y = centerLine[i + 1].y;
 
    }
 
    filterRoad(centerLine, centerLineCount);
 
    resampleRoad(centerLine, &centerLineCount, i, 2);
 
}
B.5  斑马线识别 haveZebra
uint8 haveZebra(void) {
 
    int16 i = 0;
 
    if (!LBorderCount) return 0;
 
    while (i < LBorderCount && LBorder[i].x > ZEBRA_TRIGGER_POS)
 
        i += 3;
 
    if (i >= LBorderCount) return 0;
 
    if (LBorder[i].x > ZEBRA_TRIGGER_POS) return 0;
 
    return findZebra(i);
 
}
B.6  激光发射 laser_fire
void laser_fire(uint8 col)
{
	uint8 k;
	if (Nowtime < laser_ready_time) return;// 还没到冷却时间，直接不发射
	if (col <= 80 || col >= 115) return;// 靶心不在中间有效区（79~112），不发射//col <= 78 || col >= 113
	laser_ready_time = Nowtime + 150;///// 这次发射后，150ms 内禁止再发射
	laser_off_time = Nowtime + 6;//6ms 后自动关闭激光
	k = (uint8)((col - 80) * 7 / 27);// 把列坐标映射成 0~6（选第几个激光管）78-35
	if (k >= 7) k = 6;// 兜底，防止越界
	laser_dismiss();// 先关掉所有激光
	gpio_set_level(laser_pin[k], 1); // 只点亮第 k 个激光管
}
