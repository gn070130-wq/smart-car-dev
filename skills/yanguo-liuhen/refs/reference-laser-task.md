# 激光打靶任务模式

## 赛题要点（报告共识）

- 紫外激光在感光纸靶区留下可判紫色痕迹；区外尽量不留痕  
- 传感器侧通常**只允许摄像头**感知赛道与靶（无额外光电循迹）  
- 成绩含打靶罚时；故「稳命中 + 安全互锁」优先于盲目提速  

## 硬件方案对比

| 方案 | 代表 | 特点 |
|------|------|------|
| 固定多路阵列 | 锦城 9 路、浙江工院 8 路、重庆 9 路、芜湖 5 路 | 按角度选通，降低瞄准自由度要求 |
| 激光云台 | 湖南电气 | 舵机 ± 范围瞄准，需提前减速与云台 PD |

驱动：GPIO → 限流 → MOS/三极管 → 激光；上电下拉保证默认关。

## 软件安全状态机（强烈推荐）

浙江工院写得很完整，作为默认模板：

```
条件全满足才发射：
  任务有效 ∧ 车辆稳定 ∧ 通道合法 ∧ 当前全部激光已关闭
→ 选通唯一通道 → 启动限时计数
→ 超时 / 异常 / 停车 / 斑马线 → 立即全关
```

其它共识：

- **默认全关**；禁止多路同时常亮  
- **脉冲宽度** ms 级（锦城约 3 ms 定时器关断）  
- 出界、`stop_flag`、调试复位、ISP 下载期间保持关闭  
- 人眼安全：调试遮光/低功率，禁止对射眼睛（报告安全提示）

## 靶环视觉

1. 在左右边线之间 ROI 搜靶  
2. 方法举例（湖南电气）：  
   - 黑白跳变定左右/上下边界 → 中点  
   - 黑点坐标平均  
   - 最长白列/路宽异常辅助  
3. 锦城：`element_ring()` + `ring_maze_*` 搜靶边，拟合 `ring_x_middle/y_middle`，按相对方位点亮对应激光  

命中率技巧：靶区**提前降速**；云台方案加超前量；阵列方案保证支架标定与编号一致。

## 与运动控制的耦合

```
识别到靶 → 切 TARGET_SPEED / 低速
→ 姿态稳定（偏差与角速度阈值内）
→ laser 模块发射
→ 恢复循迹表速
```

不要在满速直道中段开长脉冲激光。

## 阅读锚点

`close_laser` / `element_ring` / `RING_SPEED` / `TARGET_SPEED` / `单路互锁` / `限时` / `AO3400`
