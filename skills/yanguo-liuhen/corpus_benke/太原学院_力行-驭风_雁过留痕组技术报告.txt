摘要
本文介绍太原学院“力行—驭风”队面向第二十一届全国大学生智能汽车竞赛雁过留痕组设计的智能车系统。车模采用博思威龙B型四轮舵机车模，以微控制器为核心完成环境信息采集、路径判断、转向控制、速度控制和激光执行。车头布置一排九路激光执行器，用于在目标区域形成规定的留痕效果；底盘采用前轮舵机转向、后轮电机驱动的基本结构，并结合电源管理、电机驱动、人机交互和安全保护模块完成整车系统集成。软件部分围绕赛道信息处理、目标区域判断、转向与速度闭环、九路激光时序控制以及障碍规避展开。本文同时记录车模机械安装、硬件组成和调试方法，为后续参数完善与车辆技术检查提供依据。

第一章 引言
全国大学生智能汽车竞赛以智能车为研究对象，强调学生在机械结构、嵌入式系统、传感检测、自动控制和工程调试等方面的综合实践能力。参赛队伍需要在规定硬件平台和竞赛规则约束下完成车模设计、软件编写、整车装调与现场比赛。雁过留痕组将传统循迹竞速任务与目标区域留痕任务结合，要求车模在稳定行驶的同时完成目标识别、激光执行和障碍规避，对系统实时性、机械可靠性和控制精度提出了较高要求。
采用博思威龙B型四轮舵机车模搭建参赛平台。整车以路径检测为基础，以转向舵机和驱动电机为主要执行机构，在车头横向布置九路激光阵列，以扩大目标覆盖范围并提高留痕任务的容错能力。设计过程中遵循结构紧凑、重心合理、走线清晰、调试方便和运行可靠的原则，通过机械、硬件与软件三部分协同优化，使车辆具备完成雁过留痕组任务的基本能力。
本报告采用技术报告常用的章节结构，车辆参数、组别任务、检测方式和控制方案均按本队车模重新组织。当前版本已经补入主控、供电、摄像头、舵机、编码器和激光器参数，电机驱动板型号及电路板信息区域留待后续补充。

第三章 机械结构的设计及调整
3.1 博思威龙C车模机械结构
本车采用博思威龙C型四轮舵机车模。底盘由车架、前后轮组、转向机构、驱动机构和安装平台组成，前轮通过舵机连杆完成转向，后轮承担主要驱动任务。在不影响原车模基本传动关系的前提下，车体上层用于布置控制板、显示模块和电源连接，车头区域用于安装路径检测装置与九路激光阵列。

图3.1  B车模实物图
3.2 整车重心及结构调整
四轮舵机车模的质量分布会直接影响加速、制动和弯道稳定性。整车布置时应尽量使电池、驱动板等质量较大的部件靠近底盘并位于车体纵向中心附近，避免左右质量差异造成直线跑偏。主控板和显示模块安装在便于观察与维护的位置，同时控制上层结构高度，减少高速转向时的侧倾趋势。
图 3.2 车模侧部照片
完成机械安装后，通过静态压轮检查四轮受力是否均匀，并在低速直线条件下观察车体偏移。若车辆在相同舵机中值下持续偏向一侧，应依次检查前轮前束、舵机连杆长度、轮胎状态和左右负载，而不应仅依靠软件补偿掩盖机械误差。
3.3 九路激光阵列的安装
九路激光执行器沿车头横向排成一列，并固定在黑色安装杆上。横向排布能够覆盖一定宽度的目标区域，减少车模横向位置误差对留痕结果的影响。安装时需要保证各激光单元高度和朝向一致，使光斑落点形成规则阵列；安装杆应具有足够刚度，避免车辆振动导致光斑明显漂移。
激光阵列与车体之间采用可拆卸连接，便于单个器件维护和整体角度标定。实际标定时可在固定高度放置测试纸，依次开启各通道，记录光斑位置、亮度和响应一致性，再通过调整安装角度或控制时间修正差异。激光装置调试时应采取遮挡和限时措施，避免光束直接照射人员眼睛。
3.4 转向舵机的安装与调整
舵机通过舵盘和转向拉杆带动前轮转向。安装后首先确定机械中位，使左右轮在舵机中值脉宽下基本保持直行；随后分别测量左右最大允许转角，在程序中设置输出限幅，避免舵机堵转或连杆与车架发生干涉。转向机构应尽量减小间隙，拉杆连接处需要可靠锁紧。
3.5 电路板及负压风扇的安装
根据当前车模实物，电路板集中布置在底盘中部，显示模块位于上层便于观察的位置，车体两侧安装风扇组件。各部件使用螺柱、支架或扎带可靠固定，电源线与信号线分区整理，避免线束进入齿轮、车轮和风扇转动范围。风扇外围设置防护结构，可在调试和搬运过程中降低叶片碰撞风险。
3.6 轮胎处理
对于智能车模，低速行驶时轮胎状态对整车性能影响并不明显，但车速提升、过小半径弯道时，轮胎容易因摩擦力不足出现侧滑，同时胎皮和轮辋之间会产生相对滑移，这种错位会破坏赛车行驶的平稳性与稳定性。为解决该问题，调试时我们使用乳胶将胎皮与轮辋粘接固定，避免胎皮打滑错位造成驱动力损耗。同时对轮胎做打磨和涂抹软化剂处理，经过实车多次跑赛道磨合优化轮胎抓地性能。打磨时不对轮胎中部过多处理，重点打磨轮胎边缘；车辆过弯直行主要依靠轮胎中部提供摩擦力。

第四章 系统方案设计
4.1 车模系统概述
整车系统由环境感知、核心控制、运动执行、激光执行、电源管理和人机交互六部分构成。控制器周期性读取赛道检测信息，计算车模相对期望路径的位置偏差，输出舵机控制量和电机驱动量；当目标区域满足触发条件时，控制九路激光阵列按预设策略工作；当检测到障碍或异常状态时，降低目标速度或进入保护状态。
表4.1  车模系统组成
软件按照“采集—判断—控制—执行”的顺序运行。上电后首先完成端口、定时器、显示和传感模块初始化，并进行舵机中位与激光关闭状态检查；进入运行状态后，高频任务负责采集和基础控制，低频任务负责状态显示、参数管理和故障诊断。该结构能够避免显示刷新等非关键任务占用过多实时控制时间。
九路激光阵列采用独立通道或分组控制方式。对于覆盖完整的目标区域，可根据车模横向位置选择相邻通道开启，避免无关通道长时间工作；若当前硬件采用统一开关控制，则由整体触发窗口保证留痕范围。最终控制方式需根据驱动板实际接口在后续版本中补充。

第五章 硬件电路设计
5.1 单片机最小系统
雁过留痕组控制平台采用STC32G144K246微控制器，数量为1个。开发与下载使用Keil5和AiCube-ISP-v6.96K。最小系统主要包括微控制器、电源去耦、时钟与复位、程序下载接口以及必要的输入输出接口。控制器需要提供足够的定时器和PWM资源，用于电机驱动、舵机控制和九路激光时序；同时需要保留通信接口，连接显示模块、调试工具和赛道检测装置。
主控板布局应将高频信号与大电流驱动区域适当分隔，在各电源引脚附近配置去耦电容，并为下载口、调试串口和关键测试点预留清晰标识。软件上电后先将电机、舵机和激光输出设置为安全状态，完成外设初始化后再允许进入运行模式。
5.2 电源模块
整车电源需要同时满足驱动电机、转向舵机、控制器、摄像头、九路激光和风扇等负载需求。电机和风扇属于波动较大的功率负载，控制器与检测模块对电压稳定性要求较高，因此电源设计采用分级供电和公共地连接方式，并在负载入口配置滤波和必要的保护。
车模采用12.6V、2200mAh电池1块。5V电源以SCT2450SOT23-8稳压芯片为核心，3.3V电源采用RT9013-33GB稳压芯片。后续应测量静态电流、起步峰值电流、风扇启动电流和激光全开电流，检查供电压降及器件温升。电源开关和连接器应便于快速断电，线径与接插件额定电流应留有余量。

5.3 九路激光驱动模块
九路激光阵列采用逐飞官方405nm激光器，是本组任务的主要执行机构。控制器的普通I/O口不能直接承担多路激光器的工作电流，因此各通道应通过驱动器件完成开关控制，并根据实际激光器规格设置限流。驱动电路需要保证上电默认关闭，防止控制器复位或端口悬空时误点亮。

5.4 电机驱动模块
电机驱动模块接收控制器输出的方向信号和PWM信号，将低功率控制信号转换为能够驱动电机的电压与电流。驱动板具体型号暂不在本版报告中展开。硬件设计应考虑续流、过流、散热和电源干扰，驱动回路与控制回路之间保持合理布线距离。
调试时先将车轮架空，以较低占空比检查电机方向和PWM响应，再逐步提高输出。若采用速度反馈装置，应确认反馈方向与控制方向一致，避免闭环接反导致电机输出迅速饱和。
5.5 舵机控制模块
转向舵机采用S-U400。舵机由周期性PWM脉冲控制，控制器根据路径偏差计算期望转角，再将其换算为舵机脉宽。中值脉宽和允许脉宽范围在整车调试时标定。舵机供电需要具有足够的瞬态电流能力，并通过软件限幅避免超出机械转向范围。

第六章 车模软件算法
6.1 赛道信息采集与处理
6.1.1 二值化
摄像头所获取的是一个灰度图，而灰度图每个像素拥有 0-255 共 256 个亮度等级，可以保留图像丰富的明暗细节，但同时携带的数据量较大，会占用单片机较多内存，带来较大的计算压力，图像里也会保留场地反光、阴影、污渍形成的各种中间灰色，无法直接简单区分赛道黑线和背景，不方便直接完成循迹判断。正是因为灰度图存在这些问题，所以要进行二值化处理，二值化将灰度图转化为只有黑白两种像素的图像，大幅减少数据量，减轻单片机的运算压力，避免处理延迟造成小车失控，同时去掉多级灰度，只保留黑线与背景两类信息，通过识别黑白跳变就可以得到黑线中心位置给 PID 使用，还能把阴影污渍带来的中间灰度按照阈值归类，过滤一部分环境噪声，也方便后续进行腐蚀、膨胀这类形态学处理来消除噪点，不过固定阈值的二值化容易受光线变化影响，这种情况下我们所采用的是大津法及动态阈值来对图像进行二值化。

6.1.2 边线提取
二值化后的图像只有黑背景和白赛道，赛道边界就是黑白跳变的位置。
首先算法从下到上逐行扫描图像，利用前一行的边界位置，在小范围内局部搜索，提升速度并抗干扰。
在范围内检测二值像素的黑白跳变，找到本行左右边界。如果是正常跳变，直接保存边界；如果是异常大跳变，会重新精细扫描像素，找到出真实边界。
最后根据每行左右边界计算赛道中心和赛道宽度，并做坐标限幅，保证边界合理稳定，最终输出完整、可靠的赛道边界数据用于路径计算。
6.2 车模路径计算
路径计算的目标是获得车模当前位置相对期望行驶轨迹的偏差。根据赛道检测装置输出，我们采用加权位置、几何中心拟合等方法计算偏差，并结合近处信息保证稳定性、远处信息反映道路趋势。直道时提高前向趋势权重，弯道时适当降低目标速度并增强对近端偏差的响应。
为了防止特殊区域或障碍造成路径突变，程序对相邻周期的偏差变化量设置合理限制，并通过状态机区分普通循迹、目标确认、激光执行、障碍规避和恢复运行等状态。状态切换同时参考空间特征与连续帧计数，避免一次误检测直接触发关键动作。
6.3 转向舵机控制
6.3.1 位置式PID
PID 是“比例-积分-微分”（Proportional-Integral-Derivative）的缩写，是一种常见的反馈控制算法，广泛应用于工业控制系统和各种自动化设备中。PID 控制器通过计算偏差或误差值（即期望输出与实际输出之间的差值），并应用比例（P）、积分（I）和微分（D）三种控制作用来调整控制量，以达到期望的控制效果。我们转向舵机的控制则是采用位置式PID以路径偏差为输入，以舵机脉宽增量为输出。

e( i )     误差值的累加
e(k - 1)   上一次的误差值
比例项根据当前偏差快速产生转向作用，微分项根据偏差变化趋势抑制摆动。在直道和弯道中可使用不同参数或随速度调整控制增益，以兼顾高速稳定性和急弯通过能力。
6.3.2 输出限幅
舵机控制做输出限幅，一是硬件层面保护设备，舵机有机械最大转角，输出数值超限会让舵机被强行顶住，内部齿轮、舵机电机持续堵转，短时间就会发热烧机、打齿损坏；二是适配赛道行驶需求，过大转向量会让小车猛打方向，高速下侧滑、冲出赛道，限幅能把转向角度约束在安全区间，保证行驶平稳；三是配合 PID 运算优化控制效果，微分环节遇突变偏差容易算出超大瞬时输出，限幅可以压制异常峰值，避免转向剧烈抖动，让 PD 输出平缓合理；另外单片机传给舵机的 PWM 信号对应固定数值范围，限幅能保证输出始终落在有效 PWM 区间，不会出现信号失效、舵机无响应的问题。
6.4 电机速度控制
6.4.1 增量式 PID
电机控制分为闭环和开环而开环控制没有反馈，遇到电压波动、地面打滑等干扰时无法自动修正，偏移会越来越大，小车容易跑飞。因此，本队车模配置编码器速度反馈装置，采用增量式PID进行电机闭环控制。

6.4.2 速度决策
速度控制根据赛道状态设置目标速度：普通直道使用较高目标值，弯道、目标区域和障碍附近降低速度，丢线或异常状态进一步限速或停车。

结论
本文围绕太原学院“力行—驭风”队参加全国大学生智能汽车竞赛雁过留痕组的车模方案展开介绍，完成了从车模平台、机械结构、硬件电路到软件控制的整体梳理。车模采用博思威龙B型四轮舵机车模，以STC32G144K246微控制器为控制核心，配合逐飞科技专用总钻风摄像头获取赛道信息，通过舵机完成前轮转向，通过驱动电机实现车辆前进，并使用逐飞官方405nm九路激光装置完成目标区域留痕。整个系统的设计目标不是单独追求某一模块的性能，而是在规则约束下实现感知、决策、执行和安全保护之间的协调。
在机械结构方面，B型车模具有四轮支撑和舵机转向的特点，底盘结构相对稳定，适合在室内PVC赛道上进行连续运行。设计过程中重点考虑了车体重心、车轮受力、舵机中位、激光安装高度以及线束固定等问题。车模裸车尺寸为长280mm、宽180mm、高80mm，采用光头胎，未对轮胎和传动机构进行改装。通过将控制板、电源连接和执行器合理布置在底盘上，能够减少车体左右质量差异和上层结构晃动对运行状态的影响。机械部分看似简单，却直接决定了后续软件调参的上限，只有先保证结构可靠，控制算法的参数调整才具有稳定的基础。
在赛道感知方面，系统采用逐飞科技STC32G144K246专用总钻风摄像头。摄像头采集到的图像需要经过有效区域提取、灰度或二值化处理、噪声抑制和边界判断，最终转换为控制器能够使用的路径偏差和道路趋势信息。与单纯依靠单点信号相比，图像信息能够提供更丰富的赛道形态特征，但也更容易受到光照变化、反光、阴影和目标区域干扰的影响。因此程序不能只依赖某一行或某一个像素点，而应结合连续采样结果进行判断，并在检测失效时采取限速、保持或安全停车等保护措施，避免错误数据直接造成舵机大幅摆动。
九路405nm激光阵列是本组车模区别于普通循迹车的重要执行部分。九个激光单元沿车头横向排列，能够在车模存在一定横向偏差时扩大有效覆盖范围。激光模块的安装不仅要保证各通道间距基本一致，还要保证光束方向、安装高度和车体姿态变化之间具有可重复性。实际使用时，控制器应根据目标区域识别结果决定激光的开启时刻和持续时间，并在离开目标区域后及时关闭，避免误触发和重复留痕。激光系统还必须具备上电默认关闭、故障时关闭和调试限时等安全机制，确保车辆调试过程可控，避免对人员和周围设备造成不必要的风险。
在硬件电路方面，车模使用12.6V、2200mAh电池1块供电，并通过电源模块得到控制器和外设所需要的工作电压。5V电源采用SCT2450SOT23-8稳压方案，3.3V电源采用RT9013-33GB稳压方案。主控板需要同时处理摄像头数据、编码器数据、舵机PWM、电机驱动信号和九路激光控制信号，因此端口分配、定时器资源和电源去耦都需要提前规划。奥凯特编码器共2个，可用于获取车轮转动信息，为速度判断和闭环控制提供反馈。硬件设计的重点是使各模块接口清晰、供电稳定、驱动回路与弱信号回路相互影响较小，并为后续检修保留足够的操作空间。
在运动控制方面，车模采用舵机控制转向、电机控制速度的分层思路。路径偏差经过处理后形成转向误差，比例环节用于快速纠正当前位置偏差，微分环节用于抑制偏差变化过快导致的左右摆动；速度部分则根据直道、弯道、目标区域和障碍区域设置不同的目标值。调试时应先校准舵机机械中位和左右极限，再逐步调整转向比例、微分和速度参数，不能在机械中位尚未确定时直接依靠软件参数进行补偿。加减速采用渐变方式能够降低轮胎打滑、电源压降和车体姿态突变的影响，使车辆在进入弯道和目标区域时更容易保持稳定。
软件系统采用模块化和状态机相结合的组织方式。底层程序负责端口、定时器、PWM、摄像头和编码器等基础功能；功能层负责图像处理、路径计算、速度估计、舵机控制和激光驱动；应用层根据赛道状态组织普通循迹、目标确认、激光执行、障碍规避、丢线处理和异常保护等工作状态。这样的分层方式有利于定位问题：当车辆直线跑偏时可以优先检查机械中位和路径偏差，当弯道摆动时可以重点检查转向控制参数，当激光动作不正确时则可以独立检查目标判断和激光驱动时序。模块之间通过明确的状态量和接口连接，也便于后续替换传感器或调整控制策略。
从工程实践角度看，智能车调试不能只依靠最终赛道成绩判断方案好坏，而需要建立逐级验证过程。首先检查电源极性、稳压输出和主控下载功能，再分别验证摄像头图像、编码器计数、舵机中位、电机方向和激光单路动作，最后才进行整车联调。调试过程中应保留关键参数、现象和修改原因，避免重复试错。对于偶发问题，需要通过降低速度、增加数据记录和重复运行来区分机械松动、接触不良、信号噪声与算法判断错误。通过这种方式，队员不仅能够完成一辆可以运行的车模，也能够逐步形成对嵌入式系统、自动控制和工程可靠性的综合认识。
目前方案仍有需要继续完善的地方。首先，驱动电机和驱动板的最终型号、额定参数及散热状态需要结合实物进一步核对，并在技术检查表中补全。其次，电路板数量、功能分配、PCB上的学校和队伍标识等信息需要根据板卡实物和设计文件整理归档。再次，摄像头在不同光照条件下的有效识别范围、九路激光光斑的一致性、编码器反馈的稳定性以及舵机在高速转向时的机械间隙，都应通过重复测试得到更可靠的参数。报告中没有把尚未实测的内容写成确定成绩，后续应以实际记录为依据继续修订。
通过本次方案设计，队员对智能车竞赛从机械装配到软件控制的完整流程有了更加具体的理解。机械结构决定车辆能否稳定运行，传感器决定系统能否获得可靠信息，控制算法决定车辆能否及时作出正确动作，而电源、线束和安全保护则决定整车能否持续工作。任何一个环节存在明显缺陷，都会在高速运行和复杂赛道环境中被放大。团队在查阅资料、讨论方案、制作车模和反复调试的过程中，不仅提高了对STC微控制器、摄像头、编码器、舵机和激光执行器的应用能力，也锻炼了分工协作、问题复盘和工程取舍能力。
总体而言，太原学院“力行—驭风”队的雁过留痕组车模已经形成了较为完整的技术路线：以B型四轮舵机车模为机械基础，以STC32G144K246为控制核心，以总钻风摄像头完成赛道感知，以奥凯特编码器辅助速度反馈，以S-U400舵机完成转向，以九路405nm激光阵列完成目标留痕。后续工作将围绕驱动参数核对、板卡信息完善、光斑标定、控制参数优化和整车可靠性测试展开，在保证安全和合规的前提下逐步提高运行稳定性。无论最终比赛结果如何，这套从需求分析、方案设计、硬件集成到软件调试的完整经历，都是队员工程实践能力和创新意识的重要积累。

B.2 左右轮速度 PID
void l_speed_pid(int l_speed)
{
    l_error = l_speed - l_target_speed;
    l_output += s_p * (l_error - l_last_error)
              + si * l_error
              + sd * (l_error - 2 * l_last_error + l_last_last_error);
    l_last_last_error = l_last_error;
    l_last_error = l_error;
    if (l_output >= MAX_Speed) l_output = MAX_Speed;
    if (l_output <= -MAX_Speed) l_output = -MAX_Speed;
}

void r_speed_pid(int r_speed)
{
    r_error = r_speed - r_target_speed;
    r_output += s_p * (r_error - r_last_error)
              + si * r_error
              + sd * (r_error - 2 * r_last_error + r_last_last_error);
    r_last_last_error = r_last_error;
    r_last_error = r_error;
    if (r_output >= MAX_Speed) r_output = MAX_Speed;
    if (r_output <= -MAX_Speed) r_output = -MAX_Speed;
}
B.3 电机方向与 PWM 输出
void Speed(int Speed1, int Speed2)
{
    if (Speed1 >= 0) {
        gpio_set_level(DIR_L1, 1);
        pwm_set_duty(PWM_L1, Speed1);
    } else {
        gpio_set_level(DIR_L1, 0);
        pwm_set_duty(PWM_L1, -Speed1);
    }

    if (Speed2 >= 0) {
        gpio_set_level(DIR_R1, 1);
        pwm_set_duty(PWM_R1, Speed2);
    } else {
        gpio_set_level(DIR_R1, 0);
        pwm_set_duty(PWM_R1, -Speed2);
    }
}
