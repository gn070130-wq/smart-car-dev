摘要
本文系统介绍了一往无前队在二十一届全国大学生智能汽车竞赛雁过留痕
组中的系统方案。本次大赛采用大赛组委会统一指定的 C 车模，以 STC32G 为核
心控制器，一个总转分摄像头作为信息采集，再通过逐飞编码器检测智能车的实
时速度，使用，陀螺仪 imu660ra 获得车的偏角，使用舵机 SU400 控制车的偏转，
使用 PID 控制算法检测电机的转速使，从而实现智能车载运动过程中转向和速度
的闭环控制。为了提高车的稳定性，进行了大量的硬件与软件调试。
为保证巡线的稳定性，我们还进行了中线提取，丢线补偿，特殊元素判断等
算法。在打靶方面，我们使用了特殊的元素判断，单独判断靶纸的位置，然后通
过位置的不一样性判断多激光打靶。
关键词：智能车，雁过留痕，PID 闭环控制

一、引言
1.1 全国大学生智能汽车竞赛简介
全国大学生智能汽车竞赛是以智能汽车为研究对象的创意性科技竞赛，是面
向全国大学生的一种具有探索性的工程实践活动，是教育部倡导的大学生科技竞
赛之一。
本竞赛的起源可追溯至 2005 年。为加强大学生实践、创新能力和团队精神
的培养，促进高等教育教学改革，教育部高等教育司以教高司函〔2005〕201 号
文委托教育部高等学校自动化专业教学指导分委员会创办该项赛事。竞赛于
2005 年 11 月正式启动，首届比赛吸引了来自全国 57 所大学的 112 个团队参赛。
自 2006 年首届举办以来，竞赛规模不断扩大，已发展成为覆盖全国 30 个省市自
治区、两百余所高校广泛参与的全国性大学生科技竞赛。竞赛在创办后入选中国
高等教育学会《全国普通高校学科竞赛排行榜》，被列为教育部认可的 A类赛事。
2020 年起，竞赛主办单位由教育部高等学校自动化类专业教学指导委员会转为
中国自动化学会。
竞赛以“立足培养，重在参与，鼓励探索，追求卓越”为指导思想，旨在促
进高等学校素质教育，培养大学生的综合知识运用能力、基本工程实践能力和创
新意识，激发大学生从事科学研究与探索的兴趣和潜能，倡导理论联系实际、求
真务实的学风和团队协作的人文精神，为优秀人才的脱颖而出创造条件。
竞赛过程涵盖了理论设计、实际制作、整车调试、现场比赛等环节，要求学
生组成团队协同工作，初步体验一个工程性研究开发项目从设计到实现的全过程。
竞赛内容以迅猛发展的汽车电子为背景，涉及自动控制、模式识别、传感技术、
电子、电气、计算机、机械与汽车等多学科专业知识。竞赛规则透明，评价标准
客观，坚持公开、公平、公正的原则。比赛形式包括竞速比赛与创意比赛两大类，
分赛区预赛和全国总决赛一般安排在每年暑假期间。
1.2 智能汽车制作要求及任务
本组别要求使用四轮竞速车模（B 型或 C 型），以 STC 微控制器为主控芯片，
电路板须自行设计并在嘉立创指定渠道制作。赛道为白色 PVC 材质，蓝色背景，
不设路肩。车模须完成一周赛道运行，赛道包含直弯、十字路口、环岛、坡道及
路障等元素。核心任务为紫外感光打靶——在铺设有紫外感光纸的路段，使用紫
外激光将光斑精准投射于圆形目标区域内，区域外不得留痕。车模仅限使用单个
摄像头进行赛道检测，不允许采用其他光电管检测赛道及感光纸，姿态传感器可
酌情使用。比赛以完成时间和打靶精度综合评定成绩。

二、模型车设计制作思路及技术方案概要
2.1 设计思路
本组车模设计以满足竞赛要求、实现高效稳定行驶和精准打靶为核心目标。
整体设计追求结构简洁、重量轻便，以提升车模灵活性和动力性能。传感器布局
方面，以单个摄像头为核心，兼顾赛道检测与路标识别。紫外激光模组与云台的
设计需兼顾响应速度与瞄准精度。电路设计遵循稳定可靠、低功耗原则，保障车
模长时间运行的稳定性。
2.2 技术方案概要
车模采用 C 型四轮车模，以原车模结构为基础进行合理改装，安装摄像头、
云台紫外激光模组、电路板等部件。以 STC 微控制器作为控制核心，接收摄像头
采集的赛道图像信息，经图像处理后提取赛道中线与元素特征，运用 PID控制算
法计算电机驱动信号，实现车模转向与速度控制。
三、模型车机械结构设计
车模的机械结构是智能车稳定运行的物理基础，直接影响行驶稳定性、传感
器数据准确性以及打靶任务的执行精度。本组选用大赛组委会统一指定的C 型四
轮竞速车模作为平台，以原车模结构为基础进行合理改装，在不改变车轮轴距、
轮距及驱动传动机构的前提下，优化各部件布局与安装方式。
C 型车模采用后轮驱动、前轮转向的方案，底盘设计较为宽大，具有较好的
行驶稳定性。后轮采用滚珠差速器实现转弯差速，确保车模在弯道中左右轮能够
以不同转速平稳转动，减少轮胎磨损并提高过弯稳定性。C 型车模相比 B型车模
具有更低的底盘高度和更宽的车身，这为降低整车重心和提升高速过弯稳定性提
供了有利条件。
3.1 重心位置的调整和电池的放置
重心位置是影响车模行驶稳定性的关键因素。智能车在高速行驶和过弯时会
产生较大离心力，若重心偏高或分布不均，易导致车模侧翻、甩尾或在急弯处发
生偏移。因此，降低整车重心并使质量分布均匀是机械设计的首要任务。
C 型车模原结构中，电机及驱动部件安装于车身后部，尾部质量明显大于前
端，导致后轮负载过重，过弯时后轮抓地力不足，容易发生侧滑。此外，C 型车
模底盘较低，电池仓位于底盘中部，但原装电池固定方式使电池处于悬空状态，
重心仍有优化空间。为解决此问题，本车模采取以下重心优化措施：
7
电池低位安装：电池是车模中最重的部件之一，其安装位置对重心影响最大。
本方案将 2200mAh 3S 锂电池通过 3D 打印支架固定于车模底盘最低位置，充分利
用 C 型车模底盘较低的先天优势，将电池紧贴底盘下表面安装，并尽量靠近车模
几何中心区域。电池采用水平卧式放置，避免倾斜安装导致重心偏移。经实测，
此布局使整车重心高度显著降低，有效抑制了过弯时的侧倾趋势。
各部件高度控制：电路板采用紧凑布局，通过铜柱固定于底盘上方尽可能低
的位置。C 型车模底盘面积充裕，为电路板的水平铺开提供了良好条件，避免了
电路板叠放导致重心升高。摄像头安装高度经反复调试确定，在保证足够前瞻视
野的前提下尽量压低。云台及紫外激光模块安装于车模顶部偏后位置，其重量较
轻，对整体重心影响有限。通过上述措施，整车重心控制在车模底盘平面附近，
处于车体总高度约 1/3 处，达到了较为理想的平衡状态。
左右对称布局：编码器、电机驱动线等部件在安装时严格保持左右对称，避
免单侧过重导致车模直线行驶时跑偏。C 型车模本身左右对称性良好，在此基础
上进一步优化布线，实现了质量的均匀分布。
3.2 摄像头的设计安装
摄像头是车模获取赛道信息的核心传感器，本组严格按照赛规要求仅使用单
个摄像头进行赛道检测。摄像头的安装需同时满足以下要求：视野开阔以获取足
够的前瞻距离、图像畸变小以保证识别精度、安装稳固以抵抗行驶振动。
支架选材与结构：摄像头支架采用碳素杆作为主支撑结构。碳素杆具有密度
低（约 1.5 g/cm³）、抗弯模量高（可达 120 GPa）的优点，同等刚度下重量仅
为铝合金的 60%，能够有效降低车模上部重量，避免重心上移。碳素杆底部通过
铝合金法兰盘与 C 型车模底盘固定连接，法兰盘采用螺丝紧固方式，利用C 型车
模底盘预留的安装孔位，确保支架在激烈行驶中不发生松动或位移。
安装位置与角度：摄像头安装于车模前端中央的碳素杆上，位于车模纵向中
轴线上，确保左右视野对称。C 型车模前端空间较为充裕，摄像头镜头中心离地
高度约 20 厘米，镜头与碳素杆连接部位呈一定俯角，使摄像头能够同时获取近
处赛道信息和足够的前瞻距离（约 40-50 厘米）。摄像头通过专用固定座与碳素
杆连接，使用顶丝和螺丝双重紧固，防止摄像头角度在行驶中发生偏转。
防抖与减振：为防止车模通过颠簸路段或坡道时碳素杆发生抖动影响图像质
量，碳素杆底部采用铝合金固定件牢牢锁紧于底盘，杆体中部不设额外负重，保
持较高的固有频率以避开行驶振动频段。C 型车模底盘刚度较高，进一步增强了
支架的整体稳定性。
光学优化：摄像头镜头前方加装偏振片，有效滤除赛道表面反光和环境杂散
光，提高图像对比度与边缘清晰度，降低光照变化对识别稳定性的影响。
3.3 多激光打靶方案设计思路
8
为提高打靶成功率并应对车模高速行驶时的姿态扰动，本系统采用多激光管
并行照射的方案。其核心设计思路如下。
提高容错率：车模在行驶中难以保持绝对静止，单一激光管易因瞬间抖动而
偏离靶心。多激光管形成的“光斑阵列”可显著增大有效照射范围，确保至少一
束激光命中目标。
覆盖瞄准误差：通过合理布局，使多束激光在目标距离处形成略微分散的光
斑分布，有效覆盖因云台指向误差或车模姿态变化带来的位置偏差。
冗余设计：在激烈比赛中，单个激光管可能因震动、温度等因素发生功率波动，
多激光管方案提供了硬件层面的冗余，保障了打靶任务的可靠性。
3.4 编码器与姿态传感器的安装
编码器：为精确测量车速，在两个后轮处各安装一个 1024 线正交编码器。
编码器通过专用安装支架固定于电机尾部，其齿轮与电机输出轴齿轮精密啮合。
安装时确保传动轴与电机轴保持平行，齿轮啮合间隙适中——间隙过小会发出刺
耳卡齿声，间隙过大会产生明显迟滞。调整完成的齿轮传动机构运行噪声小、无
卡滞，能够输出稳定的脉冲信号。C 型车模的电机固定座结构稳固，为编码器的
可靠安装提供了良好条件。
IMU 姿态传感器：六轴 IMU（含三轴加速度计和三轴陀螺仪）安装于车模重
心位置附近的底盘上，通过双面胶或尼龙柱牢固固定。此位置能最准确地反映车
模的真实姿态变化，为坡道检测和行驶稳定性控制提供可靠数据。
四、系统硬件设计
系统硬件设计遵循稳定可靠、轻量化、低功耗的基本原则。从方案论证到最
终定稿，经过多次讨论与迭代优化。本车模电路部分主要包括主控单元、电源管
理模块、摄像头接口、电机驱动模块、云台与激光驱动模块、人机交互模块六大
组成部分。各模块设计以稳定可靠为首要原则，同时兼顾车模自身结构特点与轻
量化需求。为尽量减轻车模负载、降低重心，电路设计力求简洁，减少元器件数
量，缩小电路板面积，并注重 PCB 布局优化与信号走线合理性。
4.1 主控芯片选型与电路板设计
主控芯片选用 STC32G144K246 高性能单片机。该芯片采用 32 位 8051 内核，
主频可达 35MHz，内置 144KB Flash 和 5KB SRAM，支持硬件乘除法器、DSP运算
单元与浮点/三角函数运算器，具有强大的实时运算能力。其丰富的外设资源包
括多路 PWM 输出、硬件正交编码器接口、高速 ADC 以及多个串行通信接口，能够
充分满足赛道图像采集与处理、电机闭环控制、云台舵机驱动及激光管触发等多
样化任务需求。STC32G144K246 的国产自主特性与高性价比优势，使其成为本组
别的理想主控平台。
9
电路板为自行设计制作，在嘉立创指定渠道免费下单。主板正面覆铜层标注
有学校名称、队伍名称、制作日期等信息，丝网层包含制作文件链接二维码，完
全符合赛规要求。整板采用双层 PCB 设计，元器件排列紧凑有序，关键信号线（如
摄像头数据线、编码器信号线）进行包地处理以减少电磁干扰，电源线与地线适
当加宽以降低压降。
4.2 电源管理模块
电源采用 3S 锂电池（2200mAh） 供电，为整个系统提供能量来源。为满足
不同模块的供电需求，电源管理模块设计为多路稳压输出。
5V（DCDC）：采用高效同步降压 DCDC 转换器，为摄像头、编码器、IMU 等
传感器供电。SCT2450 芯片最大输入电压范围宽，输出持续电流大，满足传感器
组的总功耗需求。
3.3V（LDO）：采用 RT9013 芯片，为 STC32G144K246 主控芯片供电。LDO 方
案具有输出纹波小、噪声低的优势，确保主控芯片在高速运算时的电源质量。
7.8V（舵机供电）：采用独立稳压模块，为云台双舵机提供稳定电源。舵机
工作时电流波动较大，独立供电可有效避免对主控及其他传感器造成干扰。
各电源输出端均配置适当容量的滤波电容（陶瓷电容与电解电容并联），并
在输入端加入 TVS 管进行过压保护，确保电路在电池电压波动及电机启停冲击下
的工作稳定性。
4.3 摄像头接口
本组严格按照赛规要求仅使用单个摄像头进行赛道检测。摄像头选用适宜嵌
入式视觉应用的低成本 CMOS 摄像头模块，通过 DCMI 数字摄像头接口与
STC32G144K246 连接。摄像头接口电路设计包含以下要点。
数据线：8 位并行数据总线，直接连接 MCU 的 DCMI 接口引脚，实现高速图
像数据传输。
时钟与同步信号：PCLK（像素时钟）、HREF（行参考信号）、VSYNC（帧同
步信号）分别接入 MCU 对应引脚，确保图像采集时序的准确性。
电源滤波：摄像头供电端配低ESR 陶瓷电容，滤除高频噪声，保证图像质量。
电平匹配：摄像头与 MCU 之间无需额外电平转换，直接兼容连接。
4.4 电机驱动模块
电机驱动模块用于驱动车模的两个后轮驱动电机，实现速度闭环控制。驱动
电路的核心为专用直流电机驱动芯片，将 MCU 输出的 PWM 控制信号与方向信号转
换为足以驱动电机的电流和电压。
10
驱动方案特点：
支持电机正反转控制，实现车模的前进、后退与差速转向内置死区保护与过
流保护功能，提高系统可靠性驱动能力充足，满足 C 型车模电机在高速行驶与急
加减速时的功率需求。
由于电机工作时功率较大、工作电流也较大，为防止电机驱动电路对主控芯
片造成干扰，在驱动电路的输入级接入逻辑隔离芯片，实现控制信号的单向传输
与电气隔离。电机驱动板与主控板分离设计，通过排线连接，有利于散热与布局
灵活性。
4.5 人机交互模块
为方便现场调试与参数整定，硬件电路中配备了完整的人机交互模块
IPS 屏幕：通过 SPI 接口与MCU 连接，实时显示摄像头采集的图像、赛道中
线偏差、当前速度、打靶状态等关键信息，便于现场观察与故障排查。
按键：多个独立按键接入 MCU 的 GPIO，用于现场参数调节（如 PID 系数、
目标速度）、模式切换（调试模式/比赛模式）及菜单导航。
蜂鸣器：由 MCU 的 PWM 或 GPIO 控制驱动，用于指示元素识别成功、进入打
靶区域、打靶完成等关键状态，实现非视觉反馈。
无线串口：通过 UART 接口连接无线透传模块，与上位机进行数据交互，实
时传输图像数据、控制参数与运行日志，便于在 PC 端进行深度调试与数据分析。
五、智车控制软件设能计说明
软件设计主要分为赛道图像处理、紫外打靶识别与控制、速度与转向 PID
控制三大模块。
5.1 赛道图像处理
摄像头采集灰度图像后，首先进行中值滤波去除噪声。采用动态阈值二值化
算法，根据图像灰度分布计算最佳分割阈值，将赛道（白色）与背景（蓝色）分
离。随后提取赛道左右边界，计算赛道中心线位置。在弯道、十字路口等元素处，
结合历史数据与边缘特征判断丢线状态并进行补偿。
赛道中线获取流程：动态阈值计算，图像二值化，左右边界扫描（由中点向
两侧），丢线判断与边界补偿，赛道中心线计算。

5.3 紫外感光打靶
紫外感光打靶是雁过留痕组的核心任务。具体实现流程如下：
感光纸区域识别：摄像头检测到赛道旁特定颜色或形状标记时，进入打靶准
备状态。
目标定位：识别感光纸上圆形目标区域的中心坐标。
云台指向控制：根据目标在图像中的位置，通过算法控制选择开启的激光通
道，将紫外激光光斑对准靶心。
照射与校验：开启紫外激光照射，同时监测光斑位置，进行实时微调。
感光纸区域外不允许留有照射痕迹，因此云台控制需具备较高的指向精度，
并在驶离感光纸区域后立即关闭激光。
六、PID 控制算法实现
6.1 PID 控制原理简述
PID 控制是工业控制中经典的闭环控制算法，凭借结构简洁、鲁棒性强、参
数整定便捷的特点，成为系统控制的首选方案。当控制对象模型未知或参数不确
定时，依靠经验调试 PID 参数即可实现稳定控制，适配绝大多数工程场景。
PID 控制的核心是偏差闭环调节：通过目标值与实时采集值的差值，经比例、
积分、微分三项运算生成控制指令，修正系统输出，使实际值快速逼近目标值。
12
三项作用：比例项：快速响应偏差，偏差越大调节力度越强；积分项：消除
稳态静差，避免系统长期存在固定偏差；微分项：预判偏差变化趋势，抑制超调、
提升系统响应速度。
6.2 车速闭环控制
速度控制采用增量式 PID 算法，以编码器反馈的实际速度与目标速度的偏差
为输入，计算电机 PWM 控制量：
∆U(k) = Kp[e(k) − e(k−1)] + Kie(k) + Kd[e(k) − 2e(k−1) + e(k−2)]

迹。以赛道中心线与车模预设中心线的偏差为输入：

/**
* @brief 差比和核心算法 C89标准
* @param a: 像素 1 灰度 b:像素 2灰度
* @retval 差比和计算结果
*/
int DiffSumCalc(int a, int b)
{
int sum;
int diff;
sum = a + b;
diff = a - b;
if(sum == 0)
{
return 0;
}
return (diff << 7) / sum; //移位表示乘法
}

/**
* @brief 75行黑环左右边界检测（单步差比和判定）
* @note 斑马线触发后，100内屏蔽黑环检测
* 基于赛道左右边界向内搜索白→黑跳变，复用原差比和与收缩逻辑
*/
41
void FindBlackRing75(void)
{
int row = 75;
int current, next_p;
int now_x, check_x, move_cnt, tr;
int ring_width;
ring_left_75 = -1;
ring_right_75 = -1;
ring_lost_75 = 0;
/* 赛道本身丢线则直接返回 */
if(line_lost[row] == 1 || left_edge[row] >= right_edge[row])
{
ring_lost_75 = 1;
return;
}
/* ========== 黑环左边界：从赛道左边界向右搜，白→黑跳变 ========== */
current = left_edge[row];
while(1)
{
next_p = current + STEP;
/* 搜到赛道右边界仍未找到，判定丢线 */
if(next_p >= right_edge[row])
{
ring_left_75 = -1;
break;
}
/* 单步差比和超阈值，判定为有效跳变 */
if(DiffSumCalc(mt9v03x_image[row][current],
mt9v03x_image[row][next_p]) > threshold)
{
/* 逐像素向内收缩校验，提升边界精度 */
now_x = current;
move_cnt = 0;
while(move_cnt < STEP)
{
check_x = now_x + 1;
if(check_x >= right_edge[row])
break;
tr = DiffSumCalc(mt9v03x_image[row][check_x],
42
mt9v03x_image[row][check_x - STEP]);
if(tr > threshold)
{
now_x = check_x;
move_cnt++;
}
else
{
break;
}
}
ring_left_75 = now_x;
break;
}
current += 2;
}
/* ========== 黑环右边界：从赛道右边界向左搜，白→黑跳变 ========== */
current = right_edge[row];
while(1)
{
next_p = current - STEP;
/* 搜到赛道左边界仍未找到，判定丢线 */
if(next_p <= left_edge[row])
{
ring_right_75 = -1;
break;
}
/* 单步差比和超阈值，判定为有效跳变 */
if(DiffSumCalc(mt9v03x_image[row][current],
mt9v03x_image[row][next_p]) > threshold)
{
/* 逐像素向内收缩校验，提升边界精度 */
now_x = current;
move_cnt = 0;
while(move_cnt < STEP)
{
check_x = now_x - 1;
if(check_x <= left_edge[row])
break;
tr = DiffSumCalc(mt9v03x_image[row][check_x],
43
mt9v03x_image[row][check_x + STEP]);
if(tr > threshold)
{
now_x = check_x;
move_cnt++;
}
else
{
break;
}
}
ring_right_75 = now_x;
break;
}
current -= 2;
}
if(ring_left_75 == -1 || ring_right_75 == -1)
{
ring_lost_75 = 1;
}
else
{
ring_width = ring_right_75 - ring_left_75;
if(ring_width < 14 || ring_width > 45)
{
ring_lost_75 = 1;
ring_left_75 = -1;
ring_right_75 = -1;
}
}
}

* @note 适配 C251 16位 int 环境，使用无符号整型避免求和溢出
*/

if(gray_sum < 1000 || gray_sum > 6000)

return 1;
}
