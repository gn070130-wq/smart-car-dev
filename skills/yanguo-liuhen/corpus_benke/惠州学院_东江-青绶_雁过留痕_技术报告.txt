摘  要
本文以惠州学院“东江-青绶”队参加第二十一届全国大学生智能汽车竞赛雁过留痕组的技术方案为对象，以博思威龙 C 型车模和 3S 锂电池为平台，围绕一套基于 STC32G144K246 微控制器的智能车控制系统展开设计。系统以 MT9V034 灰度摄像头获取赛道图像，通过自适应二值化、边界搜索、路径中线提取与特殊元素状态判定获得横向偏差；采用舵机分段 PD 控制实现转向，使用双路正交编码器构成直流电机增量式 PI 速度闭环，并配置 IMU660RA 角速度采集与滤波模块辅助姿态信息处理。驱动部分由 DRV8701 全桥直流电机驱动板和基于 STC32G12K128 的三相无刷电调组成，兼顾主驱动、辅助动力与模块化调试需求。软件采用分层设计，将图像处理、速度控制、转向控制、姿态处理和无线调参相互解耦。现有工程已完成主要算法、底层驱动和整车硬件集成，并通过实车照片、上位机识别结果及感光纸留痕效果对系统功能进行说明。控制参数可根据正式赛道环境继续整定。
关键词：智能车；STC32G144K；MT9V034；DRV8701；无刷电调；视觉循迹；增量式 PI

第一章 引言
1.1 项目背景
全国大学生智能汽车竞赛要求参赛车模在限定硬件与规则条件下自主完成赛道感知、路径决策和运动控制。系统性能不仅取决于单一算法，还受到传感器质量、机械安装、电源完整性、驱动能力、实时调度和参数整定等多方面影响。因此，本项目从控制器、视觉、驱动、执行机构与调试工具五个层面进行协同设计。
1.2 雁过留痕组任务与规则要点
根据卓晴老师发布的第二十一届竞赛总规则及“雁过留痕组比赛场地与紫外线感光片说明”，本组采用室内 PVC 赛道，赛道规格沿用第二十届标准；赛道宽度不小于 45 cm，可能包含直道、弯道、十字交叉、坡道、环岛、路障、发车斑马线和锥桶等元素。弯道曲率半径不小于 50 cm，十字路口要求直行通过，环岛半径不小于 50 cm。
专项任务是在赛道紫外感光纸的圆形区域内留下清晰可辨、长度不小于 1 cm 的紫外变色痕迹；痕迹位于圆形外部时，该次任务判定失败。场地设置 1～5 张感光纸，圆形中心距赛道边界不小于 10 cm；遗漏 M 个留痕任务时，比赛用时增加 5×M s。因此系统除稳定循迹外，还需完成目标识别、横向定位、紫外执行器启停和运动时序配合。上述内容以组委会赛前发布的最新修订版为最终依据。
1.3 设计目标
本系统的阶段性目标是构建可重复调试的视觉循迹平台：以灰度摄像头提取赛道与背景的灰度跃迁边界和路径中心，以舵机完成横向控制，以编码器反馈构成双电机速度闭环，并通过无线调参和上位机波形观察提高参数整定效率。对于十字、环岛等赛道元素，采用状态机和几何特征相结合的方法实现识别与补线。
1.4 资料基础与规则说明
本报告依据主控工程、STC32G144K246 主板、DRV8701 驱动板和 STC32G12K128 无刷电调的原理图、PCB 及三维装配图编制，并结合整车装配照片、上位机识别结果和感光纸留痕效果进行说明。规则部分采用智能车竞赛官网赛事章程、卓晴老师发布的第二十一届竞赛规则及雁过留痕组专项说明；本队采用的博思威龙 C 型车模、3S 锂电池和 MT9V034 摄像头属于本队具体技术方案，器材合规性以竞赛秘书处发布的最新规则、车模清单及材料名单为准。
第二章 系统总体设计
2.1 总体架构
控制系统以 STC32G144K246 主板为核心，由 3S 锂电池向主板、DRV8701 驱动板以及左右两路无刷电调供电。MT9V034 摄像头、IMU660RA、转向舵机和九路蓝紫色（近紫外）光源模块均通过线束接入主板，其中摄像头与舵机由主板板载降压模块供电。DRV8701 驱动板用于驱动博思威龙 C 车模原有的有刷直流电机；两路无刷电调则分别驱动左右两只 RS2205 无刷电机，构成相互独立的两类动力通道。

2.2 软件执行流程
系统上电后完成时钟、调试接口、外设、算法和舵机初始化。摄像头场同步信号触发采集，DMA 将图像搬运至缓冲区；主循环检测一帧完成标志后依次执行图像处理、路径误差计算、舵机控制、姿态处理和调试数据发送。定时器中断以固定周期读取编码器增量并更新速度闭环。当前 main.c 中摄像头处理、陀螺仪和电机闭环调用仍有部分被注释，表明工程处于分模块联调阶段。
2.3 车模平台与机械布置
整车采用博思威龙 C 型四轮车模作为运动平台，车模原有有刷直流电机经 DRV8701 全桥驱动板控制，用于车轮行进；车体左右两侧另配置两套由无刷电调和 RS2205 无刷电机构成的辅助动力单元。3S 锂电池同时为主板、DRV8701 驱动板及两路无刷电调供电，主板再通过板载降压模块向摄像头、舵机等低压负载供电。
机械布置以功能明确、线束可靠和视野无遮挡为原则。MT9V034 摄像头安装在车体上方，九路蓝紫色（近紫外）光源沿车体前部横向布置，用于在目标区域完成留痕；主板、电池、驱动板和两路无刷动力单元根据底盘空间分区安装。技术报告仅保留与系统方案相关的结构说明，不展开整车尺寸与加工细节。

第三章 硬件系统设计
3.1 主控制器与外设
主控工程面向 STC32G144K 平台，使用 Keil MDK for C251 构建。工程已集成 GPIO、PWM、编码器、定时器、UART、SPI 和 USB CDC 等底层驱动，并包含 MT9V034、IMU660RA、IPS 显示、无线串口和上位机调试等设备支持，能够满足整车感知、控制与调试需要。
3.1.1 MCU 核心与基础接口
主板核心器件为 STC32G144K246 系列微控制器。原理图将各端口按功能网络名引出，并配置复位、状态指示、时钟/去耦及 USB 接口。USB Type-C 接口引出 DP、DN，可用于程序调试或数据通信；核心电源附近布置多组 100 nF 去耦电容和储能电容，以降低数字开关噪声对微控制器的影响。主板还设置独立调试接口，便于下载、串口观察和故障定位。

图3.1 STC32G144K246 核心、USB 与基础电路原理图
3.1.2 多路电源系统
整车由 3S 锂电池统一供电，电池电源分别接入主板、DRV8701 驱动板及左右两路无刷电调。主板设置开关稳压和低压差稳压等多级电源，形成 5 V、3.3 V 以及摄像头、舵机等供电分支。大电流动力负载与主控、摄像头等低压负载采用分区供电，可减小电机工作时的电源扰动。

图3.2 主板多路电源模块原理图
3.1.3 传感器、执行器与调试接口
主板将整车常用接口集中布置：包括屏幕、无线串口、无线 SPI、编码器、电机、舵机、串口、蜂鸣器、按键和多路传感器接口。摄像头通道配置 AL422B FIFO，用于缓存并行图像数据，降低图像采集对 CPU 实时性的影响；其写时钟、读时钟、读写使能及数据总线均与主控连接。按键输入设置上拉/下拉网络，蜂鸣器和部分外设使用三极管或 MOS 管进行电平与驱动能力扩展。接口按功能分组可以减少飞线，并便于更换模块和分阶段调试。

3.4 光源执行与整车互联
雁过留痕任务采用九路蓝紫色（近紫外）光源作为执行机构，各路光源通过线束与主板连接，由主控根据目标识别结果统一控制。摄像头、IMU 和舵机同样接入主板，构成感知、决策与执行链路；摄像头及舵机所需低压电源由主板板载降压模块提供。实测中，蓝紫色（近紫外）光源能够使感光纸目标区域产生肉眼可辨的变色痕迹，可用于完成圆形区域内的留痕任务。 所用光源应工作在竞赛允许的安全功率范围内，安装与调试过程中避免光束直射人员眼睛。

3.5 硬件设计注意事项
后续实板验证应重点检查功率回路面积、栅极回路长度、驱动去耦位置、采样地与功率地连接方式、MOSFET 温升以及电池反接与浪涌保护。DRV8701 的 nFAULT 和电流检测接口、无刷电调的母线电压与反电动势采样均应在软件中增加故障记录，以便形成可量化的可靠性测试结果。

4.2 中断与实时调度

第五章 视觉处理与路径识别
5.1 图像预处理
视觉模块直接读取 MT9V034 灰度图像。快速二值化算法根据相邻像素灰度变化和比例阈值判断黑白跳变，并设置低阈值、高阈值及回退阈值，以兼顾不同照度下的边缘保持。工程同时保留 Otsu 阈值计算接口，可按固定帧间隔更新全局阈值。
5.2 边界搜索与中线生成
算法由图像底部向远端逐行搜索赛道与背景之间的灰度跃迁边界；当赛道存在黑色边界线时，同时利用黑线特征增强边界定位，局部搜索失败时以最近有效边界或上一行中心为参考扩大搜索范围。边界检测要求连续黑点确认并检查黑白跃迁，以抑制孤立噪声。左右边界均有效时取几何中心；单边丢失时依据赛道宽度或历史中心估计路径。中心点跳变受到限幅，避免异常像素造成舵机突变。

图5.1 上位机边界与路径中线提取效果
上位机图像中以不同颜色标记左右赛道边界及计算得到的路径中线，可直观观察二值化、边界搜索和中线生成结果。实际运行时，算法结合历史边界与连续帧状态对局部缺失或噪声进行修正，为后续转向控制提供路径偏差信息。
5.3 特殊元素处理
现有代码包含十字元素的拐点搜索、有效边界检查和延长补线逻辑，同时设置环岛状态参数与目标检测计数。算法通过多帧判断、进入与退出条件以及状态复位降低单帧误判，并根据不同赛道元素切换相应的路径处理策略。
第六章 运动控制算法
6.1 舵机转向控制
舵机控制以路径中心偏差为主要输入，根据直道、弯道和环岛等工况采用不同的控制强度。比例环节用于快速修正方向偏差，微分环节用于抑制转向变化过快造成的车身摆动，同时对控制输出进行限幅，以保证舵机动作平稳。

6.2 双电机速度闭环
左右驱动通道通过编码器获取速度反馈，并采用增量式 PI 完成速度闭环。系统根据直道、弯道及特殊元素切换合适的目标速度，控制输出经过限幅后分别作用于左右通道，同时保留差速修正接口，以兼顾行驶速度和转向稳定性。
6.3 角速度处理
IMU660RA 上电后进行静态零偏校准，运行过程中对角速度数据进行死区处理和低通滤波，以减小零点漂移及高频噪声。处理后的姿态信息可作为转向控制的辅助量，是否启用及其作用强度根据整车实际运行情况确定。

C.1 图像快速二值化子程序
static void Image_Binarization_Fast(uint8 xdata *gray_image,
                               uint8 xdata *bin_image)
{
    uint8 x;
    uint8 y;
    uint16 diff;
    uint16 sum;

    uint8 first_strong_x;
    uint8 gray_now;
    uint8 gray_prev;
    uint8 current_color;

    uint8 xdata *gray_row;
    uint8 xdata *bin_row;

    gray_row = gray_image;
    bin_row = bin_image;

    for(y = 0; y < MT9V03X_H; y++)
    {
        first_strong_x = 255;

        /* 找到本行第一个由双阈值明确确定的黑/白像素。 */
        for(x = 0; x < MT9V03X_W; x++)
        {
            gray_now = gray_row[x];

            if((gray_now <= BIN_CBH_LOW_THRESHOLD) ||
               (gray_now >= BIN_CBH_HIGH_THRESHOLD))
            {
                first_strong_x = (uint8)x;
                break;
            }
        }

        /*
         * 本行没有明确锚点：保持原版本 threshold=120 的实际结果。
         */
//        if(first_strong_x == 255)
//        {
//            for(x = 0; x < MT9V03X_W; x++)
//            {
//                bin_row[x] =
//                    (gray_row[x] > BIN_CBH_FALLBACK_THRESHOLD) ? 255 : 0;
//            }

//            gray_row += MT9V03X_W;
//            bin_row += MT9V03X_W;
//            continue;
//        }

        gray_prev = gray_row[first_strong_x];

        if(gray_prev <= BIN_CBH_LOW_THRESHOLD)
        {
            current_color = 0;
        }
        else
        {
            current_color = 255;
        }

        /* 第一个明确点左侧继承该明确点颜色。 */
        for(x = 0; x <= first_strong_x; x++)
        {
            bin_row[x] = current_color;
        }

        /* 从第一个明确点右侧继续向右传播。 */
        for(x = first_strong_x + 1;
            x < MT9V03X_W;
            x++)
        {
            gray_now = gray_row[x];

            if(gray_now <= BIN_CBH_LOW_THRESHOLD)
            {
                current_color = 0;
            }
            else if(gray_now >= BIN_CBH_HIGH_THRESHOLD)
            {
                current_color = 255;
            }
            else if(gray_now > gray_prev)
            {
                diff = (uint16)gray_now - (uint16)gray_prev;
                sum = (uint16)gray_now + (uint16)gray_prev;

                if((diff << BIN_CBH_RATIO_SHIFT) >=
                   (sum * BIN_CBH_RATIO_THRESHOLD))
                {
                    current_color = 255;
                }
            }
            else if(gray_now < gray_prev)
            {
                diff = (uint16)gray_prev - (uint16)gray_now;
                sum = (uint16)gray_now + (uint16)gray_prev;

                if((diff << BIN_CBH_RATIO_SHIFT) >=
                   (sum * BIN_CBH_RATIO_THRESHOLD))
                {
                    current_color = 0;
                }
            }

            bin_row[x] = current_color;
            gray_prev = gray_now;
        }

        gray_row += MT9V03X_W;
        bin_row += MT9V03X_W;
    }
}
C.2 电机增量式PI子程序
static void dianji_motor_pi(volatile dianji_motor_t *m)
{
    int32 delta;

    m->error = m->target - m->count;

    delta = (int32)dianji_kp *
            (int32)(m->error - m->last_error);
    delta += (int32)dianji_ki * (int32)m->error;

    m->last_error = m->error;
    m->delta_pwm = dianji_limit_pwm(delta);
    m->pwm = dianji_limit_pwm((int32)m->pwm + delta);
}
C.3 IMU数据处理子程序
void gyro_process(void)
{
    uint8 ea_temp;
    int16 raw_now;
    int16 corrected_raw;
    float gyro_now;

    ea_temp = EA;
    EA = 0;

    if(gyro_sample_ready == 0)
    {
        EA = ea_temp;
        return;
    }

    raw_now = gyro_z_raw_latest;
    gyro_sample_ready = 0;

    EA = ea_temp;

    corrected_raw =
        (int16)(raw_now - gyro_z_offset_raw);

    gyro_now = imu660ra_gyro_transition(corrected_raw);

    if((gyro_now < GYRO_DEADBAND_DPS) &&
       (gyro_now > -GYRO_DEADBAND_DPS))
    {
        gyro_now = 0.0f;
    }

    gyro_filter_Z +=
        (gyro_now - gyro_filter_Z) * GYRO_FILTER_NEW_WEIGHT;
