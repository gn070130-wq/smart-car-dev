摘 要
在本次比赛中，针对第二十一届全国大学生智能汽车竞赛“雁过留痕”组别的任务要求，本系统以官方指定的标准车模C车模为基础，采用STC32G144K246作为核心控制单元，自主构思控制方案及系统设计，实现了一套能够高速自主循迹、识别复杂赛道元素并精准完成“圆圈打靶留痕”的智能车控制系统。

在制作小车的过程中，我们对小车的整体架构进行了深入的研究与工程化优化。机械结构方面，重点降低了底盘重心、调校了阿克曼转向几何，并专门设计了高稳定性的多激光笔打靶阵列；硬件电路上，完善了多级电源管理系统，并设计了低内阻全桥电机驱动与多路激光阵列的高速瞬态触发电路。软件算法方面，本系统在赛道信息提取上摒弃了传统的全局二值化，采用基于灰度对比度的边缘检测与特征识别算法，能够更鲁棒地适应不同光照环境，稳定处理十字、环岛及路障等复杂赛道元素；运动控制以闭环 PID 控制为主。特别针对本组别“雁过留痕”动态打靶的核心难点，系统创新性地选用了多激光笔硬件方案。通过多路紫外激光器的物理几何空间精确定位与阵列联合触发，用纯物理层面的光路从根本上消除了高速行驶下系统响应带来的留痕滞后与出圈痛点，实现了极高命中率的瞬态精准打靶。

系统总体方案
1.1车模整体概述
本智能车模严格遵循全国大学生智能车竞赛赛事规范搭建，主体采用博思威龙四轮C型车模，整体结构稳定、适配赛事赛道行驶需求。车模采用差异化动力结构设计，后轮为行驶驱动结构，前轮为舵机转向结构；车身配备无刷无感电机构成负压吸附系统，可产生向下的负压压力，有效提升车模与赛道地面的贴合度，增强整车抓地力，大幅降低高速行驶、弯道过弯过程中的打滑、侧移问题，提升行驶稳定性。
整车控制系统以赛事指定的STC32G144K246主控芯片为核心，统筹协调赛道数据采集、姿态检测、动力驱动、电源管理及人机调试等所有功能模块。各硬件模块分工明确、协同工作，通过多传感器融合采集赛道、车速、车身姿态数据，结合专属驱动与供电方案，实现车模自主循迹、稳定调速、姿态自校正等核心功能，满足赛事高速、精准、稳定的行驶要求。车模设计见图1.1。

1.2各模块技术方案
1.2.1赛道数据采集方案
本车模赛道数据采集模块采用逐飞总钻风无MCU摄像头作为核心采集器件，该设备无辅助主控，适配智能车高速循迹的需求。摄像头实时采集赛道灰度图像，通过FIFO传递给主控对画面进行解析、降噪、阈值分割处理，精准提取赛道边线、赛道走向等基础赛道数据，同时识别赛场靶纸特征信息，完成靶纸位置数据的采集输出，为车模路径规划、转向控制、速度调节提供核心视觉依据，保障车模精准沿赛道行驶。
1.2.2车模姿态检测
为实现车身姿态的高精度实时检测，整车姿态感知系统采用ICM42688陀螺仪作为核心姿态传感器，可实时采集车模的俯仰、横滚、航向角速度与姿态角度数据，精准反馈车身倾斜、偏转、晃动等实时姿态状态，为主控芯片校正车身姿态、修正行驶偏差提供数据支撑。同时，搭配正交MINI编码器完成车速数据检测，通过采集电机转速，精准计算车模实时行驶速度，实现车速闭环控制。陀螺仪与编码器的数据融合，构建了完整的车模运动状态感知体系，有效提升车模行驶的稳定性和控制精度。
1.2.3动力方案
整车动力系统分为行驶驱动与负压吸附驱动两个部分，均严格遵循赛事硬件使用规范。行驶驱动采用双路带标380有刷电机作为后驱动力单元，为车模直行、过弯、加速行驶提供核心动力，搭配DRV8701专用电机驱动芯片完成有刷电机的启停、正反转、调速控制，驱动响应速度快、稳定性强。负压吸附动力由无刷无感电机提供，配套搭载STC32G12K128芯片控制的专用电调模块，精准驱动无刷电机工作，通过调节电机转速控制负压大小，动态适配不同赛道工况的抓地需求，解决高速行驶打滑、过弯离心力导致的车身偏移问题，全方位优化车模行驶性能。
1.2.4供电系统
为保障整车各模块稳定、持续供电，本车模采用单电源并联供电架构，电源输出稳定、带载能力强，可满足多模块同时工作的功耗需求。系统搭载两路开关、三路稳压电路，对电源输出电压进行分级稳压、分流供电，将稳定电压分别供给主控控制系统、电机驱动系统、传感器采集系统等不同功能单元。分级稳压供电方案可有效规避电压波动、电流干扰对主控芯片、传感器、驱动模块的影响，隔离动力模块工作产生的电源噪声，保障整车硬件长期稳定运行，提升系统抗干扰能力与可靠性。
1.2.5控制调试系统
为便于整车参数调试、状态监测与功能控制，本车模配备了完善的人机交互与调试系统。硬件端集成按键与拨轮模块，可实现参数手动调节、功能模式切换、参数重置等人工操作；搭载IPS200高清显示屏，可实时可视化展示车模车速、姿态角度、电源电压、赛道识别状态、设备工作状态等核心数据，方便调试人员实时观测整车运行工况。同时配置串口通信模块，支持设备与上位机的数据传输，可实现数据日志导出、算法参数在线调试、程序烧录与校正，大幅提升整车调试效率，便于后续算法优化与性能迭代升级。
 机械系统设计与实现
2.1车模重力分配
本智能车模在机械结构设计阶段，以整车重心均衡、行驶姿态稳定为核心原则，完成硬件设备的布局与重力分配优化。整车采用前后重力均衡、重心居中的布局方案，有效避免因重心偏移导致的行驶跑偏、侧翻、甩尾等问题。各类传感器、显示屏、按键、供电模块等外设器件均匀分布在车模中心区域。该布局方式能够充分平衡车身前后、左右的配重，使整车重心始终保持在车身几何中心范围内，大幅提升车模在直道高速行驶、弯道转向、坡道行驶等复杂工况下的姿态稳定性与行驶平顺性。
2.2前轮定位
为优化车模直行稳定性与过弯贴合度，本车模对前轮进行专业定位调校，采用前轮外倾搭配前轮前束的组合定位方式。前轮外倾结构使车轮滚动轨迹近似圆锥滚动形态，会产生两侧车轮向外滚开的趋势；但受转向拉杆的机械约束，车轮无法向外偏移，行驶过程中会形成边滚动、边向内贴合赛道的运动特性。基于该机械特性，本车模选用内八字前轮结构，可有效纠正高速直行时的车身偏移趋势，让车模在直道行驶过程中能够紧密贴合赛道中线行驶，显著提升直行精准度与行驶稳定性，降低赛道偏离概率。前轮安装见图2.1

2.3驱动轮与速度传感器（编码器）安装
本车模驱动轮与速度编码器采用齿轮啮合安装方式，整体装配精度高、机械匹配性好。装配过程中严格校准齿轮间隙，保证驱动电机齿轮、车轮齿轮与编码器齿轮啮合紧密、配合顺畅，车轮转动过程中齿轮咬合无卡顿、无偏移，机械阻力极小。稳定的齿轮传动结构，有效避免了因齿轮松动、啮合不良导致的转速检测误差、动力传输损耗等问题。编码器可实时、精准采集车轮转动脉冲信号，为车速闭环控制、行驶里程计算、速度动态调节提供高精度机械数据支撑，保障整车速度控制的准确性与实时性。齿轮啮合见图2.2

2.4激光笔固定
为满足赛事精准打靶的功能需求，本车模搭载9路激光笔作为打靶执行结构，激光笔总体模块长度约16cm，覆盖范围可完全适配45cm标准赛道宽度，能够实现全域精准打靶，有效提升打靶精度与成功率。在安装布局上，将整套激光笔模块对称固定于车模舵机两侧，安装位置经过多次结构调校与视野校核，可完全规避摄像头采集视野，不会遮挡赛道图像采集，保证视觉识别系统与激光打靶系统互不干扰、协同工作。同时，该侧向低位安装方式无需抬高设备高度，不会改变整车原有重心高度，可完美保留车身重心居中、配重均衡的优势，避免因加装设备导致重心上移、车身稳定性下降等问题，在实现精准打靶功能的同时，最大限度保障了车模高速行驶与转向的姿态稳定性。

2.5摄像头固定
为满足高速赛道图像采集的清晰度与稳定性需求，本车模对赛道采集摄像头采用高架稳固固定方案。摄像头整体垂直离地高度约36cm，通过8mm高强度碳素主杆固定于车模车身，碳素杆具备强度高、刚性好、不易弯折变形的优势，可有效抵御高速行驶产生的气流冲击与车身震动。为进一步强化结构稳定性，额外加装5mm碳素杆搭建三角支撑结构，利用三角形机械稳定特性，全方位加固摄像头安装基座。该固定方式极大降低了车模高速行驶、颠簸过弯时的摄像头抖动、偏移问题，保证摄像头视角稳定，为后续赛道图像处理与数据解析提供稳定的硬件基础。摄像头固定高度示意见图2.3

2.6负压实现
本车模负压吸附模块采用居中靠后的安装布局，负压动力单元选用AE2207 2100KV无刷电机，搭配5寸六叶桨叶作为负压发生结构，整套设备固定于车身中后区域，工作时可对整车形成均匀且充足的向下吸附压力。该安装位置经过配重与行驶工况优化，一方面能够配合整车重心布局，进一步平衡车身前后重力，提升整车行驶平稳性；另一方面可重点对车尾形成下压效果，有效抑制车模高速过弯时的尾部甩尾现象。同时，在坡道行驶工况下，负压的居中靠下压力可抵消车身前倾、翻头的趋势，避免坡道滑行过程中出现翘头、翻车等故障，全方位提升车模复杂赛道的行驶稳定性与容错性。搭配的5寸六叶桨叶风量大、负压输出稳定，配合高KV值无刷电机可快速响应转速调节，能够根据行驶工况动态调整负压大小，适配高速直行、急弯、坡道等多种赛道场景的抓地需求。负压固定如图2.4

第四章  软件系统设计及实现
4.1  软件总体框架
本智能车软件系统采用模块化、分层化的设计思想，将整车软件划分为图像采集与处理、赛道循迹、元素识别、运动控制、激光打靶及人机调试六大功能模块。各模块之间通过全局变量与标志位进行数据交互，在定时器中断驱动的统一调度下协同工作，实现车模的高速自主循迹与精准打靶。
软件的主流程为：摄像头采集赛道图像后，由图像处理模块完成预处理与边缘提取；循迹模块根据边缘信息拟合赛道中心线；元素识别模块判断当前所处赛道元素并切换对应控制策略；运动控制模块依据偏差计算舵机打角与电机速度；打靶模块在识别到靶纸后触发对应激光。整个控制周期与摄像头帧率同步，确保控制的实时性与连贯性。
4.2  图像处理
4.2.1  图像预处理
摄像头采集的原始图像分辨率较大，为降低MCU运算负担并去除镜头边缘畸变区域，系统对原始图像进行裁剪，保留赛道有效信息区域。裁剪后的图像作为后续所有图像处理算法的输入，在保证信息完整的同时有效提升了算法运行效率。此外，系统还对图像进行灰度化处理，将彩色图像转换为单通道灰度图，进一步减少数据量。
4.2.2  动态阈值分割
传统固定阈值二值化方法在赛场光照不均匀时容易出现误判。本系统采用动态阈值生成策略，通过统计图像近车端区域的平均亮度作为基准参考，在此基础上生成白点判定的上下限阈值。该方法能够根据当前环境光照自动调整阈值范围，在强光、弱光及局部反光等复杂场景下均能保持稳定的黑白分割效果。
4.2.3  边缘提取
赛道边缘的提取采用绝对亮度阈值与相对对比度相结合的双重判据。绝对亮度判据用于快速识别清晰的黑色赛道边线，相对对比度判据则在灰度渐变区域通过相邻像素的亮度变化捕捉边缘。双重判据既保证了对清晰黑线的快速响应，又能在边界模糊区域准确提取边缘，显著提升了循迹的鲁棒性。
4.3  赛道循迹算法
4.3.1  寻线策略
传统从图像中心列出发的寻线方式在大曲率弯道或特殊元素入口处容易出现起点即丢线的问题。本系统在正式边缘搜索前，先遍历图像各列寻找视野最开阔的一列作为寻线起始基准，确保寻线起点始终位于赛道内部，从根本上减少了弯道丢线的概率。
边缘搜索采用从基准列出发、分别向左右两侧扫描的动态追踪策略。找到边界后，下一行的搜索范围会依据上一行的边界动态收窄，使搜索始终聚焦于上一行边界附近，既提高了效率又抑制了远处干扰。当局部搜索失败时，系统会回退至基准列重新进行全范围搜索，保证了寻线的连续性。
4.3.2  中心线拟合
由于边缘搜索采用跳跃式步长进行，相邻采样行之间存在空缺行。系统采用线性插值方式补齐这些空缺，使边缘线连续平滑。中心线在普通赛道状态下直接取左右边缘的中点；在环岛等特殊元素状态下，则结合元素特征对缺失的内侧边缘进行预估补全，确保中心线的连续性与合理性。
4.4  赛道元素识别
4.4.1  环岛识别与状态机
环岛是"雁过留痕"组别赛道的核心元素之一，本系统采用有限状态机对环岛进行识别与跟踪。状态值涵盖无环岛、检测到环岛、进入环岛、环岛内部、驶出环岛等多个阶段，不同状态下系统采用差异化的循迹与控制策略，例如在环岛内部适当提高前瞻距离以获得更远的视野，在普通赛道则使用较近前瞻以保证转向灵敏度。
环岛识别主要依据边缘线的突变特征，当单侧边缘出现大幅度向内收窄且伴随丢线，同时另一侧边缘保持连续时，判定为环岛入口。驶出环岛的判定则基于边缘恢复正常宽度且中心线回正的特征。状态机的引入使车模在环岛各阶段均能保持稳定循迹，避免了在环岛内迷路或冲出赛道。
4.5  运动控制算法
4.5.1  前瞻控制
前瞻距离（即计算偏差所选取的图像行号）直接影响车模的转向响应特性。本系统根据当前赛道元素自适应调整前瞻距离：在普通赛道状态下使用适中的前瞻，兼顾响应速度与稳定性；在环岛状态下适当提高前瞻，以更远的视野预判曲率，保证行驶的平顺性。该自适应策略使车模在直道上反应敏捷、在弯道中转向从容。
4.5.2  舵机PD控制
舵机控制采用位置式PID，经过尝试我们认为I项（积分项）不适用于舵机的控制，便将PID简化为舵机的PD控制。P项决定转向的快速性，D项抑制超调与振荡，控制公式如下：
AngleChange = servoP × error + servoD × dError        公式1
由于车模不是处于匀速运动中，不能够通过固定的打角行来计算偏差。我们采用根据编码器的速度返回值计算当前打角行的高度，其策略是速度越快打角行越高，目的是使不同的速度下车模的路径相近，达到车模整体的闭环控制。
4.5.3  电机速度控制
电机速度控制采用增量式PI算法，通过正交编码器实时采集电机转速作为反馈，与目标速度比较后计算PWM输出。I项能够加快电机响应速度、减小稳态误差，P项则抑制超调。
速度决策依据图像中最长白列的长度进行自适应调节。最长白列反映了当前视野内赛道的延伸距离：白列越长，说明前方赛道越平直，可设定较高的目标速度以提升整体成绩；白列越短，说明前方即将进入弯道或遇到特殊元素，需提前降低速度以保证行驶稳定性。系统根据白列长度将速度划分为若干档位，在直道上逐步加速至最高速，在入弯前平滑减速至弯道安全速度，避免出现"猛加猛减"的情况，使车模能够流畅地通过各种赛道元素。
4.6  激光打靶控制
"雁过留痕"组别要求车模在行驶过程中通过激光笔在赛道靶纸上留下标记。本系统搭载多路激光笔阵列，各激光笔对应赛道不同横向区域，根据靶心在图像中的横向位置选择对应角度的激光笔进行触发，实现赛道全宽度覆盖。
靶纸识别采用基于归一化灰度差的圆环特征检测方法，该方法对光照不均具有较强的鲁棒性。打靶检测系统以有限状态机驱动，分为远景等待、远景跟踪、近景精跟踪、发射四个状态。远景阶段在较远处粗搜靶标位置，近景阶段在锁定区域内精修靶心坐标，当靶标到达触发距离时点亮对应激光。该远景粗搜+近景精搜的两级策略兼顾了检测距离与定位精度。环岛等特殊元素状态下系统会暂停打靶检测，避免误触发。

第五章  智能车调试说明
智能车系统的性能不仅取决于方案设计与硬件搭建，更依赖于大量细致的现场调试工作。本系统配备了完善的人机交互调试平台，包括IPS彩色显示屏、机械按键与拨轮，以及串口上位机通信接口，可实现参数在线调节与运行状态实时可视化，为整车调试提供了有力支撑。
5.1  调试系统设计
本车调试系统采用"板载显示+按键交互+串口上位机"三级架构。板载IPS显示屏可实时显示灰度图像、边缘线、中心线及关键状态变量，调试人员无需连接电脑即可直观观察算法运行效果。机械按键与拨轮支持参数的现场增减与切换，避免了反复烧录程序的繁琐。串口上位机则用于更精细的参数整定与数据记录。
5.2  实时图像调试
图像调试是整个调试工作的基础。系统在IPS屏幕上实时显示灰度图像背景，并以不同颜色叠加绘制左右边缘线与中心线，使调试人员可直观判断边缘提取是否准确、中心线拟合是否合理。同时屏幕上还以数值形式显示当前偏差、有效搜索范围、环岛状态、打靶状态等关键变量，帮助调试人员快速定位问题。该可视化调试手段极大缩短了图像算法的调优周期。
5.3  参数在线调节
为提高调试效率，系统将舵机PD参数、电机PI参数、图像处理阈值、前瞻距离等关键变量设计为可通过按键与拨轮在线修改的全局变量。调试时通过按键切换参数项，拨轮增减数值，修改后的参数立即生效并可在屏幕上实时观察效果。参数确认后可写入Flash保存，避免掉电丢失。该设计使得调试人员在赛道旁即可完成大部分参数整定工作。
5.4  现场调试流程
本车的现场调试遵循"由静到动、由慢到快、由简到繁"的原则，分为以下几个阶段：第一阶段为静态图像调试，将车模固定在赛道上方，不启动电机，仅通过屏幕观察灰度图像与边缘提取效果，重点调整阈值参数，确保在赛道各位置均能准确提取边缘。第二阶段为低速循迹调试，让车模在赛道上缓慢行驶，先整定舵机P项使车模能基本沿中心线行驶，再加入D项抑制超调。第三阶段为速度提升与元素调试，在低速循迹稳定的基础上逐步提高速度，同时整定电机PI参数，并逐一调试环岛、靶纸等特殊元素。第四阶段为整车联调与极限测试，以比赛目标速度进行完整圈速测试，针对薄弱环节进行针对性优化。

/* PID控制器结构体定义 */
typedef struct {
    float kp;           /* 比例系数 */
    float ki;           /* 积分系数 */
    float kd;           /* 微分系数 */
    float err;          /* 当前偏差 */
    float last_err;     /* 上一周期偏差 */
    float sum_err;      /* 偏差累积 */
    float output;       /* 控制输出 */
} PID_TypeDef;

/* GPIO与外设初始化 */
void Hardware_Init(void)
{
    /* 电机驱动引脚 */
    gpio_init(MOTOR_IN1, GPO, 0, GPO_PUSH_PULL);
    gpio_init(MOTOR_IN2, GPO, 0, GPO_PUSH_PULL);
    /* 舵机PWM输出，频率300Hz */
    pwm_init(SERVO_PIN, 300, SERVO_MID);
    /* 编码器接口 */
    encoder_init(ENCODER_TIMER);
    /* 激光笔阵列引脚 */
    for(uint8_t i = 0; i < LASER_NUM; i++)
        gpio_init(laser_pin[i], GPO, 0, GPO_PUSH_PULL);
    /* 定时器中断，5ms控制周期 */
    pit_init_ms(PIT_CH0, 5);
    pit_enable(PIT_CH0);
}

/* 增量式PI速度控制 */
int16_t PI_Calc(PID_TypeDef *pid, float target, float current)
{
    pid->err = target - current;
    pid->output += pid->kp * (pid->err - pid->last_err)
                  + pid->ki * pid->err;
    pid->last_err = pid->err;
    /* 输出限幅 */
    if(pid->output > PWM_MAX)  pid->output = PWM_MAX;
    if(pid->output < -PWM_MAX) pid->output = -PWM_MAX;
    return (int16_t)pid->output;
}

/* 舵机PD转向控制 */
int16_t Servo_PD_Calc(PID_TypeDef *pid, float err)
{
    float output;
    output = pid->kp * err + pid->kd * (err - pid->last_err);
    pid->last_err = err;
    if(output > DUTY_MAX)  output = DUTY_MAX;
    if(output < -DUTY_MAX) output = -DUTY_MAX;
    return (int16_t)output;
}
