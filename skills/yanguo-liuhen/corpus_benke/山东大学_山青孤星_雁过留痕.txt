第一章 引言
1.1 设计背景
全国大学生智能汽车竞赛要求参赛车模在规定赛道内完成自主感知、路径规划和闭环控制。参赛车模需要在有限的电源、计算资源和机械空间内完成赛道识别、姿态估计、电机控制、舵机转向、特殊元素处理以及调试信息输出等功能。
本车设计围绕视觉循迹、速度闭环和特殊赛道元素处理展开。硬件部分以 STC32G144K246 核心板和自制主板为基础，软件部分以逐飞 STC32G144K 开源库为底层支撑，并结合实车调试结果确定主要参数。
1.2 系统设计目标
本车以 STC32G144K246 核心板为主控制器，采用灰度摄像头获取赛道图像，利用图像阈值分割、边线搜索和中线拟合获取路径偏差；通过编码器反馈实现双后轮速度闭环，通过舵机完成前轮转向控制；同时结合 IMU660RA 陀螺仪航向角信息进行环岛等特殊元素判断和转向补偿。
代码中还包含激光打靶逻辑、斑马线停车检测、出赛道保护、WiFi 图传调试和屏幕调试接口。最终比赛程序启用 Island_analysis() 环岛分析，Ring() 圆环模块在 main.c 中处于注释状态，未作为最终比赛模块启用。
1.3 报告内容安排
下文先介绍模型车总体方案，再分别说明机械结构、电路设计和软件算法。电路部分包括主板电源、摄像头接口、核心板接口、传感器接口、电机驱动板和外设接口；软件部分包括图像处理、路径误差计算、舵机控制、电机闭环、特殊元素处理和调试显示。

第二章 系统总体方案
2.1 系统组成
模型车系统由机械车体、主控制板、电机驱动板、STC32G144K246 核心板、摄像头、IMU、编码器、舵机、驱动电机、负压风扇无刷电机、激光模块、蜂鸣器、按键/拨码开关和调试显示模块组成。
主要模块如下：
传感器统计口径按摄像头、IMU 和左右编码器计算，不将按键和激光模块计入传感器数量。因此整车传感器包括 1 个 MT9V03X 灰度摄像头、1 个 IMU660RA 和 2 路正交编码器。
2.2 工作流程
系统上电后首先完成时钟、调试串口、蜂鸣器、LED、激光、按键、IMU、舵机、电机、编码器、显示设备和摄像头初始化。主控时钟在代码中配置为 SYSTEM_CLOCK_96M。
主循环等待摄像头一帧图像采集完成。当 mt9v03x_finish_flag 置位后，程序依次执行以下步骤：
使用 OTSU 大津法计算黑白阈值。
搜索参考列和左右边线。
进行环岛分析和补线。
根据左右边线拟合中线。
计算中线平均误差和弯道强度。
执行激光目标识别和打靶控制。
检测斑马线停车和出赛道保护。
根据按键配置输出屏幕或 WiFi 调试图像。
清除图像完成标志，等待下一帧图像。
整套视觉系统按 100 帧/秒工作，每一帧完成图像读取、算法处理并更新电机控制依据。定时器中断周期为 5 ms。在 pit_handler() 中，程序更新 1 ms 计时变量、读取 IMU 陀螺仪、更新航向角、读取编码器，并执行舵机和电机闭环控制。因此车辆底层控制周期为 5 ms，即 200 Hz。
2.3 软硬件分工
硬件系统负责提供稳定电源、完成信号连接、电平隔离和功率驱动。主板上包含电池输入、7.4 V 舵机电源、5 V 系统电源、摄像头电源、3.3 V 电源、5 V 外设受控电源、核心板接口、摄像头 FIFO 接口、传感器接口和多类外设接口。
软件系统负责图像处理、路径识别、运动控制和调试输出。图像处理部分根据摄像头灰度图像得到边线与中线；控制部分根据中线误差、弯道强度和陀螺仪角速度生成舵机 PWM；电机控制部分根据编码器反馈执行左右轮增量式 PID，并结合舵机转角计算差速目标。

第三章 机械结构与传感器安装
3.1 车模机械结构
本车采用 C 车模，传动方式为后驱减速齿轮传动，轮胎采用光头胎。改造后整车长 30 cm，宽 19 cm，高 39 cm，重量约 1300 g。车模采用阿克曼底盘转向机构，转向舵机通过居中螺丝固定，并通过连杆连接前轮与舵机输出臂，实现前轮转向控制。
核心板插接在主板上，主板固定于车模中心区域上方；电机驱动板固定于后轮后方，便于缩短电机功率线长度；电池固定在主板和车模底盘之间，使主要质量集中在车体中部。整车重心调整在车模中央，导线使用扎带固定，关键结构通过螺丝和螺母紧固，以提高抗振动和防松能力。
3.2 摄像头安装
程序使用 MT9V03X 灰度摄像头，图像宽度为 188 像素，高度为 120 像素。摄像头默认配置为 100 FPS、曝光时间 144、增益 32，自动曝光关闭。
摄像头安装于车模上方约 31 cm 处，俯仰角为 45°，距前轴水平距离约 9 cm，镜头视野角为 120°。较高的安装位置可以扩大前方赛道观察范围，45° 俯视角用于兼顾近端边线识别和远端路径预判。
3.3 姿态传感器安装
代码中使用 IMU660RA 姿态传感器，并读取 imu660ra_gyro_z 作为航向角积分和舵机补偿依据。IMU660RA 默认使用硬件 SPI 接口，SPI 速率配置为 10 MHz，加速度计默认量程为 ±8G，陀螺仪默认量程为 ±2000 dps。
IMU 安装于主板排母上，Z 轴正方向定义为垂直于水平面朝下。实际安装时需要保证 IMU 固定牢靠，并尽量靠近车体旋转中心，减少振动和结构松动对角速度积分的影响。
3.4 编码器、电机与舵机安装
代码配置左右两个正交编码器。左编码器使用 PWMC_ENCODER，引脚为 P40/P42；右编码器使用 PWMA_ENCODER，引脚为 P60/P62。编码器计数在 5 ms 定时中断中读取并清零。
舵机 PWM 使用 PWME_CH1P_PA0，频率为 300 Hz。代码中的舵机中值为 4450，占空比限幅为 3950 到 4950。
驱动电机为 DC 7.2 V 380 马达直流有刷电机，共 2 个，单个最大功率大于 20 W。转向舵机为 BDS300 舵机，堵转扭力为 10 kg·cm。编码器为正交编码器，线数为 1024，安装在直流有刷电机上方，测速单位按每 1024 个脉冲对应 360° 旋转进行换算。

第四章 电路系统设计
4.1 主控核心板
本车使用 STC32G144K246_100PIN 核心板。核心板说明书中给出的核心板外形尺寸为 40.64 mm × 40.64 mm，误差 ±0.2 mm。核心板使用内部可调晶振作为时钟源，预留外部晶振接口，支持 Type-C 线连接电脑供电、下载和输出 USB CDC 信息。
本车用到的 STC32G144K246 芯片特性包括：
DSP 型 32 位 8051 / 8 位 1T 8051 内核。
144 K SRAM，246 K Flash。
CPU、DSP 可工作在 100 MHz 附近。
TFPU、PWM 可工作在 250 MHz 及以下。
带硬件 USB，支持 USB-HID 下载。
工作温度范围为 -40 ℃ 到 +125 ℃。
本工程代码中主频配置为 96 MHz。开发环境使用逐飞 STC32G144K 开源库，库版本文件显示当前库版本为 V3.2.5。核心板说明书推荐使用 MDK FOR C251 V5.60，STC-ISP 下载软件需 V6.96F 以上。
4.2 主板电源设计
主板原理图包含以下电源网络：
电池输入端使用 KF301-5.0-2P 接线端子，主板还单独引出电机电源接口 U6。主板 7.4 V 舵机电源和 5 V 系统电源均采用 TPS5430DDAR 降压电源方案；摄像头电源和 3.3 V 电源使用 RT9013-33GB 低压差稳压器。受控 5 V 外设电源使用 SY6280AAC，并由 RST 网络参与使能控制。

I_max = 1.8 Ah × 45 C = 81 A
该值表示电池放电能力上限，不等于车辆正常工作电流。驱动电机为 2 个 DC 7.2 V 380 直流有刷电机，单个电机空载电流小于 630 mA，因此双电机空载电流上限为：
I_motor_no_load < 0.63 A × 2 = 1.26 A
实测电流数据为：整车静态电流约 100 mA，巡线平均电流约 500 mA，堵转峰值电流约 1400 mA。考虑工况变化和瞬态冲击，整车正常运行总电流按小于 2 A 记录。电机标称最大功率主要反映负载能力和峰值能力，不作为正常巡线电流的估算依据。

5.3 图像阈值分割
图像处理使用 SEARCH_IMAGE_W = 188、SEARCH_IMAGE_H = 120 的灰度图像。程序首先调用 OTSU_threshold() 计算黑白阈值。
为了降低计算量，OTSU 阈值计算并非遍历所有像素，而是按 REF_OFFSET = 8 进行抽样，并通过 REF_GRAY_SHIFT = 2 将灰度级从 256 级压缩为 64 级。随后计算类间方差，选取最大类间方差对应灰度作为阈值，并左移恢复到原灰度范围。
这种处理方式减少了直方图计算量，同时保留了对环境光变化的适应能力，为后续边线搜索提供黑白判定依据。
5.4 参考列与边线搜索
Search_reference_col() 从图像左侧开始跳列搜索，在每列中从图像底部向上寻找白到黑的边界位置。程序选取最远白色区域对应列作为参考列，并记录 search_stop_row 作为当前有效赛道最远行。
Search_line() 以参考列为起点，逐行搜索左右边界。每一行先进行局部搜索，如果未找到边界，则退回参考列进行全局搜索。搜索结果分别存入 left_edge_line[] 和 right_edge_line[]。由于搜索采用 PIXEL_OFFSET = 2 的跳点策略，程序在搜索后调用 insert_val() 对缺失行进行线性插值。
这种搜索方式运算量低，能够利用上一行边界收缩下一行的搜索范围，在正常赛道中可以快速获得左右边线。赛道信息检测结果以图像像素坐标表示，因此本车赛道信息检测精度按像素级精度描述。
5.5 中线拟合、误差计算与弯道强度
左右边线搜索完成后，程序使用如下公式拟合中线：
mid_line[row] = (left_edge_line[row] + right_edge_line[row]) / 2
误差计算函数 Error_sum() 默认统计第 80 行到第 50 行之间的中线平均值；若 search_stop_row 大于默认截止行，则动态缩短统计范围。中线平均值与图像中心列 Mid_Col = 94 的差值用于舵机控制。
弯道强度计算使用第 50、75、100 行的中线偏差：
curve_level_raw = abs(e_mid) + abs(e_near - e_far)
curve_level = 0.75 * curve_level_last + 0.25 * curve_level_raw
其中 e_far、e_mid、e_near 分别表示远端、中端和近端中线相对中心列的偏差。弯道强度越大，舵机控制比例系数越大。
5.6 环岛处理
比赛程序调用 Island_analysis() 完成环岛识别与补线。程序通过左右边界丢失点数量、边界单调性、断点、凸起点、上下角点和 IMU 航向角进行状态判断。
环岛状态机包含以下过程：
初始状态，等待发现左/右环岛。
出口处补线直行，等待到达入口。
入口处拉线进入环岛，并重置航向角。
判断是否完全进入环岛内部。
环岛内部行驶并等待出口特征。
出口处拉线驶出环岛。
根据航向角与边界恢复情况判断回到正常巡线。
代码中左环岛完全进入的判断角度为 -50° 到 -70°，右环岛为 50° 到 70°；离开环岛后，左环岛回正判断角度为 20° 到 50°，右环岛为 -50° 到 -20°。
Ring.c 中另有更复杂的 11 状态圆环处理模块，但在当前 main.c 中调用被注释，最终比赛程序未启用。
5.7 舵机控制
舵机控制由 Servo_Loop() 在 5 ms 定时中断中执行。程序首先调用 Servo_pid_fit()，根据弯道强度动态调整舵机控制比例系数：
servo_pidf.kp = curve_level * 0.5
随后 PID_servof() 根据中线误差、误差二次项和陀螺仪补偿计算控制输出：
err = err_sum - Mid_Col
out = kp * err + kp2 * err * abs(err) - kg * imu660ra_gyro_z
duty = SERVO_DUTY_MID - out
代码中舵机参数为：
弯道强度增大时，舵机比例系数随之增大，转向响应更快；陀螺仪角速度项用于抑制过度转向。
5.8 电机速度闭环与差速控制
左右驱动轮采用编码器反馈的增量式 PID。pid_rf 和 pid_lf 初始参数均为：
目标基础速度由可视赛道距离决定：
tar_speed = SPEED_GAIN * (SEARCH_IMAGE_H - search_stop_row) / 10
其中 SPEED_GAIN = 20。当有效赛道延伸得更远时，search_stop_row 更小，目标速度更高；当远端赛道变短时，目标速度降低。
差速计算根据舵机输出与中值的差得到转向角近似量：
turn_signed = Out_servo - SERVO_CENTER
angle_rad = turn_signed * ANGLE_COEF_X
tan_delta ≈ angle_rad + angle_rad^3 / 3
diff_f = tar_speed * B_VERSUS_2L * tan_delta
tar_speed_l = tar_speed - diff_f
tar_speed_r = tar_speed + diff_f
代码中 ANGLE_COEF_X = 0.002，B_VERSUS_2L = 0.35。转弯时内侧轮目标速度降低、外侧轮目标速度提高，用来减小轮胎侧滑和转向负担。
当检测到斑马线或出赛道后，Motor_Loop() 立即将左右电机 PWM 置零，并触发蜂鸣器提示。
5.9 斑马线与出赛道检测
stop_check() 在图像近端区域检测斑马线和出赛道。检测区域为第 90 到 110 行，列范围由近端左右边界内缩 15 像素得到。
斑马线检测统计同一行中黑白状态跳变次数。如果多行跳变次数达到阈值，则认为遇到斑马线并置位 zebra_stop_flag。
出赛道检测统计检测区域内黑点比例。如果黑点比例达到 70% 以上，则置位 out_track_flag，小车进入停车保护。斑马线停车和出赛道保护均为正式比赛功能。
5.10 激光目标识别与打靶
实车共安装 7 个激光模块，排列在车头。软件中按 5 个目标方位定义激光输出，分别接 P9.0 到 P9.4。Target_Accquire() 在图像最后一行搜索白、黑、白、黑、白的状态序列，以两个黑色边界确定目标中心 tar_x。
Attacking() 根据目标中心相对图像中心 94 的偏移选择激光位置：
激光触发持续时间为 10 ms，冷却时间为 100 ms，用于避免同一目标被连续触发。激光打靶为正式比赛功能。
5.11 调试显示
系统提供 IPS200PRO 屏幕和 WiFi SPI 两种调试显示方式。当前 display_device = 2，默认选择 WiFi 图传。调试显示内容包括摄像头灰度图、左右边线、中线、参考列、目标框、黑白阈值、中线误差和环岛进度。
WiFi 模式使用逐飞助手发送 MT9V03X 图像和边界数据；若开启二值化显示，则程序将原始灰度图复制到 image_copy 并调用 binary_visual() 进行二值化。

6.3 软件调试过程
软件调试按以下顺序进行：
基础上电检查：确认 VCC5V、VCC3V3、VCCCAM、VCCServo 和 VCC5V_EXT 电源正常，确认核心板可通过 Type-C 下载程序。
摄像头调试：通过蜂鸣器提示确认 MT9V03X 初始化成功，再通过 WiFi 或 IPS200PRO 显示灰度图像。
阈值与边线调试：观察黑白阈值、左右边线、参考列和中线显示，调整摄像头安装、曝光和增益。
编码器调试：检查左右编码器计数方向，代码中右编码器计数取负，说明左右编码器方向经过软件统一。
舵机调试：确认舵机中值 4450 时车轮居中，并根据实际转向范围调整 3950 到 4950 的限幅。
电机闭环调试：以 5 ms 周期读取编码器，调整左右轮增量式 PID 参数，使速度响应稳定。
赛道元素调试：调试环岛识别、补线、斑马线停车和出赛道保护。
激光打靶调试：使用 KEY3 进行激光全亮测试，再验证目标识别与 5 路激光位置对应关系。
调试中最主要的问题是鲁棒性不足：车辆在原调试场地能够正常运行，但更换场地或赛道后，受环境光、赛道材质和背景差异影响，固定阈值下的黑白分割结果容易变化，导致边线搜索不稳定，车辆出现无法完整跑下赛道的情况。
为了解决这个问题，软件采用 OTSU 大津法动态阈值分割。每帧图像到来后，程序重新统计灰度分布并计算当前帧阈值，使黑白分割能够随光照和背景变化自适应调整。实车调试中，动态阈值比固定阈值更适合不同场地条件，参考列搜索、边线提取和中线拟合也更稳定。

第八章 结论
本作品完成了以 STC32G144K246 为核心的视觉循迹智能车。主板负责电源分配、核心板接口、摄像头 FIFO 接口、IMU、编码器、舵机和外设连接；电机驱动板使用双 DRV8701E 和 MOSFET H 桥驱动两台 380 直流有刷电机。机械部分采用 C 车模、后驱减速齿轮和阿克曼转向结构，摄像头安装在车模上方约 31 cm 处，IMU 固定在主板排母上。

B.3 舵机控制核心
void PID_servof(volatile PID_tf *pid)
{
    float duty;
    float err, p_out, kp2_out, kg_out;

    err = (float)err_sum - (float)Mid_Col;

    p_out = pid->kp * err;
    kp2_out = pid->kp2 * err * func_abs(err);
    kg_out = pid->kg * imu660ra_gyro_z;

    pid->out = p_out + kp2_out - kg_out;
    pid->out = func_limit_ab(pid->out, OUT_MIN, OUT_MAX);

    duty = (float)SERVO_DUTY_MID - pid->out;
    duty = func_limit_ab(duty, SERVO_DUTY_MIN, SERVO_DUTY_MAX);

    Out_servo = (uint16)duty;
    pid->err1 = err;
}
B.4 电机增量式 PID
void Increment_PIDf(volatile PID_tf *pid, float tar_val, float act_val)
{
    float error;
    float d_err;
    float dd_err;
    float delta;
    float new_out;

    error = tar_val - act_val;
    d_err = error - pid->err1;
    dd_err = error - 2 * pid->err1 + pid->err2;

    delta = 0.0;
    delta += pid->kp * d_err;
    delta += pid->ki * error;
    delta += pid->kd * dd_err;

    new_out = pid->out + delta;
    pid->out = func_limit_ab(new_out, OUT_MIN, OUT_MAX);

    pid->err2 = pid->err1;
    pid->err1 = error;
}
B.5 差速目标速度计算
void Smart_Dream_speed(void)
{
    int16 turn_signed;
    float angle_rad, tan_delta, diff_f;

    tar_speed = SPEED_GAIN * (SEARCH_IMAGE_H - (int16)search_stop_row) / 10;

    turn_signed = (int16)Out_servo - SERVO_CENTER;
    angle_rad = (float)turn_signed * ANGLE_COEF_X;
    tan_delta = angle_rad + angle_rad * angle_rad * angle_rad / 3.0;

    diff_f = (float)tar_speed * B_VERSUS_2L * tan_delta;

    tar_speed_l = tar_speed - (int16)diff_f;
    tar_speed_r = tar_speed + (int16)diff_f;
}
