第一章  引  言
1.1 竞赛介绍
全国大学生智能汽车竞赛创办于 2006 年，由教育部高等教育司委托高等学校自动化类教学指导委员会（教高司函〔2005〕201 号文）举办，是一项以提升大学生工程实践能力与创新精神、培养团队协作意识为宗旨的全国性创意科技竞赛。
2026 年，竞赛迎来第二十一届。本届赛事进一步聚焦智能交通与人工智能领域的技术前沿，旨在激发大学生的创新热情，培养智能车领域的技术人才。同时，本届竞赛新增“软硬件盲盒”环节，重点考察参赛队伍的快速学习与临场应变能力；评判方式上取消现场裁判，改由参赛队伍自行录制比赛视频，查验人员依据视频进行评判、打分，并最终确定成绩。
竞赛始终以“立足培养、重在参与、鼓励探索、追求卓越”为宗旨，在近几届比赛中逐步转向以学生为中心。其核心是将竞赛的内容选择权、参与程度与决定权更多地交由学生，让参赛学生在备赛与比赛全过程中充分发挥主动性，使大赛真正成为集知识学习、技能培养与品格养成于一体的成长平台——学生既是比赛的积极参与者，也是创新成果的创造者。
比赛采用“分赛区选拔—全国总决赛”的赛制：组委会先在全国各赛区组织预选，晋级队伍再汇聚全国赛角逐最终名次。各赛区比赛分为预赛与决赛两个阶段——预赛中，每支参赛队伍需自主设计并制作一辆能够独立完成多项任务的智能车，任务涵盖避障、循迹、定位导航、激光打靶等；决赛则是整个赛事的焦点，汇聚各赛区晋级的优秀队伍，集中展示车辆的技术能力与创新成果。
决赛任务通常涉及多种复杂场景与挑战，要求车辆能够在各类环境下稳定地完成感知、决策与执行操作。参赛队伍唯有兼具过硬的技术实力与默契的团队协作，方能在激烈竞争中脱颖而出。
除比赛本身外，智能车竞赛还搭建了重要的学术交流与校企合作平台。参赛选手可以与来自全国各地的优秀团队分享经验、交流技术，共同探讨智能车技术的发展趋势与前沿方向；同时，竞赛与英飞凌等知名企业合作，为参赛队伍提供实践机会与技术支持，促进科研成果与工业应用的深度结合。
智能车竞赛既是一项充满挑战的技术竞技，也是锻炼团队合作、创新思维与解决问题能力的绝佳舞台。通过参与比赛，大学生不仅能在实战中提升工程能力与科学素养，培养自主学习的习惯、增强自信心与竞争意识，还能结识志同道合的伙伴、拓宽视野，为未来的学业与职业发展奠定坚实基础。
1.2 第二十一届智能车大赛规则介绍
雁过留痕组要求参赛队伍制作一辆四轮竞速车模，在包含直道、弯道、十字路口、环岛、坡道、砖红色路障等元素的室内赛道上完成比赛。
比赛设置一项专项任务——激光打靶，赛道上铺设紫外感光纸并绘制圆形目标区域，车模需使用紫外激光管在目标区域内照射以留下紫色痕迹，区域外禁止留下任何照射痕迹；赛道边界处布设锥桶，车模须沿锥桶内侧通行，在无锥桶路段允许短暂驶离赛道。
硬件方面，整车仅允许使用一个摄像头进行赛道检测，不得加装其他光电管或感光器件；车模限定为 B 型或 C 型。

1.3 车模总体方案概述
本队以逐飞科技 C 型车模为基础，以 STC32G144K 开源库平台为核心，构建“感知—决策—执行”闭环控制系统。感知层由 MT9V03X 灰度摄像头及 FIFO 图像缓存模块、IMU660RA 惯性测量单元构成；决策层通过图像处理与分层状态机完成赛道边界提取、环岛、坡道、斑马线、直道等元素识别及运行模式切换；执行层采用舵机转向、双电机差速驱动和无刷风扇动态下压力方案。整车配备 IPS200 屏幕调试界面，调试参数可写入 Flash 保存。

第三章  硬件电路的设计
3.1 系统硬件总体框架
系统以 STC32G144K 单片机为核心，系统模块包括：电调模块、双路有刷电机驱动、舵机驱动、无刷风扇电调、MT9V03X 摄像头模块、IMU660RA 姿态模块、正交编码器测速模块、IPS200 显示模块及 USB CDC 调试接口。摄像头图像经 DMA 直接搬运至内存，电机与舵机由 PWM 驱动，姿态数据经 SPI 读取。

第四章  总体理论分析及控制软件算法实现
4.1 系统控制总体设计
软件系统采用"状态机 + 分层控制"架构。主循环按 CarMode 状态机运行，模式由主控板上两个拨码开关组合选择：UI 模式（调试）、RUN 模式（运行）、STOP 模式（停止）。运行模式下，图像中断完成采集与处理，电机定时中断以 1ms 周期执行速度闭环，主循环完成元素判定与模式切换，形成"感知—决策—执行"流水线。
盲盒阶段通过 BlindBoxPhase 状态机管理，盲盒停止阶段整车自动停车、舵机回正、风扇保持，并触发蜂鸣报警提示，等待下一阶段指令。
4.2 图像处理与赛道信息提取
图像处理流程为：摄像头原始图像 → 灰度图 ImageGray（80×60）→ 二值图 ImageBin → 扫线提取边界 → 计算中线偏差。
（1）动态阈值二值化：对灰度图统计直方图，根据直方图分布自适应计算分割阈值（Image.threshold），将图像分为赛道与背景，并对阈值加入偏置修正，以适应赛道光照变化。
（2）边界扫线：自下而上对二值图逐行搜索左右边界，得到左右边界点序列，并加入跳变点、丢线等处理，保证边界连续性。
（3）中线与偏差：根据左右边界计算赛道中心，与图像中心（第 39 列）作差得到横向偏差 Image.error，作为转向控制输入。
（4）元素识别：在扫线基础上识别环岛（Image.ring）、坡道（Image.is_ramp）、斑马线（ZebraHit）等赛道元素，并通过直道标志（Image.param_st）区分直道与弯道工况，供控制层切换参数。
4.3 转向控制设计
转向控制采用"PD + 误差平方项 + 陀螺仪角速度阻尼"的复合控制律，控制量计算公式为：
control = kp×error + kd×Δerror + err2_k×error²/10 − imu_d×gyro_z/100
其中：error 为图像中线偏差，Δerror 为偏差变化率（微分项），error² 项在偏差较大时提供更强的转向增益，提高大弯响应速度；gyro_z 为 IMU660RA 输出的车体偏航角速度，作为阻尼项抑制转向振荡。
针对直道、左转与右转三类工况分别配置独立的比例、微分、非线性增益和陀螺仪阻尼参数，由直道标志与偏差方向自动切换，兼顾直道稳定与弯道敏捷。控制输出经限幅后转换为舵机 PWM 占空比。
4.4 速度控制设计
速度闭环在 1ms 定时中断中执行，采用增量式 PI 控制器：
output = output_last + kp×(error − error_last) + ki×error
其中 error = target − read，read 由正交编码器四倍频计数测得，每个控制周期读取并清零。左右轮分别配置独立 PI 参数，输出经限幅后由 DIR 引脚与 PWM 实现双方向输出。
目标速度按直道、环岛、坡道和常规赛道等元素动态切换，由图像识别结果驱动，实现"直道快、弯道稳、坡道降速"的速度规划。
4.5 差速转向与阿克曼修正
转向执行采用"舵机 + 差速"协同方案：舵机负责前轮转向角，同时按转向角计算内外轮速差，实现阿克曼式转向。差速计算为：
speed_delta = speed × ackerman × tan(steer_angle) / 10000
转向时内轮减速、外轮保持，减小转向半径并降低轮胎磨损；直道与左右弯道分别采用独立阿克曼系数，兼顾弯道贴线与直道稳定。
4.6 风扇动态下压力控制
整车配备无刷风扇提供下压力。风扇转速按工况动态调整：直道降低下压力（减小风阻），弯道、环岛保持正常下压力（提高极限抓地），盲盒阶段关闭风扇。档位切换采用 3 帧防抖确认机制，避免图像抖动导致风扇频繁加减速。风扇启动时采用爬坡方式（fan_start_ramp）逐步升至目标转速，防止电流冲击。
4.7 目标识别与盲盒处理
雁过留痕组赛道包含目标识别任务。软件实现了基于二值图像的目标搜索逻辑：在图像中扫描目标区域，提取目标的中心位置、左右边界与上下边界（TargetCenterX/Y、TargetLeftX 等），结合帧间连续性进行确认，并通过激光模块（CAMERA_LASER_*）配合完成目标照射与击发动作（image_target_fire）。目标丢失时按帧间隔保持上一目标位置，避免误判。
赛道铺设紫外感光纸并绘制圆形目标区域。车模使用紫外激光头在目标区域内照射以留下痕迹，区域外不允许留下照射痕迹。程序根据目标在图像中的位置计算激光头工作位置，并结合帧间连续性确认结果，以降低偶发识别误差。
4.8 参数调试系统
控制参数包括转向参数、速度 PI 参数、各元素目标速度、风扇档位及摄像头阈值等，统一集中于参数结构体中管理，可在 IPS200 屏幕 UI 上在线修改，参数写入片上 Flash 掉电保存。调试界面支持图像显示模式切换（原图/二值图/扫线图），便于现场快速整定参数。具体参数数值不在本报告中公开。
第五章  开发工具、制作、安装、调试过程说明
5.1 开发工具
软件开发环境为 Keil MDK for C251（C251 编译器），基于逐飞科技 STC32G144K 开源库，源码版本控制采用 Git。调试工具包括 VOFA+ 串口上位机（波特率 115200）、逻辑分析仪与示波器，用于传感器数据监控与信号测量。
5.2 制作与安装过程
硬件设计使用嘉立创 EDA 完成原理图绘制与 PCB 布局，随后进行 PCB 打样、元器件焊接、通电检查与分模块测试。机械安装完成后，依次连接主控、电机驱动、摄像头、姿态传感器、激光模块和显示模块，并完成整车走线与绝缘防护。
5.3 调试过程
调试按"模块—系统"顺序进行：先分模块调试（电机开环、舵机回中、摄像头成像、IMU 读数），再联调图像处理（阈值、扫线效果），随后整定速度环 PI，最后整定转向 PD 参数与各元素速度。转向参数按"先直道后弯道"顺序整定，并用 IMU 阻尼项抑制高速振荡。

结  论
本队完成了雁过留痕组智能车模的设计与制作。整车以 STC32G144K 为控制核心，通过摄像头与 IMU 感知赛道信息，采用复合 PD 转向控制与增量式 PI 速度控制实现稳定循迹，并通过元素识别、差速转向、动态下压力与目标识别等设计满足了赛题要求。
在调试过程中也发现一些可改进之处：高速入环时图像易丢失、阈值自适应在强光下偶有波动、直道与弯道参数切换存在轻微衔接抖动等，后续可通过逆透视变换、更鲁棒的阈值算法与参数平滑过渡进一步优化。

A.1 核心控制流程
#include "headfile.h"

void main(void)
{
    clock_init(SYSTEM_CLOCK_114M);      // 时钟配置及系统初始化
    debug_init();
    para_init();
    flash_init();
    servo_init();      // IMU初始化（SPI通信）
    state_init();      // 状态初始化
    buzzer_init();
    motor_init();      // 仅初始化GPIO、PWM、编码器（不启动中断）
    image_init();      // 摄像头初始化（DMA + 中断）

    system_delay_ms(100);  // 等待所有外设稳定

    motor_start_control(); // 最后启动电机中断 + 风扇爬坡

    if(CarMode == CAR_MODE_UI)
    {
        ui_init();
    }
    while(1)
    {
        switch(CarMode)
        {
            case CAR_MODE_UI:   // 调试模式
            {
                if(ui_is_debug())
                {
                    image_update();
                    servo_update();
                }
                else
                {
                    image_update_laser_test();
                    pwm_set_duty(SERVO_PWM, SERVO_ANGLE_CENTER/3+1500);
                }
                ui_update();
            } break;

            case CAR_MODE_RUN:  // 运行模式
            {
                if(BlindBoxPhase != BLIND_BOX_STOP)
                {
                    image_update();
                }
                if(BlindBoxPhase == BLIND_BOX_STOP)
                {
                    servo_update_motor_target();
                    pwm_set_duty(SERVO_PWM, SERVO_ANGLE_CENTER/3+1500);
                    pwm_set_duty(FAN_PWM, 3000);
                    break;
                }
                servo_update();
                motor_update_fan();  // 动态调整风扇
            } break;

            case CAR_MODE_STOP: // 停止模式
            {
                pwm_set_duty(SERVO_PWM, SERVO_ANGLE_CENTER/3+1500);
                motor_output(0, 0);
                pwm_set_duty(FAN_PWM, 3000);
            } break;
        }
    }
}
A.2 速度 PID 控制与电机输出
/* 1ms 定时中断：增量式 PI 速度环 */
static void motor_timer(void)
{
    int16 error_left, error_right;
    int16 output_left, output_right;

    Motor.read_left  = encoder_get_count(ENCODER_LEFT);
    Motor.read_right = -encoder_get_count(ENCODER_RIGHT);
    encoder_clear_count(ENCODER_LEFT);
    encoder_clear_count(ENCODER_RIGHT);

    if(CarMode != CAR_MODE_RUN) return;

    error_left  = Motor.target_left  - Motor.read_left;
    error_right = Motor.target_right - Motor.read_right;

    /* 增量式 PI：输出 = 上次输出 + kp*(误差差) + ki*误差 */
    output_left  = Motor.write_left_duty +
        (SmartCar.motor.left_kp  * (error_left  - last_error_left)  +
         SmartCar.motor.left_ki  * error_left);
    output_right = Motor.write_right_duty +
        (SmartCar.motor.right_kp * (error_right - last_error_right) +
         SmartCar.motor.right_ki * error_right);

    last_error_left  = error_left;
    last_error_right = error_right;

    motor_output(motor_limit(output_left), motor_limit(output_right));
}

/* 电机输出：DIR 方向引脚 + PWM 占空比 */
void motor_output(int16 left_duty, int16 right_duty)
{
    Motor.write_left_duty  = left_duty;
    Motor.write_right_duty = right_duty;

    if(left_duty >= 0)
    {
        gpio_set_level(MOTOR_LEFT_DIR, GPIO_HIGH);
        pwm_set_duty(MOTOR_LEFT_PWM, left_duty);
    }
    else
    {
        gpio_set_level(MOTOR_LEFT_DIR, GPIO_LOW);
        pwm_set_duty(MOTOR_LEFT_PWM, -left_duty);
    }
    if(right_duty >= 0)
    {
        gpio_set_level(MOTOR_RIGHT_DIR, GPIO_LOW);
        pwm_set_duty(MOTOR_RIGHT_PWM, right_duty);
    }
    else
    {
        gpio_set_level(MOTOR_RIGHT_DIR, GPIO_HIGH);
        pwm_set_duty(MOTOR_RIGHT_PWM, -right_duty);
    }
}
A.3 转向控制算法
/* 复合转向控制：PD + 误差平方项 + IMU 角速度阻尼 */
void servo_update(void)
{
    int16 error, error_d, control;
    int16 kp, kd, err2_k, imu_d;

    if((Image.ready == 0) || (Image.result_ready == 0)) return;
    if(Image.sequence == ServoLastSequence) return;
    ServoLastSequence = Image.sequence;

    error   = Image.error;
    error_d = error - ServoLastError;

    /* 直道 / 左转 / 右转 三套参数 */
    if((Image.param_st != 0) && (Image.ring == 0) && (Image.is_ramp == 0))
    {
        kp = SmartCar.servo.st_kp;   kd = SmartCar.servo.st_kd;
        err2_k = SmartCar.servo.st_err2_k;  imu_d = SmartCar.servo.st_imu_d;
    }
    else if(error < 0)
    {
        kp = SmartCar.servo.left_kp; kd = SmartCar.servo.left_kd;
        err2_k = SmartCar.servo.left_err2_k; imu_d = SmartCar.servo.left_imu_d;
    }
    else
    {
        kp = SmartCar.servo.kp;      kd = SmartCar.servo.kd;
        err2_k = SmartCar.servo.err2_k;     imu_d = SmartCar.servo.imu_d;
    }

    imu660ra_get_gyro();
    if(error >= 0)
        control = (int16)(kp*error + kd*error_d
                    + (int32)err2_k*error*error/10
                    - (int32)imu_d*imu660ra_gyro_z/100);
    else
        control = (int16)(kp*error + kd*error_d
                    - (int32)err2_k*error*error/10
                    - (int32)imu_d*imu660ra_gyro_z/100);

    ServoLastError = error;
    ServoAngle = servo_limit(SERVO_ANGLE_CENTER - control);
    pwm_set_duty(SERVO_PWM, ServoAngle/3+1500);

    servo_update_motor_target();  /* 差速（阿克曼）修正 */
}
