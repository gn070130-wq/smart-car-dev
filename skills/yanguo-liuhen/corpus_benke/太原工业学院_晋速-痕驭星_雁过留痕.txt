摘要
本文介绍了太原工业学院智能车队为参加第二十一届全国大学生智能汽车竞赛“雁过留痕”组而设计的智能车系统。本车以大赛组委会统一提供的C型车模为基础，采用宏晶科技STC32G144K246作为核心控制单元。
在硬件方面，设计了以SCT2450为核心的降压电路为系统供电，利用DRV8701E驱动有刷电机，并自制了分电板以实现电源的高效管理。在传感系统上，采用MT9V034摄像头作为唯一的循迹传感器，配合ICM20602陀螺仪获取姿态信息，并通过3D打印定制件在前端安装了固定的激光发射装置用于打靶任务。
在软件与控制算法方面，通过摄像头采集赛道图像，利用大津法（Otsu）进行图像二值化处理，并结合“先找墙、再摸墙走”的搜线算法提取赛道边界。控制核心采用增量式PID算法对电机转速进行闭环调节，确保车模在高速行驶下的稳定性与精准度。本文详细阐述了该车模的机械结构优化、硬件电路设计、传感器信号处理及控制软件的实现过程，并对系统进行了全面的测试与验证。

关键词：智能车；STC32G；PID控制；图像处理；激光打靶；C车模

第二章 机械结构
2.1 车模平台与总体布局优化
本车选用竞赛标准C型车模作为基础平台，针对“高速自主循迹”与“精准激光打靶”的双重任务需求，对整车机械结构进行了系统性重构。设计核心遵循“极低重心、刚性强、免调试”三大原则。
整车采用分层立体布局：底层保留原厂底盘与传动系统，集中布置动力电池与大电流驱动器件；中层集成自制分电板与核心控制主板；上层及前探机构则承载视觉与任务执行模块。通过将高密度部件（如电池）紧贴底盘中心线布置，有效降低了整车质心高度，减小了高速转向时的转动惯量，为摄像头的稳定图像采集提供了坚实的机械基础。
2.2 前端激光架设计
车辆最前端的激光架采用高精度3D打印技术定制而成。这一设计具有三大显著优势：
1. 结构适配性与防撞功能：3D打印件能够完美贴合激光模组的外形尺寸，提供多点均匀支撑，相比传统通用夹具，大幅提升了激光管的抗振性能。同时该结构集成了防撞缓冲设计，能够在意外碰撞时吸收冲击能量，保护激光模组及车体内部结构。
2. 焦距确定性：该激光架在设计阶段即通过光学计算确定了最佳发射角度与高度，并利用3D打印的高成型精度，将焦距彻底锁定（固定）。激光角度确定不会乱动，保证所有的激光在发射时都在同一水平面，这意味着比赛过程中无需任何人工微调，彻底消除了因机械松动或人为误触导致的打靶偏差，实现了“即插即用”的高可靠性。
3. 方便拆卸更换：激光模组支持快速插拔，方便在赛前进行检测与更换，提升了维护效率。
2.3 视觉与姿态感知集成
为了实现精准的路径识别，在车辆的中前方使用碳纤维杆将摄像头高位架设起来。摄像头作为整车唯一的循迹传感器，其安装高度与俯仰角经过精密计算，既保证了足够的远眺距离以识别弯道曲率，又兼顾了近处盲区覆盖。碳杆的高强度特性确保了车辆在颠簸路面行驶时，摄像头相对车身的姿态角保持稳定，从物理层面消除了图像识别的抖动误差。
摄像头底座采用3D打印技术制作了坚固的基座，确保图像采集的稳定性。同时经过设计，陀螺仪模块也一起固定在基座前面，使得惯性测量单元与视觉系统的空间坐标系原点尽可能重合，极大地简化了视觉与惯性融合算法中的坐标转换复杂度。基座侧面连接打印件，并用扎带固定无刷电机驱动，结构紧凑且抗振性强。
2.4 无刷电机与电气封装
无刷电机的支撑架采用自行切割的碳纤维板，下面配有3D打印支撑件。该支架经过拓扑优化，不仅强度高，还专门设计了孔洞用于走线，使整车线路整洁有序，有效减少电磁干扰。此外，该支架同时也用于放置电池，最大化利用了车体空间。
分电板、主板和有刷驱动也通过自行设计的3D打印件全部装在一起，形成了一个稳固的核心电气模块。这种立体封装设计具有结构紧凑、抗振性强、维护便捷三大优势，保证了焊点与元器件在剧烈震动下的可靠性。
2.5 舵机转向与独立电源保障
转向系统采用原厂C车模的连杆机构，但针对舵机安装基座进行了加固处理，以减少虚位。执行机构选用高响应数字舵机，并由独立降压模块（SP1N28STER）专门供电。这种“动力电与逻辑电分离”的设计，彻底隔绝了舵机在频繁正反转及堵转时产生的巨大电流波动，防止了电源电压跌落，从而保护了摄像头与陀螺仪模块的供电纯净度。
2.6 线束管理与机械防护
考虑到激光打靶对精度的极致要求，整车在线束管理上采用了严苛的标准。所有传感器的连接线均采用高柔韧性硅胶线，并使用扎带沿碳杆及底盘边缘紧密固定，预留了充分的应力释放段，防止车轮摩擦或拉扯。强电（无刷电机、有刷电机）与弱电（激光、摄像头信号）线路在空间上严格分离，底层走动力线，上层走信号线，有效屏蔽了电机电火花产生的电磁干扰。

第四章 软件设计与实现
4.1 图像采集与处理
使用MT9V034全局快门摄像头（140度视角）获取原始的灰度图像。由于摄像头自身的特性和远小近大的视觉原理，图像会产生梯形畸变。每一个像素点都有一个从0至255的灰度值，值越大表示该像素点越亮，相反，越暗的像素点值就越小。

图 4.1.1  灰度图像展示
我们在对灰度图像进行处理的时候，为了便于观察和分析，经常需要将图像中的目标主体和背景分割开来，变成二值化图像(只有黑和白，黑白图像)。
最大类间方差是由日本学者大津(Nobuyuki Otsu)于1979年提出，是一种确定图像二值化分割阈值的算法。算法假设图像像素能够根据全局阈值，被分成背景[background]和目标[objects]两部分。然后，计算该最佳阈值来区分这两类像素，使得两类像素区分度最大。

大津法阈值采用最大类间方差的原理，适合于图像灰度分布整体呈现“双峰”的情况。大津法会自动找出一个阈值，使得分割后的两部分类间方差最大。
特性：大津法对噪音十分敏感，在处理之前应对图片进行去噪处理。如果图像有存在局部噪声，则会影响大津法的判断.
当目标与背景的面积比例悬殊的时候，类间方差函数可能呈现双峰或者多峰，这个时候 大津法的效果不好。针对大津法，破解内存与耗时痛点可以采用下采样，下采样核心就是「隔一行取一行、隔一列取一列」，直接将原图尺寸压缩一半，最终得到94×60分辨率的图像（188÷2=94，120÷2=60），后续仅用这张压缩后的图像，执行大津法阈值计算即可。而且邻两帧图像的最优二值化阈值差异极小，完全无需每帧都重复执行完整的大津法阈值计算，可通过“复用阈值”减少冗余操作。每10-20帧（可根据自身赛道的光照情况、赛道复杂度，灵活调整N值），执行一次完整的大津法阈值计算（即“计算帧”）；其余中间帧无需重复计算，直接复用上一计算帧得出的最优阈值（即“继承帧”）。

图 4.1.2  二值化处理图像及搜线处理
4.2 循迹算法设计
摄像头搜线算法就是获取赛道正确左右边界的一种方法。有传统的从中间往两边搜,生长算法等（4邻域，8邻域等）
我使用的搜线算法都是在传统的搜线算法上改进而来的，总体来说就是，针对遇到的问题进行修改。（参考龙邱科技方案）
核心就是“先找墙、再摸墙走”，具体分为3个简单步骤，对应程序的执行逻辑，没有复杂术语，直白易懂：
1找“墙根”——确定初始边界点：首先在图像的最底部（对应车辆近处的赛道，也是赛道最清晰、最容易定位的位置），从图像中间向左右两边搜索，找到黑白跳变点（黑色对应背景、白色对应赛道），这两个跳变点就是赛道的初始左边界和初始右边界，相当于我们摸到隧道墙壁的第一个触点。
2摸“墙走”——沿边界向上追踪：找到初始边界点后，程序就开始像我们摸隧道墙壁一样，顺着赛道边界向上追踪，每一步都会仔细检查当前像素的相邻像素（即八邻域范围），精准锁定下一个边界点，确保不偏离赛道轮廓。
3定“方向”——左右边界搜索有讲究：重点注意！左边界和右边界的搜索方向不一样，避免搜线跑偏，结合5×5细节示意图，具体顺序如下（记准这个顺序，调试不踩坑）：
左边界：采用逆时针搜索，顺序固定：先搜当前像素的右边 → 再搜右上角 → 接着搜上面 → 然后搜左上角 → 最后搜左边，搜到边界点后就停止，不再继续排查其他方向；
右边界：采用顺时针搜索（与左边界方向相反），按照对应对称顺序排查相邻像素，同样搜到边界点后停止，确保始终贴合赛道边缘追踪。
4.3 元素识别算法
在对图像进行最简单的预处理和赛道边界提取后，就可以开始进行元素识别了，十字的情况分为正入十字和斜入十字两种情况，根据视野中十字角点的数量也分为几种情况，要分别进行讨论。十字在所有元素中相对简单，因为即使不做识别和补线，仅仅依赖循迹也是可以通过的，但是为了防止其他元素在十字中的误判，还是需要对十字进行识别，锁定在十字中的状态；十字的特征主要就是四个90°的L形角点，抓住特征识别，误判率很低而且效果不错.
进环岛之前要先判断环岛---采用寻找下拐点的方法和判断左边为直线并且可以看到上拐点寻找下拐点需要判断赛道为黑白跳变（由于光 照影响会导致判断错误可加入额外条件--拐点上方有白块），左边线则是利用斜率和协方差判断，且出现上拐点，便可以判断圆环并且进行补线操作.
坡道与直道极其相似，正常情况下可识别图像远端左右边线差值的减小来识别坡道，但误判率较高，强烈建议有坡道的组别使用摄像头和TOF测距模块组合判断坡道。对于坡道的处理，正常电机闭环后可不必担心上不去坡的问题，所以可以不用识别坡道。但有些竞速组别要担心车速太快导致的飞坡问题，可识别到坡道后进行相应的处理，但胜负就在毫厘之间，避免出现适得其反的处理。
.因障碍物较小，很多车速较快的组别可能还未做出反应就已经走过障碍物。即使不识别障碍物，大多数组别车模都会适当做出避让。
 障碍物的识别比较容易误判，需谨慎处理，通常可识别黑色凸起区域并且出现右转上和上转左拐点（障碍物在赛道左半边），并且两点之间的Y坐标差值小于某一阈值。
斑马线可扫描固定行去识别，通常扫描图像中下部位的三行或两行，每两行之间有一定间隔，找左右边线内黑点个数，几行相加个数大于一定阈值判定为出现斑马线。
4.4 电机PID控制
在过程控制领域中，基于偏差比例（P）、积分（I）、微分（D）调节的PID控制器，是嵌入式智能控制场景中应用最为广泛的自动调控器件。本次雁过留痕组别传统四轮智能小车引入PID闭环控制算法，核心用于稳定小车行驶速度，保障车体匀速、平稳运行。
本小车四轮驱动电机由主控芯片输出PWM信号驱动控制。若采用纯开环控制方式，仅通过固定PWM占空比控制电机运转，小车行驶过程中会受地面摩擦力不均、电池电压衰减、四轮机械装配误差、路面颠簸等外界与硬件因素干扰，极易出现行驶速度不稳定、行走偏移、行驶距离精准度不足、直行轨迹歪斜等问题，无法满足精准行驶的控制要求，这也是开环控制模式的固有弊端。
为解决以上问题，小车搭载编码器实时采集四轮实际转速数据，构建闭环控制系统。系统将预设的目标行驶转速与编码器反馈的实际转速做对比，计算出速度偏差值，通过PID算法对偏差进行精准运算修正，实时调节电机PWM输出占空比，动态校正电机转速，以此补偿各类工况带来的速度误差。通过该闭环控制方式，彻底弥补了开环控制的缺陷，有效提升小车行驶的稳定性、匀速性与轨迹精准度。
代码节选
int16 PID_control(PID *P, uint16 aim, uint16 actual, uint16 *Last_sd)
{
    float PID_P, PID_I, PID_D;
    int16 increment;

    // 误差移位
    P->last_error  = P->next_error;
    P->next_error  = P->error;
    P->error       = aim - actual;

    // 增量式PID三项
    PID_P = P->Kp * (P->error - P->next_error);
    PID_I = P->Ki * P->error;
    PID_D = P->Kd * (P->error - 2*P->next_error + P->last_error);

    increment = (int16)(PID_P + PID_I + PID_D);
    P->out_value += increment;

    // 输出限幅
    if(P->out_value >= MOTOR_PWM_OUTPUT_MAX)
        P->out_value = MOTOR_PWM_OUTPUT_MAX;
    else if(P->out_value <= MOTOR_PWM_OUTPUT_MIN)
        P->out_value = MOTOR_PWM_OUTPUT_MIN;

    return P->out_value;
}
本增量式 PID 算法存在无符号数据相减易溢出、无积分抗饱和、微分噪声敏感的问题，易造成控制失效、超调与电机抖动。
针对上述问题，可将误差计算改为有符号运算规避溢出风险，增加输出积分限幅机制抑制积分饱和，同时对采样数据做滤波处理，削弱微分噪声干扰，提升控制稳定性
