摘要
本文介绍了韶关学院的队员们在准备此次比赛中的成果。本次比赛采用四轮C车模，主MCU采用STC公司的sct32g144k246，要求智能车在运行过程中用紫外激光完成打靶子的任务的同时，完整跑完全程。 
文中介绍了本次我们的智能车控制系统软硬件结构和开发流程，整个智能车涉及车模机械调整，传感器选择，信号处理电路设计，控制算法优化等许多方面。本次比赛采用总钻风摄像头对赛道信息进行检测，根据提取差比和得到赛道中线；通过编码器检测智能车的实时速度，使用PID控制算法调节电机的转速，实现智能车在运动过程中速度和方向的闭环控制，以及使用激光打靶；
为使车子能够达到更快的速度，提高其上限，我们在车上加了负压系统以增强车辆与地之间的摩擦力使其抓地力更强

第一章 系统整体设计
1.1系统概述
该系统总共包括 8个子系统：电源模块、主控制器模块、赛道采集模块、伺服器（舵机）控制模块、电机控制模块、调试模块、姿态传感器模块，激光模块。
1. 电源模块
	电源是整车运行的动力基础。系统采用标准的3S 锂电池（12.6V）作为主供电输入端，经过DC-DC降压电路和线性稳压电路进行转换：一路转化为 5V 供电，为激光等一些外设提供充足且稳定的工作电压；一路通过电位器转为6.1V为舵机提供工作电压，另一路精确降压至 3.3V，用于STC32G144K246主控芯片逻辑电平、总钻风摄像头以及姿态传感器等核心模块。设计中特别注重强弱电隔离与大电流滤波，有效抑制了电机换向时对控制电路的电源纹波干扰，保障了系统的运行稳定性。
2. 主控制器模块
	作为智能车的“大脑”，主控制器模块采用 STC32G144K246芯片。该芯片基于增强型8051内核，具备较高的运行主频和强大的处理能力。其内置的硬件16位乘除法器、高级PWM定时器以及多个独立串口，为图像数据的实时解析、电机四象限控制及多路传感器数据的融合处理提供了强大算力支撑。此外，其丰富的高速I/O口资源也极大地方便了各类外部模块的拓展与对接。
4. 赛道采集模块
	赛道采集模块主要由“总钻风”摄像头构成，负责感知赛场环境。摄像头以高帧率采集前方赛道的图像信息，并在STC32G144K246中进行边缘检测、二值化处理及赛道边界拟合。该模块在视觉前瞻和路径规划中起到决定性作用，为控制系统提供精准的横向偏差与赛道曲率数据，是车模实现稳定循迹的核心信息来源。
5. 伺服器（舵机）控制模块
	转向执行采用 DBS300 数字舵机。STC32G144K246 通过产生高精度、高分辨率的 PWM 控制信号对 DBS300 舵机进行实时驱动。配合精密定制的转向拉杆与阿克曼转向几何结构，实现了快速、准确的转向响应。该模块配合视觉反馈，在直道高速行驶和复杂连续弯道中，均能精准控制前轮角度，确保车模行驶轨迹贴合赛道中心。
6. 电机控制模块
	动力执行模块由C车模自带的直流电机和正交编码器以及自主设计的电机驱动电路组成。正交编码器与电机同轴安装，实时输出双路正交脉冲信号，由STC32G144K246内置的高速计数器进行正交解码，精确获取当前车速。主控通过 PID 闭环控制算法，动态调节驱动电路的 PWM 占空比，实现对电机输出扭矩的平滑调节，确保车模在加减速、过弯等不同工况下速度的稳定性。
7. 调试模块
搭配使用OLED显示屏，按键，无线串口等进行调参，快速对车辆进行启停操作、模式切换、PID参数在线修改以及行驶数据的实时回传与监测，极大地提高了车模的调试效率。
8. 激光模块
3d打印架子来固定逐飞出售的激光（7个到9个）架在舵机上方而不会挡到摄头。
第二章 机械系统设计与实现
2.1 前轮定位
前轮定位对赛车的速度有很大的影响，前轮定位作用还是不容忽视的。轮定位的内容有：主销后倾、主销内倾、前轮前束。好的前轮定位应该使车模在直道上行驶时没有太大阻力，并且在舵机旋转时不产生很大的垂直与地面的力，否则车模的上限速度会极大的收到影响。
2.1.1 主销后倾
转向轮（前轮）围绕主销进行旋转，前轴的轴荷通过主销传给转向轮，具备这两点的就叫做主销。主销向后倾斜，主销轴线与地面垂直线在赛车纵向平面内的夹角称为主销后倾。如图2.1所示：

   图2.1 主销后倾示意图
前轮重心在主销的轴线上，由于主销向后倾斜使前轮的重心不在车轮与地面的接触点上，于是产生了离心力，主销后倾形成的离心力，可以保证汽车直线行驶的稳定性，还可以帮助车轮自动回正。
2.1.2 主销内倾
主销在横向平面内向内倾斜，主销轴线与地面垂直线在赛车横向断面内的夹角称为主销内倾角。主销内倾角也有使轮胎自动回正的作用，当汽车转向轮在外力作用下发生偏转时，由于主销内倾，则车轮连同整个汽车的前部将被抬起一定高度，在外力消失后，车轮就会在重力作用下力图恢复到原来的中间位置。但主销内倾角不宜过大，否则在转弯时轮胎将与赛道间产生较大的滑动，从而会增加轮胎与路面间的摩擦阻力，使转向变得沉重，同时会加速轮胎的磨损。经过反复的试验，我们大约主销内倾了 5°。
2.1.3 前轮前束
通过车轮中心的汽车横向平面与车轮平面的交线与地面垂线之间的夹角，称为前轮外倾角。前轮外倾角是前轮的上端向外倾斜的角度，如果前面两个轮子呈现“V”字形则称正倾角，呈现“八”字则称负倾角。前轮外倾可以抵消由于车的重力使车轮向内倾斜的趋势，减少赛车机件的磨损与负重。前轮前束是前轮前端向内倾斜的程度，当两轮的前端距离小后端距离大时为内八字，前端距离大后端距离小为外八字。由于前轮外倾使轮子滚动时类似与圆锥滚动，从而导致两侧车轮向外滚开。但由于拉杆的作用使车轮不可能向外滚开，车轮会出现边滚变向内划的现象，使用内八字有助于车模在直道行进的过程中更加贴合中线。
2.2 车模重心
车模重心的高低及前后、左右分布，直接决定了车辆高速过弯和急加减速时的稳定性。
2.2.1高度控制
整车采用尽可能低的重心设计。电池、电路板等大质量部件均紧贴车模底盘安装。通过调整底盘与碳纤维层之间的支撑铜柱高度，将整车底盘离地间隙控制在合理的低区间，有效降低了整车重心高度，减少了侧倾力矩。
2.2.2重量分布
核心动力源（7.4V锂电池）放置于车模底盘几何中心的偏后位置（约[XX]mm处），通过高粘性魔术贴和尼龙扎带进行双重固定。主控电路板搭载于车体上层碳纤维支架，在追求轻量化的同时，确保重量分配均匀，防止左右偏载。
2.2.3重心验证
组装完成后，通过“指压平衡法”初步寻找重心位置，并配合实际跑道试跑，微调电池和配重块的位置。最终将重心控制在前后轮轴距的[38%~42%]之间（偏向于后轴），有效避免了起步抬头和刹车时车头猛烈下压造成的抓地力突变。
2.4 伺服器（舵机）安装
   经典的舵机安装有立式和卧式两种方法，我们学校经过大量的测试，各队均选择的是舵机的立式安装，原因如下：(1)首先，立式安装的舵机在响应速度方面远胜于卧式舵机，这对于车模在弯道处的转弯性能有着很大的提升。(2)其次，对于比赛选手而言，立式舵机的伺服中值很好确定，也利于车模发生故障后快速的恢复和调节。(3)车模转向时最大程度符合阿克曼转角是车模轮胎前束的最优解，经过反复比较，我们发现卧式安装的舵机在当舵机臂长度与转角臂长度相等时会导致内、外侧轮不符合阿克曼转角，这当然是我们所不希望看到的。
2.5 速度传感器（编码器）安装
编码器是用来对车速进行测算的仪器，目前很多学校使用的是通过光电编码的编码器，其精度较高、安装较为方便，但体积有点大。光电编码器的安装精度较高，要求编码器轴与赛车后轴同轴，且编码盘必须与赛车的中心线共线。我们是直接装在车上，利用齿轮与差速器上的大齿轮相咬合。这种安装方法方便快捷，更能较准确的测出电机的转速。
2.6 摄像头固定
同轴安装：鉴于采用的是C车模自带的直流电机，编码器设计为与电机尾轴同轴固定。通过[高精度弹性联轴器/特制CNC固定座]将正交编码器紧密连接于电机尾部伸出轴上，确保电机旋转时编码器能同步且无滑移地转动。垂直度与同心度校准：安装过程中，使用夹具严格校准编码器轴与电机轴的同心度，避免因不同心导致的码盘摩擦、卡滞或脉冲丢失问题。
抗振防护：编码器接线端使用[航空插头或排线]引出，并在靠近编码器处使用扎带将线缆固定在车架上，防止高速运行时线缆抖动对编码器信号产生干扰，保证正交脉冲信号高保真地传输至STC32G144K246主控芯片。
2.7 电池的固定
由于电池可以影响重心的位置， 同时要求易于拆卸， 因此， 我们采用设计了一个电池仓进行固定， 即使车子需要很大的向心力， 也可以保持稳定， 而且易于拆卸。
2.8 负压的实现
负压风扇的加入，大大提高了原c车模的上限，我们在车底盘中央靠前的地方放置5寸三叶桨，采用朗宇无刷电机，利用涵道效应来产生负压力。

4.6 控制思路


4.6.1 舵机整体控制思路
经多组PWM频率对比测试，我们确定采用 300Hz 的PWM控制信号驱动BDS300舵机，在保证其稳定运行的同时获得了更快的动态响应。在每个控制周期内，图像处理完成后，系统首先根据赛道类型辨识结果与编码器反馈的实际车速，综合决策最优舵机打角行；随后计算该行的中线偏移量作为偏差输入，代入位置式PD控制器进行运算；控制器输出叠加舵机中值后，经舵机极限位置（±560）限幅处理，得到最终的舵机控制量并输出执行。整体控制流程如图4.10所示：

4.6.2 舵机PD计算式
舵机控制采用位置是PID，由于I项（积分项）不适用与舵机的控制中，于是我们只使用了位置式的PD项，控制公式如下：
lt=servo_Kp*error_current+servo_Kd*(error_current-error_last)-imu660ra_gyro_z*servo_Wjh+abs(error_current)*error_current*servo_Kp2。
4.6.3 动态打角行的选取
我们之所以采用动态的打角行由于车模不是处于匀速的运动中，不能够通过固定的打角行来计算偏差。我们采用根据读取编码器的速度返回值来给取合适的打角行的高度，其策略是速度越快打角行越高，速度越慢打角行越低，目的是使不同的速度下小车的路径相近，达到小车整体的闭环控制。
4.6.4 不同元素的舵机PD选取
对于不同的元素我们通过图像所获取的截至行来判断当前车子所处的赛道情况，截至行由高到低可以依次对应车子进入长直道，短直道，缓弯，急弯的情况，根据截至行的大小我们给予不同的PD值，在直道上PD值要给小，保证直道不会抖动，在弯道上PD值要给大，保证弯道可以内切不会出界。
4.6.5 不同元素的速度控制策略
经过智能车的多次调试，我们认为采用直道加速，弯道减速的方案可以提高智能车的稳定性并且整体速度更快，我们通过截至行来判断直道和弯道，当车子从直道进入弯道的时候，我们通过中线偏移的误差来使小车逐渐减速，避免了速度猛加猛减的情况。
4.6.6 车模的电机PI控制
我们的电机采用增量式PID控制，我们只使用了PI项，其中I项能够加快电机响应，P项能够减少稳态误差，控制公式如下:
duty_L += Kp * (err - last_err_R) + Ki * err;
duty_R += Kp * (err - last_err_R) + Ki * err。


第五章 智能车调试说明

5.1 vofa调试软件的设计
VOFA+ 是一款插件驱动的高自由度上位机软件，在嵌入式调试与工业控制中充当人机交互界面（HMI）。它通过串口、TCP/UDP 等通信接口与下位机建立数据连接，实时采集并可视化呈现现场设备的运行状态；当现场设备出现异常时，即可在界面上直观反映各设备之间的状态信息（如正常、报警、故障等），便于快速定位与诊断问题。
从计算机集散控制系统（DCS）的层级架构来看，直接与现场设备发生数据交互、执行底层控制任务的计算机属于下位机；VOFA+ 则作为上位机监控层，负责向下位机发送控制指令或参数配置，同时接收下位机上传的状态反馈，实现对系统的远程监控与动态调参。若集散控制系统规模较大，计算机层级可能超过两级，此时上位机之上还可能存在更高级别的管理计算机进行统一调度与任务指派。图 5.1 为 VOFA+ 的软件界面。

void Motor_Control_(int Speed_L, int Speed_R)
{
static int last_err_L = 0, last_err_R = 0, duty_L = 0,duty_R = 0;
    int err;
   
     if(motor_coast)
    {
        pwm_set_duty(MotorL_pwm, 0);
        pwm_set_duty(MotorR_pwm, 0);
        return;   
    }
 
    err = Speed_L - encoder_speed_L;
    duty_L += Kp * (err - last_err_L) + Ki * err;
    last_err_L = err;
    if(duty_L >  9999)  duty_L =  9999;
    if(duty_L < 0)  duty_L = 0;  
    
    err = Speed_R - encoder_speed_R;
    duty_R += Kp * (err - last_err_R) + Ki * err;
    last_err_R = err;
    if(duty_R >  9999)  duty_R =  9999;
    if(duty_R < 0)  duty_R = 0;
    
    MotorL_SetSpeed(duty_L);
    MotorR_SetSpeed(duty_R);
}
