摘  要
本文介绍了河南工程学院“长按加速车队”参加第二十一届全国大学生智能汽车竞赛雁过留痕组的智能车系统设计方案。本车以博思威龙 C 车模为运动平台，采用逐飞科技 STC32G144K246 核心板作为主控制器，以 MT9V03X 灰度摄像头作为赛道与靶环信息的主要感知传感器，配合逐飞 1024 线正交编码器与 IMU660RA 六轴姿态传感器，实现了对赛道和打靶目标的可靠检测；动力系统采用基于 DRV8701E 栅极驱动芯片与 TPH1R403NL 场效应管的双路 H 桥驱动方案，实现左右后轮的独立驱动与差速控制。
针对雁过留痕组“紫外感光纸留痕”的特殊任务，本车设计了由 5 路固定角度排列的紫外激光模块组成的打靶装置，通过图像实时检测感光纸上的圆形靶环，并根据靶环位置选择对应角度的激光分时触发，实现行驶过程中的稳定打靶留痕。在软件上，基于逐飞开源库完成了图像采集、大津法二值化、赛道搜线与元素识别、靶环检测、速度环与转向环闭环控制以及人机交互等模块的设计与调试。
经实际测试，整车重量 1467g，外形尺寸（含传感器）为长 30cm、宽 19cm、高 40cm，系统运行稳定，能够在室内 PVC 赛道上稳定循迹并完成留痕任务，验证了本方案的可行性与可靠性。
关键词：STC32G144K246；图像处理；大津法；PID 控制；紫外激光打靶

第一章 引言
1.1 智能车竞赛简介
全国大学生智能汽车竞赛是受教育部高等教育司委托，由教育部高等学校自动化专业教学指导分委员会创办的面向全国大学生的探索性工程实践活动，并于 2020 年起由中国自动化学会作为主办单位。竞赛以“立足培养、重在参与、鼓励探索、追求卓越”为指导思想，以迅猛发展、前景广阔的汽车电子为背景，涵盖自动控制、模式识别、传感技术、电子、电气、计算机、机械与汽车等多学科专业，旨在培养大学生的综合知识运用能力、基本工程实践能力和创新意识。
竞赛要求参赛队员组成团队，综合运用多学科知识，设计制作能够在特定赛道上自主行驶且具有优越性能的智能模型汽车，并完成从理论设计、实际制作、整车调试到现场比赛的全过程。本文结合第二十一届全国大学生智能汽车竞赛雁过留痕组的规则要求，从机械、电路和软件三个方面对本车模的设计与实现进行具体阐述。
1.2 雁过留痕组规则
雁过留痕组是第二十一届全国大学生智能汽车竞赛新增的竞速组别，每支参赛队由 3 名学生组成，主控限定使用 STC 系列单片机。比赛场地为室内 PVC 赛道，赛道规格与第二十届竞赛相同：赛道宽度不小于 45cm，包含直道、弯道（曲率半径不小于 50cm）、十字交叉路口、环岛、坡道、红砖色路障、发车斑马线以及锥桶等基本元素，车模需要在赛道上自主运行一周。
除常规循迹外，雁过留痕组还设置“留痕”辅助任务：赛道上铺设 1~5 张紫外感光纸，纸上以激光打印有中心线半径为 5cm、线宽为 1cm 的圆形；车模需要识别感光纸上的圆形，并通过紫外激光照射圆形内部，留下长度不小于 1cm、肉眼可辨析的变色斑痕；若斑痕落在圆形之外，则视为该留痕任务失败。留痕任务是竞速赛的辅助任务，遗漏 M 个留痕任务，比赛成绩将在原有竞速成绩上增加 5×M 秒。
因此，本车模不仅要实现高速稳定的赛道循迹，还需要具备靶环的可靠识别与打靶留痕能力。本文第三章、第四章将分别对硬件电路中的激光打靶装置和软件中的靶环检测与打靶策略进行详细介绍。

第二章 机械系统的设计与实现
2.1 整车总体布局
本车选用博思威龙提供的四轮 C 车模作为运动平台，驱动电机采用车模原装电机。整车（含传感器）外形尺寸为长 30cm、宽 19cm、高 40cm，总重量 1467g。机械设计的总体目标是降低整车重心、保证结构强度并简化布局，为高速循迹和打靶留痕提供稳定的机械基础。
在布局上，电池安装于车体中部以平衡前后配重，主板安装于车体后部并紧贴重心位置，摄像头通过碳杆固定于车头以获得开阔视野，5 路紫外激光模块以固定角度排列安装于车头前方，编码器安装于后轮轴处用于采集实时车速。整车总体布局及各关键模块安装照片见附录 C。
2.2 摄像头的安装
摄像头是车模感知赛道与靶环的主要传感器，其安装高度和角度直接影响图像的有效视野。本车采用轻便坚固的碳素杆作为支撑杆，将摄像头固定于车头前方较高位置，使镜头能够同时覆盖近处的赛道引导线和感光纸靶环区域；摄像头底座采用铝合金件固定，保证高速运行和振动工况下的图像稳定性。摄像头安装特写照片见附录 C。
2.3 紫外激光打靶装置的安装
雁过留痕组的留痕任务要求车模在行驶过程中对感光纸上的圆形靶环进行紫外照射。考虑到云台结构会增加重量、占用空间并提高控制复杂度，本车采用无云台的固定式打靶方案：将 5 个逐飞科技紫外激光模块按不同俯仰/偏转角度固定安装于车头前方的一排支架上，使各激光的出射方向在车模前方形成扇形覆盖区域，从而在车模以不同横向位置通过感光纸时，总有一路激光能够对准靶环内部。
5 路激光由主板上的 5 路开关电路独立控制，软件根据靶环在图像中的位置和车模当前速度，选择对应角度的激光并在合适的时机触发，实现“识别靶环—选择激光—定时触发”的完整打靶流程。固定角度方案结构简单、响应快，经实际测试能够稳定完成留痕任务。激光装置安装照片见附录 C。
2.4 电池与电路板的安装
电池选用 3S 锂电池（2200mAh），通过魔术贴固定于车体中部，尽量降低重心并方便更换。主板与驱动板通过铜柱固定于车体底盘后部，紧贴整车重心位置；各模块采用接插件与主板连接，既保证了电气连接的可靠性，也便于维护和更换。电池与电路板安装照片见附录 C。
2.5 重心调整与轻量化
车体重心位置对加减速性能、转向性能和稳定性有较大影响。设计中通过将电池、电路板等较重部件尽量贴近底盘并居中布置，降低整车重心；同时采用碳杆、铝合金件等轻质材料进行支撑结构设计，控制整车重量为 1467g，在保证结构强度的前提下尽量提高速度上限。

第三章 硬件电路的设计与实现
3.1 整体方案
本着可靠、高效、简洁、节约的设计原则，本车电路系统采用“主控核心板 + 自制主板 + 自制驱动板”的模块化架构。主控部分直接采用逐飞科技开发的 STC32G144K246 核心板，避免自行设计最小系统；自制主板完成电源管理、外设接口与激光驱动等功能；自制驱动板完成双路电机驱动。电路系统整体方案如图 3.1 所示。

图 3.1 电路系统整体方案框图
3.2 主控核心板
雁过留痕组限定使用 STC 系列单片机，本车选用逐飞科技基于 STC32G144K246 芯片开发的核心板。STC32G144K246 采用增强型 8051 内核，集成 DSP 指令与浮点/三角函数数学协处理器，主频高、外设资源丰富，可同时满足图像处理、编码器测速、舵机/电机 PWM 控制以及激光打靶等多任务需求。核心板引出全部 GPIO 引脚，通过主板上的双排插座与主板连接，供电由主板提供 3.3V。
3.3 电源系统的设计
整车由 3S 锂电池（2200mAh，工作电压约 11.1V~12.6V）供电。根据各模块的供电需求，电源系统分为四路：
（1）5V 主电源：采用 SCT2450 降压芯片，将电池电压降压为 5V（VCC5V），供编码器、蜂鸣器、按键等外设使用；
（2）3.3V 主控电源：采用 TPRT9013-33 低压差线性稳压芯片，将 5V 稳压为 3.3V，供 STC32G144K246 核心板使用；
（3）3.3V 摄像头电源：采用另一路 TPRT9013-33，将 5V 稳压为 3.3V（VCCCAM），为摄像头单独供电，避免与主控电源相互干扰；
（4）舵机电源：采用 SCT2450 降压芯片，输出可调电压（VCCSERVO）为转向舵机供电，保证舵机响应速度与输出力矩。
此外，主板还设计了 SY6280A 负载开关用于外设 5V（VCC5V_EXT）的独立通断控制，并设置电压测量电路实时监测电池电压。为抑制电机启动和激光触发时造成的电压跌落，各电源输出端均配置了足够的滤波电容，全板电容总容量约 800μF（主板约 675μF、驱动板约 126μF），其中 220μF 母线电容用于抑制电机换向与激光触发时的电压波动；电路总功耗约 12W（典型工况）。
3.4 电机驱动电路
驱动电路采用逐飞/龙芯组同源的 DRV8701E 双路 H 桥方案：两块 DRV8701E 栅极驱动芯片各配合 4 只 TPH1R403NL 场效应管构成半桥，组成左右两路独立的 H 桥拓扑，实现左右后轮电机的独立控制与差速转向。DRV8701E 内部集成电荷泵，无需外部升压电路即可满足栅极驱动需求；TPH1R403NL 导通电阻仅约 1.7mΩ（VGS=4.5V），大电流工作时发热低，驱动效率高。
驱动信号与单片机之间增加 74HC125 缓冲芯片进行隔离缓冲，避免驱动电路与单片机 I/O 直接连通，有效保护主控；桥臂续流采用 1N5819 肖特基二极管，电源端配置 100nF、1μF、10μF 等多级去耦电容，保证驱动电路在大电流工况下的稳定性。驱动板通过排针与主板连接，接口定义包括 L_PH/L_EN、R_PH/R_EN 等控制信号。驱动电路原理图详见附录 C。
3.5 传感器与外设电路
摄像头接口：主板为 MT9V03X 摄像头提供独立 3.3V 供电和接口插座，并采用 AL422B 视频缓存芯片完成图像数据的缓存与读取，配合摄像头驱动实现图像采集；
编码器接口：两路正交编码器接口用于连接逐飞 1024 线编码器，采集左右后轮转速，实现速度闭环；
姿态传感器接口：预留 IMU660RA 六轴姿态传感器接口，用于车身姿态反馈与转向辅助；
激光驱动电路：5 路紫外激光由 AO3400 MOS 管开关电路独立控制，每路配有限流电阻与下拉电阻，由单片机 GPIO 控制通断，实现激光的分时触发；
人机交互电路：包括 IPS200 显示屏接口、按键、蜂鸣器驱动（S8050）、无线串口接口等，用于参数显示、模式切换与调试通信；
其他接口：预留无刷电调接口、有刷电机接口、舵机接口和电压测量接口，便于功能扩展。
3.6 PCB 的设计与制作
主板与驱动板均使用嘉立创 EDA 绘制，其中主板原理图分为电源、外设、主控三页，驱动板为一页。PCB 采用两层板设计，铺铜与阻焊层按功能分区布置，电源部分与信号部分分区走线，降低相互干扰。自制板丝印层标记有“河南工程学院 · 长按加速车队”及制作日期，满足竞赛技术检查要求。各电路板 3D 视图与实物照片、原理图详见附录 C。

第四章 软件系统的设计与实现
4.1 整体方案
高效的软件程序是智能车高速平稳运行的基础。本车软件基于逐飞科技 STC32G144K246 开源库开发，开发环境为 Keil C251。软件总体采用“主循环 + 定时器中断”的结构：定时器中断以固定周期完成编码器测速、速度环与转向环控制，主循环完成图像采集、图像处理、赛道元素识别、靶环检测与打靶决策。整体流程如图 4.1 所示。

图 4.1 软件系统总体流程图
4.2 图像采集与二值化
摄像头选用 MT9V03X 数字灰度摄像头，采集分辨率为 188×120 的灰度图像。由于赛道由白色引导线和蓝色背景构成，图像处理首先对灰度图像进行二值化处理，将赛道与背景分离。二值化阈值的选取采用大津法（最大类间方差法）自动计算，以适应不同场地和光照条件；对于光照稳定的场景，也可以使用固定阈值以降低计算量。
考虑到 STC32G144K246 的算力资源有限，在保证识别精度的前提下，对大津法进行了优化：一是对图像进行下采样（隔行隔列取点，将 188×120 图像降为 94×60）后再计算阈值，将阈值计算量降为原来的 1/4；二是采用“计算帧 + 继承帧”策略，每间隔 N 帧执行一次完整的大津法计算，中间帧直接复用上一帧阈值，进一步降低计算负载。优化后单帧图像处理耗时明显下降，有效提高了系统帧率。
4.3 赛道搜线与中线提取
完成二值化后，采用八邻域搜线算法对赛道左右边界进行提取：从图像底部（车模近处）中间向两侧搜索黑白跳变点作为初始边界点，然后按照左边界逆时针、右边界顺时针的邻域搜索规则，沿赛道边界逐行向上追踪，得到完整的左右边界轨迹；当赛道边沿丢失时，根据赛道宽度进行补线处理，保证中线计算的连续性。
得到左右边界后，取左右边界点的中点作为赛道中线，并采用多行偏差加权平均的方式计算车模相对赛道中心的位置偏差，提高偏差计算的稳定性；同时根据车速动态调整参与计算的视野范围，车速越高，取点越远，为高速循迹提供超前的转向信息。

图 4.2 赛道搜线效果图
4.4 赛道元素识别与处理
针对赛道中的十字交叉路口、环岛、坡道、路障、发车斑马线等元素，软件采用状态机的方式分状态识别与处理：将车模驶过每个元素的过程划分为若干状态，通过标志位区分状态，并对每个状态采取特定的处理策略，避免同一元素不同路段或相似路段之间的误判。
其中，十字路口根据四向边沿特征识别并保持直行；环岛根据边沿曲率与丢线特征识别，并结合补线策略完成入环、环内与出环；坡道与路障通过图像中边沿高度的突变识别，适当减速平稳通过；发车斑马线用于识别起点/终点位置，实现停车与计时控制。
4.5 靶环检测与激光打靶
靶环检测是雁过留痕组软件设计的核心内容之一。感光纸上的圆形靶环在图像中表现为特定的黑白跳变特征，软件在赛道左右边界之间搜索靶环：采用黑白跳变检测方法，从左右边界之间的水平区域搜索第一个由黑变白和第一个由白变黑的跳变点作为靶环的左右边界，并验证宽度约束；再以候选中心为起点向上、向下搜索上下边界，最终确定靶环中心坐标。对于靶环与赛道宽度差异明显的场景，也可采用最长白列特征法或黑点坐标平均法进行检测。
激光打靶采用“固定角度、分时触发”的策略：5 路紫外激光分别覆盖车模前方不同横向区域，软件根据靶环中心在图像中的横坐标判断其位于哪一路激光的覆盖范围内，并结合靶环纵向位置估算车模到达靶环正上方的时刻；当车模到达预定触发位置时，单片机通过 GPIO 开启对应激光，对感光纸圆形内部进行短时照射，留下长度不小于 1cm 的变色斑痕。打靶完成后关闭激光，防止在圆形外部留下斑痕导致任务失败。
考虑到车模高速运行时图像处理帧率有限，打靶触发采用“提前量 + 定时”方式：在检测到靶环后立即记录靶环位置与当前车速，预测触发时刻，由定时器中断在精确时刻触发激光，保证打靶时机与位置的一致性。

4.6 运动控制
车模的运动控制分为速度控制与转向控制两部分。速度控制以逐飞 1024 线编码器采集的转速为反馈量，采用增量式 PID 算法控制电机 PWM 占空比，使车速稳定在目标值附近；转向控制根据赛道偏差计算舵机打角，采用 PD/模糊 PID 控制算法，兼顾转向响应速度与稳定性，使车模在高速弯道中保持良好的走线。
由于左右后轮由两路 H 桥独立驱动，转向控制同时结合左右轮差速，通过“舵机转向 + 差速辅助”的方式提高弯道通过能力。控制周期与图像处理帧率相匹配，保证控制的实时性。
4.7 人机交互与调试
为便于调试，软件设计了人机交互模块：IPS200 显示屏用于显示摄像头图像、赛道搜线结果、靶环检测结果以及 PID 参数和车速等实时数据；按键用于模式切换与参数调节；蜂鸣器用于元素识别与打靶成功的提示；无线串口用于与上位机通信，配合逐飞助手实现图像与波形的实时显示。
调试过程中主要包含三个方面：一是图像调试，通过上位机观察二值化与搜线效果，调整阈值计算策略与搜线参数；二是控制参数整定，通过波形显示逐步整定速度环与转向环的 PID 参数；三是打靶标定，在场地中实测各激光的角度覆盖范围与触发提前量，确定打靶策略参数。

6.2 优点
在机械设计上，整车布局紧凑，重心低、重量轻，为高速循迹提供了稳定的机械基础；固定式 5 路激光打靶方案结构简单、响应快，避免了云台方案的复杂控制。
在电路设计上，采用模块化设计，主控核心板与自制主板、驱动板分离，便于调试与维护；电源系统多级稳压，保证了摄像头、主控等关键模块供电的稳定性。
在软件设计上，采用大津法自动阈值并针对 STC32G144K246 的算力进行了下采样与帧间采样优化，保证了图像处理的实时性；靶环检测与打靶策略将图像识别与控制定时相结合，实现了稳定的打靶留痕。
6.3 缺点与改进方向
本车模仍存在以下不足与改进方向：一是固定角度激光打靶对靶环位置变化的自适应能力有限，后续可研究多角度动态选择或小型云台方案，提高打靶命中率；二是图像处理在强光、反光环境下仍可能受到干扰，可进一步研究 Canny/Sobel 边缘检测与动态阈值策略；三是高速工况下的转向稳定性仍有提升空间，可研究模糊 PID 参数自整定等更先进的控制算法；四是主板目前为双层板，摄像头并行数据总线与电机驱动、电源开关电路同板，后续可考虑升级为四层板以提供完整地平面，进一步改善信号完整性与电磁兼容性。

A-2 图像采集与二值化（大津法）
二值化采用自适应大津法：先统计灰度直方图，再遍历所有灰度级搜索使类间方差最大的阈值，避免固定阈值在光照变化时失效。
// image_process.c —— 大津法二值化（示意代码）
static uint8 otsu_threshold(uint8 *gray, uint16 size)
{
    uint32 hist[256] = {0};
    uint32 total = 0, sum = 0, sum_b = 0, w_b = 0;
    uint32 max_var = 0;
    uint8 th = 0, i;
 
    for (i = 0; i < size; i++) hist[gray[i]]++;
    for (i = 0; i < 256; i++) { total += hist[i]; sum += i * hist[i]; }
    for (i = 0; i < 256; i++)
    {
        if (hist[i] == 0) continue;
        w_b += hist[i];
        sum_b += i * hist[i];
        uint32 w_f = total - w_b;
        if (w_f == 0) break;
        uint32 m_b = sum_b / w_b;
        uint32 m_f = (sum - sum_b) / w_f;
        uint32 var = w_b * w_f * (m_b - m_f) * (m_b - m_f);
        if (var > max_var) { max_var = var; th = i; }
    }
    return th;
}
 
void image_binarize(void)
{
    uint8 th = otsu_threshold((uint8 *)image, MT9V03X_W * MT9V03X_H);
    uint16 i;
    for (i = 0; i < MT9V03X_W * MT9V03X_H; i++)
        binary[i / MT9V03X_W][i % MT9V03X_W] =
            (image[i / MT9V03X_W][i % MT9V03X_W] > th) ? 255 : 0;
}
A-3 赛道搜线与中线提取
从图像底部向上逐行搜索黑白跳变沿得到左右边界，取中点作为中线；丢线行使用上一行中线外推，保证控制量连续。
// line_find.c —— 逐行搜线与中线提取（示意代码）
int16 line_left[MT9V03X_H], line_right[MT9V03X_H], mid_line[MT9V03X_H];
 
void find_line(void)
{
    int16 row, col;
    for (row = MT9V03X_H - 1; row >= 0; row--)
    {
        int16 left = -1, right = -1;
        for (col = mid_line[row + 1] - 20; col > 0; col--)
            if (binary[row][col] == 0 && binary[row][col - 1] == 255)
            { left = col; break; }
        for (col = mid_line[row + 1] + 20; col < MT9V03X_W - 1; col++)
            if (binary[row][col] == 0 && binary[row][col + 1] == 255)
            { right = col; break; }
        if (left >= 0 && right >= 0)
        {
            line_left[row] = left;
            line_right[row] = right;
            mid_line[row] = (left + right) / 2;
        }
        else
        {
            mid_line[row] = mid_line[row + 1];   // 丢线外推
        }
    }
}
A-4 赛道元素识别
根据中线突变与边界宽度变化区分十字、环岛等元素，并设置元素标志供控制策略使用。
// element.c —— 十字 / 环岛识别（示意代码）
uint8 element_flag = 0;
 
void element_judge(void)
{
    int16 mid_delta = mid_line[MT9V03X_H - 20] - mid_line[MT9V03X_H - 60];
    int16 width = line_right[MT9V03X_H - 20] - line_left[MT9V03X_H - 20];
    if (abs(mid_delta) < 8 && width > 140)       // 中线不偏且赛道明显变宽
        element_flag = ELEMENT_CROSS;
    else if (ring_enter == 1 && ring_exit_confirm())
        element_flag = ELEMENT_RING_EXIT;
    else if (ring_enter == 0 && ring_enter_confirm())
    {
        element_flag = ELEMENT_RING_ENTER;       // 检测到环岛入口
        ring_enter = 1;
    }
}
A-5 靶环检测与激光打靶控制
靶环在二值图中表现为高亮圆斑，通过统计包围盒中心与半径实现检测；根据靶环相对图像中心的横向偏差选择对应角度的激光并定时触发。
// target.c —— 靶环检测与激光触发（示意代码）
typedef struct { int16 cx, cy, radius; } target_t;
target_t target;
 
void target_detect(void)
{
    int16 x, y, min_x = MT9V03X_W, max_x = 0, min_y = MT9V03X_H, max_y = 0;
    for (y = 0; y < MT9V03X_H; y++)
        for (x = 0; x < MT9V03X_W; x++)
            if (binary[y][x] == 255)
            {
                if (x < min_x) min_x = x;
                if (x > max_x) max_x = x;
                if (y < min_y) min_y = y;
                if (y > max_y) max_y = y;
            }
    target.cx = (min_x + max_x) / 2;
    target.cy = (min_y + max_y) / 2;
    target.radius = (max_x - min_x) / 2;
}
 
void laser_fire_judge(void)
{
    if (target.radius < 8) return;               // 未检测到有效靶环
    int16 off = target.cx - MT9V03X_W / 2;
    uint8 idx = (off < -40) ? 0 : (off < -15) ? 1 :
                (off > 40) ? 4 : (off > 15) ? 3 : 2;
    if (car_speed > 200)                          // 接近感光纸时触发
        laser_on(idx);                            // 点亮对应角度激光
}
A-6 速度环与转向环 PID 控制
定时器中断中以编码器测速为速度环反馈，以中线偏差为转向环反馈，分别进行增量式 PID 计算并输出电机 PWM 与舵机转角。
// pid.c —— 速度环与转向环 PID（示意代码）
typedef struct { float kp, ki, kd, err_sum, err_last; } PID_t;
 
float pid_update(PID_t *p, float ref, float fb)
{
    float err = ref - fb;
    p->err_sum += err;
    float out = p->kp * err + p->ki * p->err_sum
              + p->kd * (err - p->err_last);
    p->err_last = err;
    return out;
}
 
void pid_control(void)
{
    float spd = get_car_speed();                 // 编码器平均速度
    float duty = pid_update(&speed_pid, speed_ref, spd);
    pwm_duty(PWM_MOTOR, duty);                   // 电机 PWM 输出
    float steer = pid_update(&steer_pid, 0, mid_err);
    servo_set(STEER_CENTER + (int16)steer);      // 舵机输出
}
