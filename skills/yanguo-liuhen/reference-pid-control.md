# PID 与运动控制结构

## 双环分工（赛道共识）

| 环 | 常用形式 | 输入 | 输出 | 理由 |
|----|----------|------|------|------|
| 转向 / 舵机 | **位置式 PD**（常无 I 或弱 I） | 中线偏差或纯跟踪角 | 舵机 PWM（中值±限幅） | 舵机要的是角度位置；I 易导致回中慢、积分饱和 |
| 速度 / 电机 | **增量式 PI/PID** | 目标速 − 编码器速 | PWM 增量累加后限幅 | 执行器要的是占空比累积；故障时增量更安全 |

湖南电气开拓者 2 队明确写了：**电机增量式 + 舵机位置式**。重庆交通队对位置式/增量式利弊有教科书式说明。

## 转向变体谱系

### 1. 经典偏差 PD

\[
u(k)=K_p e(k)+K_d\bigl(e(k)-e(k-1)\bigr)
\]

浙江工院公式即此。输出加舵机中值并限幅。

### 2. 双 PD / 二次比例（芜湖、锦城）

- 线性 P：小偏差柔和  
- **二次项** \(k_{p2}|e|^2\) 或分段：大偏差猛纠  
- D：偏差差分  
- 可选 **IMU Z 轴角速度阻尼**（抑制摆舵）

芜湖规律：直道增益小；弯道增益大；S 弯 P 小 D 略大。

### 3. 分段自适应 Kp（重庆）

按 `|error|` 查表换 `PID_fp[]`，实现简易增益调度。

### 4. 模糊 PD（锦城）

- 输入：误差 `er`、变化率 `dedt`  
- 7×7 规则表调 `KP`/`KD` 增量，叠在 `KP_Base`/`KD_Base`  
- 再进 `quadradic_pid_solve` 或舵机解算  
- 常混入 `imu660ra_gyro_z * kgyro`

### 5. 纯跟踪 Pure Pursuit + 舵机闭环（锦城、深圳）

1. 选可靠单边或双边 → 虚拟中线（单边向内偏固定距离）  
2. 逆透视后等距采样 → 按车速取前视点  
3. 用轴距算 `pure_angle`（定点 `atan2`/`isqrt`）  
4. 角度再进 PD/模糊 PD → PWM  

相对「只跟图像列偏差」，弯道更平滑、前瞻可随速度变。

## 速度环与差速

### 增量式核心（通用）

```text
Δu = Kp(e_k - e_{k-1}) + Ki·e_k + Kd(e_k - 2e_{k-1} + e_{k-2})
u_k = sat(u_{k-1} + Δu)
```

要点：

- **输出限幅**（如 ±8000~±8500）防驱动过流  
- **抗积分饱和**：触顶停积或反向清增量  
- 左右电机各一个 PID 实例（芜湖 `motor1_pid`/`motor2_pid`）

### 目标速度决策

| 工况 | 策略 |
|------|------|
| 直道小偏差 | `straight_target_speed` |
| 普通弯 / 环岛 | `normal` / `RING_SPEED` |
| 打靶 | `TARGET_SPEED` 明显降低 |
| 入弯 | 「减速场数」：高场数→低目标速，场数递减平滑过渡（芜湖） |
| 出界 / 停车 | 目标强制 0，关涵道电调，激光全关 |

### 差速

由舵机角或偏差映射：内侧减速、外侧持平或略提；系数 `diff_coe`。差速是辅助，不能替代足够打角。

## 中断与计算落点

| 队伍 | 提示 |
|------|------|
| 锦城 | 舵机相关 5 ms；编码器/电机 10 ms；激光关 3 ms；风扇 10 ms |
| 湖南电气 | 核心控制周期约 2 ms |
| 芜湖 | 帧内算偏差与舵机；速度环独立 PI；蜂鸣/停车 100 ms |

## 整定口诀（合并各队）

1. 机械中位 = 软件 `servo_mid`  
2. 低速只开线性 P，直到能直道纠偏  
3. 加大偏差二次项或分段 Kp  
4. 加 D 抑摆；再加陀螺阻尼  
5. 速度环：先对极性，再 PI；直道 PI 可大、弯道宜小  
6. 每档检查是否顶限幅（顶限幅说明增益或目标不合理）
