# 视觉流水线与元素状态机

## 图像规格（常见）

| 项目 | 取值 |
|------|------|
| 传感器 | MT9V034 / 总钻风 / 逐飞 130 灰度 |
| 原始 | 如 188×120 @ 100 fps（锦城） |
| 算法阵列 | 常压到 **80×60** 或 **94×60** 以降耗时 |
| 帧率菜单 | 50–200 fps 可调，默认约 100 |

## 预处理

1. **固定阈值**：实现简单，光照不均易挂  
2. **局部 min-max 动态阈值**（锦城）：邻域灰度极值 → 二值，适应明暗交界  
3. **大津法 Otsu**（湖南电气）：计算帧贵、可隔帧继承阈值  

输出：供搜线用的二值/灰度阵列。

## 边线提取流派

### A. 迷宫 / 扶墙法（锦城、芜湖 Dir_Labyrinth）

- 车头附近找左右起始跳变点（步长约 6）  
- 左手/右手扶墙沿边向上爬  
- 方向表：`dir_front` / `frontleft` / `frontright` + 一维偏移（188 宽）  
- 维护 `touch_boundary`、近端/远端两套边线（锦城）扩大视距  

### B. 八邻域搜线（湖南电气）

- 下采样后约 2.5 ms/帧级搜线  
- 断点靠邻域优先级优化，丢线恢复争取 1 帧内  

### C. 中心扫线 + 元素自适应起点（芜湖）

- 中心扫线：从上一行中线向左右找黑白界，稳但对环岛贵  
- 元素自适应：按十字拐点斜率、环岛特征改搜索起点（可行性剪枝）  

### D. 逐行 / 最长白列

基础方案；复杂弯与断线弱于方向跟踪。

## 中线与偏差

```
左右边 → 中点数组 C_Line
缺失边 → 上一帧趋势修补 或 单边偏移虚拟中线
偏差 e = 参考列(图像中心或前瞻行) - 中线列
```

锦城倾向：**点数更多的一侧** 作 `track_type`，`CalcCenterLineFromSingle` 向内偏固定物理距离；障碍强制走远离侧。

## 几何增强（进阶队）

1. **逆透视 mapx/mapy 查表** → 俯视近似  
2. `blur_points_fast` 滑动均值  
3. `ResampleEdge` 等距重采样  
4. **角度变化率** → 直道≈0，弯有极值，十字/环角点突变  

角点统计（`L_L_number`/`R_L_number`）+ `touch_boundary` 喂给元素机。

## 元素状态机（跨帧）

公共元素：直道、左右弯、十字、左右环岛、斑马线停车、坡道、障碍、靶环。

### 判据模式

| 元素 | 典型视觉特征 | 处理动作 |
|------|--------------|----------|
| 十字 | 左右近距直角点 / 两侧边线同时异常 | 锁 index，补线或特定走线，帧计数/里程退出 |
| 环岛 | 一侧直一侧拐点 → 入口确认 → 环内单侧弧 | 降速 `RING_SPEED`；出环看内侧线恢复 |
| 斑马线 | 条纹计数 + 停车模式 | `stop_flag`，关激光 |
| 障碍 | 边线上收/单侧异常 | 单边巡线或预设中线 |
| 坡道 | 边线形态 + IMU 辅助（部分队） | 表速调整 |
| 靶环 | ROI 内黑斑/跳变/迷宫环搜 | 见 laser 文档 |

### 状态机原则

- **识别后锁定** `element.index`，禁止每帧乱跳  
- **编码器累加里程** 或帧计数决定退出  
- 环岛分阶段（芜湖三态；重庆：入环降敏、出环恢复双线）  
- 十字 vs 环岛：十字常「两侧同时丢线」，环岛常「内侧消失外侧弧」  

## 单帧耗时预算（参考）

湖南电气量级：搜线 ~2.5 ms + 阈值 ~0.5–6 ms → 总约 9–11 ms → ~90–110 Hz。  
任何「加花活」算法必须卡在帧周期内，否则丢帧比算法更伤车。
