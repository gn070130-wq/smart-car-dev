# 飞檐走壁 · 报告级知识摘要

综合立创开源（流光溯影 / 电磁轻量化车 / 致远探界等）与赛题要求提炼，供搭建与写码调用。

## 赛题要点

- 缩微**立体电磁**赛道：水平面 + 垂直墙 + 圆筒 + 跷跷板  
- 引导：约 20kHz / ~100mA 载流导线（胶带色近地面，光电难用）  
- 元素：直角、十字、六边形环岛、Ω 弯、锥桶外侧通行  
- 负压吸附过垂直面；整车常见 **100g** 基准罚时规则  
- 主控约束：指定 **STC32** 系列  

## 默认软件栈

```text
电感ADC → 滤波/归一化 → 差比和/加权中线(err)
IMU → 角速度阻尼 / 姿态窗（环岛、跷跷板、墙面）
编码器 → 速度环 + 距离式状态机
状态机 → 直道/弯道/环岛/十字/跷跷板/垂直面
三环或串级：方向PD(+陀螺前馈) → 左右速度PI/PD → PWM
负压风机：发车升速、丢线/停车关、垂直面保持
```

算法锚点：`ELECTRO_MIDLINE` + `C01/C02/C03` + `S01` + `C10(负压)` + `P02`

## 控制建议（开源共识量级，需实车标定）

| 环 | 周期 | 要点 |
|----|------|------|
| 控制节拍 | 2ms 常见 | TIM 中断 |
| 电感 | 2–4ms 多次采样去极值 | 归一化 0~100 |
| 方向 | PD + Z 轴陀螺前馈 | 限幅差速修正 |
| 速度 | 双轮 PD/PI | 直道高、环岛中、跷跷板极低 |
| 负压 | 独立 MCU 或电调 PWM | 与主循迹解耦 |

## 元素状态机要点

1. **环岛**：外侧电感和大 / 姿态窗触发 → 距离或角度分段（入/环内/出）  
2. **跷跷板**：信号弱 + 小倾角窗 → 强制低速保持数百 ms  
3. **垂直面**：负压建立后按电磁继续循迹；丢线急停  
4. **十字/直角**：丢边+宽度特征；锥桶只允许外侧  

## 安全

- 电感总和过低 → 停车  
- PWM/电流限幅；电池欠压提示  
- 无线急停（若有）
