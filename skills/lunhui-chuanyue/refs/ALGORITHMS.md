# 轮腿穿越 · 算法卡

## A1 姿态融合
陀螺积分+加速度校正（互补/Mahony/ESKF）。输出 roll/pitch/yaw。时序 1 ms 级。

## A2 平衡串级
外：速度/倾角 → 中：倾角 → 内：角速度 → 轮力矩。平衡优先于寻迹。

## A3 轮腿 IK
目标腿长/腿角或轮端 XY → 关节角；五连杆或摆臂模型。坑：奇异位、限位。

## A4 差速转向
平衡叠加 ω 偏置；或独立横滚补偿。

## A5 越障
检测台阶/桥 → 预俯仰/抬腿/跳跃开环轨迹 + 落地收平衡。

## A6 锥桶视觉
颜色/轮廓 → 绕行点；Pure Pursuit 可选。

## A7 排雷框
进框检测 → 原地旋转两周计数 → 出框。

## A8 双核 IPC
共享结构 + 新鲜度；视觉不得堵控制核。
