# 轮腿穿越 · 完整汇总

## 架构
```
IMU → 姿态融合 → 平衡串级（速度/倾角/角速度）
关节目标(腿长/腿角/高度) → 逆运动学 → 关节位置/力矩环
视觉/ToF → 锥桶/框/障碍策略 → 模式切换（轮行/抬腿/跳）
双核：控制核高频；视觉核异步；共享内存
```

## 文件结构（逻辑）
`imu_* / balance_* / leg_ik_* / joint_* / wheel_* / vision_* / element_* / ipc_*`

## 算法
ESKF/互补滤波、平衡串级、五连杆/摆臂 IK、差速、轨迹复跑、元素抬腿策略。

## 风险
倒地、关节限位撞击、室外曝光、台阶策略失败、双核数据过期。安徽师大 PDF 未抽出文本。
