# 【学习摘要】轮腿穿越

## 组别
**第 21 届 · 轮腿穿越**（室外：绕桩、排雷、颠簸/台阶/单边桥等；轮腿复合平衡车）

## 硬件栈（共识）
| 模块 | 常见选型 |
|------|----------|
| 主控 | **CYT4BB / TRAVEO** 双核（控制+视觉隔离） |
| 机构 | 四关节摆臂/五连杆轮腿 + 左右行进轮；无刷+减速/FOC |
| 传感 | IMU（平衡关键）、磁编码器、摄像头、常配 ToF/GNSS |
| 驱动 | 关节 CAN/PWM；轮驱独立；舵机（部分） |

## 软件架构
双核：控制核高频平衡串级 + 关节逆解；视觉/规划核处理锥桶与元素策略；共享内存交换目标与模式。上电常约定下蹲/低重心初始化。

## 核心算法
1. IMU 姿态融合（互补/Mahony/ESKF）  
2. 速度—角度—角速度（或类似）**平衡串级 PID**  
3. 轮腿逆运动学（腿长/腿角→关节角）  
4. 差速转向 + 轨迹复跑  
5. 元素策略：抬腿/跳跃/俯仰横滚补偿  
6. 视觉锥桶/框内旋转检测  
7. 安全：姿态超限、关节限位、掉电保护
