第1章 引言
1.1 竞赛背景与作品概述
全国大学生智能汽车竞赛是教育部倡导的面向全国大学生的科技竞赛活动，旨在加强大学生实践、创新能力和团队精神的培养。第二十一届竞赛设立室外轮腿组，要求参赛车模以轮腿式结构在室外复杂地形环境下完成循迹、越野与多个特种科目，对车模的平衡控制、越障能力、定位精度与环境适应性提出了很高要求。
本报告介绍的作品是一辆基于英飞凌 CYT4BB 双核微控制器的轮腿式越野智能车。车模以 V 车模为底盘基础，采用"轮毂电机驱动 + 五连杆舵机变腿长"的轮腿复合结构：两只 BDS3620 轮毂无刷电机提供驱动力，四只 BDS300 舵机驱动左右两组五连杆机构实现腿长主动调节，使车模兼具轮式的高速性与腿式的越障能力，能够完成三级台阶跳跃、单边桥、颠簸路、雷区掉头等高难度科目。
整车按照"感知—定位—决策—控制"四层架构设计：以 IMU660RC 六轴传感器为核心的 4 kHz 姿态解算与 1 kHz 三环串级 PID 保证车体动态平衡；MT9V03X 摄像头与 DL1B 激光测距负责赛道与元素感知；TAU1201 GNSS 模块与惯导航迹推算经二维卡尔曼滤波融合，给出米级平面定位；上层导航状态机按科目调度路径规划与元素处理策略。
1.2 相关技术综述
轮腿复合机器人结合了轮式移动的高效率与腿式移动的高通过性，是近年来移动机器人领域的研究热点。对于双轮足式轮腿车而言，其纵向动力学本质上是一个可变腿长的轮式倒立摆，需要在平衡控制的同时协调腿长调节，控制耦合性强。常用方案是在串级 PID 平衡控制的基础上叠加腿长（重心）补偿通路，本车即采用"速度环—角度环—角速度环"三环串级加惯性辅助腿长补偿的结构。
在姿态估计方面，Mahony 互补滤波与 Madgwick 梯度下降法是嵌入式平台最常用的两类姿态解算算法，二者均以加速度计重力方向修正陀螺积分漂移，计算量小、实时性好。本车选用纯比例反馈的 Mahony 方案，并辅以二阶 Biquad 巴特沃斯低通滤波抑制越野振动引入的角速度噪声。
在室外定位方面，单点 GNSS 精度为米级且输出频率低，纯惯导航迹推算短期平滑但长期发散，二者互补性强。采用卡尔曼滤波进行松耦合融合是工程上成熟可靠的方案。本车实现了状态量为平面位置与速度的二维卡尔曼滤波器，全部矩阵运算手工展开，满足 1 kHz 实时性要求。
在路径规划方面，针对锥桶绕行等局部场景，贝塞尔曲线与 Dubins 曲线能够在保证曲率连续的前提下生成可跟踪的光滑路径，配合纯跟踪（Pure Pursuit）算法即可实现稳定的曲线跟随。
1.3 报告内容框架安排
本报告共分八章。第 1 章为引言，介绍竞赛背景、作品概况与相关技术；第 2 章给出系统总体方案，包括总体结构、器件选型与双核任务划分；第 3 章介绍机械结构设计；第 4 章介绍硬件电路设计；第 5 章详细阐述软件算法，包括姿态解算、平衡控制、转向控制、五连杆逆运动学、组合定位、路径规划、图像处理与特殊元素策略；第 6 章记录开发工具、调试过程中遇到的典型问题与解决方法以及关键参数整定过程；第 7 章汇总车模主要技术参数；第 8 章给出结论。文末附参考文献、电路原理图与核心源代码。

第2章 系统总体方案设计
2.1 总体设计思路
室外轮腿组赛题的核心难点可归纳为三点：一是双轮足式轮腿车本身是不稳定的多耦合被控对象，直立平衡是一切功能的前提；二是赛道位于室外，光照、地形变化剧烈，感知与定位必须足够鲁棒；三是三级台阶、单边桥、颠簸路、雷区等特种元素要求车模具备主动越障与策略切换能力。
针对上述难点，总体设计遵循三条原则：其一，控制优先，以高频率的姿态解算与串级控制保证动态平衡，所有上层功能都建立在稳定的平衡底盘之上；其二，传感冗余，视觉、激光测距、GNSS、IMU 多源信息互补，任一单源失效不导致整车失控；其三，策略分层，路点导航负责"把车带到元素门口"，元素内部切换为局部闭环，元素完成后用已知坐标重置定位，阻断误差累积。
2.2 系统总体结构
整车系统由主控核心、传感器组、执行机构、驱动板与电源系统五部分构成，总体结构如图 2.1 所示。

图 2.1　系统总体结构框图
主控核心为英飞凌 CYT4BB 车规级微控制器，片内双 Cortex-M7 内核分工协作；传感器组包括 MT9V03X 灰度摄像头、IMU660RC 六轴 IMU、DL1B 激光测距模块、TAU1201 GNSS 模块以及电流检测电路；执行机构为四只 BDS300 舵机与两只 BDS3620 轮毂无刷电机；无刷驱动板以 CYT2BL3 为控制核心，经 UART 与主板通信；电源系统由 3S 锂聚合物电池与多路 DC-DC/LDO 构成。

2.4 双核任务划分
CYT4BB 内部集成两个 Cortex-M7 内核（CM7_0 / CM7_1）与一个 Cortex-M0+ 启动核。系统时钟在两个核的 main() 入口处由 clock_init(SYSTEM_CLOCK_250M) 统一配置为 250 MHz。两核之间通过 0x28001000 起始的共享 RAM 区域交换数据；由于 M7 带有 D-Cache，共享变量使用 #pragma location 定位到固定地址并声明为 __no_init，读写前后显式调用 SCB_CleanInvalidateDCache_by_Addr() 按 32 字节 Cache Line 同步，保证双核数据一致性。任务划分如表 2.2 所示。

第3章 机械结构设计
3.1 整体布局
车模以竞赛指定的 V 车模为底盘基础，整体采用对称式布局：左右两组轮腿机构分居车体两侧，主板与驱动板层叠安装于车体中部甲板，电池置于甲板下方以降低重心，摄像头与激光测距模块通过碳纤维立杆架高安装。整车外形尺寸约为 16 cm（宽）× 21 cm（高）× 38 cm（长），满足竞赛对车模尺寸的限制要求。车模前视与侧视照片如图 3.1、图 3.2 所示。

3.2 轮腿机构
轮腿机构是本车机械部分的核心。每条腿由两只 BDS300 舵机驱动一组五连杆机构，连杆长度分别为 L1 = 6 cm、L2 = 9 cm、L3 = 9 cm、L4 = 6 cm，机架宽 L5 = 3.7 cm。通过两个主动连杆角的组合，足端（轮轴）可在平面内实现前后与上下两个自由度的运动：上下运动实现腿长在约 3 cm 至 11 cm 范围内的主动调节，用于跳跃、抬腿越障与地形自适应；前后运动实现等效重心前后移动，辅助速度控制与加减速姿态管理。轮腿机构照片如图 3.3 所示。

图 3.3　五连杆轮腿机构
五连杆机构相比直接舵机摆臂的优点在于：足端运动范围大且近似直线、两舵机扭矩叠加、机构刚度好；代价是需要实时求解逆运动学，该部分算法见第 5.5 节。
3.3 轮胎与轮毂
车轮采用直径 88 mm 的越野轮胎，胎纹深、抓地力强，适应室外砂石与草地路面。轮胎内部填充 3D 打印 TPU 软性材料作为弹性支撑，轮毂采用 PETG 材料 3D 打印，兼顾强度与韧性。BDS3620 轮毂无刷电机直接内置于轮内，省去了传动机构，结构紧凑、效率高。轮胎与轮毂照片如图 3.4 所示。

3.4 传感器安装
摄像头安装高度约 300 mm（轮腿车高随腿长变化，此为行驶中的典型值），镜头俯角约 50°，兼顾前瞻距离与近处盲区；DL1B 激光测距模块安装于车头前下方，用于三级台阶的距离检测；GNSS 天线架高远离电机与舵机，减小电磁干扰；IMU660RC 模块安装于车体几何中心附近并做减振处理，降低电机振动对姿态解算的影响；两块自研磁编码器板分别与左右轮毂电机同轴安装，编码芯片正对轴端磁钢，实时检测车轮绝对角度（详见第 4.4 节）。车模甲板布局与尾部照片如图 3.5、图 3.6 所示。

3.5 电路板安装
主板与无刷驱动板采用铜柱层叠安装于甲板之上，板间预留足够间隙保证散热；接插件均选用带锁扣的 WAFER/GH 连接器并点胶加固，防止越野振动导致松脱；动力线采用硅胶线并留有余量，适应轮腿大幅度运动。整车装配完成后进行重心检查，保证空载静态时重心位于两轮连线附近，为平衡控制创造良好的机械条件。

第4章 硬件电路设计
4.1 主板总体设计
主板以 CYT4BB7 最小系统为核心，集成电源变换、传感器接口、舵机接口、显示与调试接口、按键与拨码开关等全部功能，采用四层板设计，完整地平面保证信号完整性。主板 PCB 如图 4.1 所示，完整原理图见附录 A。

图 4.1　主板 PCB（顶层）
最小系统部分包括 16 MHz 外部晶振（ECO）与 32.768 kHz 手表晶振（WCO）、复位电路、SWD 调试接口、ADC 基准以及去耦电容阵列。所有对外接口均经 100 Ω 串联电阻与 ESD 器件防护。
4.2 电源电路
整车由 3S 锂聚合物电池（标称 11.1 V，2200 mAh）供电。主板电源分为三级：第一级采用 TPS54302 同步降压变换器将电池电压降至 5 V，供舵机、屏幕与外设；第二级采用 TLV62568 降压至 3.3 V 与 1.1 V，分别供 MCU 的 VDDD/VDDIO 与内核；模拟部分由 TPRT9013-33 低压差线性稳压器单独供电，降低数字噪声对 ADC 与传感器的影响。电池输入经 NCE30P50G P 沟道 MOSFET 构成电源开关，实现低损耗通断控制。舵机母线另设多路 330 μF 电解电容阵列，抑制舵机堵转冲击造成的母线跌落。
4.3 驱动板设计
无刷驱动板以 CYT2BL3 为控制核心，通过 UART（460800 bps，0xA5 帧头自定义协议）接收主板下发的目标占空比/力矩指令并回传轮速与状态。功率级采用两颗 FD6288Q 三相栅极驱动器驱动 12 只 DCN8N03 N 沟道 MOSFET 组成的双三相全桥，可独立驱动两只 BDS3620 轮毂电机；每相下桥臂串入采样电阻，经 INA240A2 电流放大器（增益 50 V/V）送入 MCU ADC，实现相电流闭环与过流保护；栅极驱动器使能端串接 SMF26CA TVS 管抑制功率回路尖峰。驱动板 PCB 如图 4.2 所示。

图 4.2　无刷驱动板 PCB（顶层）
4.4 磁编码器板设计
为精确获取左右车轮的绝对角度，两只轮毂电机轴端各安装一块自研磁编码器板。磁编板以 MagnTek MT6826 磁性角度编码芯片为核心：电机轴端粘结径向充磁磁钢，编码芯片与磁钢同轴正对安装，非接触地检测车轮绝对角度。板载 TPRT9013-33 低压差线性稳压器将输入电源稳压至 3.3 V 为芯片供电，并以 BZT52C3V6 稳压管对 3.3 V 电源轨作过压钳位保护；MT6826 的 ABZ 增量输出与 UVW 换相输出悬空不用，仅通过 SPI 接口输出角度数据，CS、MISO、MOSI、CLK 信号线均串接 100 Ω 电阻抑制振铃与干扰，另预留 CAL 校准焊盘，便于安装后现场标定零位。磁编板经 ZH1.5-6P 接插件接入驱动板，驱动板定时读取左右车轮角度后随状态量经 UART 上报主板，主板据此可对轮毂电机构成绝对角度闭环，将车轮精确转至目标角度（程序见附录 B.14）。磁编码器板 PCB 如图 4.3、图 4.4 所示，原理图见附录 A 图 A-6。

图 4.4　磁编码器板 PCB（底层）
4.5 传感器接口
主板为各类传感器预留了完整接口：摄像头经 FPC-20P 连接器接入，采用专用 LDO 供电；IMU 接口原理图上预留 LSM6DSRTR 贴片焊盘，实际装贴 IMU660RC 模块（驱动代码对应 IMU660RC，LSM6DSRTR 驱动已注释保留）；TOF 与 GNSS 分别经 IIC 与 UART 接口接入；四路舵机信号经 100 Ω 电阻隔离输出，舵机母线电流经四路 INA181 电流检测放大器监测，可实现舵机堵转保护；另预留蜂鸣器、五向按键、拨码开关、编码器与无线串口接口。
4.6 可靠性设计
针对室外越野的恶劣工况，硬件层面采取了多项可靠性措施：电源入口设防反与 TVS 防护；所有对外信号线串联小电阻限流；功率地与信号地单点连接，舵机与电机大电流回路单独走线；关键接插件点胶防松；主板与驱动板均铺铜散热并留安装孔加固。软件层面的打滑、堵转、离地、俯仰角与遥控失控保护见第 5.9 节。

第5章 软件算法设计
5.1 软件总体架构
整车软件由"感知—定位—决策—控制"四层构成：底层以 4 kHz 姿态解算与 1 kHz 串级 PID 保证车体直立与速度跟踪；中间层以 GPS/惯导卡尔曼融合给出米级平面坐标；上层由导航状态机按科目调度路径规划与元素处理策略。软件总体架构如图 5.1 所示。

图 5.1　软件总体架构
两个核心各自拥有独立的 main()，上电后由 CM0+ 依次启动。CM7_0 的启动序列为：clock_init(250 MHz) → debug_init() → all_init()（外设与参数初始化）→ IMU 零偏标定（3 s）→ 使能中断进入主循环；CM7_1 完成摄像头与 TOF 初始化后进入图像处理主循环，处理结果经共享 RAM 供 CM7_0 读取。
5.2 IMU 姿态解算
姿态解算在 PIT0 CH2 的 0.25 ms 中断中执行，采样率 4 kHz。原始数据取自 IMU660RC 六轴传感器，处理链路为：零偏补偿 → 静态死区 → Mahony 互补滤波 → 四元数转欧拉角。
零偏标定：上电后在 IMU_calibration() 中关全局中断，以 250 μs 间隔连续采样，每 4000 点求一次均值，连续 3 秒取平均得到三轴零偏。静态死区：零偏补偿后若单轴角速度绝对值小于 5 LSB（约 0.35 °/s）则直接置零，抑制静止时的积分漂移。
Mahony 互补滤波取 twoKp = 1.6、twoKi = 0（纯比例反馈，避免积分项在长时间越野颠簸中发散）：用加速度计测得的重力方向与四元数推算的重力方向作叉积得到误差，反馈修正陀螺积分。归一化使用 Quake III 的 invSqrt() 位运算近似，相比 1.0f/sqrtf() 在 4 kHz 中断中显著节省周期。工程中同时保留了 Madgwick 梯度下降解算（beta = 0.11）作为对比方案，实际参赛版本调用的是 Mahony 分支。
三轴角速度另经 30 Hz 截止、Q = 0.7071（二阶巴特沃斯，相位失真最小）的 Biquad 低通滤波，得到 Pitch_g_F / Roll_g_F / Yaw_g_F，直接作为角速度环反馈与转向前馈；对角速度做一阶低通差分（时间常数 DGyroLPF = 0.00225）得到角加速度，用于跳跃与颠簸段的姿态突变判断。

分频通过 loop_counter % 5 实现：角速度环每次 1 ms 中断都执行，速度环与角度环每 5 次执行一次，形成 200 Hz / 1 kHz 的内外环带宽比，保证内环足够快而外环不与内环打架。速度环的微分项刻意作用在实际速度而非误差上（Derivative = actual_speed − LastActual），原因是目标速度在状态机切换时会发生阶跃，微分作用于测量值可避免阶跃引起的微分冲击。
除三环之外，还有一条并行的"惯性辅助腿长补偿"通路：Inertial_assistedCrl_X() 用速度误差经 special_PID 解算出腿部前后坐标 wheel_x 的补偿量，等效于用重心前后移动承担大部分速度跟踪职责。为适应越野下坡工况，update_speed_pid_output_limit_by_pitch() 会在俯仰角小于 −16° 时按每度 0.1 的斜率收缩腿长补偿的输出限幅，俯仰越大补偿越保守，避免前扑。
科目三的三级台阶完成前、以及颠簸路段与反三级台阶期间，three_cascade_target_angle() 会直接丢弃速度环输出、把目标俯仰角强制置零，只保留角度环 + 角速度环稳住车身——此时"平衡"比"速度"更重要。
5.4 转向控制
转向不使用舵机，而是通过左右轮占空比差实现差速转向。控制器为航向角外环 + 航向角速度内环的串级结构，外环 Dual_PD_Control() 的输出为
	u = Kp·e + Kp2·e·|e| + Kd·Δe + Gkd·ω	(1)
其中 e 为航向误差，已作 ±180° 环绕处理（保证车永远选劣角转向而不会绕远路）；e·|e| 为非线性比例项，小误差时增益低、抑制直道抖动，大误差时增益迅速增大、提高大角度纠偏速度；ω 为 Biquad 滤波后的航向角速度前馈。
转向参数按科目分档存放于 turn_pid_profile_t 结构体数组中，进入不同科目时由 turn_pid_select_subject() 整体切换，避免单套参数在三种赛道上顾此失彼，如表 5.2 所示。在特殊工况下还有一层运行时增益覆盖：科目三元素段将内外环 D 项放大 30 倍以强化阻尼；单边桥视觉循线时 D 放大 50 倍同时 P 减半；原地打圆时外环 Kp 另行调整。

5.5 五连杆腿部逆运动学
每条腿由两个舵机驱动一组五连杆机构，杆长参数为 L1 = 6 cm、L2 = 9 cm、L3 = 9 cm、L4 = 6 cm、机架宽 L5 = 3.7 cm。给定足端目标坐标 (x, y)，需要反解两个主动连杆角 φ1 与 φ4。以左侧支链为例，设 a = 2(x + L5/2)·L1，b = 2y·L1，c = (x + L5/2)² + y² + L1² − L2²，则由半角公式得到解析解：
	φ1 = 2·atan2( b + √(a² + b² − c²),  a + c )	(2)
右侧支链形式相同，但取判别式的负根（φ4 = 2·atan2(b₁ − √Δ, a₁ + c₁)），以选择机构的正确装配构型。判别式 Δ = a² + b² − c² 小于零表示目标点超出工作空间，此时逆解函数直接返回失败，调用方保持上一拍角度不写入，杜绝 NaN 传播到 PWM 寄存器。解算得到的连杆角还需映射到舵机角：motor1 = 270° − φ1；φ4 大于 270° 时 motor2 = φ4 − 270°，φ4 小于 90° 时 motor2 = 90° + φ4，其余情况保留原角度。
5.6 GNSS/INS 组合定位
GNSS 模块输出频率约 10 Hz、单点精度米级，直接用于闭环导航会造成航向指令跳变；而纯航迹推算（轮速 + 航向积分）短期平滑但长期发散。因此采用二维卡尔曼滤波器融合两者，状态量取平面坐标与速度 (x, y, vx, vy)，融合结构如图 5.3 所示。

图 5.3　GNSS/INS 组合定位结构框图
预测步（1 kHz，与电机中断同频）的状态转移为
	xₖ⁺ = xₖ + vx·dt + ½·aₓ·dt²,　yₖ⁺ = yₖ + vy·dt + ½·ay·dt²	(3)
其中体轴加速度经 Mahony 输出的航向角 ψ 投影到当地平面。更新步在 GPS 到帧时触发，观测矩阵 H = I，新息协方差 S = P + R，2×2 矩阵解析求逆后得到卡尔曼增益 K = P·S⁻¹；协方差更新采用 Joseph 形式
	P = (I − KH)·P·(I − KH)ᵀ + K·R·Kᵀ	(4)
并在最后强制 P01 = P10 = (P01 + P10)/2 保持数值对称，防止长时间运行后浮点误差累积导致协方差矩阵失对称。噪声参数取过程噪声 Q = 0.0001、量测噪声 R = 1.0，二者比值由稳态增益公式 k = nQ/(nQ + R) 反推确定，n = 预测频率/更新频率 = 1000/10 = 100。全部矩阵运算均手工按元素展开（hand-unrolled），不引入通用矩阵库，避免循环开销与动态内存分配。经纬度到本地平面的转换由 gps_to_local() 完成：以录点时的第一个点为原点，x = Δlon·k_lon，y = Δlat·k_lat，其中 k_lat、k_lon 按参考纬度椭球修正，在赛道尺度上误差可忽略。
5.7 路径规划
科目一的锥桶绕行段不采用"直接打点"而是生成连续曲线跟随，流程分四步：直线拟合——对录入的锥桶坐标做全最小二乘（Total Least Squares）拟合，通过协方差矩阵最小特征值对应的特征向量求出一般式直线，相比普通最小二乘，TLS 同时考虑 x、y 两个方向的误差；绕行点生成——沿拟合直线法向左右交替偏移 0.8 m 生成绕行点，对"先左后右"与"先右后左"两种起始方向各试算一次总路程，取较短者，自动适配车辆进桩方向；曲线化——默认使用三次贝塞尔曲线，控制点由 Catmull-Rom 切线给出（切线长度 = 段长 × 0.3），每段采样 8 点，保证经过所有绕行点且一阶连续，工程同时实现了完整的 Dubins 曲线作为备选；跟随——规划结果写入统一缓冲 planned_path[200]，跟随时以 0.3 m 为到点阈值逐点推进，该阈值约为点间距的 40 %，与 GPS 定位精度匹配。
科目三的 P7→P9 段另有一套"1/4 圆弧 + 直线 + 1/4 圆弧"规划器（generate_arc_line_arc_path）：以 P7→P9 连线为基准，中间点 P8 只提供到该连线的垂距，配合固定前视半径 0.8 m 的纯跟踪算法，解决了直瞄路点时前视距离缩短导致航向指令抖动的问题。
5.8 图像处理与赛道识别
图像处理全部运行在 CM7_1 核，摄像头为 MT9V03X（188 × 120 灰度）。基础处理链为：大津法（OTSU）自适应阈值——统计 256 级灰度直方图，遍历求最大类间方差得到最佳阈值，再叠加 +20 的经验偏置以适应赛道白线偏亮的特点；二值去噪——按行游程处理，孤立白点（连续白 ≤ 2）删除，细窄黑缝（连续黑 ≤ 7）填白；边线提取——逐行从左向右扫描，连续"黑黑→白白"记为左边界、"白白→黑黑"记为右边界，相邻行跳变量超过 15 像素则限幅；中线连续度——统计中线列差小于 3 的最长连续段，取该段对应行作为最可信的循线目标行，输出偏差 image_error 与角度 image_error_angle；逆透视变换（IPM）——按相机安装高度、俯仰安装角与实时 Pitch/Roll 建立映射，将透视图还原为俯视图，用于元素几何尺寸的判定。赛道元素视觉识别判据如表 5.3 所示。

6.3 关键参数整定过程
例一：三环串级 PID（由内环到外环）。串级系统必须自内向外逐环整定，否则外环的振荡会被误判为内环参数问题。第一步整定角速度环：断开外环直接给定固定目标角速度，P 从 0 逐步增大至 5；此环最典型的故障是"车变成陀螺"，即反馈符号取反。第二步整定角度环：P 从 20 起逐步上调至 48，D 从 8 降到 4，因为角度环 D 过大会引起高频抖动。第三步整定速度环：输出为目标俯仰角，限幅 ±40° 防止外环把车顶翻，取 P = 0.010、I = 0、D = 0，由于腿长补偿通路已承担大部分速度跟踪职责，此环只需提供慢速重心配平。第四步整定腿长补偿 PID：P = 0.0103、I = 0.00004、D = 0.002，积分限幅按 Integralmax = maxoutput/I/3 自动计算，保证纯积分项最多贡献 1/3 输出。整定辅助手段：通过 VOFA+ 无线串口在线改写参数，单次迭代从数分钟缩短到数秒。
例二：三级台阶跳跃时序。三级台阶要求车在三级连续台阶上完成三次跳跃，时序偏差几十毫秒就会导致撞台阶或落空，是整个赛题中最难整定的部分。触发阈值由固定值改为自动标定：车在接近元素起点 1 m 内时先延时若干拍等待姿态稳定，再连续采样 TOF 距离求均值，三次跳跃的触发阈值取"均值 − 40 mm"。跳跃内部时序由 Jump_test() 状态机的计数器决定，全部以 2 ms 为一拍。跳间延时——第一跳到第二跳 128 ms、第二跳到第三跳 60 ms，这两个值与车速强相关，是在固定通过速度 270 下扫描得到的。落地稳定——第三跳落地后锁定航向并保持 400 ms，期间不接受任何新的航向指令，等车身姿态收敛后再交回路点导航。
例三：白色带状元素识别阈值（雷区触发）。雷区改为纯视觉触发后，误触发一次就意味着在错误位置原地转 720°，因此识别阈值的整定标准是"宁可漏、不可错"。整定顺序为：先放宽全部阈值观察能否稳定命中，再逐项收紧到刚好排除误检。所有中间量（跨度、厚度、最近行、倾角、拟合偏差、命中通道）都实时显示在 IPS200 屏幕上，可在不连电脑的情况下直接观察每一帧的判据取值。

第8章 结论
本报告完整地介绍了一辆室外轮腿组智能车的设计、实现与调试过程。作品以英飞凌 CYT4BB 双核微控制器为核心，采用轮腿复合结构，主要成果与创新点可归纳为以下四个方面。
第一，构建了高带宽的平衡控制体系。4 kHz Mahony 姿态解算与"速度—角度—角速度"三环串级 PID 加惯性辅助腿长补偿的控制结构，使双轮足式车模在室外颠簸路面上保持了可靠的动态平衡；微分作用于测量值、陀螺前馈、俯仰自适应限幅等工程细节显著改善了控制品质。
第二，发挥了双核架构的算力优势。CM7_0 专职实时控制、CM7_1 专职视觉与测距，配合基于固定地址共享 RAM 与显式 D-Cache 维护的跨核通信机制，在保证 1 kHz 控制回路确定性的同时实现了约 50 Hz 的图像处理能力。
第三，形成了鲁棒的室外定位与元素处理策略。GNSS 与惯导经手工展开的二维卡尔曼滤波融合，给出平滑的米级定位；"路点导航到门口 + 元素内部局部闭环 + 元素终点坐标重置"的三段式策略，有效阻断了误差在六个连续元素间的累积。
第四，沉淀了一套高效的调试方法论。菜单可调参数、VOFA 在线整定、全量中间变量上屏与 Git 版本管理，使三级台阶跳跃时序、雷区视觉阈值等难题的整定效率成倍提升。
限于时间与水平，车模仍有可改进之处：轮速观测目前依赖电机霍尔，精度有限，后续可考虑融合轮毂编码器与 IMU 的紧耦合里程计；纯白视觉的雷区触发在强逆光下仍有漏检风险，可引入 TOF 阵列做多模态确认；五连杆逆解目前逐腿独立计算，尚未考虑双腿耦合的全身姿态优化。我们将在后续训练中继续完善。

B.1 Mahony 互补滤波姿态解算（project/code/ICM.c）
void MahonyAHRSupdateIMU(float gx, float gy, float gz, float ax, float ay, float az)
{
    static float recipNorm;
    static float halfvx, halfvy, halfvz;
    static float halfex, halfey, halfez; // 方向误差
    static float qa, qb, qc;
 
    if (!((ax == 0.0f) && (ay == 0.0f) && (az == 0.0f)))
    {
        // 将角速度从度/秒转换为弧度/秒
        gx *= 0.0174532925f;
        gy *= 0.0174532925f;
        gz *= 0.0174532925f;
 
        // 归一化加速度测量值
        recipNorm = invSqrt(ax * ax + ay * ay + az * az);
        ax *= recipNorm;
        ay *= recipNorm;
        az *= recipNorm;
 
        // 计算重力方向与加速度方向的叉积
        halfvx = q1 * q3 - q0 * q2;
        halfvy = q0 * q1 + q2 * q3;
        halfvz = q0 * q0 - 0.5f + q3 * q3;
 
        // 测量重力方向与推算重力方向的误差
        halfex = (ay * halfvz - az * halfvy);
        halfey = (az * halfvx - ax * halfvz);
        halfez = (ax * halfvy - ay * halfvx);
 
        if (twoKi > 0.0f)
        {
            integralFBx += twoKi * halfex * invsampleFreq;
            integralFBy += twoKi * halfey * invsampleFreq;
            integralFBz += twoKi * halfez * invsampleFreq;
            gx += integralFBx;
            gy += integralFBy;
            gz += integralFBz;
        }
        else
        {
            integralFBx = 0.0f;
            integralFBy = 0.0f;
            integralFBz = 0.0f;
        }
 
        // 应用比例反馈
        gx += twoKp * halfex;
        gy += twoKp * halfey;
        gz += twoKp * halfez;
    }
 
    // 四元数微分积分
    gx *= (0.5f * invsampleFreq);
    gy *= (0.5f * invsampleFreq);
    gz *= (0.5f * invsampleFreq);
    qa = q0;
    qb = q1;
    qc = q2;
    q0 += (-qb * gx - qc * gy - q3 * gz);
    q1 += (qa * gx + qc * gz - q3 * gy);
    q2 += (qa * gy - qb * gz + q3 * gx);
    q3 += (qa * gz + qb * gy - qc * gx);
 
    // 四元数归一化
    recipNorm = invSqrt(q0 * q0 + q1 * q1 + q2 * q2 + q3 * q3);
    q0 *= recipNorm;
    q1 *= recipNorm;
    q2 *= recipNorm;
    q3 *= recipNorm;
 
    static float r11, r12, r21, r31, r32;
    r11 = 2.0f * (q0 * q1 + q2 * q3);
    r12 = 1.0f - 2.0f * (q1 * q1 + q2 * q2);
    r21 = 2.0f * (q0 * q2 - q3 * q1);
    r31 = 2.0f * (q0 * q3 + q1 * q2);
    r32 = 1.0f - 2.0f * (q2 * q2 + q3 * q3);
 
    q[0] = q0;  q[1] = q1;  q[2] = q2;  q[3] = q3;
 
    // 计算欧拉角（弧度）
    Yaw_a_Pi   = atan2f(r31, r32);
    Pitch_a_Pi = -asinf(r21);
    Roll_a_Pi  = atan2f(r11, r12);
}

B.2 二阶 Biquad 巴特沃斯低通滤波（project/code/ICM.c）
void biquad_filter_init(biquad_state *state, biquad_type type, int fs, float fc, float q_value)
{
    float w0, sin_w0, cos_w0, alpha;
    float b0, b1, b2, a0, a1, a2;
 
    w0 = 2 * PI * fc / fs;          // 频率转换
    sin_w0 = sinf(w0);
    cos_w0 = cosf(w0);
    alpha = sin_w0 / (2.0 * q_value); // 衰减系数
 
    switch(type)
    {
    case BIQUAD_LOWPASS:
        b0 = (1.0 - cos_w0) / 2.0;
        b1 = b0 * 2;
        b2 = b0;
        a0 = 1.0 + alpha;
        a1 = -2.0 * cos_w0;
        a2 = 1.0 - alpha;
        break;
    case BIQUAD_HIGHPASS:
        b0 = (1.0 + cos_w0) / 2.0;
        b1 = -b0 * 2;
        b2 = b0;
        a0 = 1.0 + alpha;
        a1 = -2.0 * cos_w0;
        a2 = 1.0 - alpha;
        break;
    default:
        b0 = alpha; b1 = 0.0; b2 = -alpha;
        a0 = 1.0 + alpha; a1 = -2.0 * cos_w0; a2 = 1.0 - alpha;
        break;
    }
    state->a0 = b0 / a0;
    state->a1 = b1 / a0;
    state->a2 = b2 / a0;
    state->a3 = a1 / a0;
    state->a4 = a2 / a0;
    state->x1 = state->x2 = 0.0;
    state->y1 = state->y2 = 0.0;
}
 
// 二阶滤波
float biquad(biquad_state *state, float data)
{
    float result = 0;
    result = state->a0 * data + state->a1 * state->x1 + state->a2 * state->x2
           - state->a3 * state->y1 - state->a4 * state->y2;
    state->x2 = state->x1;
    state->x1 = data;
    state->y2 = state->y1;
    state->y1 = result;
    return result;
}

B.4 速度环 PID（微分作用于测量值）
float SpeedToPitch_PID(float actual_speed, float target_speed, PID_Datatypedef *motorpid)
{
    float Error = actual_speed - target_speed;
 
    motorpid->Integral += Error;
    if(motorpid->Integral > motorpid->Integralmax)
        motorpid->Integral = motorpid->Integralmax;
    else if(motorpid->Integral < motorpid->Integralmin)
        motorpid->Integral = motorpid->Integralmin;
 
    if(motorpid->EC == 0)
    {
        motorpid->LastActual = actual_speed;
        motorpid->EC = 1;
    }
 
    // 微分作用于实际速度而非误差，避免目标阶跃引起微分冲击
    motorpid->Derivative = actual_speed - motorpid->LastActual;
    motorpid->out_p = motorpid->P * Error;
    motorpid->out_i = motorpid->I * motorpid->Integral;
    motorpid->out_d = motorpid->D * motorpid->Derivative;
    motorpid->DeltaOutput = motorpid->out_p + motorpid->out_i + motorpid->out_d;
    motorpid->LastError = Error;
    motorpid->LastActual = actual_speed;
 
    if(motorpid->DeltaOutput > motorpid->maxoutput)
        motorpid->DeltaOutput = motorpid->maxoutput;
    else if(motorpid->DeltaOutput < motorpid->minoutput)
        motorpid->DeltaOutput = motorpid->minoutput;
 
    return motorpid->DeltaOutput;
}

B.5 通用位置式 PID（含陀螺前馈）
float Common_PID(float Actual, float Target, PID_Datatypedef *motorpid)
{
    float Error;
    Error = Target - Actual;
    motorpid->Integral += Error;
 
    if(motorpid->Integral >= motorpid->Integralmax)
        motorpid->Integral = motorpid->Integralmax;
    else if(motorpid->Integral <= motorpid->Integralmin)
        motorpid->Integral = motorpid->Integralmin;
 
    motorpid->Integralout = motorpid->I * motorpid->Integral;
    motorpid->Derivative = Error - motorpid->LastError;
 
    motorpid->DeltaOutput =
        motorpid->P * Error +
        motorpid->I * motorpid->Integral +
        motorpid->D * motorpid->Derivative +
        motorpid->Gkd * Pitch_g_F;   // 陀螺仪前馈项
 
    motorpid->LastError = Error;
 
    if(motorpid->DeltaOutput > motorpid->maxoutput)
        motorpid->DeltaOutput = motorpid->maxoutput;
    else if(motorpid->DeltaOutput < motorpid->minoutput)
        motorpid->DeltaOutput = motorpid->minoutput;
 
    return motorpid->DeltaOutput;
}

B.6 转向双 PD 控制（project/code/motor.c）
float Dual_PD_Control(float target_yaw, float current_yaw, float omega_gyro,
                      DualPD_DataTypeDef *controller)
{
    // 航向误差，±180° 环绕处理
    float error = target_yaw - current_yaw;
    if(error > 180.0f)  error -= 360.0f;
    else if(error < -180.0f) error += 360.0f;
 
    float delta_e = error - controller->Last_e;
    float nonlinear_p = error * fabs(error);   // 非线性比例项 e·|e|
 
    float output = controller->Kp * error
                 + controller->Kp2 * nonlinear_p
                 + controller->Kd * delta_e
                 + controller->Gkd * omega_gyro;   // 陀螺仪前馈
 
    if(output > controller->maxoutput)      output = controller->maxoutput;
    else if(output < controller->minoutput) output = controller->minoutput;
 
    controller->Last_e = error;
    return output;
}

B.7 五连杆腿部逆运动学解算（project/code/steer.c）
uint8 FiveLinkage_InverseRaw(float link1, float link2, float link3, float link4,
                             float base_width, float x, float y, float *ph1, float *ph4)
{
    float a, b, c, disc;
    float a1, b1, c1;
 
    if(NULL == ph1 || NULL == ph4) return 0;
 
    a = 2.0f * (x + base_width / 2.0f) * link1;
    b = 2.0f * y * link1;
    c = (x + base_width / 2.0f) * (x + base_width / 2.0f) + y * y
        + link1 * link1 - link2 * link2;
    disc = a * a + b * b - c * c;
    if(disc < 0.0f)   // 目标点超出工作空间
    {
        *ph1 = NAN;  *ph4 = NAN;
        return 0;
    }
 
    *ph1 = 2.0f * atan2f(b + sqrtf(disc), a + c) * 180.0f / (float)M_PI;
    *ph1 = steer_norm_angle_deg(*ph1);
 
    a1 = 2.0f * (x - base_width / 2.0f) * link4;
    b1 = 2.0f * y * link4;
    c1 = (x - base_width / 2.0f) * (x - base_width / 2.0f) + y * y
         + link4 * link4 - link3 * link3;
    disc = a1 * a1 + b1 * b1 - c1 * c1;
    if(disc < 0.0f)
    {
        *ph1 = NAN;  *ph4 = NAN;
        return 0;
    }
 
    *ph4 = 2.0f * atan2f(b1 - sqrtf(disc), a1 + c1) * 180.0f / (float)M_PI;
    *ph4 = steer_norm_angle_deg(*ph4);
    return 1;
}
 
void TargetAngleGet_L(float xx, float yy)

    {
        Tarangle11 = motor1;

    }
}

void Jump_test(void)
{
    static float32_t start_pitch = 0, pitch_check = 0;
    static float32_t start_x = 0, start_y = 0;
    static float32_t pre_height = 0;
    switch (jump_state)

                jump_state = 2;
                start_pitch = imu660ra_pitch;
                target_leg_length = jump_length3;    // 起跳腿高

                jump_time = 0;
            }
            else
            {
                target_leg_length = jump_length1;    // 下蹲到 7.5cm
                leg_pid.pOut = 0;                    // 原地站立
            }
            break;
        case 2:  // 起跳姿态确认
            if (imu660ra_pitch > pitch_check + 2.5f)
            { jump_state = 3; jump_time = 0; }
            else if (jump_time > 400)
            { jump_state = 4; jump_time = 0; }       // 超时兜底
            break;
        case 3:  // 离地检测与最高点检测
            jump_time++;
            target_leg_length = jump_length2;        // 空中收腿
            if (abs(imu660ra_acc_z) < 0.3 && imu660ra_pitch <= 10 &&
                imu660ra_pitch >= 4 && jump_time >= 260)
            { jump_state = 4; jump_time = 0; }
            else if (jump_time > 700)
            { jump_state = 4; jump_time = 0; }
            break;
        case 4:  // 落地缓冲
            jump_time++;
            target_leg_length = jump_length4;        // 落地下蹲缓冲
            if (jump_time > 150)
            { jump_state = 5; jump_time = 0; }
            break;
        case 5:  // 退出跳跃
            if (abs(imu660ra_acc_z) < 0.3 && imu660ra_pitch <= 10)
            {
                target_leg_length = normal_length;
                jump_state = 0;
                jump_flag = 0;
            }
            break;
    }
}

B.10 二维卡尔曼组合定位
// 经纬度 -> 本地平面坐标
static void gps_to_local(double lat, double lon, double *x, double *y)
{
    double lat_ref = HOME_LAT * DEG2RAD, lon_ref = HOME_LON * DEG2RAD;
    double lat_r = lat * DEG2RAD, lon_r = lon * DEG2RAD;
    double k_lat = 111132.92 - 559.82 * cos(2*lat_ref)
                 + 1.175 * cos(4*lat_ref) - 0.0023 * cos(6*lat_ref);
    double k_lon = 111412.84 * cos(lat_ref) - 93.5 * cos(3*lat_ref)
                 + 0.118 * cos(5*lat_ref);
    *x = (lon_r - lon_ref) * k_lon;
    *y = (lat_r - lat_ref) * k_lat;
}
 
// 预测步（含航向投影补偿）
static void kf2d_predict(KF2D_State *s, float a_body, float dt, float az_meas)
{
    float A = (float)s->att.yaw;
    float sinA = sinf(A), cosA = cosf(A);
    float a0 = a_body * cosA, a1 = a_body * sinA;
    s->x[0] += s->x[2]*dt + 0.5f*a0*dt*dt;
    s->x[1] += s->x[3]*dt + 0.5f*a1*dt*dt;
    s->x[2] += a0*dt;  s->x[3] += a1*dt;
    float dt2 = dt*dt, dt3 = dt2*dt, dt4 = dt3*dt;
    float q = Q_PROCESS;
    float p00 = s->P[0], p01 = s->P[1], p02 = s->P[2], p03 = s->P[3];
    float p10 = s->P[4], p11 = s->P[5], p12 = s->P[6], p13 = s->P[7];
    float p20 = s->P[8], p21 = s->P[9], p22 = s->P[10], p23 = s->P[11];
    float p30 = s->P[12], p31 = s->P[13], p32 = s->P[14], p33 = s->P[15];
    float n00 = p00 + dt*(p20+p02) + dt2*p22 + q*0.25f*dt4;
    float n01 = p01 + dt*(p21+p03) + dt2*p23;
    float n02 = p02 + dt*p22 + q*0.5f*dt3;
    float n03 = p03 + dt*p23;
    float n10 = p10 + dt*(p30+p12) + dt2*p32;
    float n11 = p11 + dt*(p31+p13) + dt2*p33 + q*0.25f*dt4;
    float n12 = p12 + dt*p32;
    float n13 = p13 + dt*p33 + q*0.5f*dt3;
    float n20 = p20 + dt*p22 + q*0.5f*dt3;
    float n21 = p21 + dt*p23;
    float n22 = p22 + q*dt2;
    float n23 = p23;
    float n30 = p30 + dt*p32;
    float n31 = p31 + dt*p33 + q*0.5f*dt3;
    float n32 = p32;
    float n33 = p33 + q*dt2;
    s->P[0]=n00;  s->P[1]=n01;  s->P[2]=n02;  s->P[3]=n03;
    s->P[4]=n10;  s->P[5]=n11;  s->P[6]=n12;  s->P[7]=n13;
    s->P[8]=n20;  s->P[9]=n21;  s->P[10]=n22; s->P[11]=n23;
    s->P[12]=n30; s->P[13]=n31; s->P[14]=n32; s->P[15]=n33;
}
 
// 量测更新（Joseph 形式）
static void kf2d_update(KF2D_State *s, float mx, float my)
{
    float r = R_MEAS;
    float p00=s->P[0], p01=s->P[1], p02=s->P[2], p03=s->P[3];
    float p10=s->P[4], p11=s->P[5], p12=s->P[6], p13=s->P[7];
    float p20=s->P[8], p21=s->P[9], p22=s->P[10], p23=s->P[11];
    float p30=s->P[12], p31=s->P[13], p32=s->P[14], p33=s->P[15];
    float s00 = p00 + r, s11 = p11 + r;
    float det = s00*s11;
    float inv00 = s11/det, inv01 = 0, inv10 = 0, inv11 = s00/det;
    float k00 = p00*inv00, k01 = p01*inv11;
    float k10 = p10*inv00, k11 = p11*inv11;
    float k20 = p20*inv00, k21 = p21*inv11;
    float k30 = p30*inv00, k31 = p31*inv11;
    float y0 = mx - s->x[0], y1 = my - s->x[1];
    s->x[0] += k00*y0 + k01*y1;  s->x[1] += k10*y0 + k11*y1;
    s->x[2] += k20*y0 + k21*y1;  s->x[3] += k30*y0 + k31*y1;
    float ikh00 = 1.0f-k00, ikh01 = -k01, ikh10 = -k10, ikh11 = 1.0f-k11;
    float ikh20 = -k20, ikh21 = -k21, ikh30 = -k30, ikh31 = -k31;
    float t00 = ikh00*p00 + ikh01*p10, t01 = ikh00*p01 + ikh01*p11;
    float t02 = ikh00*p02 + ikh01*p12, t03 = ikh00*p03 + ikh01*p13;
    float t10 = ikh10*p00 + ikh11*p10, t11 = ikh10*p01 + ikh11*p11;
    float t12 = ikh10*p02 + ikh11*p12, t13 = ikh10*p03 + ikh11*p13;
    float t20 = ikh20*p00 + ikh21*p10, t21 = ikh20*p01 + ikh21*p11;
    float t22 = ikh20*p02 + ikh21*p12, t23 = ikh20*p03 + ikh21*p13;
    float t30 = ikh30*p00 + ikh31*p10, t31 = ikh30*p01 + ikh31*p11;
    float t32 = ikh30*p02 + ikh31*p12, t33 = ikh30*p03 + ikh31*p13;
    s->P[0]  = t00*ikh00 + t01*ikh10 + k00*r*k00 + k01*r*k01;
    s->P[1]  = t00*ikh01 + t01*ikh11 + k00*r*k10 + k01*r*k11;
    s->P[2]  = t00*ikh20 + t01*ikh30 + k00*r*k20 + k01*r*k21;
    s->P[3]  = t00*ikh21 + t01*ikh31 + k00*r*k30 + k01*r*k31;
    s->P[4]  = t10*ikh00 + t11*ikh10 + k10*r*k00 + k11*r*k01;
    s->P[5]  = t10*ikh01 + t11*ikh11 + k10*r*k10 + k11*r*k11;
    s->P[6]  = t10*ikh20 + t11*ikh30 + k10*r*k20 + k11*r*k21;
    s->P[7]  = t10*ikh21 + t11*ikh31 + k10*r*k30 + k11*r*k31;
    s->P[8]  = t20*ikh00 + t21*ikh10 + k20*r*k00 + k21*r*k01;
    s->P[9]  = t20*ikh01 + t21*ikh11 + k20*r*k10 + k21*r*k11;
    s->P[10] = t20*ikh20 + t21*ikh30 + k20*r*k20 + k21*r*k21;
    s->P[11] = t20*ikh21 + t21*ikh31 + k20*r*k30 + k21*r*k31;
    s->P[12] = t30*ikh00 + t31*ikh10 + k30*r*k00 + k31*r*k01;
    s->P[13] = t30*ikh01 + t31*ikh11 + k30*r*k10 + k31*r*k11;
    s->P[14] = t30*ikh20 + t31*ikh30 + k30*r*k20 + k31*r*k21;
    s->P[15] = t30*ikh21 + t31*ikh31 + k30*r*k30 + k31*r*k31;
}

B.11 锥桶 TLS 直线拟合
static int fitTotalLeastSquaresLine(float *xs, float *ys, int n, float *theta)
{
    if (n < 2) return 0;
    float mean_x = 0, mean_y = 0;
    for (int i = 0; i < n; i++) { mean_x += xs[i]; mean_y += ys[i]; }
    mean_x /= n; mean_y /= n;
    float sxx = 0, syy = 0, sxy = 0;
    for (int i = 0; i < n; i++)
    {
        float dx = xs[i] - mean_x, dy = ys[i] - mean_y;
        sxx += dx*dx; syy += dy*dy; sxy += dx*dy;
    }
    *theta = 0.5f * atan2f(2*sxy, sxx - syy);
    return 1;
}

B.12 贝塞尔曲线路径生成
static void bezier_cubic(const Point2D *p0, const Point2D *p1,
                         const Point2D *p2, const Point2D *p3,
                         float t, Point2D *out)
{
    float u = 1.0f - t;
    float b0 = u*u*u, b1 = 3*u*u*t, b2 = 3*u*t*t, b3 = t*t*t;
    out->x = b0*p0->x + b1*p1->x + b2*p2->x + b3*p3->x;
    out->y = b0*p0->y + b1*p1->y + b2*p2->y + b3*p3->y;
}
 
int generate_bezier_cone_path(const Point2D *car_pos, float heading_rad,
    const ConePosition *left_cones, int left_count,
    const ConePosition *right_cones, int right_count,
    Point2D *out_points, int max_points)
{
    float center_x = 0, center_y = 0; int total = 0;
    for (int i = 0; i < left_count; i++)
    { center_x += left_cones[i].x; center_y += left_cones[i].y; total++; }
    for (int i = 0; i < right_count; i++)
    { center_x += right_cones[i].x; center_y += right_cones[i].y; total++; }
    if (total == 0) return 0;
    center_x /= total; center_y /= total;
    float t2x = 0, t2y = 0, t1x = 0, t1y = 0; int cnt2 = 0, cnt1 = 0;
    for (int i = 0; i < left_count; i++)
    {
        if (left_cones[i].y > 0.8f)
        { t2x += left_cones[i].x; t2y += left_cones[i].y; cnt2++; }
        else { t1x += left_cones[i].x; t1y += left_cones[i].y; cnt1++; }
    }
    for (int i = 0; i < right_count; i++)
    {
        if (right_cones[i].y > 0.8f)
        { t2x += right_cones[i].x; t2y += right_cones[i].y; cnt2++; }
        else { t1x += right_cones[i].x; t1y += right_cones[i].y; cnt1++; }
    }
    if (cnt2 > 0) { t2x /= cnt2; t2y /= cnt2; }
    if (cnt1 > 0) { t1x /= cnt1; t1y /= cnt1; }
    float vx = t2x - t1x, vy = t2y - t1y;
    float vlen = sqrtf(vx*vx + vy*vy);
    if (vlen < 1e-3f) { vx = 0; vy = 1; vlen = 1; }
    float dir_x = vx/vlen, dir_y = vy/vlen;
    Point2D p0 = { car_pos->x, car_pos->y };
    Point2D p3 = { center_x, center_y };
    float dist = sqrtf((p3.x-p0.x)*(p3.x-p0.x) + (p3.y-p0.y)*(p3.y-p0.y));
    float d1 = 0.25f * dist, d2 = 0.75f * dist;
    float hx = cosf(heading_rad), hy = sinf(heading_rad);
    Point2D p1 = { p0.x + hx*d1, p0.y + hy*d1 };
    Point2D p2 = { p3.x - dir_x*d2, p3.y - dir_y*d2 };
    int num = (max_points < 12) ? max_points : 12;
    for (int i = 0; i < num; i++)
    {
        float t = (float)i / (num - 1);
        bezier_cubic(&p0, &p1, &p2, &p3, t, &out_points[i]);
    }
    return num;
}

B.13 OTSU 大津法自适应阈值
short LQ_GetOSTU (unsigned char tmImage[LCDH][LCDW])
{
    signed short i, j;
    unsigned long PixelAmount = 0;
    unsigned long PixelIntegral = 0;
    signed short Delta, DeltaB;
    unsigned long NewAvg = 0, NewAvgB = 0, Count = 0, CountB = 0;
    unsigned long Max = 0;
    unsigned long Total = 0;
    short Threshold = 0;
    unsigned long HistoGram[256];
    unsigned long Widest = 0;
    unsigned long Min1 = 100000, Min2 = 100000;
    unsigned long Ave, Ave2, Ave3;
    signed short Max1, Max2;
    float T;
    for (j = 0; j < LCDH; j++)
        for (i = 0; i < LCDW; i++)
            HistoGram[tmImage[j][i]]++;
    for (i = 0; i < 256; i++)
    {
        Total += HistoGram[i];
        PixelIntegral += HistoGram[i] * i;
    }
    for (i = 0; i < 256; i++)
    {
        PixelAmount += HistoGram[i];
        NewAvg += HistoGram[i] * i;
        Count = Total - PixelAmount;
        if (Count == 0) break;
        NewAvgB = PixelIntegral - NewAvg;
        Delta = PixelAmount * NewAvgB - Count * NewAvg;
        if (Delta * Delta > Max * PixelAmount * Count)
        {
            Max = Delta * Delta / (PixelAmount * Count);
            Threshold = i;
        }
    }
    Count = Total;
    Ave = PixelIntegral / Count;
    for (i = 0; i < 256; i++)
    {
        DeltaB = i - Ave;
        if (DeltaB < 0) DeltaB = -DeltaB;
        Widest += HistoGram[i] * DeltaB * DeltaB;
    }
    T = 4.0f * sqrt(Widest / Count) / Ave;
    Ave2 = 0; Ave3 = 0;
    Count = 0; CountB = 0;
    for (i = 0; i < Threshold; i++)
    {
        Count += HistoGram[i];
        Ave2 += HistoGram[i] * i;
    }
    for (i = Threshold; i < 256; i++)
    {
        CountB += HistoGram[i];
        Ave3 += HistoGram[i] * i;
    }
    if (Count) Ave2 = Ave2 / Count;
    if (CountB) Ave3 = Ave3 / CountB;
    Max1 = Ave2 + T * (Ave3 - Ave2);
    Max2 = Ave2 + (Ave3 - Ave2) / T;
    return (Max1 + Max2) / 2;
}
B.14 车轮绝对角度闭环（project/code/steer.c）
// 角度误差归一化到 [-180, 180]
static float _servo_angle_err_norm(float err)
{
    while(err >  180.0f) err -= 360.0f;
    while(err < -180.0f) err += 360.0f;
    return err;
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介     车轮角度闭环 PID 更新（磁编码器绝对值反馈）
// 参数说明     s              控制结构体指针
// 参数说明     enc            当前磁编码器绝对值（0~MOTOR_ENCODER_PRECISION）
// 参数说明     out_duty       输出占空比指针（±10000，经 UART 下发驱动板）
//-------------------------------------------------------------------------------------------------------------------
void motor_servo_update(motor_servo_ctrl_t *s, uint16 enc, float *out_duty)
{
    if(!s->enable)
    {
        *out_duty = 0.0f;
        return;
    }

    float cur_angle = (float)enc / (float)MOTOR_ENCODER_PRECISION * 360.0f;  // 当前角度 0~360°
    float err       = _servo_angle_err_norm(s->target_angle - cur_angle);    // 最短路径误差

    if(fabsf(err) < s->deadzone)        // 死区：误差在 ±deadzone° 以内直接停止输出
    {
        *out_duty     = 0.0f;
        s->integral   = 0.0f;
        s->last_error = err;
        return;
    }

    s->integral += err;
    if(s->integral >  300.0f) s->integral =  300.0f;    // 积分限幅
    if(s->integral < -300.0f) s->integral = -300.0f;

    float output = s->kp * err
                 + s->ki * s->integral
                 + s->kd * (err - s->last_error);
    s->last_error = err;

    if(output >  s->output_limit) output =  s->output_limit;   // 输出限幅
    if(output < -s->output_limit) output = -s->output_limit;

    if(s->dir == 1) output = -output;     // 左电机反转

    *out_duty = output;
}
