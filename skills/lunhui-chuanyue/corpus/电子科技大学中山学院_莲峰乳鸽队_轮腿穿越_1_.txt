摘要
本文针对第二十一届全国大学生智能汽车竞赛轮腿穿越组赛事需求，设计并实现了一套基于CYT4BB7主控的轮腿式智能车系统。整车以轮腿复合结构为载体，结合总钻风灰度摄像头视觉识别、LSM6DSRTR六轴陀螺仪姿态解算、多周期串级PID控制算法，实现赛道循迹、姿态平衡、越障跳跃、定点行驶等赛事功能。
硬件方面，系统完成主控最小系统、多级稳压电源、陀螺仪恒温电路等模块设计，保证设备在颠簸、光照变化、大电流负载工况下稳定工作。软件采用“主循环感知层+1ms中断控制层”双架构，将图像采集、人机交互与实时运动控制解耦。通过多周期PID分时调度、车身姿态保护、PID软启动、跳跃模式自适应降参、陀螺仪航向补偿等算法优化，有效解决了轮腿车起步抖动、高速漂移、落地失稳、姿态漂移等问题。
经过分模块调试与整车联调，本车能够稳定完成赛道识别、差速循迹、姿态自平衡、分段式越障跳跃等任务，整体可靠性、实时性与环境适应性均满足轮腿穿越组竞赛要求。
关键词：CYT4BB7、总钻风灰度摄像头、陀螺仪、差速循迹





第一章：引言
1.1智能车研究背景
随着机器人技术、嵌入式控制、机器视觉与多体运动控制技术持续发展，兼具移动能力与环境适应能力的移动机器人成为智能领域重要研究方向。轮腿复合机器人结合轮式移动高速高效、腿式机器人越障能力强的优势，能够在平整路面快速行进，同时应对台阶、沟壑、颠簸路面、单边桥等复杂非结构化地形，在巡检、抢险、野外探测等场景具备广阔应用前景。
1.2智能车发展现状（轮腿）
轮腿复合机器人融合轮式机构高速移动与腿式机构优秀越障的优势，近年来成为移动机器人领域研究热点。国外相关研究起步较早，多款成熟轮腿样机依托多自由度关节、先进控制算法实现复杂地形自适应通行，但设备成本高、结构复杂。
国内各大高校持续开展轮腿机器人样机研发，重点针对台阶、颠簸路面优化机械结构与姿态控制算法。在全国大学生智能汽车竞赛中，轮腿穿越组别参赛方案主要分为多舵机主动轮腿结构与六无刷轮腿结构两类。
1.3报告框架
报告整体遵循“理论铺垫—方案设计—硬件搭建—软件开发—调试优化”的完整逻辑逐层展开撰写，首先结合轮腿智能车的研究背景与发展现状，明确本次参赛车辆的设计目标与核心设计思路，确定整体软硬件架构方案；其次完成各功能器件的选型与安装，详细阐述主控、摄像头、陀螺仪等核心器件的选型依据与安装方案；随后系统性介绍整车硬件电路设计，涵盖核心最小系统、各级电源电路、传感器及外设驱动电路等硬件模块；在此基础上，分层拆解软件程序设计内容，依次对姿态感知、视觉图像处理、舵机与电机驱动、多周期PID控制、车辆状态自适应管理等核心软件模块进行详细说明；最后介绍系统开发环境与分阶段模块化调试流程，梳理调试过程中遇到的问题及优化方案，并总结全文工作成果、创新亮点与现存不足，同时提出后续优化方向，形成完整且严谨的智能车系统设计报告。
第二章：项目设计思路
本车以CYT4BB7主控芯片作为核心控制单元，搭载总钻风灰度摄像头完成赛道图像采集与图像解析工作，结合无刷电机差速控制算法实现车身稳定循迹行驶。姿态感知与惯性导航功能由LSM6DSRTR陀螺仪模块实现，实时采集车身姿态数据并完成姿态校正，保障车体行驶稳定性与运动控制精度。
动力驱动方面，整车采用电调驱动无刷电机，搭配BDS300舵机完成车体转向与轮腿姿态调节。系统配备四位拨码开关与独立功能按键，可快速切换车辆运行模式、调试参数。同时搭载TFT显示屏与蜂鸣器模块，实现参数可视化显示、工作状态提示及故障预警，极大提升调试与实操便捷性。
此外，车辆尾部增设自制灯光创意灯板。整车配合逐飞接收器实现可靠信号接收与远程控制，完善整车人机交互与状态指示体系，满足轮腿穿越组多场景、多模式的赛事运行需求。

第三章：器件的选型与安装
3.1摄像头部分
3.1.1摄像头选型
视觉采集选用总钻风灰度摄像头，FPC2 为总钻风摄像头 FPC 接插件，连接单片机多组 IO 口，包含 8 位数据信号 ZZF_D0~D7、行场同步信号 ZZF_VS、串口收发 ZZF_TX/RX 以及像素时钟 ZZF_PCLK，实现图像数据的采集传输。接口采用 3.3V 供电，并联 22μF 与 100nF 滤波电容 C67、C66 完成电源滤波降噪，保障摄像头供电稳定。该摄像头采用全局快门 CMOS 传感器，相较于卷帘快门摄像头，车辆高速行驶、颠簸越障过程中不易产生图像拖影畸变；支持帧率、曝光参数软件可调，环境光照适应性更强。模块输出灰度图像，有效降低主控图像处理开销；搭配并行 DVP 接口传输图像，数据传输实时性高、延迟低，可以持续输出清晰稳定的画面，满足锥桶识别、雷区检测、障碍边界提取等视觉任务需求，为轮腿智能车循迹、障碍预判与步态切换提供可靠图像信息。

3.3.1 陀螺仪选型

第四章：硬件开发设计说明
4.1核心板电路
我们采用英飞凌CYT4BB7 单片机作为控制核心，CYT4BB7 具备高速运算、三核异构处理与强大实时计算能力。它的主 Cortex-M7 内核主频高达 250 MHz，采用双 Cortex-M7 加 Cortex-M0 + 三核架构，可实现任务解耦并行处理，能够满足复杂实时应用的需求。CYT4BB7 核心板集成了丰富的外设功能，包含多路 CAN-FD 接口、多路 UART、SPI、I2C 通信接口，多路 PWM 输出，同时搭载多路模拟输入输出与多通道高精度 12 位 ADC 模块。这些外设资源可用于连接和控制各类传感器、执行器与外部设备，完整实现整套系统各项功能。其最小系统原理图如下：

4.2电源电路
4.2.1舵机电源
本系统采用四路独立同步降压 DC-DC 电源作为舵机供电核心，四路电源电路结构完全一致，相互独立输出，能够为多路舵机提供大电流、低纹波的稳定供电。该降压芯片支持大电流输出，具备内部过流保护、过压保护、过热保护功能，可应对舵机瞬间大电流冲击的工况。每路电源配置 4.7μH 功率电感，输入端配置大容量电解电容搭配多颗陶瓷电容组合滤波，抑制电源输入侧的电压尖峰与噪声；输出端同样采用大容量电解电容并联多颗陶瓷电容，实现输出纹波抑制，保障舵机工作时电压稳定。
每路电源均配置分压电阻反馈网络，通过电阻分压设置输出电压，适配舵机额定工作电压；同时芯片使能引脚、电源良好指示引脚配套外围电阻，可实现电源使能控制与电源状态监测。四路独立电源相互隔离，各路舵机负载之间互不干扰，避免多路舵机同时动作产生的大电流互相串扰，防止电压跌落。该电源模块可用于多路舵机等大功率执行机构的供电，满足舵机频繁启停、瞬间大电流拉载的使用场景，保障整套执行机构稳定可靠运行。

图4-2-1舵机电源电路原理图
4.2.2 5V电源输出电路
本系统采用同步降压 DC-DC 芯片实现 5V 电源输出，芯片内置过流、过压、过热保护，为主控、传感器等外设提供供电。输入端增加防反接保护，搭配多组电容滤波，配合 4.7μH 功率电感完成电压转换。通过 FB 分压电阻配置 5V 输出电压，EN 引脚支持主控使能控制，PG 引脚反馈电源状态。输出端采用电解与陶瓷电容并联，降低输出纹波；同时设置状态指示 LED，直观反映电源工作状态。模块可适应负载动态变化，保障系统数字电路稳定运行。

图4-2-2 5V电源输出电路原理图
4.2.3 3.3V电源输出电路
采用 RT9013-33GB 线性 LDO 芯片，将 5V 电压转换为稳定 3.3V，为 CYT4BB7 主控内核及外设供电。输入端并联 10μF 与 100nF 电容滤除电源噪声，芯片 EN 引脚直接接 5V 持续使能。输出端配置 10μF、100nF 滤波电容，搭配 SMF3.3A 稳压管做输出保护，抑制浪涌尖峰。电路增设电源指示 LED，直观反馈 3.3V 电源工作状态。该 LDO 输出噪声低，外围电路简洁，可为主控芯片提供干净稳定的核心供电。

图4-2-3 3.3V电源输出电路原理图
4.3自制灯板
电路为多颗 5050 RGB LED，采用共阳极架构，LED 阳极统一接 5V，红、绿、蓝三色负极分别由三路 SS8050 NPN 三极管做低侧驱动开关。三极管基极串联 1kΩ 限流电阻接入主控 IO，搭配 4.7kΩ 下拉电阻，IO 悬空时保证三极管可靠关断；三色支路分别串联 220Ω/330Ω 限流电阻，限制 LED 工作电流。U1 为 XH2.54-6P 接插件，引出控制信号、5V 与 GND，支持外接拓展 RGB 灯带。主控 IO 输出高电平时三极管导通，对应颜色 LED 点亮；输出 PWM 信号调节占空比，可实现多色混光，用于设备状态指示与灯光效果展示。

图4-3-1 自制灯板电路原理图
4.4 按键、开关电路
电路包含 4 位拨码开关 与 4 路独立按键。3V3 通过 4.7kΩ 电阻作为上拉，开关 / 按键导通时引脚被拉至 GND；每条通路串联 470Ω 限流电阻，保护单片机 IO。拨码开关 SW1 对应 IO 21.6、21.5、22.5、22.6，按键对应 IO 20.3、20.2、20.1、20.0。单片机读取引脚电平，即可识别拨码档位与按键触发状态，用于模式选择、参数配置与人机交互。

图4-4-1 按键、开关电路原理图
4.5陀螺仪与恒温加热部分
陀螺仪单元采用 LSM6DSRTR 芯片，芯片供电为 3V3，搭配 100nF 电源滤波电容 C73。I2C 通信引脚 SDA、SCL、CS、SDO/SA0 连接对外 FPC 接口，INT1、INT2 为中断输出引脚。LED2 为状态指示灯，经 4.7kΩ 限流电阻接 3V3，用于指示模块工作状态。
恒温加热电路包含 NTC 热敏电阻 U36 与 AO3400 NMOS 管 Q2。NTC 接到主控 ADC0_P08_1 引脚，采集当前温度；主控输出 PWM_P09_0 信号，经 10kΩ 电阻 R3 驱动 MOS 管。MOS 管导通控制加热电阻 R9、R10 工作，通过 PWM 占空比调节加热功率，实现陀螺仪模组恒温，减小温度漂移对姿态采样的影响。L1 为磁珠，用于 FPC 接口电源滤波，抑制电源噪声。

图4-5-1 陀螺仪与恒温加热电路原理图
4.6蜂鸣器电路
使用SS8050 NPN 三极管，作为开关驱动 2.7kHz 有源蜂鸣器 BUZZER1。主控 IO (19.4) 输出控制信号，经 1kΩ 电阻 R18 接入三极管基极；R19 为 4.7kΩ 下拉电阻，IO 悬空时保证三极管可靠关断。R17 (10Ω) 为蜂鸣器限流电阻；D3 (1N4148W) 续流二极管，吸收蜂鸣器断电产生的反向感应电动势，保护三极管。IO 输出高电平时三极管导通，蜂鸣器鸣响；输出低电平则停止发声，用于状态提示、报警提醒。

图4-6-1 蜂鸣器电路原理图
4.7磁编电路
本电路采用 TLE5012BE1000 磁编码器芯片，电源输入端配置 SMF3.3A 稳压管做 ESD 防护，搭配 10μF 与 100nF 电容组成电源滤波网络，滤除供电噪声，保证芯片供电稳定。芯片通过 SPI 总线与主控进行通信，SCK、CS、MOSI 信号串联限流电阻，MISO 设置 470Ω 上拉电阻，提升信号完整性，抑制长线传输干扰。外接 6P 接插件对外引出 SPI 全部信号与供电、地引脚，方便与外部磁码盘结构对接，实现角度位置数据采集，为主控提供角度反馈信息。

图4-7-1 磁编电路原理图
4.8无刷电调驱动电路
主控以CYT2BL3系列单片机作为核心控制器，外部配置16MHz晶振提供系统工作时钟，内核电源、模拟参考电源分别配置多组去耦电容，滤除电源噪声，保障主控稳定运行。芯片引出PWM控制信号输出至驱动芯片，同时引出SPI通信接口外接编码器，获取电机转速位置信息；配置复位按键与模式按键，实现系统复位与功能模式切换；预留调试下载接口，用于程序烧录与在线调试，状态指示灯通过IO口进行控制，直观反馈系统运行状态。主控同时引出UART串口，用于和外部设备的数据交互，完成整机控制逻辑运算、信号采集与电机驱动输出。

{

    {
        int16 base_duty = (int16)roll_balance_cascade.angular_speed_cycle.out;
        base_duty = func_limit_ab(base_duty, -BALANCE_DUTY_MAX, BALANCE_DUTY_MAX);

        left_motor_duty  = base_duty - turn_pwm + imu660rb_gyro_z / JGEOYXUE;
        right_motor_duty = base_duty + turn_pwm - imu660rb_gyro_z / JGEOYXUE;
        left_motor_duty = func_limit_ab(left_motor_duty, -TURN_DUTY_MAX, TURN_DUTY_MAX);
        right_motor_duty = func_limit_ab(right_motor_duty, -TURN_DUTY_MAX, TURN_DUTY_MAX);
    }
    else
    {
        left_motor_duty  = 0;
        right_motor_duty = 0;
    }
    small_driver_set_duty(-left_motor_duty, right_motor_duty);
}
5.5.2模块说明
无刷电机由电调驱动，依靠差速实现前进、转向。
输出量组成解析：
base_duty：平衡角速度环 PID 输出，维持车体直立的基础动力；
2、turn_pwm：转向串级 PID 输出，实现左右轮差速转向；
3、imu660rb_gyro_z //JGEOYXUE：Z 轴陀螺仪角速度补偿项，抑制转向时航向漂移；
所有占空比进行上下限幅，避免电机功率饱和。车辆停止时直接清零占空比。

第七章：结论
7.1 工作总结
本文完整完成了轮腿式智能车的整体设计、硬件搭建、软件编程与整车调试工作。机械结构采用轻量化轮腿布局，适配赛道越障与高速行驶需求；硬件电路完成多级电源系统、传感器接口、执行器驱动及拓展外设设计，电路稳定性强、抗干扰能力优异。软件系统采用分层架构设计，主循环负责图像采集与人机交互，定时器中断负责高频姿态解算与运动控制，保证系统运行稳定、逻辑清晰、实时性高。
控制算法上，本车采用多周期串级PID控制方案，分别实现角度平衡、角速度闭环、速度闭环与转向闭环。同时加入上电软启动、倾角安全保护、跳跃自适应参数调整、Z轴陀螺仪航向补偿等优化策略，有效提升车辆起步平顺性、行驶稳定性与越障容错能力。视觉模块依靠总钻风摄像头完成赛道特征提取，输出稳定横向偏差，为车辆循迹行驶提供可靠输入。最终整车可稳定完成绕桩循迹、姿态平衡、分段跳跃越障等全部赛事核心任务。
7.2 创新与亮点
本次设计采用独立多路舵机电源方案，有效避免多舵机同步动作带来的电压跌落与串扰问题；针对陀螺仪漂移问题设计恒温加热电路，大幅提升姿态采样稳定性。软件层面采用多速率PID分时调度，在保证控制精度的同时降低主控运算压力。针对轮腿跳跃工况，设计四段式时序跳跃状态机并搭配自适应降参逻辑，解决腾空、落地阶段车体失控问题。同时搭载自定义灯板、按键与拨码多模式切换，人机交互便捷，调试效率高。
7.3 现存不足
车辆在高速连续弯道场景下，视觉识别容错性仍有提升空间；越障落地瞬间仍存在小幅姿态波动；未完全引入速度前馈算法，极限工况下响应速度仍有优化余地。同时复杂光影变化场景下，单一灰度视觉识别抗干扰能力有限。
7.4 未来优化方向
后续可引入图像预处理滤波与自适应阈值算法，提升复杂光照下赛道识别稳定性；增加速度前馈与姿态预测算法，进一步提升弯道与越障动态响应效果；优化跳跃时序参数，提升落地缓冲稳定性；
同时可加入更多传感器融合策略，进一步提升整车定位精度与环境适应性；同时还可以对整车车身架构进行迭代优化，重新规划 PCB 电路板尺寸与器件摆放位置，优化整车重心分布，减少线缆杂乱带来的电磁干扰，提升车体结构紧凑度与机械抗冲击能力。
在动力方案上，考虑将当前四舵机搭配两无刷电机的驱动方案升级为六无刷电机驱动架构，进一步提升车体动力储备，增强轮腿机构的地形适应与越障能力，更好应对台阶、颠簸路面等复杂赛道工况。

    car_state_calculate();   // 检测车身状态
    car_steer_control();     // 舵机控制
    car_motor_control();     // 电机控制
}
