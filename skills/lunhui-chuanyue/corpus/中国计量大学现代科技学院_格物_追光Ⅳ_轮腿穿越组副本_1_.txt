摘要
本文详细介绍了中国计量大学现代科技学院在第二十一届全国大学生智能汽车竞赛室外轮腿组别的系统方案。我队选择自制车模即对逐飞V车模进行改造，以英飞凌科技公司生产的CYT4BB7微控制器为核心控制器，配合CYT2BL3驱动控制器实现无刷电机的底层驱动，采用IMU与编码器融合实现局部位置估计与姿态感知，通过灰度摄像头识别台阶、单边桥等道路元素，利用磁编码器检测两个无刷电机转速，结合四路舵机驱动的轮腿机构，使用PID控制算法及卡尔曼滤波实现对车速、腿高与运动方向的闭环控制。为提高复杂地形下的通过性与稳定性，对车模底板进行加宽改造，并采用3D打印电池壳下置方案，配合TFT180屏幕、按键及无线调试工具进行了大量硬件与软件测试。实验结果表明，该系统能够稳定完成绕桩、定点排雷及多地形穿越任务，方案切实可行。

第二章 模型车设计制作的主要思路以及实现的技术方案
2.1设计目标与总体思路
本车针对第二十一届全国大学生智能汽车竞赛室外轮腿组别设计。室外赛道环境复杂，要求车辆具备较好的通过性、姿态稳定性和自主控制能力。因此，本车选用逐飞V车模作为基础平台，并对原车底板进行加宽处理，以增大安装面积、降低整车重心、提高复杂路面条件下的行驶稳定性。
整体方案采用“上层感知决策、下层驱动执行”的主从式结构。上层以CYT4BB7主板为核心，完成图像采集、姿态解算、路径识别与控制决策；下层以CYT2BL3驱动板为执行核心，完成无刷电机和舵机的驱动控制。主板与驱动板之间通过UART进行实时通信。
2.2整车系统组成
执行机构方面，整车配置四个BDS300舵机、两个无刷电机和两个磁编码器。四个BDS300舵机用于轮腿机构关节驱动执行，实现轮腿姿态调整和速度控制；两个无刷电机作为主动力源，配合越野轮胎使用，提高室外路面驱动能力；两个磁编码器分别用于检测两个无刷电机的转速信号，为速度闭环和里程估计提供反馈。
传感器系统方面，摄像头安装于主板中心位置，用于获取前方道路及目标信息；逐飞RC陀螺仪用于采集车体角速度、加速度及姿态信息；磁编码器用于轮速和位置反馈。
控制系统方面，采用CYT4BB7主板与CYT2BL3驱动板组成双层控制结构。主板负责高层决策和传感器数据处理，驱动板负责底层行进电机驱动，二者通过UART交互控制指令、状态信息和反馈数据。
2.3技术实现方案概要
感知采用“视觉+惯性+磁编”多源信息融合方式：摄像头提供前方目标与道路信息，陀螺仪提供车身姿态信息，磁编码器提供车轮速度、位置信息。控制上采用分层闭环结构，上层根据视觉和姿态信息进行路径规划和轮腿动作规划，下层完成无刷电机速度闭环和BDS300舵机角度控制。

结构上，3D打印电池仓安装在底板最下方，以降低整车重心；主板在上、驱动板在下，通过铜柱连接并固定到车模底板。该方案便于模块化安装与维护，减少动力线干扰，提高系统在室外振动环境下的可靠性。
2.4 主要技术参数
整车主要技术参数：总体重量：1.170 kg；长260 mm、宽170 mm、高330 mm；电路功耗：5 W；所有电容总容量：200 μF；轴距185 mm、轮距138 mm；传感器为 MT9V03 摄像头×1、IMU660RC 陀螺仪×1、自制磁编码器×2；新增伺服电机为 BDS300×4；传动机构未改装，未更换原装车模机械元器件；赛道信息检测精度：20 cm；检测频率：600 Hz。

第三章 车模搭建、传感器的设计安装、电路板的固定
3.1车模搭建
原逐飞V车模底板空间有限，在安装四组舵机、无刷电机、传感器及双层电路板后，安装空间较为紧张。因此，本车对底板进行加宽处理，增加有效安装面积，使各模块布置更加合理，同时提高越野路面行驶时的横向稳定性。
四个BDS300舵机安装于轮腿机构的相应关节位置，实现轮腿动作和速度控制；两个无刷电机作为动力来源，轮胎选用越野轮胎，以增强室外复杂路面的附着力。两个磁编码器安装于无刷电机或车轮转轴处，用于测量转速和位置信号。
电池仓采用3D打印工艺制作，安装在底板最下方。将电池布置在整车较低位置，可有效降低重心，提高车辆行驶稳定性和抗侧倾能力。整车整体布置自上而下为“主板—驱动板—车模底板—电池仓”，模块分区清晰，便于安装、调试和维护。
3.2传感器设计安装
摄像头的镜头采用140度智能车竞赛高清大镜头镜头组CCD组双车组通用兼容镜头无畸变，安装在主板中心位置。增加滤光片过滤强光，并通过3d打印件接到镜头前，光轴尽量与车体纵轴保持一致，保证前视图像左右对称、视野居中，为赛道识别和路径规划提供稳定的图像输入。
采用逐飞RC陀螺仪安装于电池仓槽中，靠近整车重心，并采取减振处理，降低车体振动对姿态数据的干扰。
磁编码器通过机械连接安装于电机轴端，保证与被测轴同步转动，提高测速和位置反馈精度。
3.3系统电路板固定及连接
整车电路板采用上下分层布置。主板CYT4BB7位于上层，驱动板CYT2BL3位于下层，两板之间通过铜柱连接成一个整体，再与车模底板固定。该布置方式使主板远离驱动板功率器件和电机动力线，减少电磁干扰；驱动板位于下层，靠近无刷电机和舵机，便于缩短大电流动力线，降低线路损耗。
3.4 电路设计说明
主板与驱动板之间通过UART进行通信，传输控制指令、状态反馈及传感器数据。电源线、电机动力线、舵机信号线和通信线分类布置并固定，防止因行驶振动导致插头松动或信号干扰。
第四章微处理器控制软件主要理论、算法说明及代码设计介绍等
4.1 传感器数据预处理
4.1.1姿态解算（四元数EKF）
IMU660RC提供三轴加速度、陀螺仪数据。采用四元数误差状态卡尔曼（ESKF）进行姿态估计。系统状态为四元数（4维）与陀螺仪零偏（2维，Z轴零偏不估计）。预测阶段采用四元数微分方程，并使用加速度计归一化重力向量作为观测更新。算法实现见QuaternionEKF.c，关键流程代码如下：C

4.1.2定位融合（编码器+IMU）
定位子系统在本车实际运行中融合轮速里程计与 IMU 信息，未启用 GPS 或 RTK。采用误差状态卡尔曼滤波对轮速和惯性信息进行估计，并通过 ZUPT 抑制静止阶段的漂移。工程中的 KF_GPS_ENC.c 保留了 GPS/编码器融合接口，但 GPS 更新分支未接入本车实际控制链路。
4.2 路径规划
4.2.1锥桶绕桩路径生成（科目一）
科目一比赛要求从发车区出发直行至掉头区，返程依次穿过锥桶间隙。我们在准备阶段通过手动记录锥桶坐标（菜单打点）存储于Flash，或现场利用里程计记录。路径生成算法见GD.c中GD_Generate_Task_Path()。其中，直行段长度可调（STRAIGHT_DIST_VAR）；掉头段采用半圆弧，半径UTURN_RADIUS_VAR，方向由最远锥桶位置决定；返程绕桶路径使用Catmull-Rom样条通过锥桶偏移点（偏移量CONE_OFFSET_VAR），并利用安全距离SAFE_CLR避开锥桶；生成路径经过重采样，点间距约2cm，形成平滑轨迹。 [5]

4.2.2 定点排雷路径（科目二）
科目二需要依次到达多个旋转点并原地转圈。路径生成算法GD_Generate_Task_Point_Path()。首先将用户记录的任务点按顺序连接直线段，并在最后一个点（终点）前生成半圆形掉头路径；旋转点处路径与任务点重合，旋转完成后继续下一段直线；路径点带航向信息，用于旋转结束后的方向引导。
4.2.3 科目三元素路径
科目三包含多个固定元素（楼梯、桥、颠簸路、草地等），我们通过关键（keypts）描述元素位置和方向，并在菜单中录制或调整。路径生成算法GD_Generate_Ordered_Path()。按照设定的元素顺序，使用三次贝塞尔曲线连接元素之间的过渡段；每个元素内部的路段根据元素长度和方向生成直线；掉头点为折返点，之后生成返程路径。

第五章 开发工具、制作、安装、调试过程说明
5.1 开发工具
开发工具包括：IAR Embedded Workbench 9.40.1（CYT4BB7/CYT2BL3同用）作为IDE；J-Link或CMSIS-DAP作为调试器；逐飞助手（查看图像、波形、调参）、逐飞上位机、VOFA+、TCP调试工具作为上位机；SolidWorks用于3D打印件机械设计；示波器、万用表、电子负载、热风枪作为硬件调试工具。 [7]
5.2 制作、安装工具
一开始我们采用的是逐飞原装车模，但在提速过程中发现该车模有局限性，于是我们3d打印底板和舵机支架，又由于材料硬度不够，在网上找到3k碳纤维进行定制底板，支架选择FDM工艺中PETG进行打印，最后我们的车模趋于稳定。
5.3调试要点
姿态解算调试时，在静止状态下采集陀螺仪零漂并补偿，调节滤波参数使Pitch/Roll无漂移；定位融合调试时，进行编码器里程标定（每圈脉冲数），利用ZUPT适应室外停车；路径跟随调试时，调节前瞻距离、方向PID增益和速度PID，确保不同速度下稳定过弯；视觉元素调试时，调整图像曝光和阈值，结合不同光照条件提高识别鲁棒性；腿控制调试时，调试VMC逆解参数，限制舵机角度，避免机械碰撞。


第六章 结论总结
本车在逐飞V车模基础上完成了机械改造、硬件搭建和软件调试，实现了室外轮腿组多个科目的自主运行。整车采用上下分层控制架构，集成摄像头、陀螺仪、磁编码器等传感器，姿态解算和定位融合满足实时控制要求，路径跟随和腿部控制基本稳定，能够完成锥桶绕桩、定点排雷及规定元素通过等任务。调试中发现的主要问题是室外复杂环境下视觉识别鲁棒性不足。后续可从多曝光视觉处理、视觉、里程计融合、模型预测或自适应腿部控制等方面改进。其中最关键的问题是多传感器融合的可靠性与实时性平衡，我们提出了分层融合与自适应切换策略，在不同场景下动态调整各传感器的置信度，在保证计算效率的同时提高系统鲁棒性。

/* ==================== 单腿逆运动学求解 ==================== */
static void solve_one_leg(float anglePhi0, float length,
                          float *out_front, float *out_rear)
{
    /* 腿长限幅 */
    if (length > 150) length = 150;
    else if (length < 30) length = 30;

    /* 足端直角坐标 */
    float Xc = leg_gauge / 2 + cosf(anglePhi0 * _PI / 180.0f) * length;
    float Yc = sinf(anglePhi0 * _PI / 180.0f) * length;

    /* 前腿参数 */
    float a = 2 * Xc * Upper_leg;
    float b = 2 * Yc * Upper_leg;
    float c = Xc * Xc + Yc * Yc + Upper_leg * Upper_leg - Lower_leg * Lower_leg;

    /* 后腿参数 */
    float d = 2 * Upper_leg * (Xc - leg_gauge);
    float e = 2 * Upper_leg * Yc;
    float f = (Xc - leg_gauge) * (Xc - leg_gauge) + Upper_leg * Upper_leg + Yc * Yc - Lower_leg * Lower_leg;

    /* sqrt保护：防止判别式为负导致NaN */
    float disc_front = a * a + b * b - c * c;
    if (disc_front < 0) disc_front = 0;

    float disc_rear = d * d + e * e - f * f;
    if (disc_rear < 0) disc_rear = 0;

    /* 求解两组解 */
    float Alpha1 = 2 * atan2f(b + sqrtf(disc_front), a + c);
    float Alpha2 = 2 * atan2f(b - sqrtf(disc_front), a + c);
    float Beta1  = 2 * atan2f(e + sqrtf(disc_rear),  d + f);
    float Beta2  = 2 * atan2f(e - sqrtf(disc_rear),  d + f);

    /* Alpha 角度规范化到 [0, 2π) */
    Alpha1 = fmodf(Alpha1, 2 * PI);
    if (Alpha1 < 0) Alpha1 += 2 * PI;
    Alpha2 = fmodf(Alpha2, 2 * PI);
    if (Alpha2 < 0) Alpha2 += 2 * PI;

    /* Beta 角度规范化到 [-π, π) */
    Beta1 = fmodf(Beta1, 2 * PI);
    if (Beta1 < -PI) Beta1 += 2 * PI;
    else if (Beta1 > PI) Beta1 -= 2 * PI;
    Beta2 = fmodf(Beta2, 2 * PI);
    if (Beta2 < -PI) Beta2 += 2 * PI;
    else if (Beta2 > PI) Beta2 -= 2 * PI;

    /* 选择正确的解 */
    float FrontAngle, RearAngle;

    if (Alpha1 >= PI / 2 && Alpha1 <= 3 * PI / 2)
        FrontAngle = Alpha1;
    else
        FrontAngle = Alpha2;

    if (Beta1 >= -PI / 2 && Beta1 <= PI / 2)
        RearAngle = Beta1;
    else
        RearAngle = Beta2;

    /* 转换为舵机角度 */
    *out_front = 180.0f - (FrontAngle / _PI * 180.0f);
    *out_rear  = RearAngle / _PI * 180.0f;
}

/* ==================== 主函数：直接逆运动学解算（无平滑） ==================== */
void inverseKinematics_VMC(float Left_anglePhi0, float Left_Lenth,
                           float Right_anglePhi0, float Right_Lenth)
{
    float lf, lr, rf, rr;

    /* 直接使用输入值求解逆运动学 */
    solve_one_leg(Left_anglePhi0,  Left_Lenth,  &lf, &lr);
    solve_one_leg(Right_anglePhi0, Right_Lenth, &rf, &rr);

    Steer_AngleControl(lf, lr, rf, rr);
}
