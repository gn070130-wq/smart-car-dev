第一章、模型车设计制作的主要思路及技术方案概要
1.1 总体设计思路
本车以惯导为主、视觉为辅为设计思路，围绕三大科目（行进绕桩、定点排雷、颠簸路段）解决导航、平衡与越障三个核心问题。
车模平台选用龙邱六无刷轮腿车模：五连杆腿机构由 4 个关节无刷电机驱动，2 个无刷电机作为行进电机；主控采用逐飞 CYT4BB7 核心板，与 3 块自制无刷驱动板之间通过串口通信。

关键设计决策：
惯导为主、视觉为辅：三个科目的元素位置现场可测，导航采用纯惯导（IMU 航向 + 轮速里程），摄像头仅用于曝光 / 阈值标定与台阶识别，降低对视觉的依赖，提高室外可靠性；
双速度控制通路：直接串级（速度环 → 角度环）加减速快；间接控制（速度环 → 关节倾角 → 重心）车身稳定，按科目需求切换；
离线规划 + 在线调度：轨迹与任务序列发车前一次性生成，运行时按里程推进，各算法模块独立、易扩展、易调试；
多速率实时控制：1 ms 中断内分频执行 20 / 5 / 1 / 15 ms 各控制环，兼顾实时性与计算量。


第二章、机械部分安装及改造
车模结构：保留龙邱六无刷车模的五连杆腿机构，两条腿各由前后两个关节电机驱动，实现腿部末端（足端）在平面内的二维定位，从而控制车身俯仰、横滚与高度。
传感器安装：摄像头安装于车头，俯仰角可调，保证近端视野覆盖赛道；IMU 安装于车体重心附近，减少振动与角加速度耦合。
电路板固定：主板、无刷驱动板、电池通过 3D 打印安装板 固定于车架上，使用 金属尼龙柱、M3 螺丝与 M3 螺母 连接，兼顾强度与减振。
走线与防护：关节电机线缆沿连杆走向布置并留有运动余量，避免关节运动时拉扯。



第三章、电路设计说明
组委会提供了 CYT4BB7 核心 MCU 电路板，本车直接采用逐飞 CYT4BB7 核心板，其电路不做说明。其余电路均为自制：
自制主板：参考逐飞 CYT4BB7 主板原理图重新设计，删去与轮腿车无关的配件（如扩展排针、部分外设接口），集成摄像头、IMU、屏幕、按键、拨码开关、蜂鸣器等接口，体积与重量更适配轮腿车。
自制无刷驱动板 ×3：参考逐飞 CYT2BL3 无刷双驱板设计，一块驱动两个行进电机，两块分别驱动前、后关节电机，板载三相驱动。
自制磁编码器：用于无刷电机转子位置检测，为关节角位置闭环与行进速度测量提供反馈。
通信架构：主板与各无刷驱动板采用 UART 串口通信（7 字节定长帧，带校验和），发送占空比 / 目标角度指令，接收速度、角度、位置及电压数据。


第四章、微处理器控制软件设计
4.1 软件总体架构与数据流
控制软件运行于 CYT4BB7 的 CM7_0 核，按“感知—决策—控制—执行”四层架构组织，模块间以全局变量松耦合衔接，形成由感知到执行、再由反馈闭环的完整控制链路：

图 3软件总体架构和数据流图
实时调度框架：采用”1 ms 周期中断驱动实时控制 + 主循环慢速任务调度”的结构：
表 2调度框架表
多速率控制：各控制环在 1 ms 中断内分频执行——速度环 20 ms、角度环 5 ms、角速度环 1 ms、转向环 15 ms。内环（角速度）最快以保证稳定，外环（速度）较慢以匹配轮速响应带宽。
决策—控制解耦：状态引擎与控制层之间仅通过三个全局变量通信——set_speed（速度目标）、offset（航向偏差）、jump_flag（跳跃触发）。状态引擎只负责”产生目标”，控制层只负责”跟踪目标”，二者可独立调试。
4.2 感知层：姿态解算（AHRS）
IMU963RA 六轴数据在 1 ms 中断中读取，经硬编码零偏矫正（陀螺仪三轴分别修正）与 10 dps 死区处理后，送入四元数梯度下降法 AHRS（Madgwick 类算法）：
以加速度计实测重力方向与四元数估计重力方向做叉积误差，经比例（梯度步长 β=0.8）与积分（零漂补偿 ζ=0.005）校正陀螺仪角速度，再积分更新四元数并归一化；
静止检测：加速度模长落在 [0.9, 1.1] g 判定为静止，此时加大加速度低通滤波系数（α=0.8，运动时 0.5）与校正强度，抑制运动加速度对姿态的污染；
快速收敛：上电前 0.5 s 使用强比例校正（kp=100）使姿态快速收敛；
解算输出俯仰 / 横滚 / 偏航角，分别供平衡控制、横滚补偿与惯导导航使用，不使用磁力计。
4.3 控制层：速度控制（直接 / 间接）与平衡
速度控制是控制层的核心，提供直接控制与间接控制两条通路，由 `speed_control_mode` 切换，按科目需求选用。
直接控制（串级）：速度环（PI）→ 角度环（PD）→ 角速度环（PD）三串级结构，全部采用位置式 PID（调试发现增量式 PID 加减速性能极差，故弃用）：
// 1ms 中断内的多速率控制骨架
if (i % 20 == 1) {                                   // 20ms 速度环
    balance_speed_pid_interpolate(set_speed);        // 速度环参数随目标速度插值
    pid_control(&speed_cycle, run_speed, car_speed);
}
if (i % 5 == 1) {                                    // 5ms 角度环
    pid_control(&angle_cycle,
        mechanical_zero - speed_cycle.out * speed_control_mode,
        filtering_angle);
}
pid_control(&angular_speed_cycle, angle_cycle.out, gyro[1]);  // 1ms 角速度环
串级结构的意义：内环角速度环阻尼车身振荡、提供快速力矩响应；中环角度环维持俯仰角稳定；外环速度环控制车速。各环输出限幅逐级放宽，避免饱和叠加。

间接控制的具体实现（见 4.5）：速度环输出经增益 0.06、限幅 ±0.8° 后得到前后倾角度，叠加到四腿关节角上使重心偏移，从而间接改变车速；同时依据俯仰角大小对补偿量做衰减（俯仰角大时减弱），防止过补偿。
速度环参数自适应：速度目标越大，整车对力矩响应越平缓，故速度环参数随目标速度线性插值（低速端 Kp=0.10 / Ki=0.01 以克服静摩擦，高速端 Kp=0.20 / Ki=0.02 以减少震荡）。
4.4 控制层：转向控制
转向环在位置式 PID 基础上引入两个非线性项：
out = Kp*e + Ki*i_value + Kd*diff_value
    + Kp2 * fabsf(e) * e          // 非线性比例：大误差增强转向力矩
    + Kd2 * gyro_z;               // 角速度阻尼：抑制转向速度
Kp2·|e|·e：误差大时提供更强的转向力矩，误差小时退化为线性，兼顾快速回正与精确锁线；
Kd2·gyro：引入偏航角速度阻尼（Kd2=0.2），有效抑制转向过程中的角速度，对转向性能的改善非常显著。
转向环输出 trans_error 以差速形式叠加到左右轮：left = 角速度环输出 ? trans_error、right = 角速度环输出 + trans_error，再经占空比限幅（±80%）后下发。
转向参数自适应：转向误差越大越需平滑回正，故转向环参数随误差大小线性插值（小误差端 Kp=3.6 / Kd=0.2 精准锁线，大误差端 Kp=0.4 / Kd=0.2 平滑回中）。

基于逆运动学实现三类腿动作：
前后倾速度调节（间接控制）：四腿关节角统一叠加速度环输出的前后倾量 jointAngles.*= speed_output，通过重心偏移间接调速；
横滚腿高差补偿（单边桥）：横滚角经 5 ms 纯积分控制（Ki=10、输出限幅 ±40）后映射为左右腿高度差（±60 mm），“只抬一条腿”自适应保持横滚平衡（含 5° 死区，跳跃时禁用）；
压弯控制：转向偏移经中值滤波后超过阈值时，降低内侧腿高度并向后收腿，提升高速过弯稳定性。
关节角度经映射（前：200-α，后：β+20）后通过 UART 下发给前后关节驱动板。
4.6 控制层：跳跃控制（三级台阶）
跳跃采用基于腿长的状态机，以 Z 轴加速度检测离地与触地：
蓄势 → 起跳 → 空中收腿 → 等待触地 → 缓冲 → 完成

各阶段腿长用三次缓动函数（ease-in-out-cubic）平滑过渡，避免腿速突变；离地 / 触地检测均带超时保护，防止传感器误判导致失控。
4.7 感知层：视觉处理（摄像头）
摄像头选用逐飞 MT9V03X（188×120 灰度），图像在主循环中按帧处理：
自动曝光（标定模式）：取图像底部 1/3 行、中间 50% 列计算平均灰度，使其落在 [100,156] 区间，以步长 2 调节曝光时间（每 5 帧检测一次，避免频繁 I?C 通信），应对室外光线剧烈变化；
大津法自适应阈值（标定模式）：对中间 50% 列建立直方图求最优二值化阈值（钳位 [60,200]），每 6 帧更新并做 EMA 平滑（α=0.3）防抖；
台阶边缘检测：检测指定行黑白跳变（白色像素占比 >80% 判白），用上升沿检测避免同一台阶重复触发，输出 is_jump 供台阶算法触发跳跃；
中线提取：对近端行由图像中心向两侧搜索赛道边界求中线偏差（二值化法与行内对比度自适应法两种），输出 mid_offset 作为视觉循迹备选。
曝光与阈值在标定模式下自动整定后固定用于比赛，无需在线自适应，降低主循环负载。
4.8 决策层：惯导轨迹规划与执行
三个科目场地元素位置现场可测，据此规划轨迹。定义途径点描述每一段路径：
typedef struct {
    waypoint_type_t type;   /* 类型：起点/自转/台阶/单边桥/颠簸/匀速/到达/终点 */
    float distance;         /* 到下一点的距离 (cm) */
    float azimuth;          /* 行驶方位角 (°) */
    int16 speed;            /* 该段目标速度 */
} waypoint_t;
轨迹引擎将途径点转化为可回放的航向序列：
支持三种路径生成算法：折线、Catmull-Rom 样条（C1 连续、拐弯平滑）、Dubins 路径（直线 + 圆弧过渡），编译期宏切换；
按 5 cm 弧长等距重采样生成 heading_samples[]，并建立途径点 → 实际弧长映射 wp_arc_dist[]——样条路径比直线段长，状态引擎与速度查询均以真实弧长定位，保证里程准确；
发车基准：发车瞬间记录航向角与里程（traj_start_mileage / traj_start_anglez），此后 dist = accumulated_dist ? traj_start_mileage，消除上电姿态不确定的影响，显著提高发车成功率；
航向前瞻：按车速分档（0–150 / 150–420 / >420）向前偏移 0 / 1 / 2 个采样点查询航向，补偿转向响应滞后。
里程计算：由轮速积分得到 accumulated_dist += 0.89495·(car_speed/60)·轮周长(π×12 cm)·0.001，系数 0.89495 为标定的打滑修正。
4.9 决策层：任务状态引擎
状态引擎在 1 ms 中断中运行，将途径点解析为状态条目序列，按 SE.current 顺序调度：
typedef struct {
    state_type_t state;     /* 状态类型 */

4.10 关键调试历程与工程决策
三级台阶跳跃（STAIRS_T）——调试投入最大的算法：
识别：台阶边界线检测 → 固定行黑白跳变 → 上升沿去重；灰度处理由对比度法切换为二值化法（配合自动曝光与自适应阈值后效果稳定）；
触发：三级全视觉触发 → 第二、三级改时间锁 → 仅第一级视觉触发 → 最终第一级距离触发、第二三级时间锁触发；
三次跳跃分别设置不同触发行阈值与跳跃参数（第三跳提高腿长、缩短起跳时间），第三跳后做里程补偿，保证后续循迹不偏。
自转（SPIN）：早期尝试 PID 控制转向 offset 实现丝滑自转，但不同场地摩擦力差异导致部分地块无法完成两圈，最终改为固定转向力自转，并在自转结束时将方向对准下一段路径以提速。
转向环 KD2 与两侧补偿：加入偏航角速度阻尼（KD2）显著改善转向；同时实测多块自制驱动板两侧性能不对称，通过在占空比输出施加左右比值补偿（左 ×1.2、右 ×1.0）——该补偿是转向环有效工作的前提。
位置式 vs 增量式 PID：速度环实际调试发现增量式 PID 加减速性能极差，故全部控制环采用位置式 PID。
4.11 安全保护机制
倾倒检测：俯仰角超过 60° 立即停车并蜂鸣提示；
转圈保护：累计偏航超过 8 圈时强制停车，防止自转失控；
拨码开关 4 档模式：0=菜单初始化、1=图像调试（自动标定曝光 / 阈值）、2=进入平衡、3=发车，现场快速切换；
控制与显示隔离：菜单 / 图像模式（DIP=0/1）下控制中断不执行，运动模式下不刷新屏幕，从架构上避免控制与显示抢占同一 SPI 总线导致异常。
