摘要
本文详细介绍了第二十一届全国大学生智能汽车竞赛轮腿穿越组上海工程技术大学保安大队的车模系统设计方案。本队选用竞赛指定的博思威龙V型车模，以英飞凌CYT4BB7单片机为核心控制器，采用CYT2BL3双路FOC无刷驱动板驱动无刷电机，自主设计制作了CYT4BB7主控与四路舵机电源二合一主板，将主控核心与舵机供电模块高度集成，有效降低了整车重心与重量。传感器方案包括MT9V034总钻风灰度摄像头、IMU660RC六轴陀螺仪及TLE5012BE1000磁编码器。机械结构上，将原V车模小直径车轮更换为L型车模越野轮胎，增设配重铁块实现重心前移，加装偏振片与摄像头保护板以适应室外强光环境。控制策略采用“惯导寻迹为主，摄像头辅助修正”的双模融合架构，结合串级PID与扩张状态观测器（ESO）扰动补偿算法，实现了车模在室外复杂地形下的稳定循迹与姿态控制。经大量测试验证，系统设计方案切实可行。
关键词：轮腿穿越组；CYT4BB7；惯导寻迹；MT9V034；PID
第一章 引言
随着智能控制技术的持续发展，智能汽车作为融合控制理论、模式识别、传感检测、电子电气、计算机科学及机械工程等多学科知识的高新技术载体，已成为当代电子产业的重要发展方向。为提升大学生的实践创新能力与团队协作意识，教育部高等学校自动化专业教学指导委员会每年举办全国大学生智能汽车竞赛。大赛为智能车领域输送了大量专业人才，为多学科背景的大学生提供了创新实践平台。
第二十一届竞赛中，原平衡轮腿组演进为轮腿穿越组，比赛场地由室内PVC赛道移至室外塑胶跑道，赛制由单圈竞速调整为多科目综合评定，包含行进绕桩、定点排雷与颠簸路段三个科目。其中颠簸路段涵盖交错单边桥、颠簸路段、草地及三级台阶坡道等复杂地形，台阶坡道需正反两个方向各通过一次。科目制比赛对车模的导航精度、地形适应能力及任务切换能力提出了远超传统竞速赛的技术要求。
面对室外环境的不确定性与多科目任务的多样性，本队确立了“惯性导航为主、视觉校正为辅”的双模融合控制策略。车模正常行驶时，主要依靠IMU660RC六轴陀螺仪与TLE5012BE1000磁编码器构成的高频惯导系统进行航位推算与姿态感知，以短控制周期实现转向与速度闭环，规避图像处理延迟对动态响应的影响；MT9V034摄像头用于识别赛道边界与元素标识，经滤波处理后以低频注入惯导系统，抵消陀螺仪累积漂移。在颠簸路段，惯导实时感知俯仰与横滚姿态，腿部舵机据此动态调节虚拟腿长以适应单边桥、台阶坡道等不同地形；定点排雷科目中，依靠惯导航向角积分实现精确的原地旋转；行进绕桩科目中，惯导系统完成路径规划与航向保持，摄像头辅助识别锥桶边界。为提高姿态环抗扰能力，本队在串级PID基础上引入扩张状态观测器（ESO），将外部扰动（地面颠簸、腿部负载变化等）视为扩张状态进行在线估计并前馈补偿，显著提升了车模在连续颠簸路段及台阶冲击下的姿态稳定性。
硬件方面，主控芯片选用英飞凌CYT4BB7（Cortex®-M7内核，250MHz），无刷电机由独立CYT2BL3芯片驱动，形成高效双芯片分工。本队自主设计制作了主控与四路舵机电源二合一四层PCB主板，将舵机供电与主控电路高度集成，有效降低了整车重量、重心与线束复杂度。机械结构方面，针对原V车模小直径车轮越障能力受限的问题，更换为L型车模越野轮胎以提升通过性与抓地力；增设配重铁块实现重心前移，改善加速与制动响应；加装偏振片抑制室外强光反光，设计摄像头保护板防止碰撞损伤。
本报告将依次介绍车模结构设计、硬件电路实现、软件控制算法及调试过程，期望为后来者提供有价值的参考。

第二章 车模结构设计
2.1 车模简介
第二十一届全国大学生智能汽车竞赛轮腿穿越组采用官方指定的V型平衡轮腿车模，由广东东莞市博思电子数码科技有限公司生产。整车外形尺寸为180mm×187mm×192mm，轮腿关键结构件均采用开模注塑一体化成型工艺，一致性强、精度高且强度充足；底盘选用高强度碳纤维板材，整车18处活动连接点全部采用滚动轴承，确保车模运行顺滑、灵活可靠，结构稳定性与使用寿命均得到有效保障。
动力系统采用官方配备的BDS3620直流无刷电机，极对数为14，转速常数为500KV，对应12V供电条件下额定转速为6000rpm。为精确获取转子位置与转速信息，本队自行设计制作了基于TLE5012BE1000的绝对式磁编码器，精度15位，单次采集耗时仅4μs，采用ZH-1.5 6P接口，通过SPI总线与驱动芯片通信，为FOC控制算法提供高精度、低延迟的角度反馈。
车模腿部由四个BDS300舵机驱动，额定工作电压7.4V，堵转扭矩达10kg/cm，在该电压下舵机响应速度/60°为0.13s，具备充足的力矩输出与快速的动态响应特性，能够满足轮腿车模在颠簸路段、三级台阶等复杂地形下对腿部姿态精确调节的严苛要求。
车轮使用二十届智能车越野组官方指定L车模前轮，单轮直径88mm，轮宽32mm，采用优质防滑越野胎，在复杂路况下有良好的通过性与抓地力。
2.2 车模设计制作主要思路
2.2.1 主要设计思路
在车模设计过程中，动态性能与姿态稳定性是贯穿始终的两大优化主线。我们将车体重心置于几何中心线上，力求达到最优的静态自平衡效果，同时对重心位置进行了多次对比测试，在调整重心纵向位置的基础上，我们进一步采取多项措施降低整车质心高度，有效提升了车模的抗侧倾能力和姿态保持能力。车模整体设计最终形成了“纵向重心前移、垂向重心降低”的布局思路，在稳定性和机动性之间取得了较好的平衡。
2.2.2 电池安装位置
为有效降低整车重心高度，本队采用电池底部悬挂安装方案。利用3D打印技术定制高强度电池固定支架，将电池组稳固安装于车体底板下方，使电池重量集中于车体最低处。经实测对比，该方案较传统顶部电池布置使重心高度显著降低，有效改善了整车质量分布，车体在高速转向与颠簸路段行驶时的动态稳定性得到明显提升。电池盒结构及安装位置如附图所示：

2.2.3 陀螺仪安装位置
陀螺仪作为整车姿态控制的核心传感元件，其安装位置直接决定了系统控制性能的优劣。为确保陀螺仪能够真实反映车体俯仰角的变化，并规避因固定不良引入的姿态解算误差，本队在安装方案的设计上进行了充分考量。理想的安装位置需同时满足两项要求：其一是能够灵敏、准确地感知车体姿态变化，其二是具备足够的机械刚度以抑制振动干扰。经反复实测与验证，本队最终将陀螺仪固定于主板正下方。该位置贴近车体质心，能够真实反映整车运动状态，从而在测量精度与机械稳定性之间取得良好平衡。

2.2.4 摄像头安装位置

第三章 模型车硬件电路设计
3.1 概述
硬件设计是智能车模高效运行的核心保障。一套优秀的硬件设计方案不仅需要确保车模在调试过程中的安全性和可靠性，更要充分释放其性能潜力。然而，高性能的实现并非硬件设计的唯一目标，还需综合考虑以下关键因素：首先，设计方案必须与车模机械结构实现完美适配；其次，要充分考虑调试人员的使用便利性。真正出色的硬件设计需要实现原理图设计、PCB布局与结构设计的有机统一，这三个要素相互协同才能打造出卓越的作品。
3.2 主控板电路
基于结构设计要求，主板需要集成控制与配电功能，同时满足电机驱动的大电流需求和四个舵机的精准控制。为此，我们采用双PCB架构设计：主控板负责信号处理与舵机驱动，确保控制精度；电机驱动板专注于大电流功率输出，通过优化布局降低阻抗和热损耗。这种模块化方案在保证系统可靠性的同时，兼顾了结构适配性和调试便利性。
3.2.1 主控板供电
使用一块3s电池供电时，12v电源可由电池直接提供，生成所需要的电源为+5v电源与+3.3v电源，单片机所需的+5v电源由DC-DC电源芯片SCT2450直接生成。其具有的宽输入范围与5a最大供电电流功能对电路集成具有极大帮助。在输入+12v后加入高低频组合滤波：大容量电容滤除电源低频纹波，小容量陶瓷电容滤除高频干扰，抑制输入线上的噪声，保证 LDO 输入端电压稳定。相同的，在输出加入高低频组合滤波：大容量电容滤除电源低频纹波，小容量陶瓷电容滤除高频干扰，抑制输出线上的噪声，稳定输出电压，防止对后级元件造成损坏。
在生成+5v供电时，使用SY6280对+5v外设上电进行时序控制，进行短路保护，过流保护，反向电流阻断，输出放电功能和过温保护，防止+5v电源模块的损坏。

3.2.3 舵机供电
为降低车模高度，增加车模稳定性舵机电源板集成到控制板上。为可以分路精细控制每路舵机，因此最终选用了分立式DC-DC四路单独供电方案，使用SCT（芯洲科技）公司的SCT2450STER。SCT2450是5A同步降压变换器宽输入电压，范围从3.8V到36V，其中集成了一个45mΩ高侧MOSFET和一个20mΩ下部MOSFET。SCT2450，采用峰值当前模式控制，支持脉冲跳变调制（PSM）具有典型的25uA低静态帮助转换器达到高电压的电流在轻负荷或待机状态下的效率。采用可调电位器，可对每路舵机电压进行单独调整以应对不同情况。

第四章 模型车软件设计
4.1 主要理论
4.1.1 分层PID控制
本车为轮腿式结构（两轮毂电机驱动+四腿并联机构调节腿高），软件采用"角速度环—角度环—速度环—转向环—腿高/横滚环"多环嵌套的闭环控制架构，各环相互独立又通过共享状态量协同工作：
姿态内环（1ms周期）：angular_velocity_pid直接作用于俯仰角速度误差，输出Base_PWM_Out驱动腿部电机维持车身竖直姿态； 
姿态外环（5ms周期）：angle_pid根据俯仰角误差给出角速度环的目标量，velocity_pid根据编码器反馈的mid_speed与目标速度误差，输出前后腿伸展量X0的调节斜率，形成"角度—角速度—腿部前后位移"三级串级控制；
转向环（20ms周期）：车辆无机械转向机构，转向由左右轮差速及ins_turn_pid/yaw_angle_pid输出的Offset_PWM_Out叠加到左右轮基础PWM上实现，属于"差速转向"
横滚/腿高环：roll_angle_pid（增量式PID）根据横滚角误差计算balance_out，叠加到左右两侧腿高目标值Y0±roll_cmd，用于单边桥等需要左右腿高度差补偿的场景。
各PID均基于PID结构体统一实现，包含位置式（PID_Normal）与增量式（PID_Increase）两种形式：
位置式：out = Kp·Error + Ki·ΣError + Kd·(Error − LastError)
增量式：Δout = Kp·(Error − LastError) + Ki·Error + Kd·(Error − 2·LastError + PrevError)
其中增量式仅用于横滚角环（roll_angle_pid），因其只需输出增量补偿量而非绝对量，避免了积分累积在腿高控制中造成的漂移。
针对台阶、单边桥、颠簸路等不同元素场景，yaw_angle_pid、ins_turn_pid会在进入对应元素时切换到该场景专用的Kp/Kd（如台阶正面Kp=20/Kd=7，颠簸路Kp=10/Kd=3等），并在惯导循迹段通过曲率自适应连续调度增益，避免固定参数在直线段和转弯段之间顾此失彼。
4.1.2扩张状态观测器（ESO）与扰动观测理论
为提升姿态环抗扰能力，软件中集成了扩张状态观测器思想，将模型未建模的外部扰动（地面颠簸、腿部负载变化等）视为扩张状态量进行在线估计并前馈补偿：
俯仰通道采用二阶线性扩张状态观测器（LESO2），假设被控对象满足 ẏ = b₀u + d 的一阶扰动模型，观测器递推为：
z1 += dt × (z2 + b0×u − 2ωo×e)
z2 += dt × (−ωo²×e)
其中e为观测误差，估计出的扰动量z2/b0作为补偿量叠加到控制输出中抵消未建模扰动。
横滚通道采用结构更简单的静态增益一阶扰动观测器（SDOB），通过一阶低通滤波跟踪"测量输出与已知增益预测输出之差"来估计扰动，计算量更小，适合5ms周期的横滚环调用。
4.2 算法说明
4.2.1 电机闭环算法
驱动轮为带编码器反馈的无刷轮毂电机，通过独立的通信驱动板经UART（460800波特率，7字节定长帧，含帧头与校验和）进行PWM下发与转速读取，核心接口为small_driver_set_duty(left, right)与small_driver_get_speed()，中断中解析回传数据得到left_speed、right_speed。
左右轮差速并非通过阿克曼转向几何计算得出，而是在单边桥等需要左右轮转速独立修正的场景下，由Simple_Bridge_Correction()基于左右轮编码器反馈的PID闭环实现：
out_l = Base_PWM_Out + Offset_PWM_Out
out_r = Base_PWM_Out − Offset_PWM_Out
当检测到左侧或右侧车轮上桥（left_bridge_flag/right_bridge_flag，由横滚角输出balance_out超过±0.6触发）时，对应侧叠加PID_Normal(&left_wheel_pid/right_wheel_pid, 实际转速, 目标转速)的输出并经一阶低通滤波后修正该侧PWM，抑制单边桥上因负载不均导致的转速偏差，最终限幅至[-2500, 2500]后下发给驱动板。
4.2.2 舵机控制算法
内环角速度控制：1ms周期计算angular_velocity_pid输出Base_PWM_Out（一阶低通0.9/0.1平滑，限幅±3500），并叠加俯仰扰动观测器补偿Pitch_DOB_Comp()，用于抵消腿部动作引起的俯仰扰动；
外环角度与速度控制：5ms周期依次计算angle_pid（俯仰角外环）与velocity_pid（速度环），速度环输出经低通滤波后映射为腿部前后位移目标target_X0，并以X0_STEP_MAX=0.08的斜率限幅逐步逼近，避免腿部动作过冲；
腿高/横滚控制：roll_angle_control()根据当前所处场景动态设定基准腿高Y0：
站立/起跳前：Y0以Y0_RAMP_STEP=0.1每5ms斜坡爬升至Y0_RAMP_TARGET=6.5；
颠簸路防卡死：设计了"正常→伸腿→顶部保持→缩腿→复原"五状态踢腿状态机，当检测到车速持续为0（即mid_speed≤BUMPY_STUCK_SPEED）累计满BUMPY_STUCK_TRIGGER_CNT个控制周期后触发一次踢腿动作（腿高从BUMPY_NORMAL_Y0=5.0冲高至BUMPY_KICK_Y0=7.0保持BUMPY_KICK_HOLD_CNT=30周期后回收至BUMPY_DOWN_Y0=3.0再缓慢复位），用于颠簸路面卡轮时的主动脱困；
起跳（三级台阶）：jump()按状态机在腾空阶段临时切换angle_pid、angular_velocity_pid、velocity_pid增益并将Y0推高至11.0完成蹬地动作，落地收腿阶段回落至Y0=4.4，可连续起跳3次完成三级台阶；
常规行驶：Y0保持默认值4.4。横滚方向上，balance_out叠加扰动观测器补偿Roll_DOB_Comp()后限幅，分别加减到左右腿高Y0∓roll_cmd并通过逆运动学inverseKinematics()换算为四个舵机角度输出。
4.2.3惯导预瞄误差计算算法
由于台阶、单边桥间的过渡路径不依赖图像行数据，误差计算不采用多行融合，而是基于惯导位置与预录制路径点的空间几何关系动态计算：
预瞄距离随车速自适应，并根据当前路径曲率收缩，避免高速直线段预瞄过远、弯道段预瞄过近：
preview_distance = (PREVIEW_BASE_DISTANCE + mid_speed × PREVIEW_SPEED_GAIN) × 1/(1 + curvature × CURVATURE_PREVIEW_GAIN)，限幅[0.35, 8.0]m
航向误差由当前车头方向与"最近点到预瞄点"方向的夹角给出：
target_heading = π/2 − atan2(Δy, Δx)（归一化至[0, 2π)）
heading_error = target_heading − yaw_plus（归一化至[−π, π]，且|heading_error|<0.05时置零抑制小抖动）
曲率估计取路径上首/中/尾三点外接圆半径的倒数，用于两个用途：一是就近曲率驱动schedule_ins_turn_gains()对ins_turn_pid的Kp/Kd做低通平滑插值调度（直线段与弯道段各设定一组增益，按曲率线性过渡）；二是前视窗口内的最大曲率驱动弯道限速：
v_max = sqrt(CORNER_LAT_ACCEL_MAX × R)
按向心加速度约束计算允许的最大速度，并经限幅与速度斜率限制（apply_speed_slew）平滑过渡到目标速度，防止入弯速度过高侧滑。
4.2.4元素识别算法
面对台阶、单边桥、颠簸路、雷区四类元素，识别算法均基于Sobel边缘梯度提取赛道/元素边界特征，而非车道线跳变或圆环几何特征：
台阶正面（起跳）识别：scan_for_steps()在图像下方固定列区间逐行计算水平方向Sobel梯度均值，动态阈值取全图均值与固定下限PEAK_MIN_GRAD中的较大者，通过局部极大值搜索找出多条水平边缘（对应台阶各级踏面边线），当检测到不少于3条边缘且最上一条边缘所在行数超过阈值时判定进入三级台阶，锁定元素并触发起跳；
远端元素预判：distant_recognition()作为通用的远端底边识别函数，从图像中部按固定步长逐行沿EMA方向跟踪左右边界，剔除斜率突变或连续丢线的干扰点，得到元素底边中点位置及斜率误差，供转向环提前修正车身姿态；根据该中点所在行号是否超过元素对应的经验阈值，将识别状态locked_element由"未识别(0)"推进为"远端锁定(1)"再到"近场可执行(2)"，实现从粗定位到精确触发的分级识别；
单边桥识别：逐行Sobel边界扫描得到近端与远端赛道宽度，当近端宽度显著大于正常值且远端宽度明显偏窄时判定进入单边桥准备姿态（触发站立动作），并根据横滚角输出方向判断车辆偏向左桥或右桥，驱动对应侧轮速补偿；
台阶背面识别：种子点根据底部区域平均灰度动态切换梯度阈值（防止背光/顺光造成的漏检），采用EMA预测配合失败计数容错逐行向上爬升跟踪台阶背面边界，并用行加权中线（近端行权重更大）计算下台阶时的中线纠偏量；
雷区识别：多行梯度突变点检测结合白色/蓝色像素比例校验，防止误判，并在检测到雷区拐角特征时触发原地旋转搜索模式，寻找下一个可通行点位。

5.2 制作与安装过程
本车模以博思威龙V型车模为基础进行改造，整体安装过程严格按照第二章所述的结构设计方案执行。主要步骤包括：
1）电池安装：采用电池底部悬挂方案，利用3D打印的电池固定支架将电池组稳固安装于车体底板下方，有效降低整车重心高度。
2）陀螺仪安装：将IMU660RC陀螺仪固定于主板正下方，贴近车体质心，以保证姿态测量的灵敏度与抗振性。
3）摄像头安装：将MT9V034摄像头安装于车体几何中心位置，并加装偏振片以抑制室外强光反光。摄像头支架通过3D打印件固定，视角可微调。
4）主板安装：摄像头安装：将MT9V034摄像头安装于车体几何中心位置，并加装偏振片以抑制室外强光反光。摄像头支架通过3D打印件固定，视角可微调。
5）电机驱动板安装：CYT2BL3无刷驱动板通过3D打印件直接固定于车体正后方，与大电流走线保持最短路径，降低阻抗与热损耗。
6）配置块安装：在车模前端加装两块50g配重铁块，实现重心前移，改善加速与制动时的俯仰响应。
7）车轮转接件安装：更换为直径88mm的R型越野轮胎，通过3D打印转接件连接无刷电机与轮毂，提高离地间隙与抓地力。
8）走线与防护：对所有电源线、信号线进行扎带固定，避免运动过程中松动或干涉。关键接插件使用热缩管绝缘。
以上安装完成后，进行通断测试与电压检测，确保各模块供电正常，传感器信号无误。
5.3 调试过程
在线调试通过 IAR 的 Debug 模式配合 VOFA+ 上位机实现。在 IAR 中设置断点、单步执行、查看寄存器与内存变量；同时通过串口将关键变量（如位置坐标 pos_east/pos_north、航向角 yaw_plus、目标点距离 dist 等）实时发送至 VOFA+，以波形或数值形式显示。这种方式能够直观地观察惯导追点过程中的目标跟踪效果、段切换时机以及速度变化曲线，便于快速定位问题。
离线调试通过人机交互模块实现。本队设计了以 IPS 屏幕为显示、按键为输入设备的交互方案：屏幕实时刷新当前参数值与运行状态，发车选手通过按键的功能键可直接记录、存点、取点显示，无需连接电脑即可完成离线调整。这一模块不仅满足日常调试需求，在比赛现场也能快速响应参数修改需求，通过物理按键的直观操作减少调试失误，确保在限时环境下高效完成参数优化。

第七章 结论
7.1 智能车整体制作情况​
本模型车以博思威龙V车模为基础，严格遵循轮腿穿越组竞赛规则，核心控制单元采用组委会提供的英飞凌CYT4BB7。搭载MT9V034总钻风摄像头（752*480 分辨率，60fps帧率）采集赛道图像，IMU660RC陀螺仪监测车身姿态，TLE5012BE1000磁编码器获取轮速信息，实现对赛道环境与车身状态的全方位感知。
整体设计涵盖机械结构、硬件电路和软件系统。机械结构上，完成了电池安装、防撞板设计、重心降低、质心前移、轮胎适配、底板加固以及各传感器的安装固定等；硬件电路由主控板、无刷驱动板、磁编码器板等构成；软件系统按“惯导导航为主、视觉引导为辅”逻辑构建，辅助以“速度方向双闭环控制”等控制思路。
经测试，车模能在包含多种元素的赛道上自主行驶，横向偏差控制在合理范围，元素识别精度达标，最大速度可达3m/s，通过调试验证，性能满足竞赛要求。​
7.2 存在的问题及解决方案​
在机械结构设计方面，本队以整车重心管控为核心，对器件布局位置进行了多轮迭代优化。通过将电池组悬挂于车体底部、增添配重块、主控与舵机电源二合一板紧凑布置于车体中部偏下位置，有效降低了整车质心高度，同时适度前移重心改善了加速与制动时的俯仰响应特性，车体在高速过弯与颠簸路段的动态稳定性得到显著增强。
在硬件方案方面，针对室外强光环境下赛道元素产生的镜面反射光斑干扰问题，本队为摄像头选配了偏振片进行光学滤波。通过3D打印定制固定支架，使偏振片精准贴合于镜头外沿，并预留微调空间以旋转偏振角度，使透光方向与反射光偏振方向垂直，最大限度消除反光干扰，有效改善了视觉系统在复杂光照条件下的图像质量与识别稳定性。
在软件调试与参数整定方面，本队依托VOFA+与逐飞科技上位机构建在线调试体系。VOFA+ 实时回传惯导追点过程中的位置坐标、偏航角及目标距离等变量快照，以波形辅助分析段切换时刻的收敛特性；逐飞科技上位机则回传摄像头图像，验证元素识别准确性。同时，程序中嵌入蜂鸣器辅助反馈，在段切换与元素完成时发出提示音，帮助调试人员快速定位状态跳变节点。该方案有效提升了参数标定效率，确保了分段式控制策略的稳定执行。
尽管当前车模已基本满足竞赛要求，但仍有进一步优化的空间：在极端强光或阴影交错的场景下，偏振片与摄像头自动曝光的协同效果尚存在波动，连续穿越多个复杂地形时控制算法的实时响应能力可进一步提升。未来计划引入更先进的自适应图像增强算法与优化控制算法，以进一步提升系统的环境适应性与任务执行效率。

float PID_Normal(PID *PID, float NowData, float Point)
{
    float out=0;
    float last_out = 0;
    // 计算当前误差
    PID->Error = Point - NowData;
    PID->Error_Inc += PID->Error;

    out = PID->Kp * PID->Error
               + PID->Ki * PID->Error_Inc
               + PID->Kd * (PID->Error - PID->LastError);
    
    // 更新误差历史
    PID->LastError = PID->Error ;
    
    
    out = last_out* PID->LowPass+out* (1-PID->LowPass);
    last_out=out;
    return out;
}

float PID_Increase(PID *PID, float NowData, float Point)
{
    // 计算当前误差
    PID->Error = Point - NowData;

    // 增量计算（标准增量式PID）
    float delta = PID->Kp * (PID->Error - PID->LastError)
               + PID->Ki * PID->Error
               + PID->Kd * (PID->Error - 2*PID->LastError + PID->PrevError);
              // - pitch_angle_v* 0.0001;

    // 更新误差历史
    PID->PrevError = PID->LastError;
    PID->LastError = PID->Error ;

    return delta;
}


float locked_yaw = 0.0f; // 锁定的目标偏航角
float yaw_error=0.0;//锁定的航向角-实时航向角
uint8 lock_active = 0;   // 锁定状态标志位
extern float YAW_Offset_PWM;

void lock_yaw_control(void)
{
    if(bumpy_road_flag==1 || three_step_stairs_flag==1 || stand_up_flag==1||back_staris_flag==2||(three_step_stairs_flag== 1&&element_type_list[current_segment_index]==ELEMENT_TYPE_STAIRS_FRONT))
    {
        if (lock_active == 0) 
        {
            locked_yaw = yaw;
            lock_active = 1;
        }
        if (lock_active==1)
        {
            yaw_error = locked_yaw - yaw;
            if (yaw_error > 180.0f) yaw_error -= 360.0f;
            else if (yaw_error < -180.0f) yaw_error += 360.0f;
        }
    }
    else
    {
        lock_active = 0;
        yaw_error = 0;
    }
}
