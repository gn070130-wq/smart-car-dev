引 言
由于本届智能车轮腿穿越组别要求为车模自制，本小组为了更好的适配本次轮腿组多科目多赛道元素的需求，分别尝试了不同的车模设计方案，分别为六无刷关节电机车模，传统V车模，以及尺寸改良V车模，最终确定为尺寸改良V车模。在电路设计方面对电路板进行了多代迭代更新，控制算法上也进行了多种方案的尝试，本技术报告将对车模设计理念，车模机械设计，车模硬件设计，车模控制理论等在下文按顺序依次阐述。

车模详解
2.1 车模设计理念与技术实现方案
2.1.1 车模设计理念
本次参赛智能车轮腿穿越车模，紧扣轮腿复合、全域穿越、稳定高效的核心设计思路，针对智能车轮腿穿越组赛事复杂路况、障碍翻越、灵活机动、精准行进的核心竞技需求打造。整车采用轮腿式的机械结构设计，便于高效完成赛事全场景穿越任务。
本次赛事核心考核车模的复杂地形通过能力、障碍自适应能力、行进稳定性与智能响应速度。基于赛事赛道包含平地、陡坡、凹凸路面、低矮障碍、台阶等多元场景的特点，我们摒弃单一轮式或单一腿式结构的设计短板，采用轮腿一体化复合结构设计。让车模在平整赛道依托轮式结构实现高速稳定行进，在复杂障碍路段依托腿式结构完成抬升、跨越、缓冲、脱困动作，全方位适配赛事各类极限穿越场景，最大化提升赛事综合得分能力。
结构设计遵循“轻量化、高刚性、高灵活度”三大原则，在降低车身负重、提升机动灵敏度的同时，保障高强度赛事行进中的结构稳定性。
车身主体采用轻量化高强度材料，兼顾韧性与抗撞击性，可有效抵御赛道障碍磕碰、颠簸带来的结构损耗，同时降低整车自重，减少动力消耗，提升续航与机动速度。车身框架采用模块化集成设计，布局紧凑合理，重心居中偏低，有效规避高速行进、障碍翻越过程中侧翻、失衡问题，保障全程行进稳定。
我们采用独立可控的多自由度轮腿组合，每一组轮腿均可实现独立伸缩、抬升、摆动与缓冲调节。轮体采用防滑耐磨橡胶材质，增大接地摩擦系数，避免平地、斜坡路段打滑；腿部机械关节采用精密传动结构，响应灵敏、动作精准，可根据路况自动调节抬腿高度、支撑角度与落地力度。面对凹凸路面，轮腿可独立自适应缓冲，过滤颠簸；面对台阶、低矮障碍物，可通过腿部抬升结构完成平稳翻越，解决传统轮式车模无法跨障、易卡滞的痛点，实现全地形无死角穿越。
同时，整车兼顾实用性与竞技性，结构坚固耐用，操作稳定、容错性强，能够充分应对赛事过程中的各类突发状况，以稳定的发挥、优秀的地形适配能力、高效的穿越效率，展现智能机械设计的创新优势与团队的设计研发能力。

2.1.2 技术实现方案

整车控制以PID算法为核心。PID算法无需被控对象的精确数学模型，仅凭比例（P）、积分（I）、微分（D）三个环节的线性组合便能实现高效控制。比例系数增大响应速度，积分环节消除稳态误差，微分环节抑制超调并加快响应，同时算法结构简单、计算量小，易于在各类硬件上部署，三个参数物理意义明确，工程整定直观便捷，且对系统内部参数变化和外部干扰具有强鲁棒性。
IMU660RB同时输出三轴加速度和角速度，其中陀螺仪积分提供高频动态响应，加速度计测量重力方向用于长期漂移校正。两者通过四元数解算配合互补滤波融合，最终输出平滑的三轴欧拉角。采用四元数可避免万向节锁问题，且计算量适合嵌入式实时运行，为直立串级PID提供准确、低延迟的姿态反馈。
轮腿车模的平衡由PID直立环输出值赋予电机实现，其结构为角度环与角速度环的串级PID。角度环为外环，角速度环为内环。在这种串级架构中，角度环外环根据实时倾角与目标值的偏差，计算出维持直立所需的目标角速度，并将其作为指令传入内环；角速度环内环则迅速跟踪该指令，经PID运算后输出电机扭矩控制量。外环专注于消除稳态倾角误差，确保姿态准确；内环侧重抑制突发冲击和振动，提升动态响应速度。二者内外串联、各司其职，使电机输出的直立环控制量既稳又准，有效兼顾了轮腿车模在复杂路况下的姿态刚性与抗扰柔性。
为发挥轮腿车模的腿部优势，通过动态调节腿部舵机占空比的方式来控制整车速度、改变小车重心，并进一步实现跳跃功能。
车模的导航系统以轮速里程计为核心，结合IMU提供的航向角，采用航位推算法实时递推车体位置。系统在每个控制中断周期内，根据左右轮速计算前向速度，并利用当前航向将其投影到世界坐标系，对投影后的速度分量进行时间积分，累加得到当前位置坐标。同时，系统按固定时间间隔将位置信息记录为轨迹点，支持将轨迹数据存入Flash以供后续调用。在复刻循迹模式下，系统动态搜索车体前方轨迹上的最近点，并选取其前方若干点作为目标，计算目标方向以生成转向指令。此外，系统具备障碍标记与恢复机制：遇到障碍时可记录当前轨迹索引并暂停循迹，待避障完成后从断点处恢复，继续跟踪轨迹，从而实现记忆式复刻与主动避障的结合。



2.2 车模安装
2.2.1 车模机械设计与参数 
设计车模时针对赛场上复杂、多样的路况，在采用轮腿式车模的前提下，将车模的宽度做长，以便于更加平稳、快捷地通过单边桥、颠婆路段等障碍。同时基于车模对平衡的要求，设计时将车模的重心尽可能的降低，且使其尽量处于中心位置。另外为应对复杂多样的障碍与室外环境的复杂性，车模采用较大外径的轮胎，用于保证车模行驶时的稳定。

2.2.2 车模硬件安装
PCB电路板的设计预留的孔位并不能直接与车模对应，以及室外坏境的不稳定因素较多，以及平衡车模对平衡的需求，所以硬件电路板的安装应尽可能保持车辆重心较低，在车上不占用过多空间，重量尽可能低。所以对硬件进行了相应的改良，将在下文指出，以及为了安装硬件而设计了转接板，保护壳等等。

2.4.1 开发环境
代码开发基于逐飞科技CYT4BB7核心板，在IAR软件开发环境中进行，如图2.4.1.1所示。IAR Embedded Workbench是一款专为嵌入式应用设计的集成开发环境，集成了编辑器、编译器、链接器和调试器等全套工具链。其编译器优化能力出色，能生成高效紧凑的目标代码，对资源受限的MCU开发非常友好；C-SPY调试器支持源码级调试和实时变量监控，便于系统调测。该软件支持广泛的芯片架构，并提供了通过功能安全标准认证的版本，为车模控制这类对实时性和可靠性有较高要求的项目提供了坚实的技术保障。

volatile uint8_t g_rot_active = 0;    // 0=空闲  1=旋转中  2=已完成

// 外部启动旋转（在GPS判定到达旋转点时调用一次）
void rotate_trigger(void)

    g_rot_active = 1;
}


// ========== 放进定时中断，每 5ms 调用 ==========
void rotate_isr(void)
{
    static float   accum  = 0.0f;
    static float   last   = 0.0f;
    static uint8_t first  = 1;

    if(g_rot_active != 1) return;     // 未启动或已完成，直接返回

    float yaw = eulerAngle_yaw;

    if(first)
    {
        last  = yaw;
        first = 0;
        return;
    }

    float d = yaw - last;
    if(d > 180.0f)       d -= 360.0f;
    else if(d < -180.0f) d += 360.0f;

    accum += fabsf(d);
    last   = yaw;

    if(accum >= 690.0f)       //转满两圈时
    {
        g_rot_active = 2;     // 标记完成
        electric_motor_flag = 2;  //直行模式
        accum = 0.0f;         // 清累计，准备下次
        first = 1;            // 下次启动时重新记录起点
        dir_switch^=1;        //方向切换
        direction_correct_flag = 1;
    }
    else
    {
        electric_motor_flag = 1; //转圈模式
    }
}

float I_ex, I_ey, I_ez;  // 误差积分

float Q_info_0 ,Q_info_1, Q_info_2, Q_info_3= 1;


float icm_kp= 2;    // 加速度计的收敛速率比例增益 0.17
float icm_ki= 0.005;   // 陀螺仪收敛速率的积分增益0.004
int IMU_init_flag ;  //陀螺仪初始化标志位

void icmAHRSupdate(void)
{
    float halfT = 0.5 * delta_T;    // 采样周期一半
    float vx, vy, vz;               // 当前姿态计算得来的重力在三轴上的分量
    float ex, ey, ez;               // 当前加速计测得的重力加速度在三轴上的分量与用当前姿态计算得来的重力在三轴上的分量的误差
    float gx1, gy1, gz1;

    float q0 = Q_info_0;  //四元数
    float q1 = Q_info_1;
    float q2 = Q_info_2;
    float q3 = Q_info_3;

    float q0q0 = q0 * q0;  //先相乘，方便后续计算
    float q0q1 = q0 * q1;
    float q0q2 = q0 * q2;
    //float q0q3 = q0 * q3;
    float q1q1 = q1 * q1;
   // float q1q2 = q1 * q2;
    float q1q3 = q1 * q3;
    float q2q2 = q2 * q2;
    float q2q3 = q2 * q3;
    float q3q3 = q3 * q3;

//    // 正常静止状态为-g 反作用力。
//    if(ax * ay * az == 0) // 加计处于自由落体状态时(此时g = 0)不进行姿态解算，因为会产生分母无穷大的情况
//        return;

    // 对加速度数据进行归一化 得到单位加速度 (a^b -> 载体坐标系下的加速度)
    float norm = 1/sqrtf(ax * ax+ ay * ay + az * az);
    ax = ax * norm;
    ay = ay * norm;
    az = az * norm;

    // 载体坐标系下重力在三个轴上的分量
    vx = 2 * (q1q3 - q0q2);
    vy = 2 * (q0q1 + q2q3);
    vz = q0q0 - q1q1 - q2q2 + q3q3;

    // g^b 与 a^b 做向量叉乘，得到陀螺仪的校正补偿向量e的系数
    ex = ay * vz - az * vy;
    ey = az * vx - ax * vz;
    ez = ax * vy - ay* vx;

    // 误差累加
    I_ex += halfT * ex;
    I_ey += halfT * ey;
    I_ez += halfT * ez;

    // 使用PI控制器消除向量积误差(陀螺仪漂移误差)
    gx1 = gx + icm_kp* ex  + icm_ki* I_ex;
    gy1 = gy + icm_kp* ey + icm_ki* I_ey;
    gz1 = gz+ icm_kp* ez + icm_ki* I_ez;

    // 一阶龙格库塔法求解四元数微分方程，其中halfT为测量周期的1/2，gx gy gz为b系陀螺仪角速度。
    q0 = q0 + (-q1 * gx1 - q2 * gy1 - q3 * gz1) * halfT;
    q1 = q1 + (q0 * gx1 + q2 * gz1 - q3 * gy1) * halfT;
    q2 = q2 + (q0 * gy1 - q1 * gz1 + q3 * gx1) * halfT;
    q3 = q3 + (q0 * gz1 + q1 * gy1 - q2 * gx1) * halfT;

    // 单位化四元数在空间旋转时不会拉伸，仅有旋转角度，下面算法类似线性代数里的正交变换
    norm = 1/(q0 * q0 + q1 * q1 + q2 * q2 + q3 * q3);
    Q_info_0 = q0 * norm;
    Q_info_1 = q1 * norm;
    Q_info_2 = q2 * norm;
    Q_info_3 = q3 * norm;  // 用全局变量记录上一次计算的四元数值

    eulerAngle_pitch = asin(2 * q0 * q2 - 2 * q1 * q3) * 180 / PI;
    eulerAngle_roll = atan2(2 * q2 * q3 + 2 * q0 * q1, -2 * q1 * q1 - 2 * q2 * q2 + 1) * 180 / PI;
    eulerAngle_yaw = atan2(2 * q1 * q2 + 2 * q0 * q3, -2 * q2 * q2 - 2 * q3 * q3 + 1) * 180 / PI;
    

    float temp;
    temp = eulerAngle_pitch;  eulerAngle_pitch = eulerAngle_roll;  eulerAngle_roll = temp;
    eulerAngle_pitch = -eulerAngle_pitch;
    
    //while (eulerAngle_yaw > 180.0f)  eulerAngle_yaw -= 360.0f;
    //while (eulerAngle_yaw < -180.0f) eulerAngle_yaw += 360.0f;

    eulerAngle_yaw = -eulerAngle_yaw;
    if(eulerAngle_yaw<0.0f) eulerAngle_yaw+=180.0f;
    else if(eulerAngle_yaw>0.0f) eulerAngle_yaw-=180.0f;
    
}

// 输入：左右轮线速度 (m/s)，前进为正。

float compute_forward_speed(float left_rpm, float right_rpm) 
{
    // 转速 -> 线速度 (m/s)
    float left_speed  = (left_rpm  / 60.0f) * wheel_circumference;
    float right_speed = (right_rpm / 60.0f) * wheel_circumference;
    return (left_speed - right_speed) * 0.5f;
}

/* ---------- 核心航位推算（每中断周期调用一次） ---------- */
// left_speed / right_speed : 左右轮线速度，单位 m/s
// yaw                      : 当前航向角，单位 弧度（不是角度！）
// dt                       : 中断周期，单位 秒（如 5ms = 0.005f）
void ins_update(INS_Simple *ins, float left_speed, float right_speed, float yaw, float dt2)
{
    // 1. 前向速度（车体坐标系）
    float v_forward = compute_forward_speed(left_speed, right_speed);
    
    // 2. 更新航向
    ins->yaw = yaw;
    
    // 3. 投影到世界坐标系
    // 如果你的坐标系定义和实际方向相反，把下面两行的负号加回来：
    // ins->vel_x = -v_forward * cosf(yaw);
    ins->vel_x =  v_forward * cosf(yaw);
    ins->vel_y =  v_forward * sinf(yaw);
    
    // 4. 积分得到位置
    ins->pos_x += ins->vel_x * dt2;
    ins->pos_y += ins->vel_y * dt2;
}

/* ---------- 复刻轨迹：无预瞄，直接追最近点的下一个 ---------- */
// 每5ms调用一次
void replay_update_no_lookahead(float left_speed, float right_speed)
{
    if(!is_replaying || traj_cnt < 2)
        return;
    
  // ========== 1. 确定搜索窗口 ==========
    // 起点：允许少量回退（防索引抖动），但不能退到已走过的反向路段
    int16_t search_start = traj_idx - BACKTRACK_LIMIT;
    if(search_start < 0) search_start = 0;
    
    // 终点：前方有限窗口，不要搜到末尾所有点
    uint16_t search_end = traj_idx + SEARCH_WINDOW;
    if(search_end > traj_cnt) search_end = traj_cnt;
    // 1. 找轨迹上离小车最近的点（从当前idx往后，防止回退）
    float min_dist = 9999.0f;
    uint16_t best_idx = traj_idx;
    uint8_t found_forward = 0;
    
    for(uint16_t i = search_start; i < search_end; i++)
    {
        float dx = traj[i].x - ins.pos_x;
        float dy = traj[i].y - ins.pos_y;
        float dist   = sqrtf(dx*dx + dy*dy);
        
        float dot = dx * cosf(ins.yaw) + dy * sinf(ins.yaw);
        if(dot < 0.0f) continue;   // 在后方，跳过（防止跳到对面来向路段）
        
        if(dist < min_dist)
        {
            min_dist = dist;
            best_idx = i;
            found_forward = 1;
        }
    }
    traj_idx = best_idx;
    //////////////////////////////////////////////////////////////////////////////////
    // ========== 【新增】障碍检测 ==========
    if(!is_obstacle_passing && current_obstacle < obstacle_cnt)
    {
        // 当索引到达或超过障碍标记点，退出循迹
        if(traj_idx >= obstacle_idx[current_obstacle])
        {
            is_obstacle_passing = 1;
            is_replaying = 0;       // 退出循迹
            obstacle_count++;       //用来计数到达第几个障碍
            return;                 // 不输出转向
        }
    }
    ////////////////////////////////////////////////////////////////////////////////
    // 2. 目标 = 最近点的下一个点（取消预瞄）
    uint16_t target_idx = traj_idx + 3;
    if(target_idx >= traj_cnt)
        target_idx = traj_cnt - 1;      // 已到最后，锁定最后一个点
    
    target_x = traj[target_idx].x;
    target_y = traj[target_idx].y;
    
    // 3. 目标点转到车体坐标系（X前，Y右，左负右正）
    dx_world = target_x - ins.pos_x;
    dy_world = target_y - ins.pos_y;
    
    
    // 4. 直接算目标在小车的哪个方向（无预瞄，无曲率）
    // 返回值：正=目标在右侧（需右转），负=目标在左侧（需左转）
    angle_to_target = atan2f(dy_world, dx_world);
    
    
 
    // 6. 终点判定：到了最后一点且足够近
    if(traj_idx >= traj_cnt - 1 && min_dist < ARRIVE_THRESHOLD)
    {
        is_replaying = 0;        // 你的停车函数
        STOP_OVER = 1;
    }
}

void recover()
{
  is_obstacle_passing = 0;
  current_obstacle++;     // 这个障碍处理完了
  is_replaying = 1;       // 恢复循迹
}

void INS_write_flash(void)
{
    if(traj_cnt == 0 || traj_cnt > TRAJ_MAX_POINTS)
        return;
    __disable_irq(); 
    
    uint16_t page;
    if(KEY3_mode==CLASS_ONE)       page = INS_FLASH_PAGE1;
    else if(KEY3_mode==CLASS_TWO)  page = INS_FLASH_PAGE2;
    else                           page = INS_FLASH_PAGE3;
    
    if(flash_check(INS_FLASH_SECTION, page)) 
      flash_erase_page(INS_FLASH_SECTION, page);    
       
    flash_buffer_clear();
    
    // [0] 高16位魔数 + 低16位点数
    flash_union_buffer[0].uint32_type = ((uint32_t)INS_TRAJ_MAGIC << 16) | 
                                        ((uint32_t)obstacle_cnt << 8) | 
                                        (uint32_t)traj_cnt;
    
    // 从[1]开始存，索引规律：4*i-3 ~ 4*i
    for(uint16_t i = 1; i <= traj_cnt; i++)
    {
        uint16_t base = 2 * i - 1;
        flash_union_buffer[base + 0].uint32_type = *(uint32_t*)&traj[i-1].x;
        flash_union_buffer[base + 1].uint32_type = *(uint32_t*)&traj[i-1].y;
    }
    
    uint16_t obs_base = 1 + traj_cnt * 2;   // 障碍索引在 buffer 中的起始位置
    for(uint8_t i = 0; i < obstacle_cnt; i++)
    {
        flash_union_buffer[obs_base + i].uint32_type = (uint32_t)obstacle_idx[i];
    }
    
    uint32_t word_count = 1 + traj_cnt * 2 + obstacle_cnt;
    flash_write_page_from_buffer(INS_FLASH_SECTION, page, word_count);   
    
    __enable_irq(); 
}

// ---------- 从 Flash 读惯导轨迹 ----------
// 返回 1：成功，traj_cnt 已更新
// 返回 0：无有效数据
uint8 INS_read_flash(void)
{
    flash_buffer_clear();
    
    uint16_t page;
    if(KEY3_mode==CLASS_ONE)       page = INS_FLASH_PAGE1;
    else if(KEY3_mode==CLASS_TWO)  page = INS_FLASH_PAGE2;
    else                           page = INS_FLASH_PAGE3;
    
    flash_read_page_to_buffer(INS_FLASH_SECTION, page, TRAJ_MAX_POINTS * 2 + 1 + MAX_OBSTACLES);
    
    uint32_t header = flash_union_buffer[0].uint32_type;  // 补 _t
    uint16_t magic  = (uint16_t)(header >> 16);           // 补 _t
    uint8_t  obs    = (uint8_t)((header >> 8) & 0xFF);    // 【改7】新增：提取障碍数
    uint8_t  cnt    = (uint8_t)(header & 0xFF);           // 【改8】只取低8位作为 traj_cnt
    
    if(magic != INS_TRAJ_MAGIC)      return 0;
    if(cnt == 0 || cnt > TRAJ_MAX_POINTS) return 0;
    if(obs > MAX_OBSTACLES)                 return 0;     // 【改9】校验障碍数，防垃圾数据
    
    traj_cnt = cnt;
    obstacle_cnt = obs;
    
    for(uint16 i = 1; i <= traj_cnt; i++)
    {
        traj[i-1].x   = *(float*)&flash_union_buffer[2*i - 1].uint32_type;
        traj[i-1].y   = *(float*)&flash_union_buffer[2*i    ].uint32_type;
    }
    
    uint16_t obs_base = 1 + traj_cnt * 2;
    for(uint8_t i = 0; i < obstacle_cnt; i++)
    {
        obstacle_idx[i] = (uint16_t)flash_union_buffer[obs_base + i].uint32_type;
    }
    return 1;
}

      pit_ms_init(PIT_CH13,5); //内含惯导中断
      
    }
    if(KEY1_mode==RACE_MODE)   //进入比赛模式

      if(stage_flag == 1)

        is_recording = 0;
        pit_disable(PIT_CH1);  
        pit_disable(PIT_CH0); 
        pit_disable(PIT_CH2); 
        pit_disable(PIT_CH10); 
        pit_disable(PIT_CH11); 
        pit_disable(PIT_CH13); 
        INS_write_flash();
        pit_enable(PIT_CH1);
        pit_enable(PIT_CH0);
        pit_enable(PIT_CH2);
        pit_enable(PIT_CH10);
        pit_enable(PIT_CH11);
        pit_enable(PIT_CH13);
        stage_flag = 0; 
      }
    }
    if(KEY1_mode==3) KEY1_mode=VACANT_MODE;
  }
  /////////////////////////////////////////////////////////////////////
  else if(!gpio_get_level(KEY2))
  {
    two_buffer();
    if(KEY1_mode==STAGE_MODE)
    {
      begin_record_mode();     //打开存点标志
      stage_flag = 1;
    }
    if(KEY1_mode==RACE_MODE)
    {
      KEY2_mode++;
      if(KEY2_mode==GO) 
      {
        CAM_SHARED_CLASS_TWO->mode=2;   //摄像头

        pit_disable(PIT_CH1);  
        pit_disable(PIT_CH0); 
        pit_disable(PIT_CH2);

        pit_disable(PIT_CH11);

        verify = INS_read_flash();

        pit_enable(PIT_CH0);
        pit_enable(PIT_CH2);
        pit_enable(PIT_CH10);
        pit_enable(PIT_CH11);
        pit_enable(PIT_CH13);
        begin_play_mode();
      }
      if(KEY2_mode==2) KEY2_mode=CONTROL;
    }
  }
  /////////////////////////////////////////////////////
  else if(!gpio_get_level(KEY3))
  {
    three_buffer();
    if(KEY1_mode==STAGE_MODE)
    {
       if(is_recording && obstacle_cnt < MAX_OBSTACLES)
        {
            // 【暂停】记录当前索引为障碍点
            is_recording = 0;
            obstacle_idx[obstacle_cnt++] = traj_cnt-1;   // 标记！
            
        }
       else if(!is_recording)
        {
            // 【继续】恢复录制
            is_recording = 1;
            record_div = 0;                // 重置定时器，避免立刻触发存点
            
        }
    }
    else KEY3_mode++;
    if(KEY3_mode==3) KEY3_mode=CLASS_ONE;
  }
  system_delay_ms(10);
}

//PID计算
void Position_PID_Calc(Position_PID* pid, float target, float current, float dt1)
{
    if (current != current) return;
    
    float err = target - current;
     if (pid == &turn_loop) 
    {
        err = circular_limit(err);                    // 角度限幅
        
        float diff = current - pid->last_current;      // 解缠绕
        if (diff > 180.0f)  pid->last_current += 360.0f;
        else if (diff < -180.0f) pid->last_current -= 360.0f;
    } 
    // 【修复1】先更新积分（带 dt）
    pid->integral += err * dt1;
    
    // 【修复2】积分限幅
    if (pid->integral > pid->integral_max)
        pid->integral = pid->integral_max;
    else if (pid->integral < -pid->integral_max)
        pid->integral = -pid->integral_max;
    
    // 【修复3】微分：对反馈值微分，消除 Derivative Kick
    // 注意符号：(current - last_current) / dt1 = -(err - err_last) / dt1
    if (dt1 > 0.0001f) 
    {
      float raw_derivative = (pid->last_current - current) / dt1;
// 一阶低通：系数 alpha 通常取 0.05~0.2（取决于噪声频率）
      pid->derivative_filtered += 1.0f * (raw_derivative - pid->derivative_filtered);
    }
    float derivative = pid->derivative_filtered;
    // 【修复4】用更新后的积分计算输出
    float output = pid->Kp * err 
                 + pid->Ki * pid->integral 
                 + pid->Kd * derivative;
    
    // 输出限幅
    if (output > pid->max_output)
        output = pid->max_output;
    else if (output < pid->min_output)
        output = pid->min_output;
    
    pid->output = output;
    pid->err_last = err;
    pid->last_current = current;   // 【新增】保存本次反馈值，下周期算微分用
}

    // 把任意角度差归一化到 [-180, 180]
float circular_limit(float angle)
{
    while (angle > 180.0f)  angle -= 360.0f;
    while (angle < -180.0f) angle += 360.0f;
    return angle;
}

void Increasing_PID_Calc(Increasing_PID* pid, float target, float current, float dt2)
{
    // ========== 【新增】NaN 防火墙 ==========
    if (current != current) {   // NaN 的唯一判断方法
        return;                 // 保持上次 output，不更新历史
    }
    
    float err = target - current;
    
    // ========== 【修复】加入 dt，保证量纲一致 ==========
    float delta_output = pid->Kp * (err - pid->err_last)
                       + pid->Ki * err * dt2
                       + pid->Kd * (err - 2.0f * pid->err_last + pid->err_prev) / dt2;
    
    pid->output += delta_output;
    
    // 输出限幅
    if(pid->output > pid->max_output)
        pid->output = pid->max_output;
    else if(pid->output < pid->min_output)
        pid->output = pid->min_output;
    
    // 历史误差更新
    pid->err_prev = pid->err_last;
    pid->err_last = err;
}

    if(KEY3_mode==CLASS_TWO) class_two_logic();
    if(KEY3_mode==CLASS_THREE) class_three_logic();
    if(PID_count > 1000) PID_count = 0;
    
}
