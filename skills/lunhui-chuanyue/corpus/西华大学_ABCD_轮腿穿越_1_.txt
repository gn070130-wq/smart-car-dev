摘要
本文围绕第二十一届全国大学生智能汽车竞赛轮腿穿越组别的竞赛任务，基于 V 型轮腿车模完成了智能车的整体设计与实现。系统以英飞凌 CYT4BB7 单片机为核心控制单元，搭建 MT9V034 摄像头与 IMU660RB 惯性传感器融合的感知方案：摄像头负责元素图像采集与路径特征提取，陀螺仪输出车体姿态与航向数据，共同支撑平衡控制与路径导航功能。机械设计采用低重心、低重量、高强度的优化策略，通过 3D 打印定制支架完成传感器与电路模块的安装，在控制整车质量的同时提升动态稳定性。硬件采用主控与驱动分离的模块化架构，通过 DC-DC 与 LDO 多级稳压方案满足不同器件的供电需求，提升系统运行可靠性。软件层面采用串级 PID 算法实现车模直立平衡控制；图像处理通过二值化提取赛道与特殊元素，实现稳定的路径跟踪。经实际场地测试验证，该车模可稳定完成竞赛科目，系统响应迅速、抗扰能力强，整体性能满足竞赛要求。
关键词：智能车，PID，CYT4BB7

Abstract
This paper focuses on the competition tasks of the wheel-leg traversal category in the 21st National University Student Smart Car Competition, and completes the overall design and implementation of the smart car based on a V-shaped wheel-leg vehicle model.
The system takes the Infineon CYT4BB7 microcontroller as the core control unit, and constructs a multi-sensor fusion perception scheme integrating an MT9V034 camera and an IMU660RB inertial sensor. The camera is responsible for track element image acquisition and path feature extraction, while the inertial sensor outputs vehicle attitude and heading data, which jointly support the functions of balance control and path navigation.
For mechanical design, the optimization strategy of low center of gravity, light weight and high strength is adopted. Custom mounting brackets fabricated by 3D printing are used for the installation of sensors and circuit modules, which improves dynamic stability while controlling the overall vehicle mass.
The hardware adopts a modular architecture with separated main control and drive modules. A multi-stage voltage regulation scheme composed of DC-DC converters and LDOs is applied to meet the power supply requirements of different devices, enhancing the operational reliability of the system.
On the software level, a cascade PID algorithm is implemented to achieve the upright balance control of the vehicle. Track boundaries and special elements are extracted via image binarization to realize stable path tracking.
Verified by on-site field tests, the vehicle model can complete all competition tasks stably. The system features fast response and strong disturbance rejection capability, and its overall performance meets the competition requirements.
Keywords: Intelligent Vehicle, PID,CYT4BB7

































第一章 引言
全国大学生智能汽车竞赛是融合机械设计、嵌入式控制、传感技术与智能算法的综合性科技竞赛，旨在培养大学生的工程实践能力与创新思维。第二十一届全国大学生智能汽车竞赛轮腿穿越组别，以轮腿式平衡车模为载体，要求车模具备稳定直立行驶与自主循迹能力，对系统的机械可靠性、硬件稳定性与算法鲁棒性均提出了较高要求。
轮腿式移动平台的平衡控制与自主导航是当前移动机器人领域的研究热点。在直立控制方向，串级PID控制架构凭借分层调控的优势被广泛应用于两轮直立系统，通过角度环与角速度环的协同配合，可同时保障系统的稳态控制精度与动态抗干扰能力；针对轮腿机构的独有特性，通过调节腿部姿态改变整车重心分布实现加减速，进一步丰富了平衡控制的调节手段。在路径导航领域，纯追踪算法以其简洁的几何模型与较低的算力需求，成为嵌入式智能车路径跟踪的主流方案，结合惯性导航技术可在无外部定位信号的场景下实现自主循迹。在环境感知方向，基于摄像头的元素识别技术已发展成熟，通过图像预处理与特征提取可快速获取元素与赛道信息，为车辆自主行驶提供可靠的环境依据。
本文针对轮腿穿越组的竞赛任务要求，完成了智能车控制系统的整体设计与实现。系统以英飞凌CYT4BB7单片机为控制核心，融合惯性传感器与摄像头构建多源感知体系；采用串级PID算法实现车模直立平衡控制，结合惯性导航与纯追踪算法完成路径导航，并同步完成了机械结构优化与硬件电路设计。经实际场地测试验证，系统可稳定完成各竞赛科目，基本满足竞赛要求。
本报告后续章节安排如下：第二章介绍车模机械结构的设计与优化方案；第三章阐述硬件系统的电路架构与模块设计；第四章说明软件系统的整体架构与核心控制算法；第五章介绍系统的开发工具与调试过程；第六章给出模型车的主要技术参数；最后为结论与参考文献部分。





第二章 车模机械结构设计
智能车中的控制都是在一定的机械结构基础上实现的，因此在设计整个软件架构和算法之前一定要对整个车模的机械结构有一个感性的认识，然后建立相应的数学模型。从而再针对具体的设计方案来调整赛车的机械结构，并在实际的调试过程中不断的改进和提高。本章将主要介绍智能车车模的机械结构和调整方案。
2.1 整车机械结构
根据此次竞赛规则要求，轮腿穿越组别允许自制车模，我们采用的是博思威龙公司生产的V车模。整车机械结构围绕低重心、轻量化、高刚性的原则优化布局，为直立平衡控制与路径导航提供稳定的机械基础。
车体采用碳板作为主控板安装平台，在保证结构刚性、削弱振动干扰的同时控制上层重量，避免整车重心过度抬升。电池组通过3D打印定制电池板固定于车模底部，下沉式布局有效压低重心，同时可靠限位电池，防止行驶中电池滑动造成重心偏移；陀螺仪直接安装于底部电池板上，紧邻整车质心，姿态数据采集更精准。前端视觉摄像头采用碳素杆支架支撑，前置布局保障图像采集的前瞻性，碳素杆材质可有效抑制画面抖动。整体排布紧凑合理，兼顾装配调试便利性与系统运行稳定性。下图是我们车模整体机械结构情况。

2.3 陀螺仪安装 
陀螺仪是轮腿车平衡控制与路径导航的核心传感器，其安装位置的选择直接决定姿态解算与路径导航的准确性，对整套控制系统的性能有着关键影响。在确定安装方案时，我们围绕感知精度与抗振稳定性两个核心目标展开验证：既要保证传感

器能够灵敏捕捉车体的姿态变化，真实反馈车体运动状态，也要尽可能削弱行驶过程中机械振动对测量信号的干扰，避免姿态解算出现偏差。
经过不断测试与方案对比，我们最终将陀螺仪固定在车模底部的电池板上。该位置紧邻整车质心，采集到的姿态数据能够真实反映车体的整体运动状态，避免了安装位置偏置带来的姿态测量偏差；同时电池板自身具备良好的结构刚性，能够为传感器提供稳固的安装基底，有效抑制路面颠簸与机构运动带来的高频振动干扰，最终在测量精度与机械稳定性之间取得了理想的平衡效果。安装方式如下图所示。

第三章 硬件系统设计
3.1 硬件电路系统设计方案
硬件电路是整个系统的基础，其设计直接影响整机运行的稳定性。本着可靠、模块化的原则，电路划分为单片机最小系统、电源模块、电机驱动模块等单元。
电源采用分级降压架构，路径为12V→5V→3.3V。先由两个DC-DC芯片 TPS565201DDCR 将 12V 降至 5V 分别为核心板和外设——蜂鸣器、GPS模块、TFT、无线串口、IMU模块供电，芯片外围配置输入输出滤波电容（47μF、100nF）、功率电感（3.3μH）和反馈电阻网络，保证输出电压精度与纹波抑制；5V 后接 LDO 降压至 3.3V，用于按键和摄像头。
电机驱动模块以 CYT2BL3 为控制核心，设计为双路电调，驱动左右侧电机。整体电源分配清晰，各级均经合理滤波去耦，确保各模块获得稳定供电，提升系统抗干扰能力与运行可靠性。
3.2 电源管理模块
电源模块是控制系统的能量核心，其性能优劣直接决定了整机能否稳定运行，因此在系统设计时需慎重选型。为保证智能车在室外高速行驶场景下具备充足的续航能力，我们选用了容量为 1500mAh 的 3S 航模锂电池，为主控板及驱动模块提供整机供电。
电源模块主要由三部分构成：即 12V-5V 给核心板供电部分、12V-5V 给外设供电部分、5V-3.3V 部分。第一、二部分是基于 TPS565201DDCR 设计的，在该环节中，由于输入输出压差较大，若采用线性稳压方案将产生显著的热耗散，不仅降低能量利用效率，还会给系统热管理带来负担。因此我们选用同步降压 DC-DC 芯片 TPS565201DDCR 实现该级转换，其依托电感储能原理，具备发热量小、转换效率高的优势，最大输出电流可达 5A，能够充分满足后级负载的功率需求。外围配合 3.3μH 功率电感及 47μF、100nF 输出电容，有效抑制开关纹波，确保 5V 母线电压稳定纯净，为无线串口、IMU、蜂鸣器、TFT 及 GPS 等模块提供可靠供电。


第三部分 5V 降 3.3V，采用LDO芯片TPRT9013。

其中直立平衡控制采用双环串级结构，由外环俯仰角度环与内环俯仰角速度环级联构成。外环以车体目标俯仰角度为设定值，将 IMU660RB 解算得到的实时俯仰角度作为反馈量计算角度偏差，经位置式 PID 运算后输出内环的期望角速度指令；内环以陀螺仪采集的实时俯仰角速度为反馈信号，快速跟踪外环输出的角速度目标值，经位置式 PID 运算输出无刷电机的驱动占空比，动态调节电机输出力矩以修正车体姿态偏差，兼顾姿态控制的稳态精度与系统动态响应速度。


图4.1 直立环串级PID

速度调节环路同样采用位置式 PID 算法，以设定的目标车速与采集的实际转速差值作为输入偏差，运算输出的控制量直接作用于腿部舵机：通过改变舵机占空比调节舵机输出角度，带动腿部产生前后俯仰动作，进而改变整车重心的前后位置，利用重心偏移形成的重力分力实现车模的平稳加速与减速。该速度调节方式与直立平衡双环相互协同，在加减速过程中可通过姿态环实时修正车体倾角，保障行驶过程中的直立稳定性与平顺性。

4.2 路径导航
路径导航采用惯性导航与纯追踪算法相结合的自主循迹方案，无需依赖外部GPS定位，仅通过车载传感器即可完成路径记录与复现。惯性导航模块融合IMU输出的偏航角与磁编码器采集的车轮转速，通过运动积分实时解算车体的坐标位置，并以固定步长离散记录轨迹点，形成基准行驶路径。路径跟踪基于纯追踪算法实现，以上一时刻匹配的最近轨迹点为基准，在局部限定范围内搜索当前位置对应的最近轨迹点，再向前选取固定距离的预瞄点，通过几何计算得到目标航向与车体当前航向的偏差，经角度归一化后输出至转向控制环节，通过差速修正行驶方向，完成车模对基准路径的稳定跟踪。该方案运算量适配单片机算力，跟踪过程平滑连续，可与直立平衡、速度调节控制环路协同工作。


图4.3 惯性导航记录轨迹函数

4.3 图像处理
图像处理部分大致分为赛道循迹与台阶跳变特征检测两部分。赛道循迹首先对摄像头采集的灰度图像进行二值化，再通过由近至远的搜索方式结合历史赛道信息完成循迹，有效应对赛道遮挡、短暂丢线等异常情况。同时对提取的赛道中线进行平滑滤波处理，降低识别抖动，最终输出稳定的赛道中心偏差数据，为车辆直行循迹提供依据。
台阶跳变点检测是程序选取图像中部多列像素点纵向扫描，利用差比和算法计算，以此判定黑白边界跳变位置；收集多处采样得到的跳变点，通过误差约束剔除异常采样值，对有效点位求取平均值，输出稳定的跳变纵向位置。
4.4.菜单、状态机
菜单承担人机交互功能，支持在不重新下载程序的前提下修改参数，实现快速现场调试。菜单基于索引表架构搭建，使用枚举变量映射各个菜单页面，依托上、下、确认、返回四颗按键完成操作控制。理论上支持数量不限的可调参数，能够依据不同页面功能展示对应信息，可完成参数修改、一键发车等操作，极大提升调试便捷性。

第七章 结论
本文围绕第二十一届全国大学生智能汽车竞赛轮腿穿越组任务要求，完成了轮腿平衡智能车的机械结构、硬件电路与控制软件全流程设计调试。系统以英飞凌 CYT4BB7 单片机为核心，采用串级 PID 方案实现直立平衡控制，通过调节轮腿姿态改变整车重心完成速度调控，结合惯性导航与纯追踪算法实现自主路径导航；机械端采用底部电池低重心布局，搭配 3D 打印定制结构件与碳素杆摄像头支架，调试采用按键离线调参结合逐飞助手上位机的方案。经测试，车模可稳定完成直立行驶、元素识别与路径复现，整体性能基本满足竞赛技术要求。
测试中也发现系统仍存在多处不足：轮腿运动与路面颠簸产生的机械振动会干扰 IMU 姿态解算，高速、越障工况下平衡稳定性有所下降；固定阈值图像处理对光照变化适应性不够强，强光、阴影场景下元素识别易出现偏差；惯性导航存在固有累积误差，长距离行驶后轨迹复现偏移量会逐步增大；高速下重心调节与直立平衡环的动态耦合效果仍有提升空间。
针对上述问题，后续可从多方向优化：引入卡尔曼滤波并配合结构减振设计，抑制振动干扰、提升姿态解算精度；加入自适应二值化与光照补偿机制，增强复杂光照下赛道识别的鲁棒性；进一步优化速度环与直立环的耦合控制策略，提升车模高速与越障情况下的稳定性。
本次实践表明，轮腿平衡车是机械、硬件与算法高度耦合的系统，单一环节的优化难以实现整车性能突破，需多维度协同配合。嵌入式控制系统设计必须紧密结合实车反复调试，在有限硬件资源下兼顾实时性与可靠性。本次项目积累的经验，为后续相关研究打下了坚实基础。

{
  float q00_t,q11_t,q22_t,q33_t;

    gx *= Gyro_Gr;
    gy *= Gyro_Gr;
    gz *= Gyro_Gr;//转为弧度/秒
  
     ax = (float)raw_ax / 4098.0f; 
     ay = (float)raw_ay / 4098.0f;
     az = (float)raw_az / 4098.0f;//加速度转为g
     
     
     
     float acc_norm = sqrt(ax*ax + ay*ay + az*az);
           if (acc_norm>=0.9f && acc_norm<=1.1f)//判断是否静止
        {
            kp_current = kp_base;
            ki_current = ki_base;
            integral_gain=1.0f;//静止
            acc_alpha=0.8f;
        }
        else
        {
            kp_current = kp_base*0.5f;
            ki_current = ki_base;
            integral_gain=0.1f;//运动
            acc_alpha=0.5f;

        }

        
//        filter_gx = filter_gx * 0.6f +0.4f * gx;
//        filter_gy = filter_gy * 0.6f +0.4f * gy;
//        filter_gz = filter_gz * 0.6f +0.4f * gz;

     
     filter_ax=filter_ax*acc_alpha+ax*(1-acc_alpha);//加速度低通滤波
     filter_ay=filter_ay*acc_alpha+ay*(1-acc_alpha);
     filter_az=filter_az*acc_alpha+az*(1-acc_alpha);
     

     
    // 加速度归一化
    float norm_a = sqrt(filter_ax*filter_ax + filter_ay*filter_ay + filter_az*filter_az);
    
    if(norm_a < 0.1f) return;     // 防除零，异常值直接退出更新
    filter_ax /= norm_a; filter_ay /= norm_a; filter_az /= norm_a;

    float gx_map = gx;   float gy_map = gy;   float gz_map = gz; // 陀螺轴映射+符号
    float ax_map = filter_ax;   float ay_map = filter_ay;   float az_map = filter_az; // 加速度同步映射+符号


    // 根据当前四元数计算重力向量在机体坐标系投影
    float gx_q = 2 * (q11*q33 - q00*q22);
    float gy_q = 2 * (q00*q11 + q22*q33);
    float gz_q = q00*q00 - q11*q11 - q22*q22 + q33*q33;
    
    // 重力叉乘误差
    float ex = ay_map * gz_q - az_map * gy_q;
    float ey = az_map * gx_q - ax_map * gz_q;
    float ez = ax_map * gy_q - ay_map * gx_q;

    
    if (imu_count < (uint32)(INIT_TIME / DT))//初始0.5s增大kp加速收敛
    {
        kp_current = kp_init;
        imu_count++;
    }
            
    
    // 积分累积静态误差
    ex_int += (ex * DT)*integral_gain;
    ey_int += (ey * DT)*integral_gain;
    ez_int += (ez * DT)*integral_gain;

    
    ex_int = (ex_int > INT_LIMIT) ? INT_LIMIT : (ex_int < -INT_LIMIT) ? -INT_LIMIT : ex_int;
    ey_int = (ey_int > INT_LIMIT) ? INT_LIMIT : (ey_int < -INT_LIMIT) ? -INT_LIMIT : ey_int;
    ez_int = (ez_int > INT_LIMIT) ? INT_LIMIT : (ez_int < -INT_LIMIT) ? -INT_LIMIT : ez_int;//积分限幅

    // 陀螺动态准+加速度稳态准，融合后无漂移且响应快
    gx_map += kp_current * ex + ki_current * ex_int;
    gy_map += kp_current * ey + ki_current * ey_int;
    gz_map += kp_current * ez + ki_current * ez_int;

    
    q00_t=q00;  q11_t=q11;  q22_t=q22;  q33_t=q33;

    //更新四元数微分方程
     q00 = q00_t+(-q11_t*gx_map - q22_t*gy_map - q33_t*gz_map) * 0.5f * DT;
     q11 = q11_t+( q00_t*gx_map + q22_t*gz_map - q33_t*gy_map) * 0.5f * DT;
     q22 = q22_t+( q00_t*gy_map - q11_t*gz_map + q33_t*gx_map) * 0.5f * DT;
     q33 = q33_t+( q00_t*gz_map + q11_t*gy_map - q22_t*gx_map) * 0.5f * DT;
  

    // 四元数归一化
    float norm_q = sqrt(q00*q00 + q11*q11 + q22*q22 + q33*q33);
    if(norm_q > 0.001f) 
    {
    q00 /= norm_q; 
    q11 /= norm_q; 
    q22 /= norm_q;
    q33 /= norm_q;
    }

    // 四元数解算Roll/Pitch
    Roll  = atan2(2*(q00*q11 + q22*q33), 1 - 2*(q11*q11 + q22*q22)) * (180.0f / M_PI); // 横滚角（°）
    Roll+=180.0f;
  if(Roll>180.0f){Roll-=360.0f;}
        else if(Roll<-180.0f){Roll+=360.0f;}
   // Roll = atan2(2*(q00*q11 - q22*q33), q00*q00 - q11*q11 - q22*q22 + q33*q33) * (180.0f / M_PI);
  Pitch = asin(2*(q00*q22 - q11*q33)) * (180.0f / M_PI);    // 俯仰角（°）
       // Yaw_1 = atan2(2*(q11*q22 + q00*q33), q00*q00 + q11*q11 - q22*q22 - q33*q33) * (180.0f / M_PI);

}
