# 走马观碑 · 由开源工程提炼的搭建要点

本组报告 KB 未单独挂接；以下来自本地推荐仓与 `smart-car-dev/references` 多仓解析。

## 典型栈

- 计算平台：龙芯 LS2K / Linux 用户态常见  
- 传感：相机（碑文/路径）  
- 软件：采集 → 检测/OCR 或特征 → 导航点任务状态机 → 底盘控制  

## 搭建顺序

1. 相机预览 + 保存帧  
2. 碑点/目标检测最小模型或传统 CV  
3. 任务状态机（寻碑→识别→下一目标）  
4. 底盘控制与超时保护  
5. 详见 `../../smart-car-dev/references/` 下走马相关 overview/algorithms（若存在）

## 改代码原则

视觉推理与控制解耦；控制环不阻塞在推理上。
