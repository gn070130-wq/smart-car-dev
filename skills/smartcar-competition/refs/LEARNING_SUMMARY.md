## 1. 项目组别与硬件栈

| 项 | 结论 |
|----|------|
| 组别 | **第 21 届全国大学生智能汽车竞赛 · 雁过留痕**（本批以**本科组**为主；工作区另有专科语料） |
| 核心任务 | 视觉循迹 + 赛道元素处理 + **紫外激光打靶留痕** |
| 主控 | 几乎统一 **STC32G144K246/256**（Keil C251 / 逐飞库） |
| 摄像头 | **MT9V034 / 总钻风 / MT9V03X** 灰度，单目 |
| 驱动 | 左右有刷 + **DRV8701** H 桥为主；涵道/负压用自制无刷电调 |
| 反馈 | 双编码器；常见 **IMU660RA**；少数队加 **ToF(DL1B)** |
| 执行 | 舵机转向；**5–9 路激光阵列**或云台；常配备负压/涵道 |
| 电源 | 约 3S 锂电 → 多路 DC-DC（3.3V MCU / 5V 外设 / ~8V 舵机 / 电机直供） |

## 2. 软件架构（共识）

```
摄像头帧完成 flag ──► 主循环：阈值/搜线/中线/元素/打靶决策
TIM PIT（1ms 基时）──► 5ms 速度PID+电机；5–8ms 舵机；激光脉冲/保护；按键/遥测
UART/按键/屏     ──► 在线调参、模式、启停
```

依赖关系：**视觉输出偏差/状态 → 决策状态机 → 舵机&速度目标 → 电机PID/激光**；激光模块应只消费「任务有效+稳定」标志，不直接改搜线。

逐飞典型目录（湖文孔明九队）：

- `project/mdk/seekfree.uvproj` 工程入口  
- `project/user` / `project/code` 用户算法  
- `libraries/zf_common|zf_driver|zf_device` 公共/驱动/设备层  

## 3. 核心算法清单（跨队）

| 类别 | 高频方案 | 低频/进阶 |
|------|----------|-----------|
| 预处理 | 动态阈值、大津、下采样 | 逆透视查表 |
| 搜线 | **最长白列**、差比和扫线、中心扫线 | 八邻域、迷宫扶墙 |
| 控制转向 | 位置式/偏差 **PD**、**模糊自整定 Kp**、二次/动态 Kd | **纯跟踪**（少数队） |
| 控制速度 | **增量式 PI/PID** + 差速/阿克曼分配 | — |
| 元素 | **状态机**：环岛多态、十字、斑马停车、坡道 | IMU 航向辅助出环 |
| 打靶 | ROI 跳变找靶心 → 通道映射 → ms 级脉冲 | **目标运动预测+延迟补偿** |
| DL/SLAM | 本批报告中 **几乎无 YOLO/CNN/LQR** 作主链路 | 文本可做检索挖掘，非车载主循迹 |
