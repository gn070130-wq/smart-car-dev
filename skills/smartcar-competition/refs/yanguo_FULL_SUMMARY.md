## 1. 项目整体梳理

### 1.1 组别与硬件

| 项 | 内容 |
|----|------|
| 组别 | 第 21 届国赛 **雁过留痕**（本科为主） |
| 任务 | 室内 PVC 循迹一周 + **紫外激光打靶留痕** |
| 主控 | **STC32G144K246/256**（Keil C251 / 逐飞库） |
| 视觉 | **MT9V034 / 总钻风 / MT9V03X** 单目灰度 |
| 驱动 | DRV8701 H 桥 + 双有刷；涵道用自制无刷电调 |
| 反馈 | 双编码器；常见 IMU660RA；少数 ToF |
| 执行 | 舵机；5–13 路激光阵列或云台；常配负压/涵道 |
| 电源 | ~3S → 3.3V MCU / 5V 外设 / ~7–8V 舵机 / 电机直供 |

### 1.2 软件架构依赖

```
摄像头帧完成 ──► 主循环：阈值→搜线→中线→元素状态机→打靶决策→跟踪
PIT(1ms基时) ──► 5ms速度PID；5–8ms舵机；激光脉冲/保护；按键
UART/屏/按键 ──► 在线调参、启停、模式（不进实时闭环热路径）
```

依赖：**视觉 → 决策 → 舵机/速度目标 → 电机 PID / 激光**；激光只消费「任务有效+稳定」标志。

## 3. 多算法对比与优化

### 对比

| 维度 | 更稳/简单 | 更猛/难调 |
|------|-----------|-----------|
| 搜线 | 最长白列、差比和 | 迷宫+逆透视 |
| 转向 | 固定PD | 模糊Kp / 纯跟踪 |
| 打靶 | 固定行跳变+位码 | 运动预测+路况补偿 |

### 短板

参数耦合；阈值怕光变；元素误锁；速度环饱和；激光误触发；主循环过重丢帧。

### 优化分轨

- **快速改版**：曝光/阈值偏置、前瞻行、表速、舵机限幅、激光延迟/冷却；少改状态机拓扑  
- **长期重构**：感知/元素/运动/激光四层接口；逆透视+可切换纯跟踪；参数 IAP；激光安全状态机标准化

## 4. 竞赛评估与高频坑

**优势**：硬件合规清晰；帧+PIT 可复现；负压+差速利于速度；UART 调参降现场成本。  
**风险**：元素误判、曝光失效、打靶罚时、积分顶死、中断过重。

**高频坑**：曝光波动｜反光｜断线｜环岛误入｜斑马误停｜编码器极性反｜舵机中值偏｜PWM 顶限幅｜激光常开｜PIT 与帧抢时间。
