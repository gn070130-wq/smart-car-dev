# 多算法对比 · 短板 · 优化 · 竞赛评估

## 1. 寻迹横向对比

| 方案 | 优点 | 缺点 | 算力 | 抗扰 | 适合 |
|------|------|------|------|------|------|
| 航向回放 IMU_Go | 实现简单、好调 | 初值/漂移敏感 | 极低 | 低 | 重复性高的短路径 |
| Pure Pursuit+前馈 | 弯道提前量好 | 参数多、依赖坐标质量 | 低 | 中 | 绕锥、复杂段主用 |
| Stanley | 贴线强、公式清晰 | 低速 atan 项敏感 | 低 | 中高 | 八字/精细贴线 |
| 杜宾斯 | 尊重最小转弯半径 | 需准锥点、规划前置 | 低 | 中 | 锥桶科目 |
| 余弦绕锥 | 平滑左右摆 | 偏移过大易扫桶 | 极低 | 中 | 快速工程凑合 |

## 2. 控制横向对比

| 方案 | 优点 | 缺点 | 场景 |
|------|------|------|------|
| 串级 PD/PID 平衡 | 主流、可解释 | 参数耦合、科目要多套表 | 默认基线 |
| 参数插值调度 | 全速度平滑 | 表要采全 | 直道↔弯道切换 |
| 半开环急减速 | 响应快 | 表依赖、易过刹 | 进锥/进障前 |
| ADRC/LQR/MPC | 理论更强 | 调参/算力/可维护性差 | 少数进阶队 |

## 3. 原方案常见短板

1. **惯导漂移**：Yaw 无磁修正；段太长必偏  
2. **打滑**：草地速度反馈≠对地速度 → INS 歪  
3. **平衡与寻迹抢舵**：大打角寻迹时横滚失稳  
4. **UART 丢帧/延迟**：速度环与 INS 同时劣化  
5. **低速八字**：速度低于自稳区易倒  
6. **参数耦合**：科目多套 PID 无调度时来回拧  
7. **调试打印过重**：拖垮控制周期导致倒车  

## 4. 优化方向

**比赛快速改版**  
- 缩短动作段、多切点重置误差  
- 先锁平衡限幅与中位，再开寻迹  
- PP：先调 `offset`→`k_lat`→`limit`→`ff_gain`  
- 进锥/草地强制降速表；保护倾角阈值收紧  
- 关掉高频屏刷与串口刷屏  

**长期进阶重构**  
- 姿态/INS/寻迹/平衡/驱动五层接口固化  
- 寻迹策略可热切换（Go / PP / Stanley）  
- 科目参数表 + 无扰切换/插值  
- 录包（Roll,Yaw,INS,cte,duty）复盘  
- 可选：视觉锥桶检测只作校正，不替代短时惯导  

## 5. 国赛角度评估

**优势**  
- 纯惯导硬件简单、合规（不靠视觉标线）  
- 分层控制可复现；FOC+磁编动力强  
- 轨迹回放降低现场识别负担  

**风险**  
- 八字低速倒车直接出局  
- 绕锥扫桶/切内；草地漂移导致后续段全崩  
- 现场重采轨迹成本高；参数科目间冲突  

## 6. 高频坑点清单

| 现象 | 优先查 |
|------|--------|
| 原地/低速倒 | 平衡环极性、中位、速度是否过低、IMU 方向 |
| 越跑越偏 | 零偏、Yaw 漂移、点距、采样时车速 |
| 绕锥切内/扫桶 | PP 前瞻、横向限幅、降速、锥点坐标 |
| 草地后全乱 | 打滑→INS；段切分与重标定 |
| 电机抖/不跟 | UART 校验、FOC 板、占空比限幅饱和 |
| 舵机尖叫 | 平衡与寻迹增益同时过大、限幅太宽 |
| 控制周期不稳 | 打印/刷屏/Flash 写入放进实时环 |

## 7. 现场调参顺序（可照做）

1. 静态 IMU 方向与零偏  
2. 架空：舵机方向、电机方向、UART 速度帧  
3. 只开平衡+速度，低速直行不倒  
4. 低速采样轨迹 → 写 Flash → 校验点数  
5. `IMU_Go` 回放 → 再开 PP  
6. 分科目锁速度表与 PID 表  
7. 保护阈值实车验证（故意偏航/侧倾）
