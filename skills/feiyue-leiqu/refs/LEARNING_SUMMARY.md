# 【学习摘要】飞跃雷区

## 组别

**第 21 届全国大学生智能汽车竞赛 · 飞跃雷区**

- 场地约 5–7 m 室内；乳白色扁圆**信标灯**分批点亮  
- 系统 = **悬停飞行器** + **地面车** + **≤1.5 m 系留线**（供电+有线数据，禁止任务无线）  
- 飞机感知信标并下发目标；地面车驶向并从上方**轧灭灯**；计时期间队员不得遥控闭环  

## 硬件栈（共识）

| 模块 | 常见选型 |
|------|----------|
| 飞控/车控主控 | 英飞凌 **CYT4BB7 / TRAVEO**（双核常见）；电调侧 **AI8051 / STC32G** |
| 视觉 | 飞行器机载 **MT9V03X/总钻风**（单目或多目）；车端**禁止**用环境感知找信标 |
| 飞控传感 | IMU（660/963 等）、光流、ToF/激光测高 |
| 地面车 | 麦轮 / Y 型全向 / 差速三轮 F 车等；编码器+IMU；常配负压风扇 |
| 动力 | 飞行无刷+自制电调；车端有刷 H 桥或无刷 FOC |
| 通信 | 系留 **UART / RS-485**；结构化结果跨节点，原始图像多留在采集核 |

## 软件架构（依赖）

```
飞机器视觉(核) → 信标/车标结构化结果
     ↓
Air规划/状态估计 → 系留链路命令
     ↓
Car底盘运动学逆解 + 速度/航向PID → 轧灯
飞控串级(角/角速度/高度/水平) 与 车控 并行；安全：授权丢失/姿态超限/数据过期 → 停机
```

调度：多核分工 + PIT/裸机多速率；图像/Flash/刷屏不得阻塞飞控 1 ms 环。

## 核心算法清单

1. 灰度阈值二值化 + 连通域/质心（信标团块）  
2. 多目/多视野融合与目标连续性  
3. 飞控串级 PID（角+角速度；高度/水平外环）  
4. 光流+IMU+ToF 融合（互补滤波/EKF/ESO·ADRC）  
5. 麦轮/全向/差速运动学 + 轮速闭环  
6. 空地任务状态机（搜灯→跟踪→轧灭→下一批）  
7. 系留扰动前馈 / 线缆拉力补偿  
8. 通信帧 CRC、新鲜度、急停与 MODE 授权
