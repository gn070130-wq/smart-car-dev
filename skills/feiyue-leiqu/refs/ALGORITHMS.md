# 飞跃雷区 · 算法卡

## A1 阈值 + 连通域质心（信标）

**作用**：从灰度图提取亮灯区域质心。  
**公式/流程**：`B=gray>T` → 八连通标记 → 面积∈[Amin,Amax] → `cx=Σx/N, cy=Σy/N`。  
**伪代码**：
```
for each blob:
  if area ok and aspect ok: score = f(area, brightness, roundness)
pick best score → (u,v)
```
**参数**：T、Amin/Amax、打分权重。  
**适用**：室内信标灯；反光强时抬 T 或加形态学开运算。  
**坑**：车灯/反光地板误检；过曝融并多灯。

## A2 双通道（信标 vs 车标）

**作用**：区分场上信标与车上标识灯。  
**方法**：高阈+面积→信标；低阈/边缘→车灯；或分 ROI。  
**坑**：同一曝光难兼顾；需分时曝光或双阈值流。

## A3 多目映射融合

**作用**：三路/多路相机统一到车体系或场地系。  
**方法**：各相机外参投影 → 加权/最近邻选主目标 → 丢帧保持上一帧并降置信。  
**坑**：时间戳不同步；外参漂移。

## A4 姿态串级 PID

**外环角度 → 内环角速度 → 电机混控**。  
姿态：Mahony/互补/简易 EKF。  
**参数**：外Kp小、内环带宽更高；限幅防饱和。  
**坑**：内环过猛振荡；系留力矩当扰动未建模。

## A5 高度：ToF + EKF/ADRC

**测量**：下视 ToF（可双 DL1B）；光流辅助水平。  
**控制**：PID / 高度 EKF / ADRC（抗系留扰动常用）。  
**坑**：地效、倾斜测距偏短；系留张力突变。

## A6 水平位置 PID + 光流/ESO

把像素误差→机体/场地平面速度指令；光流或 ESO 抑抖。  
**坑**：像素→米刻度随高度变化，需除以焦距/高度。

## A7 麦轮 / Y 全向逆解

`vx,vy,ω → [w1..wn]`（标准麦克纳姆或 120° Y 轮矩阵）。  
**坑**：轮半径/轴距标定错→斜走；打滑时开环漂移。

## A8 轮速 PID

位置式或增量式；输出 PWM/电流指令。  
**坑**：编码器跳变；静摩擦死区需 bang-bang 或前馈。

## A9 系留扰动前馈

张力/倾角估计 → 推力补偿（湖文等报告）。  
无张力计时用观测器近似。

## A10 通信帧 + 新鲜度

帧：`HDR | type | payload | CRC`；解析后写共享结构。  
`if now-stamp > T_expire: zero_cmd / hover_safe`。  
**坑**：半包粘包；车端未校验 CRC 跟飞目标。
