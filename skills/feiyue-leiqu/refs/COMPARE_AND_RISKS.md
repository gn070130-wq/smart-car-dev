# 飞跃雷区 · 对比与风险

## 方案对比（报告侧）

| 维度 | 常见选择 | 何时更稳 |
|------|----------|----------|
| 相机 | 单下视 / 三目 | 多灯、遮挡多 → 多目 |
| 主控 | CYT4BB7 多核 / 分板 | 算力紧 → 视觉独立核 |
| 车底盘 | 麦轮 / Y全向 / 差速+负压 | 需平移轧灯 → 全向；要贴地稳 → 负压差速 |
| 高度 | PID / EKF / ADRC | 系留抖严重 → ADRC/前馈 |
| 通信 | UART / RS-485 | 长线噪声 → 485+CRC |

## 缺陷与改版

- **检灯飘**：曝光/阈值死板 → 自适应 T + 面积打分 + 形态学。  
- **轧偏**：像素系未按高度标定 → `err_m = k * pix * h`。  
- **飞抖**：图像处理进飞控中断 → 挪核、共享内存、非阻塞。  
- **车乱跑**：旧帧未过期 → 强制新鲜度。  
- **系留扯飞**：无扰动补偿 → 前馈/限加速度。

快速改版：阈值、限速、超时、急停、目标选择。  
长期：坐标系契约、录包、统一参数表 Flash。

## 竞赛风险清单

1. 系留缠绕/过短过长  
2. 多灯竞争选错目标  
3. 飞控掉高砸车/砸灯  
4. 电调/电机过热饱和  
5. 联调只有整机、缺分段回放  
6. 赛场光照与实验室差大  

高频故障树：反光误检 → 丢目标悬停/乱跟 → 通信丢帧 → 车冲 → 姿态超限保护切停。
