# 飞跃雷区 · 完整汇总

## 1. 架构说明

**空中感知 + 地面执行** 的系留协同：

```
[飞行器] 摄像头(1~3路) → 视觉核 → 结构化目标
         IMU/光流/ToF → 飞控核 → 姿态/高度/水平
                ↓ 系留 UART/RS-485（禁止任务无线）
[地面车] 收目标坐标 → 运动学 → 轮速环 → 轧灯
         车载电池 → 系留供电飞机（飞机不得自带电池）
```

安全边界：遥控仅赛前/急停；RUN 数据过期、姿态超限、授权丢失 → 停执行器。

## 2. 文件结构索引（报告共识 · 无统一开源树时的逻辑工程）

```
Air/（飞行器）
  vision_*     # 灰度、阈值、连通域、多目融合
  attitude_*   # IMU、Mahony/EKF、串级PID
  altitude_*   # ToF/光流、ADRC/EKF高度
  planner_*    # 任务状态机、目标选择
  air_comm_*   # 组帧 CRC、共享快照 IPC
Car/（地面）
  kinematics_* # 麦轮/Y全向/差速逆解
  motor_pid_*  # 轮速环
  uart_rx_*    # 收Air命令
Esc/（电调固件）
  AI8051/STC32 # 无感或FOC、PWM捕获
```

入口：各核 `main` + PIT（飞控常 1 ms）；图像在独立核/前台，禁止堵飞控中断。  
配置：Flash 参数槽、MODE 授权、限幅与新鲜度超时。

（具体 `.c` 名因队而异；杭电附录给出 Car 10 ms 节拍、AI8051、AirComm、三摄边界等清单，开发时以你选定主锚工程对齐。）

## 3. 算法清单（要点）

见 `ALGORITHMS.md`。高频：**连通域信标**、**飞控串级 PID**、**高度融合**、**全向/麦轮逆解**、**有线协议+新鲜度**。

## 4. 对比与缺陷

| 方案 | 优点 | 风险 |
|------|------|------|
| 单目下视 | 简单 | 视野/遮挡 |
| 三目/多核 | 覆盖与连续性好 | 同步、算力、调试难 |
| 麦轮/Y全向 | 平移轧灯灵活 | 打滑、标定复杂 |
| 差速F车+负压 | 结构稳、附着力 | 机动性弱于全向 |
| ADRC高度 | 抗系留扰动 | 参数多 |

隐患：多核抢总线；视觉堵控制；系留扯飞；灯与车标混淆；通信过期仍跟旧目标；电机饱和。

**快速改版**：阈值/打分权重、目标选择策略、限速、新鲜度超时、急停。  
**长期重构**：感知/规划/飞控/车控接口固化；统一坐标系契约；录包复盘。

## 5. 竞赛风险

优势：任务分解清晰（看灯的飞、轧灯的车）；有线抗无线干扰。  
薄弱：系留缠绕/扯拽；多灯同时；轧灯偏移；飞控掉高；联调周期长。  
高频故障：曝光/反光 → 检错灯；丢目标；编码器噪声；中断冲突导致飞抖；UART 丢帧车乱跑。
