# 飞跃雷区 · 逻辑工程结构

资料以技术报告为主，**无统一开源整树**；下列为多队共识骨架，开发时按你选定主锚对齐文件名。

## Air（飞行器）

| 逻辑模块 | 职责 | 节拍建议 |
|----------|------|----------|
| `vision_*` | 采集、二值、连通域、多目融合 | 按帧；勿堵飞控 |
| `attitude_*` | IMU 融合、串级姿态 | 1 ms 级 |
| `altitude_*` | ToF/光流、高度环 | 5–20 ms |
| `horiz_*` | 像素/平面位置环 | 与视觉同步或略慢 |
| `air_comm_*` | 组帧、CRC、发车 | 10–20 ms |
| `fsm_*` | 授权、任务、安全 | 与主循环 |

## Car（地面）

| 逻辑模块 | 职责 |
|----------|------|
| `uart_rx_*` | 解帧、新鲜度 |
| `kinematics_*` | vx,vy,ω→轮速 |
| `motor_pid_*` | 轮速/电流 |
| `car_fsm_*` | 跟目标/轧灯/停 |

## Esc

AI8051 / STC32：PWM 捕获、无感或 FOC、保护。

## 配置与入口

- 各核 `main` + PIT/定时器  
- Flash 参数：PID、阈值、外参、超时  
- MODE/遥控：仅赛前与急停
