智能车系统总体设计概述
1.1机械设计概述
根据组委会要求，我们的系统由悬停飞机和地面车两部分组成，通过不超过1.5米的系留线缆连接，线缆同时承担供电与数据传输。悬停飞机采用五寸穿越机碳板机架，搭载MT9V03X全局快门摄像头、激光ToF、UPFLOW302光流模块及imu963ra九轴IMU。地面车采用M全向轮车模，顶部安装V形红外灯板作为视觉信标，主控板与DRV8701E驱动板分层固定于车身，搭载imu660rcIMU与四路编码器。
1.2硬件电路设计概述
硬件电路是保证无人机稳定行驶以及功能实现的基础，所以其稳定性至关重要，通过EDA以及AD设计所需的驱动模块，降压稳压模块等模块的原理图，并将其功能凝聚在三块PCB板中，为保证系统的稳定，我们将驱动PCB，主板PCB 分离互不干扰，而最小系统板由于自己设计焊接难度以及稳定性较差，最后采用商家提供的最小系统板，若损坏可随时更换。

1.3软件设计概述
本系统软件采用空地精细架构，核心包含视觉感知、控制与成型解算三大模块。无人机主控通过图像快速算法提取信标与车体坐标解算位置偏差后下发。飞端利用串级PID算法执行姿势与定高闭环实现稳定悬停；地面车接收偏差指令，完成全向运动学解算与电机闭环速度保障，驱动车模精准灭灯。整体设计系统具有高鲁棒性。
智能车系统总体设计详述
本章主要描述了智能车系统总体的设计方案，在后文中主要分为总体思路，机械设计，电路设计，软件控制这几个部分来进行描述。

2.1 总体思路
本次设计对象为无人机与地面车协同系统，是智能车大赛中首次引入空地协同任务的竞赛组别，对系统的感知、控制与协同能力提出了更高要求。基于前期智能车项目的实践经验，在确定采用无人机搭载摄像头进行视觉感知后，我们围绕无人机姿态稳定控制、目标识别定位以及与地面车协同通信等关键问题展开研究。通过对无人机飞行控制系统的学习与调试，我们逐步掌握了姿态调整、位置控制以及视觉信息处理等核心技术，并结合任务需求设计了协同控制方案，使无人机能够稳定完成信标灯定位任务，并为地面车提供有效的导航信息，从而实现空地平台之间的高效配合。任务要求利用安装在无人机上的摄像头对场地内信标灯进行精准定位，并引导无人机与地面车协同完成灭灯任务。无人机负责空中视觉感知、目标识别与位置定位，通过实时获取信标灯信息，为地面车提供导航与决策依据；随后，地面车通过搭载的遮挡板依次划过各信标灯上方，实现信标灯的熄灭。当所有信标灯熄灭后，系统将自动点亮下一组信标灯，无人机与地面车继续协同执行任务循环，直至完成全部任务，最终以总用时最短者获胜。相较于传统单一移动平台任务，该赛题更加注重空地协同能力，无人机不仅需要具备稳定飞行与精准定位能力，还需要与地面车实现高效的信息交互与任务配合，这为系统设计与算法优化提供了更大的挑战与发挥空间。
 


图1.1  M车车模图
根据题目要求以及团队前期智能车项目经验，主控芯片我们选择了 Infineon TRAVEO™ T2G CYT3BB/4BB 系列微控制器。该芯片基于 Arm® Cortex®-M7 架构，最高运行频率可达250MHz，具备单/双精度浮点运算单元（FPU）以及DSP运算支持，能够满足无人机姿态控制、传感器数据融合以及实时任务处理的需求。同时，该芯片集成了丰富的存储资源，包括最高4160KB代码Flash、256KB工作Flash以及768KB SRAM，可为控制算法、通信协议以及数据处理提供充足的存储空间。
空中单元：采用五寸穿越机机架作为飞行平台，搭载两颗英飞凌CYT4BB7 主控芯片作为图像处理芯片和飞控、双广角红外摄像头、ToF传感器及陀螺仪。无人机负责全局视觉定位、车模相对位姿解算、航线规划，是系统的“大脑”和“眼睛”。
地面单元：采用传统麦轮结构车模，由英飞凌CYT4BB7主控，顶部安装定制V形红外灯板作为视觉信标。车模接收无人机下发的期望路径和速度指令，执行高精度轨迹跟踪，并承担无人机供电、盲盒任务供电等职责。
系统工作流程为：无人机通过双摄像头实时识别地面车模灯板，解算其位置与航向；将灯与车的误差实时传输给下车；车模采用pid控制算法跟踪期望轨迹。整个系统实现了实时处理。

2.3 硬件电路设计
硬件是智能车系统的基础。其设计依据于AD2023（Altium Designer2023）以及立创EDA，内容包括原理图设计，PCB设计。以下文章将详细讲述各个模块的设计原理，目的，以及单片机资源分配和其中的注意事项。
2.3.1 最小系统板模块
本组无人机协同系统采用 Infineon TRAVEO™ T2G CYT3BB/4BB 系列最小系统板作为核心控制平台，负责无人机飞行控制、传感器数据采集以及空地协同任务的数据交互。考虑到自制控制板在硬件稳定性、调试效率以及可靠性方面存在一定不确定性，因此本系统采用成熟的商用最小系统板作为主控平台。TRAVEO™ T2G CYT3BB/4BB系列微控制器基于 Arm® Cortex®-M7 架构，最高支持单/双 Cortex®-M7 内核运行，单核最高运行频率可达250MHz，并集成浮点运算单元（FPU）以及DSP运算功能，能够满足无人机姿态解算、控制算法运行以及多传感器数据融合等实时计算需求。该芯片具备丰富的存储资源，包括最高4160KB代码Flash、256KB工作Flash以及768KB SRAM，可为飞控程序、通信协议以及任务控制逻辑提供充足的存储空间。

2.4 软件设计
在软件部分中，空地协同控制是飞跃雷区系统的核心。本系统软件基于imu963ra九轴IMU、UPFLOW302光流、DL1B ToF、MT9V03X摄像头和四路512线编码器完成悬停飞机稳定飞行、信标灯识别定位以及地面车全向运动灭灯任务。系统采用双控制器协同架构：飞机端CYT4BB7同时负责视觉感知决策与飞控姿态位置闭环，地面车CYT4BB7负责运动执行。
2.4.1 飞控姿态与定点控制
飞机端飞控在5ms（200Hz）PIT中断内运行，采用"角度环→角速度环"串级PID结构。姿态解算采用Mahony互补滤波四元数算法：加速度经标量卡尔曼滤波（Q=0.01/R=0.10），陀螺一阶低通（α=0.73）并扣除零偏，以加速度模长与帧间变化检测运动状态生成置信权重，融合参数KP=2.75、KI=0.027，按ZYX序提取欧拉角。外环角度误差归一化到±180°，积分限幅Angle_IMAX=100；内环角速度环增益按kp/10、ki/100标定，积分下限Gyro_IMIN=50，偏航内环imax=15。低油门（Oil_n<70）时清除全部积分并令平衡输出归零，实现积分分离。定高采用DL1B ToF与加速度二阶互补滤波融合（K_POS=0.10、K_VEL=0.02，ToF超时100ms失能），经"高度环（kp=1.8）→垂直速度环（kp=55,ki=2.4,kd=0.5）"串级输出油门补偿，目标高度1.3m按0.4m/s斜坡爬升。定点融合UPFLOW302光流速度（经陀螺转动补偿、5Hz低通、高度换算、限幅±60cm/s）与加速度互补融合（β=0.60），速度环100Hz输出期望倾斜角（限幅±10°）。


2.4.2 地面车运动控制
地面车采用"视觉外环（50Hz）→运动内环（200Hz）"双闭环结构。视觉外环接收飞机下发的信标与小车像素坐标，计算前向误差（by−cy）与侧向误差（cx−bx），经EMA滤波（α=0.3）后映射为速度指令：误差<3px停车（到达信标正上方），<18px以70cm/s开环冲刺，中距按10×√err曲线逼近（封顶50cm/s）。运动内环依次执行速度斜坡（4000cm/s²）、航向锁定（分段P控制，<7.5°用3.0、7.5~15°用2.0、>15°用1.2，输出限幅±40）、麦轮逆解与轮速闭环。麦轮逆解公式为：LF=vy+vx−vz、LB=vy−vx−vz、RF=vy−vx+vz、RB=vy+vx+vz。轮速环采用增量式PI+速度/加速度前馈：增量项Kp×(err−err_last)+Ki×err累加为积分输出，前馈Kv×目标速度+Ka×计划加速度叠加，运行时参数Kp=36、Ki=1.25、Kv=8，输出限幅±7000，并采用前馈占用后剩余额度分配给积分项的抗饱和策略。丢帧保护四级降级：200ms滑行、500ms半速、1000ms减速、2000ms刹停。
1. 由于输出直接对应实际控制量，无需额外计算增量，结构直观，便于理解与实现。  
2. 积分项通过累积历史误差，能够完全消除系统的静态误差，适用于高精度控制场景。  
3. 微分项基于当前误差变化率实时调整输出，有效抑制超调，提高系统动态响应速度。  
4. 适用于需要精确位置控制的场合，直接输出绝对量，无需考虑增量累积。  
5. 参数物理意义明确，比例、积分、微分三部分作用清晰，便于通过实验整定参数。  
6. 算法稳定性较好，对控制量突变不敏感，执行机构动作平滑。  
但位置式PID也存在缺点：积分项可能引起饱和现象，需结合抗饱和措施（如积分限幅）；且每次输出需计算全量，对计算资源要求略高。实际应用中常采用积分分离、变增益等改进算法以优化性能。
2.4.3 连通域寻灯
本系统采用搭载红外滤光镜头的摄像头进行信标灯识别。由于比赛场地中信标灯采用红外光源，当环境中不存在强烈阳光干扰以及其他红外热源时，摄像头采集图像中的主要红外辐射来源为信标灯，因此通过调整摄像头曝光、增益以及阈值等参数，可以有效突出信标灯目标，使其在图像中呈现明显的高亮区域。
针对视觉图像中同时存在信标灯与地面车V型灯板的问题，系统采用基于连通域分析的目标检测算法进行信标定位。首先对红外滤光摄像头采集的图像进行灰度化处理，并根据目标区域的亮度特征进行阈值分割，提取潜在红外光源区域；随后对二值化图像进行形态学处理，减少环境噪声以及边缘干扰的影响。之后利用连通域分析提取各独立亮区，并计算其面积、中心坐标、外接矩形以及填充度等特征参数。
由于无人机任务过程中需要准确区分信标灯与地面车上的V型灯板，系统结合目标区域的亮度特征和填充度特征进行筛选。其中，信标灯通常表现为面积较小、亮度集中且填充度较高的点状目标，而V型灯板由于结构尺寸较大、形状规则，与信标灯在区域面积和填充比例上存在明显差异。因此，通过设置合理的亮度阈值和填充度判断条件，可以有效过滤V型灯板干扰，实现对信标灯目标的准确识别与定位，为后续无人机引导地面车完成灭灯任务提供可靠视觉信息。

5.1 核心算法子程序
5.1.1 IMU姿态解算（Mahony互补滤波+四元数）
/*************************************************************************
IMU姿态解算 - Mahony互补滤波 + 四元数（飞机端 driver_imu.c）
作用：加速度一阶卡尔曼去噪，动态检测机体运动状态；
陀螺积分四元数，加速度重力向量做误差修正（带动态/模长置信权重），
静止时才允许积分累积；最后输出ZYX顺规欧拉角。
**************************************************************************/

// 一阶标量卡尔曼滤波（加速度去噪）
static void run_kalman_scalar(ekf_filter_t *ekf, float input)
{
    ekf->now_p = ekf->last_p + ekf->q;                     // 先验协方差
    ekf->kg = ekf->now_p / (ekf->now_p + ekf->r);          // 卡尔曼增益
    ekf->out = ekf->out + ekf->kg * (input - ekf->out);    // 状态更新
    ekf->last_p = (1.0f - ekf->kg) * ekf->now_p;           // 后验协方差
}

// 快速开方倒数（四元数归一化用，牛顿迭代一次）
static float inv_sqrt(float x)
{
    float xhalf = 0.5f * x;
    union { float f; uint32_t i; } u;
    u.f = x; u.i = 0x5f3759df - (u.i >> 1);
    u.f = u.f * (1.5f - xhalf * u.f * u.f);
    return u.f;
}

// 置信度权重：0~1光滑过渡，value越小越信任
static float imu_confidence_weight(float value, float scale)
{
    if (value >= scale) return 0.0f;
    if (value <= 0.0f) return 1.0f;
    return 1.0f - value / scale;
}

// 积分项仅在静止且加速度可信时更新（防机动时积分发散）
static float imu_integral_step(float integral, float error,
                               float dt, uint8_t update_enable)
{
    if (update_enable) integral += error * dt;
    else integral *= 0.95f;                               // 不更新时缓慢衰减
    return integral;
}

// ================= 单步姿态解算（每周期调用） =================
static void imu_solve_step(imu_context_t *ctx,
    float ax, float ay, float az,
    float gx_deg, float gy_deg, float gz_deg,
    float dt, float yaw_gain)
{
    (void)yaw_gain;
    // 1. 加速度一阶卡尔曼滤波
    run_kalman_scalar(&ctx->kalman_acc_x, ax);
    run_kalman_scalar(&ctx->kalman_acc_y, ay);
    run_kalman_scalar(&ctx->kalman_acc_z, az);
    float acc_x = ctx->kalman_acc_x.out;
    float acc_y = ctx->kalman_acc_y.out;
    float acc_z = ctx->kalman_acc_z.out;

    // 2. 帧间加速度变化率 -> 动态运动检测
    float delta_ax = fabsf(acc_x - ctx->acc_x_prev);
    float delta_ay = fabsf(acc_y - ctx->acc_y_prev);
    float delta_az = fabsf(acc_z - ctx->acc_z_prev);
    float acc_delta = delta_ax;
    if (delta_ay > acc_delta) acc_delta = delta_ay;
    if (delta_az > acc_delta) acc_delta = delta_az;
    ctx->acc_x_prev = acc_x; ctx->acc_y_prev = acc_y; ctx->acc_z_prev = acc_z;

    // 3. 陀螺零偏扣除 + 一阶低通（IMU_GYRO_LPF_ALPHA=0.73）
    float gx = (gx_deg - ctx->gyro_x_offset) * IMU_GYRO_LPF_ALPHA
             + (1.0f - IMU_GYRO_LPF_ALPHA) * ctx->gyro_x_filtered;
    float gy = (gy_deg - ctx->gyro_y_offset) * IMU_GYRO_LPF_ALPHA
             + (1.0f - IMU_GYRO_LPF_ALPHA) * ctx->gyro_y_filtered;
    float gz = (gz_deg - ctx->gyro_z_offset) * IMU_GYRO_LPF_ALPHA
             + (1.0f - IMU_GYRO_LPF_ALPHA) * ctx->gyro_z_filtered;
    ctx->gyro_x_filtered = gx; ctx->gyro_y_filtered = gy; ctx->gyro_z_filtered = gz;

    // 4. 严苛静止判定（模长≈1g + 各轴变化小 + 角速度小）
    float acc_norm = sqrtf(acc_x*acc_x + acc_y*acc_y + acc_z*acc_z);
    float acc_err = fabsf(acc_norm - 1.0f);
    ctx->is_static = (delta_ax < IMU_ACC_DYNAMIC_THRESHOLD) &&
                     (delta_ay < IMU_ACC_DYNAMIC_THRESHOLD) &&
                     (delta_az < IMU_ACC_DYNAMIC_THRESHOLD) &&
                     (acc_err  < IMU_STATIC_ACC_NORM_THR_G) &&
                     (fabsf(gx) < IMU_STATIC_GYRO_THR_DPS) &&
                     (fabsf(gy) < IMU_STATIC_GYRO_THR_DPS) &&
                     (fabsf(gz) < IMU_STATIC_GYRO_THR_DPS);
    gx *= DEG2RAD; gy *= DEG2RAD; gz *= DEG2RAD;          // deg/s -> rad/s

    // 5. 由当前四元数计算重力参考向量 v=(vx,vy,vz)
    float q0=ctx->q.q0, q1=ctx->q.q1, q2=ctx->q.q2, q3=ctx->q.q3;
    float vx = 2.0f * (q1*q3 - q0*q2);
    float vy = 2.0f * (q0*q1 + q2*q3);
    float vz = q0*q0 - q1*q1 - q2*q2 + q3*q3;

    // 6. 叉积求误差，加速度方向 e = a x v
    float ex=0, ey=0, ez=0, acc_weight=0;
    float acc_norm_sq = acc_x*acc_x + acc_y*acc_y + acc_z*acc_z;
    if (acc_norm_sq > 1.0e-6f) {
        float norm = inv_sqrt(acc_norm_sq);
        float axn=acc_x*norm, ayn=acc_y*norm, azn=acc_z*norm;
        ex = (ayn*vz - azn*vy);
        ey = (azn*vx - axn*vz);
        ez = (axn*vy - ayn*vx);
        // 模长可信度 x 动态可信度
        float norm_w = imu_confidence_weight(acc_err, IMU_ACC_FUSION_ERR_G);
        float dyn_w  = imu_confidence_weight(acc_delta, IMU_ACC_DYNAMIC_THRESHOLD);
        acc_weight = norm_w * dyn_w;
    }

    // 7. 误差积分（静止才积分）
    uint8_t up_int = (ctx->is_static &&
        acc_weight >= IMU_INTEGRAL_ACC_WEIGHT_MIN) ? 1U : 0U;
    ctx->err.exInt = imu_integral_step(ctx->err.exInt, ex, dt, up_int);
    ctx->err.eyInt = imu_integral_step(ctx->err.eyInt, ey, dt, up_int);
    ctx->err.ezInt = imu_integral_step(ctx->err.ezInt, ez, dt, up_int);

    // 8. 陀螺角速度 + PI修正（IMU_KP=2.75）
    gx += IMU_KP * acc_weight * ex + ctx->err.exInt;
    gy += IMU_KP * acc_weight * ey + ctx->err.eyInt;
5.1.2 飞控级联PID与光流IMU融合
/*************************************************************************
飞控级联PID - 通用位置式PID（I带抗饱和Anti-Windup）飞机端 pid.c
角度环->角速度环串级，误差±180度归一化，油门低于基础值自动清积分。
**************************************************************************/
float pid_position_calc(pid_param_t *pid, float current_error,
                        float dt, uint8 clear_i)
{
    float derivative;
    pid->err = current_error;
    if (clear_i) {                          // 清积分
        pid->integrator = 0.0f;
        pid->out_i = 0.0f;
    } else {
        pid->integrator += pid->err;        // 误差累加
    }
    pid->out_i = pid->ki * pid->integrator;
    // 积分限幅 + 反算回integrator（Anti-Windup）
    if (pid->out_i >= pid->imax) {
        pid->out_i = pid->imax;
        if (pid->ki != 0.0f) pid->integrator = pid->imax / pid->ki;
    } else if (pid->out_i <= -pid->imax) {
        pid->out_i = -pid->imax;
        if (pid->ki != 0.0f) pid->integrator = -pid->imax / pid->ki;
    }
    pid->out_p = pid->kp * pid->err;        // P
    derivative = (pid->err - pid->last_error);  // D
    pid->out_d = pid->kd * derivative;
    pid->out = pid->out_p + pid->out_i + pid->out_d;
    pid->last_error = pid->err;
    return pid->out;
}

// ================= 滑动窗口中值滤波（3点，无循环排序） =================
float gyro_median_filter_update(gyro_median_filter_t *f, float raw)
{
    f->buf[f->idx] = raw;
    f->idx = (f->idx + 1) % 3;
    if (f->cnt < 3) f->cnt++;
    if (f->cnt < 3) return raw;             // 窗口未满直接返回
    float a=f->buf[0], b=f->buf[1], c=f->buf[2];
    if (a > b) { float t=a; a=b; b=t; }
    if (b > c) { float t=b; b=c; c=t; }
    if (a > b) { float t=a; a=b; b=t; }
    return b;                               // 中值
}

/*************************************************************************
光流+IMU融合 - opticalflow_fusion.c
光流原始角速度换算水平速度（乘高度），扣除机体旋转分量
（陀螺补偿、死区+限幅），再与加速度积分互补融合；
光流失效时靠加速度维持/衰减，输出平滑水平速度与位置。
**************************************************************************/

// 低通系数：由截止频率与采样周期换算
static float lpf_alpha(float cutoff_hz, float dt)
{
    float x = 2.0f * 3.1415926f * cutoff_hz * dt;
    return x / (1.0f + x);
}

// 姿态投影提取水平加速度（去除重力分量），单位 cm/s2
static void calc_horizontal_acc(float *acc_right, float *acc_forward)
{
    float roll_rad  = g_imu_control.roll  * DEG2RAD;
    float pitch_rad = g_imu_control.pitch * DEG2RAD;
    *acc_right  = (Original_imu.acc_y * cosf(roll_rad)
                 - Original_imu.acc_z * sinf(roll_rad)) * 980.0f;
    *acc_forward= (Original_imu.acc_x * cosf(pitch_rad)
                 + Original_imu.acc_z * sinf(pitch_rad)) * 980.0f;
}

// 旋转补偿：陀螺角速度产生的光流假速度扣除，带回差死区与限幅
static void rotational_compensation(float raw_forward, float raw_right,
    float dt_flow, float *flow_forward, float *flow_right)
{
    float wf = LIMIT(fabsf(raw_forward)/FLOW_ANG_DEADZONE_RAD_S,0.0f,1.0f);
    float wr = LIMIT(fabsf(raw_right)  /FLOW_ANG_DEADZONE_RAD_S,0.0f,1.0f);
    raw_forward *= wf;                    // 角速度死区软抑制
    raw_right   *= wr;
    float alpha_gyro = lpf_alpha(GYRO_COMP_LPF_CUTOFF_HZ, dt_flow);
    gyro_lpf_roll  += (imu_gyro.roll  - gyro_lpf_roll)  * alpha_gyro;
    gyro_lpf_pitch += (imu_gyro.pitch - gyro_lpf_pitch) * alpha_gyro;
    float gr = LIMIT(gyro_lpf_roll *DEG2RAD,-FLOW_ANG_LIMIT_RAD_S,FLOW_ANG_LIMIT_RAD_S);
    float gp = LIMIT(gyro_lpf_pitch*DEG2RAD,-FLOW_ANG_LIMIT_RAD_S,FLOW_ANG_LIMIT_RAD_S);
    *flow_forward = raw_forward + GYRO_COMP_GAIN * gp;   // 前向配pitch
    *flow_right   = raw_right   + GYRO_COMP_GAIN * gr;   // 右向配roll
}

// 互补融合核心：光流速度与加速度积分互相修正
static void fuse_with_acc(float dt, uint8 flow_new_valid,
    float flow_vx, float flow_vy, float acc_right, float acc_forward)
{
    acc_int_vx += acc_right * dt;         // 加速度积分
    acc_int_vy += acc_forward * dt;
    if (fabsf(acc_right) < ACC_STILL_THR_CM_S2)
        acc_int_vx *= flow_new_valid?ACC_DECAY_WITH_FLOW:ACC_DECAY_NO_FLOW;
    if (fabsf(acc_forward) < ACC_STILL_THR_CM_S2)
        acc_int_vy *= flow_new_valid?ACC_DECAY_WITH_FLOW:ACC_DECAY_NO_FLOW;
    if (flow_new_valid) {
        float err_x = flow_vx - acc_int_vx;   // 光流与加速度积分之差
        float err_y = flow_vy - acc_int_vy;
        fused_vx = acc_int_vx + FLOW_BETA * err_x;         // 速度互补输出
        fused_vy = acc_int_vy + FLOW_BETA * err_y;
        acc_int_vx += FLOW_BETA * ACC_PULL_GAIN * err_x;   // 加速度积分被拉回
        acc_int_vy += FLOW_BETA * ACC_PULL_GAIN * err_y;
    } else if (flow_timeout_cnt <= FLOW_TIMEOUT_MAX) {
        fused_vx = acc_int_vx;             // 短时丢失用纯加速度
        fused_vy = acc_int_vy;
    } else {
        fused_vx *= FLOW_LOST_VEL_DECAY;   // 长时丢失速度衰减
        fused_vy *= FLOW_LOST_VEL_DECAY;
        acc_int_vx = fused_vx;
        acc_int_vy = fused_vy;
    }
}

// ================= 周期更新入口（ISR或定时调用） =================
void opticalflow_update(float dt)
{
    float use_height = height_est;         // 当前融合高度
    float raw_forward=0, raw_right=0;
    uint8 flow_new_valid = 0;
    if (flow_valid) {                      // 光流有数据
        rotational_compensation(flow_raw_forward, flow_raw_right, dt,
                                &raw_forward, &raw_right);
        float alpha_flow = lpf_alpha(FLOW_RAW_LPF_CUTOFF_HZ, dt);
        flow_forward_lpf += (raw_forward - flow_forward_lpf)*alpha_flow;
        flow_right_lpf   += (raw_right   - flow_right_lpf)  *alpha_flow;
        speed_obs_x = LIMIT(use_height*flow_forward_lpf,
                            -FLOW_SPEED_LIMIT_CM_S, FLOW_SPEED_LIMIT_CM_S);
        speed_obs_y = LIMIT(use_height*flow_right_lpf,
                            -FLOW_SPEED_LIMIT_CM_S, FLOW_SPEED_LIMIT_CM_S);
        flow_timeout_cnt = 0;
        flow_new_valid = 1;
    } else {
        if (flow_timeout_cnt < 65535) flow_timeout_cnt++;
    }
    float acc_right=0, acc_forward=0;
    calc_horizontal_acc(&acc_right, &acc_forward);
    fuse_with_acc(dt, flow_new_valid, speed_obs_y, speed_obs_x,
                  acc_right, acc_forward);
    float spd_x = fused_vx, spd_y = fused_vy;
    if (fabsf(spd_x) < 1.0f) spd_x = 0.0f;
    if (fabsf(spd_y) < 1.0f) spd_y = 0.0f;
    opt_fusion.speed_x = spd_x;            // 输出融合速度
    opt_fusion.speed_y = spd_y;
    opt_fusion.position_x += spd_x * dt;   // 位置积分
    opt_fusion.position_y += spd_y * dt;
    opt_fusion.valid = (flow_timeout_cnt<=FLOW_TIMEOUT_MAX) ? 1 : 0;
}

    }

          for (int x = 0; x < WIDTH; x++) {

        int sum_y;

                blobs[lbl].sum_y += y;
            }
        }
    }
    uint16 blob_count = 0;

    for (int i = 1; i <= label; i++) {

        }
    }

/*************************************************************************
地面车视觉伺服减速曲线 - MotorCtrl.c 的 Arrive_at_Target
视觉外环50Hz。error_x/error_y合成距离，「死区->线性->sqrt曲线」
平滑输出目标速度，分解回XY命令交给内环执行。
**************************************************************************/
void Arrive_at_Target(void)
{
    float err_dis, target_speed, err_angle;
    float v_x_out=0, v_y_out=0;
    float err_lat = error_x;                // 侧向误差
    float err_fwd = error_y;                // 前向误差
    err_dis = sqrtf(err_lat*err_lat + err_fwd*err_fwd);
    if (err_dis < 3.0f)                     // 0~3死区（到达停车）
        target_speed = 0.0f;
    else if (err_dis < 10.0f)               // 3~10线性接续
        target_speed = 4.517f * (err_dis - 3.0f);
    else {                                  // 10+ sqrt曲线限幅50
        target_speed = 10.0f * sqrtf(err_dis);
        if (target_speed > 50.0f) target_speed = 50.0f;
    }
    if (target_speed > 0.1f) {
        err_angle = atan2f(err_fwd, err_lat);
        v_x_out = target_speed * cosf(err_angle);
        v_y_out = target_speed * sinf(err_angle);
    }
    cmd_vx = v_x_out; cmd_vy = v_y_out;     // 外环只写目标速度
}

/*************************************************************************
麦轮运动学逆解 - MoveBase.c
LF=vy+vx-vz; LB=vy-vx-vz; RF=vy-vx+vz; RB=vy+vx+vz
**************************************************************************/
void calc_wheelSpd(MoveBase *move, float v_x, float v_y, float v_z)
{
    if (!move) return;
    move->SpeedLF = v_y + v_x - v_z;
    move->SpeedLB = v_y - v_x - v_z;
    move->SpeedRF = v_y - v_x + v_z;
    move->SpeedRB = v_y + v_x + v_z;
}

/*************************************************************************
轮速环执行 - PID+PWM输出（MotorCtrl.c）
**************************************************************************/
void updateCtrl(MotorCtrl *ctrl, float tar_wheelSpeed)
{
    if(!ctrl||!ctrl->_motor||!ctrl->_encoder||!ctrl->_controller) return;
    ctrl->output = (int32)speedCtrl(ctrl->_controller,
                        ctrl->_encoder->spd, tar_wheelSpeed);
    setPWM(ctrl->_motor, ctrl->output);
}
void applyMotorCtrl(MoveBase *move)
{
    if (!move) return;
    updateCtrl(&motorCtrlLF, move->SpeedLF);
    updateCtrl(&motorCtrlLB, move->SpeedLB);
    updateCtrl(&motorCtrlRF, move->SpeedRF);
    updateCtrl(&motorCtrlRB, move->SpeedRB);
}

/*************************************************************************
轮速环PID - 前馈(Kv*v+Ka*Dv) + 增量式PI（PID.c）
前馈先占额度，剩余限幅分配给PI积分项，抗饱和。
**************************************************************************/
float speedCtrl(SpeedPID *pid, const float actual_speed, const float tar_spd)
{
    pid->Kp=tune_speed_kp; pid->Ki=tune_speed_ki;
    pid->Kv=tune_speed_kv; pid->Ka=tune_speed_ka;
    pid->err = tar_spd - actual_speed;
    float a_plan = tar_spd - pid->tar_spd_last;   // 目标加速度
    float ff_out = pid->Kv*tar_spd + pid->Ka*a_plan; // 前馈
    float pi_inc = pid->Kp*(pid->err-pid->err_last) + pid->Ki*pid->err;
    pid->pi_output += pi_inc;                      // 增量式PI
    float max_pi = pid->max_output - fabsf(ff_out); // PI额度=限幅-前馈
    if (max_pi < 0) max_pi = 0;
    pid->pi_output = constrain(pid->pi_output, -max_pi, max_pi);
    float out = ff_out + pid->pi_output;
    out = constrain(out, -pid->max_output, pid->max_output);
    pid->tar_spd_last = tar_spd; pid->err_last = pid->err;
    return (pid->output = out);
}
