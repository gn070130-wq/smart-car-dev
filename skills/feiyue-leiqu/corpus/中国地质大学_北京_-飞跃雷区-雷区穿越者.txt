摘  要
本报告面向第二十一届全国大学生智能汽车竞赛“飞跃雷区”任务，介绍一套由四旋翼飞行器、麦克纳姆轮智能车和机载视觉模块组成的空地协同系统。飞行器采用双核 CYT4BB7 控制器：CM7_0承担姿态、高度、水平位置、安全状态和通信调度，CM7_1负责188×120灰度图像处理。视觉链路通过梯度自适应双阈值、孤立点清除、八邻域连通域、双灯车辆配对以及信标时序跟踪，输出车辆中心、轴向角、信标相对误差和有效性状态，并通过固定共享RAM交给飞控核心。
飞控采用1 ms基准多速率调度，形成角速度、姿态、垂向速度、高度、水平速度和视觉位置等层级控制，并通过锁定、解锁、失控下降、人工优先和输出限幅等机制约束执行器。地面车利用IMU660RA、四路编码器和麦克纳姆轮底盘完成航向保持、里程计、世界坐标导航和视觉跟随。空地间通过UART3传输16字节定长帧，飞行器根据信标有效性发送跟随或返回中心命令，地面车在500 ms通信超时后强制进入空闲状态。
报告中的软件流程、调度周期、接口字段、方向关系和控制参数均取自当前工程源码。尚未由源码证明的机械、电气和实测性能数据保持空白，不以估计值替代。
关键词：飞跃雷区；空地协同；四旋翼；麦克纳姆轮；视觉跟踪；双核控制

ABSTRACT
This report presents an air-ground cooperative robotic system developed for the Flying over the Minefield category of the 21st National University Student Intelligent Car Competition. The system consists of a quadrotor, a Mecanum-wheel ground vehicle, and an onboard vision processor. A dual-core CYT4BB7 controller is used on the aerial platform. CM7_0 executes flight control, state estimation, safety arbitration, and communication, while CM7_1 processes 188 by 120 grayscale frames and publishes vehicle and beacon observations through a fixed shared-memory contract.
The flight controller uses a 1 ms base tick and multiple execution rates for inertial acquisition, angular-rate control, attitude control, altitude control, optical-flow velocity estimation, and vision-aided horizontal control. The ground vehicle performs attitude estimation, four-wheel odometry, field-oriented navigation, visual following, and Mecanum-wheel speed control. A 16-byte UART frame carries commands and target information between the platforms. All software parameters and interfaces described in this report are traced to the current source tree; unverified mechanical, electrical, and measured performance data are intentionally left blank.
Keywords: air-ground cooperation; quadrotor; Mecanum wheel; visual tracking; dual-core control

第一章  绪论
1.1 竞赛任务与系统目标
“飞跃雷区”任务要求空中平台与地面车辆在限定环境中协同完成信息感知、目标搜索、越障与引导等动作。系统既要解决飞行器姿态和高度稳定问题，又要将机载视觉得到的车辆、信标信息转换为地面车可执行的运动指令。技术报告必须覆盖总体方案、机械安装、电路、控制软件、开发调试及主要参数，并给出原理图与核心算法程序[1-2]。
本系统以“感知与飞控分核、空地任务分层、有效性显式传递、安全优先于任务”为设计原则。CM7_1只发布经过筛选的视觉结果，CM7_0根据遥控状态、传感器有效性与飞行状态决定是否让自动控制获得权限；地面车则把通信命令解释为有限状态，并在串口超时后主动停止平移。

姿态外环以滚转、俯仰和航向误差生成角速度目标，角速度内环根据陀螺仪反馈生成控制量，再由X形混控分配给四个电机。当前源码中的初始参数为：滚转角速度环P=1.6、I=1、D=20；俯仰角速度环P=1.8、I=1、D=20；航向角速度环P=4、I=1、D=0。外环滚转P=3.2、俯仰P=3.6、航向P=4。参数只代表当前源码初值，不代表已完成全部飞行工况调优。
	uPID(k)=Kp·e(k)+Ki·Σe(k)+Kd·[e(k)-e(k-1)]	（2）
混控输出在控制层限制为800～8000。若处于锁定状态，电机命令为停转；起飞请求成立后，油门基值以每2 ms增加0.001的斜坡方式建立，约2 s完成，以降低突加推力造成的姿态扰动。
4.4 高度融合与垂向控制
垂向链路以VL53L8CX测距和IMU信息形成高度估计，外层高度PID给出垂向速度目标，内层垂向速度PID生成油门补偿。当前高度环初始参数为P=2.45、I=1、D=50，垂向速度环为P=1.75、I=1、D=0。起飞目标高度超过100 mm时判定为起飞请求。
4.5 光流与视觉水平控制
光流模块经UART2接收数据并结合滚转、俯仰角速度进行旋转补偿。当前启用路径采用固定有效高度height_used=1.5 m进行尺度换算，X方向取反、Y方向保持原符号。该值是当前工程保留的标定量，除非重新进行专门标定，否则不在报告中按实时高度改写。
视觉位置误差按焦距80 pixel和融合高度换算为平面距离；位置环P为0.05。视觉前馈根据连续坐标差形成速度项，增益0.20，死区30 cm/s，限幅40 cm/s，低通系数0.20；位置反馈和前馈合成后的水平目标限幅为65 cm/s。视觉丢失后，残余目标在约15个50 Hz周期内衰减，最终限制在±5 cm/s以内。
	vx,target=-uy,pos+vy,ff；vy,target=ux,pos-vx,ff	（3）
4.6 飞行安全状态机
飞控状态包括LOCKED、ARMED和FAILSAFE_LANDING。遥控在线且满足解锁条件后进入ARMED；空中连续500 ms未收到有效遥控帧时进入失控下降，以0.2 m/s目标速度受控下降；地面状态下失联则直接锁定。FlowHold只在解锁并且对应开关有效时启用，横滚或俯仰人工输入超过1°即覆盖自动水平控制。

5.3 孤立点去除与连通域
二值图像采用最少1个邻域像素的原地清噪规则，去除孤立单点和无法形成结构的小噪声。随后执行两遍标记：第一遍在八邻域中建立临时标签与等价关系，第二遍压缩等价类并统计面积、边界、中心和亮度信息。信标候选面积范围为5～400 pixel。
采用八邻域而非四邻域，可把斜向相连的灯斑归入同一目标，减少离散采
样导致的碎裂；同时通过面积上下限阻断小噪点和大面积反光区域进入时序跟踪池。
5.4 车辆双灯配对与轴向角
车辆识别从符合类型条件的灯斑中寻找最近的一对目标，以两点几何关系确定车头、车尾、中心和车辆轴向角。视觉相对坐标不是直接把图像X/Y发送给地面车，而是依据车辆轴向角进行旋转，使Error_X、Error_Y表达信标相对车辆坐标系的位置。
	Xc=Xraw·cosα-Yraw·sinα；Yc=Xraw·sinα+Yraw·cosα	（6）

6.1 软件调度与姿态估计
地面车CM7_0在system_init中初始化显示与菜单、四路编码器、四路PWM电机、姿态估计、控制器、UART3接收和三个PIT周期任务。PIT0每1 ms执行姿态更新，PIT1每10 ms读取编码器并执行控制主循环，PIT2每20 ms扫描按键。CM7_1当前不承担实时任务。
姿态模块使用IMU660RA。陀螺仪和加速度计分别经过截止频率100 Hz与35 Hz的二阶Bessel滤波，再由Mahony互补滤波更新四元数。比例增益为0.75，积分增益为0.006，陀螺仪零偏校准采样2000次。航向角通过跨越±180°时累加圈数得到连续total_yaw，供世界坐标里程计使用[6]。
6.2 编码器里程计
四轮编码器每10 ms读取一次，各通道根据机械安装方向修正正负号，并用0.7倍历史值与0.3倍新值形成低通输出。车体前向与横向增量由四轮组合获得，再依据当前连续航向旋转到世界坐标系。位置换算比例POS_COUNTS_TO_METERS为0.00002093。
	Δxw=Δxr·cosψ-Δyr·sinψ；Δyw=Δxr·sinψ+Δyr·cosψ	（7）
场地坐标导航反向把世界系速度目标旋转到车体系，再调用麦克纳姆轮分配函数。这样位置规划不随车头朝向改变，而航向控制仍可独立保持。
6.3 轮速与航向闭环



图6.1  地面车坐标、轮序与麦克纳姆运动学
四个轮速增量式PID初始参数均为P=15、I=2.15、D=0。四轮目标按式（1）生成后，如果任一目标幅值超过6000，则按相同比例归一化，保持轮间比例不变。航向控制器初始参数为P=6.5、D=1.5，输出作为ω分量叠加到四轮速度。
6.4 视觉跟随
视觉跟随不直接使用线性PID，而是分别通过查表把Error_Y映射为前向vx，把Error_X取反后映射为横向vy，并叠加航向保持ω。误差落入死区时平移速度为零，但航向闭环仍然工作。该映射必须与CM7_1的车辆坐标旋转保持一致。
	vx=fY(Error_Y)，vy=-fX(Error_X)	（8）

第八章  结论与展望
8.1 工作总结
本文完成了“飞跃雷区”空地协同系统的源码级技术梳理。飞行器利用双核架构把视觉处理与高频控制隔离，以1 ms基准完成多速率姿态、高度和水平控制，并通过显式飞行状态、遥控新鲜度、人工优先和执行器限幅建立安全边界。视觉系统从灰度图像中提取车辆双灯与独立信标，经时序确认和坐标旋转发布10槽共享结果。地面车以1/10/20 ms任务执行姿态估计、编码器里程计、世界坐标导航、视觉跟随和四轮闭环。
空地链路使用16字节定长帧，把信标相对误差和任务命令传递到地面车；连续丢标防抖、车辆500 ms通信超时以及飞行器失控下降构成跨平台异常处理链。上述结论均由当前源码调用链支持。
8.2 方案特点
视觉计算与飞控闭环分核运行，并通过固定地址、固定长度、显式有效位和DCache维护保证数据契约清晰。
信标追踪使用3帧确认与6帧删除，任务层再使用约200 ms连续丢标判定，形成感知层与决策层两级迟滞。
地面车将视觉跟随、世界坐标导航和航向保持统一到vx、vy、ω接口，复用同一套麦克纳姆轮分配与轮速闭环。
UAV和UGV均设置独立失联处置，异常时分别受控下降或停止平移，避免把通信旧值长期作为有效目标。
8.3 后续工作
后续工作应围绕机械、电气和实测证据完善：补充整机尺寸、质量、电源功耗、总电容、传感器安装图与原理图；在统一坐标与测试条件下测量视觉检测精度、帧率、端到端延迟、通信丢包与超时响应；完成拆桨、架空、单机和整机分阶段测试。参数调整必须建立在有效性、方向、单位、时序和控制权限均已确认的基础上。

B.1 视觉单帧主流程 image_process()
* 当前 image_process() 里这条路线是注释掉的，实际使用的是 car_follow()。
 */
void line_car_follow(void) // 基于线形目标的车身方向估计入口；选出最大type==1色块，由车头/车尾两点求方向角
{
    first_car_blob = (Blob){0};  // 清零三档候选车色块，准备重新挑选
    second_car_blob = (Blob){0}; // 清零第二候选车色块
    third_car_blob = (Blob){0};  // 清零第三候选车色块
    head_x = 94.0f;              // 车头坐标默认为图像中心（X=94）
    head_y = 60.0f;              // 车头坐标默认为图像中心（Y=60）
    end_x = 94.0f;               // 车尾坐标默认为图像中心
    end_y = 60.0f;
    delta_alpha = 0.0f;   // 方向角先清零，后面命中目标再更新
    float k_alpha = 0.4f; // 角度低通滤波系数：新角占0.4，旧角占0.6，平滑防跳变
    // [修改1] 加上 static，让它在帧与帧之间记住上一次的角度，修复滤波和历史记忆
    static float last_alpha;                             // 静态变量保存上一帧方向角，跨帧传递实现历史记忆
    static float last_head_x = 0.0f, last_head_y = 0.0f; // 新增：最后有效车头
    static float last_end_x = 0.0f, last_end_y = 0.0f;   // 新增：最后有效车尾

    // [新增] 丢失目标的帧数计数器
    static unsigned int lost_frame_count = 0; // 统计连续丢目标帧数，用于防丢失保持逻辑

    // 获取当前的帧率作为 1 秒的阈值。加入防零保护，如果开机瞬间 fps 为 0，默认按 10 帧算
    unsigned int current_fps = (fps > 0) ? fps : 10; // 当前帧率用于丢失计数钳制，开机阶段以10兜底。

    for (int i = 1; i <= label_count; i++) // 遍历所有色块，挑出 type==1 的线形目标按面积排名
    {
        if (blobs[i].type == 1) // 仅处理被线形识别判定为直线的色块
        {
            if (blobs[i].area > first_car_blob.area) // 当前面积超过暂列第一
            {
                third_car_blob = second_car_blob; // 第二退居第三
                second_car_blob = first_car_blob; // 第一退居第二
                first_car_blob = blobs[i];        // 当前成为新的最大候选车
            }
            else if (blobs[i].area > second_car_blob.area)
            {
                third_car_blob = second_car_blob; // 第二退居第三
                second_car_blob = blobs[i];       // 当前成为第二
            }
            else if (blobs[i].area > third_car_blob.area)
            {
                third_car_blob = blobs[i]; // 当前成为第三
            }
        }
    }

    if (first_car_blob.area > 5) // 最大线形目标面积够大（>5像素）才认为有效目标
    {
        lost_frame_count = 0;                    // 命中目标，立即清零丢帧计数
        int yc = (int)first_car_blob.y_centroid; // 取质心行作为车头/车尾采样基准
        if (yc >= 3 && yc <= 116)                // 质心行距上下边界至少留3行余量，避免左右边界数组越界
        {
            head_x = (first_car_blob.left_edge[yc - 3] + first_car_blob.right_edge[yc - 3]) / 2.0f; // 车头X：质心上方3行的左右边界中点
            head_y = first_car_blob.y_centroid - 5.0f;                                              // 车头Y：质心上方5行处
            end_x = (first_car_blob.left_edge[yc + 3] + first_car_blob.right_edge[yc + 3]) / 2.0f;  // 车尾X：质心下方3行的左右边界中点
            end_y = first_car_blob.y_centroid + 5.0f;                                               // 车尾Y：质心下方5行处
            last_head_x = head_x;
            last_head_y = head_y; // 保存最后有效值
            last_end_x = end_x;
            last_end_y = end_y;                      // 保存最后有效值
            float dx = head_x - end_x;               // 车头到车尾的X分量
            float dy = end_y - head_y;               // 车尾到车头的Y分量（注意y向下为正，故取 end_y - head_y）
            float mid_alpha = atan2f(dx, dy) * RTOD; // 用atan2算方向角；RTOD把弧度转成角度
            // 滤波（连续变化，防止空格跳）
            delta_alpha = (1.0f - k_alpha) * last_alpha + k_alpha * mid_alpha; // 一阶低通：保留大部分旧角+小部分新角，防抖动

            last_alpha = delta_alpha; // 更新历史角，供下一帧滤波使用
        }
    }
    else /* 没找到有效线形目标，进入防丢失保持逻辑 */
    {

        // 防丢失
        lost_frame_count++; // 丢帧计数+1

        if (lost_frame_count <= 3) // 保持 3 帧
        {
            /* 按上一个信息继续发送：head/end + 角度 */
            head_x = last_head_x;
            head_y = last_head_y;
            end_x = last_end_x;
            end_y = last_end_y;
            delta_alpha = last_alpha;
        }
        else // 丢帧超过1秒，认为目标真的丢失
        {
            delta_alpha = 0.0f; // 方向角清零
            last_alpha = 0.0f;  // 历史角清零，避免恢复时受旧值影响

            lost_frame_count = current_fps + 1; // 钳制计数器，防止无限累加溢出
        }
    }
}
B.2 视觉坐标旋转 x_y_calculate()
void x_y_calculate(int16 X_raw, int16 Y_raw, float alpha, float *X_cal, float *Y_cal)
{
    // 1. 构建 2x2 旋转矩阵 R (alpha 乘以 3.1415926f / 180.0f 转为弧度)
    R[0][0] = cosf(alpha * 3.1415926f / 180.0f);
    R[0][1] = sinf(alpha * 3.1415926f / 180.0f);
    R[1][0] = -sinf(alpha * 3.1415926f / 180.0f);
    R[1][1] = cosf(alpha * 3.1415926f / 180.0f);

    // 2. 构建 2x1 的平移后位置向量 P
    // 公式：新坐标 = 目标点原始像素坐标 - 新坐标系原点像素坐标 (车身中心)
    P[0] = (float)X_raw - (head_x + end_x) / 2.0f;
    P[1] = (float)Y_raw - (head_y + end_y) / 2.0f;
    if (X_raw == 0 && Y_raw == 0)
    {
        *X_cal = 0.0f;
        *Y_cal = 0.0f;
    }
    else
    {
        // 旋转矩阵求得相对坐标
        //  3. 矩阵相乘：[2x2] * [2x1] 得到目标相对坐标
        *X_cal = R[0][0] * P[0] + R[0][1] * P[1];
        *Y_cal = -R[1][0] * P[0] - R[1][1] * P[1];
    }
}
B.3 空地发送函数 uav_To_car()
void uav_To_car(float x, float y, float yaw, uint8 cmd)
{
    cy4_uav_value.send_data_buffer[0] = CAR_FRAME_HEADER;

                      CAR_FRAME_LENGTH);

void vision_follow_control(float error_x, float error_y)
{
    // 查表得到速度绝对值，再赋予方向
    // error_y → 前后移动(vx), error_x → 左右移动(vy)
    float vx = error_y_to_speed(error_y);   // Y误差决定前后

    }
    else
    {
        // 同时输出前后+左右，无旋转
        car_mecanum_run(vx, vy, omega_speed_target);
    }
}
B.5 麦克纳姆轮分配 car_mecanum_run()
void car_mecanum_run(float vx, float vy, float omega)
{

    // ================= 核心解算公式 (X型安装) =================
    // 注意：正负号可能需要根据电机实际接线方向微调
    // 理想情况：
    // mA = Vx - Vy - W  // 左前
    // mB = Vx + Vy + W  // 右前
    // mC = Vx + Vy - W  // 左后
    // mD = Vx - Vy + W  // 右后	
    /*
             前
           ⬆️vx正方向                   
        ⬅️vy正方向   omega为顺时针方向
         \mA      /mB  
          \      /  
           \    /  
    左      \  /       右
            /  \    
           /    \  
          /      \
         /mC      \mD   
             后
    */
    speed_mA_target = vx - vy - omega;
    speed_mB_target = vx + vy + omega;
    speed_mC_target = vx + vy - omega;
    speed_mD_target = vx - vy + omega;

    // ================= 归一化处理 (防止超速失真) =================
    // 如果某个轮子计算出的速度超过了电机最大值（比如PWM满占空比）
    // 必须等比例缩小所有轮子的速度，否则车走的方向会歪。

    float max_speed = 0.0f;
    float limit_pwm = 6000.0f; // 假设你的PWM最大限制是 8000，这里给到6000留点余量

    speed_mA = PID_Calc_Incremental(&pid_mA_speed, speed_mA_target, encoder_quad_A);
    speed_mB = PID_Calc_Incremental(&pid_mB_speed, speed_mB_target, encoder_quad_B);
    speed_mC = PID_Calc_Incremental(&pid_mC_speed, speed_mC_target, encoder_quad_C);
    speed_mD = PID_Calc_Incremental(&pid_mD_speed, speed_mD_target, encoder_quad_D);

    // 找最大值
    if (fabs(speed_mA) > max_speed)
        max_speed = fabs(speed_mA);
    if (fabs(speed_mB) > max_speed)
        max_speed = fabs(speed_mB);
    if (fabs(speed_mC) > max_speed)
        max_speed = fabs(speed_mC);
    if (fabs(speed_mD) > max_speed)
        max_speed = fabs(speed_mD);

    // 如果最大值超过限制，进行缩放
    if (max_speed > limit_pwm)
    {
        float ratio = limit_pwm / max_speed;
        speed_mA *= ratio;
        speed_mB *= ratio;
        speed_mC *= ratio;
        speed_mD *= ratio;
    }

    // ================= 输出到电机(底层) =================
    motor_set_duty(motor_A, -(int16)speed_mA);
    motor_set_duty(motor_B, (int16)speed_mB);
    motor_set_duty(motor_C, -(int16)speed_mC);
    motor_set_duty(motor_D, (int16)speed_mD);
}

    motor_set_duty(motor_B, -(int16)speed_pwm);
    motor_set_duty(motor_C, (int16)speed_pwm);
    motor_set_duty(motor_D, -(int16)speed_pwm);

        spin_done = 0;
        spin_active = 1;

        PID_Reset(&pid_yaw_turn);

        // 整套动作完成 → 收尾并切换到无人机命令模式
        if (boot_nav_phase == BOOT_NAV_DONE)
        {
