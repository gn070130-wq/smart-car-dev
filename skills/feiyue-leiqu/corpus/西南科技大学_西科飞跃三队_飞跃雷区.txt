摘要
 本文系统介绍了我们在第二十一届全国大学生智能汽车竞赛“飞跃雷区组”中所采用的系统设计方案。该方案基于自主设计的四旋翼飞行器与全向轮车模，以CYT4BB7为主控芯片，实现四旋翼对红外信标灯的自主识别与定位，并将位置信息实时传输至小车，由小车完成精确灭灯操作，力求以最短时间完赛。在四旋翼子系统中，采用总钻风MT9V034摄像头进行信标灯识别，借助IMU963RA获取飞行姿态，通过PID闭环算法动态调节RS2205无刷电机转速，从而实现飞行过程中的稳定闭环控制。全向轮小车则选用RC380电机，并利用编码器实时测速，同样基于PID闭环算法实现对运动速度与方向的精确调控。为进一步提升整体系统的运行速度与稳定性，在开发过程中广泛运用上位机、屏幕显示模块等调试工具，开展了大量硬件电路与软件算法的联合测试。
关键词：CYT4BB7，IMU963RA，四旋翼，全向轮小车，PID

第三章 硬件电路的设计
3.1 电源模块设计
电源模块为系统各功能电路提供所需的电能，其性能直接影响整机运行的可靠性与稳定性。在设计过程中，除满足基本的电压范围与电流输出能力外，还需兼顾电源转换效率、噪声抑制、抗干扰能力以及电路结构简洁性等多方面要求，以实现高效、稳定、清洁的电源供给。
系统全部硬件电路由额定电压11.1V（满电电压12.6V）的锂电池统一供电。鉴于各子模块所需工作电压与电流容量存在差异，电源模块需配置多路稳压电路，将电池电压变换为各单元所需的特定电压等级。总体而言，本车模电源方案主要提供以下2种供电电压：
(1) 使用芯片STC2450输出电压5V，用于无线WIFI、无线串口、光流、单片机等供电。原理图如图3.1所示。


图3-1 降压电路12V-5V 原理图
 (2)使用稳压芯片RT9013输出电压3.3V，用于屏幕、有线通信等供电。原理图如图3.2所示。
图3.2 降压电路 5v-3.3v 原理图
3.2 驱动模块设计
DRV8701集成完整的FET栅极控制逻辑，专用于双向有刷直流电机驱动，支持5.9V至45V的宽输入电压范围，可覆盖12V至24V电机的典型工作条件。该芯片通过简化外围元件需求，显著提升了系统集成度。此外，DRV8701具备栅极驱动强度可调、低功耗休眠模式等功能，并集成了UVLO（欠压锁定）、OCP（过流保护）、故障检测和热关机等多重保护机制，增强了系统的安全性和可靠性。
特别地，DRV8701的高侧栅极驱动电压由内部电荷泵产生，无需外部升压电路即可提供充足的驱动能力，在保证驱动性能的同时有效缩减了电路面积。综合上述优势，本设计最终选用DRV8701作为电机驱动核心方案，其性能指标和宽电压适应性能够充分满足本系统的驱动需求，整体驱动电路设计如图3.3所示。


图3-3 整体驱动电路
3.3 单片机模块设计
在单片机选型方面，本系统选用CYT4BB7作为核心主控芯片。该芯片基于ARM Cortex-M7和Cortex-M4双内核架构，具备高性能计算能力与实时处理性能，能够满足四旋翼飞行控制、全向轮小车运动控制以及多传感器数据融合等多任务并行处理的需求。
CYT4BB7片内集成丰富的外设资源，包括多路PWM输出、正交编码器接口、ADC模块以及多种标准通信接口（如UART、SPI、I2C等），可便捷地与摄像头、陀螺仪、编码器、无线通信模块等外设进行连接与数据交互，显著简化了系统硬件设计。同时，该芯片具有充足的存储空间和较高的运行主频，能够支持复杂控制算法（如PID闭环控制）和图像识别算法的实时运行，为系统的稳定性和响应速度提供了有力保障。
综合考虑处理能力、外设接口、开发资源及系统兼容性等因素，我们最终确定CYT4BB7为本方案的核心控制器，以满足竞赛环境下对高性能、高集成度和高可靠性主控平台的综合要求。


图3-4 最小系统板电路原理图
3.4 BLDC电调模块设计
无刷直流电机（BLDC）凭借高效率、高可靠性、低噪声、控制精度高、调速范围宽以及节能环保等优势，在四旋翼动力系统中得到广泛应用。为满足竞赛四旋翼飞行器对动力系统快速响应与稳定控制的要求，本设计选用STC32G12K128作为电调主控芯片，并配合  FD6288预驱芯片构成电调驱动方案。
STC32G12K128基于32位C251架构内核，主频高、处理能力强，能够高效完成无刷电机的换向逻辑计算与PWM信号生成。该芯片内部集成高级PWM定时器，支持多路独立PWM输出，可通过单PWM驱动方式灵活控制MOSFET通断时序，实现对无刷电机转速的精确调节。此外，芯片内置比较器与运算放大器，可直接处理来自预驱模块的反电动势检测信号，无需额外外设即可实现无位置传感器的无刷电机换向控制，显著简化外围电路。
FD6288作为三相预驱芯片，内置运放电路，可对相电流进行采样放大，并通过内部比较器输出换向逻辑信号，为STC32G12K128提供准确的换向参考。该组合方案在保证驱动性能的同时，有效降低了电路复杂度与成本，具有良好的集成度和可靠性，能够满足本系统对电调模块小型化和高性能的双重需求。




图3-5 电调原理图
3.5 分电板模块设计
为方便电源分配和电源管理，我们组采用分电板设计。输入接口与锂电池连接，输出端分别引出至飞控主板、四个无刷电调。板面布局充分考虑了大电流路径与信号路径的隔离，以降低电磁干扰并提升系统可靠性通过分电板的集中管理，整机布线得以大幅简化，既减轻了飞行器重量，也便于后期维护与调试。

图3-6 分电板原理图
3.6 LED驱动模块设计
在车模上，我们增加了可见光LED来增加光流稳定性。采用ILD6150英飞凌芯片作为驱动芯片。ILD6150 是一款高效降压型 LED 恒流驱动芯片，支持 4.5V 至 60V 宽电压输入，最大输出电流 1.5A。芯片采用滞环控制，响应迅速。支持 PWM 和模拟调光，内置可调过温保护和过流保护功能外围电路简单，易于设计，足够小车使用。

3.3.2 连通域标记 — search_connect()
• 两遍扫描 + 并查集（find_root 路径减半），输出每个连通域的：面积、中心行列、左右上下边界、平均灰度。

3.3.3 小车识别 — car_find() + PCA_solver()
• 先用单阈值 image_binaryzation(190) 提取"最亮"区域（车体反光）。
• 合并中心距离 <100（像素平方）的相近连通域。
• 通过面积 (15,200)、填充率 (0.1,0.6)、长宽比 (0.25,4.0) 三重约束筛选出车。
• 输出 car_pos（列/行），并在非稳定帧用 PCA_solver() 对车体点云做主方向分析，得到 car_pos.hx/hy/angle（车头朝向）。
3.3.4 信标识别 — beacon_find() + is_ring_mostly_dark()
• 先用积分图自适应阈值 Adaptive_Threshold(20, -300) 分离信标。
• 合并中心距离 <9 的相近连通域。
• 分"近处 / 远处"两档面积判断（近 (10,200)、远 (2,50)），并叠加填充率 (0.5,0.9)、长宽比 (0.7,1.4)、平均灰度约束。
• 远处信标额外做 is_ring_mostly_dark() 圆环暗环校验（R1=4 / R2=7 的环形区域内暗像素占比），用于剔除误检。
3.3.5 自适应阈值 — integral_image_get() + Adaptive_Threshold()
• integral_image_get()：4 像素批量 + 32bit 加载计算积分图（一维存储，行步长 INT_STRIDE=W+1）。
• Adaptive_Threshold(at_s, at_t)：以 at_s 为邻域半径，用积分图 O(1) 求局部均值，factor = 100 - at_t 作为相对阈值系数，8 像素展开原地写回。
3.3.6 多帧跟踪 — greedy_match_temp_to_final() + rotate_coordinates()
• greedy_match_temp_to_final(yaw, temp_used, final_used)：构造当前帧/历史信标距离矩阵，贪心选取全局最近对进行匹配，更新历史信标坐标、连续命中计数、丢失角。
• 未匹配的当前帧信标 → 新建历史信标；未匹配的历史信标 → 用 rotate_coordinates(d_yaw, ...) 依据"最后真实位置 + 累计旋转量"做旋转补偿预测（无累积误差），并累计 missing_count。
• 依据丢失位置距图像边界远近动态决定保留帧数（角落/边缘保留久、中心保留短），超过保留帧或"靠近车且丢失满 1 帧（判灭灯）"则失效。
• 最终合并距离过近（DIST_FINAL_BEACON）的重复信标，输出 beacon_pos[] / beacon_count。

4.2.3.3 IMU 姿态解算 — project/code/IMU963ra.c / .h + MadgwickAHRS.c / .h
职责：采集 IMU 数据并解算出车体姿态（重点为连续 yaw 角）。
核心流程 imu963ra_go()：
1. 读取六轴 IMU660RA 的加速度计与陀螺仪（九轴 IMU963RA 分支已注释）。
2. 减去零漂 IMU_offset（get_rid_of_zero() 中 500 次采样平均得到）。

• 标准 Madgwick 梯度下降姿态融合；beta 增益在加速度模长异常（非 1g）时自动置 0，只信陀螺仪积分。

附加功能：
• mag_calibrator_init()：磁力计软硬铁校准（椭球拟合 → Cholesky/高斯消元求硬铁偏置与软铁矩阵），当前在 Init_All 中被注释，未启用。

第六章 总 结 
从我们满怀热忱报名“恩智浦”杯智能汽车竞赛的那一刻起，整个团队便携手踏上了一条挑战与探索并存的征途。这不仅是一场技术实力的较量，更是对团队协作能力、创新思维和执着精神的全方位锤炼。我们深知，要在高手如林的赛事中脱颖而出，必须倾注全部心力，认真对待每一个环节。
在机械结构设计方面，我们深入开展了市场调研与理论分析，力求制定出既符合竞赛规则又具备一定创新性的结构方案。从概念草图勾勒，到三维模型构建，再到实物样机的反复打磨与测试，每一环节都凝聚着团队的智慧与汗水。通过持续优化材料选型，着力提升车身稳定性与抗冲击性能，确保车辆在高速行驶和复杂路况下仍能保持良好姿态。
电路系统设计上，我们坚持高度模块化的思路，将整体电路划分为最小系统、主板控制、电机驱动和电源管理等多个独立而协同的模块。这种架构不仅有利于后期维护与升级，也有助于提高系统的灵活性与可靠性。我们对元器件的选型进行了严格筛选，经过多轮实验与调试，最终确定了性能最优的电路布局与参数配置。
控制算法作为智能汽车的“大脑”，是团队攻坚的重点。我们系统研究了PID控制、模糊控制等经典与先进策略，并结合实际需求进行针对性优化。通过大量的仿真验证与场地测试，不断校准参数、迭代逻辑，最终开发出一套高效、稳定的控制程序，能够准确感知车身状态并快速响应环境变化，为车辆和四旋翼的高速行驶与路径跟踪提供了可靠支撑。
备战过程中，我们遇到了诸多困难与挑战：从理论基础薄弱到技术瓶颈突破，从团队意见分歧到外部压力叠加，每一步都并不轻松。但也正是这些挫折，使我们的信念更加坚定，团队凝聚力不断增强。我们彼此激励，相互支持，在一次次校内演练中积累经验、发现不足。每一次失败，都让我们离成功更近一步；每一次坎坷，都使我们对目标的追求更加执着。
