第一章 机械结构设计

1.1 无人机结构设计
1.1.1 无人机机架选型
无人机采用四旋翼构型,机架选用碳纤维机架,X 型电机布局,四个无刷电机对称安装于机臂末端。该构型结构对称、机动性好,便于实现水平位置与航向的独立控制,满足悬停跟随与信标搜索的任务需求。
机架中心板上下分层布置电子设备:上层安装飞控主控板(CYT4BB7)、视觉副控板(CYT2BL3)与遥控接收机,下层安装电源模块与电池接口。两路 MT9V03X 摄像头采用 V 型布局安装于机架下方,镜头朝下对准地面,分别负责信标灯与车模灯板的识别,保证对地面目标的稳定视野。两路 MT9V03X 摄像头分别安装于机架左右两边位置,镜头朝下对准地面,保证对信标灯与车模灯板的稳定视野。

机架选型综合考虑了轴距、载重与刚度要求。在满足搭载双主控、双摄像头、双 TOF、光流模块及系留线缆等全部设备的前提下,尽可能减小整机重量以提升续航与机动性。动力系统选用TMOTOR无刷电机配合五寸螺旋桨,整机质量约 1.02kg。
1.1.2 保护罩及脚架设计
按照竞赛规则,无人机螺旋桨必须安装保护罩,且保护罩网眼尺寸应小于 4cm,以保证直径大于网眼的物体(以乒乓球检验)无法触及螺旋桨。保护罩采用3D打印方案,围绕四个旋翼分别安装,在保证安全性的同时兼顾重量与气流效率,减小对升力的影响。
脚架安装于机架底部,用于无人机起降时的支撑与缓冲,保证摄像头与 TOF 传感器离地高度满足测量要求。脚架同时作为系留线缆的走线通道,线缆由机架底部引出,与车模连接。
1.2 地面车模结构设计
1.2.1 车载灯板设计
车载灯板安装于车模顶部,作为无人机视觉识别车模位置与车头朝向的标志。灯板由上、下两块电路板组成:上灯板由多颗 LED 灯珠串联排列成三角形,作为车头方向的主要识别标志;下灯板用于加长整体灯形,使无人机在不同高度与视角下都能稳定捕获车模位置与朝向。
灯珠采用串联方式连接,由车模主板供电与控制,采用独立供电线路避免与电机驱动相互干扰。灯板固定于车模顶部平台,表面与车模顶面平齐或略凸起,避免遮挡无人机对信标灯的视野;供电与信号线沿车模内部走线,与电机驱动线分离,减少电磁干扰。

图1-7 车模灯板安装位置
1.2.2 车模结构设计
车模采用四轮麦克纳姆轮底盘,四个全向轮由直流减速电机独立驱动,可实现前进、横移与原地旋转三个自由度的运动,配合无人机视觉引导完成对信标灯的精确碾压灭灯。
车模底盘采用博思威龙公司出品的 M 型麦克纳姆轮车模,上层布置车模主板与电池,下层安装四路有刷驱动板。底盘尺寸满足竞赛规则要求(含附属设备不超过 30cm×30cm 方框,高度小于 30cm)。

图1-8 电池安装位置
车模尾部设置系留线缆接口,线缆经此与无人机连接,同时承载供电与通信。车模整体结构紧凑,重心低,保证了快速导航与急停变向时的稳定性。

第二章 硬件电路设计

2.1 无人机硬件设计
2.1.1 飞控电路
无人机飞控电路采用双主控架构,由 TRAVEO T2G CYT4BB7 与 CYT2BL3 两颗英飞凌车规级微控制器协同工作,全部电路均为自制。CYT4BB7 作为飞行控制主控,负责传感器采集、姿态与位置估计、控制律解算及电机驱动输出;CYT2BL3 作为视觉副控,负责独立摄像头的图像采集与目标识别,两路视觉结果在 CYT4BB7 侧完成融合。

图2-2 无人机飞控板(CYT4BB7)实物背面

图2-3 视觉副控板(CYT2BL3)实物正面

CYT4BB7 为双核 Cortex-M7 架构,主频 250MHz,内置大容量 Flash 与 SRAM。双核分工为:CM7_0 核心运行飞行控制任务(姿态环 200Hz、位置环 100Hz),CM7_1 核心运行视觉融合与车模通信任务,两核通过片内共享内存(0x28001000 地址段)交换数据,实时性强且无需额外通信开销。
电源系统采用三级供电结构:输入电池电压经 TPS5430 开关降压芯片转换为 5V 系统电源,5V 再经两路 RT9013 低压差线性稳压器(LDO)分别转换为 3.3V 电源轨——一路为飞控外设供电,一路单独为摄像头供电。摄像头供电独立设计,可有效抑制图像采集瞬间的电流波动对其他外设的干扰。

姿态传感器选用 IMU660RC 惯性测量单元,通过 IIC 接口与主控连接,以 240Hz 频率输出四元数姿态数据。水平定位采用 LC-302-3C 串口光流模块,经 UART3(19200bps)输出两轴光流积分量;高度测量采用双路 DL1B 激光测距模块,对称安装于机体前向 ±8cm 处,通过 IIC 接口读取,双路冗余设计可避免单路被遮挡时高度失准。

遥控链路采用 ELRS/CRSF 协议接收机,经 UART4 以 420000bps 波特率接收遥控指令。CYT4BB7 与 CYT2BL3 之间通过 UART5(115200bps)交换视觉观测数据与飞控状态。为增强可靠性,2BL3 侧串口收发信号经 74LVC2T45 双向电平转换芯片进行隔离缓冲,避免上电瞬间大电流反冲损坏芯片。

电路还包含电池电压检测功能:通过电阻分压网络将电池电压按 1/11 比例分压后送入 ADC 采样,用于电机输出补偿与低压报警。四路无刷电机 PWM 信号由 CYT4BB7 的 TCPWM 模块输出。
2.1.2 无刷电调
无人机采用四路无刷电机驱动,电机控制信号由 CYT4BB7 的 TCPWM 定时器模块输出四路独立 PWM 波(P05_0~P05_3),经电调驱动无刷电机。电调接收 PWM 占空比指令,控制电机转速。
针对电机推力与占空比、电压之间的非线性关系,软件中建立了推力-电压线性模型:通过台架测试拟合电机推力与端电压的线性关系,再结合实时电池电压将推力指令换算为油门占空比,实现了电池电压变化下的输出自动补偿,保证不同电量阶段控制效果一致。
无刷电调采用开源方案,主控为 STC AI8051U 单片机,固件基于 AM32 开源无刷电调固件移植而来。AM32 固件原为 ARM 处理器设计,经移植后在 AI8051U 上实现了对无刷电机的安全、快速、平滑驱动,支持伺服 PWM 与 Dshot(300/600)电机协议、双向控制、KISS 标准 ESC 遥测、可变 PWM 频率以及正弦启动模式,可保证大惯量电机平稳加速,并具有线性油门特性。

图2-11 无刷电调实物正面
电调驱动部分采用三相全桥 MOSFET 拓扑,由 AI8051U 的 PWMA 模块输出三组互补 PWM 信号驱动六个功率管,实现三相无刷电机换相。转子位置检测采用无感反电动势(BEMF)方案:利用芯片内部运算放大器对三相绕组反电动势进行采样放大,经统一的中断入口进行过零比较处理,结合定时器精确计算换相时间,实现无感方波驱动,省去霍尔传感器,简化了电机与电调的安装。
电调电源采用两级稳压结构:输入电压经 CJ7812 稳压至 12V 供给驱动级,再经 SE8550 降压至 5V 供给控制电路。ADC 模块同时对母线电压与电流进行采样,实现低压保护与过流保护功能。电调方案参考嘉立创开源电调工程,并针对本系统需求进行了优化,加大散热开窗面积以增强过流能力,提高长时间大电流工况下的可靠性。

图2-12 电调降压电路(CJ7812/SE8550)
飞控与电调之间采用普通 PWM 油门信号连接:飞控 CYT4BB7 的 TCPWM 模块输出四路独立 PWM 波(P05_0~P05_3),分别连接四个电调的油门输入引脚,电调在伺服 PWM 模式下解析油门占空比,控制电机转速。

第三章 无人机软件设计
3.1 传感器
本系统无人机部分集成了姿态测量、水平定位、高度测量与视觉感知四类传感器,共同构成飞行控制与信标检测的信息基础。姿态与航向由 IMU660RC 惯性测量单元提供,水平位移与速度由 LC-302-3C 光流模块配合高度信息解算,高度由双路 DL1B 激光测距模块融合得到,信标检测则由 MT9V03X 摄像头完成。
姿态测量选用逐飞科技 IMU660RC 模块,内置三轴加速度计与三轴陀螺仪,工作在 240Hz 数据输出频率下,可直接输出四元数姿态信息。芯片级姿态解算与自研扩展卡尔曼滤波(EKF)姿态估计并行运行,互为校验,以保证飞行姿态的可靠性。
水平定位采用 LC-302-3C 串口光流模块,工作于 19200bps 波特率,输出两轴光流积分量。光流积分量换算为位移时需要乘以飞行高度,其公式为:实际位移 = 积分值 / 10000 × 高度。由于光流对旋转运动同样敏感,在解算平移速度时利用 IMU 角速度对旋转引起的假速度进行了补偿。
高度测量采用双路 DL1B 激光测距模块,分别安装于机体前向 ±8cm 处。两路数据在 100Hz 控制周期内融合处理:两路数值接近时取平均,相差明显时取较大值以抑制单个模块被遮挡导致的距离突降,融合结果再经过中值滤波、低通滤波以及 IMU 垂向加速度跳变保护,得到平滑可靠的高度与垂向速度估计。
视觉感知采用 MT9V03X 灰度摄像头,输出 188×120 分辨率的灰度图像,用于信标灯与小车灯板的检测与定位。
此外,系统通过 ADC 分压采样实时监测电池电压,用于电机输出的电压补偿与低压报警。遥控链路采用 ELRS/CRSF 协议,经 UART4 以 420000bps 波特率接收遥控器指令。
3.2 算法整体架构
无人机软件基于 TRAVEO T2G CYT4BB7 双核处理器实现,采用双核分工协作的架构。CM7_0 核心负责飞行控制,完成传感器读取、姿态与位置估计、控制律解算与电机输出;CM7_1 核心负责视觉感知与车模通信,完成图像采集、信标识别、视觉融合以及与小车的数据交互。两个核心之间通过固定地址的共享内存交换数据,避免了核间通信的实时性瓶颈。
共享内存区定义于地址 0x28001000,划分为两组长度均为 30 的浮点数组:CM7_0 向 CM7_1 写入飞控状态(姿态角、位置估计、飞行高度、自动控制标志等),CM7_1 向 CM7_0 写入视觉目标信息(目标相对偏移、目标有效标志、小车速度等)。读取侧通过 D-Cache 一致性操作确保数据同步。
系统任务调度采用 PIT 定时器中断驱动:姿态控制环 5ms 周期(200Hz),位置控制环与遥控失效保护 10ms 周期(100Hz),TOF 高度更新 10ms 周期,电压采样 100ms 周期,光流更新 21ms 周期(约47.6Hz)。视觉核心以 10ms 为主循环周期,摄像头帧中断触发图像处理流水线。
飞控状态机定义了四种状态:未解锁(DISARMED)、已解锁(ARMED)、急停(ESTOP)与自动控制(AUTO_CONTROL)。解锁条件为油门处于低位且解锁开关处于允许位置;急停状态由遥控急停开关、倾角超限或失联触发;自动控制模式由遥控器第七通道高段位切入,此时视觉目标参与位置控制。
整体数据流为:传感器 → 状态估计 → 控制目标生成(手动指令/视觉目标)→ 位置控制 → 姿态控制 → 控制分配 → 电机 PWM,视觉识别结果通过共享内存反馈至位置控制目标,构成完整的闭环。
3.3 视觉
按照竞赛规则,信标检测的环境感知传感器必须安装于悬停飞行器上,故视觉系统整体部署于无人机。视觉模块运行于 CM7_1 核心,负责信标灯(目标)与小车灯板(车头方向标识)的识别、跟踪与融合,并将目标位置信息发送给飞控与小车。
3.3.1 摄像头安装和视觉处理
摄像头采用下视安装方式固定于无人机机架底部,镜头朝向地面,以保证对地面信标灯与小车灯板的稳定视野。安装位置综合考虑机架重心与保护罩结构,镜头光轴与机体竖轴平行,图像坐标系与机体坐标系建立固定映射关系,并利用鱼眼畸变校正查表对镜头成像畸变进行补偿,使图像坐标能够准确换算为机体坐标系下的水平距离。
图像处理流水线依次完成灰度化、二值化、连通域分析与特征识别。二值化采用大津法自动计算分割阈值,在光照变化环境下自适应调整;二值图像经栈式八邻域连通域标记算法提取所有亮斑,并统计各连通域的面积、质心、最小外接矩形与轮廓周长等特征。
信标识别依据面积、周长、圆度等几何特征区分信标灯、小车灯板与噪声,滤除面积小于阈值的孤立噪点。识别出的目标通过对心坐标计算得到相对摄像头的横向偏移、纵向距离与直线距离。
多信标场景下,系统采用最近目标锁定策略:优先锁定距离最近的信标,并通过匹配门限判定当前候选是否仍为锁定目标,仅在连续丢失或出现显著更优目标时才切换锁定,有效避免目标跳变。
当锁定目标连续丢失超过 10 帧时,系统进入偏航搜索模式:飞控以最大 90° 的偏航角范围沿丢失前方向旋转搜索,重新捕获信标后再额外旋转 10° 以确认目标,随后恢复自动跟踪。搜索过程中同步向小车发送停车指令,防止小车失控。
为提高目标位置的鲁棒性,系统实现了本地视觉与远端视觉(经 UART5 接收的观测数据)两路信息融合。融合模块对两路目标进行一致性匹配,依据机体系坐标差异与有效状态计算置信度,并对结果进行跳变确认(连续 3 帧确认)与一阶平滑,抑制单帧识别抖动。
最终融合后的目标以世界系偏移的形式写入共享内存,供 CM7_0 位置控制使用;同时由车模控制模块解算箭头指向信标的相对矢量与期望速度,经 UART2 以 115200bps 发送至小车。
3.4 运动控制
运动控制采用典型的"位置环—姿态环—控制分配"三级结构,姿态环以 200Hz 频率运行,位置环以 100Hz 频率运行。控制目标由遥控器指令与视觉目标共同决定:手动模式下,摇杆映射为期望速度并积分成期望位置;自动模式下,视觉目标的世界系偏移叠加到基础目标上,驱动无人机飞向信标上方。
姿态估计采用芯片四元数与扩展卡尔曼滤波(EKF)并行计算。IMU660RC 芯片直接输出 240Hz 四元数,作为姿态基准;自研 EKF 融合陀螺积分与加速度计重力观测,输出参考四元数,并通过重力一致性检验与陀螺积分对比持续验证姿态可靠性,异常时可平滑切换。
位置估计采用光流与加速度计互补融合:光流提供水平速度(经 IMU 角速度补偿),加速度计积分提供短时速度预测,二者按置信度加权融合;高度与垂向速度由双 TOF 直接给出。解锁瞬间以当前位置为世界系原点清零里程计,避免历史误差累积。
位置控制律为 PD 加积分的形式,将位置误差与速度误差映射为期望加速度:a = a_d - Kp·e_p - Kd·e_v - Ki·e_i + g。期望加速度乘无人机质量得到期望总力,再结合期望偏航角构造期望姿态矩阵 Rd;总推力取期望总力在当前机体 z 轴上的投影。积分项带抗饱和限幅,水平期望加速度限制在 12.5m/s² 以内。
姿态控制采用基于 SO(3) 的几何控制方法。姿态误差向量 e_R = 0.5·vee(RdT·R - RT·Rd),角速度误差 e_Omega = omega - RT·Rd·omega_d,控制力矩 tau = -KR·e_R - KOmega·e_Omega + omega x (J·omega) + 前馈项。转动惯量 J=(0.001932, 0.002035, 0.003676) kg·m²,姿态增益 KR=400·J,角速度增益 KOmega=55·J。
控制分配环节将期望总推力与机体三轴力矩经 4x4 混控矩阵解算为四个电机的目标推力。电机采用 X 型布局,混控关系为:总推力等于四电机推力之和,滚转/俯仰力矩由对角电机推力差产生,偏航力矩由正反转电机组差动产生。
单电机推力到油门指令的映射采用线性模型:推力与电机端电压成正比(thrust = k·V + b),油门 = 所需电压 / 当前电池电压,从而在电池电压变化时自动补偿电机输出能力的变化,保持控制效果一致。油门指令限制在 [0,1] 区间,并叠加总推力限幅保护。

第四章 车模软件设计
4.1 系统软件架构
车模软件运行于与无人机同型号的 TRAVEO T2G CYT4BB7 处理器上,采用裸机前后台架构,以定时器中断驱动任务调度。软件按硬件驱动层与应用逻辑层分层组织:驱动层包括电机 PWM 与编码器读取、速度环、串口通信、蜂鸣器、按键菜单等模块;逻辑层包括任务调度、协议解析、点到点导航、里程计、打滑恢复与丢灯搜索等模块。
系统任务由 PIT 定时器以 10ms 周期触发核心控制环,控制环按固定顺序依次执行:惯性数据更新、丢灯搜索状态机、点到点导航、打滑检测与恢复、四轮速度内环、麦轮运动学解算与里程计积分。20ms 周期任务负责遥测数据发送,10ms 周期任务负责按键扫描与菜单交互。
4.2 通信协议设计
车模与无人机经系留线缆上的串口链路互联,通信速率为 115200bps,采用字符串文本协议,以换行符作为帧结束标志。接收侧按字节拼装帧数据,利用帧尾判定与缓冲区溢出保护实现断帧恢复。
无人机向车模发送三类指令。REL:x,y,speed 指令表示以车模当前位置为原点的相对目标坐标(单位 mm)与速度比例(0~100),车模收到后立即以当前位置清零里程计并启动导航;REL:LOST 指令在无人机丢失信标时发送,触发车模进入丢灯搜索状态机;REL:GET 指令由无人机视觉确认到达航点后发送,用于将车模里程计重置到对应航点以消除累积误差。GOTO:x,y,yaw 指令则用于设置绝对目标坐标与目标航向。
车模向无人机回传 VEL:vx,vy 速度信息,数值由四轮编码器经麦轮正运动学解算得到,单位为 mm/s。该速度信息经系留线缆回传无人机,用于无人机位置估计的辅助修正,构成双向闭环。
4.3 底盘运动控制
底盘为四轮独立驱动的麦克纳姆轮结构,每个车轮配备带减速齿轮箱的直流电机与增量式编码器。编码器为 1024 线,经正交四倍频后每转输出 4096 个脉冲,配合 5:1 减速比与 轮径 126mm(半径 63mm),换算系数约为 51.7 脉冲/mm,可通过菜单在线标定。
速度内环为四路独立的增量式 PID 控制器,以 10ms 为控制周期,读取各轮编码器脉冲增量作为实际速度,输出 PWM 占空比驱动电机。PID 参数包含比例、积分、微分三项,积分项带限幅防止饱和,输出限幅保护电机。
位置外环采用纯比例控制:将目标位置与里程计当前位置的误差按比例映射为车体虚拟平移速度,经过最大速度限幅与接近目标减速区(距离 80mm 以内速度线性减小)处理后,送入麦轮逆运动学解算。
麦轮逆运动学将车体三自由度运动(前进 Y、右移 X、原地旋转)解算为四轮目标速度:左前轮 = Y + X - 旋转,右前轮 = Y - X + 旋转,左后轮 = Y - X - 旋转,右后轮 = Y + X + 旋转,再分别下发至四个速度内环。
航向控制采用独立的比例闭环:以 IMU 融合的连续偏航角与目标航向的差值为误差,误差经最短路径归一化(±180°)后乘以比例增益得到旋转速度,设置 2° 死区避免抖动,旋转速度单独限幅。
4.4 定位与导航
车模定位采用轮式里程计方案:每 10ms 对四轮编码器速度做麦轮正运动学解算,得到前进速度与右移速度,分别乘以标定系数并积分,得到车体坐标系下的累计位移,同时记录连续偏航角。里程计以每次 REL 指令下发时刻为原点清零,避免长距离累积误差。
系统支持航点记录与轨迹复现:在调试阶段通过按键记录最多 50 个航点,比赛阶段可选择按航点顺序依次执行 GOTO 导航,用于固定路径的巡检与复现。
丢灯搜索状态机在收到 REL:LOST 指令后激活:车模以固定速度比例(45%)沿已记录航点环形巡检,逐个执行点到点导航,直到无人机重新捕获信标并发送 REL:GET 指令确认,车模随即重置里程计并恢复 REL 导航。
针对 REL 连续驱动模式,系统设计了速度比例限速与失联保护:无人机下发的速度比例实时限制导航最大速度,若 400ms 内未收到新的 REL 指令,则判定无人机失联,车模自动降速至安全值并停车等待。
4.5 打滑检测与恢复
麦克纳姆轮在启停与快速变向时容易发生打滑,导致里程计失真。系统设计了打滑检测与恢复模块:利用 IMU 加速度、编码器速度与目标进度三方面信息联合判断。四个轮子按对角分组(左前+右后为一组,右前+左后为一组),当某一对角组的编码器响应与加速度测量、导航进度明显不一致时,判定该组打滑。
确认打滑后,模块向打滑对角组施加反向恢复脉冲,强制轮子重新贴地,并进入短暂冷却时间。打滑状态通过蜂鸣器提示,便于调试期观察。该机制显著改善了麦轮底盘在快速导航时的定位稳定性。

5.1 软件调试
系统软件开发调试环境采用 IAR Embedded Workbench for ARM 9.40.1 集成开发环境,使用 C 语言编写嵌入式程序。工程基于逐飞科技 CYT4BB 开源库搭建,该库提供了底层驱动(时钟、GPIO、定时器、串口、ADC、PWM 等)与设备驱动(IMU、光流、TOF、摄像头等)的完整封装,显著降低了底层开发的复杂度,使开发重心集中在控制算法与视觉算法上。

5.3 调试问题与解决方法
高度测量受遮挡干扰。单路 TOF 在飞行过程中容易被机架结构、系留线缆或自身投影遮挡,导致高度数据瞬间跳变甚至失真。针对该问题,系统采用双路 TOF 对称安装方案,两路数据融合时,数值接近则取平均,相差明显则取较大值,并叠加中值滤波、低通滤波与 IMU 垂向加速度跳变保护,有效抑制了单路遮挡引起的高度突变,保证了定高控制的稳定性。
光流速度测量受旋转干扰。光流模块对机体旋转同样敏感,旋转时会产生虚假的水平速度,导致位置估计漂移。调试中发现该问题后,在解算光流速度时引入 IMU 角速度补偿,并利用 TOF 高度将光流积分量换算为实际位移,同时设置光流有效区间与速度限幅,显著改善了悬停与定点控制时的位置稳定性。
信标目标跳变与误锁定。多信标场景下,摄像头识别结果在多个灯之间跳变,或误将反光点识别为信标,导致无人机与小车的控制目标来回摆动。系统采用最近目标锁定策略,通过匹配门限判定目标是否一致,仅在连续丢失或出现显著更优目标时才切换锁定;同时利用大津法自适应阈值代替固定阈值,适应场地光照变化,降低了误识别概率。
目标丢失后的搜索恢复。飞行过程中信标可能因角度、遮挡等原因短暂丢失,若丢失后无人机无法自主找回目标,任务将中断。系统实现了丢灯搜索状态机:连续丢失超过阈值后,无人机沿丢失前方向进行偏航旋转搜索,同时向小车发送停车指令;重新捕获信标后再额外旋转一定角度确认目标,随后恢复自动跟踪。该机制保证了任务运行的连续性。
双摄视觉数据抖动与不同步。两路摄像头独立识别,输出频率与精度存在差异,直接使用会出现目标位置抖动与跳变。系统实现了视觉融合模块:对两路观测进行一致性匹配与置信度评估,对融合结果进行跳变确认(连续多帧)与一阶平滑滤波,抑制单帧误检,输出稳定的目标位置供飞控使用。
麦克纳姆轮打滑导致定位漂移。车模在快速启停与变向时,麦克纳姆轮容易打滑,造成里程计积分误差累积。系统综合 IMU 加速度、编码器速度与导航进度联合判断打滑,检测到某一对角轮组打滑后施加反向恢复脉冲强制车轮贴地,显著改善了长距离导航下的定位精度。
上电冲击问题。整机接入电池瞬间,大电流会对控制电路产生冲击,严重时损坏芯片;串口互联的板卡之间上电时序不一致也可能产生反冲。硬件上通过 HY19P03 P 沟道 MOSFET 实现小开关控制大电流通断,避免上电打火;板间串口采用 74LVC2T45 双向电平转换进行隔离缓冲,有效保护了主控芯片。

第七章 总结
本队针对第二十一届全国大学生智能汽车竞赛飞跃雷区组的任务要求,设计并实现了一套由悬停飞行器与地面车模协同组成的信标检测与灭灯系统。系统以无人机为感知核心,通过双主控双摄像头完成信标灯与车模的识别与定位,以地面麦轮车模为执行机构,在无人机视觉引导下对目标信标进行精确碾压灭灯,实现了"空中感知、地面执行"的协同工作模式。
在机械结构方面,完成了无人机机架、保护罩、脚架以及车模底盘、灯板等结构的设计与装配,合理布置了双主控、双摄像头、双 TOF、光流模块及系留线缆等设备,保证了整机结构紧凑、重心稳定。在硬件电路方面,自主完成了飞控板、视觉副控板、无刷电调、车模主板、驱动板与灯板等全部电路的设计与制作,采用 TPS5430、RT9013 构建稳定电源系统,通过 HY19P03 实现上电防打火,利用 74LVC2T45 完成板间串口隔离保护,为系统稳定运行奠定了硬件基础。
在软件算法方面,无人机基于双核架构实现了姿态估计、位置估计、几何姿态控制与推力分配等飞行控制功能,采用大津法二值化、连通域分析、目标锁定与偏航搜索等视觉算法完成信标识别与跟踪,并通过双路视觉融合提高目标定位的稳定性;车模实现了点到点导航、麦轮运动学解算、航点复现、打滑检测恢复与丢灯搜索等功能,通过系留线缆与无人机实时交互,形成完整的协同闭环。
在调试过程中,团队解决了双 TOF 遮挡干扰、光流旋转误差、信标目标跳变、双摄数据抖动、麦轮打滑漂移、上电冲击等一系列实际问题,积累了丰富的嵌入式系统调试经验。通过软硬件联调,系统在悬停稳定性、目标识别可靠性、车模导航精度与整体协同配合方面均达到了预期的效果。
本系统仍存在一些可以改进的方向:无人机续航能力与系留线缆对机动性的影响有待进一步优化;多信标场景下的目标调度策略可以更加智能;视觉识别算法在复杂光照下的鲁棒性可以进一步提升;系统集成度与整机重量仍有优化空间。后续可在算法鲁棒性、系统小型化与自动化程度等方面继续深入研究。

B.1 姿态控制(几何控制)
// 姿态控制:基于 SO(3) 的几何控制,控制周期 5ms(200Hz)
输入:当前姿态矩阵 R,角速度 ω,期望姿态矩阵 Rd

Re   = Rd^T · R                  // 姿态误差矩阵
eR   = 0.5 · vee(Re - Re^T)      // 姿态误差向量
ωd   = (Rd - Rd_last) / Ts       // 期望角速度(由期望姿态差分解算)
ωd   = LPF(ωd)                   // 一阶低通平滑期望角速度
eΩ   = ω - R^T · Rd · ωd         // 角速度误差
τ    = -KR·eR - KΩ·eΩ            // 比例-微分项
       + ω × (J·ω)               // 陀螺惯性项
       + 前馈项                   // 期望角加速度前馈
输出:三轴期望力矩 τ,送入控制分配模块
B.2 位置控制(PD + 积分)
// 位置控制:PD + 积分,控制周期 10ms(100Hz)
输入:位置 p,速度 v,期望位置 pd,期望速度 vd,偏航角 yaw

ep = p - pd                      // 位置误差
ev = v - vd                      // 速度误差
ei = ei + ep · Ts                // 误差积分(带 anti-windup 限幅)
a_cmd = ad - Kp·ep - Kd·ev - Ki·ei + g   // 期望加速度
Fd = m · a_cmd                   // 期望总力
b3d = Fd / |Fd|                  // 期望机体 z 轴方向
b2d = normalize(b3d × xc(yaw))   // 由偏航角构造水平参考轴
b1d = b2d × b3d                  // 叉乘补齐正交轴
Rd  = [b1d, b2d, b3d]            // 期望姿态矩阵
thrust = Fd · b3                 // 推力 = 总力在机体 z 轴投影
输出:期望姿态 Rd 与总推力 thrust,送姿态环

threshold = Otsu(灰度图)          // 大津法自适应阈值
bin = Binarize(灰度图, threshold) // 二值化
for 每个白色像素(未访问):
    // 栈式八邻域连通域标记
    blob = 连通域标记(面积, 质心, 最小外接矩形, 轮廓周长)

B.4 车模点到点导航
// 车模导航,控制周期 10ms
输入:四轮编码器速度 vFL, vFR, vRL, vRR,目标坐标 (tx, ty)

// 麦轮正运动学(里程计)
v_forward = (vFL + vFR + vRL + vRR) / 4
v_right   = (vFL - vFR - vRL + vRR) / 4
pos_x += v_right · dt;  pos_y += v_forward · dt

// 位置外环(纯 P,接近目标减速)
err_x = tx - pos_x;  err_y = ty - pos_y
speed_limit = 接近目标 ? 按距离线性减小 : 最大速度
out_vx = clamp(err_x · Kp, speed_limit)
out_vy = clamp(err_y · Kp, speed_limit)

// 航向环(P,2° 死区)
out_rot = clamp(yaw_err · Kp_yaw, 最大转速)  // yaw_err 归一化 ±180°

// 麦轮逆运动学(三自由度分配)
FL = out_vy + out_vx - out_rot
FR = out_vy - out_vx + out_rot
RL = out_vy - out_vx - out_rot
RR = out_vy + out_vx + out_rot
下发四轮速度内环 PID

// 通信链路:系留线缆 UART 115200,文本帧以换行符 \n 结尾

// 飞机 → 车模(导航指令)
"REL:x,y,speed"     // 相对目标坐标(mm) + 速度比例(0~100),立即启动导航
