第一章 引言
全国大学生智能汽车竞赛是一项面向大学生工程实践能力、创新设计能力和综合调试能力的科技竞赛。竞赛要求参赛队伍围绕指定赛题，自主完成模型车机械结构设计、硬件电路搭建、传感器安装、控制算法编写以及整车调试等工作。相比单一车辆控制系统，本届“飞跃雷区”相关任务对参赛作品提出了更高要求：系统不仅需要完成地面车的稳定运动控制，还需要结合无人机平台实现空中视觉感知、目标识别和空地协同控制。因此，如何在有限的车模空间、算力资源和调试时间内构建一个稳定、实时、可靠的智能控制系统，是本队设计过程中重点解决的问题。
本技术报告围绕本队参赛模型车系统的设计与实现过程展开说明。系统整体采用“无人机空中感知 + 地面车运动执行”的协同结构。无人机部分搭载姿态传感器、TOF测距模块、光流模块和视觉模块，用于完成飞行姿态估计、高度保持、位置稳定以及目标信息提取；地面车部分采用麦克纳姆轮底盘结构，通过电机驱动、编码器反馈和运动控制算法实现前后、左右和平面旋转方向上的全向运动。空中单元与地面单元之间通过通信接口交换目标位置、方向和运动误差信息，从而形成感知、决策和执行相互配合的闭环系统。
在硬件设计方面，本系统根据赛题任务需求，对无人机飞控平台、地面车底盘、电源系统、传感器布局和通信接口进行了整体规划。无人机部分重点考虑飞行稳定性、传感器安装位置和信号可靠性，通过姿态传感器、TOF和光流模块提升飞行状态估计精度；地面车部分重点考虑底盘结构紧凑性、运动灵活性和驱动稳定性，采用麦克纳姆轮实现多方向运动，并通过编码器反馈提高速度控制精度。各功能模块在机械安装和电气连接上尽量保持结构清晰、布线可靠，减少运动过程中的干扰和松动风险。
在软件设计方面，系统采用模块化与分层控制思想，将程序划分为底层驱动、传感器采集、姿态解算、视觉识别、通信处理、运动控制和调试显示等功能模块。无人机控制部分通过姿态串级PID、定高控制、光流定点和四旋翼电机混控实现基本飞行稳定；视觉部分通过图像二值化、连通域分析、目标筛选、箭头方向判断和信标识别等方法获取赛道与目标信息；地面车控制部分则结合麦克纳姆轮运动学模型、速度闭环控制和通信接收数据，实现对目标位置的跟踪与调整。通过这种分层设计方式，系统各模块之间耦合度较低，便于单独调试和整体联调。
在调试过程中，本队按照“单模块验证、局部联调、整机测试”的思路逐步推进。首先对传感器采集、飞控姿态解算、电机驱动、视觉识别和通信链路等基础功能进行测试；随后分别完成无人机定高与定点、地面车速度闭环、视觉目标识别和空地通信的联合调试；最后结合实际任务流程，对系统稳定性、实时性和目标响应能力进行反复优化。实验结果表明，该系统能够完成基本的空中视觉感知、目标信息传输和地面车运动控制任务，具备一定的协同控制能力和比赛适应性。
本报告后续章节将依次介绍模型车系统的机械结构设计、硬件电路设计、无人机软件控制、车模软件设计、开发工具与调试过程、主要技术参数以及总结。通过对系统设计思路、实现方法和调试经验的整理，希望能够较完整地反映本队在智能汽车竞赛作品制作过程中的技术路线与工程实践成果。












第二章 机械结构设计
本组车模由悬停无人机和地面麦轮车两部分组成。无人机搭载视觉与姿态传感器，在空中提供稳定的俯视感知；地面车根据无人机输出的目标位置和方向信息完成全向运动与信标压灭任务。机械设计需要同时兼顾无人机的轻量化、抗振和安全防护，以及地面车的全向机动、载荷布置和车载灯板识别效果。因此，本队在成熟竞赛平台的基础上，围绕机架刚度、传感器减振、视觉标志和整车重心进行了针对性改装。

2.1 无人机结构设计
无人机是空地协同系统中的空中感知平台，其机械结构直接影响姿态控制稳定性与图像采集质量。本队采用逐飞科技配套销售的竞赛四旋翼机架，在保留原机架对称布局和螺旋桨防护结构的基础上，将飞控、无刷电调、视觉模块和测距模块集中布置在机体中心区域，并单独设计陀螺仪减振安装结构，以减小电机振动和线缆牵引对姿态测量的影响。

2.1.1 无人机机架选型
本队选用逐飞科技配套的四旋翼无人机机架作为空中平台。机架采用典型的X形四旋翼布局，四个电机相对机体中心对称分布，使各方向的转动惯量和推力臂保持一致，有利于简化俯仰、横滚与偏航控制。机体中央使用上下两层碳纤维板构成主要承力结构，在较低质量下提供足够的弯曲和扭转刚度，同时预留大量安装孔位，便于飞控、电调、摄像头、光流和TOF等模块分层固定。无人机整体结构如图2.1所示。

2.1.2 陀螺仪减震器设计
陀螺仪是无人机姿态闭环的核心传感器。无刷电机、螺旋桨和机架在工作过程中会产生较高频率的机械振动，若传感器直接刚性固定在承力板上，振动会叠加到角速度测量值中，造成姿态解算噪声增大，严重时还会引起控制输出振荡。为此，本队将陀螺仪布置在靠近机体几何中心的位置，使其尽量接近整机质心，并与电机安装臂和功率器件保持距离。

  减振结构采用上下两级安装平台：下层底座与机架连接，上层小平台用于固定陀螺仪模块，两层之间通过四个柔性支点连接，并在底部加入粘弹性材料进行辅助缓冲。柔性支点主要衰减由电机和桨叶传递来的高频振动，上下平台则保证传感器在低频姿态变化时能够跟随机体运动。连接线在传感器附近保留适当余量，并在远离减振平台的位置固定，避免线束拉紧后形成机械旁路，使振动绕过柔性支点直接传入陀螺仪。实物安装结构如图2.4所示。

2.2 地面车模结构设计
地面执行平台采用M1麦轮车，即竞赛中常用的M型麦克纳姆轮车模。公开资料给出的原车架尺寸约为28.2 cm×21 cm×6.3 cm，配置四个RC-380有刷直流电机和四只麦克纳姆轮，单轮直径约6.3 cm、宽度约3.25 cm。四个车轮能够分别控制转速和方向，通过轮辊产生的横向分力实现前进、后退、横移、斜行和原地旋转，适合在飞跃雷区任务中根据空中视觉误差快速调整位置。

2.2.1 车载灯板设计
车载灯板用于向无人机俯视摄像头提供车辆位置和车头方向信息。本队采用三条高亮灯带构成具有明显顶点方向的箭头式轮廓，两条斜边形成主要方向特征，横向连接梁一方面增强灯板刚度，另一方面提供稳定的几何特征。灯板点亮后在灰度图像中形成大面积高亮区域，顶部尖角表示车头方向，视觉程序可根据灯板中心位置和主方向计算车辆相对信标的前向、侧向误差。

灯条固定在白色3D打印支架上，各连接节点采用螺钉锁紧，既保证三条灯带之间的相对位置不随车体振动改变，也便于单条灯带损坏后的更换。整个灯板安装在车模上层并尽量与底盘中心线重合，避免电池、屏幕和线束遮挡发光区域；灯板下方保留主板显示与调试空间，使机械结构、视觉识别和维护便利性兼顾。车载灯板整体布置如图2.5所示。

2.2.2 车模结构优化
原M型车模具有结构紧凑、四轮独立驱动和全向移动灵活等优点，但原始底盘可用于安装电池、电控和车载灯板的空间有限。为满足本组别的空地协同任务，本队在原底盘外围增加轻量化扩展底板。扩展底板采用左右对称结构，并设置大面积镂空，在增加有效安装面积和外围防护范围的同时控制额外质量。原黑色承力底盘仍负责连接四组电机与传动机构，扩展底板主要用于支撑灯板、电池及辅助结构，改装后的底盘如图2.6所示。

  由于扩展底板改变了车轮与车体外缘的相对位置，本队在原齿轮传动轴与麦克纳姆轮之间增加自制圆柱形轴套。轴套采用3D打印成型，上、下端分别与轮毂和原传动轴配合，侧面预留锁紧孔。该结构能够补偿安装距离、保证轮轴基本同轴，并使四个车轮与扩展底板保持足够间隙，避免轮辊在横移过程中与底板发生干涉。传动与轴套结构如图2.7所示。

3.1.1 飞控电路
基于飞跃雷区规则以及硬件设计综合考虑，本飞机飞控主控芯片采用的是规定公司英飞凌的CYT4bb7，由3s锂电池通过HY19P03D稳压，而后使用SCT2450芯片降为5V电源供给电压测量，无线串口、TOF以及核心板供电。再使用一块RT9013芯片降为3.3V电源供给屏幕、陀螺仪、编码器、摄像头、光流和按键。再额外使用一片RT9013给摄像头单独稳压供电。

3.1.1.2 HY19P03D稳压电路
HY19P03稳压器具有良好的稳定性，可以在不同的电压和负载条件下提供稳定的输出电压。它能够有效地抵抗输入电压的波动和负载变化对输出电压的影响，保持稳定的工作状态。压降较低，即在输入电压高于输出电压的情况下，它能够以较小的电压差为代价进行稳压。这样可以减少能量损耗和热量产生，提高整个系统的效率。还具有过压保护和短路保护功能。它可以监测和保护负载端和稳压器本身不受过高电压或短路等情况的损害，提供安全和可靠的电源保护。









图3.2 HY19P03D电路图

3.1.1.3 主控板供电
主控板供电我们分别采用SCT2450以及RT9013，使用一块3s电池供电时，12v电源可由电池直接提供，生成所需要的电源为+5v电源与+3.3v电源，单片机所需的+5v电源由DC-DC电源芯片SCT2450直接生成。其具有的宽输入范围与5a最大供电电流功能对电路集成具有极大帮助。在输入+12v后加入高低频组合滤波：大容量电容滤除电源低频纹波，小容量陶瓷电容滤除高频干扰，抑制输入线上的噪声，保证 LDO 输入端电压稳定。相同的，在输出加入高低频组合滤波：大容量电容滤除电源低频纹波，小容量陶瓷电容滤除高频干扰，抑制输出线上的噪声，，稳定输出电压，防止对后级元件造成损坏。
在生成+5v供电时，使用SY6280对+5v外设上电进行时序控制，进行短路保护，过流保护，反向电流阻断，输出放电功能和过温保护，防止+5v电源模块的损坏。

3.1.2 无刷电调

   本无人机采用逐飞STC无刷电调。电调以STC32G12K128单片机为控制核心，利用三相反电动势采样完成无位置传感器换相，并通过FD6288T栅极驱动芯片控制六只N沟道MOSFET组成的三相功率桥。控制电源、采样电路和大电流功率回路分区布置，既能满足无刷电机调速需求，又能减小换相噪声对单片机采样和控制信号的影响。

 3.1.2.1 电池母线输入与滤波

    电池电压由VBAT端输入，在母线与地之间并联多只22 μF电容。并联电容能够降低电源回路的等效阻抗，在电机换相和负载突变时就近提供脉冲电流，同时吸收母线上的低频波动和高频尖峰，减小供电线压降对功率桥和控制电路的影响。H1与GND1端子用于将滤波后的母线电压和地可靠引出。

第四章 无人机软件设计
4.1 传感器
4.1.1 姿态传感器与姿态解算
无人机姿态测量模块采用 IMU963RA，程序中由 IMU_Init() 完成硬件初始化，由 IMU_Algorithm_Init() 初始化姿态解算状态。2 ms 控制中断中先调用 IMU_Get_Data() 读取三轴加速度和三轴角速度，再调用 IMU_Update() 完成 Mahony 互补滤波并输出 Roll、Pitch、Yaw 三个欧拉角。
为了与飞机机体系及后续 PID 方向保持一致，程序对原始传感器轴向进行了映射：加速度 ax 使用传感器 y 轴，ay 使用传感器 x 轴，az 保持不变；角速度 gx 使用 -gyro_y，gy 使用 -gyro_x，gz 保持不变。映射后的加速度和角速度再分别经过一阶低通滤波，滤波系数均为 0.10，以削弱电机和桨叶振动带来的高频噪声。




上电校准时，程序先丢弃 120 组采样，再在飞机静止条件下累计 1000 组陀螺仪数据得到零偏。静止判定要求三轴角速度均小于 8 deg/s，且加速度模长位于 0.70 g 至 1.30 g 范围内。完成零偏估计后，算法继续运行 1000 个 2 ms 周期使四元数收敛，并用 300 组姿态样本记录初始安装状态。



Mahony 解算以四元数为核心。程序将加速度归一化后，与当前四元数估计出的重力方向作叉乘，得到姿态误差 e，并将比例项和积分项反馈到角速度输入中。之后按照四元数微分方程积分更新姿态，最后由四元数计算 Roll、Pitch，并对 Yaw 使用 z 轴角速度积分获得。






4.1.2 TOF高度测量与垂直速度估计
无人机高度测量采用 DL1B TOF 测距模块。由于 dl1b_get_distance() 使用软件 I2C，读取过程可能阻塞，因此 Altitude_Hold_Update_ToF() 放在主循环中执行，而不是放入 2 ms 中断。TOF 原始距离的有效范围设置为 50 mm 至 3000 mm，程序使用 5 点中值滤波去除偶发跳点。
TOF 测得的是传感器测距方向上的距离，当飞机存在横滚和俯仰角时，需要折算为世界系竖直高度。程序采用横滚角和俯仰角的余弦乘积进行倾斜补偿，并设置最小 cos 值 0.50，避免大角度时补偿过大。



垂直速度由 TOF 差分和 IMU 竖直加速度互补得到。TOF 差分速度先经过一阶低通，截止频率为 5 Hz，并限制在 +-3 m/s 范围内；IMU 侧通过姿态补偿获得世界系 z 方向加速度并积分。最终 Vz_est 使用互补滤波更新，COMP_ALPHA 为 0.90。





4.1.3 光流速度估计与位置积分
水平运动估计采用 UP-FLOW-302 光流模块。UART4 中断中调用 upflow302_receive_callback() 接收光流数据，当完整帧到达后，Optical_Flow_Capture_Frame_ISR() 将 x/y 位移、积分时间、质量标志和接收时刻写入环形队列。主循环再调用 Optical_Flow_Update() 逐帧处理，避免串口中断中执行复杂滤波。
光流帧只有在状态有效且质量标志等于 245 时才参与估计。程序根据帧积分时间将原始位移归一到 20 ms 标定周期，并乘以 UPFLOW302_VEL_SCALE=0.009375 得到原始速度量；若帧周期异常，则使用默认 0.02 s。



由于下视摄像头在飞机旋转时也会产生图像运动，程序在 2 ms 中断中保存陀螺仪历史，并在光流帧处理时按 0.008 s 延迟回溯同步角速度，利用旋转补偿矩阵扣除机体角速度造成的虚假光流。随后再按 TOF 高度进行一阶高度补偿。





为提高定点控制稳定性，光流速度还经过三点中值滤波、基于最大加速度的异常变化门限，以及二阶 Butterworth 低通滤波，低通截止频率为 4 Hz。零偏校准在解锁前自动进行，要求姿态角小于 8 deg、角速度小于 5 deg/s，累计 80 组静止样本后得到 flow_bias_x 和 flow_bias_y。零偏完成且高度位于 100 mm 至 2000 mm 时，程序对速度积分得到相对位移 flow_pos_x、flow_pos_y。


4.1.4 遥控与视觉辅助输入
遥控接收机使用 i-BUS 协议，UART0 波特率为 115200。RC_Update() 以 0x20、0x40 作为帧头接收 32 字节数据帧，通过 0xFFFF 减去前 30 字节的方式校验，并解析出 10 个遥控通道。RC_Check_State() 根据开关 A、油门和模式开关决定 LOCKED/UNLOCKED 状态，并禁止带油门、定高、追车或通信模式直接解锁。
视觉输入由 Vision_Tracking_Task() 在主循环中处理摄像头帧，并将目标相对图像中心的 error_x、error_y、target_x、target_y 和 valid 写入快照结构。Position_Hold_Task() 在 20 ms 定点控制中读取该快照，用于飞机追车；同时 Vision_Tracking_Communication_Task() 按 40 ms 周期通过 UART2 发送视觉误差给地面车。
4.2 视觉

4.2.3 箭头与信标识别
箭头候选要求面积不小于 40 像素，包围框宽高均不小于 6 像素，并通过 FindArrowTip() 寻找离连通域中心最远的边界点作为尖端特征。程序综合尖端特征、填充率、面积尺度和形状紧致度计算箭头评分，评分不低于 45 时认为箭头有效。



信标识别保留普通信标和远距离小信标两类通道：普通信标要求面积 8 至 500、紧致度不小于 70、填充率不小于 55；远距离小信标允许面积 4 至 80、紧致度不小于 40、填充率不小于 40、亮度评分不小于 55。信标综合评分由紧致度、填充率、亮度和面积评分构成，有效评分阈值为 50。



该方案先以灰度阈值 45 和 Sobel 阈值 50 将图像划分为暗边、亮边、亮区和背景，再通过嵌套连通域关系生成信标候选；候选写入多帧可靠度历史，可靠度更新率为 0.20，有效可靠度阈值为 0.30，并带有中部微小红外残留过滤逻辑。

4.2.5 视觉通信与调试显示
视觉板通过 vision_uart_send_result() 发送 7 字节二进制帧，波特率为 115200。帧头为 0xA5，帧尾为 0x5A，中间依次发送 forward_error 和 right_error 的低、高字节，校验字节为前 5 字节累加和。若本帧视觉结果无效，则前向和右向误差均置为 0x8000，底盘板据此停止或保持安全策略。
调试显示由 vision_debug_display() 完成，屏幕显示二值图 ErZhiHua_Image1，并在箭头中心绘制红色十字。右侧显示 FWD、RGT、TX 和 TXF 等状态量，便于观察视觉误差、串口发送状态和帧计数。该设计使识别结果、通信链路和控制输入可以在实车调试时同步检查。
4.3 运动控制
4.3.1 实时任务调度与飞行状态
无人机控制采用主循环与定时中断分工的方式。主循环负责 RC_Check_State()、视觉通信、光流帧处理、TOF 读取和屏幕刷新；PIT_CH0 周期为 5 ms，用于刷新遥控通道和按键扫描；PIT_CH1 周期为 2 ms，是飞行控制主周期，依次完成 IMU 更新、位置保持、姿态 PID、定高 PID、四电机混控、无线日志计时和视觉调度计时。



飞行状态由 drone_state 表示，LOCKED 时所有 PID 被复位，电机通过 Motor_Stop_Ramp() 逐步降到零；UNLOCKED 后才允许 PID 输出和电机混控。解锁条件要求开关 A 打开、油门低于 1250，并且定高、追车、小车通信、自动降落等模式开关处于安全位置。
4.3.2 姿态串级PID控制
姿态控制采用外环角度、内环角速度的串级结构。遥控器 Roll 和 Pitch 通道首先换算为目标角度，比例为 0.03 deg/us；若光流定点有效，则对应轴的手动角度指令置零，避免人工姿态指令与定点速度环重复叠加。最终目标角度由遥控角度、机械安装 trim 和位置保持输出共同组成。





Roll/Pitch 外环每 10 ms 运行一次，将目标角度与当前姿态角的误差转换为目标角速度；角速度内环每 2 ms 运行一次，将目标角速度与 IMU 角速度之差转换为 out_roll、out_pitch、out_yaw。PID_Calc_Dt() 使用测量值微分而不是误差微分，避免目标突变带来的微分冲击，并对 D 项做 PT1 低通滤波。积分项只在 air_mode_active 有效时累加，低油门或上锁状态清空积分。





Yaw 控制同时支持手动角速度模式、航向锁定模式、自动 360 度旋转和视觉搜索偏航。偏航摇杆偏离中位超过 50 us 时，程序进入角速度模式，target_rate_yaw=-yaw_stick*0.3；摇杆回中后锁定当前航向，由偏航角度环产生目标角速度。
4.3.3 定高控制
定高控制由 Altitude_Hold_Task() 在 2 ms 中断中执行。CH_SW_C 低位为手动油门，中位为保持进入定高瞬间的当前高度，高位为固定目标高度 ALT_TARGET_M=1.2 m。定高外环将高度误差转换为目标垂直速度，内环将垂直速度误差转换为油门补偿 out_alt。




高度外环参数为 Kp=2.5、Ki=0.25、Kd=0，输出限幅为 1.3 m/s；速度内环参数为 Kp=200、Ki=12、Kd=5，输出限幅为 700 PWM。油门杆离开定高中心点超过 90 us 并持续 10 个控制周期后，程序进入上升/下降速度模式，目标垂直速度由油门偏差乘以 0.003 得到；松杆回到 60 us 死区内后，将当前高度重新锁定为目标高度。
定高还包含高度上限保护：目标高度不允许超过 1.70 m；当当前高度进入上限前 0.20 m 的软制动区时，限制上升速度；若已经超过上限，则主动给出 -0.25 m/s 的下降目标。悬停油门以 HOVER_THROTTLE=4800 为初值，在高度误差小、速度小、PID 补偿较小时缓慢自适应，补偿电池电压和载重变化。
4.3.4 光流定点与视觉追踪控制
水平位置控制由 Position_Hold_Task() 每 20 ms 执行。进入定点必须同时满足无人机已解锁、定高已开启、光流帧有效、TOF 高度在 100 mm 至 2000 mm 范围内、光流零偏校准完成。若短时出现坏帧，程序会在约 200 ms 内按 0.80 系数逐步衰减输出；持续无效则退出定点并清零位置控制量。
无视觉追踪时，定点控制以光流积分位置为参考，若 flow_pos_x、flow_pos_y 超出 0.10 m 死区，则以 0.1 的位置比例系数生成一个很小的回中速度，限幅为 0.12 m/s。视觉追踪开启时，程序读取 VisionFollowSnapshot_t，把 error_x、error_y 通过像素误差 PID 转成目标速度，最大追踪速度为 3.0，目标速度每 20 ms 最大变化量为 0.8。




速度环把目标光流速度与实测光流速度之差转换为姿态角修正 out_pos_x、out_pos_y。X/Y 两轴速度 PID 的 Kp 均为 9.0，Kd 均为 0.02，最大输出角度为 5 deg；输出再经过 0.85 系数的一阶平滑和 2 deg 的步进限幅，最后叠加到 Roll/Pitch 目标角。




4.3.5 四旋翼电机混控
电机输出由 Motor_Mix_Control() 在 2 ms 中断末尾执行。PWM 频率设置为 300 Hz，四路输出分别连接 MOTOR_1 至 MOTOR_4。若飞机未解锁，电机按 MOTOR_STOP_RAMP_STEP=10 逐步降速；若 Roll 或 Pitch 超过 40 deg，程序立即停止电机，防止失控后继续加油。
油门基值在定高开启时使用 hover_throttle_adapt，定高关闭时由遥控油门乘以 3 得到，并限制在 3250 至 5800 之间。最终油门为基值叠加定高补偿 out_alt，再与三个姿态轴输出完成 X 型四旋翼混控。






混控后的电机占空比统一限制在 MOTOR_MIN=3200 与 MOTOR_MAX=6000 之间。这样既保证低油门下电机不会因占空比过小而失速，又能防止姿态、定高和追踪控制叠加后超过电调可接受范围。














第五章 车模软件设计
5.1 软件总体架构
车模软件采用视觉板和底盘板分工的双角色结构。主程序在完成 clock_init(SYSTEM_CLOCK_250M) 和 debug_init() 后，根据全局变量 g_app_role 选择运行 APP_ROLE_VISION_BOARD 或 APP_ROLE_CHASSIS_BOARD。视觉板负责摄像头识别、LCD 显示和 TTL 串口发送；底盘板负责编码器采样、IMU 姿态解算、LoRa 遥控、视觉误差接收以及四轮电机闭环控制。
这种结构将图像处理和底盘实时控制解耦，视觉板只输出前向误差 forward_error、右向误差 right_error 和有效标志 valid，底盘板再依据这些量生成车体坐标系下的运动速度。主循环只保留显示和遥测等低速任务，强实时任务全部放在 PIT 中断中执行。




5.2 底盘初始化与实时任务调度
底盘初始化由 chassis_app_init() 集中完成。程序首先绑定四个轮子对象 L1、R1、L2、R2 和编码器数据结构 data，然后依次初始化编码器、LoRa 模块、视觉串口、电机 PWM、IPS200 显示屏、IMU 姿态模块和速度 PID。若启用 INS_FEATURE_ENABLE，还会初始化按键与惯性导航模块；当前源码中该宏为 0U，因此惯导代码保留为可选功能，默认不参与运行。
实时调度分为 5 ms 和 10 ms 两个周期。PIT_CH0 每 5 ms 读取编码器计数、更新 IMU 姿态、轮询视觉 UART、处理 LoRa 控制并刷新运动目标；PIT_CH1 每 10 ms 取出累计编码器速度，执行四轮速度 PID 并输出 PWM。底盘主循环每 20 ms 发送一次示波器遥测数据，每 100 ms 刷新一次屏幕显示。



5.3 麦克纳姆轮运动解算
底盘运动接口为 Move_Tranform(Vx,Vy,Vz)，其中 Vx 表示车体前向速度指令，Vy 表示车体右向速度指令，Vz 表示绕车体中心的角速度指令。程序先保存指令，再由 Move_Target_Refresh() 对平移速度做斜坡限幅，避免目标速度突变导致车体打滑或电流冲击。

5.5 视觉通信与自动对准
视觉板通过 vision_uart_send_result() 将识别结果发送给底盘板，串口波特率为 115200，帧长为 7 字节。帧格式为帧头 0xA5、前向误差低字节、前向误差高字节、右向误差低字节、右向误差高字节、累加校验和帧尾 0x5A。若当前视觉结果无效，两个误差均置为 0x8000。



底盘板在 5 ms 中断中调用 vision_uart_poll() 接收字节并恢复最新帧，在 LoRa 切换到视觉控制模式后调用 vision_uart_control_task()。该任务只在序号 sequence 变化时把最新视觉误差交给 rs485_control_apply_vision_result()，随后由 rs485_control_tick() 执行超时和状态保持。
自动对准算法将视觉前向误差  和右向误差  合成为二维误差向量。若误差长度 d 小于 RS485_OFFSET_DEADBAND=3，则认为目标已对准并停止输出；否则按照比例系数 1.0 计算速度，并限制在 5 到 10 的范围内，再分解为车体前向和右向速度。







当视觉连续无效时，程序不会立即乱动：短时间内保持上一次有效控制，超过 RS485_VISION_INVALID_HOLD_FRAMES=12 帧后调用 rs485_control_stop() 停车。接近十字或目标丢失时，程序还保留了定距穿越和搜索状态机，用于在视觉短暂丢失时维持安全通过策略。
5.6 航向保持
姿态模块由 balance_init() 初始化，balance_get_data() 在 5 ms 中断中更新 IMU 数据和 Mahony 姿态滤波结果。麦轮底盘在平移时容易因轮间摩擦差异产生偏航，因此 Move_Update_Target() 在运动解算前调用 yaw_hold_update()，将航向闭环输出  叠加到 Vz 上。





当前参数中航向保持默认开启，Kp=1.4、Ki=0.0、Kd=0.2，角速度死区为 0.8 deg/s，角度误差死区为 2 deg，输出每次最大变化为 2。若驾驶员主动给出转向指令，航向锁定会被释放，避免控制器和人工转向相互对抗。
5.7 调试显示与参数整定
调试部分主要由 IPS200 屏幕、逐飞助手示波器和 LoRa 遥控器共同完成。ips_display() 每 100 ms 显示四个轮子的目标速度、编码器反馈和 PWM 输出，并显示 yaw、gyro z、航向目标、航向误差和航向补偿量。Speed_PID_Telemetry_Task() 每 20 ms 发送 8 通道示波器数据，用于观察 L2 轮目标值、原始反馈、滤波反馈、误差、输出、滤波系数、采样次数和速度比例。
LoRa 控制程序可以在遥控模式和视觉 UART 模式之间切换。遥控模式下，左摇杆给出前后和平移速度，右摇杆给出旋转速度；视觉模式下，底盘停止接收手动平移指令，而是调用 vision_uart_control_task() 使用视觉误差完成自动对准。程序还提供在线 PID 参数选择和限幅，便于在实车调试时逐项调整轮速闭环参数。

第六章 制作安装过程说明
6.1 制作与安装过程
6.1.1 飞机组装
 飞机以逐飞科技开源售卖机架为基础进行改造，整体安装过程严格按照结构设计方案执行。主要步骤包括：
（1）保护罩安装：通过尼龙柱与尼龙螺丝螺母相连接，将保护罩与电机同心安装以最大保证气流顺畅
（2）电调安装：将分体电调分开放置，两块电调放置在机架上侧，两块电调放置在机架下侧并以中心轴对称安装，以保证重量均匀。
（3）主板安装：通过3D打印件以及铜柱链接，将主板安装在机架中心上方。
（4）陀螺仪安装：将陀螺仪固定在飞机正中央主板下方，以保证陀螺仪贴近车体质心，以保证姿态测量的灵敏度与抗震性。
（5）分电板安装：将分电板安装在机架正下方，分电板中心与飞机中心孔洞对齐，方便通信线通过。
（6）光流，TOF安装：将二者对称安装在机架两端，保证下端无干扰。
6.1.2 麦轮车组装
本车模以博思威龙M型车模为基础进行改造，整体安装过程严格按照第二章所述的结构设计方案执行。主要步骤包括：
（1）：车轮转接件安装：更改为直径80mm的麦轮车，通过3D打印联轴器连接电机输出轴与齿轮，提高车轮离地间隙，以保证不会卡住信标。
（2）：电池安装：利用3D打印的电池固定盒将电池组固定于车模底板上方正中央，以防止车重心偏移。

（3）：侧板安装：利用3D打印件拓展车模底面面积，通过车模的固定孔位使用螺丝螺母将侧板与车模固定，以保证最大踩灯效率。
（4）：电路板安装：将主板，分电板通过3D打印件安装在车辆中心侧，将双驱板通过转接板安装在车辆两端，以保证车辆结构稳定。
综上对所有电源线，信号线进行扎带固定，避免运动过程中松动或干涉。关键接插件使用热缩管/电工胶布绝缘。以上安装完成后，进行通断测试与电压检测，确保各模块供电正常，传感器信号无误。

第八章 总结
本技术报告围绕第21届全国大学生智能汽车竞赛相关要求，详细阐述了本队智能车系统的总体设计方案、硬件组成、软件控制流程以及调试过程。系统采用无人机与地面麦克纳姆轮车协同工作的结构形式：无人机负责空中视觉感知与目标信息获取，地面车根据视觉与控制指令完成目标跟踪、姿态调整和路径执行，从而实现空地协同的智能控制任务。
在硬件设计方面，系统以飞控板、底盘控制板、视觉模块、姿态传感器、TOF测距模块、光流模块、电机驱动电路以及通信接口为核心，构建了较为完整的感知、控制和执行平台。无人机部分通过姿态传感器、TOF和光流模块实现飞行状态估计；地面车部分通过编码器、电机驱动和麦克纳姆轮底盘实现全向运动控制。各模块之间通过串口、RS485等通信方式完成信息交互，为系统稳定运行提供了硬件基础。
在软件设计方面，系统采用分层控制思想，将底层驱动、传感器采集、姿态解算、视觉识别、运动控制和调试显示等功能进行模块化设计。无人机控制部分通过姿态串级PID、定高控制、光流定点和电机混控实现基本飞行稳定；视觉部分通过图像预处理、阈值分割、连通域筛选、箭头与信标识别等方法提取目标信息；地面车部分则结合麦克纳姆轮运动学模型、编码器速度反馈和PID闭环控制，实现了前后、左右和平面旋转方向上的运动控制。
在调试过程中，本队围绕传感器数据稳定性、视觉识别准确性、通信实时性和运动控制响应速度进行了多轮测试与参数整定。通过逐步验证单个模块功能，再进行整车联调的方法，降低了系统集成难度，提高了调试效率。实验结果表明，系统能够完成基本的目标识别、数据传输和运动控制任务，各模块之间具有较好的协同性。
同时，本系统仍存在进一步改进空间。例如，视觉识别算法在复杂光照环境下的鲁棒性仍需提升；无人机与地面车之间的协同控制策略还可以进一步优化；运动控制参数在不同赛道环境下仍需要更高效的自适应调整方法。后续工作中，可进一步引入更稳定的滤波算法、更完善的目标识别策略以及更高层次的路径规划方法，从而提升系统整体稳定性、实时性和比赛适应能力。

void Motor_Mix_Control(void)
{
    if (drone_state != UNLOCKED)
    {
        Motor_Stop_Ramp();
        return;
    }

    throttle = base + (int32_t)out_alt;

    motor1 = throttle + out_roll + out_pitch + out_yaw;
    motor2 = throttle - out_roll + out_pitch - out_yaw;
    motor3 = throttle - out_roll - out_pitch + out_yaw;
    motor4 = throttle + out_roll - out_pitch - out_yaw;

    motor1_duty = LIMIT(motor1);
    motor2_duty = LIMIT(motor2);
    motor3_duty = LIMIT(motor3);
    motor4_duty = LIMIT(motor4);

    Motor_Apply_Duty();
}
