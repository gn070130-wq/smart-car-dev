1.1 竞赛背景与意义
全国大学生智能汽车竞赛是教育部倡导的大学生科技竞赛之一，自2006 年
创办以来，已发展成为国内影响力最大的本科生工程实践赛事之一。竞赛以"立
足培养、重在参与、鼓励探索、追求卓越"为指导思想，倡导参赛队伍综合运用
机械设计、电路设计、嵌入式软件、自动控制与传感器技术，自主完成智能车
作品的设计与制作。第二十一届竞赛在传统竞速类赛道基础上增设室内赛道，
进一步拓展了作品形态，对参赛队伍的多学科综合能力提出了更高要求。
本队参加的"飞跃雷区"组别要求自制一辆地面车模与一台系留悬停飞行器
协同作业，在室内信标赛道中完成信标位置检测并逐个越过信标。该赛题将地
面移动平台与空中悬停平台耦合为一个整体系统，涉及多旋翼稳定控制、信标
检测识别、车机协同与系留供电等多方面技术，对参赛队员的系统设计与工程
调试能力是很好的锻炼，参赛过程使我们受益匪浅。
1.2 赛题任务与要求分析
赛题任务为：场地为室内白色PVC 赛道（背景为蓝色广告布），场地上布
设有若干信标；车模与悬停飞行器通过一条不长于1.5 米的线缆连接，飞行器
中不包括电池，由车模通过线缆供电；系统需检测各信标位置，并控制车模依
次越过信标完成比赛。
竞赛规则对系统方案提出了明确约束：一是环境感知传感器（摄像头、光
电管、TOF 等）必须全部安装在悬停飞行器上，车模上不允许安装环境感知传
感器，即"眼睛在空中、身体在地上"；二是允许使用英飞凌硅麦传感器检测悬
停飞行器的位置；四是悬停飞行器上不允许加装摄像头的云台机构；五是飞行
器由车模经线缆供电，线缆长度不超过1.5 米。
上述约束决定了系统的基本形态：飞行器承担环境感知职能，车模承担承
载、供电与行驶职能，两者通过可靠的通信与协同控制策略配合完成任务。系
统设计必须围绕这一分工展开。

第二章 系统总体方案设计
2.1 系统总体结构
系统由车模平台、飞行器平台和系留线缆三部分组成，总体结构如图2.1
所示。车模平台以英飞凌CYT4BB7 为主控，搭载CYT2BL3 四合一无刷电调
驱动四只无刷电机实现差速转向；车上安装V 形红外LED 灯板，供飞行器定
位；供电系统为整车及飞行器提供电源。飞行器平台以英飞凌CYT4BB7 为主
控，搭载IMU660RC 六轴惯性传感器、MT9V03X 灰度摄像头、VL53L8XTOF
测距模块和优像光流模块完成位姿稳定、信标检测与自身定位。
2.2 方案论证与选择
2.2.1 车模方案选择
车模采用四轴麦轮小车，使用有刷减速电机搭配13 线的霍尔编码器进行驱
动，可实现全向移动，适合比赛中车模频繁改变速度方向的要求。
2.2.2 飞行器方案选择
悬停平台采用X 型四旋翼布局，对角轴距260mm，配5 英寸三叶桨。四旋
翼结构成熟、控制资料丰富、悬停稳定性好；动力采用四只RS2205 无刷电机
配3S 锂电池。
2.2.3 主控芯片选择
竞赛要求车模MCU 平台为英飞凌TRAVEO 系列。车模和飞行器均采用主
控选用CYT4BB7（TRAVEOT2G 系列，ArmCortex-M7 内核），飞行器的驱
动电路使用CYT2BL3 芯片，其计算性能满足任务调度与多路通信需求。
2.2.4 信标检测方案选择
通过红外摄像头读取原始图像，经过二值化和连通域处理，寻找图像中的
红外光源连通域即为信标。

2.2.6 供电方案设计

2.3 系统工作流程
比赛执行流程为：上电自检→飞行器起飞并稳定悬停→发车→飞行器旋转
搜索信标，锁定最近信标并解算相对位置→车模按目标行驶，飞行器保持相对
位置同步跟随→车模越过信标后进入下一目标循环→全部信标越过完毕，比赛
结束。

5.2.1 姿态解算算法
姿态解算采用Mahony 四元数互补滤波算法。算法先用当前四元数估计重
力方向，再与加速度计测量方向做叉积得到姿态误差，经PI 调节修正陀螺仪角
速度，最后对四元数微分方程做一阶龙格-库塔积分并归一化，如公式1 所示。
e=a×v̂，ωc=ω+kp·e+ki·∫e·dt （公式1）
式中a 为归一化加速度计测量矢量，v̂为四元数估计的重力方向矢量，e 为
叉积误差，ω为陀螺仪角速度，ωc 为修正后的角速度，kp、ki 为修正系数（取
kp=1.5、ki=0.0005），采样周期为5ms。数据预处理采用双路径滤波：控制环
使用一阶低通（α=0.1）数据，姿态解算使用截止频率30Hz 的二阶Butterworth
滤波数据，抑制桨叶高频振动；上电静止时自动采集陀螺零偏并校准roll/pitch
姿态零点。该算法计算量小，200Hz 姿态解算在CYT4BB 上耗时不足0.1ms。
5.2.2 姿态控制算法
姿态控制采用串级PID 结构：内环为角速率环（500Hz），外环为姿态角
环（200Hz）。串级结构使内环先抑制角速度扰动、提高系统阻尼，外环再跟
踪期望姿态角，具有响应快、抗扰动能力强的优点。角速率环采用微分先行结
构（微分项只对测量值微分），避免设定值突变引起的微分冲击。离散PID 算
式如公式2 所示。
u(k)=Kp·e(k)+Ki·I(k)+Kd·[e(k)-e(k-1)] （公式2）
式中e(k)为当前误差，I(k)为部分积分值（I(k)=I(k-1)+Ipro·e(k)，Ipro 为部
分积分系数，并做积分限幅），Kp、Ki、Kd 为各环整定系数。参数按"先内环
后外环"顺序整定，最终参数为：角速率环（roll/pitch）Kp=1.6、Ki=1.0、
Kd=20，输出限幅±350；姿态角环Kp=2.85（roll）、3.6（pitch）、3.5（yaw），
输出限幅±300。角速率环输出经X 型四旋翼混控矩阵分配至四路电机

A.2 Mahony 姿态解算源码
飞行器姿态解算采用Mahony 四元数互补滤波算法，核心函数IMUupdate
通过加速度计与重力方向估计的叉积误差进行PI 修正，抑制陀螺仪积分漂移，
并输出欧拉角，源码如下。
void IMUupdate(FLOAT_XYZ *Gyr_filt, FLOAT_XYZ *Acc_filt, FLOAT_ANGLE *Att_Angle)
{
float ax = Acc_filt->X, ay = Acc_filt->Y, az = Acc_filt->Z;
float halfT = imu_dt * 0.5f;
float norm;
// 加速度计有效性检查
if (ax * ay * az == 0)
return;
// 加速度归一化
norm = 1.0f / sqrtf(ax*ax + ay*ay + az*az);
ax *= norm; ay *= norm; az *= norm;
// 用当前四元数估算重力方向
float vx = 2.0f * (q1*q3 - q0*q2);
float vy = 2.0f * (q0*q1 + q2*q3);
float vz = q0*q0 - q1*q1 - q2*q2 + q3*q3;
// 叉积求姿态误差
float ex = ay * vz - az * vy;
float ey = az * vx - ax * vz;
float ez = ax * vy - ay * vx;
// PI 误差积分
I_ex += ex;
I_ey += ey;
I_ez += ez;
I_ex = LIMIT(I_ex, -100.0f, 100.0f);
I_ey = LIMIT(I_ey, -100.0f, 100.0f);
I_ez = LIMIT(I_ez, -100.0f, 100.0f);
// 陀螺仪角速度 + PI 修正
gyro_corrected[0] = Gyr_filt->X + mahony_kp * ex + mahony_ki * I_ex;
gyro_corrected[1] = Gyr_filt->Y + mahony_kp * ey + mahony_ki * I_ey;
gyro_corrected[2] = Gyr_filt->Z - gyro_z_bias + mahony_kp * ez + mahony_ki *
I_ez;
// 四元数微分方程积分（一阶龙格库塔）
float gx = gyro_corrected[0], gy = gyro_corrected[1], gz = gyro_corrected[2];
q0 += (-q1*gx - q2*gy - q3*gz) * halfT;
q1 += ( q0*gx + q2*gz - q3*gy) * halfT;
q2 += ( q0*gy - q1*gz + q3*gx) * halfT;
q3 += ( q0*gz + q1*gy - q2*gx) * halfT;
// 四元数归一化
norm = 1.0f / sqrtf(q0*q0 + q1*q1 + q2*q2 + q3*q3);
q0 *= norm; q1 *= norm; q2 *= norm; q3 *= norm;
// 欧拉角解算
Att_Angle->rol = asinf(2.0f * q0*q2 - 2.0f * q1*q3) * RadtoDeg;
Att_Angle->pit = atan2f(2.0f * q2*q3 + 2.0f * q0*q1,
q0*q0 - q1*q1 - q2*q2 + q3*q3) * RadtoDeg;
Att_Angle->yaw = atan2f(2.0f * q1*q2 + 2.0f * q0*q3,
q0*q0 + q1*q1 - q2*q2 - q3*q3) * RadtoDeg;
}
A.3 车模轮速增量式 PID 源码
车模四轮速度环采用增量式PID 控制，核心函数PID_Increment_Calc 通过
计算控制量增量并累加输出，避免积分饱和，源码如下。
float PID_Increment_Calc(PID_Increment_t *pid, float target, float feedback)
{
float error;
float delta;
error = target - feedback;
// 计算增量
delta =
pid->Kp * (error - pid->last_error) +
pid->Ki * error +
pid->Kd * (error - 2 * pid->last_error + pid->prev_error);
// 增量累加
pid->output += delta;
// 输出限幅
if (pid->output > pid->out_max)
pid->output = pid->out_max;
if (pid->output < pid->out_min)
pid->output = pid->out_min;
// 误差更新
pid->prev_error = pid->last_error;
pid->last_error = error;
return pid->output;
