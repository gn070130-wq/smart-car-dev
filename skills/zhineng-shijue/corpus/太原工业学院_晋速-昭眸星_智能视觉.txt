第二章 方案设计
本章主要介绍智能汽车系统总体方案的选定和总体设计思路，在后面的章节中将整个系统分为传感器布局，机械结构、硬件模块、控制算法等三部分对智能汽车控制系统进行深入的介绍和分析。

2.1 系统总体结构
对于M车模，首要的任务是速度角度闭环，闭环的核心是编码器，陀螺仪角速度计模块。由陀螺仪获取车模角速度信息，通过姿态解算计算出车模当前偏航角，运用PID控制麦轮保持车身稳定。由车模上的Open Art PLUS摄像头来采集屏幕上的赛道信息，以此来转向、规划路径。

2.2 系统总体方案选定
本次智能车系统方案选型严格围绕智能视觉组赛事规则、比赛场地特性与推箱子逐级闯关的任务需求展开，结合组委会指定M系列成品车模的硬件适配性，兼顾系统稳定性、实时性、容错性与可迭代性，通过多套备选方案对比测试，最终确定以RT1064主控+视觉图像识别+惯性姿态闭环控制的一体化智能控制系统方案，全方位适配赛事动态场景作业需求。

  2.3系统总体方案的设计
遵照竞赛规则规定，本组别采用NXP RT1064单片机作为核心控制单元用于车模系统的控制。在选定智能汽车系统采用摄像头方案后，目标位置的信息主要通过图像分析来进行路径规划，经RT1064 MCU对车模进行移动转向控制进而保持赛道上能够自主规划行驶，并以较短的路径以及较稳定姿态以合理的速度完成赛事任务。此外，还增加了五轴按键和拨码开关作为输入输出设备，用于车模的速度和控制方案选择。
根据以上系统方案设计，系统共包括六大模块：RT1064主控模块、DRV驱动模块、传感器模块、速度检测模块、辅助调试模块和电源模块。各模块的作用如下所述：
Rt1064主控模块：作为整个车模的“大脑”，其采集陀螺仪,摄像头传感器、编码器等传感器的信号，根据控制算法做出控制决策，驱动麦轮对车模控制。
DRV驱动模块：作为车模飞轮驱动的核心，通过接受“大脑”串口发送的信息，对麦轮转速进行调整，保证电机执行指定的转速，维持车模姿态的稳定。
传感器模块：是车模的“感官”，可以通过一定的前瞻性，提前感知前方的赛道信息，为车模的“大脑”做出决策提供必要的依据和充足的反应时间。
速度检测模块：检测反馈车模车轮的转速。
辅助调试模块：主要用于车模系统的功能调试、状态检测。
电源模块：为整个系统提供合适而又稳定的电源。

第四章 机械结构分析及调节
任何的控制算法和软件程序都是需要一定的机械结构来执行和实现的，一个好的机械结构能避免很多麻烦，因此在设计整个软件架构和算法之前一定要对整个车模的机械结构有一个理性的认识。

4.1车体机械建模
我们选用的赛车车模是逐飞科技的M车模。赛车的机械结构调整方案主要是针对竞赛车模的重心，要想实现高速稳定的运行，机械结构应当做到使重心尽可能的落在整车中心，减少车模在横向移动时歪斜，以减轻陀螺仪死区干扰，同时，要想移动灵活，机械结构应当使重心尽可能的集中，以减少车模转动惯量。对于原装的M车搭建机械结构后重心偏后，于是我们在前端加了100g配重它可以提供更大的力矩，以便于在横向平移时保持稳定。

4.2摄像头&陀螺仪&车载屏幕的安装 
摄像头与屏幕之间的距离经过了调整可以在一定范围内看全看清晰屏幕显示的赛道信息，周围添加了遮光纸板，可以减少环境光的影响。陀螺仪模块是车模获取车模姿态的传感器，为了让陀螺仪可以更好的出值，我们将陀螺仪尽可能安装在了车模中间部分，陀螺仪放在了车模的摄像头正下方，在移动时可以更好的锁定目标偏航角。为了减小移动时摄像头与屏幕相对位移导致识别不稳定，我们通过3D打印技术将其固定为一体，提高运行时车模识别稳定性。

4.3系统电路板的固定及连接
由于车模空间有限，摄像头与屏幕占据了大部分空间，而需要安装的电路板又比较多，为了保证车模重心集中和整体的协调，对电路板的位置做了多次相应的调整，提高调车效率及车模速度上限。对于各个电路板的连接也进行了调整尽可能让线路合适。

6.1 车模的运行控制
6.1.1 PID控制原理
PID控制以其结构简单、稳定性好、工作可靠、调整方便而成为工业控制的主要技术之一。当被控对象的结构和参数不能完全掌握，或得不到精确的数学模型时，系统控制器的结构和参数必须依靠经验和现场调试来确定，这时应用PID控制技术最为方便。
PID控制就是根据系统的误差，利用比例(P)、积分(I)、微分(D)计算出控制量进行控制的。目前PID控制在工业控制系统中无处不见，随着控制效果的要求不断提高，PID逐渐向智能化发展，但形形色色的现代控制理论最终还是源自经典PID理论。
PID解决了自动控制理论所要解决的最基本问题，既系统的稳定性、快速性和准确性。调节PID的参数，可实现在系统稳定的前提下，兼顾系统的带载能力和抗扰能力，同时，在PID调节器中引入积分项，系统增加了一个零积点，使之成为一阶或一阶以上的系统，这样系统阶跃响应的稳态误差就为零。
由于自动控制系统被控对象的千差万别，PID的参数也必须随之变化，以满足系统的性能要求。因此PID参数的确定是PID控制中重要的部分之一[3]。

6.1.2.M车运动控制原理
本次 M 型底盘采用四轮麦克纳姆轮全向移动结构，依托四轮独立转速配合实现平面全向运动，为适配推箱子场景高精度姿态保持、定点驻车、低速稳推需求，整车采用车体航向位置闭环（角度位置环）+ 单轮转速位置式 PID 闭环双层位置环控制架构，从上层姿态位置纠偏、车体运动学解算、底层电机位置闭环执行形成完整控制链路，下文从运动学模型、航向角度位置环控制、电机转速位置式 PID 闭环、指令平滑约束、整车联动逻辑展开完整说明。
首先麦克纳姆轮底盘运动学逆解模型是以底盘几何中心建立车体坐标系：X 轴指向车头正前方，Y 轴指向车体左侧，Z 轴垂直地面向上，绕 Z 轴转动为航向角θ。定义车体期望运动输入：Vx​：车体前后轴向线速度（向前为正）；Vy​：车体左右横向线速度（向左为正）；ω：车体绕中心旋转角速度（逆时针为正）。四轮排布：左前轮 M1、右前轮 M2、左后轮 M3、右后轮 M4，L为前后轴距半长，W为左右轮距半长，四轮目标线速度逆解公式：
⎩⎨⎧​Vw1​=Vx​−Vy​−ω(L+W)Vw2​=Vx​+Vy​+ω(L+W)Vw3​=Vx​+Vy​−ω(L+W)Vw4​=Vx​−Vy​+ω(L+W)​
结合车轮半径R、电机减速比i，将车轮线速度换算为电机期望转速，作为底层电机闭环的设定值。上层路径规划、箱子对位逻辑输出、、，通过运动学拆解为四路电机目标转速，是整车运动的数学基础。
推箱作业中车体航向偏移会直接造成箱子横向偏移、对位失效，因此以航向绝对角度作为位置环被控量，构建角度位置式 PID 闭环，直接修正车体旋转角速度指令。
通过 ICM20602 陀螺仪完成姿态解算，得到车体实时绝对航向角θreal​，任务给定目标航向角θset​，角度位置偏差：
eθ​(k)=θset​−θreal​(k)
2.2 角度位置式 PID 控制公式
位置式 PID 直接输出角速度修正总量，公式为：
Δω(k)=KPθ​⋅eθ​(k)+KIθ​⋅∑i=0k​eθ​(i)+KDθ​⋅[eθ​(k)−eθ​(k−1)]
比例项KPθ​⋅eθ​(k)：根据当前角度偏差直接输出纠偏角速度，偏差越大纠偏力度越强，快速收拢航向误差；
积分项KIθ​⋅∑eθ​(i)：对长时间累计角度误差做积分补偿，消除陀螺仪温漂、底盘机械不对称带来的稳态航向漂移，保证长时间直行航向不跑偏；
微分项KDθ​⋅Δeθ​：抑制角度超调，避免车体反复左右摆头震荡，适配低速微调航向推箱工况。
将角度环输出的角速度修正量叠加至基础旋转指令：
ωout​=ωbase​+Δω(k)
修正后的角速度重新代入麦轮逆解公式，修改四轮转速，实现航向角度的位置闭环锁定，维持车身姿态固定。

经过运动学解算得到四轮目标转速Vset1​∼Vset4​，每一路直流电机搭载正交编码器采集实时转速Vreal​(k)，以转速为被控量搭建独立位置式 PID 闭环，直接输出电机 PWM 控制占空比绝对值，对应前文增量式 PID 对比，位置式 PID 直接输出最终控制输出量u(k)。
转速偏差：e(k)=Vset​(k)−Vreal​(k)位置式 PID 输出：
u(k)=KP​⋅e(k)+KI​⋅∑i=0k​e(i)+KD​⋅[e(k)−e(k−1)]
u(k)为当前周期输出至 DRV8833 驱动模块的 PWM 占空比，正负符号控制电机正反转，幅值决定输出功率。
位置式 PID 电机控制控制输出直观：输出量直接对应驱动 PWM 幅值，标定参数时可直观对应 “偏差多大对应多大动力”，现场调试门槛低，适合竞赛现场快速调参；
稳态转速精度高：积分项持续补偿轮间机械差异、电池电压跌落带来的转速跌落，保证四个麦轮实际转速严格贴合理论解算值，避免四轮转速不一致导致的车体不自觉侧滑、航向偏移；
停机特性优异：当目标转速Vset​=0时，偏差e(k)直接由当前转速决定，PID 输出反向制动 PWM，实现主动刹车，相比增量式 PID 驻车刚性更强，推箱到位后可以牢牢锁死车轮，防止车体溜动顶推箱子移位；
必须配套输出限幅：对最终 PWM 输出u(k)设置最大最小值，限制电机满占空比输出，保护 DRV 驱动芯片与电机，防止堵转大电流烧毁功率器件。
增量式 PID 输出控制量变化值，适合连续调速场景；本车使用位置式 PID，依靠直接输出制动力矩的优势，完美适配推箱子定点驻车、精准刹停、姿态锁紧核心需求，是全向底盘高精度作业的优选方案。
上层路径规划直接给出阶跃式、、指令时，目标转速突变会让电机位置环瞬间产生超大偏差，PID 输出骤变引发车体冲击抖动。在运动学解算前增加斜坡加减速滤波，限制单周期速度最大变化量：
Vout​(k)=⎩⎨⎧​Vout​(k−1)+Vstep​Vout​(k−1)−Vstep​Vset​​Vset​>Vout​(k−1)Vset​<Vout​(k−1)∣Vset​−Vout​(k−1)∣≤Vstep​​
长距离行进使用大步长提升移动效率，靠近箱子、终点点位切换小步长，平缓改变目标转速，降低电机位置环瞬时误差，进一步提升运动平顺性。
决策层：视觉模块识别箱子、终点、场地边界，输出车体目标行进速度、与目标航向角度θset​；
航向位置环：陀螺仪解算实际航向，位置式 PID 完成角度闭环纠偏，修正车体旋转角速度指令，锁定车身朝向；
指令平滑层：斜坡滤波处理速度指令，消除阶跃冲击；
麦轮运动解算：将车体三轴运动矢量分解为四个电机目标转速；
电机转速位置环：四路独立位置式 PID 闭环，结合编码器反馈稳定轮速，PWM 输出至 DRV 驱动驱动车轮运动。
整套角度位置外环 + 转速位置内环双闭环架构，充分发挥位置式 PID 稳态控制强、制动锁止可靠的优势，解决麦克纳姆轮底盘航向漂移、轮速不一致、驻车溜车三大通病，实现赛场高速行进、低速贴箱对位、原地角度校准、到位刚性驻车的全工况稳定运动，满足虚拟推箱子多关卡高精度作业要求。

6.3识别策略
 整车搭载两台逐飞科技OpenART Plus视觉摄像头组成双目视觉识别架构，左右摄像头分工明确，分别承担全局地图环境感知与局部目标精细化分类任务，二者通过串口将解析完成的特征数据统一传输至RT1064主控下位机，为路径规划、推箱决策、爆破逻辑提供视觉数据源。 
左侧摄像头负责全局赛场地图轮廓、障碍物、功能物件定位，采用四点标定法选取场地四个基准顶点完成赛场边界框选，随后使用逆透视变换算法矫正镜头畸变与透视形变，还原出垂直俯视的标准鸟瞰地图。在矫正完成的鸟瞰图内采用LAB色彩空间阈值分割算法，依靠不同色块LAB通道数值差异区分围墙墙体、可推动箱子、目标放置点位、爆破炸弹标识，同时通过画面色块消失检测判断炸弹触发后被摧毁的墙体编号，结合场地坐标解算小车当前在地图内的坐标位置与行进姿态，实现整车全局定位与环境建模。 
右侧摄像头专注近距离目标精细化分类识别，采集画面中心240×240像素核心区域作为模型推理输入，缩减运算量提升识别帧率。模型依托NXP eIQ模型部署软件完成训练、量化与边缘端部署，整体设置11分类标签：序号0至9对应赛场内不同编号箱体目标，序号10统一识别黄色箱体与对应目标存放点位。摄像头完成模型推理后，将目标类别、中心坐标等有效信息打包，通过串口通信发送至主控下位机。 双目视觉各司其职完成环境建模与物体分类，既依靠左摄保证全局地图定位的稳定性，又依靠右摄保障箱体类别识别精度，有效规避单摄像头兼顾全局与近距离识别带来的畸变、算力不足问题，为智能车推箱配对、炸弹爆破、轨迹修正提供可靠视觉支撑。

  第九章 结论
在这份技术报告中，我们主要介绍了参赛小车整体设计思路，包含机械结构、硬件电路以及核心运动控制算法的设计与调试思路。
项目前期，我们相关工程实践经验较为欠缺，调试阶段遇到诸多软硬件故障。通过反复实车测试、算法调参和团队协作攻关，逐一解决各类问题，完成整车系统优化，自身实践能力也得到充分锻炼。
机械布局上，依托 M 型麦轮车全向移动的特性，优化摄像头、陀螺仪、编码器等传感器安装位置，在实现车体轻量化的同时，保障小车行驶结构稳定。硬件电路以 RT1064 主控搭配 DRV 电机驱动搭建，调试阶段解决了电机冲击烧管、电源压降等硬件问题，硬件稳定性得到保障。软件控制上，整车采用双位置环 PID 实现麦轮姿态与转速闭环控制，视觉模块采集箱子与场地信息，结合陀螺仪姿态数据计算运动偏差，输出车体运动指令，配合速度平滑处理，让小车既能快速行进，又可精准完成贴箱、驻车、姿态修正动作，稳定完成赛场推箱作业。

void menu(int page)
{
    pages(page);                                    //显示
    int KeyNum = Set_key_number();                    //检测按键
    if(KeyNum == 1||KeyNum == 2){find_data(KeyNum);}  //移动箭头
    else if(KeyNum == 3||KeyNum == 4||KeyNum == 5){set_data(KeyNum);} //设置数据
    while(KeyNum != 0&&KeyNum<=4){                              //防止多次计数
        KeyNum = Set_key_number();
