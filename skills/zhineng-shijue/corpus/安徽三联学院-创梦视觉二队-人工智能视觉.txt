  第一章 模型车设计制作的主要思路以及实现的技术方案概要说明
  本团队使用M车成品车模，整体采用**上层视觉感知、中层决策求解、底层运动执行**三层解耦架构，通过状态机统一调度整机任务流程，实现从地图获取、路径求解、运动执行到回原点的全自动多关卡推箱任务。硬件以 RT1064 为主控，搭配麦克纳姆轮全向底盘、IMU 惯导模块与 OpenArt Plus 视觉摄像头，分别完成姿态解算、全向运动控制与环境信息采集。系统设置难度递进的三关卡机制，依次实现基础多箱推落、数字编号精准匹配推箱、炸弹炸墙开路推箱功能，适配复杂场地任务场景。软件层面采用 16×12 轻量化栅格地图并通过 SDRAM 扩容存储，有效避免堆栈溢出；核心路径规划在 A * 算法基础上，结合洪水填充可达性检测、静态与隧道死锁剪枝、小顶堆搜索加速，同时通过 DP 最优匹配、贪心顺序优化、GTSP 全局遍历算法分别适配三关卡任务逻辑，并加入路径拉直与动作压缩策略，减少运动拐点、提升运行效率。运动控制采用**5ms 姿态快环 + 20ms 状态机慢环**双时间片架构，通过角度与角速度串级 PID、四轮独立速度 PID，结合视觉毫米级坐标闭环修正，实现栅格精准对位与高精度转向。设备通过自定义串口协议完成地图、坐标与数字模型数据交互，同时支持参数掉电保存、人机按键调参。整体方案通过感知、决策、控制全链路优化，有效提升了其自主规划能力与运动稳定性，可高效完成递进式复杂推箱子竞技任务。

第四章 微处理器控制软件主要理论、算法说明及代码设计介绍等。
本套微处理器控制软件采用感知‑规划‑决策‑执行四层分离结合前后台双任务调度架构，将串口视觉数据接收放在中断感知层，推箱 A*搜索、DP 匹配、DFS 炸墙、GTSP 组合优化等耗时算法置于后台主循环完成规划，由`car_mode`状态机完成任务流程决策，5ms 串级姿态速度快环与 20ms 视觉位置环在 PIT 中断内实现底层执行。软件依托 Mahony 四元数互补滤波完成 IMU 姿态解算并上电标定陀螺零漂，通过麦克纳姆轮逆运动学实现场地世界系到机体系的速度转换，采用位置‑速度‑角速度多级串级 PID 实现闭环控制。推箱算法以（玩家位置，箱子位置）作为搜索状态，借助桶队列、洪水填充可达性判断、静态与隧道死锁剪枝优化 A*搜索效率；关卡一使用子集 DP 完成箱子与目标最小权完美匹配，关卡三通过 DFS 启发式剪枝遍历炸弹炸墙方案生成可解地图，再由 GTSP 求解全局最优动作遍历顺序，同时增加路径拉直、动作压缩降低运动拐点。工程上按功能拆分驱动与算法模块，中断分层保障实时性，设计专用结构体管理视觉、运动、搜索、规划数据；针对 RT1064 内存限制，把搜索大数组部署到外部 SDRAM，使用代际计数器、手工节点池减少内存开销与重复内存拷贝；依靠状态标志、到位阈值判断、Flash 参数持久化完成整机流程调度与容错，完整支撑三关卡递进式推箱子M车的自主运行。

本团队控制系统拥有严格分层的实时检测与闭环频率体系，底层姿态与运动控制由 5ms 定时器 PIT_CH0 驱动，整体运行频率达到200Hz，包含 IMU 六轴姿态解算、四轮正交编码器速度采样、角度环、角速度环、电机速度环以及 PWM 输出更新，保证车体姿态与运动状态能够高频、稳定、实时刷新；上层视觉定位与任务控制由 20ms 定时器 PIT_CH1 驱动，闭环频率为50Hz，每个控制周期主动获取视觉坐标并执行位置闭环校正。系统地图采集为每关卡启动时一次性获取，共 192 字节栅格数据，在 115200bps 串口波特率、10bit 每字节传输格式下，理论传输耗时16.7ms；数字模型识别不固定频率，通过 P、Q 指令按需触发识别，节约系统资源。根据工程注释标定，整套视觉系统从图像拍摄、图像处理、坐标解算到串口输出完整链路固定延迟约40ms，系统预留了对应延迟补偿逻辑。场地采用 16×12 标准栅格地图，通过像素物理标定参数可得 X 方向单栅格尺寸19.0625cm、Y 方向单栅格尺寸**18.625cm**，整体场地物理尺寸为3.2m*2.4m。视觉坐标通信协议采用三位整数、两位小数的数据格式，坐标显示分辨率可达0.01cm（0.1mm），具备极高数值精度；软件设定视觉精准对位阈值为3.5cm（约 0.18 格），单步栅格移动完成判定阈值为6.0cm（约 0.31 格），转向收敛角度阈值为±10°，转向角速度环基准给定值为 ±3.0。结合镜头成像比例与像素误差映射关系，整机实际视觉定位误差稳定在±1~2cm，配合 200Hz 高频姿态速度内环与 50Hz 视觉位置外环双闭环架构，使机器人在栅格行走、精准停靠、定点转向任务中具备稳定、高精度的控制效果。

1. 姿态解算子程序（Gyro.c）

  1.1 四元数互补滤波更新

  /** Mahony 互补滤波：加速度计修正陀螺仪漂移，一阶RK更新四元数 */
  static void IMU_AHRS_update(IMU_Param_t* IMU)
  {
      float halfT = 0.5f * delta_T;                 // 采样周期一半
      float vx, vy, vz;                             // 姿态矩阵估计的重力方向
      float ex, ey, ez;                             // 姿态误差(叉积)

      float q0 = Q_info.q0, q1 = Q_info.q1;
      float q2 = Q_info.q2, q3 = Q_info.q3;

      if (IMU->acc_x * IMU->acc_y * IMU->acc_z == 0) // 传感器零状态保护
          return;

      // ① 加速度归一化（快速平方根倒数）
      float norm = My_Rsqrt(IMU->acc_x*IMU->acc_x + IMU->acc_y*IMU->acc_y
                            + IMU->acc_z*IMU->acc_z);
      IMU->acc_x *= norm;  IMU->acc_y *= norm;  IMU->acc_z *= norm;

      // ② 姿态矩阵第三列（估计的重力方向）
      vx = 2*(q1*q3 - q0*q2);
      vy = 2*(q0*q1 + q2*q3);
      vz = q0*q0 - q1*q1 - q2*q2 + q3*q3;

      // ③ 误差 = 实测加速度 × 估计重力（叉积）
      ex = IMU->acc_y*vz - IMU->acc_z*vy;
      ey = IMU->acc_z*vx - IMU->acc_x*vz;
      ez = IMU->acc_x*vy - IMU->acc_y*vx;

      // ④ PI 校正陀螺仪（积分抑制零漂）
      I_ex += halfT * ex;  I_ey += halfT * ey;  I_ez += halfT * ez;
      IMU->gyro_x += IMU_kp*ex + IMU_ki*I_ex;
      IMU->gyro_y += IMU_kp*ey + IMU_ki*I_ey;
      IMU->gyro_z += IMU_kp*ez + IMU_ki*I_ez;

      // ⑤ 一阶龙格-库塔更新四元数 q̇ = ½·q⊗ω
      q0 += (-q1*IMU->gyro_x - q2*IMU->gyro_y - q3*IMU->gyro_z) * halfT;
      q1 += ( q0*IMU->gyro_x + q2*IMU->gyro_z - q3*IMU->gyro_y) * halfT;
      q2 += ( q0*IMU->gyro_y - q1*IMU->gyro_z + q3*IMU->gyro_x) * halfT;
      q3 += ( q0*IMU->gyro_z + q1*IMU->gyro_y - q2*IMU->gyro_x) * halfT;

      // ⑥ 四元数归一化
      norm = My_Rsqrt(q0*q0 + q1*q1 + q2*q2 + q3*q3);
      Q_info.q0 = q0*norm;  Q_info.q1 = q1*norm;
      Q_info.q2 = q2*norm;  Q_info.q3 = q3*norm;
  }

  1.2 欧拉角提取 + 航向解缠绕

  void Gyro_Get_All_Angles(void)
  {
      static float Yaw_Angle_Old = 0;
      imu660rb_get_acc();  imu660rb_get_gyro();
      IMU_Get_Values();
      IMU_AHRS_update(&IMU_Data);

      float q0=Q_info.q0, q1=Q_info.q1, q2=Q_info.q2, q3=Q_info.q3;

      Gyro_Angle.PitchAngle = asin(2*q0*q2 - 2*q1*q3) * 180/pI;
      Gyro_Angle.RollAngle  = atan2(2*q2*q3 + 2*q0*q1,
                                    -2*q1*q1 - 2*q2*q2 + 1) * 180/pI;
      Gyro_Angle.YawAngle   = -atan2(2*q1*q2 + 2*q0*q3,
                                     -2*q2*q2 - 2*q3*q3 + 1) * 180/pI;

      // 跨 ±180° 解缠绕 → 连续累计航向
      float i = Gyro_Angle.YawAngle - Yaw_Angle_Old;
      if (i < -180)      i += 360;
      else if (i > 180)  i -= 360;
      YawAngle_Trans += i;
      Yaw_Angle_Old  = Gyro_Angle.YawAngle;
  }

  2. 全向运动分解子程序（control.c）

  /** 世界系速度 → 机体系 → 四轮转速（麦克纳姆轮逆运动学） */
  void Car_Move_World(float Speed_X, float Speed_Y, float Speed_Z)
  {
      float body_x, body_y, body_z;
      float LF_Speed, LB_Speed, RF_Speed, RB_Speed;

      float c = cosf(yaw_rad), s = sinf(yaw_rad);
      body_x = Speed_X * c - Speed_Y * s;   // 世界系→机体系旋转
      body_y = Speed_X * s + Speed_Y * c;
      body_z = Speed_Z;

      // 麦克纳姆轮四轮速度分解
      LF_Speed = body_y + body_x + body_z;
      LB_Speed = body_y - body_x + body_z;
      RF_Speed = body_y - body_x - body_z;
      RB_Speed = body_y + body_x - body_z;

      // 每轮速度环（编码器反馈）
      Speed_Loop(&speed_left_front,  LF_Speed, lf_encoder);
      Speed_Loop(&speed_right_front, RF_Speed, rf_encoder);
      Speed_Loop(&speed_left_last,   LB_Speed, lb_encoder);
      Speed_Loop(&speed_right_last,  RB_Speed, rb_encoder);

      // PWM 输出
      Left_front_pwm((int)speed_left_front.output);
      Right_front_pwm((int)speed_right_front.output);
      Left_last_pwm((int)speed_left_last.output);
      Right_last_pwm((int)speed_right_last.output);
  }



总结 
在本次智能车竞赛的备赛与调试过程中，我围绕车辆硬件搭建、程序算法优化、赛道适应性调试以及整体系统稳定性提升开展了全面的学习与实践。通过本次完整的备赛流程，我不仅熟练掌握了智能车整体开发流程，也对嵌入式控制、传感器采集、电机驱动、闭环调速与赛道识别逻辑有了系统、深入的理解，综合工程实践能力得到显著提升。
在硬件方面，我完成了整车结构装配、电路焊接、传感器布局调试、电机与编码器接线校准等工作。在反复调试中，我深刻认识到硬件稳定性是车辆稳定运行的基础，线路布局、焊接质量、模块固定、供电稳压等细节都会直接影响整车运行效果。通过排查接触不良、电压波动、传感器干扰等问题，我的硬件故障排查能力、电路分析能力与工程严谨度得到了充分锻炼。
在软件算法方面，我完成了底层驱动编写、编码器测速、PID速度闭环控制、传感器数据滤波、路径识别与循迹逻辑优化等核心工作。在多次试车对比中，我不断修正PID参数，优化调速曲线，解决了车辆过弯抖动、直行跑偏、加速减速不稳、过弯冲线等常见问题。同时通过数据对比、分段调试、分步验证的方式，逐步提升了程序的稳定性、流畅度与容错性，让车辆能够适应明暗变化、赛道标线磨损、弯道曲率突变等复杂赛道情况。
在整车调试阶段，我采用模块化、分步骤的调试思路，从单模块测试、单项功能测试，到整车联调、全场道连续跑图，逐级排查问题。面对车速提升后出现的失控、漂移、抖动、丢线、识别不稳定等问题，我通过修改滤波算法、调整控速策略、优化转向响应速度等方式逐一解决，让车辆在速度、稳定性、过弯流畅度之间达到平衡。
本次备赛过程也让我发现了自身存在的不足：面对复杂综合性问题时分析速度仍有待提升，高速动态调试经验不足，对系统整体耦合性的理解仍需加深。在后续学习中，我将进一步强化算法原理积累，提升数据分析与问题定位能力，学习更高效的调试方法与优化思路。
整体而言，本次智能车竞赛是一次完整且高质量的工程实践。我不仅掌握了智能车开发的全套技术流程，更培养了独立思考、耐心调试、团队协作与问题攻坚的能力，为后续嵌入式开发、自动控制、智能系统设计等相关学习与科研积累了宝贵经验。
