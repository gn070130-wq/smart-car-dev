摘  要
本文以全国大学生智能汽车竞赛智能视觉组为背景，设计并实现了一套基于 NXP RT1064  主控制器与双 OpenART  视觉模块的智能车系统。系统采用双摄像头协同工作方案：上位机摄像头负责车体定位与地图扫描，下位机摄像头负责卡通图案与数字识别及配对推断。主控制器通过状态机对发车、扫图、观察、推箱、返程等阶段进行统一调度，结合 BFS  观察路径规划与 A*  推箱路径规划求解器，配合麦克纳姆轮全向底盘的三层级联运动控制与视觉闭环矫正，实现了自主定位、地图解析、路径规划与推箱任务的全流程自动化。实测表明，系统能够稳定完成多关卡任务。

关键词：智能车；RT1064；OpenART；图像识别；路径规划；麦克纳姆轮

第一章  绪论

1.1  比赛任务
智能视觉组比赛要求小车在规定的场地内，通过视觉传感器识别场地内的各类元素， 自主完成地图扫描、 目标识别、路径规划与推箱等任务。场地为3.2m×2.4m  的网格地图，包含墙体、箱子、炸弹与目标点等元素。比赛共分三关，每关需要小车依次完成：发车区识别、地图扫描、观察路径规划、视觉识别与配对、推箱路径规划与执行、返回发车区等环节，最终将箱子推至对应目标点并稳定返回发车区，按完成任务的数量与用时评定成绩。
1.2  系统总体方案
本系统采用 NXP RT1064（ARM Cortex-M7 ，600MHz）作为主控制器，配合两块 OpenART  摄像头模块构成视觉感知系统。其中一块摄像头负责车体定位与地图扫描；另一块负责卡通识别、数字识别与配对推断。主控制器通过状态机对任务流程进行统一编排，路径规划采用 BFS  与 A*  相结合的求解器，运动控制采用三层级联 PID  与麦克纳姆轮全向移动，并通过视觉闭环矫正消除里程计累积误差。

第三章  OpenART 视觉识别系统

3.1  视觉系统总体架构
视觉系统由两块 OpenART  摄像头协同构成：一块作为上位机摄像头，负责车体定位与地图扫描；另一块作为下位机摄像头，负责识别箱子上的卡通图案与目标点上的数字，并完成配对推断。
3.2  车体定位与地图扫描
车体定位采用色块识别方法，通过提取车体上的标记色块并换算为厘米坐标，实现小车的实时定位。地图扫描将场地划分为 16×12  的网格，通过颜色阈值判断每个网格的类型（墙体、炸弹、箱子、 目标点），逐行发送给主控完成地图重建，并采用多帧确认机制保证识别稳定性。


3.3  卡通识别与数字识别
卡通识别基于卷积神经网络完成分类，通过加载量化模型进行分类推理；数字识别采用灰度图像与特征模板匹配的方法，将字符归一化后与预设的数字模板逐点比对。两类识别结果均经过多帧一致确认后输出， 以提高识别稳定性。
3.4  配对推断
OpenART2  在完成识别后，先通过箱子识别值与目标识别值相等进行直接匹配，再枚举所有排列方案筛选相容解，最终将配对结果压缩编码后发送给主控制器，由主控据此构建箱子到目标的映射关系。


第四章  路径规划

4.1  地图建模与坐标系
地图建模为 16  列 × 12  行的网格，每格 20cm 。统一坐标系以地图左下角为原点，X  轴向右、Y  轴向上。网格坐标（列号 c ，行号 r）与物理坐标的转换关系为 x_cm = c×20−10 ，y_cm = (11−r)×20−10 。角度制中 0°  表示 X  轴正方向（右），90°  表示 Y  轴正方向（上）。小车固定起始网格为 (r=5, c=2)。
4.2  BFS 观察路径规划
观察阶段需要小车依次经过每个箱子和目标点以便完成识别。求解器使用BFS  计算小车到各箱、 目标点之间的最短路径，并通过状态压缩动态规划优化观察顺序，生成箱子与目标交替的观察路径。
4.3  A* 推箱路径规划
推箱阶段采用"单箱 A*  策略：每次只推一个箱子，其余未激活的箱子视为不可通行的实体墙，从而将多箱推箱这一高维问题降维为二维网格搜索。
A*  算法在广度优先搜索的基础上引入启发式函数，通过对每个扩展节点估价来引导搜索方向。算法维护开放列表与关闭列表，每次从开放列表中取出估价函数值最小的节点进行扩展。估价函数定义为：
f(n) = g(n) + h(n)
其中 g(n)  为从起点到当前节点 n   的实际代价，h(n)  为从节点 n  到目标点的估计代价（启发函数）。当启发函数 h(n)  采用曼哈顿距离等可采纳启发时，A*  算法能够保证找到最优路径。
推箱问题的状态空间包含玩家与箱子的位置信息，系统将玩家位置、当前箱子、炸弹与爆炸中心等状态打包压缩为一个整数进行编码，配合哈希表实现状态去重，从而有效控制搜索规模。代价函数综合考虑移动、推炸弹与爆炸等动作的代价，并对转弯施加较大惩罚，使生成路径尽量平直。炸弹爆炸以撞击点为中心，影响范围为 3×3  的切比雪夫距离邻域。
4.4  全局 DFS 搜索与剪枝

对于多个箱子，采用 DFS  枚举推箱的先后顺序，每种顺序依次调用单箱A*  求解，状态在轮次之间继承，并通过分支限界进行剪枝（炸弹数优先、步数次之），保留最优解，最终输出方向字符串供运动控制模块执行。


第五章  运动控制

5.1  三层级联控制架构
运动控制采用位置环、角度环、速度环三层级联架构：外环位置环根据视觉反馈解算期望速度，中层角度环根据陀螺仪测量保持航向，内环速度环根据编码器反馈输出电机 PWM 。三层输出最终经麦克纳姆轮速度分解分配到四轮。
5.2  麦克纳姆轮速度分解
麦克纳姆轮由轮毂与沿圆周均布的斜向辊子组成，辊子轴线与轮毂轴线成45°  夹角，通过四轮转速的合理配合可实现车体的全向移动。设车体期望速度为 (vx, vy, ω) ，其中 vx  为横向速度、vy  为纵向速度、ω  为绕质心的角速度，则逆向运动学将车体速度分解为四轮转速：
ω1 = (vx − vy − (a+b) ·ω) / R
ω2 = (vx + vy + (a+b) ·ω) / R
ω3 = (vx + vy − (a+b) ·ω) / R
ω4 = (vx − vy + (a+b) ·ω) / R
其中 R  为车轮半径，a  为前后轴距半长，b  为左右轮距半长（式中符号与各轮辊子 的安装方 向有关 ） 。本系统 中 R = 3.06cm 、a = 10.0cm 、b = 8.75cm 。反之，由四轮转速合成车体速度的正向运动学关系为：
vx = R·(ω1 + ω2 + ω3 + ω4) / 4
vy = R·(−ω1 + ω2 + ω3 − ω4) / 4
ω = R·(−ω1 + ω2 − ω3 + ω4) / [4(a+b)]
5.3  PID 控制算法
系统速度环采用增量式 PID  算法，其控制律为：                
u(k) = u(k−1) + Δu(k)
其中 e(k)  为第 k  次采样时刻的偏差，Kp 、Ki 、Kd  分别为比例、积分、

微分系数。增量式 PID  输出的是控制量的增量，只需保存最近三次偏差，无需累加积分项，具有抗积分饱和、切换冲击小、运算量小的优点，适合电机速度环控制。

5.4  视觉闭环矫正
针对里程计的累积误差，系统设计了多模式视觉矫正系统：持续矫正、到点矫正、观察点矫正、换关矫正与旋转矫正。通过视觉位置反馈，配合中值滤波与双帧确认机制，在运动过程中实时修正车体坐标，并设置偏差超阈值拒矫、超时放弃等保护机制，防止误矫正导致的定位发散。


第六章  总结

本文设计并实现了基于 RT1064  与双 OpenART  视觉模块的智能车系统。系统采用双摄像头协同的视觉方案，分别完成定位扫图与识别配对；通过 BFS观察路径规划与 A*  推箱路径规划求解器完成自主决策；借助三层级联运动控制与视觉闭环矫正保证运动的精确性。系统能够稳定完成智能视觉组的比赛任务。未来可进一步优化识别算法的鲁棒性，提高在复杂光照条件下的定位精度，并缩短路径规划的计算时间。
