# 【学习摘要】蚂蚁搬家

## 组别
**第 21 届 · 蚂蚁搬家**（室内限定场地识别/接近/推送物品；可主从双车协同，辅助车不搬运）

## 硬件栈
| 模块 | 常见选型 |
|------|----------|
| 主控 | **NXP RT1021**（MicroPython 常见）等 |
| 底盘 | **三轮/四轮全向** |
| 视觉 | OpenArt Mini / OpenMV / 摄像头；常与主板分置 |
| 传感 | 编码器、IMU、灰度（黄边线）、无线串口 |
| 执行 | N20 等减速电机；单推杆（尺寸受限） |

## 核心算法
视觉选目标（颜色/YOLO）→ 接近对准 → 推物 → 边线确认 → INS/里程返回；主从协同帧；全向运动学 + 速度 PID；Dijkstra/可视图路径；S 曲线速度规划。

## 局限
报告为主，无统一开源整树；双车通信丢包/坐标系不一致常见。

已开启。
