摘   要
本文介绍了惠州学院智能车队的蚂蚁搬家组别参赛队伍——东江-载物在第二十一届全国大学生智能汽车竞赛的系统方案。本队在此次比赛中采用了自制车模，以主频为500MHz的RT1021_BTB单片机为核心控制器并以Thonny为开发环境，要求智能车能检测赛道边界线和网球、沙袋、小熊玩偶，并能完成出库、搬运物体、物体分类、回库等多个元素，以最短的时间完成整个比赛。本队智能车利用OpenART Plus智能视觉模块和OpenART Mini智能视觉模块采集赛道图像信息，将图像信息经算法处理进而实现电机控制；通过编码器检测智能车的实时速度，使用差速外环和角度内环的双环控制来调节电机的转速，为了提高模型车的速度和方便智能车系统中相关参数的整定，使用上位机、按键、无线串口等辅助调试工具，进行了大量硬件与软件测试。此比赛结果表明，该系统设计方案可行。

4.电机驱动模块：驱动直流电机完成智能车的加减速控制和转向控制。 
5.速度检测模块：检测反馈智能车后轮的转速，用于速度的闭环控制。 
6.感光模块：通过LED补光和感光芯片去检测赛道边界。
7.辅助调试模块：主要用于智能车系统的功能调试、赛车状态监控等方面。
第三章 智能车机械结构调整与优化
机械结构性能的好坏是关乎整个智能汽车速度最高极限的决定性因素之一。 由于模型车的自身特点，我们应当要设计好车的整体结构，在机械安装时注意一些基本的操作，保证电路板和模型车的底盘形成了较为完美的契合。在实际操作中发现，往往程序没有改动，而对机械结构进行改良之后速度又上了一个台阶，这就证明了机械结构不可忽视的重要性。

3.1摄像头 
摄像头我们采用了OpenART Plus智能视觉模块和OpenART Mini智能视觉模块，因为在智能车的竞赛中在车行驶时，我们也要确保能够采集到一幅稳定的图像，这样就需要选择动态性能较高的摄像头，最终我们采用了OpenART Plus智能视觉模块作为主车的摄像头模块，OpenART Mini智能视觉模块作为从车的摄像头模块。调整好摄像头的角度，在进行调整时我们依照的是看的距离和看到的范围是否达到了我们想要的预期效果，在摄像头的下面用一个金属的摄像头固定器配合强力胶进行固定，通过使用发现即使不在添加其他的辅助控制，摄像头也能很平稳的在车上，位置不容易移动，车在行驶的过程中也可以得到一个平稳的图像。在摄像头的安装过程中要 考虑到车的图像的前瞻距离，扫到的图像是否清晰可见。

3.2 编码器 
要使得我们的电机能够进行很好的闭环控制，我们的编码器是必不可少的， 对比市场上几款常见的编码器，我们选择了逐飞科技1024线正交编码器和普地1024正交编码器,这两款编码器易装配，坚固耐用，在安装时要特别注意一下与车轮的齿轮之间的间隔，以免太近和太远对车的整体的效果影响。为了简化结构，我们没有使用编码器自带的安装辅助工具，直接将编码器安装在车模电机上方的预留空位里，用螺栓固定在车模上。

3.3 陀螺仪 
我们在对几款常用的陀螺仪进行了对比之后还是选择了 6 轴陀螺仪Imu660RA，我们是将其固定在车模侧面的位置，这样能够使得陀螺仪更加的稳定，采集到的各种姿态信息会更加的准确与稳定。  

3.4智能车重心位置的调整 
如果车重心特别靠前，会导致车辆在行驶和搬运途中发生姿态失衡，致使车辆翻车。为了使重心后移，我们尝试了很多传感器支架的搭建方式，并且制作了合适的电路板以改善重心，使得保证结构稳定的前提下尽量减轻重量。同时，我们把电池放在摄像头模块的碳素杆上，达到了预期的效果。 
3.5电池选择与安装
我们选用的是3s锂电池，其优势在于体积小质量轻，能量密度较大，续航时间长，足以带动两个 N20 电机。而且给主控板的安装提供了足够的空间。电池安装示意图如图 3.2所示。

3.6 N20电机的安装

N20驱动电机是三轮智能小车的核心动力部件，其安装精度与齿轮啮合状态，直接决定小车的动力输出、行驶稳定性与运动控制精度。三轮小车采用单侧或双侧N20电机独立驱动结构，依靠电机齿轮配合从动齿轮传递动力，因此电机的安装位置、齿轮啮合间隙的调校是装配工作的核心环节。
在N20电机安装过程中，需重点把控主动齿轮与从动齿轮的啮合间距，同时保证电机输出轴与传动齿轮轴保持平行。若齿轮配合间隙不合理，会严重影响小车运行状态：间隙过紧会大幅增大机械传动阻力，增加N20电机运行负载，导致电机发热、转速下降，甚至出现传动卡滞、行驶迟滞的问题；间隙过松则会造成齿轮啮合不充分，小车行驶时出现齿轮打齿、抖动异响，长期运行易造成齿轮崩齿、磨损老化，降低整车传动结构的使用寿命。
为保证最佳传动效果，需采用动态调试方式完成电机安装校准。调试时为N20电机通入恒定工作电压，使其保持稳定空载转速，随后松开电机固定支架螺丝，小幅前后微调电机位置，实时观察小车传动结构的运行状态并聆听齿轮啮合声响。以齿轮转动无卡顿、无尖锐异响，运行声音纯净平稳，且小车动力输出顺畅无抖动、无迟滞为最优标准，微调完成后锁紧电机固定螺丝，完成电机定位安装。
同时，三轮小车传动结构无封闭式防护，N20电机配套传动齿轮、轴承等零部件长期裸露在外，极易吸附灰尘、碎屑等杂质，加速零件磨损。因此在电机安装完成后，需对传动齿轮、衔接轴承等部件进行清洁处理；后续使用过程中需定期检查齿轮磨损状态，及时清理杂质、更换损耗零件，保障N20电机动力传输的稳定性与传动结构的灵活性，有效避免因机械故障导致的小车行驶跑偏、动力不足等问题。

第四章 智能车硬件电路设计
硬件是基础，只有一个良好、稳定的硬件环境才能保证车能平稳快速的行驶。在符合要求的情况下，设计稳定可靠的硬件，各模块的总体设计原则是：紧凑、易于拆换、稳定可靠。考虑到芯片烧毁，方便拆卸、更换等因素，我们决定将主控板和驱动板分开设计，将电路设计得尽量安全可靠。

第五章 主、从车系统软件设计与实现
本章基于逐飞（Seekfree）RT1021 主控平台，介绍三轮福来轮红外光斑追踪小车的软件设计。系统采用「无线指令前馈 + 视觉/陀螺仪反馈校正」的分层控制架构，软件按功能模块划分为：多定时器调度、通信协议、传感器数据处理、运动控制与追踪算法四大部分。
5.1 从车软件总体架构
软件采用「中断置标志 + 主循环轮询」的软实时调度方式。四个 PIT 定时器以不同周期触发中断，中断服务函数仅置位对应标志位，具体任务在主循环中根据标志位顺序执行。这种设计保证了各控制环路的严格周期，同时避免了在中断中执行耗时操作。
系统主循环周期约 200 Hz，整体数据流如下：
主车指令(无线) ──┐
                ├─→ 前馈解算 ──┐
摄像头光斑 ───→ 视觉位置PID ──┤──→ 运动学逆解 ──→ 三路电机速度PID ──→ PWM
IMU陀螺仪 ───→ 航向角积分 ────┤
                └→ 陀螺仪角度PID┘
编码器 ──────────→ 速度反馈 ────────────────┘
5.1.1通信协议设计
无线模块采用自定义二进制帧协议，用于接收主车下发的运动指令，帧格式为：
[帧头A5 5A][帧ID 1B][数据个数N 1B][数据区 N×2B][XOR校验 1B][帧尾0D 0A]
校验算法采用逐字节异或（XOR）校验。校验初值取 msg_id ^ N，随后对每个 int16 数据的低字节、高字节依次异或，接收端重新计算并与帧内校验字节比对，不一致则判定为误帧丢弃。
组帧（发送）核心实现：
def wireless_send_int16_list(msg_id, data_list):
    n = len(data_list)
    tx_buf[0] = 0xA5; tx_buf[1] = 0x5A      # 帧头
    tx_buf[2] = msg_id & 0xFF               # 帧ID
    tx_buf[3] = n                           # 数据个数
    xor_val = msg_id ^ n                    # 校验初值

    for i, v in enumerate(data_list):       # 数据区: int16 → 2字节小端
        lo, hi = struct.pack('<h', v)
        tx_buf[4 + i*2] = lo; tx_buf[4 + i*2 + 1] = hi
        xor_val ^= lo ^ hi

    pos = 4 + n*2
    tx_buf[pos] = xor_val & 0xFF            # 校验字节
    tx_buf[pos+1] = 0x0D; tx_buf[pos+2] = 0x0A   # 帧尾
    wireless.send_bytearray(tx_buf, pos + 3)
解帧（接收）核心实现：
def wireless_recv_int16_list():
    rx_len = wireless.receive_bytearray(rx_buf, BUF_SIZE)
    if rx_len < 7: return (None, None)      # 帧太短

    # 滑动查找帧头 [0xA5, 0x5A]
    for i in range(rx_len - 1):
        if rx_buf[i] == 0xA5 and rx_buf[i+1] == 0x5A:
            head_pos = i; break
    else:
        return (None, None)

    msg_id = rx_buf[head_pos+2]; count = rx_buf[head_pos+3]
    frame_len = 4 + count*2 + 1 + 2

    # 帧尾校验
    if rx_buf[head_pos+frame_len-2] != 0x0D or rx_buf[head_pos+frame_len-1] != 0x0A:
        return (None, None)

    # XOR 校验
    xor_calc = msg_id ^ count
    for i in range(count):
        xor_calc ^= rx_buf[head_pos+4+i*2] ^ rx_buf[head_pos+4+i*2+1]
    if xor_calc != rx_buf[head_pos+4+count*2]:
        return (-1, None)                   # 校验错误

    # 解出 int16 列表
    result = [struct.unpack('<h', bytes(rx_buf[head_pos+4+i*2 : head_pos+6+i*2]))[0]
              for i in range(count)]
    return (msg_id, result)
数据字段拆装统一使用 struct 模块以小端序完成 int16/int32/float 与字节流的互转，保证跨平台数据一致性。

5.1.2 运动控制算法
5.1.2.1 PID 控制器
系统实现两类 PID 控制器，分别用于不同环节。
（1）增量式 PID（速度环），用于三路电机的速度闭环：
Δu(k) = K_p·[e(k)-e(k-1)] + K_i·e(k) + K_d·[e(k)-2e(k-1)+e(k-2)]
输出采用累加形式 u(k) = u(k-1) + Δu(k) 并做限幅，避免积分饱和：
class SpeedPID:
    def Speed_PID_Calculation(self, Target, Cnt):
        self.error[0] = Target - Cnt
        self.Iout = self.error[0] * self.Ki
        self.Pout = (self.error[0] - self.error[1]) * self.Kp
        self.Dout = (self.error[0] - 2*self.error[1] + self.error[2]) * self.Kd
        self.Out[1] = self.Pout + self.Iout + self.Dout
        self.Out[0] += self.Out[1]                 # 增量累加
        # 输出限幅
        if self.max_out is not None and self.Out[0] > self.max_out:
            self.Out[0] = self.max_out
        if self.min_out is not None and self.Out[0] < self.min_out:
            self.Out[0] = self.min_out
        self.error[2] = self.error[1]
        self.error[1] = self.error[0]
        return self.Out[0]
（2）位置式 PID（位置环/角度环），用于视觉位置闭环与航向角闭环：
u(k) = K_p·e(k) + K_i·Σe(k) + K_d·[e(k)-e(k-1)]
位置式 PID 额外引入积分限幅，限幅值取 max_out / |Kp|，防止积分项过大引起超调：
class PositionalPID:
    def Position(self, error):
        self.Error = error
        self.Iout += self.Error                    # 积分累加
        # 积分限幅: 限幅值 = 输出限幅 / |Kp|
        if self.max_out is not None and self.Kp != 0:
            max_i = self.max_out / abs(self.Kp)
            if   self.Iout >  max_i: self.Iout =  max_i
            elif self.Iout < -max_i: self.Iout = -max_i
        self.rate = self.Error - self.LastError
        self.PIDOutput = self.Kp*self.Error + self.Iout*self.Ki + self.Kd*self.rate
        # 输出限幅
        if self.max_out is not None and self.PIDOutput > self.max_out:
            self.PIDOutput = self.max_out
        if self.min_out is not None and self.PIDOutput < self.min_out:
            self.PIDOutput = self.min_out
        self.LastError = self.Error
        return self.PIDOutput
5.1.2.2 三轮全向轮运动学逆解
将机器人期望运动量（前进速度 Vx、侧移速度 Vy、自转角速度 ω）分解为三轮回转线速度：
v1 = Vx + ω·R
v2 = 0.5·Vx − (√3/2)·Vy − ω·R
v3 = 0.5·Vx + (√3/2)·Vy − ω·R
其中 R 为轮心到车体中心距离，再除以轮半径 r 得各轮角速度：
def omni_wheel_velocities(Vx, Vy, omega, R, r):
    sqrt3 = math.sqrt(3)
    v1 = Vx + omega * R
    v2 = 0.5*Vx - (sqrt3/2)*Vy - omega * R
    v3 = 0.5*Vx + (sqrt3/2)*Vy - omega * R
    w1, w2, w3 = v1/r, v2/r, v3/r
    return (v1, v2, v3), (w1, w2, w3)
主循环中三路结果经符号映射后作为三路速度 PID 的目标值：
(v1, v2, v3), _ = omni_wheel_velocities(lat, -fwd, -target_omega, ROBOT_R, WHEEL_R)
Set_Target_Speed(-v2, v1, -v3)
Motor_Speed_Ctrl()
5.1.2.3 前馈 + 反馈融合追踪算法
追踪控制采用「前馈为主、反馈校正」的复合结构。
① 前馈解算（世界坐标 → 从车坐标）。主车下发合速度幅值 V 与速度方向角 α，从车根据自身当前航向 θ_f 与固定机械安装角 PHI 进行坐标旋转：
β = α − θ_f − φ
进而分解为前进与侧移前馈分量：
fwd_feed = V·cosβ·K_FWD，　lat_feed = −V·sinβ·K_LAT
def Track_Control():
    V_mag   = WIRELESS_SPEED_MAG          # 合速度大小
    alpha   = WIRELESS_SPEED_ANGLE        # 主车速度方向角
    theta_f = GetGyroAngleZ()             # 从车当前航向

    beta = alpha - theta_f - PHI          # 坐标旋转合并
    rad  = beta * math.pi / 180.0
    fwd_feed =  V_mag * math.cos(rad) * K_FWD_FEED
    lat_feed = -V_mag * math.sin(rad) * K_LAT_FEED

    # 合成: 前馈 + 视觉反馈
    fwd = fwd_feed * K_FWD_FEED   + fwd_visual * K_FWD_VISUAL
    lat = lat_feed * K_LAT_FEED   + lat_visual * K_LAT_VISUAL

    # 软加速限幅
    speed_limit = _ramp_limit(_cam_ready_frame, SPEED_RAMP_FRAMES, SPEED_RAMP_VALUES)
    fwd = max(-speed_limit, min(speed_limit, fwd))
    lat = max(-speed_limit, min(speed_limit, lat))
② 视觉位置反馈。以目标坐标 (TARGET_X, TARGET_Y) 与光斑实测坐标 (cx, cy) 的像素误差为输入，经非线性增益整形后送入位置式 PID，输出前进/侧移修正量：
def PositionPID_Step():
    n = GetObjectCount()
    if n == 0:                                  # 丢斑
        _spot_lost_cnt += 1
        fwd_visual = 0.0; lat_visual = 0.0
    else:
        _spot_lost_cnt = 0
        err_x = shaped_gain(TARGET_X - cx, GAIN_KNOTS, GAIN_VALUES)
        err_y = shaped_gain(TARGET_Y - cy, GAIN_KNOTS, GAIN_VALUES)
        fwd_visual = pos_pid_y.Position(err_y)
        lat_visual = pos_pid_x.Position(err_x)
③ 陀螺仪角度闭环。以主车下发目标航向 θ_target 与从车积分航向的误差为输入，经非线性增益整形后送入位置式 PID 输出自转角速度 target_omega，并叠加角速度阻尼项抑制旋转过冲：
def GyroAngleControl():
    gyro_current = GetGyroAngleZ()
    gyro_err = WIRELESS_HEADING - gyro_current
    # 角度归一化到 ±180°
    while gyro_err >  180.0: gyro_err -= 360.0
    while gyro_err < -180.0: gyro_err += 360.0

    # 死区 + 非线性增益
    if abs(gyro_err) <= GYRO_DEADBAND_DEG:
        gyro_err_shaped = 0.0
    else:
        gyro_err_shaped = shaped_gain(gyro_err, GYRO_KNOTS, GYRO_GAINS)

    gyro_omega = gyro_angle_pid.Position(gyro_err_shaped)
    gyro_rate  = GetGyroZ()                     # 瞬时角速度

    target_omega  = gyro_omega * WEIGHT_GYRO_ANGLE
    target_omega -= gyro_rate * GYRO_RATE_DAMP  # 角速度阻尼
④ 丢斑降权策略：当连续 SPOT_LOST_LIMIT 帧（约 300 ms）未检测到光斑时，视觉反馈失效，切换为纯前馈控制并按 K_FWD_LOST 降权，防止目标丢失后失控：
is_lost = (_spot_lost_cnt >= SPOT_LOST_LIMIT)
if is_lost:
    fwd = fwd_feed * K_FWD_LOST
    lat = lat_feed * K_FWD_LOST
5.1.2.4 非线性增益整形算法
视觉误差直接送入 PID 存在「小误差响应不足、大误差易饱和」的问题，故引入分段非线性增益，通过 Catmull-Rom 三次样条对误差幅值插值得到增益，再乘回原误差：
e_shaped = e · gain(|e|)
Catmull-Rom 样条保证增益曲线精准过节点且一阶光滑连续，实现了「小误差高增益、大误差限幅」的软饱和特性：
def catmull_rom_general(err, knots, values):
    abs_err = abs(err)
    n = len(knots)
    if abs_err <= knots[0]:  return float(err) * values[0]    # 下限
    if abs_err >= knots[-1]: return float(err) * values[-1]   # 封顶

    for j in range(n-1):                      # 定位所在区间
        if knots[j] <= abs_err <= knots[j+1]:
            i = j; break
    y0 = values[i-1] if i > 0     else values[i]
    y1, y2 = values[i], values[i+1]
    y3 = values[i+2] if i < n-2   else values[i+1]

    t = (abs_err - knots[i]) / (knots[i+1] - knots[i])
    t2, t3 = t*t, t*t*t
    # Catmull-Rom 基函数
    c0 = -0.5*t3 +     t2 - 0.5*t
    c1 =  1.5*t3 - 2.5*t2 + 1.0
    c2 = -1.5*t3 + 2.0*t2 + 0.5*t
    c3 =  0.5*t3 - 0.5*t2
    gain = c0*y0 + c1*y1 + c2*y2 + c3*y3
    return float(err) * gain
5.1.2.5 启动软加速
为避免启动瞬间速度跳变造成冲击，通过帧号→限速值的查表线性插值实现速度软启动：
def _ramp_limit(frame, knots, values):
    if frame <= knots[0]:  return values[0]
    if frame >= knots[-1]: return values[-1]
    for i in range(len(knots)-1):
        if knots[i] <= frame <= knots[i+1]:
            span = knots[i+1] - knots[i]
            t = (frame - knots[i]) / span
            return values[i] + t * (values[i+1] - values[i])

5.2.1 系统总体设计
本工程以“中断置位 + 主循环轮询”的实时调度为核心，融合视觉、惯性、编码器与颜色传感器信息，通过双环 PID、三轮全向运动学与 α-β 预测实现了稳定的目标搬运全流程。系统模块划分清晰、层次分明，状态机与预测器具备较好的工程扩展性。
5.2.2 运动控制算法
5.2.2.1 PID 控制器
（1）增量式PID
三个轮子各自独立运行增量式 PID 速度环：误差 e0 为目标速度减实测速度，输出增量为比例、积分、微分三项之和，输出累计后限幅 ±5000，积分项单独限幅 ±100，避免积分饱和。增量式的特点是在目标切换时输出冲击小。经实测整定，三路 Kp=45.0， Ki = 14.0，Kd = 0。
ΔOut = Kp(e0 − e1) + Ki·e0 + Kd(e0 − 2e1 + e2)，　Out += ΔOut

（2）位置式PID
视觉对准采用位置式 P 控制：计算目标中心与画面中心 (145, 165) 的像素偏差，偏差进入 ±5 px 死区后输出置零；输出限幅 ±20，并将横向与纵向速度通过 atan2 合成为整车速度的大小与方向，实现平滑的横纵联动对准。

5.2.2.2 三轮全向运动学
三轮全向底盘布局为左轮 30°、右轮 150°、中轮 270°。Movement() 将整车期望速度分解到三个轮子，并叠加航向误差项与陀螺仪阻尼项（其中 2/3 为三全向轮的合成系数。）：
v_i = cos(θ_i − move_angle) × move_speed × 2/3 + z_speed − ω_z / 35
