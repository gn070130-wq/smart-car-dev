系统概述及创新点
1.1引言
全国大学生智能汽车竞赛是以智能汽车为研究对象的创意性科技竞赛，是面向大学生的一种具有探索性工程的实践活动，教育部倡导大学生参加全国大学生智能汽车竞赛，加强大学生的实践能力、创新能力、团队协作能力。它的指导思想是“立足培养，重在参与，鼓励探索，追求卓越”，其目的是促进高等学校素质教育，培养大学生的综合知识运用能力、基本工程实践能力和创新意识，激发大学生从事科学研究与探索的潜能，倡导理论联系实际、求真务实的学风和团队协作的人文精神，为优秀人才的培养挑选创造条件。
该竞赛以设计制作能够在特定的赛道上自主行驶的智能模型汽车为任务，支持大学生团队协作，综合运用学科知识，设计开发智能汽车的机械结构，硬件系统，软件系统，激发倡导理论联系实际，求真务实的学风。该竞赛涵盖自动控制、模式识别、传感技术、电子、电气、计算机、机械与汽车等多学科专业的创意性比赛。全国大学生智能汽车竞赛规则透明，评价标准客观，坚持公开、公平、公正的原则，力求向健康、普康、持续的方向发展。
本报告将详细讲解我们小组在比赛过程中的智能车系统设计方案。将从智能车的机械结构设计，硬件系统设计，软件系统设计，开发工具的制作、安装、调试以及模型车的主要技术参数几个部分展开，详细地阐述我们小组的设计思路，并对智能车的制作工程进行总结。

1.2系统概述
本系统是为第二十一届全国大学生智能汽车竞赛 “蚂蚁搬家” 组别设计的一套双车协同作业平台，由主车单元与副车单元构成，二者通过有线差分信号协同配合，共同完成物体识别、路径识别与双车跟随物体搬运任务。
主车单元：采用自主设计的三轮来福轮小车作为载体，搭载逐飞科技 OpenART plus 及 OpenART mini 视觉模块，配备 VL53L1x 测距模块、LSM6DSV16XTR 陀螺仪芯片、灰度传感器与红外发射灯板。主车负责物体识别、搬运方向判断，依靠灰度传感器完成赛道黄线识别，借助测距模块感知周边环境与两车间距，依靠陀螺仪获取自身姿态航向信息，通过红外发射灯板向副车输出跟随信标，是整套系统的决策核心。

副车单元：同样采用自主设计的三轮来福轮小车，搭载逐飞科技 openart plus 红外广角摄像头、VL53L1x 测距模块、LSM6DSV16XTR 陀螺仪芯片。副车利用测距模块获取物体与车辆距离，依靠陀螺仪采集自身姿态数据，接收主车传输的角度信号，通过红外广角摄像头识别主车的红外发射灯板，实现双车跟随，并且维持特定相对角度，配合完成物体搬运作业。
系统工作流程为：主车依靠视觉模块识别待搬运物体，利用灰度传感器检测赛道黄线，结合自身 VL53L1x 测距模块、LSM6DSV16XTR 陀螺仪获取距离与姿态信息，解算行驶路径与搬运方向；通过车载红外发射灯板输出信标，并向副车下发角度参考信号；副车通过红外广角摄像头识别主车红外灯板，结合自身 VL53L1x 测距模块获取两车间距、LSM6DSV16XTR 陀螺仪与灰度传感器获取自身运动状态，完成双车跟随控制，维持两车适宜夹角，协同执行物体搬运任务；副车将自身速度、姿态、相对距离等状态信息回传至主车，主车融合双车测距、陀螺仪姿态数据进一步优化决策逻辑，提升整套系统协同作业稳定性。

1.3硬件创新
1.3.1 一体化集成 PCB 底板设计
整车摒弃传统主控板与驱动板分离的硬件架构，采用单块 PCB 作为车模底板，将主控电路与DRV8701 驱动芯片高度集成于同一块电路板上，车模机械结构直接搭建在该 PCB 底板之上。该方案省去板间连接接插件与额外底板结构件，有效减少布线寄生干扰，最大程度降低整车自重，提升小车的机动响应性能。
1.3.2 定制化动力与驱动系统
采用 DRV8701 作为电机驱动芯片，集成功率管与驱动逻辑，简化外围功率电路；集成吸收电容与 Buck 降压电路一方面抑制电机换向带来的电压尖峰
保护功率器件与主控芯片，另一方面为车载视觉、传感器模块提供低纹波供电，保障视觉、陀螺仪、测距等感知器件稳定工作。一体化 PCB 布局实现功率回路缩短，减小功率环路寄生电感，提升电机驱动的响应速度与控制平顺性。

第二章  机械结构设计
针对第二十一届全国大学生智能汽车竞赛 “蚂蚁搬家”组别赛事规则与任务需求，本队采用双车协同方案，主、副两车均采用“三轮全向来福轮车模”硬件架构。车模底盘为三角形布局，边长约 6.7 英寸（17 cm）；主车整车高度约 34 cm，副车整车高度约 24 cm；两车前端均设置推板机构，推板尺寸为长 10 cm、宽 2 cm。
功能分工方面，主车承担全局物体识别、搬运方向判定与赛道黄线识别等核心决策任务；副车以主车为跟随目标，通过与主车维持固定相对角度，协同完成物体搬运、障碍识别与避让等作业。本章将分别对主车与副车的整体机械结构方案及各模块化设计细节进行详细阐述。

2.1车模结构设计
为适配 “蚂蚁搬家” 组别复杂的赛场环境，满足降低整车重心、感知精准识别、运动平稳可靠、抵御搬运物体干扰等核心设计需求，本队先后完成三版车模结构方案的设计与实车测试迭代。综合考量赛事尺寸约束、运动稳定性、机动灵活性等关键指标，最终确定以 PCB 板直接作为车模底板，选用三轮来福轮结构作为整车机械架构。本节将从结构方案选型、防护结构设计、轻量化减重设计三个方面，详细阐述车模的设计思路与方案取舍依据。
2.1.1结构方案选型
车模结构是小车的核心载体，其构型、尺寸及结构参数直接决定整车的运动稳定性与机动性能，是车模设计的关键环节。根据 “蚂蚁搬家” 组别官方赛事规则，单车整体外轮廓尺寸需控制在 30 cm×30 cm 以内。结合任务实际需求，本队将底盘尺寸确定为 6.7 英寸（等边三角形边长 17 cm）。
在蚂蚁搬家双车协同任务中，小车需要完成物体搬运、赛道黄线识别、障碍物避让以及坡道通行等多项作业，对整车运动速度、行驶稳定性以及环境感知能力均提出较高要求。当前竞赛主流全向车模主要分为麦克纳姆轮方案与三轮来福轮方案两类。麦克纳姆轮依靠斜向辊轮结构实现全向运动，转向灵活且无转向死角，被多数参赛队伍采用；但该方案存在明显短板，45° 斜向轮组布局会带来较大动力损耗，限制车体加速度与极速上限，同时轮组结构也会增加整车重量。而三轮来福轮车模同样具备全向运动能力，动力传递效率高，加速性能突出，高速行驶稳定性优异，还能够有效控制整车自重，更契合本项目的设计目标。
经过多轮实车对比测试验证：优化路径规划与控制算法后，三轮来福轮车模的整体任务效率优于麦克纳姆轮车模，且在高速行进、机动灵活性以及重量方面更具优势，原生动力效率高于麦克纳姆轮车模。因此本队最终选用三轮来福轮车模作为小车车模结构方案。

2.2搬运推板以及车模来福轮保护罩设计
依据蚂蚁搬家组别赛事要求，搬运车模的推杆长度不得超过 10 cm，因此本队将推板长度设定为 10 cm，在规则允许范围内最大化保障物体搬运的有效接触行程。为提升搬运作业的可靠性，推板采用向内收拢的倾斜角度设计，缩小主、副车推板之间的张开夹角，约束待搬运物体的活动空间，有效避免搬运过程中物体滑脱逃逸。

图2.1 推板3D建模图
在实车测试阶段，出现过主、副车车轮相互干涉，以及待搬运物体与车模内侧车轮剐蹭卡滞的问题。为缓解上述现象，本队设计两款车轮保护罩：一款为基础防护罩，用于规避双车交会时车轮互相干涉；另一款在基础保护罩基础上增设圆形挡板，阻挡搬运物体卷入车轮，避免物体与内侧车轮发生干涉。
保护罩集成快拆结构，有效提升整车容错能力。结构设计上完成多维度参数权衡，兼顾结构强度、轻量化指标与拆装便捷性，可满足日常调试以及赛场故障检修时快速拆装的使用需求。

2.3电机与编码器安装结构件
综合整车轻量化约束与行驶速度指标，本车选用 N20 减速电机，并搭配逐飞科技 1024 线高精度编码器，实现速度信号精准采集与运动闭环控制。本系统直接采用 PCB 作为车模底板，因此电机、编码器与 PCB 底板之间的转接连接件由团队自主设计，并通过 3D 打印完成加工制作。

3.1.1 电源管理模块
本智能车系统由一块3S锂电池进行供电。智能车系统各硬件组成部分分别需要12V、5V、3.3V以及电池的电压供电。
RT1021核心板、Open Art模块、编码器、无线串口5V的电压供电。
整车采用 3S 锂电池提供 12V 电源，为 N20 减速电机等功率器件直接供电。系统采用两级降压架构完成多路电压转换：通过 SCT2450CQSTER 开关降压芯片将电池 12V 主电压降压至 5V，为摄像头、TOF 测距模块、编码器等外设提供工作电源；再经由 RT9013 LDO 线性稳压芯片将 5V 进一步转换为 3.3V，为主控、陀螺仪等对电源纹波敏感的芯片供电。开关电源与线性稳压组合的供电方案，兼顾大功率输出能力与低纹波供电需求，保障功率器件与感知类器件同时稳定工作。

第四章 微处理器控制软件主要理论、算法说明及代码设计介绍
4.1 系统软件总体架构
本系统采用双车协同控制方案，由主车与副车两辆三全向轮智能车组成。主车承担目标搜索、目标识别、物块推送、路径阶段切换和决策调度等任务；副车根据主车下发的速度与状态命令完成相对跟随、同步对齐和“太极互换”等配合动作，并将自身测距信息回传主车。两车均采用逐飞 SmartCar 核心板，主控芯片为 NXP i.MX RT1021，运行 MicroPython 固件。
主车配置高、低两个 OpenMV 摄像头。高位摄像头负责远场 YOLO 目标检测、黄线识别、回家标志检测和推送阶段的分时避障；低位摄像头负责近场目标锁定和类别确认。主车还配置 IMU660RX、三路编码器、两路 VL53L1X ToF 和左右两路灰度传感器。副车配置一个红外跟踪 OpenMV、IMU、三路编码器和两路 ToF，两车通过无线串口交换运动指令、同步应答及距离数据。
软件采用模块化和分层化结构，自上而下划分为决策层、控制层和执行层。决策层以有限状态机为核心，融合视觉、姿态、测距、灰度和里程计信息；控制层包含视觉位置环、航向角度环和车轮速度环；执行层完成三全向轮逆运动学、电机 PWM 输出和编码器反馈。主循环使用两个硬件定时器形成 5 ms 外环和 1 ms 内环，定时器回调只置位标志，复杂处理在主循环中完成，从而降低中断占用。

4.4 PID 控制算法
系统采用由外到内的串级控制结构：视觉位置环生成平移速度，航向角度环生成旋转速度，三路车轮速度环生成电机 PWM。外环以 5 ms 周期运行，内环以 1 ms 周期运行。分层设计使目标位置误差、车体航向误差和电机速度误差分别闭合，便于独立整定和故障定位。

Visual_Inc_PIDController 在标准增量式 PID 基础上加入了工程化保护：误差在 0.5 像素内设零；按误差大小分段降低积分增益；微分增量进行一阶滤波；输出方向与误差方向相反时衰减历史输出并扩大纠正步长；安全速度上限随误差动态变化。视觉丢失超过 100 个外环周期后清空视觉控制器，超过 400 个周期时切断平移和旋转输出。

4.5 视觉感知算法
4.5.1 主车高位摄像头
高位摄像头使用 QQVGA 160×120、RGB565 图像，关闭自动白平衡、自动增益和自动曝光，固定 gain_db=10、exposure_us=2800。摄像头加载 yolo3_iou_smartcar_final_with_post_processing.tflite，可识别 6 类目标：沙包高、沙包低、玩球、熊高、熊低和红砖。前 5 类为可推送目标，红砖 ID=5 始终作为危险障碍物处理。
模式 0 执行 YOLO 目标跟踪，置信度阈值为 0.75，并对部分小目标设置面积 500 的过滤条件。上一目标框在 X 方向扩展 40 像素、Y 方向扩展 30 像素形成跟踪窗口，减少目标跳变。若红砖中心进入 X=10~125、Y=35~50 的危险区，立即发送避障方向。新目标丢失后最多保持 1 s，其中前 500 ms 继续发送旧坐标，以降低短时遮挡影响。
模式 1 使用 LAB 阈值 (43,98,−68,−18,24,93) 识别黄线，在左右 ROI 中分别提取最大有效色块，用两中心连线计算黄线角度，并在三个 HOME_ROI 中累计像素；总像素超过 430 时发送回家标志。模式 2 在黄线检测与 YOLO 避障之间按帧分时执行，既保留压线/回家信息，又降低同时运行两类重算法的计算负担。
4.5.2 主车低位摄像头
低位摄像头只在模式 0 工作，专门负责近场锁定。其 YOLO 置信度阈值为 0.70，只接受目标中心 y≥75 且包围框面积≥800 的目标，并跳过红砖。上一目标框向四周扩展 20 像素限制下一帧候选；多个候选满足条件时选择 x 坐标最小者。目标短时丢失后保留 1 s，但仅在前 50 ms 继续发送旧坐标，避免近场错误保持时间过长。
4.5.3 灰度传感器压线检测
主车左右灰度传感器连接至 B20、C20，采用数字输入，检测到引导线时输出低电平。外环按 `line_detected = (left == 0) or (right == 0)` 判断压线。该事件贯穿搜索、推送和回家流程：搜索阶段用于结束长距离搜索；推送阶段每次压线增加物块计数；回家阶段用于触发后退、沿线和横移状态。灰度方案响应直接，不占用摄像头算力，是对视觉黄线检测的独立补充。
4.5.4 副车红外双点跟踪
副车摄像头关闭自动增益、白平衡和曝光，固定 exposure_us=800，并对图像进行一次腐蚀。阈值分割后，宽高比 0.5~1.5 的色块视为单个红外点，按面积选择最大的两个；宽高比 1.5~3.0 的粘连色块按包围框的 1/4 和 3/4 位置拆分为两个近似点。两个点的中点作为跟踪坐标，连线角度作为车体相对倾角。


倾角限制在 ±60°，相邻帧跳变超过 60°时沿用上一次平滑结果。坐标和角度均使用 EMA 滤波 y=0.9x+0.1y_prev，最终打包为 [0xAA,0x01,cx,cy,θ+128,0x55] 发送给副车主控。

5.3 调试过程
调试按“底层模块—单环控制—视觉链路—双车通信—状态机—整机流程”的顺序进行，避免同时修改多个环节导致问题无法定位。每完成一个阶段均保存参数版本和串口记录，再进入下一阶段。
5.3.1 底层模块调试
逐个测试三路电机正反转和编码器计数方向，确认相同正速度目标对应正确车体运动；读取 IMU 静止值并验证 yaw 归零；用不同距离的平面目标测试两路 ToF；跨越引导线观察左右灰度电平；分别发送和接收摄像头帧及无线帧。任一传感器故障都应在进入闭环前解决。
5.3.2 PID 参数整定
车轮速度环采用先 P 后 I 的方法。先在低速下逐步增大比例系数，使轮速能够快速跟随但不产生持续振荡；再引入积分消除稳态误差，并分别校正三个电机的差异。速度环稳定后再整定航向环，使 ±90°和 180°转向无明显超调；最后整定视觉位置环，先限制最大速度，分别调节 X、Y 方向，再恢复坐标耦合。
主车高、低摄像头应分别整定，因为远场目标像素变化小、需要较大输出，而近场像素变化敏感、需要较小限幅。副车先关闭主车速度前馈，只调视觉增量 PID；视觉闭环稳定后逐步增加 FF_GAIN，再调 FF_GAIN_W 和倾角补偿，避免把机械安装误差错误地交给积分项补偿。
5.3.3 视觉算法调试
固定摄像头曝光、增益和白平衡后，在实际光照下逐类检查 YOLO 置信度、包围框面积和误检情况。高位摄像头重点调节 0.75 置信度、500 面积过滤、
跟踪窗口扩展量和红砖危险区；低位摄像头重点调节 y≥75、面积≥800 和近场保持时间。黄线阈值与 ROI 应在不同角度、不同亮度下测试，保证左右 ROI 可同时形成稳定中心。
副车红外跟踪应分别测试两个独立光点、光点粘连、单点丢失和环境反光。通过观察 raw_cx/raw_cy、平滑坐标和倾角，检查 0.9 EMA 是否在抖动和响应速度之间取得平衡。若红外点高速运动产生拖影，优先调整曝光和安装，而不是单纯增大滤波。
5.3.4 双车通信与协同调试
首先统一无线串口波特率，使用固定正负速度验证 16 位补码编码和 90°坐标旋转。然后分别测试停车、推送、同步、角度、ToF 上报和太极互换命令。同步状态下移动副车，使红外横向误差进入 ±3 像素，检查 0x07 应答能否使主车从状态 15 转到状态 16。
协同运动从低速直行开始，再测试横移、转向和推送。主车速度前馈与副车视觉补偿应同向作用；若副车反向运动，优先检查坐标旋转、摄像头偏角和误差符号。通信中断时检查前馈是否按 0.9/0.8 衰减，视觉长期丢失后是否进入停车保护。
5.3.5 状态机与整机联调
整机联调按状态逐段进行。先人工触发目标发现，验证高低摄像头切换和状态 1；再验证同步、目标类别转向和二次对齐；推送阶段分别放置红砖、普通障碍物并触发主副车 ToF，检查降速、横移和 15 cm 恢复；最后验证三次压线计数、回家转向、找线、后退 20 cm、沿线和横移 20 cm。
调试过程中应重点核查当前代码中的几个一致性问题：主副车无线波特率不一致；ToF 阈值为 10 且仍保留 220/200 注释；主车避障分支含恒为假的 `0 < 0 < dist2 < threshold`；LCD 状态字典包含 101 而实际横移状态为 102；运行状态显示块可能受 `if not car_running` 缩进影响。上述问题修正后再进行整场速度提升和重复性试验。

第六章 总结

class Inc_PIDController:
    def __init__(self, kp, ki, kd, limit=5000): 
        self.kp = kp; self.ki = ki; self.kd = kd
        self.last_error = 0; self.prev_error = 0; self.out = 0
        self.limit = limit 

    def update(self, target, current, dt):
        error = target - current
        delta_p = self.kp * (error - self.last_error)
        delta_i = self.ki * error * dt
        delta_d = self.kd * (error - 2 * self.last_error + self.prev_error) / dt
        self.out += (delta_p + delta_i + delta_d)
        self.out = max(min(self.out, self.limit), -self.limit)
        self.prev_error = self.last_error
        self.last_error = error
        return self.out

class Angle_PIDController:
    def __init__(self, kp, ki, kd, limit=5000, is_angle=True):
        self.kp = kp; self.ki = ki; self.kd = kd
        self.integral = 0; self.last_error = 0
        self.limit = limit; self.is_angle = is_angle 

    def update(self, target, current, dt):
        error = target - current
        if self.is_angle:
            if error > 180: error -= 360
            elif error < -180: error += 360
            
        if abs(error) < 0.2:
            error = 0; self.integral = 0  
            
        self.integral += error * dt
        self.integral = max(min(self.integral, 12000), -12000)
        derivative = (error - self.last_error) / dt
        output = self.kp * error + self.ki * self.integral + self.kd * derivative
        self.last_error = error
        return max(min(output, self.limit), -self.limit)

class Pos_PIDController:
    def __init__(self, kp, ki, kd, limit=5000):
        self.kp = kp; self.ki = ki; self.kd = kd
        self.integral = 0; self.last_error = 0
        self.limit = limit

    def update(self, target, current, dt):
        error = target - current
        self.integral = max(min(self.integral + error * dt, 12000), -12000)
        derivative = (error - self.last_error) / dt
        output = self.kp * error + self.ki * self.integral + self.kd * derivative
        self.last_error = error
        return max(min(output, self.limit), -self.limit)

class Encoder_Speed:
    def __init__(self, ppr, ratio, wheel_radius, alpha=0.4):
        self.ppr = ppr * 4
        self.ratio = ratio
        self.radius = wheel_radius
        self.alpha = alpha
        self.v_filt = [0.0, 0.0, 0.0]
        self.delta_pulses = [0, 0, 0] 
        self.encs = [
            encoder("C2", "C3", False, capture_div=4),
            encoder("D13", "D14",  False, capture_div=4),
            encoder("D15", "D16", False, capture_div=4)
        ]
        self.m1 = MOTOR_CONTROLLER(MOTOR_CONTROLLER.PWM_D6_DIR_D7, 13000, duty=0, invert=True)
        self.m2 = MOTOR_CONTROLLER(MOTOR_CONTROLLER.PWM_D4_DIR_D5, 13000, duty=0, invert=True)
        self.m3 = MOTOR_CONTROLLER(MOTOR_CONTROLLER.PWM_C28_DIR_C29, 13000, duty=0, invert=True)

    def set_motors_duty(self, d1, d2, d3):
        self.m1.duty(int(d1))
        self.m2.duty(int(d2))
        self.m3.duty(int(d3))

    def get_realtime_speeds(self, dt):
        for i in range(3):
            delta = self.encs[i].get()
            self.delta_pulses[i] = delta
            velocity_raw = (delta * 2 * math.pi * self.radius * 100) / (self.ppr * self.ratio * dt)
            self.v_filt[i] = (self.alpha * velocity_raw) + (1.0 - self.alpha) * self.v_filt[i]
        return self.v_filt[0], self.v_filt[1], self.v_filt[2]

class OmniOdometer:
    def __init__(self, speed_obj):
        self.speed_ctrl = speed_obj
        self.dist_x = 0.0
        self.dist_y = 0.0
        self.SQRT3 = math.sqrt(3)
        self.cm_per_pulse = (2 * math.pi * speed_obj.radius * 100) / (speed_obj.ppr * speed_obj.ratio)
        
    def update(self):
        dp1, dp2, dp3 = self.speed_ctrl.delta_pulses
        dy_pulses = (dp1 - dp2) / self.SQRT3
        dx_pulses = (2 * dp3 - dp1 - dp2) / 3.0
        self.dist_y += dy_pulses * self.cm_per_pulse
        self.dist_x += dx_pulses * self.cm_per_pulse
        return self.dist_x, self.dist_y
        
    def reset(self):
        self.dist_x = 0.0
        self.dist_y = 0.0

class OmniWheelChassis:
    def __init__(self, L=0.1):
        self.L = L
        self.SQRT3_OVER_2 = math.sqrt(3) / 2

    def inverse_kinematics(self, vx, vy, omega):
        va = -0.5 * vx + self.SQRT3_OVER_2 * vy + self.L * omega
        vb = -0.5 * vx - self.SQRT3_OVER_2 * vy + self.L * omega
        vc = vx + self.L * omega
        return va, vb, vc

class WirelessComm:
    def __init__(self, baudrate=115200):
        self.wireless = WIRELESS_UART(baudrate)
        self.dynamic_buf = [] 
        self.slave_dist1 = -1
        self.slave_dist2 = -1
        self.rx_buf = array('B', [0] * 32)

    def send_sync_data(self, cmd, vx_val, vy_val, w_val):
        vx_int = int(vx_val) & 0xFFFF
        vy_int = int(vy_val) & 0xFFFF
        w_int  = int(w_val) & 0xFFFF
        
        buf = bytearray([
            0xAA, 0x55,
            int(cmd) & 0xFF,
            (vx_int >> 8) & 0xFF, vx_int & 0xFF,
            (vy_int >> 8) & 0xFF, vy_int & 0xFF,
            (w_int >> 8) & 0xFF,  w_int & 0xFF,
            0xFF
        ])
        self.wireless.send_bytearray(buf, len(buf))

    def receive_cmd(self):
        try:
            data_len = self.wireless.receive_bytearray(self.rx_buf, 32)
            if data_len > 0:
                for i in range(data_len): self.dynamic_buf.append(self.rx_buf[i])
        except Exception:
            pass
            
        if len(self.dynamic_buf) > 60: self.dynamic_buf = self.dynamic_buf[-60:]
        last_valid_cmd = None
        while len(self.dynamic_buf) >= 8:
            if self.dynamic_buf[0] == 0xAA and self.dynamic_buf[1] == 0x55:
                if self.dynamic_buf[7] == 0xFF:
                    cmd = self.dynamic_buf[2]
                    last_valid_cmd = cmd
                    
                    if cmd == 0x0A:
                        d1_val = (self.dynamic_buf[3] << 8) | self.dynamic_buf[4]
                        d2_val = (self.dynamic_buf[5] << 8) | self.dynamic_buf[6]
                        self.slave_dist1 = d1_val if d1_val != 0xFFFF else -1
                        self.slave_dist2 = d2_val if d2_val != 0xFFFF else -1
                        
                    self.dynamic_buf = self.dynamic_buf[8:]
                else: 
                    self.dynamic_buf.pop(0) 
            else: 
                self.dynamic_buf.pop(0) 
        return last_valid_cmd

                            # 直接进入前进找线（不停止电机）
                            vx = 0.0
                            vy = 160.0                     # 前进速度（可调）
                            omega_out = 0.0
                            enable_angle_pid = True
                            # 清除积分，避免突变
                            angle_pid.integral = pid1.out = pid2.out = pid3.out = 0
                            # 摄像头设为搜索模式（保持搜索阶段）
                            camera_high.set_mode(0)
                            camera_low.set_mode(0)
                            # 重置里程计（可选，step 9 内也会重置）
                            odometer.reset()
                            robot_step = 9
                        else:
                            # 原有逻辑：停车→等待黄线→回 step 0
                            vx, vy, omega_out = 0.0, 0.0, 0.0
                            speed.set_motors_duty(0, 0, 0)
                            enable_angle_pid = True
                            angle_pid.integral = pid1.out = pid2.out = pid3.out = 0
                            camera_high.set_mode(1)
                            camera_low.set_mode(1)
                            delay_counter = 50
                            robot_step = 6               

                elif robot_step == 6:
                    vx, vy, omega_out = 0.0, 0.0, 0.0        
                    speed.set_motors_duty(0, 0, 0)      
                    
                    delay_counter -= 1
                    if (delay_counter <= 0 and line_detected) or (delay_counter < -100):
                        current_search_angle = target_yaw
                        
                        angle_pid.integral = 0
                        camera_high.set_mode(0)  
                        camera_low.set_mode(0)           
                        is_first_search = False        
                        odometer.reset() 
                        
                        delay_counter = 50  
                        robot_step = 61      

                elif robot_step == 61:
                    vx, vy, omega_out = 0.0, 0.0, 0.0
                    speed.set_motors_duty(0, 0, 0)
                    delay_counter -= 1
                    if delay_counter <= 0:
                        robot_step = 0  
                
                # 回家步骤
                elif robot_step == 70:
                    vx = ramp(vx, 0.0, ACCEL_STEP)
                    vy = ramp(vy, 0.0, ACCEL_STEP)
                    omega_out = ramp(omega_out, 0.0, ACCEL_STEP)
                    delay_counter -= 1
                    if delay_counter <= 0:
                        speed.set_motors_duty(0, 0, 0)
                        pid1.out = pid2.out = pid3.out = 0
                        
                        target_yaw = -90.0
                        enable_angle_pid = False
                        robot_step = 8

                elif robot_step == 8:
                    angle_error = target_yaw - yaw
                    if angle_error > 180.0: angle_error -= 360.0
                    elif angle_error < -180.0: angle_error += 360.0
                    
                    if abs(angle_error) > 2.0:
                        vx = ramp(vx, 0.0, ACCEL_STEP)
                        vy = ramp(vy, 0.0, ACCEL_STEP)
                        current_turn_w = turn_omega_1801 if abs(angle_error) > 40.0 else (abs(angle_error) * 3.0 + 40.0)
                        omega_out = -current_turn_w if angle_error > 0 else current_turn_w
                    else:
                        vx, vy, omega_out = 0.0, 0.0, 0.0
                        speed.set_motors_duty(0, 0, 0)
                        
                        enable_angle_pid = True
                        angle_pid.integral = pid1.out = pid2.out = pid3.out = 0
                        
                        camera_high.set_mode(2) 
                        camera_low.set_mode(1) 
                        delay_counter = 100 
                        robot_step = 9

                elif robot_step == 9:
                    camera_high.set_mode(2) 
                    camera_low.set_mode(1) 
                    vx = ramp(vx, 0.0, ACCEL_STEP)
                    vy = ramp(vy, 160.0, ACCEL_STEP) 
                    if line_detected:
                        pid1.out = pid2.out = pid3.out = 0
                        track_pid_y_high.integral = 0 
                        odometer.reset()       
                        robot_step = 91        

                elif robot_step == 91:
                    vx = ramp(vx, 0.0, ACCEL_STEP)
                    vy = ramp(vy, -100.0, ACCEL_STEP)
                    if odometer.dist_y <= -20.0:
                        odometer.reset()
                        pid1.out = pid2.out = pid3.out = 0
                        robot_step = 10        

                elif robot_step == 10:
                    vx = ramp(vx, -350.0, ACCEL_STEP)  
                    vy = ramp(vy, -5.0, ACCEL_STEP)  

                    if line_detected:
                        pid1.out = pid2.out = pid3.out = 0
                        odometer.reset()        
                        robot_step = 102        

                elif robot_step == 102:
                    vx = ramp(vx, -350.0, ACCEL_STEP)  
                    vy = ramp(vy, 0.0, ACCEL_STEP)    
                    
                    if abs(odometer.dist_x) >= 20.0:  
                        pid1.out = pid2.out = pid3.out = 0
                        robot_step = 12               

                elif robot_step == 12:
                    vx = ramp(vx, 0.0, ACCEL_STEP)
                    vy = ramp(vy, 0.0, ACCEL_STEP)
                    omega_out = ramp(omega_out, 0.0, ACCEL_STEP)
                    if abs(vx) < 0.1 and abs(vy) < 0.1 and abs(omega_out) < 0.1:
                        car_running = False

            else:
                vx, vy, omega_out = 0.0, 0.0, 0.0
                pid1.out = pid2.out = pid3.out = 0 

            if car_running:
                if enable_angle_pid:
                    omega_out = angle_pid.update(target_yaw, yaw, actual_dt_outer)

            if robot_step in [5, 8, 16]:
                active_offset = 0.0  
            elif robot_step == 1 and active_cam == 'LOW':
                active_offset = CAMERA_OFFSET_ANGLE_LOW
            else:
                active_offset = CAMERA_OFFSET_ANGLE_HIGH 

            cam_rad = math.radians(active_offset)
            real_vx = vx * math.cos(cam_rad) - vy * math.sin(cam_rad)
            real_vy = vx * math.sin(cam_rad) + vy * math.cos(cam_rad)

            if car_running:
                target1, target2, target3 = chassis.inverse_kinematics(real_vx, real_vy, omega_out)
            else:
                target1 = target2 = target3 = 0
                
            lcd_counter += 1
            if lcd_counter >= 20:
                lcd_counter = 0
                
                if not car_running:
                    run_color = 0x07E0 if car_running else 0xF800
                    lcd.str24(0, 0, "M:RUN" if car_running else "M:STOP", run_color)
                    
                    step_dict = {
                        -1: "-1: INIT", 0: "0: SRCH", 1: "1: TRACK", 15: "15: SYNC", 16: "16: TURN",
                        17: "17: ALIGN", 2: "2: PUSH", 3: "3: VIS", 4: "4: TRN-170", 5: "5: ROT", 
                        6: "6: HOLD", 61: "61: WAIT", 70: "70: PRE-T", 8: "8: E-TRN", 9: "9: WALL", 
                        91: "91: BACK", 10: "10: FLW", 101: "101: ALGN", 11: "11: PARK", 12: "12: DONE"
                    }
                    display_str = step_dict.get(robot_step, "ERR: {}".format(robot_step))
                    lcd.str16(0, 30, display_str, 0x07FF)
                    lcd.str16(0, 50, "Y:{:>4.0f} T:{:>4.0f}".format(yaw, target_yaw), 0xFFFF)
                    lcd.str16(0, 70, "Push: {}".format(pushed_blocks_count), 0x07E0)

                    if not car_running and preview_camera_mode:
                        lcd.str16(0, 90, "L:%d R:%d        " % (gray_sensor_left.value(), gray_sensor_right.value()), 0x07E0)
                    elif robot_step == -1:
                        lcd.str16(0, 90, "I-Dis:{:>4.1f}".format(odometer.dist_y), 0x07E0) 
                    elif robot_step == 0:
                        lcd.str16(0, 90, "Dist:{:>4.1f}".format(odometer.dist_y), 0x07E0) 
                    elif robot_step == 1 or robot_step == 17:
                        active_cx = CENTER_X_LOW if active_cam == 'LOW' else CENTER_X_HIGH
                        active_cy = CENTER_Y_LOW if active_cam == 'LOW' else CENTER_Y_HIGH
                        cam_label = "L" if active_cam == 'LOW' else "H"
                        lcd.str16(0, 90, "X:{:>3d}Y:{:>3d} {}".format(track_tx - active_cx, active_cy - track_ty, cam_label), 0xFFFF)
                    elif robot_step == 2:
                        obs_str = f"AVD({avoid_stage})" if avoid_stage > 0 else "CLR"
                        lcd.str16(0, 90, "{},T:{:.0f}".format(obs_str, target_yaw), 0xFFFF if avoid_stage > 0 else 0x07E0)
                    elif robot_step == 3:
                        lcd.str16(0, 90, "T-Dis:{:>4.1f}".format(target_dist - odometer.dist_y), 0xFFFF)
                    elif robot_step in [5, 16, 8]:
                        lcd.str16(0, 90, "Err:{:>5.1f}   ".format(target_yaw - yaw), 0xF800)
                    elif robot_step in [10, 101, 11]:
                        lcd.str16(0, 90, "Dist:{:>4.1f}".format(odometer.dist_y), 0x07E0)
                    elif robot_step in [4, 6, 15, 70]: 
                        lcd.str16(0, 90, "Hold:{:>3d}  ".format(delay_counter), 0xFFFF)
                    else:
                        lcd.str16(0, 90, "                ", 0x0000)
                    
                    lcd.str16(0, 115, "Vy: {:>5.1f}".format(real_vy), 0x07FF)
                    lcd.str16(0, 135, "ID: {} | Ang:{:>4.0f}".format(current_target_id, current_search_angle), 0x07E0)
                    lcd.str16(0, 155, "Dist:{:>4.1f}".format(odometer.dist_y), 0x07E0)
                    lcd.str16(0, 175, "M L:{:>4d} R:{:>4d}".format(dist1, dist2), 0xFFFF)
                    lcd.str16(0, 195, "S L:{:>4d} R:{:>4d}".format(comm.slave_dist1, comm.slave_dist2), 0xFFFF)

            comm_divider += 1
            if comm_divider >= COMM_INTERVAL:
                comm_divider = 0
                if car_running:
                    if enable_angle_pid:
                        send_cmd = CMD_ANGLE
                        send_w = int(target_yaw * 10)
                    else:
                        send_cmd = CMD_PUSH
                        send_w = int(omega_out)
                        
                    if robot_step == 15:
                        comm.send_sync_data(CMD_ASK_SYNC, vx, vy, send_w)
                    elif robot_step == 12:
                        comm.send_sync_data(CMD_STOP, vx, vy, send_w)
                    elif robot_step == 5:
                        # 🌟 在识别到黄线后转 180 度的地方（step 5），专属发送太极互换指令和角速度
                        comm.send_sync_data(CMD_TAICHI, 0, 0, int(omega_out))

                        comm.send_sync_data(send_cmd, vx, vy, send_w)
                else:
                    comm.send_sync_data(CMD_STOP, 0, 0, 0)

            if lcd_counter % 10 == 0: gc.collect()

        # ----------------- 环境感知 (30ms 非阻塞读取) -----------------
        current_time = time.ticks_ms()
        if time.ticks_diff(current_time, last_tof_time) >= 30:
            last_tof_time = current_time
            if tof1_ready:
                try:
                    if not has_data_ready or (has_data_ready and hasattr(tof1, 'data_ready') and tof1.data_ready()):
                        dist1 = tof1.read()
                except Exception:
                    pass 
            if tof2_ready:
                try:
                    if not has_data_ready or (has_data_ready and hasattr(tof2, 'data_ready') and tof2.data_ready()):
                        dist2 = tof2.read()
                except Exception:
                    pass 

        # ----------------- 内环电机闭环 (1ms) -----------------
        if speed_flag:
            speed_flag = False
            now_inner = time.ticks_us()
            actual_dt_inner = time.ticks_diff(now_inner, last_inner_time) / 1000000.0
            last_inner_time = now_inner
            if actual_dt_inner <= 0: actual_dt_inner = 0.001  

            v1, v2, v3 = speed.get_realtime_speeds(actual_dt_inner)
            odometer.update() 

            raw_pwm1 = pid1.update(target1, v1, actual_dt_inner)
            raw_pwm2 = pid2.update(target2, v2, actual_dt_inner)
            raw_pwm3 = pid3.update(target3, v3, actual_dt_inner)
            
            DEAD_ZONE = 700
            def apply_deadzone(pwm, target_v):
                if abs(target_v) < 0.1: 
                    return 0
                if target_v > 0: return pwm + DEAD_ZONE
                else: return pwm - DEAD_ZONE
                
            pwm1 = apply_deadzone(raw_pwm1, target1)
            pwm2 = apply_deadzone(raw_pwm2, target2)
            pwm3 = apply_deadzone(raw_pwm3, target3)

            speed.set_motors_duty(pwm1, pwm2, pwm3)

    except Exception as e:
        print("Error:", e)
        speed.set_motors_duty(0, 0, 0)
        time.sleep_ms(500)
