第一章 引言
1.1 竞赛任务与设计目标
全国大学生智能汽车竞赛要求参赛队在限定车模、能源与场地规则下完成自主感知、决策和运动控制，并通过技术报告准确呈现设计方案、制作过程、核心算法与技术指标。[1]
本队采用主车 newcar 与从车协同工作的双车方案，两车均使用三轮全向底盘。主车负责场地感知、目标搜索、任务决策和运动指令生成；从车接收主车运动信息，并利用双红外视觉、惯性测量和轮速反馈修正相对位置与姿态。两车共同完成目标接近、协同推送、场内换点和返航任务。
1.2 方案特点
采用三轮福来轮底盘，实现不改变车头朝向的横移、纵移与旋转组合运动。
采用角度外环与三轮速度内环的串级控制结构，分别处理航向稳定和执行器一致性。
视觉端输出物品类别与位置，底盘灰度传感器负责识别赛道黄线；主控端对感知结果进行筛选、时效判断和任务阶段匹配。
使用VL53L1X对近距离到达进行二次确认，并保留视觉判据作为传感器异常时的降级路径。
从车采用主车速度前馈与双红外相对位姿修正相结合的跟随控制，并设置通信超时、视觉丢失和惯性传感异常保护。
正式任务由状态机分解为初始化、搜索、接近、预对准、推送、返航和结束等阶段。
1.3 报告结构
第二章说明主从车总体方案，第三、四章分别介绍两车机械结构、传感器和硬件系统，第五章重点论述全向运动学、串级控制、主车任务规划与从车跟随控制，第六章记录制作调试过程，第七章分别汇总主车和从车技术参数，第八章给出结论与改进方向。附录包括主从车核心算法以及电路板原理图和PCB版图。
第二章 系统总体方案
2.1 系统组成
系统由主车任务链和从车跟随链组成。主车利用视觉、底盘灰度和TOF完成物品识别、黄线识别及到达确认，并通过状态机生成运动目标；从车接收主车的航向与平移信息，以其为前馈量，再根据双红外灯的中点、间距和连线角度修正相对位置与姿态。两车均通过航向外环和三轮轮速内环执行运动指令，从而形成感知、决策、协同和反馈闭环。

图2.1 主车系统信息链路
从车的信息链路为：主车运动指令与双红外观测进入跟随控制器，经前馈和位置修正合成为从车体速度；IMU提供航向反馈，三路编码器完成轮速闭环。主车无线指令超时后，从车立即清零运动目标并保持当前航向。

第四章 硬件系统与信息采集
4.1 主从车主控与驱动系统
主车主控负责场地感知、任务状态管理和主车闭环控制，同时向从车发送航向、平移速度及协同运动状态。从车主控负责接收主车运动目标、处理双红外视觉和惯性信息，并独立完成从车运动学与闭环控制。两车各使用三路电机驱动和三路编码器，驱动层均设置输出限幅、方向切换保护、起转补偿和零速复位。
4.2 主从车感知与协同信息
主车视觉模块识别物品类别和位置；底盘灰度传感器识别赛道黄线；车体前部TOF测量车模与物品之间的距离，用于判断是否到达物品前方，不承担避障功能。从车摄像头检测主车上的两个红外标志，根据两灯中点判断横向偏差，根据灯间距判断前后距离，根据连线角度辅助修正相对姿态。从车IMU和三路编码器分别提供航向与轮速反馈。主从信息按任务阶段融合，既保持整体协同，又保留两车各自的闭环稳定性。
第五章 控制软件与核心算法
5.1 坐标系与速度变换
绝对坐标系定义为x向右、y向前，标准极坐标逆时针为正。车体局部坐标中vx向右、vy向前。项目中的航向角顺时针为正，车头对应的绝对方向角为90°减当前航向角。对于给定绝对方向α，车体速度方向使用α与当前航向角之和完成转换。
	vₓ = V cos(α + ψ),    vᵧ = V sin(α + ψ)	（1）
5.2 三轮全向运动学
依据三个福来轮的安装角度，将车体平移速度和旋转等效线速度分解为三轮目标速度。程序预先保存1/3、√3/3和2/3常量以减少实时计算开销。
	Vₗ = ⅓vₓ + (√3⁄3)vᵧ + Vᵣ	（2）
	Vᵣ = ⅓vₓ − (√3⁄3)vᵧ + Vᵣ	（3）
	Vₘ = −⅔vₓ + Vᵣ	（4）
其中Vr为旋转分量。指定真实角速度模式下，Vr由角速度换算为rad/s后乘有效半径80 mm；兼容原角度位置环时保留既有的1/3旋转分量标定。

5.3 航向外环与轮速内环
外环使用IMU660RX的Z轴角速度积分得到航向，先扣除零偏并设置0.8 °/s小角速度死区，再以20 ms周期更新。角度误差归一化到[-180°,180°]，避免跨越0°时产生大角差。内环以10 ms周期读取三路编码器，采用增量式PID计算PWM。
Δu(k)=Kp[e(k)-e(k-1)]+Ki e(k)+Kd[e(k)-2e(k-1)+e(k-2)]	公式5
控制器包含PWM限幅、目标缓变、方向翻转时PID历史复位、编码器滤波、起转死区补偿和零速状态清理等工程保护。轮速目标按每毫米脉冲数换算：左31.274、右31.249、后30.795 pulse/mm。

5.4 主车视觉感知与信息融合
视觉端加载小型目标检测模型，识别网球、沙包、玩偶和障碍物等任务目标，并输出目标类别与位置。摄像头采用固定曝光、增益和白平衡，以降低场地光照波动造成的识别偏差。黄线识别由安装在底盘下方的灰度传感器完成，视觉模块不作为黄线判断的主要来源。
视觉结果进入主控后，先完成目标框去重、置信度筛选和数据时效判断，再根据类别、位置及任务阶段选择目标。车辆接近物品时，TOF测得的物品距离作为是否到达物品前方的确认条件；底盘灰度传感器则独立检测地面黄线，为越线判断和动作切换提供依据。TOF不参与障碍物绕行。对于短时丢帧，系统保留上一帧运动趋势并逐步降速，持续丢失后再执行横移找回或换点。
5.5 从车视觉跟随与协同控制
从车以主车下发的平移速度和目标航向作为前馈量，同时利用双红外灯图像形成相对位姿误差。两灯中点与参考中点的偏差用于横向修正，灯间距与参考间距的偏差用于前后距离修正，灯连线角度用于航向的低频校正。前馈量与视觉修正叠加后形成从车体速度，再由与主车相同的三轮运动学、航向外环和轮速内环执行。
普通跟随时，从车跟随主车平移并保持规定相对位置；协同转动时，两车围绕同一场地点运动，程序由主车当前速度反算公共角速度，再根据该圆心相对从车的位置计算从车切向速度。视觉短时丢失时，从车逐步衰减前进量并修正横向偏差；持续丢失则停车。主车有效指令超过250 ms未更新时，从车清零平移与协同转动命令、保持当前航向并执行急停。
5.6 主车状态机与双车任务协同
正式模式将任务拆分为初始化、搜索点移动、目标接近、推前预调整、协同推送、场内安全换点、返航和结束。主车负责状态切换和路径决策，并持续向从车发布当前运动目标。搜索和接近阶段，从车保持规定队形；主车利用TOF确认到达物品前方后，两车进入预对准与协同推送。需要改变推杆夹角时，两车执行共享圆心运动；推送期间主车结合障碍框、灰度黄线和超时条件决定继续、绕行或退出，从车同步跟随相应协同状态。

6.2 分阶段调试流程
1. 机械与电气检查：分别架空主车和从车，确认两车三轮正方向、编码器计数方向、急停和供电极性。
2. 单轮开环测试：使用恒定PWM验证电机接线和死区，记录起转阈值。
3. 轮速内环：先地面空载调Kp，再逐步加入Ki，观察目标脉冲、实际脉冲和PWM。
4. 航向外环：车辆静止测Z轴零漂，确认航向正方向后调节角度环输出和限幅。
5. 全向运动：分别验证绝对0°、90°、180°、-90°平移以及原地旋转。
6. 视觉与传感器：固定相机参数，逐类验证目标类别与边框位置；用不同距离的物品标定TOF到达阈值；在不同光照和离地高度下标定底盘灰度传感器的黄线识别阈值。
7. 从车跟随调试：先固定主车验证双红外中点、间距和连线角度，再低速验证前后、横向和航向修正，最后检查视觉丢失后的减速停车。
8. 主从通信与协同调试：验证普通跟随、共享圆心转动、250 ms指令超时停车及新指令恢复，再进行双车低速协同推送。
9. 状态机联调：从单个搜索点、单个物体开始，逐步增加换点、避障、推送和返航。
10. 完整赛道回归：在电池电压、光照和载荷变化下重复运行，统计成功率与平均时间。

def wrap_angle(error):
    while error > 180.0:
        error -= 360.0
    while error < -180.0:
        error += 360.0
    return error

def heading_control(target_heading, current_heading):
    error = wrap_angle(target_heading - current_heading)
    if abs(error) < heading_deadband:
        error = 0.0
    correction = k_heading * error
    return clamp(correction, -heading_limit, heading_limit)

heading_error = wrap_angle(target_heading - current_heading)
heading_cmd = clamp(k_heading * heading_error,
                    -heading_limit, heading_limit)

sqrt3_3 = 0.57735

def inverse_kinematics(vx, vy, vr):
    wheel_left  = vx / 3.0 + sqrt3_3 * vy + vr
    wheel_right = vx / 3.0 - sqrt3_3 * vy + vr
    wheel_rear  = -2.0 * vx / 3.0 + vr
    peak = max(abs(wheel_left), abs(wheel_right), abs(wheel_rear))
    if peak > max_speed:
        scale = max_speed / peak
        wheel_left *= scale
        wheel_right *= scale
        wheel_rear *= scale
    return wheel_left, wheel_right, wheel_rear

def speed_pid(target_speed, measured_speed):
    error = target_speed - measured_speed
    if abs(error) < speed_deadband:
        error = 0.0
    delta = (kp * (error - error_z1)
             + ki * error
             + kd * (error - 2 * error_z1 + error_z2))
    candidate = output_z1 + delta
    output = clamp(candidate, -pwm_limit, pwm_limit)
    if output != candidate and sign(error) == sign(candidate):
        integral_hold = True
    else:
        integral_hold = False
    error_z2, error_z1 = error_z1, error
    output_z1 = output
    return output, integral_hold

def decode_frame(frame):
    if len(frame) != FRAME_LENGTH:
        return None
    if frame[0] != 0xAA or frame[1] != 0x55:
        return None
    checksum = sum(frame[0:-1]) & 0xFF
    if checksum != frame[-1]:
        return None

    if last_sequence is not None:
        missed = (sequence - last_sequence - 1) & 0xFF
        packet_loss_count += missed
    last_sequence = sequence
    command = unpack_motion(frame[3:11])
    command.timestamp = now

def ramp_command(previous, target, dt):
    max_step = accel_limit * dt
    delta = target - previous
    if delta > max_step:
        delta = max_step
    elif delta < -max_step:
        delta = -max_step
    command = previous + delta
    return clamp(command, -speed_limit, speed_limit)

def update_master_sample(state, sample, now):
    if state is None:
        state = make_default_state()
    if sample is None:
        state.miss_count += 1
        state.valid = state.miss_count <= HOLD_LIMIT
        return state
    state.last_timestamp = now
    state.miss_count = 0
    state.valid = True
    state.raw_value = sample.sensor_sample
    state.filtered_value = low_pass(
        state.filtered_value, state.raw_value, FILTER_ALPHA)
    state.rate = difference(
        state.filtered_value, state.previous_value, state.dt)
    state.previous_value = state.filtered_value
    state.rate = clamp(state.rate, -RATE_LIMIT, RATE_LIMIT)
    state.age = 0.0
    return state

def validate_master_sample(state, now):
    state.age = max(now - state.last_timestamp, 0.0)
    if state.age > DATA_TIMEOUT:
        state.valid = False
    if abs(state.filtered_value) > SENSOR_LIMIT:
        state.valid = False
        state.fault = RANGE_FAULT
    if not finite(state.filtered_value):
        state.valid = False
        state.fault = NAN_FAULT
    return state

def fuse_master_sample(primary, backup, now):
    primary = validate(primary, now)
    backup = validate(backup, now)
    if primary.valid and backup.valid:
        value = weighted_average(
            primary.filtered_value, backup.filtered_value)
        confidence = min(primary.confidence, backup.confidence)
    elif primary.valid:
        value = primary.filtered_value
        confidence = primary.confidence * 0.8
    elif backup.valid:
        value = backup.filtered_value
        confidence = backup.confidence * 0.6
    else:
        value = 0.0
        confidence = 0.0
    return value, confidence

master_sample = update_master_sample(master_sample, sensor_sample, now)
master_sample = validate_master_sample(master_sample, now)

def update_wireless_link(state, sample, now):
    if state is None:
        state = make_default_state()
    if sample is None:
        state.miss_count += 1
        state.valid = state.miss_count <= HOLD_LIMIT
        return state
    state.last_timestamp = now
    state.miss_count = 0
    state.valid = True
    state.raw_value = sample.packet_sample
    state.filtered_value = low_pass(
        state.filtered_value, state.raw_value, FILTER_ALPHA)
    state.rate = difference(
        state.filtered_value, state.previous_value, state.dt)
    state.previous_value = state.filtered_value
    state.rate = clamp(state.rate, -RATE_LIMIT, RATE_LIMIT)
    state.age = 0.0
    return state

def validate_wireless_link(state, now):
    state.age = max(now - state.last_timestamp, 0.0)
    if state.age > DATA_TIMEOUT:
        state.valid = False
    if abs(state.filtered_value) > SENSOR_LIMIT:
        state.valid = False
        state.fault = RANGE_FAULT
    if not finite(state.filtered_value):
        state.valid = False
        state.fault = NAN_FAULT
    return state

def fuse_wireless_link(primary, backup, now):
    primary = validate(primary, now)
    backup = validate(backup, now)
    if primary.valid and backup.valid:
        value = weighted_average(

    elif primary.valid:
        value = primary.filtered_value
        confidence = primary.confidence * 0.8
    elif backup.valid:
        value = backup.filtered_value
        confidence = backup.confidence * 0.6
    else:
        value = 0.0
        confidence = 0.0
