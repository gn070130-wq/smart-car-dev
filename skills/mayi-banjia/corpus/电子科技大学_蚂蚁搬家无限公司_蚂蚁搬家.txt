摘 要
本文以第二十一届全国大学生智能车竞赛为背景，介绍了蚂蚁搬家组别智能车控制系统的软硬件及机械结构和开发流程。该比赛采用学生自主设计车模，以恩智浦NXP的RT1021芯片作为核心控制器，以OPENART MINI摄像头作为视觉采集于计算单元，要求赛车在最短时间内完成蚂蚁搬运物体的任务。整个系统涉及车模机械结构调整、传感器电路设计及信号处理、控制算法和策略优化等多个方面。赛车才用摄像头捕获实时画面利用轻量级的神经网络对物品进行识别于追踪，通过双车之间的协同控制做到不同物品（沙包、泰迪熊、网球）的搬运。
关键词：RT1021、智能车、视觉处理、神经网络、控制算法、双车协同

Abstract
This article is based on the 21st National College Students' Intelligent Vehicle Competition. It introduces the software, hardware and mechanical structure of the intelligent vehicle control system for the Ant Moving Group, as well as the development process. This competition requires students to design the vehicle model independently, using the NXP RT1021 chip as the core controller, and the OPENART MINI camera as the visual acquisition and computing unit. The racing car is required to complete the task of transporting objects for ants within the shortest time. The entire system involves multiple aspects such as the adjustment of the mechanical structure of the vehicle model, the design of sensor circuits and signal processing, control algorithms and strategy optimization. The racing car uses the camera to capture real-time images and uses a lightweight neural network to identify and track the items, and through the coordinated control between the two vehicles, different items (sand bags, teddy bears, tennis balls) can be transported.
Key words: RT1021, intelligent vehicle, visual processing, neural network, control algorithm, dual-vehicle coordination

第二章  车模整体设计思路
2.1机械设计概述
根据本届大赛组委会对蚂蚁搬家的竞赛规则，我们采取自制车模方案，并不学习沿用逐飞提供参考车模范式。从整体机械设计上迭代了三代最终完成车模的设计。车模采用PCB作为底板的设计，使用恩智浦RT1021的核心板为主控芯片，通过各项连接件连接齿轮、电机、摄像头等模块。蚂蚁组别中包含主从双车的协作，方便整体方案的统一两车的设计为对称设计，除了多加的红外发射模块以及摄像头以外车模其余部分完全相同。
2.2硬件设计概述
硬件电路是小车平稳运行的基础，在尝试多种硬件电路后，确定了一套可靠的设计方案，满足性能需求。将电路设计得尽量简洁，缩减电路板面积，尤其减轻电路重量，减轻整车重量，并且采用主驱一体的设计，将驱动电源核心板全部继承于一块总异形电路板之上。其中之一的创新点在于摒弃了经典DRV8701驱动方案，结合赛题电流小并且不需要高速转动电机特点，选用全集成H桥驱动芯片减少驱动电路占用空间。
2.3软件设计概述
完整的软件控制是小车运行的核心。蚂蚁组别对控制以及视觉部分要求更高，搬运任务整体设计复杂。其中核心传感器模块中包括TOF、IMU陀螺仪、无线串口、高精度编码器。IMU陀螺仪实时解算自身姿态角配合编码器统计的电机转动量解算蚂蚁自身的实时坐标位置方便后续路径的规划。无线串口底层采用UART协议，队内设计一套通信数据包包含数据的指令类型、数据本体、校验位，使得主从车之间通信稳定可靠。TOF传感器用于蚂蚁对砖块以及物品的避障。视觉部分采用逐飞提供的使用OPENART摄像头运行YOLOv3模型方案，实现多目标的检测与追踪。具体的目标检测方案采用yolo模型+颜色检测的方案让物品的识别又快又准。控制方案中采用从车时刻跟随主车保持相对静止状态，主车把握搬运任务中的状态机切换完成整体的搬运任务。

第四章  机械设计
全国大学生智能汽车竞赛对小车的体积和稳定性提出了极高的要求。模型车需要在  50 cm的紧凑空间内，承载驱动电机、PCB 主控板以及各类传感器。在高速转弯和急停的过程中，底盘和高空结构会受到巨大的冲击力与倾覆力矩。针对这些难题，团队独立设计并打样了一整套轻量化、高刚性的机械结构。
2.1 三轮全向轮运动学与动力学建模
为了实现在狭窄赛道内的任意方向平移与原地旋转，小车采用了呈  均匀分布的三轮全向轮底盘结构。全向轮的外圈分布着许多可以自由滚动的微型辊子，辊子的旋转轴线与主轮轴线垂直。这种几何特性使得小车可以在不改变车头朝向的前提下，完成高难度的避障平移与弧线巡线。

 软件设计
完整的软件控制是智能汽车稳定、高效运行的核心大脑。本系统以恩智浦 RT1021 芯片作为双车主控，搭载 OPENART MINI 视觉采集与计算单元。系统摒弃了传统的单车孤立运行模式，采用了“领导者-跟随者（Leader-Follower）”的主从协同控制架构。主车负责全局状态机的流转、路径规划与任务决策，从车则通过视觉追踪与前馈融合，实现高动态下的相对静止跟随。本章将从视觉图像处理、主从通信解耦、核心战术流转、底层运动学驱动及调试工具等维度进行详细阐述。
5.1 软件架构
系统的软件控制架构分为决策层、感知层与执行层三个核心维度。主控 MCU 通过定时器中断（20ms 周期）高频读取 IMU 姿态数据、TOF 测距数据与编码器速度，并通过 LPUART 异步总线与视觉协处理器、从车进行高频通信。 在全局决策上，主车由一套严密的有限状态机驱动，涵盖了开局发车、锚点导航、视觉逼近、轴权绕桩、定向盲推、极速撤退与回城等完整流程。

本系统双车通信固定采用 10 字节数据帧结构，协议字段定义严格匹配驱动代码：第0~1字节为固定双帧头（0x5A、0xA5），第2字节为协同指令码；第3~8字节分别存储16位全局X、Y坐标与车体偏航角Yaw，支持正负姿态数据解析；最后1字节为前9字节数据累加校验和，可有效过滤总线干扰、杜绝脏数据导致的协同异常，保障双车高频协同的稳定性。

5.3.2 运动学指令解耦
在“领导-跟随”架构中，系统进行了深度的系统级控制解耦： 主车仅下发车体坐标系下 X 轴和 Y 轴的前馈平移速度，而从车的偏航角（Yaw）全权交由从车自身的视觉闭环去控制。 在主车正常寻物与推物阶段，发送给从车的目标偏航角强制赋为 0。这种解耦彻底避免了主车因底盘微小滑移产生的陀螺仪偏航补偿指令与从车视觉循迹发生“指令打架”，消除了从车的超调与甩尾现象。

5.4.2 锚点导航策略
针对国赛决赛需推运 5 个不同物品的任务需求，系统摒弃了效率低下且容易受反光干扰的“原地自转扫场”方案，创新性地引入了“锚点导航法”。 在每次完成推与撤退后，主车会根据上一物品的 ID重新规划下一个最佳观测点。例如，在推完右侧的熊后，主车依靠里程计高速导航至 (X=2400.0, Y=800.0) 的黄金锚点，并在到达后将车头精准对准正前或侧边（MAIN_YAW = 90.0）再开启视觉识别。这种大范围物理坐标跑动策略，将寻物的容错率提升。
5.5 底层运动控制
5.5.1 平滑加速器
为了彻底解决长距离导航时，误差瞬间过大导致的速度阶跃及由此引发的起步弹射、从车拉扯甩尾等物理恶化现象，系统在底层控制流中加入了 S 型平滑限幅滤波器 ramp_speed。 算法在每一个 10ms 的控制周期内，对解析出的目标速度增量进行严格限幅（MAX_ACCEL = 20.0）。在起步阶段（START_Y / START_X），限幅进一步收紧至 10.0。该机制使得底盘在肉眼难以察觉的毫秒级缓冲内，平滑地推至极速。既消解了电机的瞬态过载，又保证了高速转场的分秒必争。
5.5.2 高速电机前馈与增量式 PID
为了匹配 1:50 减速比的高速电机（空载 800rpm），团队通过大量开环稳态测试，利用线性回归算法提取了极高精度的前馈动力数学模型：

由于精确的前馈模型承担了绝大部分稳态动力输出，控制系统的 PID 闭环补偿被针对性地“削弱”。在通用 pid.py 的计算中，采用了极小的比例系数作为底盘动态减震器，过滤地胶的轻微摩擦扰动；同时使用适中的积分系数充当推力储备。当车辆推重物（如沙袋）受阻时，积分项能迅速累积误差，在极短时间内爆发出庞大的破障扭矩，实现了“空跑丝滑不抖，遇阻瞬间爆发”的控制手感。
5.5.3 动态双区防碰撞避障
为应对决赛中新增的砖块障碍，主车整合了基于 DL1X 激光测距传感器的横移避障逻辑。系统依据全局坐标，将赛场划分为无缓冲防误触的“搬运区内”与长缓冲防砖块的“搬运区外”。 在推阶段，当检测到危险距离，系统会在当前的平滑前向速度上直接叠加横向避障矢量，并通过乘以 0.4 的衰减系数主动减弱推进力以防物品脱出，实现了极速推物下的流畅切线绕障。

附录 A  核心算法子程序
##A.1 通用PID控制器
适用于电机速度闭环、航向角闭环、视觉循迹等多个环节，采用积分限幅与输出限幅防止积分饱和。
```python
class PID:
    def __init__(self, kp, ki, kd, out_max=10000, out_min=-10000):
        self.kp = kp
        self.ki = ki
        self.kd = kd
        self.out_max = out_max
        self.out_min = out_min
        self.last_error = 0.0
        self.integral = 0.0
        self.output = 0.0

    def update(self, setpoint, measurement):
        error = setpoint - measurement
        self.integral += error
        # 积分限幅，防止积分饱和
        if self.integral > self.out_max:
            self.integral = self.out_max
        elif self.integral < self.out_min:
            self.integral = self.out_min

        derivative = error - self.last_error
        self.output = (self.kp * error) + (self.ki * self.integral) + (self.kd * derivative)
        self.last_error = error

        # 输出限幅
        if self.output > self.out_max:
            self.output = self.out_max
        elif self.output < self.out_min:
            self.output = self.out_min
        return self.output

    def reset(self):
        self.last_error = 0.0
        self.integral = 0.0
        self.output = 0.0
```

## A.2 三路全向底盘逆运动学

将车体坐标系下的期望速度 (v_x, v_y, ω) 解算为三个全向轮（左前 M1、右前 M2、后轮 M3）的轮速。

```python
import math

def inverse_kinematics(v_x, v_y, omega):
    """三路全向底盘逆运动学解算，输出三轮目标速度"""
    # M1 (左前轮)
    target_m1 = -0.5 * v_x - 0.866 * v_y + omega
    # M2 (右前轮)
    target_m2 = -0.5 * v_x + 0.866 * v_y + omega
    # M3 (后轮)
    target_m3 = 1.0 * v_x + omega
    return int(target_m1), int(target_m2), int(target_m3)
```

## A.3 编码器与IMU融合里程计

每 20ms 由定时器调用：将三路编码器脉冲增量换算为轮子位移，经正运动学解算得到车体坐标位移，再用 IMU 航向角旋转到全局坐标系并积分累加，得到小车在场地中的全局坐标。

```python
def update(self, d1_pulses, d2_pulses, d3_pulses, imu_yaw_deg):
    """里程计更新：编码器脉冲 + IMU 航向角 -> 全局坐标(X, Y)，单位 mm"""
    # 1. 脉冲增量 -> 轮子实际移动距离(mm)
    dist1 = d1_pulses * self.MM_PER_PULSE
    dist2 = d2_pulses * self.MM_PER_PULSE
    dist3 = d3_pulses * self.MM_PER_PULSE

    # 2. 正运动学解算：车体坐标系下的平移距离
    dx_robot = (2.0 * dist3 - dist1 - dist2) / 3.0
    dy_robot = (dist2 - dist1) / 1.73205

    # 3. 坐标旋转：用 IMU 航向角将车体位移映射到全局坐标系
    yaw_rad = math.radians(imu_yaw_deg)
    self.heading_yaw = yaw_rad
    dx_global = dx_robot * math.cos(yaw_rad) - dy_robot * math.sin(yaw_rad)
    dy_global = dx_robot * math.sin(yaw_rad) + dy_robot * math.cos(yaw_rad)

    # 4. 积分累加得到全局坐标
    self.global_x += dx_global
    self.global_y += dy_global
    return self.global_x, self.global_y
```

## A.4 相机逆透视变换IPM

利用相机内参（焦距、光心）与安装外参（高度、俯仰角），将视觉模块上报的目标底边像素坐标还原为地面上的真实物理坐标，是"像素定位 -> 全局坐标"的关键桥梁。

```python
def pixel_to_world(self, u, v):
    """像素坐标 -> 地面物理坐标（逆透视变换）
    输入：目标底边像素坐标 (u, v)
    输出：目标相对摄像头投影中心的物理距离 (X_mm, Y_mm)"""
    # 1. 归一化相机坐标
    x_cam = (u - self.cx) / self.fx
    y_cam = (v - self.cy) / self.fy

    # 2. 射线与地面平面相交计算（逆透视核心）
    sin_theta = math.sin(self.pitch_rad)
    cos_theta = math.cos(self.pitch_rad)
    denominator = sin_theta + y_cam * cos_theta
    if denominator <= 0.001:
        return 0.0, 0.0  # 目标悬空或超过地平线
    t = self.H / denominator

    # 3. 真实物理相对坐标
    x_ground = t * x_cam
    y_ground = t * (cos_theta - y_cam * sin_theta)
    return x_ground, y_ground
```

## A.5 双车无线协同通信协议

主车与从车之间通过 UART 传输 10 字节定长帧：双帧头 + 指令码 + X/Y/Yaw 三组 16 位数据 + 校验和；接收端采用有限状态机逐字节解析，并用 0xCC ACK 应答实现可靠握手，避免指令丢失。

```python
def send_cmd(self, cmd, x=0, y=0, yaw=0):
    """发送协同指令
    :param cmd: 0x01(前往坐标), 0x02(发起推球), 0x11(从机ACK到达)等
    :param x/y/yaw: 全局坐标与目标角度"""
    x_int = int(x) & 0xFFFF
    y_int = int(y) & 0xFFFF
    yaw_int = int(yaw) & 0xFFFF

    frame = bytearray(10)
    frame[0] = 0x5A  # 帧头1
    frame[1] = 0xA5  # 帧头2
    frame[2] = int(cmd) & 0xFF
    frame[3] = (x_int >> 8) & 0xFF
    frame[4] = x_int & 0xFF
    frame[5] = (y_int >> 8) & 0xFF
    frame[6] = y_int & 0xFF
    frame[7] = (yaw_int >> 8) & 0xFF
    frame[8] = yaw_int & 0xFF
    frame[9] = sum(frame[0:9]) & 0xFF  # 校验和
    self.uart.write(frame)

def update(self):
    """在主循环高频调用，用状态机解析堆叠的串口数据"""
    updated_this_loop = False
    if self.uart.any():
        data = self.uart.read()
        if data is None:
            return False
        for byte in data:
            if self.state == 0:
                if byte == 0x5A:
                    self.rx_buf[0] = byte
                    self.state = 1
                    self.rx_index = 0
            elif self.state == 1:
                if byte == 0xA5:
                    self.rx_buf[1] = byte
                    self.state = 2
                else:
                    self.state = 0
            elif self.state == 2:
                self.rx_buf[self.rx_index + 2] = byte
                self.rx_index += 1
                if self.rx_index >= 7:
                    self.state = 3
            elif self.state == 3:
                self.rx_buf[9] = byte
                check_sum = sum(self.rx_buf[:9]) & 0xFF
                if byte == check_sum:  # 校验成功，更新数据
                    self.cmd = self.rx_buf[2]
                    vx = (self.rx_buf[3] << 8) | self.rx_buf[4]
                    if vx > 32767: vx -= 65536
                    self.val_x = vx
                    vy = (self.rx_buf[5] << 8) | self.rx_buf[6]
                    if vy > 32767: vy -= 65536
                    self.val_y = vy
                    vyaw = (self.rx_buf[7] << 8) | self.rx_buf[8]
                    if vyaw > 32767: vyaw -= 65536
                    self.val_yaw = vyaw
                    self.is_updated = True
                    updated_this_loop = True
                self.state = 0
    return updated_this_loop
```

## A.6 双车编队规划

围绕目标物计算主车、从车的两个 45° 夹角预置点位（P1/P2），再依据主车当前位置就近分配角色，最后用向量叉积判定两车相对目标物的左右关系，确定各自的推球朝向角，保证两车呈"V"字形夹持推球。

```python
def plan_dual_formation(self, master_x, master_y, ball_x, ball_y, item_type):
    """双车编队规划：返回主/从车预置点与朝向角"""
    self.target_ball_x = ball_x
    self.target_ball_y = ball_y

    # 目标物到搬运区四条边界的距离
    dt = self.VZ_Y_MAX - ball_y
    db = ball_y - self.VZ_Y_MIN
    dl = ball_x - self.VZ_X_MIN
    dr = self.VZ_X_MAX - ball_x

    min_dist = min(dt, db, dl, dr)
    prep_dist = min(min_dist, 500.0)   # 预置距离不超过搬运区边界
    offset_45 = prep_dist

    # —— 核心：按目标物靠近的边界，选择两个45°夹角的预置点 ——
    if min_dist == dt:  # 目标靠近上边界：从下方推
        min_dist2 = min(db, dl, dr)
        if min_dist2 <= 400.0:
            if min_dist2 == dl:
                P1 = (ball_x, ball_y + offset_45, 180.0)
                P2 = (ball_x - min_dist2, ball_y, -90.0)
            else:
                P1 = (ball_x + min_dist2, ball_y, 90.0)
                P2 = (ball_x, ball_y + offset_45, 180.0)
        else:
            P1 = (ball_x + offset_45, ball_y + offset_45, 135.0)
            P2 = (ball_x - offset_45, ball_y + offset_45, -135.0)
    # 其余 db / dl / dr 分支与 dt 分支逻辑对称，从略

    # 根据主车当前位置就近分配预置点
    dist_M_to_P1 = abs(master_x - P1[0]) + abs(master_y - P1[1])
    dist_M_to_P2 = abs(master_x - P2[0]) + abs(master_y - P2[1])
    if dist_M_to_P1 < dist_M_to_P2:
        Master_Prep, Slave_Prep = P1, P2
    else:
        Master_Prep, Slave_Prep = P2, P1

    # 按物品类型确定推球方向（沿+X为0°，逆时针为正）
    if item_type not in ['ball', 'sandbag', 'bear']:
        item_type = 'ball'
    if item_type == 'ball':
        push_angle = 0.0
    elif item_type == 'sandbag':
        push_angle = 90.0
    elif item_type == 'bear':
        push_angle = -90.0

    # 叉积判断两车相对目标物的左右关系，确定各自朝向角（±45°）
    vec_M_x, vec_M_y = ball_x - Master_Prep[0], ball_y - Master_Prep[1]
    vec_S_x, vec_S_y = ball_x - Slave_Prep[0], ball_y - Slave_Prep[1]
    cross_product = vec_M_x * vec_S_y - vec_M_y * vec_S_x

    if cross_product > 0:
        master_f_angle = self.normalize_angle(push_angle - 45.0)
        slave_f_angle  = self.normalize_angle(push_angle + 45.0)
    else:
        master_f_angle = self.normalize_angle(push_angle + 45.0)
        slave_f_angle  = self.normalize_angle(push_angle - 45.0)

    return Master_Prep, Slave_Prep, master_f_angle, slave_f_angle, push_angle
```
