第一章 引言
1.1背景介绍
全国大学生智能汽车竞速比赛自 2006 年发起，已成为推动高等教育实践教学改革的重要赛事。由教育部高等教育司主办，该赛事连接国内众多高校，吸引大量学生参与，是展现和提升技术水平的关键平台。​
随着科技进步，比赛内容涵盖自动驾驶、智能控制等前沿技术，助力高校教育与产业接轨。第二十一届全国大学生智能车竞赛蚂蚁搬家组别，以模拟物资拾取、有序转运、任务调度为核心任务，融合小车运动控制、循迹导航、目标识别、机械结构设计与多任务逻辑规划，对软硬件协同开发、系统稳定性、实时任务调度提出较高要求。
随着智能物流、移动机器人技术快速发展，自主搬运机器人在仓储、巡检等场景得到广泛应用。蚂蚁搬家组竞赛任务高度贴合自主移动搬运机器人的工程应用场景，能够为我们搭建理论联系实际的实践平台。团队成员主修自动化、电子信息工程相关专业，系统学习过单片机开发、自动控制原理、传感器技术等课程，具备基础软硬件开发能力。为进一步走出课堂，把理论知识转化为工程实践能力，深入研究移动机器人自主搬运方案，我们选择参与蚂蚁搬家组赛事，以竞赛驱动学习，在方案设计、整车搭建、代码调试中积累项目经验，尝试解决移动机器人导航、货物搬运、任务时序控制中的实际工程难题。
1.2参赛目的
参与本次第二十一届全国大学生智能车竞赛蚂蚁搬家组，旨在将课堂所学自动控制、嵌入式开发、传感器应用、路径规划等理论知识落地实践，锻炼软硬件联合调试、问题排查的工程实操能力。通过蚂蚁搬家组物资搬运、协同调度、循迹避障的任务场景，深入学习多目标运输、任务时序规划、小车稳定控制相关技术，拓宽智能系统设计思路。在团队协作中分工配合，提升沟通协调、项目统筹与分工协作能力，学会高效推进长期科创项目。以竞赛为平台与全国各地高校选手交流学习，发现自身技术短板，积累科创竞赛经验；力争完成搬运任务目标，检验设计方案，不断优化机器人控制系统。培养严谨务实的工程思维、抗压能力与持续攻坚克难的毅力，为后续科研、工程实践打下基础。
赛事过程中，团队成员需分工协作，共同解决车模续航与竞速平衡、复杂赛道适应等难题，以此培养团队协作与项目管理能力。同时，面对新规则下的技术挑战，激励我们探索创新解决方案，锻炼创造性思维，深入了解智能汽车领域前沿技术，为未来职业发展积累经验。

第二章 在机械结构设计
智能车中的控制都是在一定的机械结构基础上实现的，因此在设计整个软件架构和算法之前一定要对整个车模的机械结构有一个感性的认识，然后建立相应的数学模型。从而再针对具体的设计方案来调整赛车的机械结构，并在实际的调试过程中不断的改进和提高。
2.1 车模选择 
此次比赛选用的赛车车模为自制车模： 两台独立搬运机器人，无物理刚性连接，依靠无线通信实现协同作业，共同推动搬运物完成任务；主体搭载车载摄像头，依靠视觉算法自主识别场内不同类型搬运目标；不以高速行驶为目标，主体运动侧重低速精准定位、姿态微调、两车动作同步，对底盘控制平顺性、位置闭环控制要求更高。

3.2电机驱动
为了保证驱动电路的性能，提高设计的可靠性，我们选用了74HC125作为缓冲隔离芯片，DRV8701E作为驱动芯片，MOS管选用的是AGM3012。
  



图3. 11电机驱动实物图（上-正面，下-反面）
缓冲电路采用 SN74HC125 四通道三态缓冲器构成电机控制信号缓冲电路。单片机输出的 PH 方向信号、EN 使能信号经过缓冲芯片整形增强后送入 DRV8701E 驱动芯片。10K 下拉电阻保证上电复位阶段控制信号稳定为低电平，避免电机误启动；电源端 C14 为去耦电容，抑制电源干扰。缓冲电路实现主控与大功率驱动电路之间信号隔离，提升 IO 驱动能力，阻隔电机侧开关噪声倒灌，保护单片机引脚，增强 PWM 信号完整性，有效防止车体运动失控。


图3. 12缓冲电路原理图（上-单驱，下-双驱）

第四章 软件系统设计
高效稳定的软件是智能车平稳快速移动的基础。电磁采集处理就成了整个软件的核心内容。经过不断的尝试和改进，本设计采用了5路电感方案，3个电感水平放置，两个电感竖直放置，并且对电感采用滑动滤波处理。在智能车的速度控制方面，本系统使用了鲁棒性很好的经典PID 控制算法，配合使用理论计算和实际参数补偿的办法，使智能车达到了运行快速而稳定的效果，在方向控制上使用了模糊pid控制，以提高稳定性和赛道的适应性。同时整个系统采用状态机的思想，构建一套高时序的操作系统，是的小车运行更加稳定。另外我们还自行设计了一套人机交互系统，用以提高调试效率以及比赛时的灵活性。
4.1软件结构框架
软件系统通过拨码开关及按键操作来切换调试模式和运行模式。

图4. 1主系统流程图

4.2 主车控制算法
4.2.1 速度环控制
主车采用增量式 PID 控制实现电机速度闭环，控制周期为 10ms（100Hz）。
控制结构：
V_out_l = PID(V_hope_l, enc_vel_l)
V_out_r = PID(V_hope_r, enc_vel_r)
V_out_m = PID(V_hope_m, enc_vel_m)
PID 参数：
KP = 100.0
KI = 0.4
KD = 0.0
输出限幅：±7000
算法特点：
采用增量式结构，输出为增量而非绝对值，天然抗积分饱和
加入低通滤波（alpha=0.84）平滑误差信号
积分项限幅 ±5000 防止溢出
4.2.2 航向锁定控制
采用 PD 控制实现航向锁定，用于搬运状态机中的转向过程。
控制结构：
turn_error = (yaw_hope - yaw_z) × 0.3
航向误差经 0.3 系数缩放后，作为前馈量叠加到各轮目标速度上：
V_hope_car1[0] = V_hope_car2[0] - turn_error
V_hope_car1[1] = V_hope_car2[1] - turn_error
V_hope_car1[2] = V_hope_car2[2] - turn_error
算法特点：
前馈补偿而非闭环 PD，结构简单响应快
系数 0.3 经实验标定，平衡转向速度与稳定性
无独立航向 PID，依赖 IMU 陀螺仪开环积分
4.2.3 运动学解算
主车为三电机差速驱动，运动学解算为：
vl = V_hope_car1[0] - turn_error
vr = V_hope_car1[1] - turn_error
vm = V_hope_car1[2] - turn_error
4.3 副车控制算法
4.3.1 三级跟随控制
副车采用视觉+前馈+反馈的三级跟随策略，实现与主车的同步运动。
（1）距离环（vcx）
基于 IR 双灯间距的横向距离控制，采用 PD 控制：
err_d = spacing_error(d_pix)
vcx = KP_D × err_d + KD_D × Δerr_d
参数：
KP_D = 30.0
KD_D = 2.0
目标间距：88~93 像素
死区：0（无死区）
最小启动速度：800
偏差放大：err_d > 0 时 × 2.0
（2）对中环（vcy）
基于 IR 双灯中心 X 坐标的纵向对中控制，采用 PD 控制：
err_cx = HOPE_CX - cx_mid
vcy = KP_CX × err_cx + KD_CX × Δerr_cx
参数：
KP_CX = 40.0
KD_CX = 2.0
目标 cx：156（画面中心偏左）
死区：4 像素
最小启动速度：800
（3）航向环（vz）
基于主车无线发送的 yaw_target 的航向锁定控制，采用 PD 控制：
vz = AnglePID(yaw_target, yaw_z)
参数：
KP_Y = 50.0
KD_Y = 8.0
死区：2°
输出限幅：±7000
4.3.2 运动学解算
副车为全向轮驱动，运动学解算为：
vl = K3 × vcx + √3/3 × vcy - K3 × vz
vr = K3 × vcx - √3/3 × vcy - K3 × vz
vm = -2 × K3 × vcx - K3 × vz
其中 K3 = 1/3，√3/3 ≈ 0.577。
4.3.3 跟随状态切换
副车根据主车速度指令与视觉检测状态切换跟随模式：
xuan_flag=0（单灯/仅速度跟随）：
set_body_velocity(vcx, 0, 0)
仅启用距离环，丢弃对中环和航向环
xuan_flag=1（双灯/全向跟随）：
set_body_velocity_xuan(vcx, vcy, vz)
启用全部三级控制
4.3.4 数据丢失保护
副车设置了数据丢失超时保护机制：
视觉丢失 400ms → 视觉控制失效，强制停车
无线丢失 300ms → 航向控制失效，强制停车

本次智能车竞赛让团队深刻体会到科创项目中精益求精、细节制胜的重要意义。未来，团队将认真总结本次参赛经验，补齐技术短板，持续深耕多车协同智能控制技术，不断打磨作品性能，提升项目专业性与稳定性，在后续科创竞赛与工程实践中争取更好的成绩。

# ---- 摄像头 & 无线轮询 ----
poll_uart_cam()
wl_buf = array('B', [0]*32)
wl_len = wireless.receive_bytearray(wl_buf, 32)
if wl_len:
    parse_wireless(wl_buf, wl_len)
if l_v_target==1 and r_v_target==1 and m_v_target==1:
    xuan_flag=1
else: xuan_flag=0    

# ---- 时间计数 ----
cam_lost_ms += 5
cam_link_ms += 5
wl_lost_ms += 5

cam_ok = (cam_qual >= QUAL_VALID and cam_lost_ms < CAM_LOST_MS)
wl_ok = (wl_lost_ms < WL_LOST_MS)

# ---- 计算误差 ----
err_d_xuan = spacing_error(cam_d) if cam_ok else 0
if err_d_xuan >0: err_d_xuan *=2.0
err_cx_xuan = long_error(cam_cx) if cam_ok else 0

vcx = 0.0
vcy_cam = 0.0
if cam_ok and xuan_flag==1:
    if err_d_xuan != 0:
        vcx = SIGN_D * (KP_D * err_d_xuan + KD_D * (err_d_xuan - err_d_last_xuan))
        err_d_last_xuan = err_d_xuan
        vcx = ensure_min_move(vcx, MIN_VCX)
        if vcx > 7000: vcx = 7000
        elif vcx < -7000: vcx = -7000
    else:
        err_d_last_xuan = 0.0
    if err_cx_xuan != 0:
        vcy_cam = SIGN_Y * (KP_CX * err_cx_xuan + KD_CX * (err_cx_xuan - err_cx_last_xuan))
        err_cx_last_xuan = err_cx_xuan
        vcy_cam = ensure_min_move(vcy_cam, MIN_VCY)
        if vcy_cam > 7000: vcy_cam = 7000
        elif vcy_cam < -7000: vcy_cam = -7000
    else:
        err_cx_last_xuan = 0.0
else:
    err_d_last_xuan = 0.0
    err_cx_last_xuan = 0.0

vz = 0.0
if wl_ok and cam_ok:
    err_y = yaw_pid._angle_diff(yaw_target, yaw_z)
    if abs(err_y) < YAW_FOLLOW_DEADBAND:           
        vz = 0.0
        yaw_pid.reset()
    else:
        vz = yaw_pid.update(yaw_z, yaw_target)
else:
    yaw_pid.reset()
      
vcy = vcy_cam

# ---- 执行 ----    
if start_key and (cam_ok or wl_ok):
    if xuan_flag:
        set_body_velocity_xuan(vcx, vcy, vz)
    else:
        set_body_velocity(vcx, 0, 0)       
else:
motor(0,0,0)
