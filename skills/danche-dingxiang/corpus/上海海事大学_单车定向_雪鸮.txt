第一章  总体设计
1.1  总体方案概要
第二十一届全国大学生智能汽车竞赛单车定向组要求参赛车模在完全依靠转向机构辅助平衡（取消动量轮）的前提下，完成直线竞速、八字慢速、颠簸路段以及电磁门无线定向等四个科目的比赛。本队采用竞赛指定
N1
单车车模，以英飞凌 TC377TP 三核微控制器（TriCore 3×300 MHz）为整车控制核心，构建了“感知—控制—执行—通信”完整的闭环系统。
感知层：采用
IMU660RA六轴
轴惯性测量单元（SPI）采集
角速度和角加速度数据
；采用磁编码器（menc15a，SPI）测量后轮电机机械角度，换算得到车速与行驶里程，为惯性导航提供航位推算输入；GPS 模块预留用于室外科目的大范围定向。
控制层：车模平衡与转向采用“
导航输出
环—横滚角度环—横滚角速度环”三环串级 PID 控制，横滚角速度环的输出经角度映射后驱动前轮转向舵机，实现完全依靠转向辅助的动态平衡；后轮无刷电机采用 FOC（磁场定向控制）驱动，速度环采用 LADRC（线性自抗扰控制）以提高抗扰性能。
导航层：基于编码器里程与 IMU 航向角进行航位推算，支持推车录制路径、路径滤波与路径生成（U 型弯、8 字、
手推
路径），采用 Stanley 控制器完成路径跟踪，并支持科目内变速路段的速度规划。
通信与调试：CRSF 遥控器（UART9）、自定义通信协议（UART9）、ESP01S WiFi 与匿名上位机、VOFA+ 配合，实现参数在线读写与波形监视，配合速度分段的 PID 参数线性插值，实现全速域稳定控制。
1.2  系统总体架构
系统总体架构如图 1-1 所示。系统围绕 TC377 三核主控分为四层：人机交互层（按键、IPS114 屏幕、蜂鸣器）、传感器层（GPS、IMU、编码器）、通信层（调试串口、ESP01S 无线模块、上位机）与执行器层（转向舵机、无刷电机）。TC377 的三个核分别承担实时控制、惯性导航和通信/UI 任务，核间通过共享全局变量交换数据。

第二章  机械设计
2.1  车模机械结构
单车定向组采用竞赛指定
N1
单车车模：前轮通过转向机构与舵机相连，舵机转动带动转向把手/前叉改变前轮方向，是整车平衡与转向控制的唯一执行机构；后轮由无刷电机直驱，承担行进动力。整车采用轻量化金属车架，电池与主控电路板布置于车架中部，在保证强度的同时尽量降低整车重心。

2.2  重心与轻量化设计
重心高度直接影响平衡控制的难度：重心越低，相同倾角下重力产生的倾倒力矩越小，平衡控制所需的修正量越小，系统响应更平缓、更稳定。为此，我们将电池、主控板等较重部件布置在车架中部偏下位置，并选用小型化电池，尽量压低整车重心。
从惯性角度看，车模质量越小，转动惯量越小，转向与姿态调整的响应越快，控制系统对执行器的要求越低。
我们对非承重结构件进行了减重处理，在保证强度的前提下简化连接件、删减非必要零件，实现轻量化设计
。

第三章  电路设计
3.1  电源系统设计
整车采用电池组供电，通过多路 DC-DC 降压电路提供各模块所需电压：后轮驱动与舵机使用较高电压（12 V/7.4 V），主控与外设使用 5 V/3.3 V，MCU 内核使用 1.25 V。电源输入端设计有防反接保护、保险丝过流保护与输入滤波；各电压域均配置去耦电容，保证供电稳定；并通过软件监控多路电压与总电流，实现欠压、过流保护。电源输入电路与MCU 电源电路见附录 B 图 B-5、图 B-3。
3.2  电机驱动电路设计
后轮无刷电机采用三相 FOC 驱动：由 FD6288Q 三相驱动器配合功率 MOSFET 构成三相逆变桥（附录 B 图 B-10），相电流通过采样电阻经 ADC 采集（图 B-11），电机机械角由磁编码器读取（图 B-9）。驱动电路设置了过流保护阈值，软件中同时对过流、过速进行保护。转向舵机由 7.4 V 电源供电（图 B-7），PWM 频率 300 Hz，输出角由控制环经角度映射函数换算为占空比。
3.3  传感器与通信接口电路
IMU660RA
通过 SPI 与主控连接；磁编码器通过 SPI4 读取；GPS 通过 UART2 接入；CRSF 遥控与自定义通信协议复用 UART9；ESP01S WiFi 通过 UART0/UART5 接入，用于无线参数调试；IPS114 屏幕通过 SPI1 显示状态；按键与蜂鸣器电路见附录 B 图 B-13。

控制调度采用时间片轮询方式（Scheduler_CPU1/CPU2 与 ControllerUpdate），每个任务记录上次执行时间，按周期判断是否执行；实时性要求最高的横滚角速度环在 1 ms 中断驱动下执行。
4.2  平衡与转向控制算法
单车依靠转向辅助平衡：当车体向一侧倾倒（横滚角变化）时，控制器控制舵机使前轮向倾倒方向转向，利用轮胎侧偏力与离心力将车体“扶正”。系统采用三环串级 PID 控制结构（图 4-1）：
（1）外环（航向/位置环）：根据导航或遥控指令给出目标横滚角（压弯角），并经低通滤波平滑，即 Set_Roll_Angle = LPF(Yaw_error)；
（2）中环（横滚角度环）：以 IMU 横滚角为反馈，输出目标横滚角速度；
（3）内环（横滚角速度环）：以陀螺仪横滚角速度为反馈，输出舵机转角指令，最终经Motorcycle_ServoAngleMapping() 映射为 300 Hz PWM 占空比输出到舵机。
图 4-1  三环串级 PID 控制框图
PID 控制库（PIDLib.c）实现了位置式与增量式 PID，并支持积分分离、不完全微分、输出死区、前馈增益（kff）与误差比例增益（k）等改进方案；控制周期 1 ms。为适应不同车速下的控制特性，PID 参数按速度 1.5~4.0 m/s 六档保存，运行时通过线性插值（LinearInterp）实时计算当前速度下的参数。
4.3  惯性导航与路径跟踪
（1）航位推算：以编码器里程（后轮线速度 v）与 IMU 航向角 yaw 进行二维航位推算：x(k+1)=x(k)+v·cos(yaw)·dt，y(k+1)=y(k)+v·sin(yaw)·dt。
推车录制时将路径点保存为地图，发车后车辆依据同样的航位推算实时定位，依次跟踪存储的路径点。
（2）路径生成与滤波：支持 U 型弯（科目一）、8 字/圆内 8 字（科目二）、手写路径（科目二备选）等路径生成方式；录制完成后对路径进行等间距重采样与平滑滤波，并计算各点航向角与曲率。
（3）Stanley 路径跟踪：以最近路径点与预瞄点确定横向误差 e 与航向误差 yaw_e，转角指令 delta = yaw_e + atan(k·e/v)，并加入曲率前馈 kff·
κ
 与转角低通滤波；速度按路径曲率自动规划（曲率越大速度越低），支持减速/变速路段。导航流程由状态机管理：IDLE→DATA_COLLECTING→DATA_COLLECTED→（SUBJECT_1/2_DATA_GET）→RUNNING→STOPPED。
4.4  电机驱动算法（FOC/LADRC）
后轮无刷电机采用 FOC 控制：电流环（Id/Iq）采用 PID，速度环采用 LADRC（线性自抗扰控制），通过线性扩张状态观测器（LESO）估计并补偿总扰动，控制带宽 wc 与观测器带宽 wo 均可在线整定。控制流程为：电流采样（Clarke 变换）→ Park 变换 →电流环 PID/LADRC → 逆 Park 变换 → SVPWM 输出三相占空比；并带有过流、过速保护与低通滤波。
4.5  通信与人机交互
CRSF 模块解析 ExpressLRS/Crossfire 遥控协议（UART9，420 000 bps），将摇杆映射为速度与航向给定，支持连接状态检测与失联保护（失联时关闭使能并蜂鸣报警）。自定义通信协议采用“0xAA 0x55 + DeviceID + Length + CMD + Data + Checksum”帧格式（UART9，2 000 000 bps），用于上位机指令下发与 IMU 偏航角、车速等数据回传。
匿名上位机（AnoPTv8）支持参数在线读写（0xE0/0xE1）与 20 Hz 遥测波形（0xF1~0xF4：PID 内部状态、控制目标、当前生效参数、Stanley 导航遥测），经 ESP01S WiFi（UDP）无
线传输，实现调参无需接线。VOFA+（JustFloat 协议）用于调试串口波形监视。IPS114 屏幕提供状态与菜单显示，按键用于科目切换、路径录制与系统使能控制，蜂鸣器提供状态提示。
第五章  开发工具与调试过程
5.1  开发工具
软件使用 AURIX Development Studio v1.10.2（ADS）开发，基于逐飞 TC377 开源库与英飞凌 iLLD；原理图与 PCB 使用嘉立创 EDA 绘制；调试使用匿名上位机（参数在线调参、波形监视）、VOFA+ 与 CRSF 遥控器。
5.2  调试过程
按照“先感知、再执行、后控制、最后导航”的顺序分模块调试：
（1）IMU 与编码器：验证
IMU660RA
姿态解算方向与量程，标定横滚零点（Zero_Roll_Angle），验证磁编码器角度连续性与方向；
（2）FOC 电机：开环→电流环→速度环，整定 LADRC 带宽参数；
（3）舵机映射：标定舵机 PWM 中值与角度映射关系（银车/绿车两套参数）；
（4）平衡控制：低速整定横滚角度环/角速度环 PID，再逐步提高速度，配合速度分段线性插值参数，使车模在 1.5~4.0 m/s 全速域稳定；
（5）转向与科目：八字慢速整定偏航角速度环，直线竞速整定压弯参数；
（6）导航：推车录制→路径滤波→Stanley 跟踪→变速路段，通过匿名上位机波形在线调参。
全部控制参数通过匿名上位机在线读写并保存至 Flash（LoadParameter/SaveParameter），支持多参数分组，方便不同科目与不同车况快速切换。

// ================= PidInit =================
void PidInit(PidStruct *pid, PidImprove *imp, PidParam *k, PidMax *max, PidValue *val)
{
    pid-&gt;pidParam = k;
    pid-&gt;pidMax = max;
    pid-&gt;pidVallue = val;
    pid-&gt;pidImprove = imp;
 
    pid-&gt;out_p = 0;
    pid-&gt;out_i = 0;
    pid-&gt;out_d = 0;
    pid-&gt;out = 0;
}
 
// ================= PID_Clear =================
void PID_Clear(PidStruct *pid)
{
    pid-&gt;out_p = 0;
    pid-&gt;out_i = 0;
    pid-&gt;out_d = 0;
    pid-&gt;out = 0;
    pid-&gt;pidVallue-&gt;integrator = 0;
    pid-&gt;pidVallue-&gt;last_error = 0;
    pid-&gt;pidVallue-&gt;last_last_error = 0;
    pid-&gt;pidVallue-&gt;last_derivative = 0;
    pid-&gt;pidVallue-&gt;last_get = 0;
}
 
// ================= PidLocCtrl_Classic =================
float PidLocCtrl_Classic(PidStruct *pid, float get, float set)
{
    float error = set - get;
    float effective_kp = pid-&gt;pidParam-&gt;kp + pid-&gt;pidParam-&gt;k * fabs(error); // Kp = K + k*|error|
    /* 累积误差 */
    pid-&gt;pidVallue-&gt;integrator += error;
 
    /* 误差限幅 */
    pid-&gt;pidVallue-&gt;integrator = constrain_float(pid-&gt;pidVallue-&gt;integrator, -pid-&gt;pidMax-&gt;iMax, pid-&gt;pidMax-&gt;iMax);
 
    pid-&gt;out_p = constrain_float((effective_kp * error),
                                 pid-&gt;pidMax-&gt;min, pid-&gt;pidMax-&gt;max);
    pid-&gt;out_i = constrain_float(((pid-&gt;pidParam-&gt;ki) * pid-&gt;pidVallue-&gt;integrator * pid-&gt;pidParam-&gt;dt),
                                 pid-&gt;pidMax-&gt;min, pid-&gt;pidMax-&gt;max);
    pid-&gt;out_d = constrain_float(((pid-&gt;pidParam-&gt;kd) * (error - pid-&gt;pidVallue-&gt;last_error) / pid-&gt;pidParam-&gt;dt),
                                 pid-&gt;pidMax-&gt;min, pid-&gt;pidMax-&gt;max);
    //    pid-&gt;out_d = constrain_float(((float)*(pid-&gt;kd)/100 * (-get + pid-&gt;last_get)), -pid-&gt;imax, pid-&gt;imax);// 微分冲击消除
 
    pid-&gt;pidVallue-&gt;last_get = get;
    pid-&gt;pidVallue-&gt;last_error = error;
 
    pid-&gt;out = constrain_float(pid-&gt;out_p + pid-&gt;out_i + pid-&gt;out_d + pid-&gt;pidParam-&gt;kff * set,
                               pid-&gt;pidMax-&gt;min, pid-&gt;pidMax-&gt;max);
 
    return pid-&gt;out;
}
 
// ================= PidIncCtrl_Classic =================
float PidIncCtrl_Classic(PidStruct *pid, float get, float set)
{
    float error = set - get;
    float effective_kp = pid-&gt;pidParam-&gt;kp + pid-&gt;pidParam-&gt;k * fabs(error); // Kp = K + k*|error|
 
    /* 增量式PID计算: delta = Kp*(e-e1) + Ki*e + Kd*(e-2*e1+e2) */
    pid-&gt;out_p = constrain_float((effective_kp * (error - pid-&gt;pidVallue-&gt;last_error)),
                                 pid-&gt;pidMax-&gt;min, pid-&gt;pidMax-&gt;max);
    pid-&gt;out_i = constrain_float(((pid-&gt;pidParam-&gt;ki) * error * pid-&gt;pidParam-&gt;dt),
                                 pid-&gt;pidMax-&gt;min, pid-&gt;pidMax-&gt;max);
    pid-&gt;out_d = constrain_float(((pid-&gt;pidParam-&gt;kd) * (error - 2.0f * pid-&gt;pidVallue-&gt;last_error + pid-&gt;pidVallue-&gt;last_last_error) / pid-&gt;pidParam-&gt;dt),
                                 pid-&gt;pidMax-&gt;min, pid-&gt;pidMax-&gt;max);
 
    /* 输出累加 */
    pid-&gt;out = constrain_float(pid-&gt;out + pid-&gt;out_p + pid-&gt;out_i + pid-&gt;out_d + pid-&gt;pidParam-&gt;kff * set,
                               pid-&gt;pidMax-&gt;min, pid-&gt;pidMax-&gt;max);
 
    /* 更新误差历史 */
    pid-&gt;pidVallue-&gt;last_last_error = pid-&gt;pidVallue-&gt;last_error;
    pid-&gt;pidVallue-&gt;last_error = error;
    pid-&gt;pidVallue-&gt;last_get = get;
 
    return pid-&gt;out;
}
 
// ================= PidLocCtrl_Improve =================
float PidLocCtrl_Improve(PidStruct *pid, float get, float set)
{
    float error = set - get;
    float effective_kp = pid-&gt;pidParam-&gt;kp + pid-&gt;pidParam-&gt;k * fabs(error); // Kp = K + k*|error|
    pid-&gt;out_p = constrain_float((effective_kp * error),
                                 pid-&gt;pidMax-&gt;min, pid-&gt;pidMax-&gt;max);
    if (fabs(error) &gt; pid-&gt;pidImprove-&gt;beta) // 误差大于一定范围的时候不进行积分，积分分离
    {
        pid-&gt;out_i = 0;
 
        pid-&gt;pidVallue-&gt;integrator = 0;
    }
    else
    {
        /* 累积误差 */
        if (fabs(error) &lt; pid-&gt;pidImprove-&gt;deadband) // 误差小于一定范围的时候对误差进行增益
        {
            pid-&gt;pidVallue-&gt;integrator += pid-&gt;pidParam-&gt;dt * error * pid-&gt;pidImprove-&gt;K;
        }
        else
        {
            pid-&gt;pidVallue-&gt;integrator += pid-&gt;pidParam-&gt;dt * error;
        }
 
        /* 误差限幅 */
        pid-&gt;pidVallue-&gt;integrator = constrain_float(pid-&gt;pidVallue-&gt;integrator, -pid-&gt;pidMax-&gt;iMax, pid-&gt;pidMax-&gt;iMax);
 
        pid-&gt;out_i = constrain_float(((pid-&gt;pidParam-&gt;ki) * pid-&gt;pidVallue-&gt;integrator),
                                     pid-&gt;pidMax-&gt;min, pid-&gt;pidMax-&gt;max);
    }
    if (pid-&gt;pidParam-&gt;dt &lt;= 0.000000000001f)
    {
        pid-&gt;pidParam-&gt;dt = 0.000000000001f;
    }
    pid-&gt;out_d = constrain_float(((pid-&gt;pidParam-&gt;kd) * (error - pid-&gt;pidVallue-&gt;last_error) / pid-&gt;pidParam-&gt;dt),
                                 pid-&gt;pidMax-&gt;min, pid-&gt;pidMax-&gt;max);
 
    pid-&gt;out_d = pid-&gt;pidVallue-&gt;last_derivative + (pid-&gt;pidImprove-&gt;gamma) * (pid-&gt;out_d - pid-&gt;pidVallue-&gt;last_derivative); // 不完全微分
 
    // if (fabs(error) &lt; pid-&gt;pidImprove-&gt;deadband) // 误差小于一定范围的时候对误差进行增益
    // {
    //     pid-&gt;out_p *= pid-&gt;pidImprove-&gt;K;
    //     pid-&gt;out_i *= pid-&gt;pidImprove-&gt;K;
    //     pid-&gt;out_d *= pid-&gt;pidImprove-&gt;K;
    // }
 
    pid-&gt;pidVallue-&gt;last_get = get;
    pid-&gt;pidVallue-&gt;last_error = error;
    pid-&gt;pidVallue-&gt;last_derivative = pid-&gt;out_d;
 
    pid-&gt;out = constrain_float(pid-&gt;out_p + pid-&gt;out_i + pid-&gt;out_d,
                               pid-&gt;pidMax-&gt;min, pid-&gt;pidMax-&gt;max);
 
    return pid-&gt;out;
