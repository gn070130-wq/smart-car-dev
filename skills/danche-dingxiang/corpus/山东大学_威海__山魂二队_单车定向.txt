摘要
本队以 N1 车模为平台，设计并实现了用于第二十一届全国大学生智能汽车竞赛单车定向组的自平衡智能单车。整车采用 TC377 与 CYT2BL3 双 MCU 架构：TC377 完成姿态解算、速度位置估计与运动控制决策，CYT2BL3 完成无刷电机驱动与转速反馈。软件采用前后台多任务架构与定时器中断调度；姿态由 IMU660RB 经陀螺 IIR 滤波、加速度一维卡尔曼滤波与四元数扩展卡尔曼滤波（EKF）融合获得；位置通过轮速与航向航位推算；控制采用“角度环＋角速度环”串级平衡 PID 与增量式速度 PID，并依据 B 样条路径与纯跟踪预瞄实现定向导航。经反复调试与参数整定，模型车稳定完成了单车定向赛项规定任务。
关键词：
自平衡单车；四元数EKF；串级PID；定向导航

Abstract
This report presents the design and implementation of a self-balancing intelligent bicycle for the Directional Riding group of the 21st National Undergraduate Intelligent Car Race, based on the N1 car model platform. The vehicle adopts a dual-MCU architecture consisting of a TC377 main controller and a CYT2BL3 driver chip: the TC377 performs attitude estimation, velocity and position estimation, and motion control decisions, while the CYT2BL3 drives the brushless motor and feeds back its speed. The software adopts a foreground/background multi-task architecture with timer interrupt scheduling. Attitude is obtained by fusing the IMU660RB gyroscope and accelerometer data through IIR filtering, one-dimensional Kalman filtering and a quaternion extended Kalman filter (EKF). The position is derived by dead reckoning from wheel speed and heading. The control strategy combines a cascade balance PID (angle loop plus angular velocity loop) with an incremental speed PID, and realizes directional navigation based on B-spline path planning and pure pursuit. After repeated debugging and parameter tuning, the model car stably completes the prescribed tasks of the directional riding event.
Key words: 
self-balancing bicycle; quaternion EKF; cascade PID; directional navigation

第五章 微处理器控制软件设计
5.1 软件总体框架
控制软件采用前后台裸机架构，基于 TC377 三核处理器与定时器中断实现实时调度，整体分为驱动层、算法层与应用层：驱动层完成 IMU660RB 采集、无刷驱动板串口通信（UART3，460800bps）、舵机 PWM 及按键/蜂鸣器/屏幕/Flash 等外设的初始化与收发；算法层完成传感器滤波与姿态解算（IIR、一维卡尔曼、四元数 EKF）、速度与位置估计、平衡/速度/方向串级 PID 控制及 B 样条路径规划[4]与纯跟踪转向误差计算；应用层完成三核任务调度、科目状态机管理与菜单调试界面。任务调度上，CPU0 运行主循环与菜单，CPU2 按科目切换调度导航与状态机，PIT 中断按 1ms/5ms 周期执行姿态解算、平衡控制、速度环与位置递推，UART 中断完成驱动板通信，保证控制实时性。

图 5.1 软件总体框架图
5.2 传感器数据处理
5.2.1 轮速数据采集
整车速度反馈由无刷驱动板（CYT2BL3）通过 UART3 串口回传，通信波特率 460800bps，采用 7 字节自定义帧（帧头 0xA5、命令码、数据、校验和＝前 6 字节累加）。主控下发 0x01 命令设置左右轮占空比（范围 −10000～10000），下发 0x02 命令查询实时转速，驱动板以 0x02 应答帧回传左右轮转速（int16 大端）。接收中断中逐字节组帧校验，解析出的转速存入 motor_value 结构体。软件以 5ms 周期调用 Calculate_Encoder()：取负号得到后轮转速，经二阶 IIR 低通滤波（截止 25Hz）后按 V＝N/60×π×D×k（D＝0.07m 轮径，k 为校正系数）换算为实际车速（m/s），作为速度环反馈量；上电阶段每 2s 查询一次转速直至通信建立。
关键代码（核心函数）：
/* Encorder.c — Calculate_Encoder() 速度换算核心 */
void Calculate_Encoder(void)
{
    Back_Wheel.new_encoder = -motor_value.receive_left_speed_data;      /* 驱动板转速 */
    Back_Wheel.new_encoder = LowPassFilterIIR2nd_all(&filter,
                              Back_Wheel.new_encoder, 200, 25);          /* IIR(25Hz) */
    /* 转速(rpm) → 车速(m/s)：V = N/60 * π * D * k */
    Back_Wheel.Velocity = (float)Back_Wheel.new_encoder / 60.0f *
                          BACK_WhEEL_DIAMETER * PI * Back_Wheel.correct_speed_k;
    Back_Wheel.Target_Velocity = BackSpeed_Pid.target[NOW];
}
/* small_driver_uart_control.c — 驱动板通信帧（UART3 @460800） */
/* 7 字节帧：[0xA5][命令码][数据x4][校验和]，命令码 0x01 设占空比、0x02 查转速 */
void small_driver_set_duty(int16 left_duty, int16 right_duty)
{
    motor_value.send_data_buffer[0] = 0xA5;
    motor_value.send_data_buffer[1] = 0x01;                              /* 设占空比 */
    motor_value.send_data_buffer[2] = (uint8)((left_duty & 0xFF00) >> 8);
    motor_value.send_data_buffer[3] = (uint8)(left_duty & 0x00FF);
    motor_value.send_data_buffer[4] = (uint8)((right_duty & 0xFF00) >> 8);
    motor_value.send_data_buffer[5] = (uint8)(right_duty & 0x00FF);
    motor_value.send_data_buffer[6] = 0;
    for (int i = 0; i < 6; i++)                                          /* 校验和 */
        motor_value.send_data_buffer[6] += motor_value.send_data_buffer[i];
    uart_write_buffer(SMALL_DRIVER_UART, motor_value.send_data_buffer, 7);
}
5.2.2 姿态解算
姿态传感器采用 IMU660RB（量程 ±2000°/s、±8g），以 1kHz 采样。解算流程为：首先由 Get_Gyro_Offest() 在静止状态下采集 4096 点完成陀螺零偏与重力模长标定；陀螺数据经二阶巴特沃斯 IIR 低通（截止 8Hz，按运行状态自适应调整）滤波，加速度数据经一维卡尔曼（R＝0.543）平滑；随后以 200Hz 周期调用 IMU_QuaternionEKF_Update()，采用含四元数与陀螺零偏共 6 维状态量的扩展卡尔曼滤波（EKF）[2]，以加速度计三轴为观测，并引入卡方检验与渐消因子（λ＝0.9996）[5]，输出车体 Roll/Pitch/Yaw 角度及角速度，同时解算世界系去重力加速度供位置估计使用。
关键代码（核心函数）：
/* Attitude.c — Attitude_Calculate() 滤波与 EKF 调用核心 */
void Attitude_Calculate(void)
{
    static uint8 counts_imu = 0;
    imu660rb_get_gyro();
    imu660rb_get_acc();

    /* 陀螺：减零偏 → IIR 低通 → 转 rad/s */
    IMU_Data.Gyro_x = -get_iir_output(pFilter_Param_Gx,
        imu660rb_gyro_transition((float)imu660rb_gyro_x) - IMU_Data.Gyro_Offestx) * 0.01745329f;
    IMU_Data.Gyro_y = -get_iir_output(pFilter_Param_Gy,
        imu660rb_gyro_transition((float)imu660rb_gyro_y) - IMU_Data.Gyro_Offesty) * 0.01745329f;
    IMU_Data.Gyro_z =  get_iir_output(pFilter_Param_Gz,
        imu660rb_gyro_transition((float)imu660rb_gyro_z) - IMU_Data.Gyro_Offestz) * 0.01745329f;

    /* 加速度：一维卡尔曼平滑 */
    IMU_Data.Accel_x = -Com_Kalman_Filter(&kf_acc[0], imu660rb_acc_transition((float)imu660rb_acc_x));
    IMU_Data.Accel_y = -Com_Kalman_Filter(&kf_acc[1], imu660rb_acc_transition((float)imu660rb_acc_y));
    IMU_Data.Accel_z =  Com_Kalman_Filter(&kf_acc[2], imu660rb_acc_transition((float)imu660rb_acc_z));

    /* 200Hz 四元数 EKF 融合 */
    if (++counts_imu % 5 == 0)
    {
        counts_imu = 0;
        IMU_QuaternionEKF_Update(IMU_Data.Gyro_x, IMU_Data.Gyro_y, IMU_Data.Gyro_z,
                                 IMU_Data.Accel_x, IMU_Data.Accel_y, IMU_Data.Accel_z);
    }
}
/* QuaternionEKF.c — IMU_QuaternionEKF_Update() EKF 核心 */
void IMU_QuaternionEKF_Update(float gx, float gy, float gz, float ax, float ay, float az)
{
    /* 状态转移 F：0.5*(Ω - 零偏)*dt（四元数运动学） */
    QEKF_INS.Gyro[0] = gx - QEKF_INS.GyroBias[0];
    QEKF_INS.Gyro[1] = gy - QEKF_INS.GyroBias[1];
    QEKF_INS.Gyro[2] = gz - QEKF_INS.GyroBias[2];
    memcpy(QEKF_INS.IMU_QuaternionEKF.F_data, IMU_QuaternionEKF_F,
           sizeof(IMU_QuaternionEKF_F));

    /* 加速度观测：归一化后作为量测 */
    float inv = invSqrt(ax*ax + ay*ay + az*az);
    QEKF_INS.IMU_QuaternionEKF.MeasuredVector[0] = ax * inv;
    QEKF_INS.IMU_QuaternionEKF.MeasuredVector[1] = ay * inv;
    QEKF_INS.IMU_QuaternionEKF.MeasuredVector[2] = az * inv;

    /* 标准卡尔曼预测/更新 */
    Kalman_Filter_Update(&QEKF_INS.IMU_QuaternionEKF);

    /* 后验四元数 → Roll / Pitch / Yaw */
    QEKF_INS.q[0] = QEKF_INS.IMU_QuaternionEKF.FilteredValue[0];
    QEKF_INS.q[1] = QEKF_INS.IMU_QuaternionEKF.FilteredValue[1];
    QEKF_INS.q[2] = QEKF_INS.IMU_QuaternionEKF.FilteredValue[2];
    QEKF_INS.q[3] = QEKF_INS.IMU_QuaternionEKF.FilteredValue[3];
    QEKF_INS.Roll  = 57.29578f * atan2f(2*(q[0]*q[2] - q[1]*q[3]),
                            q[0]*q[0] - q[1]*q[1] - q[2]*q[2] + q[3]*q[3]);
    QEKF_INS.Pitch = 57.29578f * atan2f(q[0]*q[1] + q[2]*q[3],
                            0.5f - q[1]*q[1] - q[2]*q[2]);
    QEKF_INS.Yaw   = -57.29578f * atan2f(q[1]*q[2] + q[0]*q[3],
                            0.5f - q[2]*q[2] - q[3]*q[3]);
    angle_handle_360(&QEKF_INS.Yaw);
    QEKF_INS.Yaw -= QEKF_INS.Yaw_Bias;
}
5.3 电机控制
后轮驱动采用原车模无刷电机，由 CYT2BL3 驱动板完成三相驱动。主控在 5ms 中断中执行 Back_Motor_Control()：速度环采用增量式 PID[3]（BackSpeed_Pid），以 Back_Wheel.Velocity 为反馈、按科目状态设定的目标速度为输入，计算电机占空比并做输出限幅（±5000）与积分限幅，经电机死区补偿后通过串口下发 small_driver_set_duty(Motor_Out, 0)。目标速度经 Dynamic_Speed_Target_Handler() 斜坡平滑，防止加减速冲击；坡道等特殊路段按车体 Pitch 分段降速。
关键代码（核心函数）：
/* Control.c — Back_Motor_Control() 速度环核心 */
void Back_Motor_Control(void)
{
    Dynamic_Speed_Target_Handler();      /* 目标速度斜坡平滑 */

    /* 速度闭环：增量式 PID → 串口下发占空比 */
    if (Back_Wheel.speed_get_flag == true && Bike_State == Run)
    {
        Motor_Out = PID_Calculate(&BackSpeed_Pid,
                                  BackSpeed_Pid.target[NOW], Back_Wheel.Velocity);
        small_driver_set_duty(Motor_Out, 0);
    }
    else
    {
        small_driver_set_duty(0, 0);
    }
}
/* PID.c — PID_Calculate() 增量式核心 */
float PID_Calculate(PID_TypeDef *pid, float target, float feedback)
{
    pid->feedback[NOW] = feedback;
    pid->target[NOW]   = target;
    pid->err[NOW]      = target - feedback;

    if (pid->pid_mode == DELTA_PID)             /* 增量式（本车速度环） */
    {
        pid->delta_u = pid->Kp*(pid->err[NOW] - pid->err[LAST])
                     + pid->Ki*pid->err[NOW]
                     + pid->Kd*(pid->err[NOW] - 2*pid->err[LAST] + pid->err[LLAST]);
        pid->delta_out = pid->last_delta_out + pid->delta_u;   /* 输出累加 */
        abs_limit(&pid->delta_out, pid->MaxOutput);
        pid->last_delta_out = pid->delta_out;
    }
    /* 位置式（平衡环）略 */
    pid->err[LLAST] = pid->err[LAST];
    pid->err[LAST]  = pid->err[NOW];
    return pid->pid_mode == POSITION_PID ? pid->pos_out : pid->delta_out;
}
5.4 舵机控制
转向采用 BDS300 舵机，PWM 频率 300Hz，通过 GetServoDuty() 完成角度—占空比换算（中位 SERVO_MID）。舵机控制融合于 Balance_Control()（1ms 中断）中：高速模式采用“角度环＋角速度环”串级 PD（角度环 5ms、角速度环 1ms），目标角度＝平衡零位＋动态补偿＋方向环输出，舵机输出 duty＝SERVO_MID−角速度环输出；低速模式采用增量式角度环与 Z 轴角速度环串联。转向控制由 Direction_Control() 依据转向误差计算方向 PD 输出，叠加至平衡角目标，实现“转向—倾倒—平衡恢复”的单车转向机理，并设置舵机最大角度限幅，避免猛打方向导致失稳。
关键代码（核心函数）：
/* Control.c — Balance_Control() 平衡环核心 */
void Balance_Control(void)
{
    if (car_mode_switch_num == 1 && Bike_State == Run)   /* 高速动态平衡 */
    {
        /* 角度环 PD → 角速度环 PD 串级 */
        PID_Calculate(&Dynamic_Balance_AnglePid,
                      Balance_init_zero + dynamic_zero + Direction_Pid.pos_out, QEKF_INS.Roll);
        PID_Calculate(&Dynamic_Balance_angular_velocityPid,
                      Dynamic_Balance_AnglePid.pos_out, QEKF_INS.Gyro[1] * 57.29578f);
        servo_input_duty = SERVO_MID - (int16)Dynamic_Balance_angular_velocityPid.pos_out;
    }
    /* 倾倒保护：|Roll| ≥ 40° 停车 */
    if (abs(QEKF_INS.Roll) >= 40.0f) { Bike_State = Stop; return; }
    if (Bike_State != Stop) pwm_set_duty(SERVO_PIN, servo_input_duty);
}
/* Servo.c — 角度-占空比换算 */
/* 角度 → 占空比：duty = PWM_DUTY_MAX*(校准 + angle/90)/(1000/freq)，300Hz */
uint16 GetServoDuty(float angle)
{
    return (uint16)((float)(PWM_DUTY_MAX * (global_servo_calibration + angle / 90.0f)) /
                    (1000.0f / (float)SERVO_FREQ));
}
float GetServoAngle(uint16 duty)   /* 占空比 → 角度（调试用） */
{
    return (float)(90.0f * ((uint16)duty * (1000.0f / (float)SERVO_FREQ) /
                    (float)PWM_DUTY_MAX - global_servo_calibration));
}
/* Control.c — Direction_Control() 方向环核心 */
void Direction_Control(float turn_error)
{
    if (Bike_State == Run)
    {
        /* 按科目状态设置方向 PD 参数（查表，此处略） */
        PID_Calculate(&Direction_Pid, turn_error, 0);   /* 方向 PD */
        /* 输出 pos_out 叠加至平衡角目标，实现“转向—倾倒—平衡恢复” */
    }
    else if (Bike_State == Null)
    {
        Direction_Pid.pos_out = 0;
    }
}
5.5 控制算法设计
本车主要控制算法如下：
速度环：根据科目任务设定的目标速度与无刷驱动板回传的实测速度之差进行增量式 PID 调节，输出电机占空比；
转向环：根据惯导定位信息与 B 样条路径解算转向误差，采用方向 PD 控制输出舵机 PWM，并叠加至平衡角目标；
其他算法：目标速度斜坡平滑、坡道分段降速、倾倒保护（|Roll|≥30°～40°自动停车）等。

5.6 任务状态机
整车运行状态分为 Null（待机）、Run_Wait（起步准备）、Run（运行）、Stop（停车）与 Remote（遥控，预留）。发车后经 Run_Wait 计数进入 Run；运行中当 |Roll|≥30°～40°（防倾倒）或到达终点判定时进入 Stop，回正后自动复位至 Null。各科目内部另有任务状态机：科目 1 为折返任务（发车区→前进直道→U 形弯折返→返回直道→终点，按行驶距离切换）；科目 2 为光导/慢速环线（沿跑道形闭合路径行驶，按位置分 12 段切换）；科目 3 为综合赛道（双层状态机：外层 12 种赛道元素排布，内层 10 个进度状态，弯道以延时计数判完成）。状态切换条件与保护逻辑如图 5.3 所示。

/* Route_Process.c — find_lookahead_index() 纯跟踪预瞄 */
void find_lookahead_index(void)
{
    /* 预瞄点：沿车航向前移 LOOKAHEAD_DISTANCE，前向窗口内找最近路径点 */
    if (car_mode_switch_num == 1)
    {
        float pre_x = INS.Current_X + LOOKAHEAD_DISTANCE * sinf(QEKF_INS.Yaw * 0.01745329f);
        float pre_y = INS.Current_Y + LOOKAHEAD_DISTANCE * cosf(QEKF_INS.Yaw * 0.01745329f);
        uint16 end = INS.target_index + LOOKAHEAD_SEARCH_RANGE;
        if (end >= GRAPH_NODE_TOTAL) end = GRAPH_NODE_TOTAL - 1;

        float min_dist = 1e6f, closest = INS.target_index;
        for (uint16 i = INS.target_index; i <= end; i += 2)
        {
            float dx = GlobalGraph.nodeBuff[i].X - pre_x;
            float dy = GlobalGraph.nodeBuff[i].Y - pre_y;
            float d  = dx*dx + dy*dy;
            if (d < min_dist) { min_dist = d; closest = i; }
        }
        INS.target_index = closest;
    }
    /* 终点判定：路径末段且回到起点附近 → 停车 */
    if (INS.target_index >= GRAPH_NODE_TOTAL - 10 && INS.Current_Y <= 0)
        Bike_State = Stop;
}
/* Route_Process.c — angle_diff1() 角度差归一化 */
float angle_diff1(float angle1, float angle2)   /* 角度差归一化 [-180,180) */
{
    float diff = angle1 - angle2;
    while (diff > 180.0f)  diff -= 360.0f;
    while (diff < -180.0f) diff += 360.0f;
    return diff;
}
/* Route_Process.c — Calculate_Direction_Error() 转向误差合成 */
void Calculate_Direction_Error(void)
{
    /* 1. 目标点方位角 与 路径切线角 */
    INS.Target_angle = RAD_TO_ANGLE(atan2(
        GlobalGraph.nodeBuff[INS.target_index].X - INS.Current_X,
        GlobalGraph.nodeBuff[INS.target_index].Y - INS.Current_Y));
    uint16 far_idx = INS.target_index + LOOKAHEAD_SEARCH_RANGE * 0.4;
    float path_dx = GlobalGraph.nodeBuff[far_idx].X - GlobalGraph.nodeBuff[INS.target_index].X;
    float path_dy = GlobalGraph.nodeBuff[far_idx].Y - GlobalGraph.nodeBuff[INS.target_index].Y;
    INS.Object_angle = RAD_TO_ANGLE(atan2f(path_dx, path_dy));

    /* 2. 横向误差（叉积带符号） */
    float dx = INS.Current_X - GlobalGraph.nodeBuff[INS.target_index].X;
    float dy = INS.Current_Y - GlobalGraph.nodeBuff[INS.target_index].Y;
    float len = sqrtf(path_dx*path_dx + path_dy*path_dy);
    INS.Target_distance = -(dx * (path_dy/len) - dy * (path_dx/len));

    /* 3. 斯坦利反馈项 + 合成转向误差 */
    INS.cal_angle_error_2 = angle_diff1(INS.Object_angle, QEKF_INS.Yaw);
    float vel = fabsf(Back_Wheel.Velocity) < 0.2f ? 0.2f : fabsf(Back_Wheel.Velocity);
    float distance_error = atan2f(turn_dynamic_gain * fabsf(INS.Target_distance), vel) * 57.29578f;
    if (INS.Target_distance < 0) distance_error = -distance_error;
    INS.turn_error = INS.cal_angle_error_2 + distance_error;
}
/* Subject1.c — Subject1_State_Change() 折返任务状态机 */
void Subject1_State_Change(void)
{
    switch (Subject1_Data.state)
    {
    case START_ZONE:       /* 发车区 → 直道 */
        if (INS.Current_Y >= Subject1_Data.start_zone_to_straight_change_diatance)
            Subject1_Data.state = FOWARD_STRAIGHT;
        break;
    case FOWARD_STRAIGHT:  /* 直道 → U 弯道 */
        if (Subject1_YArray[9-1] - INS.Current_Y <=
            Subject1_Data.straight_to_wandao_change_diatance)
            Subject1_Data.state = U_WANGDAO;
        break;
    case U_WANGDAO:        /* 掉头完成且回正 → 返回直道，截断后方路径 */
        if (Subject1_Data.U_turn_state == 1 &&
            fabs(QEKF_INS.Roll) <= Subject1_Data.wandao_to_straight_roll_target)
        {
            Subject1_Data.state = BACK_STRAIGHT;
            for (uint16 i = INS.target_index; i <= GRAPH_NODE_TOTAL - 1; i++)
                GlobalGraph.nodeBuff[i].X = INS.Current_X;
        }
        break;
    }
}
