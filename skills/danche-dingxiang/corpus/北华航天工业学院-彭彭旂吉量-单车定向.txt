第一章  车模及其技术方案
1.1 车模：逐飞 N1 单车定向车模
本次参赛车模选用逐飞科技 N1 单车专用车模，为第二十一届全国大学生智能汽车竞赛单车定向组别官方适配标准车模，专为两轮自平衡、定向行驶控制设计，完全满足赛事规则约束：车模静态放置无法自主维持平衡、原厂标配轮胎宽度 1.5cm（≤规则上限 1.6cm），底盘预留充足改造与传感器安装空间。
本车由一个TC264核心板，一个基于CYT2BL3的无刷驱动，一个格氏电池，一个012BE1000磁编，一个ICM42688姿态传感器和部分自制3D打印件组成




1.2技术方案
1.2.1 主控芯片方案
本次单车定向车模适配英飞凌 TC264、TC377 两套 AURIX 车规级单片机主控，为防止赛场意外损坏，我们准备了两种核心板以备不时之需。

1.2.2 FOC 驱动控制方案
采用 CYT2BL3 专用无刷 FOC 驱动作为动力驱动核心，专门适配智能车无刷电机磁场定向矢量控制场景。

1.2.3 转向舵机方案
采用 BDS300 金属齿轮竞赛舵机作为前轮转向执行机构，完美匹配逐飞 N1 单车车模原厂舵机安装底座，满足两轮自平衡高频转向修正需求。


1.2.4 动力电源方案
采用格氏 1650mAh 3S 动力锂电池作为整车功率供电电源，标称满电 12.6V，匹配 BDS3620 无刷电机与 CYT2BL3 驱动板工作电压区间

1.2.5 无刷驱动电机方案
采用 BDS3620 外转子无刷直流电机作为后轮驱动动力单元，为逐飞 N1 单车定向车模原厂适配动力，适配 3S 锂电池 12V 供电工况。

1.2.6 磁编码器方案
采用 012BE1000 迷你抗磁磁编码器采集电机转子电角度，安装于 BDS3620 电机尾部，为 FOC 矢量变换提供位置反馈。

1.2.7 姿态传感方案
采用 ICM42688 六轴高精度惯性测量单元作为车身平衡核心传感器，专门用于逐飞 N1 单车定向车模自平衡姿态解算，配备独立 3.3V 稳压供电，信号线与电机三相功率线分开布线，规避功率回路电磁干扰。


第二章 机械系统设计与实现

2.1 车载 3D 打印件
整车配套定制化结构件均依托三维建模软件完成数字化设计。传统工业建模软件 SolidWorks 具备建模精度高、装配约束完善的优势，但该软件专业门槛较高，完整安装、授权部署流程繁琐，对于以硬件开发、算法调试为主的参赛队员而言学习成本偏高，不利于备赛周期内快速完成结构迭代。综合备赛效率与上手难度考量，本团队推荐 Fusion 360 作为赛事快速建模工具，软件轻量化程度高、入门教学资源丰富，能够大幅降低三维结构设计的学习门槛，实现传感器支架、防护结构等零件快速建模与修改。
除数字化建模环节外，3D 打印设备与耗材工艺同样直接决定车载结构件的可靠性。建模人员需充分掌握不同打印耗材的力学特性，本车结构件选用 PLA、PETG 两种耗材分场景加工：常规传感器限位支架、轻量化卡扣等非受力部件采用 PLA 耗材打印，兼顾成型速度与加工成本；防撞支架、电机防护座等承受冲击载荷的关键受力构件，则选用韧性、抗冲击性能更优的 PETG 耗材。同时打印壁厚、内部填充密度等工艺参数需结合零件安装位置、受力大小针对性定制，实现轻量化与结构强度的平衡匹配，适配单车定向赛道颠簸、频繁撞击的复杂运行工况。

2.2 关键部件防护与机械故障排查
前叉为逐飞 N1 单车定向车模转向与姿态维持的核心机械部件，赛事坡道科目行驶过程中车身会承受持续冲击，极易引发前叉连接结构松动。若调试阶段忽视前叉紧固状态，会直接引入转向角度偏差，高速直线行驶时出现车身跑偏、侧倾加剧现象；即便视觉识别、姿态控制算法参数整定完成，车辆行驶轨迹依然无法达到预期精度，严重时会破坏整车自平衡闭环，导致八字圆环、坡道定向等核心科目无法正常完成。针对该风险，本车采用 3D 打印防护基座搭配弹性缓冲防撞条的复合防护方案，削弱坡道冲击对前叉结构的直接作用力。
后轮无刷驱动电机为整车动力输出核心，车身侧翻、撞击赛道障碍物时电机壳体、尾部编码器支架易发生形变损坏。为规避硬件损伤，本车增设碳纤维加固固定件包裹电机外侧，提升电机抗冲击防护能力。
赛道调试过程中车辆侧翻、撞击属于高频工况，每次摔车后需执行标准化机械校验流程，优先检查前叉紧固度、后轮电机同轴安装状态，确认无形变、松动问题后再开展算法参数调试。多数行驶失衡、轨迹偏移问题并非控制算法缺陷，而是机械结构松动、部件形变引发，遵循 “先排查机械硬件，再优化控制参数” 的调试逻辑，可大幅缩减调车周期。




第三章 硬件系统设计及实现


3.1主板整体架构框图

主板原理图


PCB电路正面

PCB电路背面

本车主控板以英飞凌 TC264 多核单片机作为核心控制器，硬件系统按照功能划分为电源管理模块、核心主控模块、传感采集模块、执行机构接口模块、人机交互模块、串行通信拓展模块六大单元。硬件分为功率链路、信号链路两套独立传输体系，实现动力供电、信号采集、控制指令输出功能分区，降低大功率负载工作产生的电磁干扰。
整车由 3S 格氏锂电池提供 12V 原始输入电压，电源输入端集成防反接保护电路与电源总开关。输入电压分为两路分配：一路直接引出电机电源接口，向外接 BDS3620 无刷驱动电机输送动力电源；另一路接入多路 DC-DC 降压电路，依次生成 7V 舵机电源、5V 外设电源、3.3V 弱电电源。系统采用多路独立电源分区供电方案，将舵机这类冲击性负载与陀螺仪、主控芯片等精密传感器供电相互隔离，有效抑制负载突变带来的电压扰动。
所有传感信号、外部控制指令统一汇总至 TC264 主控芯片完成运算处理：
传感采集通路：陀螺仪接口外接 ICM42688 惯性测量单元，采集车身加速度、陀螺仪原始数据；遥控器接口接收外部遥控指令；
执行控制通路：主控输出 PWM 信号至舵机接口，驱动 BDS300 转向舵机实现前轮角度调节；通过串口与 CYT2BL3 无刷 FOC 驱动板建立通信，下发目标转速、力矩指令；
人机交互通路：五向按键、OLED 屏幕接口、蜂鸣器、状态指示灯组成人机交互单元，支持本地参数修改、车辆运行状态可视化观测、故障声光提示；
调试拓展通路：预留无线模块串口，可搭载无线通信模块与上位机双向传输数据，实现实时波形观测、控制参数在线整定。
PCB 布局设计中，模拟传感器信号线远离大功率功率走线，电源网络配套滤波器件，提升车模在颠簸、大电流动态工况下的硬件稳定性。




3.2 CYT2BL3驱动
FOC原理图


PCB正面

PCB背面

本车后轮动力系统采用基于 CYT2BL3 芯片的无刷电机 FOC 矢量驱动板，驱动 BDS3620 外转子无刷电机，驱动板硬件架构划分为电源供电模块、FOC 核心控制单元、三相逆变功率输出模块、电流采样模块、转子位置检测模块、主控通信模块、硬件保护模块七大功能单元。驱动板与 TC264 主控主板通过串口建立数据交互链路，实现整车控制系统分层协同工作。
功率电源由格氏 3S 锂电池直接供给，直流母线电压一方面作为三相逆变桥主功率电源；另一方面经片内降压电路转换得到 3.3V 弱电，为 CYT2BL3 控制内核、磁编码器、通信外设供电。硬件设计区分功率回路与弱电信号回路，强弱电区域物理分区布线，削弱大电流开关动作带来的电磁干扰。
CYT2BL3 作为驱动核心，内部定时器生成具备死区保护功能的六路互补 PWM 信号，控制后级三相 MOS 管逆变桥，将直流电压转换为三相交流电驱动无刷电机。两路同步电流采样电路实时采集两相电机绕组电流，信号送入片内 ADC 进行模数转换，为 FOC 电流环闭环运算提供反馈量。板载 SPI 接口外接 012BE1000 磁编码器，实时获取电机转子角度与转速信息，完成帕克 / 克拉克坐标变换，保障磁场定向控制算法稳定运行。
通信链路采用 UART 串口与 TC264 主控主板对接，接收主控下发的目标转速、目标力矩指令；同时可向上位机实时上传母线电压、相电流、转子转速等运行数据，支持电机参数自学习、控制参数在线整定。驱动板集成过压、欠压、过流硬件保护机制，一旦检测到运行参数超出安全阈值，将立即封锁 PWM 输出，防止功率器件与电机发生损坏，提升赛道颠簸、意外摔车工况下系统稳定性。
PCB 布局充分考虑电磁兼容设计，功率走线短粗且路径优化，模拟采样信号线远离大功率开关走线，减小功率噪声对电流采样、角度采集信号的干扰，保障高速行驶过程中 FOC 控制环路稳定。

磁编原理图
本磁编码器采集板以英飞凌 TLE5012 磁感应芯片为核心，作为后轮无刷电机 FOC 矢量控制系统的转子位置反馈单元，硬件划分为电源稳压模块、磁场采集核心单元、SPI 信号调理模块、对外连接器接口模块四大功能单元。电路板采用圆形外形，适配电机尾部狭小安装空间，可直接固定于电机后端，实时感应同轴磁钢的磁场变化。

第四章 软件系统设计及实现


4.1 软件整体架构
本车模的软件控制系统依托于英飞凌 TC264 多核单片机进行开发与部署。软件整体架构采用分层模块化设计，主要划分为传感器数据采集与滤波层、核心控制算法层（包含多级 PID 闭环）、执行器输出驱动层以及顶层序列状态机调度模块。系统通过高频定时器中断保障控制周期的绝对实时性，确保车模能够平稳完成自平衡与赛道循迹任务。

4.2 姿态解算与数据滤波机制
车辆的自平衡强依赖于高质量的姿态数据。由于单车在赛道高速行驶时会伴随剧烈的机械高频震动与传感器噪声，本系统在引入 ICM42688 六轴惯性测量单元原始数据后，设计了完善的抗干扰滤波机制，通过互补滤波加四元数解算得出车辆实际的角度传输到控制环实现车辆的自平衡。
一阶滞后低通滤波与二阶巴特沃斯滤波：为了滤除传感器采集时引入的高频毛刺，系统对解算后的实际姿态角与速度反馈均采用了滤波算法。
一阶滞后滤波的离散化数学表达式为：
Y(k) = α · X(k) + (1 − α) · Y(k−1)    式中：Y(k) 为当前时刻的滤波输出值；X(k) 为当前时刻传感器的原始采样值；α 为滤波系数，系统在代码中依据不同车速域整定（如 0.8 或 0.7）。
在代码工程中，针对高速抖动与转向"画龙"问题，系统还进阶实现了数字信号处理标准的二阶巴特沃斯滤波器（Butterworth Filter）可以直接滤掉尖峰噪音：
// 角度环专用二阶滤波器 (针对高速抖动，截止频率 fc = 15Hz)
Butterworth2nd_t Angle_D_Filter_Sub1 = {
    .b0 = 0.0412535f, .b1 = 0.0825071f, .b2 = 0.0412535f,
    .a1 = -1.3489677f, .a2 = 0.5139819f,
    .x = {0, 0, 0}, .y = {0, 0, 0}
};

// 通用的二阶滤波计算函数
float Butterworth_2nd_Update(Butterworth2nd_t *filter, float input)
{
    filter->x[2] = filter->x[1];
    filter->x[1] = filter->x[0];
    filter->x[0] = input;
    // 核心差分方程计算
    filter->y[0] = filter->b0 * filter->x[0]
                 + filter->b1 * filter->x[1]
                 + filter->b2 * filter->x[2]
                 - filter->a1 * filter->y[1]
                 - filter->a2 * filter->y[2];
    filter->y[2] = filter->y[1];
    filter->y[1] = filter->y[0];
    return filter->y[0];
}
步长限幅保护与尖峰剔除

    为防止执行机构因控制量瞬间跳变而引发低频振荡，仅在输出端施加了严格的步长限幅，还针对陀螺仪原始数据设计了中值尖峰剔除算法。当单拍物理跳变超过设定的 max_step 阈值时，强制使用历史中值替代，极大增强了系统的抗扰动能力。
4.3 核心控制算法实现
整车的动态平衡与定向行驶由角度（外环）与速度（内环）构成的串级闭环控制系统共同维持。
位置式串级 PID 算法：对于科目二慢速的行驶可直接使用区别于高速行驶去掉角速度环去减小舵机的高频震荡。想要去保持慢速可以适当增加舵机的振荡频率去抵消低速时候的离心力，对于科目二要对舵机的输出值严格的滤波防止有尖峰值去导致舵机的突然抖动。
本车模选用位置式 PID 控制器来计算电机的补偿力矩，其标准的离散时间域计算公式如下：
U(k) = Kp · e(k) + Ki · Σ e(j) + Kd · [e(k) − e(k−1)]
其对应的 C 语言高内聚实现如下：
void PID_Calcu(PID_t *p)
{
    p->error0 = p->Target - p->Actual;
    p->Integral += p->error0;
    // 抗积分饱和机制
    if (p->Integral >  p->IntegralMax) p->Integral =  p->IntegralMax;
    if (p->Integral < -p->IntegralMax) p->Integral = -p->IntegralMax;
    // 位置式 PID 输出计算
    p->Out = p->Kp * p->error0
           + p->Ki * p->Integral
           + p->Kd * (p->error0 - p->error1);
    p->error1 = p->error0;
    // 输出极值限制
    if (p->Out > p->OutMax) p->Out = p->OutMax;
    if (p->Out < p->OutMin) p->Out = p->OutMin;
}
Stanley 横向轨迹跟踪算法

在单车的高速定向行驶与八字圆环循迹过程中，为解决前轮侧偏角带来的稳态误差，本系统引入了基于前轮运动学模型的 Stanley 算法进行横向控制。其前轮目标转角的计算公式为：
δ(t) = θ_e(t) + arctan( k · e(t) / v(t) )
当车速 v(t) 较高时，横向误差 e(t) 项的影响减弱，系统主要依赖航向误差 θ_e(t) 进行平滑纠偏，完美契合了单车"高速看向，低速看线"的运动学特性。
其底层解算逻辑如下：
float Stanley_Calculate(StanleyConfig *cfg,
                        float car_x, float car_y, float car_yaw,
                        float path_x, float path_y, float path_yaw,
                        float car_v)
{
    path_yaw = path_yaw * PI / 180.0f;
    car_yaw  = car_yaw  * PI / 180.0f;
    // 航向误差
    float theta_e = Angle_L;
    float dx = car_x - path_x;
    float dy = car_y - path_y;
    float dist = sqrtf(dx * dx + dy * dy);
    float angle_vector = atan2f(dx, dy);
    float angle_diff   = angle_vector - path_yaw;
    angle_diff = Angle_L;
    // 横向误差
    float e = dist * sinf(angle_diff);
    // 防止极低速时分母溢出
    float v_safe = (car_v < 0.5f) ? 0.5f : car_v;
    // Stanley 控制律
    float theta = theta_e + atan2f(cfg->k * e, v_safe);
    return theta;
}
Dubins 曲线生成与 Menger 曲率前馈算法

针对寻迹获取的离散赛道特征点，系统采用了 Dubins 曲线进行最佳路径拟合，并利用 Menger 曲率定理实时计算相邻三个散点所在外接圆的曲率。通过动态提取前瞻点的曲率作为前馈补偿，大幅降低了单车在入弯、出弯时的离心力冲击。
float Get_Trajectory_Curvature(int target_idx)
{
    int idx1 = target_idx - CURVE_STEP;
    int idx2 = target_idx;
    int idx3 = target_idx + CURVE_STEP;
    // ... 边界保护省略 ...
    float x1 = path[idx1].x, y1 = path[idx1].y;
    float x2 = path[idx2].x, y2 = path[idx2].y;
    float x3 = path[idx3].x, y3 = path[idx3].y;
    // 利用向量叉乘计算三角形面积的 2 倍 (自带正负号)
    float cross_product = (x2 - x1) * (y3 - y2)
                        - (y2 - y1) * (x3 - x2);
    float d1 = sqrtf((x2-x1)*(x2-x1) + (y2-y1)*(y2-y1));
    float d2 = sqrtf((x3-x2)*(x3-x2) + (y3-y2)*(y3-y2));
    float d3 = sqrtf((x3-x1)*(x3-x1) + (y3-y1)*(y3-y1));
    float denominator = d1 * d2 * d3;
    // 曲率 kappa = 4 * Area / (d1 * d2 * d3)
    if (fabsf(denominator) < 1e-6f) return 0.0f;
    return (4.0f * cross_product) / denominator;
}
4.4 状态机序列控制与任务调度
为了实现智能汽车在发车、巡航、绕锥、变轨等不同任务阶段的无缝切换，系统开发了动作序列调度与状态机切变函数。通过实时解算车身与状态判定点的绝对投影距离，实现了严密的状态转移逻辑。
对于加减速部分发现对于车辆运行过程中由于惯性速度的骤降或者骤增都会导致车辆的抖动甚至直接摔车对于速度的处理可以使用步进式加低通滤波去处理速度的骤变。
// 科目三速度状态机：去程与回程内部逻辑分离
{
    if (stage == STAGE_STRAIGHT) {
        // 起步直道冲刺
        raozhui_i = 0;
        final_target_speed = MIN_SPEED;
    }
    else if (stage == STAGE_CONE) {

        if (abs_pitch > PITCH_SAFE_THRESHOLD) {
            final_target_speed = 700;
        } else {

        // 顶部入弯前 4 米纯线性平滑刹车区
        raozhui_i = 0;

        final_target_speed = MAX_SPEED
                           - (MAX_SPEED - TURN_SPEED) * brake_progress;
    }
}

第五章 总结
本文系统性地总结了"彭彭旂-吉量"代表队在备战第二十一届全国大学生智能汽车竞赛单车定向组过程中的全套开发方案与技术细节。我们在官方指定的逐飞 N1 专用车模基础上，构建了以英飞凌 TC264 微控制器为核心、CYT2BL3 无刷 FOC 为驱动单元的稳健硬件架构。
在机械与硬件方面，我们针对单车易摔、易受冲击的特点，运用 3D 打印技术设计了完善的传感器防护支架与电机加固件，并严格规范了机械同轴度与紧固度的排查校验流程。
在软件与控制理论层面，深度结合了 ICM42688 姿态解算模块，设计了包含低通滤波、防脉冲抗抖算法的多层数据处理链路，成功搭建了基于位置式串级 PID 和防误触状态机调度的核心控制工程。通过引入 Stanley 算法与路径平滑技术，团队在备赛期间攻克了高速震荡、机械死区、坐标漂移等多项单车自平衡与循迹的痛点。
本次备赛不仅极大提升了参赛队员在嵌入式系统开发、自动控制原理应用及结构设计等领域的工程实践能力，更磨炼了团队在面对复杂电磁与机械故障时的系统性排查思维。在此，衷心感谢北华航天工业学院为本队提供的优质研发平台，并向带队教师侯艳致以最诚挚的谢意，感谢老师在备赛全周期的悉心指导与鼎力支持。
