摘要
本文以第二十一届全国大学生智能车竞赛为背景，介绍了智能赛车控制系统的软硬件结构和开发流程。比赛采用N1型模型车，以英飞凌公司生产的32位单片机TC2xx与TC3xx为核心控制器，要求赛车在固定路线上遇及未知障碍物以最快速度完成比赛。整个系统涉及车模机械结构、传感器电路设计及信号处理、控制算法的策略优化等多个方面。赛车采用IMU与编码器对路径进行规划，通过融合IMU与编码器信息获得当前位置与规划路径之间的偏差，用PID方式对舵机进行控制。
关键字： TC377，智能车，惯导， PID































引言
全国大学生智能车竞赛是从2006开始，由 教育部高等教育司委托高等学校自动化类教学指导委员会 （教高司函[2005]201号文）举办的旨在加强学生实践、创新能力和培养团队精神的一项创意性科技竞赛，至今已经成功举办了十九届。在继承和总结前十九届比赛实践的基础上，竞赛组委会努力拓展新的竞赛内涵，设计新的竞赛内容，创造新的比赛模式，使得智能车竞赛在新时代对新工科大学生培养方面作出更大的贡献。
本届比赛我们采用第二十一届全国大学生智能汽车竞赛提供的汽车模型——N1型车模作为研究载体，以英飞凌32位单片机 TC377作为主控制器。道路信息使用ST公司的LSM6DSRTR 陀螺仪与编码器生成相关路径点信息，并结合相关算法得到连续的路线。舵机使用博思威龙的DBS300舵机。电机使用博思威龙的BDS3620行进电机，并使用cyt2bl3进行驱动。























第二章 机械结构
2.1 车模选择
本届单车定向组的车模有很多选择，包括北京科宇出品的K1型车模，博思威龙出品的N型车模、N1型车模。在前期我们做了较多考虑，并最终选择了博思威龙出品的N1型车模，其优势如下：车模采用金属模具一体成型，车身具有很高的强度，后轮采用与真实电动车相同的轮驱一体结构，车模机械结构简单可靠、动能损失小，车模整体机械结构简单合理，转向灵敏轻巧。车轮采用高耐磨硅橡胶，轮胎外形弧度平缓圆滑，有利于小车灵活转向。并且N1型车模对对后轮行进电机进行了升级，扭矩为N车的两倍。
在原有车模的基础上，我们为其添加了两根平衡杆，可以使车模的平衡控制更加简单。由于N1车模的机械结构，使得车模电机安装的方式，机械零点偏左，故我们在车模右侧添加些许配重，使得车模的机械零点能保持在0°附近。

2.2 电路板及电池安装
我们将电路板安装在车身中间偏后的位置，该地方平整且有螺丝孔位，十分适合电路板的安装。将电池放在车身里，降低车辆重心，并3D打印了个电池壳，防止电池移位导致车辆重心变化。

图2.1 车模整体结构

2.3 陀螺仪的安装
陀螺仪作为竞赛所有平衡组别的核心，其安装位置尤其重要，随着安装位置不同，影响着参数大小，调试现象等等。陀螺仪的安装应选择中间，如单车需要左右平衡，不需要前后平衡，故我们将其安装在车模logo处，此处为左右方向的中间位置，并且配备两个螺丝孔位，十分适合安装。

第三章 硬件设计

3.1 硬件设计方案
整个智能车控制系统是由四部分组成的：TC377核心板、主板、无刷电机驱动电路板、磁编码器电路板。电路板。最小系统板可以插在主板上组成信号采集、处理和电机控制单元。同时为了减小电机驱动电路带来的干扰，我们把控制部分和电机驱动分开来。
3.2 系统核心板
单片机最小系统板使用 TC377核心板。该主控性能强劲，主频高达300MHz；内部有硬件浮点运算单元（FPU）；Flash高达256kb。
3.3 传感器选型
本设计中，陀螺仪选用LSM6DSRTR，该款陀螺仪为意法半导体公司生产的高性能6轴惯性测量单元（IMU），精度高、温漂小，通信可选择SPI，速度快，非常适合在运动追踪、机器人、室内导航等领域工作；磁编码器选用英飞凌公司生产的TLE5012B1000磁性角度传感器制作，该传感器通信方式丰富、精度高、宽温域，非常适合在汽车电子、工业电机控制等领域工作。

3.4.1 电源

第四章 软件设计
4.1 车模控制
4.1.1 平衡控制
本届单车在平衡上做了些限制，要求不能用除舵机以外的方式保持平衡，全程仅靠舵机，需要需要即做到稳住车身平衡，又要完成精准转向，所以难度上会比18届的动量轮单车难一点。
该车模与真实的自行车结构相近，核心控制逻辑是通过调节车把转向产生离心力，同步实现车身平衡维持与转向控制。这里需重点注意，车把转向方向需与车身倾倒方向保持一致，才能产生有效离心力，进而稳住车身平衡。
了解单车的平衡控制原理后，我们便能通过舵机调节车把转向，实现车模的稳定平衡了。在控制上，我们使用的是串级PID对车模进行控制。使用横滚角速度作为最内环，横滚角度作为中环输入到内环，转向误差作为最外环输入到中环中，其控制框图如下

图4.1 单车串级PID控制框架

4.1.2 平衡调试
串级PID控制首先调节的应该是最内环，对于角速度环来说，因为是用IMU得到的原始角速度数据作为控制量，所以其响应速度是最快的，这里我们使用1KHz的频率进行控制，角速度环并不作为平衡控制的主要手段，起到的是一个快速响应的作用，因为角速度值与车模倾倒的速度有关，与车模的倾角无关。这里我们调节到缓慢倾倒车身，舵机转角很小甚至没有；快速倾倒车身，舵机开始有明显的转角就行了。如果舵机发生高频抖动，可以对角速度数据进行滤波处理，常见的有一阶低通滤波、滑动均值滤波、卡尔曼滤波等等。
内环调节完成后，就可以调节中环了，中环是以车身的倾角作为控制量，推荐使用100-200Hz频率进行控制。角度环是对车身状态的一个实时反馈，引入角度环后，舵机转角就可以随着车身倾角的增大而增大。这里我们可以先给一个较低的速度，比如12%占空比，然后调节角度环kp就可以实现平衡了。
最后是转向环，纯舵机单车的转向环与其他车模的转向环有所不同，由于转向环的输出是作为角度环的目标倾角，所以不能一下子把转向误差带入计算，这样会使单车在运行过程中突然引入一个很大的误差，可能会使车身失去平衡。所以我们采用一种误差步进的方式，在转向误差计算出来后，给让误差慢慢步进到真实的转向误差，然后输入到角度环中作为目标倾角，这样就会有一个过渡的过程，不会瞬间引入大误差。这边建议引入z轴角速度作为微分项，可以使转向更加平稳。

4.2 路径规划
传统越野组的循迹主要靠的是GPS，GPS在高速情况下准，上限很高，但是我们从最初的设计就定下算法要简单易懂、可靠稳定，考虑到单车到不了极速越野那个速度，且活动场地较小，我们就选择了惯性导航。
以IMU初始化方向为Y轴、IMU顺时针为X轴建立直角坐标系，对车模进行航位推算，之后每20cm就保存一次小车当前的位置，并将最终记录的路径点保存到Flash中。

图4.2 航位推算代码


4.3 循迹策略
循迹方面我们使用固定前瞻点位与前瞻距离得到目标点，然后将目标点位与当前推算出来的位置计算与y轴的偏差角度，然后与当前的航向角做差得到误差转角，再输入到转向环进行PD计算。

        if(cnt_10ms % 10 == 0)
        {
            static float smooth_yaw = 0.0f;       // 平滑后的目标航向
            // 计算目标方位角与当前yaw角的差值

            // 对误差平滑步进
            if(smooth_yaw < yaw_diff)
            {
                smooth_yaw += TURN_STEP_SUB3;        // 步进3.4度
                if(run_cur.dir_y == -2) {
                    if(smooth_yaw > 45) smooth_yaw = 45;
                }
                else {
                    if(smooth_yaw > yaw_diff) smooth_yaw = yaw_diff;
                }
            }
            else if(smooth_yaw > yaw_diff)
            {
                smooth_yaw -= TURN_STEP_SUB3;        // 步进3.4度

                    if(smooth_yaw < -45) smooth_yaw = -45;

                else {

                }

                debugr_error = smooth_yaw;
