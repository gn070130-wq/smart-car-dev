摘  要
本技术报告详细阐述了第二十二届全国大学生智能汽车竞赛竞速组参赛车辆的设计方案。针对赛道无视觉标识、无电磁引导的极端工况，本车队创新性地采用“纯惯性导航（类GPS航位推算）”技术路线。系统以英飞凌TC264为主控核心，负责姿态解算与轨迹规划；以CYT2BL3为协处理器，专司底层功率驱动与霍尔编码器数据采集。两者通过高速UART全双工通信实现指令下发与状态反馈。
在算法层面，车辆基于预设的绝对坐标地图，利用IMU660RB解算的航向角与编码器反馈的里程信息进行实时航位推算，结合LQR最优控制器实现对“八字绕桩”及“颠簸路段”的高精度轨迹跟踪。本报告从总体方案、机械结构、电路设计、核心算法及仿真建模五个维度，全面展示了车辆在无外部参照系下的自主导航与控制能力。
关键词：智能汽车；纯惯性导航；航位推算；TC264；UART通信；LQR控制

第一章  总体方案设计
1.1  总体概述
本届竞赛竞速组赛道环境复杂，包含“八字绕桩”、“颠簸路段”等高难度科目，且严禁使用视觉与电磁感应方案。面对这一挑战，本车队确立了“前轮转向、后轮驱动的自行车模型”结合“纯惯性导航+航位推算”的独特技术路线。
车辆的核心控制逻辑完全依赖于内部状态的积分运算。我们预先将赛道的几何特征转化为一系列连续的绝对坐标点集P(x,y)存入主控。在运行过程中，系统依靠高精度六轴IMU实时更新航向角ψ，并通过UART串口接收来自底层驱动板CYT2BL3的霍尔编码器车速反馈v。TC264主控芯片综合上述数据，执行航位推算算法计算出车辆当前的绝对坐标(X,Y)，进而通过LQR控制器计算期望舵角，实现闭环轨迹追踪。
1.2  硬件与方案选型论证
主从分工架构　选用英飞凌TC264作为主处理器（大脑），其双核AURIX架构拥有强大的浮点运算能力，足以承担姿态解算、坐标积分及LQR矩阵运算等重负载任务。选用CYT2BL3作为协处理器（执行层），专注于MOSFET驱动与高频脉冲捕获。这种分层设计有效隔离了功率级噪声对核心算法的干扰，提升了系统稳定性。
通信协议选型　在主从芯片通信上，我们摒弃了传统的CAN总线，转而采用UART异步串行通信。虽然CAN总线抗干扰性强，但对于本车低频（100Hz~200Hz）的控制指令与状态反馈而言，UART配合屏蔽双绞线已绰绰有余。UART接线简单（仅需TX/RX/GND），协议开发周期短，且TC264的ASC模块支持硬件FIFO与DMA，能确保数据传输的实时性。
传感器选型　姿态感知是纯惯性导航的基石。我们选用IMU660RB模块（核心芯片ST LSM6DSR），该芯片具备低噪声、高稳定性的特点，通过SPI接口与主控通信，确保在颠簸路段仍能获取准确的角速度与加速度信息。
1.3  整车系统架构
整车系统采用分布式拓扑结构，具体信号流向如下：
（1）感知层：IMU660RB通过SPI接口（10Mbps）接入TC264；霍尔编码器直接连线至CYT2BL3的脉冲捕获引脚。
（2）通信层：CYT2BL3与TC264之间建立UART全双工通信链路。TC264下发“目标速度与转向方向”，CYT2BL3反馈“车速/里程”、“电机电流”及“故障码”。
（3）执行层：TC264输出PWM波控制前轮舵机；CYT2BL3驱动后轮电机。
第二章  机械结构设计
2.1  类自行车模型结构优化
本车基于博思威龙N1车模改装，严格遵循阿克曼转向几何原理。
（1）转向机构：针对前轮舵机转向机构进行了精密顺滑处理，使用特氟龙垫片消除齿轮虚位。由于采用绝对坐标法，舵机的实际打角必须与指令高度线性对应，任何机械间隙都会导致航位推算中的横向误差累积。
（2）驱动系统：后轮电机采用同轴直连方式安装霍尔编码器，杜绝了皮带传动可能产生的打滑现象，确保车速数据采集的物理真实性。
依据阿克曼转向几何，转弯时内外前轮转角δi、δo与轴距L、轮距T满足如下关系，本车转向梯形机构按该关系设计，以减小转弯时的轮胎侧滑：
cot δo − cot δi = T / L

3.3  双向UART通信接口设计
UART通信是本车“大脑”与“小脑”交互的生命线。
（1）物理层设计
TC264的TXD/RXD引脚串联33Ω匹配电阻后连接至CYT2BL3，并在接收端并联TVS二极管以防静电击穿。通信波特率设定为921600 bps，在保证误码率极低的前提下，最大化数据吞吐量。
（2）通信协议定义
我们设计了紧凑的自定义数据帧结构：
下行帧（TC264→CYT2BL3）：[帧头0xAA] [2字节目标速度] [1字节方向标志] [1字节校验和]。
上行帧（CYT2BL3→TC264）：[帧头0x55] [4字节霍尔脉冲计数值] [2字节电流检测值] [1字节故障状态] [1字节校验和]。
（3）软件实现
在TC264端，利用DMA通道自动搬运串口接收数据至内存缓冲区，仅在接收完一整帧数据后触发中断进行解析，极大降低了CPU占用率。关键点在于：TC264的速度闭环PID算法中，反馈变量v_feedback完全依赖于UART接收到的编码器数据，而非电机模型的估算值，这保证了速度控制的物理真实性。

第四章  算法与系统控制
4.1  总体软件架构
TC264双核任务分配如下：
Core 0：负责高频中断任务。包括SPI读取IMU数据（1kHz）、UART串口接收中断处理、编码器脉冲计数（由CYT2BL3转发）。
Core 1：负责核心算法运算。包括姿态解算、航位推算积分、LQR控制器求解、以及向Core 0发送UART下发指令。双核通过共享内存与信号灯机制同步数据。
4.2  基于ST LSM6DSR的姿态解算
由于车辆处于动态环境，单一传感器无法准确获取姿态。我们采用Mahony互补滤波算法融合加速度计与陀螺仪数据。
（1）陀螺仪积分：利用角速度ω短时间积分获取姿态变化，响应快但存在漂移。
（2）加速度计修正：利用重力向量在机体坐标系下的投影，计算姿态误差，通过PI控制器修正陀螺仪的零偏。
（3）输出：实时解算出车辆的三维欧拉角，其中偏航角ψ（Yaw）是后续航位推算的核心状态变量。
Mahony互补滤波以四元数q表示姿态，其修正过程可表示为：
e = a × v
ω̂ = ω + Kp·e + Ki·∫e dt
q̇ = ½ q ⊗ [0, ω̂]
式中：a为加速度计观测的重力方向，v为由四元数估计的重力分量，e为二者叉积得到的姿态误差，Kp、Ki为比例与积分增益，ω为陀螺仪角速度。
4.3  绝对坐标法的航位推算（类GPS算法）
这是本车在无外部参照下定位的核心算法。
（1）里程与速度获取
TC264解析UART数据包，提取霍尔编码器计算的瞬时车速v和微小位移增量Δs：
Δs = v · Δt
（2）坐标系转换与积分
建立2D平面世界坐标系(Xw, Yw)。假设初始时刻t=0时，车辆位于原点(0,0)且航向角ψ=0。在每一时刻k，执行以下离散积分公式：
X(k+1) = X(k) + Δs(k) · cos(ψ(k))
Y(k+1) = Y(k) + Δs(k) · sin(ψ(k))
（3）零点校准策略
由于纯积分存在累积误差，我们采用“纯人为停车、上电瞬间零点对齐”策略。比赛开始前，人工将车辆摆正并对准起点，系统上电后强制重置(X,Y,ψ)为(0,0,0)。此后所有控制均基于此相对坐标系。虽然长距离会有漂移，但在单圈比赛中，通过高精度的IMU和LQR纠偏，可将误差控制在允许范围内。
4.4  轨迹参考与LQR最优控制器设计
（1）绝对坐标轨迹定义
我们将“半径2米的八字绕桩”和“含坡道、草地的颠簸路段”离散化为数百个高精度的(x_ref, y_ref, ψ_ref)参考点。控制器任务是使车辆状态无限逼近这些参考点。
（2）LQR控制器设计
建立车辆运动学自行车模型，其连续形式为（L为轴距，δ为前轮转角）：
ẋ = v · cos ψ
ẏ = v · sin ψ
ψ̇ = (v / L) · tan δ
线性化后得到状态空间方程：
ẋ = Ax + Bu
其中状态向量x = [e_d, e_ψ]ᵀ（横向误差、航向误差），控制输入u = [δ]ᵀ（前轮转角）。
设计二次型性能指标函数：
J = ∫(xᵀQx + uᵀRu)dt
通过调节权重矩阵Q（惩罚状态误差）和R（惩罚控制量），求解代数Riccati方程得到最优反馈增益矩阵K：
AᵀP + PA − PBR⁻¹BᵀP + Q = 0
K = R⁻¹BᵀP
最终控制律为：
δ = -Kx + δ_feedforward
其中δ_feedforward为基于曲率的前馈项，用于提高过弯响应速度。
（3）基于UART反馈的速度闭环
速度控制采用增量式PID算法。TC264读取串口更新的目标车速v_target与反馈车速v_current作差：
e_v = v_target - v_current
u_motor = Kp·e_v + Ki·Σe_v + Kd·(e_v - e_v_last)
计算出的u_motor封装进UART下行帧发送给CYT2BL3执行。921600bps的波特率确保了控制回路延迟小于1ms。
第五章  仿真设计与建模
5.1  车辆动力学与航位推算模型
在MATLAB/Simulink中建立了包含UART通信时延的车辆动力学模型。我们在航位推算模块中加入了高斯白噪声模拟IMU漂移和编码器量化误差，以验证算法的鲁棒性。动力学微分方程基于类自行车运动学模型，考虑了车辆纵向速度v、横向偏移e_d和航向误差e_ψ三个核心状态变量的耦合关系。
UART通信带来的微小时延（约1ms）在仿真中被建模为一阶滞后环节G(s) = 1/(τs+1)，其中τ=1ms，以准确反映实际控制系统中的通信延迟对轨迹跟踪精度的影响。
5.2  轨迹跟踪仿真
构建模拟赛场环境，将“八字绕桩”和“颠簸路段”的绝对坐标点集输入仿真模型。运行LQR轨迹跟踪算法，输出路径追踪偏差图、速度响应曲线与舵机转角变化曲线。

图 16  MATLAB航点路径与轨迹跟踪仿真结果
仿真结果显示，在引入随机干扰的情况下，LQR控制器能将横向误差控制在5cm以内，验证了控制策略的有效性。舵机转角响应平滑，无显著超调，表明前馈项与反馈项的协同设计达到了预期效果。
5.3  积分漂移与“人为零点”对齐验证
我们在仿真中模拟了“人为停车上电对齐”的初始状态，并人为加入0.5°/s的恒定航向陀螺仪漂移。
分析表明，虽然纯航位推算存在随时间发散的漂移趋势，但在单圈比赛时长（约60~90秒）内，累积误差尚未超出赛道边界。同时证明LQR控制器对初始对准误差具有较强的鲁棒性，能够通过快速纠偏将车拉回预设的绝对坐标路径公差范围内。
5.4  通信时延的一阶滞后建模
对5.1节中的一阶滞后环节G(s) = 1/(τs+1)，其单位阶跃响应为：
y(t) = 1 − e^(−t/τ)
代入τ=1ms可知，约4~5ms后响应即达到稳态值的98%以上。相对于100Hz~200Hz的控制周期，该通信时延对轨迹跟踪精度的影响可忽略，验证了UART链路实时性满足控制需求。

第七章  开发工具与调试过程
7.1  开发工具与环境
硬件开发：嘉立创EDA，用于主板、核心板与磁编板的原理图绘制、PCB Layout与制板。
软件开发：AURIX Development Studio / Tasking编译器（TC264主程序）；ModusToolbox（CYT2BL3底层驱动与脉冲捕获）。
仿真工具：MATLAB / Simulink，用于车辆动力学建模、航位推算误差分析与LQR轨迹跟踪仿真。
调试工具：MiniWiggler调试器、USB转TTL串口助手、示波器、万用表，用于通信波形与电源纹波测试。
7.2  制作、安装与调试过程
机械装配：车模拆解检查→转向机构顺滑处理并加装特氟龙垫片消除虚位→舵机与IMU刚性安装并校准水平→后轮编码器同轴安装，杜绝打滑。
电气安装：PCB打样与焊接→按星型接地拓扑布线→电机相线与编码器信号线最短化→UART通信采用双绞屏蔽线连接，上电前完成短路检查。
调试流程：先静态后动态。静态阶段完成电源纹波测试、UART通信帧校验、IMU零偏标定与舵机中位校准；动态阶段依次进行原地转向响应测试、直线航位推算漂移测试、八字轨迹跟踪参数整定，逐环节验证后再联调。
7.3  核心算法子程序
航位推算与LQR横向控制的核心算法子程序如下：
/* 航位推算核心子程序（TC264 Core1，100Hz周期调用） */
void DeadReckoning_Update(void)
{
    float ds = v_feedback * DT;      /* v_feedback来自UART编码器反馈 */
    pos_X += ds * arm_cos_f32(yaw);  /* yaw为Mahony解算偏航角 */
    pos_Y += ds * arm_sin_f32(yaw);
}

/* LQR横向控制核心子程序 */
float LQR_SteeringControl(float e_d, float e_psi)
{
    float delta_fb = -(K[0] * e_d + K[1] * e_psi);   /* K由黎卡提方程离线求解 */
    float delta_ff = atan2f(WHEELBASE, radius_ref); /* 基于曲率的前馈项 */
    return delta_fb + delta_ff;
}

结论
综合仿真与理论分析，本方案在无视觉、无电磁感应的条件下，凭借纯惯性导航与LQR最优控制的结合，实现了满足竞赛要求的路径跟踪精度，验证了技术路线的可行性。
