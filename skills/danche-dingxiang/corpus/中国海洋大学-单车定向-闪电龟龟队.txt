摘 要
本设计以第二十一届全国大学生智能汽车竞赛为背景，针对单车定向组赛题要求，采用N1型单车车模，以TC264双核微控制器为核心控制单元，在AURIX Development Studio开发环境下完成系统设计。系统通过ICM42688六轴陀螺仪实时采集车身姿态数据，结合磁编码器里程计反馈模块，采用三闭环串级PID控制算法与实时线性插值参数调度策略，实现对舵机转向角和行进电机转速的精确控制，有效维持单车在直线、坡道、草地及S弯锥桶等多种复杂赛道环境下的动态平衡与精确路径跟踪。其中，参数调度器根据实时车速与道路类型，在两个基准PID参数表之间执行无级线性插值，并采用无扰切换算法吸收参数切换瞬间的P项跳变，确保全速度区间内的控制平滑性。系统采用基于编码器里程计的纯航位推算方案，通过分段平滑角度-位移插值控制，在不依赖外部定位设备的条件下实现高精度赛道跟随。为提升调试效率，系统设计了基于十字链表的多级菜单与Flash参数存储系统，支持PID参数、道路类型与速度档位的在线实时修改与非易失存储。大量实车测试表明，该智能单车系统运行稳定可靠，能够自主、高效地完成科目一往返行驶任务、科目二固定路径行驶与科目三多路况往返行驶任务，充分验证了方案的可行性与先进性

软件设计
4.1 软件总体思路
单车定向组的软件系统需要考虑两个核心挑战：一是如何通过前轮转向维持单车的侧向动态平衡，二是如何在维持平衡的前提下精确跟踪预定路线。这本质上是两个耦合控制目标的协调问题——平衡控制需要高频响应和较大的转向权限，而路径跟踪需要根据全局位置信息规划长周期的航向目标。如果两者协调不当，要么路线跟踪精度差，要么平衡稳定性不足。
为了体现英飞凌TC264双核单片机的计算性能以及多任务并行处理能力，我们采用了前后台结合定时中断的软件架构。CPU0承担全部核心控制任务，通过两级定时中断实现不同时间尺度上的控制计算：1ms中断作为系统的“心跳”，以1000Hz的频率执行最内层的传感器读取、PID计算和执行器输出更新，确保平衡控制的高实时性；5ms中断以200Hz的频率执行姿态解算和里程计累积，为上层导航提供位置和姿态估计。主循环则运行在20ms（50Hz）的较低频率上，负责控制策略的切换、菜单界面刷新和数据记录输出。
这种分层架构的设计思想是：将与安全直接相关的平衡控制放在最高优先级、最可靠的中断上下文中执行，而将计算量较大但对实时性要求相对宽松的导航决策和界面显示放在主循环中处理。当CPU负载过高时，主循环的任务会自然降速，但中断中的平衡控制始终以固定频率运行，确保单车在任何情况下都不会因计算资源不足而失去平衡。这一设计在实践中被证明是可靠有效的：即使在主循环中同时运行菜单显示和GPS数据解析时，中断服务程序的执行时间仍稳定在600us以内，远低于1ms的中断周期，留有充足的时间裕量。
系统上电后的初始化流程为：时钟初始化（获取系统时钟频率）→ 调试串口初始化 → GPIO初始化（电机电源使能引脚拉高）→ 滤波器初始化（速度滤波器和陀螺仪Z轴滤波器）→ ICM42688陀螺仪初始化与自检 → Mahony姿态解算算法初始化 → 机器人里程计位置初始化 → 菜单系统初始化（屏幕初始化、按键初始化、Flash读取参数恢复、菜单链表构建）→ 级联PID结构体初始化 → PWM和编码器外设初始化 → 舵机初始化 → 定时中断初始化（5ms位置更新中断和1ms核心控制中断）→ 等待双核同步就绪 → 进入主循环。
4.2 各部分软件模块设计
4.2.1平衡控制算法
单车的平衡维持是依靠程序精确控制前轮舵机的转向角度。根据自行车动力学的经典理论，单车的侧向平衡可以通过前轮转向进行主动控制。[1]当车身向右侧倾斜时（Roll角为正），控制系统驱动舵机使前轮向右偏转，单车开始向右转弯，产生的离心力将车身向左推回中位。反之，当车身向左倾斜时，前轮向左偏转，向左转弯产生的离心力将车身向右推回。这一控制原理与人类骑自行车时的“反向转向”（counter-steering）操作完全一致：要向右转时，骑行者先下意识地向左微微转动车把，使车身向右倾斜，然后车把自然回正并向右转完成变向。
为了实现这一动态平衡控制，我们采用了三闭环串级PID控制架构。串级PID算法是将多个PID控制器按照一定的顺序串连起来，其中前一个PID控制器的输出作为后一个PID控制器的输入，从而实现级联控制。[2]当需要控制多个相关联的变量且最终执行元件只有一个时（在本系统中，执行元件就是舵机），串级PID是一种行之有效的解决方案。我们将角度环、角速度环和转向环串联起来，以实现单车的平衡和精确转向控制。
在串级PID控制中，通常根据响应速度和需求优先级来确定各个环的顺序。在本系统中，三个闭环从外到内依次为：
转向环（最外环）：该环以航向角偏差（目标航向角与当前偏航角Yaw的差值）为输入，输出为目标侧倾角（期望的车身Roll角度）。转向环的响应最慢，因为它处理的是路径跟踪这一宏观目标——车身需要向哪个方向倾斜才能转弯朝向目标航向。转向环的输出（目标侧倾角）被限制在安全的物理范围内（通常为±25度），防止要求过大的倾斜角导致车身失控摔倒。
倾角环（中间环）：该环以目标侧倾角与实际侧倾角（通过陀螺仪姿态解算得到的Roll角减去机械零点偏移ROLL_OFFSET）的偏差为输入，输出为目标角速度。倾角环决定车身需要以多快的速度向目标倾斜角靠拢。当目标倾角与实际倾角偏差较大时（例如从直道进入弯道），倾角环输出较大的目标角速度，使车身快速倾斜至期望角度；当偏差减小时，目标角速度随之减小，车身平滑稳定在目标角度附近。倾角环的输出被限制在合理的角速度范围内。
角速度环（最内环）：该环以目标角速度与陀螺仪实测Roll轴角速度的偏差为输入，输出为舵机角度补偿值，直接叠加到舵机中位90度上。角速度环响应最快，直接抑制由路面颠簸、风力扰动或参数切换引起的高频角速度波动，起到“阻尼器”的作用。
这种串级结构的优势在于每个控制环的功能相对独立，参数调试更为简便。通常情况下，仅需调整每个环的P（比例）参数，就能实现较好的平衡效果。此外，内环的积分项可以消除稳态静差，防止单车在直道上出现持续的微小倾斜。然而，串级PID也存在一个问题：当车辆快速通过凸起路面或草地时，轮胎可能短暂离地或附着力突降，此时转向控制的实际效果会大打折扣，但控制系统并不知晓这一情况，继续按目标值输出控制量。一旦轮胎恢复抓地力，之前累积的积分输出会导致舵机瞬间打向极端角度，引发单车的剧烈摆动甚至摔倒。
了解问题根源后，我们采取了多种针对性措施。首先，将速度环（行进电机速度控制）独立于串级控制之外，使用增量式PID，避免速度环的积分累积影响平衡。其次，在级联PID计算中引入了目标倾角变化率限制（Slew Rate Limiter）：每次计算时检查目标倾角的变化量，若超过预设的最大步长（1度/步），则强制限制为该步长值。这一机制能彻底吸收PID参数切换或外部扰动引起的瞬时突变，防止因目标值跳变导致车身剧烈晃动而摔倒。最后，系统中添加了姿态安全保护：当检测到车身Roll角绝对值超过30度时，自动关闭动力输出（power_flag=0），舵机回中，电机停止，进入安全保护状态，等待人工扶正后重新启动。
核心的级联PID计算函数实现如下。该函数整合了三个PID环、tanh非线性平滑项、偏航角速度阻尼补偿和目标倾角变化率限制等全部机制：
float PID_Cascade_Calculate(PID_Cascade_HandleTypeDef *hcpid,
                           float steer_measure, float roll_angle_measure,
                           float roll_rate_measure,
                           float yaw_rate_raw,
                           Subject_Mode_e current_subject)
{
    hcpid->steer_measure = steer_measure;
    hcpid->roll_angle_measure = roll_angle_measure;
    hcpid->roll_rate_measure = roll_rate_measure;
    time_pid_move++;

    if(time_pid_move % 20 == 0) {
        // 1. 转向环PID计算
        float base_pid_target = PID_Position_Calculate(
            &hcpid->steer_pid, hcpid->steer_target, hcpid->steer_measure);

        // 2. tanh非线性平滑项
        float error = hcpid->steer_target - hcpid->steer_measure;
        float nonlinear_term = 0;
        if (hcpid->steer_tanh_delta != 0) {
            nonlinear_term = hcpid->steer_tanh_lambda
                           * tanhf(error / hcpid->steer_tanh_delta);
        }

        // 3. 偏航角速度阻尼
        float damping_val = yaw_rate_raw * hcpid->steer_yaw_damping;

        // 4. 合成原始目标倾角
        float raw_target_roll = base_pid_target + nonlinear_term - damping_val;

        // 5. 限幅
        if(raw_target_roll > hcpid->steer_pid.output_max)
            raw_target_roll = hcpid->steer_pid.output_max;
        if(raw_target_roll < hcpid->steer_pid.output_min)
            raw_target_roll = hcpid->steer_pid.output_min;

        // 6. Slew Rate Limiter：目标倾角变化率限制
        const float MAX_ROLL_STEP = 1.0f;
        float diff = raw_target_roll - hcpid->roll_angle_target;
        if (diff > MAX_ROLL_STEP)
            hcpid->roll_angle_target += MAX_ROLL_STEP;
        else if (diff < -MAX_ROLL_STEP)
            hcpid->roll_angle_target -= MAX_ROLL_STEP;
        else
            hcpid->roll_angle_target = raw_target_roll;
    }

    if(time_pid_move % 5 == 0) {
        // 7. 中间环：倾角PID + 前馈
        float angle_pid_out = PID_Position_Calculate(
            &hcpid->roll_angle_pid,
            hcpid->roll_angle_target,
            hcpid->roll_angle_measure);
        float roll_target_delta =
            hcpid->roll_angle_target - hcpid->last_roll_target;
        float angle_ff = roll_target_delta * hcpid->angle_Kf;
        hcpid->last_roll_target = hcpid->roll_angle_target;
        hcpid->roll_rate_target = angle_pid_out + angle_ff;
    }

    if(time_pid_move % 1 == 0) {
        // 8. 内环：科目二双环，科目三三环
        if (current_subject == SUBJECT_2) {
            hcpid->final_output = hcpid->roll_rate_target;
        } else {
            hcpid->final_output = PID_Position_Calculate(
                &hcpid->roll_rate_pid,
                hcpid->roll_rate_target,
                hcpid->roll_rate_measure);
        }
    }
    return hcpid->final_output;
}
其中值得特别说明的是tanh非线性平滑项的设计考量。在标准的PID控制中，比例项输出与误差呈线性关系，这意味着当航向偏差很大时（例如180度掉头），P项输出也会成比例地变得非常大，导致目标倾角远超安全范围。虽然可以通过输出限幅来截断，但截断后的控制特性是“饱和”的——无论偏差是90度还是180度，控制量都一样大，这显然不是最优的控制策略。tanh函数的数学特性恰好能解决这一问题：在偏差较小时，tanh近似线性（斜率近似为1），保持了PID在小偏差下的精确调节能力；在偏差增大时，tanh的输出逐渐趋于饱和值（±1），确保了控制量不会随偏差的继续增大而无限增长。通过调节tanh_lambda（非线性强度）和tanh_delta（归一化范围）两个参数，可以灵活调整非线性特性的“拐点”位置和平滑程度。
偏航角速度阻尼是另一项重要的创新设计。当单车高速行驶时，车身的偏航角速度（绕Z轴旋转的速度）如果过大，会导致后轮侧滑和前轮失去方向控制力。通过将偏航角速度乘以阻尼系数后负反馈至目标倾角，可以在高速过弯时自动减小目标倾角，降低车身倾斜程度，抑制过于激进的转向动作，从而提升高速行驶的稳定性。阻尼系数可以根据不同道路类型配置不同的值：在草地等低附着力路面上使用较大的阻尼系数，确保转向动作更为保守和稳健。

4.2.2转向控制算法
前一节介绍了级联PID如何将航向偏差转换为舵机角度输出，但航向偏差值本身的生成也需要精心设计。如果目标航向角发生突变（例如从一段路径切换至下一段路径时），直接将突变的航向偏差送入PID控制器会导致舵机剧烈摆动，车身随之大幅晃动，严重时直接摔倒。
为此，系统设计了转向误差平滑处理函数steer_error_smooth()。该函数位于航向偏差的产生与PID控制器输入之间，充当一个“低通滤波器”的角色。其工作原理是：每个控制周期比较目标航向误差（steer_error_target）与当前实际输出的航向误差（steer_error_current），若两者之间存在差值，不直接令输出等于目标，而是以可配置的增量步长（steer_inc_step）或减量步长（steer_dec_step）逐步逼近目标值：
void steer_error_smooth(void)
{
    steer_error_cnt++;
    if (steer_error_cnt >= 1) {
        steer_error_cnt = 0;
        float error_diff = steer_error_target - steer_error_current;

        if (error_diff > 0.0001f) {
            float inc_step = (error_diff < steer_inc_step)
                           ? error_diff : steer_inc_step;
            steer_error_current += inc_step;
        }
        else if (error_diff < -0.0001f) {
            float abs_diff = -error_diff;
            float dec_step = (abs_diff < steer_dec_step)
                           ? abs_diff : steer_dec_step;
            steer_error_current -= dec_step;
        }
        else {
            steer_error_current = steer_error_target;
        }
    }
}
该函数的增量步长和减量步长并非固定值，而是由PID参数调度器根据当前车速和路况动态设定的。在高速直道上，步长设置较小，转向变化平缓，防止车身晃动；在S弯绕桩区域，步长设置较大，允许快速响应锥桶位置的变化。这种动态调节机制使得单车能在“稳定性”和“灵活性”之间自动取得最优平衡。

4.2.3速度控制算法
单车的行进速度控制采用独立的增量式PID控制器，与转向-平衡的串级PID并行运行。速度环以目标速度（set_speed_current）为输入，以编码器实测速度（encoder_data2经过低通滤波后的值）为反馈，输出电机PWM占空比：
PID_Increment_Init(&speed_pid,
    1.2f, 0.006f, 0.0f,
    100.0f, -100.0f, 5.0f, 2.0f, 0.0f);
速度环使用增量式而非位置式PID的一个重要原因是防止积分饱和。在单车启动、停车和经过复杂路况时，目标速度可能频繁变化，位置式PID的积分项容易在速度偏差较大时积累过大的积分值，导致停车后电机仍在持续输出。增量式PID每次仅计算输出增量，不依赖长期的历史误差积分，天然具备更好的动态响应特性。
此外，为了防止目标速度的突变对平衡控制的冲击，系统在目标速度（set_speed）与实际期望速度（set_speed_current）之间添加了一个缓变环节speed_slow()。该函数通过设置加速步长（SPEED_ERROR_INC_STEP = 30.0）和减速步长（SPEED_ERROR_DEC_STEP = 0.05），确保实际速度目标平滑过渡。有趣的是，加速步长远大于减速步长——加速时允许较快的速度爬升（每控制周期增加30），而减速时则非常缓慢（每周期仅减少0.05）。这是因为突然加速对平衡的冲击相对较小，而突然减速（急刹车）会导致车身因惯性前倾，极易引发前后方向的失稳。
4.2.4导航算法
单车定向组的核心挑战在于如何在保持平衡的前提下精确跟踪各种形状的道路。本系统针对此次比赛赛道较小的特性，使用航位推算策略。
航位推算不使用GPS等外部定位设备，完全依赖车载传感器进行位姿推算：以ICM42688陀螺仪解算得到的航向角（Yaw）确定车头朝向，以磁编码器里程计累积行进位移，通过对航向角与位移的实时积分，推算单车在全局坐标系中的当前位置。[3]航位推算的核心是分段平滑角度-位移插值控制——将整条赛道划分为若干直线段与圆弧段，为每一段预先设定目标航向角与目标位移，单车根据当前航向偏差与剩余位移，在相邻目标航向角之间进行平滑插值，从而连续、平稳地驱动舵机沿预定路径行驶。
航位推算的主要局限性在于编码器累积误差。由于车轮在转弯时存在侧滑、在草地和坡道上存在打滑现象，编码器读数并不能精确反映单车在全局坐标系中的实际位移。但对于今年单车定向组的固定赛道，这些误差在短距离内（30米以内）的累积量尚在可接受范围内，通过精细标定和分段校准，定位误差可控制在分米级别。
4.2.5 PID参数实时调度
单车的控制参数（PID增益、限幅值、阻尼系数、平滑步长等）在不同的行驶速度、不同的道路类型下需要不同的最优取值。例如，高速直道时转向灵敏度应降低以防止振荡，而低速过锥桶时需要更高的转向响应速度以保证绕桩精度。如果使用一套固定的PID参数覆盖所有行驶工况，必然在某些工况下性能不佳。
为解决这一问题，系统建立了一套完整的PID参数表格体系，为每种科目和道路类型预定义了不同速度档位下的最优参数组合。参数表格的结构定义包含了所有可调控制参数的完整集合：
typedef struct {
    float speed_threshold;          // 速度档位阈值
    float steer_inc_step;           // 转向增量步长

系统为每种应用场景准备了独立的参数表数组。以科目三为例，针对五种不同路况（正常路NORMAL、掉头BACK、草地GRASS、S弯S_ROAD、坡道UPHILL），各准备了2至4组按速度分档的参数，总计超过15组独立配置。每组参数都经过反复的实车测试和精细调校确定，代表了该特定工况下的最优控制律。
然而，离散分档的参数表存在一个天然缺陷：当实际车速恰好位于两个速度档位之间时，系统只能选择使用较低档或较高档的参数，控制效果并非最优。特别是当车速缓慢变化跨过档位阈值时，参数的阶跃切换会导致控制量的瞬时跳变。虽然前述的无扰切换算法能缓解这一问题，但更根本的解决方案是消除参数切换的阶跃本身。
为此，我们实现了基于线性插值的实时PID参数调度器Bike_PID_Scheduler()。该调度器的核心创新在于：当实际车速位于两个基准速度档位之间时，不是简单地选择其中之一，而是根据车速在两者之间的线性比例，实时插值计算出连续的PID参数值：
该调度器在1ms中断中执行，计算开销极小（主要是几次浮点乘法和条件判断），不会影响控制实时性。通过实时插值调度，单车的控制参数随着车速变化连续平滑地渐变，彻底消除了参数阶跃切换带来的瞬态冲击。
与插值调度配套的无扰切换函数PID_Update_Gains()也包含了精巧的设计：
void PID_Update_Gains(PID_Position_HandleTypeDef *hpid,
                      float Kp, float Ki, float Kd,
                      float out_max, float int_max)
{
    // 核心：吸收Kp切换带来的瞬间跳变
    float old_p = hpid->Kp * hpid->error[0];
    float new_p = Kp * hpid->error[0];
    hpid->integral += (old_p - new_p);

    // 更新参数
    hpid->Kp = Kp; hpid->Ki = Ki; hpid->Kd = Kd;
    hpid->output_max = out_max;
    hpid->output_min = -out_max;
    hpid->integral_max = int_max;

    // 防止补偿后积分越限
    if (hpid->integral > hpid->integral_max)
        hpid->integral = hpid->integral_max;
    if (hpid->integral < -hpid->integral_max)
        hpid->integral = -hpid->integral_max;
}
无扰切换的思想是：当Kp从旧值切换为新值时，如果直接替换，P项输出将从旧Kp × 当前误差跳变至新Kp × 当前误差，这个跳变量直接叠加到控制输出上，引起舵机瞬时偏移。为了解决这一问题，函数在更新Kp的同时，将P项跳变的差值反向补偿至积分项中。这样一来，P项的跳变被积分项的等量反向变化完全抵消，控制器输出保持连续不变。此后，由于新的Kp生效，后续的控制输出将在新的控制律下平滑演进。这一机制确保了参数切换的绝对平滑性，是实现全工况自适应控制的关键技术环节。

总结
在第二十一届全国大学生智能汽车竞赛中，闪电龟龟队围绕单车定向组赛事要求，完整完成了机械结构优化、硬件电路搭建、软件算法开发与整车系统调试的全流程设计工作。本车基于N1型平衡车模平台，以英飞凌TC264主控芯片为核心，搭建了一套稳定、高效的整车控制系统。系统通过ICM42688陀螺仪与磁编码器实现多源姿态信息融合，并采用串级三闭环PID控制算法，完成自平衡车姿态、速度与位置的高精度动态调控。
本届赛事是单车组别时隔多年再度回归赛场，相较于第十八届赛事车型，新版车模取消了动量轮结构，并新增八字慢速绕桩科目，对车辆低速稳定性、姿态收敛性与平衡控制精度提出了更高要求，整体控制难度显著提升。
开发过程中，团队依托AURIX™ Development Studio开发环境，结合VOFA上位机数据可视化工具与自研车载按键调试菜单，实现了控制参数的实时监测、在线修改与快速整定，大幅提升了整车调试效率与问题排查速度。在整车调试阶段，团队先后攻克变速直立稳定性差、坡道行驶速度难以精准控制等多项难点，通过反复实验与算法优化，逐步完善整车控制性能，保证车辆在直线竞速、八字绕桩、颠簸路段等多场景下的稳定运行。
同时，本次设计仍存在可优化空间：现阶段采用的纯航位推算方案存在积分漂移问题，长距离行驶后位置误差累积明显，路径追踪精度仍有提升空间。后续团队将针对导航算法进行迭代优化，融合多传感器校正策略，进一步抑制漂移、提升轨迹跟随精度与整车鲁棒性。
