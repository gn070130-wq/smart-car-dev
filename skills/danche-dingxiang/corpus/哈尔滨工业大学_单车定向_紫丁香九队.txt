第一章 引言
全国大学生智能汽车竞赛作为一项融合了控制、模式识别、传感技术、电子、电气、计算机、机械等多学科知识的科技创意性竞赛，始终秉持“立足培养，重在参与，鼓励探索，追求卓越”的指导思想，旨在激发大学生的科研潜能与创新意识，培养其综合知识运用能力与工程实践能力。
本届竞赛的单车定向组别，要求参赛队伍在指定的单车模型平台上，以英飞凌（Infineon）公司的微控制器为核心，设计并制作一台能够自主完成指定路径任务的智能单车。本组别最大的挑战在于取消了动量轮辅助，车模需完全依靠转向舵机产生的离心力来维持高速与低速行驶下的动态平衡，并精准完成直线行驶、八字绕桩及复杂路况穿越等任务。这一规则变化对车模的机械结构、控制算法及传感器融合策略提出了更高的要求。
本技术报告将围绕单车定向组的赛题要求，从机械结构调整、硬件系统设计、软件控制算法及系统调试等方面，详细阐述我们车模的设计方案与实现过程，并总结在备赛过程中积累的经验与心得，以期为后续的参赛选手提供有益的参考与启发。
第二章 车模整体设计
2.1设计思路
针对单车定向组的挑战，我们选用N1车模并遵循“机械降重稳重心、串级控制保平衡、多源融合精定位”的核心思路。
在机械层面，通过优化N1车模结构布局，降低整车重心，为动态平衡创造物理基础。在控制层面，采用基于角速度与角度的串级PID算法，利用舵机转向产生的离心力抵消倾倒力矩，实现自稳定。在导航层面，摒弃外部定位依赖，使用惯导方案。
2.2技术方案概要
1.硬件平台：控制器以英飞凌TC364为核心，利用其浮点运算优势处理复杂惯导解算。传感器包含IMU与编码器；执行器选用舵机与无刷电机，兼顾平衡响应与动力输出。
2.核心算法：
（1）平衡控制：采用串级PID控制：角速度环－角度环－转向环。
（2）惯性导航：采用Stanley跟踪算法。

第五章 系统软件设计及算法实现
高效稳定的控制程序和高适应性的算法是智能车快速平稳运行的基础。我们设计的智能车采用英飞凌公司生产的TC364芯片作为控制器，利用陀螺仪和磁编两个传感器进行惯性导航，实现三个科目的运行。为使小车快速平稳运行，我们使用了磁编测速对小车进行速度闭环。速度和方向控制算法方面，我们采用工业控制广泛采用的经典PID算法，配合理论计算与实际参数调试过程使程序和小车充分契合，使智能车达到快速平稳运行的目的。

5.1控制算法
5.1.1 PID算法介绍
在过程控制中，PID控制器是一种应用最为广泛的一种控制器，也是众多控制算法中应用最为普遍的控制算法当被控对象的结构和参数不能完全掌握，或得不到精确的数学模型时，控制理论的其他技术难以采用时，系统控制器的结构和参数必须依靠经验和现场调试来确定，这时应用 PID 控制技术最为方便。即当我们不完全了解一个系统和被控对象，或不能通过有效的测量手段来获得系统参数时，最适合用 PID 控制技术。 PID控制，实际中也有 PI 和 PD 控制。 PID 控制器是一种线性控制器，它根据给定值与实际输出值构成控制偏差。 将偏差的比例（P）、积分（I）和微分（D）通过线性组合构成控制量，对被控对象进行控制，故称 PID 控制器。 
由于单片机控制是采样控制，只能根据采样时刻的偏差控制输出量，不能计算连续输出量，所以要采用离散化的PID算法。离散PID分为位置式和增量式两种。位置式的输出量直接就是控制量，由于全量输出，所以每次输出均与过去的状态有关，计算时要对过去偏差进行累加，计算机工作量大；而且因为计算机输出量对应的是执行机构的实际输出，如计算机出现故障，输出大幅度变化会引起执行机构位置的大幅度变化，这种情况往往是生产实践中不允许的，在某些场合，还可能造成严重的生产事故。因而产生了增量式 PID 控制的控制算法，所谓增量式PID是指数字控制器的输出只是控制量的增量。由于计算机输出增量，所以误动作时影响小算式中不需要累加。控制增量的确定仅与最近k次的采样值有关，所以较容易通过加权处理而获得比较好的控制效果。
5.1.2方向控制
方向控制采用PD控制，根据所打点位，小车位置和车身偏航角，利用Stanley算法得出方向偏差，通过PID计算作用在舵机上，使车转向达到预期行进方向。
5.1.3 PI速度控制
由于增量式PID相对于位置式PID有明显的优势，所以我们选择增量式PI作为速度控制算法，用磁编码器获取速度作为反馈量，实现闭环控制。

平衡环位置式PID
uint32 spd_WPID(RollSpd_par *Pidparameter,float error){
    uint32 pwm = 0;
    (*Pidparameter).proErr=(*Pidparameter).Err;
    (*Pidparameter).Err = -(error) + roll_spd;
    int adjusted_KP = 0;
    adjusted_KP = (*Pidparameter).KP + (*Pidparameter).dy_KP * motor_par.Target;
    (*Pidparameter).P = adjusted_KP * (*Pidparameter).Err;
    (*Pidparameter).D = (*Pidparameter).KD * ( (*Pidparameter).Err - (*Pidparameter).proErr );
    (*Pidparameter).Out = (*Pidparameter).P + (*Pidparameter).D;
    pwmChange = Pidparameter->Out;
    pwm = steerMid - pwmChange;
    if(pwm > steerMax){
        pwm = steerMax; }
    else if(pwm < steerMin) {
        pwm = steerMin; }
    return pwm}
速度环增量式PID
void ZPID(Motor_par* Pidparameter,int32 encoder_pulse){
    int16 pwm = 0;
    (*Pidparameter).Last = (*Pidparameter).Current;
    (*Pidparameter).Current = encoder_pulse;
    if((*Pidparameter).Current > 5000){
        (*Pidparameter).Current = (*Pidparameter).Last; }
    (*Pidparameter).Current = 0.25*(*Pidparameter).Current + 0.75*(*Pidparameter).Last;
    (*Pidparameter).dy_change = (*Pidparameter).dy_Kc * ANGLE[0];
    (*Pidparameter).Bias_2=(*Pidparameter).Bias_1;
    (*Pidparameter).Bias_1=(*Pidparameter).Bias_0;
    (*Pidparameter).Bias_0 = (*Pidparameter).dy_change + (*Pidparameter).Target - (*Pidparameter).Current;
    (*Pidparameter).P = (*Pidparameter).KP * ( (*Pidparameter).Bias_0 - (*Pidparameter).Bias_1);
    (*Pidparameter).I = (*Pidparameter).KI * (*Pidparameter).Bias_0;
    (*Pidparameter).D = (*Pidparameter).KD * ( (*Pidparameter).Bias_0 - 2 * (*Pidparameter).Bias_1 + (*Pidparameter).Bias_2) ;

    (*Pidparameter).Out += (*Pidparameter).P + (*Pidparameter).I + (*Pidparameter).D;
    if((*Pidparameter).Out > 7000) {
        (*Pidparameter).Out = 7000; }
    if((*Pidparameter).Out < 500){
        (*Pidparameter).Out = 500; }
    pwm = (int16)roundf(Pidparameter->Out);
    motorPwm = pwm;
    small_driver_set_duty(pwm,pwm)}
