第一章 引言
全国大学生智能汽车竞赛是面向高校自动化、电子信息等相关专业的综合性科技竞赛，竞赛以智能车实物制作为载体，融合机械结构设计、硬件电路开发、传感器信号处理、自动控制算法、嵌入式软件开发等多学科知识，是检验学生工程实践能力、创新设计能力与团队协作水平的重要平台。第二十一届全国大学生智能汽车竞赛单车定向组，以室外动态自平衡自行车为竞赛载体，要求车辆不依靠飞轮、风扇等外部辅助平衡机构，仅依靠后轮驱动与车把转向实现动态直立平衡，需要完成直线往返竞速、八字慢速绕桩、颠簸复杂路段等竞赛科目。赛场处于真实室外环境，面临光照变化、路面颠簸、坡道、草地打滑等多重干扰，对车模机械结构、硬件抗干扰能力以及平衡控制算法的鲁棒性都提出了较高的要求。
本文设计并实现了一套基于英飞凌 TC264 双核 MCU 的室外定向自平衡智能单车。硬件采用主控板与驱动板分体式架构，TC264 作为主控负责姿态解算、路径规划与上层控制逻辑，CYT2BL3CA 作为从机控制器专门完成无刷电机底层驱动；完成电源电路、IMU 姿态采集电路、磁编码器角度采集电路、三相无刷电机驱动电路的设计与调试。软件部分基于 AURIX Development Studio 开发环境，完成陀螺仪原始数据滤波、梯度下降四元数姿态解算，搭建角速度-横滚角度-航向偏航的串级三环 PID 平衡控制系统，实现多工况自适应参数切换，结合惯导 Stanley 路径跟踪算法完成赛道循迹，同时配套 WiFi 上位机、逐飞助手实现参数在线调试。经过多轮机械配重调整、硬件迭代与算法优化，车辆能够完成直线竞速、八字慢速绕桩、颠簸复杂路段等竞赛任务，满足第二十一届智能车单车定向组的赛题要求。


第二章 车模设计与技术方案
2.1 系统概述
第二十一届智能车竞赛单车定向组为室外动态自平衡自行车赛题，禁止飞轮、风扇等辅助平衡手段，车辆仅依靠后轮驱动与车把转向实现动态平衡，需完成直线往返竞速、八字慢速绕桩、颠簸复杂路段三项分赛区科目，赛道设置操场水泥地、坡道、草地、锥桶等复杂室外环境，存在光照变化、地面颠簸、车轮打滑等干扰，对车辆姿态解算、多工况平衡控制、硬件抗干扰能力提出较高要求，考验车辆高速行驶稳定性与低速大转向工况下的鲁棒性，要求系统可适配不同赛道工况完成轨迹跟踪，规避倒地、冲出赛道、碰撞锥桶等犯规问题。
本设计主控单元选用英飞凌 TC264，驱动子板搭载 CYT2BL3CA 作为从机控制器。TC264 属于 AURIX 系列双核安全 MCU，具备强大的实时运算能力，可高效完成 IMU 姿态解算、串级 PID 平衡算法以及路径规划等复杂任务，丰富的外设接口能够满足多传感器采集、串口通信等功能需求，同时该芯片为智能车竞赛官方指定主控，生态资料完善，可靠性高，适合室外单车定向项目高实时性的控制场景；驱动板选用 CYT2BL3CA，该芯片运算性能强，外设资源充足，能够独立接收主控下发的串口指令，快速输出多路 PWM 信号，完成无刷电机驱动逻辑处理，分担主控的运算压力，实现主控与驱动的软硬件解耦，分体板架构下既保障主控专注于上层算法，又让驱动板就近完成电机底层控制，减少长距离 PWM 信号传输带来的电磁干扰，提升整套系统的稳定性与响应速度。
此外，我们还使用了IMU660RA（BMI270）六轴陀螺仪，用于小车保持和循迹控制。

第三章 机械系统设计
3.1 整车结构
本次单车定向赛选用 N1 官方车模作为参赛载体，原厂出厂的 N1 车模结构预留空间有限，需要自主完成多处结构改造优化。为规整排布主控板、显示屏、电机驱动板、编码器等各类电子模块，我们定制裁切了专用亚克力安装固定板，通过铜柱将亚克力板与原车底盘刚性固定，既实现各模块有序分层安装，也方便后续线路整理与硬件调试。
考虑到电池自重较大，为平衡车身左右两侧配重、消除偏载带来的行驶偏差，同时降低整车重心、提升轮胎地面抓附力，我们将电池横向布置于车底低位区域，进一步优化小车行驶稳定性。

图3.1 整车结构
3.2舵机安装
本届第二十一届智能车竞赛单车定向组别赛事中我们选用 N1 专用车模参赛，赛场环境包含室内篮球场、室外田径场 400 米跑道两类场景，路面工况存在差异，对转向系统的耐用性与控制精度要求更高。舵机选型上我们采用 BDS300 金属舵机，对比普通塑料舵机，金属壳体与内部传动结构抗冲击、抗磨损能力更强；小车在不同场地高速行驶时转向动作频繁、负载波动大，金属舵机长期工作损耗更低，转向控制的稳定性更有保障。
舵机本体、配套舵机摆臂均选用金属材质，以此提升整套转向机构的结构刚度与运行可靠性，避免高速转向时结构形变带来的控制偏差。BDS300 舵机固定于车头原厂铝合金支架，舵机输出轴安装舵盘，舵盘与前轮转向摆臂刚性连接；前轮支架通过轴承铰接在底盘上，可实现左右摆动。当舵机输出轴旋转时，舵盘带动转向摆臂摆动，驱动前轮支架绕铰接点偏转，改变前轮朝向，以此调整小车行驶方向。
结合赛事规则要求，N1 车模底盘主体结构不可私自改造，舵机沿用车模原生安装位完成固定（如图中车头转向总成结构所示），机械传动间隙小；上层主控、驱动电路板通过定制亚克力板 + 铜柱独立分层安装，与前端舵机转向机构互不干涉，既满足规则限制，又保障了转向系统独立稳定工作，适配篮球场与室外跑道多场景的行驶需求。

图3.3 N1 车模陀螺仪安装
姿态传感器选用 IMU660RA 陀螺仪，陀螺仪用于采集车身横摆、倾斜等整体姿态信息，为姿态解算、航向控制提供原始数据。为减小车体振动、安装偏心带来的测量误差，将 IMU660RA 布置在车身几何中心位置，安装平面尽量保持水平，采用紧固件压紧固定，避免车辆行驶过程中出现松动晃动，保障陀螺仪采集姿态数据的准确性与可靠性。

第四章 电路系统设计
从最初进行硬件电路设计时我们就既定了系统的设计目标：可靠、高效、简洁，在整个系统设计过程中严格按照规范进行。可靠性是系统设计的第一要求，我们对电路设计的所有环节都进行了电磁兼容性设计，做好各部分的接地、屏蔽、滤波等工作，将高速数字电路与模拟电路分开，是本系统工作的可靠性达到了设计要求。
4.1.主板及核心板
电源模块对于一个控制系统来说极其重要，关系到整个系统是否能够正常工作，因此在设计控制系统时应选好合适的电源模块。竞赛规则规定，比赛使用智能汽车竞赛统一配发的标准车模用3s航模电池供电
主板供电分有多个部分。电池的电压约为12.6V，经过TPS5450稳定为7.4V舵机易受整体电源波动的影响，因此需单独再进行稳压。电源经过TPS54302后形成5V供电源给单片机供电，5V再由LM1117稳定为3.3V形成3.3V供电源，给陀螺仪、屏幕供电，
我们设置了按键，OLED 液晶显示屏，以便控制参数的修改，便捷了智能车的调试

4.2 电机驱动
以CYT2BL3CA 单片机为从控制器，以FD6288Q栅极预驱芯片搭配外置N-MOS管为核心的三相 BLDC 无刷电机驱动电路，整体划分为电源供电单元、单片机最小系统、通信接口、电压采样、三相功率驱动单元五大部分，作为分体硬件架构中的驱动子板，接收主控板 TC264 下发的串口指令，完成电机底层驱动控制。
电源部分采用两颗 SY9121E DC-DC 降压芯片，将电池输入VBAT电压分别降压输出两路电源，为单片机、预驱芯片供电；板上设置电阻分压网络实现电池电压采样，用于母线电压监测，完成欠压保护判断，各电源轨搭配磁珠与多级电容组合滤波，抑制开关电源带来的噪声，保障采样与单片机电源稳定。
板载CYT2BL3CA 单片机最小系统，搭载调试下载接口、按键、状态指示灯；通过 UART 串口接收来自主控 TC264 的控制指令；预留磁编编码器接口，读取无刷电机霍尔 / 磁编码器位置信号，获取电机转子角度、转速信息，为 FOC / 方波驱动提供转子位置反馈。
功率驱动部分使用 FD6288Q 三相栅极驱动芯片，单片机输出 PWM 信号送入 FD6288Q 的六路 PWM 输入引脚，驱动芯片内部集成逻辑处理、电平转换以及自举驱动电路，输出六路栅极驱动信号，经过栅极电阻驱动后级 6 颗外置 MOS 管，构成三相全桥逆变电路，把直流母线电压变换为三相交变电压，驱动无刷电机运转；栅极串联电阻抑制 MOS 管开关尖峰，减小电磁干扰。同时预留电流采样引脚，可外接采样电阻实现母线电流采集，用于过流保护、力矩闭环控制。
整体电路实现软硬件解耦，上层主控只负责姿态解算、平衡算法，将电机控制交由驱动板本地 MCU 执行，避免高速 PWM 跨板长距离传输引入干扰，提升整车系统的实时性与工作稳定性。

4.3磁编
磁编码传感器采用 TLE5012BE1000 磁性角度编码器，通过 SPI 总线与主控完成数据交互，RT9013-33GB 稳压芯片提供稳定 3.3V 供电，通信引脚串联电阻用于信号保护与阻抗匹配。该磁编码器能够采集电机转子的绝对角度信号，解算出电机转速与转动位置，既为无刷电机的换相控制提供相位依据，也将转速信息反馈至速度 PID 闭环，实现后轮的转速调节；同时依据转子转动信息计算车辆行驶里程，给惯导位置解算提供里程输入，为整车速度控制、路径跟踪提供可靠的反馈数据源。

第五章 软件算法设计
5.1 传感器的使用
在此次竞赛中，我们使用了逐飞科技的IMU660RA六轴陀螺仪，六轴陀螺仪主要用于获取车身的加速度和通过解算出来的航向角和翻滚角，用于控制小车的平衡和惯导所采集的航向角方向从而达到循迹,采用磁编采集无刷电机的速度传给驱动板，驱动板在通过串口传输给主板。

5.2 控制算法
一、陀螺仪姿态采集与姿态解算算法（Imu.c）
1、原始数据预处理滤波
硬件采用逐飞 IMU660RA（核心 BMI270 六轴传感器），软件双层滤波抑制室外颠簸、电机开关噪声：
单轴陀螺仪一阶低通滤波：Imu_lowpass_filter()函数，采用增量式低通公式out = last + alpha*(raw-last)，滤波系数 0.1 平滑陀螺仪 X 轴角速度，削弱路面冲击带来高频抖动；
加速度计动态自适应滤波：通过is_static_state()判断车身静止 / 运动状态，静止时增大滤波系数、运动时降低，避免高速过弯、坡道下加速度信号失真。
2、梯度下降互补四元数解算算法
核心函数quaternion_module_calculate()实现陀螺仪 + 加速度计融合姿态解算，替代简单互补滤波，提升室外长时间积分精度：
陀螺仪负责短时高精度角速度积分，输出车身横滚、俯仰原始变化量；
加速度计提供重力矢量校正，计算三轴重力误差 ex/ey/ez，采用 KP+PI 动态校正陀螺仪漂移；
动态修正策略：静止状态增大校正 KP 快速收敛，运动状态衰减 KP 避免加速度噪声污染姿态；积分限幅防止误差饱和；
内置分段近似 arctan/arcsin 三角函数，无需浮点库复杂运算，降低 TC264 算力开销；
输出归一化横滚角 rol（车身倾斜）、俯仰角 pit、偏航角 yaw（航向），为平衡、转向、循迹提供全部姿态数据源。
3、角度归一化工具算法
AngleErrorNormalize()将角度误差约束在[-180°,180°，解决 yaw 航向 ±180° 跳变、PID 输出震荡崩溃问题；配套StepApproach()目标角度步进限幅，防止转向突变整车倾倒。
二、舵机转向三环串级平衡控制算法（Subject 系列科目控制）
采用角速度内环→角度中环→偏航转向外环三级串级 PID 架构，1ms、5ms、20ms 分层调度，三环解耦提升低速八字、高速直线两种极端工况稳定性：
角速度内环（1ms 最高优先级）
输入：陀螺仪 X 轴角速度；目标值来自角度环输出；
作用：抑制车身瞬时抖动，快速阻尼颠簸带来的倾斜扰动，是整车稳定基础；
横滚角度中环（5ms 调度）
输入：车身实际横滚倾角；目标值由转向环输出叠加机械零点补偿；
输出直接给到舵机执行机构，通过车把左右转向抵消车身倾倒力矩，实现自行车动态自平衡；
偏航转向外环（20ms 调度）
输入：当前 yaw 航向与路径目标航向的偏差；
输出横滚角目标值，控制整车朝向赛道前进，完成直行、转弯、路径跟踪；
多工况自适应 PID 参数切换
balance_mode_parameter(Mode)函数内置 6 套独立 PID 参数集，对应不同赛道场景：
模式 1/5：直线高速工况，增大角度环响应，提升直行稳定性；
模式 2：八字慢速工况，降低环带宽、减小输出限幅，低速防止倾倒；
模式 4：折返冲刺工况，平衡与速度参数折中；
模式 6：坡道加速工况，加大微分项抵消坡道重力扰动；
程序运行计时sys_times自动切换对应参数，无需人工在线调参。
舵机执行逻辑
Steer_set()将三环 PID 输出叠加舵机中值，限幅约束左右最大转向角度，避免舵机打死、机械卡死；单独封装车身随动函数Body_keep()，仅保留角速度 + 角度环，用于离线路径录制。
三、后轮速度闭环控制算法（Common_peripherals.c）
1、磁编码器速度采集
驱动板 CYT2BL3CA 通过串口回传电机磁编脉冲，QUD_encoder_pulse_get()对速度值做一阶低通滤波，消除脉冲抖动；CYT2_get_distance_mag()通过轮径、减速比换算每 1ms 行驶里程，用于路径积分。
2、速度闭环 PID 控制
CYT2_S_motor_loop_ctrl()构成独立速度环 PID：输入：目标车速；反馈：磁编实测转速；输出无刷电机 PWM 给驱动板；
TC264 主控仅下发速度目标值、转向指令，底层 PWM 生成、MOS 驱动全部交给 CYT2BL3CA 从机，避免长距离高速 PWM 跨板引入电磁干扰，硬件分层匹配软件解耦架构。
四、Stanley 路径录制与循迹导航算法
基于惯导二维坐标积分实现分为路径录制、路径回放双模式：
1、惯导坐标积分
INS_data_get()每毫秒累加行驶距离，结合实时 yaw 航向分解 X/Y 平面位移，记录全局坐标与对应航向角；按固定间隔（录制 3cm / 回放 20cm）存入 Flash，最大存储 1000 组路径点。
2、横向误差 Stanley 跟踪算法
核心cross_error()函数实现 Stanley 横向偏差计算，滑动窗口匹配当前位置附近预存路径点，查找最近轨迹基准点，计算车身相对路径横向偏移量 c_error，引入比例积分消除稳态轨迹偏移，结合前瞻点目标航向生成整车期望 yaw 角，送入三环平衡转向环闭环。
路径启停逻辑
录制模式：按键触发开始，手动结束后将 X/Y/Yaw 数组固化至 Flash 掉电保存；
回放模式：加载轨迹数据，自动重置坐标与积分误差；遍历完所有路径点后电机速度置 0 自动停车；
分层人机交互
Menu.c 搭建多级按键菜单，支持科目切换、路径录制 / 清除、参数调试；IPS 屏幕实时打印姿态、坐标、横向误差；配套 WiFi 上位机在线实时修改 PID 参数，算法调试效率提升。

第八章 参赛心得体会
从备赛初期到省赛完成，我们团队在车模结构、硬件传感器、控制算法、赛道科目逻辑上历经多轮迭代优化，每一次调试暴露的问题都推动着整套系统不断完善，也让我们积累了扎实的工程实践经验。
备赛初期我们采用初代 N 系列车模开展调试，原车模结构存在左右配重失衡的固有缺陷，整车重心偏向一侧，行驶过程中车身会持续向单侧倾斜，极大破坏自平衡控制稳定性。最初我们尝试通过增加配重块弥补两侧重量差，虽能小幅缓解倾斜问题，但配重调节精度有限，车身偏移、倾倒的现象依旧频繁出现，低速八字科目工况下缺陷尤为突出。姿态解算方面，最初选用逐飞 IMU660RC 陀螺仪，直接调用模块自带的解算函数，室外颠簸、电机开关噪声会造成姿态角漂移严重，平衡控制基准不准确，车辆高速行驶抖动、低速极易倒地，整套系统鲁棒性难以满足赛场复杂环境要求。控制逻辑上，科目一往返直线竞速最初未设计航向转向外环，仅依靠固定延时完成掉头动作，车辆转弯轨迹僵硬、转弯半径过大，过弯时车身倾斜风险急剧升高，经常出现冲出赛道、碰撞锥桶的问题。
结束四川省赛之后，我们针对全部短板完成系统性整改。机械结构层面更换全新 N1 标准车模，重新规划电池、电路板、传感器的安装布局，将电池低位居中布置，优化各模块分层安装位置，从根源解决整车左右配重不均、单侧倾斜的核心机械问题；姿态感知硬件升级为逐飞 IMU660RA 六轴传感器，不再依赖厂商自带解算库，自主编写基于梯度下降法的四元数融合解算程序，搭配动态自适应滤波算法抑制路面颠簸、电机电磁干扰带来的采样噪声，有效改善陀螺仪长时间积分漂移问题，姿态角输出精度大幅提升，为平衡 PID 控制提供稳定可靠的数据源。
控制算法上完成核心架构升级，新增偏航转向外环构成角速度 - 横滚角 - 航向三环串级 PID 控制体系，结合航向偏差实现弯道线性减速逻辑。当车辆检测到航向误差较大时自动降低行驶速度，减小过弯时车身倾倒力矩，大幅缩小转弯半径，直行、折返掉头的流畅度与稳定性显著提升。同时将这套带转向外环的三环控制架构同步应用于科目二八字慢速绕桩、科目三颠簸复杂路段，依靠实时航向闭环修正车身轨迹，弱化路面坡度、打滑带来的轨迹偏移，车辆路径跟踪精度明显提高，有效降低冲出赛道、撞桶、倒地等犯规概率。
本次竞赛备赛过程，让我们完整走完从机械结构优化、硬件电路调试、传感器算法开发到多工况控制逻辑迭代的全流程，深刻体会到智能车系统是机械、电子、控制算法深度耦合的整体，单一模块的缺陷会直接放大整车运行问题。同时团队分工协作、反复实测调试的过程，也锻炼了我们排查工程问题、针对性优化方案的能力，理论知识真正落地到实物开发中，收获颇丰。后续我们也会继续优化算法自适应参数逻辑，进一步提升车辆在极限低速、颠簸路面下的运行稳定性。

float StepApproachAngleMode(float target, float real_angle, float step_size, int mode)
{
    static float current = 0.0f;
    static uint8_t init = 0;

    if (!init)
    {
        current = real_angle;
        init = 1;
    }
    float err;
    if (mode == 0)
    {
        err = target - current;
        if (err > 180.0f) err -= 360.0f;
        else if (err < -180.0f) err += 360.0f;
    }
    else if (mode == 1)
    {
        float cw = fmodf(current - target, 360.0f);
        if (cw < 0) cw += 360.0f;
        err = -cw;
    }
    else
    {
        float ccw = fmodf(target - current, 360.0f);
        if (ccw < 0) ccw += 360.0f;
        err = ccw;
    }

    if (fabsf(err) <= step_size)
    {
        current = target;
    }
    else
    {
        current += (err > 0 ? step_size : -step_size);
    }

    if (current > 180.0f) current -= 360.0f;
    if (current < -180.0f) current += 360.0f;

    return current;
}
