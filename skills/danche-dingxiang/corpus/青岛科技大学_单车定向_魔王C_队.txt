第一章  引言
1.1 课题背景
单车定向组要求车辆在限定场地内依靠车载计算、感知和执行机构自主完成定向行驶任务。与四轮车不同，两轮单车在低速和转向过程中存在显著的侧倾—转向耦合，既要保证纵向速度，又要通过前轮转角及时产生侧向支撑，因此系统的实时性、姿态估计质量和控制器协调性直接决定车辆能否稳定运行[1]。
本车采用单车定向 N1 一体成型车架，后轮升级为无刷电机，使用组委会提供的 TC264 核心板作为主控制器。自制主板完成供电、接口与执行机构连接，自制 CYT2BL3 无霍尔无刷单驱完成后轮驱动，ICM42688 六轴姿态传感器提供三轴角速度与三轴加速度，自制 TLE5012B 磁编码器板提供转速/里程反馈。软件基于逐飞 TC264 开源库开发，形成姿态解算、平衡转向、速度闭环、里程航位推算和分段路径控制的完整链路[6]。
1.2 设计目标与主要工作
设计目标是在不改变指定车模基本形式的前提下，实现可靠上电、自主起步、稳定直行、按预设路径转向及异常倒伏停车。围绕该目标，主要完成以下工作：一是调整机械安装位置，使电池、主板和传感器靠近车架中心并降低无效振动；二是设计分级电源、无刷驱动和磁编码器电路；三是建立 1 ms 实时控制框架，融合陀螺仪与加速度计得到姿态；四是采用方向外环—侧倾/转向内环、速度增量式 PID 和航位推算实现定向行驶；五是通过屏幕菜单、无线串口、蜂鸣器和 Flash 参数存储完成调试。
1.3 报告结构
第二章介绍总体方案；第三章说明机械安装与连接；第四章给出电路设计；第五章阐述软件架构及核心算法；第六章总结开发、制作和调试过程；第七章列出模型车主要技术参数；第八章给出结论与改进方向。附录 A 收录三张完整原理图，附录 B 收录核心算法子程序。

第二章  系统总体方案
2.1 设计思路
系统采用“机械低重心布置—多源状态反馈—分层闭环控制—路径状态机决策”的设计思路。主控以 IMU 姿态与后轮速度为快速反馈，以累计里程和航向为导航状态；路径模块给出目标航向和目标速度，方向环把航向误差换算为目标侧倾角，平衡模块再把目标侧倾角换算为前轮舵机角度，速度环则控制后轮无刷电机。目标量通过斜坡函数平滑，避免航向或速度阶跃造成瞬时冲击。

2.3 控制周期与安全策略
CCU6 通道 0 配置为 1 ms 周期中断。每次中断依次更新全局位置和惯性导航状态，读取 ICM42688 并完成四元数姿态解算，执行科目控制、速度反馈滤波、后轮命令输出和里程累计；增量式速度 PID 每 10 次中断更新一次，即 100 Hz。转向舵机 PWM 频率为 300 Hz，无刷驱动通信串口为 460800 bit/s。CPU0 后台持续检查车辆侧倾角，绝对值超过 40° 时置停止状态并清除启动标志，避免倒伏后电机持续输出。

第三章  机械结构与安装
3.1 N1 车模与改造原则
N1 车模采用金属一体成型主车架、前轮转向机构和后轮驱动机构。车架已有用于主板、电池和支架安装的孔位，可减少二次加工造成的几何误差。机械改造遵循轴线对正、结构刚度优先、线束不干涉、重心靠近纵向中心面和易维护五项原则。后轮更换为无刷电机驱动，以提高效率与速度控制性能；前轮保留舵机转向，通过控制前轮转角建立维持侧向平衡所需的轨迹曲率。

第四章  电路设计
4.1 总体电气方案
电气系统由组委会 TC264 核心板、自制单车主板、自制 CYT2BL3 无刷单驱板和自制 TLE5012B 磁编码器板构成。组委会提供的核心 MCU 板不展开内部电路，只说明其与外围板的连接。电池输入进入主板和无刷驱动板；主板生成 5 V、舵机电源、3.3 V 与独立 IMU 电源，无刷驱动板生成自身 5 V、3.3 V 电源并完成三相功率驱动。各板共地，接口按电压域和功能分组[2]。
4.2 单车主板
主板通过双排连接器引出 TC264 的 GPIO、PWM、串口和 SPI 信号。两路 SCT2450 开关降压电路分别提供 5 V 稳压电源与舵机电源，输入端设置 SS54 肖特基二极管，输出端采用电感及大容量电容滤波。RT9013-33 线性稳压器分别产生系统 3.3 V 与 ICM42688 专用电源，降低数字负载变化对惯性测量的影响。姿态传感器使用硬件 SPI0、模式 0、5 MHz 通信，SCLK、MOSI、MISO 和 CS 分别连接 P20.11、P20.14、P20.12 和 P20.13，沿用原 IMU 接口而不额外占用引脚。主板还集成五向开关、蜂鸣器、IPS200 屏接口、GPS 接口、无线串口、编码器接口和无刷信号接口。
4.3 CYT2BL3 无刷单驱
无刷单驱以 CYT2BL3CAx 为控制核心，FD6288Q 作为三相预驱，六只功率 MOS 管组成三相桥。控制器输出三组互补 PWM，经预驱产生高低侧栅极信号；自举二极管和电容为高侧驱动供电。电池输入端并联多只 22 μF 电容并设置 SMAJ16CA 瞬态抑制器，抑制换相电流造成的母线纹波和尖峰。板上 RY9121E 分别产生 5 V 与 3.3 V 电源，UART 用于接收 TC264 的占空比命令并回传后轮速度帧，通信帧采用 0xA5 帧头和累加和校验。
4.4 磁编码器板
磁编码器板采用 TLE5012BE1000 角度传感器。RT9013-33 将接口电源稳压为 3.3 V，C1～C4 完成输入、输出和芯片就地去耦；CLK、CS、MOSI、MISO 通过串联电阻连接至六针接口，5.1 V 稳压二极管提供接口过压保护。编码器角度经驱动板处理后形成后轮速度反馈，主控进一步进行五点滑动窗口求和滤波[3]。
4.5 电源完整性与电容统计
功率回路与控制回路采用分区布置：MOS 管、母线电容和相线构成尽可能短的高电流回路；MCU、晶振、调试口和通信接口远离功率桥。每个电源芯片的输入输出均配置高频陶瓷电容和储能电容，IMU 单独稳压。依据提供的三张原理图逐一按标称值折算，电容统计如下。该数值不包含组委会 TC264 核心板及屏幕、IMU 成品模块内部未给出的电容。

第五章  控制软件设计
5.1 软件架构与任务分配
软件使用 AURIX Development Studio 与逐飞 TC264 开源库，以 C 语言开发。上电后 CPU0 完成时钟与调试串口初始化，再由 all_init 依次初始化通信帧、导航、显示、ICM42688、姿态与控制结构、无线串口、无刷通信、按键、蜂鸣器、舵机、Flash 参数、路径和周期中断。CPU0 后台循环执行倒伏判断与 Flash 服务；CPU1 等待双核同步后循环执行 Path_Init、Buzzer_Judge、Key_scan、调试数据输出和 menu1。实时控制集中在 CPU0 的 1 ms 中断中，避免菜单刷新和 Flash 擦写阻塞控制链路[5]。

5.2 ICM42688 采集与四元数姿态解算
ICM42688 初始化时先保持 CS 为高电平并等待 10 ms，再以 SPI0 模式 0、5 MHz 读取 WHO_AM_I；只有芯片标识为 0x47 才继续配置。加速度计设为 ±16 g、1 kHz，陀螺仪设为 ±2000 °/s、1 kHz，二者进入低噪声模式后最多尝试 10 次有效数据读取；上层 Gyroscope_Init 在失败时最多重试 3 次。正常采集从 ACCEL_DATA_X1 起连续突发读取 12 字节，一次获得六轴原始量，避免分两次访问造成的采样时刻差异[4]。
原始坐标按 Xb=−Ys、Yb=Xs、Zb=Zs 映射到车体坐标；陀螺仪按 16.384 LSB/(°/s) 换算，加速度计按 2048 LSB/g 换算。加速度模长位于 0.9g～1.1g 时判定为近静止，低通系数取 0.8；运动时低通系数取 0.6，并将比例校正降为静止时的 0.8 倍、积分修正降为 0.1 倍，避免转弯向心加速度被误认为重力方向。初始化后的前 0.1 s 使用较强比例校正加快四元数收敛，Z 轴角速度还设置 0.05 rad/s 死区以减小静止偏航漂移。
由当前四元数计算重力在车体坐标系中的投影，与归一化加速度向量作叉乘得到误差 e。横滚与俯仰角速度经比例—积分修正后按 1 ms 步长积分四元数，再进行归一化并转换为横滚、俯仰和偏航角。ICM42688 不含磁力计，重力向量不能校正绕 Z 轴的偏航，因此偏航通道只积分经死区处理的陀螺仪角速度；航向统一归一化到 −180°～180°，解决跨越 ±180° 时的方向突变，但长时间运行仍需评估惯性积分漂移。
5.3 航位推算与路径表示
后轮速度反馈在每个 1 ms 周期内换算为位移增量 Δs，当前航向 ψ 由姿态解算给出。车辆在平面内的位置按公式2更新。路径既可通过示教过程将厘米坐标写入 Flash，也可由 Waypoint_t 数组直接给出触发里程、目标航向、目标速度和转角等待标志。Flash 坐标采用 int16_t、单位厘米，名义量化分辨率为 1 cm。
运行时，系统比较累计里程与下一航点触发距离。若当前航点要求等待转角，只有航向误差小于 5° 才继续累计里程和切换航点，从而防止掉头尚未完成就进入下一段。目标航向采用每次最大 0.5°或按科目设定步长的斜坡过渡，速度采用加速 0.005 m/s、减速 0.008 m/s 的非对称斜坡，提高起步和制动稳定性。
5.4 方向外环与侧倾—转向控制
方向外环首先计算目标航向与当前航向的最短角误差，并在 ±180°边界处修正。PD 控制器把航向误差映射为目标侧倾角，其输出按不同科目限制在 ±10°或±15°，防止方向环要求过大侧倾而导致倒伏。
侧倾—转向模块使用轴距 l=0.211 m、质心距后轮接地点 lm=0.0852 m 和当前速度 v 建模。侧倾误差经自适应 PD 得到等效横向加速度指令；低于 0.5 m/s 时按 0.5/v 放大微分阻尼，并把模型计算速度下限限制为 0.2 m/s，避免分母过小。随后由自行车几何关系求得舵机目标角，反三角函数输入、舵机角和目标侧倾角均设限幅[7]。
舵机中值占空比为 5100，每度增量约 32.333，占空比最终限制在 2000～8000。目标侧倾角还经过 0.01°/ms 的软启动斜坡，避免使能瞬间的转向冲击。
5.5 后轮速度闭环
主控通过 UART3 在初始化时请求无刷驱动连续回传速度帧，驱动默认约每 10 ms 上报一次；接收回调验证 0xA5 帧头及七字节累加和后更新速度。1 ms 中断读取最新反馈并送入长度为 5 的滑动窗口求和滤波。速度目标乘以标定系数 1357.9125，换算为每毫秒反馈单位；增量式 PID 每 10 ms 以当前、上次和上上次误差计算输出增量，输出限制在 ±6000 后由 1 ms 任务持续发送给无刷驱动。
当前速度环参数为 Kp=1.65、Ki=0.03、Kd=0。程序使用 |目标值|×1.3+100 作为动态积分阈值：误差超出阈值时停止积分，避免起步或堵转阶段积分累积；当控制输出方向与误差方向相反时，将积分增益临时放大为 3 倍以加快反向修正。参数同时支持从 Flash 读取，便于针对直线、弯道和掉头速度分别整定。
5.6 状态机与故障处理
Car_State、start_flag、page_5 和当前航点索引共同构成运行状态。路径模块根据科目选择不同的航点表和控制器组合；坡道、绕桩、草地等特殊标志可写入 Flash 并在运行时切换状态。蜂鸣器用于初始化完成、参数操作和阶段提示。侧倾绝对值超过 40°触发倒伏截停；ICM42688 初始化与数据有效性、速度、航向和舵机输出均设置检查或限幅，Flash 数据使用魔数与计数信息校验，通信帧使用累加和校验。

第八章  结论
8.1 工作总结
本车以 N1 两轮车模和 TC264D 为核心，完成了机械安装、主板/无刷驱动/磁编码器三块电路设计，以及 ICM42688 六轴数据采集、四元数姿态解算、速度闭环、方向—侧倾—舵机控制、航位推算和航点状态机的软件实现。系统以 1 ms 周期读取 IMU 并运行姿态与核心控制，以 10 ms 周期更新速度 PID；方向外环生成目标侧倾角，再由带低速增益调度的自行车模型求解舵机角。速度、航向和侧倾目标均采用斜坡过渡，并设置传感器自检、倒伏、通信、Flash 和输出限幅保护。
8.2 特点与不足
方案的主要特点是把单车的方向控制与侧倾平衡统一到目标侧倾角这一中间变量，并针对低速模型奇异性增加有效速度下限和微分阻尼；ICM42688 采用六轴同步突发读取并设置身份与数据有效性检查；路径既可示教存储，也可由航点表配置，便于多科目复用。现阶段不足在于 ICM42688 不含磁力计，航向依赖 Z 轴角速度积分，长距离存在漂移；后轮里程会受轮胎打滑和直径变化影响；部分路径参数仍依赖人工整定。
8.3 后续改进方向
后续可引入磁航向或 GNSS/RTK 的低频校正，与 IMU 和轮速构成误差状态滤波；利用在线曲率和侧倾裕量进行速度规划；对电流、母线电压和温度增加采样保护；通过结构模态检查优化 IMU 安装刚度；建立自动化数据记录与参数辨识流程。

程序B-2  ICM42688 初始化与自检
uint8 icm42688_init (void)
{
    uint8 return_state = 0;
    uint8 data_check_count = 0;
 
    // ICM42688 上电期间 CS 必须保持高电平，避免芯片进入错误的串行接口状态。
    gpio_init(ICM42688_CS_PIN, GPO, GPIO_HIGH, GPO_PUSH_PULL);
    ICM42688_CS(1);
    system_delay_ms(10);                                                        // 等待传感器上电稳定
    spi_init(ICM42688_SPI, SPI_MODE0, ICM42688_SPI_SPEED,
             ICM42688_SPC_PIN, ICM42688_SDI_PIN, ICM42688_SDO_PIN, SPI_CS_NULL);
    ICM42688_CS(1);
    icm42688_who_am_i = 0;
    icm42688_data_valid = 0;
 
    do
    {
        icm42688_write_register(ICM42688_REG_BANK_SEL, 0x00);                   // 确保后续访问 Bank 0
        if(icm42688_self_check())
        {
            zf_log(0, "ICM42688 self check error.");
            return_state = 1;
            break;
        }
 
        // 与官方例程保持一致：先关闭传感器，再配置量程和输出速率。
        icm42688_write_register(ICM42688_PWR_MGMT0, 0x00);
        system_delay_ms(10);                                                    // PWR_MGMT0 写入后至少等待 200 us
 
        if(icm42688_set_config(ICM42688_ACC_SAMPLE_DEFAULT, ICM42688_ACC_ODR_DEFAULT,
                               ICM42688_GYRO_SAMPLE_DEFAULT, ICM42688_GYRO_ODR_DEFAULT))
        {
            zf_log(0, "ICM42688 default config error.");
            return_state = 1;
            break;
        }
 
        icm42688_write_register(ICM42688_PWR_MGMT0, 0x0F);                      // 陀螺仪和加速度计进入低噪声模式
        system_delay_ms(50);                                                    // 等待陀螺仪启动并输出稳定数据
 
        // 连续尝试读取有效数据，避免上电后的第一帧全 0 被送入姿态解算。
        for(data_check_count = 0; data_check_count < 10; data_check_count ++)
        {
            icm42688_get_acc_gyro();
            if(icm42688_data_valid)
            {
                break;
            }
            system_delay_ms(2);
        }
 
        if(0 == icm42688_data_valid)
        {
            zf_log(0, "ICM42688 data check error.");
            return_state = 1;
        }
    }while(0);
 
    return return_state;
}
程序B-3  ICM42688 六轴突发采集
void icm42688_get_acc_gyro (void)
{
    uint8 data[12];
 
    icm42688_read_registers(ICM42688_ACCEL_DATA_X1, data, 12);
    icm42688_acc_x  = (int16)(((uint16)data[0]  << 8) | data[1]);
    icm42688_acc_y  = (int16)(((uint16)data[2]  << 8) | data[3]);
    icm42688_acc_z  = (int16)(((uint16)data[4]  << 8) | data[5]);
    icm42688_gyro_x = (int16)(((uint16)data[6]  << 8) | data[7]);
    icm42688_gyro_y = (int16)(((uint16)data[8]  << 8) | data[9]);
    icm42688_gyro_z = (int16)(((uint16)data[10] << 8) | data[11]);
 
    // 静止时加速度至少有一个轴包含约 1 g；全 0 或全 0xFFFF 表示 SPI 数据无效。
    if(((0 == icm42688_acc_x) && (0 == icm42688_acc_y) && (0 == icm42688_acc_z)) ||
       ((-1 == icm42688_acc_x) && (-1 == icm42688_acc_y) && (-1 == icm42688_acc_z)))
    {
        icm42688_data_valid = 0;
    }
    else
    {
        icm42688_data_valid = 1;
    }
}
程序B-4  四元数姿态解算
void quaternion_module_calculate(cascade_value_struct *cascade_value)
{
    static float first_count_time = 0;  // 首次计算时间计数器（用于快速收敛）
    float length;                       // 四元数模长（用于归一化）
    float x, y, z;                      // 陀螺仪角速度（弧度/秒）
    int32 gyro_x_count;
    int32 gyro_y_count;
    int32 gyro_z_count;
 
    // 保持 new_imu 的坐标映射和 10 LSB 量化方式，直接使用陀螺仪原始数据。
    gyro_x_count = (int32)GYRO_DATA_X;
    gyro_y_count = (int32)GYRO_DATA_Y;
    gyro_z_count = (int32)GYRO_DATA_Z;
 
    gyro_x_count = gyro_x_count / 10 * 10;
    gyro_y_count = gyro_y_count / 10 * 10;
    gyro_z_count = gyro_z_count / 10 * 10;
 
    x = (float)gyro_x_count / GYRO_TRANSITION_FACTOR * 0.01745329f;
    y = (float)gyro_y_count / GYRO_TRANSITION_FACTOR * 0.01745329f;
    z = (float)gyro_z_count / GYRO_TRANSITION_FACTOR * 0.01745329f;
 
    // 加速度计数据转换：原始数据 -> g 为单位（1g ≈ 9.8 m/s2）
    float ax_g = (float)ACC_DATA_X / ACC_TRANSITION_FACTOR;
    float ay_g = (float)ACC_DATA_Y / ACC_TRANSITION_FACTOR;
    float az_g = (float)ACC_DATA_Z / ACC_TRANSITION_FACTOR;
 
    bool static_state = is_static_state(ax_g, ay_g, az_g);  // 判断设备是否静止
    float acc_alpha = static_state ? 0.8f : 0.6f;           // 静止时滤波系数更大（平滑效果更好）
 
    // 加速度计数据低通滤波
    acc_lowpass_filter(&ax_g, &ay_g, &az_g,
                       &cascade_value->quaternion.pro.acc_filtered[0],
                       &cascade_value->quaternion.pro.acc_filtered[1],
                       &cascade_value->quaternion.pro.acc_filtered[2], acc_alpha);
 
    // 取滤波后的加速度数据
    float ax = cascade_value->quaternion.pro.acc_filtered[0];
    float ay = cascade_value->quaternion.pro.acc_filtered[1];
    float az = cascade_value->quaternion.pro.acc_filtered[2];
 
    acc_normalize(&ax, &ay, &az);  // 加速度数据归一化
 
    // 取出当前四元数 (w, x, y, z)
    float q0 = cascade_value->quaternion.pro.qua[0];
    float q1 = cascade_value->quaternion.pro.qua[1];
    float q2 = cascade_value->quaternion.pro.qua[2];
    float q3 = cascade_value->quaternion.pro.qua[3];
 
    // 根据当前四元数计算重力向量在机体坐标系中的投影（用于与加速度计数据对比）
    float gx = 2 * (q1 * q3 - q0 * q2);
    float gy = 2 * (q0 * q1 + q2 * q3);
    float gz = q0 * q0 - q1 * q1 - q2 * q2 + q3 * q3;
 
    // 计算加速度计与重力投影的误差（梯度误差）
    float ex = ay * gz - az * gy;
    float ey = az * gx - ax * gz;
    float ez = ax * gy - ay * gx;
 
    // 根据静止状态调整校正系数（运动时减弱校正，避免引入噪声）KI不衰减，保证积分校正力度
    float kp = static_state ? cascade_value->posture_value.correct_kp : cascade_value->posture_value.correct_kp * 0.8f;
    float ki = cascade_value->posture_value.correct_ki;
 
    // 首次计算的前 0.1 秒，使用大比例系数加速收敛
    if(first_count_time < 0.1f)
    {
        first_count_time += cascade_value->posture_value.call_cycle;  // 累加时间
        kp = 10.0f;  // 强比例校正，快速收敛
    }
 
    // 动态时积分力度降为1/10
    float integral_gain = static_state ? 1.0f : 0.1f;
 
    cascade_value->quaternion.parameter.acc_err[0] += (ex * cascade_value->posture_value.call_cycle) * integral_gain;
    cascade_value->quaternion.parameter.acc_err[1] += (ey * cascade_value->posture_value.call_cycle) * integral_gain;
    cascade_value->quaternion.parameter.acc_err[2] += (ez * cascade_value->posture_value.call_cycle) * integral_gain;
 
    // 积分限幅：防止饱和
    float acc_err_limit = 1.0f;
    cascade_value->quaternion.parameter.acc_err[0] = (cascade_value->quaternion.parameter.acc_err[0] > acc_err_limit) ? acc_err_limit :
                                                      (cascade_value->quaternion.parameter.acc_err[0] < -acc_err_limit) ? -acc_err_limit :
                                                      cascade_value->quaternion.parameter.acc_err[0];
    cascade_value->quaternion.parameter.acc_err[1] = (cascade_value->quaternion.parameter.acc_err[1] > acc_err_limit) ? acc_err_limit :
                                                      (cascade_value->quaternion.parameter.acc_err[1] < -acc_err_limit) ? -acc_err_limit :
                                                      cascade_value->quaternion.parameter.acc_err[1];
    cascade_value->quaternion.parameter.acc_err[2] = (cascade_value->quaternion.parameter.acc_err[2] > acc_err_limit) ? acc_err_limit :
                                                      (cascade_value->quaternion.parameter.acc_err[2] < -acc_err_limit) ? -acc_err_limit :
                                                      cascade_value->quaternion.parameter.acc_err[2];
 
    // 偏航角速度死区：必须在叠加加速度计校正项之前施加
    // 原因：加速度计 ez 分量无法修正偏航漂移（重力无偏航信息），
    // 若死区放在校正之后，校正噪声会将 z 推出死区，死区完全失效
    // 阈值约 2°/s（0.035 rad/s），可在 0.02~0.06 之间调整
#define YAW_GYRO_DEAD_ZONE  (0.05f)
    if(z > -YAW_GYRO_DEAD_ZONE && z < YAW_GYRO_DEAD_ZONE)
        z = 0.0f;
 
    // 用误差校正陀螺仪数据（比例+积分校正）
    // z 轴（偏航）不叠加加速度计校正，acc_err[2] 强制清零以防止噪声积累
    x += kp * ex + ki * cascade_value->quaternion.parameter.acc_err[0];
    y += kp * ey + ki * cascade_value->quaternion.parameter.acc_err[1];
    cascade_value->quaternion.parameter.acc_err[2] = 0.0f;
 
    // 四元数微分方程更新（根据陀螺仪角速度）
    cascade_value->quaternion.pro.qua[0] += ((-q1 * x - q2 * y - q3 * z) * cascade_value->posture_value.call_cycle / 2.0f);
    cascade_value->quaternion.pro.qua[1] += (( q0 * x + q2 * z - q3 * y) * cascade_value->posture_value.call_cycle / 2.0f);
    cascade_value->quaternion.pro.qua[2] += (( q0 * y - q1 * z + q3 * x) * cascade_value->posture_value.call_cycle / 2.0f);
    cascade_value->quaternion.pro.qua[3] += (( q0 * z + q1 * y - q2 * x) * cascade_value->posture_value.call_cycle / 2.0f);
 
    // 取出当前四元数 (w, x, y, z)
    q0 = cascade_value->quaternion.pro.qua[0];
    q1 = cascade_value->quaternion.pro.qua[1];
    q2 = cascade_value->quaternion.pro.qua[2];
    q3 = cascade_value->quaternion.pro.qua[3];
 
    // 四元数归一化（避免数值漂移）
    length = sqrt(q0 * q0 + q1 * q1 + q2 * q2 + q3 * q3);  // 计算模长
    if (length > 0.001f)  // 模长有效时才归一化
    {
        q0 /= length;
        q1 /= length;
        q2 /= length;
        q3 /= length;
 
        cascade_value->quaternion.pro.qua[0] = q0;
        cascade_value->quaternion.pro.qua[1] = q1;
        cascade_value->quaternion.pro.qua[2] = q2;
        cascade_value->quaternion.pro.qua[3] = q3;
    }
    else
    {
        // 异常四元数恢复为单位四元数，避免后续姿态角持续输出无效数据。
        q0 = 1.0f;
        q1 = 0.0f;
        q2 = 0.0f;
        q3 = 0.0f;
        cascade_value->quaternion.pro.qua[0] = q0;
        cascade_value->quaternion.pro.qua[1] = q1;
        cascade_value->quaternion.pro.qua[2] = q2;
        cascade_value->quaternion.pro.qua[3] = q3;
    }
 
    // 必须使用归一化后的四元数构造旋转矩阵。
    float q0_2 = q0 * q0;
    float q1_2 = q1 * q1;
    float q2_2 = q2 * q2;
    float q3_2 = q3 * q3;
 
    // 根据四元数计算旋转矩阵（用于后续姿态角计算）
    cascade_value->quaternion.data.rot_mat[0][0] = q0_2 + q1_2 - q2_2 - q3_2;
    cascade_value->quaternion.data.rot_mat[0][1] = 2 * (q1 * q2 + q0 * q3);
    cascade_value->quaternion.data.rot_mat[0][2] = 2 * (q1 * q3 - q0 * q2);
    cascade_value->quaternion.data.rot_mat[1][0] = 2 * (q1 * q2 - q0 * q3);
    cascade_value->quaternion.data.rot_mat[1][1] = q0_2 - q1_2 + q2_2 - q3_2;
    cascade_value->quaternion.data.rot_mat[1][2] = 2 * (q2 * q3 + q0 * q1);
    cascade_value->quaternion.data.rot_mat[2][0] = 2 * (q1 * q3 + q0 * q2);
    cascade_value->quaternion.data.rot_mat[2][1] = 2 * (q2 * q3 - q0 * q1);
    cascade_value->quaternion.data.rot_mat[2][2] = q0_2 - q1_2 - q2_2 + q3_2;
//------------------------------------------到时候自己看下输出结果 输出结果正负号记录在手机上了
    // 根据旋转矩阵计算姿态角（横滚角、俯仰角、偏航角）
    cascade_value->posture_value.rol = arctan2(cascade_value->quaternion.data.rot_mat[2][2], cascade_value->quaternion.data.rot_mat[1][2]);  // 横滚角
    cascade_value->posture_value.pit = -arcsin(cascade_value->quaternion.data.rot_mat[0][2]);                                            // 俯仰角
    cascade_value->posture_value.yaw = arctan2(cascade_value->quaternion.data.rot_mat[0][0], cascade_value->quaternion.data.rot_mat[0][1]);   // 偏航角
}
程序B-5  方向外环
float Direction_Tick(float current_yaw, float current_yaw_rate, float target_yaw)
{
    // 1. 计算偏航角误差
    dir_data.yaw_error = target_yaw - current_yaw;
 
    // 2. 处理 Yaw 角 360 度环绕问题 (非常重要！)
    // 如果 Yaw 角在 -180 到 180 之间跳变，误差计算会出错，必须将其限制在 ±180 内
    if (dir_data.yaw_error > 180.0f) {
        dir_data.yaw_error -= 360.0f;
    } else if (dir_data.yaw_error < -180.0f) {
        dir_data.yaw_error += 360.0f;
    }
 
    // 3. PD 控制计算目标倾角
    // 误差(P)决定要压多少弯，偏航角速度(D)产生阻尼，防止车头晃动
    dir_data.target_roll_out = (dir_data.kp * dir_data.yaw_error) - (dir_data.kd * current_yaw_rate);
 
    // 4. 目标倾角严格限幅 (核心保护机制)
    // 绝对不能让方向环给出过大的倾角，否则单车内环救不回来直接摔倒。
    // 一般限制在正负 15 度以内 (根据你的车速和轮胎抓地力决定)
 
    if (dir_data.target_roll_out > MAX_TARGET_ROLL[page_5]) {
        dir_data.target_roll_out = MAX_TARGET_ROLL[page_5];
    } else if (dir_data.target_roll_out < -MAX_TARGET_ROLL[page_5]) {
        dir_data.target_roll_out = -MAX_TARGET_ROLL[page_5];
    }
 
    return dir_data.target_roll_out;
}
程序B-6  侧倾—转向控制
void Balance_Tick(float current_roll, float current_roll_rate, float current_speed, float target_angle)
{
    float temp_val;
    float temp_arc;
 
    // 1. 获取状态数据
    balance_data.roll = current_roll;
    balance_data.roll_rate = current_roll_rate;
 
    // 【优化点 1：放宽速度下限】
    // 允许运动学模型下探到更低的速度（比如0.2），让低速时依然能算出足够大的转向角来救车。
    // 具体数值(0.15~0.25)根据你的车体重量和舵机响应速度微调。
    float v_eff = (current_speed < 0.2f) ? 0.2f : current_speed;
 
    // 2. 姿态误差计算
    balance_data.angle_car_deg = balance_data.roll - balance_data.angle_core_deg;
    balance_data.d_angle_deg = balance_data.angle_core_deg + target_angle - balance_data.angle_car_deg;
 
    // 【优化点 2：动态增益调度 (Gain Scheduling)】
    // 提取当前的 PID 参数
    float adaptive_kp = balance_data.kp;
    float adaptive_kd = balance_data.kd;
 
    // 如果处于低速区间（如小于0.5m/s），动态放大阻尼
    if (current_speed < 0.5f)
    {
        // 计算速度跌落的比例，速度越低，ratio 越大
        // 例如当 v_eff = 0.2 时，ratio = 0.5 / 0.2 = 2.5
        float damping_ratio = 0.5f / v_eff;
 
        // 大幅放大 Kd 以抑制低速时因为分母太小导致的舵机高频“画龙”
        adaptive_kd = balance_data.kd * damping_ratio;
 
        // 可选：极低速时，可以将 Kp 稍微削弱一点，防止舵机反应过敏
        // adaptive_kp = balance_data.kp * 0.9f;
    }
 
    // 3. PD 控制器计算横向加速度 (使用自适应后的参数)
    balance_data.ax_cmd = adaptive_kp * balance_data.d_angle_deg - adaptive_kd * balance_data.roll_rate;
 
    // 4. 几何映射 (使用 TC264 FPU 指令)
    // 这里的分母使用了放宽后的 v_eff，算出来的向心力补偿更符合真实的低速物理模型
    temp_val = (-balance_data.ax_cmd * balance_data.lm) / (v_eff * v_eff);
 
    // 防止后续 asinf 运算后触发 tan(90°) 奇点翻转
    if (temp_val > 0.99f) temp_val = 0.99f;
    if (temp_val < -0.99f) temp_val = -0.99f;
 
    temp_arc = asinf(temp_val);
 
    // 计算舵机目标角度
    balance_data.servo_target_deg = atanf((balance_data.l / balance_data.lm) * tanf(temp_arc)) * RAD_TO_DEG;
 
    // 5. 限幅保护
    if (balance_data.servo_target_deg > SERVO_MAX_ANGLE)
    {
        balance_data.servo_target_deg = SERVO_MAX_ANGLE;
    }
    else if (balance_data.servo_target_deg < SERVO_MIN_ANGLE)
    {
        balance_data.servo_target_deg = SERVO_MIN_ANGLE;
    }
 
    // 6. 执行输出
//    Servo_Output(balance_data.servo_target_deg);
}
程序B-7  增量式速度 PID
int32 PID_Calculate_Incremental(Pid_TypeDef *pid, int32 target, int32 feedback)
{
    pid->target = target;
    pid->feedback = feedback;
    pid->error = pid->target - pid->feedback;
 
    float current_ki = 0.0f;
    float dynamic_threshold = fabsf((float)pid->target) * 1.3f + 100.0f;
 
    if((pid->output > 0.0f && pid->error < 0) ||
       (pid->output < 0.0f && pid->error > 0))
    {
        current_ki = (float)pid->ki * 3.0f;
    }
    else if(fabsf((float)pid->error) < dynamic_threshold)
    {
        current_ki = (float)pid->ki;
    }
 
    float delta_output = (float)pid->kp * (float)(pid->error - pid->last_error) +
                         current_ki * (float)pid->error +
                         (float)pid->kd * (float)(pid->error - 2 * pid->last_error + pid->prev_error);
 
    if(delta_output > pid->max_output)  delta_output = pid->max_output;
    if(delta_output < -pid->max_output) delta_output = -pid->max_output;
 
    pid->output += delta_output;
 
    pid->prev_error = pid->last_error;
    pid->last_error = pid->error;
 
    if(pid->output > pid->max_output)  pid->output = pid->max_output;
    if(pid->output < -pid->max_output) pid->output = -pid->max_output;
 
    return (int32)pid->output;
}
程序B-8  全局位置更新
void Update_Global_Position(int32 current_encoder_pulse)
{
    // 1. 将 1 毫秒内的脉冲转化为物理距离 (米)
    float delta_s = (float)current_encoder_pulse / (SPEED_TO_PULSE_1MS * 1000.0f);
 
    // 2. 获取当前真实的陀螺仪偏航角，并转为弧度
    float Car_Yaw_Rad = track_relative_yaw() * (3.14159265f / 180.0f);
 
    // 3. 极坐标转直角坐标积算 (XY 积分)
    Car_X += delta_s * cosf(Car_Yaw_Rad);
    Car_Y += delta_s * sinf(Car_Yaw_Rad);
}
程序B-9  航点状态机
void Navigation_Tick(void)
{
    // 1. 获取当前科目对应的路径数组指针 (根据你的页面判断逻辑)
    Waypoint_t* active_path;
    if(page_5 == 0 || page_5 == 4)      active_path = path_subject1;
    else if(page_5 == 1||page_5==3) active_path = path_subject2;
    else                 active_path = path_subject3;
 
    // 2. 判断是否达到了【下一个点】的触发里程
    // 注意：如果是末尾填充的 999.0f 的点，永远不会触发这里的 if
    if (total_distance_m >= active_path[current_wp_index + 1].trigger_distance)
    {
        // 3. 拦截判断：【当前正在执行的点】是否配置了强制等待
        if (active_path[current_wp_index].wait_angle_flag == 1)
        {
            // 获取实际陀螺仪偏航角 (Angle_Z_Quaternions) 与 当前目标角 的偏差
            // AngleErrorNormalize 用于把角度差处理到 ±180 度以内
            float angle_diff = fabs(AngleErrorNormalize(Angle_Z_Quaternions - active_path[current_wp_index].target_yaw));
 
            // 如果车头还没转过来
            if (angle_diff > ANGLE_WAIT_TOLERANCE)
            {
                pause_mileage_flag = 1; // 【强制冻结里程】
                return;                 // 直接退出函数，不执行后续的 current_wp_index++
            }
        }
 
        // 4. 角度已转到位，或者这个点根本不需要等待
        pause_mileage_flag = 0; // 解除冻结，恢复里程计算
        current_wp_index++;     // 顺利切入下一个路段
    }
 
    // 5. 更新全局控制目标
    current_target_yaw   = active_path[current_wp_index].target_yaw;
    current_target_speed = active_path[current_wp_index].target_speed;
}
