本项目以N1车模为基础平台，面向全国大学生智能汽车竞赛单车定向赛题开展设计。整车不进行额外机械改造，主要工作集中在传感器安装、姿态与速度信息采集、路径规划、控制算法设计和现场参数调试等方面。系统以TC387作为主控核心，利用IMU963获取车体姿态角和角速度信息，利用磁编码器获取速度与里程反馈，并通过BDS300舵机和无刷电机完成转向与动力输出。
控制策略上，车辆采用惯导循迹作为主要运行方式，通过LQR控制提高车体姿态和转向响应的稳定性，再结合PID对速度、误差和执行输出进行补偿修正。针对科目二路径变化较大的特点，使用贝塞尔曲线生成平滑参考路线，使车辆在转弯和过渡区域减少突变，提高轨迹跟随的连续性与通过稳定性。

第一章 引言
1.1 概述
全国大学生智能汽车竞赛是一项综合性工程实践竞赛，要求参赛车模在限定规则下完成感知、决策、控制和稳定运行。本队采用N1车模作为底盘平台，围绕单车定向赛题完成了传感器安装、控制程序设计和现场调试工作。
本报告按竞赛技术报告要求编写，重点说明整车设计思路、机械布置、硬件接口、软件控制算法、调试工具和主要技术参数。由于本队无机械改造，报告将重点放在传感器布置、控制策略与调试过程上。
1.2 整车设计思路
整车设计的核心目标是保持结构简单、安装可靠、控制清晰。底盘采用N1标准车模，无额外机械改造；在此基础上完成IMU、磁编码器、舵机和电机相关部件的安装与连接。控制上以惯导循迹为主，结合LQR+PID实现姿态和速度的综合控制。
路径规划方面，科目二采用贝塞尔曲线对轨迹进行平滑处理，使车辆在转弯和过渡区域中获得更自然的参考路径，减少折线式控制带来的抖动。

第二章 车模结构与机械布置
2.1 车模结构
本队采用N1车模作为基础平台，车辆机械结构保持原始底盘配置，不进行额外机械改造。整车安装重点集中在传感器固定、线束整理和控制部件布局上，以减少震动和松动对比赛稳定性的影响。
由于不做机械改造，整车维护难度较低，现场调试时只需对传感器角度、安装高度和电气连接进行检查即可。
图2.1 N1车模整体照片（侧视）
2.2 传感器与执行器布置
IMU963安装在车体相对稳定的位置，用于获取姿态信息；磁编码器安装在轮系相关位置，用于提供速度与里程信息；BDS300舵机负责转向输出。各部件布置时尽量保持质心居中，并避免传感器线缆与电机线束长距离并行，以降低干扰。
线束采用分组固定方式，转向、测速、姿态和通信线缆分别整理，方便调试和更换。

2.3 安装说明
安装过程中主要关注两点：一是保证传感器方向与车体坐标一致，二是保证连接牢靠、可重复拆装。由于底盘不做机械改造，整车装配以标准化、模块化为原则，便于后续维护。
第三章 系统硬件与接口设计
3.1 硬件总体结构
系统硬件主要由TC387主控平台、IMU963惯性模块、磁编码器、BDS300舵机、无刷电机及其驱动单元、调试通信模块组成。主控平台承担整车数据采集、状态估计、控制计算和执行输出任务；IMU963用于获取车体姿态变化，磁编码器用于提供速度与里程反馈，舵机和无刷电机分别完成方向控制与动力输出。


3.2 舵驱和电驱
舵驱部分采用BDS300舵机作为转向执行机构，主控根据LQR+PID计算得到的转向控制量输出PWM信号，并在软件中加入中值校准、机械限幅和变化率限制，防止舵机因控制量突变产生过大转向。舵机输出直接影响车辆轨迹跟随效果，因此调试时需要重点确认舵机方向、舵机中值和左右极限是否与程序设定一致。
电驱部分采用无刷电机提供车辆动力，电机输出根据目标速度、赛道状态和当前速度反馈进行调整。车辆在直线段可以使用较高输出，在转弯、路径切换或姿态变化较大时适当降低输出，以保证车体稳定性。电驱控制与磁编码器测速配合使用，可为速度PID提供反馈数据，使车辆在不同赛段保持更稳定的速度响应。
舵驱和电驱在软件中统一由控制周期调度：先完成IMU963和磁编码器数据更新，再进行路径误差和姿态误差计算，随后分别输出舵机PWM和电机控制量。这样可以保证转向与动力控制在同一状态信息下协同工作，减少单独调节造成的控制不一致。
第四章 软件系统与控制算法设计
4.1 软件总体思路
软件采用“感知-判断-控制-输出”的闭环结构。主循环负责状态切换与数据整理，中断或定时任务负责稳定周期采样与控制运算。系统以惯导循迹为基础，通过IMU和磁编码器获取车辆状态，再由控制算法输出转向和速度控制量。
4.2 惯导循迹与状态判断
惯导循迹部分以姿态变化和速度反馈为核心，持续估计车辆在赛道中的偏差。系统根据当前状态判断是否进入弯道、减速区或特殊区域，并切换不同控制参数。这样可以在保证稳定性的同时提高通过效率。
4.3 LQR+PID控制
方向控制采用LQR作为主控制框架，结合PID进行误差修正。LQR用于在状态空间内给出较平滑的控制方向，PID则负责对偏差和扰动进行补偿，二者配合后可兼顾稳定性和响应速度。
速度控制采用PID调节，根据不同赛段设定目标速度。直线段保持较高输出，转弯和特殊区域适当降速，以减小侧向摆动。
4.4 贝塞尔曲线路径规划
科目二路径采用贝塞尔曲线进行平滑规划。与直接使用折线路径相比，贝塞尔曲线更容易获得连续变化的参考轨迹，能够减少方向控制在转折处的突变，使车辆过弯更加自然。
在实现上，先根据赛道特征点确定控制点，再通过曲线插值生成目标路径，并将路径误差输入控制系统。

4.5 核心程序设计
程序结构上将传感器采集、状态识别、控制计算和执行输出分别封装，便于维护和现场修改。核心算法子程序见附录B，提交时可替换为最终工程版本。
第五章 开发工具与调试过程
5.1 开发工具
本队使用ADS进行程序开发与编译，使用VOFA+进行在线调试与变量观察。通过上位机实时查看姿态、误差、速度和控制量，能更快完成参数整定。
5.2 制作与安装过程
制作阶段首先完成器件选型和安装位置规划，再进行车模组装、线束整理和软件初始化。由于车模无机械改造，主要工作集中在传感器安装角度、主控连接和调试接口布局上。
5.3 调试过程
调试过程采用分步骤推进的方式：先验证单个传感器，再验证舵机和电机输出，然后进行惯导循迹联调，最后加入LQR+PID和贝塞尔曲线路径规划。VOFA+主要用于观察误差变化和控制输出，辅助完成参数调整。
实际调试中若出现转向过冲、速度波动或路径偏离，通常先检查传感器安装是否松动，再修改控制参数和目标速度，最后在赛道上进行复测。

/*
 * lqr_balance.c
 *
 * LQR平衡控制应用层实现
 *
 * Created on: 2025
 * Author: suiyungui
 */

#include "lqr_balance.h"
#include "WP_Math.h"
#include <math.h>

// ==================== 全局变量 ====================
LQR_Controller_t lqr_ctrl;
float lqr_expect_phi = 0.0f;        // 期望侧倾角（度）

// 轮子参数（可运行时调整）
static float wheel_radius = LQR_WHEEL_RADIUS;
static float gear_ratio = LQR_GEAR_RATIO;

// ==================== 函数实现 ====================

/**
 * @brief  转向角转换为舵机PWM
 * @param  delta: 转向角（rad），正值=右转
 * @return 舵机PWM值
 */
uint32 lqr_delta_to_servo_pwm(float delta)
{
    float ratio, pwm;

    // 线性映射：delta -> PWM
    // delta = 0 -> mid
    // delta = +max -> r_max (右转)
    // delta = -max -> l_max (左转)
    ratio = delta / LQR_DELTA_MECHANICAL_MAX;

    // 限幅
    if (ratio > 1.0f) ratio = 1.0f;
    if (ratio < -1.0f) ratio = -1.0f;

    // 映射到PWM（左右分段，适应不对称舵机）
    if (ratio >= 0)
        pwm = (float)LQR_SERVO_MID + ratio * (float)(LQR_SERVO_RIGHT - LQR_SERVO_MID);
    else
        pwm = (float)LQR_SERVO_MID + ratio * (float)(LQR_SERVO_MID - LQR_SERVO_LEFT);

    // 边界保护
    if (pwm > (float)LQR_SERVO_RIGHT) pwm = (float)LQR_SERVO_RIGHT;
    if (pwm < (float)LQR_SERVO_LEFT) pwm = (float)LQR_SERVO_LEFT;

    return (uint32)pwm;
}

/**
 * @brief  初始化LQR平衡控制
 */
//20260225 最终确定 vmc控制周期是5ms
//实际电机供电6.96v对应我们的舵机“0.138s/60°” 即每秒转 60*1/0.138=434°，换算成弧度是 434 * π/180 ≈ 7.588 rad/s）；
//换算成rad/1ms= rad/s/1000 换算换算成rad/5ms= (7.588 rad)/1000ms =(7.588 rad)/1000ms=(7.588/200 rad)/5ms=0.03794

void lqr_balance_init(void)
{
    // 初始化LQR控制器
    lqr_init(&lqr_ctrl);

    // 设置物理参数（后续根据实测调整）物理参数: h=0.120m, L=0.210m, g=9.80m/s^2
    lqr_set_physical_params(&lqr_ctrl, 0.12f, 0.21f, 0.02f);

    // 设置限幅
    lqr_set_limits(&lqr_ctrl,
                   LQR_DELTA_MECHANICAL_MAX,    // 最大转向角
                   8.0f,                        // 最大转向角速度
                   0.2f);                       // 最小速度

    // 初始化期望角度
    lqr_expect_phi = 0.0f;

    // 默认使能
    lqr_enable(&lqr_ctrl, 1);
}

/**
 * @brief  从电机RPM估计车速
 * @return 速度（m/s），恒正
 */
float lqr_get_velocity(void)
{
    float rpm, omega, velocity;

    // 获取电机转速（RPM）
    rpm = (float)motor_get_speed();

    // 转换为线速度：v = rpm * 2*pi*r / 60 / gear_ratio
    omega = rpm * 2.0f * M_PI_F / 60.0f / gear_ratio;
    velocity = omega * wheel_radius;

    // 取绝对值（速度恒正）
    if (velocity < 0.0f) {
        velocity = -velocity;
    }

    return velocity;
}



/**
 * @brief  LQR平衡控制主函数
 * @note   在5ms中断中调用
 */
void lqr_balance_control(void)
{
    float velocity;
    float phi, phi_dot;
    float delta_cmd;
    uint32 servo_pwm;
    int8_t ret;

    // 1. 获取当前速度
    velocity = lqr_get_velocity();

    // 2. 更新增益（根据速度插值）
    ret = lqr_update_gain(&lqr_ctrl, velocity);

    // 2.5 计算配套的目标转向角（物理套餐）
    // 公式：tan(phi) = v^2 / (g*L) * delta
    // 反推：delta = tan(phi) * g * L / v^2
    {
        float L = lqr_ctrl.params.L;
        float g = lqr_ctrl.params.g;
        float target_phi_rad = lqr_expect_phi * DEG_TO_RAD;

        if (velocity > 0.5f) {
            lqr_ctrl.target_delta = tanf(target_phi_rad) * g * L / (velocity * velocity);
            // 限幅保护
            if (lqr_ctrl.target_delta > LQR_DELTA_MECHANICAL_MAX) {
                lqr_ctrl.target_delta = LQR_DELTA_MECHANICAL_MAX;
            }
            if (lqr_ctrl.target_delta < -LQR_DELTA_MECHANICAL_MAX) {
                lqr_ctrl.target_delta = -LQR_DELTA_MECHANICAL_MAX;
            }
        } else {
            lqr_ctrl.target_delta = 0.0f;  // 低速时不允许压弯
        }
    }

    // 3. 获取IMU数据并转换单位
    // pitch_kalman: 度 -> rad（减去期望角度）
    // gyro_y_rate: 度/s -> rad/s
    // 注意：IMU定义左倾为正，LQR模型假设右倾为正，需取反
    phi = -(pitch_kalman - lqr_expect_phi) * DEG_TO_RAD;
    phi_dot = -gyro_y_rate * DEG_TO_RAD;

    // 4. 低速保护：速度过低时缓慢回中
    if (ret < 0) {
        // 低速时缓慢回中（衰减系数0.95）
        lqr_ctrl.delta_cmd *= 0.95f;
    } else {
        // 5. 执行LQR计算
        lqr_compute(&lqr_ctrl, phi, phi_dot);
    }

    // 6. 获取转向角命令
    delta_cmd = lqr_ctrl.delta_cmd;

    // 7. 转换为舵机PWM并输出
    servo_pwm = lqr_delta_to_servo_pwm(delta_cmd);
    servo_set(servo_pwm);
}

/**
 * @brief  设置期望侧倾角（用于转弯）
 * @param  phi_deg: 期望侧倾角（度）
 */
void lqr_set_expect_phi(float phi_deg)
{
    lqr_expect_phi = phi_deg;
}

/**
 * @brief  运行时调整物理参数
 */
void lqr_tune_params(float h, float L)
{
    lqr_set_physical_params(&lqr_ctrl, h, L, lqr_ctrl.params.b);
}

/**
 * @brief  运行时调整轮子参数
 */
void lqr_tune_wheel_params(float radius, float ratio)
{
    wheel_radius = radius;
    gear_ratio = ratio;
}

/**
 * @brief  获取调试信息
 */
void lqr_get_debug_info(float *phi, float *velocity, float *delta_deg)
{
    if (phi != NULL) {
        *phi = pitch_kalman;
    }
    if (velocity != NULL) {
        *velocity = lqr_ctrl.current_velocity;
    }
    if (delta_deg != NULL) {
        *delta_deg = lqr_ctrl.delta_cmd * RAD_TO_DEG;
    }
}
