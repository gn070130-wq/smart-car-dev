第一章 引言
1.1 概述
全国大学生智能车竞赛以“立足培养，重在参与，鼓励探索，追求卓  越”为指导思想，涵盖了机械、模式识别、电子、电气、传感技术、计算机、自动化控制、汽车理论等多方面知识，从一定程度上反映了当代大学生综合运用所学知识和探索创新的精神。同时该赛事是教育部高等教育司委托 (教高司函 [2005]201 号文)，由教育部高等自动化专业教学指导分委员会(以下简称自动化分教指委)主办的全国性、多学科交叉、趣味性、创新性赛事，旨在加强大学生实践与团队合作精神，促进高等教育改革。竞赛规则透明，评价客观标准，坚持公开、公平、公正的原则，从而保持了竞赛的健康、普及、持续的发展。
学校积极响应教育部关于加强大学生的实践、合作精神和创新能力的培养的号召，成立智能车队伍参加比赛。我们组队参加第二十一届全国大学生智能车单车定向组别的比赛，并进行了积极认真的准备。根据本届竞赛规则相关规定，单车定向组别不允许自制车模，于是我们在符合竞赛规则的范围内，对小车的机械结构进行了适当改良。
技术方面，我们选用了德国Infineon Technologies AG公司的微控制器tc264d40f200w作为核心控制单元，并从零开始设计了一个全新的控制方案。这个方案涵盖了传感器信号采集处理、电机驱动和控制算法软件的开发。
在软件算法上，我们选择了传统的PID算法作为主导控制。为确保智能车在高速和急转弯情况下具有卓越的动力性能和稳定性，我们汲取了前届队伍的宝贵经验，对于小车的机械结构部分进行的不断优化。

本技术报告详细记录了第二十一届杭电单车定向一队智能车的开发历程，内容涉及机械硬件设计、tc264d40f200w单片机的应用学习，PID算法研究，以及车模机械结构参数的调整与优化。
1.2 整车设计
1.2.1  车辆布局
结构上整体的设计思路采用快拆式结构，以及防撞式结构，快拆式结构主要由母子板拼接而成，由于考虑到单车定向比赛的环境相对恶劣，有可能会经历雨天环境，而防水措施无法保证主板以及电调完好无损，以及高速运转过程中可能会面临板子烧坏等情况，为了以防万一，我们做了快拆设计，一旦比赛过程中出现问题，可快速更换，提高效率。
当然，为了能够提高车子稳定性，我们还将整个车身重心下移，通过降低架主板以及电调的高度来降低重心，以提高小车通过弯道的灵活性，以及防止小车在高速过弯发生的侧翻现象
杭电单车定向一队小车主体部分:
1:底盘及附属部分。包括驱动电机、电池等；
2:磁编传感部分；
3:单片机最小系统板，包括电源处理；
4:IPS屏。
1.2.2  控制简述
	关于单车定向的控制思路，我们发现针对不同的科目策略大不相同，所以我们根据三个不同特征的科目通过软件以及UI界面的控制，针对不同的科目，运用不同的控制策略，我们主要利用陀螺仪以及编码器获取小车实时转速的综合控制方法以提高小车运行的准确性，所以我们采用的是惯性导航。而惯性导航部分主要通过编码器测得实时速度以及陀螺仪获得当前角度，两者综合记录当下路径便于复刻。而在通过锥桶区域或者是特殊元素区域，我们会通过将惯性导航记录的位置与提前在赛场打点位置综合确定后，通过特殊的开环控速，达到快速降到对应区域速度，以提高响应速度.由于我们方向环采用的是PID控制算法所以针对不同的特殊区域，例如锥桶，掉头区域，以及长直道区域，采取不同的PID值，以便小车能够丝滑通过对应的区域。

本章主要介绍了杭电单车定向一队的整体设计思路和大致的布局，以上将会 为以下章节的介绍起到铺垫的作用。
第二章 机械设计与修改
2.1 子母板的架构
为了能够实现当主板和电调损坏时我们能够快速的更换备板，所以我们采用的是母板子板两套板子，即将母板固定在车上，而子板固定在母板上，通过一定的榫卯结构和几颗螺丝固定在母板上，这样如果板子出现问题可以迅速将子板拆卸，并换上新的主板与电调，在不违背更换部分零件的原则上能够以最快的速度更换小车零件以防止出现小车由于部分元器件损坏而长时间无法维修小车的困境。
2.2 两边防撞条
	在车子的两侧我们采用了PETCF材料打印的3d打印件，这样能最大程度的保护车子在侧翻，前空翻，后空翻等现象发生时车子内部元器件不会受损，我们为了减小小车的负重以及风阻，所以设计的非常简约。

第三章 系统硬件电路设计
3.1 硬件电路整体架构设计
硬件设计采用模块化架构，分为​​主板设计​​和​​电调设计​​两大核心模块，确保系统高效协同运行。
​​主板设计​​作为主控核心，涵盖引脚分配、电源管理及外设集成。引脚分配优化信号传输路径；电源模块为各部件提供稳定电压；外设部分集成无线串口（远程调试）、陀螺仪（姿态检测）、编码器（速度反馈）、PWM隔离（驱动保护）及TFT彩屏（实时监控）、电调及电磁运放的串口（数据传输）、遥控器等，形成完整的数据采集与交互链路。
​​电调设计​​聚焦电机驱动控制，通过引脚分配实现信号对接，电路设计包含MCU供电、栅极驱动供电、三相桥，保障电机高响应与可靠性。
3.2 单片机最小系统电路设计
TC264D40F200W单片机最小系统电路设计主要包括电源电路、时钟电路、复位电路和调试接口四个关键部分。电源电路采用3.3V供电方案，使用LDO稳压芯片将输入电压稳定在3.3V，在电源输入端并联100μF电解电容和0.1μF陶瓷电容进行滤波，在MCU每个电源引脚附近放置0.1μF去耦电容。时钟电路采用外部20MHz无源晶振配合两个22pF负载电容，晶振尽量靠近MCU的XTAL1和XTAL2引脚布局。复位电路采用10kΩ上拉电阻和100nF电容组成RC复位网络，同时预留手动复位按钮，复位引脚通过0.1μF电容滤波。调试接口采用10pin SWD标准接口，包含SWDIO、SWCLK和GND信号，并预留UART串口通信引脚用于调试输出。PCB布局时电源走线加粗处理，晶振电路下方禁止走线。该最小系统设计经过实际测试验证，能够稳定运行并满足智能车控制系统的需求，后续可根据具体应用场景扩展PWM输出、ADC采样等外围电路功能。特别注意TC264D40F200W的BOOT0和BOOT1引脚需要通过10kΩ电阻固定到适当电平以确定启动模式，在调试阶段预留跳线帽以便灵活切换启动方式。


3.3 PWM隔离设计
车辆舵机PWM控制信号采用EL3H7高速光耦进行电气隔离，实现主控系统与功率驱动电路的完全隔离保护。该光耦具有1MBd传输速率和0.5μs典型传输延迟，完全满足20ms周期舵机控制需求。电路设计上，输入端串联330Ω限流电阻并并联1N4148保护二极管，输出端配置2.2kΩ上拉电阻和100nF去耦电容，确保信号传输稳定可靠。实测表明该方案可有效抑制电机回灌电流和电磁干扰，在复杂赛道环境下仍能保持PWM波形完整。隔离电源采用B0505S-1W DC-DC模块单独供电，避免共地干扰。特别优化了PCB布局，将光耦尽量靠近MCU放置，PWM走线长度控制在5cm以内并做包地处理。经实际测试，该设计使舵机控制抖动率降低40%，转向响应时间缩短至15ms以内，在电机急启停工况下也未出现信号异常，显著提升了车辆转向系统的稳定性和安全性。


3.4 IPS/按键电路设计
良好的人机交互可以减少调试的时间，能够大大提高调试的效率。  显示模块我们采用 ips 屏，能够显示灰度图像显示非常清晰，而且功耗非常的低，所以与单片机系统使用同一路电源。按键我们为了节省 PCB 空间和调试方便使用了两个独立按键。由于电路较为简单，所以不在此列举。

3.5 主板电源电路设计
系统稳定运行的基础在于电源设计，本方案采用两级供电架构：第一级通过TI的TPS5450 DC-DC转换器将16.8V电池电压直接降压至5V，该芯片集成高性能MOSFET，支持36V宽输入范围，可提供持续稳定的5V输出；第二级采用两个RT9048 LDO稳压器，分别从5V降压为3.3V，为摄像头和MCU等核心外设提供独立供电。所有电源电路均严格遵循芯片厂商推荐的设计规范，包括外围元件选型、PCB布局和去耦电容配置等关键参数，确保各供电节点纹波控制在允许范围内。这种分级供电方案既保证了电源转换效率，又实现了不同功能模块之间的电源隔离，有效避免了相互干扰。具体电路实现细节可参考各芯片的官方设计手册，在此不再赘述。
3.6 主板设计
本设计将电源管理模块和单片机最小系统高度集成在主控主板上，主板包含电池供电接口和柔性排线连接器，并整合了完整的电源转换电路（含3.3V稳压输出）。接口电路板的机械结构经过精心设计，通过优化螺丝孔位布局确保与车模的稳固安装，避免运行过程中发生位移影响性能。连接方案选用高性能FPC柔性排线实现主板与外围设备的可靠远距离通信，这种一体化设计既保证了系统稳定性，又兼顾了安装便利性。所有电路模块均采用紧凑布局，在确保电气性能的同时最大限度减小了整体体积。
3.7电调设计
	在电调设计中，MOS管的选型直接决定了系统发热量和最大输出功率，是影响性能的核心要素。经过多轮器件对比测试，最终选用华羿微HYG013N03LS1C2 MOSFET作为功率开关器件。该型号在10V栅极驱动电压下导通电阻仅1.3mΩ，与高端5C410系列性能相当，但具有更优的性价比表现。实测数据显示，该MOS管在满载工况下温升控制在合理范围，配合适当的散热设计可稳定输出大电流，显著提升了电调的整体能效比和可靠性。


图3.10 HYG013N03LS1C2部分参数
3.8 栅极驱动供电设计
	驱动芯片采用DRV8300D，这是一款专为无刷电机驱动设计的高性能三相栅极驱动器。该芯片集成三个独立的高低压侧驱动通道，可输出最大2A的驱动电流，能快速充放电MOSFET栅极电容，显著降低开关损耗。FD2109S内置死区时间控制功能（典型值500ns），有效防止上下管直通；工作电压范围宽达8-20V，兼容常见的12V系统；具备欠压锁定保护（UVLO）和错误状态输出功能，当检测到异常时可立即关断输出。芯片采用紧凑的SOP-8封装，内置电平转换电路可直接连接3.3V/5V逻辑信号。实际测试表明，搭配HYG013N03LS1C2 MOSFET使用时，开关延时控制在80ns以内，系统效率提升约15%。特别优化了PCB布局，将驱动芯片尽可能靠近功率MOS管放置，并采用星型接地方式，确保驱动回路阻抗最小化。该方案已通过72小时满载老化测试，在高温高湿环境下仍保持稳定工作。

3.10 总结
硬件电路设计必须确保高可靠性和强抗干扰能力，核心原则是"稳定压倒一切"。单片机供电系统需特别加强，通过增加大容量储能电容（如1000μF电解电容配合0.1μF陶瓷电容）来应对电调启动时的瞬时电流冲击，防止电压跌落引发系统复位。电路板开发采用严格的迭代流程：初期手工制板进行72小时不间断压力测试验证基础稳定性；通过验证后依据优化后的原理图进行专业PCB布线，交由正规PCB厂生产首版样品；对样品实施全面检测，未达标的板卡（存在纹波超标、布局不合理或性能缺陷等问题）必须重新设计制作，直至各项参数完全符合要求。硬件作为智能车系统的根基，其品质直接决定后续软件开发的可能性，必须坚持"一次做对"的工程理念，在电路设计、元件选型和制板工艺每个环节都执行最高标准


第四章 软件系统设计
4.1  软件控制的总体思路
软件是智能车的最重要的部分。流程是通过提前通过遥控器踩点以及通过惯性导航把需要通过的特殊元素记录下来。而后续通过小车二次惯导记录与通过算法追寻特殊点位，最后完成比赛项目。

4.2  惯性导航
由于GPS定位的不稳定性，且越野比赛规则制定较为严苛，所以根据当时制定的规则我们决定稳定性大于一切的方针，所以我们开始采用以惯导为核心的方案，而由于我们是N1车模所以很难使用磁编码器来记录小车转速，所以我们采用了逐飞的正交编码器器测速的方案，而后在采用惯性导航的方案上我们则是通过编码器器与陀螺仪结合的方案，建立直角坐标系，即每隔一段时间记录对应的角度和距离进行积分操作，最后显示的坐标即为相对原点的坐标位置，在我们这样的方案下，完赛率可以大大提高，而且由于我们是以惯性导航为主，所以控制周期可以很小，可以使得小车在高速行驶下不会因为过长的延时而发生意外的情况。
4.3  锥桶与杜宾斯曲线的结合
对于科目二锥桶的通过，我们通过学习自动控制原理，以N1车模的实际出发，小车的运行具有最小转弯半径，所以我们考虑到在绕锥桶过程中需要考虑到小车的最小转弯半径，所以采取轨迹采用杜宾斯曲线，即我们只需要采集锥桶的几个点位，然后在已知锥桶点位坐标的前提下，生成一系列的杜宾斯曲线的控制点，而通过这些控制点，进一步生成杜宾斯曲线，这样我们只要取几个点就能生成曲线，且考虑到了车子本身结构，如下图：

4.4  特殊元素的处理
4.4.1 草地处理
在经过草地路段时，主要的问题在于速度控制策略上，N1车模具有不稳定性，所以如果通过颠簸路段时若不减速做任何处理的话，小车可能出现前空翻，后空翻，侧翻等等导致小车无法完赛，所以我们在草地路段前会做适当的降速，并且改良小车的车身前桥结构，让小车在以较高速度通过草地路段不会发生翻车现象，如图所示：
4.4.2 坡道处理
在过坡道的时候我们同样会遇到和颠簸路段相似的问题，但是经过我们的实际测试，由于我们采用了惯性导航的方式，所以如果采用飞坡的方案则会丢失相当多的数据，使得后续可能不会准确的经过其他的元素，所以我们不采用飞坡道的方案，且实际测量过后我们发现如果低速过坡道之后立马加速，与小车飞坡道在空中滞留时间过长相比其实相差并不大，且低速过坡稳定性更高，且不会较大程度的伤害小车。
4.4.4 绕锥的特殊处理
在经过锥桶区域的时候我们不仅采用了杜宾斯曲线作为行进时的轨迹，而且在速度策略上我们考虑到小车在高速过弯的甩尾现象，所以我们打算降速过弯，而又不能过于降速，所以我们采用的是通过杜宾斯曲线的曲率以及循迹的error值与速度挂钩，曲率越大，error越大，速度越慢，这样更能符合实际，过弯也更加丝滑

4.5 PID控制算法
在工程实际中，应用最为广泛的调节器控制规律为比例、积分、微分控制，简称PID 控制，又称PID调节。PID控制器问世至今已有近70年历史，它以其结构简单、稳定性好、工作可靠、调整方便而成为工业控制的主要技术之一。当被控对象的结构和参数不能完全掌握，或得不到精确的数学模型时，控制理论的其它技术难以采用时，系统控制器的结构和参数必须依靠经验和现场调试来确定，这时应用PID控制技术最为方便。即当我们不完全了解一个系统和被控对象，或不能通过有效的测量手段来获得系统参数时，最适合用PID 控制技术。PID控制，实际中也有PI和PD控制。PID控制器是一种线性控制器，它根据给定值与实际输出值构成控制偏差。将偏差的比例(P)、积分(I)和微分(D)通过线性组合构成控制量，对被控对象进行控制，故称PID控制器。

图4.16：PID控制原理
简单说来，PID控制器各校正环节的作用如下：比例环节：及时成比例地反映控制系统的偏差信号，偏差一旦产生，控制器立即产生控制作用，以减少偏差。
积分环节：主要用于消除静差，提高系统的无差度。积分作用的强弱取决于积分时间常数，越大，积分作用越弱，反之则越强。
微分环节：能反映偏差信号的变化趋势(变化速率)，并能在该偏差信号变得太大之前，在系统中引入一个有效的早期修正信号，从而加快系统的动作速度，减小调节时间。
4.5.1 位置式PID
位置式PID中，由于计算机输出的u(k) 直接去控制执行机构(如阀门)，u(k)的值和执行机构的位置(如阀门开度)是一一对应的，所以通常称公式(4.2)为位置式PID控制算法。
位置式PID控制算法的缺点是：由于全量输出，所以每次输出均与过去的状态有关，计算时要对过去e(k)进行累加，计算机工作量大；而且因为计算机输出的u(k)对应的是执行机构的实际位置，如计算机出现故障，u(k)的大幅度变化，会引起执行机构位置的大幅度变化，这种情况往往是生产实践中不允许的，在某些场合，还可能造成严重的生产事故。因而产生了增量式PID 控制的控制算法，所谓增量式PID 是指数字控制器的输出只是控制量的增量△u(k)。

增量式PID具有以下优点：

算式中不需要累加。控制增量△u(k)的确定仅与最近k次的采样值有关，所以较容易通过加权处理而获得比较好的控制效果。
但增量式PID也有其不足之处：积分截断效应大，有静态误差；溢出的影响大。使用时，常选择带死区、积分分离等改进PID控制算法。

4.6 速度环控制(半开环控制)
由于单车定向速度过快的特殊性，所以我们采用的是半开环的模式，即在经过某些特殊性的元素时我会更改不同的pwm值以达到大致的速度，而在降速过程中我通过实际测量，列举了一个pwm值和小车转速的对应表，所以当我需要降速到某个需要输出的PWM值时，我会直接给一定的反转值，当小车转速降低到需要输出的PWM值对应表上的转速时，就停止给反转，这样在一定程度上也实现了闭环，所以我称之为半开环的速度环控制。

本报告详细介绍了我们为第二十一届全国大学生智能汽车大赛而准备的智 能车系统方案:主板，电调，PID算法实现前打角以及速度控制算法的实现。分析整个车模系统，我们在车模硬件及软件上都有许多改进与创新。系统上主要有以下特色:

void draw_circle_radius_37000(void)
{
    int radius = 37000;
    int r = radius / 400;
    int cx = 119;           // 圆心x
    int cy = 239 - r-18500/400;       // 圆心y（最下点向上偏移r）

    for (int i = 0; i < 360; i++)
    {
        float a = i * 3.14159f / 180.0f;
        int x = cx + (int)(r * cosf(a));
        int y = cy + (int)(r * sinf(a));
        ips200_draw_point(x, y, RGB565_YELLOW);
    }

    r=37000/5/700;
    cy = 239 - radius / 800-18500/400;
    for (int i = 0; i < 360; i++)
    {
        float a = i * 3.14159f / 180.0f;
        int x = cx + (int)(r * cosf(a));
        int y = cy + (int)(r * sinf(a));
        ips200_draw_point(x, y, RGB565_YELLOW);
    }

    cy = 239 - radius / (800/3)-18500/400;
    for (int i = 0; i < 360; i++)
    {
        float a = i * 3.14159f / 180.0f;
        int x = cx + (int)(r * cosf(a));
        int y = cy + (int)(r * sinf(a));
        ips200_draw_point(x, y, RGB565_YELLOW);
    }

}

void Menu()
{
    static  uint8 Key_number;
    Key_number=Key();
    if(Key_number==key_down || Key_number==key_down_long)
    {
        func_index = table[func_index].down; //向下翻
        system_delay_ms (50);
    }
    else if(Key_number==key_up || Key_number==key_up_long)
    {
         func_index = table[func_index].up     ; //向上翻
         system_delay_ms (50);
    }
    else if(Key_number==key_middle)//确认
    {
        func_index = table[func_index].enter;    //确认
        clear_flag=1;
    }

    else if(Key_number==key_left|| Key_number==key_left_long)//减
    {
        minus_jian();
        system_delay_ms (50);
    }
    else if(Key_number==key_right|| Key_number==key_right_long)//加
    {
        plus_jia();
        system_delay_ms (50);
    }

    if(func_index !=last_index || Key_number!=0||func_index==SUB_MENU_show_imu_data||func_index==SUB_MENU_SB1_Map_draw||func_index==SUB_MENU_SB1_Map_show_imu||func_index==SUB_MENU_SB2_Map_show_imu||func_index==SUB_MENU_SB3_Map_show_imu)
    {
        current_operation_index=table[func_index].current_operation;
        last_arrow_key=arrow_key;
        arrow_key=table[func_index].arrow;
        ips200_show_string(X_0,last_arrow_key,"   ");
        ips200_show_string(X_18,last_arrow_key," ");
        if(clear_flag)
        {
           clear_flag=0;
           ips200_clear();
        }
        (*current_operation_index)();
            last_index=func_index;
    }
}
