## 项目组别

**第 21 届全国大学生智能汽车竞赛 · 单车定向组**

- 车模：**N1 两轮单车**（前轮舵机转向 + 后轮无刷驱动），禁止负压/加宽胎等“作弊式”辅助平衡  
- 场景：**室外**操场，科目含往返直线、**慢速八字**、复杂路段（草地/坡道/**锥桶绕桩**）  
- 国赛口径（报告共识）：科目一往返直线可能取消或不参与排名；科目二八字等有严格判定  

与「雁过留痕」本质不同：主矛盾是 **自平衡 + 短时惯导寻迹**，不是摄像头循迹打靶。

## 硬件栈（跨队共识）

| 模块 | 主流选型 |
|------|----------|
| 主控 | **英飞凌 TC264**（ADS 开发）；少数 TC377 等 |
| 驱动协控 | **CYT2BL3** / 自制 FOC 板，UART 收速度命令 |
| 电机 | **BDS3620** 无刷 + FOC |
| 转向 | **BDS300** 舵机（兼平衡打角） |
| 姿态 | **IMU660RA/RB/RC**、BMI270、ICM42688 等六轴 |
| 测速 | 磁编码器（如 **TLE5012**）/ 正交编码器里程计 |
| 电源 | 约 **3S** 高倍率锂电；动力与控制电源隔离滤波 |
| 调试 | IPS/TFT + 按键；VOFA+/串口上位机 |

摄像头在本赛道 **非标配主感知**；多数队走 **纯惯导/航位推算**。

## 软件架构（依赖关系）

```
IMU采样/零偏标定 → 四元数EKF姿态(Roll/Pitch/Yaw)
编码器/驱动板速度 → 航位推算(INS_X,INS_Y)
遥控器/人工踩点 → 轨迹点Flash(yaw,x,y)
        ↓
任务状态机(直线/八字/绕锥/坡草/停车)
        ↓
寻迹(航向回放 | Pure Pursuit | Stanley | 杜宾斯)
        ↓
目标速度 + 航向误差
        ↓
【最高优先】横滚平衡环(角+角速度) → 舵机
速度环(增量PID) → UART→FOC→电机
保护(倾角超限/偏航越界/电压) → 降功率停车
```

## 核心算法清单

1. IMU 零偏标定 + **四元数 EKF** 姿态  
2. 速度×航向 **航位推算**（忌加速度二次积分）  
3. 轨迹采样写入 Flash + 回放  
4. 寻迹：`IMU_Go` 航向回放 / **Pure Pursuit** / **Stanley** / 杜宾斯绕锥  
5. **串级平衡**：横滚角环 + 角速度环 + 转向耦合  
6. **增量式速度 PID** + 半开环急减速（部分队）  
7. 科目状态机 + 路径安全距离保护  
8. 进阶少数：ADRC、LQR、MPC、参数插值调度
