# 深度学习速查（智能车向）

## 检测（YOLO 系）

- 输入：相机帧；输出：框/类/置信度  
- 关键参：imgsz、conf、iou、类别表  
- 赛场：降 imgsz 换 FPS；提高 conf 减误检；多帧投票减抖  
- 与控制：取目标中心 → 像素偏差 → 转向/平移指令  

## 分割

- 车道/可行驶区/信标区域 mask → 中线或质心  
- 算力通常高于检测；可 ROI 或隔帧  

## 量化 / NPU

- PTQ 快、可能掉点；关键类要验证  
- 目标：控制周期内稳定出结果（常见 30–100 ms 级，视主控而定）  
- 失败模式：量化后小目标消失、类别混淆  

## 传统 vs DL

| | 传统阈值/边线 | DL |
|--|----------------|-----|
| 延迟 | 低 | 中高 |
| 光照 | 敏感 | 相对稳 |
| 调试 | 参数直观 | 需数据 |
| 适用 | 循迹主线 | 元素/目标/复杂场景 |

原则：**能用传统稳定完成的主环，DL 做增强或特定元素**；智能模型/视觉组除外（赛题要求模型）。
