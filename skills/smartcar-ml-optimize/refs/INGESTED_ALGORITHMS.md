## 5. 深度学习部署链（报告共识）

```
相机 → 预处理(缩放/归一) → YOLO/分割(NPU/RKNN) → 后处理(NMS/投票)
     → 偏差/目标结构体 → UART → MCU PID/运动学 → 执行器
```

关键约束：推理异步；控制周期固定；`now-stamp > T` → 降速/停车；量化后复测小目标。
