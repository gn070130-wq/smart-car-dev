# 学习 → 优化 → 部署 工作流

## 1. 学习（从知识库）

1. 打开赛道 `INDEX.md`，锁定算法编号  
2. 读 `ALGORITHMS.md` 对应卡：原理、IO、参数、时序  
3. 需要原文时在 `corpus/` 搜队名/关键词  
4. 输出：算法清单 + 当前瓶颈假设（延迟/精度/鲁棒）

## 2. 优化（LLM 辅助决策）

| 层级 | 动作 | 风险 |
|------|------|------|
| L0 参数 | 阈值、置信度、分辨率、PID | 低 |
| L1 后处理 | NMS、多帧投票、丢失保持 | 低 |
| L2 模型 | 更小骨干、蒸馏、剪枝、量化 | 中 |
| L3 架构 | 双线程推理、ROI、多模型级联 | 中高 |
| L4 换范式 | 传统↔DL 替换 | 高，需对比赛场 |

默认从 L0→L1；用户点名再上 L2+。

## 3. 部署（嵌入式）

1. 导出 ONNX →（RK）RKNN / 其他 NPU 工具  
2. 量测：单帧 ms、端到端 ms、CPU/NPU 占用  
3. 协议：定长帧 + CRC + 超时  
4. 安全：无检测 → 降速/停车；控制环不被推理阻塞  

## 4. 回归

- 固定录包/图集对比前后指标  
- 赛场清单：强光、阴影、反光、远处小目标、运动模糊
