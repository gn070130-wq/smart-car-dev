# 【学习摘要】智能模型（人工智能模型）

## 组别
**第 21 届 · 人工智能模型 / 智能模型**（车载 AI 推理：检测/分割/OCR 等 + 运动控制）

## 硬件栈
| 模块 | 常见选型 |
|------|----------|
| 运动主控 | **TC264** |
| AI 算力 | **RK3588S** / 香橙派 OrangePi 5（**NPU**） |
| 车模 | 阿克曼常见（C 车等） |
| 传感 | 摄像头、编码器、可选雷达/定位模块 |

## 软件架构
上位机（RK）跑 YOLO/分割/OCR → 串口下发偏差/目标 → TC264 做 PID/舵机电机闭环。

## 核心算法
YOLOv8 等检测、语义分割、量化部署、NPU 推理、扫线/车道偏差、PID 转向速度、标定与通讯协议。

## 局限
模型与控制耦合靠串口；量化精度/帧率权衡；完整训练工程少见入库。
