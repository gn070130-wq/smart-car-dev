摘  要
本文面向全国大学生智能汽车竞赛人工智能模型组，给出一套基于 C 型阿克曼转向四轮车的视觉感知、任务决策与分层控制方案。系统采用 RK3588 类平台作为上位机，完成图像帧读取、逆透视变换、HSV 赛道边线提取、RKNN/YOLO 目标检测以及车辆、行人、禁止左转、金币和停车标志等任务的状态管理；采用 TC264 主驱一体控制板作为下位机，通过 3 Mbps 串口接收速度与舵机 PWM 指令，并利用电机驱动、舵机和编码器接口完成执行与状态回传。
巡迹部分对 640×480 俯视图进行颜色阈值分割，逐行提取左右边界，按照断点距离分段并利用二次曲线进行拟合，再由边线偏移生成参考跟踪线。在预瞄区间内采用近端权重更高的横向误差统计，并通过带微分滤波的 PD 控制器换算舵机 PWM。目标检测部分以 320×320 RGB 图像作为 NPU 输入，使用三上下文并发推理、DFL 解码和分类感知 NMS，实现 13 类赛道元素识别。多任务层采用明确的速度与转向优先级，降低不同任务同时触发时的控制冲突。
现有工程能够证明上述软件架构、通信格式、配置参数和主驱控制板电路设计；车模总质量、整车外形尺寸、实装传感器型号及数量、总电容容量、整车功耗、实测检测精度和控制频率尚需结合校赛技术检查表、下位机源码和最终实车补录。本报告以可追溯方式区分已证实内容与待测内容，为后续联调和正式提交提供统一文档基础。
关键词：人工智能模型车；阿克曼转向；逆透视变换；HSV 巡迹；RKNN；多任务决策

第一章 引言
1.1 竞赛背景与任务要求
全国大学生智能汽车竞赛要求总决赛参赛队在赛前提交模型汽车制作技术报告。报告既是参赛作品的一部分，也是评委了解技术路线、工程实现与创新工作的主要依据。根据组委会给出的写作规范，基本内容必须覆盖机械安装与改造、传感器布置、电路设计、微处理器控制算法、开发与调试过程、主要技术参数、详细原理图及核心算法子程序，并在正文后列出参考文献和附录。[1]
本队参加人工智能模型组，选用 C 型阿克曼转向四轮车。该类车模通过前轮转向形成曲率、后轮提供驱动力，机械结构与普通乘用车的转向关系相近。比赛场景同时包含连续赛道边线与多种语义目标，因此系统既要保持高速、稳定的几何巡迹，又要对行人、车辆、禁止左转、金币、停车标志等离散事件进行识别和响应。
1.2 相关技术与方案选择
传统电磁或灰度传感器方案具有响应快、控制链路短的优点，但对人工智能模型组中的语义目标缺少直接表达能力。视觉方案能够在同一输入中同时获得赛道几何信息和目标类别信息，但需要处理透视畸变、颜色变化、推理延迟与任务冲突。OpenCV 提供成熟的颜色空间转换、轮廓提取和几何变换算法，[6] Rockchip RKNN 运行时可利用 RK3588 的 NPU 进行神经网络推理，TC264 则具有适合电机与舵机控制的 GTM、CCU6、VADC、ASCLIN 等外设资源。[2]
综合实时性和可维护性，本方案采用“上位机感知与决策、下位机执行与反馈”的分层结构。上位机保留可快速调参的 JSON 配置，将巡迹与检测放在并行链路中；下位机负责稳定产生电机和舵机控制信号。两者通过固定长度串口帧通信，使算法开发与底层驱动相互解耦。
1.3 主要工作与技术特点
构建共享内存防撕裂取帧与 640×480 IPM 俯视变换链路，统一赛道几何坐标。
设计基于左右边线分段二次拟合、边线偏移和加权预瞄误差的视觉巡迹方法。
采用三个 RKNN 上下文并行完成 13 类目标识别，以非阻塞缓存降低推理对控制主循环的阻塞。
针对车辆、行人、禁止左转、金币和 STOP 标志设计独立状态机，并在主循环中进行统一速度与转向仲裁。
制定 3 Mbps、12 字节控制帧和 6 字节状态帧，实现上位机指令下发与编码器状态回传。
1.4 报告结构安排
第二章说明总体方案、机械结构和部件安装；第三章分析主驱一体板、电源、电机驱动和接口电路；第四章介绍上位机视觉巡迹与目标检测；第五章说明多任务状态机及控制仲裁；第六章介绍下位机功能边界和串口协议；第七章记录开发工具、制作与调试过程；第八章汇总技术参数和测试项目；第九章给出结论、问题与改进方向。正文之后附参考文献、详细原理图、核心程序、技术检查映射表和可选研究论文。

2.1 系统总体方案
模型车由机械底盘、视觉/上位机模块、TC264 主驱一体板、转向舵机、后轮驱动电机、编码器以及供电和线束组成。系统的感知、决策、执行和反馈关系如图 2.1 所示。视觉输入首先进入上位机，经过赛道几何处理和目标识别后生成速度与舵机 PWM；TC264 接收指令并驱动执行机构，编码器状态沿串口返回上位机。

2.2 C 型阿克曼四轮车结构
车模采用前轮转向、后轮驱动的四轮布局。阿克曼几何要求转弯时内侧前轮转角大于外侧前轮转角，使两前轮延长线与后轴延长线近似交于同一瞬时转动中心，从而减小轮胎侧滑。对于轴距 L、前轮轮距 B 和转弯半径 R，理想内外轮转角满足：
	tan(δin)=L/(R−B/2)，tan(δout)=L/(R+B/2)	（1）
实际车模通过舵机、摆臂和转向拉杆形成近似阿克曼关系。
2.3 部件安装与重心控制
2.3.1 视觉与上位机安装
视觉模块应安装在车辆纵向中心面附近，并保证支架具有足够刚度。相机俯仰角、离地高度或 AR 图像坐标系变化会直接影响 IPM 单应矩阵，因此支架位置一旦标定完成不应在比赛前随意调整。上位机板卡宜靠近车体中心布置，接口朝向应便于插拔和散热，同时避免遮挡舵机连杆。
2.3.2 主控板与线束固定
TC264 主驱一体板承担电源转换和电机驱动，宜置于通风、低重心且远离轮胎卷入区域的位置。电机相线和电池线采用短而粗的布线，与视觉信号线、编码器线分开走线；连接器应有极性标识和应力释放。板卡底面不得与金属底盘直接接触，固定柱高度应为焊点和散热留出余量。

第四章 上位机视觉感知与巡迹算法
4.1 图像输入与逆透视变换
当前上位机程序在 Linux 系统中以只读方式映射 POSIX 共享内存 shm_ar_video。共享区头部包含 frame_id、width 和 height，程序在深拷贝图像前后两次读取头部；若帧号或尺寸变化，则判定写入过程中发生撕裂并最多重试 3 次。有效 RGB 图像经上下翻转和 RGB→BGR 转换后进入算法。
为减弱透视缩短对道路几何测量的影响，程序根据已标定单应矩阵建立映射表，并通过 cv::remap 生成固定 640×480 俯视图。若俯视坐标为 p=(x,y,1)^T、原图坐标为 q=(u,v,1)^T，则映射关系可写为：
	λq=Hp	（4）
矩阵 H 由 config.json 保存，当前 9 个系数与 ar_renderer.cpp 中的默认矩阵一致。相机支架或输入图像裁剪发生变化后，必须重新标定并更新矩阵，否则边线位置和目标 IPM 坐标会系统性偏移。
4.2 HSV 赛道边线提取

图 4.1 视觉巡迹与转向控制流程
4.2.1 颜色分割与轮廓筛选
程序将 BGR 图像转换至 HSV 空间，当前阈值下界为 (96,121,134)，上界为 (133,255,255)。二值掩膜经外轮廓提取后，以 100 pixel² 作为一般最小面积阈值；行人活跃时将普通有效轮廓阈值提高至 2000 pixel²，以减少行人附近碎片对巡迹的干扰。阈值通过 JSON 配置，便于在不同光照或仿真渲染参数下重新标定。
4.2.2 边线分段与二次拟合
算法对有效掩膜逐行扫描，提取每一行的最左和最右像素作为原始边界点。相邻点欧氏距离超过阈值时将边线切分为多个连续段，当前左右最大断点阈值分别为 400 和 100 pixel。对不少于 3 个点的边线段采用最小二乘二次曲线拟合：
	x(y)=ay²+by+c	（5）
拟合问题通过 SVD 求解，失败时退化为原始点序列。常规模式优先跟踪左边线并向右偏移 35 pixel 生成中心参考；禁止左转任务锁定右线时改用右边线并向左偏移 40~60 pixel。该方法允许在只观测到单侧边线时仍构造稳定参考路径。
4.3 加权预瞄误差与 PD 控制
在 y=200~230 的预瞄带内取 30 个目标点。对每一行插值得到跟踪线横坐标，并令靠近车辆的行具有更大权重。以图像中心 x0=320 为参考，横向误差为：
	e=Σwi[x(yi)−320]/Σwi，wi=1+(yi−ytop)	（6）
控制器采用比例加带一阶记忆的微分项。当前 Kp=0.06、Kd=0.60，微分更新及舵机 PWM 换算为：
	Dk=0.9Kd(ek−ek−1)+0.1Dk−1	（7）
	PWM=clip[3290−10(Kpek+Dk), 2890, 3690]	（8）
PWM 限幅同时保护舵机机械行程并抑制异常误差。由于 PWM 中值和边界会受舵机、拉杆孔位和前束影响，正式参数应在车轮离地、低速直行和连续弯道三阶段逐步标定。
4.4 RKNN/YOLO 目标检测
4.4.1 NPU 并行推理
Detector 初始化 3 个 RKNN 上下文，并分别绑定 RK3588 的三个 NPU 核。输入图像缩放至 320×320，优先使用 RGA 完成 BGR→RGB 与尺寸变换，失败时回退至 OpenCV CPU 路径。工作线程从任务队列取出最新帧，完成推理后将结果写入完成队列；主循环通过 try_get 非阻塞获取最新结果，并丢弃过时排队帧。
4.4.2 后处理与类别
网络输出同时兼容 NCHW 和 NHWC 排布。边界框采用 DFL 期望值解码，类别得分按类别设置阈值，再用分类感知 NMS 删除高重叠候选框。[8] 当前一般目标阈值为 0.50，red 为 0.38，person 为 0.35，noleft 为 0.40，NMS 阈值为 0.45。

4.5 并发与实时性设计
巡迹线程使用双缓冲交换 IPM 图像，主循环与巡迹计算解耦；RKNN 线程池采用有界队列，队列已满时移除旧任务；目标检测默认每 2 个主循环帧提交一次，并返回最新缓存框。该架构的目标是让控制始终使用“最近可用结果”，避免因单次 NPU 推理或可视化编码造成长时间阻塞。实际主循环 FPS、巡迹 FPS、NPU 单核 FPS 和端到端延迟需在比赛硬件上记录。

第五章 多任务决策与控制策略
5.1 统一任务仲裁框架
各任务模块不直接写串口，而是输出速度建议、横向偏移、边线选择或等待状态。主循环先取得基础巡迹结果，再按固定顺序更新车辆/行人、门区、禁止左转、金币和 STOP 状态，最后统一生成 ControlCmd。该结构将“看见什么”“当前处于什么状态”和“最终执行什么”分离，便于单独测试每个任务。

5.2 车辆与行人处理
5.2.1 车辆避障
CarAvoid 将车辆检测框底部中心映射至 IPM 坐标，并与当前跟踪线在相同 y 处的横坐标比较。车辆进入有效区域后，模块输出横向路径偏移；连续 5 帧未检测到车辆后解除避障，偏移量按衰减系数平滑回归零，避免瞬时回正造成舵机阶跃。当前配置的车辆偏移量为 −70 pixel，避障速度上限为 0.50（控制量纲以技术检查表为准）。
5.2.2 行人冻结决策
行人检测置信度阈值为 0.35。模块对“行人与跟踪线的横向间距”进行 EMA 平滑，并利用相邻帧差分判断移动方向。当行人进入 IPM 图像 y≥180 的近场区域时冻结当前 STOP/GO 决策，防止检测抖动导致命令反复切换；STOP 转 GO 需要连续 5 帧满足释放条件。行人消失后保留短时粘滞停车，并在连续丢失达到阈值后清除历史。
5.3 禁止左转任务
NoleftHandler 对 noleft 目标进行连续帧确认、面积和置信度筛选。当前配置要求连续 3 帧、面积大于 8000 pixel²、置信度不低于 0.75。确认后可裁剪局部图像并请求外部视觉语言模型判断直行或右转，在等待期间令车辆停车；决策完成后通过左/右边线模式切换和 6 s 右线锁定实现路径选择，并在目标连续清除 3 帧后重新布防。
5.4 金币吸引策略
金币模块沿当前参考路径建立累计弧长 s 和切向角 θ，将金币投影至 Frenet 坐标，得到纵向位置 sg 与横向偏移 lg。仅保留预瞄点前后窗口内的金币，并按弧长距离给予高斯权重：
	wj=exp{−(spre−sg,j)²/(2σ²)}	（10）
加权横向期望经限幅和低通滤波后转换为像素偏移，并叠加到基础巡迹误差。当前 delta_back=50、delta_forward=250、sigma=45、最大横移=50、滤波系数 alpha=0.3、增益=1.2；可见金币数量达到 3 个时速度限制为 0.40。现有 imgToWorld/worldToImg 仍为恒等映射，因此这些量目前本质上是像素域参数，后续可引入真实平面标定。
5.5 STOP 标志与故障回退
首次识别 STOP 标志后启动稳态时钟，默认延迟 3.0 s 再输出速度 0，使停车位置相对识别时刻前移。STOP 指令处于最高优先级。若巡迹结果无效，程序应使用保守速度和舵机中值或最近有效值；若串口、图像或检测器初始化失败，正式比赛版本还应增加明确的安全停车条件和故障指示。

double HsvLineTracker::pid_control(double error) {
    double out_d = 0.9 * steering_d_ * (error - last_error_) + 0.1 * last_out_d_;
    double output = steering_p_ * error + out_d;
    last_error_ = error;
    last_out_d_ = out_d;

}
 
int HsvLineTracker::calculate_pwm(double tracking_error) {
    double pwm_offset = pid_control(tracking_error) * pwm_scale_;
    int pwm = pwm_mid_ - static_cast<int>(std::lround(pwm_offset));
    return clip(pwm, pwm_min_, pwm_max_);
}
 
int HsvLineTracker::clip(int val, int lo, int hi) {
    if (val < lo) return lo;
    if (val > hi) return hi;
    return val;
}

B.2 加权预瞄带误差计算
程序 B.2 加权预瞄带误差计算
struct WeightedPathBandMetrics {
    double mean_x = 320.0;
    double mean_error = 0.0;
    bool valid = false;
};
 
static bool interpolate_path_x_at_y(
    const std::vector<cv::Point>& sorted_points,
    int target_y,
    double* out_x) {
    if (out_x == nullptr || sorted_points.empty()) {
        return false;
    }
 
    for (const auto& point : sorted_points) {
        if (point.y == target_y) {
            *out_x = static_cast<double>(point.x);
            return true;
        }
    }
 
    if (sorted_points.size() < 2U) {
        return false;
    }
 
    for (size_t i = 0; i + 1U < sorted_points.size(); ++i) {
        const cv::Point& p0 = sorted_points[i];
        const cv::Point& p1 = sorted_points[i + 1U];
        const int segment_top_y = std::min(p0.y, p1.y);
        const int segment_bottom_y = std::max(p0.y, p1.y);
        if (target_y < segment_top_y || target_y > segment_bottom_y) {
            continue;
        }
 
        const int delta_y = p1.y - p0.y;
        if (delta_y == 0) {
            *out_x = 0.5 * static_cast<double>(p0.x + p1.x);
            return true;
        }
 
        const double ratio =
            static_cast<double>(target_y - p0.y) / static_cast<double>(delta_y);
        *out_x = static_cast<double>(p0.x) +
                 ratio * static_cast<double>(p1.x - p0.x);
        return true;
    }
 
    return false;
}
 
static WeightedPathBandMetrics compute_weighted_path_band_metrics(
    const std::vector<cv::Point>& path_points,
    int sample_bottom_y,
    int sample_top_y,
    double reference_x) {
    WeightedPathBandMetrics metrics;
    if (path_points.empty()) {
        return metrics;
    }
 
    const int band_top_y = std::min(sample_top_y, sample_bottom_y);
    const int band_bottom_y = std::max(sample_top_y, sample_bottom_y);
 
    std::vector<cv::Point> sorted_points = path_points;
    std::sort(sorted_points.begin(), sorted_points.end(),
              [](const cv::Point& a, const cv::Point& b) {
                  if (a.y != b.y) return a.y > b.y;
                  return a.x < b.x;
              });
 
    double weighted_x_sum = 0.0;
    double weighted_error_sum = 0.0;
    double weight_sum = 0.0;
    for (int y = band_top_y; y <= band_bottom_y; ++y) {
        double path_x = 0.0;
        if (!interpolate_path_x_at_y(sorted_points, y, &path_x)) {
            continue;
        }
 
        const double weight = 1.0 + static_cast<double>(y - band_top_y);
        weighted_x_sum += weight * path_x;
        weighted_error_sum += weight * (path_x - reference_x);
        weight_sum += weight;
    }
 
    if (weight_sum > 1e-6) {
        metrics.mean_x = weighted_x_sum / weight_sum;
        metrics.mean_error = weighted_error_sum / weight_sum;
        metrics.valid = true;
    }
    return metrics;
}

B.3 DFL 解码与分类感知 NMS
程序 B.3 DFL 解码与分类感知 NMS
static float dfl_decode(const float* vals, int len) {
    float max_v = vals[0];
    for (int i = 1; i < len; i++)
        if (vals[i] > max_v) max_v = vals[i];
    float sum_exp = 0, result = 0;
    for (int i = 0; i < len; i++) {
        float e = std::exp(vals[i] - max_v);
        sum_exp += e;
        result += e * static_cast<float>(i);
    }
    return result / sum_exp;
}
 
// -- NMS: class-aware, in-place modification (matches reference nms) --
static void nms(std::vector<DetResult>& dets, float threshold) {
    std::sort(dets.begin(), dets.end(),
        [](const DetResult& a, const DetResult& b) {
            return a.score > b.score;
        });
 
    std::vector<bool> suppressed(dets.size(), false);
    for (size_t i = 0; i < dets.size(); i++) {
        if (suppressed[i]) continue;
        for (size_t j = i + 1; j < dets.size(); j++) {
            if (suppressed[j] || dets[i].class_id != dets[j].class_id) continue;
            float xx1 = std::max(dets[i].x1, dets[j].x1);
            float yy1 = std::max(dets[i].y1, dets[j].y1);
            float xx2 = std::min(dets[i].x2, dets[j].x2);
            float yy2 = std::min(dets[i].y2, dets[j].y2);
            float iw = std::max(0.0f, xx2 - xx1);
            float ih = std::max(0.0f, yy2 - yy1);
            float iarea = iw * ih;
            float uarea = (dets[i].x2 - dets[i].x1) * (dets[i].y2 - dets[i].y1) +
                          (dets[j].x2 - dets[j].x1) * (dets[j].y2 - dets[j].y1) - iarea;
            if (uarea > 0 && iarea / uarea > threshold) suppressed[j] = true;
        }
    }
 
    std::vector<DetResult> kept;
    for (size_t i = 0; i < dets.size(); i++)
        if (!suppressed[i]) kept.push_back(dets[i]);
    dets = kept;
}

InferResult RknnPool::do_inference(int ctx_idx, cv::Mat& frame, std::vector<cv::Point>& curve_pts)
{
    rknn_context ctx = contexts_[ctx_idx];
 
    int orig_w = frame.cols, orig_h = frame.rows;
 
    // Pre-processing: resize to 320x320 + BGR→RGB
    cv::Mat rgb;
#ifdef USE_RGA
    rgb.create(INPUT_H, INPUT_W, CV_8UC3);
    rga_buffer_t rga_src = wrapbuffer_virtualaddr(frame.data,
        frame.cols, frame.rows, RK_FORMAT_BGR_888);
    rga_buffer_t rga_dst = wrapbuffer_virtualaddr(rgb.data,
        INPUT_W, INPUT_H, RK_FORMAT_RGB_888);

        cv::Mat resized;
        cv::resize(frame, resized, cv::Size(INPUT_W, INPUT_H));
        cv::cvtColor(resized, rgb, cv::COLOR_BGR2RGB);
    }
#else
    cv::Mat resized;
    cv::resize(frame, resized, cv::Size(INPUT_W, INPUT_H));
    cv::cvtColor(resized, rgb, cv::COLOR_BGR2RGB);
#endif
 
    // Input: UINT8, NHWC, 320x320x3
    rknn_input inputs[1];
    memset(inputs, 0, sizeof(inputs));
    inputs[0].index = 0;
    inputs[0].type = RKNN_TENSOR_UINT8;
    inputs[0].fmt = RKNN_TENSOR_NHWC;
    inputs[0].size = INPUT_W * INPUT_H * 3;
    inputs[0].buf = rgb.data;
    inputs[0].pass_through = 0;
    if (rknn_inputs_set(ctx, 1, inputs) < 0) return {cv::Mat(), std::move(curve_pts), {}};
    if (rknn_run(ctx, nullptr) < 0) return {cv::Mat(), std::move(curve_pts), {}};
 
    // Output: want_float=1 (matches reference)
    std::vector<rknn_output> outs(num_outputs_);
    for (int i = 0; i < num_outputs_; ++i) {
        memset(&outs[i], 0, sizeof(rknn_output));
        outs[i].index = i;
        outs[i].want_float = 1;
        outs[i].is_prealloc = 0;
    }
    rknn_outputs_get(ctx, num_outputs_, outs.data(), nullptr);
 
    // Build float* array and shape array for yolo_post_process
    std::vector<float*> ptrs(num_outputs_);
    for (int i = 0; i < num_outputs_; ++i) ptrs[i] = (float*)outs[i].buf;
 
    int shf_arr[num_outputs_ * 4];
    for (int i = 0; i < num_outputs_; ++i)
        for (int j = 0; j < 4; ++j) shf_arr[i * 4 + j] = output_shapes_[i][j];
 
    auto dets = yolo_post_process(
        ptrs.data(),
        (const int(*)[4])shf_arr,
        output_is_nchw_.data(),
        num_outputs_,
        orig_h, orig_w,
        INPUT_W, INPUT_H);
 
    rknn_outputs_release(ctx, num_outputs_, outs.data());
    return {cv::Mat(), std::move(curve_pts), std::move(dets)};
}

void Uart::sendControlCmd(const ControlCmd& cmd) {

    buff[5] = s_u.buff[2];
    buff[6] = s_u.buff[3];
 
    // 写入 4字节 angle (下标 [7~10])
    buff[7] = a_u.buff[0];
    buff[8] = a_u.buff[1];
    buff[9] = a_u.buff[2];
    buff[10] = a_u.buff[3];
 
    uint8_t check = 0;
    for (int i = 0; i < 11; i++) {
        check += buff[i];
    }
    buff[11] = check; // 累加和校验位

    ;//std::cout << "[Uart TX] 发送: 速度=" << cmd.speed << " 角=" << cmd.steering_angle << std::endl;
    // =============================================================
 
    ssize_t wr = ::write(fd_, buff, 12);
    (void)wr;
}

B.6 Frenet 金币吸引误差
程序 B.6 Frenet 金币吸引误差
float FrenetGoldAttractor::computeError(float mean_preview_x,
                                         const std::vector<cv::Point2f>& gold_coins,
                                         bool& should_slow_down)
{
    // 1. Get preview point arc length s_pre
    const cv::Point2f preview_pt_img(mean_preview_x, 288.0f);
    const cv::Point2f preview_pt_world = imgToWorld(preview_pt_img);
 
    float s_pre, l_pre_unused, theta_ref;
    cv::Point2f ref_pt_pre;
    projectToRef(preview_pt_world, s_pre, l_pre_unused, ref_pt_pre, theta_ref);
 
    // 2. Process each gold coin
    float l_des_raw = 0.0f;
    float weight_sum = 0.0f;
    int valid_gold_count = 0;
 
    for (const auto& coin : gold_coins) {
        const cv::Point2f coin_world = imgToWorld(coin);
 
        float s_g, l_g, theta_g;
        cv::Point2f ref_g;
        projectToRef(coin_world, s_g, l_g, ref_g, theta_g);
 
        // Filter: only coins within the relative window around preview point
        if (s_g < s_pre - delta_back_ || s_g > s_pre + delta_forward_)
            continue;
        if (s_g - s_pre > max_lookahead_)
            continue;
 
        valid_gold_count++;
 
        // Gaussian weight based on arc-length distance to preview point
        const float ds = s_pre - s_g;
        const float w = std::exp(-(ds * ds) / (2.0f * sigma_ * sigma_));
        l_des_raw += w * l_g;
        weight_sum += w;
    }
 
    if (valid_gold_count > 0 && weight_sum > 1e-9f) {
        l_des_raw /= weight_sum;
    } else {
        l_des_raw = 0.0f;
    }
 
    // 3. Clamp to max lateral offset
    l_des_raw = std::clamp(l_des_raw, -max_l_, max_l_);
 
    // 4. Low-pass filter
    const float l_des = alpha_ * l_des_raw + (1.0f - alpha_) * l_des_prev_;
    l_des_prev_ = l_des;
 
    // 5. Compute pixel offset
    const float X_ref = ref_pt_pre.x;
    const float Y_ref = ref_pt_pre.y;
 
    // Desired path point (shifted laterally from reference)
    const float X_des = X_ref - l_des * std::sin(theta_ref);
    const float Y_des = Y_ref + l_des * std::cos(theta_ref);
 
    const cv::Point2f des_img = worldToImg(cv::Point2f(X_des, Y_des));
    const cv::Point2f ref_img = worldToImg(cv::Point2f(X_ref, Y_ref));
 
    const float delta_pixel = des_img.x - ref_img.x;
 
    // 6. Compute final error
    const float error_raw = mean_preview_x - 320.0f;
    const float error = error_raw + delta_pixel;
 
    // 7. Slow down when gold coins are in range
    should_slow_down = (valid_gold_count > 0);
 
    return error;
}

B.7 STOP 延时停车状态
程序 B.7 STOP 延时停车状态
double StopSign::update(const std::vector<Box>& boxes)
{
    // 扫描 STOP 标志 (class_id=3)
    bool has_stop = false;
    for (const auto& b : boxes) {
        if (b.class_id == DetClassId::STOP) { has_stop = true; break; }
    }
 
    // 首次检测到 STOP → 启动定时器
    if (has_stop && !timer_active_) {
        timer_active_ = true;
        timer_start_ = std::chrono::steady_clock::now();
    }
 
    // 定时器激活 → 计时，到期返回 0.0 停车
    if (timer_active_) {
        const auto now = std::chrono::steady_clock::now();
        double elapsed = std::chrono::duration<double>(now - timer_start_).count();
        if (elapsed >= stop_delay_sec_) {
            if (!stop_printed_) {
                std::cout << std::string(100, '?') << std::endl;
                stop_printed_ = true;
            }
            return 0.0;  // 停车（最高优先级）
        }
    }
 
    return -1.0;  // 不干预速度
}

附录 C 基于 Frenet 路径偏移的金币吸引策略研究
C.1 问题描述
人工智能模型组赛道中的金币属于离散视觉目标。若直接将金币横坐标作为舵机误差，车辆容易在多个金币之间来回摆动，且目标远近关系无法与当前道路曲率统一表达。为此，本文以巡迹参考线为基准建立 Frenet 坐标，并把金币吸引转换为沿参考线的平滑横向偏移。
C.2 方法
首先对参考折线累计弧长得到 s，并由相邻点计算切向角 θ。对每个金币点遍历参考线段，求取最近投影点，得到纵向弧长 sg 和横向偏移 lg。仅保留 sg∈[spre−Δback, spre+Δforward] 的金币，按式（D-1）计算权重：
	wj=exp{−(spre−sg,j)²/(2σ²)}	（D-1）
期望横向偏移为金币横向位置的加权平均，并经最大偏移限幅与一阶低通滤波。最后在预瞄点处把横向偏移映射回图像横坐标，与原巡迹误差相加。该方法能够让多个金币共同作用，并通过 σ、最大偏移和滤波系数分别调节作用范围、控制强度和响应平滑性。
C.3 工程实现与局限
当前实现以像素坐标作为参考线坐标，imgToWorld 和 worldToImg 为恒等函数，因此 Δback、Δforward、σ 和最大横移均是像素域参数。这种实现无需额外标定，便于快速调试，但相机高度或 IPM 比例变化会改变参数物理含义。后续可利用地面标定将参考线和金币统一到米制坐标，并在不同速度下调整预瞄距离。
