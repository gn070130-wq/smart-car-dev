摘要 
本文以第二十一届全国大学生智能汽车竞赛为背景，详细介绍了面向人工智能
模型组赛道、基于深度视觉感知的智能车设计与实现方案。系统采用香橙派
RK3588S 上位机与英飞凌 TC264 下位机的双处理器异构架构：上位机搭载四核
Cortex-A76 加四核 Cortex-A55 CPU 及三核 NPU（6TOPS），运行 Linux 操作系
统，经共享内存读取 640×480 赛道图像并完成视觉推理与驾驶决策；下位机采
用 200MHz 双核 TriCore 车规级微控制器，通过 UART 三线接收速度与转向指
令，实现实时运动控制与传感器闭环反馈。整车以逐飞科技 C 型后驱前转阿克
曼车模为载体，按"重件低置、信号隔离"原则分层布局；供电采用 3S 锂电池经
SCT2450 同步降压产生 5V 主电源与舵机可调电压，再经 RT9013-33GB 低压差
线性稳压器隔离出 3.3V，为编码器等传感器提供低噪声电源，实现功率域与信
号域的分离。 
在控制策略上，采用"视觉感知—控制决策—运动执行"逐层闭环架构：上层的
深度学习感知采用 PaddleYOLO 分割与检测一体化模型，经 RKNN-Toolkit2 
INT8 量化后部署至三核 NPU 并行推理池，同时输出道路二值掩码用于巡线，
以及道路、发车标志、停车标志、路牌、行人、金币、大门、车辆、限速标志
等 9 类赛道元素的检测框用于场景识别；道路掩码经 ROI 裁剪与逆透视变换
（IPM）转为鸟瞰视角，采用邻行递推搜索提取左右边线并经贝塞尔拟合与单
边丢失补全生成中线，以预瞄控制计算转向误差。下层运动控制由 TC264 基于
经典控制理论执行，融合阿克曼软件差速与动态 PD 舵机控制：以舵机偏转角
与车速计算等效曲率，经一次项与三次项补偿得到左右后轮目标速度，实现内
外轮的差速驱动；舵机控制频率 330Hz，采用动态 P 项提升对曲率与速度的适
应性。速度反馈以两个 1024 线正交编码器（TIM 四倍频后等效 4096 脉冲/圈）
实现 10ms 周期的闭环跟踪，最终在比赛中稳定完成环岛、行人、车辆、金币
等多种复杂元素的自主应对任务。

第一章 引言 
1.1 竞赛背景 
全国大学生智能汽车竞赛以"立足培养、重在参与、鼓励探索、追求卓越"为指
导思想，是面向全国大学生的多学科交叉综合性科技赛事。人工智能模型组作
为竞赛中侧重端侧智能推理的重要组别，要求参赛队伍设计能够自主识别赛道
并完成规定任务的智能车。赛道中融合了环岛、路牌识别、行人避让、车辆避
障、金币收集等多种复杂元素，对参赛队伍在自动控制、计算机视觉、嵌入式
系统和机械设计等方面的综合能力提出了较高要求。 
1.2 本队研究内容概述 
本队针对人工智能模型组的赛道特点与任务要求，设计并制作了基于香橙派
RK3588S 上位机与 Infineon TC264 下位机双处理器架构的智能车系统。上位机
运行 Linux 操作系统，利用内置的三核 NPU 进行深度学习模型端侧推理，负责
赛道图像获取、道路分割、元素检测、巡线跟踪和驾驶决策。下位机基于裸机
环境运行，负责电机速度闭环控制、舵机转向执行和传感器数据采集。系统整
体实现了从图像感知到运动控制的完整自动驾驶链路。 
本系统的研究亮点与创新点主要体现在以下四个方面： 
一、三核 NPU 并行推理，针对 RK3588S 内置的三核 NPU，建立 3 个相互独立
的推理上下文并绑定各自 NPU 核心，通过推理池并发调度分割与检测任务，充
分利用端侧算力以降低推理延迟。 
二、分割与检测一体化模型，采用单模型同时输出道路二值掩码与九类赛道元
素的检测框，一通推理完成巡线所需的道路分割和场景判别，避免多模型串行
带来的时间开销。 
三、基于优先级状态机的多元素协同决策，对环岛、限速、停车区、行人、车
辆、道闸、金币等元素按优先级顺序统一调度，高优先级元素激活时屏蔽后续
判断，从根本上消除多元素同时触发时的策略冲突。 
四、转向与差速的精细化控制，下位机引入误差平方加权的动态 P 项舵机 PD
控制，以及一次项加三次项曲率映射、自适应增益的阿克曼软件差速，兼顾直
道稳定性与弯道响应速度。

第二章 系统总体方案设计 
2.1 系统总体架构 
本系统采用双处理器分布式控制架构。上位机 RK3588S 通过共享内存从裁判系
统获取赛道图像，利用三核 NPU 并行运行深度学习模型完成道路分割与元素检
测，基于视觉信息进行巡线计算和场景决策，通过 UART 串口向下位机发送速
度与转向指令。下位机 TC264 接收指令后执行 PID 闭环控制和软件差速计算，
驱动电机和舵机完成车辆运动控制，同时采集编码器传感器数据实现闭环反馈。
上下位机通过自定义二进制通信协议进行数据交互，控制周期约 10ms。

第三章 机械结构设计 
3.1 车模布局与传感器安装 
车模采用逐飞科技 C 型车模，为后轮驱动、前轮转向的经典阿克曼布局，整车
沿纵向分为前、中、后三个功能区，各部件按"重件低置、信号隔离"的原则合
理安排。 
前部负责转向与感知。舵机及转向连杆机构安装在车头，通过连杆将舵机转角
传递至前轮，实现前轮转向控制；摄像头通过支架固定在车体上方偏前位置，
正视前方赛道以获取完整且稳定的道路图像，安装高度兼顾了视场范围与逆透
视变换的计算精度。 
中部为整车控制与供电核心区。电池、上位机主板以及下位机核心板等核心电
子模块集中布置于此，采用层叠式结构分层安装：重量较大的电池置于最下层
靠近底盘，以显著降低整车重心、提升过弯稳定性；控制与运算类板卡置于上
层，便于散热与接线维护。各板卡之间按信号流向就近布线，缩短了高频信号
与大电流回路的走线长度。 
后部为驱动动力区。电机驱动板和 RS380 驱动电机安装于车尾，经齿轮减速机
构放大扭矩，再通过差速器将动力分配至左右两个后轮，实现驱动与转弯时的
差速输出。 
两个 1024 线正交编码器分别安装在左右后轮的驱动半轴上，与车轮同步旋转，
可实时、精确地测量两侧车轮的实际转速，为下位机的速度闭环控制提供反馈。
编码器的信号线在走线上刻意远离电机驱动的 PWM 功率线缆，并采用屏蔽与
分类布线，有效减小了驱动回路大电流开关对编码器信号的电磁干扰，保证速
度反馈的准确性。

3.2 电路板固定与连接 
各电路板采用铜柱与尼龙螺柱组合的层叠式结构固定于底盘中部，既保证了机
械强度，又通过尼龙螺柱的绝缘特性避免了板卡间及与车架的短路风险。在分
层布置上，遵循"动力就近、大小电流分离"的原则：电机驱动板、电源板等大
功率模块置于最下层、紧靠电池安装，使动力回路走线最短、回路阻抗最低，
从而减小大电流传输中的线路损耗与对外电磁辐射；上位机主板、下位机核心
板等控制类板卡置于上层，与动力回路在空间上隔离，降低强电回路对弱电信
号的干扰。 
在电气连接上，上下位机采用模块化接口设计，各板卡间连线清晰、分工明确：
上位机与下位机之间通过 UART 三线（TX/RX/GND）进行数据交互，传输速
度与转向指令；下位机通过 PWM 与 GPIO 接口连接电机驱动板和舵机，分别
实现电机调速（含方向控制）与转向执行；编码器经正交编码器接口接入下位
机，构成速度反馈通路。所有接插件均采用防松脱设计，防止车辆行驶振动导
致接触不良；关键信号线预留测试点，便于现场使用示波器或逻辑分析仪快速
定位问题、缩短调试周期。

第四章 电路系统设计 
4.1 下位机控制系统 
下位机采用逐飞科技推出的 Infineon TC264 核心板。TC264 是 AURIX 系列的双
核 TriCore 处理器，主频 200MHz，内置 GTM 高精度 PWM 模块、TIM 编码器
接口和多路 UART/SPI 通 信 接 口 。 TC264 的 IO 分 配 如 下 ： 左 电 机 使 用
P21_2(PWM)和 P21_3(DIR)，右电机使用 P21_4(PWM)和 P21_5(DIR)，舵机使
用 P33_9(PWM)，左右编码器分别接入 TIM2 和 TIM6 正交解码通道，上位机通
信使用 UART0(P14_0/P14_1)。 
4.2 电机驱动电路 
电机驱动采用 TI 公司 DRV8701 H 桥栅极驱动芯片，配合外部 N-MOSFET 构成
全桥驱动电路。TC264 输出 17kHz 的 PWM 信号进行电机转速调节，频率选择
超出人耳可听范围以消除 PWM 啸叫。通过独立的方向 GPIO 控制 H 桥导通方
向实现正反转。PWM 占空比分辨率范围为 0～7000，设有输出限幅保护防止极
端工况下电机失控。

4.3 舵机控制电路 
舵机采用塞曙科技 CS-3120 数字舵机，控制频率设置为 330Hz 以充分发挥数字
舵机的快速响应特性。PWM 中位值对应约 1.5ms 脉宽，左右极限分别对应约
1.64ms 和 1.34ms 脉宽，实际转角范围通过机械限位和软件限幅双重保护。 
4.4 传感器模块 
速度反馈采用两个 1024 线正交编码器，通过 TC264 的 TIM 模块四倍频解码后
等效为 4096 脉冲/圈。编码器安装在电机输出轴上，经齿轮减速比换算后得到
车轮实际转速，速度采样周期为 10ms。 
4.5 电源管理 
整车采用 3S 锂电池供电，标称电压 12.6V、容量 2800mAh。功率与信号供电分
离：电池电压经 SCT2450 同步降压芯片降压，提供 5V 主电源以及舵机所需的
可调电压（8.1V～3.4V），直接为上位机、下位机、舵机和大功率负载供电；
5V 再经 RT9013-33GB 低压差线性稳压器降为 3.3V，为编码器等传感器提供稳
定的低噪声电源。这种分级供电方案既保证了功率回路的供电能力，又通过独
立 LDO 隔离了数字与功率回路的干扰。

4.6 上位机主板 
上位机采用香橙派 RK3588S，搭载四核 Cortex-A76 加四核 Cortex-A55 CPU，

第五章 上位机软件系统设计 
5.1 总体软件架构 
上位机软件基于 C++17 开发，采用多线程流水线架构。系统包含四个核心线程：
图像获取线程负责从裁判系统共享内存读取 640×480 RGB 图像；AI 推理线程
将图像送入三核 NPU 推理池进行分割与检测模型的并行推理；控制线程接收推
理结果，依次完成赛道巡线、元素识别、速度决策和 UART 指令发送；按键线
程监听键盘输入实现停车、恢复、退出等运行时操作。线程间通过线程安全队
列传递数据，实时模式下队列满时自动丢弃最旧帧以保证低延迟。 
程序启动流程严格按照依赖顺序进行：加载配置文件→初始化模型和推理池→
打开共享内存并验证首帧→初始化各元素识别模块→启动工作线程→打开
UART 并发送握手信号→进入正常控制循环。 
5.2 图像获取与预处理 
系统通过共享内存（shm_ar_video）从裁判系统获取 640×480 RGB 三通道的赛
道图像。FrameSource 模块在启动时验证共享内存的存在性和图像尺寸的正确
性，确保不会在无有效图像源的情况下启动车辆。每帧图像附带单调递增的
frame_id 贯穿整个处理链路，用于追踪每帧的处理状态。 
道路分割掩码在进入巡线算法前进行 ROI 裁剪，根据当前场景类型调整 cut_up
和 cut_down 参数以排除天空和无效区域。随后通过逆透视变换（IPM）将相机
视角的道路掩码转换为鸟瞰视角，便于后续的几何计算。 
5.3 深度学习模型推理 
系统采用 PaddleYOLO 分割与检测一体化模型，经 RKNN-Toolkit2 工具链 INT8
量化后部署至 RK3588S NPU。模型同时输出两路结果：640×480 的道路二值掩
码用于巡线跟踪，以及 9 类赛道元素（道路、发车标志、停车标志、路牌、行
人、金币、大门、车辆、限速标志）的检测框用于场景识别。 
为充分利用三核 NPU 的并行能力，系统创建了 3 个独立的 RKNN 推理上下文
（各绑定一个 NPU 核心），通过推理池进行并发调度。后处理流水线包含
DFL 边界框解码、道路掩码解码、置信度过滤和 NMS 去重等步骤，最终合并
为统一的推理结果输出。经端侧实测，三核并行推理可将单帧处理时延控制在
满足上位机控制周期要求的范围内。

5.4 赛道巡线算法 
在 IPM 视角的道路二值图像中，从图像底端向顶部逐行扫描提取左右道路边界
点。采用邻行递推搜索策略，利用道路边界的空间连续性提高搜索效率和鲁棒
性。对提取的边界点进行角度分析和异常点过滤以抑制噪声，当某一侧边线丢
失时根据已知道路宽度和另一侧边线推算丢失侧位置。 
左右边线配对后计算中线点集，采用预瞄控制策略：在中线上选取距车头一定
预瞄距离处的中心点，计算该点相对车头中轴线的横向偏移作为转向误差。预
瞄距离可根据不同赛道场景动态调整，直道时使用较长预瞄距离以保证稳定跟
踪，弯道时适当调整以提前响应曲率变化。 
5.5 赛道元素识别策略 
元素识别按照优先级顺序依次判断：环岛→行人→车辆→金币→普通赛道。当
高优先级元素处于激活状态时跳过后续判断，避免多元素同时触发导致策略冲
突。 
环岛识别结合了深度学习目标检测（路牌定位），通过有限状态机管理入环→
环内通行→出环减速→出环直行各阶段的巡线策略和速度切换。行人识别基于
检测框的空间位置分层判断（远/近、左/右），通过停车等待→冲刺通过→冷
却的状态机实现安全避让。车辆识别采用面积过滤和连续帧确认机制，根据车
辆出现次数区分不同的避障策略。大门识别用于自动圈数计数，不影响车速和
转向。金币识别通过判断金币相对于赛道中线的位置决定车辆偏向策略。 
5.6 速度与转向决策 
系统根据当前场景类型决定目标车速：行人经过区域、车辆避让区域等特殊场
景下使用对应的限制速度；环岛内以基础速度行驶，出环前自动减速，停车状
态下发送零速指令。 
目标速度和转向误差通过 UART 串口以自定义二进制帧协议发送给下位机，每
帧包含帧头(0x42)、地址码、帧长、速度(float32)、转向误差(float32)及校验和。

6.1 软件架构与任务调度

6.2 电机速度 PID 控制 
每个速度控制周期（10ms），系统读取编码器脉冲增量并通过一阶低通滤波消
除高频噪声得到滤波速度。左右电机独立采用增量式 PI 控制器进行速度闭环控
制，输出限幅在安全范围。PI 参数支持通过按键+IPS 屏幕、无线 VOFA+上位
机和 Flash 存储三种方式进行在线调整和断电保存。 
6.3 舵机转向控制 
舵机采用位置式 PD 控制算法，并引入基于误差平方的动态 P 项：小误差时 P
项接近基础值以保证直道稳定性，大误差时 P 项自适应增强以提升弯道响应速
度。动态 P 项限幅在基础 Kp 的±1/3 范围内防止过增。舵机 PWM 输出在左右
极限之间做限幅保护，确保机械安全。 
6.4 阿克曼差速控制 
为提升车辆过弯性能，系统在软件层面实现阿克曼差速控制。根据舵机转角和
车速为左右后轮计算差异化的目标速度：转弯时内侧车轮减速、外侧车轮加速
以消除滑动摩擦。算法包含以下关键设计：转向死区判断（小角度视为直行不
施加差速）、非线性曲率映射（一次项+三次项补偿轮胎侧偏特性）、自适应
差速增益（根据转向角和车速动态调整差速强度）。差速参数均为可调并支持
Flash 保存。

9.1 总结 
本队设计并制作了一台面向人工智能模型组赛道的智能车系统，采用 RK3588S

现赛道理解与驾驶决策，下位机基于经典控制理论实现实时运动控制与传感器
闭环反馈。系统在多线程流水线架构、三核 NPU 并行推理、有限状态机元素处

主应对多种复杂赛道元素的智能车模，并在比赛中稳定完成了规定任务。 
9.2 存在的问题与改进方向 
视觉感知方面：在逆光和赛道反光等强干扰光照下，道路分割掩码的边界易出
现毛刺，可进一步扩充低光照与反光场景的训练数据，并引入图像自适应曝光
预处理。

系统可靠性方面：上下位机串口通信在电磁干扰下偶发丢帧，可在现有校验机
制基础上增加重传与超时保护，进一步提高通信鲁棒性。

void imgprocess(Mat& roadMask) 
{ 
    // 校验输入：必须为 640x480 单通道灰度道路掩码 
    if (roadMask.empty() || roadMask.type() != CV_8U || 
        roadMask.cols != 640 || roadMask.rows != 480) 
    { 
        throw invalid_argument("tracking requires a 640x480 CV_8U road mask"); 
    } 
 
    // 下采样至 320x240，降低后续巡线计算量 
    Mat mask320; 
    resize(roadMask, mask320, Size(320, 240), 0.0, 0.0, INTER_NEAREST); 
 
    // 二值化：道路区域与背景分离 
    threshold(mask320, binaryImg, 0, 255, THRESH_BINARY_INV);

    morphologyEx(binaryImg, binaryImg, MORPH_CLOSE, kernel); 
    morphologyEx(binaryImg, binaryImg, MORPH_OPEN, kernel); 
}

    float steer_norm_abs = fabsf(steer_norm); 
 
    // 死区判断：小角度视为直行，不施加差速 
    if (steer_norm_abs < Ackermann_Str.steer_deadzone) 
    { 
        Motor_L.Motor_speed_aim = Motor_R.Motor_speed_aim = 
            vehicle_speed * pulse_scale; 
        Ackermann_Str.Ackermann_Kdiff_now = 1.0f; 
        return; 
    } 
 
    // 等效曲率：一次项负责基础响应，三次项补偿大舵角非线性 
    float steer_norm_abs3 = steer_norm_abs * steer_norm_abs * steer_norm_abs; 
    float kappa = 0.0f; 
    if (steer_norm > 0) 
        kappa = Ackermann_Str.kappa_l1 * steer_norm_abs + 
                Ackermann_Str.kappa_l3 * steer_norm_abs3;   // 左转为正 
    else if (steer_norm < 0) 
        kappa = -(Ackermann_Str.kappa_r1 * steer_norm_abs + 
                  Ackermann_Str.kappa_r3 * steer_norm_abs3); // 右转为负 
    
 // 阿克曼前馈：左右轮中心速度差的一半

    static const float half_wheel_track = WHEEL_TRACK * 0.5f; 
    float diff_ff = vehicle_speed * half_wheel_track * kappa; 
 
    // 自适应差速增益：随转向角与车速动态调整，并做限幅 
    float Kdiff = Ackermann_Str.kdiff_base + 
                  Ackermann_Str.kdiff_steer * steer_norm_abs + 
                  Ackermann_Str.kdiff_speed * vehicle_speed * vehicle_speed; 
    Kdiff = Limit_Min_Max(Kdiff, Ackermann_Str.kdiff_min, 
Ackermann_Str.kdiff_max); 
    Ackermann_Str.Ackermann_Kdiff_now = Kdiff; 
    float diff = Kdiff * diff_ff; 
    Motor_L.Motor_speed_aim = (vehicle_speed - diff) * pulse_scale; // 内侧轮减速 
    Motor_R.Motor_speed_aim = (vehicle_speed + diff) * pulse_scale; // 外侧轮加速 
}
