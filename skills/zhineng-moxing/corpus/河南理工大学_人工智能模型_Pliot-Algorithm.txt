第一章 模型车设计制作的主要思路以及实现的技术方案概要

本次智能模型车整体采用阿克曼结构车架作为整车基础机械结构，依托阿克曼转向原理实现前轮精准转向，保证车辆行驶轨迹贴合赛道走线要求。整车采用舵机独立转向、直流电机独立驱动的经典控制架构，结构简洁、稳定性强，适配智能车自主循迹行驶需求。
在硬件方案实现上，本车采用单直流电机作为整车动力输出单元，负责为车身行进、加减速提供动力；采用专用舵机作为前轮转向执行机构，实现角度可控的精准转向动作。控制系统选用主逐飞科技TC264D核心板作为整车主控MCU，负责传感器数据采集、算法运算、舵机与电机控制信号输出。除官方核心主控板外，团队自主设计并焊接外设拓展电路，完成整车供电、驱动、通信、信号采集等外围功能电路搭建，实现整套智能车控制系统的完整闭环。


第二章 模型车机械部分安装固定及连接

本车模机械结构以原厂阿克曼底盘为基础，无大规模结构改造，主要通过精准固定与自主加装结构完成整车装配。
车辆动力电机与转向舵机均利用底盘预留标准螺丝孔位进行刚性固定，安装位置贴合原厂机械设计标准，保证传动结构稳定、无虚位、行驶无抖动。针对车载电路设备的安装需求，团队自主三维建模并3D打印专用电路板安装支架，实现主控板与外设电路板的分层固定，布线整齐、抗震性强。同时，为适配车载3S锂电池的安装固定，单独设计并打印电池限位凹槽结构，可牢固固定电池，防止车辆高速行驶、过弯颠簸时电池位移，提升整车结构稳定性与安全性。整体机械装配布局紧凑合理，重心居中，满足赛道高速行驶与连续过弯的工况需求。


第三章 电路设计说明

本车模主控采用主飞科技TC264D核心板，外围全部功能电路由团队自主设计绘制，整体原理图分为电源模块、电机驱动模块、信号采集模块、通信模块与人机交互模块。整车由3S锂电池提供12V直流输入，通过多路DC‑DC降压芯片生成多组不同电压，分别为单片机、RK上位机板卡、舵机等外设供电；动力回路保留电池原始12V直接供给驱动电机。
电源供电电路
电源系统使用TPS5430、TPS5450两款DC‑DC降压芯片搭建三路独立降压回路：
5V主控降压电路：TPS5430将输入12V电池电压降压输出5V，为TC264D单片机、编码器、CH340通信芯片、按键、声光提示电路等数字器件供电，输入端与输出端配置大容量电解电容与陶瓷电容，完成滤波、抑制纹波，保证数字电路供电纯净。
舵机6.35V降压电路：采用TPS5450独立降压，输出6.35V专门给转向舵机供电，独立电源避免舵机大电流工作时压降干扰主控系统，保障舵机扭矩与转向响应性能。
RK板卡供电电路：另一路TPS5430降压输出5V，专门为RK上位机板卡供电，与单片机5V电源相互独立，减少上下位机之间的电源串扰。
3.3V降压电路：由LDO稳压芯片将5V进一步转换得到3.3V，为部分外设电平匹配电路提供电源。
电机驱动直接使用电池输入12V电压，不经过降压，保证电机动力输出能力。
电源输入端口增加防反接、滤波电路，防止电池接反损坏后级电路，提升硬件容错能力。 
电机驱动电路 
电机驱动采用英飞凌IRS2184驱动芯片搭建H桥功率驱动电路，实现直流电机正转、反转、PWM调速与电磁制动。TC264D输出PWM控制信号输入IRS2184，驱动后级MOS管完成功率放大，驱动直流动力电机。电路增加续流、RC吸收网络，吸收电机换向产生的反向电动势，保护功率器件与主控芯片。电机轴配套光电编码器电路，编码器供电与信号调理电路集成在板上，将转速脉冲信号送入MCU，实现电机转速采集，为速度闭环控制提供反馈数据。
舵机PWM信号电路
舵机供电取自独立6.35V电源，单片机输出PWM控制信号经过电平缓冲、隔离处理之后输出至舵机信号引脚，增强信号驱动能力，抑制电机驱动带来的电磁干扰，防止PWM信号畸变造成舵机抖动、转角不准。 
上下位机通信接口电路
板载CH340G串口芯片构成USB转串口通信电路，实现TC264D主控与上位机、RK板卡之间的数据交互。可以实时上传车速、转向角度、传感器原始数据，支持在线参数调试、数据记录，为算法调参提供硬件基础。原理图同时预留RK板卡USB配套接口，拓展板卡通信链路。 
人机交互与外设电路 
板上集成按键电路、LED指示灯电路、蜂鸣器报警电路与GPIO扩展接口：按键用于模式切换；LED用于状态指示；蜂鸣器实现故障、启动提示；GPIO外扩排针预留传感器拓展接口，方便后期外接各类检测传感器。
电路整体设计特点
电路采用模块化分页设计，功率回路与信号回路分区布局；动力电源与数字电源相互隔离，降低电机启停带来的纹波干扰；电源输入增加防反接保护，各个接口预留滤波与缓冲，硬件抗干扰能力较强，满足阿克曼智能车高速运行、频繁加减速、转向的竞赛工况。
 
第四章 微处理器控制软件主要理论、算法说明及代码设计介绍
                                                                                                                                                                                                                                                                                                                                                                                                                                                        本系统主控平台采用英飞凌AURIX TC264DA双核单片机，基于TriCore架构，CPU主频200MHz，SPB外设总线100MHz。开发工具链选用AURIX Development Studio或TASKING，底层依托英飞凌官方库，核心驱动由龙邱智能科技提供的LQ_前缀库实现，作为全国大学生智能汽车竞赛AI模型组的下位机，设备通过UART/USB与RK3588、香橙派EdgeBoard等上位机完成交互，接收目标速度与转向指令，完成电机、舵机的闭环控制，同时向上位机回传车速、电池电压、设备自检状态等信息。系统双核分工明确，core0_main（Cpu0_Main.c）负责全部外设初始化与主控制循环，core1_main在CPU0完成初始化之后依靠互斥量进入空转状态，系统依靠CCU60定时器1ms中断t12驱动全部周期任务线程。

软件采用三层架构进行搭建，Libraries/iLLD为英飞凌官方底层寄存器驱动库，src/Driver为LQ_驱动层，包含UART、SPI、GTM(PWM)、GPT12(编码器)、CCU6(定时器)、GPIO、STM、ADC、QSPI、I2C、FFT、EEPROM、EMEM驱动模块；src/APP为显示外设层，实现OLED096、TFT1.8/2.0、按键、LED相关功能；src/User为应用层，包含Icar整车状态机、Motor电机控制、Encoder编码器处理、Servo舵机控制、Pid算法、Usb通信、Rgb状态灯、Gpio、Imu（已禁用）、Flash、Soc电池管理模块。工程通过include.h统一汇总全部头文件，各个模块依靠extern声明的全局结构体完成交互，包括icarStr、motorStr、servoStr、pidStr、usbStr、rgbStr，模块之间不存在直接耦合关系。

系统采用增量式PID完成速度闭环控制，搭配死区处理与输出限幅机制，增量式PID输出PWM增量，计算公式为U(n) = U(n-1) + Kp·Δe(n) + Ki·e(n) + Kd·Δ²e(n)，其中e代表目标值与反馈值的偏差，Δe为偏差一阶差分，Δ²e为偏差二阶差分；当误差落在±VV_DEADLINE即±2范围内时，跳过积分累加，抑制编码器静止抖动，输出PWM幅值限制在±MOTOR_PWM_MAX也就是±1000，对应约95%占空比，防止MOS管烧毁，实际标定参数Kp=1.6，Ki=0.5，Kd=0.02，控制周期设置为10ms。Motor.c中完成单位换算，实现目标速度m/s到10ms脉冲计数的转换，也可以将编码器脉冲计数换算为实际运行速度，硬件参数为编码器512线、4倍频，减速比2.7，轮径0.064m。系统内置安全逻辑，只有冲刺使能开启或者USB通信在线时，才允许输出PWM信号，否则强制输出为0，规避上电或者通信掉线带来的电机误动作风险。编码器测速依靠GPT12定时器硬件正交解码，无需软件判别转向，使用引脚P10_3计数、P10_1方向，16位计数器读取数值后完成有符号转换，得到10ms内脉冲增量，直接作为PID控制器的反馈输入。

舵机控制实现角度到PWM脉宽的线性映射，输出50Hz PWM信号，硬件引脚为ATOM3_6即P11_11，脉宽区间500~2500us，中位1500us，左极限1150us，右极限1850us；调用SERVO_AngleControl函数完成角度线性换算，左转、右转分别以左右极限作为基准计算输出，舵机中位补偿、左右极限阈值支持上位机通过USB在线下发参数，并且写入Flash实现掉电保存，SERVO_SetPwmValueCorrect完成参数处理与输出限幅。

上下位机通信采用自定义UART帧协议，波特率115200，帧结构依次为帧头0x42、设备地址、帧长4~30字节、有效数据、累加和校验字节，校验方式为对长度-1个字节求和后和末尾校验字节比对；地址最高位0x80区分读写操作，置位代表读指令，否则为写指令。为降低控制指令延迟，0x01速度转向控制帧在串口中断内直接解析执行，不进入主循环排队处理，通信地址分别为0x01控制指令、0x02速控模式、0x03舵机阈值、0x04蜂鸣器、0x05灯效、0x06按键、0x07电池、0x08车速反馈、0x0A自检心跳、0x0B自检指令。通信掉线检测逻辑设置3秒超时，接收不到有效通信帧时判定连接断开，执行强制停车、速度清零保护。

整车逻辑由Icar状态机实现，按键支持计时检测，长按2秒开启冲刺使能，目标速度设置2.0m/s，持续3秒之后自动结束冲刺并停车，按键触发时长通过USB向上位机上报。设备自检状态流转顺序为Selfcheck_None、MotorA~H、ServoA、Com、Buzzer、RgbLed、Key、Finish，自检过程先执行电机开环正反转，采集速度校验转向正确性，再运行电机闭环控制，对比实际速度和目标速度，偏差小于0.3m/s判定正常，各个自检步骤出现超时或者故障，将错误信息存入errorCode位域，回传给上位机。测速数据采用中值滤波算法，连续采集5组测速样本，通过冒泡排序取中间值，调用ICAR_SortFloat函数，滤除单点毛刺干扰。

WS2812 RGB状态灯采用ATOM1_CH7输出800kHz PWM配合DMA实现时序驱动，预先计算每一位对应的比较寄存器数值，DMA在CM0匹配中断触发下自动改写ATOM影子寄存器SR1，输出精准的0、1电平波形，高电平0.4us代表数据0，高电平0.8us代表数据1，复位信号维持48个周期，整个过程CPU无需参与运算。通过50ms短时间窗口、200ms长时间窗口的速度平均值差值识别车辆运动状态，匀速显示白色、加速显示绿色、减速显示蓝色，停车状态为黑色，状态变更增加200ms防抖，需要连续3次判定确认才切换；舵机脉宽相对于中位偏移大于60且维持150ms以上识别为转向，左转点亮左侧9颗灯珠、右转点亮右侧9颗灯珠，灯光为黄色，代码内部完成RGB向GRB位序转换，并且实现RGB_SetColorToColor颜色渐变功能。

软件整体采用线程化周期调度，1ms定时器中断依次调用GPIO_Timer、MOTOR_Timer、ICAR_Timer、USB_Edgeboard_Timer、RGB_Timer，各个任务内部使用计数器做时间分频，电机控制周期10ms，自检步骤间隔2-3s，任务之间互不阻塞。整体架构属于前后台系统，中断服务程序负责数据采样、标志位置位，编码器、串口接收、按键检测放在中断中，core0_main主循环完成业务逻辑处理，调用ICAR_Handle、USB_Edgeboard_Handle，遵循嵌入式系统快中断、慢主循环的设计原则。整车全部运行状态封装至全局结构体icarStr，各个模块通过include.h以extern方式访问，便于上位机调试与功能对接；舵机阈值、速度控制模式支持上位机在线标定，参数写入Flash实现掉电不丢失。软件设置多重安全保护，电机默认闭环控制，通信丢失自动停机，冲刺功能限时，自检超时自动回退，PWM输出限幅，全方位保障硬件运行安全。

第五章 开发工具、制作、安装、调试过程说明

整车作品的制作工作分为硬件制作、机械加工、软件工程搭建三个核心环节。硬件制作阶段，依托嘉立创EDA完成全套电路设计与电气检测，输出PCB生产文件后完成电路板打样，按需采购芯片、阻容元件、接插件等各类元器件，通过焊接工艺完成自主设计外围电路板的制作，保障硬件电路基础功能完整。机械加工阶段，利用SolidWorks完成定制结构建模并通过3D打印完成零件加工，基于阿克曼底盘的预留标准孔位，完成驱动电机、转向舵机的固定安装，再将3D打印的支架、电池槽等配件装配至底盘，完成电路板、电池等核心部件的定位安装，保证整车机械结构稳固。软件工程搭建阶段，在AURIX Development Studio中新建项目工程，完成系统时钟、PWM输出、外部中断、串口通信等底层外设的参数配置与驱动初始化，同时借助VS Code完成车速闭环控制、舵机转向控制等上层算法程序的编写与优化，程序调试无误后编译生成可执行文件，下载烧录至TC264D核心板，完成整套控制程序的移植部署。

第八章 核心算法子程序

一、速度闭环控制
1. 增量式 PID —— PID_MoveCalculate（src/User/Pid.c）

signed int PID_MoveCalculate(PIDStruct *pp)
{
    float error, d_error, dd_error;
    error   = pp->vi_Ref - pp->vi_FeedBack;      // 速度误差
    d_error = error - pp->vi_PreError;           // 误差一阶差分（比例+微分增量）
    dd_error = d_error - pp->vi_PreDerror;       // 误差二阶差分（加速度抑制）

    pp->vi_PreError  = error;
    pp->vi_PreDerror = d_error;

    if( ( error < VV_DEADLINE ) && ( error > -VV_DEADLINE ) )  // 死区消抖
        ;
    else
        pp->vl_PreU += ( pp->v_Kp * d_error + pp->v_Ki * error + pp->v_Kd * dd_error );
                                                               // 增量累加
    if( pp->vl_PreU >= MOTOR_PWM_MAX )   pp->vl_PreU = MOTOR_PWM_MAX;   // 输出限幅
    else if( pp->vl_PreU <= MOTOR_PWM_MIN ) pp->vl_PreU = MOTOR_PWM_MIN;
    return (pp->vl_PreU);
}

算法要点：
位置增量式PID公式：U(n)=U(n-1)+Kp·Δe+Ki·e+Kd·Δ²e
死区：±2 范围内不累加；输出限幅 ±1000
PID参数：Kp=1.6，Ki=0.5，Kd=0.02，控制周期10ms


2. 速度目标换算 + 闭环调用 —— MOTOR_ControlLoop（src/User/Motor.c）

void MOTOR_ControlLoop(float speed)
{
    if(speed > MOTOR_SPEED_MAX)  speed = MOTOR_SPEED_MAX;
    else if(speed < -MOTOR_SPEED_MAX) speed = -MOTOR_SPEED_MAX;

    // 目标 m/s → 编码器脉冲数/10ms
    pidStr.vi_Ref = (float)(speed * MOTOR_CONTROL_CYCLE / motorStr.DiameterWheel
                          / PI * motorStr.EncoderLine * motorStr.ReductionRatio);
    MOTOR_SetPwmValue(PID_MoveCalculate(&pidStr));
}


3. 电机 PWM + 方向输出 —— MOTOR_SetPwmValue（src/User/Motor.c）

void MOTOR_SetPwmValue(signed int pwm)
{
    pwm = -pwm;
    if(pwm>=0) { PIN_Write(P11_3, 1);  if(pwm>MOTOR_PWM_MAX) pwm=MOTOR_PWM_MAX;
                 ATOM_PWM_SetDuty(IfxGtm_ATOM2_4_TOUT98_P11_9_OUT, pwm*5, 12000); }
    else if(pwm<0){ PIN_Write(P11_3, 0); if(pwm<MOTOR_PWM_MIN) pwm=MOTOR_PWM_MIN;
                 pwm=-pwm;
                 ATOM_PWM_SetDuty(IfxGtm_ATOM2_4_TOUT98_P11_9_OUT, pwm*5, 12000); }
}

硬件说明：
12kHz PWM载波，通道ATOM2_4/P11_9；方向控制IO：P11_3；PWM正负实现电机正反转。


二、编码器测速反馈
4. 编码器采样 + 速度换算 —— ENCODER_RevSample（src/User/Encoder.c）

void ENCODER_RevSample(void)
{
    motorStr.EncoderValue = ENC_GetCounter(ENC5_InPut_P10_3);
    if(motorStr.EncoderValue > 32767)
        motorStr.EncoderValue -= 65536;        // 16位计数器转有符号

    pidStr.vi_FeedBack = motorStr.EncoderValue;               // PID反馈（脉冲）
    // 脉冲 → m/s
    icarStr.SpeedFeedback = (float)(motorStr.EncoderValue * PI * motorStr.DiameterWheel)
                          / MOTOR_CONTROL_CYCLE / motorStr.EncoderLine / motorStr.ReductionRatio;
    // 记录最高速
    if(icarStr.SpeedFeedback > 0 && icarStr.SpeedFeedback > icarStr.SpeedMaxRecords)
        icarStr.SpeedMaxRecords = icarStr.SpeedFeedback;
    else if(icarStr.SpeedFeedback < 0 && -icarStr.SpeedFeedback > icarStr.SpeedMaxRecords)
        icarStr.SpeedMaxRecords = -icarStr.SpeedFeedback;
}

硬件参数：
GPT12硬件四倍频正交解码，引脚P10_3/P10_1；编码器512线，减速比2.7，轮径0.064m。


三、舵机转向控制
5. 角度 → 脉宽线性映射 —— SERVO_AngleControl（src/User/Servo.c）

void SERVO_AngleControl(float angle)
{
    uint16_t pwm = 1500;
    angle = -angle;
    if(angle > SERVO_ANGLE_MAX)  angle = SERVO_ANGLE_MAX;
    else if(angle < -SERVO_ANGLE_MAX) angle = -SERVO_ANGLE_MAX;

    if(angle >= 0)   // 右转
        pwm = (float)angle/SERVO_ANGLE_MAX * (SERVO_PWM_MAX_R - servoStr.thresholdMiddle) + servoStr.thresholdMiddle;
    else             // 左转
        pwm = (float)angle/SERVO_ANGLE_MAX * (servoStr.thresholdMiddle - SERVO_PWM_MAX_L) + servoStr.thresholdMiddle;
    SERVO_SetPwmValue(pwm);
}


6. 中值补偿 + 限幅输出 —— SERVO_SetPwmValueCorrect（src/User/Servo.c）

void SERVO_SetPwmValueCorrect(signed int pwm)
{
    pwm = 3000 - pwm;                        // 左→右方向反转
    pwm -= servoStr.thresholdMiddle - SERVO_PWM_MIDDLE;   // 中值补偿

    uint16_t pwmMax = 3000 - servoStr.thresholdLeft;
    uint16_t pwmMin = 3000 - servoStr.thresholdRight;
    if(pwm < pwmMin) pwm = pwmMin;
    else if(pwm > pwmMax) pwm = pwmMax;
    ATOM_PWM_SetDuty(IfxGtm_ATOM3_6_TOUT100_P11_11_OUT, pwm/2, 50);  // 50Hz
}

说明：
舵机PWM频率50Hz；左/中/右阈值1150/1500/1850，支持在线标定，参数保存至Flash。


四、上位机通信协议
7. 串口中断收帧 + 控制指令实时执行 —— USART1_IRQHandler（src/User/Usb.c）

void USART1_IRQHandler(void)
{
    Uart1Res = UART_GetChar(UART0);
    if(Uart1Res == USB_FRAME_HEAD && !usbStr.receiveStart){ ... }   // 帧头0x42
    else if(usbStr.receiveIndex == 2){ ... }                        // 帧长合法检查
    else if(usbStr.receiveStart && usbStr.receiveIndex < USB_FRAME_LENMAX)
        usbStr.receiveBuff[usbStr.receiveIndex++] = Uart1Res;

    if(帧接收完毕) {
        for(i=0;i<length-1;i++) check += receiveBuff[i];            // 累加和校验
        if(check == receiveBuff[length-1]) {
            memcpy(receiveBuffFinished, receiveBuff, USB_FRAME_LENMAX);
            receiveFinished = TRUE;
            if(USB_ADDR_CONTROL == receiveBuffFinished[1]) {        // 0x01 控制帧
                // 中断内直接解析，保证实时性
                SERVO_SetPwmValueCorrect(bint16_Union.U16);          // 舵机 int16
                icarStr.ServoPwmSet = bint16_Union.U16;
                icarStr.SpeedSet = bint32_Union.Float;               // 速度 float
            }
        }
    }
}

帧结构：0x42 | 地址 | 帧长 | 数据 | 累加和；地址最高位区分读、写。

五、测速中值滤波
9. 5点采样取中值 —— ICAR_SpeedSample + ICAR_SortFloat（src/User/Icar.c）

float ICAR_SpeedSample(void)
{
    if(icarStr.counterModuleCheck > 100) {        // 100ms 采一点
        switch(icarStr.speedSampleStep) {
            case 0..3: buffSample[step]=SpeedFeedback; step++; break;
            case 4:    buffSample[4]=SpeedFeedback; step=0;
                       ICAR_SortFloat(buffSample,0,5);   // 冒泡排序

        icarStr.counterModuleCheck = 0;

    return 0;

七、RGB 状态灯算法
11. 加减速 / 停车分类 —— RGB_Classify（src/User/Rgb.c）

static RGB_State_t RGB_Classify(void)
{
    // 200ms 环形缓冲存速度历史
    hist[histIdx] = cur;  histIdx=(histIdx+1)%RGB_LONG_WIN;
    // 停车：|v|<0.03 连续3次
    if(停稳判断) return RGB_STATE_STOP;
    // 长平均(200ms) 与 短平均(50ms)
    diff = shortAvg - longAvg;
    if(diff >  RGB_ACCEL_THR) return RGB_STATE_ACCEL;   // 加速 → 绿
    if(diff < -RGB_ACCEL_THR) return RGB_STATE_DECEL;   // 减速 → 蓝
    return RGB_STATE_CONST;                              // 匀速 → 白
}
