第一章 引言
1.1 概述
全国大学生智能汽车竞赛以“立足培养、重在参与、鼓励探索、追求卓越”为指导思想，涉及机械、模式识别、电子、电气、传感技术、计算机、自动化控制和汽车理论等多个领域，充分体现了大学生综合运用所学知识与探索创新的精神。该赛事由教育部高等教育司委托（教高司函〔2005〕201号），由教育部高等学校自动化专业教学指导分委员会（以下简称“自动化分教指委”）主办，是一项全国性、多学科交叉、兼具趣味性与创新性的赛事，旨在培养大学生的实践能力与团队合作精神，促进高等教育改革。竞赛规则透明、评价标准客观，并坚持公开、公平、公正的原则，从而保障赛事健康、广泛、持续发展。
学校积极响应教育部关于加强大学生实践能力、合作精神和创新能力培养的号召，组建智能车队伍参赛。我们参加第二十一届全国大学生智能汽车竞赛人工智能模型组，并进行了充分、认真的准备。根据本届竞赛规则，人工智能模型组允许自制车模，因此我们在符合规则的前提下完成了车模设计与制作。
技术方面，我们选用德国 Infineon Technologies AG 公司的 TC264D40F200W 微控制器作为核心控制单元，并从零开始设计控制方案，涵盖传感器信号采集与处理、电机驱动以及控制算法软件开发。
在软件算法方面，我们以传统 PID 算法为主要控制方法。为保证智能车在高速行驶和急转弯工况下的动力性能与稳定性，我们借鉴往届队伍的经验，并持续优化车模机械结构。

本技术报告详细记录了第二十一届全国大学生智能汽车竞赛杭电人工智能模型一队的智能车开发过程，内容涵盖机械与硬件设计、TC264D40F200W 单片机应用、PID 算法研究，以及车模机械结构参数的调整与优化。
1.2 整车设计
1.2.1  车辆布局
结构上保留传统 C 车模的前、后桥，并对底盘进行改进，以便安装板卡、主板等部件。板卡和主板通过塑料柱架高，避免与底盘接触而导致短路。
为提高车辆稳定性，我们下移了车身重心，并将电池布置在车辆右后侧，以平衡左侧板卡的重量。该布局有助于改善整车配重，提高过弯灵活性，并降低高速过弯时发生侧翻的风险。
杭电人工智能模型一队车模主要由以下部分组成：
1）底盘及附属部件，包括驱动电机、电池等；
2）官方 RK3588S 板卡；
3）龙邱编码器测速模块；
4）单片机最小系统板，包括电源处理与检波电路；
5）机械结构件、摄像头支架及摄像头传感器；
6）IPS 显示屏。



1.2.2  控制简述
上位机部分的总体思路与百度官方方案一致：首先利用 PPseg 语义分割模型识别赛道，再对分割得到的黑白图像进行传统扫线，拟合赛道中线以实现循迹。对于赛道元素，则部署 YOLO 模型进行识别，并针对不同类别分别处理，例如车辆避让和行人避让；对于路牌元素，先通过百度开源 OCR 模型识别文字，再调用大模型 API 进行语义判断。
上、下位机之间采用串口通信。上位机将扫线计算得到的偏差发送至主板，再由主板完成相应的 PID 控制。
在人工智能模型组的控制方案中，我们采用周期为 5 ms 的模糊 PID 舵机控制环实现转向，并采用周期为 2 ms 的速度环进行闭环控制，以提高速度控制精度。由于本组别需要处理多种赛道元素，我们还为各元素区段分别设置 PD 参数，以更好地完成赛题任务。
1.3 小结
本章介绍了杭电人工智能模型一队的总体设计思路与车辆布局，为后续机械、硬件和软件系统的详细说明奠定基础。

第三章 系统硬件电路设计
3.1 硬件电路整体架构设计

图3.1 杭电人工智能模型一队硬件结构示意图
系统整体结构如图3.1 ，硬件设计采用模块化架构，分为​​主板设计​​、​​电机驱动设计和电源降压设计​三大核心模块，确保系统高效协同运行。
​​主板设计​​作为主控核心，涵盖引脚分配、电源管理及外设集成。引脚分配优化信号传输路径；电源模块为各部件提供稳定电压；外设部分集成无线串口（远程调试）、陀螺仪（姿态检测）、编码器（速度反馈）、PWM隔离（驱动保护）及IPS彩屏（实时调试），形成完整的数据采集与交互链路。
​​电机驱动设计​​聚焦电机驱动控制，通过引脚分配实现信号对接，电路设计包含栅极驱动供电（功率放大）、H桥电路（电机驱动），保障电机高响应与可靠性。
电源降压设计包括TPS5450降压电路，为板卡提供稳定供电。
整体架构层次清晰，为智能车在人工智能模型组任务场景下的稳定运行奠定了硬件基础。

3.2 单片机最小系统电路设计
TC264D40F200W单片机最小系统电路设计主要包括电源电路、时钟电路、复位电路和调试接口四个关键部分。电源电路采用3.3V供电方案，使用LDO稳压芯片将输入电压稳定在3.3V，在电源输入端并联100μF电解电容和0.1μF陶瓷电容进行滤波，在MCU每个电源引脚附近放置0.1μF去耦电容。时钟电路采用外部20MHz无源晶振配合两个22pF负载电容，晶振尽量靠近MCU的XTAL1和XTAL2引脚布局。复位电路采用10kΩ上拉电阻和100nF电容组成RC复位网络，同时预留手动复位按钮，复位引脚通过0.1μF电容滤波。调试接口采用10pin SWD标准接口，包含SWDIO、SWCLK和GND信号，并预留UART串口通信引脚用于调试输出。所有未使用的IO口通过10kΩ电阻上拉或下拉处理，避免悬空状态。PCB布局时电源走线加粗处理，数字地和模拟地单点连接，晶振电路下方禁止走线，高速信号线尽量缩短走线长度。在电源入口处放置TVS二极管进行过压保护，关键信号线上串联33Ω电阻抑制信号反射。为方便扩展，所有GPIO口通过排针引出，重要电源测试点预留测试焊盘。该最小系统设计经过实际测试验证，能够稳定运行并满足智能车控制系统的需求，后续可根据具体应用场景扩展CAN总线、PWM输出、ADC采样等外围电路功能。特别注意TC264D40F200W的BOOT0和BOOT1引脚需要通过10kΩ电阻固定到适当电平以确定启动模式，在调试阶段预留跳线帽以便灵活切换启动方式。
 
3.3 PWM隔离设计


图3.2 隔离电路
该模块基于 SN74LVC245APWR 8 位总线收发器实现 4 路 PWM 信号的缓冲隔离与方向可控传输，输入端通过 GH1.25 连接器 U9 引入 PWM1~PWM4 信号至芯片 A 侧，经内部缓冲后由 B 侧输出至后端网络；芯片采用 VCC5V 供电，方向控制引脚 DIR 接排针 H4 引入的 PWMS1 信号，用于配置数据传输方向，输出使能端 OE# 控制缓冲器的开关状态；电路通过总线收发器实现前后级电气缓冲隔离，增强 PWM 信号的驱动能力与抗干扰性能，防止后端负载对前端控制器产生不良影响，适用于多路 PWM 控制信号的隔离转发与电平兼容场景。

3.4 电源管理电路设计
系统稳定运行的基础在于电源设计，本方案采用两级供电架构：第一级通过TI的TPS5450 DC-DC转换器将16.8V电池电压直接降压至5V，该芯片集成高性能MOSFET，支持36V宽输入范围，可提供持续稳定的5V输出；第二级采用两个RT9048 LDO稳压器，分别从5V降压为3.3V，为摄像头和MCU等核心外设提供独立供电。所有电源电路均严格遵循芯片厂商推荐的设计规范，包括外围元件选型、PCB布局和去耦电容配置等关键参数，确保各供电节点纹波控制在允许范围内。这种分级供电方案既保证了电源转换效率，又实现了不同功能模块之间的电源隔离，有效避免了相互干扰。具体电路实现细节可参考各芯片的官方设计手册，在此不再赘述。

3.5 主板与板卡通信

图3.3 USB转串口电路
该模块采用 CH340N USB 转串口芯片，通过 USB A 型母座 实现主板与板卡之间的 USB-UART 通信转换；USB 差分信号 D+/D- 接入 CH340N 的 UD+/UD- 引脚，经芯片内部转换后由 RXD、TXD 引脚输出 TTL 电平串口信号至后端板卡，VCC 供电端配合 C29、C30 退耦电容稳定芯片工作，V3 引脚外接 100nF 电容为内部 3.3V 稳压输出提供滤波，整体电路简洁、即插即用，适用于主板通过 USB 接口与板卡进行串口数据交互的场景。

3.6 主板设计
本设计将电源管理模块与单片机最小系统高度集成于主控主板。主板设置电池 XT30 供电接口及各类外设连接器，并集成完整的电源转换电路。接口电路板的机械结构经过优化，通过合理布置螺丝孔位，确保其能够稳固安装在车模上，避免运行过程中发生位移。主板与外围设备之间采用 GH1.25 和 GH2.54 接口连接；五向按键作为独立模块插接于 H5 排针，并通过 M5 孔固定。该一体化设计兼顾系统稳定性、安装便利性与集成度。各电路模块采用紧凑布局，在保证电气性能的同时尽量减小整体体积。主板如图 3.4 所示。

图3.4 主板

3.7 电机驱动电路设计
该模块为 4 路半桥电机驱动电路，采用 IR2104STRPBF 半桥栅极驱动器配合 TPH1R403NL N 沟道 MOSFET 组成四组独立的半桥功率级，由 VCC12V 供电；每路通道中，IR2104 通过自举电路（SS54 二极管与 1μF 电容）生成高侧驱动电压，分别输出 HO/LO 信号驱动上下桥臂 MOSFET，栅极串接 10Ω 电阻抑制振铃，并辅以 4.7kΩ 下拉电阻防止误导通，输出端并联 SS54 续流二极管吸收反电动势；PWM1~PWM4 信号经连接器输入，分别控制四路半桥的开关时序，模块配备输入滤波电容、电源指示灯及安装孔，整体可驱动多路直流电机、组合成 H 桥驱动步进电机或用于其他功率开关场景。
3.8 电源降压板设计
该模块基于 TI TPS5450DDAG4 降压芯片，将 12V 输入（经 XT30 接口 CN7 接入）转换为稳定的 5V 输出（VCC5V），通过 XT30 接口 CN9 及 USB Type-C 座 U12 为板卡和外设供电。电路中，L1（10μH）为功率电感，D2 为续流二极管，R70（12kΩ）与 R71（3.9kΩ）组成反馈分压网络将输出电压设定在约 5V；输入端设有 220μF 电解电容及陶瓷电容进行滤波，并配备 F1（2A 自恢复保险丝）和 D3（SMAJ13A TVS 管）实现过流与浪涌保护；USB Type-C 的 CC 引脚经 5.1kΩ 电阻下拉，标识本端口为 UFP 受电设备。整体电路结构简洁，具备宽压输入、高效率输出及完善的输入保护特性，适用于从 12V 总线获取 5V 电源的嵌入式供电场景。

3.9 总结
硬件电路设计必须确保高可靠性和强抗干扰能力，核心原则是"稳定压倒一切"。单片机供电系统需特别加强，通过增加大容量储能电容（如1000μF电解电容配合0.1μF陶瓷电容）来应对电调启动时的瞬时电流冲击，防止电压跌落引发系统复位。电路板开发采用严格的迭代流程：初期手工制板进行72小时不间断压力测试验证基础稳定性；通过验证后依据优化后的原理图进行专业PCB布线，交由正规PCB厂生产首版样品；对样品实施全面检测，未达标的板卡（存在纹波超标、布局不合理或性能缺陷等问题）必须重新设计制作，直至各项参数完全符合要求。硬件作为智能车系统的根基，其品质直接决定后续软件开发的可能性，必须坚持"一次做对"的工程理念，在电路设计、元件选型和制板工艺每个环节都执行最高标准。


第四章 软件系统设计
4.1  软件控制的总体思路
软件系统是智能车的核心组成部分。板卡首先完成语义分割与 YOLO 模型识别，再通过路径规划拟合循迹路线；随后，板卡经串口将偏差发送至主板，由主板进行 PID 计算并控制车辆循迹，最终完成比赛任务。
4.2  基础巡线
赛题发布初期，我们采用传统巡线方案，即使用 OpenCV 进行图像处理并拟合中线完成循迹。但该方案鲁棒性较弱，容易受到与赛道颜色相近物体的干扰。参考官方提供的思路后，我们改用语义分割模型获得二值化赛道图像，再结合传统扫线方法进行循迹。改进后的方案鲁棒性更高，也更不易受外界环境干扰。
4.3  元素识别
由于本届赛题中的模型与往届差异较大，仅依靠传统图像处理难以准确区分各类元素。考虑到本届采用的 RK3588S 板卡具有足够的计算性能，我们选用 YOLO 模型进行元素识别，以兼顾识别准确率与处理速度，更好地满足赛题要求。





4.4  特殊元素的处理
4.4.1 车辆的处理
通过 YOLO 模型识别车辆类别后，根据目标在图像中的位置进行路径规划。例如，当目标车辆位于赛道左侧时，将规划线向右侧偏移，使本车能够正常避让。

4.4.2 行人处理
通过 YOLO 模型识别行人位置，并依据其图像坐标判断是否处于赛道内。当行人进入设定阈值范围时，车辆强制停车；待行人离开赛道后，车辆继续循迹。

4.4.3 路牌处理
首先通过 YOLO 模型判断目标是否为路牌，再利用 OCR 模型识别路牌文字；随后通过 API 将识别结果提交给远程大模型进行语义判断，以确定车辆应直行还是右转进入岔路。

4.5 PID控制算法
在工程实际中，应用最为广泛的调节器控制规律为比例、积分、微分控制，简称PID 控制，又称PID调节。PID控制器问世至今已有近70年历史，它以其结构简单、稳定性好、工作可靠、调整方便而成为工业控制的主要技术之一。当被控对象的结构和参数不能完全掌握，或得不到精确的数学模型时，控制理论的其它技术难以采用时，系统控制器的结构和参数必须依靠经验和现场调试来确定，这时应用PID控制技术最为方便。即当我们不完全了解一个系统和被控对象，或不能通过有效的测量手段来获得系统参数时，最适合用PID 控制技术。PID控制，实际中也有PI和PD控制。PID控制器是一种线性控制器，它根据给定值与实际输出值构成控制偏差。将偏差的比例(P)、积分(I)和微分(D)通过线性组合构成控制量，对被控对象进行控制，故称PID控制器。

简单说来，PID控制器各校正环节的作用如下：比例环节：及时成比例地反映控制系统的偏差信号，偏差一旦产生，控制器立即产生控制作用，以减少偏差。
积分环节：主要用于消除静差，提高系统的无差度。积分作用的强弱取决于积分时间常数，越大，积分作用越弱，反之则越强。
微分环节：能反映偏差信号的变化趋势(变化速率)，并能在该偏差信号变得太大之前，在系统中引入一个有效的早期修正信号，从而加快系统的动作速度，减小调节时间。
4.5.1 位置式PID
位置式PID中，由于计算机输出的u(k) 直接去控制执行机构(如阀门)，u(k)的值和执行机构的位置(如阀门开度)是一一对应的，所以通常称公式(4.2)为位置式PID控制算法。
位置式PID控制算法的缺点是：由于全量输出，所以每次输出均与过去的状态有关，计算时要对过去e(k)进行累加，计算机工作量大；而且因为计算机输出的u(k)对应的是执行机构的实际位置，如计算机出现故障，u(k)的大幅度变化，会引起执行机构位置的大幅度变化，这种情况往往是生产实践中不允许的，在某些场合，还可能造成严重的生产事故。因而产生了增量式PID 控制的控制算法，所谓增量式PID 是指数字控制器的输出只是控制量的增量△u(k)。

增量式PID具有以下优点：
由于计算机输出增量，所以误动作时影响小，必要时可用逻辑判断的方法关掉。
手动/自动切换时冲击小，便于实现无扰动切换。此外，当计算机发生故障时，由于输出通道或执行装置具有信号的锁存作用，故能保持原值。
算式中不需要累加。控制增量△u(k)的确定仅与最近k次的采样值有关，所以较容易通过加权处理而获得比较好的控制效果。
但增量式PID也有其不足之处：积分截断效应大，有静态误差；溢出的影响大。使用时，常选择带死区、积分分离等改进PID控制算法。


4.6 速度环控制
由于行人可能在车辆距离较近时才进入识别范围，为避免碰撞，系统需要执行紧急制动。接收到制动指令后，立即将速度环目标速度设为负值，以实现快速减速；当编码器反馈值降至较小范围、车辆接近静止时，再将目标速度设为 0。该方法能够缩短停车距离，并减少速度超调。
第五章 开发工具、调试过程说明
前几章主要介绍系统方案及其细化设计，而系统的最终完善仍依赖现场调试。各功能模块涉及较多参数，其确定需要开展软硬件联合调试，因此必须配备完整的开发与调试环境，包括源代码编辑与编译环境、参数调节和设定工具等。
我们主要的开发环境是 AURIX™ Development Studio，版本是 1.10.2，主要使用的编码语言是 C 语言。
5.1 现场调试
基本程序完成后，仍需在现场进行微调。为此，我们自制了按键和 IPS 模块。比赛现场，操作队员根据赛道状况和智能车循迹表现，通过按键调整程序参数，主要包括：
1）不同类型赛道的速度参数；
2）方向环 PD 控制的 Kp、Kd 等参数。方向环控制参数显示在 IPS 屏幕上，并通过主板按键进行增减调节。
为确定适用于不同赛道的参数，我们投入了大量时间完成赛道绘制、车辆测试和参数整定。尽管调试过程较为曲折和辛苦，但车辆性能持续提升也让团队的付出更具价值。
5.2 调试中遇到的问题及解决过程
赛车即使在相同赛道上运行，其实际轨迹也可能存在差异，因此仅依靠预设状态难以覆盖全部情况，需要建立完善的实时监控方案。为此，我们使用了插件驱动、自由度较高的 VOFA+ 上位机，以降低图形化调试门槛。其主要特点包括：
保留了传统字节流调试助手风格的数据收发功能，以应对非图形化调试需求；
通过直观极简的协议设计和方便快捷的命令绑定，硬件工程师无需处理复杂的协议逻辑，只需以面向串口助手的编程方式，就能获得强大的数据可视化、数据分析、使用控件发送指令的能力；
拥有一个可裁剪的系统，"丰俭由人"。通过添加控件的方式，工程师可以定制一个无限丰富的调试界面；
拥有一个开放、开源的插件系统：
用户可以定制符合自己需求的协议和控件；
通过开源社区的力量，VOFA+的调试生态可以不断发展繁荣。

第七章 结论
本报告详细介绍了杭电人工智能模型一队为第二十一届全国大学生智能汽车竞赛设计的智能车系统方案，包括主板、驱动板、基于 PID 的转向控制以及速度控制算法。通过对整车系统的分析与优化，我们在车模硬件和软件方面均进行了改进。系统主要具有以下特点：
1）采用 IMU 和编码器作为传感器，并通过编码器反馈实现速度闭环控制；
2）主板和驱动板采用塑料柱与胶带固定，在保证稳定性的同时便于快速更换；
3）根据实际需求定制主板和驱动板，较高的集成度有效减轻了重量、缩小了体积，并便于机械布局；
4）增加按键与 IPS 辅助调试电路，便于现场快速调整参数，增强车辆对赛道的适应能力；
5）根据实际需求调整车模前桥、后桥及重心位置，降低通过特殊元素时的侧翻风险，并提高转弯灵活性。
程序控制部分仅启用一个定时中断，控制流程简洁，便于调试。整体系统仍有进一步优化空间，我们将在后续测试中持续改进。

static void Menu_InsZoneLoad(uint8_t lap)
{
    uint8_t count;

    if(lap >= 3 ||INS_NAV_is_split_ready() == false)
    {
        return;
    }

    count = INS_NAV_get_manual_count(lap);

    if(count >= INS_NAV_MANUAL_ZONE_MAX)
    {
        if(ins_zone_id >= count)
        {
            ins_zone_id = count - 1;
        }
    }
    else if(ins_zone_id > count)
    {
        // 不允许在count后面产生空洞。
        ins_zone_id = count;
    }

    if(ins_zone_id < count &&INS_NAV_get_manual_zone(lap,ins_zone_id,&ins_zone_edit))
    {
        // 已有区段。
        ins_zone_start =ins_zone_edit.start_index;
        ins_zone_end =ins_zone_edit.end_index;

        ins_zone_select_state = 3;
        ins_map_cursor = ins_zone_start;
    }
    else
    {
        // ins_zone_id == count，表示新区段。
        Menu_InsZoneSetDefault();

        ins_zone_start = 0;
        ins_zone_end = 0;
        ins_zone_select_state = 0;
    }

    ins_zone_last_lap = lap;
    ins_zone_last_id = ins_zone_id;

    ins_zone_delete = false;
    ins_zone_delete_confirm = false;

    ins_map_need_redraw = true;
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       将快速地图编辑步长限制为不小于一个轨迹点
// 参数简介       无
// 返回参数       void                     无返回值
// 备注信息       直接复用公共SetupNumber和SetupIndex，不建立第二套步长。
//-------------------------------------------------------------------------------------------------------------------
static void Menu_InsZoneClampStep(void)
{
    while(SetupNumber[SetupIndex] < 1.0f)
    {
        MenuNumber_SetupCtrl_Plus();
    }
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       增大快速地图编辑使用的公共步长
// 参数简介       无
// 返回参数       void                     无返回值
// 备注信息       公共步长从1000回绕后会被修正到1。
//-------------------------------------------------------------------------------------------------------------------
static void Menu_InsZoneStepPlus(void)
{
    MenuNumber_SetupCtrl_Plus();
    Menu_InsZoneClampStep();
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       减小快速地图编辑使用的公共步长
// 参数简介       无
// 返回参数       void                     无返回值
// 备注信息       步长为1时继续减小仍保持1。
//-------------------------------------------------------------------------------------------------------------------
static void Menu_InsZoneStepSub(void)
{
    MenuNumber_SetupCtrl_Sub();
    Menu_InsZoneClampStep();
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       开始当前显示物理圈的手动区域快速编辑
// 参数简介       lap                      当前显示物理圈，范围0~2
// 返回参数       bool                     验证通过并进入编辑时返回true
// 备注信息       新区域只复制ZoneDef参数，不修改任何已有区域。
//-------------------------------------------------------------------------------------------------------------------
static bool Menu_InsZoneQuickBegin(uint8_t lap)
{
    uint8_t manual_count;
    uint16_t lap_point_count;

    if(lap >= 3 ||INS_NAV_is_split_ready() == false)
    {
        return false;
    }

    manual_count = INS_NAV_get_manual_count(lap);
    lap_point_count = INS_NAV_get_lap_point_count(lap);

    if(manual_count >= INS_NAV_MANUAL_ZONE_MAX ||lap_point_count == 0)
    {
        return false;
    }

    if(ins_map_cursor >= lap_point_count)
    {
        ins_map_cursor = lap_point_count - 1u;
    }

    ins_zone_id = manual_count;
    Menu_InsZoneSetDefault();

    ins_zone_start = ins_map_cursor;
    ins_zone_end = ins_map_cursor;
    ins_zone_select_state = 1;
    ins_zone_quick_active = true;
    ins_zone_delete = false;
    ins_zone_delete_confirm = false;
    ins_zone_last_lap = lap;
    ins_zone_last_id = ins_zone_id;

    Menu_InsZoneClampStep();
    ins_map_need_redraw = true;
    return true;
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       按公共步长移动快速编辑地图光标
// 参数简介       direction                正数向上增加下标，负数向下减小下标
// 返回参数       void                     无返回值
// 备注信息       终点选择阶段不允许光标小于已经锁定的起点。
//-------------------------------------------------------------------------------------------------------------------
static void Menu_InsZoneQuickMove(int8_t direction)
{
    uint16_t lap_point_count;
    uint16_t min_index;
    uint16_t max_index;
    uint16_t step;
    uint8_t lap;

    if(ins_zone_quick_active == false ||
       ins_zone_select_state == 0 ||
       ins_zone_select_state == 3 ||
       ins_display_lap < 1 ||
       ins_display_lap > 3)
    {
        return;
    }

    lap = (uint8_t)(ins_display_lap - 1u);
    lap_point_count = INS_NAV_get_lap_point_count(lap);

    if(lap_point_count == 0)
    {
        return;
    }

    Menu_InsZoneClampStep();
    step = (uint16_t)SetupNumber[SetupIndex];
    min_index = (ins_zone_select_state == 2) ? ins_zone_start : 0u;
    max_index = lap_point_count - 1u;

    if(direction > 0)
    {
        if(ins_map_cursor >= max_index ||
           step >= max_index - ins_map_cursor)
        {
            ins_map_cursor = max_index;
        }
        else
        {
            ins_map_cursor += step;
        }
    }
    else
    {
        if(ins_map_cursor <= min_index ||
           step >= ins_map_cursor - min_index)
        {
            ins_map_cursor = min_index;
        }
        else
        {
            ins_map_cursor -= step;
        }
    }

    ins_map_need_redraw = true;
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       处理快速地图编辑的中键状态切换
// 参数简介       无
// 返回参数       void                     无返回值
// 备注信息       第一次锁定起点，第二次锁定终点，等待状态不响应中键。
//-------------------------------------------------------------------------------------------------------------------
static void Menu_InsZoneQuickMid(void)
{
    if(ins_zone_quick_active == false)
    {
        return;
    }

    if(ins_zone_select_state == 1)
    {
        ins_zone_start = ins_map_cursor;
        ins_zone_end = ins_map_cursor;
        ins_zone_select_state = 2;
        ins_map_need_redraw = true;
    }
    else if(ins_zone_select_state == 2)
    {
        ins_zone_end = ins_map_cursor;
        ins_zone_edit.start_index = ins_zone_start;
        ins_zone_edit.end_index = ins_zone_end;
        ins_zone_select_state = 3;
        ins_map_need_redraw = true;
    }
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       取消当前快速地图区域选择
// 参数简介       无
// 返回参数       void                     无返回值
// 备注信息       不调用INS_NAV_set_manual_zone，因此不会写入手动区域表。
//-------------------------------------------------------------------------------------------------------------------
static void Menu_InsZoneQuickCancel(void)
{
    ins_zone_quick_active = false;
    ins_zone_quick_edit = false;
    ins_zone_select_state = 0;
    ins_zone_start = 0;
    ins_zone_end = 0;
    ins_zone_last_lap = 0xFF;
    ins_zone_last_id = 0xFF;
    ins_map_need_redraw = true;
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       保存当前快速地图选择形成的新手动区域
// 参数简介       无
// 返回参数       void                     无返回值
// 备注信息       保存统一通过INS_NAV_set_manual_zone完成，失败时保留等待状态。
//-------------------------------------------------------------------------------------------------------------------
static void Menu_InsZoneQuickSave(void)
{
    uint8_t lap;

    if(ins_zone_quick_active == false ||
       ins_zone_select_state != 3 ||
       ins_display_lap < 1 ||
       ins_display_lap > 3)
    {
        return;
    }

    lap = (uint8_t)(ins_display_lap - 1u);
    ins_zone_edit.start_index = ins_zone_start;
    ins_zone_edit.end_index = ins_zone_end;

    if(INS_NAV_set_manual_zone(lap,
                               ins_zone_id,
                               &ins_zone_edit))
    {
        ins_zone_quick_active = false;
        ins_zone_quick_edit = false;
        ins_zone_select_state = 0;
        ins_zone_last_lap = lap;
        ins_zone_last_id = ins_zone_id;
        ins_zone_delete = false;
        ins_zone_delete_confirm = false;
        ins_map_need_redraw = true;
    }
}
//-------------------------------------------------------------------------------------------------------------------
// 函数简介       初始化三圈的终点
// 参数简介       无
// 返回参数       void                     无返回值
// 备注信息       画图完成后进行调用
//-------------------------------------------------------------------------------------------------------------------
void Menu_InsNavTask(void)
{
#if INS_NAV_ENABLE
    uint8_t lap;
    uint8_t manual_count;

    if(INS_NAV_is_preview_ready() == false)
    {
        if(ins_split_menu_initialized)
        {
            ins_map_need_redraw = true;
        }

        ins_menu_lap1_end = 0;
        ins_menu_lap2_end = 0;
        ins_menu_lap3_end = 0;
        ins_split_confirm = false;
        ins_split_menu_initialized = false;
        ins_map_cursor = 0;

        Menu_InsZoneReset();
        return;
    }

    if(ins_split_menu_initialized == false)
    {
        uint16_t confirmed_boundary[4];

        if(INS_NAV_is_split_ready())
        {
            if(INS_NAV_get_confirmed_boundaries(confirmed_boundary) == false)
            {
                return;
            }

            ins_menu_lap1_end = confirmed_boundary[1];
            ins_menu_lap2_end = confirmed_boundary[2];
            ins_menu_lap3_end = confirmed_boundary[3];
        }
        else if(INS_NAV_get_boundary(&ins_menu_lap1_end,
                                     &ins_menu_lap2_end,
                                     &ins_menu_lap3_end) == false)
        {
            return;
        }

        ins_split_menu_initialized = true;
        ins_map_need_redraw = true;
    }

    if(ins_split_confirm)
    {
        if(INS_NAV_confirm_boundaries(ins_menu_lap1_end,
                                      ins_menu_lap2_end,
                                      ins_menu_lap3_end))
        {
            ins_map_cursor = 0;
            Menu_InsZoneReset();
            ins_map_need_redraw = true;
        }

        ins_split_confirm = false;
    }

    if(ins_display_lap < 1 || ins_display_lap > 3)
    {
        ins_display_lap = 1;
    }

    lap = (uint8_t)(ins_display_lap - 1u);

    if(INS_NAV_is_split_ready() == false)
    {
        Menu_InsZoneReset();
        return;
    }

    if(ins_zone_quick_edit && ins_zone_quick_active == false)
    {
        if(Menu_InsZoneQuickBegin(lap) == false)
        {
            ins_zone_quick_edit = false;
        }
    }

    if(ins_zone_quick_active == false &&
       (ins_zone_last_lap != lap ||
        ins_zone_last_id != ins_zone_id))
    {
        Menu_InsZoneLoad(lap);
    }

    if(ins_zone_quick_active == false &&
       ins_zone_delete_confirm)
    {
        ins_zone_delete_confirm = false;
        manual_count = INS_NAV_get_manual_count(lap);

        if(ins_zone_delete)
        {
            ins_zone_delete = false;

            if(ins_zone_id < manual_count &&
               INS_NAV_delete_manual_zone(lap, ins_zone_id))
            {
                manual_count = INS_NAV_get_manual_count(lap);

                if(manual_count == 0)
                {
                    ins_zone_id = 0;
                }
                else if(ins_zone_id >= manual_count)
                {
                    ins_zone_id = manual_count - 1u;
                }

                ins_zone_last_id = 0xFF;
                Menu_InsZoneLoad(lap);
            }
        }
        else if(ins_zone_id < manual_count &&
                INS_NAV_set_manual_zone(lap,
                                        ins_zone_id,
                                        &ins_zone_edit))
        {
            ins_zone_last_id = 0xFF;
            Menu_InsZoneLoad(lap);
        }
    }
#endif
}

        return INS_MENU_ROWS;

    return EVERY_FOLDER_NUMBER;
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       计算当前菜单项目的屏幕Y坐标
// 参数简介       row                      当前显示窗口中的项目行号，从1开始
// 返回参数       uint16_t                 项目的屏幕Y坐标
// 备注信息       分屏状态下第1行从Y=240开始。
//-------------------------------------------------------------------------------------------------------------------
static uint16_t Mymenu_get_item_y(int row)
{
    if(Mymenu_is_ins_page())
        return INS_MENU_Y + FONT_H * (row - 1);

    return SHOW_STAR_Y + FONT_H * row;
}


//-------------------------------------------------------------------------------------------------------------------
// 函数简介       计算当前菜单窗口的首个显示项序号
// 参数简介       无
// 返回参数       int                      返回计算或查询结果
// 备注信息       仅在本文件内部调用。
//-------------------------------------------------------------------------------------------------------------------
static int Mymenu_get_show_start(void)
{
    int start = 1;
    int count = key_menu_p->father->sons_Count;
    int visible_rows = Mymenu_get_visible_rows();

    if(key_menu_p->No > visible_rows)
        start = key_menu_p->No - visible_rows + 1;

    if(start < 1)
        start = 1;

    if(count > visible_rows &&
       start > count - visible_rows + 1)
    {
        start = count - visible_rows + 1;
    }

    return start;
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       计算当前菜单窗口能够显示的项目数量
// 参数简介       start                    当前页面首个显示节点
// 返回参数       int                      返回计算或查询结果
// 备注信息       仅在本文件内部调用。
//-------------------------------------------------------------------------------------------------------------------
static int Mymenu_get_show_count(int start)
{
    int count = key_menu_p->father->sons_Count - start + 1;
    int visible_rows = Mymenu_get_visible_rows();

    if(count > visible_rows)
        count = visible_rows;

    if(count < 0)
        count = 0;

    return count;
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       按照序号查找指定父菜单的子节点
// 参数简介       father                   父菜单节点地址
// 参数简介       no                       需要查找的同级节点编号
// 返回参数       Folder_Menu *            返回目标对象地址，查找失败时可能为NULL
// 备注信息       仅在本文件内部调用。
//-------------------------------------------------------------------------------------------------------------------
static Folder_Menu *Mymenu_get_child_by_no(Folder_Menu *father, int no)
{
    Folder_Menu *p = father->son_first;
    while (p != NULL && p->No < no)
        p = p->next_brother;
    return p;
}
//-------------------------------------------------------------------------------------------------------------------
// 函数简介       绘制当前文件夹菜单页面
// 参数简介       无
// 返回参数       void                     无返回值
// 备注信息       由对应模块任务或上层控制流程调用。
//-------------------------------------------------------------------------------------------------------------------
void Mymenu_show_task(void)
{
    char tmpchar[FOLDER_NAME_LEN + 1];
    int show_start = Mymenu_get_show_start();
    int show_count = Mymenu_get_show_count(show_start);
    Folder_Menu *son_p = Mymenu_get_child_by_no(key_menu_p->father, show_start);

    for (int row = 1; row <= show_count && son_p != NULL; row++)
    {
        for (int j = 0; j < FOLDER_NAME_LEN + 1; j++)
            tmpchar[j] = ' ';

        if (son_p->kind == Normal_Folder)
            sprintf(tmpchar, "%s[%d]", son_p->name, son_p->sons_Count);
        else
            sprintf(tmpchar, "%s", son_p->name);
        tmpchar[strlen(tmpchar)] = ' ';
        tmpchar[FOLDER_NAME_LEN] = '\0';

        menu_show_string(FONT_W * 2, Mymenu_get_item_y(row), tmpchar);
        son_p = son_p->next_brother;
    }

    for (int j = 0; j < FOLDER_NAME_LEN + 1; j++)
        tmpchar[j] = ' ';
    tmpchar[FOLDER_NAME_LEN] = '\0';

    for (int row = show_count + 1; row <= Mymenu_get_visible_rows(); row++)

}

        clean[j] = ' ';

    clean[FOLDER_NUMBER_LEN + 2] = '\0';
    for (int row = show_count + 1; row <= Mymenu_get_visible_rows(); row++)
    {
        menu_show_string(FONT_W * (COLS_SUM_LEN - FOLDER_NUMBER_LEN - 2), Mymenu_get_item_y(row), clean);
    }
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       获取当前显示圈在连续预览数组中的范围
// 参数简介       start                    返回当前圈起点下标
// 参数简介       end                      返回当前圈终点下标
// 返回参数       bool                     边界和预览有效时返回true
// 备注信息       使用菜单中的临时边界，因此确认分圈前也可以查看轨迹。
//-------------------------------------------------------------------------------------------------------------------
static bool Mymenu_get_ins_map_range(uint16_t *start, uint16_t *end)
{
    uint16_t total;

    if(start == NULL || end == NULL || INS_NAV_is_preview_ready() == false)
        return false;

    total = INS_NAV_get_preview_point_count();
    if(ins_menu_lap1_end == 0 ||
       ins_menu_lap1_end >= ins_menu_lap2_end ||
       ins_menu_lap2_end >= ins_menu_lap3_end ||
       ins_menu_lap3_end > total)
    {
        return false;
    }

    switch(ins_display_lap)
    {
        case 1:
            *start = 0;
            *end = ins_menu_lap1_end;
            break;

        case 2:
            *start = ins_menu_lap1_end;
            *end = ins_menu_lap2_end;
            break;

        case 3:
            *start = ins_menu_lap2_end;
            *end = ins_menu_lap3_end;
            break;

        default:
            return false;
    }

    return (*end > *start);
}

}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       计算当前圈轨迹的统一缩放和中心
// 参数简介       start                    当前圈起点下标
// 参数简介       end                      当前圈终点下标
// 返回参数       bool                     成功取得全部轨迹点时返回true
// 备注信息       X和Y使用同一个缩放比例，保持轨迹形状不变。
//-------------------------------------------------------------------------------------------------------------------
static bool Mymenu_calc_ins_map_scale(uint16_t start, uint16_t end)
{
    const INS_NAV_POINT *origin;
    const INS_NAV_POINT *point;
    uint16_t index;
    float x;
    float y;
    float min_x = 0.0f;
    float max_x = 0.0f;
    float min_y = 0.0f;
    float max_y = 0.0f;
    float range_x;
    float range_y;
    float scale_x;
    float scale_y;

    if(end <= start)
        return false;

    origin = INS_NAV_get_preview_point(start);
    if(origin == NULL)
        return false;

    for(index = start + 1; index < end; index++)
    {
        point = INS_NAV_get_preview_point(index);
        if(point == NULL)
            return false;

        x = point->x - origin->x;
        y = point->y - origin->y;

        if(x < min_x) min_x = x;
        if(x > max_x) max_x = x;
        if(y < min_y) min_y = y;
        if(y > max_y) max_y = y;
    }

    range_x = max_x - min_x;
    range_y = max_y - min_y;
    if(range_x < 1.0f) range_x = 1.0f;
    if(range_y < 1.0f) range_y = 1.0f;

    scale_x = (float)(INS_MAP_W - 2 * INS_MAP_MARGIN) / range_x;
    scale_y = (float)(INS_MAP_H - 2 * INS_MAP_MARGIN) / range_y;
    ins_map_scale = (scale_x < scale_y) ? scale_x : scale_y;
    ins_map_center_x = (min_x + max_x) * 0.5f;
    ins_map_center_y = (min_y + max_y) * 0.5f;

    return true;
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       将当前圈局部坐标转换成上方屏幕坐标
// 参数简介       x                        当前圈局部X坐标
// 参数简介       y                        当前圈局部Y坐标
// 参数简介       sx                       返回屏幕X坐标
// 参数简介       sy                       返回屏幕Y坐标
// 返回参数       void                     无返回值
// 备注信息       输出坐标限制在上方轨迹区域的安全边距内。
//-------------------------------------------------------------------------------------------------------------------
static void Mymenu_ins_map_to_screen(float x, float y, int16_t *sx, int16_t *sy)
{
    int16_t screen_x;
    int16_t screen_y;

    screen_x = (int16_t)((float)(INS_MAP_W / 2) + (x - ins_map_center_x) * ins_map_scale);
    screen_y = (int16_t)((float)(INS_MAP_H / 2) + (y - ins_map_center_y) * ins_map_scale);

    if(screen_x < INS_MAP_MARGIN) screen_x = INS_MAP_MARGIN;
    if(screen_x > INS_MAP_W - INS_MAP_MARGIN - 1) screen_x = INS_MAP_W - INS_MAP_MARGIN - 1;
    if(screen_y < INS_MAP_MARGIN) screen_y = INS_MAP_MARGIN;
    if(screen_y > INS_MAP_H - INS_MAP_MARGIN - 1) screen_y = INS_MAP_H - INS_MAP_MARGIN - 1;

    *sx = screen_x;
    *sy = screen_y;
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       在轨迹图中绘制十字标记
// 参数简介       x                        标记中心X坐标
// 参数简介       y                        标记中心Y坐标
// 参数简介       size                     标记半径
// 参数简介       color                    标记颜色
// 返回参数       void                     无返回值
// 备注信息       用于元素marker和圈终点。
//-------------------------------------------------------------------------------------------------------------------
static void Mymenu_draw_ins_cross(int16_t x, int16_t y, int16_t size, uint16_t color)
{
    ips200_draw_line(x - size, y, x + size, y, color);
    ips200_draw_line(x, y - size, x, y + size, color);
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       绘制一段圈内人工区段轨迹
// 参数简介       lap_start                当前圈在连续点数组中的起点
// 参数简介       lap_point_count          当前圈点数
// 参数简介       origin                   当前圈局部坐标原点
// 参数简介       zone_start               区段圈内起点
// 参数简介       zone_end                 区段圈内终点
// 参数简介       color                    绘制颜色
// 返回参数       void                     无返回值
// 备注信息       只读取已经生成的预览点，不建立区段绘图数组。
//-------------------------------------------------------------------------------------------------------------------
static void Mymenu_draw_ins_zone_range(uint16_t lap_start,
                                        uint16_t lap_point_count,
                                        const INS_NAV_POINT *origin,
                                        uint16_t zone_start,
                                        uint16_t zone_end,
                                        uint16_t color)
{
    const INS_NAV_POINT *point;
    uint16_t index;
    float x;
    float y;
    int16_t sx;
    int16_t sy;
    int16_t last_sx;
    int16_t last_sy;

    if(origin == NULL ||
       zone_start > zone_end ||
       zone_end >= lap_point_count)
    {
        return;
    }

    point = INS_NAV_get_preview_point(lap_start + zone_start);
    if(point == NULL)
    {
        return;
    }

    x = point->x - origin->x;
    y = point->y - origin->y;
    Mymenu_ins_map_to_screen(x, y, &last_sx, &last_sy);

    if(zone_start == zone_end)
    {
        Mymenu_draw_ins_cross(last_sx, last_sy, 2, color);
        return;
    }

    for(index = zone_start + 1;
        index <= zone_end;
        index++)
    {
        point = INS_NAV_get_preview_point(lap_start + index);
        if(point == NULL)
        {
            return;
        }

        x = point->x - origin->x;
        y = point->y - origin->y;
        Mymenu_ins_map_to_screen(x, y, &sx, &sy);

        if(sx != last_sx || sy != last_sy)
        {
            ips200_draw_line(last_sx, last_sy, sx, sy, color);
        }

        last_sx = sx;
        last_sy = sy;
    }
}

//-------------------------------------------------------------------------------------------------------------------
// 函数简介       绘制当前显示圈的只读轨迹
// 参数简介       无
// 返回参数       void                     无返回值
// 备注信息       White path, colored markers, selected zone, start and end are drawn above.
//-------------------------------------------------------------------------------------------------------------------
static void Mymenu_show_ins_map(void)
{
    const INS_NAV_POINT *origin;
    const INS_NAV_POINT *point;
    uint16_t start;
    uint16_t end;
    uint16_t index;
    uint16_t lap_point_count;
    uint16_t zone_draw_end;
    float x;
    float y;
    int16_t sx;
    int16_t sy;
    int16_t last_sx;
    int16_t last_sy;
    int16_t marker_size;
    uint16_t marker_color;
    INS_AUTO_ZONE auto_zone;
    uint8_t auto_index;
    uint8_t auto_count;
    INS_MANUAL_ZONE manual_zone;
    uint8_t manual_lap;
    uint8_t manual_count;
    uint8_t manual_index;

    if(ins_map_need_redraw == false)
        return;

    Mymenu_clear_ins_map();
    ins_map_need_redraw = false;

    if(Mymenu_get_ins_map_range(&start, &end) == false || end - start < 2)
    {
        ips200_show_string(72, 112, "No Lap Map");
        return;
    }

    lap_point_count = end - start;
    if(ins_map_cursor >= lap_point_count)
        ins_map_cursor = lap_point_count - 1;

    if(Mymenu_calc_ins_map_scale(start, end) == false)
    {
        ips200_show_string(72, 112, "No Lap Map");
        return;
    }

    origin = INS_NAV_get_preview_point(start);
    if(origin == NULL)
        return;

    Mymenu_ins_map_to_screen(0.0f, 0.0f, &last_sx, &last_sy);

    for(index = start + 1; index < end; index++)
    {
        point = INS_NAV_get_preview_point(index);
        if(point == NULL)
            return;

        x = point->x - origin->x;
        y = point->y - origin->y;
        Mymenu_ins_map_to_screen(x, y, &sx, &sy);

        if(sx != last_sx || sy != last_sy)
            ips200_draw_line(last_sx, last_sy, sx, sy, INS_COLOR_WHITE);

        last_sx = sx;
        last_sy = sy;
    }

    auto_count = INS_NAV_get_auto_count();

    for(auto_index = 0;
        auto_index < auto_count;
        auto_index++)
    {
        if(INS_NAV_get_auto_zone(auto_index, &auto_zone) == false)
        {
            continue;
        }

        if(auto_zone.physical_lap != (uint8_t)(ins_display_lap - 1u))
        {
            continue;
        }

        Mymenu_draw_ins_zone_range(start,
                                   lap_point_count,
                                   origin,
                                   auto_zone.start_index,
                                   auto_zone.end_index,
                                   INS_COLOR_ORANGE);
    }
    if(ins_display_lap >= 1 && ins_display_lap <= 3)
    {
        manual_lap = (uint8_t)(ins_display_lap - 1);
        manual_count = INS_NAV_get_manual_count(manual_lap);

        for(manual_index = 0;
            manual_index < manual_count;
            manual_index++)
        {
            if(INS_NAV_get_manual_zone(manual_lap,
                                       manual_index,
                                       &manual_zone) == false)
            {
                continue;
            }

            Mymenu_draw_ins_zone_range(start,
                                       lap_point_count,
                                       origin,
                                       manual_zone.start_index,
                                       manual_zone.end_index,
                                       INS_COLOR_CYAN);
        }
    }

    if(ins_zone_select_state >= 2 &&
       ins_zone_start < lap_point_count)
    {
        zone_draw_end = ins_zone_start;

        if(ins_zone_select_state == 2 &&
           ins_map_cursor >= ins_zone_start &&
           ins_map_cursor < lap_point_count)
        {
            zone_draw_end = ins_map_cursor;
        }
        else if(ins_zone_select_state == 3 &&
                ins_zone_end >= ins_zone_start &&
                ins_zone_end < lap_point_count)
        {
            zone_draw_end = ins_zone_end;
        }

        point = INS_NAV_get_preview_point(start + ins_zone_start);

        if(point != NULL)
        {
            x = point->x - origin->x;
            y = point->y - origin->y;
            Mymenu_ins_map_to_screen(x, y, &last_sx, &last_sy);

            Mymenu_draw_ins_cross(last_sx,
                                  last_sy,
                                  4,
                                  INS_COLOR_MAGENTA);

            for(index = ins_zone_start + 1;
                index <= zone_draw_end;
                index++)
            {
                point = INS_NAV_get_preview_point(start + index);

                if(point == NULL)
                    return;

                x = point->x - origin->x;
                y = point->y - origin->y;
                Mymenu_ins_map_to_screen(x, y, &sx, &sy);

                if(sx != last_sx || sy != last_sy)
                {
                    ips200_draw_line(last_sx,
                                     last_sy,
                                     sx,
                                     sy,
                                     INS_COLOR_MAGENTA);
                }

                last_sx = sx;
                last_sy = sy;
            }

            if(zone_draw_end > ins_zone_start)
            {
                Mymenu_draw_ins_cross(last_sx,
                                      last_sy,
                                      4,
                                      INS_COLOR_MAGENTA);
            }
        }
    }

    for(index = start; index < end; index++)
    {
        point = INS_NAV_get_preview_point(index);
        if(point == NULL)
            return;

        if(point->marker != INS_MARKER_NONE)
        {
            marker_color = INS_COLOR_ORANGE;
            marker_size = 2;

            if(point->marker == INS_MARKER_COIN)
            {
                marker_color = INS_COLOR_YELLOW;
                marker_size = 3;
            }

            x = point->x - origin->x;
            y = point->y - origin->y;
            Mymenu_ins_map_to_screen(x, y, &sx, &sy);
            Mymenu_draw_ins_cross(sx, sy, marker_size, marker_color);
        }
    }

    Mymenu_ins_map_to_screen(0.0f, 0.0f, &sx, &sy);
    ips200_draw_line(sx - 4, sy - 4, sx + 4, sy - 4, INS_COLOR_GREEN);
    ips200_draw_line(sx + 4, sy - 4, sx + 4, sy + 4, INS_COLOR_GREEN);
    ips200_draw_line(sx + 4, sy + 4, sx - 4, sy + 4, INS_COLOR_GREEN);
    ips200_draw_line(sx - 4, sy + 4, sx - 4, sy - 4, INS_COLOR_GREEN);

    point = INS_NAV_get_preview_point(end - 1);
    if(point != NULL)
    {
        x = point->x - origin->x;

void menu_show_All(void)
{
    static bool last_ins_page = false;

#if NAVIGATION_ENABLE
    static bool last_navi_mode = false;

    if(navi_mode)
    {
        if(!last_navi_mode)
            NaviMenu_Invalidate();
        NaviMenu_Show();
        if(MenuPool_IsFull())
            ips200_show_string(0, 224, "Menu Full!     ");
        last_navi_mode = true;
        return;
    }
    if(last_navi_mode)
    {
        ips200_clear();
        last_navi_mode = false;
    }
#endif

    bool ins_page = Mymenu_is_ins_page();

    if(ins_page != last_ins_page)
    {
        ips200_clear();
#if INS_NAV_ENABLE
        if(ins_page)
            ins_map_need_redraw = true;
#endif
    }

#if INS_NAV_ENABLE
    if(ins_page)
        Mymenu_show_ins_map();
#endif

    if(!ins_page)
    {
        Mymenu_show_title();
    }

#if INS_NAV_ENABLE
    if(!ins_page || ins_zone_quick_active)
#else
    if(!ins_page)
#endif
    {
        Mymenu_show_Setup();
    }

    Mymenu_show_task();
    Mymenu_show_key();
    Mymenu_show_data();

    if(!ins_page)
    {
        NaviFlash_ShowSaveStatus();
        if(MenuPool_IsFull())
            ips200_show_string(0, 224, "Menu Full!     ");
    }

    last_ins_page = ins_page;
}

{
    interrupt_global_enable(0);
    pit_clear_flag(CCU60_CH1);
    static uint8_t count_in_2ms = 0;
    static uint8_t count_5ms = 0;
    static uint8_t count_out_2ms = 0;
    static uint8_t count_10ms = 0;
    static uint8_t count_20ms = 0;
    UART_ErrorWatchdogTick1ms();
    count_10ms++;
    count_20ms++;
    count_out_2ms++;
    if(my_car_state==ready||my_car_state==test)
    {
        count_in_2ms++;
        count_5ms++;
        if(count_in_2ms>=2)
        {
            count_in_2ms=0;
            NaviFlash_TickSaveStatus();
        }
        if(count_5ms>=5)
        {
            count_5ms = 0;
            MY_key_scan();
            MY_key_all_ctrl();
        }
    }
    if(count_out_2ms>=2)
    {
        count_out_2ms=0;
        Encoder_Data_get();
#if INS_NAV_ENABLE
        INS_NAV_2msALL(motor_left.encoder_speed,motor_right.encoder_speed);
#endif
#if NAVIGATION_ENABLE
        NaviCore_OnEncoderTick();
#endif
        speed_control();
    }
    if(count_20ms>=20)
    {
        count_20ms=0;
        pisend = true;
    }
    IMU_Fusion_Task();
    if(count_10ms>=10)
    {
        count_10ms=0;
        UART_PublishYawLatest(IMU_Fusion_GetYaw());
    }
}

IFX_INTERRUPT(uart1_rx_isr, 0, UART1_RX_INT_PRIO)
{
    interrupt_global_enable(0);
    uint8_t data;
    while(uart_query_byte(UART_1, &data))
    {
        if(rx_index == 0 && data != 0x55)
        {
            continue;
        }
        rx_buffer[rx_index] = data;
        rx_index++;
        if(rx_index == 3)
        {
            if(rx_buffer[0] != Frame_h || rx_buffer[2] != param1_longest_byte)
            {
                memset(rx_buffer, 0, sizeof(rx_buffer));
                rx_index = 0;
                continue;
            }
        }
        if(rx_index >= param1_send_all_byte)
        {
            process_received_data(rx_buffer, rx_index);
            memset(rx_buffer, 0, sizeof(rx_buffer));
            rx_index = 0;
        }
        if(rx_index >= 60)
        {
            memset(rx_buffer, 0, sizeof(rx_buffer));
            rx_index = 0;
        }
    }
}
