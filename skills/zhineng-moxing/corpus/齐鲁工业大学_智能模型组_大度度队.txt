第一章 引言
本参赛队伍参加了人工智能模型组竞赛，历时约4个月，完成了智能模型车从方案论证、结构改造、电路设计、软件编写、模型训练到整车调试的全过程。系统采用"上位机（RK3588）+ 下位机（TC377）"的双处理器架构：上位机以目标检测模型结合路径预测与大模型语义决策完成感知与决策，下位机以 LADRC 级联控制完成转向与速度的闭环调节。经反复场地整定，模型车能够稳定完成包含直道、弯道、环岛、坡道、路障、路牌、金币等多种元素的完整赛道行驶，达到了预期的技术指标。
在智能车视觉循迹领域，早期方案多采用图像二值化、边缘检测、透视变换与赛道中心线拟合等传统数字图像处理方法实现赛道识别[1][3]，此类方法计算量小、实时性好，但对光照变化与复杂赛道元素鲁棒性不足。随着深度学习的发展，以卷积神经网络为代表的模型在目标检测、文字识别等任务中表现出更强的鲁棒性与泛化能力[4][5][7]，而大语言模型的兴起则为路牌等语义信息的理解与决策提供了新途径。针对嵌入式平台算力与存储受限的特点，研究者提出了多种轻量化网络结构，通过深度可分离卷积、通道剪枝、量化等手段在精度与实时性之间取得平衡。在控制层面，传统方案多采用PD/PID 实现转向与速度闭环[6]；而自抗扰控制通过扩张状态观测器对总扰动进行估计与补偿，抗扰动能力更强，已在诸多运动控制场景中得到应用[9]。
本报告在借鉴上述工作的基础上，结合竞赛对实时性的严格要求，设计并实现了一套以"目标检测 + 大模型语义决策"为感知核心、以自抗扰级联控制为执行手段的双处理器完整技术方案。本报告的内容框架安排如下：第二章介绍模型车设计制作的主要思路与技术方案概要；第三章介绍机械部分的安装与改造；第四章介绍电路设计；第五章介绍上下位机控制软件的主要理论、算法与代码设计；第六章介绍开发工具与制作、安装、调试过程；第七章给出模型车的主要技术参数；第八章为结论。附录部分给出了电路原理图（附录 A）和核心算法程序源代码（附录 B）。


第二章 系统总体方案设计
2.1 系统总体结构
系统采用"上位机 + 下位机"的分层双处理器架构，如图2.1所示。上位机为 Orange Pi 5 单板计算机（搭载瑞芯微 RK3588 处理器，内置算力约 6 TOPS 的 NPU），负责视觉感知与决策；下位机为组委会提供的英飞凌（Infineon）AURIX TC377 三核微控制器核心板，负责运动控制与执行。二者通过 UART 串口（115200 bps）进行双向数据交换。

图2.1 系统总体结构框图
上位机（感知与决策层）通过ov13850摄像头采集赛道图像，利用 RKNN 框架在 RK3588 NPU 上运行目标检测模型，识别箭头、路牌、行人、车辆、金币、起点等赛道元素；随后完成基于自然三次样条的路径预测、基于势场法的避障、金币吸引，以及路牌文字识别与大模型语义决策，综合得到转向偏移量与目标速度，通过串口下发给下位机。
下位机（控制与执行层）接收上位机的转向偏移量与目标速度，运行"LADRC 外环（位置环）—PID 内环（角速度环）—差速与车轮速度环"的级联控制算法，驱动转向舵机与左右驱动电机；同时通过 IMU660RB 惯性测量单元与左右编码器实时采集车模角速度、姿态与车速，一方面作为控制反馈，另一方面通过串口回传上位机用于里程计定位。
2.2 主要设计思路
本方案的设计思路可以概括为以下四点：
（1）双处理器各司其职。上位机发挥 NPU 算力与成熟 AI 生态的优势，完成计算密集型的视觉感知与路径决策；下位机发挥 MCU 实时性与确定性的优势，完成对实时性要求极高的运动控制。二者通过轻量串口协议解耦，既保证了 AI 推理的算力需求，又保证了控制环路的实时稳定。
（2）“自抗扰 + 级联”的分层控制。转向外环采用线性自抗扰控制（LADRC），通过扩张状态观测器对模型不确定性与外界扰动进行估计与补偿，抗扰动能力强；内环采用 PID 对角速度进行快速调节。级联结构实现“位置—角速度”两级闭环，兼顾转向的快速性与稳定性。
（3）多源信息融合的感知决策。视觉（箭头方向、路牌语义、障碍物位置）、里程计（编码器）、姿态（IMU）等信息统一到决策层，路径预测、避障、金币吸引等多任务协调运行，并通过大语言模型理解路牌语义，提升复杂赛道元素下的决策能力。
（4）模块化、分层的软硬件设计。硬件按电源、驱动、接口分模块设计；软件按“采集—推理—规划—控制”分层组织，上位机与下位机独立开发、独立调试，降低耦合、提高可维护性。
2.3 技术方案概要
机械方面，在阿克曼转向车模基础上，设计并定制碳纤维承载隔板，通过铜柱、螺丝、螺母分层固定上位机、核心控制板、电源与驱动等板卡，并采用 3D 打印摄像头支架，尽量降低整车重心、保证前方视野。
电路方面，设计独立电源模块为上位机、下位机、舵机、电机及传感器分别供电，减少相互干扰；设计电机 H 桥驱动电路与舵机驱动接口；为摄像头、IMU、编码器等外设提供可靠的信号接口。
软件方面，上位机以固定周期完成“图像采集 → AI 目标检测 → 路径预测/避障/金币吸引 → OCR+大模型决策 → 速度决策 → 串口下发”的决策流程；下位机在 1 ms 定时中断的调度下，以 20 ms 周期运行 LADRC 外环、5 ms 周期运行角速度内环与舵机输出、10 ms 周期运行车轮速度环，最终输出舵机与电机 PWM 信号。

第三章 机械结构设计
3.1 车模基本结构及改造
根据竞赛规则，本组要求使用阿克曼（Ackermann）转向小车，并对整车外形尺寸（长、宽、高）作出了明确限制。为此，我们自行采购了一款符合尺寸要求的阿克曼转向车模作为底盘。该车模采用阿克曼转向结构，前轮由转向舵机通过转向拉杆（梯形转向机构）驱动，使左、右前轮在转向时按不同角度偏转，尽量使各车轮绕同一瞬时转向中心转动，从而减小轮胎侧滑；后轮由驱动电机通过减速齿轮驱动。

3.2 传感器
（1）摄像头：采用ov13850摄像头，用小型螺丝螺母固定于 3D 打印的摄像头支架上（支架固定于上承载板），通过选择不同高度的螺丝孔位调整安装高度（约12cm）；摄像头角度固定、水平正视前方，用于采集赛道前方图像。镜头正对赛道中心，保证左右视野对称。
（2）编码器：采用1024线增量式编码器 ×2，分别安装于左右后轮电机齿轮左上方，用于测量车速，为速度闭环控制提供反馈。
（3）惯性测量单元：逐飞科技IMU660RB，安装于车身质心附近，用于检测车身姿态，辅助坡道与转弯判断。
3.3 电路板的固定与连接
核心控制器电路板、电源板用螺丝螺母按孔位固定于车身中部的承载隔板和车模底板，驱动板用扎带固定于车后。各电路板之间的信号线与电源线等用扎带分类捆扎固定，便于调试与维护。

第四章 电路设计
根据竞赛规则，本组采用组委会提供的核心 MCU 电路板，因此本报告不对该电路板内部设计进行说明，仅介绍外围自行设计的电路。
4.1 电源电路
整车采用3S格氏锂电池（11.1V）供电。电源电路将电池电压变换为各模块所需的电压等级：一路通过RY9121E开关电源模块降压至 5 V，供mcu核心板和5V供电的外设使用,再经RT9013-33GB线性稳压芯片降压至 3.3 V，供控制器及传感器逻辑电路使用。另外两路分别通过独立的SP1N28STER开关型降压输出7.4V和5V分别给舵机和上位机供电。电机驱动部分直接由电池供电，以减小大电流负载对控制电路的干扰。电源输入端并联大容量电解电容与高频陶瓷电容，抑制瞬态电压波动。
4.2 电机驱动电路
驱动电机采用DRV8701 型 H 桥驱动芯片构成全桥驱动电路，支持正反转与 PWM 调速。PWM 信号由核心控制器输出，经驱动芯片放大后驱动电机。驱动电路独立铺设较宽的电源与地走线，并加装续流二极管与吸收电容，抑制电机换向产生的尖峰电压。
4.3 舵机驱动电路
转向舵机采用标准 50 Hz PWM 信号控制，脉宽 500～2500 μs 对应舵机左右极限位置。舵机由独立 SP1N28STER开关型降压电源供电（11.1V降至7.4V），信号线串接100R限流电阻，保证控制信号的稳定。
4.4 传感器接口电路
摄像头与上位机（Orange Pi 5 / RK3588S）相连之后，将画面与虚拟系统融合，完成赛道图像采集；IMU660RB 惯性测量单元通过SPI 接口与下位机（TC377）通信，输出三轴姿态与角速度；左右编码器输出正交信号，接入下位机定时器（TIM5、TIM6）的正交解码接口。
4.5 主控电路与接口
下位机（TC377）通过 UART 接口与上位机（RK3588）实现双向通信，接收转向偏移量与目标速度指令，并向上位机回传车速、航向及角速度信息；通过 PWM 接口输出舵机与驱动电机的控制信号；利用正交解码接口采集编码器脉冲信号；借助 JTAG/DAP 接口完成程序下载与在线调试工作。上位机除搭载摄像头、串口外设外，还可通过无线网络调用外部大模型服务，实现路牌语义识别与决策功能。系统完整电路原理图详见附录 A。

第五章 控制软件与算法设计
5.1 软件总体框架
软件分为上位机程序与下位机程序两部分。上位机程序运行于 Orange Pi 5（RK3588），使用 Python 语言编写，负责图像采集、AI 目标检测、路径预测、避障、金币吸引、路牌识别与大模型决策，最终输出转向偏移量与目标速度；下位机程序运行于 AURIX TC377，使用 C 语言编写，在 1 ms 定时中断的调度下运行级联控制算法，驱动舵机与电机。上位机与下位机通过 UART 串口交换数据，软件整体处理流程如图5.1所示。

图5.1 软件处理流程图
5.2 上位机软件设计
上位机软件采用"检测—规划—决策"的流水线结构，主要包含以下模块：
（1）AI 目标检测模块。基于 RKNN 框架在 RK3588 NPU 上部署目标检测模型，实时检测赛道中的箭头、路牌、行人、车辆、金币、起点等目标，输出各类目标的位置、类别与置信度。
（2）路径预测模块。当检测到箭头时，将相邻箭头的中心点按空间顺序连接为路径点链，利用自然三次样条（natural cubic spline）对路径点进行插值拟合，得到 C² 连续的路径曲线；再结合车速动态选择前瞻距离，计算前瞻点的曲率半径，进而得到转向目标。
（3）避障与金币吸引模块。避障采用多障碍物加权势场法，对检测到的行人与车辆建立斥力势场，并对行人进行运动轨迹预测，引导车辆绕行；金币吸引采用单目标锁定与滞回切换策略，依据金币距离缩放引力，引导车辆接近金币。
（4）路牌识别与大模型决策模块。路牌区域先经 PP-OCR 文字识别得到牌面文字，再调用大语言模型（百度文心一言 ernie-4.5-turbo）对文字语义进行理解，输出"左转/右转"等行驶决策，从而在复杂路牌场景下作出正确选择。
（5）速度决策模块。根据赛道类型、路径曲率、避障与金币状态，综合计算目标速度，实现"直道加速、弯道减速"的速度规划。
5.3 下位机软件设计
下位机软件基于 1 ms 周期定时中断（PIT）调度，各控制环按不同周期分级执行：主中断每 1 ms 触发一次；每 5 ms读取一次 IMU 并完成姿态解算；每 10 ms 读取一次编码器并通过串口回传状态帧；舵机转向控制上分为 LADRC 外环（20 ms）、角速度内环（5 ms）输出舵机PWM占空比，并在角速度内环加入阿克曼差速计算，在目标速度上叠加差速，得到左右轮的目标速度，通过增量式PI控制器得到左右轮电机占空比，最终通过5MS中断把舵机和电机占空比给到执行器输出。
数据采集方面，对 IMU 输出的角速度与编码器车速先进行滑动平均（MAF，窗口长度为 8）与一阶低通滤波，抑制噪声与高频抖动，为控制环提供平滑的反馈量。参数方面，下位机开机后阻塞接收上位机下发的控制参数包（共 22 个浮点参数，覆盖 LADRC、内外环 PID 与车轮速度环的全部参数），校验通过后再进入正常控制循环，实现"参数在线下发、无需重新编译"。
5.4 控制算法设计
舵机转向控制采用"LADRC 外环 + PID 内环"的级联结构，如图5.2所示。外环为位置环，输入为上位机下发的图像像素偏差，输出为目标角速度；内环为角速度环，以 IMU 测得的 z 轴角速度 gyro_z 为反馈，输出舵机占空比。两级闭环既保证了转向对赛道偏差的快速响应，又抑制了转向过程中的横摆扰动。

图 5.2 控制算法结构框图
外环采用一阶线性自抗扰控制（LADRC），由跟踪微分器（TD）、线性扩张状态观测器（LESO）与线性状态误差反馈（LSEF）三部分组成：TD 通过最速综合函数 fhan 为目标值安排平滑的过渡过程，避免给定突变引起超调；LESO 以二阶扩张状态同时估计系统状态与总扰动，其中扰动估计 z2 用于前馈补偿；LSEF 以 kp = wc 的比例反馈生成初步控制量，再经扰动补偿 u = (u0 − z2) / b0 得到最终输出。相比传统 PID，LADRC 将模型不确定性、转向摩擦、负载变化等统一视为扰动并在线补偿，抗扰动能力更强。
内环采用位置式 PID 控制，并对微分项引入"微分先行 + 一阶低通滤波"，即仅对反馈量（角速度）求微分，避免给定值突变带来的微分冲击，同时抑制测量噪声放大。
速度控制分为两部分：一是车轮速度环，对左右电机分别采用增量式 PID 跟踪目标速度，并加入"遇限削弱积分"的抗饱和措施，防止积分饱和；二是阿克曼差速，根据车模实时角速度按 diff = Wff × gyro_z 计算左右轮差速量，叠加到目标车速上，使后轮差速辅助前轮转向，提升过弯平顺性。核心算法源代码见附录 B。
5.5 通信协议设计
上位机与下位机之间通过 UART（115200 bps）通信。下行帧（上位机 → 下位机）用于下发转向偏移与目标速度，帧格式为：帧头 0xAA 0x55 + 偏移量（int16，2 字节）+ 目标速度（int16，2 字节）+ 帧尾 0xFF。下位机采用状态机逐字节解析，校验帧头帧尾后提取有效载荷。
上行帧（下位机 → 上位机）用于回传车模状态，共 19 字节：帧头 0xAA 0x55 + 左轮车速（int16）+ 右轮车速（int16）+ 偏航角（float32）+ z 轴角速度（float32）+ 舵机角度（float32）+ 帧尾 0xFF。上位机据此进行里程计定位与状态监测。
此外，上位机在上电初始化阶段还会向下位机下发一组控制参数包（帧头 0x5A 0xA5、帧尾 0x0D，共 22 个浮点参数，覆盖 LADRC、内外环 PID 与车轮速度环等全部参数），下位机接收并校验占位符后启用，实现了参数的在线可配置。


第六章 开发工具与制作调试
6.1 开发工具
上位机开发使用 Python 语言，运行于 Orange Pi 5（RK3588）；AI 模型通过 RKNN-Toolkit 转换为 RKNN 格式并在 RK3588 NPU 上推理，文字识别采用 PaddleOCR 的 PP-OCR 模型，语义决策调用百度文心一言（ernie-4.5-turbo）大模型接口。下位机开发使用英飞凌 AURIX Development Studio（ADS）与 SEEKFREE（逐飞）TC377 开源库，通过 JTAG / DAP 接口下载与在线调试。调试方面使用 VOFA+ 串口可视化工具实时观测车速、角速度、舵机角度等波形，辅助在线调参；使用串口助手、图像回显工具查看中间结果；版本管理使用 Git。
硬件调试使用万用表、数字示波器、可调稳压电源、逻辑分析仪、焊台等工具，完成电路的静态检查、信号波形测试与故障定位。
6.2 制作与安装过程
制作过程按照"机械装配 → 电路焊接与检查 → 传感器安装与标定 → 软件下载"的顺序进行。
（1）机械装配。在自行采购的阿克曼转向车模基础上，首先安装自行定制的碳纤维承载隔板，通过铜柱、螺丝与螺母将上位机、核心控制板、电源与驱动板分层固定于隔板上，并在电路板与隔板之间垫入橡胶减震垫；随后将 3D 打印的摄像头支架用螺丝、螺母固定于上承载板，并根据前瞻视野需要选择合适的螺丝孔位确定摄像头安装高度。
（2）电路焊接与静态检查。电路板焊接完成后，先进行电源对地短路检查，确认无短路后逐步上电，用万用表测量各电压点（电池电压、5 V、3.3 V）是否正常，再连接各传感器与执行机构。动力线（电机、舵机）与信号线（摄像头、编码器、IMU）分开走线并捆扎，减小电磁干扰。
（3）传感器安装与标定。摄像头通过 USB 接入上位机，调整曝光与视野；IMU660RB 通过 SPI 接入下位机，安装于车身质心附近并完成零偏标定；左右编码器分别接入下位机定时器 TIM5、TIM6 的正交解码接口，并标定脉冲方向与每米脉冲数；转向舵机标定中值与左右极限。
（4）软件下载。下位机程序经 AURIX Development Studio 编译后通过 JTAG / DAP 接口下载；上位机程序直接运行于 RK3588。下载完成后进入联调。
6.3 调试过程
调试遵循"分模块调试 → 上下位机联调 → 场地整定"的流程。
（1）下位机基础调试。分别验证 IMU 姿态解算与角速度输出、编码器计数、舵机角度控制与电机 PWM 调速，通过 VOFA+ 观察角速度与车速波形，确认 IMU 零偏与编码器方向正确。
（2）上位机感知调试。部署 RKNN 目标检测模型，验证箭头、路牌、行人、车辆、金币等目标的检测效果；调试路径预测、避障与金币吸引逻辑，并通过图像回显查看中间结果；联调 PP-OCR 文字识别与文心一言大模型接口，确认路牌语义决策正确。
（3）通信联调。验证上下位机之间的下行帧（偏移/速度）、上行帧（车速/航向/角速度）与控制参数包，检查帧头帧尾校验与参数下发是否正常，排除串口丢帧与误码问题。
（4）控制参数整定。采用"先内环、后外环"的顺序：先整定内环 PID（角速度环），使陀螺仪角速度能快速、平稳地跟踪目标角速度；再整定外环 LADRC，先根据转向增益近似确定 b0，再逐步增大观测器带宽 wo（一般取控制器带宽 wc 的 3～5 倍）以加快扰动估计，最后增大 wc 提高响应速度，并整定车轮速度环 PID。整定过程通过 VOFA+ 实时观察目标角速度与实测角速度的跟踪波形，以无超调、无振荡且响应迅速为准则。
（5）场地整定。在正式赛道上反复试跑，针对弯道路牌、金币等元素逐一优化路径预测前瞻距离、速度决策与差速系数，最终确定一套稳定的参数。
6.4 调试中遇到的问题与解决
调试过程中遇到的主要问题及解决措施如下：
（1）串口帧丢帧与误码。上下位机高速通信时偶发丢帧或字节错位，导致控制量跳变。解决措施：采用状态机逐字节解析并严格校验帧头帧尾，超时或异常自动复位到等待帧头状态，丢弃不完整帧，保证每次提取的都是完整有效帧。
（2）IMU 零偏漂移。上电初期陀螺仪存在零偏，导致角速度积分漂移。解决措施：开机时进行零偏标定，并对角速度输出进行滑动平均与一阶低通滤波，抑制零偏与高频噪声的影响。
（3）舵机抖动与微分冲击。内环直接对给定值微分时，目标角速度突变会引起舵机抖动。解决措施：内环采用"微分先行 + 低通滤波"的 PID，仅对反馈的角速度求微分，并对微分项做一阶低通滤波，明显减小舵机高频抖动。
（4）LADRC 参数整定困难。观测器带宽 wo、控制器带宽 wc 与增益 b0 相互耦合，盲目调节容易发散。解决措施：按"先 b0、后 wo、再 wc"的顺序整定，并借助 VOFA+ 波形观察扰动估计量与控制量，结合阶跃响应逐步收敛，最终得到稳定的参数组合。
（5）双机决策延迟。上位机检测与决策周期较长，高速行驶时转向响应滞后。解决措施：通过动态前瞻与路径预测对延迟进行前馈补偿，并压缩决策链路耗时。

第八章 结论
8.1 整体情况与技术指标总结
本报告完整介绍了人工智能模型组模型车的设计制作过程。系统采用"上位机（RK3588）+ 下位机（TC377）"的双处理器架构：上位机通过 RKNN 部署目标检测模型，结合自然三次样条路径预测、势场法避障、金币吸引、PP-OCR 文字识别与大模型语义决策完成感知与决策；下位机通过"LADRC 外环 + PID 内环 + 车轮速度环"的级联控制完成运动控制。机械结构通过定制碳纤维承载隔板、3D 打印摄像头支架与降低重心提升了行驶稳定性；电路采用模块化设计保证供电与信号的可靠性。整车主要技术指标为：重量约 1.6 kg，长 × 宽 × 高约 32 cm × 21 cm × 14.5 cm，平均功耗约 8 W，控制主中断频率 1 kHz，LADRC 外环 20 ms、角速度内环 5 ms、车轮速度环 10 ms，整体达到了预期的设计目标。
8.2 存在的问题与分析
在制作与调试过程中，我们认为以下问题较为重要，值得着重指出并给出我们的见解。
（1）复杂光照与遮挡下目标检测鲁棒性不足。这是影响比赛成绩最主要的问题。逆光、阴影与目标相互遮挡会使目标检测模型出现漏检或误检，进而引起路径预测与决策偏差。我们的见解是：单纯增大训练数据规模的收益递减，更有效的手段是结合多帧时序信息对检测结果进行平滑与跟踪，并在训练中引入更多真实场地的负样本与光照扰动。
（2）高速过弯的欠转向与侧滑。车速提高后，转向机构响应延迟与轮胎侧向力不足共同导致车模出现欠转向。我们认识到，问题的根源不仅在于控制参数，更在于速度与弯道曲率缺乏前馈匹配；应依据路径曲率在入弯前主动降速，并借助后轮差速辅助转向，从根本上避免车模进入侧滑区。
（3）双机通信与决策延迟。上位机 AI 检测与决策周期（约 20～30 Hz）远低于下位机控制环（1 kHz），二者之间存在通信与决策延迟，车速较高时前轮转向对赛道偏差的响应存在滞后。我们的见解是：通过动态前瞻与轨迹预测对延迟进行前馈补偿，并尽量压缩决策链路耗时，以时间换稳定。
8.3 改进方向
针对上述问题，后续改进方向为：进一步扩充训练数据的场景覆盖并引入目标跟踪与时序融合，提升目标检测在光照变化与遮挡下的鲁棒性；建立"路径曲率—目标速度"的前馈映射，优化差速与 LADRC 参数，改善高速过弯性能；压缩上位机决策链路并引入延迟前馈补偿，同时探索模型预测控制（MPC）等先进方法进一步提升控制品质。

附录B 核心算法程序源代码
本附录给出下位机（TC377）控制软件中的核心算法子程序，包括线性自抗扰控制（LADRC）、微分先行 PID、增量式 PID（遇限削弱积分抗饱和）、级联控制主函数、串口帧解析与滑动平均滤波，并给出上位机（RK3588）路径预测中的自然三次样条拟合。
B.1 线性自抗扰控制（LADRC）
/* 一阶线性自抗扰控制器：TD(跟踪微分器) + LESO(线性扩张状态观测器) + LSEF(线性状态误差反馈)
 * beta1 = 2*wo, beta2 = wo*wo, kp = wc, 扰动补偿 u = (u0 - z2) / b0
 */
typedef struct {
    float Ts;      /* 控制周期 */
    float td_r0;   /* TD 速度因子 */
    float td_N0;   /* TD 滤波因子 */
    float wo;      /* 观测器带宽 */
    float wc;      /* 控制器带宽 */
    float b0;      /* 控制增益 */
    float z1, z2;  /* LESO 状态估计（z1: 状态, z2: 总扰动） */
    float x1, x2;  /* TD 输出及其导数 */
    float u;       /* 控制量 */
    float lim;     /* 输出限幅 */
} LADRC_1st_t;
 
/* fhan 最速综合函数 */
static float fhan(float x1, float x2, float r, float h)
{
    float d = r * h, d0 = h * d;
    float y = x1 + h * x2;
    float a0 = sqrtf(d * d + 8.0f * r * fabsf(y));
    float a = (fabsf(y) > d0) ? (x2 + (a0 - d) / 2.0f * (y > 0 ? 1.0f : -1.0f))
                              : (x2 + y / h);
    return (fabsf(a) > d) ? (-r * (a > 0 ? 1.0f : -1.0f)) : (-r * a / d);
}
 
void LADRC_1st_Update(LADRC_1st_t *s, float target, float feedback)
{
    float e, u0;
 
    /* 1. 跟踪微分器 TD：为给定值安排平滑过渡过程 */
    float fh = fhan(s->x1 - target, s->x2, s->td_r0, s->td_N0);
    s->x1 += s->Ts * s->x2;
    s->x2 += s->Ts * fh;
 
    /* 2. 线性扩张状态观测器 LESO */
    e = s->z1 - feedback;
    s->z1 += s->Ts * (s->z2 - 2.0f * s->wo * e + s->b0 * s->u);
    s->z2 += s->Ts * (-s->wo * s->wo * e);
 
    /* 3. 线性状态误差反馈 LSEF + 扰动补偿 */
    u0 = s->wc * (s->x1 - s->z1);
    s->u = (u0 - s->z2) / s->b0;
    if (s->u >  s->lim) s->u =  s->lim;
    if (s->u < -s->lim) s->u = -s->lim;
}
B.2 微分先行 PID（位置式）
/* 位置式 PID，微分先行 + 一阶低通滤波（用于角速度内环，输出舵机角度）
 * 微分仅作用于反馈量，避免给定值突变引起微分冲击
 */
float PID_location_1(PID_t *pid, float target, float feedback)
{
    float err = target - feedback;
 
    /* 积分（含限幅） */
    pid->integral += err;
    if (pid->integral >  pid->i_max) pid->integral =  pid->i_max;
    if (pid->integral < -pid->i_max) pid->integral = -pid->i_max;
 
    /* 微分先行：对反馈量微分，并经一阶低通滤波 */
    float d_fb = feedback - pid->last_fb;
    pid->d_filter = pid->D_filter_alpha * d_fb
                  + (1.0f - pid->D_filter_alpha) * pid->d_filter;
    pid->last_fb = feedback;
 
    float out = pid->Kp * err + pid->Ki * pid->integral - pid->Kd * pid->d_filter;
 
    if (out >  pid->out_max) out =  pid->out_max;
    if (out < -pid->out_max) out = -pid->out_max;
    return out;
}
B.3 增量式 PID（遇限削弱积分抗饱和）
/* 增量式 PID，用于左右车轮速度环，含"遇限削弱积分"抗饱和
 * 当输出到达限幅且误差方向一致时，削弱本次积分增量，防止积分饱和
 */
float PID_increment(PID_t *pid, float target, float feedback)
{
    float err = target - feedback;
    float d_out = pid->Kp * (err - pid->last_err)
                + pid->Ki * err
                + pid->Kd * (err - 2.0f * pid->last_err + pid->prev_err);
    float out = pid->last_out + d_out;
 
    if (out >= pid->out_max) {                     /* 正向饱和 */
        if (err > 0) d_out -= pid->Ki * err;       /* 遇限削弱积分 */
        out = pid->out_max;
    } else if (out <= -pid->out_max) {             /* 负向饱和 */
        if (err < 0) d_out -= pid->Ki * err;
        out = -pid->out_max;
    }
 
    pid->prev_err = pid->last_err;
    pid->last_err = err;
    pid->last_out = out;
    return out;
}
B.4 级联控制主函数
/* 级联控制：LADRC 外环(位置) -> PID 内环(角速度) -> 差速 -> 车轮速度环 -> 执行 */
void control_Cascade(void)
{
    /* 外环：LADRC 位置环，输入像素偏差，输出目标角速度 */
    LADRC_1st_Update(&ladrc, real.pixel_error_f, 0.0f);
    float target_gyro = ladrc.u;
 
    /* 内环：PID 角速度环，反馈 IMU gyro_z，输出舵机角度 */
    float servo_angle = PID_location_1(&pid_gyro, target_gyro, real.gyro_z_f);
 
    /* 阿克曼差速：按实时角速度叠加左右轮差速 */
    float diff_speed = Wff * real.gyro_z_f;
    speed.L_speed_t = speed.V_t - diff_speed;
    speed.R_speed_t = speed.V_t + diff_speed;
 
    /* 车轮速度环：增量式 PID */
    float pwm_L = PID_increment(&pid_L, speed.L_speed_t, real.v_left);
    float pwm_R = PID_increment(&pid_R, speed.R_speed_t, real.v_right);
 
    /* 执行：输出舵机 PWM 与电机 PWM */
    servos_SetAngle(servo_angle);
    motor_L_control(pwm_L);
    motor_R_control(pwm_R);
}
B.5 串口帧解析状态机
/* 下传帧解析：0xAA 0x55 OFFSET_L OFFSET_H SPEED_L SPEED_H 0xFF */
typedef enum {
    STATE_WAIT_AA = 0, STATE_WAIT_55,
    STATE_GET_OFFSET_L, STATE_GET_OFFSET_H,
    STATE_GET_SPEED_L, STATE_GET_SPEED_H, STATE_WAIT_FF
} frame_state_t;
 
void frame_parser(uint8_t byte)
{
    static uint8_t state = STATE_WAIT_AA;
    static int16_t offset = 0, speed = 0;
 
    switch (state) {
        case STATE_WAIT_AA:
            if (byte == 0xAA) state = STATE_WAIT_55; break;
        case STATE_WAIT_55:
            state = (byte == 0x55) ? STATE_GET_OFFSET_L : STATE_WAIT_AA; break;
        case STATE_GET_OFFSET_L:
            offset = byte; state = STATE_GET_OFFSET_H; break;
        case STATE_GET_OFFSET_H:
            offset |= (int16_t)byte << 8; state = STATE_GET_SPEED_L; break;
        case STATE_GET_SPEED_L:
            speed = byte; state = STATE_GET_SPEED_H; break;
        case STATE_GET_SPEED_H:
            speed |= (int16_t)byte << 8; state = STATE_WAIT_FF; break;
        case STATE_WAIT_FF:
            if (byte == 0xFF) on_frame_received(offset, speed);
            state = STATE_WAIT_AA; break;
        default:
            state = STATE_WAIT_AA; break;
    }
}
B.6 滑动平均滤波（MAF）
/* 滑动平均滤波，窗口长度为 8，用于 IMU 角速度与编码器车速的平滑 */
#define MAF_WINDOW 8
 
typedef struct {
    float buf[MAF_WINDOW];
    uint8_t idx;
    float sum;
} MAF_t;
 
float MAF_Update(MAF_t *m, float in)
{
    m->sum -= m->buf[m->idx];
    m->buf[m->idx] = in;
    m->sum += in;
    m->idx = (m->idx + 1) % MAF_WINDOW;
    return m->sum / (float)MAF_WINDOW;
}
B.7 自然三次样条路径拟合（上位机）
import numpy as np
 
def natural_cubic_spline(points):
    """自然三次样条插值，返回分段三次多项式系数（C2 连续，端点二阶导为 0）。"""
    n = len(points) - 1
    x = np.array([p[0] for p in points], dtype=float)
    y = np.array([p[1] for p in points], dtype=float)
    h = np.diff(x)
 
    # 三对角方程组求解二阶导数 M
    A = np.zeros((n + 1, n + 1)); b = np.zeros(n + 1)
    A[0, 0] = 1.0; A[n, n] = 1.0
    for i in range(1, n):
        A[i, i - 1] = h[i - 1]
        A[i, i]     = 2.0 * (h[i - 1] + h[i])
        A[i, i + 1] = h[i]
        b[i] = 6.0 * ((y[i + 1] - y[i]) / h[i] - (y[i] - y[i - 1]) / h[i - 1])
    M = np.linalg.solve(A, b)
 
    coeffs = []
    for i in range(n):
        a = y[i]; c = M[i] / 2.0
        d = (M[i + 1] - M[i]) / (6.0 * h[i])
        b = (y[i + 1] - y[i]) / h[i] - h[i] * (2.0 * M[i] + M[i + 1]) / 6.0
        coeffs.append((a, b, c, d))
    return coeffs
 
def curvature_at(coeffs, x, xi):
    """由样条系数计算某点曲率 k = |y''| / (1 + y'^2)^(3/2)。"""
    a, b, c, d = coeffs
    dx = x - xi
    y1 = b + 2.0 * c * dx + 3.0 * d * dx * dx
    y2 = 2.0 * c + 6.0 * d * dx
    return abs(y2) / (1.0 + y1 * y1) ** 1.5
