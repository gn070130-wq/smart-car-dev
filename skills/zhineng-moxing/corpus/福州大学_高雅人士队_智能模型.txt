摘要
针对人工智能模型组比赛中智能车在混合现实环境下自主驾驶任务需求，本文设计了一套融合视觉感知、行为决策与运动控制的智能车系统。系统采用上位机计算与下位机控制相结合的分层架构，以 Orange Pi 5B 和 Infineon TC264 分别作为智能计算平台与实时控制平台，并自主设计下位机扩展板和电机驱动板，实现整车软硬件集成。
视觉感知部分基于 MIPI-CSI 摄像头采集环境信息，结合赛道视觉处理与 PP-YOLOE-S 目标检测方法，实现道路信息、任务目标以及路牌信息识别。控制系统根据感知结果完成行为决策、路径规划和运动控制，实现车辆自主运行闭环。
通过系统设计与软硬件调试，本文实现了面向人工智能模型组任务的智能车自主驾驶系统，为复杂环境下智能车辆感知与控制提供了实现方案。
关键词：人工智能模型；视觉感知；目标检测；路径规划；运动控制

引言
研究背景
随着人工智能、计算机视觉以及智能控制技术的发展，智能汽车逐渐向环境感知、自主决策和运动控制方向发展[1]。智能车竞赛作为智能驾驶技术的重要实践平台，对车辆感知能力、算法设计能力以及系统集成能力提出了更高要求。
人工智能模型组比赛面向智能驾驶中的视觉理解与自主决策问题，要求车辆在混合现实环境下完成环境感知、任务识别以及自主行驶[2]。相比传统智能车系统，该赛道更加关注车辆对复杂环境信息的理解能力以及基于视觉信息的自主决策能力。
比赛任务分析
人工智能模型组区域赛采用混合现实驾驶环境，车辆需要通过车载视觉系统获取环境信息，并完成连续自主驾驶任务。根据现场比赛规则，车辆需要完成三圈有效运行，并根据路牌信息完成动态导航，同时处理行人、车辆等任务目标[2]。
比赛采用净胜时间计算方式，综合考虑车辆运行时间、任务罚时以及奖励抵扣，并遵循“圈数优先、时间次之”的排名原则。因此，智能车系统不仅需要具备较高的运行速度，还需要保证感知准确性、决策可靠性以及长期运行稳定性。
针对上述需求，本文设计了一套融合视觉感知、行为决策和运动控制的智能车系统，实现车辆从环境理解到自主执行的完整闭环。
本文主要工作
本文围绕人工智能模型组比赛任务需求，完成了智能车软硬件系统设计与算法实现。
主要工作包括：
（1）设计智能车硬件平台，采用 Orange Pi 5B 与 Infineon TC264 构成上下位机协同架构，并自主设计下位机扩展板和电机驱动板。
（2）构建基于 ROS 2[3] 的软件系统，实现视觉处理、任务决策、路径规划以及上下位机通信功能。
（3）设计融合传统视觉方法与深度学习模型的感知方案，实现赛道信息提取、目标检测以及路牌语义识别。
（4）设计行为决策与运动控制方法，实现车辆避障、动态导航以及稳定行驶。

智能车系统总体设计
比赛任务需求分析
人工智能模型组比赛面向智能驾驶系统中的环境感知、任务理解与自主决策能力进行考核。比赛采用虚实融合的混合现实驾驶环境，车辆通过车载摄像头获取场景信息，并完成目标检测、语义理解以及自主驾驶任务。
根据区域赛现场比赛规则，车辆需要连续完成三圈自主行驶任务，并根据比赛过程中出现的动态任务进行决策。比赛成绩采用净胜时间计算方式：

其中，为车辆实际行驶时间，为任务罚时，为奖励抵扣时间。比赛同时采用“圈数优先、时间次之”的排名规则[2]，因此系统设计需要在保证运行速度的同时，提高车辆自主驾驶过程中的稳定性和任务完成率。
针对比赛任务需求，本文设计了一套由上位机智能感知决策系统和下位机实时控制系统组成的自主驾驶平台，实现从环境感知、任务决策到车辆执行的完整闭环。
系统总体架构设计
为兼顾人工智能算法计算需求与车辆实时控制需求，系统采用“上位机 + 下位机”的分层式架构。
上位机采用 Orange Pi 5B，负责视觉数据处理、目标检测、语义理解、路径规划以及控制指令生成；下位机采用 Infineon TC264，负责接收上位机控制指令，并完成电机控制、舵机控制以及车辆状态反馈。系统整体架构如图 2-1所示。

硬件系统总体设计
车载计算平台设计
为满足人工智能模型组对边缘计算能力的需求，系统采用 Orange Pi 5B 作为车载计算平台。
上位机主要完成视觉感知与决策任务，包括摄像头数据采集、图像预处理、AI模型推理、OCR识别、路径规划以及控制指令生成。通过将高计算量任务部署于上位机，可以提高视觉算法运行效率，为车辆自主驾驶提供计算支持。
实时控制平台设计
下位机采用 Infineon TC264 作为实时控制核心，主要负责车辆底层运动控制。
TC264接收上位机发送的目标速度和目标转角信息，通过编码器获取车辆运动状态，并完成电机速度闭环控制以及舵机转向控制。
该分层设计将复杂视觉算法与实时运动控制任务分离，提高系统整体稳定性。
执行机构与传感系统设计
车辆采用逐飞科技 C 型车模作为机械平台，动力系统由 RS380 电机和数字无刷舵机构成。
其中，RS380 电机负责车辆纵向运动，数字无刷舵机负责车辆方向调整；1024线正交编码器用于采集车辆速度信息，为下位机闭环控制提供反馈。

本章小结
本章针对人工智能模型组混合现实环境下自主驾驶任务需求，设计了一套基于上位机智能计算与下位机实时控制相结合的智能车系统架构。
系统采用 Orange Pi 5B 完成视觉感知与任务决策，利用 Infineon TC264 实现车辆底层控制，通过UART通信建立上下位机数据交互，实现从环境感知到车辆执行的完整闭环，为后续视觉感知算法、路径规划算法以及运动控制算法设计提供系统基础。

软件系统设计
为实现智能车环境感知、任务决策与运动控制之间的信息交互，本文设计了一套分层式软件系统。上位机基于 ROS 2 框架实现视觉处理与决策计算，下位机基于 Infineon TC264 实现实时控制任务，通过通信链路完成上下位机协同。
软件总体架构设计
智能车软件系统采用模块化设计，整体由上位机软件系统和下位机控制系统组成。
上位机负责处理摄像头输入数据，完成环境感知、任务决策以及控制指令生成；下位机接收上位机输出的运动控制信息，并完成车辆执行与状态反馈。软件总体架构设计如图 2-2上位机软件系统架构图。

为提高软件系统模块化程度，上位机采用 ROS 2 框架[3]进行功能划分，各模块通过消息通信实现数据交互。
系统主要包括图像处理节点、视觉感知节点、决策规划节点以及通信节点，其节点关系如图 4-1所示。

混合现实环境视觉感知与语义理解算法设计
本章围绕混合现实环境下的视觉感知需求，设计了由赛道感知、目标检测和语义识别组成的感知系统。通过传统视觉方法与 PP-YOLOE-S 目标检测模型[4]相结合，实现了车辆对道路环境和任务目标的有效识别，为后续决策与控制提供了感知基础。
视觉感知总体方案
系统以车载 MIPI-CSI 摄像头作为视觉输入，通过上位机完成图像处理、目标识别和语义解析，最终输出环境信息供决策与控制模块使用。
整体感知流程如图 5-1所示。系统首先对输入图像进行预处理，然后分别完成赛道区域提取、目标检测和路牌识别，最后将各类感知结果进行融合，形成车辆当前环境状态。

图 5-1视觉感知总体流程图
赛道视觉感知方法
为获得车辆前方道路几何信息，系统对采集图像进行预处理，并结合颜色特征提取赛道区域。在此基础上，采用逆透视变换[5]将原始图像映射到俯视视角，以提高道路边界提取和路径生成的稳定性。
通过对赛道边界进行检测与拟合，可以得到车辆前方的可行驶区域和参考路径，为后续路径规划与运动控制提供输入。赛道感知流程如图 5-2所示。

行为决策与运动控制算法设计
基于第五章视觉感知模块输出的道路信息、目标信息以及语义信息，本文进一步设计车辆行为决策与运动控制算法，实现从环境理解到车辆执行的闭环控制。
针对人工智能模型组比赛中的自主驾驶任务，系统采用分层控制结构：上层根据视觉感知结果完成行为决策和路径规划，下层根据目标速度和目标转角完成车辆运动控制。
行为决策算法设计
车辆在运行过程中，根据视觉感知模块输出的环境信息建立当前状态，并根据任务类型选择对应行为策略。系统主要针对赛道跟踪、障碍物避让、路牌导航以及金币收集等任务进行决策。整体行为决策流程如图 6-1所示。

图 6-1多任务行为决策流程图
在正常行驶状态下，车辆根据赛道信息生成基础行驶路径；当检测到任务目标时，根据目标类别切换对应行为模式。其中，障碍物检测结果用于避让决策，路牌信息用于导航路径调整，金币信息用于局部路径优化。通过任务状态切换，使车辆能够适应比赛过程中的动态环境变化。
基于视觉信息的避障策略
针对比赛中的行人与车辆避让任务，系统根据目标检测结果判断障碍物位置，并结合当前道路状态调整车辆运动轨迹。
当检测目标进入车辆行驶区域时，系统进入避障状态，根据目标位置选择合适的绕行方向，并对局部路径进行调整，使车辆能够在保持连续运行的同时完成障碍物规避。避障过程中，系统通过路径平滑方法降低转向突变，提高车辆运行稳定性。避障流程如图 6-2所示。

图 6-2障碍物避让流程图
基于路牌语义的导航决策
比赛中第二圈和第三圈分别设置一处动态路牌，用于指引车辆进入对应道路。两处路牌分别对应直道和岔道，具体顺序由系统随机生成[2]，因此车辆不能依赖固定路径完成导航。针对该任务，系统首先利用第五章中的路牌识别结果获取文字及语义信息，再根据语义解析结果生成车辆导航方向。导航决策流程如下：
路牌检测 → OCR识别 → 语义理解 → 方向判断 → 路径调整。
该方法使车辆能够根据实时环境信息完成动态导航，提高系统对随机任务的适应能力。
基于收益约束的金币路径规划
金币任务要求车辆在完成正常驾驶的基础上，根据金币位置进行路径优化。金币可能位于非最优路径区域，车辆需要综合考虑绕行时间成本与金币奖励收益。针对该任务，系统将金币位置作为局部路径规划目标，根据当前车辆状态和金币分布情况生成候选路径，并通过路径代价评估选择较优方案。金币路径规划流程如图 6-3所示。

总结与展望
基于逐飞科技 C 型车模搭建了智能车硬件平台，采用 Orange Pi 5B 作为车载计算平台，Infineon TC264 作为底层控制核心，并自主设计下位机扩展板和电机驱动板，实现了计算平台、控制平台以及执行机构之间的硬件集成。
在软件系统方面，构建了基于 ROS 2 的模块化软件架构，实现了视觉感知、任务决策、路径规划以及上下位机通信等功能模块的协同运行。在视觉感知方面，针对混合现实比赛环境，设计了融合传统视觉方法与深度学习模型的感知方案。通过赛道视觉处理、PP-YOLOE-S目标检测以及路牌语义识别，实现了车辆对道路环境和任务目标的有效感知。在行为决策与运动控制方面，设计了多任务状态决策、局部路径规划以及闭环运动控制方法，使车辆能够根据环境信息完成避障、导航以及自主行驶任务。通过软硬件系统集成与调试，构建了完整的智能车自主驾驶闭环，为人工智能模型组比赛任务提供了实现基础。
虽然本文完成了智能车自主驾驶系统的设计与实现，但系统仍存在进一步优化空间。
在视觉感知方面，后续可通过优化模型结构和数据处理方法，提高复杂环境下目标识别的稳定性，进一步降低视觉误差对车辆决策的影响。在决策规划方面，可进一步完善多任务场景下的路径优化方法，提高车辆面对复杂任务状态时的适应能力。在运动控制方面，可结合更多车辆状态信息优化控制参数，提高高速运行过程中的轨迹跟踪精度和稳定性。
未来，随着车载计算平台性能提升以及智能驾驶算法的发展，智能车系统将在感知精度、决策能力以及控制性能方面进一步提升。

// 双电机增量式PI速度控制
void Motor_Control(void)
{
    float error_l =
        target_l - encoder_l;

    float error_r =
        target_r - encoder_r;

    output_l +=
        Kp * (error_l - last_error_l)
        + Ki * error_l;

    output_r +=
        Kp * (error_r - last_error_r)
        + Ki * error_r;

    output_l = constrain(output_l, -4000, 4000);
    output_r = constrain(output_r, -4000, 4000);

    left_motor(output_l);
    right_motor(output_r);

    last_error_l = error_l;
    last_error_r = error_r;
}
