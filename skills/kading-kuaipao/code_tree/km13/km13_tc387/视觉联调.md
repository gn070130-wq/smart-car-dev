# KM13 视觉联调

CPU0 负责摄像头配置和 DMA，视觉识别运行在 CPU1，并通过 `car_vision_set_command(speed_mps, steer_deg, valid, parking_reached)` 向 CPU0 发布命令。CPU2 只处理语音任务，跟随控制与回放参数互不干扰。

视觉识别固定启用；只需用 `CAR_DISPLAY_MODE` 控制 IPS200 是否显示调试画面。

当前移植的识别器不是通用二维码解码器，而是固定追踪 `tag36h11 ID 0` 的黑白标志。比赛贴纸如果是普通 QR Code，需要视觉队友替换识别器；如果实际使用的是 AprilTag/tag36h11 ID0，则现有算法可以直接联调。

需要看画面时，把 `CAR_DISPLAY_MODE` 改为 `1`；比赛时改为 `0`，IPS200 将不再刷新，但视觉识别仍正常运行。

## 接口约定

- `speed_mps`：只允许 0 到 `CAR_VISION_SPEED_MAX_MPS`。人停下时必须输出 0。
- `steer_deg`：目标在画面右侧时，默认输出正角度。
- `valid`：二维码可信时为 1；丢失、低置信度或处理超时时为 0。
- `parking_reached`：目前不使用自动停车区识别，比赛由 P20.6 确认。
- CPU0 超过 250 ms 没收到新命令会停车，不会保持上一帧继续跑。

## 距离跟随

当前视觉用二维码像素尺寸估计距离：

- 小于 `CAR_VISION_FAR_SIZE_PX`：按远距离速度前进。
- 大于 `CAR_VISION_NEAR_SIZE_PX`：速度为 0，实现人停、车停。
- 中间区域：使用正常跟随速度。

所有视觉和跟随参数都在 `car_follow_config.h`。回放参数位于 `car_replay_config.h`，视觉联调时不要修改。

## 首次测试

1. 架空后轮，二维码置于画面中央，确认转向接近中位。
2. 二维码移到右侧，前轮应向右；方向相反就翻转 `CAR_VISION_STEER_SIGN`。
3. 遮住二维码，后轮应在 250 ms 内开始降到零。
4. 逐步靠近二维码，达到近距离阈值时后轮 PWM 应归零。
5. 落地后先用低速测试，人突然停车、重新行走、短暂遮挡都必须安全。
