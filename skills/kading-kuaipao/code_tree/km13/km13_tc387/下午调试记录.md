# KM13 下午调试记录

日期：2026-08-18

## 一、当前整车流程

1. 上电后车辆进入等待状态，电机停止。
2. 按下 KEY1 进入 `REC`，视觉跟随人的二维码，同时根据后轮里程和 IMU 航向记录本次路线。
3. 再按一次 KEY1 结束录制，路线有效时进入 `READY`。
4. `READY` 中后轮保持停止，前轮位置环大致回到 `SA=2006`；该动作不校验、不阻止 KEY2 启动。
5. 按下 KEY2 进入 `BACK`，车辆倒车并按照刚记录的路线返回起点。
6. 剩余里程到达停车阈值后，后轮立即停止，前轮自动大致回到 `SA=2006`，状态显示 `DONE`。

比赛路径随机，因此只保留本次上电后录制的当前路径，不使用历史路线。WiFi 功能已经禁用，避免占用运行时间和引脚资源。

## 二、视觉跟随

- 二维码横向偏差 `DX`：左侧为正，右侧为负。
- 不设置视觉转向死区，`DX` 每个像素变化都会连续改变目标位置。
- `DX=-60~+60` 线性映射为约 `-55~+55 deg` 的抽象转向命令，再映射为传感器原始目标值。
- 实车反接转向电机线后原始值闭环稳定，因此保留当前电机接线；视觉转向符号设为 `-1`，单独修正二维码左右方向。
- 跟随和回放共用原始值位置闭环；视觉目标保留轻度低通，防止单像素噪声导致高频反打。
- 二维码丢失或视觉命令超时后，后轮停止、转向 PWM 归零并保持当前位置，不再自动回正；重新识别后才继续追踪。
- `DIST <= 400 mm` 停车。
- `DIST < 500 mm` 时逐渐降低后轮速度，避免急刹。
- `DIST >= 550 mm` 时开始正常跟随。
- 跟随目标速度约 `0.23 m/s`，远距离目标速度约 `0.28 m/s`。

## 三、后轮编码器与里程

- 两个后轮编码器都参与里程计算，使用左右轮平均值。
- 前进计数为正，后退计数为负。
- 每个后轮约 1024 计数/圈。
- 后轮直径约 0.25 m，一圈理论路程约 0.785 m。
- 录制时只累计前进里程，手动反转车轮不会写入录制里程。
- 路线至少需要 0.8 m 且不少于 3 个路径点，否则不能进入有效回放。

## 四、IMU 与路径滤波

- 上电保持车辆静止，先完成陀螺仪零偏标定。
- 陀螺仪角速度设有 `0.6 deg/s` 死区。
- 角速度使用两级低通，系数为 `0.18`。
- 在线零偏跟踪只允许在首次录制前的 `READY` 状态，并要求路线为空、后轮/电机静止且角速度残差不超过 `0.30 deg/s`；进入 `REC` 后冻结零偏。
- 车辆没有前进时不更新录制航向，避免停车等待按键时把陀螺仪漂移写成弯道。
- 录制航向使用 `0.5 deg` 死区和 `0.35` 低通。
- 航向累计变化约 `5 deg` 时记录转弯关键点。
- 直线路段约每 0.08 m 记录一个路径点。
- 每个路径点同时保存相对固定中位 `SA=2006` 的实测前轮角；前轮角使用 `0.35 deg` 死区和 `0.50` 低通，并且只在车轮前进时更新。
- 回放优先复现记录前轮角，双窗口曲率降为无有效转角时的兜底；IMU 航向误差、角速度和直线小积分负责闭环修正。
- 回放同时计算 0.12 m 短窗口和 0.30 m 长窗口曲率：短窗口保留紧弯/S 弯方向，长窗口发现大半径缓弯。
- 回放目标航向使用 `0.5 deg` 死区和 `0.35` 低通，最终转向命令还有 `0.30` 低通。
- 回放时只有录制前轮角小于 `1 deg`、曲率不超过 `0.10`、航向误差不超过 `1.2 deg` 且角速度不超过 `3 deg/s`，前轮才保持原始中位 `SA=2006`；超出后 IMU 立即参与纠偏。
- 直角弯可能产生接近 `90 deg` 的目标航向差，回放航向异常保护阈值由 `70 deg` 提高到 `120 deg`，避免进入弯道前误判为故障。
- 原始值位置内环由跟随和回放共用，不按模式改变电机极性。实车右弯回放曾因外环额外乘 `-1` 而向左倒，现已将 `CAR_REPLAY_STEER_SIGN` 改为 `+1`：正向右弯倒车原路返回时，前轮仍向物理右侧打。
- 完整绕桶时航向保持连续，不把 `360 deg` 折叠为 `0 deg`。弯道内使用 IMU 在编码器参考点前后 0.40 m 做局部相位校正，并限制参考索引只能向起点移动。
- 回放已取消转弯限速，直线和弯道统一使用跟随的目标速度、PWM 前馈、最小启动 PWM 和速度 PI 参数；转向位置环与 PWM 档位本来就是跟随/回放共用。

## 五、前轮绝对角度传感器

实测原始值：

| 位置 | 原始值 |
| --- | ---: |
| 右机械极限 | 925 |
| 机械中位 | 2006 |
| 左机械极限 | 2960 |

接线：

| 传感器信号 | TC387 引脚 |
| --- | --- |
| SCLK | P10.3 |
| MOSI | P10.1 |
| MISO | P10.2 |
| CS | P10.5 |
| VCC | 3.3 V |
| GND | GND |

当前修改：

- 屏幕 `SA` 直接显示传感器原始值，不再显示换算后的角度。
- 回放转向闭环直接比较原始目标值和原始 `SA`。
- 抽象转向命令按左右不同量程，分段映射到 `925~2960`。
- 左软限位设为 2960，右软限位设为 925。
- 满舵时跟随与回放都启用后轮差速：内轮为基础 PWM 的 60%，外轮为 140%，平均驱动力仍为 100%；普通转角两轮仍同速。
- 软限位位于转向 PWM 的统一出口，对跟随和回放都有效；它只禁止继续向限位方向驱动，反向回正命令始终允许。
- 跟随与回放都使用原始值位置闭环，不再保留视觉步进控制代码。

## 六、屏幕参数

| 显示项 | 含义 |
| --- | --- |
| ST | `REC`、`READY`、`BACK`、`DONE` 等状态 |
| ERR | 错误码，正常为 0 |
| DX | 二维码横向偏差 |
| DIST | 二维码距离，单位 mm |
| REC | 已记录里程，单位 mm |
| REM | 回放剩余里程，单位 mm |
| PT | 当前路径点数量 |
| SA | 前轮角度传感器原始值，正常约 925~2960 |
| YAW | IMU 累计航向角整数值 |
| SPWM | 当前转向电机 PWM，正负表示两个方向 |

## 七、下一步测试顺序

1. 架空前轮，上电确认 `SA` 在中位附近约为 2006。
2. 手动转到左右极限，确认原始值仍接近 2960 和 925，且没有跳变。
3. 进入 `REC`，直行一圈后轮，确认记录里程接近 0.785 m。
4. 录制 2~3 m 直线并进入 `READY`。
5. 架空驱动轮后按 KEY2，确认进入 `BACK`，后轮倒转且 `REM` 持续减小。
6. 直线回放时观察 `SA` 和 `SPWM`，转向不应持续顶向任一软限位。
7. 如果给出左转目标，`SA` 应向更大的原始值靠近；给出右转目标，`SA` 应向更小的原始值靠近。
8. 架空测试通过后，再落地测试直线，最后测试单个大弯和绕桩。
9. 绕桶录制结束后，屏幕 `YAW` 相对起点应累计接近正负 360 度；若只回到 0 附近或中途跳变，禁止开始整圈回放。

## 八、异常判断

- `SA` 正常但电机一直顶向限位：首先检查 PWM 正负方向是否与原始值增减方向一致。
- 左转命令下 `SA` 反而减小，或右转命令下 `SA` 反而增大：反馈方向错误，不能继续调 PID。
- `SA` 到 2960 后仍继续向左驱动，或到 925 后仍继续向右驱动：软限位逻辑或电机方向定义错误，应立即断电检查。
- `REM` 不下降：检查后轮倒车计数和回放里程累计。
- 直线回放左右抖动：先降低回放航向增益，不要先取消 IMU 滤波。
- 转弯明显滞后：适当增大回放前视距离；切弯过早则减小前视距离。
