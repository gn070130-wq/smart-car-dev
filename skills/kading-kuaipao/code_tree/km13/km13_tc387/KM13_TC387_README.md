# KM13 TC387

决赛流程：上电静止完成 IMU 标定，按 KEY1 进入 `REC`，视觉跟随并记录本次随机路线；停车区再按 KEY1 进入 `READY`；确认倒车区域无人后按 KEY2 进入 `BACK`，车辆沿刚记录的路线倒车返回发车区并停车。

## 当前核心分工

| 核心 | 任务 |
| --- | --- |
| CPU0 | 总钻风初始化、相机 DMA 和帧生产 |
| CPU1 | AprilTag/二维码识别、结果发布、IPS200 参数显示 |
| CPU2 | UART3 语音协议、无源蜂鸣器和 LED 动作 |
| CPU3 | 10 ms 底盘控制、编码器、IMU、跟随、记录和回放 |

PIT 中断归 CPU3，相机 ERU/DMA 归 CPU0，UART3 中断归 CPU2。IPS200 只由 CPU1 写，其他核心不得初始化或刷新屏幕。

## 软件边界

| 模块 | 职责 | 参数文件 |
| --- | --- | --- |
| `car_follow.c` | 视觉命令超时、距离速度闭环、跟随输出 | `car_follow_config.h` |
| `car_path.c` | 后轮里程、连续 IMU 航向和实测前轮角的关键点记录 | `car_path_config.h` |
| `car_replay.c` | 倒车里程、实测前轮角前馈、IMU 相位与航向闭环 | `car_replay_config.h` |
| `car_nav.c` | 状态机、传感器采样、电机和转向位置内环 | `car_config.h` |

跟随与回放不共享速度积分器、航向参数或转向滤波状态，只共享底层电机限幅、前轮原始值位置环以及录制完成后的只读路线。

## 路线记录与回放

路线点保存 `累计里程 s + 连续航向 yaw + 实测前轮角 steer`，不保存 GPS、二维坐标或旧地图。航向不折叠到正负 180 度，因此完整绕锥桶一圈会保留约正负 360 度的变化；前轮角相对固定标定中位 `SA=2006` 解算，不使用每次上电位置作为零点。

回放流程：

1. 两个后轮编码器平均值累计倒车里程。
2. 按 `总里程 - 已回放里程` 取得参考位置，并沿倒车方向前视 0.15 m。
3. 优先把该里程处录到的实际前轮角作为转向前馈，直接复现跟随时的机械转角；曲率只在前轮角接近中位时兜底并参与弯道判定。
4. IMU 航向误差和角速度作为反馈；直线路段还累积小幅航向积分，修正前轮看似回正但车辆因机械偏差持续跑偏的问题。
5. 0.12 m 短窗口识别紧弯和 S 弯换向，0.30 m 长窗口识别大半径缓弯；弯道内在编码器参考点前后 0.40 m 搜索与当前连续 IMU 航向最相符的位置。
6. 搜索误差不做 360 度取模，所以整圈入口和出口不会因物理朝向相同而混淆；参考索引只允许沿回放方向前进。
7. 回放不按曲率限速，直线和转弯都使用与跟随相同的目标速度及 PWM 参数；只在剩余 0.65 m 时减速，剩余 0.06 m 停车。

停车仍由后轮剩余里程决定。IMU 只校正路线相位和航向，不会单独宣布到达起点。回放结束后后轮立即停止，前轮随后主动回到 `SA=2006` 附近再关闭转向 PWM。

## 操作与显示

- KEY1：`READY/DONE/ERR -> REC`；`REC -> READY`。进入 `READY` 后后轮停止，前轮自动回到 `SA=2006`。
- KEY2：路线有效时立即 `READY -> BACK`；前轮回正只作为准备动作，不作为启动条件。
- WiFi 已禁用，不参与比赛进程。
- `CAR_DISPLAY_MODE=0`：不刷新屏幕。
- `CAR_DISPLAY_MODE=1`：CPU1 黑底红字显示参数，不显示相机图像。

屏幕项目：`ST` 状态、`ERR` 错误码、`DX`、`DIST`、`REC` 已记录里程、`REM` 剩余里程、`PT` 路径点数、`SA` 前轮传感器原始值、`YAW` 连续航向整数度、`SPWM` 转向 PWM。

## 比赛前验证顺序

1. 架空确认后轮前进均为正、倒车均为负，一圈约 1024 count。
2. 录制并回放 2 至 3 m 直线，先验证里程停车。
3. 分别验证宽左弯、宽右弯和 90 度宽弯。
4. 录制完整一圈，确认 `YAW` 累计接近正负 360 度且 `PT` 持续增加。
5. 最后测试随机路线、S 弯和绕单个锥桶一圈。
