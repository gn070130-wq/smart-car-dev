第一章 引言
1.1 概述
本项目为第二十一届全国大学生智能汽车竞赛卡丁快跑组别参赛作品，由山东工商学院迅雷卡丁一队基于科宇T型载人卡丁车车模完成整车软硬件一体化开发。作品以视觉引导自主学习路径、色块触发自动回溯复刻为核心实现思路，全程不依赖GPS、RTK等室外定位设备，仅依靠车尾后置视觉采集单元、IMU惯性单元与车轮编码器完成车辆位姿解算，实现赛道自主跟随、路径记忆、自动折返复刻全流程功能。
硬件层面采用双英飞凌TC264多核微控制器分布式架构：主TC264负责整车运动控制、视觉色块处理、航迹推算与Pure Pursuit路径跟踪算法运算；另一路TC264独立承载语音采集识别、Wi-Fi云端语音交互、LoRa无线指令转发功能，配套自研主板、双路电机驱动板、灯光显示板、24V转12V降压模块、硅麦采集电路等自制PCB，完成传感器、执行机构、通信模块集成布局。原车底盘、传动、轮胎、驱动电机等机械结构完全保留，仅增设电子设备安装支架，不改动原车动力与转向机械参数。
软件层面基于AURIX ADS开发环境使用C语言开发，视觉模块采用逐飞凌摄像头采集RGB565图像，转换至HSL色彩空间结合动态自适应阈值算法，解决场地光照波动带来的色块丢失、误识别问题；运动解算依靠左右轮编码器里程增量搭配IMU航向角完成二维平面航迹推算，按固定空间阈值自动记录路径坐标点；当画面内色块面积达到设定阈值后，系统自动存储完整路径并反转点位序列，切换纯追踪算法实现原路精准折返；底层搭配增量式PID速度闭环、转向角度位置闭环保障行驶平稳，支持参数掉电Flash存储、遥控急停安全保护、IPS屏实时状态调试。同时配套Python语音识别服务端，经硅麦采集语音、云端解析后下发控制指令，拓展车辆语音交互控制能力。
整车完整覆盖卡丁快跑赛题全部任务，完成视觉循迹学习、路径存储、触发折返、稳定行驶、语音辅助控制等核心功能，针对光照干扰、航迹累积误差、远距离色块误触发等赛场痛点做优化，具备较强环境适应性与运行稳定性，下文将从机械结构、硬件电路、软件算法、调试优化等维度阐述整套智能卡丁车的设计与实现方案。
1.2 卡丁快跑任务与技术路线
本队卡丁车的核心任务流程为：车辆首先利用安装在车尾的逐飞凌瞳摄像头追踪引导人员携带的目标色块；在跟随过程中，通过左右轮编码器和IMU航向角持续估计车辆相对位姿，并按距离阈值记录路径点；当摄像头识别到另一种触发色块后，系统结束路径记录、保存终点并反转已记录的路径点序列，随后切换至路径复刻模式，利用Pure Pursuit算法和底层速度、转向闭环沿所学习的路径返回。该方案的特点是“先视觉跟随学习路径，再自动复刻路径”，不依赖GPS或RTK进行实际导航。[4]

第四章 微处理器软件与核心算法设计
4.1 双TC264软件架构
主车TC264工程基于AURIX TC264平台运行。CPU0执行车辆主状态机、传感器状态更新、路径记录和复刻、速度与转向控制；CPU1在指定模式下持续调用image_process()完成视觉图像处理。周期中断负责读取IMU和编码器并执行底层闭环。另一套TC264运行voice_device2工程，承担语音采集、Wi-Fi传输和LoRa命令转发。[4]

图4.1  软件状态与核心算法流程
4.2 色块识别与颜色自适应
视觉程序读取逐飞凌瞳摄像头图像，并以160×120的程序处理尺寸进行RGB565像素处理。算法将像素颜色转换到HSL空间，根据目标色阈值判断候选像素，再采用连通域搜索得到最大目标色块，输出中心位置、宽度、高度和面积。目标跟随色块与触发色块使用两套相互独立的阈值，避免触发色检测覆盖目标色结果。[4]
实际调试中存在“光照变化后目标色块容易丢失”和“色块颜色不好确定”的问题。为提高环境适应性，程序支持基于摄像头中心区域的颜色标定，并对目标色块采用H/S/L动态自适应，在已有有效检测结果附近更新参考颜色范围。该策略用于降低不同光照和色温变化引起的阈值漂移。
4.3 视觉跟随控制
当最大目标色块有效时，程序根据色块几何尺寸估计目标距离distance_mm和横向偏移offset_x_mm。View_Trace()将代码中的目标跟随距离设为约600 mm，距离大于目标值时通过View_D_Loop生成前后速度指令，同时依据横向偏移计算转向指令。摄像头采用车尾后向、近似水平安装，使色块尽量平视进入画面，有利于减小透视变化对距离估计的影响。[4]

上述600 mm为当前程序中的代码参数。若赛前最终参数经过重新标定，应以实际比赛版本程序中的参数为准。

4.5 路径记点与触发色块判断
guandao_recode()持续更新车辆位姿，并由recode_waypoint()判断当前位置与上一个记录点的距离。当移动距离达到recode_threshold时记录新的路径点。当前代码默认recode_threshold=0.4 m，同时该参数可以从Flash中读取并覆盖默认值。[4]

另一种触发色块由stop_color_check()独立检测。程序计算触发色块最大连通域面积与整幅画面面积之比，只有面积超过STOP_TRIGGER_AREA_PERCENT对应阈值时才进入触发状态。当前代码该比例为35%，用于降低远距离颜色相似目标造成的误触发。

4.6 路径反转与模式切换
触发条件满足后，程序结束路径记录并调用Flash_Store_Mode(2)保存当前阶段数据。随后portion3_points_switch()对已记录路径点序列进行反向处理，并将主状态切换到Guandao_portion_3路径复刻模式。由此实现“学习路径”和“复刻路径”之间的自动转换。[4]
4.7 Pure Pursuit路径复刻
复刻阶段调用guandao_trace()更新当前位置，并通过pursuit_contral_mode()执行Pure Pursuit纯追踪。算法计算当前车辆与目标路径点之间的距离、目标方位角和航向误差；当车辆已到达当前目标点附近或目标点已位于车辆侧后方时，切换到后续路径点。程序根据预瞄点与车辆当前位置计算预瞄角和预瞄距离，再得到目标转向角。


实际代码在目标转角计算中加入经验比例系数，以适配本车转向机构和轮距/轴距参数；到达路径终点附近时还会降低中心速度，实现末端减速。Pure Pursuit输出的目标转角和左右轮目标速度随后交给底层闭环执行。[4]

转向控制使用360°绝对角度位置传感器作为反馈。Steer_Moter_Contral()根据目标转向位置与实际角度误差生成转向电机控制量，并根据误差大小调整比例系数，同时进行目标角和输出限幅，从而构成“路径算法—目标转角—角度反馈—转向电机”的位置闭环。

4.10 语音与LoRa通信
voice_device2工程以状态机方式完成固定时长的语音采集，并通过Wi-Fi将PCM数据发送至语音服务端。服务端对语音数据进行识别，返回命令码后，语音/通信TC264使用LORA3A22向主车发送命令帧，主车再解析相应指令。附录B给出相关源代码。

5.4 调试问题与处理
5.4.1 光照变化后目标色块容易丢失
在室内外光照强度、局部阴影或色温发生变化时，同一色块的RGB分量会明显变化，固定阈值容易导致目标脱离颜色范围。程序采用RGB565转HSL判定，并在有效检测后对目标色的H/S/L参考范围进行动态自适应，用于降低亮度变化对识别稳定性的影响。
5.4.2 触发色块远距离容易误识别
触发色块用于结束路径记录，一旦误触发会造成状态机提前切换。实际调试中远处相似颜色区域容易被识别为触发目标，因此程序将目标色块和触发色块采用独立颜色阈值，并额外增加最大连通域面积门限。当前代码要求触发色块面积超过画面35%才进入触发状态，从逻辑上限制远距离小目标引发误触发。
5.4.3 色块颜色阈值不易确定
不同场地照明、色块材料和表面反光会改变相机中的颜色表现，固定HSL阈值难以一次确定。程序保留中心区域颜色标定功能，目标色和触发色可分别标定；目标色再结合动态自适应进行小范围修正。现场调试时应在实际比赛光照下分别完成两类颜色标定，并通过连续运行检查两组阈值是否存在交叉。

第7章 结论
本报告围绕第二十一届全国大学生智能汽车竞赛技术报告细则，对山东工商学院迅雷卡丁一队卡丁快跑组T型载人卡丁车的整车方案、机械安装、硬件电路、控制软件、开发调试和主要技术指标进行了系统整理。机械部分保持原车轮胎、轴距/轮距、传动机构和后轮驱动电机基本结构；电子系统使用两套英飞凌TC264，构建视觉、IMU/编码器航迹推算、双路电机驱动、语音识别、LoRa通信、灯板显示和电源转换等功能。
核心控制方案采用“视觉跟随学习路径—触发色块结束记录—Pure Pursuit复刻路径”的技术路线。逐飞凌瞳摄像头安装在车尾并以近似水平视角观察引导人员腰部高度的色块；程序通过HSL阈值和最大连通域提取目标，通过编码器与IMU记录路径点，并在第二色块达到面积阈值后自动反转路径序列进入复刻模式。底层采用左右轮速度PID和转向位置闭环完成执行。
实际调试中遇到的主要问题包括光照变化导致目标色块容易丢失、触发色块远距离误识别以及颜色阈值不易确定。当前程序通过HSL颜色空间、目标色动态自适应、独立触发色阈值和面积门限等方式提高识别稳定性。后续可进一步研究自动曝光/颜色恒常性、更加鲁棒的目标分类、基于距离的自适应触发条件，以及对编码器+IMU航迹累积误差的在线校正。

#define min3v(v1, v2, v3)   ((v1)>(v2)? ((v2)>(v3)?(v3):(v2)):((v1)>(v3)?(v3):(v1)))
#define max3v(v1, v2, v3)   ((v1)<(v2)? ((v2)<(v3)?(v3):(v2)):((v1)<(v3)?(v3):(v1)))
#define SWAPBYTE(h) ((((uint16_t)h << 8)&0xFF00) | ((uint16_t)h >> 8))

// 坐标合法判断
static inline bool in_range(int16_t x, int16_t y)
{
    return (x >= 0 && x < SCC8660_W && y >= 0 && y < SCC8660_H);
}

static inline float color_clampf(float value, float min_value, float max_value)
{
    if(value < min_value) return min_value;
    if(value > max_value) return max_value;
    return value;
}

static float color_radial_scale(float x, float y)
{
    float cx = ((float)SCC8660_W - 1.0f) * 0.5f;
    float cy = ((float)SCC8660_H - 1.0f) * 0.5f;
    float nx;
    float ny;
    float r2;
    float scale;

    if(cx <= 0.0f || cy <= 0.0f)
    {
        return 1.0f;
    }

    nx = (x - cx) / cx;
    ny = (y - cy) / cy;
    r2 = nx * nx + ny * ny;
    scale = 1.0f + g_distance_lens_k1 * r2;

    return color_clampf(scale, 0.55f, 1.45f);
}

static float color_correct_length_px(float pixel_len, float x, float y)
{
    if(pixel_len <= 0.0f)
    {
        return 0.0f;
    }
    return pixel_len / color_radial_scale(x, y);
}

static float color_blob_corrected_size_px(const Blob_t *blob)
{
    float w_px;
    float h_px;
    float sum = 0.0f;
    uint8_t cnt = 0;

    if(blob == 0)
    {
        return 0.0f;
    }

    w_px = color_correct_length_px((float)blob->w, (float)blob->center.x, (float)blob->center.y);
    h_px = color_correct_length_px((float)blob->h, (float)blob->center.x, (float)blob->center.y);

    if(w_px > 0.0f && g_distance_target_w_mm > 0.0f)
    {
        sum += w_px;
        cnt++;
    }
    if(h_px > 0.0f && g_distance_target_h_mm > 0.0f)
    {
        sum += h_px;
        cnt++;
    }

    if(cnt > 0)
    {
        return sum / (float)cnt;
    }

    if(w_px <= 0.0f) return h_px;
    if(h_px <= 0.0f) return w_px;
    return (w_px + h_px) * 0.5f;
}

static float color_blob_distance_mm(const Blob_t *blob)
{
    float w_px;
    float h_px;
    float sum = 0.0f;
    uint8_t cnt = 0;

    if(blob == 0 || g_distance_focal_px <= 0.0f)
    {
        return -1.0f;
    }

    w_px = color_correct_length_px((float)blob->w, (float)blob->center.x, (float)blob->center.y);
    h_px = color_correct_length_px((float)blob->h, (float)blob->center.x, (float)blob->center.y);

    if(w_px >= COLOR_DISTANCE_MIN_SIZE_PX && g_distance_target_w_mm > 0.0f)
    {
        sum += (g_distance_focal_px * g_distance_target_w_mm) / w_px;
        cnt++;
    }
    if(h_px >= COLOR_DISTANCE_MIN_SIZE_PX && g_distance_target_h_mm > 0.0f)
    {
        sum += (g_distance_focal_px * g_distance_target_h_mm) / h_px;
        cnt++;
    }

    if(cnt == 0)
    {
        return -1.0f;
    }
    return sum / (float)cnt;
}

static float color_blob_offset_x_px(const Blob_t *blob)
{
    float image_center_x;
    float raw_offset_px;
    float scale;

    if(blob == 0)
    {
        return 0.0f;
    }

    image_center_x = ((float)SCC8660_W - 1.0f) * 0.5f;
    raw_offset_px = (float)blob->center.x - image_center_x;
    scale = color_radial_scale((float)blob->center.x, (float)blob->center.y);

    if(scale <= 0.0f)
    {
        return raw_offset_px;
    }

    return raw_offset_px / scale;
}

static float color_blob_offset_x_mm(const Blob_t *blob, float distance_mm)
{
    if(blob == 0 || g_distance_focal_px <= 0.0f || distance_mm <= 0.0f)
    {
        return 0.0f;
    }

    return color_blob_offset_x_px(blob) * distance_mm / g_distance_focal_px;
}

// 取像素 RGB565，并转换为 RGB888 近似值
static void readcolor(unsigned int x, unsigned int y, color_rgb_struct* rgb)
{
    unsigned short c16;
    c16 = SWAPBYTE(scc8660_image[y][x]);
    rgb->red   = (unsigned char)((c16 & 0xf800) >> 8);
    rgb->green = (unsigned char)((c16 & 0x07e0) >> 3);
    rgb->blue  = (unsigned char)((c16 & 0x001f) << 3);
}

static void rgbtohsl(const color_rgb_struct* rgb, color_hsl_struct* hsl)
{
    int h = 0;
    int s = 0;
    int l;
    int maxval;
    int minval;
    int difval;
    int r = rgb->red;
    int g = rgb->green;
    int b = rgb->blue;

    maxval = max3v(r, g, b);
    minval = min3v(r, g, b);
    difval = maxval - minval;

    l = (maxval + minval) * 240 / 255 / 2;

    if(maxval != minval)
    {
        if(maxval == r)
        {
            if(g >= b)
            {
                h = 40 * (g - b) / difval;
            }
            else
            {
                h = 40 * (g - b) / difval + 240;
            }
        }
        else if(maxval == g)
        {
            h = 40 * (b - r) / difval + 80;
        }
        else
        {
            h = 40 * (r - g) / difval + 160;
        }

        if(l == 0)
        {
            s = 0;
        }
        else if(l <= 120)
        {
            s = difval * 240 / (maxval + minval);
        }
        else
        {
            s = difval * 240 / (480 - (maxval + minval));
        }
    }

    hsl->hue        = (unsigned char)(((h > 240) ? 240 : ((h < 0) ? 0 : h)));
    hsl->saturation = (unsigned char)(((s > 240) ? 240 : ((s < 0) ? 0 : s)));
    hsl->luminance  = (unsigned char)(((l > 240) ? 240 : ((l < 0) ? 0 : l)));
}

static float color_absf(float value)
{
    return (value < 0.0f) ? -value : value;
}

static float color_hue_wrap(float hue)
{
    while(hue < 0.0f) hue += 240.0f;
    while(hue >= 240.0f) hue -= 240.0f;
    return hue;
}

// Signed shortest hue difference: target - reference, range [-120, 120].
static float color_hue_diff_signed(float target, float reference)
{
    float diff = color_hue_wrap(target) - color_hue_wrap(reference);
    if(diff > 120.0f) diff -= 240.0f;
    if(diff < -120.0f) diff += 240.0f;
    return diff;
}

static float color_hue_diff_abs(float a, float b)
{
    return color_absf(color_hue_diff_signed(a, b));
}

static unsigned char color_u8_round_clamp(float value)
{
    if(value <= 0.0f) return 0;
    if(value >= 240.0f) return 240;
    return (unsigned char)(value + 0.5f);
}

// Rebuild only H/S/L limits; keep width/height limits untouched.
static void color_condition_from_center(float h, float s, float l, target_condi_struct *condition)
{
    float h_min;
    float h_max;

    if(condition == 0) return;

    h = color_hue_wrap(h);
    s = color_clampf(s, 0.0f, 240.0f);
    l = color_clampf(l, 0.0f, 240.0f);

    h_min = h - (float)CONDI_H_RANGE;
    h_max = h + (float)CONDI_H_RANGE;

    // h_min > h_max means this range crosses the 0/240 hue boundary.
    if(h_min < 0.0f)
    {
        condition->h_min = color_u8_round_clamp(h_min + 240.0f);
        condition->h_max = color_u8_round_clamp(h_max);
    }
    else if(h_max > 240.0f)
    {
        condition->h_min = color_u8_round_clamp(h_min);
        condition->h_max = color_u8_round_clamp(h_max - 240.0f);
    }
    else
    {
        condition->h_min = color_u8_round_clamp(h_min);
        condition->h_max = color_u8_round_clamp(h_max);
    }

    condition->s_min = color_u8_round_clamp(s - (float)CONDI_S_RANGE);
    condition->s_max = color_u8_round_clamp(s + (float)CONDI_S_RANGE);
    condition->l_min = color_u8_round_clamp(l - (float)CONDI_L_RANGE);
    condition->l_max = color_u8_round_clamp(l + (float)CONDI_L_RANGE);
}

static float color_condition_hue_center(const target_condi_struct *condition)
{
    float h;

    if(condition->h_min <= condition->h_max)
    {
        h = ((float)condition->h_min + (float)condition->h_max) * 0.5f;
    }
    else
    {
        float width = (240.0f - (float)condition->h_min) + (float)condition->h_max;
        h = (float)condition->h_min + width * 0.5f;
    }

    return color_hue_wrap(h);
}

static void color_adapt_reset(float h, float s, float l)
{
    g_adapt_base_h = color_hue_wrap(h);
    g_adapt_base_s = color_clampf(s, 0.0f, 240.0f);
    g_adapt_base_l = color_clampf(l, 0.0f, 240.0f);

    g_adapt_track_h = g_adapt_base_h;
    g_adapt_track_s = g_adapt_base_s;
    g_adapt_track_l = g_adapt_base_l;

    g_adapt_frame_count = 0;
    g_adapt_has_center = 0;
    g_adapt_miss_count = 0;
    g_adapt_initialized = 1;
}

static void color_adapt_init_from_condition(const target_condi_struct *condition)
{
    float h;
    float s;
    float l;

    if(condition == 0) return;

    h = color_condition_hue_center(condition);
    s = ((float)condition->s_min + (float)condition->s_max) * 0.5f;
    l = ((float)condition->l_min + (float)condition->l_max) * 0.5f;
    color_adapt_reset(h, s, l);
}

static void color_adapt_before_detect(void)
{
    int16_t dx;
    int16_t dy;
    uint16_t valid_count = 0;
    float hue_diff_sum = 0.0f;
    float s_sum = 0.0f;
    float l_sum = 0.0f;
    float candidate_h;
    float candidate_s;
    float candidate_l;

    if(!g_adapt_initialized)
    {
        color_adapt_init_from_condition(&target_color_condi);
    }

    if(!g_adapt_has_center)
    {
        return;
    }

    g_adapt_frame_count++;
    if(g_adapt_frame_count < COLOR_ADAPT_FRAME_INTERVAL)
    {
        return;
    }
    g_adapt_frame_count = 0;

    // Sample the new frame around the previous successfully detected center.
    for(dy = -COLOR_ADAPT_SAMPLE_RADIUS; dy <= COLOR_ADAPT_SAMPLE_RADIUS; dy++)
    {
        for(dx = -COLOR_ADAPT_SAMPLE_RADIUS; dx <= COLOR_ADAPT_SAMPLE_RADIUS; dx++)
        {
            int16_t x = g_adapt_last_center.x + dx;
            int16_t y = g_adapt_last_center.y + dy;
            color_rgb_struct rgb;
            color_hsl_struct hsl;
            float hue_diff;

            if(!in_range(x, y))
            {
                continue;
            }

            readcolor((unsigned int)x, (unsigned int)y, &rgb);
            rgbtohsl(&rgb, &hsl);

            hue_diff = color_hue_diff_signed((float)hsl.hue, g_adapt_track_h);

            // Remove obvious background/edge pixels before averaging.
            if(color_absf(hue_diff) > COLOR_ADAPT_SAMPLE_H_LIMIT ||
               color_absf((float)hsl.saturation - g_adapt_track_s) > COLOR_ADAPT_SAMPLE_S_LIMIT ||
               color_absf((float)hsl.luminance - g_adapt_track_l) > COLOR_ADAPT_SAMPLE_L_LIMIT)
            {
                continue;
            }

            hue_diff_sum += hue_diff;
            s_sum += (float)hsl.saturation;
            l_sum += (float)hsl.luminance;
            valid_count++;
        }
    }

    if(valid_count < COLOR_ADAPT_MIN_SAMPLE_PIXELS)
    {
        return;
    }

    candidate_h = color_hue_wrap(g_adapt_track_h + hue_diff_sum / (float)valid_count);
    candidate_s = s_sum / (float)valid_count;
    candidate_l = l_sum / (float)valid_count;

    // One update must be small enough, and the total drift from the original color is bounded.
    if(color_hue_diff_abs(candidate_h, g_adapt_track_h) > COLOR_ADAPT_STEP_H_LIMIT ||
       color_absf(candidate_s - g_adapt_track_s) > COLOR_ADAPT_STEP_S_LIMIT ||
       color_absf(candidate_l - g_adapt_track_l) > COLOR_ADAPT_STEP_L_LIMIT ||
       color_hue_diff_abs(candidate_h, g_adapt_base_h) > COLOR_ADAPT_TOTAL_H_LIMIT ||
       color_absf(candidate_s - g_adapt_base_s) > COLOR_ADAPT_TOTAL_S_LIMIT ||
       color_absf(candidate_l - g_adapt_base_l) > COLOR_ADAPT_TOTAL_L_LIMIT)
    {
        return;
    }

    g_adapt_track_h = color_hue_wrap(g_adapt_track_h +
                        color_hue_diff_signed(candidate_h, g_adapt_track_h) * COLOR_ADAPT_H_ALPHA);
    g_adapt_track_s = color_clampf(g_adapt_track_s +
                        (candidate_s - g_adapt_track_s) * COLOR_ADAPT_S_ALPHA, 0.0f, 240.0f);
    g_adapt_track_l = color_clampf(g_adapt_track_l +
                        (candidate_l - g_adapt_track_l) * COLOR_ADAPT_L_ALPHA, 0.0f, 240.0f);

    color_condition_from_center(g_adapt_track_h, g_adapt_track_s, g_adapt_track_l, &target_color_condi);
}

static void color_adapt_detection_result(uint8_t blob_num)
{
    if(blob_num >= 1)
    {
        g_adapt_last_center = blobs[0].center;
        g_adapt_has_center = 1;
        g_adapt_miss_count = 0;
    }
    else if(g_adapt_has_center)
    {
        if(g_adapt_miss_count < 255)
        {
            g_adapt_miss_count++;
        }
        if(g_adapt_miss_count >= COLOR_ADAPT_MAX_MISSED_FRAMES)
        {
            g_adapt_has_center = 0;
            g_adapt_frame_count = 0;
        }
    }
}
#endif

static int colormatch(const color_hsl_struct* hsl, const target_condi_struct* condition)
{
    int hue_match;

    // h_min > h_max represents a hue interval crossing 0/240.
    if(condition->h_min <= condition->h_max)
    {
        hue_match = (hsl->hue >= condition->h_min && hsl->hue <= condition->h_max);
    }
    else
    {
        hue_match = (hsl->hue >= condition->h_min || hsl->hue <= condition->h_max);
    }

    if(hue_match &&
       hsl->saturation >= condition->s_min &&
       hsl->saturation <= condition->s_max &&
       hsl->luminance  >= condition->l_min &&
       hsl->luminance  <= condition->l_max)
    {
        return 1;
    }
    return 0;
}

void set_color_target_condi(uint16 rgb565_data, target_condi_struct* condition)
{
    color_rgb_struct rgb;
    color_hsl_struct hsl;

    rgb.red   = (unsigned char)((SWAPBYTE(rgb565_data) & 0xf800) >> 8);
    rgb.green = (unsigned char)((SWAPBYTE(rgb565_data) & 0x07e0) >> 3);
    rgb.blue  = (unsigned char)((SWAPBYTE(rgb565_data) & 0x001f) << 3);

    rgbtohsl(&rgb, &hsl);

#if COLOR_ADAPT_ENABLE
    color_condition_from_center((float)hsl.hue, (float)hsl.saturation, (float)hsl.luminance, condition);
    if(condition == &target_color_condi)
    {
        // Manual target refresh creates a new immutable base-color anchor.
        color_adapt_reset((float)hsl.hue, (float)hsl.saturation, (float)hsl.luminance);
    }
#else
    condition->h_min = (hsl.hue > CONDI_H_RANGE) ? (hsl.hue - CONDI_H_RANGE) : 0;
    condition->h_max = (hsl.hue < (240 - CONDI_H_RANGE)) ? (hsl.hue + CONDI_H_RANGE) : 240;
    condition->s_min = (hsl.saturation > CONDI_S_RANGE) ? (hsl.saturation - CONDI_S_RANGE) : 0;
    condition->s_max = (hsl.saturation < (240 - CONDI_S_RANGE)) ? (hsl.saturation + CONDI_S_RANGE) : 240;
    condition->l_min = (hsl.luminance > CONDI_L_RANGE) ? (hsl.luminance - CONDI_L_RANGE) : 0;
    condition->l_max = (hsl.luminance < (240 - CONDI_L_RANGE)) ? (hsl.luminance + CONDI_L_RANGE) : 240;
#endif
}

static inline uint8_t get_pix(const target_condi_struct* condition, int16_t x, int16_t y)
{
    color_rgb_struct rgb;
    color_hsl_struct hsl;

    readcolor(x, y, &rgb);
    rgbtohsl(&rgb, &hsl);

    return colormatch(&hsl, condition) ? 0 : 1;
}

static uint16_t blob_flood(uint16_t *img, int16_t sx, int16_t sy, Blob_t *blob, const target_condi_struct* condition)
{
    uint16_t stk_top = 0;
    uint16_t cnt = 0;
    int16_t min_x = sx;
    int16_t max_x = sx;
    int16_t min_y = sy;
    int16_t max_y = sy;

    (void)img;

    if(blob == 0 || !in_range(sx, sy) || get_pix(condition, sx, sy) != 0)
    {
        return 0;
    }

    stack[stk_top++] = (Point_t){sx, sy};
    mark[sy * SCC8660_W + sx] = 1;

    while(stk_top > 0)
    {
        Point_t cur = stack[--stk_top];
        cnt++;

        if(cur.x < min_x) min_x = cur.x;
        if(cur.x > max_x) max_x = cur.x;
        if(cur.y < min_y) min_y = cur.y;
        if(cur.y > max_y) max_y = cur.y;

        for(uint8_t i = 0; i < 4; i++)
        {
            int16_t nx = cur.x + dir4[i].x;
            int16_t ny = cur.y + dir4[i].y;
            uint16_t idx;

            if(!in_range(nx, ny))
            {
                continue;
            }

            idx = ny * SCC8660_W + nx;
            if(mark[idx] == 0 && get_pix(condition, nx, ny) == 0)
            {
                mark[idx] = 1;
                if(stk_top < MAX_STACK)
                {
                    stack[stk_top++] = (Point_t){nx, ny};
                }
            }
        }
    }

    blob->min.x = min_x;
    blob->min.y = min_y;
    blob->max.x = max_x;
    blob->max.y = max_y;
    blob->center.x = (min_x + max_x) / 2;
    blob->center.y = (min_y + max_y) / 2;
    blob->w = max_x - min_x;
    blob->h = max_y - min_y;
    blob->area = cnt;

    return cnt;
}

// 遍历整张图，统计检测到的色块数量，但只保存面积最大的色块到 largest_blob。
static uint8_t blob_find_largest(uint16_t *img, Blob_t *largest_blob, uint16_t min_area, const target_condi_struct* condition)
{
    uint8_t detected_num = 0;
    uint16_t max_area = 0;
    Blob_t max_blob;

    if(largest_blob == 0)
    {
        return 0;
    }

    memset(&max_blob, 0, sizeof(max_blob));
    memset(mark, 0, sizeof(mark));

    for(int16_t y = 0; y < SCC8660_H; y += 6)
    {
        for(int16_t x = SCC8660_W - 1; x > 0; x -= 6)
        {
            uint16_t idx = y * SCC8660_W + x;
            if(get_pix(condition, x, y) == 0 && mark[idx] == 0)
            {
                Blob_t tmp;
                uint16_t tmp_area = blob_flood(img, x, y, &tmp, condition);

                if(tmp_area >= min_area)
                {
                    if(detected_num < 255)
                    {
                        detected_num++;
                    }

                    if(tmp_area > max_area)
                    {
                        max_area = tmp_area;
                        max_blob = tmp;
                    }
                }
            }
        }
    }

    if(max_area > 0)
    {
        *largest_blob = max_blob;
    }
    else
    {
        memset(largest_blob, 0, sizeof(*largest_blob));
    }

    return detected_num;
}


static void stop_color_check(void)
{
    static uint8_t stop_alarm_active = 0;
    Blob_t stop_blob;
    uint8_t stop_num;
    uint32_t screen_area;
    uint32_t trigger_area;

    screen_area = (uint32_t)SCC8660_W * (uint32_t)SCC8660_H;
    trigger_area = (screen_area * (uint32_t)STOP_TRIGGER_AREA_PERCENT) / 100U;

    // Use a separate blob object so stop-color detection never overwrites blobs[0].
    stop_num = blob_find_largest((uint16_t*)scc8660_image, &stop_blob, 1, &stop_threshold);

    if(stop_num >= 1 && (uint32_t)stop_blob.area > trigger_area)
    {
        // Beep once when entering the over-threshold state.
        ips200_show_int(X(1),  Y(11),1,5);
        if(!stop_alarm_active)
        {
            Buzzer_check(50);
            x6f_out[2] = 200;
            stop_alarm_active = 1;
        }
    }
    else
    {
        // Rearm after the stop-color area falls back below the threshold.
        stop_alarm_active = 0;
        ips200_show_int(X(1),  Y(11),0,5);
    }
}

/*基于编码器数据更新当前位姿（航迹推算）*/
void update_state(guandao_state * state , Encoder_t * ecd)
{
    float delta_real_center = 0;
    float delta_real_l = 0;
    float delta_real_r = 0;
    Encoder_Get(ecd);
    switch(slip_state)
    {
        case NONE:
            delta_real_l = (float)ecd->delta_l*ONE_TICK_DISTANCE;
            delta_real_r = (float)ecd->delta_r*ONE_TICK_DISTANCE;

            break;

        case Left_Slip:
            delta_real_r = (float)ecd->delta_r*ONE_TICK_DISTANCE;
            delta_real_l = delta_real_r;

            break;

        case Right_Slip:
            delta_real_l = (float)ecd->delta_l*ONE_TICK_DISTANCE;
            delta_real_r = delta_real_l;

            break;

        default : break;
    }

    if(!daoche_flag)
    {
        delta_real_center  = (delta_real_l+delta_real_r)/2.0f;
        state->current_state.theta =Yaw_1;
    }
    else
    {
        delta_real_center  = -(delta_real_l+delta_real_r)/2.0f;
        state->current_state.theta =Yaw_1+180.0f;
        angle_plan(&state->current_state.theta);
    }




    state->current_state.x+=delta_real_center*sinf(state->current_state.theta/180.0f*M_PI);
    state->current_state.y+=delta_real_center*cosf(state->current_state.theta/180.0f*M_PI);

}

当移动距离超过记录阈值时记录新点

void recode_waypoint(guandao_state * state)
{
    if(state ->length_index >=MAX_LENGTH_INDEX)return;

    if(state ->length_index ==0)
    {
        state->recode_map[state->length_index] =state->current_state;
        state->length_index++;

    }

    state_t last_recoded =  state->recode_map[state->length_index-1];
    float dist = get_distance(state->current_state, last_recoded );

    if(dist >=recode_threshold)
    {
        state->recode_map[state->length_index] =state->current_state;
        state->length_index++;
    }

    static uint8 dche_flag = 1;
    if(state == &INS && (x6f_out[3] ==200) && dche_flag ==1)  //遥控器控制

        daoche_point_length = state->length_index;
        state->length_index++;
        daoche_flag =1;
        daoche_flash_cheack =1;
    }
}

/*功能：纯追踪（Pure Pursuit）控制算法的核心实现

计算到目标点的距离和角度偏差

判断是否到达当前目标点（距离<阈值或角度>90°）

计算预瞄点的转向角

终点减速逻辑

差速驱动模型：左右轮速度分配

调用打滑检测函数*/
void pursuit_contral_mode(guandao_state * state,float * out_v_l,float * out_v_r,float *out_servo)
{
    float actual_ld = 0 , preview_alpha =0;
    float actual_ld2 = 0 , preview_alpha2 =0;
    float target_steering = 0;
    float v_center = 0;

    if(state->length_index == 0 || state->current_point_index ==state->length_index)
    {
        * out_v_l = 0;
        * out_v_r = 0;
        *out_servo = 0;
//        Buzzer_check(50);
        return;
    }

    state_t current_point = state->current_state;
    state_t target_point = state->recode_map[state->current_point_index];

    float dx = target_point.x - current_point.x;
    float dy = target_point.y - current_point.y;
    float distance_to_target = hypotf(dx, dy);
    float angle_to_target = atan2f(dx,dy)/M_PI*180.0f;
    float angle_diff = angle_to_target - state->current_state.theta;

    while (angle_diff > 180.0f) angle_diff -= 360.0f;
    while (angle_diff < -180.0f) angle_diff += 360.0f;


    if(distance_to_target <= persuit_threshold|| fabsf(angle_diff) > 90.0f )//  || fabsf(angle_diff) > 90.0f
    {
        state->current_point_index++;
        if(state->current_point_index >=state->length_index )
        {   state->current_point_index = state->length_index;
            * out_v_l = 0;
            * out_v_r = 0;
            *out_servo = 0;
//            Buzzer_check(50);
            return;
        }
    }




    pursuit_midhandle(state , &current_point , preview_spets , &preview_alpha , &actual_ld);
    pursuit_midhandle(state , &current_point , 8  , &preview_alpha2 , &actual_ld2);



   if(angle_diff >=90)
   {
       target_steering = 90.0f;

   }
   else if(angle_diff <= -90)
   {
       target_steering = -90.0f;
   }
   else if(fabsf(angle_diff) <=90)
   {
       target_steering = 3.0f*atan2f(2.0f * WHEEL_BASE * sinf(preview_alpha/180.0f*M_PI), actual_ld)/M_PI*180.0f;
   }
   ips200_show_float(X(10),  Y(9),target_steering ,5 ,5);

   //限幅
   Value_Limit_float(&target_steering ,-MAX_STEERING_RAD,MAX_STEERING_RAD);

//   slip_cheak(&guandao_ecd,target_steering);

   float dist_to_final = get_distance(state->current_state, state->recode_map[state->length_index -1]);

//   float k = 1.0f - 0.0008f * fabs(3.0f * preview_alpha2);
//   Value_Limit_float(&k, 0.8, 1);
   float k = k_get(3.0f * preview_alpha2 , 0.8  ,60);
//   if(base_speed >= 65 )v_center = base_speed*k;
//   else v_center = base_speed;
   v_center = base_speed;
   if(state == &INS && base_speed >= 29)portion1_speedstrategy(&v_center);
   if(state == &portion_3 ) v_center *= k;


   if(state == &INS)
   {
       if(dist_to_final < 2.0 && state->current_point_index >= state->length_index - 30)
       {
           persuit_threshold = persuit_threshold*(dist_to_final / 2.0);
           if(persuit_threshold < 0.7f){persuit_threshold = 0.7f;}
       }
       if (dist_to_final < final_dsts && state->current_point_index >= state->length_index - 30)
       {
           v_center = base_speed * (dist_to_final / final_dsts);
           if (v_center < MIN_SPEED) v_center = MIN_SPEED; // 最低速度限制
       }
   }
   else
   {
       if (dist_to_final < final_dsts && state->current_point_index >= state->length_index - 20)
       {

           persuit_threshold = persuit_threshold*(dist_to_final / final_dsts);
           if(persuit_threshold < 0.4f){persuit_threshold = 0.4f;}
           v_center = base_speed * (dist_to_final / final_dsts);
           if (v_center < MIN_SPEED) v_center = MIN_SPEED; // 最低速度限制


       }
   }

   // 差动驱动速度分配
   float w = 0;
   if(state != &portion_3)
   {


       w = (v_center * tanf(target_steering/1.70f/180.0f*M_PI)) / WHEEL_BASE;
   }
   else
   {
       w = (v_center * tanf(target_steering/3.0f/180.0f*M_PI)) / WHEEL_BASE;
   }

   if(state != &portion_3)
   {
       *out_v_l = v_center + (w * TRACK_WIDTH / 2.0f);
       *out_v_r = v_center - (w * TRACK_WIDTH / 2.0f);
   }
   else
   {
       *out_v_l = v_center + (w * TRACK_WIDTH / 2.0f);
       *out_v_r = v_center - (w * TRACK_WIDTH / 2.0f);
   }


   *out_servo = target_steering;


}

/*终点航向角校正函数，
 * 用于在车辆接近终点时修正行驶方向，
 * 确保以特定角度到达目标点。
 */
void azimuth_adjust(guandao_state * state ,float start_d , float dist_to_final , float * target_steering , float target_yaw )
{
    float angle_delta = 0;
    if(dist_to_final < start_d && state->current_point_index >= state->length_index - 30)
    {
        if(!daoche_flag)angle_delta  = target_yaw - Yaw_1;
        else angle_delta  = -(target_yaw - Yaw_1);
        angle_plan(&angle_delta);

        float kp_d = (1 - ANGLE_CORRECT_KP)/start_d*dist_to_final +ANGLE_CORRECT_KP;
        float kp_y = (ANGLE_CORRECT_KP -1)*(dist_to_final/start_d - 1);

        * target_steering = kp_d*(* target_steering) + kp_y *angle_delta;
    }
}
/*中间计算函数

计算预看点相对于当前位置的夹角

计算到预看点的距离*/
void pursuit_midhandle(guandao_state * state ,state_t * current_state , int index ,float * angle , float * distanse)
{
    int preview_index = 0;
    if(main_mode == Guandao_Recode_Mode)
    {
        preview_index = state->length_index - 1;
    }
    else
    {
        preview_index = state->current_point_index+index;
    }

   if(preview_index >=state->length_index)preview_index = state->length_index - 1;

   state_t preview_point = state->recode_map[preview_index];

   float p_dx = preview_point.x - current_state->x;
   float p_dy = preview_point.y - current_state->y;
    * angle = atan2f(p_dx,p_dy)/M_PI*180.0f - state->current_state.theta;

   while (* angle > 180.0f) * angle -= 360.0f;
   while (* angle < -180.0f) * angle += 360.0f;

    * distanse = hypotf(p_dx, p_dy);
    if(*distanse < 0.1f) *distanse = 0.1f;

}

/*这是管道路径记录的核心函数，负责实时记录车辆行驶轨迹，
 * 并支持多路径选择和存储。
 * 它根据当前选择的路径编号，将位姿数据记录到对应的路径数据结构中。*/
void guandao_recode(guandao_state * state)
{
    static uint8 flag0 = 1;                                                 // 首次调用标志（1=首次，0=已初始化），用于执行一次性初始化
    static uint8 flag1 = 1;                                                 // Flash存储标志（1=允许存储，0=已存储），防止重复保存
    int choice_flag = 0;                                                    // 路径选择计数器，用于遍历链表找到目标路径

    guandao_state * p = state;                                          // 工作指针，指向当前路径节点，用于链表遍历
    while(choice_flag < route_setting_choice)               // 根据route_setting_choice的值，遍历链表选择目标路径
                                                                                        // route_setting_choice: 0=INS, 1=passage, 2=portion_3, 3=portion_2
    {
        p = p->next;                                                        // 指针后移，指向下一个路径节点
        if(p == NULL)return;                                            // 空指针保护：若链表提前结束则退出函数
        choice_flag++;                                                  // 空指针保护：若链表提前结束则退出函数
    }

    if(flag0){  guandao_state_init(p);   flag0 =0;}          // 清空路径点数组，重置索引和位姿
    update_state(p  , &guandao_ecd);                        // 基于编码器数据更新当前车辆位姿（x, y, theta）

    if( p == &passage)portion2_points_recode();     // passage路径：按键手动记录（适合构建复杂赛道）
    else if (p == &INS)portion1_guandao_recode();
    else recode_waypoint(p);                                         // 其他路径：自动等距记录（移动超过阈值自动记录）

//    guandao_show(p);                                                // 在IPS200屏幕上显示路径信息（长度、位姿等）
    if(GPS_WORK_FLAG){if(key2_flag == 1){ key2_flag = 0 ; recode_gps(p);  }}        // GPS辅助记录（可选）：当GPS工作标志为真且按键2被按下时
//     guandao_show();



    if((gpio_get_level(SWITCH1)||x6f_out[2] == 200)&&flag1&&mem_point_flag){   Flash_Store_Mode(route_setting_choice);  Buzzer_check(50);  flag1 = 0; };    // Flash存储触发：检测物理开关1或遥控器通道2（值为200）
    // flag1确保只存储一次，避免重复写入

}

/*管道路径跟踪主函数

根据路径选择标志选择数据结构

更新当前位姿

调用纯追踪控制算法

如果启用GPS，调用GPS轨迹跟踪

显示跟踪状态*/
void guandao_trace(guandao_state * state)
{
    int choice_flag = 0;                           // 路径选择计数器，用于遍历链表找到目标路径
    guandao_state * p = state;                // 工作指针，指向当前路径节点，用于链表遍历
    while(choice_flag < route_setting_choice)
    {
        p = p->next;                             // 指针后移，指向下一个路径节点
        if(p == NULL)return;              // 空指针保护：若链表提前结束则退出函数
        choice_flag++;
    }
    update_state(p,&guandao_ecd); // 基于编码器数据更新当前车辆位姿（x, y, theta）
    pursuit_contral_mode(p ,&out_v_l ,&out_v_r ,&out_servo);
    if(GPS_WORK_FLAG)trace_gps(p);                              // 调用GPS轨迹跟踪函数
    follow_points_show(p);

}

float speed_calculate(Encoder_t * ecd , float time_tick)
{
    float v_speed = (ecd->delta_l +ecd->delta_r)*ONE_TICK_DISTANCE/time_tick/2.0f;
            return v_speed;
}

void slip_cheak(Encoder_t * ecd,float steer_angle)
{
    static int flag = 0;

    float v_speed = 0 ;
    v_speed =speed_calculate(ecd , 0.007);
    float w = (v_speed * tanf(steer_angle/180.0f*M_PI)) / WHEEL_BASE;
    float slip_index = fabs(w - IMU_Data.gyro_z);
    if(v_speed >= 1.0 &&  slip_index >= SLIP_CHEAK_INDEX)
    {
        flag++;
        if(ecd->delta_l > ecd->delta_r){ slip_state =Left_Slip; }
        else if(ecd->delta_r >=ecd->delta_l ) {slip_state =Right_Slip;}
    }
    else slip_state =NONE;
}

uint16 portion3_foint_flag = 0;
uint8 portion3_points_switch(void)
{
    int16 left;
    int16 right;
    state_t temp_point;
    if (portion_3.length_index <= 0 ||
        portion_3.length_index > MAX_LENGTH_INDEX)
    {
        return 0;
    }
    left  = 0;
    right = portion_3.length_index - 1;
    while (left < right)
    {
        temp_point = portion_3.recode_map[left];
        portion_3.recode_map[left] =portion_3.recode_map[right];
        portion_3.recode_map[right] =temp_point;
        left++;
        right--;
    }
    portion_3.current_point_index = 0;
    portion3_foint_flag = 0;
    return 1;
}

{

    e->recode_map[e->length_index] =e->current_state;
    e->length_index  ++;
}

void mapbuild_line(guandao_state *state, Point start, Point end)
{
    float dx = end.x - start.x;
    float dy = end.y - start.y;
    float dir_x = sinf(atan2f(dx, dy));
    float dir_y = cosf(atan2f(dx, dy));
    float distance_to_target = hypotf(dx, dy);
    int length = distance_to_target / SET_LINE_INDEX;

    if(state->length_index + length >= MAX_LENGTH_INDEX) return;

    float current_length = state->length_index ;
    for(int16 i = current_length, j = 0; j < length; i++, j++)
    {
        state->recode_map[i].x = start.x + SET_LINE_INDEX * j * dir_x;
        state->recode_map[i].y = start.y + SET_LINE_INDEX * j * dir_y;
        state->length_index++;
    }

    if(fmodf(distance_to_target, SET_LINE_INDEX) != 0)
    {
        state->recode_map[state->length_index].x = end.x;
        state->recode_map[state->length_index].y = end.y;
        state->length_index++;
    }
}
void mapbuild_circle(guandao_state *state, Point start, Point end, Circle circle, uint8 dir, uint8 num)
{
    if(state == NULL || circle.r <= 0) return;

    float start_angle = atan2f(start.y - circle.y, start.x - circle.x);
    float end_angle = atan2f(end.y - circle.y, end.x - circle.x);

    float delta_to_end;
    if(dir == 0)
    {
        delta_to_end = end_angle - start_angle;
        if(delta_to_end <= 0) delta_to_end += 2 * M_PI;
    }
    else
    {
        delta_to_end = start_angle - end_angle;
        if(delta_to_end <= 0) delta_to_end += 2 * M_PI;
    }

    float total_angle = delta_to_end + num * 2 * M_PI;


    float arc_length = circle.r * total_angle;
    int point_count = (int)(arc_length / SET_CIRCLE_INDEX);

    if(state->length_index + point_count + 2 >= MAX_LENGTH_INDEX) return;

    float angle_step = total_angle / point_count;

    for(int16 i = state->length_index, j = 0; j < point_count; i++, j++)
    {
        float current_angle;
        if(dir == 0)
            current_angle = start_angle + angle_step * j;
        else
            current_angle = start_angle - angle_step * j;
        state->recode_map[i].x = circle.x + circle.r * cosf(current_angle);
        state->recode_map[i].y = circle.y + circle.r * sinf(current_angle);
        state->length_index++;
    }

    float remainder = fmodf(arc_length, SET_CIRCLE_INDEX);
    if(remainder > 0.001f || point_count == 0)
    {
        state->recode_map[state->length_index].x = end.x;
        state->recode_map[state->length_index].y = end.y;
        state->length_index++;
    }
}

void mapbuild_tangent(guandao_state * state,  guandao_circle * para,Point p,  Phase dir_goal , Phase1 dir_cir)
{
    Point t1, t2 , t3[2];
    double dx[3] = {0} , dy[3] = {0} , angle[3] = {0};
    get_tangent_points_from_point(p, para->center, &t3[0], &t3[1]);

    dx[0] = para->center.x - p.x;
    dy[0] = para->center.y - p.y;
    dx[1] = t3[0].x - p.x;
    dy[1] = t3[0].y  - p.y;
    dx[2] = t3[1].x - p.x;
    dy[2] = t3[1].y  - p.y;
    for(uint8 i = 0 ; i < 3 ;i++)
    {
        angle[i] = atan2f( dx[i], dy[i]);
        while(angle[i] >M_PI)angle[i] = -M_PI;
    }
    if(!dir_goal)
    {
        t1 = t3[0] ; t2 = t3[1];
    }
    else
    {
        t2 = t3[0] ; t1 = t3[1];
    }
    if(!dir_cir&&!dir_goal)
    {
        mapbuild_line(state, p , t1);
        para->enter = t1;
        para->data.dir = 1;
    }
    else if(dir_cir&&!dir_goal)
    {
        mapbuild_line(state, p , t2);
        para->enter = t2;
        para->data.dir = 0;
    }
    else if(!dir_cir&&dir_goal)
    {
        cir_detail.cir_length[0][cir_detail.length_index] = INS.length_index;
        mapbuild_circle(state, para->enter, t1 ,para->center,  para->data.dir,  para->data.num);
        cir_detail.cir_length[1][cir_detail.length_index] = INS.length_index - 1;
        cir_detail.length_index++;
        mapbuild_line(state , t1 , p);
    }
    else if(dir_cir&&dir_goal)
    {
        cir_detail.cir_length[0][cir_detail.length_index] = INS.length_index;
        mapbuild_circle(state, para->enter, t2 ,para->center,  para->data.dir,  para->data.num);
        cir_detail.cir_length[1][cir_detail.length_index] = INS.length_index - 1;
        cir_detail.length_index++;
        mapbuild_line(state ,  t2 , p);
    }

}

    {
        dx = circle_p1[i+1].center.x -  circle_p1[i].center.x;
        dy = circle_p1[i+1].center.y -  circle_p1[i].center.y;
        distance_to_target  = hypotf(dx, dy);
        if(distance_to_target <= 2*COLUMU_R)
        {
            cir_detail.infor[i].err_route_flag =1;
            cir_detail.infor[i].v_down_flag = 1;
        }
    }

    Point start , end;
    uint16 length1 , length2 , length3 ,length4;;
    for(uint8 i = 0 ; i < circle_p1_length -1 ; i++)
    {
        if(cir_detail.infor[i].err_route_flag ==1 && circle_p1[i].data.out != circle_p1[i +1].data.in )
        {
            distance1 = distance_calcu(circle_p1[i].exit , circle_p1[i + 1].enter);
            add_index = (int)(distance1/SET_LINE_INDEX) + 1;
            minus_index = 2 * add_index;
            add_index = 5 * add_index;
            length1_index = cir_detail.cir_length[0][ i+1] + minus_index;
            length2_index = cir_detail.cir_length[1][i] - minus_index;
            for(int16 i = length1_index , j =  length2_index ; i < INS.length_index  ;i ++ , j++)
            {
                INS.recode_map[j] = INS.recode_map[i];
            }
            INS.length_index -= (add_index +1 );
            cir_detail.cir_length[1][i] -= minus_index;
            cir_detail.cir_length[0][i +1] = cir_detail.cir_length[1][i] +1;
            cir_detail.cir_length[1][i +1] -= add_index;
            for(uint8 m = i + 2 ; m < circle_p1_length -1 ; m++)
            {
                cir_detail.cir_length[0][ m] -=add_index;
                cir_detail.cir_length[1][ m] -=add_index;
            }

            for(uint16 m = cir_detail.cir_length[0][i] ; m < cir_detail.cir_length[1][ i + 1] ; m++)
            {
                dx = INS.recode_map[m+ 1].x -  INS.recode_map[m].x;
                dy = INS.recode_map[m + 1].y -  INS.recode_map[m].y;
                distance_to_target  = hypotf(dx, dy);
                if(distance_to_target > 0.4f)
                {
                        start.x = INS.recode_map[m].x;
                        start.y = INS.recode_map[m].y;
                        end.x = INS.recode_map[m + 1].x;
                        end.y= INS.recode_map[m + 1].y;
                        length3 = INS.length_index - m - 2;
                        for(uint16 i = 0 , j = m + 1 +1; i < length3  ; i ++ , j++)
                        {
                            route_buff[0][i] = INS.recode_map[j].x;
                            route_buff[1][i] = INS.recode_map[j].y;
                        }
                        length4 = INS.length_index;
                        INS.length_index = m +1;
                        length1 = m;
                        mapbuild_line(&INS , start , end);
                        length2 = INS.length_index- length1 -1 ;
                        for( uint16 i = 0 ; i < length3 ; i ++)
                        {
                            INS.recode_map[INS.length_index].x = route_buff[0][i];
                            INS.recode_map[INS.length_index].y = route_buff[1][i];
                            INS.length_index ++;
                        }
                        for(uint8 m = i + 1 ; m < circle_p1_length -1 ; m++)
                        {
                            cir_detail.cir_length[0][ m] +=length2;
                            cir_detail.cir_length[1][ m] +=length2;
                        }
                        break ;
                }
            }
        }
    }

    for(uint8 i = 0 ; i < circle_p1_length -1 ; i++)
    {
        if(circle_p1[i].data.out != circle_p1[i + 1].data.in &&cir_detail.infor[i].v_down_flag == 1)
        {
            for(uint16 m = cir_detail.cir_length[0][i] ; m <= cir_detail.cir_length[1][i + 1] ; m++ )
            {
                err_check[m] = 1;
            }
        }
    }

}

void portion1_speedstrategy(float * v)
{
    static uint8 p1_ssg = 0;
    static int state_record = 0;
    uint8 pre_index = 4;
    if(cir_detail.cur_index > cir_detail.length_index)return;
    if(INS.current_point_index + pre_index >= cir_detail.cir_length[0][cir_detail.cur_index])
    {
        cir_detail.cur_index ++;
    }
    switch(p1_ssg)
    {
        case 0:
            if(cir_detail.cur_index !=0 &&
                    cir_detail.infor[cir_detail.cur_index -1 ].v_down_flag ==1&&
                    circle_p1[cir_detail.cur_index -1].data.out != circle_p1[cir_detail.cur_index ].data.in)
            {
                state_record = cir_detail.cur_index - 1;
                p1_ssg = 1;
            }
            else if(cir_detail.cur_index !=0 && INS.current_point_index + pre_index + pre_index>= cir_detail.cir_length[0][cir_detail.cur_index - 1]
                                                                                                                &&INS.current_point_index  <= cir_detail.cir_length[1][cir_detail.cur_index - 1])
            {
                *v = 70;
            }
            break;
        case 1:
            if(cir_detail.cir_length[0][state_record] <=  INS.current_point_index+ pre_index  &&  INS.current_point_index <= cir_detail.cir_length[1][state_record + 1])
            {
                    *v = 70;
            }
            else if(INS.current_point_index > cir_detail.cir_length[1][state_record + 1])
            {
                p1_ssg  = 0;
            }
            break;
        default : break;
    }
}
