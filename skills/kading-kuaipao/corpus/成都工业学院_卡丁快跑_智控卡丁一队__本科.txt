主要符号表

绪论
研究背景
全国大学生智能汽车竞赛以智能模型汽车为载体，综合考察学生在机械结构、嵌入式系统、传感器融合、运动控制、图像处理及系统调试等方面的综合能力。科目三要求模型汽车采用视觉方案实现对队员的跟随，并在到达停车区域后完成自主返回发车区域的任务，因此系统既要具有稳定的视觉感知与跟随能力，又要具备脱离视觉目标后的自主导航能力。
作品设计思路
本作品采用TC264作为主控制器，以逐飞科技凌瞳摄像头获取环境视觉信息，以IMU660RA获取车辆角速度和加速度信息，并利用后轮双编码器获取车辆运动速度。前轮采用绝对值编码器与执行电机构成转向角闭环控制，使期望转角能够准确转换为实际前轮转角。系统将视觉跟随与惯性导航结合：去程以视觉目标为主要导航依据，IMU及编码器用于车辆姿态、速度和运动状态估计；到达停车区域后，系统记录的历史运动轨迹经反向处理后用于自主倒车返回。
报告主要内容
报告围绕模型车机械结构、硬件电路、视觉感知、惯性导航、轨迹记录、自主倒车、运动控制、软件设计以及调试测试展开。重点介绍IMU660RA姿态解算、基于速度与航向的二维位置估计、历史轨迹反向以及视觉与惯导协同控制方法。
模型车总体方案设计
系统总体架构
整车控制系统由视觉感知层、状态估计层、决策与控制层以及执行机构组成。凌瞳摄像头负责采集前方图像并提取队员目标；IMU660RA负责获取车体姿态变化信息；后轮两个编码器用于获得车轮运动反馈；前轮绝对值编码器用于检测实际转向角，并通过转向执行电机闭环实现精确打角。TC264完成多源信息处理、状态机管理和控制输出。
工作模式
系统设置发车初始化、视觉跟随、停车识别、轨迹保存、倒车回程和发车区停车等状态。视觉跟随状态下，车辆根据目标在图像中的横向位置和相对距离进行速度与转向控制；进入停车区后，系统保存有效轨迹并进行轨迹反向；倒车状态下，以历史轨迹点作为参考，同时使用IMU航向信息和编码器速度信息进行路径跟踪。
技术路线
系统技术路线为：视觉采集→目标检测→视觉误差计算→视觉跟随控制→IMU姿态融合→速度估计→二维位置积分→轨迹点记录→轨迹反向与重采样→动态目标点选择→航向约束路径跟踪→转向闭环与速度控制→自主倒车返回。
模型车机械结构设计
车模机械结构
模型车采用竞赛允许的基础车模进行机械改造。整体保持低重心和结构紧凑的设计原则，在保证转向机构运动范围的基础上，为主控板、摄像头、IMU、电源及编码器信号线路预留安装空间。
摄像头安装
凌瞳摄像头安装于车体前部较高位置，使其具有较大的前方视场范围，同时通过刚性支架降低车辆振动对图像稳定性的影响。摄像头安装方向与车体纵向中心线保持一致，便于建立图像坐标系与车辆坐标系之间的对应关系。
IMU安装
IMU660RA固定于车体刚性较好的中心区域，安装面尽量与车辆水平面保持一致，并使IMU坐标轴与车体坐标轴方向对应。通过机械固定降低松动和高频振动引起的测量误差。
转向机构
前轮转向采用执行电机驱动，并配置绝对值编码器检测实际转向角。控制器根据期望转角与实际转角之间的误差进行闭环调节，使车辆能够较准确地执行路径跟踪算法输出的目标转角。
硬件电路系统设计
主控制器



系统主控采用TC264。TC264承担图像数据处理、IMU数据读取、编码器采集、状态机运行、导航计算以及电机和转向执行器控制等任务。核心MCU及其配套开发板部分按照竞赛相关要求使用，不再对核心板内部电路进行重复展开。
视觉采集模块

凌瞳摄像头输出图像数据供主控进行目标区域检测。软件侧完成图像读取、目标区域筛选、目标中心提取及异常目标抑制，并输出视觉横向误差与距离相关信息。
惯性测量模块
 IMU660RA提供三轴陀螺仪与三轴加速度计数据。启动阶段进行静态零偏估计，运行过程中采用姿态融合算法获得稳定的姿态和航向信息。
编码器反馈系统
后轮设置两个编码器，分别采集左右后轮运动信息，通过脉冲计数及采样周期换算轮速，并结合车辆运动学关系得到车辆纵向速度。前轮设置一个绝对值编码器，实时获得转向机构实际角度，与转向执行电机共同形成前轮转角闭环。
电机与舵机执行
驱动电机负责车辆纵向运动，前轮转向执行电机根据控制器输出完成转向动作。控制系统将纵向速度控制和前轮转角控制分开设计，以提高整车运动控制的稳定性。

视觉跟随系统设计
图像采集与预处理
摄像头连续获取前方图像，在满足实时性的前提下对感兴趣区域进行裁剪，减少无关图像数据带来的计算负担。针对队员目标的视觉特征，对图像进行颜色、亮度及区域特征筛选，并通过连通区域分析得到候选目标。
凌瞳摄像头输出分辨率为160×120像素的灰度图像，帧频为50fps。图像采集通过DMA方式直接传输至内存缓冲区，CPU在帧中断触发后开始处理。感兴趣区域（ROI）设置为图像下半部分的160×80区域，该区域包含队员目标的主要信息，同时排除天空和远处环境的干扰。预处理流程包括高斯滤波去除图像噪声（3×3核）、亮度归一化补偿光照变化、颜色阈值分割提取队员服装颜色区域。颜色分割在HSV空间进行，根据队员服装颜色设定色相H、饱和度S和明度V的上下限阈值，将符合条件的像素标记为目标候选像素。阈值参数在不同光照环境下进行标定，并支持运行时根据图像平均亮度自适应调整V通道阈值。
目标中心计算
设目标区域的像素中心为(x_t,y_t)，图像中心横坐标为x_c，则视觉横向误差定义为e_x=x_t-x_c。通过目标区域面积、边界尺寸或其他稳定特征估计目标与车辆之间的相对距离，并形成距离误差e_d。
连通区域分析采用两遍扫描法：第一遍为每个连通区域分配临时标签并记录等价对，第二遍合并等价区域并计算各区域的面积、质心和外接矩形。对所有候选区域按面积降序排列，选取面积最大且满足宽高比约束（0.3至2.0之间）的区域作为目标区域。目标中心坐标(x_t, y_t)为该区域所有像素坐标的加权平均值。距离估计采用基于目标区域面积的经验模型：目标距离d=k/√A，其中A为目标区域像素面积，k为标定常数。标定时在已知距离（1m、2m、3m、4m）处测量目标面积，通过最小二乘法拟合得到k值。该模型在1-5m范围内估计误差小于10%，满足跟随控制需求。
视觉跟随控制
车辆转向控制综合考虑视觉横向误差、误差变化率以及惯导提供的车辆航向变化信息。纵向速度根据目标距离进行分级或连续调节，当目标距离较大时提高速度，当目标距离接近设定值时降低速度，从而保持相对稳定的跟随距离。
转向控制采用PD控制律：δ=Kp·e_x+Kd·(e_x-e_x_prev)/Δt，其中e_x为目标中心与图像中心的横向像素差，e_x_prev为上一帧横向误差。Kp和Kd根据车速自适应调整，高速时减小比例增益防止超调，低速时增大增益提高响应速度。横向误差经过归一化处理，将像素差转换为角度指令：δ_max对应图像半宽（80像素），即目标在图像边缘时输出最大转角。纵向速度控制采用三段式策略：当目标距离d>3m时以全速（1.2m/s）跟随；当1.5m<d≤3m时以0.8m/s跟随；当d≤1.5m时以0.4m/s跟随并准备停车。速度切换处加入斜坡过渡，避免加减速突变。
异常检测与滤波
为降低图像噪声和短时间误检的影响，目标检测采用面积阈值、位置连续性和多帧一致性进行筛选。对于瞬时丢失目标的情况，系统在限定时间内保持上一周期有效目标信息，并根据车辆状态进行速度限制，避免因单帧误检产生剧烈转向。
目标检测的异常处理机制包括多帧确认、面积突变检测和位置连续性校验。多帧确认要求目标在连续3帧中均被检测到才确认为有效目标，避免单帧噪声误触发；面积突变检测比较当前帧与上一帧目标面积，若变化率超过50%则判定为异常，保持上一帧目标信息；位置连续性校验限制目标中心在两帧间的移动距离不超过图像宽度的1/3，超出则认为目标丢失。目标丢失后进入保持模式，在1秒内继续使用最后一次有效目标信息进行控制，同时降低速度至0.3m/s；若超过1秒仍未恢复目标，则车辆减速停车并等待。横向误差信号经过一阶低通滤波（截止频率10Hz）处理，抑制图像噪声引起的控制抖动。

惯性导航系统设计
惯导系统总体方案
惯性导航模块是本作品自主回程方案的核心。系统利用IMU660RA获取车辆角速度和加速度，通过姿态融合得到航向角，再结合后轮编码器测得的车辆速度完成二维位置积分，从而连续建立车辆运动轨迹。
惯性导航系统的核心思想是通过对运动传感器数据的积分推算车辆位置。由于纯惯性导航存在随时间累积的位置漂移，本系统采用IMU与轮式编码器组合的方案：IMU提供高精度的航向角信息，编码器提供可靠的纵向速度信息，二者互补。航向角由IMU的陀螺仪积分获得，并通过加速度计进行姿态校正，短期精度高且不受地面条件影响；纵向速度由编码器直接测量，无累积误差。组合后的二维位置积分在短距离（<50m）范围内具有足够的精度，满足科目三自主回程的需求。系统导航坐标系取东-北平面，车辆初始位置设为原点，初始航向由车辆静止时的朝向确定。
Mahony姿态融合
系统采用四元数形式进行姿态更新。陀螺仪提供角速度积分，加速度计提供重力方向参考，通过比例积分校正陀螺仪长期积分产生的姿态误差。该方法计算量较小，适合TC264实时运行。
Mahony互补滤波器采用四元数表示姿态，其核心更新方程为：q̂=q⊗exp(½(ω+Kp·e+Ki·∫e dt)Δt)，其中ω为陀螺仪测量角速度，e为加速度计测量重力方向与估计重力方向之间的误差向量，Kp和Ki分别为比例和积分增益。比例项用于快速校正陀螺仪的瞬时误差，积分项用于估计并补偿陀螺仪零偏。本系统中Kp取2.0，Ki取0.005，采样周期为2ms。加速度计权重在车辆运动时动态调整：当检测到车辆线加速度较大时，降低加速度计权重以避免加速运动对重力方向估计的干扰，当车辆静止或匀速时恢复正常权重。四元数归一化在每次更新后执行，防止数值漂移。
车辆航向估计
通过姿态四元数计算车体航向角ψ，并对角度范围进行归一化处理。为避免角度跳变对控制器产生影响，航向误差采用最小角度差计算。
航向角由四元数转换得到，计算公式为ψ=atan2(2(q0q3+q1q2), 1-2(q2²+q3²))，输出范围为(-π, π]。在实际使用中，航向角需要连续输出而不出现跳变，因此采用角度展开处理：当相邻两帧航向角差值超过π时，通过加减2π使差值落在(-π, π]范围内，从而得到连续累积的航向角。航向误差的计算同样采用最小角度差原则：e_ψ=atan2(sin(ψ_ref-ψ), cos(ψ_ref-ψ))，确保控制器收到的误差信号始终在合理范围内。为进一步抑制航向漂移，系统在车辆直线行驶且转向角接近零时，利用编码器左右轮速差对航向角进行辅助校正。
速度与位置估计
由左右后轮编码器获得左右轮速度后，根据差速运动学关系计算车辆纵向速度。在离散采样周期Δt内，根据当前航向角将车体速度转换到导航坐标系，并进行位置积分：
左右后轮编码器分别安装在左右驱动轮轴上，每转脉冲数为1024，经4倍频后分辨率为4096脉冲/转。轮速计算采用M法：在固定采样周期Δt=10ms内计数脉冲数N，轮速v_wheel=2πr·N/(4096·Δt)，其中r为车轮半径。车辆纵向速度取左右轮速的平均值v=(v_l+v_r)/2，横摆角速度可由左右轮速差估算ω=(v_r-v_l)/B，其中B为轮距，该估算值用于与IMU陀螺仪交叉验证。位置积分采用一阶欧拉法，在每个导航周期（20ms）执行一次。为降低积分误差，系统在车辆静止时（速度小于0.05m/s）停止位置积分，避免零漂导致静止时位置缓慢移动。

轨迹记录
车辆运行过程中周期性保存(x,y,ψ,v,t)等状态量。当车辆进入有效运动状态时开始记录，停车或进入回程状态前结束记录。为控制存储量，可采用固定距离间隔而非固定时间间隔保存轨迹点，并对异常跳变点进行剔除。
轨迹记录采用距离触发机制，当车辆行驶距离超过10cm时保存一个轨迹点，而非固定时间间隔，这样在低速和高速时都能获得空间分布均匀的轨迹数据。每个轨迹点包含x坐标、y坐标、航向角ψ、车速v和时间戳t五个字段，数据类型为单精度浮点数，每个点占20字节。轨迹缓冲区大小为2000点，可记录最长约200m的行驶轨迹，远超科目三路线长度。记录起始条件为车辆速度超过0.1m/s且持续0.5s以上，结束条件为车辆进入停车状态。记录过程中实时检查轨迹点质量，若某点与前一点的距离超过最大可能行驶距离，则丢弃该点。

历史轨迹处理
到达停车区域后，将前进过程中获得的有效轨迹点按照时间顺序排列。回程时将轨迹序列反向，使终点成为回程起点、发车区成为回程终点。对于点间距离过小或存在明显跳变的点进行合并和剔除，以形成更加平滑的参考轨迹。
轨迹反向操作将轨迹点数组首尾交换，同时对每个轨迹点的航向角进行修正：回程时车辆运动方向与去程相反，因此目标航向角应在去程航向角基础上增加π（180°），并归一化到[-π, π]范围。异常点剔除采用速度和加速度判据：若相邻两点间的距离对应速度超过车辆最大速度的1.5倍，或航向角变化超过60°/采样周期，则判定为异常点并予以删除。点间合并采用距离阈值法，当相邻两点距离小于5cm时，将两点坐标取平均合并为一个点，以减少冗余数据。重采样采用等弧长插值法，在原始轨迹点之间进行三次样条插值，生成间距均匀（10cm）的参考轨迹点。
动态目标点选择
倒车控制不采用固定追踪相邻点的方法，而是依据车辆当前速度动态确定前视距离。可采用Ld=L0+kvv的形式，使低速时选择较近目标点、高速时选择较远目标点，从而兼顾跟踪精度与控制平滑性。
前视距离的动态调整是路径跟踪性能的关键。固定前视距离在低速时会导致目标点过近、转向过于敏感，在高速时会导致目标点过远、弯道跟踪滞后。采用Ld=L0+kv·v的线性模型后，低速（0.2m/s）时前视距离约0.38m，高速（0.6m/s）时前视距离约0.54m。目标点搜索算法从当前最近轨迹点索引开始，依次计算各点与车辆当前位置的距离，找到第一个距离大于等于Ld的轨迹点作为目标点。为提高搜索效率，记录上一帧目标点索引，下一帧从该索引附近开始搜索，通常只需遍历3-5个点即可找到新目标点。
航向约束
仅依靠位置误差追踪历史轨迹容易出现车辆提前切入或滞后进入弯道的问题，因此参考轨迹点同时保存目标航向。控制器综合位置误差与航向误差生成转向指令，使车辆不仅追踪目标位置，还能够保持与参考轨迹一致的运动方向。
航向约束的引入显著改善了弯道跟踪性能。仅使用位置误差时，车辆在进入弯道前不会提前转向，导致弯道内侧切入；出弯时位置误差减小但航向尚未回正，导致弯道外侧滞后。加入航向误差后，控制律变为δ=Kx·e_lat+Kψ·e_ψ，其中航向误差项在弯道入口处提前产生转向指令，在弯道出口处帮助回正方向。航向误差采用最小角度差计算：e_ψ=atan2(sin(ψ_ref-ψ), cos(ψ_ref-ψ))，确保误差范围在[-π, π]内，避免角度跳变。Kψ的取值根据车速自适应调整，高速时增大航向权重以提高方向稳定性。实验表明，加入航向约束后90°弯道的最大横向误差从25cm降低至8cm。
转向闭环控制
路径跟踪算法输出期望前轮转角δ_ref，绝对值编码器测得实际转角δ_real，二者形成闭环。转向执行器控制误差定义为eδ=δ_ref-δ_real，通过比例或PID控制输出执行电机指令。该结构可以降低机械间隙、负载变化及执行器响应差异对路径跟踪的影响。
转向闭环采用位置式PID控制，期望值为路径跟踪算法输出的δ_ref，反馈值为绝对值编码器测得的δ_real。PID参数通过阶跃响应实验整定，比例系数Kp=8.0，积分系数Ki=2.0，微分系数Kd=0.3。控制输出为转向执行电机PWM占空比，范围±100%。为防止执行器堵转，当转向角达到机械限位时切断电机输出。转向闭环的加入有效补偿了执行电机的死区、减速箱间隙和负载变化带来的非线性，使实际转向角与期望转角的稳态误差控制在0.5°以内。转向闭环以200Hz频率运行，高于路径跟踪的100Hz，确保转角能够快速跟踪期望指令。
倒车控制状态机
倒车过程依次执行轨迹初始化、目标点搜索、目标点跟踪、终点判断和停车五个阶段。车辆接近轨迹终点后逐步降低速度，当位置误差和航向误差同时满足设定条件时判定完成回程。
倒车控制状态机五个阶段的具体功能如下：轨迹初始化阶段完成轨迹反向、异常点剔除和重采样，设置倒车速度上限和控制参数；目标点搜索阶段计算当前位置到轨迹的最近点，并根据前视距离确定初始目标点；目标点跟踪阶段持续执行路径跟踪算法，实时更新目标点和控制输出；终点判断阶段当车辆距离最后一个轨迹点小于0.3m时激活，开始线性减速；停车阶段当位置误差小于5cm且航向误差小于5°时，切断电机输出并施加制动。状态转换均带有确认机制，避免单帧数据异常导致误切换。

车辆运动控制算法
速度控制
速度环以编码器反馈为主要依据，通过目标速度与实际速度之间的误差调节驱动电机输出。根据视觉跟随阶段和自主倒车阶段的任务特点分别设置速度上限。
速度环采用增量式PID控制算法，以100Hz周期运行。目标速度由上层决策模块根据当前运行模式和目标距离给定，实际速度由后轮编码器反馈计算得到。速度环输出为驱动电机PWM占空比，范围为-100%至+100%，正值对应前进、负值对应倒车。PID参数通过实验整定获得，比例系数Kp=2.5，积分系数Ki=0.8，微分系数Kd=0.1，并加入积分限幅防止启动时积分饱和。视觉跟随阶段速度上限设为1.2m/s，自主倒车阶段速度上限设为0.6m/s，停车阶段速度目标为0并加入制动占空比使车辆快速停止。速度环还包含前馈补偿项，根据目标加速度预先增加电机输出。
路径跟踪控制
路径跟踪控制综合横向位置误差和航向误差。基本控制形式可表示为δ=Kx·e_x+Kψ·eψ，其中参数根据车辆速度和曲率进行调整。对于高速状态适当增大前视距离，以降低舵机频繁动作。
横向位置误差的计算方法为：将目标点坐标转换到车体坐标系下，目标点在车体横轴方向的偏移量即为横向误差e_lat。航向误差e_ψ为目标航向角与当前航向角的最小角度差，范围限制在[-π, π]。转向控制律采用δ=Kx·e_lat+Kψ·e_ψ的形式，其中Kx和Kψ为速度自适应增益，低速时Kx较大以保证跟踪精度，高速时Kψ较大以保持航向稳定。前视距离Ld=L0+kv·v，其中L0为最小前视距离取0.3m，kv为速度系数取0.4s。当目标轨迹点的曲率较大时，系统自动减小前视距离并降低速度上限，以避免弯道驶出。转向角输出经过限幅处理，最大转角限制为±30°。
多模式控制
系统采用有限状态机实现控制模式切换，不同状态使用不同的速度上限、前视距离和误差权重，避免在视觉跟随与自主倒车之间直接复用同一组参数造成控制性能下降。
有限状态机包含初始化、待发车、视觉跟随、停车识别、轨迹保存、自主倒车和终点停车七个状态。各状态之间的转换条件如下：初始化完成后自动进入待发车状态；待发车状态检测到发车信号后进入视觉跟随状态；视觉跟随状态检测到停车区标识后进入停车识别状态，确认停车后保存轨迹并进入自主倒车状态；自主倒车状态检测到终点条件后进入终点停车状态。每个状态拥有独立的控制参数集，包括速度上限、前视距离系数、横向误差增益、航向误差增益和转向角限幅。状态切换时执行参数平滑过渡，在5个控制周期内线性插值到新参数，避免切换瞬间产生控制量跳变。

软件系统设计与程序实现
软件架构
软件采用模块化设计，主要包括系统初始化、摄像头驱动、视觉处理、IMU驱动、姿态融合、编码器采集、惯导计算、轨迹管理、路径跟踪、速度控制、转向闭环和状态机等模块。
各模块之间通过全局状态结构体和消息队列进行数据交互。视觉处理模块以摄像头帧中断为触发源，每帧完成后更新目标状态结构体；IMU驱动模块以1kHz定时器中断读取原始数据并送入姿态融合算法，姿态融合输出频率为500Hz；编码器采集模块利用输入捕获接口记录脉冲边沿时间，在100Hz控制周期内计算轮速；惯导计算模块以50Hz频率执行位置积分和轨迹记录；路径跟踪与速度控制模块以100Hz频率运行，读取最新的视觉、惯导和轨迹数据，计算转向角和电机PWM输出；状态机模块以10Hz频率运行，负责模式切换和异常处理。
主程序流程
系统上电后首先完成外设初始化与IMU零偏校准，然后进入待发车状态。车辆检测到启动条件后进入视觉跟随模式，同时持续运行惯导与轨迹记录任务；到达停车区后切换到自主回程模式；回程完成后进入终点停车状态。
主程序采用前后台架构，后台为无限循环，负责执行视觉处理、惯导计算、路径跟踪和状态机等非实时任务；前台为中断服务程序，负责IMU数据读取、编码器脉冲计数、摄像头帧同步和控制周期定时。中断服务程序仅执行数据采集和标志位置位，复杂算法在主循环中根据标志位执行，以保证中断响应时间小于10μs。系统上电后首先执行时钟配置、GPIO初始化、定时器配置和外设驱动加载，然后进行IMU零偏校准和编码器零点标定，校准完成后点亮就绪指示灯，等待发车信号。发车信号可通过按键触发或无线遥控触发。
核心程序设计
核心算法程序采用函数化结构，将姿态更新、导航更新、轨迹记录、目标点搜索和转向控制分别封装。附录A给出与本文算法对应的核心程序框架，正式提交前应使用参赛队伍实际工程代码替换或补充。
核心算法模块采用C语言实现，遵循模块化和可重入设计原则。姿态融合模块输入为三轴角速度和三轴加速度，输出为四元数和欧拉角，内部状态变量使用静态变量保存，支持固定步长调用；导航更新模块输入为航向角和左右轮速，输出为全局坐标位置，位置积分采用一阶欧拉法，在采样周期10ms时积分误差满足系统要求；轨迹记录模块采用环形缓冲区设计，最大支持2000个轨迹点，当缓冲区满时覆盖最旧数据，确保长距离运行不溢出；目标点搜索模块从当前最近点开始向后遍历，找到第一个距离大于前视距离的轨迹点作为目标点，搜索过程中记录索引位置以提高下一帧搜索效率。

制作、安装、调试与测试
制作过程
制作过程按照机械结构改造、传感器安装、电路连接、软件移植、单模块测试和整车联调的顺序进行。首先确定摄像头、IMU和控制板安装位置，再完成线束固定及电源分配，随后分别进行视觉、惯导、编码器和转向执行机构调试。
在机械结构改造阶段，重点对原车模的转向连杆、电机固定座和传感器安装支架进行加固处理。摄像头支架采用铝合金型材加工，通过螺栓固定于车头立柱上方，确保摄像头光轴与车体纵向平面平行；IMU安装座采用3D打印工艺制作，内部填充减震泡棉以降低电机高频振动对加速度计的干扰。电路连接阶段按照强电与弱电分离的原则进行布线，动力线与信号线分别走车体两侧，编码器信号线采用屏蔽双绞线并单端接地，以减少驱动电机PWM开关噪声对传感器信号的耦合干扰。
IMU调试
静止状态下记录IMU原始数据，计算陀螺仪零偏并建立启动校准流程；随后通过人工改变车体姿态验证姿态解算方向及角度连续性。车辆运动过程中重点观察航向角变化与实际转向方向是否一致。
IMU零偏校准采用上电后静止采样200个数据点取均值的方法，采样期间车体保持水平静止，校准完成后将零偏值写入非易失性存储器，避免每次上电重复校准。姿态验证时，分别将车体绕纵轴、横轴和竖轴旋转±90°，通过串口实时输出欧拉角曲线，检查角度变化方向是否与实际旋转一致、角度是否在旋转停止后保持稳定无漂移。航向角调试中，将车体在地面做整圈旋转，验证航向角在0°至360°范围内的连续性以及过零点时的归一化处理是否正确。
转向闭环调试
通过给定多个目标转角，记录绝对值编码器反馈的实际转角，逐步调整转向闭环参数，使执行器能够快速到达目标角度并减小稳态误差。
转向闭环调试采用阶跃响应法，依次给定±10°、±20°、±30°目标转角，记录绝对值编码器反馈曲线。调试中先调节比例增益使系统达到临界振荡状态，再逐步引入微分环节抑制超调，最后加入积分项消除稳态误差。调试完成后，转向系统在±30°范围内的阶跃响应上升时间控制在150ms以内，超调量小于10%，稳态误差小于0.5°。同时对左右极限位置进行机械限位标定，防止转向执行器过载。
视觉跟随调试
分别测试目标丢失、目标偏左、目标偏右以及目标距离变化等情况，根据目标中心误差调整转向控制参数，并通过多帧确认机制降低瞬时误检造成的控制抖动。
视觉跟随调试在不同光照条件下进行，包括室内荧光灯、室外自然光和逆光场景。调试中首先根据队员服装颜色确定HSV颜色空间的阈值范围，然后通过调整目标面积阈值和宽高比约束排除地面阴影和远处行人的干扰。转向参数整定采用从小到大逐步增加比例增益的方法，直至车辆在S形路线跟随中出现轻微振荡后回调20%。速度分级参数根据目标在图像中的纵向位置设定三档，确保停车时不发生碰撞。
自主倒车调试
先在低速条件下验证轨迹记录与轨迹反向功能，再逐步提高速度。测试重点包括位置积分误差、目标点选择、航向误差、弯道切入以及终点停车误差。正式报告应在本节补充实际测试曲线、数据表和最终参数。
自主倒车调试分为三个阶段：第一阶段在直线段验证轨迹记录与反向的正确性，记录去程和回程的位置偏差；第二阶段在含90°弯道的路线上测试动态前视距离和航向约束的效果，对比不同前视距离系数下的弯道切入误差；第三阶段进行全路线综合测试，统计连续10次运行的终点停车误差。调试中发现，当速度超过0.8m/s时弯道跟踪误差显著增大，因此将倒车阶段最高速度限制在0.6m/s。终点停车采用位置误差小于5cm且航向误差小于5°的双重判据。

调试问题与改进
在历史轨迹自主回程过程中，单纯增加轨迹点密度并不能从根本上解决弯道提前切入、滞后转向等问题。其原因在于车辆运动具有惯性，轨迹点本身存在定位误差，同时位置追踪与车辆航向之间存在耦合。因此，本方案通过轨迹点反向、动态前视距离、航向约束以及转向角闭环等方法进行综合改进。
调试过程中还发现以下典型问题及对应改进措施：一是IMU航向漂移导致长距离回程终点偏差，通过增加零偏校准时长和引入航向角高通滤波得到改善；二是视觉目标在队员转身或侧身时丢失率升高，通过扩大颜色阈值范围和增加目标轮廓特征匹配提高了检测鲁棒性；三是转向执行器在低温环境下响应变慢，通过在控制算法中加入温度补偿系数和适当降低转向速度上限解决；四是编码器在高速时出现丢脉冲现象，通过更换更高分辨率编码器和优化中断服务程序执行时间得到解决。

结论与展望
工作总结
本作品围绕科目三任务需求，设计了一套以TC264为核心、融合凌瞳视觉、IMU660RA惯性测量、后轮编码器速度反馈及前轮绝对值编码器转向闭环的智能模型汽车控制系统。车辆去程采用视觉跟随完成队员跟随任务，并持续记录车辆运动状态；到达停车区域后，通过历史轨迹反向与惯性导航路径跟踪实现自主倒车返回。
技术特点
本方案的主要特点包括：视觉与惯性信息协同使用；基于IMU与编码器建立二维历史轨迹；采用动态前视目标点改善路径跟踪平滑性；利用参考航向降低弯道提前切入和滞后转向；利用绝对值编码器构成前轮转角闭环，提高转向执行精度。
不足与展望
由于IMU积分存在累计误差，纯惯性位置估计的长期稳定性有限。后续可以进一步引入视觉里程计、赛道特征校正或其他绝对位置约束，对历史轨迹进行在线修正。同时，可根据车辆实时曲率、速度和目标距离进一步优化动态前视距离及速度规划策略。

附录A 核心算法程序
以下为与正文算法对应的核心程序框架示例。正式提交时建议用参赛队伍实际工程代码替换，并根据实际硬件接口补充驱动部分。
typedef struct
{
float x;
float y;
float yaw;
float speed;
} TrackPoint;

static TrackPoint track_points[MAX_TRACK_POINTS];
static int track_count = 0;

void INS_Update(float dt)
{
IMU660RA_Read(&imu);
Mahony_Update(imu.gyro_x, imu.gyro_y, imu.gyro_z,
imu.acc_x, imu.acc_y, imu.acc_z, dt);

navigation_yaw = GetYaw();

float vl = Encoder_GetSpeed(ENC_LEFT);
float vr = Encoder_GetSpeed(ENC_RIGHT);
navigation_speed = 0.5f * (vl + vr);

navigation_x += navigation_speed * cosf(navigation_yaw) * dt;
navigation_y += navigation_speed * sinf(navigation_yaw) * dt;
}

void Track_Record(void)
{
(navigation_speed < RECORD_SPEED_MIN)
return;

(DistanceFromLastPoint() < RECORD_DISTANCE)
return;

track_points[track_count].x = navigation_x;
track_points[track_count].y = navigation_y;
track_points[track_count].yaw = navigation_yaw;
track_points[track_count].speed = navigation_speed;
track_count++;
}

void Track_Reverse(void)
{
for (int i = 0; i < track_count / 2; i++)
    {
TrackPoint temp = track_points[i];
track_points[i] = track_points[track_count - 1 - i];
track_points[track_count - 1 - i] = temp;
    }
}

void Reverse_Control(void)
{
int target = FindLookAheadPoint();
float ex = track_points[target].x - navigation_x;
float ey = track_points[target].y - navigation_y;

float target_yaw = track_points[target].yaw;
float eyaw = Angle_Normalize(target_yaw - navigation_yaw);

float lateral_error =
-sinf(navigation_yaw) * ex +
cosf(navigation_yaw) * ey;

float target_angle =
_LAT * lateral_error +
_YAW * eyaw;

Steering_SetAngle(target_angle);
Speed_SetTarget(REVERSE_SPEED);
}

void Steering_ClosedLoop(float target_angle)
{
float actual_angle = Steering_Encoder_GetAngle();
float error = target_angle - actual_angle;

float output = STEER_KP * error
+ STEER_KI * Steering_Error_Integral()
+ STEER_KD * Steering_Error_Derivative();

Steering_Motor_Output(output);
}
