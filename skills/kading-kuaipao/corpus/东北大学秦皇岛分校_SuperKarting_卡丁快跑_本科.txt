第一章  引言
1.1  项目概述
本车用于第21届全国大学生智能汽车竞赛卡丁快跑组。车辆采用前轮转向、左右后轮独立驱动结构，以AURIX TC377为主要控制平台，完成视觉感知、惯性与卫星导航信息处理、车辆任务决策以及底盘闭环控制。设计重点是保证大尺寸车辆在较大惯量和室外环境下的控制稳定性，并使机械、电气和软件模块便于维护。[1]
1.2  报告内容
报告按照竞赛技术报告基本内容要求，依次介绍总体技术方案、机械与传感器安装、电气系统、控制软件与算法、开发调试过程以及主要技术参数；附录给出自制电路板原理图位置和核心算法源程序。本文不附加研究论文。

第二章  总体技术方案
2.1  系统总体结构
整车采用“传感器采集—状态估计—任务决策—底盘控制—执行机构”的分层结构。摄像头、IMU660RA、GNSS、后轮编码器和绝对转角传感器提供环境与车辆状态；上层任务产生目标速度和目标转角；底盘控制器完成左右后轮速度闭环和前轮转向闭环。

图2.1  智能卡丁车总体技术架构
2.2  主副控制器分工
主控制器负责高实时性的底盘控制、任务管理和主要导航计算；副控制器承担视觉处理及部分辅助功能。TC377多核任务进一步按实时性拆分，使5 ms底盘控制任务与视觉、显示等任务相互隔离。

第三章  机械结构与传感器安装
3.1  车体与部件布置
车模采用前轮转向、左右后轮独立驱动的卡丁车结构。控制板、电源管理板和驱动板固定在车体中部区域，IMU尽量靠近车辆刚体中心，GNSS天线布置在车体上方，摄像头朝向车辆前方。线束按照动力线与弱信号线分区布置，并通过固定点减小车辆振动造成的接口松动。

图3.1  车体主要部件与传感器安装示意
3.2  传感器安装
左右后轮分别安装1024线增量式编码器，用于5 ms周期的轮速反馈；转向机构安装欧艾迪OID-R2.3808B-17S1S绝对值编码器，用于测量等效前轮角。IMU660RA安装方向与车体坐标系保持一致；MT9V03X灰度摄像头用于视觉信息检测；GNSS模块用于车辆位置与速度相关信息。

第四章  电气系统设计
4.1  电气系统组成
整车共设计主板、电源管理板、通用驱动板、灯驱动板、灯屏、扬声器功率放大模块、麦克风运放板和按键板八类电路模块。各板通过统一供电与信号接口连接，便于单板测试和比赛现场更换。

图4.1  整车电气系统功能框图
4.2  电源管理与主板
车上24 V电池首先通过隔离DC/DC模块转换为12 V，12 V再由TPS5430降压形成5 V电源。电源板设置两路TPS5430降压支路，并配置肖特基二极管、电感及输入输出滤波电容；主板采用嘉立创四层板设计，板上RT9013将5 V转换为3.3 V，为IMU和其他3.3 V外设供电。
4.3  电机驱动板
转向与后轮驱动采用同一套通用驱动板，以减少备件种类并便于快速更换。单块驱动板集成两路HIP4082全桥栅极驱动器和IRFB4110PbF功率MOSFET，控制输入端加入SN74HC125PWR缓冲器，并通过栅极电阻、保护器件及母线滤波电容改善H桥开关质量。电机PWM频率为17 kHz。
4.4  灯光、声音与按键模块
灯驱动板采用Infineon TLD7002，使用12 V输入，并通过MP2315生成约7 V供相关电路使用；灯屏采用四层PCB。声音输出使用PAM8403功率放大芯片驱动2 W以上无源扬声器，麦克风前端采用LMV321放大微弱信号。按键板采用FSM101机械按键，按键信号配置4.7 kΩ上拉、470 Ω串联电阻及100 nF电容进行基础滤波，用于屏幕菜单控制。

第五章  控制软件与算法
5.1  5 ms底盘控制
CPU0以5 ms为基本底盘控制周期，即200 Hz。每个周期更新后轮编码器、转向角等反馈，进行链路安全检查，刷新目标速度与目标转角，然后执行后轮速度控制和转向控制。高频闭环任务与低频显示、菜单和任务逻辑分离。

图5.1  5 ms底盘控制流水线
5.2  后轮速度闭环
后轮控制采用速度前馈与PI修正相结合的结构。前馈根据目标轮速给出基础PWM，PI根据目标速度与实际速度的误差进行补偿。最终输出经过限幅、输出斜坡和换向保护后作用于H桥，从而兼顾响应速度和稳态误差。

图5.2  后轮“前馈+PI”速度控制结构

5.3  转向双环控制
转向控制使用绝对转角反馈。位置外环根据目标转角与实际转角误差给出目标角速度，角速度内环输出转向电机PWM，同时加入静摩擦补偿和输出限幅，以减轻低速死区与大角度快速转向时的过冲。

图5.3  转向位置—角速度双环控制结构
5.4  状态估计与Pure Pursuit返程
系统利用GNSS、IMU660RA和后轮里程信息获得车辆位置、速度和航向状态。科目三返程阶段根据记录路径搜索车辆投影点，并选取前瞻目标点Aim；通过车辆航向Yaw与Aim方向角计算方向误差α，再依据Pure Pursuit几何关系计算目标前轮角并进行限幅。

第六章  开发、制作与调试
6.1  开发工具
主控制器程序使用C语言开发，基于TC377相关底层驱动与工程框架进行二次开发；电路板使用嘉立创EDA完成原理图和PCB设计。调试过程中先完成电源和单板测试，再依次验证传感器、执行机构、底盘闭环和任务状态机。
6.2  制作与安装流程
•  分别完成八类自制电路板的原理图、PCB和单板通电检查。
•  验证24 V→12 V→5 V→3.3 V各级供电后再连接主控和传感器。
•  台架测试通用H桥驱动板的方向、PWM、温升和换向保护。
•  安装编码器、转向角传感器、IMU、GNSS和摄像头，并完成机械固定和线束应力释放。
•  先低速验证轮速环和转向环，再逐步开启完整任务。
6.3  典型调试问题
实车调试重点处理了编码器脉冲/方向毛刺、车辆振动导致的连接可靠性、转向机构静摩擦和回差、以及返程路径投影跳点等问题。软件中采用方向稳定确认、控制限幅、故障安全输出和路径搜索窗口约束等方法提高可靠性。

B.1  5 ms底盘控制任务
void ChassisControlTask_Run5ms(void)
{
    ChassisControlTask_UpdateSensors();

    if (ChassisControlTask_CheckEncoderOnline() == 0u)
    {
        return;
    }

    ChassisControlTask_UpdateTarget();
    ChassisFeedback_Update(g_target_base_speed);
    Control_Task();
}
B.2  后轮速度前馈
static int16_t RearWheelController_CalcFeedforward(
    float target_speed,
    float current_speed)
{
    float abs_speed = fabsf(target_speed);
    int32_t ff_abs;

    if (abs_speed <= 0.02f)
    {
        return 0;
    }

    ff_abs = MOTOR_STATIC_FRICTION_DUTY +
             (int32_t)(abs_speed * MOTOR_SPEED_FEEDFORWARD_GAIN);

    if (ff_abs > MOTOR_SPEED_FEEDFORWARD_MAX)
    {
        ff_abs = MOTOR_SPEED_FEEDFORWARD_MAX;
    }

    return (target_speed > 0.0f) ?
           (int16_t)ff_abs : (int16_t)(-ff_abs);
}
B.3  转向控制核心流程
void SteeringController_Update(
    SteeringController_t *controller,
    ControlMode_e mode,
    volatile float *target_steer,
    float current_angle)
{
    controller->angle = current_angle;
    SteeringController_UpdateSpeedEstimator(controller, current_angle);

    *target_steer = ControlMath_LimitFloat(
        *target_steer,
        STEER_RIGHT_LIMIT_DEG,
        STEER_LEFT_LIMIT_DEG);

    controller->error = *target_steer - current_angle;
    /* 位置外环产生目标角速度，角速度内环产生PWM；
       实际工程还包含中心死区、摩擦前馈和输出限幅。 */
}
B.4  科目三Pure Pursuit返程转角
static float Sub3_ReturnPurePursuitSteer(
    GPS_local_Point_struct position,
    GPS_local_Point_struct aim,
    float body_yaw)
{
    float aim_yaw = get_angle(position, aim);
    float alpha_deg = get_relative_angle(body_yaw, aim_yaw);
    float lookahead_distance = get_distance(position, aim);
    float alpha_rad = degree_to_rad(alpha_deg);

    if (lookahead_distance < SUB3_LOOKAHEAD_MIN_POINT_DISTANCE_M)
    {
        lookahead_distance = SUB3_LOOKAHEAD_MIN_POINT_DISTANCE_M;
    }

    float steer_rad = atanf(
        (2.0f * SUB3_WHEELBASE_M * sinf(alpha_rad)) /
        lookahead_distance);

    return Sub3_Clamp(
        rad_to_degree(steer_rad),
        -SUB3_MAX_STEER_DEG,
        SUB3_MAX_STEER_DEG);
}
