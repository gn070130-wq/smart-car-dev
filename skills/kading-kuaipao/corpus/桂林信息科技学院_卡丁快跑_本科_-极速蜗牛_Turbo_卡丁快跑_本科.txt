摘要
在第二十一届全国大学生智能汽车竞赛背景下，本文深入探讨了卡丁快跑车模型智能车系统的机械结构、硬件电路设计及软件开发流程。该系统以英飞凌TC387四核微控制器为核心，融合GPS与IMU姿态传感器数据进行多源信息融合，实现高精度自主导航。通过GPS模块采集实时经纬度坐标，结合IMU六轴陀螺仪解算的航向角，计算当前位置与规划路径之间的角度偏差，经由串级PID算法实现差速转向控制。同时，编码器实时检测车速并反馈至速度环PID，构成双闭环控制结构，实现了对车辆行驶速度与转向的精确调节。在硬件选型上，GPS模块采用华大北斗TAU1201，IMU选用逐飞科技IMU660RA六轴陀螺仪（不含MCU），编码器用于速度实时采集与反馈。此外，本文还对车模机械结构进行了针对性优化，以提升整体行驶稳定性与动态响应性能，为气垫式智能车的自主导航与控制提供了可行的工程设计方案。
关键词： 智能汽车，PID算法，GPS，IMU，TC387微控制器，编码器

2.2单片机模块
本卡丁快跑组电控系统采用英飞凌AURIX™ TC387作为主控芯片，该芯片是一款车规级高性能多核MCU，专为极致算力与功能安全而设计。TC387基于三核TriCore™架构（主频均达300MHz），集成6MB闪存与2.5MB SRAM，符合ASIL-D最高功能安全等级，配备锁步核与硬件安全模块（HSM），支持AES-128/256加密，确保固件防篡改与通信安全。
TC387提供丰富的数字与模拟外设：包括4路12位高速SAR ADC（转换时间＜1µs）、2路Δ-Σ ADC用于高精度电流采样，8个GTM（通用定时器模块）及24个PWM通道，可输出带死区互补的复杂电机控制信号，适配永磁同步电机（PMSM）的FOC算法；同时集成6路CAN-FD、12路LIN、4路QSPI、1路千兆以太网（TSN）及2路FlexRay，满足车载骨干网与实时诊断的高带宽需求。此外，芯片还提供丰富的GPIO接口、多个UART串口以及片上Flash存储资源，可满足复杂控制系统对存储与通信的多样化需求。
核心板主要用来处理GPS传感器、姿态传感器、摄像头采集到的信号，同时输出控制信号，根据GPS采集到的位置信息给出方向角，通过一定的计算后求得规划的行车路径，并根据 PID 算法对电机进行控制，同时它还控制速度参数的设定等工作，因此核心板是整个系统的控制中心。

2.3电源管理模块
小车采用铅蓄电池供电，标称电压为22.2V（6S），满电状态下供电电压可达27.6V。由于主控芯片、IMU、GPS模块、及电机驱动等各模块所需供电电压不尽相同，同时大功率电机启停时会产生较大的电压波动与纹波干扰，因此系统采用“逐级降压、分开供电”的电源管理策略，以兼顾转换效率与供电质量。

3.2机械结构优化
3.2.1前转向优化
卡丁快跑车辆在行驶过程中需要根据路径跟踪算法实时调整前轮转向角，因此转向机构不仅需要具备足够的转向响应速度，还需要能够准确获取当前转向角度，为闭环转向控制提供可靠的反馈信号。
初始方案采用普通直流电机作为转向执行机构。普通直流电机主要负责提供转向动力，但其本身无法直接获取电机轴或转向机构的绝对位置，因此无法准确判断当前前轮的实际转向角度。在采用闭环转向控制时，如果缺少位置反馈，控制系统只能根据电机的运行时间或 PWM 输出量估计转向位置，随着运行时间增加，误差会逐渐累积，难以满足卡丁快跑车辆对转向精度和重复性的要求。
因此，在转向电机上增加霍尔编码器，通过检测电机转轴的转动脉冲来获取电机的转动位置。主控芯片对霍尔编码器输出的脉冲信号进行计数，根据单位时间内的脉冲变化量可以获得电机的转动速度，通过累计脉冲数则可以计算电机的相对转动位置。

图3.2.1.1 卡丁快跑车转向电机结构
增加霍尔编码器后，转向系统由原来的开环控制转变为具有位置反馈的闭环控制结构。控制系统根据目标转向角与编码器反馈位置之间的误差调整转向电机，使实际转向角逐渐接近目标值。该方案结构简单、成本较低，能够满足初步的转向位置检测需求。
但在实际调试过程中发现，霍尔编码器采用脉冲计数方式获取位置，受到编码器分辨率、信号采样以及车辆高速运动过程中电机转速变化等因素影响，在部分情况下可能出现脉冲丢失或计数误差。当转向电机转动速度较高时，若编码器脉冲频率超过系统有效采集能力，就可能造成部分脉冲无法被正确识别，从而使累计位置产生偏差。随着转向动作次数增加，这种误差还可能进一步累积，最终导致编码器计算得到的转向位置与实际前轮转角之间产生较明显的偏差。
对于卡丁快跑车辆而言，转向角度直接影响车辆的行驶方向和路径跟踪效果。当转向角反馈出现较大误差时，控制系统无法准确判断车辆当前转向状态，容易出现转向不足、转向过量以及车辆在弯道中出现摆动等问题。因此，仅采用霍尔编码器难以满足高速运行状态下对转向角度检测精度和可靠性的要求。
针对上述问题，系统进一步对转向角度检测方案进行优化，将原有的霍尔编码器位置检测方案改为角度编码器直接测量转向机构的实际角度。与安装在电机侧的霍尔编码器相比，角度编码器可以直接获取转向机构的角度变化，减少了电机轴与实际车轮转向角之间由于机械传动间隙、安装误差以及编码器脉冲累计造成的误差。

图3.2.1.2 卡丁快跑角度传感器结构

3.2.2后轮结构优化
为了准确获取卡丁快跑车辆的实际行驶速度，在车辆后轮处设计并安装了专用的速度检测结构。相比直接通过电机转速估算车辆速度，将编码器安装在后轮能够更加直接地反映车辆的实际运动状态，减少电机与车轮之间传动机构对速度测量造成的影响。
在结构设计过程中，将编码器安装于后轮轮轴附近，并通过专用支架对编码器进行固定，使编码器与车轮保持可靠的机械连接。当车辆行驶时，后轮转动带动编码器同步转动，编码器输出与车轮转速对应的脉冲信号。主控芯片通过实时读取编码器脉冲数量，计算单位时间内车轮的转动圈数，进而得到车辆的实际行驶速度。
后轮速度检测结构主要由编码器、固定支架、连接机构以及后轮轮毂组成。编码器安装位置经过合理布置，保证其旋转轴与车轮旋转轴保持较好的同轴度，避免由于安装偏心造成额外的测量误差。同时，在支架设计中兼顾结构刚度和安装空间，使编码器能够稳定固定，并方便后期进行拆卸、维护和位置调整。

第四章 智能车软件控制设计
4.1 软件系统总体设计
卡丁快跑车模在比赛过程中需要完成路径记录、姿态测量、位置解算、速度控制和方向控制等多项任务。为保证车辆在高速行驶过程中的实时性与稳定性，软件系统采用模块化设计，将程序划分为底层驱动层、传感器数据处理层、状态估计层、路径规划与跟踪层以及运动控制层。
系统以主控芯片为核心，通过定时器建立固定周期的实时控制任务。编码器用于获取车辆在单位时间内的运动距离，并计算车辆当前行驶速度；IMU 姿态传感器用于获取车辆角速度及航向信息。软件根据编码器测得的位移增量和陀螺仪得到的航向角，对车辆在二维平面内的位置进行实时积分，从而获得车辆当前的相对坐标。
系统的软件控制流程主要包括以下几个部分：
系统初始化，包括主控芯片、定时器、编码器、IMU、PWM 和通信接口等外设初始化； 
IMU 数据采集与航向角解算； 
编码器数据采集与车辆速度、位移计算； 
基于航向角和位移增量的二维位置更新； 
参考路径数据读取与当前车辆位置匹配； 
根据当前位置和前方目标路径点计算目标航向角； 
根据实际航向角与目标航向角之间的偏差计算转向控制量； 
根据编码器反馈速度进行速度闭环控制； 
将速度控制量与转向控制量进行综合，输出至车辆驱动模块。 
整个软件系统采用定时器中断与主循环相结合的运行方式。其中，传感器采集、位置更新和实时控制等对时间要求较高的任务采用固定周期定时器执行；参数设置、状态显示及非实时通信等任务由主循环完成，从而避免显示和通信任务对核心控制任务造成较大影响。
4.2 卡丁快跑惯导定位与路径跟踪方案
4.2.1 惯导定位原理
卡丁快跑车辆在比赛过程中需要根据自身运动状态判断当前位置和行驶方向。由于车辆主要在赛道平面内运动，因此可以将车辆运动简化为二维平面运动，并建立以发车位置为原点的局部坐标系。
设车辆初始位置为：
P0​=(X0​,Y0​) 
车辆在一个控制周期内由编码器测得的运动距离为：ΔS 
陀螺仪测得车辆当前航向角为：ψ 
其中，规定车辆发车时航向为 0∘，航向角按照顺时针方向增加。
在本系统坐标系中，车辆沿 Y 轴正方向运动时航向角为 0∘，沿 X 轴正方向运动时航向角为 90∘。因此车辆在一个控制周期内的坐标增量为：
ΔX=ΔSsinψ ΔY=ΔScosψ 
经过连续积分后可以得到车辆当前的位置：
Xk​=Xk−1​+ΔX Yk​=Yk−1​+ΔY 
该方法不依赖外部视觉环境，可以在赛道环境变化较大的情况下持续获得车辆相对位置，因此适用于卡丁快跑车辆的连续运动状态估计。
原方案采用 GPS 与 IMU 融合进行位置和航向判断，但 GPS 数据存在更新频率和短时间波动等问题；而本项目实际控制过程中以 IMU 和编码器为主要实时定位信息，因此将编码器位移测量与陀螺仪航向信息结合进行航位推算。这样既可以充分利用编码器对车辆运动距离的直接测量能力，又可以利用陀螺仪的高频响应特性获取车辆实时航向变化。原报告中关于 GPS/IMU 寻点循迹的描述与当前方案不一致，因此在本章中进行调整。
4.2.2 编码器位移计算
车辆运动距离由编码器进行测量。系统在固定的 10 ms 控制周期内读取编码器累计值，并计算相邻两个控制周期之间的编码器增量：
ΔN=Nk​−Nk−1​ 
其中，Nk​ 为当前编码器累计值，Nk−1​ 为上一周期编码器累计值。
根据编码器每转对应的计数值以及车轮实际周长，可以得到单位编码器计数对应的车辆行驶距离：
Ks​=Nc​C​ 
其中，C 为车轮实际滚动周长，Nc​ 为车轮转动一周对应的有效编码器计数值。
因此车辆在一个 10 ms 控制周期内的实际运动距离为：
ΔS=Ks​ΔN 
在实际调试过程中，通过测量车辆在固定距离内的实际行驶距离与编码器累计值，对距离转换系数进行标定，以减小轮胎尺寸误差、轮胎变形、编码器安装误差以及机械传动误差对位置计算造成的影响。
4.2.3 航向角处理
IMU 通过陀螺仪获取车辆绕垂直方向的角速度，并经过积分得到车辆航向角。由于车辆在高速运动过程中会产生较明显的姿态变化，因此控制程序采用较高频率更新航向信息。
位置更新周期为 10 ms。为了减小离散积分过程中直接使用当前航向角造成的计算误差，在计算一个周期内车辆的位移时，采用前后两个时刻航向角的中间值作为车辆该周期内的平均航向角。
设上一周期航向角为：
ψk−1​ 
当前航向角为：
ψk​ 
则当前周期的平均航向角为：
ψm​=2ψk−1​+ψk​​ 
考虑到航向角存在 0∘ 与 360∘ 的周期跳变，在计算角度差时需要进行角度归一化处理，避免车辆从 359∘ 转动到 1∘ 时被错误判断为发生了 358∘ 的大幅转动。
最终使用平均航向角进行位置积分：
ΔX=ΔSsinψm​ ΔY=ΔScosψm​ 
这种处理方式能够减小固定采样周期下的离散化误差，提高车辆短时间位置计算的连续性。
4.2.4 位置误差抑制
纯航位推算方法具有计算简单、实时性高的优点，但其位置误差会随着车辆行驶距离增加而逐渐累积。造成位置误差的主要因素包括编码器测距误差、车轮打滑、轮胎有效周长变化以及陀螺仪零偏等。
因此，在系统设计过程中主要采取以下措施降低误差：
（1）编码器距离标定
通过实际测试车辆在固定距离内的编码器计数值，对编码器距离转换系数进行修正，使计算得到的累计距离尽可能接近车辆实际运动距离。
（2）陀螺仪零偏校准
车辆静止时对陀螺仪进行多次采样，计算角速度零偏，并在运行过程中进行补偿，降低零偏积分产生的航向角漂移。
（3）航向角中值积分
利用相邻两个控制周期的航向角中值计算车辆位移，减小由于固定采样周期产生的积分误差。
（4）异常数据检测
当编码器数据出现明显突变或者陀螺仪数据超出车辆正常运动范围时，对异常数据进行限制，防止单次错误数据直接影响位置积分。
（5）路径匹配修正
由于比赛赛道具有固定路线特征，因此车辆控制并不完全依赖绝对坐标，而是将当前估计位置与预先记录的参考路径进行匹配，得到车辆在赛道中的相对位置，从而降低累计位置误差对路径跟踪的影响。
通过以上措施，可以在保证实时性的同时，提高车辆在长距离运行过程中的位置估计稳定性。

4.4 车辆运动控制算法
4.4.1 控制系统总体结构
卡丁快跑车辆属于高速运动平台，控制系统既需要保证车辆能够准确跟踪目标路径，又需要保证车辆速度稳定。因此，本系统采用方向控制与速度控制相结合的闭环控制方式。
系统整体控制流程为：
参考路径 → 目标点 → 目标航向角 → 航向误差 → 转向控制器 → 电机控制
同时：速度设定值 → 速度控制器 → 编码器速度反馈 → 电机驱动
最终将速度控制量与方向控制量进行综合，实现车辆速度和方向的协调控制。

4.4.4 速度与方向协调控制
卡丁快跑车辆在直线路段和弯道路段具有不同的速度需求。若车辆始终以最高速度运行，在进入弯道时会由于惯性较大导致转向误差增加，因此系统根据路径曲率和航向误差对目标速度进行动态调整。
在直线路段，路径变化较小，车辆采用较高的目标速度，以提高整体运行效率；在弯道、掉头以及路径变化较大的区域，适当降低目标速度，使车辆获得更充足的转向控制余量。
同时，根据航向误差对速度进行限制：
当航向误差较小时，车辆保持较高速度；当航向误差增大时，自动降低目标速度。

通过速度与方向之间的协调控制，使车辆在保证路径跟踪精度的同时尽可能提高平均运行速度。
第五章 总结与展望
回虽然当前系统已经能够实现卡丁快跑车辆的自主运行，但在长距离高速运动过程中，基于编码器和陀螺仪的航位推算仍存在一定的位置累积误差。
后续可以从以下几个方面进一步优化。
（1）提高组合导航精度
目前车辆位置主要通过编码器和陀螺仪进行航位推算。随着运行距离增加，编码器测距误差和陀螺仪零偏会逐渐累积。后续可以进一步研究编码器、IMU 与 GPS 或其他绝对位置传感器的组合导航算法，通过外部位置数据对航位推算结果进行周期性修正，从而降低长期运行的位置漂移。
（2）完善 IMU 误差补偿
陀螺仪零偏、温度变化以及车辆振动都会影响航向角解算精度。后续可以增加车辆静止状态下的自动零偏校准，并研究温度补偿和数字滤波方法，提高高速运动状态下航向角数据的稳定性。
（3）提高路径跟踪算法性能
当前系统主要根据最近路径点和前视目标点进行路径跟踪。后续可以进一步研究 Pure Pursuit、Stanley 等车辆路径跟踪算法，根据车辆速度和赛道曲率动态调整前视距离，使车辆在高速弯道中具有更好的路径跟踪性能。
（4）实现更加完善的速度规划
当前速度主要根据不同路径段进行设置。后续可以根据路径曲率、车辆航向误差以及车辆最大横向加速度建立更加完善的速度规划模型，使车辆能够在保证安全和稳定的前提下尽可能提高平均速度。
（5）提高系统工程可靠性
在实际比赛过程中，车辆会受到振动、电源波动以及电磁干扰等因素影响。后续可以进一步完善异常数据检测、传感器故障处理、通信异常保护和电机失控保护等机制，提高车辆在复杂比赛环境中的可靠性。
总体而言，卡丁快跑智能车的设计是机械结构、电子硬件、传感器技术、嵌入式软件和自动控制算法相结合的综合性工程。后续通过进一步优化组合导航、路径跟踪和速度规划算法，可以在保持车辆运行稳定性的基础上进一步提高车辆的平均运行速度和赛道完成效率。

// 数组数据解析
//-------------------------------------------------------------------------------------------------------------------
void Nag_Decode(int32 raw, float *yaw, int8 *dir)
{
    *yaw = (raw & 0x00FFFFFF) / 100.0f;

    *dir = (int8)(raw >> 24);

    if(*dir != 1 && *dir != -1)
    {
        *dir = 1;
    }
}


//-------------------------------------------------------------------------------------------------------------------
// 惯导路线复现（插值平滑版）
//-------------------------------------------------------------------------------------------------------------------
void Nag_Read(void)
{
    static uint8 Dir_flag=0;
    float t;
   float yaw_diff;
   float yaw_change;

   //==================== 初始化 ====================//

   if(Run_Index == 0 && Nag_ResdPoint_Flag > 1)
   {
       // 起点Yaw
       Nag_Decode(Nag_data2[0],&Yaw_Start,&Nag_Target_Dir);

       // 终点Yaw
       Nag_Decode(Nag_data2[1],&Yaw_End,&Nag_Target_Dir);
       Yaw_Target = Yaw_Start;
       Last_Yaw_Target = Yaw_Start;
       Last_Dir = 0;
       Run_Index = 1;
       Last_Encoder_Read =Read_Encoder_Aggregate_Value(TIM5_ENCODER);

   }

   //================================================//

   Read_Continue_Encoder_Left=Read_Encoder_Aggregate_Value(TIM5_ENCODER);
   // 当前段行驶距离
   delta2 =Read_Continue_Encoder_Left - Last_Encoder_Read;

   //==================== 插值 ====================//
   // 当前段完成比例
   t = (float)abs(delta2) / (float)Nag_Set_mileage;

   if(t > 1.0f)
   {
       t = 1.0f;
   }

   // 计算最短角度差
   yaw_diff =angle_diff(Yaw_End,Yaw_Start);

   // 按最短方向插值
   Yaw_Target = Yaw_Start + yaw_diff * t;

   // 限制到0~360

   if(Yaw_Target >= 360.0f)
   {
       Yaw_Target -= 360.0f;
   }

   if(Yaw_Target < 0.0f)
   {
       Yaw_Target += 360.0f;
   }

   //==================== 环形限幅 ====================//

   // 注意：
   // 必须用 angle_diff
   // 不能直接减
   yaw_change = angle_diff(Yaw_Target,Last_Yaw_Target);
   // 限制每次变化量

   if(yaw_change > YAW_MAX_CHANGE)
   {
       yaw_change = YAW_MAX_CHANGE;
   }

   if(yaw_change < -YAW_MAX_CHANGE)
   {
       yaw_change = -YAW_MAX_CHANGE;
   }
   // 重新生成Yaw_Target

   Yaw_Target = Last_Yaw_Target + yaw_change;
   // 限制到0~360

   if(Yaw_Target >= 360.0f)
   {
       Yaw_Target -= 360.0f;
   }

   if(Yaw_Target < 0.0f)
   {
       Yaw_Target += 360.0f;
   }

   // 保存
   Last_Yaw_Target = Yaw_Target;

   //================================================//

   if((Last_Dir * Nag_Target_Dir) == -1 && !Dir_flag)
   {
       Dir_flag=1;
       Back_Motor_SetPwm(0,0);
       system_delay_ms(1000);
   }
   //==================== 控制 ====================//
   if(Nag_Target_Dir == 1)
   {
       // 前进
       Angle_Target_Position = -GPS_IMU_PID_Start(Open,angle_diff(Yaw_Target,Yaw),0);
       Back_Motor_SetPwm(300,300);
   }
   else
   {
       // 后退
       Angle_Target_Position =GPS_IMU_PID_Start(Open,angle_diff(Yaw_Target,Yaw),0);
       Back_Motor_SetPwm(-300,-300);
   }

   //================================================//




   //==================== 切换下一段 ====================//

   if(abs(delta2) >= Nag_Set_mileage)
   {
       Run_Index++;

       Last_Dir = Nag_Target_Dir;
       // 已结束
       if(Run_Index >= Nag_ResdPoint_Flag - 1)
       {
           Back_Motor_SetPwm(0,0);
           Angle_Target_Position = 0;
           return;
       }

       // 当前终点变下一段起点
       Yaw_Start = Yaw_End;

       // 下一段终点
       Nag_Decode(Nag_data2[Run_Index],&Yaw_End,&Nag_Target_Dir);
       Last_Encoder_Read = Read_Continue_Encoder_Left;
   }

       //================================================//
}


void Nag_ReversePath(void)
{
    int32 reversed_data[NagPoint_MAX];
    float yaw;
    int8 dir;
    float reversed_yaw;
    int8 reversed_dir;

    if(Nag_ResdPoint_Flag == 0) return;

    for(int i = 0; i < Nag_ResdPoint_Flag; i++)
    {
        // 取正向的第 (总点数-1-i) 个点
        uint32 src_index = Nag_ResdPoint_Flag - 1 - i;
        Nag_Decode(Nag_data2[src_index], &yaw, &dir);

        // 角度转180°
        reversed_yaw = yaw + 180.0f;
        if(reversed_yaw >= 360.0f) reversed_yaw -= 360.0f;

        // 方向保持前进（dir已经是1，因为正着走）
        reversed_dir = 1;  // 始终前进

        // 重新打包
        reversed_data[i] = (reversed_dir << 24) | (int32)(reversed_yaw * 100);
    }

    // 覆盖原数组
    for(int i = 0; i < Nag_ResdPoint_Flag; i++)
    {
        Nag_data2[i] = reversed_data[i];
    }
}

int32 Pack_XY(int16 x_cm, int16 y_cm)  //打包数据函数
{
    // 将X左移16位放入高16位
    // Y直接放入低16位

    return ((int32)x_cm << 16)
            | ((uint16)y_cm);
}


void Unpack_XY(int32 data,int16 *x_cm,int16 *y_cm)  //解析数据包函数
{
    // 右移16位得到X
    *x_cm = (int16)(data >> 16);

    // 直接取低16位得到Y
    *y_cm = (int16)data;
}

void Navigation_Update(void)
{
    // 保存上一次编码器值
    static int32_t last_encoder = 0;

    //--------------------------
    // 读取编码器
    //--------------------------

    int32_t now_encoder;

    now_encoder =
        Read_Encoder_Aggregate_Value(
            TIM5_ENCODER);

    // 本周期编码器增量
    int32_t delta_encoder;

    delta_encoder =
        now_encoder
        - last_encoder;

    last_encoder =
        now_encoder;

    //--------------------------
    // 计算行驶距离
    //--------------------------

    float ds;

    ds =
        delta_encoder
        * WHEEL_C
        / ENCODER_PPR;

    //--------------------------
    // 平均航向
    //--------------------------

    float delta_yaw;

    delta_yaw =angle_diff(Yaw,last_yaw);

    float yaw_avg;

    yaw_avg =
        last_yaw
        + delta_yaw / 2.0f;

    last_yaw = Yaw;

    //--------------------------
    // 转弧度
    //--------------------------

    float yaw_rad;

    yaw_rad =
        yaw_avg
        * PI
        / 180.0f;

    //--------------------------
    // 更新位置
    //--------------------------

    pos_x +=
        ds * sinf(yaw_rad);

    pos_y +=
        ds * cosf(yaw_rad);
}

/************************************************************
 * 函数名称: 纯编码器和陀螺仪转二维坐标函数
 * 功能说明: 利用编码器计算10ms内移动距离，
 *           利用前后两次Yaw的中值进行二维坐标积分
 * 参数说明: 无
 * 函数返回: 无
 * 修改时间: 2026年8月11日
 * 备注: 放中断执行，10ms
 ************************************************************/
float INS_X = 0.0f;          // X坐标(m)
float INS_Y = 0.0f;          // Y坐标(m)
float INS_Yaw = 0.0f;        // 当前航向角(rad)

int32 INS_Last_Encoder = 0;  // 上次编码器值
float INS_Last_Yaw = 0.0f;   // 上一次航向角(rad)

void INS_Update(void)
{
    /* 读取累计编码器 */
    int32 Encoder_Now = (Read_Encoder_Aggregate_Value(TIM5_ENCODER) + Read_Encoder_Aggregate_Value(TIM2_ENCODER))/2;

    /* 计算编码器增量 */
    int32 delta_encoder = Encoder_Now - INS_Last_Encoder;

    /* 保存本次编码器值 */
    INS_Last_Encoder = Encoder_Now;

    /* 脉冲转距离 */
    float ds = (WHEEL_C / 2048.0f) * delta_encoder;

    /* 当前Yaw（映射值）：角度 → 弧度 */
    float Yaw_Now = Yaw_Mapped * PI / 180.0f;

    /*
     * 处理Yaw 0°/360°跳变
     * 例如：
     * 上一次 = 359°
     * 当前   = 1°
     * 不能直接平均成180°
     */
    float yaw_diff = Yaw_Now - INS_Last_Yaw;

    if (yaw_diff > PI)
    {
        yaw_diff -= 2.0f * PI;
    }
    else if (yaw_diff < -PI)
    {
        yaw_diff += 2.0f * PI;
    }

    /* 得到10ms期间的中间Yaw */
    float Yaw_Mid = INS_Last_Yaw + yaw_diff * 0.5f;

    /* 更新二维坐标 */
    INS_X += ds * sinf(Yaw_Mid);
    INS_Y += ds * cosf(Yaw_Mid);

    /* 保存当前Yaw，供下一次使用 */
    INS_Last_Yaw = Yaw_Now;

    /* 保存当前航向角 */
    INS_Yaw = Yaw_Now;
}


/************************************************
 *  函数名称: 计算俩个坐标之间的距离
 *  功能说明：
 *  参数说明： x1, y1：出发点坐标；x2, y2：目标点坐标；
 *  参   数：无
 *  函数返回：无
 *  修改时间：2026年6月17日
 *  备   注：单位（m）
 ************************************************/
float Get_Two_Point_Distance(float x1, float y1,float x2, float y2)
{
    float dx = x2 - x1;
    float dy = y2 - y1;

    return sqrtf(dx * dx + dy * dy);
}


/************************************************
 *  函数名称: 计算俩个坐标之间的角度
 *  功能说明：
 *  参数说明：x1, y1：出发点坐标；x2, y2：目标点坐标；
 *  参   数：无
 *  函数返回：无
 *  修改时间：2026年6月17日
 *  备   注：范围0-360
 ************************************************/
float Get_Target_Angle(float x1, float y1,float x2, float y2)
{
    float dx = x2 - x1;
    float dy = y2 - y1;

    // 注意参数顺序！
    float angle = atan2f(dx, dy) * 180.0f / PI;

    // 转成 0~360°
    if(angle < 0)
        angle += 360.0f;

    return angle;
}

// 【新增】修点路径图静态缓冲（避免大数组占用栈空间）
static int16 INS_path_sx[NagPoint_MAX];
static int16 INS_path_sy[NagPoint_MAX];

// 【新增】绘制当前 INS 路线的路径图（X/Y 平面坐标），并高亮选中点
void INS_Draw_Path(void)
{
    int i;
    int n = INS_Resd_Point_Count;

    if(n <= 1)
    {
        return;   // 点数不足，无法画图
    }

    // 1. 求所有点的 X/Y 范围（单位 m）
    float min_x = (float)(int16)(INS_data2[0] >> 16) / 100.0f;
    float max_x = min_x;
    float min_y = (float)(int16)(INS_data2[0] & 0xFFFF) / 100.0f;
    float max_y = min_y;

    for(i = 1; i < n; i++)
    {
        float xi = (float)(int16)(INS_data2[i] >> 16) / 100.0f;
        float yi = (float)(int16)(INS_data2[i] & 0xFFFF) / 100.0f;
        if(xi < min_x) min_x = xi;
        if(xi > max_x) max_x = xi;
        if(yi < min_y) min_y = yi;
        if(yi > max_y) max_y = yi;
    }

    float w = max_x - min_x;
    float h = max_y - min_y;
    if(w < 0.05f) w = 0.05f;
    if(h < 0.05f) h = 0.05f;

    // 2. 显示区域（屏幕中下部，避开顶部文字和底部提示）
    int16 rx = 8;
    int16 ry = 100;
    int16 rw = 224;
    int16 rh = 180;

    // 3. 等比缩放 + 居中
    float scale = (w / rw > h / rh) ? (rw / w) : (rh / h);
    float ox = (rw - w * scale) / 2.0f;
    float oy = (rh - h * scale) / 2.0f;

    // 4. 计算各点屏幕坐标
    for(i = 0; i < n; i++)
    {
        float xi = (float)(int16)(INS_data2[i] >> 16) / 100.0f;
        float yi = (float)(int16)(INS_data2[i] & 0xFFFF) / 100.0f;
        INS_path_sx[i] = rx + (int16)((xi - min_x) * scale + ox);
        INS_path_sy[i] = ry + (int16)(rh - (yi - min_y) * scale - oy);  // 翻转Y
    }

    // 5. 画路径连线
    for(i = 0; i < n - 1; i++)
    {
        ips200_draw_line(INS_path_sx[i], INS_path_sy[i],
                         INS_path_sx[i+1], INS_path_sy[i+1], RGB565_WHITE);
    }

    // 6. 画点：普通点小圆，选中点黄色双圈高亮，标记点青色
    for(i = 0; i < n; i++)
    {
        if(i == INS_Edit_Point)
        {
            ips200_draw_circle(INS_path_sx[i], INS_path_sy[i], 5, RGB565_YELLOW);
            ips200_draw_circle(INS_path_sx[i], INS_path_sy[i], 6, RGB565_YELLOW);
            if(INS_point_mark[i])  // 选中点同时被标记，再加青色外圈
            {
                ips200_draw_circle(INS_path_sx[i], INS_path_sy[i], 8, RGB565_CYAN);
            }
        }
        else if(INS_point_mark[i])
        {
            ips200_draw_circle(INS_path_sx[i], INS_path_sy[i], 4, RGB565_CYAN);  // 【新增】标记点
        }
        else
        {
            ips200_draw_circle(INS_path_sx[i], INS_path_sy[i], 2, RGB565_GRAY);
        }
    }
}

void INS_Point_Edit(void)
{
    int enc;
    int32 pack;
    int16 x, y;
    int i;

    // 旋钮采样（每帧一次，累计步数）
    menu_encoder_update();

    // ---- key1：循环切换 空闲 → 修X → 修Y → 空闲 ----
    if(key1_flag)
    {
        // ---- 全屏重绘（修点模式下车是停着的，重绘开销可接受）----
        ips200_clear();
        key1_flag = 0;
        switch(INS_edit_state)
        {
            case INS_EDIT_IDLE: INS_edit_state = INS_EDIT_X;    break;
            case INS_EDIT_X:    INS_edit_state = INS_EDIT_Y;    break;
            case INS_EDIT_Y:    INS_edit_state = INS_EDIT_IDLE; break;
            default:            INS_edit_state = INS_EDIT_IDLE; break;
        }
        Buzzer_check(30);
    }

    // ---- key2：保存写回当前线路 flash ----
    if(key2_flag)
    {
        // ---- 全屏重绘（修点模式下车是停着的，重绘开销可接受）----
        ips200_clear();
        key2_flag = 0;
        INS_FlashWrite_Edit();
        Buzzer_check(50);
    }

    // ---- key3：标记/取消标记当前点（整体修点用）----
    if(key3_flag)
    {
        ips200_clear();
        key3_flag = 0;
        if(INS_Resd_Point_Count > 0)
        {
            INS_point_mark[INS_Edit_Point] = !INS_point_mark[INS_Edit_Point];  // 切换标记
        }
        Buzzer_check(30);
    }

    // ---- key4：清除所有标记点 ----
    if(key4_flag)
    {
        ips200_clear();
        key4_flag = 0;
        for(i = 0; i < INS_Resd_Point_Count; i++)
        {
            INS_point_mark[i] = 0;
        }
        Buzzer_check(30);
    }

    // ---- 旋钮 ----
    enc = menu_encoder_get_change();
    if(enc != 0)
    {
        ips200_clear();   // 【新增】有改动就清屏，避免路径图残影
        if(INS_Resd_Point_Count <= 0)
        {
            // 没有路线数据，忽略旋钮
        }
        else if(INS_edit_state == INS_EDIT_IDLE)
        {
            // 空闲态：切换选中点，循环
            INS_Edit_Point += enc;
            while(INS_Edit_Point >= INS_Resd_Point_Count) INS_Edit_Point -= INS_Resd_Point_Count;
            while(INS_Edit_Point < 0) INS_Edit_Point += INS_Resd_Point_Count;
        }
        else
        {
            // 判断是否有标记点：有 → 整体移动所有标记点；无 → 只移当前点
            uint8 has_mark = 0;
            for(i = 0; i < INS_Resd_Point_Count; i++)
            {
                if(INS_point_mark[i]) { has_mark = 1; break; }
            }

            if(has_mark)
            {
                // 【新增】整体修点：所有标记点一起 ±1cm
                for(i = 0; i < INS_Resd_Point_Count; i++)
                {
                    if(INS_point_mark[i])
                    {
                        pack = INS_data2[i];
                        x = (int16)(pack >> 16);
                        y = (int16)(pack & 0xFFFF);
                        if(INS_edit_state == INS_EDIT_X) x += (int16)enc;
                        else                              y += (int16)enc;
                        INS_data2[i] = (((uint32)(uint16)x) << 16) | ((uint16)y);
                    }
                }
            }
            else
            {
                // 单点修：只移当前点
                pack = INS_data2[INS_Edit_Point];
                x = (int16)(pack >> 16);
                y = (int16)(pack & 0xFFFF);
                if(INS_edit_state == INS_EDIT_X) x += (int16)enc;
                else                              y += (int16)enc;
                INS_data2[INS_Edit_Point] = (((uint32)(uint16)x) << 16) | ((uint16)y);
            }
        }
    }

    // 路径图（含选中点高亮）
    INS_Draw_Path();

    // ---- 文字信息 ----
    pack = (INS_Resd_Point_Count > 0) ? INS_data2[INS_Edit_Point] : 0;
    x = (int16)(pack >> 16);
    y = (int16)(pack & 0xFFFF);

    //ips200_show_string(0, 16*0, "Route:");  ips200_show_int(60, 16*0, current_route_index + 1, 1);
    ips200_show_string(0, 16*1, "Edit");    // 修点状态标签
    ips200_show_string(0, 16*2, "N:");      ips200_show_int(30, 16*2, INS_Edit_Point, 3);
    ips200_show_string(0, 16*3, "X:");      ips200_show_int(30, 16*3, x, 6);   // 当前点 X（cm）
    ips200_show_string(0, 16*4, "Y:");      ips200_show_int(30, 16*4, y, 6);   // 当前点 Y（cm）

    if(INS_edit_state == INS_EDIT_X)      ips200_show_string(120, 16*1, "X");
    else if(INS_edit_state == INS_EDIT_Y) ips200_show_string(120, 16*1, "Y");
    else                                  ips200_show_string(120, 16*1, "-");

    ips200_show_string(0, 16*18, "K1:mode K2:save K3:mark K4:clr");
}

void reverse_path_xy(int32 *path, int32 len)  //二维坐标反转函数
{
    if(len == 0) return;

    int16 end_x = (int16)(path[len - 1] >> 16);
    int16 end_y = (int16)(path[len - 1] & 0xFFFF);

    // 倒序
    for(uint16 i = 0; i < len / 2; i++)
    {
        uint32 temp = path[i];
        path[i] = path[len - 1 - i];
        path[len - 1 - i] = temp;
    }

    // 去掉新的起点并坐标变换
    for(uint16 i = 0; i < len - 1; i++)
    {
        int16 x = (int16)(path[i + 1] >> 16);
        int16 y = (int16)(path[i + 1] & 0xFFFF);

        x -= end_x;
        y -= end_y;

        path[i] = (((uint32)(uint16)x) << 16) |
                   ((uint16)y);
    }

    // 最后一个目标点：原来的(0,0)
    path[len - 1] =
        (((uint32)(uint16)(-end_x)) << 16) |
         ((uint16)(-end_y));
}


int32 total = 0;  // 总点数
/************************************************
 *  函数名称: INS_OneKeyReturn
 *  功能说明：一键原路返回，不经过Flash，直接从内存取数据
 *           1. 将录制数据从 INS_data 拷贝到 INS_data2
 *           2. 反转坐标路径（倒序 + 坐标变换到当前位置为原点）
 *           3. 重置INS原点为当前位置
 *           4. 启动路径复现
 *  使用方法：倒车录制结束后，按一个键，车自动原路返回
 ************************************************/
void INS_OneKeyReturn(void)
{
    // 1. 先根据当前线路索引从Flash读取对应路线数据
    INS_FlashRead();

    if(INS_Resd_Point_Count == 0) return;

    // 2. 停止录制
    INS_Flag = 0;
    // 4. 重置复现状态
    next = 0;

    // 5. 启动路径复现
    dispatch_car = 1;
    Camera_Navigation_Motor_flag = 1;
    Back_Motor_Set_Speed = -200;
    Back_Motor_SetPwm(-200, -200);
    INS_Flag = 3;
}


float INS_two_points_distance = 0;


/************************************************
 *  函数名称: INS_track_oneway
 *  功能说明：单向路径复现（只有前进，无后退段）
 *           配合 INS_OneKeyReturn 使用
 ************************************************/
void INS_track_oneway(void)
{
    int16 total = (int16)INS_Resd_Point_Count;

    int32 pack = INS_data2[next];
    int16 x_int = (int16)(pack >> 16);
    int16 y_int = (int16)(pack & 0xFFFF);
    float x = x_int / 100.0f;
    float y = y_int / 100.0f;
    
    // 最后一个点Y坐标偏移
    if(next == total - 1)
    {
        y += LAST_POINT_Y_OFFSET_CM * 0.01f;
    }
    
    float INS_Error = 0;
    float INS_azimuth = 0;

    ips200_show_int( 80, 16*2, total, 3);

    INS_two_points_distance = Get_Two_Point_Distance(INS_X, INS_Y, x, y);
    INS_azimuth = Get_Target_Angle(INS_X, INS_Y, x, y);

    ips200_show_int(0, 100, next, 2);

    ips200_show_string(0, 16*3, "x:");
    ips200_show_string(0, 16*4, "Y:");
    ips200_show_float(60, 16*3, x, 3, 1);
    ips200_show_float(60, 16*4, y, 3, 1);

    ips200_show_string(0, 16*5, "INS_X:");
    ips200_show_string(0, 16*6, "INS_Y:");
    ips200_show_float(60, 16*5, INS_X, 3, 1);
    ips200_show_float(60, 16*6, INS_Y, 3, 1);

    // 距离目标点足够近 → 前进到下一个点
    if(INS_two_points_distance < INS_distance && next < total - 1)
    {
        if(next == 0)
        {
            Back_Motor_PID_Start_flag = 1;
        }
        next++;
        Back_Motor_Set_Speed = -200;
        Buzzer_SetTimer(50);
    }

    // 电机输出
    if(next >= 1 && next < total && Camera_Navigation_Motor_flag == 1)
    {
        Back_Motor_SetPwm(Back_Motor_Set_Speed, Back_Motor_Set_Speed);
    }

    // 方向PID
    if(dispatch_car == 1)
    {
        INS_Error = -angle_diff(INS_azimuth,((Yaw_Mapped+180) >=360 ) ? (Yaw_Mapped-180) : (Yaw_Mapped+180));
        Angle_Target_Position = -GPS_IMU_PID_Start(Open, INS_Error, 0);
    }

    // 到达终点 → 停车
    if(INS_two_points_distance < INS_distance_final && next >= total - 1)
    {
        next = total;
        dispatch_car = 0;
        Back_Motor_Set_Speed = 0;
        Back_Motor_SetPwm(0, 0);
        Back_Motor_PID_Start_flag = 0;
        INS_Flag = 0;
        Buzzer_SetTimer(1000);
    }
}


void INS_track(void)
{

    int32 pack = INS_data2[next];
    int16 x_int = (int16)(pack >> 16);
    int16 y_int = (int16)(pack & 0xFFFF);
    float x = x_int / 100.0f;
    float y = y_int / 100.0f;
    float INS_Error=0;
    float INS_azimuth = 0;

    INS_two_points_distance = Get_Two_Point_Distance(INS_X,INS_Y,x,y); //获取俩点间距离
    INS_azimuth = Get_Target_Angle(INS_X,INS_Y,x,y);    //获取俩点之间的角度

    ips200_show_int(0, 100, next, 2);//显示实时到达点位

    ips200_show_string(0, 16*3, "x:");
    ips200_show_string(0, 16*4, "Y:");
    ips200_show_float( 60, 16*3,x, 3,1);
    ips200_show_float( 60, 16*4,y, 3,1);

    ips200_show_string(0, 16*5, "INS_X:");
    ips200_show_string(0, 16*6, "INS_Y:");
    ips200_show_float( 60, 16*5,INS_X, 3,1);
    ips200_show_float( 60, 16*6,INS_Y, 3,1);

    if(INS_two_points_distance < INS_distance  && next==0)
    {
       next++;

       Back_Motor_PID_Start_flag = 1; //为1时开启位置PID
       Back_Motor_Set_Speed = 300;//设置速度
       Buzzer_SetTimer(50);
    }
    if(INS_two_points_distance < INS_distance &&  next!=0 &&  next < INS_Resd_Point_Count - 1)
    {
       next++;
       Back_Motor_Set_Speed = 300;//设置速度
       Buzzer_SetTimer(50);
    }

      //电机速度模式选择
    if(next >= 1 && next < INS_Resd_Point_Count)
    {
      Back_Motor_SetPwm(Back_Motor_Set_Speed,Back_Motor_Set_Speed);      //电机速度赋值
    }


      //方向PID选择是否开启
    if(dispatch_car == 1)
    {
        INS_Error = angle_diff(INS_azimuth,Yaw_Mapped);    // 方向角与航向角之间的误差（用于控制）
        Angle_Target_Position = -GPS_IMU_PID_Start(Open,INS_Error,0);
    }

    if(INS_two_points_distance < INS_distance_final  && next >= INS_Resd_Point_Count - 1)
    {
        next = (int16)INS_Resd_Point_Count;
        delay_ScanTemp = 0;//关闭定时器延迟发车标志位
        dispatch_car = 0;//关闭发车标志位
        Back_Motor_Set_Speed = 0;//设置速度
        Back_Motor_SetPwm(0,0);
        Back_Motor_PID_Start_flag = 0; //关闭位置PID，给电机速度为0
        INS_Flag = 0;
        Buzzer_SetTimer(1000);
    }

}
