摘要
本报告介绍一套基于英飞凌 AURIX TC387QP 的智能车控制方案。工程采用模块化软件结构，将设备驱动、车辆状态、路径与控制算法、摄像头识别以及多核任务调度分层组织。源码中已实现电机增量式编码器测速、角度编码器转角测量、IMU 数据采集与 Mahony 姿态融合、里程计位置积分、摄像头图像处理、双圆目标识别与跟随、速度/角度 PID、轨迹回放及可选前视点选择等功能。摄像头新跟随路径采用 CPU0 负责 DMA 采集与结果处理、CPU1 负责图像处理的流水线结构，并通过固定槽位、邮箱和快照机制管理图像所有权。
关键词：TC387QP；多核流水线；双圆目标识别；PID控制；Mahony姿态融合；轨迹回放；智能车

第一章 绪论
1.1 项目背景
智能车竞赛要求参赛车辆在限定场地和规则约束下完成感知、定位、决策与运动控制。技术报告的作用是说明方案如何从机械结构、硬件接口、底层驱动、感知算法和控制算法形成闭环，并大致验证方案的有效性。
本项目以 TC387 逐飞科技开源工程为软件基础，面向带有摄像头目标识别、路径记录/回放和车辆闭环控制需求的智能车系统。报告重点放在工程中已经出现的技术实现，讲解技术思路。
1.2 设计目标
系统设计目标包括：完成车辆底盘运动控制；稳定获取轮速、舵角、姿态、里程和位置信息；完成摄像头图像采集、目标识别与图像解析；支持相机跟随、遥控器控制、轨迹记录与轨迹回放等工作模式；在多核环境下避免 DMA、图像算法和显示之间的内存冲突；提供参数存储、菜单调试和故障停机接口。
1.3 报告范围
本报告覆盖总体方案、机械与硬件接口、软件架构、感知与控制算法。
第二章 系统总体方案
2.1 系统组成
系统由车辆机械本体、TC387QP主控、逐飞科技总钻风摄像头、左右轮增量式编码器、前轮角度编码器、IMU、IPS200显示与摁键互模块、无线/语音/灯板等外设组成。主控读取传感器数据，经过图像识别、姿态估计、位置更新和控制算法，输出左右驱动电机 PWM 以及前轮转向电机控制信号。

2.2 多核任务与数据流
源码将 CPU0、CPU1、CPU2、CPU3 入口分别保留。当前工程中，CPU0 负责系统启动、摄像头流水线启动、车辆初始化和菜单、车辆控制；CPU1 负责 Camera_New_Worker 图像处理服务；CPU2 与 CPU3 入口保留为空循环。
新摄像头流水线的核心数据流为：摄像头 DMA 写入 CPU1 DSRAM 的图像槽位；DMA 完成中断发布已完成槽位；CPU1 获取最新槽位并执行曝光统计和双圆识别；CPU1 将结果写入结果邮箱，并按较低频率发布显示快照；CPU0 读取稳定结果、进行跟随控制和显示。槽位状态包括 FREE、DMA_WRITING、PENDING_LATEST、CPU1_PROCESSING，体现了明确的图像所有权。

2.4 故障与安全策略
摄像头跟随代码包含目标丢失、控制停止、工作线程握手超时、结果过期和流水线统计等状态。出现控制停止条件时，代码将速度期望、转向期望以及图像控制标志清零。对于 DMA 与 CPU1 处理之间的竞争，流水线采用非阻塞锁和槽位释放策略，避免在中断中长时间等待。整车控制中额外增加遥控器紧急停车功能，预防突发状况。

4.4 供电部分电路
整车采用24V铅酸蓄电池供电，经过电源防过压电路接到开关。主板设置电池输入与多路电源变换电路：SP1N28STER用于5 V降压供电以及输出6-10V可调电压对灯板进行单独供电，RT9013用于3.3 V电源稳压，摄像头采用RT9013单独供电，保证摄像头电源的稳定。在24 V输入条件下，整车静止待机电流约50 mA，对应输入功耗约1.2 W；系统运行时输入电流约8A，对应输入功耗约192 W。上述两项功耗按输入电压与电流乘积换算。该值不是电流表直接测量结果。
4.5 驱动部分电路
行进系统采用北京科宇的KW-068有刷电机，电机电压24V，空载转速500RPM±10%。转向系统采用北京科宇的有刷电机。主板设置三路DRV8701E栅极驱动器，并配合AOD4184功率MOSFET构成两组有刷电机全桥驱动电路；SN74HC125A用于相关使能信号处理。
4.6 离线语音模块电路（CI1302)
基于CI1302离线语音方案，板载功放电路与MIC接口。MIC信号经C13耦合电容接入功放，功放输出经100µF电容滤波后由MIC OUT输出，该反馈信号接入主控AEC引脚用于回声消除。MIC接口部分，板载MIC1~MIC608共608路麦克风输入接口，按项目实际配置接入单路或多路麦克风。整板由5V供电，主控内置PMU电源管理单元，可支持本地语音唤醒、命令词识别及语音播报反馈功能。
4.7 TLD7002灯板驱动电路
板载TLD7002-16ES多通道LED驱动芯片，该芯片是一款16通道的汽车级恒流源驱动器，各通道电流（6位分辨率）及PWM占空比（14位分辨率）均可独立配置，单通道最大输出电流为76.5mA，输出级可并联以驱动更大电流负载。芯片通过HSLI（高速照明接口）进行通信控制，兼容UART over CAN协议，最高通信速率可达2Mbit/s。
本方案中，TLD7002-16ES用于驱动13个5×7点阵LED灯板。每个5×7灯板共需控制35个LED点阵像素，13个灯板合计需驱动455个LED像素点。芯片的16个通道需通过通道复用与PWM扫描控制的方式，分时驱动各灯板的行/列电极，以实现全灯板点亮。TLD7002-16ES支持100Hz~2kHz的独立PWM频率配置，可满足点阵扫描的动态显示需求。
4.8 电机端保护板、摄像头转接板及其它辅助电路
鉴于电机强大的反电动势，设计了电机端保护板。电机端保护板并联了TVS管和一个100NF陶瓷电容。TVS管负责吸收线路寄生电感产生的瞬间高压尖峰，陶瓷电容处理了剩下的10%高压尖峰和电磁干扰。
摄像头转接板将FPC排线接口转换为2.54的排线接口，保证这个系统连接线的稳定。
4.9 PCB设计与可靠性考虑

5.3 摄像头多核流水线
CPU0启动摄像头和流水线会话，DMA完成中断发布图像槽位并切换下一块DMA目的地；CPU1 worker 获取最新帧，计算曝光统计、调用 Camera_New_ProcessFrame()，发布结果邮箱和显示快照，再释放处理槽位。CPU0在跟随循环中读取稳定结果，控制车辆并周期性刷新显示。该结构将实时采集、识别计算和显示访问分开，减少在DMA中断中复制整帧图像的需要。

第六章 关键算法设计
6.1 摄像头图像处理与双圆识别
Camera_New_ProcessFrame() 的处理链路包括灰度统计、Otsu阈值计算、二值化、连通域/洪泛填充、候选区域筛选、圆形度和填充率评价、双圆配对以及时序滤波。源码对候选数量、面积、宽高比、填充率、圆形度、周围白色比例、半径相似度、双圆间距比例和对角线斜率设置了明确宏。

6.2 相机标定、跟踪与误差模型
源码设置相机标定最多采集30个有效样本，去除前后各3个样本后计算稳定参考值；标定内容包括双圆中心、间距、大小不对称度和板线角度。跟踪阶段对中心、间距和灰度模型进行低通或限幅更新，最多允许连续丢失6帧后进入完全丢失状态。
跟随误差包括横向误差、表观距离误差、大小不对称度、透视误差和转向误差。横向误差以图像中心归一化；距离误差由参考双圆间距与当前间距之比构造；透视误差使用当前大小不对称度减去标定值；转向误差将横向与透视项加权组合。权重和视场角配置需要在实车测试中复核。
6.3 曝光与灰度统计
新跟随路径使用8条居中采样行、行间距5像素遍历图像宽度，计算平均灰度和饱和像素比例。目标平均灰度为90，灰度大于等于245视为饱和；当饱和比例达到8%时优先降低曝光。曝光候选值限制在3~600，更新间隔为每3帧一次，写入失败时不提交新的当前曝光值。以上是源码控制逻辑，不等于已经完成环境覆盖测试。
6.4 电机速度与摄像头控制
左右轮分别使用 PID_Controller，参数独立保存（虽然有区分左右轮PID，但实际使用中为相同值）。电机PID实现了积分抗饱和、积分输出限幅和目标速度为零时的最小启动占空比处理。摄像头距离和角度PID在当前配置下积分、微分参数为0，实际配置为P控制；输出分别受电机占空比和转向角边界限制。
motor_set() 根据转向角计算左右轮差速，并对电机输出和转向电机输出设置斜率限制；摄像头新跟随转向控制还设置了死区、最小占空比、最大占空比和每5 ms的最大变化量，用于减少转向突变。
6.5 姿态、里程计与位置积分
IMU初始化阶段连续采样1000次估计陀螺仪和加速度计零偏，IMU_Get() 在后续数据中扣除零偏。MahonyAHRSupdate() 使用陀螺仪和加速度计更新四元数并提取Z轴偏航角。Position.c 使用编码器里程增量和相邻时刻航向变化的中间角度进行二维位置积分，形式为 x += ds·cos(theta_mid)、y += ds·sin(theta_mid)。
6.6 路径滤波与轨迹回放
SG_Filter.c 对路径点使用11点窗口的Savitzky-Golay系数，并跳过特殊点和间距不均匀的区域，以避免改变停止、倒车或科目边界。Trace.c 根据回放路径的目标点计算航向误差；对科目一、三、四可使用弧长前视选择器，前视距离按前进/倒车方向和科目配置区分，特殊点不被跨越，目标选择不会覆盖 Replay_Path.Index 的进度状态。
6.7 回放PID的可变P策略
轨迹回放中，源码将5°作为小误差边界、15°作为大误差边界，在小误差P和大误差P之间使用 smoothstep 平滑过渡。科目一前进、科目一倒车、科目三/四分别使用对应小P与大P参数，积分项在这些回放入口中置零；科目二保持独立参数路径。最终报告应补充各参数的标定过程和曲线。

8.2 后续改进
后续可从四个方面改进：一是建立自动化参数扫描和可视化标定工具；二是将识别置信度、曝光、处理耗时和控制误差同步记录，形成可回放数据集；三是针对赛道任务将状态机、停止点和倒车逻辑独立建模；四是对多核流水线进行长时间压力测试，明确最坏情况下的帧延迟、槽位占用和故障恢复策略。
第九章 总结
本方案以 TC387QP 为核心，形成了从传感器采集、车辆状态估计、视觉识别到运动控制的完整软件闭环。源码已经体现出较清晰的模块划分：底层设备驱动与车辆状态相互独立，控制算法按电机、摄像头和轨迹回放分工，多核摄像头路径使用槽位和邮箱管理数据生命周期，便于后续扩展和调试。

#define MOTOR_SLEW_STEP_PER_CALL   (33)   // 每5ms最大变化33（占空比单位，最大是10000）
static int16 last_left_duty = 0;
static int16 last_right_duty = 0;
static int16 camera_new_last_steering_duty = 0;

/* 内部函数：带换向保护的斜率限制 */
static int16 motor_slew(int16 last, int16 target, int16 max_step)
{
    int16 step_target = target;
    int16 delta;

    /* 换向保护：如果符号相反，先回零 */
    if ((last > 0 && my_car.Speed < 0) || (last < 0 && my_car.Speed > 0))
    {
        step_target = 0;
    }

    delta = step_target - last;
    if (delta > max_step)       delta = max_step;
    else if (delta < -max_step) delta = -max_step;

    return last + delta;
}

static int16 steering_motor_slew(int16 last, int16 target, int16 max_step)
{
    int16 delta = target - last;

    if (delta > max_step)       delta = max_step;
    else if (delta < -max_step) delta = -max_step;

    return last + delta;
}

/*
 * 新视觉模式的转向电机控制。
 * 与原来的固定 5000/8000 占空比相比，这里按角度误差逐渐增加推力，
 * 并限制每 5 ms 的占空比变化，避免转向电机突然抽动。
 */
static int16 camera_new_steering_motor_control(float expected_angle)
{
    float angle_error = expected_angle - my_car.duoji_angle;
    float absolute_error = fabsf(angle_error);
    int16 target_duty = 0;

    if (absolute_error > CAMERA_NEW_STEER_MOTOR_DEAD_ZONE)
    {
        float duty_magnitude = CAMERA_NEW_STEER_MOTOR_MIN_DUTY +
            CAMERA_NEW_STEER_MOTOR_KP *
            (absolute_error - CAMERA_NEW_STEER_MOTOR_DEAD_ZONE);

        if (duty_magnitude > CAMERA_NEW_STEER_MOTOR_MAX_DUTY)
        {
            duty_magnitude = CAMERA_NEW_STEER_MOTOR_MAX_DUTY;
        }

        target_duty = (int16)duty_magnitude;
        if (angle_error < 0.0f)
        {
            target_duty = (int16)(-target_duty);
        }
    }

    camera_new_last_steering_duty = steering_motor_slew(
        camera_new_last_steering_duty,
        target_duty,
        CAMERA_NEW_STEER_MOTOR_SLEW_STEP);

    return camera_new_last_steering_duty;
}

void motor_set(int duty, float angle)
{
    int left_duty, right_duty;          // 目标值（差速后）
    int left_apply, right_apply;        // 实际输出值（经斜率限制）

    // ================== 1. 差速计算（保持不变） ==================
    if (angle > -DIFF_STEER_DEADZONE && angle < DIFF_STEER_DEADZONE)
    {
        left_duty  = duty;
        right_duty = duty;
    }
    else
    {
        float angle_rad = fabsf(angle) * (PI / 180.0f);
        float tan_val = tanf(angle_rad);
        if (tan_val < 1e-4f) tan_val = 1e-4f;

        float R, ratio_outer, ratio_inner;
        if (Reverse_Start_Flag == 1)
        {
            R = car_L / tan_val;
            ratio_outer = (R + car_D_Back * 0.5f) / R;
            ratio_inner = (R - car_D_Back * 0.5f) / R;
        }
        else
        {
            R = car_L / tan_val;
            ratio_outer = (R + car_D * 0.5f) / R;
            ratio_inner = (R - car_D * 0.5f) / R;
        }

        int v_outer = (int)(duty * ratio_outer);
        int v_inner = (int)(duty * ratio_inner);

        if (angle > DIFF_STEER_DEADZONE)
        {
            left_duty  = v_inner;
            right_duty = v_outer;
        }
        else
        {
            left_duty  = v_outer;
            right_duty = v_inner;
        }
    }

    // ================== 2. 处理停止请求（软停止） ==================
    if (Stop_Flag == 1)
    {
        // 目标设为 0，后续通过斜率限制逐步减到 0
        left_duty = 0;
        right_duty = 0;
        // 转向电机直接停止（保持原有逻辑，也可以加软停，但暂不变）
        gpio_set_level(DIR1_motor_duoji, 0);
        pwm_set_duty(PWM1_motor_duoji, 0);
        camera_new_last_steering_duty = 0;
    }
    else
    {
        // 新视觉模式使用比例加斜坡控制，其他模式保留原来的控制。
        if (angle > MOTOR_DUOJI_ANGLE_MAX)  angle = MOTOR_DUOJI_ANGLE_MAX;
        if (angle < -MOTOR_DUOJI_ANGLE_MAX) angle = -MOTOR_DUOJI_ANGLE_MAX;
        int motor_duoji_duty = 0;

        if (Camera_New_Following_IsControlActive())
        {
            motor_duoji_duty = camera_new_steering_motor_control(angle);
        }
        else
        {
            camera_new_last_steering_duty = 0;
            if (my_car.duoji_angle >= angle + 1.5f)  motor_duoji_duty = -5000;
            if (my_car.duoji_angle <= angle - 1.5f)  motor_duoji_duty =  5000;
            if (my_car.duoji_angle >= angle + 7.0f)  motor_duoji_duty = -10000;
            if (my_car.duoji_angle <= angle - 7.0f)  motor_duoji_duty =  10000;

//            /* 新车模 */
//            if (my_car.duoji_angle >= angle + 1.5f)  motor_duoji_duty = 5000;
//            if (my_car.duoji_angle <= angle - 1.5f)  motor_duoji_duty = -5000;
//            if (my_car.duoji_angle >= angle + 7.0f)  motor_duoji_duty = 10000;
//            if (my_car.duoji_angle <= angle - 7.0f)  motor_duoji_duty = -10000;
        }
        // 输出转向
        if (motor_duoji_duty >= 0) {
            gpio_set_level(DIR1_motor_duoji, 0);
            pwm_set_duty(PWM1_motor_duoji, motor_duoji_duty);
        } else {
            gpio_set_level(DIR1_motor_duoji, 1);
            pwm_set_duty(PWM1_motor_duoji, -motor_duoji_duty);
        }
    }

    // ================== 3. 限幅（目标值） ==================
    if (left_duty > MAX_MOTOR_DUTY)   left_duty = MAX_MOTOR_DUTY;
    if (left_duty < -MAX_MOTOR_DUTY)  left_duty = -MAX_MOTOR_DUTY;
    if (right_duty > MAX_MOTOR_DUTY)  right_duty = MAX_MOTOR_DUTY;
    if (right_duty < -MAX_MOTOR_DUTY) right_duty = -MAX_MOTOR_DUTY;

    // ================== 4. 斜率限制（软启停） ==================
    left_apply = motor_slew(last_left_duty, left_duty, MOTOR_SLEW_STEP_PER_CALL);
    right_apply = motor_slew(last_right_duty, right_duty, MOTOR_SLEW_STEP_PER_CALL);

    // 更新上次值
    last_left_duty = left_apply;
    last_right_duty = right_apply;

    // ================== 5. 后轮驱动输出 ==================
    // 左轮

//    /* 新车模 */
//    left_apply = left_apply * 0.84;

    if (left_apply >= 0) {
        gpio_set_level(DIR1_left, 0);
        pwm_set_duty(PWM1_left, left_apply);
    } else {
        gpio_set_level(DIR1_left, 1);
        pwm_set_duty(PWM1_left, -left_apply);
    }
    // 右轮

//    /* 新车模 */
//    right_apply = - right_apply;

    if (right_apply >= 0) {
        gpio_set_level(DIR1_right, 0);
        pwm_set_duty(PWM1_right, right_apply);
    } else {
        gpio_set_level(DIR1_right, 1);
        pwm_set_duty(PWM1_right, -right_apply);
    }
}

/*
 * 函数名：驱动电机编码器数值获取
 * 备注：左右轮均为前进为正(包括：距离、速度)
 */
void encoder_motor_get()
{
    //1.获取左右轮速度
    /* 左轮 */
    int encoder_left = encoder_get_count(ENCODER_3);                            // 获取编码器计数
//    int encoder_left = -encoder_get_count(ENCODER_3);                            // 获取编码器计数（新车模）
    if(encoder_left * (2 * PI * car_R / sum_encoder_rad) > Ddistance / 2 || encoder_left * (2 * PI * car_R / sum_encoder_rad) < -Ddistance / 2)
    {
        my_car.speed_left = encoder_left * Ddistance * 1.21 / 0.005;//实际路程除以5ms
    }else
    {
        my_car.speed_left = 0;
    }
    encoder_clear_count(ENCODER_3);                                             // 清空编码器计数
    /* 右轮 */
    int encoder_right = -encoder_get_count(ENCODER_4);                           // 获取编码器计数
//    int encoder_right = encoder_get_count(ENCODER_4);                           // 获取编码器计数（新车模）

    if(encoder_right * (2 * PI * car_R / sum_encoder_rad) > Ddistance / 2 || encoder_right * (2 * PI * car_R / sum_encoder_rad) < -Ddistance / 2)
    {
        my_car.speed_right = encoder_right * Ddistance * 1.21 / 0.005;//实际路程除以5ms
    }else
    {
        my_car.speed_right = 0;
    }
    encoder_clear_count(ENCODER_4);                                             // 清空编码器计数
    // 车速
    my_car.Speed = (my_car.speed_left + my_car.speed_right)/2;
    //2.低通滤波
    /* 左轮 */
    double encoder_left_distance = 0;
    if(encoder_left * (2 * PI * car_R / sum_encoder_rad) > Ddistance / 2 || encoder_left * (2 * PI * car_R / sum_encoder_rad) < -Ddistance / 2)
    {
        encoder_left_distance = encoder_left * Ddistance;
    }
    /* 右轮 */
    double encoder_right_distance = 0;
    if(encoder_right * (2 * PI * car_R / sum_encoder_rad) > Ddistance / 2 || encoder_right * (2 * PI * car_R / sum_encoder_rad) < -Ddistance / 2)
    {
        encoder_right_distance = encoder_right * Ddistance;
    }
    //3.计算路程
    my_car.last_distance = my_car.distance;
    float dangle = my_car.YAW - my_car.last_YAW;//转向角度
//    if(dangle > 0)//左转
//    {
//        my_car.distance += encoder_left_distance * 0.8 + encoder_right_distance * 0.2;
//    }
//    if(dangle < 0)//右转
//    {
//        my_car.distance += encoder_left_distance * 0.2 + encoder_right_distance * 0.8;
//    }
//    if(dangle == 0)
//    {
//        my_car.distance += encoder_left_distance * 0.5 + encoder_right_distance * 0.5;
//    }
    my_car.distance += (encoder_left_distance * 0.5 + encoder_right_distance * 0.5) * 1.21;
}

void Display_image_data(int red_flag, int yellow_flag, int display_image_flag, int dispaly_data_flag)
{
    /*
     * red_flag：标红目标圆；yellow_flag：标记两个圆心和目标中心；
     * display_image_flag：显示图像；dispaly_data_flag：显示几何与控制数据。
     * “dispaly”是已有接口拼写，为避免改动调用关系而保留。
     */
    static int success_search_flag = 0;
    if (Image.Circle_sum != 2) {
        if(success_search_flag == 1)
        {
            success_search_flag = 0;
            ips200_clear();
        }
        ips200_displayimage03x((const uint8 *)Image.image, MT9V03X_W, MT9V03X_H);
        uint16_t line_height = 16;   // 可根据 ips200_display_font 动态获取，此处固定
        uint16_t text_y = MT9V03X_H + 2;   // 图像底部留 2 像素空隙
        // 检查剩余空间是否足够显示两行
        if (text_y + 2 * line_height < ips200_height_max) {
            ips200_show_string(0, text_y, "cx_err:NULL!!!");
            ips200_show_string(0, text_y+line_height, "cy_err:NULL!!!");
            ips200_show_string(0, text_y+2*line_height, "R:NULL!!!");
            ips200_show_string(0, text_y+3*line_height, "dist:NULL!!!");
            ips200_show_string(0, text_y+4*line_height, "ang:NULL!!!");
        }
        return;
    }
    if(success_search_flag == 0)
    {
        success_search_flag = 1;
        ips200_clear();
    }
    // ========== 1. 生成基础图像（红色标记或普通二值图） ==========
    if (red_flag == 1) {
        image_with_red_mark();   // 生成包含红色标记的 rgb_buffer
    } else {
        // 普通黑白二值图
        for (uint32_t r = 0; r < MT9V03X_H; r++) {
            for (uint32_t c = 0; c < MT9V03X_W; c++) {
                rgb_buffer[r][c] = (Image.image[r][c] == 255) ? RGB565_WHITE : RGB565_BLACK;
            }
        }
    }

    // ========== 2. 如果需要，绘制黄色标记（必须在红色生成之后） ==========
    if (yellow_flag == 1) {
        int x1 = (int)(Image_Control.x1+0.5f);
        int y1 = (int)(Image_Control.y1+0.5f);
        int x2 = (int)(Image_Control.x2+0.5f);
        int y2 = (int)(Image_Control.y2+0.5f);
        int cx = (int)(Image_Control.cx+0.5f);
        int cy = (int)(Image_Control.cy+0.5f);
        draw_point(x1,y1,RGB565_BLUE);
        draw_point(x2,y2,RGB565_BLUE);
        draw_point(cx,cy,RGB565_BLUE);
    }

    // ========== 3. 显示图像 ==========
    if (display_image_flag == 1) {
        ips200_show_rgb565_image(0, 0, (uint16_t*)rgb_buffer,
                                 MT9V03X_W, MT9V03X_H,
                                 MT9V03X_W, MT9V03X_H, 0);
    }

    // ========== 4. 显示数据（在图像下方，并检查空间） ==========
    if (dispaly_data_flag == 1) {
        // 先获取当前字体高度（默认 8x16 => 16 像素）
        uint16_t line_height = 16;   // 可根据 ips200_display_font 动态获取，此处固定
        uint16_t text_y = MT9V03X_H + 2;   // 图像底部留 2 像素空隙

        // 检查剩余空间是否足够显示两行
        if (text_y + 2 * line_height < ips200_height_max) {

            ips200_show_string(0, text_y, "cx_err:");
            ips200_show_float(100, text_y, Image_Control.cx_error, 3, 3);
            ips200_show_string(0, text_y+line_height, "cy_err:");
            ips200_show_float(100, text_y+line_height, Image_Control.cy_error, 3, 3);

            ips200_show_string(0, text_y+2*line_height, "R:");
            ips200_show_float(100, text_y+2*line_height, Image_Control.Circle_R, 3, 3);
            ips200_show_string(0, text_y+3*line_height, "dist:");
            ips200_show_float(100, text_y+3*line_height, Image_Control.image_distance, 3, 3);
            ips200_show_string(0, text_y+4*line_height, "ang:");
            ips200_show_float(100, text_y+4*line_height, Image_Control.image_angle, 3, 3);

            ips200_show_string(0, text_y+7*line_height, "duoji:");
            ips200_show_float(100, text_y+7*line_height, raw_angle, 3, 3);
            ips200_show_string(0, text_y+8*line_height, "speed:");
            ips200_show_float(100, text_y+8*line_height, raw_speed, 3, 3);
        }
    }
}
