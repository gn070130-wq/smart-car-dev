第一章  引言
1.1 智能汽车概述
智能汽车是集环境感知、规划决策、多等级辅助驾驶等功能于一体的综合系统，其研究涉及机械工程、电子技术、计算机科学、自动控制、传感器技术等多个学科。随着人工智能与电子控制技术的快速发展，智能汽车已经成为汽车产业转型升级的重要方向。在高校工程教育领域，以智能汽车为载体的竞赛活动为电子信息类、自动化类等相关专业学生提供了良好的工程实践平台。
1.2 竞赛简介
全国大学生智能汽车竞赛是一项面向全国大学生的探索性工程实践活动，以「立足培养、重在参与、鼓励探索、追求卓越」为宗旨，倡导理论联系实际、求真务实的学风和团队协作的人文精神。卡丁车组作为竞赛邀请组别，对车身综合美观程度提出较高要求，同时车模出厂时已自带电机驱动模块，参赛队伍需要根据车身模块所需的供电电压与信号完成整车控制系统的设计与改装。
1.3 本文工作安排
本文围绕广州职业技术大学卡丁车组 Re0 队智能车的设计制作过程展开，系统阐述了模型车的机械结构改装、电路设计、软件算法与调试过程。全文共分为七章：第二章介绍系统总体设计思路与车模布局；第三章详细说明电路设计，包括主控板、电机驱动板、灯板、语音模块板与人机交互板五大板卡；第四章阐述惯性导航算法与双闭环 PID 控制等软件设计；第五章介绍开发工具与制作调试过程；第六章给出模型车主要技术参数；第七章对整体工作进行总结。
第二章  系统总体设计
2.1 设计思路与技术方案概要
本设计以英飞凌 TC264 微控制器作为整车唯一主控，负责电机驱动、转向控制、传感器数据采集、惯性导航解算与语音交互控制等全部任务。导航方案采用惯性导航：以 IMU963RA 陀螺仪与加速度计解算车辆航向角（Yaw），以逐飞编码器测量车轮速度并累计行驶里程，通过航位推算实现路径点跟踪，全程不依赖 GPS 等卫星定位信号，具有更强的环境适应性与抗干扰能力。
2.2 车模总体布局
卡丁车模自带电机驱动器，电池型号为铅酸蓄电池、额定电压为 24V、容量 14Ah。本设计选择采用 TC264 作为车身总体主控；为实现灯光控制与数码管显示，专门设计了独立灯板，采用英飞凌 TLD700216ESXUMA1 十六通道 LED 驱动芯片驱动车灯与数码管。由于车辆电池和驱动电机位于车辆后部，整车重心偏向车身后部，且车身后部电池部分有较大空间，可以安置稳压电源、分线板等模块。

2.3 机械结构改装
为满足转向角闭环控制需求，在车模前轮转向机构上加装逐飞角度编码器，通过斜齿圆柱齿轮啮合传动与转向轴联动，实时反馈前轮实际转角。同时，为固定五块电路板并保证走线整洁，设计了基于 3D 打印 ABS 材料的三层电路板分层支架，将主控板、电机驱动板、灯板、语音模块板与人机交互板分层固定，兼顾散热与信号隔离。

第三章  电路设计说明
3.1 系统硬件结构
本车模的硬件系统由五块核心电路板构成：主控板、电机驱动板、灯板、人机交互板与语音模块板，全部围绕英飞凌 TC264 微控制器展开。车辆采用 24V 铅酸蓄电池供电，各板卡通过 TPS5430DDA DC-DC 降压、AMS1117-3.3 LDO 及 CJ7805 线性稳压等多级电源方案为不同外设提供稳定的工作电压。
主控板集成 TC264 主控芯片、IMU963RA 惯性测量单元、TPS5430DDA 降压芯片与 AMS1117-3.3 LDO，并引出 FPC 连接器、XT60H-M 电源接口与蜂鸣器，负责整车控制、惯性导航解算与各外设通信。电机驱动板采用 6 片 IR2104STRPBF 半桥栅极驱动芯片搭配 12 片 NCE8295AD N沟道 MOSFET 构成 H 桥驱动电路，用于驱动转向电机等直流电机。灯板集成英飞凌 TLD700216ESXUMA1 十六通道 LED 驱动芯片、三片 1357BS 七段数码管及 AO3401A/S8050 驱动管。人机交互板集成四颗凯华热插拔机械按键、TC5050RGBF08 RGB LED 与 KT-0603R 红色指示灯。语音模块板集成 ASRPRO4M 语音识别芯片、CH340N USB 转串口芯片及两片 FM8002A 音频功放。
传感器选型方面，赛道图像采集采用逐飞科技总钻风摄像头，其核心为 MT9V034 全局快门灰度图像传感器，具备全局快门曝光与宽动态范围特性，能够有效抑制运动模糊并适应赛道光照变化，灰度图像经 DMA 采集送入 TC264 主控后用于赛道元素识别。

3.2 电源供电电路设计
系统由 24V 铅酸蓄电池供电。主控板与电机驱动板采用 TPS5430DDA DC-DC 降压芯片将电池电压降压至所需电压，TPS5430DDA 支持宽电压输入、输出电流大、转换效率高；灯板额外采用 CJ7805B 线性稳压器输出稳定的 5V；各板卡上的 AMS1117-3.3 LDO 将 5V 进一步降压为 3.3V，为 TC264 内核、IMU963RA、LED 驱动芯片等低压器件提供低纹波电源。

3.3 TC264 主控电路
主控板以英飞凌 TC264 微控制器为核心，TC264 属于 AURIX 系列 TriCore 架构，具备双核处理能力、丰富的定时器与 ADC 外设，以及 SPI、UART、CAN 等通信接口，能够满足惯性导航实时解算、双闭环 PID 控制与多外设数据采集的需求。主控板上集成 IMU963RA 惯性测量单元、TPS5430DDA 降压芯片、AMS1117-3.3 LDO，并布置蜂鸣器、FPC 连接器与 XT60H-M 电源接口。

3.4 电机驱动电路
车辆前轮转向采用 24V 直流有刷电机作为转向动力。电机驱动板通过 6 片 IR2104STRPBF 半桥栅极驱动芯片搭配 12 片 NCE8295AD N沟道 MOSFET 构成 H 桥驱动电路驱动转向电机，配合角度传感器构成闭环转向系统。IR2104STRPBF 为杰盛微（JSMSEMI）半桥栅极驱动器，支持宽电压输入，内部集成欠压锁定保护；NCE8295AD 为无锡新洁能大功率 N-MOSFET，导通电阻低、耐压高，适合驱动大电流直流电机。板卡上布置 4 个 XT60H-M 电源接口与 35V/1000uF 大容量电解电容，保证大电流工况下的电源稳定。

3.5 灯板电路
灯板以英飞凌 TLD700216ESXUMA1 十六通道 LED 驱动芯片为核心。TLD7002 是一款多通道线性 LED 驱动芯片，支持通过串行接口接收控制指令，实现多路 LED 的独立恒流驱动与亮度调节，广泛应用于汽车照明。灯板上集成三片 1357BS 七段数码管用于显示车速、里程等信息，同时搭配 AO3401A P-MOSFET 与 S8050 NPN 三极管组成驱动级，用于驱动大功率车灯。灯板由 TPS5430DDA 将电池电压降压后供电，配合 CJ7805 与 AMS1117-3.3 为驱动芯片与逻辑电路提供稳定电压。

3.6 语音模块板电路
语音模块板以 ASRPRO4M 语音识别芯片为核心。ASRPRO4M 是一款离线语音识别芯片，内置语音识别算法，支持通过串口输出识别结果，无需联网即可实现本地语音指令识别。板上集成 CH340N USB 转串口芯片，用于上位机配置与调试；两片 FM8002A 音频功放芯片用于驱动扬声器实现语音播报。语音模块通过 UART 串口与 TC264 主控通信，将识别到的语音指令发送给主控执行。

3.7 人机交互板电路
人机交互板集成四颗凯华热插拔机械按键（1U），支持按键的快速插拔更换，用于手动控制与调试操作。板上集成 TC5050RGBF08 RGB LED 用于状态指示，以及 KT-0603R 红色指示灯用于电源指示。按键信号与 LED 控制信号通过 FPC 连接器连接至主控板，由 TC264 通过 GPIO 读取按键状态并控制指示灯。

3.8 IMU963RA 惯性测量单元
IMU963RA 是一款集成了三轴陀螺仪与三轴加速度计的惯性测量单元，通过 SPI 接口与 TC264 通信。陀螺仪提供角速度信息，加速度计提供重力方向参考，二者通过互补滤波融合，得到车辆实时的航向角（Yaw）。IMU963RA 具有体积小、功耗低、零偏稳定性好等特点，是惯性导航的核心反馈器件。
3.9 逐飞编码器
采用逐飞科技 mini 正交编码器（512 线增量式）测量车轮转速，通过四倍频正交解码提高测速分辨率，并结合车轮周长计算行驶速度与累计里程，为航位推算提供里程基准。编码器信号经 GPIO 中断输入 TC264 进行正交解码计数。
3.10 角度传感器
转向角反馈采用逐飞角度编码器，通过斜齿圆柱齿轮啮合传动与转向轴联动，实时输出前轮转角，经 SPI 接口读取后作为转向角内环 PID 的反馈量。
第四章  软件系统设计
4.1 软件整体框架
软件系统基于英飞凌 AURIX Development Studio 开发，采用模块化设计，主要包含系统初始化模块、传感器采集模块、惯性导航解算模块、双闭环 PID 控制模块、语音交互模块与通信模块。主循环依次完成 IMU 航向角解算、编码器测速、路径点判断、航向角外环与转向角内环 PID 计算，以及 PWM 输出控制。
赛道图像处理采用基于霍夫变换（Hough Transform）的赛道元素检测算法。总钻风摄像头采集的灰度图像经二值化预处理后，利用霍夫变换在参数空间对赛道边缘直线与圆环元素进行投票检测，实现对赛道边界、圆环等特征元素的稳定识别，为循迹控制提供横向偏差与赛道元素类型信息。

4.2 惯性导航算法
4.2.1 航位推算
航位推算利用车辆当前航向角与行驶里程推算车辆位置。车辆在 t 时刻的航向角为 Yaw(t)，采样周期 dt 内行驶里程为 ds，则位置更新可表示为：

X(k+1) = X(k) + ds·cos(Yaw(k))；Y(k+1) = Y(k) + ds·sin(Yaw(k))     （公式1）

4.2.2 互补滤波姿态解算
陀螺仪短期精度高但存在积分漂移，加速度计长期稳定但受振动干扰大。采用互补滤波融合二者，得到稳定的航向角估计：

Yaw = 0.98·(Yaw + Gyro_Z·dt) + 0.02·Acc_Angle     （公式2）

4.3 双闭环 PID 控制算法
转向控制采用航向角外环与转向角内环的串联双闭环 PID 结构。外环根据当前航向角与目标航向角的偏差计算期望转角，内环根据期望转角与角度传感器反馈的实际转角的偏差计算 PWM 输出。位置式 PID 控制规律为：

u(k) = Kp·e(k) + Ki·Σe(i) + Kd·(e(k)-e(k-1))     （公式3）

4.4 UART/SPI 通信
TC264 与 IMU963RA 之间通过 SPI 接口进行数据通信，与逐飞编码器通过 GPIO 中断进行正交解码计数，与语音模块板通过 UART 串口通信，与灯板通过 TLD700216ESXUMA1 的串行接口传输灯光控制指令，与人机交互板通过 GPIO 读取按键状态。此外，系统还设计了 SPI 通信接口用于微控制器与调试 TFT 屏幕之间的数据交互。
第五章  开发工具与制作调试过程说明
5.1 开发工具
硬件设计采用 Altium Designer 完成五块电路板的原理图绘制与 PCB 布局布线；软件基于英飞凌 AURIX Development Studio 集成开发环境进行 TC264 的 C 语言程序编写与调试；机械结构改装使用 SolidWorks 进行三维建模，并通过 3D 打印完成电路板分层支架的加工；语音模块使用 ASRPRO4M 配套的上位机工具完成语音指令词条的录入与烧录。
5.2 制作过程
首先根据 BOM 清单完成元器件采购，随后完成五块电路板的焊接与基本功能测试，依次验证主控板最小系统、电机驱动板 H 桥输出、灯板数码管显示、语音模块识别与播报、人机交互板按键响应。最后组装机械结构，将角度传感器、编码器、电路板分层支架安装到车模上。

5.3 安装过程
按照分层支架设计，将主控板置于上层以利于散热与调试，电机驱动板置于下层靠近电机与电池，灯板、语音模块板、人机交互板分别固定于支架对应位置。各板之间通过 FPC 排线与 XT60H-M 电源接口连接，保证信号线远离大电流走线，减少电磁干扰。
5.4 调试过程
调试过程分为模块调试与整机联调两个阶段。模块调试阶段分别完成 IMU 航向角标定、编码器测速校准、转向 PID 参数整定与语音指令验证。整机联调阶段通过预采集路径点进行惯导航位推算循迹测试。调试中曾遇到 UART 串口无法收发数据的问题，经排查发现是 CH340N 型 USB 转串口芯片供电电压不稳导致上下位机信号无法正常通信，更换稳压方案后问题解决。

第七章  结论
本设计完成了卡丁车组智能车的机械结构改装、五板卡电路设计与惯性导航软件系统开发。系统以英飞凌 TC264 为唯一主控，采用 IMU963RA 惯性测量单元与逐飞编码器实现航位推算导航，通过航向角外环与转向角内环的双闭环 PID 实现稳定转向控制，并集成 ASRPRO4M 语音识别与人机交互功能。经调试，车辆能够沿预采集路径点稳定循迹行驶。
目前系统仍存在一些不足：IMU 航向角在长时间运行后存在漂移，需结合路径点航向基准进行在线校正；CH340N 串口供电的稳定性有待进一步优化；灯板数码管显示内容较为简单，后续可扩展显示更多状态信息。未来改进方向包括引入更高精度的航向角融合算法、优化 PID 参数自整定策略，以及增强人机交互的直观性。

B.1 IMU 航向角读取与互补滤波解算
// IMU963RA 航向角读取与互补滤波解算
void IMU_Update_Yaw(void)
{
    float gyro_z = Read_IMU_GyroZ();
    float acc_angle = atan2f(acc_y, acc_x) * 180.0f / PI;
    float dt = 0.01f;
    yaw = 0.98f * (yaw + gyro_z * dt) + 0.02f * acc_angle;
}

B.2 逐飞编码器四倍频测速与里程累计
// 逐飞 mini 编码器四倍频测速与里程累计
void Encoder_Update(void)
{
    int16_t delta = Encoder_GetCounter() - last_count;
    last_count = Encoder_GetCounter();
    speed = delta * WHEEL_PERIMETER / (ENCODER_RES * SAMPLE_TIME);
    distance += delta * WHEEL_PERIMETER / ENCODER_RES;
}

B.3 路径点存储与预采集
// 路径点目标航向角与里程预采集
typedef struct { float target_yaw; float target_dist; } WayPoint;
WayPoint path[PATH_NUM];
void Path_Record(int idx, float yaw, float dist)
{
    path[idx].target_yaw = yaw;
    path[idx].target_dist = dist;
}

B.4 惯性导航航位推算循迹
// 惯性导航航位推算循迹
void Dead_Reckoning(void)
{
    float yaw_err = path[cur_idx].target_yaw - yaw;
    if (distance >= path[cur_idx].target_dist)
    {
        cur_idx++;
    }
    Steering_Control(yaw_err);
}

B.5 航向角外环 PID 控制
// 航向角外环 PID 控制
float Yaw_PID(float yaw_err)
{
    static float integral = 0.0f, last_err = 0.0f;
    integral += yaw_err;
    float output = KP_YAW * yaw_err + KI_YAW * integral + KD_YAW * (yaw_err - last_err);
    last_err = yaw_err;
    return output;
}

B.6 转向角内环 PID 控制
// 转向角内环 PID 控制
float Steer_PID(float steer_err)
{
    static float integral = 0.0f, last_err = 0.0f;
    integral += steer_err;
    float output = KP_STEER * steer_err + KI_STEER * integral + KD_STEER * (steer_err - last_err);
    last_err = steer_err;
    return output;
}
