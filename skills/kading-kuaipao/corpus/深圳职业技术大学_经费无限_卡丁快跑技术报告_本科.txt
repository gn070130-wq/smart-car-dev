第一章 引言
1.1 项目概述
本项目面向第二十一届全国大学生智能汽车竞赛卡丁快跑组，设计并实现一套基于智能卡丁车平台的视觉跟随、路径录制、反向路径生成、倒车回放及语音动作执行系统。系统主控为 Infineon AURIX TC387QP，采用逐飞 TC387 开源库 V3.4.3 和 Infineon iLLD 1.0.11.0。
国赛固件 kemu3 采用一体化任务流程：车辆首先通过朝向车辆前进方向的 SCC8660 前视彩色摄像头识别前方紫色目标物，利用视觉偏差控制车辆跟随目标，同时由 IMU 与左右轮编码器进行局部航位推算并以 0.03 m 间隔记录轨迹；视觉目标消失或进入近距停车区后，轨迹写入 DFlash，CPU2 将记录轨迹变换为以终点为原点的反向返回路径；随后车辆关闭摄像头采集，采用录制转向前馈、航向 PI 修正和 CTE 横向修正倒车返回起点；返回成功后，CPU3 启动在线语音识别，CPU0 串行执行灯光和鸣笛命令。
当前国赛构建仅在任务菜单中开放 RC 对中/遥控模式与 Task3 综合任务。旧工程中 Task1、Task2 的入口和路径规划接口保留为兼容空壳，但不会在本固件中运行。因此本报告以实际启用的 Task3 全流程为主线，不将未启用模块描述为已完成竞赛功能。
1.2 技术背景
车辆定位采用轮编码器里程增量与 IMU 航向角融合的局部航位推算。该方法不依赖外部 GNSS 基站，适合短距离、封闭场地运行，但误差会随距离累积，因此系统在录制和返回阶段均通过较短的轨迹间隔、航向闭环与 CTE 反馈抑制偏差。
视觉跟随采用 YCbCr 颜色阈值、形态学闭运算、BFS 连通域搜索及候选评分识别目标，再使用 Pure Pursuit 几何关系把图像横向偏差转换为前轮转角。Pure Pursuit 算法计算量较低，适合嵌入式实时控制；其经典实现和前视距离对跟踪性能的影响可参考 Coulter 的技术报告[4]。
语音部分采用讯飞流式语音听写 WebAPI。音频以 8 kHz、16 bit、单声道 PCM 形式采集，通过 WebSocket 上传，返回 UTF-8 JSON 文本后在本地执行最长关键词匹配。讯飞官方接口允许 8 kHz 或 16 kHz PCM，并使用 WebSocket 鉴权通信[5]。
1.3 报告结构
第二章介绍总体架构和多核分工；第三章介绍底盘、传感器与执行机构；第四章整理接口及引脚；第五章详细说明视觉、INS、轨迹录制、反向路径生成、CTE 回放和语音系统；第六章说明开发与调试过程；第七章汇总技术参数；第八章总结成果、限制与后续改进方向。

第二章 系统总体设计
2.1 系统总体架构
系统由感知、定位、决策、控制和人机交互五部分构成：
感知层：SCC8660 摄像头、IMU963RA、方向盘绝对编码器、左右轮增量编码器、ADC 麦克风和 SBUS 接收机。
定位层：IMU 航向与轮编码器里程融合形成局部 INS 位姿。
决策层：Task3 六状态流程管理、视觉距离状态机、反向路径生成及完成判定。
控制层：视觉 Pure Pursuit、返回 CTE/航向复合修正、转向位置 PID、双后轮增量式速度 PID。
交互层：IPS200Pro、7×15 点阵屏、TLD7002 灯光驱动、蜂鸣器/喇叭和在线语音识别。

2.3 综合任务流程
车辆上电，CPU0 完成时钟、显示、定时器、任务及执行器初始化。
在菜单中选择 Task3，系统进入 IDLE，允许遥控对中并等待开始命令。
按下 P11.3 进入视觉录制；CPU1 通过前视相机识别前方紫色目标，CPU0 每 5 ms 更新视觉跟随控制，INS 每 10 ms 更新位置。
系统每累计 0.03 m 保存一个 (x,y,steer,key) 轨迹点。视觉目标持续无效或过近约 1 s 时触发自动停车、保存轨迹和终点航向。
CPU2 反转点序、平移至终点坐标系并根据终点航向旋转，生成倒车返回路径。
系统暂停摄像头与点阵扫描冲突链路，进入 RETURNING，以 CTE、航向和录制转向前馈控制车辆倒车。
正常到达终点后进入 DONE，停车并请求 CPU3 启动语音服务；识别出的灯光/鸣笛命令由 CPU0 依次执行。
任意阶段检测到遥控紧急变化、手动取消、路径无效或超时，系统强制停车。

第四章 电路设计
4.1 核心控制器
核心控制器为逐飞科技 TC387 核心板，搭配自制竞赛底板；核心芯片为 AURIX TC387QP，工程配置主频 300 MHz。Infineon 官方器件页面给出的 TC387QP 主要特性包括 4 个 300 MHz TriCore、片上 Flash、SRAM、DMA 和丰富的通信外设[2]。本工程使用逐飞 TC387 开源库 V3.4.3，iLLD 版本宏为 1.0.1.11.0，对应项目文档中的简写 1.0.11.0。核心板型号已确认为逐飞 TC387（实物照片见图4-1、图4-2）。
自制电机功率级实装信息为 6 颗 Infineon BTN8982TA 集成大电流半桥，而非单颗分立 MOSFET；芯片内部集成高侧/低侧功率开关、驱动与保护功能[8]。每两颗半桥构成一路完整 H 桥，三路分别驱动左后轮、右后轮和转向电机。每路 PWM 信号经过一颗 Texas Instruments SN74LVC2G241DCUR 双路三态缓冲/驱动器后送入功率级[9]。驱动板原理图的六个功率器件符号均标为 BTN8982TA，与实装器件一致；主控底板原理图核心板符号原标为 TC264_CoreBoard，与国赛实装 TC387 不一致，最终版本已更正为 TC387。

4.5 电源与功耗
整车采用 LONG WAY（龙威）12FM14 阀控式密封铅酸蓄电池，铭牌容量为 24 V、14 Ah（20 h 率）。铭牌给出的 25 ℃充电参数为：浮充 27.0～27.6 V、循环使用 28.8～30.0 V，初始充电电流小于 4.20 A。逻辑电源由 SCT2450STER 生成 5 V，再由 RT9013-33GB 生成 3.3 V。驱动电机使用基于 BTN8982TA 集成半桥的自制 H 桥电路，PWM 前级采用 SN74LVC2G241DCUR 缓冲器。
系统保留原车保险丝，设置机械急停开关和遥控软件急停；当前未配置独立的板级反接保护和外置过流保护，应在报告中如实披露。BTN8982TA 芯片本身具有内部保护功能[8]，但不能替代整车电源入口的反接、熔断和线束保护。
根据两张原理图的标称值逐项求和，驱动板电容为 944.7094 µF，主控底板电容为 804.5094 µF，整车两张自制 PCB 的电容名义总容量为 1749.2188 µF，报告取 1749.22 µF（约 1.749 mF）。该结果包含储能、滤波、去耦和补偿电容；若只统计不小于 1 µF 的储能/滤波电容，则合计 1746.8 µF。
整车三台电机的总额定功率为 350 W，其中两台后轮驱动电机合计 300 W，转向电机为 50 W。待机约 10 W、正常运行约 240 W 仍作为工程估算值，峰值约 320 W 已于 2026-08-17 整机实测确认；按 24 V 换算的等效电流约为 0.42 A、10.0 A 和 13.33 A。电池最大持续放电电流暂按约 20 A 估计，其 24 V 理论功率上限约 480 W。

5.3 视觉目标识别
5.3.1 冻结帧与跨核快照
SCC8660 以单缓冲 DMA 写入 scc8660_image。DMA 完成后，CPU1 将 160×120×2=38400 byte 图像复制到 s3_frame_copy，识别和显示均读取冻结副本，使下一帧 DMA 写入不破坏正在处理的数据。视觉输出再通过互斥锁复制到跨核快照，CPU0 的 5 ms 控制中断只读取完整快照。

5.6 Flash 存储与反向路径生成
每个 DFlash 逻辑页保存 512 个 32 bit 数值，7500 点需要 15 页。Task3 使用页 20～80：经度命名数组实际存局部 y，纬度命名数组实际存局部 x，另存运动标志、终点航向和转向 ADC。坐标按 106 缩放后转为 int32，并用魔数和保存点数恢复路径。
CPU2 生成返回路径的步骤为：
从 Flash 读取原始轨迹和终点航向；
以原轨迹终点为新原点，将点序完全反转；
按终点航向的相反角度旋转全部点，使当前位置对应返回坐标系原点；
复制录制转向 ADC 作为返回前馈；
按局部曲率和剩余距离标记直线、一般跟踪和减速段；
将所有段转为倒车标志并计算累计路径长度。

6.2.2 摄像头冻结帧诊断
项目曾针对彩色斑点和画面卡顿进行隔离诊断。最终结构恢复 SCC8660 单 DMA 缓冲，在 CPU1 收到完整帧后立即复制 38400 byte 冻结副本；算法与显示只读取副本。该方法将“采集写入”和“算法/显示读取”在时间和存储上隔离，避免下一帧 DMA 覆盖当前处理帧。

第八章 结论
8.1 工作总结
本项目在 TC387 四核平台上实现了前视彩色目标识别、视觉 Pure Pursuit 跟随、IMU/轮编码器局部航位推算、0.03 m 轨迹记录、CPU2 异步反向路径构建、CTE/航向/转向前馈复合倒车回放，以及返回后的在线语音灯光鸣笛执行。多核分工将图像处理、路径生成和网络语音从 CPU0 实时控制链路中拆分，冻结帧和互斥快照提高了图像与跨核数据的一致性。
8.2 主要特点
前视摄像头视觉跟随与路径记录同步进行，无需 GNSS 定位；
YCbCr＋形态学＋BFS＋候选评分组成可解释的嵌入式视觉链路；
视觉跟随采用偏差自适应前视距离和转角斜坡限制；
返回路径在 CPU2 异步生成，避免阻塞控制核；
返回控制融合录制转向前馈、航向 PI 和 CTE 比例/阻尼修正；
对无视觉、过近、路径失败、超时、人工取消和电机输出超时均设置停车保护；
返回完成后才启动在线 ASR，降低视觉、控制和网络任务同时运行的资源竞争。

8.3 当前限制与改进方向
INS 最终航向增量当前只采用 IMU，已计算的转向运动学和轮差航向未参与融合；后续可引入互补滤波或扩展卡尔曼滤波，减小短时冲击和长期漂移。

返回 CTE 和航向参数由经验设置，缺少系统化实测曲线；应记录 CTE、航向误差和控制输出完成定量整定。
在线 ASR 依赖 WiFi 和云端服务，应准备网络失败提示或离线降级方案。

 128  {
 129      float radius_cm;
 130      float min_radius_cm;
 131      float steer_rad;
 132      float steer_deg;
 133      int16 steer_adc;

 138      }

 141      min_radius_cm = chassis_get_min_turn_radius_m() * 100.0f;
 142      if(radius_cm < min_radius_cm)
 143      {
 144          radius_cm = min_radius_cm;
 145      }
 146
 147      steer_rad = atanf(CHASSIS_WHEEL_BASE_CM / radius_cm);
 148      steer_deg = steer_rad * 180.0f / 3.1415926f;

 152      }

 157      }
 158      else
 159      {

 161      }

 166  void chassis_mix_rear_speed(int16 steer_adc, int16 base_speed, int16 *left_speed, int16 *right_speed)
 167  {
 168      float steer_deg = chassis_steer_adc_to_deg(steer_adc);
 169      float steer_rad = steer_deg * 3.1415926f / 180.0f;
 170      float curvature = tanf(steer_rad) / CHASSIS_WHEEL_BASE_CM;
 171      float half_track = CHASSIS_REAR_TRACK_CM * 0.5f;
 172  #if CHASSIS_REAR_DIFF_REVERSED
 173      float left_factor = 1.0f - curvature * half_track;
 174      float right_factor = 1.0f + curvature * half_track;
 175  #else
 176      float left_factor = 1.0f + curvature * half_track;
 177      float right_factor = 1.0f - curvature * half_track;
 178  #endif
 179      float left_target = (float)base_speed * left_factor;
 180      float right_target = (float)base_speed * right_factor;
 181
 182      if(left_factor < 0.0f) left_target = 0.0f;
 183      if(right_factor < 0.0f) right_target = 0.0f;
 184
 185      *left_speed = chassis_round_to_int16(left_target);
 186      *right_speed = chassis_round_to_int16(right_target);
 187  }

 203      target->steer_deg = chassis_steer_adc_to_deg(steer_adc);
 204      target->base_speed = base_speed;
 205      target->left_speed = left_speed;
