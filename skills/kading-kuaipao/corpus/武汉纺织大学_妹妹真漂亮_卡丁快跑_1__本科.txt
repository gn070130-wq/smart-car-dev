第一章　引言
1.1　竞赛背景与任务概述
第二十一届全国大学生智能汽车竞赛“卡丁快跑”组别要求参赛车辆在规定赛道上完成自动驾驶、战场救护（科目二）和如影随形（科目三）等任务。其中科目二要求车辆自主行驶至指定区域完成“救护”任务，科目三要求车辆跟随引导车行驶，保持规定距离。本参赛队围绕上述任务，基于英飞凌TC387三核微控制器，设计了集视觉感知、惯性导航、RTK定位、编码器里程计和Pure Pursuit路径跟踪于一体的智能车系统，通过多传感器融合实现赛道环境下的高精度定位与稳定路径跟踪。
1.2　国内外研究现状与文献综述
（1）惯性导航与多传感器融合
惯性导航系统（INS）通过陀螺仪和加速度计的积分运算获取载体的姿态、速度与位置，具有完全自主、短时高精度、高数据率的优势，但存在随时间累积的漂移误差。针对低成本MEMS IMU的漂移问题，国内外学者开展了大量研究。Woodman等人系统阐述了MEMS惯性导航的误差模型与校准方法，指出零速更新（ZUPT）和零角率更新（ZARU）是抑制漂移的有效手段[1]。在智能车领域，由于载体运动约束明确（非完整约束），可通过编码器里程计与IMU进行紧耦合融合[4][5]。本项目采用六轴姿态卡尔曼滤波（加速度计校正roll/pitch，陀螺仪积分yaw）结合航向EKF（陀螺仪+磁力计融合），并引入ZUPT静止检测在停车时修正陀螺仪零偏，有效抑制了yaw漂移（实测静态漂移率约1.42度/min）。
（2）Pure Pursuit路径跟踪算法
Pure Pursuit算法由R. Wallace于1985年提出，是一种基于几何的路径跟踪方法，通过计算前视距离处目标点对应的曲率来控制转向角[2]。该算法结构简单、鲁棒性强，被广泛应用于移动机器人和自动驾驶车辆。Couetil等人对Pure Pursuit的前视距离参数进行了自适应研究，提出根据车速动态调整前视距离以兼顾稳定性与响应速度[3]。在智能车竞赛中，由于赛道宽度有限且车速较高，通常采用固定前视距离结合转向角限幅、死区滤波和变化率限幅。本项目在传统Pure Pursuit基础上，将视觉色块目标经LUT映射为车体坐标后直接代入PP公式，并增加一阶低通滤波与转向角变化率限幅，有效抑制了单帧抖动导致的转向振荡。
（3）RTK高精度定位
实时动态差分定位（RTK）通过基准站与流动站之间的载波相位差分，可实现厘米级定位精度。双天线RTK进一步利用两天线基线方向直接测量载体航向，摆脱了对运动状态的依赖[6][12]。近年来，低成本RTK模块（如u-blox F9P、和芯星通UM980等）的普及使得小型无人平台也能获得厘米级定位[13]。本项目采用GN43RFA双天线RTK模块，通过纳度整数经纬度差避免浮点精度丢失，将WGS84坐标投影为局部ENU平面坐标，并利用双天线真北航向完成INS坐标系对齐，为视觉/惯导系统提供绝对位置参考。
（4）编码器里程计与差速转向
轮式编码器里程计通过测量左右轮转速差推算车体位移与航向，是移动机器人最基本的定位手段。差速转向模型中，车体角速度与左右轮速度差成正比，与轮距成反比[10]。对于前轮转向+后轮驱动的车辆模型（Ackermann几何），转向角与转弯半径满足R = L / tan(delta)关系。本项目在传统Ackermann转向基础上，引入后轮几何差速助力（基于平行转向运动学公式R = L*cot(2*delta) + sqrt(L^2*csc^2(2*delta) + b^2/4)），将等效转向能力从机械极限25度扩展至约40度，最小转弯半径从1.67m降至约1.2m。
1.3　报告内容与章节安排
本报告共分八章。第一章为引言，概述竞赛背景、任务要求及相关研究现状；第二章介绍系统总体技术方案，包括三核架构与任务调度体系；第三章描述机械结构设计与改造方案；第四章说明自制电路板设计与电源方案；第五章详细阐述微处理器控制软件设计，包括惯性导航、转向控制、速度控制、Pure Pursuit路径跟踪、RTK定位和图像视觉等核心算法；第六章介绍开发工具与调试过程；第七章列出模型车主要技术参数；第八章为结论。报告附有参考文献及程序源代码附录。

第二章　总体技术方案设计
2.1　系统架构
本系统以英飞凌AURIX TC387三核微控制器为核心（通过自制TC387转接板兼容TC377开源库），采用“视觉+惯导+RTK+里程计”多源融合定位体系。三核分工如下：

CPU0主循环采用InterruptTasks_Poll()轮询调度：4ms任务包括IMU采样、转向控制、编码器更新、速度环PID、INS更新、RTK更新、RAM赛道处理；8ms任务包括按键扫描、遥控数据处理、科目三更新；40ms任务包括陀螺仪数据输出、科目三显示、图像显示。低优先级Flash写入通过track_flash_poll()轮询。CPU1等待摄像头帧完成标志scc8660_finish_flag后执行image_trace_HSV()，结果通过全局变量传递给CPU0。
2.2　中断与任务调度体系
系统中断体系基于PIT（周期中断定时器）和EXTI（外部中断）实现。PIT产生1ms基准中断，在interrupt.c的run_4ms_tasks()中按4ms周期依次执行：IMU采样、转向控制、编码器更新、速度PID、INS更新、RAM赛道处理、RTK更新。8ms任务和40ms任务通过计数器分频触发。EXTI中断用于摄像头VSYNC帧同步和UART接收。DMA用于摄像头图像数据传输，减少CPU开销。
2.3　感知-决策-执行闭环（技术方案概要）
系统感知层包括SCC8660摄像头（视觉色块检测）、ASM330LHH六轴IMU（姿态与角速度）、GN43RFA双天线RTK（绝对位置与航向）、左右轮正交编码器（里程计）和转向绝对编码器（角度反馈）。决策层在CPU1上运行HSV色块追踪算法，经LUT查表将视觉目标映射为车体坐标，结合INS航向和RTK位置信息进行路径规划。执行层在CPU0上以4ms周期运行转向PD控制（含陀螺仪前馈和几何差速助力）和速度环增量PID，驱动DRV8701电机控制器。
2.4　本章小结
本章介绍了系统的三核架构分工、中断调度体系和感知-决策-执行闭环。CPU0承担控制与融合任务，CPU1独立运行视觉算法，CPU2预留。下一章将详细介绍机械结构设计与改造方案。

第三章　机械结构设计与改造
3.1　车模平台
本车模采用智能车竞赛四轮车模平台（前轮转向+后轮双电机驱动）。车模进行了以下系统性改装：
1. 主控升级：由原TC264单核升级为TC387三核，通过自制TC387转接板（兼容原核心板插座）实现引脚映射，保留主板原有外设接口。
2. 多传感器融合：新增ASM330LHH六轴IMU（自制陀螺仪板）、GN43RFA双天线RTK模块、IMU963RA九轴模块（LSM6DSRTR+QMC5883L），构建多源融合定位体系。
3. 驱动板自制：设计DRV8701双驱板（后轮）与单驱板（转向），采用光耠隔离（SN74HC125）抑制电机干扰。
4. 电源分配：自制分电板，XT60输入+双路XT30输出，船型开关总控。
5. 人机交互：自制灯光秀+点阵屏板（74HC595驱动）、语音模块（LTK1026D功放+硅麦拓展板）。
车模基本参数：轮胎为10x4.0-6充气轮胎，外径254mm；轴距0.632m；轮距0.60m。

5.2　惯性导航算法（INS）
INS以4ms（250Hz）周期更新，包含三个核心环节：
（1）六轴姿态卡尔曼滤波：roll/pitch由加速度计观测校正，yaw由陀螺仪纯积分。状态更新方程：yaw(k) = yaw(k-1) + (gyro_z - bias) x dt
（2）航向扩展卡尔曼滤波（EKF）：状态量为[yaw, gyro_bias]，预测步使用陀螺仪积分，更新步使用倾斜补偿后的磁力计航向。关键调参：Q_yaw=1e-7，R_mag=5e-2，N_b=5e-5，创新限并0.035rad(2度)，K1限并0.08。实测静态yaw漂移率约1.42度/min（63s静态测试）。
（3）ZUPT零速更新：通过编码器速度阈值（0.00m/s）和陀螺仪阈值（0.08rad/s）检测静止状态，静止时增大bias过程噪声，加速零偏收敛。
编码器位置积分：左右轮位移=脉冲数x周长/2048，车体中心位移取两轮平均，航向由yaw角投影至ENU平面积分。核心函数Ins_update()源码见附录B.1。
5.3　转向控制算法
转向控制采用绝对编码器反馈PD+陀螺仪前馈，4ms周期。控制律：output = Kp x error + Kd x d(error)/dt + Kg x gyro_z
其中error=目标角-当前角（绝对编码器不对称映射），STEER_KP/STEER_KD/STEER_GKD为PD参数。输出限幅后驱动DRV8701（DIR方向+PWM占空比，10kHz）。
几何差速助力：基于平行转向运动学公式 R = L*cot(2*delta) + sqrt(L^2*csc^2(2*delta) + b^2/4)，计算最优轮速比 k_opt = (R+b/2)/(R-b/2)，差速偏移与车速成正比，限幅2脉冲。右转时左轮加速辅助。等效转向能力从25度扩展至约40度。
核心函数steering_control()源码见附录B.2。
5.4　速度控制算法
速度环采用增量式PID，双轮独立控制，4ms周期。增量式PID公式：delta_u = Kp*(e(k)-e(k-1)) + Ki*e(k) + Kd*(e(k)-2*e(k-1)+e(k-2))
当前参数：Kp=0, Ki=20, Kd=0（纯I控制），输出限幅9000。差速偏移通过wheel_pid_set_target_speed()叠加到左右轮目标速度：左轮=target+diff，右轮=target-diff，安全保护防止反转。
核心函数PID_Increase_vLB()源码见附录B.3。
5.5　轨迹录制与循迹算法（Pure Pursuit）
Pure Pursuit路径跟踪算法将LUT得到的车体坐标目标点代入PP公式：curvature = 2*y / ld^2, steer = atan(curvature x L)
其中ld为前视距离（目标点到车体原点距离），L为轴距(0.632m)，y为横向偏移。输出经死区滤波、正负30度限幅、一阶低通滤波（alpha=0.3）和变化率限幅（2.0度/帧）后送至转向控制器。
Flash赛道记忆功能框架已搭建（track_init()、track_flash_poll()），但track_proc()被注释，实际赛道记忆与重放功能未完成调试。
核心函数image_follow_steer()源码见附录B.5。
5.6　RTK 卫星定位
RTK采用GN43RFA双天线模块，10Hz更新。核心处理流程：
1. NMEA解析：gnss_data_parse()解析GGA/VTG语句，提取纳度整数经纬度（避免float精度丢失）、固定质量（4=RTK固定,5=RTK浮点）、卫星数。
2. 双天线航向：antenna_direction_to_yaw_rad()对MAIN到AUX方向做+180度修正（因MAIN到AUX指向车尾，取反得车头航向）。
3. 原点采样：首次定位时收集N个点，剔除离群点，计算平均原点经纬度。
4. ENU投影：经纬度差 x1.113188e-4 m/纳度，转换为局部ENU平面坐标。
5. INS坐标系对齐：以首次有效RTK位置和航向为基准，将ENU坐标旋转至车体前-左坐标系。
核心函数rtk_update()源码见附录B.6。
5.7　图像视觉与色块跟随
视觉系统在CPU1上运行，基于SCC8660总钻风数字摄像头（188x120灰度，8位并行，DMA传输，配置串口UART1）。实测帧率50~100fps，代码支持运行时读取scc8660_fps_value。
HSV高动态色块追踪算法流程：RGB转HSV转换、计算目标色相似度距离图、种子点选取、十字区域扩张、形态学腐蚀迭代、最小外接矩形提取目标中心。该方法对光照变化具有较强鲁棒性。
像素到惯导LUT查表：预先标定11x13网格点（x=20~140步长10，y=10~110步长10），摄像头安装高度7.8cm、俯角60度。每个网格点存储{ins_forward_m, ins_lateral_m}，运行时通过查表将目标像素位置转换为前向距离与横向偏移。LUT数据来源于image_error.c中img2ins_lut[11][13]常量数组。
图像PP跟随：最小前视距离0.10m，转向低通滤波系数0.65，变化率限幅1.0度/帧。
核心函数image_trace_HSV()源码见附录B.4。

3. 惯性导航系统：六轴姿态卡尔曼滤波+航向EKF（陀螺仪/磁力计融合）+编码器里程计，4ms周期更新，支持ZUPT零速修正。

6. 转向与差速控制：绝对编码器反馈PD+陀螺仪前馈，几何差速助力将等效转向从25度扩展至约40度。

存在的问题：
1. INS长时漂移：纯惯导航向随时间累积漂移，磁力计易受车内电机/电流干扰，EKF融合在强磁干扰场景下仍可能跳变。
2. Flash轨迹重构未完成：track.c中Flash存储赛道记忆点功能框架已搭建但track_proc()被注释，实际赛道记忆与重放功能未完成调试。
3. CPU1/CPU2未充分利用：CPU2完全空壳，CPU1仅做视觉处理，三核算力资源浪费。
4. 语音模块未启用：硬件已就绪但软件全部注释，未实现语音控制功能。
5. RTK与INS松耦合：当前RTK仅作为独立位置参考输出，未与INS做紧耦合滤波。
6. 部分参数为估算值：整车重量、尺寸、功耗、电容总量等需实测确认。
改进方向：
1. RTK/INS紧耦合融合：设计EKF将RTK位置/航向作为观测值修正INS累积误差。
2. CPU2启用：将显示、语音、赛道记忆等低优先级任务迁移至CPU2。
3. Flash赛道记忆完善：调试track_proc()实现赛道点自动存储与重放。
4. 语音功能启用：调试访飞ASR语音识别实现语音启动/停止/模式切换。
5. 自适应Pure Pursuit：前视距离随车速动态调整。
6. 磁干扰抑制：增加电机开关状态与磁力计读数关联分析，电机大电流时降低磁力计权重。

B.1 Ins_update() — 惯性导航核心更新函数
文件：code/ins/Ins.c，调用周期：4ms（250Hz）
void Ins_update(const INS_Input *input, float dt_s)
{
    float yaw_gyro = 0.0f;
    uint8_t is_stationary = 0;
 
    if(!s_initialized) return;
    if(!ins_input_is_valid(input, dt_s)) return;
 
    s_kalman_6axis.T = dt_s;
 
    // 1. 六轴姿态卡尔曼更新
    yaw_gyro = ins_kalman_6axis_update(
        imu660.data_Ripen.gyro_x, imu660.data_Ripen.gyro_y,
        input->gyro_z_rad_s,
        imu660.data_Ripen.acc_x, imu660.data_Ripen.acc_y,
        imu660.data_Ripen.acc_z);
 
    // 2. 静止检测（ZUPT）
    is_stationary = ins_is_stationary(input);
 
    // 3. 航向 EKF 预测
    yaw_ekf2_predict(s_kalman_6axis.Uk[2], dt_s, is_stationary);
 
    // 4. 航向 EKF 更新（磁力计观测，含倾斜补偿）
    if(input->mag_valid) {
        float body_roll, body_pitch;
        map_body_attitude_for_mag_compensation(
            s_kalman_6axis.roll, s_kalman_6axis.pitch,
            &body_roll, &body_pitch);
        s_mag_yaw_raw = compute_tilt_compensated_mag_yaw(
            imu660.data_Ripen.mag_x, imu660.data_Ripen.mag_y,
            imu660.data_Ripen.mag_z, body_roll, body_pitch);
        if(!s_mag_initial_yaw_captured) {
            s_initial_mag_yaw = normalize_angle_rad(s_mag_yaw_raw - s_yaw_ekf.x[0]);
            s_mag_initial_yaw_captured = 1;
        }
        s_mag_yaw_rel = normalize_angle_rad(s_mag_yaw_raw - s_initial_mag_yaw);
        s_mag_yaw_rel_filtered = s_config.mag_alpha * s_mag_yaw_rel
            + (1.0f - s_config.mag_alpha) * s_mag_yaw_rel_filtered;
        yaw_ekf2_update(s_mag_yaw_rel_filtered);
    }
 
    // 5. 状态输出
    s_state.yaw = s_yaw_ekf.x[0];
    s_state.roll = s_kalman_6axis.roll;
    s_state.pitch = s_kalman_6axis.pitch;
 
    // 6. 编码器位置积分
    ins_position_update(s_state.yaw, input->delta_left_m, input->delta_right_m);
    s_state.x = s_pos_x;
    s_state.y = s_pos_y;
}
B.2 steering_control() — 转向控制函数
文件：code/control/steering_control.c，调用周期：4ms
void steering_control(void)
{
    float current = steering_get_current_angle();
    float error = g_target_angle - current;
    float derivative = (error - g_last_error) / STEER_CONTROL_DT;
    float output = STEER_KP * error
                 + STEER_KD * derivative
                 + STEER_GKD * imu660.data_Ripen.gyro_z;
    output = func_limit(output, (float)STEER_PWM_MAX);
    int16_t abs_duty = (int16_t)fabsf(output);
    if(output >= 0.0f) gpio_low(STEER_DIR_PIN);
    else               gpio_high(STEER_DIR_PIN);
    pwm_set_duty(STEER_PWM_PIN, (uint16_t)abs_duty);
    g_last_error = error;
 
    // 几何差速助力
    if(g_diff_enabled) {
        float steer_deg = steering_get_current_angle();
        float abs_steer = fabsf(steer_deg);
        if(abs_steer < DIFF_KINEMATIC_DEADZONE_DEG) {
            g_diff_delta = 0.0f;
        } else {
            if(abs_steer > DIFF_KINEMATIC_MAX_STEER_DEG)
                abs_steer = DIFF_KINEMATIC_MAX_STEER_DEG;
            float steer_rad = abs_steer * DEG2RAD;
            float sin_2d = sinf(2.0f * steer_rad);
            if(fabsf(sin_2d) < 1e-6f) {
                g_diff_delta = 0.0f;
            } else {
                float cot_2d = cosf(2*steer_rad) / sin_2d;
                float csc_2d = 1.0f / sin_2d;
                float L = VEHICLE_WHEELBASE_M;
                float b = VEHICLE_TRACK_WIDTH_M;
                float R = L*cot_2d + sqrtf(L*L*csc_2d*csc_2d + b*b*0.25f);
                float k_opt = (R + b*0.5f) / (R - b*0.5f);
                float ratio = (k_opt - 1.0f) / (k_opt + 1.0f);
                float avg_speed = (fabsf(g_state.tick_left)+fabsf(g_state.tick_right))*0.5f;
                float diff_used = avg_speed * ratio * DIFF_KINEMATIC_GAIN;
                if(diff_used > DIFF_KINEMATIC_MAX_DELTA) diff_used = DIFF_KINEMATIC_MAX_DELTA;
                g_diff_delta = (steer_deg > 0) ? diff_used : -diff_used;
            }
        }
    }
}
B.3 PID_Increase_vLB() — 速度环增量PID
文件：code/control/PID.c，调用周期：4ms
void wheel_pid_set_target_speed(int16_t target)
{
    float diff = steering_get_diff_delta();
    float target_l = (float)target + diff;
    float target_r = (float)target - diff;
    if(target >= 0) {
        if(target_l < 0) target_l = 0;
        if(target_r < 0) target_r = 0;
    } else {
        if(target_l > 0) target_l = 0;
        if(target_r > 0) target_r = 0;
    }
    Yao.Target_Speed_L = (int16_t)target_l;
    Yao.Target_Speed_R = (int16_t)target_r;
}
 
float PID_Increase_vLB(PID_INFO *pid_info, float *PID_Parm,
                        float NowPoint, float SetPoint)
{
    float Increase;
    pid_info->iError = SetPoint - NowPoint;
    Increase = PID_Parm[KP] * (pid_info->iError - pid_info->LastError)
             + PID_Parm[KI] * pid_info->iError
             + PID_Parm[KD] * (pid_info->iError - 2*pid_info->LastError + pid_info->PrevError);
    pid_info->PrevError = pid_info->LastError;
    pid_info->LastError = pid_info->iError;
    pid_info->LastData = NowPoint;
    return Increase;
}

float image_follow_steer(void)
{
    float x_local = image_to_ins_xy.ins_forward_m;
    float y_local = image_to_ins_xy.ins_lateral_m;
    float ld = sqrtf(x_local*x_local + y_local*y_local);
    if(ld < IMG_FOLLOW_MIN_LD_M) return 0.0f;
 
    float curvature = 2.0f * y_local / (ld * ld);
    float steer_rad = atanf(curvature * TRACK_WHEELBASE);
    float steer_deg = -steer_rad * RAD2DEG;
 
    if(fabsf(steer_deg) < VEHICLE_STEER_DEADZONE_DEG) steer_deg = 0.0f;
    steer_deg = func_limit(steer_deg, VEHICLE_PP_MAX_STEER_DEG);
 
    s_follow_steer_filt = IMG_FOLLOW_STEER_ALPHA * steer_deg
        + (1.0f - IMG_FOLLOW_STEER_ALPHA) * s_follow_steer_filt;
    if(ld > IMG_FOLLOW_RATE_LIMIT_DIST) {
        s_follow_steer_filt = func_limit(s_follow_steer_filt - s_follow_steer_prev,
                                          IMG_FOLLOW_RATE_LIMIT) + s_follow_steer_prev;
    }
    s_follow_steer_prev = s_follow_steer_filt;
    return s_follow_steer_filt;
}
B.6 rtk_update() — RTK坐标转换与INS对齐
文件：code/rtk/rtk.c，调用周期：4ms
void rtk_update(void)
{
    if(gnss_flag == 0) return;
    gnss_flag = 0;
    if(gnss_data_parse() != 0) return;
 
    int64_t lat_e9 = gnss.lat_e9;
    int64_t lon_e9 = gnss.lon_e9;
    uint8_t fix_q = gnss.fix_quality;
    uint8_t sats = gnss.satellite_used;
 
    if(gnss.antenna_direction_state == 1) {
        s_rtk_state.yaw_true_north = antenna_direction_to_yaw_rad(gnss.antenna_direction);
        s_rtk_state.yaw_valid = 1;
    }
 
    if(s_rtk_origin.is_set == 0 && rtk_is_solution_acceptable(fix_q, sats)) {
        // 原点采样平均
    }
 
    if(s_rtk_origin.is_set) {
        rtk_latlon_to_enu(lat_e9, lon_e9, &s_rtk_state.x_enu, &s_rtk_state.y_enu);
    }
 
    if(!s_is_aligned && pos_valid && yaw_valid) {
        s_align_x_enu_0 = s_rtk_state.x_enu;
        s_align_y_enu_0 = s_rtk_state.y_enu;
        s_align_yaw_0   = s_rtk_state.yaw_true_north;
        s_is_aligned = 1;
    }
    if(s_is_aligned && pos_valid) {
        float dx = s_rtk_state.x_enu - s_align_x_enu_0;
        float dy = s_rtk_state.y_enu - s_align_y_enu_0;
        float sin_t = sinf(s_align_yaw_0), cos_t = cosf(s_align_yaw_0);
        s_rtk_state.x_ins =  sin_t*dx + cos_t*dy;
        s_rtk_state.y_ins = -(cos_t*dx - sin_t*dy);
        s_rtk_state.yaw_ins = rtk_normalize_angle(
            s_rtk_state.yaw_true_north - s_align_yaw_0);
    }
}

static void run_4ms_tasks(float dt_s)
{
    imu_sample_valid = date_handle(&imu_date);
    steering_control();
    encoder_layer_update(dt_s);
    if(Yao.flag_motor_start_user == 1) {
        Yao.OutP_LB += PID_Increase_vLB(&Yao_pid.vLB_pid, param_vLB,
                                         g_state.tick_left, Yao.Target_Speed_L);
        Yao.OutP_RB += PID_Increase_vRB(&Yao_pid.vRB_pid, param_vRB,
                                         g_state.tick_right, Yao.Target_Speed_R);
        Yao.OutP_LB = func_limit(Yao.OutP_LB, param_vLB[3]);
        Yao.OutP_RB = func_limit(Yao.OutP_RB, param_vRB[3]);
        Motor_Ctrl(MOTOR_L, (int32)Yao.OutP_LB);
        Motor_Ctrl(MOTOR_R, (int32)Yao.OutP_RB);
    }
    s_ins_input.v_mps = g_state.speed_average_mps;
    s_ins_input.gyro_z_rad_s = imu660.data_Ripen.gyro_z;
    s_ins_input.delta_left_m = g_state.delta_left_m;
    s_ins_input.delta_right_m = g_state.delta_right_m;
    s_ins_input.omega_rad_s = s_ins_input.v_mps * tanf(steer_rad) / INS_WHEELBASE_M;
    if(imu_sample_valid) Ins_update(&s_ins_input, imu_dt_s);
    ram_track_proc();
    rtk_update();
}
