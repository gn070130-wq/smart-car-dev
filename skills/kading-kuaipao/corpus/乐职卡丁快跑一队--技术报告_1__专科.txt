摘 要
本作品面向第二十一届全国大学生智能汽车竞赛“卡丁快跑组别”，设计并
实现了一款基于英飞凌 TC264D（AURIX TriCore 双核）微控制器的智能车系
统。通过遥控驾驶录制行驶路径（惯导寻迹和摄像头跟随），再由车辆闭环自
主复现；并在此基础上集成了语音识别控制、穿门洞、动作区任务、灯光与喇
叭控制等功能，形成一套按“科目式”组织的运动控制与摄像头跟随。
硬件方面，采用“主控板 + 电机驱动模块 + 灯板 + 硅麦模块”的模块化架
构：主控板以TC264D 最小系统为核心，集成多路电源与摄像头、屏幕、姿态
传感器、舵机、编码器、遥控器、WiFi 等外设接口；电机驱动采用单通道/ 双
通道驱动模块实现双有刷电机功率驱动；灯光系统基于 TLD7002 十六通道
LED 驱动；语音采用英飞凌 IM68A130A 芯片比较放大后送主控ADC 采样。
软件方面，科目一实现遥控惯导寻迹与全闭环回放，回放采用航向PID 闭
环控制转向、速度前馈与积分控制车速、差速辅助转弯，并引入陀螺与编码器
差速的互补融合抑制航向漂移；科目二采用本地 VAD 语音唤醒与讯飞在线语
音识别，实现灯光、喇叭、行驶的语音控制以及门洞穿越与动作区任务；科目
三采用SCC8660 摄像头视觉跟随引导员（颜色识别+ 单目测距），跟随同时记
录路径，倒序闭环回放实现自动返回。
经整机联调与测试，系统各科目功能稳定，路径复现精度与语音识别响应
满足竞赛要求，验证了方案的有效性。

第一章 绪论
1.1 竞赛背景与任务
全国大学生智能汽车竞赛是一项以“立足培养、重在参与、鼓励探索、追求
卓越”为宗旨的全国性学科竞赛，要求参赛队伍以给定的车模平台为基础，自主
设计软硬件，使车辆在特定场地内完成自主行驶任务。竞赛内容综合考查嵌入
式系统、传感器技术、自动控制、机电一体化与软件工程等多学科知识的综合
运用能力。
本组别比赛车模需完成多项任务：在遥控驾驶阶段录制行驶路径，随后由
车辆自主复现该路径；通过语音指令控制灯光、喇叭与行驶动作；完成门洞穿
越与动作区规定动作；最终实现路径的精准追踪。上述任务对车模的运动控制
精度、航向感知能力、语音交互可靠性以及软硬件协同设计均提出了较高要
求。
1.2 主要研究内容
围绕比赛任务，本作品重点开展以下四个方面的工作：
• 高精度路径记忆：以编码器脉冲+IMU 陀螺仪航向+ 舵机角度为路径特
征，遥控录制行驶轨迹，回放时采用航向 PID 闭环与速度前馈 / 积分复合
控制实现高精度复现；
• 语音人机交互：本地VAD 语音活动检测实现低功耗唤醒，讯飞在线语音
识别实现灯光、喇叭、门洞、动作命令的解析与执行；
• 模块化硬件设计：自主设计主控板、电机驱动模块、灯板与硅麦模块，
实现功率驱动、灯光控制与音频采集；
• 分层软件架构：驱动统一管理器 + 应用层按科目组织，配合菜单系统与
参数在线调优，保证系统的可维护性与可扩展性。
第二章 系统总体方案
2.1 需求分析
结合比赛任务，系统需满足以下功能与非功能需求：
• 运动控制：前轮转向 + 后轮双电机驱动，需舵机高精度定位控制与左右
轮差速；
• 路径记忆：录制阶段实时记录轨迹特征，回放阶段闭环复现，需里程与
航向感知；
• 语音交互：语音唤醒+ 在线识别，需音频采集、网络通信与命令执行；
• 灯光控制：远近光、转向、雾灯、双闪等多路灯光，需多通道 LED 驱
动；
• 实时性与可靠性：控制周期短、中断响应及时、外设掉线与失控保护完
备。
2.2 系统总体架构
系统采用“主控板 + 电机驱动模块 + 灯板 + 硅麦模块+姿态传感器”的硬件
架构，以及“底层驱动+ 应用层”的软件架构。主控板完成运算控制与外围接口
管理；单通道 / 双通道驱动模块完成双电机功率驱动；灯板实现多路灯光；硅
麦模块完成语音采集。软件层通过驱动统一管理器集中初始化与启停各硬件，
应用层按科目组织任务逻辑。

第三章 机械结构设计
3.1 车模总体布局
车模采用前轮转向、后轮驱动（后置双直流电机）的四轮布局，转向由舵
机带动前轮实现。整车采用模块化分区安装：主控板与电机驱动模块分层固定
于车身中部，灯板布置于车头方向，硅麦模块靠近车头前部以利于拾音，电池
布置于车身后部并尽量压低重心。
3.2 底盘与驱动结构
后轮由两台有刷直流电机分别驱动，通过左右轮差速配合前轮转向实现灵
活转弯；每台电机同轴安装增量编码器，用于测速与里程累计。舵机内部集成
绝对值编码器，可实时反馈前轮角度。
3.3 机械结构特点
• 模块化安装，便于硬件拆装与维护；
• 编码器与电机同轴刚性连接，减小测量误差；
• 舵机连杆机构简单可靠，转向回中一致性好。
3.4 传感器安装与电路板固定
各传感器按功能就近布置：IMU 安装于车尾的几何中心附近，保证航向积
分与车体一致；左右增量编码器与电机输出轴同轴刚性连接，避免传动间隙引
入测量误差；舵机绝对值编码器集成于舵机内部；硅麦安装于车头前部并朝向
前方，减小风噪并利于拾音；摄像头（SC8660）安装于车尾处用摄像头支架增
高保证视野，用于科目三视觉跟随。
电路板通过铜柱与尼龙螺柱分层固定于车身上，主控板与电机驱动模块上
下叠放并用排线连接，动力线（电机、电池）与控制线（信号、传感器）分开
走线，减小功率回路对控制信号的干扰。各接插件采用防反插设计，便于现场
拆装与维护。

第四章 硬件电路设计
4.1 主控板设计
主控板以TC264D 最小系统为核心，承担全部运算控制与外围接口管理，
分为核心电路、接口电路与电源电路三部分。
4.1.1 接口电路
接口电路覆盖系统全部外设连接需求，具体包括：摄像头接口（逐飞凌瞳
SC8660，用于科目三视觉跟随）、GPS 接口、屏幕接口、按键与拨码开关、姿
态传感器（IMU）接口、电压测量接口、TLD7002 灯板接口（UART2）、舵机
接口、有刷电机接口、硅麦接口、方向编码器接口、遥控器串口（UART2）以
及 WiFi 模块 SPI 接口。各接口按信号类型就近布置，模拟信号（硅麦、电压
测量）与数字信号（串口、SPI）分区走线，减小相互干扰。
4.1.2 电源电路
电源电路提供多路供电：外部电池输入24V 主电源，再经 LDO 产生3.3V
供 MCU 与外设；电机电源独立输出以隔离功率噪声，避免大功率负载对控制
电路的干扰。

第五章 软件系统设计
5.1 软件总体架构
软件采用“底层驱动层 + 应用层”的分层架构。底层驱动层基于逐飞科技
TC264 开源库，封装电机、舵机、编码器、IMU、WiFi、语音等设备驱动；应
用层通过驱动统一管理器集中管理硬件初始化与启停，并按科目组织任务逻
辑。
5.2 驱动统一管理器
驱动统一管理器提供 drv_basic_init（基础硬件）与 drv_all_init（全部比赛
硬件）两级初始化，以及各模块独立的 init/start /stop 接口，避免各科目重复
初始化代码；同时提供 drv_emergency_stop 紧急停车接口，实现电机停转与舵
机回中，保证异常情况下的安全性。
5.3 科目一：全闭环路径寻迹与回放
5.3.1 路径录制
录制阶段遥控驾驶，系统以 20ms 为周期记录一个路径点，每个点 6 字
节，包含编码器脉冲增量、IMU 航向角（度×10）与舵机绝对角度。航向由陀
螺仪积分与编码器差速互补融合得到（陀螺 98%+ 编码器差速 2%），以抑制
陀螺漂移。单次最多记录2730 点，约54.6 秒。
5.3.2 回放控制算法
回放采用“航向闭环+ 速度前馈+ 差速”的复合控制：
• 航向闭环：航向 PID（Kp=1.5、Ki=0.05、Kd=0.5）输出叠加到录制舵机
角度（限幅±200），修正转向偏差；
• 速度控制：以录制里程增量乘以速度前馈系数得到基础占空比，再对里
程误差积分，形成对目标距离的跟踪；
• 差速转弯：按舵机偏离中位的比例对左右轮施加差速，缩小转弯半径；
• 直行防漂移：当舵角接近中位时，若检测到航向偏差则极慢修正陀螺零
点并小幅拉回航向；
• 遥控接管：回放过程中油门或转向偏离寻迹路线防止发生安全问题即切
换为遥控直连，停止巡线。

if(yaw_err < -1800.0f) yaw_err += 3600.0f;
gyro_bias += yaw_err * 0.00005f; // 极慢修正零点
yaw += yaw_err * 0.005f; // 小幅拉回
}
// 航向 PID 闭环修正舵机（叠加限幅 ±200）
PID_SetTarget(&yaw_pid, (float)tg->yaw);
PID_Calc_Inc(&yaw_pid, yaw);
int adj = tg->servo + (int)yaw_pid.out;
if(adj > tg->servo + 200) adj = tg->servo + 200;
if(adj < tg->servo - 200) adj = tg->servo - 200;
servo_target = adj;
// 速度前馈 + 里程积分
int ff = (int)(tg->dist * g_s1_spd_ff_k);
spd_integral += (float)(rec_total - total_dist) * g_s1_spd_int_ki;
cur_duty = ff + (int)spd_integral;
// 差速转弯：按舵角比例分配左右轮
int diff_duty = (int)(cur_duty * diff_norm * g_s1_diff_gain);
motor_set_duty(cur_duty - diff_duty, cur_duty + diff_duty);
