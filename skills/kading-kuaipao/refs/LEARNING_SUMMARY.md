# 【学习摘要】卡丁快跑

## 组别
**第 21 届 · 卡丁快跑**（专科+本科；载人卡丁车模智能化：跟随/录径回放/语音灯光等科目）

## 硬件栈（共识）
| 模块 | 常见选型 |
|------|----------|
| 主控 | **TC387** 多核 / 双 **TC264** / 扩展视觉板 |
| 平台 | 科宇等 **T 型卡丁**；阿克曼转向（舵机或电机+绝对编码器闭环） |
| 感知 | 前视摄像头（跟标志/跟人员）、IMU、轮速编码器 |
| 人机 | 语音（云端 ASR 或离线）、灯组、点阵屏、遥控 |
| 驱动 | 24V 有刷等；制动执行机构（队间差异） |

## 软件架构
多核/多任务：视觉核或扩展板 → 横向偏差/目标 → 转向闭环；录径 Flash 点列 → CTE 回放；语音指令状态机；速度门控多层限速。

## 核心算法
1. 视觉目标/显示板检测与跟随  
2. 路径录制（定距采样）+ CTE 横向纠偏回放  
3. 转向位置式/串级 PID（绝对编码器）  
4. 速度 PID + 多层速度门控  
5. IMU 航向/姿态融合  
6. 语音 ASR + 本地指令匹配  
7. 竞赛多科目状态机  

## 代码锚点
合肥工大宣城「宛陵能行」附件含 `km13_tc387_source`（TC387 工程树，入库 `code_tree/`）。深圳职业技术大学专科长文含较完整架构叙述与算法章节。
